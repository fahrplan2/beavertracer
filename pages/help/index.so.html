Saddexda hab

BeaverTracer wuxuu leeyahay saddex hab. Waxaad u beddeli kartaa iyaga isku-duweysa isticmaalka buttada toolbar-ka sare.

Edit Naqdo shabakaddaada — dhig devices, isku xidhidh, iyaga habayn.
Run Bilow simulation-ka oo daawee traffic-ka dabagalkiisa shabakaddaada.
Trace Qaado oo baarro packets-ka socdaalka shabakaddaada.

Режим редактирования — постройка сети

В режиме редактирования на левой стороне экрана появляется панель инструментов. Выберите инструмент, щелкнув по нему, а затем используйте его на холсте.

Инструменты

Выбрать Щелкните устройство, чтобы открыть его панель. Перетащите устройство, чтобы переместить его.
Ссылка Соедините два устройства кабелем (см. ниже).
Текст Поместите текстовую метку на холст для аннотации вашей диаграммы.
Прямоугольник Нарисуйте прямоугольник на холсте, чтобы визуально сгруппировать устройства.
Удалить Щелкните устройство или кабель, чтобы удалить его.

Совет: Щелкните правой кнопкой мыши в любом месте холста, чтобы отменить текущий инструмент и вернуться к Выбрать.

Размещение устройства

  1. Щелкните кнопку устройства на левой панели инструментов (например, Компьютер).
  2. Предпросмотр следует за курсором мыши.
  3. Щелкните на холсте, чтобы разместить устройство.

Соединение двух устройств

  1. Щелкните инструмент Ссылка.
  2. Щелкните первое устройство — появится средство выбора port. Выберите port.
  3. Переместите мышь на второе устройство и щелкните его — выберите port там тоже.
  4. Кабель создается автоматически.

Ports, которые уже используются, отображаются как отключенные и не могут быть выбраны.

Перемещение устройства

В режиме Выбрать щелкните и перетащите любое устройство, чтобы переместить его на холсте.

Удаление устройства или кабеля

  1. Щелкните инструмент Удалить.
  2. Щелкните устройство или кабель, который вы хотите удалить.

При удалении устройства все подключенные к нему кабели автоматически удаляются.

Devices

Devices yadu ayaa lagu heli karo toolbar bidix inta lagu jiro Edit mode:

Computer Computer leh network interface wired ah. Waxaad ku run kartaa apps-yada (tusaale ahaan web browser ama ping tool) iyo configure kartaa IP address-keeda.
Tablet Sida Computer, balse waxay ku xidhdho Wi-Fi halka ay cable adeegsato. Isticmaal iyada oo la mid ah Access Point ama Home Router.
SW Switch Waxa ay isku xidhdho devices badan oo segment network isku mid ah. Forwards frames saldhig ah MAC addresses. Supports VLANs iyo Spanning Tree Protocol (STP).
RT Router Waxa ay isku xidhdho networks kala duwan iyo forwards packets iyaga dhexdooda. Supports static routes, OSPF, BGP, iyo IP tunnels (VPN).
Home Router Router isku mid ah, DHCP server, NAT gateway iyo Wi-Fi access point — caadi ah sida home internet router. Isku xidh Router-ka (sida WAN) iyo Computer ama Tablets (sida LAN/Wi-Fi). Supports port forwarding rules.
Access Point Waxa ay ballaariyo network wired ah leh Wi-Fi connection. Xidh wired port-keeda Switch ama Router, dabadeedna xidh Tablets iyada oo wireless ah.
Firewall Filters traffic iyada iyada u dhexeysa network segments saldhig ah rules caddaynta leh. Panel-ku waxa ay muujiso rule set iyo live log oo packets la taaban ay.

Gaashaanbarka waaxiga

Dhig waax kasta oo jira canvas-ka si aad u furisho gaashaanbar — daaqad habeynta oo muuqata dhinaca midig ee shaashada. Dhig waaxga mar labaad (ama × batinka ku jira madaxa gaashaanbar) si aad u xidho.

Waax magacaabista

Dhig batinka ku jira magaca waaxga gaashaanbar madaxa si aad magac khaas ah siiso (tusaale ahaan "Office-PC" ama "Core-Router").

Router tabs

Router gaashaanbar waxaa leh tabs soo socda:

  • Interfaces — habeyn IP addresses oo ku jira qof kasta port
  • Routing table IPv4 — daawad iyo edis IPv4 routes (static iyo aqoon la'
  • Routing table IPv6 — daawad iyo edis IPv6 routes
  • OSPF — habeyn iyo daawad OSPF dynamic routing
  • BGP — habeyn BGP neighbours iyo daawad BGP table
  • VPN — habeyn IP tunnels oo u dhexeeya routers

Switch tabs

Switch gaashaanbar waxaa leh tabs Switch Address Table (SAT), VLAN habeynta, iyo Spanning Tree Protocol (STP) settings.

Home Router tabs

Home Router gaashaanbar waxaa leh tabs soo socda:

  • Status — muuqaal dhedig WAN/LAN state iyo clients ku xidhan
  • WAN — habeyn uplink (static IP ama DHCP)
  • LAN — habeyn LAN subnet iyo IP address
  • DHCP — daawad leases firfircoon iyo habeyn DHCP pool
  • WiFi — habeyn access point ku jira (SSID, password)
  • NAT — daawad NAT connection table firfircoon
  • Port Forwarding — qeexid qawaaidka lagu fujiyo ports gudaha LAN hosts

Firewall tabs

Firewall gaashaanbar waxaa leh Rules tab si aad u maareeyso filter rules iyo Log tab muuqaya packets waxa lagu ogolaadday ama tuuray.

Computer iyo Tablet

Computers iyo Tablets waxaa ku jira simulated operating system buuxa gaashaanbar gudahooda. Waxaad furin kartaa apps desktop ka, habeyn network settings, iyo amarro furin.

Hore darbeedka — Fulainta Simulation-ka

Iska bedel Fulin hore si aad u bilowdo simulation-ka. Network-ka wuxuu nool noqonaa: qalabka waxay isku wareejiyaan packets, DHCP leases waxaa la siin karaa, routing tables waxay cusboonaadinayaan, iyo iyo kaloo.

Jooga iyo dib u billow

Jooga Jabjab simulation-ka xaaladdii hadda jirta.
Dib u billow Dib u fulin simulation-ka bilawga ah (dhammaan xaalada firfircoon waxaa la nadiifiyey).

Ogsiin: Ma karaan aad tababarto network topology intaad jirta Run mode. Iska bedel hore Edit mode marka hore.

Trace Mode — Analysing Packets

Switch to Trace mode si aad u furato built-in packet analyser — oo la mid ah Wireshark.

Sare, dooro device iyo port aad dooneyso inaad ka qaadato. Dhammaan packets ee maraya port taas waxaa lagu kaydiyaa oo lagu tusaa liiska.

Click packet kasta oo jira liiska si aad u aragtid fahaminteedu buubuuta: protocol layers, header fields, iyo payload — sidii tool xirfadeed oo network ah ay tusaan lahayd.

Capture-ka wuxuu socda oo isugu taal habka simulation markii uu socdo. Waxaad iska dhex bedelan kartaa Trace mode iyo Run mode waqti kasta oo aan luminin captured data.

Kaydin iyo gelitaanka

Nidaamka network-iga waxaa lagu kaydhin karaa faylka lagu dib gelitaan karaa dib mar kale. Isticmaal buttada ku yaal toolbar-ka sare (ku muuqda Edit mode):

Cusub Bilow canvas madhan. Isbedelka la kaydin waaye ayaa lumici doona.
Gelitaan Fur faylka simulation-ka hore ee la kaydiyey.
Kaydin Ku raji faylka simulation-ka hadda jira computer-kaaga.

Waxaa lagaa cabsanayaa? Hubi in network-iga si sahiih ah loo xidho oo in ay dhammaan devisyada IP addresses oo sax ah lagu qaabayn.

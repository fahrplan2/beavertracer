The Three Modes

Beaver Tracer has three modes. You switch between them using the buttons in the top toolbar.

Edit Design your network — place devices, connect them, configure them.
Run Start the simulation and watch traffic flow through your network.
Trace Capture and inspect the packets travelling across your network.

Edit Mode — Building a Network

In Edit mode, a toolbar appears on the left side of the screen. Select a tool by clicking it, then use it on the canvas.

Tools

Select Click a device to open its panel. Drag a device to move it.
Link Connect two devices with a cable (see below).
Text Place a text label on the canvas to annotate your diagram.
Rectangle Draw a rectangle on the canvas to visually group devices.
Delete Click a device or cable to remove it.

Tip: Right-click anywhere on the canvas to cancel the current tool and return to Select.

Placing a Device

  1. Click a device button in the left toolbar (e.g. PC).
  2. A preview follows your mouse cursor.
  3. Click on the canvas to place the device.

Connecting Two Devices

  1. Click the Link tool.
  2. Click the first device — a port picker appears. Select a port.
  3. Move your mouse to the second device and click it — select a port there too.
  4. The cable is created automatically.

Ports that are already in use are shown as disabled and cannot be selected.

Moving a Device

In Select mode, click and drag any device to reposition it on the canvas.

Deleting a Device or Cable

  1. Click the Delete tool.
  2. Click the device or cable you want to remove.

When you delete a device, all cables connected to it are removed automatically.

Devices

These devices are available in the left toolbar during Edit mode:

PC A personal computer with a wired network interface. You can run apps on it (e.g. a web browser or a ping tool) and configure its IP address.
Laptop Like a PC, but connects via Wi-Fi instead of a cable. Use it together with an Access Point or Home Router.
SW Switch Connects multiple devices in the same network segment. Forwards frames based on MAC addresses. Supports VLANs and Spanning Tree Protocol (STP).
RT Router Connects different networks and forwards packets between them. Supports static routes, OSPF, BGP, and IP tunnels (VPN).
Home Router A combined router, DHCP server, NAT gateway and Wi-Fi access point — similar to a typical home internet router. Connect it to a Router (as WAN) and to PCs or Laptops (as LAN/Wi-Fi). Supports port forwarding rules.
Access Point Extends a wired network with a Wi-Fi connection. Connect its wired port to a Switch or Router, then connect Laptops to it wirelessly.
Firewall Filters traffic between network segments based on configurable rules. The panel shows the rule set and a live log of matched packets.

Device Panels

Click any device on the canvas to open its panel — a configuration window that appears on the right side of the screen. Click the device again (or the × button in the panel header) to close it.

Renaming a Device

Click the button next to the device name in the panel header to give it a custom name (e.g. "Office-PC" or "Core-Router").

Router Tabs

A Router panel has the following tabs:

  • Interfaces — configure IP addresses on each port
  • Routing table IPv4 — view and edit IPv4 routes (static and learned)
  • Routing table IPv6 — view and edit IPv6 routes
  • OSPF — configure and monitor OSPF dynamic routing
  • BGP — configure BGP neighbours and view the BGP table
  • VPN — set up IP tunnels between routers

Switch Tabs

A Switch panel has tabs for its Switch Address Table (SAT), VLAN configuration, and Spanning Tree Protocol (STP) settings.

Home Router Tabs

A Home Router panel has the following tabs:

  • Status — overview of current WAN/LAN state and connected clients
  • WAN — configure the uplink (static IP or DHCP)
  • LAN — configure the LAN subnet and IP address
  • DHCP — view active leases and configure the DHCP pool
  • WiFi — configure the built-in access point (SSID, password)
  • NAT — view the active NAT connection table
  • Port Forwarding — define rules to forward incoming ports to LAN hosts

Firewall Tabs

A Firewall panel has a Rules tab to manage filter rules and a Log tab showing which packets have been allowed or dropped.

PC and Laptop

PCs and Laptops have a full simulated operating system inside their panel. You can open apps from the desktop, configure network settings, and run commands.

Run Mode — Running the Simulation

Switch to Run mode to start the simulation. The network becomes live: devices exchange packets, DHCP leases are assigned, routing tables update, and so on.

Speed Controls

Use the speed buttons in the top toolbar to control how fast the simulation runs:

0.5×Slow — good for observing individual steps
1×Normal speed
4×Fast
8×Very fast

Pause and Reset

Pause Freeze the simulation at its current state.
Reset Restart the simulation from the beginning (all dynamic state is cleared).

Note: You cannot edit the network topology while in Run mode. Switch back to Edit mode first.

Trace Mode — Analysing Packets

Switch to Trace mode to open the built-in packet analyser — similar to Wireshark.

At the top, select the device and port you want to capture from. All packets passing through that port are recorded and shown in a list.

Click on any packet in the list to see its full details: the protocol layers, header fields, and payload — exactly as a professional network tool would show them.

The capture runs automatically while the simulation is running. You can switch between Trace mode and Run mode at any time without losing the captured data.

Saving and Loading

Your network design can be saved as a file and loaded again later. Use the buttons in the top toolbar (visible in Edit mode):

New Start with a blank canvas. Any unsaved changes will be lost.
Load Open a previously saved simulation file.
Save Download the current simulation as a file to your computer.

Having trouble? Check that your network is correctly connected and that all devices have valid IP addresses configured.

Tiga Mode

Beaver Tracer memiliki tiga mode. Anda beralih di antara mereka menggunakan tombol di bilah alat atas.

Edit Rancang jaringan Anda — tempatkan perangkat, hubungkan mereka, konfigurasikan mereka.
Run Mulai simulasi dan saksikan lalu lintas mengalir melalui jaringan Anda.
Trace Tangkap dan inspeksi paket yang melintasi jaringan Anda.

Mode Edit — Membangun Jaringan

Dalam mode Edit, toolbar muncul di sisi kiri layar. Pilih alat dengan mengkliknya, kemudian gunakan di kanvas.

Alat

Pilih Klik perangkat untuk membuka panelnya. Seret perangkat untuk memindahkannya.
Tautan Hubungkan dua perangkat dengan kabel (lihat di bawah).
Teks Letakkan label teks di kanvas untuk menganotasi diagram Anda.
Persegi Panjang Gambar persegi panjang di kanvas untuk mengelompokkan perangkat secara visual.
Hapus Klik perangkat atau kabel untuk menghapusnya.

Tip: Klik kanan di mana saja di kanvas untuk membatalkan alat saat ini dan kembali ke Pilih.

Menempatkan Perangkat

  1. Klik tombol perangkat di toolbar kiri (mis. PC).
  2. Pratinjau mengikuti kursor mouse Anda.
  3. Klik di kanvas untuk menempatkan perangkat.

Menghubungkan Dua Perangkat

  1. Klik alat Tautan.
  2. Klik perangkat pertama — pemilih port muncul. Pilih port.
  3. Pindahkan mouse Anda ke perangkat kedua dan kliknya — pilih port di sana juga.
  4. Kabel dibuat secara otomatis.

Port yang sudah digunakan ditampilkan sebagai dinonaktifkan dan tidak dapat dipilih.

Memindahkan Perangkat

Dalam mode Pilih, klik dan seret perangkat apa pun untuk mengubah posisinya di kanvas.

Menghapus Perangkat atau Kabel

  1. Klik alat Hapus.
  2. Klik perangkat atau kabel yang ingin Anda hapus.

Saat Anda menghapus perangkat, semua kabel yang terhubung padanya akan dihapus secara otomatis.

Perangkat

Perangkat-perangkat ini tersedia di toolbar kiri selama mode Edit:

PC Komputer pribadi dengan antarmuka jaringan berwired. Anda dapat menjalankan aplikasi di dalamnya (misalnya browser web atau alat ping) dan mengonfigurasi alamat IP-nya.
Laptop Seperti PC, tetapi terhubung melalui Wi-Fi alih-alih kabel. Gunakan bersama dengan Access Point atau Home Router.
SW Switch Menghubungkan beberapa perangkat dalam segmen jaringan yang sama. Meneruskan frame berdasarkan alamat MAC. Mendukung VLAN dan Spanning Tree Protocol (STP).
RT Router Menghubungkan jaringan berbeda dan meneruskan paket di antara mereka. Mendukung rute statis, OSPF, BGP, dan terowongan IP (VPN).
Home Router Router gabungan, server DHCP, gateway NAT dan titik akses Wi-Fi — mirip dengan router internet rumah yang khas. Hubungkan ke Router (sebagai WAN) dan ke PC atau Laptop (sebagai LAN/Wi-Fi). Mendukung aturan port forwarding.
Access Point Memperluas jaringan berwired dengan koneksi Wi-Fi. Hubungkan port berwired-nya ke Switch atau Router, lalu hubungkan Laptop ke dalamnya secara nirkabel.
Firewall Memfilter lalu lintas antara segmen jaringan berdasarkan aturan yang dapat dikonfigurasi. Panel menampilkan set aturan dan log langsung paket yang cocok.

Panel Perangkat

Klik perangkat apa pun di kanvas untuk membuka panel-nya — jendela konfigurasi yang muncul di sisi kanan layar. Klik perangkat lagi (atau tombol × di header panel) untuk menutupnya.

Mengubah Nama Perangkat

Klik tombol di sebelah nama perangkat di header panel untuk memberikan nama khusus (misalnya "Office-PC" atau "Core-Router").

Tab Router

Panel Router memiliki tab berikut:

  • Interfaces — konfigurasi alamat IP di setiap port
  • Routing table IPv4 — lihat dan edit rute IPv4 (statis dan learned)
  • Routing table IPv6 — lihat dan edit rute IPv6
  • OSPF — konfigurasi dan monitor perutean dinamis OSPF
  • BGP — konfigurasi tetangga BGP dan lihat tabel BGP
  • VPN — siapkan terowongan IP antara router

Tab Switch

Panel Switch memiliki tab untuk Switch Address Table (SAT), konfigurasi VLAN, dan pengaturan Spanning Tree Protocol (STP).

Tab Home Router

Panel Home Router memiliki tab berikut:

  • Status — ringkasan status WAN/LAN saat ini dan klien yang terhubung
  • WAN — konfigurasi uplink (IP statis atau DHCP)
  • LAN — konfigurasi subnet LAN dan alamat IP
  • DHCP — lihat lease aktif dan konfigurasi pool DHCP
  • WiFi — konfigurasi access point bawaan (SSID, password)
  • NAT — lihat tabel koneksi NAT aktif
  • Port Forwarding — tentukan aturan untuk meneruskan port masuk ke host LAN

Tab Firewall

Panel Firewall memiliki tab Rules untuk mengelola aturan filter dan tab Log yang menunjukkan paket mana yang telah diizinkan atau dijatuhkan.

PC dan Laptop

PC dan Laptop memiliki sistem operasi yang disimulasikan sepenuhnya di dalam panel mereka. Anda dapat membuka aplikasi dari desktop, mengkonfigurasi pengaturan jaringan, dan menjalankan perintah.

Mode Jalankan — Menjalankan Simulasi

Beralih ke mode Jalankan untuk memulai simulasi. Jaringan menjadi aktif: perangkat bertukar paket, lease DHCP ditetapkan, tabel routing diperbarui, dan seterusnya.

Kontrol Kecepatan

Gunakan tombol kecepatan di toolbar atas untuk mengontrol seberapa cepat simulasi berjalan:

0,5×Lambat — bagus untuk mengamati langkah-langkah individual
1×Kecepatan normal
4×Cepat
8×Sangat cepat

Jeda dan Atur Ulang

Jeda Bekukan simulasi pada keadaan saat ini.
Atur Ulang Mulai ulang simulasi dari awal (semua keadaan dinamis dihapus).

Catatan: Anda tidak dapat mengedit topologi jaringan saat dalam mode Jalankan. Beralih kembali ke mode Edit terlebih dahulu.

Mode Trace — Menganalisis Paket

Beralih ke mode Trace untuk membuka penganalisis paket bawaan — mirip dengan Wireshark.

Di bagian atas, pilih perangkat dan port yang ingin Anda tangkap. Semua paket yang melewati port tersebut direkam dan ditampilkan dalam daftar.

Klik pada paket mana pun dalam daftar untuk melihat detail lengkapnya: lapisan protokol, bidang header, dan payload — persis seperti yang ditunjukkan oleh alat jaringan profesional.

Penangkapan berjalan secara otomatis saat simulasi berjalan. Anda dapat beralih antara mode Trace dan mode Run kapan saja tanpa kehilangan data yang tertangkap.

Menyimpan dan Memuat

Desain jaringan Anda dapat disimpan sebagai file dan dimuat lagi nanti. Gunakan tombol di toolbar atas (terlihat dalam mode Edit):

Baru Mulai dengan kanvas kosong. Perubahan apa pun yang belum disimpan akan hilang.
Muat Buka file simulasi yang telah disimpan sebelumnya.
Simpan Unduh simulasi saat ini sebagai file ke komputer Anda.

Mengalami masalah? Pastikan jaringan Anda terhubung dengan benar dan semua perangkat memiliki alamat IP yang valid dikonfigurasi.

Tiga mode

BeaverTracer memiliki tiga mode. Kamu bisa berganti antara mode-mode tersebut menggunakan tombol di toolbar bagian atas.

Edit Rancang jaringanmu — letakkan perangkat, hubungkan mereka, konfigurasi mereka.
Run Mulai simulasi dan lihat traffic mengalir melalui jaringanmu.
Trace Tangkap dan periksa paket yang bepergian melintasi jaringanmu.

Mode edit — membangun jaringan

Dalam mode edit, toolbar muncul di sisi kiri layar. Pilih alat dengan mengkliknya, kemudian gunakan di kanvas.

Alat

Pilih Klik perangkat untuk membuka panelnya. Seret perangkat untuk memindahkannya.
Tautan Hubungkan dua perangkat dengan kabel (lihat di bawah).
Teks Letakkan label teks di kanvas untuk memberi anotasi pada diagram kamu.
Persegi panjang Gambar persegi panjang di kanvas untuk mengelompokkan perangkat secara visual.
Hapus Klik perangkat atau kabel untuk menghapusnya.

Tip: Klik kanan di mana saja di kanvas untuk membatalkan alat saat ini dan kembali ke Pilih.

Menempatkan perangkat

  1. Klik tombol perangkat di toolbar kiri (misalnya Komputer).
  2. Pratinjau mengikuti kursor mouse kamu.
  3. Klik di kanvas untuk menempatkan perangkat.

Menghubungkan dua perangkat

  1. Klik alat Tautan.
  2. Klik perangkat pertama — pemilih port muncul. Pilih port.
  3. Gerakkan mouse kamu ke perangkat kedua dan kliknya — pilih port di sana juga.
  4. Kabel dibuat secara otomatis.

Port yang sudah digunakan ditampilkan sebagai dinonaktifkan dan tidak dapat dipilih.

Memindahkan perangkat

Dalam mode Pilih, klik dan seret perangkat apa pun untuk memposisikan ulang di kanvas.

Menghapus perangkat atau kabel

  1. Klik alat Hapus.
  2. Klik perangkat atau kabel yang ingin kamu hapus.

Ketika kamu menghapus perangkat, semua kabel yang terhubung dengannya dihapus secara otomatis.

Perangkat

Perangkat-perangkat ini tersedia di toolbar kiri selama mode Edit:

Komputer Sebuah komputer dengan antarmuka jaringan berkabel. Kamu dapat menjalankan aplikasi di atasnya (misalnya peramban web atau alat ping) dan mengonfigurasi alamat IP-nya.
Tablet Seperti Komputer, tetapi terhubung melalui Wi-Fi daripada kabel. Gunakan bersama Access Point atau Home Router.
SW Switch Menghubungkan beberapa perangkat dalam segmen jaringan yang sama. Meneruskan frame berdasarkan alamat MAC. Mendukung VLAN dan Spanning Tree Protocol (STP).
RT Router Menghubungkan jaringan yang berbeda dan meneruskan paket di antaranya. Mendukung rute statis, OSPF, BGP, dan terowongan IP (VPN).
Home Router Router gabungan, server DHCP, gateway NAT dan titik akses Wi-Fi — mirip dengan router internet rumah pada umumnya. Hubungkan ke Router (sebagai WAN) dan ke Komputer atau Tablet (sebagai LAN/Wi-Fi). Mendukung aturan port forwarding.
Access Point Memperluas jaringan berkabel dengan koneksi Wi-Fi. Hubungkan port berkabelnya ke Switch atau Router, kemudian sambungkan Tablet secara nirkabel.
Firewall Menyaring lalu lintas antara segmen jaringan berdasarkan aturan yang dapat dikonfigurasi. Panel menampilkan kumpulan aturan dan log langsung paket yang cocok.

Panel perangkat

Klik perangkat apa pun di kanvas untuk membuka panelnya — jendela konfigurasi yang muncul di sisi kanan layar. Klik perangkat lagi (atau tombol × di header panel) untuk menutupnya.

Mengganti nama perangkat

Klik tombol di sebelah nama perangkat di header panel untuk memberinya nama khusus (misalnya "Office-PC" atau "Core-Router").

Tab router

Panel Router memiliki tab berikut:

  • Interfaces — konfigurasi alamat IP pada setiap port
  • Routing table IPv4 — lihat dan edit rute IPv4 (statis dan yang dipelajari)
  • Routing table IPv6 — lihat dan edit rute IPv6
  • OSPF — konfigurasi dan pantau routing dinamis OSPF
  • BGP — konfigurasi neighbor BGP dan lihat tabel BGP
  • VPN — siapkan tunnel IP antar router

Tab switch

Panel Switch memiliki tab untuk Switch Address Table (SAT), konfigurasi VLAN, dan pengaturan Spanning Tree Protocol (STP).

Tab home router

Panel Home Router memiliki tab berikut:

  • Status — gambaran umum keadaan WAN/LAN saat ini dan klien yang terhubung
  • WAN — konfigurasi uplink (IP statis atau DHCP)
  • LAN — konfigurasi subnet LAN dan alamat IP
  • DHCP — lihat lease aktif dan konfigurasi pool DHCP
  • WiFi — konfigurasi access point bawaan (SSID, password)
  • NAT — lihat tabel koneksi NAT aktif
  • Port Forwarding — tentukan aturan untuk meneruskan port masuk ke host LAN

Tab firewall

Panel Firewall memiliki tab Rules untuk mengelola aturan filter dan tab Log yang menampilkan paket mana yang telah diizinkan atau dijatuhkan.

Komputer dan tablet

Komputer dan Tablet memiliki sistem operasi yang disimulasikan sepenuhnya di dalam panelnya. Kamu bisa membuka aplikasi dari desktop, mengonfigurasi pengaturan jaringan, dan menjalankan perintah.

Mode jalankan — menjalankan simulasi

Beralih ke mode Jalankan untuk memulai simulasi. Jaringan menjadi aktif: perangkat bertukar paket, lease DHCP diberikan, tabel routing diperbarui, dan sebagainya.

Kontrol kecepatan

Gunakan tombol kecepatan di bilah alat atas untuk mengontrol seberapa cepat simulasi berjalan:

0,5×Lambat — bagus untuk mengamati langkah-langkah individual
1×Kecepatan normal
4×Cepat
8×Sangat cepat

Jeda dan setel ulang

Jeda Bekukan simulasi dalam keadaan saat ini.
Setel ulang Mulai ulang simulasi dari awal (semua status dinamis dihapus).

Catatan: Kamu tidak dapat mengedit topologi jaringan saat dalam mode Jalankan. Beralih kembali ke mode Edit terlebih dahulu.

Mode pelacakan — Menganalisis paket

Beralih ke mode Trace untuk membuka penganalisis paket bawaan — mirip dengan Wireshark.

Di bagian atas, pilih perangkat dan port yang ingin kamu tangkap. Semua paket yang melewati port tersebut dicatat dan ditampilkan dalam daftar.

Klik pada paket apa pun dalam daftar untuk melihat detailnya secara lengkap: lapisan protokol, bidang header, dan payload — persis seperti yang ditampilkan oleh alat jaringan profesional.

Tangkapan berjalan secara otomatis saat simulasi sedang berjalan. Kamu dapat beralih antara mode Trace dan mode Run kapan saja tanpa kehilangan data yang ditangkap.

Menyimpan dan memuat

Desain jaringanmu dapat disimpan sebagai file dan dimuat kembali nanti. Gunakan tombol di toolbar atas (terlihat dalam mode Edit):

Baru Mulai dengan kanvas kosong. Perubahan apa pun yang belum disimpan akan hilang.
Muat Buka file simulasi yang telah disimpan sebelumnya.
Simpan Unduh simulasi saat ini sebagai file ke komputermu.

Mengalami masalah? Pastikan jaringan kamu terhubung dengan benar dan semua perangkat memiliki alamat IP yang valid yang dikonfigurasi.

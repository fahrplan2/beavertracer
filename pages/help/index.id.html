Tiga Mode

Beaver Tracer memiliki tiga mode. Anda beralih di antara mereka menggunakan tombol di bilah alat atas.

Edit Rancang jaringan Anda — letakkan perangkat, hubungkan mereka, konfigurasi mereka.
Jalankan Mulai simulasi dan lihat lalu lintas mengalir melalui jaringan Anda.
Lacak Tangkap dan periksa paket yang bepergian di seluruh jaringan Anda.

Mode Edit — Membangun Jaringan

Dalam mode Edit, bilah alat muncul di sisi kiri layar. Pilih alat dengan mengkliknya, lalu gunakan di kanvas.

Alat

Pilih Klik perangkat untuk membuka panelnya. Seret perangkat untuk memindahkannya.
Hubung Hubungkan dua perangkat dengan kabel (lihat di bawah).
Teks Tempatkan label teks di kanvas untuk memberikan anotasi pada diagram Anda.
Persegi Panjang Gambar persegi panjang di kanvas untuk mengelompokkan perangkat secara visual.
Hapus Klik perangkat atau kabel untuk menghapusnya.

Tips: Klik kanan di mana pun pada kanvas untuk membatalkan alat saat ini dan kembali ke Pilih.

Menempatkan Perangkat

  1. Klik tombol perangkat di bilah alat kiri (mis. PC).
  2. Pratinjau mengikuti kursor mouse Anda.
  3. Klik pada kanvas untuk menempatkan perangkat.

Menghubungkan Dua Perangkat

  1. Klik alat Hubung.
  2. Klik perangkat pertama — pemilih port muncul. Pilih port.
  3. Pindahkan mouse ke perangkat kedua dan kliknya — pilih port di sana juga.
  4. Kabel dibuat secara otomatis.

Port yang sudah digunakan ditampilkan sebagai dinonaktifkan dan tidak dapat dipilih.

Memindahkan Perangkat

Dalam mode Pilih, klik dan seret perangkat apa pun untuk mengubah posisinya di kanvas.

Menghapus Perangkat atau Kabel

  1. Klik alat Hapus.
  2. Klik perangkat atau kabel yang ingin Anda hapus.

Ketika Anda menghapus perangkat, semua kabel yang terhubung kepadanya otomatis dihapus.

Perangkat

Perangkat ini tersedia di bilah alat kiri selama mode Edit:

PC Komputer pribadi dengan antarmuka jaringan berkabel. Anda dapat menjalankan aplikasi di dalamnya (mis. web browser atau alat ping) dan mengonfigurasi alamat IP-nya.
Laptop Seperti PC, tetapi terhubung melalui Wi-Fi bukan kabel. Gunakan bersama dengan Access Point atau Home Router.
SW Switch Menghubungkan banyak perangkat dalam segmen jaringan yang sama. Meneruskan frame berdasarkan alamat MAC. Mendukung VLAN dan Spanning Tree Protocol (STP).
RT Router Menghubungkan jaringan berbeda dan meneruskan paket di antara mereka. Mendukung rute statis, OSPF, BGP, dan terowongan IP (VPN).
Home Router Router gabungan, server DHCP, gateway NAT dan access point Wi-Fi — mirip dengan router internet rumah khas. Hubungkan ke Router (sebagai WAN) dan ke PC atau Laptop (sebagai LAN/Wi-Fi). Mendukung aturan port forwarding.
Access Point Memperluas jaringan berkabel dengan koneksi Wi-Fi. Hubungkan port berkabelnya ke Switch atau Router, lalu hubungkan Laptop ke dalamnya secara nirkabel.
Firewall Memfilter lalu lintas antara segmen jaringan berdasarkan aturan yang dapat dikonfigurasi. Panel menampilkan set aturan dan log langsung paket yang cocok.

Panel Perangkat

Klik perangkat apa pun di kanvas untuk membuka panelnya — jendela konfigurasi yang muncul di sisi kanan layar. Klik perangkat lagi (atau tombol × di header panel) untuk menutupnya.

Mengganti Nama Perangkat

Klik tombol di sebelah nama perangkat di header panel untuk memberikan nama khusus (mis. "Office-PC" atau "Core-Router").

Tab Router

Panel Router memiliki tab berikut:

  • Antarmuka — konfigurasi alamat IP pada setiap port
  • Tabel Routing IPv4 — lihat dan edit rute IPv4 (statis dan dipelajari)
  • Tabel Routing IPv6 — lihat dan edit rute IPv6
  • OSPF — konfigurasi dan pantau perutean dinamis OSPF
  • BGP — konfigurasi tetangga BGP dan lihat tabel BGP
  • VPN — siapkan terowongan IP antara router

Tab Switch

Panel Switch memiliki tab untuk Switch Address Table (SAT), konfigurasi VLAN, dan pengaturan Spanning Tree Protocol (STP).

Tab Home Router

Panel Home Router memiliki tab berikut:

  • Status — gambaran umum keadaan WAN/LAN saat ini dan klien yang terhubung
  • WAN — konfigurasi uplink (IP statis atau DHCP)
  • LAN — konfigurasi subnet LAN dan alamat IP
  • DHCP — lihat lease aktif dan konfigurasi pool DHCP
  • WiFi — konfigurasi access point bawaan (SSID, password)
  • NAT — lihat tabel koneksi NAT aktif
  • Port Forwarding — tentukan aturan untuk meneruskan port masuk ke host LAN

Tab Firewall

Panel Firewall memiliki tab Aturan untuk mengelola aturan filter dan tab Log yang menampilkan paket mana yang telah diizinkan atau ditolak.

PC dan Laptop

PC dan Laptop memiliki sistem operasi yang disimulasikan sepenuhnya di dalam panelnya. Anda dapat membuka aplikasi dari desktop, mengonfigurasi pengaturan jaringan, dan menjalankan perintah.

Mode Jalankan — Menjalankan Simulasi

Beralih ke mode Jalankan untuk memulai simulasi. Jaringan menjadi aktif: perangkat menukar paket, lease DHCP diberikan, tabel routing diperbarui, dan seterusnya.

Kontrol Kecepatan

Gunakan tombol kecepatan di bilah alat atas untuk mengontrol seberapa cepat simulasi berjalan:

0,5×Lambat — bagus untuk mengamati langkah individual
1×Kecepatan normal
4×Cepat
8×Sangat cepat

Jeda dan Reset

Jeda Bekukan simulasi pada keadaan saat ini.
Reset Mulai ulang simulasi dari awal (semua keadaan dinamis dihapus).

Catatan: Anda tidak dapat mengedit topologi jaringan saat dalam mode Jalankan. Beralih kembali ke mode Edit terlebih dahulu.

Mode Lacak — Menganalisis Paket

Beralih ke mode Lacak untuk membuka penganalisis paket bawaan — mirip dengan Wireshark.

Di bagian atas, pilih perangkat dan port yang ingin Anda tangkap dari. Semua paket yang melewati port itu dicatat dan ditampilkan dalam daftar.

Klik pada paket apa pun dalam daftar untuk melihat detail lengkapnya: lapisan protokol, bidang header, dan payload — persis seperti yang ditunjukkan alat jaringan profesional.

Penangkapan berjalan otomatis saat simulasi berjalan. Anda dapat beralih antara mode Lacak dan mode Jalankan kapan saja tanpa kehilangan data

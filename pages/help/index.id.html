Tiga Mode

Beaver Tracer memiliki tiga mode. Anda beralih di antara mereka menggunakan tombol di toolbar atas.

Edit Rancang jaringan Anda — letakkan perangkat, hubungkan, dan konfigurasi.
Jalankan Mulai simulasi dan tonton lalu lintas mengalir melalui jaringan Anda.
Trace Tangkap dan periksa paket yang berpindah di jaringan Anda.

Mode Edit — Membangun Jaringan

Dalam mode Edit, toolbar muncul di sisi kiri layar. Pilih alat dengan mengkliknya, lalu gunakan pada kanvas.

Alat

Pilih Klik perangkat untuk membuka panelnya. Seret perangkat untuk memindahkannya.
Hubung Hubungkan dua perangkat dengan kabel (lihat di bawah).
Hapus Klik perangkat atau kabel untuk menghapusnya.

Tip: Klik kanan di mana saja pada kanvas untuk membatalkan alat saat ini dan kembali ke Pilih.

Menempatkan Perangkat

  1. Klik tombol perangkat di toolbar kiri (misalnya PC).
  2. Pratinjau mengikuti kursor mouse Anda.
  3. Klik pada kanvas untuk menempatkan perangkat.

Menghubungkan Dua Perangkat

  1. Klik alat Hubung.
  2. Klik perangkat pertama — pemilih port muncul. Pilih port.
  3. Pindahkan mouse Anda ke perangkat kedua dan kliknya — pilih port di sana juga.
  4. Kabel dibuat secara otomatis.

Port yang sudah digunakan ditampilkan sebagai dinonaktifkan dan tidak dapat dipilih.

Memindahkan Perangkat

Dalam mode Pilih, klik dan seret perangkat apa pun untuk memposisikan ulang di kanvas.

Menghapus Perangkat atau Kabel

  1. Klik alat Hapus.
  2. Klik perangkat atau kabel yang ingin Anda hapus.

Saat Anda menghapus perangkat, semua kabel yang terhubung padanya dihapus secara otomatis.

Perangkat

Perangkat ini tersedia di toolbar kiri selama mode Edit:

PC Komputer pribadi dengan antarmuka jaringan berkabel. Anda dapat menjalankan aplikasi di dalamnya (misalnya browser web atau alat ping) dan mengonfigurasi alamat IP-nya.
Laptop Seperti PC, tetapi terhubung melalui Wi-Fi bukan kabel. Gunakan bersama Access Point atau Home Router.
SW Switch Menghubungkan beberapa perangkat dalam segmen jaringan yang sama. Meneruskan frame berdasarkan alamat MAC. Mendukung VLAN dan Spanning Tree Protocol (STP).
RT Router Menghubungkan jaringan berbeda dan meneruskan paket di antara mereka. Anda dapat mengonfigurasi rute statis dan alamat IP di setiap antarmuka.
Home Router Router gabungan, server DHCP, gateway NAT, dan access point Wi-Fi — mirip dengan router internet rumah biasa. Hubungkan ke Router (sebagai WAN) dan ke PC atau Laptop (sebagai LAN/Wi-Fi).
Access Point Memperluas jaringan berkabel dengan koneksi Wi-Fi. Hubungkan port berakatnya ke Switch atau Router, kemudian hubungkan Laptop ke dalamnya secara nirkabel.

Panel Perangkat

Klik perangkat apa pun pada kanvas untuk membuka panelnya — jendela konfigurasi yang muncul di sisi kanan layar. Klik perangkat lagi (atau tombol × di header panel) untuk menutupnya.

Mengganti Nama Perangkat

Klik tombol di samping nama perangkat di header panel untuk memberinya nama khusus (misalnya "Office-PC" atau "Core-Router").

Tab

Sebagian besar perangkat memiliki beberapa tab di dalam panel. Misalnya, Router memiliki:

  • Antarmuka — konfigurasi alamat IP di setiap port
  • Tabel Routing IPv4 — lihat dan edit rute statis IPv4
  • Tabel Routing IPv6 — lihat dan edit rute statis IPv6

Switch memiliki tab untuk Tabel Alamat Switch (SAT), konfigurasi VLAN, dan pengaturan Spanning Tree Protocol (STP).

Home Router memiliki tab untuk Status, pengaturan WAN, dan lease DHCP.

PC dan Laptop

PC dan Laptop memiliki sistem operasi simulasi penuh di dalam panelnya. Anda dapat membuka aplikasi dari desktop, mengonfigurasi pengaturan jaringan, dan menjalankan perintah.

Mode Jalankan — Menjalankan Simulasi

Beralih ke mode Jalankan untuk memulai simulasi. Jaringan menjadi aktif: perangkat menukar paket, lease DHCP diberikan, tabel routing diperbarui, dan sebagainya.

Kontrol Kecepatan

Gunakan tombol kecepatan di toolbar atas untuk mengontrol seberapa cepat simulasi berjalan:

0.5×Lambat — bagus untuk mengamati langkah individual
1×Kecepatan normal
4×Cepat
8×Sangat cepat

Jeda dan Reset

Jeda Bekukan simulasi pada status saat ini.
Reset Mulai ulang simulasi dari awal (semua status dinamis dihapus).

Catatan: Anda tidak dapat mengedit topologi jaringan saat dalam mode Jalankan. Beralih kembali ke mode Edit terlebih dahulu.

Mode Trace — Menganalisis Paket

Beralih ke mode Trace untuk membuka penganalisis paket bawaan — mirip dengan Wireshark.

Di bagian atas, pilih perangkat dan port yang ingin Anda tangkap. Semua paket yang melewati port itu dicatat dan ditampilkan dalam daftar.

Klik paket apa pun dalam daftar untuk melihat detail lengkapnya: lapisan protokol, bidang header, dan payload — seperti yang ditunjukkan alat jaringan profesional.

Penangkapan berjalan otomatis saat simulasi berjalan. Anda dapat beralih antara mode Trace dan mode Jalankan kapan saja tanpa kehilangan data yang ditangkap.

Menyimpan dan Memuat

Desain jaringan Anda dapat disimpan sebagai file dan dimuat lagi nanti. Gunakan tombol di toolbar atas (terlihat dalam mode Edit):

Baru Mulai dengan kanvas kosong. Perubahan yang belum disimpan akan hilang.
Muat Buka file simulasi yang disimpan sebelumnya.
Simpan Unduh simulasi saat ini sebagai file ke komputer Anda.

Mengalami kesulitan? Periksa bahwa jaringan Anda terhubung dengan benar dan semua perangkat memiliki alamat IP yang valid yang dikonfigurasi.

세 가지 모드

Beaver Tracer에는 세 가지 모드가 있습니다. 상단 도구 모음의 버튼을 사용하여 모드를 전환합니다.

편집 네트워크를 설계합니다 — 장치를 배치하고, 연결하고, 구성합니다.
실행 시뮬레이션을 시작하고 네트워크를 통한 트래픽 흐름을 관찰합니다.
추적 네트워크를 통해 이동하는 패킷을 캡처하고 검사합니다.

편집 모드 — 네트워크 구축

편집 모드에서는 화면 왼쪽에 도구 모음이 나타납니다. 도구를 클릭하여 선택한 다음 캔버스에서 사용합니다.

도구

선택 장치를 클릭하여 해당 패널을 엽니다. 장치를 드래그하여 이동합니다.
연결 두 장치를 케이블로 연결합니다 (아래 참조).
삭제 장치 또는 케이블을 클릭하여 제거합니다.

팁: 캔버스의 아무 곳이나 마우스 오른쪽 버튼을 클릭하여 현재 도구를 취소하고 선택으로 돌아갑니다.

장치 배치

  1. 왼쪽 도구 모음에서 장치 버튼을 클릭합니다 (예: PC).
  2. 미리보기가 마우스 커서를 따릅니다.
  3. 캔버스를 클릭하여 장치를 배치합니다.

두 장치 연결

  1. 연결 도구를 클릭합니다.
  2. 첫 번째 장치를 클릭합니다 — 포트 선택기가 나타납니다. 포트를 선택합니다.
  3. 마우스를 두 번째 장치로 이동하고 클릭합니다 — 여기서도 포트를 선택합니다.
  4. 케이블이 자동으로 생성됩니다.

이미 사용 중인 포트는 비활성화되어 표시되며 선택할 수 없습니다.

장치 이동

선택 모드에서 장치를 클릭하고 드래그하여 캔버스에서 위치를 변경합니다.

장치 또는 케이블 삭제

  1. 삭제 도구를 클릭합니다.
  2. 제거하려는 장치 또는 케이블을 클릭합니다.

장치를 삭제하면 연결된 모든 케이블도 자동으로 제거됩니다.

장치

편집 모드 중에 왼쪽 도구 모음에서 사용할 수 있는 장치는 다음과 같습니다:

PC 유선 네트워크 인터페이스가 있는 개인용 컴퓨터입니다. 앱을 실행하고 (예: 웹 브라우저 또는 ping 도구) IP 주소를 구성할 수 있습니다.
노트북 PC와 비슷하지만 케이블 대신 Wi-Fi를 통해 연결합니다. 액세스 포인트 또는 홈 라우터와 함께 사용합니다.
SW 스위치 동일한 네트워크 세그먼트의 여러 장치를 연결합니다. MAC 주소를 기반으로 프레임을 전달합니다. VLAN 및 스패닝 트리 프로토콜(STP)을 지원합니다.
RT 라우터 다양한 네트워크를 연결하고 패킷을 그 사이에서 전달합니다. 각 인터페이스에서 정적 경로 및 IP 주소를 구성할 수 있습니다.
홈 라우터 라우터, DHCP 서버, NAT 게이트웨이 및 Wi-Fi 액세스 포인트를 결합합니다 — 일반적인 가정용 인터넷 라우터와 유사합니다. 라우터에 연결(WAN)하고 PC 또는 노트북에 연결(LAN/Wi-Fi)합니다.
액세스 포인트 유선 네트워크를 Wi-Fi 연결로 확장합니다. 유선 포트를 스위치 또는 라우터에 연결한 다음 노트북을 무선으로 연결합니다.

장치 패널

캔버스의 장치를 클릭하여 패널을 엽니다 — 화면 오른쪽에 나타나는 구성 창입니다. 장치를 다시 클릭하거나(또는 패널 헤더의 × 버튼) 닫습니다.

장치 이름 바꾸기

패널 헤더의 장치 이름 옆에 있는 버튼을 클릭하여 사용자 정의 이름을 지정합니다 (예: "Office-PC" 또는 "Core-Router").

탭

대부분의 장치에는 패널 내에 여러 탭이 있습니다. 예를 들어 라우터에는 다음이 있습니다:

  • 인터페이스 — 각 포트에서 IP 주소 구성
  • 라우팅 테이블 IPv4 — IPv4 정적 경로 보기 및 편집
  • 라우팅 테이블 IPv6 — IPv6 정적 경로 보기 및 편집

스위치에는 스위치 주소 테이블(SAT), VLAN 구성 및 스패닝 트리 프로토콜(STP) 설정 탭이 있습니다.

홈 라우터에는 상태, WAN 설정 및 DHCP 임대 탭이 있습니다.

PC 및 노트북

PC와 노트북에는 패널 내부에 완전히 시뮬레이션된 운영 체제가 있습니다. 데스크톱에서 앱을 열고, 네트워크 설정을 구성하고, 명령을 실행할 수 있습니다.

실행 모드 — 시뮬레이션 실행

실행 모드로 전환하여 시뮬레이션을 시작합니다. 네트워크가 활성화됩니다: 장치가 패킷을 교환하고, DHCP 임대가 할당되고, 라우팅 테이블이 업데이트되는 등의 작업이 진행됩니다.

속도 제어

상단 도구 모음의 속도 버튼을 사용하여 시뮬레이션 속도를 제어합니다:

0.5×느림 — 개별 단계를 관찰하기에 좋음
1×정상 속도
4×빠름
8×매우 빠름

일시 중지 및 재설정

일시 중지 시뮬레이션을 현재 상태에서 멈춥니다.
재설정 시뮬레이션을 처음부터 다시 시작합니다 (모든 동적 상태가 지워집니다).

참고: 실행 모드에서는 네트워크 토폴로지를 편집할 수 없습니다. 먼저 편집 모드로 전환하세요.

추적 모드 — 패킷 분석

추적 모드로 전환하여 내장된 패킷 분석기를 엽니다 — Wireshark와 유사합니다.

상단에서 캡처할 장치 및 포트를 선택합니다. 해당 포트를 통과하는 모든 패킷이 기록되고 목록에 표시됩니다.

목록의 패킷을 클릭하여 전체 세부 정보

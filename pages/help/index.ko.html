세 가지 모드

Beaver Tracer는 세 가지 모드를 가지고 있습니다. 상단 도구 모음의 버튼을 사용하여 모드를 전환합니다.

편집 네트워크를 설계해 보세요 — 장치를 배치하고, 연결하고, 설정합니다.
실행 시뮬레이션을 시작하고 네트워크를 통해 트래픽이 흐르는 것을 관찰하세요.
추적 네트워크를 통해 이동하는 패킷을 캡처하고 검사합니다.

편집 모드 — 네트워크 구축

편집 모드에서는 화면의 왼쪽에 도구 모음이 나타납니다. 도구를 클릭하여 선택한 다음 캔버스에서 사용하세요.

도구

선택 기기를 클릭하여 패널을 열어요. 기기를 드래그하여 이동시켜요.
연결 케이블로 두 기기를 연결해요 (아래 참고).
텍스트 캔버스에 텍스트 레이블을 배치하여 다이어그램에 주석을 달아요.
직사각형 캔버스에 직사각형을 그려서 기기들을 시각적으로 그룹화해요.
삭제 기기나 케이블을 클릭하여 제거해요.

팁: 캔버스의 아무 곳이나 오른쪽 클릭하면 현재 도구가 취소되고 선택으로 돌아가요.

기기 배치하기

  1. 왼쪽 도구 모음의 기기 버튼을 클릭해요 (예: PC).
  2. 미리보기가 마우스 커서를 따라다녀요.
  3. 캔버스를 클릭하여 기기를 배치해요.

두 기기 연결하기

  1. 연결 도구를 클릭해요.
  2. 첫 번째 기기를 클릭하면 포트 선택기가 나타나요. 포트를 선택해요.
  3. 마우스를 두 번째 기기로 이동한 후 클릭해요 — 거기서도 포트를 선택해요.
  4. 케이블이 자동으로 생성돼요.

이미 사용 중인 포트는 비활성화되어 표시되고 선택할 수 없어요.

기기 이동하기

선택 모드에서 기기를 클릭하고 드래그하여 캔버스에서 위치를 변경해요.

기기나 케이블 삭제하기

  1. 삭제 도구를 클릭해요.
  2. 제거하려는 기기나 케이블을 클릭해요.

기기를 삭제하면 연결된 모든 케이블이 자동으로 제거돼요.

장치

편집 모드 중에 왼쪽 도구 모음에서 이러한 장치들을 사용할 수 있습니다:

PC 유선 네트워크 인터페이스가 있는 개인용 컴퓨터입니다. 앱을 실행할 수 있고 (예: 웹 브라우저 또는 핑 도구) IP 주소를 설정할 수 있습니다.
Laptop PC와 같지만 케이블 대신 Wi-Fi를 통해 연결됩니다. Access Point 또는 Home Router와 함께 사용합니다.
SW Switch 같은 네트워크 세그먼트의 여러 장치를 연결합니다. MAC 주소 기반으로 프레임을 전달합니다. VLAN과 스패닝 트리 프로토콜(STP)을 지원합니다.
RT Router 다양한 네트워크를 연결하고 패킷을 전달합니다. 정적 라우트, OSPF, BGP, IP 터널(VPN)을 지원합니다.
Home Router 라우터, DHCP 서버, NAT 게이트웨이, Wi-Fi 액세스 포인트가 결합된 장치입니다. 일반적인 가정용 인터넷 라우터와 비슷합니다. Router에 연결하고(WAN으로) PC나 Laptop에도 연결합니다(LAN/Wi-Fi로). 포트 포워딩 규칙을 지원합니다.
Access Point 유선 네트워크를 Wi-Fi 연결로 확장합니다. 유선 포트를 Switch나 Router에 연결한 후, Laptop을 무선으로 연결합니다.
Firewall 설정 가능한 규칙에 따라 네트워크 세그먼트 간의 트래픽을 필터링합니다. 패널에서 규칙 집합과 일치하는 패킷의 실시간 로그를 보여줍니다.

장치 패널

캔버스의 장치를 클릭하면 화면 오른쪽에 나타나는 패널 — 설정 창이 열린다. 해당 장치를 다시 클릭하거나 패널 헤더의 × 버튼을 클릭하면 닫을 수 있다.

장치 이름 바꾸기

패널 헤더의 장치 이름 옆에 있는 버튼을 클릭하면 커스텀 이름(예: "Office-PC" 또는 "Core-Router")을 지정할 수 있다.

라우터 탭

라우터 패널에는 다음 탭들이 있다:

  • 인터페이스 — 각 포트의 IP 주소 설정
  • 라우팅 테이블 IPv4 — IPv4 경로(정적 및 학습된 경로) 보기 및 편집
  • 라우팅 테이블 IPv6 — IPv6 경로 보기 및 편집
  • OSPF — OSPF 동적 라우팅 설정 및 모니터링
  • BGP — BGP 이웃 설정 및 BGP 테이블 보기
  • VPN — 라우터 간 IP 터널 설정

스위치 탭

스위치 패널에는 스위치 주소 테이블(SAT), VLAN 설정, 스패닝 트리 프로토콜(STP) 설정을 위한 탭들이 있다.

홈 라우터 탭

홈 라우터 패널에는 다음 탭들이 있다:

  • 상태 — 현재 WAN/LAN 상태 및 연결된 클라이언트 개요
  • WAN — 업링크 설정(정적 IP 또는 DHCP)
  • LAN — LAN 서브넷 및 IP 주소 설정
  • DHCP — 활성 임대 보기 및 DHCP 풀 설정
  • WiFi — 내장 액세스 포인트 설정(SSID, 암호)
  • NAT — 활성 NAT 연결 테이블 보기
  • 포트 포워딩 — 수신 포트를 LAN 호스트로 전달하는 규칙 정의

방화벽 탭

방화벽 패널에는 필터 규칙을 관리하는 규칙 탭과 허용되거나 차단된 패킷을 보여주는 로그 탭이 있다.

PC 및 노트북

PC와 노트북은 패널 내에 완전히 시뮬레이션된 운영 체제를 가지고 있다. 데스크톱에서 앱을 열고, 네트워크 설정을 구성하고, 명령어를 실행할 수 있다.

실행 모드 — 시뮬레이션 실행

실행 모드로 전환하여 시뮬레이션을 시작하세요. 네트워크가 활성화됩니다: 장치들이 패킷을 교환하고, DHCP 임대가 할당되며, 라우팅 테이블이 업데이트되는 식으로 말이에요.

속도 조절

상단 도구 모음의 속도 버튼을 사용하여 시뮬레이션이 실행되는 속도를 조절하세요:

0.5×느림 — 개별 단계를 관찰하기 좋음
1×정상 속도
4×빠름
8×매우 빠름

일시 정지 및 재설정

일시 정지 시뮬레이션을 현재 상태에서 멈춥니다.
재설정 시뮬레이션을 처음부터 다시 시작합니다 (모든 동적 상태가 초기화됩니다).

참고: 실행 모드에서는 네트워크 토폴로지를 편집할 수 없습니다. 먼저 편집 모드로 전환하세요.

추적 모드 — 패킷 분석

추적 모드로 전환하여 Wireshark와 유사한 내장 패킷 분석기를 열어보자.

맨 위에서 캡처하려는 장치와 포트를 선택해. 그 포트를 통과하는 모든 패킷이 기록되고 목록으로 표시된다.

목록의 패킷을 클릭하면 완전한 세부 정보를 볼 수 있어: 프로토콜 계층, 헤더 필드, 페이로드 — 전문 네트워크 도구가 표시하는 것과 정확히 같다.

캡처는 시뮬레이션이 실행 중일 때 자동으로 작동한다. 캡처된 데이터를 잃지 않고도 추적 모드와 실행 모드 사이를 언제든지 전환할 수 있어.

저장 및 로드

네트워크 디자인을 파일로 저장했다가 나중에 다시 로드할 수 있어. 상단 툴바의 버튼들을 사용하면 돼 (편집 모드에서 보임):

새로 만들기 빈 캔버스에서 시작해. 저장하지 않은 변경 사항은 모두 없어져.
로드 이전에 저장한 시뮬레이션 파일을 열어.
저장 현재 시뮬레이션을 파일로 다운로드해서 컴퓨터에 저장해.

문제가 있어? 네트워크가 제대로 연결되어 있는지, 그리고 모든 기기에 유효한 IP 주소가 설정되어 있는지 확인해봐.

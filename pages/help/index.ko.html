세 가지 모드

BeaverTracer에는 세 가지 모드가 있다. 상단 도구 모음의 버튼을 사용하여 모드 간에 전환한다.

편집 네트워크를 설계한다 — 장치를 배치하고, 연결하고, 구성한다.
실행 시뮬레이션을 시작하고 네트워크를 통해 트래픽이 흐르는 것을 본다.
추적 네트워크를 통해 이동하는 패킷을 캡처하고 검사한다.

편집 모드 — 네트워크 구축

편집 모드에서는 화면 왼쪽에 도구 모음이 나타납니다. 도구를 클릭하여 선택한 다음 캔버스에서 사용합니다.

도구

선택 기기를 클릭하여 패널을 열어요. 기기를 드래그하여 이동할 수 있어요.
연결 두 기기를 케이블로 연결해요(아래 참고).
텍스트 캔버스에 텍스트 레이블을 배치하여 다이어그램에 주석을 달아요.
사각형 캔버스에 사각형을 그려 기기를 시각적으로 그룹화해요.
삭제 기기나 케이블을 클릭하여 제거해요.

팁: 캔버스의 아무 곳이나 오른쪽 클릭하여 현재 도구를 취소하고 선택으로 돌아갈 수 있어요.

기기 배치하기

  1. 왼쪽 도구 모음에서 기기 버튼을 클릭해요(예: 컴퓨터).
  2. 미리보기가 마우스 커서를 따라다녀요.
  3. 캔버스를 클릭하여 기기를 배치해요.

두 기기 연결하기

  1. 연결 도구를 클릭해요.
  2. 첫 번째 기기를 클릭하면 포트 선택기가 나타나요. 포트를 선택해요.
  3. 마우스를 두 번째 기기로 이동한 후 클릭하고 여기서도 포트를 선택해요.
  4. 케이블이 자동으로 생성돼요.

이미 사용 중인 포트는 비활성화되어 표시되며 선택할 수 없어요.

기기 이동하기

선택 모드에서 기기를 클릭하고 드래그하여 캔버스에서 위치를 바꿔요.

기기 또는 케이블 삭제하기

  1. 삭제 도구를 클릭해요.
  2. 제거할 기기나 케이블을 클릭해요.

기기를 삭제하면 연결된 모든 케이블이 자동으로 제거돼요.

기기

편집 모드에서 왼쪽 도구 모음에 이러한 기기들이 있어:

컴퓨터 유선 네트워크 인터페이스가 있는 컴퓨터야. 앱을 실행하고 (예: 웹 브라우저나 ping 도구) IP 주소를 설정할 수 있어.
태블릿 컴퓨터와 비슷하지만 케이블 대신 Wi-Fi로 연결돼. 액세스 포인트나 홈 라우터와 함께 사용해.
SW 스위치 같은 네트워크 세그먼트의 여러 기기를 연결해. MAC 주소를 기반으로 프레임을 전달해. VLAN과 스패닝 트리 프로토콜(STP)을 지원해.
RT 라우터 다른 네트워크를 연결하고 그 사이에서 패킷을 전달해. 정적 라우트, OSPF, BGP 및 IP 터널(VPN)을 지원해.
홈 라우터 라우터, DHCP 서버, NAT 게이트웨이 및 Wi-Fi 액세스 포인트가 결합된 기기야 — 일반적인 가정용 인터넷 라우터와 비슷해. 라우터에 연결하고(WAN으로) 컴퓨터나 태블릿에 연결해(LAN/Wi-Fi). 포트 포워딩 규칙을 지원해.
액세스 포인트 유선 네트워크를 Wi-Fi 연결로 확장해. 유선 포트를 스위치나 라우터에 연결한 다음 태블릿을 무선으로 연결해.
방화벽 설정 가능한 규칙에 따라 네트워크 세그먼트 간의 트래픽을 필터링해. 패널에 규칙 집합과 매칭된 패킷의 실시간 로그를 보여줘.

기기 패널

캔버스에서 기기를 클릭하면 화면의 오른쪽에 나타나는 패널 — 설정 창이 열린다. 기기를 다시 클릭하거나 (또는 패널 헤더의 × 버튼을 클릭하면) 닫을 수 있다.

기기 이름 바꾸기

패널 헤더의 기기 이름 옆에 있는 버튼을 클릭하면 사용자 지정 이름을 지정할 수 있다 (예: "Office-PC" 또는 "Core-Router").

라우터 탭

라우터 패널에는 다음의 탭이 있다:

  • 인터페이스 — 각 포트에서 IP 주소 설정
  • 라우팅 테이블 IPv4 — IPv4 경로 보기 및 편집 (정적 및 학습된 경로)
  • 라우팅 테이블 IPv6 — IPv6 경로 보기 및 편집
  • OSPF — OSPF 동적 라우팅 설정 및 모니터링
  • BGP — BGP 이웃 설정 및 BGP 테이블 보기
  • VPN — 라우터 간에 IP 터널 설정

스위치 탭

스위치 패널에는 스위치 주소 테이블 (SAT), VLAN 설정, 그리고 Spanning Tree Protocol (STP) 설정을 위한 탭이 있다.

홈 라우터 탭

홈 라우터 패널에는 다음의 탭이 있다:

  • 상태 — 현재 WAN/LAN 상태 및 연결된 클라이언트 개요
  • WAN — 업링크 설정 (정적 IP 또는 DHCP)
  • LAN — LAN 서브넷 및 IP 주소 설정
  • DHCP — 활성 임대 보기 및 DHCP 풀 설정
  • WiFi — 기본 제공 액세스 포인트 설정 (SSID, 비밀번호)
  • NAT — 활성 NAT 연결 테이블 보기
  • 포트 포워딩 — 들어오는 포트를 LAN 호스트로 전달하는 규칙 정의

방화벽 탭

방화벽 패널에는 필터 규칙을 관리하는 규칙 탭과 허용되거나 차단된 패킷을 보여주는 로그 탭이 있다.

컴퓨터 및 태블릿

컴퓨터와 태블릿에는 패널 내부에 완전한 시뮬레이션 운영 체제가 있다. 데스크톱에서 앱을 열고, 네트워크 설정을 구성하고, 명령을 실행할 수 있다.

실행 모드 — 시뮬레이션 실행하기

실행 모드로 전환하여 시뮬레이션을 시작해보자. 네트워크가 활성화되면 기기들이 패킷을 교환하고, DHCP 임대가 할당되며, 라우팅 테이블이 업데이트되는 등의 작업이 진행된다.

속도 조절

상단 도구 모음의 속도 버튼을 사용하여 시뮬레이션 실행 속도를 조절할 수 있다:

0.5×느림 — 개별 단계를 관찰하기에 좋음
1×정상 속도
4×빠름
8×매우 빠름

일시 중지 및 초기화

일시 중지 시뮬레이션을 현재 상태에서 멈춘다.
초기화 시뮬레이션을 처음부터 다시 시작한다(모든 동적 상태가 초기화됨).

참고: 실행 모드에서는 네트워크 토폴로지를 편집할 수 없다. 먼저 편집 모드로 전환하자.

추적 모드 — 패킷 분석

추적 모드로 전환하여 Wireshark와 유사한 내장 패킷 분석기를 엽니다.

상단에서 캡처할 장치와 포트를 선택합니다. 해당 포트를 통과하는 모든 패킷이 기록되고 목록에 표시됩니다.

목록의 패킷을 클릭하여 전체 세부 정보를 확인합니다: 프로토콜 레이어, 헤더 필드 및 페이로드 — 전문 네트워크 도구가 표시하는 방식과 동일합니다.

시뮬레이션이 실행되는 동안 캡처가 자동으로 실행됩니다. 캡처된 데이터를 잃지 않고 언제든지 추적 모드와 실행 모드 사이를 전환할 수 있습니다.

저장 및 로드

네트워크 설계를 파일로 저장했다가 나중에 다시 로드할 수 있어. 상단 도구 모음의 버튼을 사용하면 돼 (편집 모드에서 표시됨):

새로 만들기 빈 캔버스로 시작해. 저장하지 않은 변경 사항은 모두 손실돼.
로드 이전에 저장한 시뮬레이션 파일을 열어.
저장 현재 시뮬레이션을 파일로 다운로드해서 컴퓨터에 저장해.

문제가 있니? 네트워크가 올바르게 연결되어 있고 모든 장치에 유효한 IP 주소가 설정되어 있는지 확인해봐.

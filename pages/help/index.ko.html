세 가지 모드

Beaver Tracer에는 세 가지 모드가 있습니다. 상단 도구 모음의 버튼을 사용하여 모드 간에 전환합니다.

편집 네트워크를 설계합니다 — 장치를 배치하고, 연결하고, 구성합니다.
실행 시뮬레이션을 시작하고 네트워크를 통한 트래픽 흐름을 봅니다.
트레이스 네트워크를 통해 이동하는 패킷을 캡처하고 검사합니다.

편집 모드 — 네트워크 구축

편집 모드에서는 화면 왼쪽에 도구 모음이 나타납니다. 도구를 클릭하여 선택한 후 캔버스에서 사용합니다.

도구

선택 장치를 클릭하여 패널을 엽니다. 장치를 드래그하여 이동합니다.
링크 두 장치를 케이블로 연결합니다 (아래 참조).
텍스트 캔버스에 텍스트 레이블을 배치하여 다이어그램에 주석을 추가합니다.
직사각형 캔버스에 직사각형을 그려 장치를 시각적으로 그룹화합니다.
삭제 장치나 케이블을 클릭하여 제거합니다.

팁: 캔버스의 아무 곳이나 마우스 우클릭하여 현재 도구를 취소하고 선택으로 돌아갑니다.

장치 배치

  1. 왼쪽 도구 모음의 장치 버튼을 클릭합니다 (예: PC).
  2. 미리보기가 마우스 커서를 따릅니다.
  3. 캔버스를 클릭하여 장치를 배치합니다.

두 장치 연결

  1. 링크 도구를 클릭합니다.
  2. 첫 번째 장치를 클릭합니다 — 포트 선택기가 나타납니다. 포트를 선택합니다.
  3. 마우스를 두 번째 장치로 이동하고 클릭합니다 — 거기서도 포트를 선택합니다.
  4. 케이블이 자동으로 생성됩니다.

이미 사용 중인 포트는 비활성화된 상태로 표시되며 선택할 수 없습니다.

장치 이동

선택 모드에서 임의의 장치를 클릭하고 드래그하여 캔버스에서 위치를 변경합니다.

장치 또는 케이블 삭제

  1. 삭제 도구를 클릭합니다.
  2. 제거할 장치나 케이블을 클릭합니다.

장치를 삭제하면 연결된 모든 케이블이 자동으로 제거됩니다.

장치

편집 모드 중에 왼쪽 도구 모음에서 다음 장치를 사용할 수 있습니다:

PC 유선 네트워크 인터페이스가 있는 개인용 컴퓨터입니다. 이 위에서 앱을 실행할 수 있으며 (예: 웹 브라우저 또는 ping 도구) IP 주소를 구성할 수 있습니다.
랩톱 PC와 유사하지만 케이블 대신 Wi-Fi를 통해 연결됩니다. 액세스 포인트 또는 홈 라우터와 함께 사용합니다.
SW 스위치 같은 네트워크 세그먼트의 여러 장치를 연결합니다. MAC 주소를 기반으로 프레임을 전달합니다. VLAN 및 스패닝 트리 프로토콜(STP)을 지원합니다.
RT 라우터 다양한 네트워크를 연결하고 그들 간에 패킷을 전달합니다. 정적 경로, OSPF, BGP 및 IP 터널(VPN)을 지원합니다.
홈 라우터 라우터, DHCP 서버, NAT 게이트웨이 및 Wi-Fi 액세스 포인트가 통합된 장치입니다 — 일반적인 홈 인터넷 라우터와 유사합니다. 라우터에 (WAN으로) 연결하고 PC 또는 랩톱에 (LAN/Wi-Fi로) 연결합니다. 포트 포워딩 규칙을 지원합니다.
액세스 포인트 Wi-Fi 연결로 유선 네트워크를 확장합니다. 유선 포트를 스위치 또는 라우터에 연결한 후 랩톱을 무선으로 연결합니다.
방화벽 구성 가능한 규칙을 기반으로 네트워크 세그먼트 간 트래픽을 필터링합니다. 패널에는 규칙 집합과 일치된 패킷의 실시간 로그가 표시됩니다.

장치 패널

캔버스의 임의의 장치를 클릭하여 패널을 엽니다 — 화면 오른쪽에 나타나는 구성 창입니다. 장치를 다시 클릭하거나 패널 헤더의 × 버튼을 클릭하여 닫습니다.

장치 이름 바꾸기

패널 헤더의 장치 이름 옆에 있는 버튼을 클릭하여 사용자 정의 이름을 지정합니다 (예: "Office-PC" 또는 "Core-Router").

라우터 탭

라우터 패널에는 다음 탭이 있습니다:

  • 인터페이스 — 각 포트의 IP 주소 구성
  • 라우팅 테이블 IPv4 — IPv4 경로 보기 및 편집 (정적 및 학습됨)
  • 라우팅 테이블 IPv6 — IPv6 경로 보기 및 편집
  • OSPF — OSPF 동적 라우팅 구성 및 모니터링
  • BGP — BGP 이웃 구성 및 BGP 테이블 보기
  • VPN — 라우터 간 IP 터널 설정

스위치 탭

스위치 패널에는 스위치 주소 테이블(SAT), VLAN 구성 및 스패닝 트리 프로토콜(STP) 설정을 위한 탭이 있습니다.

홈 라우터 탭

홈 라우터 패널에는 다음 탭이 있습니다:

  • 상태 — 현재 WAN/LAN 상태 및 연결된 클라이언트 개요
  • WAN — 업링크 구성 (정적 IP 또는 DHCP)
  • LAN — LAN 서브넷 및 IP 주소 구성
  • DHCP — 활성 임대 보기 및 DHCP 풀 구성
  • WiFi — 내장 액세스 포인트 구성 (SSID, 암호)
  • NAT — 활성 NAT 연결 테이블 보기
  • 포트 포워딩 — 들어오는 포트를 LAN 호스트로 전달하는 규칙 정의

방화벽 탭

방화벽 패널에는 필터 규칙을 관리하는 규칙 탭과 허용되거나 삭제된 패킷을 표시하는 로그 탭이 있습니다.

PC 및 랩톱

PC 및 랩톱에는 패널 내부에 완전히 시뮬레이션된 운영 체제가 있습니다. 데스크톱에서 앱을 열고, 네트워크 설정을 구성하고, 명령을 실행할 수 있습니다.

三种模式

BeaverTracer 有三种模式。您可以使用顶部工具栏中的按钮在它们之间切换。

编辑 设计您的网络 — 放置设备、连接它们、配置它们。
运行 启动模拟并观看流量流经您的网络。
追踪 捕获和检查在您的网络中传输的数据包。

编辑模式 — 构建网络

在编辑模式中，屏幕左侧会出现一个工具栏。 通过点击来选择一个工具，然后在画布上使用它。

工具

选择 点击设备打开其面板。拖动设备来移动它。
链接 用电缆连接两个设备（见下文）。
删除 点击设备或电缆以将其移除。

提示：右键点击画布上的任何地方以取消当前工具 并返回到 选择。

放置设备

  1. 点击左侧工具栏中的设备按钮（例如 电脑）。
  2. 一个预览框会跟随您的鼠标光标。
  3. 在画布上点击以放置设备。

连接两个设备

  1. 点击 链接 工具。
  2. 点击第一个设备 — 会出现一个端口选择器。选择一个端口。
  3. 将您的鼠标移到第二个设备并点击它 — 也在那里选择一个端口。
  4. 电缆会自动创建。

已在使用中的端口显示为禁用状态，无法选择。

移动设备

在 选择模式中，点击并拖动任何设备以在画布上重新定位它。

删除设备或电缆

  1. 点击 删除 工具。
  2. 点击您要移除的设备或电缆。

删除设备时，连接到它的所有电缆都会自动移除。

设备

编辑模式期间，左侧工具栏中提供以下设备：

电脑 一台具有有线网络接口的个人计算机。您可以在其上运行应用程序 （例如网络浏览器或 ping 工具）并配置其 IP 地址。
笔记本电脑 类似于电脑，但通过 Wi-Fi 而不是电缆连接。 与接入点或家庭路由器一起使用。
SW 交换机 在同一网络段中连接多个设备。 基于 MAC 地址转发帧。 支持 VLAN 和生成树协议 (STP)。
RT 路由器 连接不同网络并在它们之间转发数据包。 您可以在每个接口上配置静态路由和 IP 地址。
家庭路由器 结合了路由器、DHCP 服务器、NAT 网关和 Wi-Fi 接入点的设备 — 类似于典型的家庭互联网路由器。 将其连接到路由器（作为 WAN）和电脑或笔记本电脑（作为 LAN/Wi-Fi）。
接入点 用 Wi-Fi 连接扩展有线网络。 将其有线端口连接到交换机或路由器，然后以无线方式将笔记本电脑连接到它。

设备面板

在画布上点击任何设备以打开其 面板 — 一个配置窗口 出现在屏幕右侧。 再次点击设备（或面板标题中的 × 按钮）以关闭它。

重命名设备

点击面板标题中设备名称旁边的 按钮 为其设置自定义名称（例如"办公室电脑"或"核心路由器"）。

标签

大多数设备在面板内有多个标签。 例如，路由器有：

  • 接口 — 在每个端口上配置 IP 地址
  • IPv4 路由表 — 查看和编辑 IPv4 静态路由
  • IPv6 路由表 — 查看和编辑 IPv6 静态路由

交换机具有其 交换机地址表 (SAT)、VLAN 配置和 生成树协议 (STP) 设置的标签。

家庭路由器具有 状态、WAN 设置和 DHCP 租赁的标签。

电脑和笔记本电脑

电脑和笔记本电脑在其面板内有一个完整的模拟操作系统。 您可以从桌面打开应用程序、配置网络设置并运行命令。

运行模式 — 运行模拟

切换到 运行 模式以启动模拟。 网络变为实时：设备交换数据包、DHCP 租赁被分配、 路由表更新等等。

速度控制

使用顶部工具栏中的速度按钮来控制模拟的运行速度：

0.5×慢速 — 适合观察单个步骤
1×正常速度
4×快速
8×非常快

暂停和重置

暂停 冻结模拟在其当前状态。
重置 从头开始重启模拟（所有动态状态都会被清除）。

注意：您无法在运行模式中编辑网络拓扑。 先切换回 编辑模式。

追踪模式 — 分析数据包

切换到 追踪 模式以打开 内置数据包分析器 — 类似于 Wireshark。

在顶部，选择您要捕获的 设备 和 端口。 通过该端口的所有数据包都会被记录并显示在列表中。

点击列表中的任何数据包以查看其完整详情： 协议层、标头字段和有效载荷 — 正如专业网络工具所显示的那样。

模拟运行时捕获会自动进行。 您可以随时在追踪模式和运行模式之间切换，而不会丢失捕获的数据。

保存和加载

您的网络设计可以保存为文件，并在以后再次加载。 使用顶部工具栏中的按钮（在编辑模式中可见）：

新建 从空白画布开始。任何未保存的更改都将丢失。
加载 打开之前保存的模拟文件。
保存 将当前模拟作为文件下载到您的计算机。

遇到问题？请检查您的网络是否正确连接，以及所有设备是否都配置了有效的 IP 地址。

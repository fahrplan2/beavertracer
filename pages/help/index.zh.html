三种模式

Beaver Tracer 有三种模式。您可以使用顶部工具栏中的按钮在它们之间切换。

编辑 设计您的网络 — 放置设备、连接设备、配置设备。
运行 启动模拟并观察流量通过您的网络。
追踪 捕获并检查在您的网络中传输的数据包。

编辑模式 — 构建网络

在编辑模式中，屏幕左侧会出现一个工具栏。 点击一个工具来选择它，然后在画布上使用它。

工具

选择 点击一个设备来打开其面板。拖动一个设备来移动它。
连接 用电缆连接两个设备（见下文）。
文本 在画布上放置文本标签来注释您的图表。
矩形 在画布上绘制矩形来将设备分组显示。
删除 点击一个设备或电缆来删除它。

提示：在画布上右键点击任何地方来取消当前工具 并返回 选择。

放置设备

  1. 点击左侧工具栏中的一个设备按钮（例如 PC）。
  2. 一个预览会跟随您的鼠标光标。
  3. 在画布上点击来放置设备。

连接两个设备

  1. 点击 连接 工具。
  2. 点击第一个设备 — 会出现一个端口选择器。选择一个端口。
  3. 将您的鼠标移到第二个设备并点击它 — 也在那里选择一个端口。
  4. 电缆会自动创建。

已被使用的端口会显示为禁用状态，无法选择。

移动设备

在 选择模式中，点击并拖动任何设备来在画布上重新定位它。

删除设备或电缆

  1. 点击 删除 工具。
  2. 点击您想要删除的设备或电缆。

当您删除一个设备时，所有连接到它的电缆都会自动删除。

设备

在编辑模式期间，左侧工具栏中提供以下设备：

PC 具有有线网络接口的个人计算机。您可以在其上运行应用程序 （例如网络浏览器或 ping 工具）并配置其 IP 地址。
笔记本电脑 与 PC 相同，但通过 Wi-Fi 而不是电缆连接。 将其与接入点或家庭路由器一起使用。
SW 交换机 在同一网络段中连接多个设备。 基于 MAC 地址转发帧。 支持 VLAN 和生成树协议 (STP)。
RT 路由器 连接不同的网络并在它们之间转发数据包。 支持静态路由、OSPF、BGP 和 IP 隧道 (VPN)。
家庭路由器 组合了路由器、DHCP 服务器、NAT 网关和 Wi-Fi 接入点 — 类似于典型的家庭互联网路由器。 将其连接到路由器（作为 WAN）以及 PC 或笔记本电脑（作为 LAN/Wi-Fi）。 支持端口转发规则。
接入点 用 Wi-Fi 连接扩展有线网络。 将其有线端口连接到交换机或路由器，然后将笔记本电脑无线连接到它。
防火墙 基于可配置规则在网络段之间过滤流量。 该面板显示规则集和匹配数据包的实时日志。

设备面板

点击画布上的任何设备来打开其 面板 — 一个配置窗口 会显示在屏幕右侧。 再次点击设备（或面板标题中的 × 按钮）来关闭它。

重命名设备

点击面板标题中设备名称旁边的 按钮 来给它一个自定义名称（例如"Office-PC"或"Core-Router"）。

路由器标签

路由器面板有以下标签：

  • 接口 — 在每个端口上配置 IP 地址
  • 路由表 IPv4 — 查看和编辑 IPv4 路由（静态和学习的）
  • 路由表 IPv6 — 查看和编辑 IPv6 路由
  • OSPF — 配置和监控 OSPF 动态路由
  • BGP — 配置 BGP 邻居并查看 BGP 表
  • VPN — 在路由器之间设置 IP 隧道

交换机标签

交换机面板有用于其 交换机地址表 (SAT)、VLAN 配置和 生成树协议 (STP) 设置的标签。

家庭路由器标签

家庭路由器面板有以下标签：

  • 状态 — 当前 WAN/LAN 状态和连接的客户端的概览
  • WAN — 配置上行链路（静态 IP 或 DHCP）
  • LAN — 配置 LAN 子网和 IP 地址
  • DHCP — 查看活跃租约并配置 DHCP 池
  • WiFi — 配置内置接入点（SSID、密码）
  • NAT — 查看活跃 NAT 连接表
  • 端口转发 — 定义规则来将传入端口转发到 LAN 主机

防火墙标签

防火墙面板有一个 规则 标签用于管理过滤规则，以及一个 日志 标签显示哪些数据包已被允许或丢弃。

PC 和笔记本电脑

PC 和笔记本电脑在其面板内具有完整的模拟操作系统。 您可以从桌面打开应用程序、配置网络设置并运行命令。

运行模式 — 运行模拟

切换到 运行 模式来启动模拟。 网络变为活动状态：设备交换数据包、分配 DHCP 租约、 路由表更新，等等。

速度控制

使用顶部工具栏中的速度按钮来控制模拟的运行速度：

0.5×慢速 — 适合观察各个步骤
1×正常速度
4×快速
8×非常快

暂停和重置

暂停 在当前状态冻结模拟。
重置 从头重新启动模拟（所有动态状态已清除）。

注意：您不能在运行模式中编辑网络拓扑。 请先切换回 编辑模式。

追踪模式 — 分析数据包

切换到 追踪 模式来打开 内置数据包分析器 — 类似于 Wireshark。

在顶部，选择您想要捕获的 设备 和 端口。 通过该端口的所有数据包都会被记录并显示在一个列表中。

点击列表中的任何数据包来查看其完整详情： 协议层、报头字段和有效载荷 — 完全如专业网络工具会显示的那样。

三種模式

Beaver Tracer 有三種模式。你可以使用頂部工具列中的按鈕在它們之間切換。

編輯 設計你的網路 — 放置裝置、連接它們、配置它們。
執行 啟動模擬並觀看流量流經你的網路。
追蹤 擷取並檢查在你的網路上傳輸的封包。

編輯模式 — 建構網路

在編輯模式中，螢幕左側會出現一個工具列。 點選一個工具，然後在畫布上使用它。

工具

選取 點選一個裝置來開啟它的面板。拖曳一個裝置來移動它。
連結 用纜線連接兩個裝置（見下方）。
文字 在畫布上放置文字標籤來註解你的圖表。
矩形 在畫布上繪製矩形來視覺化地分組裝置。
刪除 點選一個裝置或纜線來移除它。

提示： 在畫布上按右鍵可以取消目前工具 並回到 選取。

放置裝置

  1. 點選左工具列中的一個裝置按鈕（例如 電腦）。
  2. 一個預覽會跟隨你的滑鼠游標。
  3. 在畫布上點選以放置裝置。

連接兩個裝置

  1. 點選 連結 工具。
  2. 點選第一個裝置 — 一個連接埠選擇器會出現。選擇一個連接埠。
  3. 移動滑鼠到第二個裝置並點選它 — 也在那裡選擇一個連接埠。
  4. 纜線會自動建立。

已經在使用中的連接埠會顯示為停用狀態，無法選擇。

移動裝置

在 選取模式中，點選並拖曳任何裝置以在畫布上重新定位它。

刪除裝置或纜線

  1. 點選 刪除 工具。
  2. 點選你想要移除的裝置或纜線。

當你刪除一個裝置時，所有連接到它的纜線都會自動移除。

裝置

編輯模式下，這些裝置在左側工具列中可用：

電腦 具有有線網路介面的電腦。你可以在其上執行應用程式 （例如網頁瀏覽器或 ping 工具）並設定其 IP 位址。
平板電腦 類似電腦，但透過 Wi-Fi 而非纜線連接。 將其與存取點或家用路由器搭配使用。
SW 交換器 在同一網路區段中連接多個裝置。 根據 MAC 位址轉發訊框。 支援 VLAN 和生成樹協議 (STP)。
RT 路由器 連接不同的網路並在其間轉發封包。 支援靜態路由、OSPF、BGP 和 IP 隧道 (VPN)。
家用路由器 組合的路由器、DHCP 伺服器、NAT 閘道和 Wi-Fi 存取點—— 類似典型的家用網際網路路由器。 將其連接到路由器 (作為 WAN) 和電腦或平板電腦 (作為 LAN/Wi-Fi)。 支援連接埠轉發規則。
存取點 使用 Wi-Fi 連接擴展有線網路。 將其有線連接埠連接到交換器或路由器，然後無線連接平板電腦。
防火牆 根據可設定的規則在網路區段之間過濾流量。 面板顯示規則集和符合的封包的即時日誌。

裝置面板

點擊畫布上的任何裝置以開啟其面板——一個出現在螢幕右側的設定視窗。 再次點擊該裝置（或面板標題中的×按鈕）以關閉它。

重新命名裝置

點擊面板標題中裝置名稱旁邊的按鈕，為它設定一個自訂名稱（例如「Office-PC」或「Core-Router」）。

路由器標籤

路由器面板具有下列標籤：

  • 介面——在每個連接埠上設定 IP 位址
  • IPv4 路由表——檢視和編輯 IPv4 路由（靜態和學習的）
  • IPv6 路由表——檢視和編輯 IPv6 路由
  • OSPF——設定和監控 OSPF 動態路由
  • BGP——設定 BGP 鄰居並檢視 BGP 表
  • VPN——在路由器之間設定 IP 隧道

交換器標籤

交換器面板具有其交換器地址表 (SAT)、VLAN 設定和生成樹協定 (STP) 設定的標籤。

家用路由器標籤

家用路由器面板具有下列標籤：

  • 狀態——目前 WAN/LAN 狀態和已連線用戶端的概述
  • WAN——設定上行連結（靜態 IP 或 DHCP）
  • LAN——設定 LAN 子網和 IP 位址
  • DHCP——檢視有效租賃並設定 DHCP 集區
  • WiFi——設定內建存取點（SSID、密碼）
  • NAT——檢視有效的 NAT 連線表
  • 連接埠轉發——定義規則以將傳入連接埠轉發到 LAN 主機

防火牆標籤

防火牆面板具有用於管理篩選規則的規則標籤和顯示哪些封包已被允許或丟棄的 記錄標籤。

電腦和平板

電腦和平板在其面板內具有完整的模擬作業系統。 你可以從桌面開啟應用程式、設定網路設定，以及執行指令。

執行模式 — 執行模擬

切換到 執行模式以開始模擬。 網路變成即時的：裝置交換封包、DHCP 租期被分配、 路由表更新等等。

速度控制

使用頂部工具列中的速度按鈕來控制模擬執行的速度：

0.5×慢速 — 適合觀察個別步驟
1×正常速度
4×快速
8×非常快速

暫停和重置

暫停 在目前狀態凍結模擬。
重置 從頭開始重新啟動模擬（所有動態狀態都會被清除）。

注意：在執行模式中無法編輯網路拓撲。 請先切換回 編輯模式。

Trace 模式 — 分析數據包

切換到 Trace 模式以開啟內建的數據包分析器 — 類似於 Wireshark。

在頂部，選擇你想要擷取的設備和連接埠。 通過該連接埠的所有數據包都會被記錄並以列表形式顯示。

點擊列表中的任何數據包以查看其完整詳細資訊： 協議層、標頭欄位和負載 — 就像專業的網路工具顯示的一樣。

當模擬運行時，擷取會自動進行。 你可以隨時在 Trace 模式和 Run 模式之間切換，而不會遺失擷取的數據。

儲存和載入

你的網路設計可以儲存為檔案，稍後再載入。 使用頂部工具列中的按鈕（在編輯模式中可見）：

新增 以空白畫布開始。任何未儲存的變更都會遺失。
載入 開啟先前儲存的模擬檔案。
儲存 將目前的模擬下載為檔案到你的電腦。

遇到問題了嗎？請檢查你的網路是否正確連接，以及所有裝置是否都配置了有效的IP位址。

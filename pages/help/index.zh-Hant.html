三種模式

BeaverTracer 有三種模式。你可以使用頂部工具欄中的按鈕在它們之間切換。

編輯 設計你的網路——放置設備、連接它們、配置它們。
執行 啟動模擬並觀看流量流經你的網路。
追蹤 捕獲並檢查跨越你的網路傳輸的數據包。

編輯模式 — 構建網絡

在編輯模式中，螢幕左側會出現一個工具欄。 點擊選擇一個工具，然後在畫布上使用它。

工具

選擇 點擊一個設備來打開它的面板。拖動一個設備來移動它。
連結 用網線連接兩個設備（見下文）。
文字 在畫布上放置一個文字標籤來標註你的圖表。
矩形 在畫布上繪製一個矩形來直觀地分組設備。
刪除 點擊一個設備或網線來移除它。

提示：在畫布上的任何地方按右鍵來取消當前工具 並回到 選擇。

放置設備

  1. 在左側工具欄中點擊一個設備按鈕（例如 PC）。
  2. 預覽會跟隨你的滑鼠游標。
  3. 在畫布上點擊來放置設備。

連接兩個設備

  1. 點擊 連結 工具。
  2. 點擊第一個設備 — 會出現一個連接埠選擇器。選擇一個連接埠。
  3. 將滑鼠移到第二個設備並點擊它 — 也在那裡選擇一個連接埠。
  4. 網線會自動創建。

已經在使用中的連接埠會顯示為禁用狀態，無法選擇。

移動設備

在 選擇模式中，點擊並拖動任何設備來在畫布上重新定位它。

刪除設備或網線

  1. 點擊 刪除 工具。
  2. 點擊你想要移除的設備或網線。

當你刪除一個設備時，所有連接到它的網線都會自動移除。

裝置

這些裝置在編輯模式的左邊工具列中可用：

個人電腦 一台具有有線網路介面的個人電腦。你可以在上面執行應用程式 （例如網頁瀏覽器或 ping 工具）並設定其 IP 位址。
筆記型電腦 與個人電腦類似，但透過 Wi-Fi 而不是網線連接。 將它與無線存取點或家用路由器一起使用。
SW 交換機 連接同一網路區段中的多個裝置。 根據 MAC 位址轉發訊框。 支援 VLAN 和生成樹協議 (STP)。
RT 路由器 連接不同的網路並在它們之間轉發封包。 支援靜態路由、OSPF、BGP 和 IP 隧道 (VPN)。
家用路由器 一個結合路由器、DHCP 伺服器、NAT 閘道和 Wi-Fi 無線存取點的裝置 — 類似於典型的家庭網際網路路由器。 將它連接到路由器（作為 WAN）以及連接到個人電腦或筆記型電腦（作為 LAN/Wi-Fi）。 支援埠轉發規則。
無線存取點 使用 Wi-Fi 連接擴展有線網路。 將其有線埠連接到交換機或路由器，然後將筆記型電腦無線連接到它。
防火牆 根據可設定的規則篩選網路區段之間的流量。 面板顯示規則集和相符封包的即時日誌。

裝置面板

按一下畫布上的任何裝置來開啟它的面板——一個設定視窗會出現在螢幕的右側。 再按一次裝置（或按面板標題列中的×按鈕）來關閉它。

重新命名裝置

按一下面板標題列中裝置名稱旁邊的按鈕，為它取一個自訂名稱（例如「Office-PC」或「Core-Router」）。

路由器標籤

路由器面板有以下標籤：

  • 介面——在每個連接埠上設定 IP 位址
  • 路由表 IPv4——檢視及編輯 IPv4 路由（靜態及已學習的）
  • 路由表 IPv6——檢視及編輯 IPv6 路由
  • OSPF——設定及監視 OSPF 動態路由
  • BGP——設定 BGP 鄰居及檢視 BGP 表
  • VPN——在路由器之間設定 IP 通道

交換器標籤

交換器面板有交換器位址表 (SAT)、VLAN 設定及生成樹協議 (STP) 設定的標籤。

家用路由器標籤

家用路由器面板有以下標籤：

  • 狀態——目前 WAN/LAN 狀態及已連接用戶端的概覽
  • WAN——設定上行連結（靜態 IP 或 DHCP）
  • LAN——設定 LAN 子網路及 IP 位址
  • DHCP——檢視使用中的租約及設定 DHCP 集區
  • WiFi——設定內建無線存取點（SSID、密碼）
  • NAT——檢視使用中的 NAT 連線表
  • 連接埠轉發——定義規則以將傳入連接埠轉發至 LAN 主機

防火牆標籤

防火牆面板有規則標籤來管理過濾規則及 記錄標籤顯示哪些封包已被允許或丟棄。

PC 及筆記型電腦

PC 及筆記型電腦在其面板內有一個完整的模擬作業系統。 你可以從桌面開啟應用程式、設定網路設定，以及執行命令。

執行模式 — 執行模擬

切換到 執行 模式以啟動模擬。 網路變為實時：裝置交換封包、DHCP 租約被分配、 路由表更新等等。

速度控制

使用頂部工具欄中的速度按鈕來控制模擬執行的速度：

0.5×緩慢 — 適合觀察各個步驟
1×正常速度
4×快速
8×非常快速

暫停和重設

暫停 在目前狀態凍結模擬。
重設 從頭重新啟動模擬（所有動態狀態已清除）。

注意：在執行模式中無法編輯網路拓撲。 請先切換回 編輯模式。

追蹤模式 — 分析封包

切換到 追蹤模式以開啟內建的封包分析工具 — 類似於 Wireshark。

在頂部，選擇你想要擷取封包的裝置和連接埠。 通過該連接埠的所有封包都會被記錄並顯示在列表中。

點擊列表中的任何封包以查看其完整詳細資訊： 協議層、標頭欄位和負載 — 就像專業網路工具顯示的一樣。

當模擬運行時，擷取會自動進行。 你可以隨時在追蹤模式和執行模式之間切換，而不會遺失擷取的資料。

保存與載入

你可以將網路設計保存為文件，之後再載入。 使用頂部工具欄中的按鈕（在編輯模式中可見）：

新建 從空白畫布開始。任何未保存的更改都將丟失。
載入 打開之前保存的模擬文件。
保存 將當前模擬下載為文件到你的計算機。

有問題嗎？檢查一下你的網路是否正確連接，以及所有設備是否都已設定有效的IP位址。

Οι Τρεις Λειτουργίες

Το Beaver Tracer έχει τρεις λειτουργίες. Μπορείτε να μεταβείτε ανάμεσά τους χρησιμοποιώντας τα κουμπιά στη γραμμή εργαλείων στο πάνω μέρος.

Επεξεργασία Σχεδιάστε το δίκτυό σας — τοποθετήστε συσκευές, συνδέστε τες, ρυθμίστε τες.
Εκτέλεση Ξεκινήστε την προσομοίωση και παρακολουθήστε την κυκλοφορία που διέρχεται από το δίκτυό σας.
Ανίχνευση Καταγράψτε και επιθεωρήστε τα πακέτα που ταξιδεύουν στο δίκτυό σας.

Λειτουργία Επεξεργασίας — Δημιουργία Δικτύου

Στη λειτουργία Επεξεργασίας, εμφανίζεται μια γραμμή εργαλείων στην αριστερή πλευρά της οθόνης. Επιλέξτε ένα εργαλείο κάνοντας κλικ σε αυτό, στη συνέχεια χρησιμοποιήστε το στον καμβά.

Εργαλεία

Επιλογή Κάντε κλικ σε μια συσκευή για να ανοίξετε τον πίνακά της. Σύρετε μια συσκευή για να την μετακινήσετε.
Σύνδεσμος Συνδέστε δύο συσκευές με ένα καλώδιο (δείτε παρακάτω).
Κείμενο Τοποθετήστε μια ετικέτα κειμένου στον καμβά για να σχολιάσετε το διάγραμμά σας.
Ορθογώνιο Σχεδιάστε ένα ορθογώνιο στον καμβά για να ομαδοποιήσετε οπτικά τις συσκευές.
Διαγραφή Κάντε κλικ σε μια συσκευή ή καλώδιο για να την αφαιρέσετε.

Συμβουλή: Κάντε δεξί κλικ οπουδήποτε στον καμβά για να ακυρώσετε το τρέχον εργαλείο και να επιστρέψετε στην Επιλογή.

Τοποθέτηση Συσκευής

  1. Κάντε κλικ στο κουμπί μιας συσκευής στη γραμμή εργαλείων στα αριστερά (π.χ. PC).
  2. Μια προεπισκόπηση ακολουθεί το δείκτη του ποντικιού σας.
  3. Κάντε κλικ στον καμβά για να τοποθετήσετε τη συσκευή.

Σύνδεση Δύο Συσκευών

  1. Κάντε κλικ στο εργαλείο Σύνδεσμος.
  2. Κάντε κλικ στην πρώτη συσκευή — εμφανίζεται ένας επιλογέας θύρας. Επιλέξτε μια θύρα.
  3. Μετακινήστε το ποντίκι σας στη δεύτερη συσκευή και κάντε κλικ — επιλέξτε και εκεί μια θύρα.
  4. Το καλώδιο δημιουργείται αυτόματα.

Οι θύρες που είναι ήδη σε χρήση εμφανίζονται ως απενεργοποιημένες και δεν μπορούν να επιλεγούν.

Μετακίνηση Συσκευής

Στη λειτουργία Επιλογή, κάντε κλικ και σύρετε οποιαδήποτε συσκευή για να την τοποθετήσετε ξανά στον καμβά.

Διαγραφή Συσκευής ή Καλωδίου

  1. Κάντε κλικ στο εργαλείο Διαγραφή.
  2. Κάντε κλικ στη συσκευή ή το καλώδιο που θέλετε να αφαιρέσετε.

Όταν διαγράψετε μια συσκευή, όλα τα καλώδια που συνδέονται με αυτήν αφαιρούνται αυτόματα.

Συσκευές

Αυτές οι συσκευές είναι διαθέσιμες στη γραμμή εργαλείων στα αριστερά κατά τη λειτουργία Επεξεργασίας:

PC Ένας προσωπικός υπολογιστής με ένα ενσύρματο διεπαφή δικτύου. Μπορείτε να εκτελέσετε εφαρμογές σε αυτόν (π.χ. ένα πρόγραμμα περιήγησης ιστού ή ένα εργαλείο ping) και να ρυθμίσετε τη διεύθυνση IP του.
Laptop Όπως ένας PC, αλλά συνδέεται μέσω Wi-Fi αντί για καλώδιο. Χρησιμοποιήστε το μαζί με ένα Access Point ή Home Router.
SW Switch Συνδέει πολλές συσκευές στο ίδιο τμήμα δικτύου. Προωθεί πλαίσια βάσει διευθύνσεων MAC. Υποστηρίζει VLANs και Spanning Tree Protocol (STP).
RT Router Συνδέει διαφορετικά δίκτυα και προωθεί πακέτα ανάμεσά τους. Υποστηρίζει στατικές διαδρομές, OSPF, BGP και IP tunnels (VPN).
Home Router Ένας συνδυασμένος router, DHCP server, NAT gateway και Wi-Fi access point — παρόμοιος με έναν τυπικό router διαδικτύου σπιτιού. Συνδέστε το με ένα Router (ως WAN) και με PCs ή Laptops (ως LAN/Wi-Fi). Υποστηρίζει κανόνες προώθησης θυρών.
Access Point Επεκτείνει ένα ενσύρματο δίκτυο με σύνδεση Wi-Fi. Συνδέστε τη θύρα ενσύρματη σύνδεσης σε ένα Switch ή Router, στη συνέχεια συνδέστε Laptops σε αυτό ασύρματα.
Firewall Φιλτράρει την κυκλοφορία ανάμεσα στα τμήματα δικτύου βάσει προσαρμόσιμων κανόνων. Ο πίνακας εμφανίζει το σύνολο κανόνων και ένα ζωντανό αρχείο καταγραφής των ταιριασμένων πακέτων.

Πίνακες Συσκευών

Κάντε κλικ σε οποιαδήποτε συσκευή στον καμβά για να ανοίξετε τον πίνακά της — ένα παράθυρο ρυθμίσεων που εμφανίζεται στη δεξιά πλευρά της οθόνης. Κάντε κλικ στη συσκευή ξανά (ή στο κουμπί × στην κεφαλίδα του πίνακα) για να το κλείσετε.

Μετονομασία Συσκευής

Κάντε κλικ στο κουμπί δίπλα στο όνομα της συσκευής στην κεφαλίδα του πίνακα για να της δώσετε ένα προσαρμοσμένο όνομα (π.χ. "Office-PC" ή "Core-Router").

Καρτέλες Router

Ένας πίνακας Router έχει τις ακόλουθες καρτέλες:

  • Interfaces — ρύθμιση διευθύνσεων IP σε κάθε θύρα
  • Routing table IPv4 — προβολ

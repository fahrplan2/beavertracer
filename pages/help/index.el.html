Οι τρεις λειτουργίες

Το BeaverTracer έχει τρεις λειτουργίες. Μπορείς να εναλλάσσεσαι μεταξύ τους χρησιμοποιώντας τα κουμπιά στη γραμμή εργαλείων στο πάνω μέρος.

Επεξεργασία Σχεδίασε το δίκτυό σου — τοποθέτησε συσκευές, συνδέστες τις, διαμόρφωσέ τις.
Εκτέλεση Ξεκίνησε την προσομοίωση και παρακολούθησε την κίνηση δεδομένων στο δίκτυό σου.
Ανίχνευση Καταγράφε και επιθεώρησε τα πακέτα που ταξιδεύουν στο δίκτυό σου.

Λειτουργία επεξεργασίας — Δημιουργία δικτύου

Στη λειτουργία επεξεργασίας, εμφανίζεται μια γραμμή εργαλείων στην αριστερή πλευρά της οθόνης. Επίλεξε ένα εργαλείο κάνοντας κλικ σε αυτό, στη συνέχεια χρησιμοποίησέ το στον καμβά.

Εργαλεία

Επιλογή Κάνε κλικ σε μια συσκευή για να ανοίξει το παράθυρό της. Σύρε μια συσκευή για να την μετακινήσεις.
Σύνδεση Σύνδεσε δύο συσκευές με ένα καλώδιο (δες παρακάτω).
Κείμενο Τοποθέτησε μια ετικέτα κειμένου στον καμβά για να σχολιάσεις το διάγραμμά σου.
Ορθογώνιο Σχεδίασε ένα ορθογώνιο στον καμβά για να ομαδοποιήσεις οπτικά τις συσκευές.
Διαγραφή Κάνε κλικ σε μια συσκευή ή καλώδιο για να την αφαιρέσεις.

Συμβουλή: Κάνε δεξί κλικ οπουδήποτε στον καμβά για να ακυρώσεις το τρέχον εργαλείο και να επιστρέψεις στην Επιλογή.

Τοποθέτηση συσκευής

  1. Κάνε κλικ σε ένα κουμπί συσκευής στη γραμμή εργαλείων στα αριστερά (π.χ. Υπολογιστής).
  2. Μια προεπισκόπηση ακολουθεί τον κέρσορα του ποντικιού σου.
  3. Κάνε κλικ στον καμβά για να τοποθετήσεις τη συσκευή.

Σύνδεση δύο συσκευών

  1. Κάνε κλικ στο εργαλείο Σύνδεση.
  2. Κάνε κλικ στην πρώτη συσκευή — εμφανίζεται ένας επιλογέας θυρών. Επίλεξε μια θύρα.
  3. Μετακίνησε το ποντίκι σου στη δεύτερη συσκευή και κάνε κλικ σε αυτήν — επίλεξε και εκεί μια θύρα.
  4. Το καλώδιο δημιουργείται αυτόματα.

Οι θύρες που είναι ήδη σε χρήση εμφανίζονται ως απενεργοποιημένες και δεν μπορούν να επιλεγούν.

Μετακίνηση συσκευής

Στη λειτουργία Επιλογή, κάνε κλικ και σύρε οποιαδήποτε συσκευή για να την αναπροσανατολίσεις στον καμβά.

Διαγραφή συσκευής ή καλωδίου

  1. Κάνε κλικ στο εργαλείο Διαγραφή.
  2. Κάνε κλικ στη συσκευή ή στο καλώδιο που θέλεις να αφαιρέσεις.

Όταν διαγράφεις μια συσκευή, όλα τα καλώδια που συνδέονται με αυτήν αφαιρούνται αυτόματα.

Συσκευές

Αυτές οι συσκευές είναι διαθέσιμες στη αριστερή γραμμή εργαλείων κατά τη λειτουργία επεξεργασίας:

Υπολογιστής Ένας υπολογιστής με ενσύρματη διεπαφή δικτύου. Μπορείς να εκτελέσεις εφαρμογές σε αυτόν (π.χ. ένα πρόγραμμα περιήγησης ιστού ή ένα εργαλείο ping) και να διαμορφώσεις την IP διεύθυνσή του.
Ταμπλέτα Όπως ένας υπολογιστής, αλλά συνδέεται μέσω Wi-Fi αντί για καλώδιο. Χρησιμοποίησέ τον μαζί με ένα σημείο πρόσβασης ή έναν δρομολογητή οικίας.
SW Διακόπτης Συνδέει πολλές συσκευές στο ίδιο τμήμα δικτύου. Προωθεί πλαίσια βάσει διευθύνσεων MAC. Υποστηρίζει VLAN και Spanning Tree Protocol (STP).
RT Δρομολογητής Συνδέει διαφορετικά δίκτυα και προωθεί πακέτα μεταξύ τους. Υποστηρίζει στατικές διαδρομές, OSPF, BGP και σήραγγες IP (VPN).
Δρομολογητής οικίας Ένας συνδυασμένος δρομολογητής, διακομιστής DHCP, πύλη NAT και σημείο πρόσβασης Wi-Fi — παρόμοιος με έναν τυπικό δρομολογητή διαδικτύου οικίας. Συνδέστε τον σε έναν δρομολογητή (ως WAN) και σε υπολογιστές ή ταμπλέτες (ως LAN/Wi-Fi). Υποστηρίζει κανόνες προώθησης θυρών.
Σημείο πρόσβασης Επεκτείνει ένα ενσύρματο δίκτυο με σύνδεση Wi-Fi. Συνδέστε τη θύρα ενσύρματης σύνδεσης του σε έναν διακόπτη ή δρομολογητή, στη συνέχεια συνδέστε ταμπλέτες σε αυτόν ασύρματα.
Τείχος προστασίας Φιλτράρει την κίνηση μεταξύ τμημάτων δικτύου βάσει διαμορφώσιμων κανόνων. Το πάνελ εμφανίζει το σύνολο κανόνων και ένα ζωντανό αρχείο καταγραφής των αντιστοιχισμένων πακέτων.

Πίνακες συσκευών

Κάνε κλικ σε οποιαδήποτε συσκευή στο καμβά για να ανοίξεις τον πίνακά της — ένα παράθυρο ρυθμίσεων που εμφανίζεται στη δεξιά πλευρά της οθόνης. Κάνε κλικ στη συσκευή ξανά (ή στο κουμπί × στην κεφαλίδα του πίνακα) για να το κλείσεις.

Μετονομασία συσκευής

Κάνε κλικ στο κουμπί δίπλα στο όνομα της συσκευής στην κεφαλίδα του πίνακα για να της δώσεις ένα προσαρμοσμένο όνομα (π.χ. "Office-PC" ή "Core-Router").

Καρτέλες δρομολογητή

Ένας πίνακας δρομολογητή έχει τις ακόλουθες καρτέλες:

  • Διεπαφές — ρύθμιση διευθύνσεων IP σε κάθε θύρα
  • Πίνακας δρομολόγησης IPv4 — προβολή και επεξεργασία δρομολογίων IPv4 (στατικών και μαθημένων)
  • Πίνακας δρομολόγησης IPv6 — προβολή και επεξεργασία δρομολογίων IPv6
  • OSPF — ρύθμιση και παρακολούθηση δυναμικής δρομολόγησης OSPF
  • BGP — ρύθμιση γειτόνων BGP και προβολή του πίνακα BGP
  • VPN — ρύθμιση σήραγγων IP μεταξύ δρομολογητών

Καρτέλες διακόπτη

Ένας πίνακας διακόπτη έχει καρτέλες για τον Πίνακα διευθύνσεων διακόπτη (SAT), ρύθμιση VLAN και ρυθμίσεις Spanning Tree Protocol (STP).

Καρτέλες δρομολογητή σπιτιού

Ένας πίνακας δρομολογητή σπιτιού έχει τις ακόλουθες καρτέλες:

  • Κατάσταση — επισκόπηση της τρέχουσας κατάστασης WAN/LAN και συνδεδεμένων πελατών
  • WAN — ρύθμιση της ανάντη σύνδεσης (στατική IP ή DHCP)
  • LAN — ρύθμιση του δικτύου LAN και της διεύθυνσης IP
  • DHCP — προβολή ενεργών μισθώσεων και ρύθμιση της δεξαμενής DHCP
  • WiFi — ρύθμιση του ενσωματωμένου σημείου πρόσβασης (SSID, κωδικός)
  • NAT — προβολή του ενεργού πίνακα σύνδεσης NAT
  • Προώθηση θυρών — ορισμός κανόνων για προώθηση εισερχόμενων θυρών σε κεντρικούς υπολογιστές LAN

Καρτέλες τείχους προστασίας

Ένας πίνακας τείχους προστασίας έχει μια καρτέλα Κανόνες για τη διαχείριση κανόνων φίλτρου και μια καρτέλα Αρχείο καταγραφής που δείχνει ποια πακέτα έχουν επιτραπεί ή απορριφθεί.

Υπολογιστής και ταμπλέτα

Οι υπολογιστές και οι ταμπλέτες έχουν ένα πλήρες προσομοιωμένο λειτουργικό σύστημα μέσα στον πίνακά τους. Μπορείς να ανοίξεις εφαρμογές από την επιφάνεια εργασίας, να ρυθμίσεις τις ρυθμίσεις δικτύου και να εκτελέσεις εντολές.

Λειτουργία εκτέλεσης — Εκτέλεση της προσομοίωσης

Μεταβείτε στη λειτουργία Εκτέλεση για να ξεκινήσετε την προσομοίωση. Το δίκτυο γίνεται ενεργό: οι συσκευές ανταλλάσσουν πακέτα, ανατίθενται μισθώσεις DHCP, ενημερώνονται οι πίνακες δρομολόγησης κ.ο.κ.

Έλεγχοι ταχύτητας

Χρησιμοποιήστε τα κουμπιά ταχύτητας στην επάνω γραμμή εργαλείων για να ελέγξετε την ταχύτητα εκτέλεσης της προσομοίωσης:

0,5×Αργή — καλή για παρατήρηση μεμονωμένων βημάτων
1×Κανονική ταχύτητα
4×Γρήγορη
8×Πολύ γρήγορη

Παύση και επαναφορά

Παύση Καταψύξτε την προσομοίωση στην τρέχουσα κατάστασή της.
Επαναφορά Επανεκκινήστε την προσομοίωση από την αρχή (όλη η δυναμική κατάσταση διαγράφεται).

Σημείωση: Δεν μπορείτε να επεξεργαστείτε την τοπολογία του δικτύου ενώ είστε σε λειτουργία εκτέλεσης. Μεταβείτε πρώτα στη λειτουργία Επεξεργασία.

Λειτουργία ανίχνευσης — Ανάλυση πακέτων

Μετάβαση στη λειτουργία Ανίχνευσης για να ανοίξεις τον ενσωματωμένο αναλυτή πακέτων — παρόμοιο με το Wireshark.

Στο επάνω μέρος, επέλεξε τη συσκευή και τη θύρα από την οποία θέλεις να καταγράψεις. Όλα τα πακέτα που διέρχονται από αυτή τη θύρα καταγράφονται και εμφανίζονται σε μια λίστα.

Κάνε κλικ σε οποιοδήποτε πακέτο στη λίστα για να δεις τις πλήρεις λεπτομέρειές του: τα στρώματα πρωτοκόλλου, τα πεδία κεφαλίδας και το φορτίο — ακριβώς όπως θα τα εμφάνιζε ένα επαγγελματικό εργαλείο δικτύου.

Η καταγραφή εκτελείται αυτόματα κατά την εκτέλεση της προσομοίωσης. Μπορείς να εναλλάσσεσαι μεταξύ της λειτουργίας Ανίχνευσης και της λειτουργίας Εκτέλεσης ανά πάσα στιγμή χωρίς να χάσεις τα καταγεγραμμένα δεδομένα.

Αποθήκευση και φόρτωση

Ο σχεδιασμός του δικτύου σου μπορεί να αποθηκευτεί ως αρχείο και να φορτωθεί ξανά αργότερα. Χρησιμοποίησε τα κουμπιά στη γραμμή εργαλείων στο πάνω μέρος (ορατά στη λειτουργία επεξεργασίας):

Νέο Ξεκίνησε με ένα κενό καμβά. Οποιεσδήποτε αποθήκευτες αλλαγές θα χαθούν.
Φόρτωση Άνοιξε ένα προηγουμένως αποθηκευμένο αρχείο προσομοίωσης.
Αποθήκευση Λήψε την τρέχουσα προσομοίωση ως αρχείο στον υπολογιστή σου.

Έχεις κάποιο πρόβλημα; Έλεγξε ότι το δίκτυό σου είναι σωστά συνδεδεμένο και ότι όλες οι συσκευές έχουν έγκυρες διευθύνσεις IP διαμορφωμένες.

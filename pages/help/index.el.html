Οι Τρεις Λειτουργίες

Το BeaverTracer έχει τρεις λειτουργίες. Μεταγραφείς μεταξύ τους χρησιμοποιώντας τα κουμπιά στην επάνω γραμμή εργαλείων.

Επεξεργασία Σχεδιάστε το δίκτυό σας — τοποθετήστε συσκευές, συνδέστε τις, ρυθμίστε τις.
Εκτέλεση Ξεκινήστε την προσομοίωση και παρακολουθήστε την κίνηση δεδομένων να ρέει μέσα από το δίκτυό σας.
Ανίχνευση Καταγράψτε και επιθεωρήστε τα πακέτα που ταξιδεύουν στο δίκτυό σας.

Λειτουργία Επεξεργασίας — Κατασκευή Δικτύου

Στη Λειτουργία Επεξεργασίας, εμφανίζεται μια γραμμή εργαλείων στην αριστερή πλευρά της οθόνης. Επίλεξε ένα εργαλείο κάνοντας κλικ σε αυτό, και στη συνέχεια χρησιμοποίησέ το στον καμβά.

Εργαλεία

Επιλογή Κάνε κλικ σε μια συσκευή για να ανοίξει το πάνελ της. Σύρε μια συσκευή για να τη μετακινήσεις.
Σύνδεση Σύνδεσε δύο συσκευές με ένα καλώδιο (δες παρακάτω).
Κείμενο Τοποθέτησε μια ετικέτα κειμένου στον καμβά για να σχολιάσεις το διάγραμμά σου.
Ορθογώνιο Σχεδίασε ένα ορθογώνιο στον καμβά για να ομαδοποιήσεις οπτικά τις συσκευές.
Διαγραφή Κάνε κλικ σε μια συσκευή ή καλώδιο για να τα αφαιρέσεις.

Συμβουλή: Κάνε δεξί κλικ οπουδήποτε στον καμβά για να ακυρώσεις το τρέχον εργαλείο και να επιστρέψεις στο Επιλογή.

Τοποθέτηση Συσκευής

  1. Κάνε κλικ σε ένα κουμπί συσκευής στη γραμμή εργαλείων στα αριστερά (π.χ. PC).
  2. Μια προεπισκόπηση ακολουθεί τον δείκτη του ποντικιού σου.
  3. Κάνε κλικ στον καμβά για να τοποθετήσεις τη συσκευή.

Σύνδεση Δύο Συσκευών

  1. Κάνε κλικ στο εργαλείο Σύνδεση.
  2. Κάνε κλικ στην πρώτη συσκευή — εμφανίζεται ένα πρόγραμμα επιλογής θύρας. Επίλεξε μια θύρα.
  3. Μετακίνησε το ποντικί σου στη δεύτερη συσκευή και κάνε κλικ σε αυτήν — επίλεξε και μια θύρα εκεί.
  4. Το καλώδιο δημιουργείται αυτόματα.

Οι θύρες που χρησιμοποιούνται ήδη εμφανίζονται ως απενεργοποιημένες και δεν μπορούν να επιλεγούν.

Μετακίνηση Συσκευής

Στη λειτουργία Επιλογή, κάνε κλικ και σύρε οποιαδήποτε συσκευή για να την αναθέσεις ξανά στον καμβά.

Διαγραφή Συσκευής ή Καλωδίου

  1. Κάνε κλικ στο εργαλείο Διαγραφή.
  2. Κάνε κλικ στη συσκευή ή στο καλώδιο που θέλεις να αφαιρέσεις.

Όταν διαγράψεις μια συσκευή, όλα τα καλώδια που είναι συνδεδεμένα σε αυτήν αφαιρούνται αυτόματα.

Συσκευές

Αυτές οι συσκευές είναι διαθέσιμες στη αριστερή γραμμή εργαλείων κατά τη λειτουργία Επεξεργασίας:

PC Ένας προσωπικός υπολογιστής με ενσύρματη διεπαφή δικτύου. Μπορείς να εκτελέσεις εφαρμογές σε αυτόν (π.χ. ένα πρόγραμμα περιήγησης ιστού ή ένα εργαλείο ping) και να διαμορφώσεις τη διεύθυνση IP του.
Laptop Όπως ένα PC, αλλά συνδέεται μέσω Wi-Fi αντί για καλώδιο. Χρησιμοποίησέ το μαζί με ένα Access Point ή ένα Home Router.
SW Switch Συνδέει πολλές συσκευές στο ίδιο τμήμα δικτύου. Προωθεί πλαίσια με βάση τις διευθύνσεις MAC. Υποστηρίζει VLANs και Spanning Tree Protocol (STP).
RT Router Συνδέει διαφορετικά δίκτυα και προωθεί πακέτα μεταξύ τους. Υποστηρίζει στατικές διαδρομές, OSPF, BGP και σήραγγες IP (VPN).
Home Router Ένας συνδυασμένος δρομολογητής, διακομιστής DHCP, πύλη NAT και σημείο πρόσβασης Wi-Fi — παρόμοιος με ένα τυπικό δρομολογητή διαδικτύου για το σπίτι. Συνδέσ του με ένα Router (ως WAN) και με PCs ή Laptops (ως LAN/Wi-Fi). Υποστηρίζει κανόνες προώθησης θυρών.
Access Point Επεκτείνει ένα ενσύρματο δίκτυο με μια σύνδεση Wi-Fi. Συνδέσ τη ενσύρματη θύρα του σε ένα Switch ή Router, και έπειτα συνδέσ τα Laptops σε αυτό ασύρματα.
Firewall Φιλτράρει την κίνηση μεταξύ τμημάτων δικτύου με βάση παραμετροποιήσιμους κανόνες. Το πάνελ εμφανίζει το σύνολο κανόνων και ένα ζωντανό αρχείο καταγραφής των ταιριασμένων πακέτων.

Πίνακες Συσκευών

Κάνε κλικ σε οποιαδήποτε συσκευή στον καμβά για να ανοίξεις το πάνελ της — ένα παράθυρο διαμόρφωσης που εμφανίζεται στη δεξιά πλευρά της οθόνης. Κάνε κλικ στη συσκευή ξανά (ή στο κουμπί × στην κεφαλίδα του πάνελ) για να το κλείσεις.

Μετονομασία Συσκευής

Κάνε κλικ στο κουμπί δίπλα στο όνομα της συσκευής στην κεφαλίδα του πάνελ για να της δώσεις ένα προσαρμοσμένο όνομα (π.χ. "Office-PC" ή "Core-Router").

Καρτέλες Δρομολογητή

Ένα πάνελ Δρομολογητή έχει τις παρακάτω καρτέλες:

  • Διεπαφές — διαμόρφωση διευθύνσεων IP σε κάθε θύρα
  • Πίνακας δρομολόγησης IPv4 — προβολή και επεξεργασία διαδρομών IPv4 (στατικές και μαθημένες)
  • Πίνακας δρομολόγησης IPv6 — προβολή και επεξεργασία διαδρομών IPv6
  • OSPF — διαμόρφωση και παρακολούθηση δυναμικής δρομολόγησης OSPF
  • BGP — διαμόρφωση γειτόνων BGP και προβολή του πίνακα BGP
  • VPN — ρύθμιση σήραγγων IP μεταξύ δρομολογητών

Καρτέλες Διακόπτη

Ένα πάνελ Διακόπτη έχει καρτέλες για τον Πίνακα Διευθύνσεων Διακόπτη (SAT), τη διαμόρφωση VLAN και τις ρυθμίσεις Spanning Tree Protocol (STP).

Καρτέλες Δρομολογητή Οικιακού

Ένα πάνελ Δρομολογητή Οικιακού έχει τις παρακάτω καρτέλες:

  • Κατάσταση — επισκόπηση της τρέχουσας κατάστασης WAN/LAN και συνδεδεμένων πελατών
  • WAN — διαμόρφωση της ανοδικής σύνδεσης (στατική IP ή DHCP)
  • LAN — διαμόρφωση του υποδικτύου LAN και της διεύθυνσης IP
  • DHCP — προβολή ενεργών δανείων και διαμόρφωση του χώρου διευθύνσεων DHCP
  • WiFi — διαμόρφωση του ενσωματωμένου σημείου πρόσβασης (SSID, κωδικός πρόσβασης)
  • NAT — προβολή του πίνακα ενεργών συνδέσεων NAT
  • Προώθηση Θυρών — καθορισμός κανόνων για προώθηση εισερχόμενων θυρών σε κεντρικούς υπολογιστές LAN

Καρτέλες Τείχους Προστασίας

Ένα πάνελ Τείχους Προστασίας έχει μια καρτέλα Κανόνες για διαχείριση κανόνων φιλτραρίσματος και μια καρτέλα Αρχείο καταγραφής που δείχνει ποια πακέτα έχουν επιτραπεί ή απορριφθεί.

PC και Laptop

Τα PC και τα Laptops έχουν ένα πλήρως προσομοιωμένο λειτουργικό σύστημα μέσα στο πάνελ τους. Μπορείς να ανοίξεις εφαρμογές από την επιφάνεια εργασίας, να διαμορφώσεις τις ρυθμίσεις δικτύου και να εκτελέσεις εντολές.

Λειτουργία Εκτέλεσης — Εκτέλεση της Προσομοίωσης

Μετάβαση στη λειτουργία Εκτέλεση για να ξεκινήσεις την προσομοίωση. Το δίκτυο γίνεται ενεργό: οι συσκευές ανταλλάσσουν πακέτα, εκχωρούνται DHCP leases, ενημερώνονται οι πίνακες δρομολόγησης, και ούτω καθεξής.

Έλεγχος Ταχύτητας

Χρησιμοποίησε τα κουμπιά ταχύτητας στη γραμμή εργαλείων για να ελέγξεις πόσο γρήγορα εκτελείται η προσομοίωση:

0.5×Αργή — καλή για παρατήρηση μεμονωμένων βημάτων
1×Κανονική ταχύτητα
4×Γρήγορη
8×Πολύ γρήγορη

Παύση και Επαναφορά

Παύση Παγώνει την προσομοίωση στην τρέχουσα κατάστασή της.
Επαναφορά Επανάληψη της προσομοίωσης από την αρχή (όλη η δυναμική κατάσταση διαγράφεται).

Σημείωση: Δεν μπορείς να επεξεργαστείς την τοπολογία του δικτύου ενώ είσαι σε λειτουργία Εκτέλεσης. Μετάβαση πίσω στη λειτουργία Επεξεργασία πρώτα.

Λειτουργία Ανίχνευσης — Ανάλυση Πακέτων

Μετάβαση στη Ανίχνευση λειτουργία για να ανοίξεις τον ενσωματωμένο αναλυτή πακέτων — παρόμοιος με το Wireshark.

Στην κορυφή, επέλεξε τη συσκευή και τη θύρα από την οποία θέλεις να καταγράψεις. Όλα τα πακέτα που διέρχονται από αυτή τη θύρα καταγράφονται και εμφανίζονται σε μια λίστα.

Κάνε κλικ σε οποιοδήποτε πακέτο στη λίστα για να δεις τις πλήρεις λεπτομέρειες του: τα επίπεδα πρωτοκόλλου, τα πεδία κεφαλίδας και το περιεχόμενο — ακριβώς όπως θα τα έδειχνε ένα επαγγελματικό εργαλείο δικτύου.

Η καταγραφή εκτελείται αυτόματα ενώ η προσομοίωση εκτελείται. Μπορείς να μεταβείς μεταξύ της λειτουργίας Ανίχνευσης και της λειτουργίας Εκτέλεσης ανά πάσα στιγμή χωρίς να χάσεις τα καταγεγραμμένα δεδομένα.

Αποθήκευση και Φόρτωση

Το σχέδιό σου του δικτύου μπορεί να αποθηκευτεί ως αρχείο και να φορτωθεί ξανά αργότερα. Χρησιμοποίησε τα κουμπιά στη γραμμή εργαλείων στην κορυφή (ορατά σε λειτουργία επεξεργασίας):

Νέο Ξεκίνησε με κενό καμβά. Τυχόν αναποθήκευτες αλλαγές θα χαθούν.
Φόρτωση Άνοιξε ένα αρχείο προσομοίωσης που είχες αποθηκεύσει προηγουμένως.
Αποθήκευση Κατέβασε την τρέχουσα προσομοίωση ως αρχείο στον υπολογιστή σου.

Έχεις κάποιο πρόβλημα; Έλεγξε ότι το δίκτυό σου είναι σωστά συνδεδεμένο και ότι όλες οι συσκευές έχουν έγκυρες διευθύνσεις IP ρυθμισμένες.

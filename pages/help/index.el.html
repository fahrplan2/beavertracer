Οι Τρεις Λειτουργίες

Το Beaver Tracer έχει τρεις λειτουργίες. Μπορείτε να εναλλάσσεστε μεταξύ τους χρησιμοποιώντας τα κουμπιά στη γραμμή εργαλείων στο πάνω μέρος.

Επεξεργασία Σχεδιάστε το δίκτυό σας — τοποθετήστε συσκευές, συνδέστε τις, ρυθμίστε τις.
Εκτέλεση Ξεκινήστε την προσομοίωση και παρακολουθήστε την κίνηση που διακινείται στο δίκτυό σας.
Ανίχνευση Καταγράψτε και επιθεωρήστε τα πακέτα που ταξιδεύουν στο δίκτυό σας.

Λειτουργία Επεξεργασίας — Κατασκευή Δικτύου

Στη λειτουργία Επεξεργασίας, εμφανίζεται μια γραμμή εργαλείων στην αριστερή πλευρά της οθόνης. Επιλέξτε ένα εργαλείο κάνοντας κλικ σε αυτό, στη συνέχεια χρησιμοποιήστε το στον καμβά.

Εργαλεία

Επιλογή Κάντε κλικ σε μια συσκευή για να ανοίξετε τον πίνακά της. Σύρετε μια συσκευή για να την μετακινήσετε.
Σύνδεσμος Συνδέστε δύο συσκευές με ένα καλώδιο (δείτε παρακάτω).
Διαγραφή Κάντε κλικ σε μια συσκευή ή ένα καλώδιο για να το αφαιρέσετε.

Συμβουλή: Κάντε δεξί κλικ οπουδήποτε στον καμβά για να ακυρώσετε το τρέχον εργαλείο και να επιστρέψετε στην Επιλογή.

Τοποθέτηση Συσκευής

  1. Κάντε κλικ σε ένα κουμπί συσκευής στη γραμμή εργαλείων στα αριστερά (π.χ. PC).
  2. Μια προεπισκόπηση ακολουθεί τον δείκτη του ποντικιού σας.
  3. Κάντε κλικ στον καμβά για να τοποθετήσετε τη συσκευή.

Σύνδεση Δύο Συσκευών

  1. Κάντε κλικ στο εργαλείο Σύνδεσμος.
  2. Κάντε κλικ στην πρώτη συσκευή — εμφανίζεται ένας επιλογέας θύρας. Επιλέξτε μια θύρα.
  3. Μετακινήστε το ποντίκι σας στη δεύτερη συσκευή και κάντε κλικ σε αυτή — επιλέξτε και εκεί μια θύρα.
  4. Το καλώδιο δημιουργείται αυτόματα.

Οι θύρες που χρησιμοποιούνται ήδη εμφανίζονται ως απενεργοποιημένες και δεν μπορούν να επιλεγούν.

Μετακίνηση Συσκευής

Στη λειτουργία Επιλογή, κάντε κλικ και σύρετε οποιαδήποτε συσκευή για να την αναθέσετε στον καμβά.

Διαγραφή Συσκευής ή Καλωδίου

  1. Κάντε κλικ στο εργαλείο Διαγραφή.
  2. Κάντε κλικ στη συσκευή ή το καλώδιο που θέλετε να αφαιρέσετε.

Όταν διαγράφετε μια συσκευή, όλα τα καλώδια που είναι συνδεδεμένα σε αυτή αφαιρούνται αυτόματα.

Συσκευές

Αυτές οι συσκευές είναι διαθέσιμες στη γραμμή εργαλείων στα αριστερά κατά τη λειτουργία Επεξεργασίας:

PC Ένας προσωπικός υπολογιστής με μια σύρματη διεπαφή δικτύου. Μπορείτε να εκτελέσετε εφαρμογές σε αυτό (π.χ. ένα πρόγραμμα περιήγησης ιστού ή ένα εργαλείο ping) και να ρυθμίσετε τη διεύθυνση IP του.
Laptop Όπως ένα PC, αλλά συνδέεται μέσω Wi-Fi αντί για καλώδιο. Χρησιμοποιήστε το μαζί με ένα Access Point ή Home Router.
SW Switch Συνδέει πολλές συσκευές στο ίδιο τμήμα δικτύου. Προωθεί πλαίσια με βάση τις διευθύνσεις MAC. Υποστηρίζει VLANs και Spanning Tree Protocol (STP).
RT Router Συνδέει διαφορετικά δίκτυα και προωθεί πακέτα μεταξύ τους. Μπορείτε να ρυθμίσετε στατικές διαδρομές και διευθύνσεις IP σε κάθε διεπαφή.
Home Router Ένας συνδυασμένος δρομολογητής, διακομιστής DHCP, πύλη NAT και σημείο πρόσβασης Wi-Fi — παρόμοιος με ένα τυπικό δρομολογητή διαδικτύου οικίας. Συνδέστε το σε ένα Router (ως WAN) και σε PC ή Laptops (ως LAN/Wi-Fi).
Access Point Επεκτείνει ένα σύρματο δίκτυο με μια σύνδεση Wi-Fi. Συνδέστε τη σύρματη θύρα του σε ένα Switch ή Router, στη συνέχεια συνδέστε Laptops σε αυτό ασύρματα.

Πίνακες Συσκευών

Κάντε κλικ σε οποιαδήποτε συσκευή στον καμβά για να ανοίξετε τον πίνακά της — ένα παράθυρο ρύθμισης παραμέτρων που εμφανίζεται στη δεξιά πλευρά της οθόνης. Κάντε κλικ στη συσκευή ξανά (ή το κουμπί × στην κεφαλίδα του πίνακα) για να το κλείσετε.

Μετονομασία Συσκευής

Κάντε κλικ στο κουμπί δίπλα στο όνομα της συσκευής στην κεφαλίδα του πίνακα για να του δώσετε ένα προσαρμοσμένο όνομα (π.χ. "Office-PC" ή "Core-Router").

Καρτέλες

Οι περισσότερες συσκευές έχουν πολλές καρτέλες μέσα στον πίνακα. Για παράδειγμα, ένας Router έχει:

  • Διεπαφές — ρυθμίστε διευθύνσεις IP σε κάθε θύρα
  • Πίνακας δρομολόγησης IPv4 — προβολή και επεξεργασία στατικών διαδρομών IPv4
  • Πίνακας δρομολόγησης IPv6 — προβολή και επεξεργασία στατικών διαδρομών IPv6

Ένα Switch έχει καρτέλες για τον Πίνακα Διευθύνσεων Switch (SAT), ρύθμιση VLAN και ρυθμίσεις Spanning Tree Protocol (STP).

Ένα Home Router έχει καρτέλες για Κατάσταση, ρυθμίσεις WAN και μισθώσεις DHCP.

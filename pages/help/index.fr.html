Les trois modes

BeaverTracer a trois modes. Tu les utilises en cliquant sur les boutons dans la barre d'outils supérieure.

Édition Conçois ton réseau — place des appareils, connecte-les, configure-les.
Exécution Lance la simulation et observe le trafic circuler dans ton réseau.
Trace Capture et inspecte les paquets qui circulent dans ton réseau.

Mode édition — construire un réseau

En mode édition, une barre d'outils apparaît sur le côté gauche de l'écran. Sélectionne un outil en cliquant dessus, puis utilise-le sur le canevas.

Outils

Sélectionner Clique sur un appareil pour ouvrir son panneau. Glisse un appareil pour le déplacer.
Lien Connecte deux appareils avec un câble (voir ci-dessous).
Texte Place une étiquette de texte sur le canevas pour annoter ton diagramme.
Rectangle Dessine un rectangle sur le canevas pour regrouper visuellement les appareils.
Supprimer Clique sur un appareil ou un câble pour le supprimer.

Conseil : Fais un clic droit n'importe où sur le canevas pour annuler l'outil actuel et revenir à Sélectionner.

Placer un appareil

  1. Clique sur un bouton d'appareil dans la barre d'outils de gauche (p. ex. Ordinateur).
  2. Un aperçu suit ton curseur de souris.
  3. Clique sur le canevas pour placer l'appareil.

Connecter deux appareils

  1. Clique sur l'outil Lien.
  2. Clique sur le premier appareil — un sélecteur de port apparaît. Sélectionne un port.
  3. Déplace ta souris vers le deuxième appareil et clique dessus — sélectionne aussi un port là.
  4. Le câble est créé automatiquement.

Les ports qui sont déjà en usage sont affichés comme désactivés et ne peuvent pas être sélectionnés.

Déplacer un appareil

En mode Sélectionner, clique et glisse n'importe quel appareil pour le repositionner sur le canevas.

Supprimer un appareil ou un câble

  1. Clique sur l'outil Supprimer.
  2. Clique sur l'appareil ou le câble que tu veux supprimer.

Quand tu supprimes un appareil, tous les câbles connectés à celui-ci sont supprimés automatiquement.

Appareils

Ces appareils sont disponibles dans la barre d'outils de gauche en mode Édition :

Ordinateur Un ordinateur avec une interface réseau filaire. Tu peux exécuter des applications dessus (par exemple un navigateur web ou un outil ping) et configurer son adresse IP.
Tablette Comme un ordinateur, mais se connecte via Wi-Fi au lieu d'un câble. Utilise-la avec un point d'accès ou un routeur personnel.
SW Commutateur Connecte plusieurs appareils dans le même segment réseau. Transmet les trames en fonction des adresses MAC. Supporte les VLAN et le protocole Spanning Tree (STP).
RT Routeur Connecte différents réseaux et transfère les paquets entre eux. Supporte les routes statiques, OSPF, BGP et les tunnels IP (VPN).
Routeur personnel Un routeur combiné, serveur DHCP, passerelle NAT et point d'accès Wi-Fi — similaire à un routeur Internet personnel typique. Connecte-le à un routeur (comme WAN) et à des ordinateurs ou tablettes (comme LAN/Wi-Fi). Supporte les règles de redirection de ports.
Point d'accès Étend un réseau filaire avec une connexion Wi-Fi. Connecte son port filaire à un commutateur ou un routeur, puis connecte les tablettes sans fil.
Pare-feu Filtre le trafic entre les segments réseau en fonction de règles configurables. Le panneau affiche l'ensemble des règles et un journal en direct des paquets correspondants.

Panneaux d'appareil

Clique sur n'importe quel appareil sur la toile pour ouvrir son panneau — une fenêtre de configuration qui apparaît sur le côté droit de l'écran. Clique à nouveau sur l'appareil (ou sur le bouton × dans l'en-tête du panneau) pour le fermer.

Renommer un appareil

Clique sur le bouton à côté du nom de l'appareil dans l'en-tête du panneau pour lui donner un nom personnalisé (par ex. « Office-PC » ou « Core-Router »).

Onglets du routeur

Un panneau de routeur a les onglets suivants :

  • Interfaces — configure les adresses IP sur chaque port
  • Table de routage IPv4 — affiche et édite les routes IPv4 (statiques et apprises)
  • Table de routage IPv6 — affiche et édite les routes IPv6
  • OSPF — configure et supervise le routage dynamique OSPF
  • BGP — configure les voisins BGP et affiche la table BGP
  • VPN — configure les tunnels IP entre routeurs

Onglets du commutateur

Un panneau de commutateur a des onglets pour sa table d'adresses du commutateur (SAT), la configuration VLAN et les paramètres du protocole STP (Spanning Tree Protocol).

Onglets du routeur domestique

Un panneau de routeur domestique a les onglets suivants :

  • État — aperçu de l'état actuel WAN/LAN et des clients connectés
  • WAN — configure la liaison montante (IP statique ou DHCP)
  • LAN — configure le sous-réseau LAN et l'adresse IP
  • DHCP — affiche les baux actifs et configure le pool DHCP
  • WiFi — configure le point d'accès intégré (SSID, mot de passe)
  • NAT — affiche la table active des connexions NAT
  • Redirection de port — définit les règles pour rediriger les ports entrants vers les hôtes LAN

Onglets du pare-feu

Un panneau de pare-feu a un onglet Règles pour gérer les règles de filtrage et un onglet Journal montrant quels paquets ont été autorisés ou bloqués.

Ordinateur et tablette

Les ordinateurs et les tablettes ont un système d'exploitation entièrement simulé dans leur panneau. Tu peux ouvrir des applications à partir du bureau, configurer les paramètres réseau et exécuter des commandes.

Mode exécution — Exécuter la simulation

Passe au mode Exécution pour démarrer la simulation. Le réseau devient actif : les appareils échangent des paquets, les baux DHCP sont assignés, les tables de routage se mettent à jour, et ainsi de suite.

Contrôles de vitesse

Utilise les boutons de vitesse dans la barre d'outils supérieure pour contrôler la vitesse d'exécution de la simulation :

0,5×Lent — bon pour observer les étapes individuelles
1×Vitesse normale
4×Rapide
8×Très rapide

Pause et réinitialisation

Pause Gèle la simulation dans son état actuel.
Réinitialisation Redémarre la simulation depuis le début (tout l'état dynamique est effacé).

Remarque : Tu ne peux pas modifier la topologie du réseau en mode Exécution. Reviens d'abord au mode Édition.

Mode trace — Analyser les paquets

Bascule vers le mode Trace pour ouvrir l'analyseur de paquets intégré — similaire à Wireshark.

En haut, sélectionne le périphérique et le port à partir desquels tu veux capturer. Tous les paquets passant par ce port sont enregistrés et affichés dans une liste.

Clique sur n'importe quel paquet dans la liste pour voir ses détails complets : les couches de protocole, les champs d'en-tête et la charge utile — exactement comme un outil réseau professionnel les afficherait.

La capture s'exécute automatiquement pendant que la simulation est en cours. Tu peux basculer entre le mode Trace et le mode Exécution à tout moment sans perdre les données capturées.

Enregistrement et chargement

Tu peux enregistrer ta conception réseau dans un fichier et la charger à nouveau plus tard. Utilise les boutons dans la barre d'outils en haut (visibles en mode Édition) :

Nouveau Commence avec un canevas vierge. Toutes les modifications non enregistrées seront perdues.
Charger Ouvre un fichier de simulation précédemment enregistré.
Enregistrer Télécharge la simulation actuelle en tant que fichier sur ton ordinateur.

Tu as des problèmes ? Vérifie que ton réseau est correctement connecté et que tous les appareils ont des adresses IP valides configurées.

Les trois modes

Beaver Tracer a trois modes. Tu peux passer de l'un à l'autre en utilisant les boutons de la barre d'outils supérieure.

Édition Conçois ton réseau — place les appareils, connecte-les, configure-les.
Exécution Lance la simulation et regarde le trafic circuler dans ton réseau.
Trace Capture et inspecte les paquets qui circulent sur ton réseau.

Mode Édition — Construire un réseau

En mode Édition, une barre d'outils apparaît sur le côté gauche de l'écran. Sélectionne un outil en cliquant dessus, puis utilise-le sur le canevas.

Outils

Sélectionner Clique sur un appareil pour ouvrir son panneau. Fais glisser un appareil pour le déplacer.
Lien Connecte deux appareils avec un câble (voir ci-dessous).
Texte Place une étiquette de texte sur le canevas pour annoter ton diagramme.
Rectangle Dessine un rectangle sur le canevas pour regrouper visuellement les appareils.
Supprimer Clique sur un appareil ou un câble pour le supprimer.

Conseil : Fais un clic droit n'importe où sur le canevas pour annuler l'outil actuel et revenir à Sélectionner.

Placer un appareil

  1. Clique sur un bouton d'appareil dans la barre d'outils gauche (par ex. PC).
  2. Un aperçu suit ton curseur de souris.
  3. Clique sur le canevas pour placer l'appareil.

Connecter deux appareils

  1. Clique sur l'outil Lien.
  2. Clique sur le premier appareil — un sélecteur de port apparaît. Sélectionne un port.
  3. Déplace ta souris vers le deuxième appareil et clique dessus — sélectionne aussi un port là-bas.
  4. Le câble est créé automatiquement.

Les ports déjà utilisés sont affichés comme désactivés et ne peuvent pas être sélectionnés.

Déplacer un appareil

En mode Sélectionner, clique et fais glisser n'importe quel appareil pour le repositionner sur le canevas.

Supprimer un appareil ou un câble

  1. Clique sur l'outil Supprimer.
  2. Clique sur l'appareil ou le câble que tu veux supprimer.

Quand tu supprimes un appareil, tous les câbles qui y sont connectés sont supprimés automatiquement.

Appareils

Ces appareils sont disponibles dans la barre d'outils de gauche pendant le mode Édition :

PC Un ordinateur personnel avec une interface réseau câblée. Tu peux exécuter des applications dessus (par ex. un navigateur web ou un outil ping) et configurer son adresse IP.
Laptop Comme un PC, mais se connecte via Wi-Fi au lieu d'un câble. Utilise-le avec un Point d'accès ou un Routeur domestique.
SW Switch Connecte plusieurs appareils dans le même segment réseau. Transfère les trames en fonction des adresses MAC. Supporte les VLANs et le protocole Spanning Tree (STP).
RT Routeur Connecte différents réseaux et transfère les paquets entre eux. Supporte les routes statiques, OSPF, BGP et les tunnels IP (VPN).
Routeur domestique Un routeur combiné, serveur DHCP, passerelle NAT et point d'accès Wi-Fi — similaire à un routeur internet domestique typique. Connecte-le à un Routeur (en tant que WAN) et à des PCs ou Laptops (en tant que LAN/Wi-Fi). Supporte les règles de redirection de ports.
Point d'accès Étend un réseau câblé avec une connexion Wi-Fi. Connecte son port câblé à un Switch ou Routeur, puis connecte les Laptops sans fil.
Pare-feu Filtre le trafic entre les segments réseau en fonction de règles configurables. Le panneau affiche l'ensemble des règles et un journal en direct des paquets correspondants.

Panneaux des appareils

Clique sur n'importe quel appareil sur le canevas pour ouvrir son panneau — une fenêtre de configuration qui apparaît sur le côté droit de l'écran. Clique à nouveau sur l'appareil (ou sur le bouton × dans l'en-tête du panneau) pour le fermer.

Renommer un appareil

Clique sur le bouton à côté du nom de l'appareil dans l'en-tête du panneau pour lui donner un nom personnalisé (par exemple « Office-PC » ou « Core-Router »).

Onglets du routeur

Un panneau Routeur a les onglets suivants :

  • Interfaces — configure les adresses IP sur chaque port
  • Table de routage IPv4 — affiche et modifie les routes IPv4 (statiques et apprises)
  • Table de routage IPv6 — affiche et modifie les routes IPv6
  • OSPF — configure et surveille le routage dynamique OSPF
  • BGP — configure les voisins BGP et affiche la table BGP
  • VPN — configure des tunnels IP entre les routeurs

Onglets du Switch

Un panneau Switch a des onglets pour la Table d'adresses du Switch (SAT), la configuration VLAN et les paramètres du Spanning Tree Protocol (STP).

Onglets du routeur domestique

Un panneau Routeur domestique a les onglets suivants :

  • État — aperçu de l'état WAN/LAN actuel et des clients connectés
  • WAN — configure la liaison montante (adresse IP statique ou DHCP)
  • LAN — configure le sous-réseau LAN et l'adresse IP
  • DHCP — affiche les baux actifs et configure le pool DHCP
  • WiFi — configure le point d'accès intégré (SSID, mot de passe)
  • NAT — affiche la table de connexion NAT active
  • Redirection de port — définit les règles pour rediriger les ports entrants vers les hôtes LAN

Onglets du pare-feu

Un panneau Pare-feu a un onglet Règles pour gérer les règles de filtrage et un onglet Journal qui montre quels paquets ont été autorisés ou rejetés.

PC et ordinateur portable

Les PC et ordinateurs portables ont un système d'exploitation entièrement simulé à l'intérieur de leur panneau. Tu peux ouvrir des applications à partir du bureau, configurer les paramètres réseau et exécuter des commandes.

Mode Exécution — Lancer la simulation

Bascule vers le mode Exécution pour démarrer la simulation. Le réseau devient actif : les appareils échangent des paquets, les baux DHCP sont attribués, les tables de routage se mettent à jour, et ainsi de suite.

Contrôles de vitesse

Utilise les boutons de vitesse dans la barre d'outils supérieure pour contrôler la rapidité d'exécution de la simulation :

0,5×Lent — idéal pour observer les étapes individuelles
1×Vitesse normale
4×Rapide
8×Très rapide

Pause et Réinitialisation

Pause Gèle la simulation dans son état actuel.
Réinitialisation Relance la simulation depuis le début (tous les états dynamiques sont effacés).

Remarque : Tu ne peux pas modifier la topologie du réseau en mode Exécution. Bascule d'abord vers le mode Édition.

Mode Trace — Analyser les paquets

Bascule vers le mode Trace pour ouvrir l'analyseur de paquets intégré — similaire à Wireshark.

En haut, sélectionne l'appareil et le port à partir desquels tu veux capturer. Tous les paquets passant par ce port sont enregistrés et affichés dans une liste.

Clique sur n'importe quel paquet dans la liste pour voir ses détails complets : les couches de protocole, les champs d'en-tête et la charge utile — exactement comme le montrerait un outil réseau professionnel.

La capture s'exécute automatiquement pendant que la simulation est en cours. Tu peux basculer entre le mode Trace et le mode Exécution à tout moment sans perdre les données capturées.

Sauvegarde et chargement

Tu peux sauvegarder ta conception réseau dans un fichier et la charger à nouveau plus tard. Utilise les boutons dans la barre d'outils supérieure (visibles en mode Édition) :

Nouveau Commencer avec une toile vierge. Les modifications non sauvegardées seront perdues.
Charger Ouvre un fichier de simulation précédemment sauvegardé.
Sauvegarder Télécharge la simulation actuelle en tant que fichier sur ton ordinateur.

Tu as des problèmes ? Vérifie que ton réseau est correctement connecté et que tous les appareils ont des adresses IP valides configurées.

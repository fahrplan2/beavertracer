It-tliet modi

Beaver Tracer għandu tliet modi. Tibdel bejniethom billi tuża l-buttuni fil-toolbar ta' fuq.

Edit Iddesinnja n-network tiegħek — poġġi l-devices, konnettjihom, ikkonfigurihom.
Run Ibda s-simulazzjoni u ara t-traffic jiċċirkola permezz tan-network tiegħek.
Trace Aqbad u inspettja l-packets li jivvjaġġaw fuq in-network tiegħek.

Modalità ta' modifika — Bini ta' network

Fil-modalità ta' modifika, toolbar jidher fuq in-naħa tax-xellug tal-iskrin. Agħżel għodda billi tikklikkja fuqha, imbagħad użaha fuq il-canvas.

Għodod

Agħżel Agħfas fuq device biex tiftaħ il-panel tiegħu. Idraq device biex itmovvuha.
Link Qabbel żewġ devices b'cable (ara hawn taħt).
Test Poġġi etiketta ta' test fuq il-canvas biex tannoта d-dijagramma tiegħek.
Rettangolu Ġbid rettangolu fuq il-canvas biex gupp viżwalment devices.
Ħassar Agħfas fuq device jew cable biex taħsarha.

Għarfien: Agħfas dritt fuq kwalunkwe post fuq il-canvas biex ikkanċella l-għodda attwali u terġa lura għal Agħżel.

Poġġi device

  1. Agħfas button ta' device fit-toolbar tax-xellug (eż. Computer).
  2. Preview isegwi l-cursor tal-mouse tiegħek.
  3. Agħfas fuq il-canvas biex tpoġġi l-device.

Qabbel żewġ devices

  1. Agħfas l-għodda Link.
  2. Agħfas l-ewwel device — port picker jidher. Agħżel port.
  3. Mowwi l-mouse tiegħek għat-tieni device u agħfas fuqu — agħżel port hemm ukoll.
  4. Il-cable tinħoloq awtomatikament.

Ports li diġà qed jintużaw jintwraw bħala disabilitati u ma jistgħux jintgħażlu.

Mowwi device

Fil-modalità ta' Agħżel, agħfas u idraq kwalunkwe device biex terġa poġġih fuq il-canvas.

Ħassar device jew cable

  1. Agħfas l-għodda Ħassar.
  2. Agħfas fuq il-device jew cable li trid taħsarha.

Meta taħsarr device, il-cables kollha konnessi għalih jitħassru awtomatikament.

Apparati

Dawn apparati huma disponibbli fit-toolbar tax-xellug waqt il-modalità Edit:

Computer Kompjuter b'interface ta' network wired. Tista' tħarreġ applikazzjonijiet fuqu (eż. web browser jew ping tool) u tikkonfigura l-IP address tiegħu.
Tablet Bħal Computer, imma tikkonnettja permezz ta' Wi-Fi minflok cable. Uża dan flimkien ma' Access Point jew Home Router.
SW Switch Tikkonnettja apparati multipli fl-istess network segment. Iforwarda frames ibbażata fuq MAC addresses. Tappoġġja VLANs u Spanning Tree Protocol (STP).
RT Router Tikkonnettja networks differenti u iforwarda packets bejniethom. Tappoġġja static routes, OSPF, BGP, u IP tunnels (VPN).
Home Router Router kombinat, DHCP server, NAT gateway u Wi-Fi access point — simili għal tipikali home internet router. Konnettjaha ma' Router (bħala WAN) u ma' Computers jew Tablets (bħala LAN/Wi-Fi). Tappoġġja port forwarding rules.
Access Point Testendi network wired b'connessjoni Wi-Fi. Konnettja l-wired port tiegħu ma' Switch jew Router, imbagħad konnettja Tablets magħha wireless.
Firewall Tafiltra traffic bejn network segments ibbażata fuq rules konfigurabbli. Il-panel juri s-rule set u live log ta' packets matched.

Pannelli tal-apparat

Ikklikkja xi apparat fuq il-canvas biex tiftaħ il-panel tiegħu — finestra ta' konfigurazzjoni li tidher fuq il-lemin tal-iskrin. Ikklikkja l-apparat mill-ġdid (jew il-buttuna × fil-header tal-panel) biex tagħlaqha.

Iċċanja l-isem ta' apparat

Ikklikkja l-buttuna ħdejn l-isem tal-apparat fil-header tal-panel biex tagħtieha isem personalizzat (eż. "Office-PC" jew "Core-Router").

Tabs tar-router

Panel ta' Router għandu t-tabs li ġejjin:

  • Interfaces — konfigura indirizzi IP fuq kull port
  • Routing table IPv4 — ara u editja routes IPv4 (statiku u imtellma)
  • Routing table IPv6 — ara u editja routes IPv6
  • OSPF — konfigura u monitorja OSPF dynamic routing
  • BGP — konfigura BGP neighbours u ara t-table BGP
  • VPN — issettja IP tunnels bejn routers

Tabs tal-switch

Panel ta' Switch għandu tabs għat-Switch Address Table (SAT) tiegħu, il-konfigurazzjoni ta' VLAN, u s-settings tal-Spanning Tree Protocol (STP).

Tabs tal-Home Router

Panel ta' Home Router għandu t-tabs li ġejjin:

  • Status — sommarju tal-istatus WAN/LAN attwali u clients konnessi
  • WAN — konfigura l-uplink (static IP jew DHCP)
  • LAN — konfigura s-subnet LAN u l-indirizz IP
  • DHCP — ara l-leases attivi u konfigura l-pool DHCP
  • WiFi — konfigura l-access point integrat (SSID, password)
  • NAT — ara t-table tal-konnessjoni NAT attiva
  • Port Forwarding — iddefiniċi regoli biex iwakkla ports inċomming lejn hosts LAN

Tabs tal-Firewall

Panel ta' Firewall għandu tab Rules biex jimmaniġġja regoli tal-filter u tab Log li juri liema packets ġew permessi jew dropped.

Computer u Tablet

Computers u Tablets għandhom sistema operattiva simulata sħiħa ġewwa l-panel tagħhom. Tista' tiftaħ apps mill-desktop, tikonfigura network settings, u taħdem instructions.

Modalità Run — Avvio della simulazione

Passa alla modalità Run per avviare la simulazione. La rete diventa attiva: i dispositivi scambiano packets, vengono assegnati i DHCP leases, le routing tables si aggiornano, e così via.

Controlli di velocità

Usa i pulsanti di velocità nella barra degli strumenti superiore per controllare la velocità di esecuzione della simulazione:

1/4×Lento — buono per osservare i singoli passaggi
1×Velocità normale
4×Veloce
16×Molto veloce

Pausa e reset

Pausa Congela la simulazione nello stato attuale.
Reset Riavvia la simulazione dall'inizio (tutto lo stato dinamico viene cancellato).

Nota: Non puoi modificare la topology della rete mentre sei in modalità Run. Torna prima alla modalità Edit.

Trace Mode — Analizzar Packets

Ibdel għal Trace mode biex tiftaħ l- analyser ta' packets integrat — simili għal Wireshark.

Fuq, agħżel id-device u l-port li trid taqbad minnha. Il-packets kollha li jgħaddu minn dak il-port huma rrekordjati u murija f'lista.

Ikklikkja fuq kwalunkwe packet fil-lista biex tara d-dettalji sħaħ tiegħu: il-protocol layers, il-header fields, u l-payload — eżattament kif għodda professjonali ta' network jippresentawhom.

Il-capture jibda' awtomatikament waqt li l-simulazzjoni qed taħdem. Tista' tibdel bejn Trace mode u Run mode fi kwalunkwe ħin mingħajr ma titlef id-data meqbuda.

Salvataġġ u tagħbija

Id-disinn tal-network tiegħek jista' jiġi salvat bħala file u jinġabar mill-ġdid aktar tard. Uża l-buttuni fil-toolbar ta' fuq (viżibbli fil-Edit mode):

New Ibda b'kanvas vojta. Kwalunkwe bidla mhux salvata se tinqalad.
Load Iftaħ file ta' simulazzjoni salvat qablu.
Save DownloadIl-simulazzjoni attwali bħala file fuq il-kompjuter tiegħek.

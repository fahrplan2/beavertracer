# HTTPS

:::osi 5
:::

**HTTPS** (*HTTP Secure*) është HTTP krejt normal — vetëm se nuk funksionon drejtpërdrejt mbi TCP, por përmes një shtrese të enkriptuar në mes: **TLS** (*Transport Layer Security*). Paraardhësi i TLS quhej **SSL**; prandaj shpesh flitet ende për „certifikata SSL“.

```
ohne Verschlüsselung:   HTTP  →  TCP  →  IP
mit Verschlüsselung:    HTTP  →  TLS  →  TCP  →  IP
```

HTTP nuk e vëren asgjë nga kjo: ai dërgon kërkesat e tij si zakonisht, TLS i enkripton ato, TCP i transporton. Në modelin OSI, TLS ndodhet midis shtresës së transportit dhe shtresës së aplikacionit, pra në shtresën 4/5 — ai mbështetet te TCP dhe menaxhon një seancë të sigurt.

| | HTTP | HTTPS |
|---|---|---|
| Porta | 80 | **443** |
| Adresa | `http://…` | `https://…` |
| Përmbajtja e lexueshme në Tracer? | po | jo |
| Shfletuesi tregon | „jo i sigurt“ | dryn |

Gjatë ngritjes së lidhjes, TLS kryen gjithçka që ke mësuar në këtë kapitull:

- Serveri identifikohet me **certifikatën** e tij (**autenticiteti**).
- Të dyja palët bien dakord me **Diffie-Hellman** për një **çelës seance** — serveri e **nënshkruan** pjesën e tij.
- Pas kësaj, të gjitha të dhënat enkriptohen me **AES** (**konfidencialiteti**) dhe mbrohen kundër ndryshimit (**integriteti**).

Parimi nuk kufizohet vetëm te uebi: edhe e-mail-i (seksioni 8.4) dhe shumë protokolle të tjera kalojnë në të njëjtën mënyrë përmes TLS.

Në seksionet vijuese e vëzhgon HTTPS në Tracer, e konfiguron vetë dhe shqyrton se kur paralajmëron shfletuesi — dhe pse.

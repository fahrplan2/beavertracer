# POP3 apo IMAP?

:::sim
url=/sims/lesson-6.3.btsim
:::

Për marrjen e e-mail-eve ekzistojnë dy protokolle. Në këtë simulim **Anna përdor POP3** dhe **Ben përdor IMAP**.

## Eksperimenti

1. Në :fa-play: modalitetin **Ekzekuto**, dërgo një e-mail nga **Ben** te `anna@beaver-schule.de`.
2. Te **Anna**, në aplikacionin **E-Mail**, kliko **Përshkruaj**.
3. Hap gjurmët (Traces) për **Anna** dhe për **Ben** dhe krahaso komandat gjatë marrjes së e-mail-eve.

:::quiz match
USER / PASS -> POP3: identifikim me emrin e përdoruesit dhe fjalëkalimin në dy hapa
RETR -> POP3: shkarkimi i një mesazhi
LOGIN -> IMAP: identifikim me emrin e përdoruesit dhe fjalëkalimin
SELECT INBOX -> IMAP: hapja e një dosjeje në server
:::

:::evaluate
Kontrollo përshoqërimin
:::

## Ndryshimi

| | POP3 | IMAP |
|---|---|---|
| Porta | 110 | 143 |
| Ideja bazë | e-mail-et **shkarkohen** — pastaj zakonisht fshihen në server | e-mail-et **mbeten në server** dhe administrohen aty |
| Dosjet, të lexuara/të palexuara | vetëm në pajisjen tënde | në server — kudo njësoj |
| Disa pajisje (celular, laptop) | jopraktik: çdo pajisje ka një gjendje tjetër | ideal: të gjitha pajisjet shohin të njëjtën kuti postare |

:::note
Programi i e-mail-it në BeaverTracer i lë e-mail-et në server edhe me POP3. Programet reale shpesh i fshijnë pas shkarkimit — ose i lënë aty vetëm për një kohë.
:::

:::quiz mc
Lena i lexon e-mail-et në celular, në tablet dhe në laptopin e shkollës. Çfarë duhet të përdorë?
- [ ] POP3, sepse është më e thjeshtë
- [x] IMAP, sepse të gjitha pajisjet shohin të njëjtën kuti postare në server
- [ ] SMTP, sepse është menduar për marrjen e e-mail-eve
:::

:::evaluate
Kontrollo përgjigjen
:::

:::tip Mbaj mend
**POP3** shkarkon e-mail-et nga serveri në **një** pajisje. **IMAP** administron kutinë postare **në server** — me dosje dhe statusin e leximit për të gjitha pajisjet njëkohësisht. Të dy shërbejnë vetëm për **marrjen**; dërgimi bëhet gjithmonë me **SMTP**.
:::

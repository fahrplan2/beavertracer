## Si duket një kërkesë

Kliko në trace te paketa `GET / HTTP/1.1` dhe hap **Hypertext Transfer Protocol**. Një kërkesë HTTP është tekst i thjeshtë:

```
GET / HTTP/1.1              ← Methode, Pfad, Version
Host: 192.168.0.20          ← Header: zusätzliche Angaben
…
                            ← Leerzeile: Ende der Anfrage
```

Përgjigja e serverit është ndërtuar saktësisht njësoj — me një rresht statusi, header-a, një rresht bosh dhe pas tij skedarin e vërtetë:

```
HTTP/1.1 200 OK             ← Version, Statuscode, Text
Content-Type: text/html     ← Header: Art der Datei
Content-Length: 301         ← Header: Größe in Byte
                            ← Leerzeile
<!doctype html> …           ← die Datei selbst
```

:::seq
mode: text
Client-PC -> Server: GET / | Kërkesë HTTP
Server -> Client-PC: 200 OK | index.html
Client-PC -> Server: GET /style.css | Kërkesë HTTP
Server -> Client-PC: 200 OK | style.css
:::

## Metodat dhe kodet e statusit

**Metoda** tregon çfarë dëshiron klienti:

| Metoda | Kuptimi |
|---|---|
| **GET** | të marrë një skedar |
| **POST** | t'i dërgojë serverit të dhëna, p.sh. një formular të plotësuar |
| **HEAD** | të marrë vetëm header-at, pa skedarin |

**Kodi i statusit** tregon se si ka shkuar. Shifra e parë tregon llojin e përgjigjes:

| Kodi | Teksti | Kuptimi |
|---|---|---|
| **200** | OK | gjithçka në rregull |
| **301** | Moved Permanently | faqja është zhvendosur përgjithmonë |
| **404** | Not Found | skedari nuk ekziston |
| **405** | Method Not Allowed | kjo metodë nuk lejohet këtu |
| **500** | Internal Server Error | gabim në server |

`2xx` do të thotë sukses, `3xx` ridrejtim, `4xx` gabim i klientit (kërkesë e gabuar), `5xx` gabim i serverit.

:::tip Mbaj mend
**HTTP** funksionon sipas **parimit kërkesë-përgjigje**: klienti dërgon një **kërkesë** (metodë si `GET`, rrugë, header-a), serveri përgjigjet me një **kod statusi** (p.sh. `200 OK`, `404 Not Found`), header-a dhe skedarin. Për çdo skedar të një faqeje interneti ka një kërkesë më vete.
:::

:::quiz match
200 -> Gjithçka në rregull
301 -> Faqja është zhvendosur përgjithmonë
404 -> Skedari i kërkuar nuk ekziston

:::

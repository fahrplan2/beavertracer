# 상태 비저장 방식과 상태 저장 방식

연결은 항상 **두 방향**으로 이루어진다. 교사 PC가 인터넷의 웹 서버에 요청을 보내면, 웹 서버는 웹 페이지를 다시 돌려보낸다. 따라서 화이트리스트 원칙에 따른 방화벽은 요청뿐만 아니라 **응답**도 통과시켜야 한다.

이를 위해 두 가지 종류의 패킷 필터가 있다.

| | **상태 비저장** (*stateless*) | **상태 저장** (*stateful*) |
|---|---|---|
| 동작 방식 | 기억 없이 각 패킷을 개별적으로 검사한다 | 허용된 연결을 **상태 테이블**에 기억한다 |
| 응답 | 반대 방향을 위한 별도의 규칙이 필요하다 | 알려진 연결에 속하므로 자동으로 통과된다 |
| 사용처 | 단순한 장비, 매우 빠른 필터 | 오늘날 거의 모든 방화벽 |

다음 두 섹션에서는 상태 비저장 필터가 응답을 처리할 때 왜 문제가 생기는지, 그리고 상태 저장 방화벽이 이를 어떻게 해결하는지 직접 체험해 본다.

# DMZ

:::sim
url=/sims/lesson-9.3.btsim
:::

지금까지 **Schulserver**는 **Lehrer-PC**와 같은 네트워크에 있었어. 이건 위험해. Schulserver는 인터넷에서 접근할 수 있기 때문이야. 공격자가 웹 서버의 취약점을 찾아 이 컴퓨터를 장악하면, 공격자는 **학교 네트워크 한가운데**에 들어와 있게 되고, 방화벽은 더 이상 아무것도 할 수 없어. Schulserver에서 Lehrer-PC로 가는 트래픽은 방화벽을 통과하지 않기 때문이야.

해결책은 이거야. 인터넷에서 접근할 수 있어야 하는 서버는 인터넷과 내부 네트워크 사이의 **별도 네트워크**에 둬. 이 네트워크를 **DMZ**(*비무장 지대*, 두 국경 사이의 중립 지대에서 따온 이름)라고 해.

## 구성

작업 영역에는 **방화벽 두 대**를 사용하는 전형적인 모델이 있어.

```
Internet ──[ Firewall außen ]── Schulrouter ──── DMZ: Schulserver (198.51.100.10)
                                    │
                             [ Firewall innen ]
                                    │
                    LAN: Lehrer-PC (192.0.2.20), Schüler-PC (192.0.2.21)
```

- **Firewall außen**은 모든 것을 인터넷으로부터 보호해. 포트 A는 인터넷에, 포트 B는 Schulrouter에 연결되어 있어.
- **Firewall innen**은 LAN을 보호하고, DMZ로부터도 보호해. 포트 A는 Schulrouter에, 포트 B는 LAN에 연결되어 있어.

지금은 두 방화벽 모두 아직 모든 트래픽을 통과시켜.

:::quiz multi
어떤 연결이 합리적이어서 허용해야 할까?
- [x] 인터넷 → DMZ: Schulserver의 웹(80)과 메일(25)
- [x] LAN → DMZ: 예를 들어 메일 가져오기(110)
- [x] LAN → 인터넷: 웹 서핑

## 작업: DMZ 보호하기

**두 방화벽 모두** **Stateful**과 **Alle verwerfen**으로 설정하고 알맞은 규칙을 입력해 봐.

- **Firewall außen:** 안에서 밖으로(B → A)는 모두 허용해. 밖에서(A → B)는 Schulserver `198.51.100.10`으로 가는 TCP 80과 25만 허용해.
- **Firewall innen:** LAN에서(B → A)는 모두 허용해. LAN 방향(A → B)에는 규칙이 필요 없어. 응답은 상태 테이블을 통해 돌아오기 때문이야.

:::task
title: DMZ 보호 완료?
인터넷, DMZ, LAN 사이에서 허용된 경로와 금지된 경로를 확인해 봐.
check: tcpOpen(1, "198.51.100.10", 80)
check: tcpOpen(1, "198.51.100.10", 25)
check: tcpFails(1, "198.51.100.10", 22)
check: pingFails(1, 10)
check: tcpOpen(10, "198.51.100.10", 110)
check: tcpOpen(10, "203.0.113.80", 80)
check: pingFails(7, 10)
:::

:::note
많은 방화벽은 포트를 세 개 이상("존") 가지고 있어서, 장치 하나로 DMZ를 구현해. 원리는 같아. 인터넷, DMZ, LAN 사이의 트래픽은 항상 규칙을 거쳐야 해. 방화벽 두 대를 쓰는 모델에는 장점이 하나 있어. 공격자가 **두 개의** 장벽을 넘어야 한다는 점이야. 같은 보안 취약점이 두 방화벽을 모두 열어 버리지 않도록 서로 다른 제조사의 장비를 쓰는 경우도 많아.
:::

:::tip 핵심 정리
**DMZ**에는 인터넷에서 접근할 수 있어야 하는 모든 서버를 둬. DMZ는 두 방화벽 사이(또는 방화벽의 별도 존)에 있어. 인터넷은 DMZ의 특정 서비스에만 접근할 수 있고, LAN은 DMZ와 인터넷에 접근할 수 있어. 하지만 DMZ와 인터넷에서 **LAN으로 가는 길은 없어**. DMZ의 서버가 장악되어도 LAN은 보호돼.
:::

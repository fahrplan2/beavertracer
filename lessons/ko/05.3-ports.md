# 포트: 여러 연결을 동시에

:::goal
**학습 목표:** 포트가 한 컴퓨터에서 여러 연결을 어떻게 구분하는지 설명하고, 가장 중요한 Well-known 포트를 말하며, 전형적인 포트 오류를 찾을 수 있다.
:::

:::

5.1절에서 너는 브라우저와 TCP 클라이언트가 같은 IP 주소로 패킷을 보내는데도 각 패킷이 올바른 서비스에 도착하는 것을 보았다. 그 차이를 만든 것이 `80`과 `5000`이라는 숫자, 바로 **포트**였다. 포트가 어떻게 작동하는지 이제 좀 더 자세히 살펴보자.

## 그 뒤에서 일어나는 일

가정용 라우터는 인터넷으로 나가는 모든 패킷에서 사설 송신자 주소를 자신의 **공인 WAN 주소**로 바꾸고, 대개 송신자 포트도 함께 바꾼다. 웹 서버에게는 요청이 가정용 라우터에서 온 것처럼 보인다. 응답이 돌아오면 가정용 라우터는 주소를 다시 원래대로 바꾸어 패킷을 PC로 전달한다.

이렇게 하면 홈 네트워크 전체가 단 하나의 공인 주소로 인터넷에 접속할 수 있고, 인터넷에 있는 장치는 사설 주소를 전혀 볼 수 없다.

## 인터넷으로 가는 경로

**PC**의 :fa-terminal: **터미널**에 다음을 입력한다:

```
$ traceroute 192.0.2.80
```

:::

:::quiz mc

- [ ] `203.0.113.2` — 가정용 라우터의 WAN 주소

:::

:::tip 핵심 정리
**NAT**(*Network Address Translation*)는 인터넷으로 나갈 때 장치의 **사설** 송신자 주소를 라우터의 **공인 WAN 주소**로 바꾸고, 응답이 올 때는 그 반대로 바꾼다. 이렇게 홈 네트워크의 모든 장치가 **하나의** 공인 IPv4 주소를 함께 사용한다. 덕분에 주소를 절약할 수 있고 사설 주소를 인터넷에서 숨길 수 있다.
:::

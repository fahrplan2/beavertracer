# 여러 PC를 스위치에 연결하기

:::sim
url=/sims/lesson-3.1.1.btsim
:::

작업 영역에는 스위치 한 대와 PC 세 대가 있다: **Anna**, **Ben**, **Clara**. 이들의 IP 주소는 이미 설정되어 있다(`192.168.0.10`, `.11`, `.12`). 이제 케이블만 연결하면 된다.

## 케이블 연결하기

1. :fa-pencil: **편집** 모드로 전환하고 :fa-link: **연결** 도구를 선택한다.
2. **Anna**를 클릭한 다음 **스위치**를 클릭한다. 스위치의 포트(1~8)가 나열된 선택 창이 나타난다. **1**을 선택한다.
3. 다시 :fa-link:를 선택하고 **Ben**을 포트 **2**에, **Clara**를 포트 **3**에 연결한다.

이제 각 케이블에 작은 숫자가 보인다. 이 숫자는 케이블이 꽂혀 있는 스위치의 포트 번호이다.

:::tip 핵심 정리
**스위치**는 **포트**라고 하는 연결 단자가 많이 달린 분배 장치이다. 하나의 스위치에 연결된 모든 장치는 함께 **로컬 네트워크**(영어로 *Local Area Network*, **LAN**)를 이룬다.
:::

## 테스트하기

:fa-play: **실행** 모드로 전환하고, **Anna**에서 :fa-terminal: **터미널**을 열어 Clara에게 ping을 보낸다:

```
$ ping 192.168.0.12
```

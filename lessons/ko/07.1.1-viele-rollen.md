## 가정용 라우터 안에 들어 있는 것들

| 가정용 라우터 안의 역할 | 하는 일 | 배운 곳 |
|---|---|---|
| **스위치** | LAN 포트에 연결된 장치들을 서로 연결한다 | 3.1장 |
| **액세스 포인트** | 휴대폰, 태블릿, 노트북을 WLAN으로 네트워크에 연결한다 | 3.3장 |
| **라우터** | 홈 네트워크를 프로바이더의 네트워크와 연결한다 — 이것이 **게이트웨이**다 | 4.3장 |
| **DHCP 서버** | 주소, 게이트웨이, DNS 서버를 나눠 준다 | 6.4장 |
| **DNS** | 이름 조회 요청을 전달하거나 프로바이더의 DNS 서버를 알려 준다 | 6.2장 |
| **NAT** | 모든 장치를 **하나의** 공인 주소로 인터넷에 연결한다 | 새로운 내용 — 7.2절 |

**WAN**(*Wide Area Network*) 포트는 프로바이더로 이어지고, **LAN** 포트와 WLAN은 홈 네트워크로 이어진다. 많은 가정용 라우터에는 **모뎀**도 들어 있다. 모뎀은 데이터를 회선(DSL, 케이블, 광섬유)에 맞게 변환해 준다. BeaverTracer는 이를 시뮬레이션하지 않는다. 여기서는 WAN 포트가 프로바이더의 네트워크에 바로 연결되어 있다.

:::quiz match
스위치 -> LAN 포트에 연결된 장치들을 서로 연결한다
액세스 포인트 -> 태블릿과 휴대폰을 WLAN으로 네트워크에 연결한다
DHCP 서버 -> 홈 네트워크의 장치들에 주소를 나눠 준다
라우터 -> 홈 네트워크를 프로바이더의 네트워크와 연결한다
:::

:::evaluate
짝짓기 확인
:::

:::tip 핵심 정리
**가정용 라우터**는 여러 장치를 하나로 합친 것이다. **스위치**, **WLAN 액세스 포인트**, **라우터**(인터넷으로 가는 게이트웨이), **DHCP 서버**, **DNS 전달**이 들어 있고, 여기에 **NAT**까지 더해진다. **WAN** 포트는 프로바이더로 이어지고, **LAN** 포트와 WLAN은 홈 네트워크로 이어진다.
:::

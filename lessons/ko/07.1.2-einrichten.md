# 가정용 라우터 설정하기

:::sim
url=/sims/lesson-7.1.2.btsim
:::

새 가정용 라우터를 방금 연결했지만, 아직 아무도 인터넷에 접속하지 못한다. 인터넷 제공업체(ISP)에서 **접속 정보**가 적힌 편지를 받았다.

| 접속 정보 | 값 |
|---|---|
| WAN IP 주소 | `203.0.113.2` |
| 프리픽스 길이 | `/30` |
| 게이트웨이 (ISP의 라우터) | `203.0.113.1` |
| ISP의 DNS 서버 | `198.51.100.10` |

1. :fa-play: **실행** 모드로 전환하고, **Heimrouter**를 클릭한 다음 **WAN** 탭을 열어.
2. 접속 정보를 입력하고 **적용**을 클릭해.
3. **Tablet**을 Wi-Fi에 연결해: :fa-gear: **IP 설정**, **WiFi** 탭, SSID `Biberbau`, **적용**.
4. PC에서 `ping 192.0.2.80`으로 테스트하거나, 브라우저에서 `http://www.beispiel.de/`로 테스트해 봐.

:::note
실제로는 가정용 라우터가 WAN 주소를 대개 ISP로부터 자동으로 받는다(DHCP 또는 사용자 이름과 비밀번호를 이용한 로그인 방식). 여기처럼 고정된 접속 정보는 기업용 회선에서 더 흔하다.
:::

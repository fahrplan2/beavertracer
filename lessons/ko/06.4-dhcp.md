# DHCP: 네트워크에 자동으로 접속하기

:::goal
**학습 목표:** DHCP를 통해 장치가 IP 설정을 자동으로 받는 과정을 설명하고, DHCP 서버를 설정하며, 대표적인 DHCP 오류(예: 169.254 주소)를 찾아 해결할 수 있다.
:::

:::sim
url=/sims/lesson-6.4.btsim
:::

지금까지는 모든 장치에 IP 주소, 넷마스크, 게이트웨이, DNS 서버를 직접 입력했다. 노트북, 태블릿, 휴대폰이 수백 대나 있는 학교에서는 그렇게 하는 것이 불가능하고, 오타 하나하나가 네트워크의 오류가 된다.

이 일을 대신해 주는 것이 **Dynamic Host Configuration Protocol**(**DHCP**)이다. **DHCP 서버**가 네트워크에 들어오는 모든 장치에 설정을 자동으로 나눠 준다.

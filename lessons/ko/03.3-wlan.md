# WLAN: 케이블 없는 네트워크

:::goal
**학습 목표:** 액세스 포인트가 WLAN을 유선 네트워크와 어떻게 연결하는지 설명하고, SSID를 통해 기기를 WLAN에 연결하며, WLAN을 왜 암호화해야 하는지 근거를 들어 설명할 수 있다.
:::

휴대폰, 태블릿, 노트북에는 대부분 네트워크 단자가 아예 없다. 이런 기기들은 무선으로, 즉 **WLAN**(*Wireless LAN*, 무선 로컬 네트워크)으로 연결된다. 그래도 케이블로 연결된 PC나 서버와 통신하려면 무선과 유선을 이어 주는 장치가 필요하다.

:::note
실제 WLAN은 통신 범위, 벽, 간섭에 영향을 받는다. BeaverTracer는 이를 단순화했다. 같은 WLAN 이름을 가진 모든 기기는 작업 영역의 어디에 놓여 있든 하나의 무선 네트워크를 공유한다.
:::

Client-PC는 IP 주소를 알게 된 후에야 웹 서버와 TCP 연결을 설정한다 — 5장에서 본 것과 똑같다.

:::seq
mode: text
Client-PC -> DNS-Resolver: DNS-Anfrage | A www.beaver-schule.de?
DNS-Resolver -> Client-PC: DNS-Antwort | A 192.168.0.20
:::

## PC는 DNS 서버를 어떻게 알까?

**Client-PC**에서 :fa-gear: **IP 설정**을 열어라. **DNS-Server** 필드에 `192.168.0.53`이 들어 있다 — 바로 **DNS-Resolver** 컴퓨터다. PC는 모든 이름 요청을 이 서버로 보낸다.

브라우저 없이 DNS 서버에 직접 물어볼 수도 있다. :fa-terminal: **터미널**을 열고 다음을 입력해라:

```
$ nslookup www.beaver-schule.de
```

`nslookup`은 먼저 어떤 서버에 물어봤는지 보여 주고, 그다음 응답을 보여 준다. 비교를 위해 존재하지 않는 이름도 물어봐라. 예를 들면 `nslookup gibtsnicht.beaver-schule.de`이다.

:::quiz mc
알 수 없는 이름에 대해 DNS 서버는 무엇이라고 응답하는가?
- [ ] 임의의 IP 주소
- [x] `NXDOMAIN` — 그런 이름은 존재하지 않는다
- [ ] 아무 응답도 없다
:::

:::evaluate
답 확인
:::

:::tip 핵심 정리
**DNS**는 이름(예: `www.beaver-schule.de`)을 IP 주소로 변환한다. PC가 이름으로 연결을 설정하기 전에, IP 설정에 등록된 **DNS 서버**에 먼저 물어본다 — 대개 **UDP, 포트 53**을 사용한다. `nslookup`을 사용하면 DNS 요청을 직접 보낼 수 있다.
:::

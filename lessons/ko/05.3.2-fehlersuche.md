# 문제 해결: 서비스가 응답하지 않음

:::sim
url=/sims/lesson-5.3.2.btsim
:::

업데이트 후 학교에서 다음과 같이 알려 왔다. "에코 서비스가 모든 연결을 거부하고, 웹 페이지도 더 이상 로드되지 않습니다." 계획에 따르면 **웹 서버**는 포트 `80`에서, **에코 서비스**(TCP 에코 서버)는 포트 `5000`에서 대기해야 한다. 오류를 찾아서 해결해 보자.

<details>
<summary>힌트 1: 서버는 어떻게 응답할까?</summary>

**단순 TCP 클라이언트**로 `192.168.0.20`, 포트 `5000`에 연결해 보고, 클라이언트 PC에 대해 트레이스를 열어 보자. 서버는 네가 보낸 `[SYN]`에 무엇으로 응답할까?
</details>

<details>
<summary>힌트 2: 어떤 포트가 열려 있을까?</summary>

클라이언트 PC의 터미널에 `nmap -p 80,5000 192.168.0.20`을 입력해 보자. `nmap`은 포트를 차례로 시도해 보고 어떤 포트가 열려 있는지 보여 준다. 서버에서 `ss`를 사용하면 어떤 포트에서 실제로 프로그램이 대기하고 있는지 볼 수 있다.
</details>

<details>
<summary>힌트 3: 어디에서 설정할까?</summary>

**Server**에서 **TCP 에코 서버**와 **HTTP 서버** 앱을 열어 보자. 서비스가 실행 중일까? 그리고 어떤 포트에서 실행 중일까?
</details>

:::task
title: 서비스에 접속할 수 있는가?
클라이언트 PC가 포트 5000의 에코 서비스와 포트 80의 웹 서버에 접속할 수 있는지 확인한다. 이를 위해 시뮬레이션이 실행 모드에서 동작 중이어야 한다.
check: tcpOpen(1, 2, 5000)
check: tcpOpen(1, 2, 80)
:::

## 무슨 일이 있었을까?

:::quiz multi
다음 중 옳은 설명은 무엇일까?
- [x] 포트 5000으로 보낸 `[SYN]`에 서버는 `[RST, ACK]`로 응답했다
- [x] 에코 서비스가 포트 5000이 아니라 포트 5050에서 대기하고 있었다
- [x] 웹 서버가 아예 시작되지 않았다
- [ ] 클라이언트 PC와 서버 사이의 케이블이 고장 나 있었다
:::

:::evaluate
답 확인
:::

:::tip 핵심 정리
`SYN`에 대해 **`RST`**가 돌아오면 해당 포트에서 대기하는 **프로그램이 없다**는 뜻이다. 컴퓨터에는 도달할 수 있지만 서비스에는 도달할 수 없는 상태다. 전형적인 원인은 서비스가 **시작되지 않았거나** **다른 포트**에서 대기하고 있는 경우다. 서버에서 `ss`로 확인해 보면 어떤 포트가 실제로 열려 있는지 알 수 있다.
:::

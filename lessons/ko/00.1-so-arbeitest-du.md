# 강의를 활용하는 방법

이 강의는 BeaverTracer 안에서 바로 진행됩니다. 왼쪽에서는 네트워크를 만들고 관찰하고, 오른쪽 **학습 창**에서는 그에 대한 안내를 읽어요.

## 페이지 넘기기

**이전**과 **다음**으로 강의를 한 페이지씩 넘겨 가며 진행해요. **목차**(또는 학습 창 위쪽의 :fa-list:)를 누르면 원하는 장으로 바로 이동할 수 있어요.

## 모든 페이지에 알맞은 시뮬레이션

페이지를 넘길 때마다 BeaverTracer가 그 페이지에 해당하는 시뮬레이션을 자동으로 불러와요. 그래서 항상 정상적으로 동작하는 상태에서 시작할 수 있어요.

:::warning
한 페이지에서 만들거나 바꾼 내용은 다음 페이지에서 사라져요. 이는 의도된 동작이에요. 모든 페이지는 깨끗한 초기 상태에서 시작하거든요.
:::

- 학습 창 위쪽의 :fa-rotate-left:를 누르면 시뮬레이션을 현재 페이지의 처음 상태로 되돌려요. 길을 잃었을 때 편리해요.
- 시뮬레이션을 직접 이어서 만들고 싶다면 도구 모음에서 :fa-file-import: **채택**을 클릭하세요. 학습 창이 닫히고, 그 시뮬레이션은 네가 마음대로 쓸 수 있게 돼요.

## 저장과 불러오기

시뮬레이션은 네트워크 전체, 즉 모든 장치와 케이블, 그리고 그 설정을 담고 있는 하나의 파일(`.btsim`)이에요. 학습 창이 열려 있는 동안에는 :fa-file: **새로 만들기**, :fa-file-arrow-up: **불러오기**, :fa-file-arrow-down: **저장** 버튼이 숨겨져 있어요. **채택**을 누른 뒤(또는 **×**로 학습 창을 닫은 뒤)에는 편집 모드에서 도구 모음의 모드 버튼 오른쪽에서 이 버튼들을 찾을 수 있어요.

## 상자, 퀴즈, 작업

:::goal
**학습 목표** — 섹션의 맨 앞에 나와요. 이 섹션을 마치면 무엇을 할 수 있는지 알려 줘요.
:::

:::tip 핵심 정리
중요한 전문 용어나 개념 간의 관계를 짧게 요약해 줘요. 시험 공부에 좋아요.
:::

- **퀴즈 문제**는 페이지에서 바로 답하고, 아래에 있는 버튼으로 확인해요. 화면을 자세히 보면 거의 모든 답을 직접 읽어 낼 수 있어요.
- **작업**에서 **작업 확인** 버튼을 누르면 네 시뮬레이션을 살펴보고 모든 것이 올바르게 설정되었는지 확인해 줘요. 예를 들어 두 PC가 서로 통신할 수 있는지 같은 것들이에요.

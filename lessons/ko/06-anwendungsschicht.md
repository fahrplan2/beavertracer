5장에서 TCP와 UDP는 데이터를 포트를 통해 올바른 프로그램에 안정적으로(또는 빠르게) 전달한다는 것을 살펴봤다. 이 데이터 *안에 무엇이 들어 있는지*는 **응용 계층**의 프로토콜이 정한다. TCP/IP 모델에서는 하나의 계층이고, ISO/OSI 모델에서는 5계층부터 7계층에 해당한다.

이 프로토콜들은 저마다 고유한 역할과 고유한 포트를 가지고 있다.

| 프로토콜 | 역할 | 포트 | 전송 |
|---|---|---|---|
| **HTTP** | 웹 페이지 가져오기 | 80 | TCP |
| **DNS** | 이름을 IP 주소로 변환 | 53 | 주로 UDP |
| **SMTP** | 이메일 보내기 | 25 | TCP |
| **POP3** / **IMAP** | 이메일 가져오기 | 110 / 143 | TCP |
| **DHCP** | 장치에 IP 주소를 자동으로 할당 | 67 / 68 | UDP |

1.3장에서는 웹 페이지를 IP 주소로 직접 불러왔다. 하지만 일상에서 `192.168.0.20`을 직접 입력하는 사람은 없고, 새 노트북에 주소를 손으로 일일이 입력하지도 않는다. 이 모든 것이 어떻게 맞물려 동작하는지는 이 장에서 프로토콜별로 하나씩 알아보자.

# 2진법

컴퓨터는 가장 깊은 곳에서는 두 가지 상태만 알고 있다. 전류가 흐르거나(켜짐), 흐르지 않거나(꺼짐). 이를 **1**과 **0**으로 표기한다. 이런 한 자리를 **비트**라고 한다. IP 주소도 컴퓨터에게는 0과 1의 나열일 뿐이다. 넷마스크가 어떻게 동작하는지 이해할 수 있도록, 이 페이지에서 이런 수를 읽고 직접 변환하는 법을 배운다.

## 우리가 평소에 세는 방법: 10진법

일상에서 우리는 열 개의 숫자(0부터 9)로 계산한다. 각 자리는 오른쪽 자리보다 10배의 값을 가진다. 일의 자리, 십의 자리, 백의 자리, 천의 자리가 그렇다. 따라서 `305`라는 수는 다음을 의미한다.

| 자릿값 | 100 | 10 | 1 |
|---|---|---|---|
| 숫자 | 3 | 0 | 5 |
| 값 | 300 | 0 | 5 |

300 + 0 + 5 = **305**

## 2진법

**2진법**(*이진법*이라고도 함)에는 0과 1, 두 개의 숫자만 있다. 각 자리는 오른쪽 자리보다 **2배**의 값을 가진다: 1, 2, 4, 8, 16, 32, 64, 128 …

따라서 2진수 `00001101`은 다음을 의미한다.

| 자릿값 | 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1 |
|---|---|---|---|---|---|---|---|---|
| 비트 | 0 | 0 | 0 | 0 | 1 | 1 | 0 | 1 |
| 값 | | | | | 8 | 4 | | 1 |

8 + 4 + 1 = **13**

즉, 1이 있는 자리의 자릿값을 모두 더하면 된다.

:::tip 핵심 정리
**비트**는 2진법의 한 자리(0 또는 1)이다. **8비트**는 **1바이트**가 된다. 네트워크 기술에서는 이런 8비트 묶음을 **옥텟**이라고도 부른다. 옥텟의 자릿값은 **128, 64, 32, 16, 8, 4, 2, 1**이다.
:::

:::quiz short
`00000110`은 10진수로 얼마일까?
= 6
:::

:::quiz short
`10000001`은 10진수로 얼마일까?
= 129
:::

:::quiz fill
옥텟 하나(8비트)로는 {0}부터 {255}까지의 수를 나타낼 수 있다.

## 10진수에서 2진수로

반대로 변환할 때는 자릿값을 왼쪽에서 오른쪽으로 차례대로 살펴보면서 매번 이렇게 묻는다. **이 자릿값이 내 (남은) 수에 들어갈 수 있는가?** 들어갈 수 있으면 1을 쓰고 그 자릿값을 뺀다. 들어갈 수 없으면 0을 쓴다.

예시: `168`

| 자릿값 | 들어가는가? | 비트 | 나머지 |
|---|---|---|---|
| 128 | 168 → 예 | **1** | 40 |
| 64 | 40 → 아니요 | **0** | 40 |
| 32 | 40 → 예 | **1** | 8 |
| 16 | 8 → 아니요 | **0** | 8 |
| 8 | 8 → 예 | **1** | 0 |
| 4 | 0 → 아니요 | **0** | 0 |
| 2 | 0 → 아니요 | **0** | 0 |
| 1 | 0 → 아니요 | **0** | 0 |

위에서 아래로 읽으면 168 = **10101000**

## 연습

시도할 때마다 새로운 수가 나온다. 확실히 익힐 때까지 연습해 보자.

:::quiz random dec2bin
count=3
:::

:::quiz random bin2dec
count=3
:::

답안 확인
:::

:::tip 팁
이 값들은 넷마스크에서 계속 등장하므로 외워 두면 좋다: `10000000` = 128, `11000000` = 192, `11100000` = 224, `11110000` = 240, `11111000` = 248, `11111100` = 252, `11111110` = 254, `11111111` = 255.
:::

## 2진법으로 본 IP 주소

IPv4 주소는 **32비트**, 즉 네 개의 옥텟으로 이루어져 있다. 0과 1이 32개 나열된 것을 외울 수 있는 사람은 없으므로, 각 옥텟을 10진수로 쓰고 점으로 구분한다.

```
11000000 . 10101000 . 10110010 . 00000001
   192   .   168    .   178    .    1
```

:::quiz short
IPv4 주소는 몇 비트로 이루어져 있을까?
= 32
:::

:::quiz mc
이론상 서로 다른 IPv4 주소는 몇 개일까?
- [ ] 256 × 4 = 1024
- [x] 2³² — 약 43억 개
- [ ] 충분하고도 남는다 — 지구상의 모든 사람에게 여러 개씩
:::

:::evaluate
답안 확인
:::

:::note
약 43억 개라고 하면 많게 들리지만, 지구상의 사람 수보다도 적다. 사람 한 명당 주소 하나도 돌아가지 않는 셈이다. 그래서 IPv4는 오래전부터 부족했다. 이 문제를 어떻게 다루는지는 나중에 NAT와 IPv6에서 배운다.
:::

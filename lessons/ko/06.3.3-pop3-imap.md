# POP3 또는 IMAP?

:::sim
url=/sims/lesson-6.3.btsim
:::

메일을 가져오는 데는 두 가지 프로토콜이 있다. 이 시뮬레이션에서 **Anna는 POP3**를, **Ben은 IMAP**을 사용한다.

## 실험

1. :fa-play: **실행** 모드에서 **Ben**이 `anna@beaver-schule.de`로 메일을 보내 봐.
2. **Anna**의 **E-Mail** 앱에서 **가져오기**를 클릭해.
3. **Anna**와 **Ben**의 트레이스를 열고 메일을 가져올 때 사용하는 명령을 비교해 봐.

:::quiz match
USER / PASS -> POP3: 사용자 이름과 비밀번호로 두 단계에 걸쳐 로그인
RETR -> POP3: 메시지 하나를 다운로드
LOGIN -> IMAP: 사용자 이름과 비밀번호로 로그인
SELECT INBOX -> IMAP: 서버에서 폴더 열기
:::

:::evaluate
짝짓기 확인
:::

## 차이점

| | POP3 | IMAP |
|---|---|---|
| 포트 | 110 | 143 |
| 기본 개념 | 메일을 **다운로드**한 뒤 대개 서버에서 삭제 | 메일이 **서버에 남아** 있고 서버에서 관리됨 |
| 폴더, 읽음/읽지 않음 | 자신의 기기에만 있음 | 서버에 있음 — 어디서나 동일 |
| 여러 기기 (휴대폰, 노트북) | 불편함: 기기마다 상태가 다름 | 이상적: 모든 기기가 같은 사서함을 봄 |

:::note
BeaverTracer의 메일 프로그램은 POP3를 사용할 때도 메일을 서버에 그대로 둔다. 실제 프로그램은 다운로드 후 메일을 삭제하는 경우가 많고, 일정 기간 동안만 남겨 두기도 한다.
:::

Lena는 휴대폰, 태블릿, 학교 노트북에서 메일을 읽는다. 어떤 것을 사용해야 할까?
- [ ] POP3, 더 간단하기 때문에
- [x] IMAP, 모든 기기가 서버의 같은 사서함을 보기 때문에
- [ ] SMTP, 메일을 가져오기 위한 프로토콜이기 때문에
:::

:::tip 핵심 정리
**POP3**는 서버의 메일을 **한 대의** 기기로 다운로드한다. **IMAP**은 사서함을 **서버에서** 관리하며, 폴더와 읽음 상태를 모든 기기에 동시에 적용한다. 둘 다 **가져오기** 전용이며, 메일을 보낼 때는 항상 **SMTP**를 사용한다.
:::

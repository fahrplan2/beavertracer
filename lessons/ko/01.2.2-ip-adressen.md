# IP 주소 할당하기

:::sim
url=/sims/lesson-1.2.2.btsim
:::

두 장치가 서로 통신하려면 같은 네트워크 안에 있는 IP 주소가 필요해. 작업 영역에는 연결된 PC 두 대가 보여. 방금 네가 직접 만든 것과 똑같은 구성이야.

1. :fa-play: **실행** 모드로 전환하고 **Computer 1**을 클릭해서 열어.
2. 거기서 :fa-gear: **IP 설정**을 열어. 새 PC에는 이미 주소 `192.168.0.10`과 넷마스크 `/24`가 설정되어 있어. 그대로 두어도 돼.
3. 이제 **Computer 2**를 열어. 이 PC도 *똑같은* 주소 `192.168.0.10`을 가지고 있어. 이러면 제대로 동작할 수 없어. 네트워크 안에서 모든 주소는 한 번만 나타날 수 있기 때문이야. 주소를 `192.168.0.11`(넷마스크 `/24`)로 바꿔.

:::tip 핵심 정리
**IP 주소**(예: `192.168.0.10`)는 네트워크에서 장치의 주소야. 집 번지수와 비슷해. 모든 IP 주소는 한 네트워크 안에서 **한 번만** 나타날 수 있어.
:::

:::task
title: 주소를 제대로 할당했나요?
실행 모드를 그대로 유지한 채, 두 PC에 알맞은 주소가 할당되어 있고 서로 통신할 수 있는지 확인해 봐.
check: ip(1, "192.168.0.10/32")
check: ip(3, "192.168.0.11/32")
check: pingOk(1, 3)
:::

:::note
`/24`가 정확히 무엇을 뜻하는지, 그리고 네트워크를 어떻게 알맞게 나누는지는 4장에서 자세히 다룰 거야. 지금은 두 주소가 모두 `192.168.0.`으로 시작해야 하고 서로 겹치면 안 된다는 것만 알면 충분해.
:::

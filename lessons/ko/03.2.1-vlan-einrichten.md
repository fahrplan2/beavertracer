# 하나의 스위치, 두 개의 네트워크

:::sim
url=/sims/lesson-3.2.1.btsim
:::

스위치에는 PC 네 대가 연결되어 있어요. 행정실의 **Sekretariat**(포트 1)과 **Schulleitung**(포트 2), 그리고 컴퓨터실의 **Anna**(포트 3)와 **Ben**(포트 4)이에요. 모두 같은 네트워크 `192.168.0.0/24`에 속해 있어요.

## 문제 상황

:fa-play: **실행** 모드로 전환하고, **Anna**에서 :fa-terminal: **터미널**을 열어 Sekretariat에 ping을 보내 봐.

```
$ ping 192.168.0.10
```

Anna는 아무 문제 없이 Sekretariat에 접근할 수 있어. 바로 이것을 막고 싶은 거야.

## VLAN 설정하기

**VLAN**(*Virtual LAN*)은 스위치 안에서 따로 분리된 하나의 네트워크야. 각 VLAN에는 번호가 있는데, 이것을 **VLAN ID**라고 해. 행정실은 **VLAN 10**, 컴퓨터실은 **VLAN 20**으로 정하자.

1. 실행 모드에서 **스위치**를 클릭하고 **VLAN** 탭을 열어.
2. **VLAN 활성화**를 체크해. 포트마다 한 줄씩 있는 표가 나타나.
3. **PVID** 열에 VLAN ID를 입력해. **port 1**과 **port 2**에는 각각 `10`, **port 3**과 **port 4**에는 각각 `20`을 입력해. **모드**는 `untagged`로 그대로 둬.
4. 아래에 있는 **적용**을 클릭해.

:::note
**PVID**는 *Port VLAN ID*의 약자야. 이 포트로 들어오는 모든 것은 이 VLAN에 속해. `untagged` 모드는 이 포트에 VLAN에 대해 몰라도 되는 평범한 PC가 연결되어 있다는 뜻이야.
:::

## 테스트하기

**Anna**에서 Sekretariat에 다시 ping을 보내 보고, 이어서 Ben에게도 보내 봐(`ping 192.168.0.21`).

:::quiz mc
이제 어떻게 될까?
- [ ] Anna는 Sekretariat과 Ben에게 접근할 수 있다
- [x] Anna는 Ben에게는 접근할 수 있지만 Sekretariat에는 더 이상 접근할 수 없다
- [ ] Anna는 더 이상 아무에게도 접근할 수 없다
:::

:::evaluate
답 확인
:::

:fa-magnifying-glass: **추적** 모드에서 **Sekretariat**의 트레이스를 열어 봐. Anna의 ARP 요청("Who has 192.168.0.10?")이 거기에는 전혀 나타나지 않아. Anna의 브로드캐스트는 VLAN 20 안에만 머물러. 스위치에게 이제 이 둘은 서로에 대해 아무것도 알지 못하는 별개의 두 네트워크인 거야.

:::tip 핵심 정리
**VLAN**을 사용하면 하나의 스위치를 논리적으로 분리된 여러 네트워크로 나눌 수 있어. 서로 다른 VLAN에 있는 장치끼리는 직접 통신할 수 없고, 브로드캐스트도 자기 VLAN 안에만 머물러. 각 VLAN에는 번호가 있는데, 이것이 **VLAN ID**야.
:::

# 처음부터 끝까지 하나의 연결

:::sim
url=/sims/lesson-5.1.btsim
:::

**Server**에서는 에코 서비스가 포트 `5000`에서 실행된다. 서버는 받은 메시지를 모두 곧바로 되돌려 보낸다. **단순 TCP 클라이언트**를 사용하면 연결을 단계별로 제어할 수 있다. 버튼 하나하나가 각각 한 단계다.

## 실험

1. :fa-play: **실행** 모드로 전환하고 **Client-PC**를 클릭한 다음 **단순 TCP 클라이언트**를 연다.
2. **Host**에 `192.168.0.20`을, **Port**에 `5000`을 입력한다.
3. **연결**을 클릭한다.
4. 메시지 입력란에 `Hello World`를 입력하고 **전송**을 클릭한다. 곧바로 채팅 창에서 서버의 에코를 볼 수 있다.
5. **연결 해제**를 클릭한다.
6. :fa-magnifying-glass: **추적** 모드로 전환하고 **+**를 눌러 **Client-PC**의 `eth0` 포트에 대한 트레이스를 연다.

:::note
처음에 나오는 두 개의 ARP 패킷은 1장에서 이미 배웠다. TCP 패킷의 **Info** 열에는 먼저 `49152 → 5000`(어느 포트에서 어느 포트로 가는지)이 나오고, 그다음 대괄호 안에 **플래그**가, 그 뒤에 `Seq=`, `Ack=`, `Len=` 같은 숫자가 나온다. 이 숫자들은 5.2.3쪽부터 다룬다. 여기서는 플래그와 `Len`에 주목한다.
:::

## 1단계: 연결

:::quiz short
**연결**을 클릭한 뒤 내 메시지가 전송되기 전까지 TCP 패킷은 몇 개 오갔을까?
= 3
= 세 개
= 삼
:::

:::quiz mc
`[SYN]`이 있는 첫 번째 패킷을 보내는 쪽은 누구일까?
- [x] Client-PC
- [ ] Server
:::

:::quiz mc
서버는 여기에 어떤 플래그로 응답할까?
- [ ] `[SYN]`
- [x] `[SYN, ACK]`
- [ ] `[ACK]`
- [ ] `[FIN, ACK]`
:::

## 2단계: 전송

`Len`은 패킷이 몇 바이트의 페이로드를 담고 있는지 나타낸다.

:::quiz short
내 메시지가 담긴 패킷은 몇 바이트를 담고 있을까(`Len`)?
= 13
:::

:::note
`Hello World`는 11자뿐이다. 하지만 TCP 클라이언트는 줄 끝(2바이트, `\r\n`)을 덧붙인다. SMTP나 HTTP 같은 많은 인터넷 프로토콜이 이런 형식을 기대하기 때문이다.
:::

:::quiz mc
서버는 내 메시지 직후, 에코보다도 먼저 무엇을 되돌려 보낼까?
- [x] `[ACK]`와 `Len=0`이 있는 패킷 — 데이터 없는 확인 응답
- [ ] 아무것도 보내지 않는다
- [ ] 새로운 `[SYN]`
:::

# TCP/IP 참조 모델

ISO/OSI 모델은 매우 상세하지만, 순전히 이론적으로 만들어졌다. 실무에서, 그리고 인터넷에서도 실제로는 계층이 네 개뿐인 더 간결한 **TCP/IP 모델**이 자리를 잡았다. 이 모델은 여러 OSI 계층을 하나로 묶는다:

| TCP/IP 계층 | 대응하는 OSI 계층 | 예시 프로토콜 |
|---|---|---|
| 응용 | 5, 6, 7 (세션, 표현, 응용) | HTTP, DNS, SMTP |
| 전송 | 4 (전송) | TCP, UDP |
| 인터넷 | 3 (네트워크) | IP, ICMP |
| 네트워크 액세스 | 1, 2 (물리, 데이터 링크) | Ethernet, WLAN |

ARP는 네트워크 액세스 계층과 인터넷 계층의 경계에 위치한다(OSI 2/3 계층, 마지막 페이지의 경계 사례 참고).

세션/표현/응용으로의 구분은 실무에서 명확하게 나뉘는 경우가 드물다. HTTP 같은 대부분의 응용 계층 프로토콜은 이 모든 것을 스스로 처리한다. TCP/IP 모델은 이 세 계층을 하나로 묶어 이러한 점을 반영한다.

:::note
다음 장에서 "계층 2", "계층 3", "계층 4"라는 표현을 읽게 되면, 이는 항상 ISO/OSI 모델의 번호를 의미한다. 이 강의에서는 BeaverTracer와 실무가 흔히 TCP/IP 범주로 생각하더라도, OSI 번호를 공통 기준으로 계속 사용한다.
:::

:::quiz fill
TCP/IP 모델은 OSI 계층인 세션, {표현}, 응용 계층을 하나의 응용 계층으로 묶는다. OSI 1계층과 2계층은 함께 TCP/IP 계층의 {네트워크 액세스}에 해당한다.
:::

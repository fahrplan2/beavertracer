# HTTPS 설정하기

:::sim
url=/sims/lesson-8.3.3.btsim
:::

여기서는 8.2.2절에서 끝난 부분부터 이어서 진행한다. 웹 서버 **www.beaver-schule.de**에는 **Schul-CA**와 그 CA가 발급한 서버 인증서가 있고, **Client-PC**는 Schul-CA를 신뢰한다. 다만 웹 서버는 아직 HTTPS를 사용하지 않는다.

## 사전 확인

:fa-play: **실행** 모드로 전환하고 **Client-PC**에서 :fa-globe: **브라우저**로 `https://www.beaver-schule.de/`에 접속해 봐라.

:::quiz mc
어떻게 될까?
- [x] 연결이 되지 않는다 — 포트 443에서 대기 중인 서비스가 없다
- [ ] 브라우저가 안전하지 않은 인증서에 대해 경고한다
- [ ] 페이지가 자물쇠 없이 표시된다
:::

:::evaluate
답 확인
:::

## HTTPS 켜기

1. 웹 서버에서 **HTTP 서버**를 열고 **Stoppen**을 클릭해라 — 서버가 실행 중인 동안에는 설정을 변경할 수 없다.
2. **HTTPS** 탭으로 이동해라:
    - **HTTPS aktivieren**에 체크하고, **HTTPS-Port**는 `443`으로 설정
    - **Zertifikat**에서 서버 인증서 `www.beaver-schule.de`를 선택 — Schul-CA가 아니다!
    - **Verwenden**을 클릭
3. **시작**을 클릭해라.

Client-PC에서 다시 `https://`로 페이지에 접속해 봐라. 자물쇠를 클릭해서 발급자와 유효 기간을 확인해 봐라.

:::task
title: HTTPS 설정 완료?
Client-PC가 https://www.beaver-schule.de/ 를 인증서 경고 없이 가져올 수 있는지 확인한다. 이를 위해 시뮬레이션이 실행 모드에서 동작 중이어야 한다.
check: httpsOk(2, "https://www.beaver-schule.de/")
:::

:::quiz mc
HTTP 서버에서 **Schul-CA**의 인증서를 선택하면 안 되는 이유는 무엇일까?
- [ ] CA 인증서는 암호화를 할 수 없기 때문에
- [x] 그 인증서는 `www.beaver-schule.de`가 아니라 `Schul-CA`라는 이름으로 발급되어 있어서 브라우저가 경고하기 때문에
- [ ] Schul-CA에는 개인 키가 없기 때문에
:::

:::quiz mc
Schul-CA를 신뢰하지 **않는** 기기, 예를 들어 손님의 휴대폰에서는 무엇이 보일까?
- [ ] 자물쇠와 함께 페이지가 평소처럼 보인다
- [x] 알려진 CA까지 신뢰 체인을 추적할 수 없으므로 인증서 경고가 표시된다
- [ ] 연결이 거부되므로 아무것도 보이지 않는다
:::

:::note
공개 웹사이트에는 모든 브라우저에 미리 설치되어 있는 CA의 인증서가 필요하다. 2015년부터는 이런 인증서를 무료로 자동 발급해 주는 CA인 **Let's Encrypt**가 있으며, 오늘날 거의 모든 웹사이트가 HTTPS를 사용하게 된 주요 이유 중 하나이다.
:::

:::tip 핵심 정리
**HTTPS**를 사용하려면 웹 서버에 주소와 이름이 일치하는, **개인 키가 있는 서버 인증서**가 필요하고 **포트 443**에서 대기해야 한다. 클라이언트는 발급한 **CA**를 알고 있을 때에만 그 사이트를 신뢰한다.
:::

# 첫 번째 규칙 만들기

:::sim
url=/sims/lesson-9.btsim

이제 네가 직접 해 볼 차례야. 방화벽은 아직 모든 트래픽을 통과시키고 있어. 인터넷에서는 학교 서버의 **Webseite (80)** 과 **Mail-Empfang (25)** 만 접근할 수 있도록 설정해 봐. **SSH (22)**, **POP3 (110)**, **IMAP (143)** 은 인터넷에서 더 이상 접근할 수 없어야 해.

## 규칙 추가하기

1. **Firewall**을 클릭해. 기본 정책은 일단 **Alle zulassen**으로 그대로 둬.
2. 기존 규칙은 어차피 모든 것을 허용하니까 삭제하고, **+ Regel hinzufügen**으로 차단하려는 포트마다 규칙을 하나씩 만들어:
    - **Richtung** A → B (인터넷에서 들어오는 방향)
    - **Protokoll** TCP
    - **Ziel-Port** 예: `22`
    - **Aktion** Verwerfen
3. **Internet-PC**에서 `nmap 198.51.100.10`을 실행해서 올바른 포트만 열려 있는지 확인해 봐.

:::task
title: 외부에서는 웹과 메일만 가능할까?
학교 서버가 인터넷에서 포트 80과 25로만 접근 가능한지, 그리고 Lehrer-PC가 여전히 메일을 가져오고 인터넷을 사용할 수 있는지 확인해. 이를 위해 시뮬레이션이 실행 모드로 동작 중이어야 해.
check: tcpOpen(1, "198.51.100.10", 80)
check: tcpOpen(1, "198.51.100.10", 25)
check: tcpFails(1, "198.51.100.10", 22)
check: tcpFails(1, "198.51.100.10", 110)
check: tcpFails(1, "198.51.100.10", 143)
check: tcpOpen(8, "198.51.100.10", 110)
check: tcpOpen(8, "203.0.113.80", 80)
:::

:::quiz mc
Lehrer-PC는 여전히 POP3(110)로 학교 서버에서 메일을 가져올 수 있어. 방화벽이 왜 이것을 방해하지 않을까?
- [ ] 방화벽이 교사를 알아보기 때문에
- [x] 패킷이 방화벽을 아예 통과하지 않기 때문에 — Lehrer-PC와 학교 서버는 방화벽 뒤의 같은 스위치에 연결되어 있다
- [ ] POP3는 안전한 프로토콜이기 때문에
:::

답 확인

:::note
방화벽은 **자신을 통과해서** 흐르는 트래픽만 보호해. 학교 네트워크 내부에서 일어나는 일은 방화벽이 볼 수 없어. 그래서 학교 네트워크 안에 감염된 컴퓨터가 있으면 여전히 학교 서버를 공격할 수 있어. 이 내용은 DMZ를 다루는 부분에서 살펴볼 거야.
:::

:::tip 핵심 정리
외부에서 접근하면 안 되는 서비스는 **Richtung**, **Protokoll**, **Ziel-Port**를 지정한 규칙으로 접근을 차단해. 규칙이 제대로 작동하는지는 외부에서 **포트 스캔**으로 확인해.
:::

# 태블릿을 WLAN에 연결하기

:::sim
url=/sims/lesson-3.3.1.btsim
:::

스위치에는 **Schul-PC**(`192.168.0.10`)와 **액세스 포인트**가 연결되어 있다. 태블릿 **Anna**(`192.168.0.30`)를 학교 WLAN에 연결해야 한다.

## WLAN 찾기

:fa-play: **실행** 모드로 전환하고 **액세스 포인트**를 클릭해 봐. 여기에 이 액세스 포인트의 WLAN 이름인 **SSID**가 표시되어 있어: `Schule`.

액세스 포인트는 브리지처럼 동작해. 무선으로 도착한 것을 케이블을 통해 스위치로 전달하고, 반대 방향도 마찬가지야. 그래서 Anna와 Schul-PC는 같은 로컬 네트워크에 속하게 돼.

## 태블릿 연결하기

1. **Anna**를 클릭하고 :fa-gear: **IP 설정**을 연 다음 **WiFi** 탭을 선택해.
2. **SSID**에 WLAN 이름 `Schule`을 입력하고 **적용**을 클릭해.
3. Anna에서 :fa-terminal: **터미널**을 열고 Schul-PC에 ping을 보내 봐:
   ```
   $ ping 192.168.0.10
   ```

ping을 보내는 동안 작업 영역을 잘 봐. Anna와 액세스 포인트 주변으로 전파가 퍼져 나가.

:::tip 핵심 정리
**WLAN**은 무선으로 연결되는 로컬 네트워크다. **액세스 포인트**는 WLAN을 유선 네트워크와 연결한다. 모든 WLAN에는 **SSID**(*Service Set Identifier*)라는 이름이 있다. 장치는 연결하려면 올바른 SSID를 알아야 한다.
:::

:::quiz mc
Anna의 SSID를 `schule`(소문자)로 입력하면 어떻게 될까?
- [ ] 아무 일도 일어나지 않는다 — 대소문자는 중요하지 않다
- [x] Anna의 연결이 끊어진다 — SSID가 정확히 일치해야 한다
- [ ] Anna가 다른 WLAN에 연결된다
:::

title: Anna가 WLAN에 연결되어 있을까?
Anna가 올바른 SSID로 연결되어 있고 Schul-PC에 도달할 수 있는지 확인한다. 이를 위해 시뮬레이션이 실행 모드로 동작 중이어야 한다.

:::

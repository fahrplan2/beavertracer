# 3계층: 라우터, IP 주소, 서브네팅

:::goal
**학습 목표:** IP 주소를 2진수로 읽고, 네트워크 주소와 브로드캐스트 주소를 계산하고, 네트워크를 같은 크기의 서브넷으로 나누고, 라우터와 라우팅 테이블로 네트워크를 연결할 수 있다.
:::

지금까지는 모든 장치가 스위치와 액세스 포인트로 연결된 *하나의* 로컬 네트워크 안에 있었어. 하지만 인터넷은 이런 네트워크가 수백만 개 모여 이루어져 있어. 너의 홈 네트워크, 학교 네트워크, 이동통신사의 네트워크, 대형 데이터 센터의 네트워크가 모두 그 예야.

패킷은 어떻게 한 네트워크에서 다른 네트워크로 가는 길을 찾을까? 이 일을 맡는 것이 **3계층**, 즉 네트워크 계층이야. 여기서는 **인터넷 프로토콜(IP)**, IP 주소, 그리고 네트워크를 서로 연결하는 장치인 **라우터**가 사용돼.

:::note
IP는 1981년부터 **RFC 791**이라는 표준으로 규정되어 있어. 이 장에서 주로 다루는 버전은 **IPv4**야. 더 새로운 버전인 **IPv6**는 이 장의 끝부분에서 배우게 돼.
:::

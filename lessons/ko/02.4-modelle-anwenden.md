# 모델 적용하기

이 장의 처음에 했던 실험에 나온 프로토콜을 해당하는 OSI 계층에 짝지어 보세요:

:::quiz match
Ethernet -> 2계층 — 데이터 링크
IPv4 -> 3계층 — 네트워크
TCP -> 4계층 — 전송
HTTP -> 7계층 — 응용
:::

:::evaluate
짝짓기 확인
:::

마지막으로 데이터 단위의 이름을 짝지어 보세요:

:::quiz match
프레임 -> 2계층 — 데이터 링크
패킷 -> 3계층 — 네트워크
세그먼트 -> 4계층 — 전송
:::

:::evaluate
짝짓기 확인
:::

이제 앞으로 프로토콜을 정확하게 분류할 수 있는 도구를 갖추었다. 다음 장부터는 계층을 차례대로 살펴본다. 2계층부터 시작해서, 스위치는 패킷을 어디로 전달해야 하는지 어떻게 알고 있는지를 다룬다.

# DNS는 어떻게 구성되어 있을까

:::sim
url=/sims/lesson-6.2.btsim
:::

어떤 서버도 세상의 모든 이름을 혼자서 알 수는 없다. 그래서 DNS는 이름 자체와 마찬가지로 **계층적**으로 구성되어 있다. 이름은 오른쪽에서 왼쪽으로 읽는다:

```
www . beaver-schule . de . (Root)
 │          │         │      └─ Root-Server: kennen die Server aller Top-Level-Domains
 │          │         └─ Top-Level-Domain (TLD): der de-Server kennt alle .de-Domains
 │          └─ Domain: der Schul-DNS ist für beaver-schule.de zuständig
 └─ Rechnername innerhalb der Domain
```

도메인을 담당하며 답을 실제로 알고 있는 서버를 **권한 있는(authoritative)** 서버라고 한다. 그곳까지 가는 과정은 PC를 대신해 **리졸버(Resolver)**가 맡는다. 여기서는 **DNS-Resolver** 컴퓨터가 그 역할을 한다.

## 실험

1. :fa-play: **실행** 모드로 전환하고 **Client-PC**의 :fa-terminal: **터미널**에 다음을 입력한다:
   ```
   $ nslookup www.beaver-schule.de
   ```
2. :fa-magnifying-glass: **추적** 모드에서 **DNS-Resolver**의 트레이스를 연다.

리졸버는 너를 대신해 여러 번의 질의를 보냈다. 어떤 서버가 어떤 응답을 주었는지 짝지어 보자:

:::quiz match
Root-Server (192.168.0.101) -> 참조: .de는 ns.nic.de가 담당한다
de-Server (192.168.0.102) -> 참조: beaver-schule.de는 ns.beaver-schule.de가 담당한다
Schul-DNS (192.168.0.103) -> 응답: www.beaver-schule.de의 주소는 192.168.0.20이다
:::

:::quiz mc
리졸버는 가장 먼저 누구에게 질의할까?
- [x] Root 서버
- [ ] Schul-DNS
- [ ] Client-PC
:::

:::evaluate
답 확인
:::

:::note
중간에 리졸버는 자신이 안내받은 서버의 주소도 질의한다(`A ns.nic.de`). 실제 DNS 서버는 보통 이런 주소를 처음부터 함께 보내 준다. 또한 리졸버는 모든 응답을 한동안 기억해 둔다(**캐시**). 같은 이름에 대한 다음 질의에는 곧바로 직접 응답한다. 얼마나 오래 기억하는지는 레코드에 **TTL**(*Time to Live*)로 초 단위로 적혀 있다.
:::

## 가장 중요한 레코드 유형

| 유형 | 의미 | 예시 |
|---|---|---|
| **A** | 이름 → IPv4 주소 | `www.beaver-schule.de` → `192.168.0.20` |
| **AAAA** | 이름 → IPv6 주소 | `www.beaver-schule.de` → `2001:db8::20` |
| **CNAME** | 이름 → 다른 이름(별칭) | `web.beaver-schule.de` → `www.beaver-schule.de` |
| **MX** | 도메인을 담당하는 메일 서버 | `beaver-schule.de` → `mail.beaver-schule.de` |
| **NS** | 도메인을 담당하는 DNS 서버 | `beaver-schule.de` → `ns.beaver-schule.de` |

:::tip 핵심 정리
DNS는 **계층적**이다. **루트 서버**는 **최상위 도메인(TLD)**(예: `.de`)의 서버를 안내하고, TLD 서버는 개별 **도메인**의 서버를 안내한다. 담당 **권한 있는** 서버가 답을 알고 있다. **리졸버**는 PC를 대신해 이 경로를 따라가며 응답을 기억해 둔다(**캐시**). 중요한 레코드 유형은 **A**, **AAAA**, **CNAME**, **MX**, **NS**이다.
:::

## 레코드 추가하기

학교는 웹사이트를 `intranet.beaver-schule.de`로도 접속할 수 있기를 원한다.

1. :fa-play: **실행** 모드에서 **Schul-DNS**를 클릭하고 **DNS-Server** 앱을 연다.
2. **A** 탭을 연다. **+**를 클릭하고 새 행에 이름 `intranet.beaver-schule.de`와 주소 `192.168.0.20`을 입력한다.
3. Client-PC에서 `nslookup intranet.beaver-schule.de`로 테스트한다.

:::task
title: 새 이름을 등록했나요?
Client-PC가 intranet.beaver-schule.de 이름을 웹 서버의 주소로 해석하는지 확인한다. 이를 위해 시뮬레이션이 실행 모드에서 동작 중이어야 한다.
check: resolves(2, "intranet.beaver-schule.de", "192.168.0.20")
:::

# 해시값: 데이터의 지문

:::sim
url=/sims/lesson-8.1.3.btsim
:::

**해시 함수**는 문장, 문서, 영화 한 편 전체처럼 길이에 상관없이 어떤 데이터든 입력받아 고정된 길이의 짧은 문자열인 **해시값**을 계산한다. 해시값은 **지문**처럼 작동한다. 같은 데이터는 항상 같은 해시값이 되고, 다른 데이터는 다른 해시값이 된다.

오늘날 일반적으로 쓰는 해시 함수는 **SHA-256**이다. SHA-256의 해시값은 항상 256비트 길이이며, 16진수로 나타내면 64자이다.

## 실험

**PC**의 `/home` 폴더에는 간단한 매매 계약서가 담긴 파일 세 개가 있다. :fa-play: **실행** 모드로 전환하고, **PC**에서 :fa-terminal: **터미널**을 연 다음 다음을 입력해 봐.

```
$ cd /home
$ cat vertrag.txt vertrag-kopie.txt vertrag-neu.txt
$ sha256sum vertrag.txt vertrag-kopie.txt vertrag-neu.txt
```

## 해시 함수의 특성

| 특성 | 의미 |
|---|---|
| **고정 길이** | 데이터가 아무리 커도 해시값의 길이는 항상 같다. |
| **결정적** | 같은 데이터는 항상 같은 해시값이 된다. |
| **눈사태 효과** | 아주 작은 변경만으로도 완전히 다른 해시값이 된다. |
| **일방향 함수** | 해시값으로부터 원래 데이터를 되돌려 계산할 수 **없다**. |
| **충돌 저항성** | 같은 해시값을 가진 서로 다른 두 파일을 찾는 것은 사실상 불가능하다. |

해시 함수는 **암호화가 아니다**. 키도 없고 복호화도 없다. 해시 함수는 다른 목적, 즉 **무결성**을 위해 쓰인다.

## 어디에 필요할까?

- **다운로드 확인:** 많은 웹사이트가 파일과 함께 SHA-256 값을 제공한다. 내가 내려받은 파일의 해시값이 이 값과 일치하면, 전송 도중 파일이 변경되지 않은 것이다.
- **비밀번호 저장:** 좋은 웹사이트는 비밀번호 자체가 아니라 그 해시값만 저장한다. 로그인할 때는 입력한 값의 해시값을 비교한다. 데이터베이스를 도난당하더라도 도둑은 비밀번호를 알 수 없다.
- **디지털 서명:** 문서 전체 대신 그 해시값에만 서명한다. 자세한 내용은 다음 절에서 다룬다.

:::tip 핵심 정리
**해시 함수**(예: **SHA-256**)는 임의의 데이터로부터 고정된 길이의 **해시값**, 즉 **지문**을 계산한다. 아주 작은 변경만으로도 완전히 다른 해시값이 되며, 해시값으로부터 데이터를 되돌려 계산할 수 없다. 해시값은 데이터의 **무결성**을 보장한다.
:::

# 여러 대의 라우터

:::goal
**학습 목표:** 라우팅 테이블을 읽고, 정적 경로를 등록하고, `traceroute`로 패킷의 경로를 추적하고, 대표적인 라우팅 오류를 찾아낼 수 있다.
:::

:::sim
url=/sims/lesson-4.5.2.btsim
:::

지금까지는 두 네트워크 사이에 항상 라우터가 정확히 한 대만 있었고, 그 라우터는 두 네트워크에 직접 연결되어 있어서 둘 다 알고 있었어. 하지만 인터넷에서는 송신자와 목적지 사이에 라우터가 여러 대 이어져 있는 경우가 많아. 그렇다면 각 라우터는 패킷을 다음에 어디로 보내야 하는지 어떻게 알까?

답은 라우터의 **라우팅 테이블**에 있어. 라우팅 테이블을 읽는 방법과 직접 보완하는 방법을 이번 절에서 배우게 될 거야.

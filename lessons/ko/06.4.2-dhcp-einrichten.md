# DHCP 서버 설정하기

:::sim
url=/sims/lesson-6.4.2.btsim
:::

이번에는 DHCP 서버가 아직 설정되어 있지 않아. 서버가 어떤 설정을 배포할지는 네가 정해 줘:

| 설정 | 값 |
|---|---|
| 주소 범위 | `192.168.0.100` ~ `192.168.0.120` |
| 게이트웨이 | `192.168.0.1` |
| DNS 서버 | `192.168.0.53` |

1. :fa-play: **실행** 모드로 전환하고, **DHCP-Server**를 클릭한 다음 **DHCP 서버** 앱을 열어.
2. **범위 시작**, **범위 끝**, **Gateway**, **DNS-Server**를 입력하고 **저장**을 클릭한 다음 **시작**을 클릭해.
3. **Laptop 1**과 **Laptop 2**에서 :fa-gear: **IP 설정**의 모드를 **DHCP**로 바꾸고, 각각 **적용**을 클릭해.
4. DHCP 서버의 **Leases** 탭에서 어떤 장치가 어떤 주소를 받았는지 확인해.

:::note
주소 범위는 고정 주소와 충돌하지 않도록 선택한다. 서버, 라우터, 프린터는 흔히 DHCP 범위 밖의 고정 주소를 받는다. 여기서는 예를 들어 DHCP 서버 자신이 `192.168.0.2`를 사용한다.
:::

:::task
title: DHCP를 설정했나요?
두 노트북이 모두 DHCP 범위에서 주소를 받았고 DHCP 서버에 도달할 수 있는지 확인한다. 이를 위해 시뮬레이션이 실행 모드로 동작 중이어야 한다.
check: ip(3, "192.168.0.96/27")
check: ip(4, "192.168.0.96/27")
check: pingOk(3, 2)
check: pingOk(4, 2)
:::

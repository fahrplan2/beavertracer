**하이퍼텍스트 전송 프로토콜**(**HTTP**, Hypertext Transfer Protocol)은 브라우저와 웹 서버가 서로 대화할 때 사용하는 언어야. 서버에는 **Beaver-Schule**의 웹 페이지가 있어. 시작 페이지, 연락처 페이지, 그리고 모양을 꾸미는 스타일시트가 들어 있어.

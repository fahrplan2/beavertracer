# 외부에서 내부로: 포트 포워딩

:::sim
url=/sims/lesson-7.2.3.btsim
:::

홈 네트워크에 이제 별도의 **Heim-Webserver**(`192.168.178.10`)가 있다. Clara는 외출 중에 이 페이지에 접속하고 싶어 한다. Clara의 노트북 **Clara**는 오른쪽 인터넷에 연결되어 있다.

## 문제

1. :fa-play: **실행** 모드로 전환하고 **Clara**의 :fa-globe: **브라우저**에서 `http://203.0.113.2/`에 접속해 봐라. 이 주소는 홈 네트워크의 공인 주소다.
2. 브라우저가 계속 기다리기만 한다. 몇 초 후 **Stopp**를 클릭해라.
3. :fa-magnifying-glass: **추적** 모드에서 **Heimrouter**의 `wan0` 포트에 대한 트레이스를 열어 봐라.

:::quiz mc
Clara의 연결 설정(`[SYN]`, 포트 80)은 어떻게 될까?
- [x] 가정용 라우터까지는 도착하지만, 라우터가 이를 전달하지도 응답하지도 않는다
- [ ] Heim-Webserver에 도달하고, 서버가 RST로 응답한다
- [ ] 가정용 라우터에 아예 도착하지 않는다
:::

:::evaluate
답 확인
:::

외부에서 들어오는 패킷에 대해서는 NAT 테이블에 항목이 없다. 홈 네트워크의 누구도 이 연결을 시작하지 않았기 때문이다. 가정용 라우터는 이 패킷을 어느 장치로 보내야 할지 알지 못하고, 그래서 폐기한다.

## 포트 포워딩 설정하기

**포트 포워딩**(일부 라우터에서는 *포트 개방*이라고도 한다)으로 다음과 같이 정할 수 있다. 특정 WAN 포트로 들어오는 모든 것은 홈 네트워크의 특정 장치로 전달된다.

1. **Heimrouter**를 클릭하고 **Port FW** 탭을 열어라.
2. 규칙을 하나 추가해라. 프로토콜 `TCP`, WAN 포트 `80`, LAN IP `192.168.178.10`, LAN 포트 `80`을 입력하고 **+ Hinzufügen**을 클릭해라.
3. **Clara**에서 `http://203.0.113.2/`에 다시 접속해 봐라.

:::task
title: 외부에서 홈 웹 서버에 접속할 수 있을까?
Clara가 인터넷에서 홈 네트워크 공인 주소의 포트 80으로 연결을 설정할 수 있는지 확인한다. 이를 위해 시뮬레이션이 실행 모드로 동작 중이어야 한다.
check: tcpOpen(12, "203.0.113.2", 80)
:::

:::warning
포트 포워딩은 내부로 향하는 구멍을 연다. 인터넷의 누구나 그 뒤에 있는 장치에 접근할 수 있고, 열린 포트를 자동으로 찾아다니는 공격자도 예외가 아니다. 그러므로 꼭 필요한 것만 전달하고 장치를 항상 최신 상태로 유지해라. 이에 대해서는 9장(방화벽)에서 더 자세히 다룬다.
:::

:::tip 핵심 정리
외부에서는 NAT 뒤에 있는 장치로 연결을 시작할 수 없다. 라우터가 어디로 보내야 할지 모르기 때문이다. **포트 포워딩**은 특정 **WAN 포트**로 들어오는 패킷을 특정 **LAN IP**(와 LAN 포트)로 보내도록 정한다. 이렇게 해서 홈 네트워크의 서버를 인터넷에서 접속할 수 있게 된다.
:::

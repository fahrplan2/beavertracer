# DNS: 숫자 대신 이름

:::goal
**학습 목표:** DNS가 이름을 IP 주소로 어떻게 변환하는지, 이름이 어떻게 계층적으로 구성되는지 설명할 수 있다. 직접 레코드를 하나 만들 수 있고, 전형적인 DNS 오류를 찾을 수 있다.
:::

:::sim
url=/sims/lesson-6.2.btsim
:::

IP 주소를 외우는 사람은 거의 없지만, `www.beaver-schule.de` 같은 이름은 기억하기 쉽다. 이 변환을 담당하는 것이 **Domain Name System**(**DNS**)이며, 인터넷의 전 세계 전화번호부와 같은 역할을 한다.

작업 영역에는 이제 조금 더 큰 네트워크가 놓여 있다. **Client-PC**와 **Webserver** 외에 **DNS-Server**가 네 대 있다. 왜 이렇게 많이 필요한지는 다다음 페이지에서 확인할 수 있다.

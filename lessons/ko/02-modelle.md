# 모델

:::goal
**학습 목표:** 패킷이 계층으로 어떻게 구성되는지(캡슐화) 설명할 수 있고, 트레이서에서 각 계층의 이름을 말할 수 있으며, ISO/OSI 참조 모델과 TCP/IP 참조 모델을 설명하고 서로 비교할 수 있다.
:::

1장에서 링크를 한 번 클릭하는 것만으로도 ARP, TCP, HTTP처럼 서로 다른 여러 프로토콜이 동작한다는 것을 보았다. 각 프로토콜은 저마다 맡은 역할이 있다. 이렇게 많은 프로토콜을 체계적으로 분류하기 위해 네트워크 기술에서는 계층 모델을 사용한다.

이 장에서는 먼저 패킷 하나를 분해해 살펴보고, 이어서 가장 중요한 두 모델을 알아본다. 7개의 계층으로 이루어진 ISO/OSI 참조 모델과, 좀 더 실용적인 4개 계층의 TCP/IP 모델이다. 이 두 모델은 앞으로의 장에서도 계속 등장한다. 지금부터 우리가 네트워크에 대해 이야기할 때 함께 쓰는 공통 용어이기 때문이다.

# 프로젝트: 네 개 지점을 가진 회사

:::sim
url=/sims/lesson-4.5.4.btsim
:::

한 회사가 **Hanau**에 본사를 두고, **Kassel**, **Gießen**, **Darmstadt**에 지사를 두고 있다. 각 지점은 자체 네트워크와 자체 라우터를 가지고 있다. 모든 라우터는 전용선을 통해 **중앙 네트워크**에 연결되어 있으며, 이곳에 회사의 메인 서버도 있다.

## 주소 계획

관리자는 다음과 같은 방식으로 주소를 할당했다. 이 주소들은 시뮬레이션에 이미 입력되어 있다.

| 네트워크 | 주소 범위 |
|---|---|
| 중앙 네트워크 | `10.19.0.0/24` |
| Hanau | `10.19.1.0/24` |
| Kassel | `10.19.2.0/24` |
| Gießen | `10.19.3.0/24` |
| Darmstadt | `10.19.4.0/24` |

| 장치 | 중앙 네트워크에서 | 지점 네트워크에서 |
|---|---|---|
| Server | `10.19.0.10` | — |
| Router Hanau | `10.19.0.1` | `10.19.1.1` |
| Router Kassel | `10.19.0.2` | `10.19.2.1` |
| Router Gießen | `10.19.0.3` | `10.19.3.1` |
| Router Darmstadt | `10.19.0.4` | `10.19.4.1` |
| 지점의 PC | — | 각각 `.2` (예: PC Kassel `10.19.2.2`) |

모든 라우터에서 `eth0`은 중앙 네트워크를, `eth1`은 지점 네트워크를 향한다.

## 너의 과제

회사의 모든 컴퓨터가 서로, 그리고 서버에 도달하려면 아직 두 가지가 빠져 있다.

1. **게이트웨이:** 네 대의 PC와 서버 모두에 게이트웨이를 입력해라. PC는 각자 지점의 라우터를 사용하고, 서버는 **Router Hanau**를 사용한다.
2. **라우팅 테이블:** 네 대의 라우터 모두에 아직 빠져 있는 경로를 추가해라. 각 라우터는 **다른 세 곳**의 지점 네트워크를 알아야 한다.

중간중간 `ping`과 `traceroute`로 테스트해 봐라.

<details>
<summary>힌트: 여기서 경로는 어떤 모습일까?</summary>

**Router Kassel**의 예시: Gießen(`10.19.3.0/24`)으로 가는 패킷은 중앙 네트워크에 있는 Router Gießen으로 보낸다. 즉 **다음 홉**은 `10.19.0.3`, **Iface**는 `eth0`이다. 이 패턴에 따라 각 라우터는 세 개의 경로가 필요하다.
</details>

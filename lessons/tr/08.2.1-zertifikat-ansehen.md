# Bir sertifikayı görüntüleme

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Çalışma alanında **Client-PC**'yi, bir **DNS-Server**'ı ve okulun web sunucusu olan `www.beaver-schule.de`'yi görüyorsun. Web sunucusu sayfalarını **HTTPS** üzerinden de sunuyor.

## Tarayıcıdaki kilit

1. :fa-play: **Çalıştır** moduna geç, **Client-PC**'ye tıkla ve :fa-globe: **Tarayıcı**'yı aç.
2. `https://www.beaver-schule.de/` adresini aç — **https** kısmına dikkat et.
3. Adresin solunda bir **kilit** görünür. Ona tıkla.

:::quiz short
Sertifika hangi ad için düzenlenmiş (`CN=` olmadan konu)?
= www.beaver-schule.de
:::

:::quiz short
Sertifikayı kim düzenlemiş (`CN=` olmadan veren)?
= Biber Root CA
:::

:::evaluate
Cevapları kontrol et
:::

## Client-PC neden sertifikaya güveniyor?

**Client-PC** üzerinde :fa-shield-halved: **Zertifikatverwaltung**'u aç ve **Vertrauenswürdige CAs** sekmesine geç.

:::quiz mc
Orada ne buluyorsun?
- [x] **Biber Root CA**'nın sertifikasını
- [ ] `www.beaver-schule.de` sertifikasını
- [ ] Hiç kayıt yok
:::

:::quiz mc
Biber Root CA'nın bir kök CA olduğu nasıl anlaşılır?
- [x] **Kendinden imzalıdır**: Konu ve veren aynıdır
- [ ] Adı „CA“ ile biter
- [ ] Açık anahtarı yoktur
:::

:::quiz mc
Client-PC'de **Privater Schlüssel** altında „Ja“ mı yoksa „Nein“ mı yazıyor?
- [ ] Ja — istemci, imzaları doğrulamak için CA'nın özel anahtarına ihtiyaç duyar
- [x] Nein — doğrulamak için açık anahtar yeterlidir; özel anahtar yalnızca CA'dadır
:::

:::evaluate
Cevapları kontrol et
:::

## Karşı taraf: web sunucusu

Şimdi **www.beaver-schule.de** web sunucusunda :fa-shield-halved: **Zertifikatverwaltung**'u aç (**Meine Zertifikate** sekmesi) ve sertifikasına bak.

:::quiz multi
Web sunucusundaki sertifika için hangileri doğrudur?
- [x] **Privater Schlüssel** altında „Ja“ yazar — sunucu buna bağlantı kurulumu için ihtiyaç duyar
- [x] **Zincir** `www.beaver-schule.de ← Biber Root CA` şeklindedir
- [x] **Parmak izi**, tarayıcının kilit penceresindekiyle aynıdır
- [ ] Kendinden imzalıdır
:::

:::evaluate
Cevapları kontrol et
:::

:::note
**Parmak izi**, sertifika üzerinden hesaplanan bir özet (hash) değeridir. Bununla iki sertifika, tüm alanları tek tek kontrol etmeden hızlıca karşılaştırılabilir.
:::

:::tip Anahtar nokta
**Web sunucusu** sertifikasına **özel anahtarıyla birlikte** sahiptir. **İstemci** ise yalnızca **kök CA'nın sertifikasını** (özel anahtar olmadan) bilir — sunucu sertifikasındaki imzayı doğrulamak için bu yeterlidir. Tarayıcıda **kilide** tıklandığında konu, veren, parmak izi ve geçerlilik süresi görülür.
:::

# Sıralama diyagramı

:::sim
url=/sims/lesson-5.1.btsim
:::

Bir bağlantının akışı **sıralama diyagramı** ile çizilir: İstemci ve sunucu için birer dikey çizgi vardır, zaman yukarıdan aşağıya doğru akar. Her ok bir pakettir. Ok eğik çizilir, çünkü her paket yolda biraz zaman geçirir.

Bir önceki sayfadaki bağlantın şöyle görünür — onu izle ile satır satır karşılaştır:

:::seq
Client-PC -> Server: SYN
Server -> Client-PC: SYN, ACK
Client-PC -> Server: ACK
Client-PC -> Server: PSH, ACK "Hello World" len=13
Server -> Client-PC: ACK
Server -> Client-PC: PSH, ACK len=13
Client-PC -> Server: ACK
Client-PC -> Server: FIN, ACK
Server -> Client-PC: ACK
Server -> Client-PC: FIN, ACK
Client-PC -> Server: ACK
:::

Her okun üstünde **bayraklar (flag)**, altında ise `SEQ` ve `ACK` numaraları yer alır. **DATA**, veri taşıyan paketleri işaretler. Kırmızı sayılar istemciye, mavi sayılar sunucuya aittir — ne anlama geldiklerini bir sonraki sayfa açıklıyor.

## Bayraklar

| Bayrak | açılımı | Anlamı |
|---|---|---|
| **SYN** | *synchronize* | Bağlantı kurmak, başlangıç numarasını belirlemek |
| **ACK** | *acknowledge* | Alınan verileri onaylar |
| **PSH** | *push* | Verileri hemen uygulamaya iletmek |
| **FIN** | *finish* | „Ben bittim“ — bağlantıyı sonlandırmak |
| **RST** | *reset* | Bağlantıyı iptal etmek veya reddetmek (bununla ilgili daha fazlası 5.3.2'de) |

## Üç aşama

**Kurulum:** İstemci `SYN` gönderir, sunucu `SYN, ACK` ile yanıt verir, istemci `ACK` ile onaylar. Tam olarak üç paket gerektiği için buna **üçlü el sıkışma (three-way handshake)** denir.

**Veri:** Veri içeren her paket alıcı tarafından bir `ACK` ile onaylanır. Burada sunucu yankıyı (echo) geri gönderir — istemci bunu da onaylar.

**Sonlandırma:** Her taraf kendi gönderme yönünü ayrı ayrı kapatır: istemciden `FIN`, sunucudan `ACK` — ardından sunucudan `FIN`, istemciden `ACK`. Bu dört pakettir.

:::tip Anahtar nokta
Bir TCP bağlantısı üç aşamada ilerler: **Kurulum**, **üçlü el sıkışma** ile (`SYN` → `SYN, ACK` → `ACK`), **veri aktarımı** (her veri paketi `ACK` ile onaylanır) ve **sonlandırma** (her taraf `FIN` gönderir ve bir `ACK` alır).
:::

## Şimdi sıra sende

İstemci bu sefer yalnızca `Hi` gönderiyor (satır sonuyla birlikte 4 bayt). Eksik bayrakları gir — bir alan içindeki sıra önemli değildir.

Server -> Client-PC: ? ACK
Client-PC -> Server: ? FIN, ACK
Server -> Client-PC: ? ACK
Server -> Client-PC: ? FIN, ACK
Client-PC -> Server: ? ACK

Demek ki bir web sayfası çoğu zaman birçok dosyadan oluşur: metin, stil dosyaları, resimler. Tarayıcı her biri için ayrı bir istek gönderir.

## Bir istek nasıl görünür

İz kaydında `GET / HTTP/1.1` paketine tıkla ve **Hypertext Transfer Protocol** bölümünü aç. Bir HTTP isteği düz metindir:

```
GET / HTTP/1.1              ← Methode, Pfad, Version
Host: 192.168.0.20          ← Header: zusätzliche Angaben
…
                            ← Leerzeile: Ende der Anfrage
```

Sunucunun yanıtı da aynı şekilde oluşturulmuştur — bir durum satırı, başlıklar, bir boş satır ve ardından asıl dosya bulunur:

```
HTTP/1.1 200 OK             ← Version, Statuscode, Text
Content-Type: text/html     ← Header: Art der Datei
Content-Length: 301         ← Header: Größe in Byte
                            ← Leerzeile
<!doctype html> …           ← die Datei selbst
```

:::seq
mode: text
Client-PC -> Server: GET / | HTTP isteği
Server -> Client-PC: 200 OK | index.html
Client-PC -> Server: GET /style.css | HTTP isteği
Server -> Client-PC: 200 OK | style.css
:::

## Yöntemler ve durum kodları

**Yöntem**, istemcinin ne istediğini söyler:

| Yöntem | Anlamı |
|---|---|
| **GET** | bir dosyayı getirmek |
| **POST** | sunucuya veri göndermek, ör. doldurulmuş bir form |
| **HEAD** | dosya olmadan yalnızca başlıkları getirmek |

**Durum kodu**, işin nasıl sonuçlandığını söyler. İlk rakam yanıtın türünü belli eder:

| Kod | Metin | Anlamı |
|---|---|---|
| **200** | OK | her şey yolunda |
| **301** | Moved Permanently | sayfa kalıcı olarak taşındı |
| **404** | Not Found | böyle bir dosya yok |
| **405** | Method Not Allowed | bu yönteme burada izin verilmiyor |
| **500** | Internal Server Error | sunucuda hata |

`2xx` başarı, `3xx` yönlendirme, `4xx` istemci hatası (yanlış istek), `5xx` ise sunucu hatası anlamına gelir.

:::tip Anahtar nokta
**HTTP**, **istek-yanıt ilkesine** göre çalışır: İstemci bir **istek** gönderir (`GET` gibi bir yöntem, yol, başlıklar), sunucu ise bir **durum kodu** (ör. `200 OK`, `404 Not Found`), başlıklar ve dosya ile yanıt verir. Bir web sayfasının her dosyası için ayrı bir istek yapılır.
:::

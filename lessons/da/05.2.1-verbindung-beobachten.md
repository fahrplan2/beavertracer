# En forbindelse fra start til slut

:::sim
url=/sims/lesson-5.1.btsim
:::

På **Server** kører echo-tjenesten på port `5000`: Den sender hver besked med det samme tilbage. Med **Simpel TCP-klient** kan du styre en forbindelse trin for trin — hver knap er én fase.

## Eksperimentet

1. Skift til :fa-play: **Kør**-tilstand, klik på **Client-PC** og åbn **Simpel TCP-klient**.
2. Indtast `192.168.0.20` ved **Host** og `5000` ved **Port**.
3. Klik på **Forbind**.
4. Skriv `Hello World` i beskedfeltet, og klik på **Send**. I chatvinduet ser du lige efter serverens echo.
5. Klik på **Afbryd forbindelse**.
6. Skift til :fa-magnifying-glass: **Spor**-tilstand, og åbn med **+** et trace for **Client-PC**, port `eth0`.

:::note
De to ARP-pakker i begyndelsen kender du allerede fra kapitel 1. I **Info**-kolonnen for TCP-pakkerne står først `49152 → 5000` (fra hvilken port til hvilken port), derefter i kantede parenteser **flagene** og til sidst tal som `Seq=`, `Ack=` og `Len=`. Tallene behandles fra side 5.2.3 — her skal du holde øje med flag og `Len`.
:::

## Fase 1: Forbind

:::quiz short
Hvor mange TCP-pakker blev udvekslet, efter at du klikkede på **Forbind** — før din besked blev sendt afsted?
= 3
= tre
:::

:::quiz mc
Hvem sender den første pakke med `[SYN]`?
- [x] Client-PC
- [ ] Serveren
:::

:::quiz mc
Med hvilke flag svarer serveren på den?
- [ ] `[SYN]`
- [x] `[SYN, ACK]`
- [ ] `[ACK]`
- [ ] `[FIN, ACK]`
:::

## Fase 2: Send

`Len` angiver, hvor mange bytes nyttedata en pakke bærer.

:::quiz short
Hvor mange bytes bærer pakken med din besked (`Len`)?
= 13
:::

:::note
`Hello World` har kun 11 tegn. TCP-klienten tilføjer dog et linjeskift (2 bytes, `\r\n`) — det forventer mange internetprotokoller som SMTP eller HTTP.
:::

:::quiz mc
Hvad sender serveren tilbage lige efter din besked — allerede før echoet?
- [x] En pakke med `[ACK]` og `Len=0` — en kvittering uden data
- [ ] Slet ingenting
- [ ] Et nyt `[SYN]`
:::

## Fase 3: Afbryd forbindelse

:::quiz short
Hvor mange pakker hører med til nedlukningen — fra den første pakke med `FIN`?
= 4
= fire
:::

:::quiz mc
Hvad meddeler en side med `FIN`?
- [x] „Jeg er færdig“ — den sender ikke flere data
- [ ] „Der er opstået en fejl“
- [ ] „Her kommer nye data“
:::

:::evaluate
Tjek svar
:::

## Hvor finder du de fire opgaver?

Match, hvor du i trace'et genfinder opgaverne fra afsnit 5.1:

:::quiz match
Opbygning af forbindelse -> De tre pakker [SYN], [SYN, ACK] og [ACK]
Pålidelig overførsel -> Pakker med [ACK] og Len=0, der bekræfter modtagelsen
Nedlukning af forbindelse -> Pakkerne med FIN og deres kvitteringer
Multipleksing -> Portnumrene 49152 → 5000 før de kantede parenteser
:::

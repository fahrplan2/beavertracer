# Observer TCP

:::goal
**Læringsmål:** Du kan finde ud af, hvor TCP løser transportlagets fire opgaver i Traceren, kan fremstille en TCP-forbindelse som et sekvensdiagram og kan efterregne sekvensnumre og kvitteringsnumre.
:::

:::sim
url=/sims/lesson-5.1.btsim
:::

**Transmission Control Protocol** (**TCP**) ligger bag næsten alt på internettet, som skal nå pålideligt frem: websider, e-mails, downloads og fjernvedligeholdelse via SSH.

På de næste sider observerer du én enkelt TCP-forbindelse fra start til slut — og leder selv efter, hvor TCP klarer opbygning af forbindelse, pålidelig overførsel og nedlukning af forbindelsen.

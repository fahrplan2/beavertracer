# HTTP og HTTPS sammenlignet

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Webserveren **www.beaver-schule.de** tilbyder skolens karakterportal både via HTTP og via HTTPS. Hvad kan en lytter se?

## Eksperimentet

1. Skift til :fa-play: **Kør**-tilstand, og åbn på **Client-PC** i :fa-globe: **Browser** først `http://www.beaver-schule.de/` og derefter `https://www.beaver-schule.de/`.
2. Åbn i :fa-magnifying-glass: **Spor**-tilstand et trace for **Client-PC**.
3. Find først pakken `HTTP/1.1 200 OK`, og klik på den. Nederst i detaljerne finder du sidens indhold.

:::quiz mc
Hvad kan en lytter se ved **HTTP**?
- [x] Hele websiden, også Annas karakterer
- [ ] Kun serverens adresse
- [ ] Ingenting, fordi HTTP kører over TCP
:::

:::quiz short
Hvilken karakter har Anna i matematik?
= 2
:::

:::evaluate
Tjek svar
:::

Nu til HTTPS-delen. Find `[SYN]`-pakken, hvormed klienten starter den anden forbindelse.

:::quiz short
Hvilken målport har HTTPS-forbindelsen (kolonnen **Info**, `… → ???`)?
= 443
:::

Skriv nu `tls` i filterfeltet øverst i tracet — så ser du kun TLS-pakkerne.

:::quiz mc
Hvad står der i kolonnen **Info** ved de pakker, der indeholder websiden?
- [ ] `HTTP/1.1 200 OK`
- [x] `Application Data`
- [ ] `Encrypted HTML`
:::

:::quiz multi
Hvad kan en lytter stadig se ved **HTTPS**?
- [x] IP-adresserne på klient og server
- [x] At port 443 bruges, altså sandsynligvis HTTPS
- [x] Cirka hvor mange data der overføres
- [ ] Hvilken side der blev åbnet, og hvad der står på den
:::

:::evaluate
Tjek svar
:::

:::note
Klik på en **Application Data**-pakke: Nyttedataene er kun en række tilsyneladende tilfældige bytes. Traceren kan ikke dekryptere dem — den kender lige så lidt til sessionsnøglen som en angriber.
:::

:::tip Husk
Ved **HTTP** kan enhver lytter læse hele websiden. Ved **HTTPS** kan vedkommende kun se, **hvem der taler med hvem** (IP-adresser, port 443) og **hvor meget** — indholdet ligger krypteret i **Application Data**-pakker.
:::

På arbejdsområdet ser du **Client-PC**, en **DNS-Server** og skolens webserver, `www.beaver-schule.de`. Webserveren tilbyder også sine sider via **HTTPS**.

## Låsen i browseren

1. Skift til :fa-play: **Kør**-tilstand, klik på **Client-PC** og åbn :fa-globe: **Browser**.
2. Åbn `https://www.beaver-schule.de/` — læg mærke til **https**.
3. Til venstre for adressen vises en **lås**. Klik på den.

:::quiz short
Til hvilket navn blev certifikatet udstedt (emne uden `CN=`)?
= www.beaver-schule.de
:::

:::quiz short
Hvem har udstedt certifikatet (udsteder uden `CN=`)?
= Biber Root CA
:::

:::evaluate
Tjek svar
:::

## Hvorfor stoler Client-PC på certifikatet?

Åbn :fa-shield-halved: **Zertifikatverwaltung** på **Client-PC** og skift til fanen **Vertrauenswürdige CAs**.

:::quiz mc
Hvad finder du der?
- [x] Certifikatet fra **Biber Root CA**
- [ ] Certifikatet fra `www.beaver-schule.de`
- [ ] Ingen poster
:::

:::quiz mc
Hvordan kan man se, at Biber Root CA er en root-CA?
- [x] Den er **selvsigneret**: Emne og udsteder er ens
- [ ] Dens navn ender på "CA"
- [ ] Den har ingen offentlig nøgle
:::

:::quiz mc
Står der "Ja" eller "Nein" under **Privater Schlüssel** på Client-PC?
- [ ] Ja — klienten har brug for CA'ens private nøgle for at kontrollere signaturer
- [x] Nej — for at kontrollere er den offentlige nøgle nok; den private nøgle har kun CA'en
:::

:::evaluate
Tjek svar
:::

## Modparten: webserveren

Åbn nu :fa-shield-halved: **Zertifikatverwaltung** på webserveren **www.beaver-schule.de** (fanen **Meine Zertifikate**) og se på dens certifikat.

:::quiz multi
Hvad gælder for certifikatet på webserveren?
- [x] Under **Privater Schlüssel** står der "Ja" — serveren har brug for den ved opbygning af forbindelse
- [x] **Kæden** er `www.beaver-schule.de ← Biber Root CA`
- [x] **Fingeraftrykket** er det samme som i browserens låsevindue
- [ ] Det er selvsigneret
:::

:::evaluate
Tjek svar
:::

:::note
**Fingeraftrykket** er en hashværdi over certifikatet. Med den kan man hurtigt sammenligne to certifikater — uden at skulle kontrollere alle felter enkeltvis.
:::

:::tip Husk
**Webserveren** har sit certifikat **med privat nøgle**. **Klienten** kender kun **root-CA'ens certifikat** (uden privat nøgle) — det er nok til, at den kan kontrollere signaturen på servercertifikatet. Når man klikker på **låsen** i browseren, kan man se emne, udsteder, fingeraftryk og gyldighed.
:::

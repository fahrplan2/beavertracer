# Sådan er DNS organiseret

:::sim
url=/sims/lesson-6.2.btsim
:::

Ingen enkelt server kan kende alle navne i verden. DNS er derfor opbygget **hierarkisk** — ligesom selve navnene. Man læser dem fra højre mod venstre:

```
www . beaver-schule . de . (Root)
 │          │         │      └─ Root-Server: kennen die Server aller Top-Level-Domains
 │          │         └─ Top-Level-Domain (TLD): der de-Server kennt alle .de-Domains
 │          └─ Domain: der Schul-DNS ist für beaver-schule.de zuständig
 └─ Rechnername innerhalb der Domain
```

Den server, der er ansvarlig for et domæne og virkelig kender svaret, kaldes **autoritativ**. Vejen derhen overtager en **resolver** for pc'en — her computeren **DNS-Resolver**.

## Eksperimentet

1. Skift til :fa-play: **Kør**-tilstand, og skriv på **Client-PC** i :fa-terminal: **Terminal**:
   ```
   $ nslookup www.beaver-schule.de
   ```
2. Åbn i :fa-magnifying-glass: **Spor**-tilstand et trace for **DNS-Resolver**.

Resolveren har stillet en hel række forespørgsler for dig. Match, hvem der har givet hvilket svar:

:::quiz match
Root-Server (192.168.0.101) -> Henvisning: Für .de ist ns.nic.de zuständig
de-Server (192.168.0.102) -> Henvisning: Für beaver-schule.de ist ns.beaver-schule.de zuständig
Schul-DNS (192.168.0.103) -> Svar: www.beaver-schule.de har adressen 192.168.0.20
:::

:::quiz mc
Hvem spørger resolveren først?
- [x] Root-serveren
- [ ] Schul-DNS
- [ ] Client-PC
:::

:::evaluate
Tjek svar
:::

:::note
Undervejs spørger resolveren også efter adresserne på de servere, den blev henvist til (`A ns.nic.de`). Rigtige DNS-servere sender normalt disse adresser med med det samme. Desuden husker resolvere hvert svar et stykke tid (**cache**) — den næste forespørgsel på det samme navn besvarer de straks selv. Hvor længe, står i posten som **TTL** (*Time to Live*) i sekunder.
:::

## De vigtigste posttyper

| Type | Betydning | Eksempel |
|---|---|---|
| **A** | navn → IPv4-adresse | `www.beaver-schule.de` → `192.168.0.20` |
| **AAAA** | navn → IPv6-adresse | `www.beaver-schule.de` → `2001:db8::20` |
| **CNAME** | navn → andet navn (alias) | `web.beaver-schule.de` → `www.beaver-schule.de` |
| **MX** | ansvarlig mailserver for et domæne | `beaver-schule.de` → `mail.beaver-schule.de` |
| **NS** | ansvarlig DNS-server for et domæne | `beaver-schule.de` → `ns.beaver-schule.de` |

:::tip Husk
DNS er **hierarkisk**: **Root-servere** henviser til serverne for **top-level-domænerne** (f.eks. `.de`), og disse henviser til serverne for de enkelte **domæner**. Den ansvarlige **autoritative** server kender svaret. En **resolver** går denne vej for pc'en og husker svarene (**cache**). Vigtige posttyper: **A**, **AAAA**, **CNAME**, **MX**, **NS**.
:::

## Oprettelse af en post

Skolen vil gerne have, at dens hjemmeside også kan nås på `intranet.beaver-schule.de`.

1. Klik i :fa-play: **Kør**-tilstand på **Schul-DNS**, og åbn appen **DNS-Server**.
2. Åbn fanen **A**. Klik på **+**, og skriv navnet `intranet.beaver-schule.de` og adressen `192.168.0.20` i den nye række.
3. Test på Client-PC med `nslookup intranet.beaver-schule.de`.

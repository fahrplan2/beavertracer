# Første egne regler

:::sim
url=/sims/lesson-9.btsim
:::

Nu er det din tur. Firewallen lader stadig alt slippe igennem. Sørg for, at kun **websiden (80)** og **mailmodtagelse (25)** på skoleserveren kan nås fra internettet. **SSH (22)**, **POP3 (110)** og **IMAP (143)** skal ikke længere kunne nås fra internettet.

## Indtast regler

1. Klik på **firewallen**. Standardpolitikken forbliver indtil videre på **Tillad alle**.
2. Slet den eksisterende regel (den tillader alligevel alt), og opret med **+ Tilføj regel** en regel for hver port, der skal lukkes:
    - **Retning** A → B (fra internettet)
    - **Protokol** TCP
    - **Målport** f.eks. `22`
    - **Handling** Forkast
3. Tjek fra **Internet-PC** med `nmap 198.51.100.10`, om kun de rigtige porte stadig er åbne.

:::task
title: Kun web og mail udefra?
Tjekker, om skoleserveren fra internettet kun kan nås på port 80 og 25 — og om Lehrer-PC'en stadig kan hente mails og surfe på internettet. Simulationen skal køre i Kør-tilstand for at kunne tjekkes.
check: tcpOpen(1, "198.51.100.10", 80)
check: tcpOpen(1, "198.51.100.10", 25)
check: tcpFails(1, "198.51.100.10", 22)
check: tcpFails(1, "198.51.100.10", 110)
check: tcpFails(1, "198.51.100.10", 143)
check: tcpOpen(8, "198.51.100.10", 110)
check: tcpOpen(8, "203.0.113.80", 80)
:::

:::quiz mc
Lehrer-PC'en kan stadig hente mails fra skoleserveren via POP3 (110). Hvorfor generer firewallen den ikke?
- [ ] Fordi firewallen genkender lærere
- [x] Fordi dens pakker slet ikke passerer firewallen — Lehrer-PC og skoleserver sidder på den samme switch bag firewallen
- [ ] Fordi POP3 er en sikker protokol
:::

:::note
En firewall beskytter kun trafik, der løber **igennem den**. Hvad der sker inde i skolenetværket, kan den ikke se. En inficeret computer i skolenetværket kan derfor stadig angribe skoleserveren — det handler afsnittet om DMZ om.
:::

:::tip Husk
For hver tjeneste, der ikke skal kunne nås udefra, spærrer en regel med **retning**, **protokol** og **målport** adgangen. Om reglerne virker, tjekker man udefra med en **portscanning**.
:::

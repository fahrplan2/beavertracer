# POP3 eller IMAP?

:::sim
url=/sims/lesson-6.3.btsim
:::

Der findes to protokoller til at hente mails. I denne simulation bruger **Anna POP3** og **Ben IMAP**.

## Eksperimentet

1. Send i :fa-play: **Kør**-tilstand en mail fra **Ben** til `anna@beaver-schule.de`.
2. Klik hos **Anna** i appen **E-Mail** på **Hent**.
3. Åbn traces for **Anna** og for **Ben**, og sammenlign kommandoerne ved hentningen.

:::quiz match
USER / PASS -> POP3: Log ind med brugernavn og adgangskode i to trin
RETR -> POP3: hente en besked
LOGIN -> IMAP: Log ind med brugernavn og adgangskode
SELECT INBOX -> IMAP: åbne en mappe på serveren
:::

## Forskellen

| | POP3 | IMAP |
|---|---|---|
| Port | 110 | 143 |
| Grundidé | **Hente** mails ned — derefter som regel slette dem på serveren | Mails **bliver på serveren** og administreres dér |
| Mapper, læst/ulæst | kun på ens egen enhed | på serveren — det samme overalt |
| Flere enheder (mobil, laptop) | upraktisk: Hver enhed har en forskellig status | ideelt: alle enheder ser den samme postkasse |

:::note
E-mail-programmet i BeaverTracer lader mails ligge på serveren, også ved POP3. Rigtige programmer sletter dem ofte efter download — eller lader dem kun ligge i et stykke tid.
:::

:::quiz mc
Lena læser sine mails på mobilen, tabletten og skolens laptop. Hvad bør hun bruge?
- [ ] POP3, fordi det er enklere
- [x] IMAP, fordi alle enheder ser den samme postkasse på serveren
- [ ] SMTP, fordi det er beregnet til at hente mails
:::

:::tip Husk
**POP3** henter mails fra serveren ned på **én** enhed. **IMAP** administrerer postkassen **på serveren** — med mapper og læst-status for alle enheder på samme tid. Begge bruges kun til at **hente**; afsendelse sker altid med **SMTP**.
:::

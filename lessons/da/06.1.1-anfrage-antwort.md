En webside består altså ofte af mange filer: tekst, stylesheets, billeder. For hver af dem sender browseren en separat anmodning.

## Sådan ser en anmodning ud

Klik på pakken `GET / HTTP/1.1` i tracet, og fold **Hypertext Transfer Protocol** ud. En HTTP-anmodning er ren tekst:

```
GET / HTTP/1.1              ← Methode, Pfad, Version
Host: 192.168.0.20          ← Header: zusätzliche Angaben
…
                            ← Leerzeile: Ende der Anfrage
```

Serverens svar er opbygget på samme måde — med en statuslinje, headere, en tom linje og derefter selve filen:

```
HTTP/1.1 200 OK             ← Version, Statuscode, Text
Content-Type: text/html     ← Header: Art der Datei
Content-Length: 301         ← Header: Größe in Byte
                            ← Leerzeile
<!doctype html> …           ← die Datei selbst
```

:::seq
mode: text
Client-PC -> Server: GET / | HTTP-anmodning
Server -> Client-PC: 200 OK | index.html
Client-PC -> Server: GET /style.css | HTTP-anmodning
Server -> Client-PC: 200 OK | style.css
:::

## Metoder og statuskoder

**Metoden** fortæller, hvad klienten vil have:

| Metode | Betydning |
|---|---|
| **GET** | hente en fil |
| **POST** | sende data til serveren, f.eks. en udfyldt formular |
| **HEAD** | kun hente headerne uden filen |

**Statuskoden** fortæller, hvordan det gik. Det første ciffer afslører svarets type:

| Kode | Tekst | Betydning |
|---|---|---|
| **200** | OK | alt er i orden |
| **301** | Moved Permanently | siden er flyttet permanent |
| **404** | Not Found | filen findes ikke |
| **405** | Method Not Allowed | denne metode er ikke tilladt her |
| **500** | Internal Server Error | fejl på serveren |

`2xx` betyder succes, `3xx` omdirigering, `4xx` en fejl hos klienten (forkert anmodning), `5xx` en fejl hos serveren.

:::tip Husk
**HTTP** arbejder efter **anmodning-svar-princippet**: Klienten sender en **anmodning** (metode som `GET`, sti, headere), og serveren svarer med en **statuskode** (f.eks. `200 OK`, `404 Not Found`), headere og filen. For hver fil på en webside er der en separat anmodning.
:::

:::

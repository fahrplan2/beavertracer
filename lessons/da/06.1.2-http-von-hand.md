# HTTP i hånden

:::sim
url=/sims/lesson-6.1.btsim
:::

Hvis HTTP er ren tekst — kan man så også selv tale med en webserver helt uden en browser? Ja: Med `telnet` opbygger du en TCP-forbindelse til en vilkårlig port og skriver selv teksten.

## Eksperimentet

1. Skift til :fa-play: **Kør**-tilstand, og åbn :fa-terminal: **Terminal** på **Client-PC**.
2. Forbind til port 80 på serveren:
   ```
   $ telnet 192.168.0.20 80
   ```
3. Skriv forespørgslen linje for linje — og afslut den med en **tom linje** (tryk blot på **Enter** en gang til):
   ```
   GET /kontakt.html HTTP/1.1
   Host: 192.168.0.20

   ```

Serveren svarer med en statuslinje, headere og kontaktsiden — som tekst, præcis som browseren også modtager den.

:::quiz mc
Hvordan kan serveren se, at din forespørgsel er slut?
- [ ] På en særlig kommando `END`
- [x] På den tomme linje
- [ ] Efter et bestemt tidsrum
:::

:::quiz short
Hvilken værdi står der i svaret ved headeren `Content-Type`? (kun den første del før `;`)
= text/html
:::

## Fremprovokér fejl

Et mere bekvemt værktøj er `curl`: Det sender forespørgslen for dig. Med `-v` (*verbose*, udførlig) viser det alt, hvad der sendes frem og tilbage — linjer med `>` har `curl` sendt, linjer med `<` kom fra serveren.

Prøv det:

```
$ curl -v http://192.168.0.20/gibtsnicht.html
$ curl -X POST -d name=Anna http://192.168.0.20/
```

:::quiz short
Hvilken statuskode får du for `/gibtsnicht.html`?
= 404
:::

:::quiz short
Og hvilken får du for forespørgslen med metoden `POST`?
= 405
:::

:::evaluate
Tjek svar
:::

:::note
Webserveren i BeaverTracer kan kun levere filer — derfor tillader den kun `GET` og `HEAD`. Rigtige webservere modtager for eksempel formularer med `POST` og sender dataene videre til et program.
:::

:::tip Husk
Mange protokoller i applikationslaget er **tekstbaserede** — HTTP, men også SMTP, POP3 og IMAP. Derfor kan man tale dem i hånden med `telnet` og læse med i Spor. Det er praktisk til fejlfinding — men også et sikkerhedsproblem: Enhver, der opfanger trafikken, kan læse alt. Hvordan kryptering (HTTPS) hjælper, lærer du i kapitel 8.
:::

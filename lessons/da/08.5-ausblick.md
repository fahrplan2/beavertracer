# Opsummering og udblik

## Byggestenene i overblik

| Byggesten | Beskyttelsesmål | Eksempel |
|---|---|---|
| **Symmetrisk kryptering** | Fortrolighed | AES krypterer data i en HTTPS-forbindelse |
| **Asymmetrisk kryptering** | Fortrolighed, nøgleudveksling | Diffie-Hellman, RSA |
| **Hashværdier** | Integritet | SHA-256-kontrolsum for en download |
| **Digital signatur** | Autenticitet, integritet | Serveren signerer sin Diffie-Hellman-andel |
| **Certifikat** | Autenticitet | bekræfter: Denne nøgle tilhører `www.biberbank.de` |

## Det samme princip mange steder

Det, du har lært om HTTPS, optræder også i mange andre teknikker:

- **WLAN (WPA2/WPA3):** I kapitel 3.3.2 kunne alle enheder inden for rækkevidde læse med. Med WPA2 eller WPA3 bliver hver radioramme krypteret med AES. WPA3 forhandler desuden nøglen på en sådan måde, at en aflytter ikke kan dekryptere gamle optagelser, selv om vedkommende kender WLAN-adgangskoden.
- **SSH:** Den krypterede fjernadministration fra kapitel 6.6. I stedet for certifikater husker klienten serverens nøgles **fingeraftryk**, første gang den forbinder, og advarer, hvis det senere ændrer sig.
- **VPN:** En krypteret tunnel gennem internettet, f.eks. ind i skolens eller virksomhedens netværk. Det handler kapitel 10 om.
- **Beskedtjenester:** Signal, WhatsApp og andre krypterer **ende-til-ende**: Ikke engang tjenestens udbyder kan læse beskederne.

:::note
Store **kvantecomputere** kunne en dag knække opdelingen af store tal i primfaktorer — og dermed RSA og Diffie-Hellman. Derfor indføres der allerede i dag nye, **kvantesikre** metoder. Symmetriske metoder som AES med lange nøgler anses fortsat for sikre.
:::

## Test dig selv

:::quiz mc
Ved HTTPS bliver selve data krypteret med …
- [ ] RSA, fordi det er mest sikkert
- [x] en symmetrisk metode som AES og en forhandlet sessionsnøgle
- [ ] serverens private nøgle
:::

:::quiz mc
Du åbner `https://www.biberbank.de/`, og browseren melder: "Certifikatet er udstedt til `www.gewinn-biber.de`". Hvad gør du?
- [ ] Klikker på "Fortsæt alligevel" — forbindelsen er jo krypteret alligevel
- [x] Afbryder — måske taler browseren slet ikke med banken
- [ ] Åbner siden via `http://`, så kommer der ingen advarsel
:::

- [x] Rod-CA'er er forudinstalleret i browseren eller operativsystemet
- [ ] Ved HTTPS kan en aflytter ikke engang se serverens IP-adresse

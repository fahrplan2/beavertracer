# Læs e-mail med i tracer

:::sim
url=/sims/lesson-6.3.btsim
:::

Ligesom HTTP er SMTP også en **tekstprotokol**. Se, hvor meget der sendes over ledningen i klartekst.

## Eksperimentet

1. Send i :fa-play: **Kør**-tilstand en mail fra **Anna** til `ben@biber-mail.de`, ligesom på den forrige side.
2. Åbn i :fa-magnifying-glass: **Spor**-tilstand et trace for **Anna**. I kolonnen **Info** står SMTP-dialogen: Linjer med `C:` sendes af klienten, linjer med `S:` af serveren.

:::quiz short
Hvilken adresse står efter `MAIL FROM:`?
= anna@beaver-schule.de
= <anna@beaver-schule.de>
:::

:::quiz short
Og hvilken står efter `RCPT TO:`?
= ben@biber-mail.de
= <ben@biber-mail.de>
:::

:::quiz mc
Hvilken talkode sender serveren, når den accepterer en kommando?
- [x] `250`
- [ ] `200`
- [ ] `404`
:::

:::evaluate
Tjek svar
:::

## Og adgangskoden?

Før `MAIL FROM` logger Annas program ind med `AUTH PLAIN` og en tegnstreng som `AGFubmEAZ2VoZWlt`. Det ser krypteret ud, men det er det ikke: Det er kun **Base64**, en kodning, som enhver straks kan oversætte tilbage — den indeholder `anna` og hendes adgangskode `geheim`.

Hent nu posten hos **Ben** (**Hent**) og åbn et trace for **Ben**. Når posten hentes via IMAP, ser man det endnu tydeligere:

:::quiz short
Hvilken adgangskode sender Bens mailprogram i klartekst til serveren? (Kig på linjen med `LOGIN`.)
= biber123
:::

:::evaluate
Tjek svar
:::

:::warning
Uden kryptering kan enhver, der opfanger datatrafikken, læse **indhold, afsender, modtager og adgangskoder**. Derfor bruger man i dag krypterede varianter (f.eks. SMTP med STARTTLS, IMAPS på port 993). Hvordan det fungerer, lærer du i kapitel 8.
:::

:::tip Husk
**SMTP**, **POP3** og **IMAP** er tekstprotokoller: Kommandoer som `MAIL FROM`, `RCPT TO`, `DATA` (SMTP) eller `LOGIN` (IMAP) og svarene kan læses. Uden kryptering sendes også **adgangskoder** i klartekst (eller kun Base64-kodet) over ledningen.
:::

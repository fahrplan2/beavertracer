# Fejlfinding: Tjenesten svarer ikke

:::sim
url=/sims/lesson-5.3.2.btsim
:::

Efter en opdatering melder skolen: "Echo-tjenesten afviser enhver forbindelse, og hjemmesiden indlæses heller ikke længere." Ifølge planen skal **webserveren** lytte på port `80` og **echo-tjenesten** (TCP Echo-server) på port `5000`. Find fejlene og ret dem.

<details>
<summary>Tip 1: Hvad svarer serveren?</summary>

Forsøg at forbinde til `192.168.0.20`, port `5000` med **Simpel TCP-klient**, og åbn et trace for klient-pc'en. Hvad svarer serveren på dit `[SYN]`?
</details>

<details>
<summary>Tip 2: Hvilke porte er åbne?</summary>

Skriv `nmap -p 80,5000 192.168.0.20` i terminalen på klient-pc'en. `nmap` afprøver portene én efter én og viser, hvilke der er åbne. Med `ss` på serveren kan du se, på hvilke porte et program faktisk lytter dér.
</details>

<details>
<summary>Tip 3: Hvor indstiller man det?</summary>

Åbn apperne **TCP Echo-server** og **HTTP-server** på **serveren**. Kører tjenesten? Og på hvilken port?
</details>

:::task
title: Er tjenesterne tilgængelige?
Tjek, om klient-pc'en kan nå echo-tjenesten på port 5000 og webserveren på port 80. Simuleringen skal køre i Kør-tilstand for at gøre det.
check: tcpOpen(1, 2, 5000)
check: tcpOpen(1, 2, 80)
:::

## Hvad var der galt?

:::quiz multi
Hvilke udsagn er rigtige?
- [x] Serveren svarede på `[SYN]` til port 5000 med `[RST, ACK]`
- [x] Echo-tjenesten lyttede på port 5050 i stedet for port 5000
- [x] Webserveren var slet ikke startet
- [ ] Kablet mellem klient-pc'en og serveren var defekt
:::

:::evaluate
Tjek svar
:::

:::tip Husk
Hvis der kommer et **`RST`** tilbage på et `SYN`, lytter **intet program** på den port: Computeren kan nås, men tjenesten kan ikke. Typiske årsager: Tjenesten er **ikke startet** eller lytter på en **anden port**. Et kig med `ss` på serveren viser, hvilke porte der faktisk er åbne.
:::

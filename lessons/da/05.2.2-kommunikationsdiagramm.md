# Sekvensdiagrammet

:::sim
url=/sims/lesson-5.1.btsim
:::

Forløbet af en forbindelse tegner man som et **sekvensdiagram**: Klient og server får hver en lodret linje (livslinje), og tiden løber oppefra og ned. Hver pil er en pakke. Den er tegnet skrå, fordi hver pakke er lidt tid undervejs.

Sådan ser din forbindelse fra den sidste side ud — sammenlign den linje for linje med sporingen:

:::seq
Client-PC -> Server: SYN
Server -> Client-PC: SYN, ACK
Client-PC -> Server: ACK
Client-PC -> Server: PSH, ACK "Hello World" len=13
Server -> Client-PC: ACK
Server -> Client-PC: PSH, ACK len=13
Client-PC -> Server: ACK
Client-PC -> Server: FIN, ACK
Server -> Client-PC: ACK
Server -> Client-PC: FIN, ACK
Client-PC -> Server: ACK
:::

Over hver pil står **flagene**, under dem numrene `SEQ` og `ACK`. **DATA** markerer pakker med nyttedata. De røde tal hører til klienten, de blå til serveren — hvad de betyder, afklarer den næste side.

## Flagene

| Flag | står for | Betydning |
|---|---|---|
| **SYN** | *synchronize* | opbygge forbindelse, fastlægge startnummer |
| **ACK** | *acknowledge* | kvitterer for modtagne data |
| **PSH** | *push* | give data videre til programmet med det samme |
| **FIN** | *finish* | „Jeg er færdig“ — nedbryde forbindelsen |
| **RST** | *reset* | afbryde eller afvise forbindelse (mere om det i 5.3.2) |

## Tre faser

**Opbygning:** Klienten sender `SYN`, serveren svarer med `SYN, ACK`, og klienten kvitterer med `ACK`. Fordi der netop skal bruges tre pakker, hedder det **three-way handshake**.

**Data:** Hver pakke med data kvitteres af modtageren med et `ACK`. Her sender serveren ekkoet tilbage — også det kvitterer klienten for.

**Nedbrydning:** Hver side afslutter sin egen senderetning for sig: `FIN` fra klienten, `ACK` fra serveren — derefter `FIN` fra serveren, `ACK` fra klienten. Det er fire pakker.

:::tip Husk
En TCP-forbindelse forløber i tre faser: **Opbygning** med **three-way handshake** (`SYN` → `SYN, ACK` → `ACK`), **dataoverførsel** (hver datapakke kvitteres med `ACK`) og **nedbrydning** (hver side sender `FIN` og får et `ACK`).
:::

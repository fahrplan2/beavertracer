# ISO/OSI参照モデル

ISO/OSIモデルは、2台のデバイス間の通信を7つの層に分けます。各層の役割ははっきり区切られていて、すぐ下の層が提供するサービスだけを利用します。

前のページの実験で、これらのうち4つの層はすでに登場しています。Ethernet(2)、IPv4(3)、TCP(4)、HTTP(7)です。トレーサーはプロトコルツリーで、まさにこの番号と色を表示します。

:::tip 覚え方
7層から下へ向かって「アプセトネデブ」と覚えましょう。**ア**プリケーション、**プ**レゼンテーション、**セ**ッション、**ト**ランスポート、**ネ**ットワーク、**デ**ータリンク、**ブ**ツリ(物理)です。
:::

:::note 例外的なケース
すべてのプロトコルがきれいに1つの層に収まるわけではありません。そのため、トレーサーは次のプロトコルでは複数の層を表示します。

- **ARP** — 層2/3: IPヘッダーはありませんが、IPアドレス(層3)とハードウェアアドレス(層2)を結び付けます。
- **TLS** — 層4/5: TCPのすぐ上で動作し、保護されたセッションを管理します。
- **HTTPS**(TLSの中のHTTP) — 層5〜7: 次のページで学ぶTCP/IPモデルの、典型的なアプリケーション層です。
:::

:::note
層1は、ケーブル上または無線による実際の信号伝送を表します。BeaverTracerはこの層をシミュレートしません。ケーブルは常にエラーなく接続されているものとして扱われ、信号の問題もコリジョンもありません。そのため、トレーサーでは実質的に層2から見ていくことになります。
:::

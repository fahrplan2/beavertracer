# WLAN: ケーブルのないネットワーク

:::goal
**学習目標:** アクセスポイントがWLANと有線ネットワークをどのようにつなぐかを説明できる。SSIDを使って機器をWLANに接続でき、WLANを暗号化しなければならない理由を説明できる。
:::

スマホ、タブレット、ノートPCには、ネットワーク用の接続口がそもそもないことがほとんどです。これらの機器は無線で、**WLAN**（*Wireless LAN*、無線ローカルネットワーク）を通じて接続します。それでもケーブルでつながったPCやサーバーと通信できるようにするには、無線と有線をつなぐ機器が必要です。

:::note
実際のWLANは、電波の届く範囲、壁、干渉の影響を受けます。BeaverTracerではこれを単純化しています。同じWLAN名を持つすべての機器は、ワークスペース上のどこに置かれていても、1つの共通の無線ネットワークを共有します。
:::

# NATテーブル

:::sim
url=/sims/lesson-7.1.btsim
:::

PCとタブレットが同時に同じWebページを読み込むと、2つのリクエストはどちらも `203.0.113.2` からWebサーバーに届きます。では、ホームルーターは返信が誰宛てのものかをどうやって知るのでしょうか。ルーターは記録をつけています。それが **NATテーブル**です。

## 実験

1. :fa-play: の**実行**モードに切り替えて、**PC**と**タブレット**でそれぞれ `http://www.beispiel.de/` を開きます。
2. **Heimrouter** をクリックして、**NAT** タブを開きます。

各行は1つの**対応付け**です。プロトコル、家庭内ネットワーク内の機器のLAN IPとLANポート、そしてルーターがその機器のために自分のパブリックアドレス上で使う**WANポート**が記録されています。

:::quiz short
テーブルの上に表示されているWAN IPは何ですか？
= 203.0.113.2
:::

:::quiz mc
PCとタブレットが、どちらもLANポート `49152` で接続を確立しました。それぞれどのWANポートが割り当てられますか？
- [ ] 2台とも同じ `49152`
- [x] それぞれ別のポート。そうでないと、ルーターは返信が誰のものか分からなくなる
- [ ] どちらも割り当てられない。NATが変更するのはIPアドレスだけ
:::

:::quiz mc
Webサーバーからの返信が、特定の**宛先ポート**を付けて `203.0.113.2` に届きました。ホームルーターはこのパケットをどう処理しますか？
- [x] NATテーブルでそのポートを探し、対応するLAN IPとLANポートへパケットを送る
- [ ] 家庭内ネットワークのすべての機器にパケットを送る
- [ ] パケットを破棄する
:::

:::evaluate
答えを確認
:::

ここで第5章の**ポート**が再び登場します。NATはポートも書き換えるため、何百もの接続が1つのアドレスを共有できます。そのため厳密には **PAT**（*Port Address Translation*）、または*ポート変換付きNAT*と呼ばれますが、普段は単にNATと言うのが一般的です。

このような変換は、たとえば次のようになります。

| | PCからのパケット（家庭内ネットワーク内） | 同じパケット（インターネット上） |
|---|---|---|
| 送信元 | `192.168.178.20 : 49152` | `203.0.113.2 : 10001` |
| 受信者 | `192.0.2.80 : 80` | `192.0.2.80 : 80` |

:::tip ポイント
ルーターは **NATテーブル**に、接続ごとにどの機器（**LAN IPとLANポート**）がどの**WANポート**の背後にあるかを記録しています。インターネットからの返信は、宛先ポートをもとに正しい機器へ振り分けます。ポートも書き換えられるため、より正確には **PAT** と呼ばれます。
:::

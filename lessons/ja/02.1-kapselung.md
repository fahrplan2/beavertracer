この実験では、1.3章のシミュレーションをもう一度読み込んでいます。**Client-PC** と **Webserver** が1台ずつあります。

## 実験

1. :fa-play: **実行**モードに切り替えます。
2. **Client-PC** で :fa-globe: **ブラウザ**を開き、`http://192.168.0.20/` にアクセスします。
3. :fa-magnifying-glass: **トレース**モードに切り替え、**+** で **Client-PC** のポート `eth0` のトレースを開きます。
4. Info列に `GET` と表示されているパケットをクリックし、その下にあるプロトコルツリーを見てみましょう。

:::note
一番上の行の **Frame** には、記録に関する情報（サイズや時刻）だけが入っていて、独立したプロトコルではありません。その下のプロトコルツリーは上から順に、**Ethernet**、その下に **IPv4**、その下に **TCP**、一番下に **HTTP** という構成になっています。右端にある色付きの数字は第1章ですでに見ていますね。その意味は次のページで学びます。
:::

## 層ごとに展開する

**Ethernet**、**Internet Protocol Version 4**、**Transmission Control Protocol**、**Hypertext Transfer Protocol** の手前にある小さな三角をクリックしてみましょう。各層がそれぞれ独自の情報を持っています。

| ツリー内の層 | 中に見えるもの | 役割 |
|---|---|---|
| Ethernet | `Source` と `Destination`：`aa:57:28:…` のようなMACアドレス | ローカルネットワーク内のどのネットワークカードか |
| IPv4 | `Source Address` `192.168.0.10`、`Destination Address` `192.168.0.20` | どのコンピューターか（ネットワークの境界を越えても） |
| TCP | `Source Port` `49152`、`Destination Port` `80` | コンピューター上のどのプログラムか |
| HTTP | `GET / HTTP/1.1`、`Host: 192.168.0.20` | ブラウザが伝えたい本来のメッセージ |

次の2つの行にも注目しましょう。Ethernetには `Type: IPv4`、IPv4には `Protocol: TCP` とあります。このように、各層が*自分の中に何が入っているか*を示しているので、受信者はその先をどう取り出せばよいかが分かります。

## 封筒の中の封筒

今見たものは、送信元では次のようにして作られます。

1. ブラウザが本来のメッセージ `GET / HTTP/1.1`（**HTTP**）を作成します。
2. **TCP** がそれを包み、先頭にポートを付けます。正しいプログラムに届くようにするためです。
3. **IP** がそれ全体を包み、先頭にIPアドレスを付けます。正しいコンピューターに届くようにするためです。
4. **Ethernet** がすべてをMACアドレス付きのフレームに入れます。ローカルネットワーク内で正しいネットワークカードに届くようにするためです。

受信者側では、まったく逆の順序で処理されます。各層が自分の部分を取り外し、残りを上の層に渡します。これは、手紙を何重もの封筒に入れるのと同じです。中にメッセージがあり、各封筒の外側には、次にそれを開ける人への宛先が書かれています。

:::tip ポイント
各層は、自分用の制御情報である**ヘッダー**を、上の層のデータの前に付けます。この包む・取り出すという処理を**カプセル化**と呼びます。
:::

層によって、この「小包」には固有の名前があります。

| 層 | 例のプロトコル | データ単位の名前 |
|---|---|---|
| 第2層 | Ethernet | **フレーム**（Frame） |
| 第3層 | IPv4 | **パケット** |
| 第4層 | TCP | **セグメント** |

:::note
日常では、そしてこのコースでも、どの層でも単に「パケット」と呼ぶことがよくあります。正確さが求められるときは、表の名前を使いましょう。
:::

:::quiz fill
送信元では、各層が上の層のデータを包み、その前に{ヘッダー}を付けます。この原則を{カプセル化}と呼びます。第2層のデータ単位は{フレーム}、TCPの第4層では{セグメント}と呼ばれます。
:::

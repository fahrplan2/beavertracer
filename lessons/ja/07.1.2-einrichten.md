# ホームルーターを設定する

:::sim
url=/sims/lesson-7.1.2.btsim
:::

新しいホームルーターが接続されたところですが、まだ誰もインターネットに接続できません。プロバイダーから**接続情報**が書かれた手紙が届いています。

| 接続情報 | 値 |
|---|---|
| WAN IPアドレス | `203.0.113.2` |
| プレフィックス長 | `/30` |
| ゲートウェイ（プロバイダーのルーター） | `203.0.113.1` |
| プロバイダーのDNSサーバー | `198.51.100.10` |

1. :fa-play: **実行**モードに切り替え、**Heimrouter** をクリックして **WAN** タブを開きます。
2. 接続情報を入力し、**適用** をクリックします。
3. **Tablet** を無線LANに接続します。:fa-gear: **IP設定**、**WiFi** タブ、SSID `Biberbau`、**適用** の順に操作します。
4. PCで `ping 192.0.2.80` を実行するか、**ブラウザ**で `http://www.beispiel.de/` を開いて確認します。

:::note
実際には、ホームルーターのWAN側アドレスは、たいていプロバイダーから自動的に割り当てられます（DHCP、またはユーザー名とパスワードによる認証を使用）。ここで使っているような固定の接続情報は、むしろ法人向け回線でよく使われます。
:::

# トラブルシューティング: サービスが応答しない

:::sim
url=/sims/lesson-5.3.2.btsim
:::

アップデートの後、学校から次の連絡が入りました。「エコーサービスがすべての接続を拒否し、Webページも読み込めなくなった。」計画では、**Webサーバー**がポート `80` で、**エコーサービス**(TCP エコーサーバー)がポート `5000` で待ち受けることになっています。エラーを見つけて修正しましょう。

<details>
<summary>ヒント1: サーバーは何と応答する?</summary>

**シンプル TCP クライアント**で `192.168.0.20` のポート `5000` に接続を試み、クライアントPCのトレースを開きましょう。あなたの `[SYN]` に対して、サーバーは何で応答していますか?
</details>

<details>
<summary>ヒント2: どのポートが開いている?</summary>

クライアントPCの**ターミナル**で `nmap -p 80,5000 192.168.0.20` と入力します。`nmap` はポートを順に試し、どれが開いているかを表示します。サーバー上で `ss` を使うと、実際にどのポートでプログラムが待ち受けているかを確認できます。
</details>

<details>
<summary>ヒント3: どこで設定する?</summary>

**サーバー**で **TCP エコーサーバー**と **HTTPサーバー**のアプリを開きましょう。サービスは動いていますか?また、どのポートで待ち受けていますか?
</details>

:::task
title: サービスに到達できる?
クライアントPCがポート 5000 のエコーサービスとポート 80 のWebサーバーに到達できるか確認します。そのためには、シミュレーションが実行モードで動作している必要があります。
check: tcpOpen(1, 2, 5000)
check: tcpOpen(1, 2, 80)
:::

## 何が起きていた?

:::quiz multi
正しい記述はどれですか?
- [x] ポート 5000 への `[SYN]` に対して、サーバーは `[RST, ACK]` で応答した
- [x] エコーサービスはポート 5000 ではなくポート 5050 で待ち受けていた
- [x] Webサーバーがそもそも起動していなかった
- [ ] クライアントPCとサーバーの間のケーブルが故障していた
:::

:::evaluate
回答を確認
:::

:::tip ポイント
`SYN` に対して **`RST`** が返ってきた場合、そのポートでは**どのプログラムも待ち受けていません**。コンピューター自体には到達できるものの、サービスには到達できない状態です。典型的な原因は、サービスが**起動していない**か、**別のポート**で待ち受けていることです。サーバー上で `ss` を使えば、実際にどのポートが開いているかを確認できます。
:::

# 主なアドレスの種類

IPv6では、アドレスの先頭を見れば何のためのアドレスかがわかります。

| アドレスの種類 | 見分け方 | 用途 |
|---|---|---|
| **リンクローカル** | `fe80::` | **自分のローカルネットワーク内**でのみ有効。各デバイスがこのアドレスを自動的に自分に割り当てる。ルーターによって転送されることはない。 |
| **グローバルユニキャスト** | `2…` または `3…` (`2000::/3`) | 世界中で一意のアドレスで、インターネットから到達できる。プレフィックスはインターネットプロバイダーから割り当てられる。 |
| **ユニークローカル** | `fd…` (`fc00::/7`) | プライベートネットワーク用。IPv4の `192.168.x.x` に相当する。 |
| **ループバック** | `::1` | 自分自身のデバイス。IPv4の `127.0.0.1` に相当する。 |
| **マルチキャスト** | `ff…` | デバイスの**グループ**宛て。例: `ff02::1` = ローカルネットワーク内のすべてのデバイス。 |

:::note
`2001:db8::/32` の範囲は、例や教材用に予約されており、実際のインターネットでは使われません。そのため、このコースではこの範囲のアドレスが登場します。
:::

大きな変更点があります。**IPv6にはブロードキャストがありません。** IPv4でブロードキャストによって全員に送っていたことは、IPv6では**マルチキャスト**アドレスで行います。メッセージは、そのグループに関心のあるデバイスにだけ届きます。

:::tip ポイント
IPv6のデバイスは、自分のネットワーク用に少なくとも1つの**リンクローカルアドレス** (`fe80::…`) を持ち、たいていはそれに加えてインターネット用の**グローバルアドレス**も持っています。ブロードキャストの代わりに、IPv6では**マルチキャスト** (`ff…`) を使います。
:::

:::quiz match
fe80::a828:39ff:fee2:4182 -> リンクローカル — 自分のネットワーク内のみ
2001:db8:1::10 -> グローバルユニキャスト — 世界中で一意
::1 -> ループバック — 自分自身のデバイス
ff02::1 -> マルチキャスト — ローカルネットワーク内のすべてのデバイス
fd12:3456::1 -> ユニークローカル — プライベートネットワーク用
:::

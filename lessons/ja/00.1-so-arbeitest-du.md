# コースの進め方

このコースはBeaverTracerの中で直接進めます。左側でネットワークを作って観察し、右側の**レッスンパネル**で手順を読みます。

## ページをめくる

**戻る**と**次へ**で、コースを1ページずつ進めます。**目次**(またはレッスンパネル上部の:fa-list:)を使うと、どの章にもジャンプできます。

## ページごとに対応するシミュレーション

ページを切り替えるたびに、BeaverTracerはそのページに対応するシミュレーションを自動的に読み込みます。そのため、いつも正しく動く状態から始められます。

:::warning
あるページで作ったり変更したりした内容は、次のページでは消えてしまいます。これは意図的なものです。どのページもきれいな初期状態から始まります。
:::

- レッスンパネル上部の:fa-rotate-left:を使うと、シミュレーションを現在のページの開始時点に戻せます。わからなくなってしまったときに便利です。
- シミュレーションを自分で作り進めたいときは、ツールバーの:fa-file-import: **採用**をクリックします。レッスンパネルが閉じて、そのシミュレーションはあなたのものになります。

## 保存と読み込み

シミュレーションは1つのファイル(`.btsim`)で、ネットワーク全体、つまりすべての機器とケーブル、そしてそれらの設定を記述しています。レッスンパネルを開いている間は、:fa-file: **新規**、:fa-file-arrow-up: **読み込み**、:fa-file-arrow-down: **保存**のボタンは表示されません。**採用**した後(または**×**でレッスンパネルを閉じた後)は、編集モードのとき、ツールバーのモード切り替えボタンの右隣に表示されます。

## ボックス、クイズ、タスク

:::goal
**学習目標** — セクションの冒頭に表示されます。このセクションを終えると何ができるようになるかを示します。
:::

:::tip ポイント
重要な専門用語や関連性を短くまとめたものです。試験勉強に役立ちます。
:::

- **クイズ**はページ上で直接答えて、下のボタンで確認します。画面をよく見れば、ほとんどの答えは画面から読み取れます。
- **タスクを確認**ボタンのある**タスク**は、シミュレーションの中を調べて、すべてが正しく設定されているかを確認します。たとえば、2台のPCが互いに通信できるかどうかです。

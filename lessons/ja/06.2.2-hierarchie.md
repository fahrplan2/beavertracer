# DNSの構成

:::sim
url=/sims/lesson-6.2.btsim
:::

世界中のすべての名前を1台のサーバーだけで把握することはできません。そのためDNSは、名前そのものと同じように**階層構造**になっています。名前は右から左へ読みます。

```
www . beaver-schule . de . (Root)
 │          │         │      └─ Root-Server: kennen die Server aller Top-Level-Domains
 │          │         └─ Top-Level-Domain (TLD): der de-Server kennt alle .de-Domains
 │          └─ Domain: der Schul-DNS ist für beaver-schule.de zuständig
 └─ Rechnername innerhalb der Domain
```

ドメインを担当し、その答えを実際に知っているサーバーを**権威サーバー**と呼びます。そこへたどり着くまでの道のりは、PCに代わって**リゾルバー**が担当します。ここではコンピューター**DNS-Resolver**がその役割です。

## 実験

1. :fa-play: **実行**モードに切り替え、**Client-PC**の:fa-terminal: **ターミナル**に次のように入力します。
   ```
   $ nslookup www.beaver-schule.de
   ```
2. :fa-magnifying-glass: **トレース**モードで、**DNS-Resolver**のトレースを開きます。

リゾルバーは、あなたの代わりにいくつもの問い合わせを行いました。どのサーバーがどの回答を返したのか、対応づけてみましょう。

:::quiz match
Root-Server (192.168.0.101) -> 参照先の案内: .de の担当は ns.nic.de
de-Server (192.168.0.102) -> 参照先の案内: beaver-schule.de の担当は ns.beaver-schule.de
Schul-DNS (192.168.0.103) -> 回答: www.beaver-schule.de のアドレスは 192.168.0.20
:::

:::quiz mc
リゾルバーが最初に問い合わせるのはどれですか?
- [x] ルートサーバー
- [ ] Schul-DNS
- [ ] Client-PC
:::

:::evaluate
回答を確認
:::

:::note
途中で、リゾルバーは案内された先のサーバーのアドレスも問い合わせています(`A ns.nic.de`)。実際のDNSサーバーは、こうしたアドレスを最初から一緒に返すのが普通です。さらにリゾルバーは、すべての回答をしばらくのあいだ記憶します(**キャッシュ**)。同じ名前への次の問い合わせには、リゾルバー自身がすぐに答えます。どのくらいの間記憶するかは、レコードに**TTL**(*Time to Live*)として秒単位で書かれています。
:::

## 主なレコードタイプ

| タイプ | 意味 | 例 |
|---|---|---|
| **A** | 名前 → IPv4アドレス | `www.beaver-schule.de` → `192.168.0.20` |
| **AAAA** | 名前 → IPv6アドレス | `www.beaver-schule.de` → `2001:db8::20` |
| **CNAME** | 名前 → 別の名前(エイリアス) | `web.beaver-schule.de` → `www.beaver-schule.de` |
| **MX** | ドメインを担当するメールサーバー | `beaver-schule.de` → `mail.beaver-schule.de` |
| **NS** | ドメインを担当するDNSサーバー | `beaver-schule.de` → `ns.beaver-schule.de` |

:::tip ポイント
DNSは**階層構造**です。**ルートサーバー**は**トップレベルドメイン**(例: `.de`)のサーバーを案内し、トップレベルドメインのサーバーは個々の**ドメイン**のサーバーを案内します。担当する**権威**サーバーが答えを知っています。**リゾルバー**はPCに代わってこの道をたどり、回答を記憶します(**キャッシュ**)。重要なレコードタイプは **A**、**AAAA**、**CNAME**、**MX**、**NS** です。
:::

## レコードを追加する

学校は、自分たちのWebサイトに `intranet.beaver-schule.de` でもアクセスできるようにしたいと考えています。

1. :fa-play: **実行**モードで**Schul-DNS**をクリックし、アプリ**DNS-Server**を開きます。
2. タブ**A**を開きます。**+** をクリックし、新しい行に名前 `intranet.beaver-schule.de` とアドレス `192.168.0.20` を入力します。
3. Client-PCで `nslookup intranet.beaver-schule.de` を実行してテストします。

:::task
title: 新しい名前を登録できた?
Client-PCが、名前 intranet.beaver-schule.de をWebサーバーのアドレスに名前解決できるかを確認します。そのためには、シミュレーションが実行モードで動作している必要があります。
check: resolves(2, "intranet.beaver-schule.de", "192.168.0.20")
:::

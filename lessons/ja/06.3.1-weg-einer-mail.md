## 実験

1. :fa-play: **実行**モードに切り替え、**Anna** をクリックして **E-Mail** アプリを開きます。
2. **新規作成**タブに切り替えます。**An** に `ben@biber-mail.de` を入力し、件名と短い本文を入力して **送信** をクリックします。
3. 数秒待ちます。メールはまずメールサーバーからメールサーバーへ渡される必要があるためです。そのあと **Ben** をクリックして **E-Mail** アプリを開き、**取得** をクリックします。Anna からのメールが届いています。
4. :fa-magnifying-glass: **トレース**モードで、**Mailserver Schule** のトレースを開きます。

## 背景にある仕組み

メールは、2つの郵便局を経由する手紙のように、いくつかの段階を経て届きます。

1. Anna のメールソフトが、**SMTP** でメールを Anna のメールサーバーに渡します。
2. Mailserver Schule は、受信者が**別のドメイン**に属していることを確認します。**DNS** で `biber-mail.de` の **MX レコード**（*Mail Exchanger*）を問い合わせ、`mail.biber-mail.de` を受け取ります。そのあと、そのサーバーの IP アドレスも問い合わせます。
3. **SMTP** でメールを Mailserver Biber に届けます。メールはそこにある Ben のメールボックスに保管されます。
4. Ben は **IMAP**（または **POP3**）で、自分のメールサーバーからメールを取り出します。

:::seq
mode: text
Mailserver Schule -> Mailserver Biber: SMTP: MAIL FROM | anna@beaver-schule.de
Mailserver Biber -> Mailserver Schule: 250 OK
Mailserver Schule -> Mailserver Biber: SMTP: RCPT TO | ben@biber-mail.de
Mailserver Biber -> Mailserver Schule: 250 OK
Mailserver Schule -> Mailserver Biber: SMTP: DATA | メール本体
Mailserver Biber -> Mailserver Schule: 250 OK queued
:::

:::tip ポイント
**SMTP**（ポート 25）はメールを**送信**するためのプロトコルです。メールソフトから自分のメールサーバーへ、そこから受信者のメールサーバーへと送ります。あるドメインをどのメールサーバーが担当しているかは、DNS の **MX レコード**に書かれています。**POP3**（ポート 110）と **IMAP**（ポート 143）は、自分のメールボックスからメールを**取り出す**ためだけに使います。
:::

:::quiz match
SMTP -> メールを送信し、メールサーバー間で転送する
MX レコード -> あるドメインをどのメールサーバーが担当しているかを示す
IMAP -> 自分のメールボックスからメールを取り出す
:::

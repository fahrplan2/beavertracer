# トレースでメールを読み取る

:::sim
url=/sims/lesson-6.3.btsim
:::

HTTPと同じく、SMTPも**テキストプロトコル**です。どんな内容が平文でそのまま回線を流れているのか、確かめてみましょう。

## 実験

1. :fa-play: **実行**モードで、前のページと同じように **Anna** から `ben@biber-mail.de` 宛てにメールを送ります。
2. :fa-magnifying-glass: **トレース**モードで **Anna** のトレースを開きます。**Info** 列に SMTP のやり取りが表示されます。`C:` で始まる行はクライアントが、`S:` で始まる行はサーバーが送信したものです。

:::quiz short
`MAIL FROM:` の後ろにあるアドレスは何ですか?
= anna@beaver-schule.de
= <anna@beaver-schule.de>
:::

:::quiz short
では、`RCPT TO:` の後ろにあるアドレスは何ですか?
= ben@biber-mail.de
= <ben@biber-mail.de>
:::

:::quiz mc
サーバーがコマンドを受け付けたときに送ってくる数字コードはどれですか?
- [x] `250`
- [ ] `200`
- [ ] `404`
:::

:::evaluate
答えを確認
:::

## パスワードはどうなっている?

`MAIL FROM` の前に、Anna のメールソフトは `AUTH PLAIN` と `AGFubmEAZ2VoZWlt` のような文字列を使ってログインします。暗号化されているように見えますが、そうではありません。これは単なる **Base64** で、誰でもすぐに元に戻せるエンコード方式です。この中には `anna` とそのパスワード `geheim` が入っています。

次に **Ben** でメールを受信(**取得**)し、**Ben** のトレースを開きましょう。IMAP で受信する場合は、さらにはっきりと見えます。

:::quiz short
Ben のメールソフトは、どのパスワードを平文でサーバーに送っていますか?(`LOGIN` の行を見てください。)
= biber123
:::

:::evaluate
答えを確認
:::

:::warning
暗号化されていないと、通信を盗聴できる人なら誰でも**内容、送信元、受信者、パスワード**を読み取れます。そのため現在では、暗号化された方式(例:STARTTLS を使った SMTP、ポート 993 の IMAPS)が使われています。その仕組みは第8章で学びます。
:::

:::tip ポイント
**SMTP**、**POP3**、**IMAP** はテキストプロトコルです。`MAIL FROM`、`RCPT TO`、`DATA`(SMTP)や `LOGIN`(IMAP)といったコマンドとその応答は、人間が読める形で流れます。暗号化されていなければ、**パスワード**も平文(あるいは Base64 でエンコードされただけの状態)で回線を流れます。
:::

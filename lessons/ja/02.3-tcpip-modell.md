# TCP/IPリファレンスモデル

ISO/OSIモデルは非常に詳細ですが、純粋に理論として作られたものです。実際には、インターネットでも、より簡潔で4つの層だけからなる**TCP/IPモデル**が普及しました。TCP/IPモデルは、複数のOSI層を1つにまとめています。

| TCP/IP層 | 対応するOSI層 | プロトコルの例 |
|---|---|---|
| アプリケーション | 5, 6, 7(セッション層、プレゼンテーション層、アプリケーション層) | HTTP, DNS, SMTP |
| トランスポート | 4(トランスポート層) | TCP, UDP |
| インターネット | 3(ネットワーク層) | IP, ICMP |
| ネットワークアクセス | 1, 2(物理層、データリンク層) | Ethernet, WLAN |

ARPはネットワークアクセス層とインターネット層の境界にあります(OSI 2/3。最後のページの境界事例を参照してください)。

セッション層・プレゼンテーション層・アプリケーション層という分け方は、実際にはあまり明確に区別できません。HTTPのようなほとんどのアプリケーション層プロトコルは、そのすべてを自分で処理します。TCP/IPモデルはこの点を考慮して、これら3つの層を1つにまとめています。

:::note
この先の章で「層2」「層3」「層4」と出てきたら、それは常にISO/OSIモデルの番号付けを指します。BeaverTracerや実務ではTCP/IPの区分で考えることも多いですが、このコースではOSIモデルの番号付けを共通の基準としています。
:::

:::quiz fill

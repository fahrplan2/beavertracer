# 1台のスイッチ、2つのネットワーク

:::sim
url=/sims/lesson-3.2.1.btsim
:::

スイッチには4台のPCがつながっています。管理部門の **Sekretariat**(ポート1)と **Schulleitung**(ポート2)、そしてコンピューター室の **Anna**(ポート3)と **Ben**(ポート4)です。すべて同じネットワーク `192.168.0.0/24` に属しています。

## 問題点

:fa-play: **実行**モードに切り替え、**Anna** で :fa-terminal: **ターミナル** を開いて、Sekretariat に ping を送ってみましょう。

```
$ ping 192.168.0.10
```

Anna は問題なく Sekretariat に届きます。まさにこれを防ぎたいのです。

## VLANの設定

**VLAN**(*Virtual LAN*)とは、スイッチの内部に作る、独立して分離されたネットワークのことです。各 VLAN には **VLAN ID** という番号があります。ここでは、管理部門を **VLAN 10**、コンピューター室を **VLAN 20** に割り当てます。

1. 実行モードで **スイッチ** をクリックし、**VLAN** タブを開きます。
2. **VLANを有効にする** にチェックを入れます。ポートごとに1行ずつの表が表示されます。
3. **PVID** 列に VLAN ID を入力します。**port 1** と **port 2** にはそれぞれ `10`、**port 3** と **port 4** にはそれぞれ `20` を入れます。**モード**は `untagged` のままにします。
4. 下部の **適用** をクリックします。

:::note
**PVID** は *Port VLAN ID* の略で、そのポートに届くものはすべてこの VLAN に属する、という意味です。モード `untagged` は、そのポートに VLAN を意識する必要のない通常のPCがつながっていることを意味します。
:::

## テスト

もう一度 **Anna** から Sekretariat に ping を送り、続けて Ben にも送ってみましょう(`ping 192.168.0.21`)。

:::quiz mc
このとき何が起こるでしょうか?
- [ ] Anna は Sekretariat にも Ben にも届く
- [x] Anna は Ben には届くが、Sekretariat にはもう届かない
- [ ] Anna はもう誰にも届かない
:::

:::evaluate
答えを確認
:::

:fa-magnifying-glass: **トレース**モードで **Sekretariat** のトレースを開いてみましょう。Anna の ARP リクエスト(「Who has 192.168.0.10?」)はそこにまったく現れません。Anna のブロードキャストは VLAN 20 の中にとどまります。スイッチにとっては、今や互いに何も知らない2つの別々のネットワークになっているのです。

:::tip ポイント
**VLAN** を使うと、1台のスイッチを論理的に分離された複数のネットワークに分割できます。異なる VLAN にあるデバイス同士は直接通信できず、ブロードキャストも自分の VLAN の中にとどまります。各 VLAN には **VLAN ID** という番号があります。
:::

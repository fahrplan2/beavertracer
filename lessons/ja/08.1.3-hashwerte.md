# ハッシュ値: データの指紋

:::sim
url=/sims/lesson-8.1.3.btsim
:::

**ハッシュ関数**は、任意の大きさのデータ(1つの文、1つの文書、映画1本まるごとでも)から、固定長の短い文字列である**ハッシュ値**を計算します。ハッシュ値は**指紋**のように働きます。同じデータからは常に同じハッシュ値が得られ、異なるデータからは異なるハッシュ値が得られます。

現在よく使われているハッシュ関数は**SHA-256**です。そのハッシュ値は常に256ビットの長さで、16進数で表すと64文字になります。

## 実験

**PC**の`/home`フォルダに、簡単な売買契約書の3つのファイルがあります。:fa-play: **実行**モードに切り替え、**PC**で:fa-terminal: **ターミナル**を開き、次のように入力しましょう。

```
$ cd /home
$ cat vertrag.txt vertrag-kopie.txt vertrag-neu.txt
$ sha256sum vertrag.txt vertrag-kopie.txt vertrag-neu.txt
```

## ハッシュ関数の性質

| 性質 | 意味 |
|---|---|
| **固定長** | データの大きさに関係なく、ハッシュ値の長さは常に同じです。 |
| **一意性(決定性)** | 同じデータからは常に同じハッシュ値が得られます。 |
| **雪崩効果** | ほんのわずかな変更でも、まったく異なるハッシュ値になります。 |
| **一方向関数** | ハッシュ値からデータを逆算することは**できません**。 |
| **衝突耐性** | 同じハッシュ値を持つ2つの異なるファイルを見つけることは、事実上不可能です。 |

ハッシュ関数は**暗号化ではありません**。鍵も復号もありません。ハッシュ関数は別の目的、つまり**完全性**のために使われます。

## 何に使うのか?

- **ダウンロードの検証:** 多くのウェブサイトでは、ファイルと並んでそのSHA-256値が公開されています。ダウンロードしたファイルのハッシュ値がそれと一致すれば、そのファイルは途中で改ざんされていません。
- **パスワードの保存:** 信頼できるウェブサイトは、パスワードそのものではなく、そのハッシュ値だけを保存します。ログイン時には、入力された内容のハッシュ値が比較されます。データベースが盗まれても、盗んだ人はパスワードを知ることができません。
- **デジタル署名:** 文書全体ではなく、そのハッシュ値だけに署名します。詳しくは次のセクションで説明します。

:::tip ポイント
**ハッシュ関数**(例: **SHA-256**)は、任意のデータから固定長の**ハッシュ値**、つまり**指紋**を計算します。ほんのわずかな変更でもまったく異なるハッシュ値になり、ハッシュ値からデータを逆算することはできません。ハッシュ値はデータの**完全性**を守ります。
:::

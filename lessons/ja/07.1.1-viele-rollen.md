## ホームルーターの中身

| ホームルーター内の役割 | 何をするか | 学んだ場所 |
|---|---|---|
| **スイッチ** | LAN ポートにつないだ機器同士を接続する | 3.1 章 |
| **アクセスポイント** | スマートフォン、タブレット、ノート PC を WLAN でネットワークに接続する | 3.3 章 |
| **ルーター** | 家庭内ネットワークとプロバイダーのネットワークを接続する。これが**ゲートウェイ**にあたる | 4.3 章 |
| **DHCPサーバー** | アドレス、ゲートウェイ、DNSサーバーを配布する | 6.4 章 |
| **DNS** | 名前解決の問い合わせを転送する、またはプロバイダーの DNSサーバーを知らせる | 6.2 章 |
| **NAT** | すべての機器を**1つ**のパブリックアドレスでインターネットに接続する | 新出 — 7.2 節 |

**WAN**(*Wide Area Network*)ポートはプロバイダーにつながり、**LAN** ポートと WLAN は家庭内ネットワークにつながります。多くのホームルーターには**モデム**も内蔵されています。モデムは、データを回線(DSL、ケーブル、光ファイバー)用に変換します。BeaverTracer ではこれをシミュレートしません。ここでは WAN ポートがプロバイダーのネットワークに直接つながっています。

:::quiz match
スイッチ -> LAN ポートにつないだ機器同士を接続する
アクセスポイント -> タブレットやスマートフォンを WLAN でネットワークに接続する
DHCPサーバー -> 家庭内ネットワークの機器にアドレスを配布する
ルーター -> 家庭内ネットワークとプロバイダーのネットワークを接続する
:::

:::evaluate
対応を確認
:::

:::tip ポイント
**ホームルーター**は複数の機器の機能をまとめたものです。**スイッチ**、**WLAN アクセスポイント**、**ルーター**(インターネットへのゲートウェイ)、**DHCPサーバー**、**DNS 転送**に加えて **NAT** も備えています。**WAN** ポートはプロバイダーにつながり、**LAN** ポートと WLAN は家庭内ネットワークにつながります。
:::

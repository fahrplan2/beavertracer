# スイッチネットワークのトラブルシューティング

:::sim
url=/sims/lesson-3.1.3.btsim
:::

**David** がネットワークに新しく加わってから、問題が起きています。Clara には誰も接続できず、Ben の様子もどこかおかしいようです。ネットワークのプロとして、これを直してください。

## ネットワーク構成図

ネットワークは本来、次のような構成になっているはずです。

| 機器 | IPアドレス | スイッチポート |
|---|---|---|
| Anna | `192.168.0.10/24` | 1 |
| Ben | `192.168.0.11/24` | 2 |
| Clara | `192.168.0.12/24` | 3 |
| David | `192.168.0.13/24` | 4 |

構成図とシミュレーションを見比べてみましょう。どこが違っていますか？ 見つけた不具合はすべて直してください。

<details>
<summary>ヒント1：どこから始めればいい？</summary>

まずケーブルを確認します。どの PC も正しいポートにつながっていますか？ そのあと、各 PC の IP設定 を確認しましょう。
</details>

<details>
<summary>ヒント2：Ben は ping に応答しているのに …？</summary>

Anna から Ben に ping を送り（`ping 192.168.0.11`）、Anna のトレースを開きます。ARP の応答をよく見てください。応答はいくつありますか？ そして、どの MAC アドレスからですか？
</details>

:::task
title: ネットワークは直った？
すべての機器がネットワーク構成図どおりのアドレスを持ち、互いに通信できるかを確認します。そのため、シミュレーションは実行モードで動かしておく必要があります。
check: ip(3, "192.168.0.10/32")
check: ip(5, "192.168.0.11/32")
check: ip(7, "192.168.0.12/32")
check: ip(11, "192.168.0.13/32")
check: pingOk(3, 7)
check: pingOk(3, 11)
check: pingOk(5, 7)
:::

## 何が起きていたのか

:::quiz mc
2台の機器が同じIPアドレスを持っていることは、トレーサーのどこからわかる？
- [ ] ping が常に失敗する
- [x] 1つの ARP 要求に対して、異なる MAC アドレスから2つの応答が返ってくる
- [ ] スイッチがエラーメッセージを表示する
:::

:::evaluate
回答を確認
:::

:::tip ポイント
**トラブルシューティング**では、**あるべき状態**（ネットワーク構成図）と**実際の状態**（ケーブル、設定、トレーサー）を見比べます。注意：ping が成功したからといって、すべてが正しいとは限りません。IPアドレスが重複している場合、間違った機器がたまたま応答しているだけかもしれません。
:::

# 学校ネットワークを分割する

:::sim
url=/sims/lesson-4.4.2.btsim
:::

学校には `192.168.10.0/24` のアドレス範囲があります。事務室、職員室、コンピューター室には、それぞれ専用のサブネットを割り当てます。必要なのは3つのネットワークですが、同じ大きさのサブネットに分けられるのは2のべき乗の数だけです。そこで**4つ**のサブネットに分割し、4つ目は予備として残します（たとえば将来の無線LAN用です）。

## ステップ1：計算する

:::quiz table
| 拡張ビット数 | プレフィックス長 | サブネットマスク |
|---|---|---|
| {2} | /{26} | {255.255.255.192} |
:::

:::quiz table
| サブネット | 用途 | ネットワークアドレス | ブロードキャストアドレス |
|---|---|---|---|
| 1 | 事務室 | {192.168.10.0} | {192.168.10.63} |
| 2 | 職員室 | {192.168.10.64} | {192.168.10.127} |
| 3 | コンピューター室 | {192.168.10.128} | {192.168.10.191} |
| 4 | 予備 | {192.168.10.192} | {192.168.10.255} |
:::

:::evaluate
答えを確認
:::

## ステップ2：設定する

ルーターはすでに設定済みです。ルーターは各サブネットで**最初に使えるアドレス**（`192.168.10.1`、`192.168.10.65`、`192.168.10.129`）を持っています。

では、3台のPCを設定しましょう。各PCには、そのサブネットの**2番目に使えるアドレス**、適切なプレフィックス長、そして自分のサブネットにあるルーターのアドレスをゲートウェイとして設定します。

1. :fa-play: **実行**モードに切り替えます。
2. **PC Verwaltung** の :fa-gear: **IP設定**を開き、**IP**、**プレフィックス長**、**ゲートウェイ**を入力して、**適用**をクリックします。
3. **PC Lehrerzimmer** と **PC Computerraum** でも同じように設定します。
4. `ping` を使って、PC同士が互いに通信できるかテストします。

:::task
title: 学校ネットワークの設定はできた？
3台のPCのアドレスと、ルーター経由で互いに到達できるかを確認します。そのためには、シミュレーションを実行モードで動かしておく必要があります。
check: ip(9, "192.168.10.2/32")
check: ip(11, "192.168.10.66/32")
check: ip(13, "192.168.10.130/32")
check: pingOk(9, 11)
check: pingOk(9, 13)
check: pingOk(11, 13)
:::

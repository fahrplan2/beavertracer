# 2進数

コンピューターは、その内部では2つの状態しか知りません。電気が流れているか、流れていないかです。これを **1** と **0** で書き表します。このような1桁分を **ビット** と呼びます。IPアドレスも、コンピューターにとっては0と1が並んだものにすぎません。サブネットマスクの仕組みを理解できるように、このページではそうした数を読み取り、自分で変換する方法を学びます。

## ふだんの数え方：10進数

日常生活では、10個の数字（0〜9）を使って計算します。各桁は、右隣の桁の10倍の値を持ちます。1の位、10の位、100の位、1000の位です。したがって、数 `305` は次のような意味になります。

| 桁の重み | 100 | 10 | 1 |
|---|---|---|---|
| 数字 | 3 | 0 | 5 |
| 値 | 300 | 0 | 5 |

300 + 0 + 5 = **305**

## 2進数

**2進数**（*バイナリ*とも言います）では、数字は0と1の2つだけです。各桁は、右隣の桁の **2倍** の値を持ちます。1、2、4、8、16、32、64、128 …

したがって、2進数 `00001101` は次のような意味になります。

| 桁の重み | 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1 |
|---|---|---|---|---|---|---|---|---|
| ビット | 0 | 0 | 0 | 0 | 1 | 1 | 0 | 1 |
| 値 | | | | | 8 | 4 | | 1 |

8 + 4 + 1 = **13**

つまり、1が立っている桁の重みをすべて足し合わせるだけです。

:::tip ポイント
**ビット** は2進数の1桁（0または1）です。**8ビット** で1 **バイト** になります。ネットワーク技術では、この8ビットのまとまりを **オクテット** とも呼びます。オクテットの桁の重みは **128、64、32、16、8、4、2、1** です。
:::

:::quiz short
`00000110` は10進数でいくつですか？
= 6
:::

:::quiz short
`10000001` は10進数でいくつですか？
= 129
:::

## 10進数から2進数へ

逆に変換するときは、桁の重みを左から右へ順に見ていき、そのたびに **この桁の重みは、(残りの)数に入るか？** と考えます。入るなら1を書き、その重みを引きます。入らないなら0を書きます。

例：`168`

| 桁の重み | 入るか？ | ビット | 残り |
|---|---|---|---|
| 128 | 168 → はい | **1** | 40 |
| 64 | 40 → いいえ | **0** | 40 |
| 32 | 40 → はい | **1** | 8 |
| 16 | 8 → いいえ | **0** | 8 |
| 8 | 8 → はい | **1** | 0 |
| 4 | 0 → いいえ | **0** | 0 |
| 2 | 0 → いいえ | **0** | 0 |
| 1 | 0 → いいえ | **0** | 0 |

上から下へ読むと、168 = **10101000** になります。

## 練習

試すたびに新しい数が出題されます。確実に身につくまで繰り返し練習しましょう。

:::quiz random dec2bin
count=3
:::

:::quiz random bin2dec
count=3
:::

:::evaluate
答えを確認
:::

:::tip ヒント
サブネットマスクでは、次の値が何度も登場します。覚えておくと役立ちます。`10000000` = 128、`11000000` = 192、`11100000` = 224、`11110000` = 240、`11111000` = 248、`11111100` = 252、`11111110` = 254、`11111111` = 255。
:::

## 2進数で見るIPアドレス

IPv4アドレスは **32ビット**、つまり4つのオクテットでできています。0と1が32個も並んでいては誰も覚えられないので、各オクテットを10進数で書き、ドットで区切ります。

```
11000000 . 10101000 . 10110010 . 00000001
   192   .   168    .   178    .    1
```

:::quiz short
IPv4アドレスは何ビットでできていますか？
= 32
:::

:::quiz mc
理論上、IPv4アドレスは何通りありますか？
- [ ] 256 × 4 = 1024
- [x] 2³² — 約43億
- [ ] 十分すぎるほど — 地球上の1人につき複数
:::

:::evaluate
答えを確認
:::

:::note
約43億と聞くと多く感じますが、地球上の人間1人につき1つにも足りません。そのため、IPv4アドレスは以前から不足しています。この問題への対処法は、あとでNATとIPv6のところで学びます。
:::

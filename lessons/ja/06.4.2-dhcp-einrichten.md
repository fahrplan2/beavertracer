# DHCPサーバーを設定する

:::sim
url=/sims/lesson-6.4.2.btsim
:::

今回は、DHCPサーバーはまだ設定されていません。どの設定を配布するかは、あなたが決めます。

| 設定 | 値 |
|---|---|
| アドレス範囲 | `192.168.0.100` ～ `192.168.0.120` |
| ゲートウェイ | `192.168.0.1` |
| DNSサーバー | `192.168.0.53` |

1. :fa-play: **実行**モードに切り替え、**DHCP-Server** をクリックして、アプリ **DHCPサーバー** を開きます。
2. **範囲開始**、**範囲終了**、**Gateway**、**DNS-Server** を入力し、**保存** をクリックしてから **開始** をクリックします。
3. **Laptop 1** と **Laptop 2** の :fa-gear: **IP設定** で、モードを **DHCP** に変更し、それぞれ **適用** をクリックします。
4. DHCPサーバーの **Leases** タブで、どの端末がどのアドレスを取得したかを確認します。

:::note
アドレス範囲は、固定アドレスと衝突しないように選びます。サーバー、ルーター、プリンターには、DHCPの範囲外の固定アドレスを割り当てることがよくあります。ここでは、たとえばDHCPサーバー自身が `192.168.0.2` を使っています。
:::

:::task
title: DHCPは設定できた？
両方のラップトップがDHCPの範囲内のアドレスを取得し、DHCPサーバーに到達できるかを確認します。そのためには、シミュレーションを実行モードで動かしておく必要があります。
check: ip(3, "192.168.0.96/27")
check: ip(4, "192.168.0.96/27")
check: pingOk(3, 2)
check: pingOk(4, 2)
:::

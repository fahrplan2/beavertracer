# 証明書を見てみよう

:::sim
url=/sims/lesson-8.2.1.btsim
:::

ワークスペースには、**Client-PC**、**DNS-Server**、そして学校のWebサーバー `www.beaver-schule.de` が表示されています。このWebサーバーは、**HTTPS** でもページを提供しています。

## ブラウザの鍵マーク

1. :fa-play: **実行**モードに切り替え、**Client-PC** をクリックして :fa-globe: **ブラウザ** を開きます。
2. `https://www.beaver-schule.de/` にアクセスします。**https** になっていることに注意しましょう。
3. アドレスの左側に**鍵マーク**が表示されます。それをクリックします。

:::quiz short
この証明書は、どの名前に対して発行されていますか（サブジェクト、`CN=` は除く）？
= www.beaver-schule.de
:::

:::quiz short
この証明書を発行したのは誰ですか（発行者、`CN=` は除く）？
= Biber Root CA
:::

:::evaluate
回答を確認
:::

## なぜClient-PCはこの証明書を信頼するのか？

**Client-PC** で :fa-shield-halved: **Zertifikatverwaltung** を開き、**Vertrauenswürdige CAs** タブに切り替えます。

:::quiz mc
そこには何がありますか？
- [x] **Biber Root CA** の証明書
- [ ] `www.beaver-schule.de` の証明書
- [ ] エントリーはない
:::

:::quiz mc
Biber Root CA がルートCAであることは、どうすれば分かりますか？
- [x] **自己署名**されている：サブジェクトと発行者が同じ
- [ ] 名前の末尾が「CA」である
- [ ] 公開鍵を持っていない
:::

:::quiz mc
Client-PC の **Privater Schlüssel** の欄は「Ja」と「Nein」のどちらですか？
- [ ] Ja — クライアントは署名を検証するために、CAの秘密鍵を必要とする
- [x] Nein — 検証には公開鍵だけで十分で、秘密鍵を持っているのはCAだけである
:::

:::evaluate
回答を確認
:::

## もう一方の側：Webサーバー

次に、Webサーバー **www.beaver-schule.de** で :fa-shield-halved: **Zertifikatverwaltung**（**Meine Zertifikate** タブ）を開き、そのサーバーの証明書を見てみましょう。

:::quiz multi
Webサーバー上の証明書について正しいものはどれですか？
- [x] **Privater Schlüssel** の欄は「Ja」になっている — サーバーは接続確立のためにそれを必要とする
- [x] **チェーン**は `www.beaver-schule.de ← Biber Root CA` である
- [x] **フィンガープリント**は、ブラウザの鍵マークのウィンドウに表示されるものと同じである
- [ ] 自己署名されている
:::

:::evaluate
回答を確認
:::

:::note
**フィンガープリント**は、証明書に対するハッシュ値です。これを使えば、すべてのフィールドを一つずつ確認しなくても、2つの証明書をすばやく比較できます。
:::

:::tip ポイント
**Webサーバー**は、自分の証明書を**秘密鍵とともに**持っています。**クライアント**が知っているのは**ルートCAの証明書**だけ（秘密鍵なし）ですが、それだけでサーバー証明書上の署名を検証できます。ブラウザで**鍵マーク**をクリックすると、サブジェクト、発行者、フィンガープリント、有効期間を確認できます。
:::

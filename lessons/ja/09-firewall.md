Beaver-Schule は独自のグローバルアドレス(`198.51.100.…`)を持っています。**Schulserver** は NAT なしでインターネットから直接アクセスできます。IPv6 では、近いうちにどこでもこうなります(第7.3章)。インターネットと **Schulrouter** の間には**ファイアウォール**が置かれていますが、今のところはすべての通信を通してしまいます。

左側には「インターネット」があり、**Internet-PC** と Web サーバー `www.beispiel.de` が接続されています。右側は学校ネットワークで、**Schulserver** と **Lehrer-PC** があります。

## 攻撃者には何が見えるのか?

サーバーを攻撃しようとする人は、まず**開いているポート**、つまり接続を待ち受けているサービスを探します。そのためのツールが**ポートスキャナ**で、最もよく知られているのが `nmap` です。

:fa-play: **実行**モードに切り替え、**Internet-PC** で :fa-terminal: **ターミナル**を開いて、次のように入力しましょう。

```
$ nmap 198.51.100.10
```

`nmap` は、よく使われる上位20個のポートに対して TCP 接続を試み、どのポートが開いているかを報告します。

:::evaluate
回答を確認

Web サイト(80)とメールの受信(25)は、インターネットから到達できる必要があります。しかし、**リモート保守**(22)とメールの取得(110、143)は、学校ネットワークの中でしか必要ありません。開いているポートはどれも、攻撃される可能性のある入口になります。サービスにセキュリティ上の欠陥があったり、パスワードが脆弱だったりすると、攻撃者は世界中のどこからでもそこを突くことができます。しかも、インターネット上の自動スキャナは、まさにそれを24時間休みなく試しています。

:::tip ポイント
**ファイアウォール**は、2つのネットワークの境界でデータの流れを制御し、明示的に許可されたものだけを通します。これにより、内部でしか必要のないサービスはインターネットから見えないままになります。
:::

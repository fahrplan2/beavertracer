# POP3 か IMAP か?

:::sim
url=/sims/lesson-6.3.btsim
:::

メールを受信(取得)するためのプロトコルは2種類あります。このシミュレーションでは、**Anna は POP3**、**Ben は IMAP** を使っています。

## 実験

1. :fa-play: **実行**モードで、**Ben** から `anna@beaver-schule.de` にメールを送りましょう。
2. **Anna** の **E-Mail** アプリで **取得** をクリックします。
3. **Anna** と **Ben** のトレースを開いて、メールを取得するときのコマンドを比較しましょう。

:::quiz match
USER / PASS -> POP3: ユーザー名とパスワードで2段階でログインする
RETR -> POP3: メッセージを1通ダウンロードする
LOGIN -> IMAP: ユーザー名とパスワードでログインする
SELECT INBOX -> IMAP: サーバー上のフォルダを開く
:::

:::evaluate
対応を確認
:::

## 違い

| | POP3 | IMAP |
|---|---|---|
| ポート | 110 | 143 |
| 基本的な考え方 | メールを**ダウンロード**する(その後、通常はサーバー上から削除する) | メールは**サーバー上に残り**、サーバー上で管理される |
| フォルダ、既読/未読 | 自分のデバイスのみ | サーバー上で管理 — どこでも同じ |
| 複数のデバイス(スマートフォン、ノートPC) | 不便: デバイスごとに状態が異なる | 理想的: すべてのデバイスが同じメールボックスを見られる |

:::note
BeaverTracer のメールプログラムは、POP3 の場合でもメールをサーバー上に残します。実際のメールソフトでは、ダウンロード後にメールを削除することが多く、あるいはしばらくの間だけ残しておきます。
:::

:::quiz mc
Lena はスマートフォン、タブレット、学校のノートPCでメールを読んでいます。何を使うべきでしょうか?
- [ ] POP3、より簡単だから
- [x] IMAP、すべてのデバイスがサーバー上の同じメールボックスを見られるから
- [ ] SMTP、受信用のプロトコルだから
:::

:::evaluate
答えを確認
:::

:::tip ポイント
**POP3** は、メールをサーバーから**1台の**デバイスにダウンロードします。**IMAP** は、メールボックスを**サーバー上で**管理し、フォルダや既読状態をすべてのデバイスで同時に共有します。どちらも**受信(取得)**のためだけのプロトコルで、送信は常に **SMTP** で行います。
:::

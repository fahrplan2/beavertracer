# DMZ

:::sim
url=/sims/lesson-9.3.btsim
:::

これまで**Schulserver**は**Lehrer-PC**と同じネットワークにありました。これは危険です。Schulserverはインターネットから到達できます。攻撃者がWebサーバーの脆弱性を見つけてこのコンピューターを乗っ取ると、攻撃者は**学校ネットワークの真ん中**に入り込んでしまいます。しかも、Schulserverから Lehrer-PC へのトラフィックはファイアウォールを通過しないため、ファイアウォールにはもう何もできません。

解決策は、インターネットから到達できなければならないサーバーを、インターネットと内部ネットワークの間にある**専用のネットワーク**に置くことです。このネットワークを**DMZ**（*非武装地帯*。2つの国境の間にある中立地帯にちなんだ名前）と呼びます。

## 構成

ワークスペースには、**2台のファイアウォール**を使った典型的なモデルが表示されています。

```
Internet ──[ Firewall außen ]── Schulrouter ──── DMZ: Schulserver (198.51.100.10)
                                    │
                             [ Firewall innen ]
                                    │
                    LAN: Lehrer-PC (192.0.2.20), Schüler-PC (192.0.2.21)
```

- **Firewall außen**は、すべてをインターネットから守ります。ポートAはインターネットに、ポートBはSchulrouterにつながっています。
- **Firewall innen**はLANを守ります。DMZからも守ります。ポートAはSchulrouterに、ポートBはLANにつながっています。

現時点では、どちらのファイアウォールもすべての通信を通しています。

:::quiz multi
どの通信が妥当で、許可すべきでしょうか？
- [x] インターネット → DMZ：Schulserverの Web（80）とメール（25）
- [x] LAN → DMZ：たとえばメールの受信（110）
- [x] LAN → インターネット：Webの閲覧
- [ ] インターネット → LAN
- [ ] DMZ → LAN
:::

:::evaluate
回答を確認
:::

## タスク：DMZを保護する

**両方の**ファイアウォールを**Stateful**と**Alle verwerfen**に設定し、適切なルールを登録しましょう。

- **Firewall außen：** 内側から外側（B → A）はすべて許可します。外側から（A → B）は、Schulserver `198.51.100.10` への TCP 80 と 25 だけを許可します。
- **Firewall innen：** LANから（B → A）はすべて許可します。LAN方向（A → B）にはルールは不要です。応答はステートテーブルを通って戻ってきます。

:::task
title: DMZは保護されましたか？
インターネット、DMZ、LANの間で、許可された経路と禁止された経路を確認します。
check: tcpOpen(1, "198.51.100.10", 80)
check: tcpOpen(1, "198.51.100.10", 25)
check: tcpFails(1, "198.51.100.10", 22)
check: pingFails(1, 10)
check: tcpOpen(10, "198.51.100.10", 110)
check: tcpOpen(10, "203.0.113.80", 80)
check: pingFails(7, 10)
:::

:::quiz mc
攻撃者がDMZ内のSchulserverを乗っ取りました。攻撃者は今、何ができるでしょうか？
- [ ] 妨げられることなくLehrer-PCにアクセスできる
- [x] DMZから出られない。Firewall innenがDMZからLANへの接続を許可しないため
- [ ] Firewall außenを停止できる
:::

:::evaluate
回答を確認
:::

:::note
多くのファイアウォールは3つ以上のポート（「ゾーン」）を持ち、1台の機器でDMZを再現します。原則は同じで、インターネット、DMZ、LANの間のトラフィックは必ずルールを通過しなければなりません。2台のファイアウォールを使うモデルには利点があります。攻撃者は**2つ**の障壁を突破しなければなりません。同じ脆弱性で両方が突破されないように、異なるメーカーの機器を使うことも少なくありません。
:::

:::tip ポイント
**DMZ**には、インターネットから到達できなければならないサーバーをすべて置きます。DMZは2台のファイアウォールの間（またはファイアウォールの専用ゾーン）にあります。インターネットからは、DMZ内の特定のサービスにだけアクセスでき、LANはDMZにもインターネットにもアクセスできます。ただし、DMZからもインターネットからも、**LANへの経路はありません**。DMZ内のサーバーが乗っ取られても、LANは守られます。
:::

# ポート: 同時に多数の接続を扱う

:::goal
**学習目標:** 1台のコンピュータ上の複数の接続をポートがどのように区別しているかを説明でき、主なウェルノウンポートを挙げられ、典型的なポートの不具合を見つけられる。
:::

:::sim
url=/sims/lesson-5.1.btsim
:::

5.1節で見たとおり、ブラウザとTCPクライアントは同じIPアドレスにパケットを送っているのに、それぞれ正しいサービスに届きます。その違いを生んでいたのが、`80` と `5000` という数字、つまり**ポート**です。ここからは、ポートがどのように働くのかをもう少し詳しく見ていきましょう。

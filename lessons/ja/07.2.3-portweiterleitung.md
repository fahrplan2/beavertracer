# 外から内へ：ポートフォワーディング

:::sim
url=/sims/lesson-7.2.3.btsim
:::

家庭内ネットワークに、専用の**Heim-Webserver**(`192.168.178.10`)が置かれました。Clara は外出先からそのページを開きたいと考えています。彼女のノートPC **Clara** は、右側のインターネットにつながっています。

## 問題

1. :fa-play: **実行**モードに切り替え、**Clara** の :fa-globe: **ブラウザ**で `http://203.0.113.2/` を開きます。これは家庭内ネットワークの公開アドレスです。
2. ブラウザはずっと待ち続けます。数秒後に **Stopp** をクリックします。
3. :fa-magnifying-glass: **トレース**モードで、**Heimrouter** のポート `wan0` のトレースを開きます。

:::quiz mc
Clara の接続確立(ポート 80 宛ての `[SYN]`)はどうなるでしょうか?
- [x] ホームルーターには届くが、ルーターは転送せず、応答も返さない
- [ ] Heim-Webserver に届き、RST で応答される
- [ ] そもそもホームルーターに届かない
:::

:::evaluate
回答を確認
:::

外から来たパケットに対応するエントリは、NATテーブルにありません。家庭内ネットワークの誰もこの接続を開始していないからです。ホームルーターはどの機器に送ればよいか分からず、パケットを破棄します。

## ポートフォワーディングを設定する

**ポートフォワーディング**(ルーターによっては*ポート開放*とも呼ばれます)では、特定のWANポートに届いたものをすべて、家庭内ネットワークの特定の機器に送るよう設定します。

1. **Heimrouter** をクリックし、**Port FW** タブを開きます。
2. ルールを作成します。プロトコルは `TCP`、WANポートは `80`、LAN IP は `192.168.178.10`、LANポートは `80` にして、**+ Hinzufügen** をクリックします。
3. **Clara** でもう一度 `http://203.0.113.2/` を開きます。

:::task
title: Heim-Webserver に外部からアクセスできる?
Clara がインターネットから、家庭内ネットワークの公開アドレスのポート 80 へ接続を確立できるかを確認します。そのためには、シミュレーションが実行モードで動いている必要があります。
check: tcpOpen(12, "203.0.113.2", 80)
:::

:::warning
ポートフォワーディングは、内側への穴を開けることになります。インターネット上の誰でも、その先の機器にアクセスできます。開いているポートを自動的に探す攻撃者も例外ではありません。そのため、本当に必要なものだけを転送し、機器を常に最新の状態に保ちましょう。詳しくは第9章(ファイアウォール)で扱います。
:::

:::tip ポイント
外部からは、NATの内側にある機器への接続を開始できません。ルーターが転送先を知らないからです。**ポートフォワーディング**は、特定の**WANポート**宛てのパケットを、特定の**LAN IP**(とLANポート)に送るよう定めます。こうして、家庭内ネットワークのサーバーがインターネットから利用できるようになります。
:::

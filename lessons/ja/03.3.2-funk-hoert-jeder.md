# 電波は誰にでも聞こえる

:::sim
url=/sims/lesson-3.3.2.btsim
:::

今、WLAN `Schule` には2台のタブレットがあります。**Anna**(`192.168.0.30`)と **Ben**(`192.168.0.31`)です。

3.1章を思い出してみよう。Anna がスイッチ経由で Ben に ping を送ったとき、Clara はそのことに気づかなかったね。スイッチは ping を Ben のポートにだけ送っていたからだ。WLAN でも同じだろうか? どう予想するか、少し考えてみよう。

## 実験

1. :fa-play: **実行**モードに切り替えて、**Anna** からスクールPCに ping を送る(`ping 192.168.0.10`)。
2. :fa-magnifying-glass: **トレース**モードに切り替えて、**+** で **Ben** のトレースを開く。ポートは `wlan0` を選ぶ。

:::quiz mc
Ben では何が見えるでしょうか?
- [ ] Anna の ARP リクエストだけ ― スイッチのときと同じ
- [x] Anna とスクールPCの間のすべてのパケット(ping も含む)
- [ ] 何も見えない。ping は Ben には関係ないから
:::

答えを確認
:::

## その仕組み

電波はあらゆる方向に広がります。そのため、Anna が送信したものは、アクセスポイントだけでなく、近くにある*すべての*デバイスに届きます。無線は**共有メディア**なのです。Ben のタブレットは、通常、自分宛てではないものをすべて無視します。しかし、傍受しようと*思えば*、誰でもすべてを読み取ることができます。

| | スイッチ(有線) | WLAN(無線) |
|---|---|---|
| ユニキャストを受け取るのは? | 受信者のポートだけ | 電波の届く範囲のすべてのデバイス |
| 第三者が盗み見できる? | 通常はできない | できる。簡単に |

:::tip ポイント
無線は**共有メディア**です。WLAN で送信されたものはすべて、電波の届く範囲にあるどのデバイスでも受信できます。だから WLAN は**暗号化**しなければなりません(現在は **WPA2** や **WPA3** を使います)。そうすれば、第三者がデータを受信できても、読み取ることはできません。
:::

:::note
BeaverTracer は WLAN の暗号化をシミュレートしません。だからここではすべてを読み取れるのです。暗号化の仕組みは8章で学びます。
:::

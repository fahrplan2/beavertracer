# トラブルシューティング：メールが届かない

:::sim
url=/sims/lesson-6.3.4.btsim
:::

Annaから連絡が来ました。「Benにメールを送れない！」 本来は次のように設定されているはずです。

| 項目 | あるべき設定 |
|---|---|
| Annaの送信メールサーバー（SMTP） | `mail.beaver-schule.de`、ポート `25` |
| `biber-mail.de` のMXレコード | `mail.biber-mail.de`（優先度 10） |

エラーを見つけて修正しましょう。そのうえでAnnaから `ben@biber-mail.de` 宛にメールを送ります。タスクでは、メールがBenのメールボックスに届いたかどうかを確認します。（メールサーバー間の転送には数秒かかることがあります。）

<details>
<summary>ヒント1：Annaのメールプログラムは何と言っている？</summary>

メールを送信してみて、**プロトコル**タブを見てみましょう。サーバーは何と応答していますか？ それはSMTPの応答らしく見えますか？
</details>

<details>
<summary>ヒント2：メールがエラーメッセージとして返ってくる？</summary>

Annaでメールを受信して、`MAILER-DAEMON` からのメッセージを読みましょう。配送はなぜ失敗したのでしょうか？ AnnaのPCで `nslookup -type=MX biber-mail.de` を実行して、DNSサーバーが担当のメールサーバーを知っているか確認しましょう。
</details>

<details>
<summary>ヒント3：どこで設定する？</summary>

送信メールサーバーは、Annaのアプリ**E-Mail**の**Einstellungen**で設定します。MXレコードは**DNSサーバー**の**MX**タブにあります。
</details>

:::task
title: メールは届いた？
メールサーバー Biber上のBenのメールボックスにメールがあるかを確認します。
check: fileExists(5, "/var/mail/ben.mbox")
:::

## 何が起きていた？

:::quiz multi
正しい記述はどれですか？
- [x] Annaの送信メールサーバーのポートが110になっていた。そこで応答するのはPOP3サービスで、SMTPではない
- [x] `biber-mail.de` のMXレコードがなかった。Mailserver Schuleは担当のメールサーバーを見つけられなかった
- [x] 配送できなかったメールが `MAILER-DAEMON` からエラーメッセージとして返ってきた
- [ ] Benのパスワードが間違っていた
:::

:::evaluate
回答を確認
:::

:::tip ポイント
メールでよくあるエラーは、メールプログラムの**サーバーやポート**の誤り（SMTPはポート25、POP3は110、IMAPは143）と、DNSの**MXレコード**の欠落や誤りです。メールサーバーがメールを配送できないと、エラーメッセージを付けて送信元に返送します（**バウンス**）。
:::

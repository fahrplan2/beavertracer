# 展望：ダイナミックルーティング

プロジェクトでは、4つの拠点のために12本のルートを手作業で登録したね。大企業のネットワークにはルーターが数百台あり、インターネットには数万台ある。しかも、どこかで回線が切れたり、新しい回線が加わったりと、状況は絶えず変化している。これを手作業でこなすのはもう無理だ。

そのため、ルーターは通常、互いにルートを自動的に交換している。そのための仕組みが**ルーティングプロトコル**だ。これを**ダイナミックルーティング**と呼ぶ。すべてを手作業で登録する**スタティックルーティング**とは対照的だ。

代表的なルーティングプロトコル：

| プロトコル | 考え方 | 主な用途 |
|---|---|---|
| **RIP** (*Routing Information Protocol*) | 各ルーターが、どのネットワークにルーター何台分（*ホップ*）で到達できるかを、定期的に隣のルーターに伝える。 | 小規模ネットワーク、学習用の例 |
| **OSPF** (*Open Shortest Path First*) | 各ルーターがネットワーク全体の構成を把握しており、そこから最短経路を自分で計算する。 | 企業ネットワーク |
| **BGP** (*Border Gateway Protocol*) | 大規模なネットワーク事業者（例：インターネットサービスプロバイダー）が、到達可能なネットワークを互いに知らせ合う。 | 事業者間をつなぐインターネット |

:::quiz match
RIP -> ルーターが、ネットワークまで何ホップで到達できるかを隣のルーターに知らせる
OSPF -> 各ルーターがネットワーク構成図全体を把握し、最短経路を計算する
BGP -> 大手インターネットプロバイダーのネットワーク同士をつなぐ
:::

:::tip ポイント
**スタティックルーティング**では、管理者がすべてのルートを手作業で登録する。**ダイナミックルーティング**では、ルーターが RIP、OSPF、BGP などの**ルーティングプロトコル**を使ってルートを自動的に交換し、接続が切れたときには自分で経路を調整する。
:::

:::note
BeaverTracer では RIP、OSPF、BGP をシミュレートできる。ルーターの同名のタブで確認できるよ。このコースでは展望として触れるだけにとどめる。
:::

## 背景にある仕組み

ホームルーターは、インターネットへ向かうすべてのパケットについて、プライベートな送信元アドレスを自分自身の**パブリックな WAN アドレス**に置き換えます。たいていは送信元ポートも置き換えます。Webサーバーからは、リクエストがホームルーターから来たように見えます。応答が戻ってくると、ホームルーターはアドレスを元に戻し、パケットを PC に転送します。

こうして、家庭内ネットワーク全体が 1 つのパブリックアドレスでインターネットに接続できます。そして、インターネット上の機器にはプライベートアドレスが見えることはありません。

## インターネットへの経路

**PC** で :fa-terminal: **ターミナル**に次のように入力します。

```
$ traceroute 192.0.2.80
```

:::quiz short
PC と Webサーバーの間には、ルーターがいくつありますか?(最後の行より前のすべての行を数えます。)
= 4
= 四つ
= 4つ
= 4台
:::

:::quiz mc
`traceroute` は、1台目のルーターのアドレスとして何を表示しますか?
- [x] `192.168.178.1` — ホームルーターの LAN アドレス
- [ ] `203.0.113.2` — ホームルーターの WAN アドレス
- [ ] `203.0.113.1` — プロバイダの最初のルーター
:::

:::

:::tip ポイント
**NAT**(*Network Address Translation*)は、インターネットへ向かうときに、機器の**プライベート**な送信元アドレスをルーターの**パブリックな WAN アドレス**に置き換え、応答のときはその逆を行います。これにより、家庭内ネットワークのすべての機器が**1つ**のパブリック IPv4 アドレスを共有します。アドレスを節約でき、プライベートアドレスをインターネットから隠せます。
:::

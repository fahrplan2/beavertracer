# 家庭内ネットワーク：ルーターとNAT

:::goal
**学習目標:** ホームルーターの役割を挙げ、ホームルーターを設定し、NATによって多数の機器が1つのパブリックアドレスでインターネットに接続できる仕組みを説明し、ポートフォワーディングを設定して確認できるようになる。
:::

:::

url=/sims/lesson-7.1.btsim

家庭では、スマートフォン、ノートPC、テレビ、ゲーム機、スピーカーなど、気づけば10台以上の機器がネットワークにつながっています。どの機器にも `192.168.178.20` のようなアドレスが割り当てられます。これはインターネット上では転送されない**プライベート**範囲のアドレスです(4.2.2章)。それでも、これらの機器はどれもインターネットにつながります。

それを可能にしているのが、目立たない小さな箱、**ホームルーター**です。ワークスペースの左側には、PCとタブレットがある家庭内ネットワークが、右側には「インターネット」が表示されています。プロバイダーのルーター、DNSサーバー、そしてWebサーバー `www.beispiel.de` です。

:::note
この章で使うパブリックアドレス(`203.0.113.…`、`198.51.100.…`、`192.0.2.…`)は、例や教材用に予約されています。IPv6の `2001:db8::` と同じです。
:::

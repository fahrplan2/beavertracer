# NAT: 多数のデバイス、1つのアドレス

:::goal
**学習目標:** トレースで、NATが送信元アドレスをどのように置き換えるかを示し、NATテーブルを読み取り、なぜ外部から家庭内ネットワークへの接続にはポートフォワーディングが必要なのかを説明できる。
:::

:::sim
url=/sims/lesson-7.1.btsim
:::

プロバイダーは、通常、家庭の回線に対して公開IPv4アドレスを**1つ**しか割り当てません。それがホームルーターのWANアドレスです。家庭内ネットワークのすべてのデバイスは、このアドレスを共有しなければなりません。この仕組みを**NAT**(*Network Address Translation*、アドレス変換)と呼びます。

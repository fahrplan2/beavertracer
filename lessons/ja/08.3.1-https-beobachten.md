# HTTPとHTTPSの比較

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Webサーバー **www.beaver-schule.de** は、学校の成績ポータルをHTTPとHTTPSの両方で提供しています。盗聴者には何が見えるでしょうか?

## 実験

1. :fa-play: **実行**モードに切り替え、**Client-PC** の :fa-globe: **ブラウザ**で、まず `http://www.beaver-schule.de/` を開き、次に `https://www.beaver-schule.de/` を開きます。
2. :fa-magnifying-glass: **トレース**モードで、**Client-PC** のトレースを開きます。
3. まず `HTTP/1.1 200 OK` のパケットを探してクリックします。下の詳細に、ページの内容が表示されます。

:::quiz mc
**HTTP** の場合、盗聴者は何を見ることができますか?
- [x] Webページ全体。Annaの成績も含まれる
- [ ] サーバーのアドレスだけ
- [ ] 何も見えない。HTTPはTCP上で動作しているから
:::

:::quiz short
Annaの数学の成績は何点ですか?
= 2
:::

:::evaluate
回答を確認
:::

次はHTTPSの部分です。クライアントが2つ目の接続を開始する `[SYN]` パケットを探しましょう。

:::quiz short
HTTPS接続の宛先ポートは何番ですか(**Info** 列の `… → ???`)?
= 443
:::

次に、トレース上部のフィルター欄に `tls` と入力します。すると、TLSパケットだけが表示されます。

:::quiz mc
Webページを含むパケットの **Info** 列には何と表示されていますか?
- [ ] `HTTP/1.1 200 OK`
- [x] `Application Data`
- [ ] `Encrypted HTML`
:::

:::quiz multi
**HTTPS** でも、盗聴者にはまだ何が見えますか?
- [x] クライアントとサーバーのIPアドレス
- [x] ポート443が使われていること(つまりおそらくHTTPSであること)
- [x] おおよそどれくらいのデータ量が転送されているか
- [ ] どのページが開かれ、そこに何が書かれているか
:::

:::evaluate
回答を確認
:::

:::note
**Application Data** パケットをクリックしてみましょう。ペイロードは、一見ランダムに見えるバイト列にすぎません。トレーサーはこれを復号できません。セッション鍵を知らないのは、攻撃者と同じだからです。
:::

:::tip ポイント
**HTTP** では、盗聴者はWebページ全体を読むことができます。**HTTPS** では、**誰と誰が**通信しているか(IPアドレス、ポート443)と、**どれくらい**のデータ量かしか見えません。内容は暗号化されて **Application Data** パケットの中に入っています。
:::

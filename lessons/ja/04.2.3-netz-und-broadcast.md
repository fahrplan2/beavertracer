# ネットワークアドレス、ブロードキャストアドレス、ホスト

どのネットワークでも、2つのアドレスには特別な役割があります。

- **ネットワークアドレス**は、ネットワークの**最も小さい**アドレスです。ホスト部のビットがすべて0になります。ネットワーク全体を表し、たとえばルーティングテーブルで使われます。
- **ブロードキャストアドレス**は、ネットワークの**最も大きい**アドレスです。ホスト部のビットがすべて1になります。このアドレス宛に送られたものは、ネットワーク内のすべての機器に届きます。

この2つのアドレスは機器に**割り当てられません**。その間のアドレスはすべて、機器(**ホスト**)に使えます。

## 簡単な例

`192.168.0.12/24` — ホスト部は最後のオクテットです。

| | アドレス |
|---|---|
| ネットワークアドレス(ホスト部 = 0) | `192.168.0.0` |
| ブロードキャストアドレス(ホスト部 = 255) | `192.168.0.255` |
| ホストに使える範囲 | `192.168.0.1` – `192.168.0.254` |
| ホスト数 | 254 |

## 境界がオクテットの途中にある場合

プレフィックス長が8の倍数でないと、少し難しくなります。その場合は、該当するオクテットを2進数に変換して考えます。例: `194.9.190.12/27`。

最初の3つのオクテットは完全に[[n|ネットワーク部]](24ビット)に属します。最後のオクテットのうち**3ビット**もネットワーク部に属し(24 + 3 = 27)、残りの**5ビット**が[[h|ホスト部]]になります。

| | 最後のオクテット(2進数) | 10進数 |
|---|---|---|
| IPアドレス | [[n|000]][[h|01100]] | 12 |
| サブネットマスク(`/27`) | [[n|111]][[h|00000]] | 224 |
| ネットワークアドレス: ホストビットをすべて0に | [[n|000]][[h|00000]] | **0** |
| ブロードキャストアドレス: ホストビットをすべて1に | [[n|000]][[h|11111]] | **31** |

結果:

- ネットワークアドレス: `194.9.190.0`
- ブロードキャストアドレス: `194.9.190.31`
- ホストに使える範囲: `194.9.190.1` – `194.9.190.30`
- ホスト数: 2⁵ − 2 = **30**

:::tip ポイント
**ネットワークアドレス:** ホストビットをすべて0にしたもの(最も小さいアドレス)。**ブロードキャストアドレス:** ホストビットをすべて1にしたもの(最も大きいアドレス)。どちらも機器には割り当てられません。プレフィックス長が *n* のネットワークでは、ホストに使えるアドレスは **2<sup>32 − n</sup> − 2** 個です。
:::

:::tip ヒント: ブロックサイズ
2進数での手順が理解できたら、近道があります。**256からマスクのオクテットを引く**と、そのオクテットにおけるネットワークの大きさが求まります。`/27`(マスク224)なら 256 − 224 = **32** です。ネットワークは0、32、64、96 … から始まります。アドレス `.12` は `.0` から始まるネットワークに、アドレス `.70` は `.64` から始まるネットワークに属します。
:::

## 主なネットワークサイズ

| プレフィックス | サブネットマスク | ホスト数 |
|---|---|---|
| `/8` | `255.0.0.0` | 16 777 214 |
| `/16` | `255.255.0.0` | 65 534 |
| `/24` | `255.255.255.0` | 254 |
| `/25` | `255.255.255.128` | 126 |
| `/26` | `255.255.255.192` | 62 |
| `/27` | `255.255.255.224` | 30 |
| `/28` | `255.255.255.240` | 14 |
| `/29` | `255.255.255.248` | 6 |
| `/30` | `255.255.255.252` | 2 |

:::note
実務でよく使われる最小のネットワークは `/30` です。使えるアドレスはちょうど2つで、2台のルーター間の接続によく使われます。`/32` は単一のアドレスを表します。ネットワークとしては使えませんが、ルーティングテーブルやファイアウォールのルールには登場します。
:::

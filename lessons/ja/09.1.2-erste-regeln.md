# 最初のルール作成

:::sim
url=/sims/lesson-9.btsim
:::

今度はあなたの番です。Firewall は今のところ、すべての通信を通してしまいます。インターネットから到達できるのは、スクールサーバーの **ウェブサイト (80)** と **メール受信 (25)** だけになるように設定しましょう。**SSH (22)**、**POP3 (110)**、**IMAP (143)** は、インターネットから到達できないようにします。

## ルールを登録する

1. **Firewall** をクリックします。デフォルトポリシーは、まず **すべて許可** のままにしておきます。
2. 既存のルールを削除します(どのみちすべてを許可するルールです)。そのうえで **+ ルールを追加** を使い、閉じたいポートごとにルールを1つずつ作成します。
    - **方向** A → B(インターネットから)
    - **プロトコル** TCP
    - **宛先ポート** 例: `22`
    - **アクション** 破棄
3. **Internet-PC** から `nmap 198.51.100.10` を実行し、正しいポートだけが開いているかを確認します。

:::task
title: 外部からはウェブとメールだけ?
Schulserver がインターネットからポート 80 と 25 でのみ到達可能になっているか、そして Lehrer-PC がこれまでどおりメールを取得し、インターネットを閲覧できるかを確認します。そのため、シミュレーションを実行モードで動かしておく必要があります。
check: tcpOpen(1, "198.51.100.10", 80)
check: tcpOpen(1, "198.51.100.10", 25)
check: tcpFails(1, "198.51.100.10", 22)
check: tcpFails(1, "198.51.100.10", 110)
check: tcpFails(1, "198.51.100.10", 143)
check: tcpOpen(8, "198.51.100.10", 110)
check: tcpOpen(8, "203.0.113.80", 80)
:::

:::quiz mc
Lehrer-PC は、これまでどおり POP3 (110) で Schulserver からメールを取得できます。Firewall が Lehrer-PC の邪魔をしないのはなぜでしょうか?
- [ ] Firewall が教師を見分けているから
- [x] Lehrer-PC のパケットはそもそも Firewall を通過しないから。Lehrer-PC と Schulserver は、Firewall の内側にある同じスイッチにつながっている
- [ ] POP3 は安全なプロトコルだから
:::

:::evaluate
回答を確認
:::

:::note
Firewall が守るのは、**Firewall を通過して**流れる通信だけです。学校のネットワーク内部で起きていることは、Firewall からは見えません。そのため、学校のネットワーク内で感染したコンピューターが Schulserver を攻撃することは、依然として可能です。この点については DMZ の節で扱います。
:::

:::tip ポイント
外部から到達できないようにしたいサービスごとに、**方向**、**プロトコル**、**宛先ポート**を指定したルールでアクセスを遮断します。ルールが効いているかどうかは、外部から**ポートスキャン**で確認します。
:::

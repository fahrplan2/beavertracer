# 暗号の基礎

**暗号技術**(クリプトグラフィー)は、暗号化に関する学問です。始める前に、この章で繰り返し出てくる用語をいくつか確認しておきましょう。

| 用語 | 意味 |
|---|---|
| **平文** | 読むことができるメッセージ。例:`Treffen um 10 Uhr` |
| **暗号文** | 暗号化されたメッセージ。例:`Wuhiihq xp 10 Xku` |
| **暗号化** | 平文 → 暗号文 |
| **復号** | 暗号文 → 平文 |
| **方式**(*アルゴリズム*) | 暗号化の際に使う計算手順 |
| **鍵** | 方式が必要とする、秘密の追加情報 |

## 秘密なのは方式ではなく鍵

方式を知っている人が少ないほど安全だ、と思うかもしれません。しかし、実際はその逆です。現在使われているほとんどの方式は**公開**されており、世界中の専門家が長年にわたって弱点がないかを検証してきました。秘密のままにするのは**鍵**だけです。

この原則は、オランダ人のオーギュスト・ケルクホフスが1883年にすでに提唱しています。利点は、鍵が漏れてしまっても、方式全体ではなく鍵を交換するだけで済むことです。

2. **公開鍵暗号** — 公開鍵と秘密鍵
3. **ハッシュ値** — データの指紋
4. **デジタル署名** — 電子的な署名

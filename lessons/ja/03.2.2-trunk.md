# 2台のスイッチをまたぐVLAN: トランク

:::sim
url=/sims/lesson-3.2.2.btsim
:::

学校には2つのフロアがあり、それぞれにスイッチが1台ずつあります。2台は **ポート8** のケーブルで接続されています。

| スイッチ | ポート1 (VLAN 10、管理) | ポート2 (VLAN 20、コンピューター室) |
|---|---|---|
| **Switch EG** (1階) | Sekretariat `192.168.0.10` | Anna `192.168.0.20` |
| **Switch OG** (2階) | Schulleitung `192.168.0.11` | Ben `192.168.0.21` |

PC側ポートのVLANは、すでに設定済みです。

## 問題

:fa-play: **実行**モードに切り替えて、**Anna** から Ben に ping を送ってみましょう (`ping 192.168.0.21`)。2台とも VLAN 20 に属しているのに、応答は返ってきません。

どちらかのスイッチの **VLAN** タブで、**port 8** の行を見てください。まだ `untagged` で、PVID は `1` のままです。つまり、このケーブルを通るのは VLAN 1 だけで、VLAN 10 も VLAN 20 も通りません。

ところが、スイッチ間のケーブルには、*両方の* VLAN のフレームを通す必要があります。そのためスイッチは、すべてのフレームに VLAN ID を書いた小さな札を貼り付けます。これが **VLANタグ** です。こうすることで、反対側のスイッチは、そのフレームがどの VLAN に属するのかを判断できます。

## トランクを設定する

これを**両方の**スイッチで行います。

1. スイッチをクリックして、**VLAN** タブを開きます。
2. **port 8** の行で、**モード**を `tagged` にし、**許可されたVLAN** に `10,20` を入力します。
3. **適用** をクリックします。

そのあと、もう一度 **Anna** から Ben に ping を送ります。比較のため、Schulleitung にも送ってみましょう (`ping 192.168.0.11`)。

:::quiz mc
今、何が起こるでしょうか?
- [x] Anna は Ben には届くが、Schulleitung には届かない
- [ ] Anna は Ben にも Schulleitung にも届く
- [ ] Anna は引き続きどこにも届かない
:::

:::evaluate
答えを確認
:::

## トレースで見る VLAN タグ

:the magnifying glass: 

:fa-magnifying-glass: **トレース**モードに切り替え、**+** で **Switch EG** のポート **8** のトレースを開きます。これがスイッチ間のケーブルです。Anna の ping (`Echo (ping) request`) の1つをクリックします。

プロトコルツリーの Ethernet のすぐ下に、新しい行 **802.1Q Virtual LAN** が現れています。これが VLAN タグです。

:::quiz short
Anna の ping のタグには、どの VLAN ID が入っていますか?
= 20
:::

比較のため、**Ben** (`eth0`) のトレースを開き、同じ ping をクリックしてみましょう。

:::quiz mc
Ben 側では何に気づきますか?
- [ ] 同じ ID 20 のタグがある
- [x] 802.1Q の行がない。スイッチが Ben のポートの手前でタグを再び取り除いたため
- [ ] Ben には ping がまったく届かない
:::

:::evaluate
答えを確認
:::

:::tip ポイント
**トランク**とは、複数の VLAN のフレームが通る接続のことで、通常は2台のスイッチの間に設けます。そのために、各フレームには VLAN ID を持つ **VLANタグ** が付けられます (規格は **IEEE 802.1Q**)。このようなポートは **tagged** と呼ばれます。**untagged** ポートには通常の機器を接続します。スイッチは、フレームをそこへ送る前にタグを取り除きます。
:::

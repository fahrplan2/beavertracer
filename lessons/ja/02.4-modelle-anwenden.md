# モデルを応用する

この章の冒頭の実験で登場したプロトコルを、それぞれが属するOSI参照モデルの層に対応づけましょう。

:::quiz match
Ethernet -> 第2層 — データリンク
IPv4 -> 第3層 — ネットワーク
TCP -> 第4層 — トランスポート
HTTP -> 第7層 — アプリケーション
:::

:::evaluate
対応を確認
:::

最後に、データ単位の名前も対応づけましょう。

:::quiz match
フレーム -> 第2層 — データリンク
パケット -> 第3層 — ネットワーク
セグメント -> 第4層 — トランスポート
:::

:::evaluate
対応を確認
:::

これで、プロトコルをきちんと分類するための道具がそろいました。次の章からは、各層を順番に見ていきます。最初は第2層から始めて、スイッチはパケットをどこへ転送すればよいのかをどうやって知るのか、という疑問を取り上げます。

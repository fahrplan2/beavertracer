# まとめと今後の展望

## さまざまな場所にあるファイアウォール

この章で学んだパケットフィルタは、多くの機器の中にも入っています。

- **ホームルーター:** ホームルーターはどれもステートフルファイアウォールでもあります。IPv4 では NAT がその役割の一部を担います。ポートフォワーディングがない限り、外部からは誰も接続を開始できません(第7章)。IPv6 ではすべての機器がグローバルアドレスを持つため、「外部からの新規接続は通さない」というファイアウォールのルールだけで同じ保護を実現します。
- **パーソナルファイアウォール:** Windows、macOS、Linux には、パソコン自体に組み込まれたファイアウォールがあります。たとえばカフェの Wi-Fi のような他人のネットワークの中でも機器を守り、プログラムごとにルールを設定できます。
- **次世代ファイアウォール(NGFW)**と**Web アプリケーションファイアウォール(WAF)**: アドレスやポートだけでなく、パケットの中身をアプリケーション層まで調べます。これにより、たとえば HTTP リクエストに含まれる攻撃を検知できます。HTTPS の場合は、そのために暗号化を解除する必要があります(第8章)。
- **IDS/IPS:** *侵入検知システム(Intrusion Detection System)*は、通信の中の疑わしいパターンを検知して警告を出します。*侵入防止システム(Intrusion Prevention System)*は、それに加えて自らその通信をブロックします。

:::note
ファイアウォールはセキュリティの要素の**ひとつ**にすぎません。許可されたサービス(たとえば Web サーバー)自体に脆弱性がある場合、誰かがメールで届いた悪意のあるプログラムを開いてしまった場合、パスワードが弱い場合には、ファイアウォールは役に立ちません。だから、アップデート、安全なパスワード、暗号化、そしてネットワークの賢い分割(DMZ、第3章の VLAN)は常に欠かせません。
:::

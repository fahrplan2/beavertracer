# ルーター

:::goal
**学習目標:** ルーターが2つのネットワークをどのようにつなぐのかを説明できる。PCのゲートウェイを設定できる。PCがパケットを直接届ける場合とゲートウェイ経由で届ける場合を、理由を挙げて説明できる。
:::

:::sim
url=/sims/lesson-4.3.1.btsim
:::

**ルーター**は、異なるネットワーク同士をつなぎます。そのために、ネットワークごとに専用のポートを持ち、各ポートには、そのネットワークに属する固有のIPアドレスが割り当てられます。ワークスペースには、またFirma AとFirma Bが表示されていますが、今回はその間にルーターがあります。

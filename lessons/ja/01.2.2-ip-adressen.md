# IP アドレスの割り当て

:::sim
url=/sims/lesson-1.2.2.btsim
:::

2台のデバイスが通信するには、同じネットワーク内の IP アドレスが必要です。ワークスペースには、接続された2台の PC が表示されています。先ほど自分で組み立てたものと同じ構成です。

1. :fa-play: **実行**モードに切り替えて、**Computer 1** をクリックして開きます。
2. そこで :fa-gear: **IP設定**を開きます。新しい PC には、すでにアドレス `192.168.0.10` とサブネットマスク `/24` が設定されています。このままで大丈夫です。
3. 次に **Computer 2** を開きます。こちらにも*同じ*アドレス `192.168.0.10` が設定されています。ネットワーク内で同じアドレスは1つしか使えないため、これでは通信できません。アドレスを `192.168.0.11`（サブネットマスク `/24`）に変更しましょう。

:::tip ポイント
**IP アドレス**（例: `192.168.0.10`）は、ネットワーク上のデバイスのアドレスです。家の番地のようなものだと考えるとよいでしょう。同じネットワーク内で、同じ IP アドレスを使えるのは**1台だけ**です。
:::

:::task
title: アドレスを正しく割り当てられた？
実行モードのまま、2台の PC に適切なアドレスが設定され、互いに通信できるかを確認しましょう。
check: ip(1, "192.168.0.10/32")
check: ip(3, "192.168.0.11/32")
check: pingOk(1, 3)
:::

:::note
`/24` が具体的に何を意味するのか、またネットワークをどのように適切に分割するのかについては、第4章で詳しく扱います。今のところは、両方のアドレスが `192.168.0.` で始まっていて、重複していないことが大事だと覚えておいてください。
:::

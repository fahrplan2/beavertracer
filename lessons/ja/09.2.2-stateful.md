# ステートフルファイアウォール

:::sim
url=/sims/lesson-9.2.btsim
:::

**ステートフル**(*stateful*)ファイアウォールは、一度許可した接続をすべて**ステートテーブル**に記憶します。記録するのは、プロトコル、双方のアドレス、双方のポートです。エントリに一致するパケットが届けば、どちらの方向であっても、それ以上のチェックなしで通過させます。一方、新しい接続はルールを通過しなければなりません。

## 観察する

1. **Firewall** で **Modus** を **Stateful** に設定します。
2. **Lehrer-PC** の :fa-globe: **ブラウザ** で、もう一度 `http://203.0.113.80/` を開きます。
3. すぐにファイアウォールの **Zustände** タブを開きます。

:::quiz mc
このとき何が起こるでしょうか?
- [x] ページが読み込まれ、**Zustände** に Lehrer-PC から `203.0.113.80:80` への接続が表示される
- [ ] 応答に対するルールがまだないので、ページが読み込まれない
:::

:::quiz short
ステートテーブルの**宛先**には、どのポートが表示されていますか?
= 80
:::

:::evaluate
回答を確認
:::

**Zustände** のエントリは、その接続で何も通信が行われなくなると、しばらくして消えます(**Timeout** 列)。

## タスク: 学校のファイアウォール

実際の学校で必要とされるように、ファイアウォールを設定しましょう。

- **学校ネットワークから**は、インターネットへのすべての通信を許可します(方向 B → A、任意のプロトコル)。
- **インターネットから**は、学校サーバーのWeb(80)とメール受信(25)だけにアクセスできるようにします。
- それ以外はすべて**破棄**し、モードは **Stateful** にします。

:::task
title: 学校のファイアウォールを設定できましたか?
学校ネットワークからインターネットに接続できるか、外部から学校サーバーのWebとメールだけにアクセスできるか、そして外部から Lehrer-PC にアクセスできないかを確認します。
check: tcpOpen(8, "203.0.113.80", 80)
check: tcpOpen(1, "198.51.100.10", 80)
check: tcpOpen(1, "198.51.100.10", 25)
check: tcpFails(1, "198.51.100.10", 22)
check: pingFails(1, 8)
:::

:::quiz mc
Lehrer-PC が `203.0.113.80` に ping を送ります。応答は戻ってくるでしょうか?
- [x] はい。ping は B → A で許可されており、その応答はこの接続状態に属しているから
- [ ] いいえ。外部からの ICMP にはルールがないから
:::

:::evaluate
回答を確認
:::

:::tip ポイント
**ステートフルファイアウォール**は、許可した接続をすべて**ステートテーブル**に登録し、その接続のパケットを**双方向**で通過させます。そのため、**接続確立**に対するルールだけで足ります。たとえば「内側から外側へは許可」「外側からは特定のサービスにのみ許可」といった具合です。外側から開始された学校ネットワークへの接続は、引き続きブロックされます。
:::

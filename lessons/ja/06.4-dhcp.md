# DHCP: 自動でネットワークに参加する

:::goal
**学習目標:** DHCPによってデバイスが自動的にIP設定を取得する仕組みを説明でき、DHCPサーバーを設定でき、典型的なDHCPの障害（例：169.254のアドレス）を見つけて解決できる。
:::

:::sim
url=/sims/lesson-6.4.btsim
:::

これまでは、各デバイスのIPアドレス、サブネットマスク、ゲートウェイ、DNSサーバーを手作業で入力してきました。何百台ものノートPC、タブレット、スマートフォンがある学校では、それは不可能ですし、入力ミスが1つあるだけでネットワークの障害になります。

この作業を引き受けてくれるのが**Dynamic Host Configuration Protocol**（**DHCP**）です。**DHCPサーバー**が、ネットワークに参加するすべてのデバイスに設定を自動的に配布します。

# タブレットをWi-Fiにつなぐ

:::sim
url=/sims/lesson-3.3.1.btsim
:::

スイッチには **Schul-PC** (`192.168.0.10`) と **アクセスポイント** がつながっています。タブレットの **Anna** (`192.168.0.30`) を学校のWi-Fiに接続しましょう。

## Wi-Fiを見つける

:fa-play: **実行**モードに切り替えて、**アクセスポイント** をクリックします。ここには、そのWi-Fiの名前である **SSID** が表示されています: `Schule`。

アクセスポイントはブリッジのように動作します。無線で届いたものをケーブル経由でスイッチに中継し、逆方向も同様に中継します。これによって、AnnaとSchul-PCは同じローカルネットワークに入ります。

## タブレットを接続する

1. **Anna** をクリックし、:fa-gear: **IP設定** を開いて、**WiFi** タブを選びます。
2. **SSID** にWi-Fiの名前 `Schule` を入力し、**適用** をクリックします。
3. Anna で :fa-terminal: **ターミナル** を開き、Schul-PC に ping を送ります:
   ```
   $ ping 192.168.0.10
   ```

ping を送っている間、ワークスペースに注目してください。Annaとアクセスポイントの周りに電波が広がっていきます。

:::tip ポイント
**WLAN** (無線LAN) は、無線を使ったローカルネットワークです。**アクセスポイント** は、WLANを有線のネットワークにつなぎます。どのWLANにも **SSID** (*Service Set Identifier*) という名前があり、接続するには、デバイスが正しいSSIDを知っている必要があります。
:::

:::quiz mc
AnnaのSSIDに `schule` (小文字) と入力すると、どうなるでしょうか。
- [ ] 何も起こらない。大文字と小文字は区別されない
- [x] Annaの接続が切れる。SSIDは完全に一致していなければならない
- [ ] Annaは別のWLANに接続する
:::

:::evaluate
答えを確認
:::

:::tip 試してみよう
Annaの **WiFi** タブで `schule` と入力し、**適用** をクリックして、もう一度 Schul-PC に ping を送ってみましょう。その後、`Schule` に戻してください。
:::

:::task
title: AnnaはWi-Fiにつながっている?
Annaが正しいSSIDで接続され、Schul-PCに到達できるかを確認します。そのためには、シミュレーションが実行モードで動作している必要があります。
check: pingOk(7, 3)
:::

## 実験

1. :fa-play: **実行**モードに切り替え、**Client-PC** をクリックして :fa-globe: **ブラウザ** を開きます。`http://192.168.0.20/` にアクセスしてください。
2. ウィンドウ上部の **Zurück**（戻る）をクリックし、**シンプル TCP クライアント** を開いて `192.168.0.20`、ポート `5000` に接続します。接続は開いたままにしておきます。
3. :fa-magnifying-glass: **トレース**モードに切り替え、**Client-PC** のトレースを開いて、`[SYN]` のパケットをクリックします。**Transmission Control Protocol** を展開してください。

TCPヘッダーの一番上に、2つのポートがあります。**Source Port**（送信元ポート）と **Destination Port**（宛先ポート）です。

:::quiz table
| 接続 | 送信元ポート | 宛先ポート |
|---|---|---|
| ブラウザ → Webサーバー | {49152} | {80} |
| TCPクライアント → エコーサービス | {49153} | {5000} |
:::

:::evaluate
答えを確認
:::

## 2種類のポート

**宛先ポート — サービス:** サーバープログラムは決まったポートで接続を待ち受けます。これを、そのポートで**リッスン**している（lauschen）といいます。有名なサービスの番号は世界共通で決められており、これを**ウェルノウンポート**（0〜1023）といいます。そのため、ブラウザは問い合わせなくても、Webサーバーがポート80でリッスンしていることを知っています。

**送信元ポート — 送信元:** クライアント側のポートは、新しい接続ごとにオペレーティングシステムが高い番号の範囲から自動的に選びます（BeaverTracer では49152から）。クライアントはこのポートによって、受け取った応答が自分のどの接続に属するのかを判別します。

つまり、1つの接続は4つの情報によって一意に決まります。**両側のIPアドレスとポート**です。IPアドレスとポートの組を**ソケット**といいます。例: `192.168.0.20:80`

## サーバーを見てみよう

:fa-play: **実行**モードに戻り、**Server** で :fa-terminal: **ターミナル** を開いて、次のように入力します。

```
$ ss
```

`ss` は、そのコンピューターのすべてのソケットを表示します。`LISTEN` の行は、ポートでリッスンしているプログラムです。`ESTABLISHED` の行は確立済みの接続で、自分側のソケット（*Local Address:Port*）と相手側のソケット（*Peer Address:Port*）が表示されます。

- [ ] 443
:::

:::note
ブラウザの接続はすでに終了しています。ページの読み込み後、`FIN` で切断されました。`ss` では、しばらくの間 `TIME-WAIT` として表示されます。サーバーは、この接続の遅れて届くパケットがないかどうかを、しばらく待つためです。一方、TCPクライアントの接続は、まだ **切断** をクリックしていないので開いたままです。
:::

## 主なウェルノウンポート

| ポート | プロトコル | サービス |
|---|---|---|
| 22 | SSH | 安全なリモート管理（暗号化されたコマンドライン） |
| 25 | SMTP | メールの送信 |
| 53 | DNS | 名前をIPアドレスに変換（主にUDP） |
| 80 | HTTP | Webページ |
| 110 | POP3 | メールの受信 |
| 143 | IMAP | サーバー上でのメール管理 |
| 443 | HTTPS | 暗号化されたWebページ |

:::tip ポイント
**ポート**（0〜65535）は、1台のコンピューター上の接続を区別します。サーバーのサービスは決まった**ウェルノウンポート**（例: HTTP 80、HTTPS 443）で**リッスン**し、クライアントは接続ごとに空いている高い番号の**送信元ポート**を割り当てられます。1つの接続は、**両側のIPアドレスとポート**によって一意に決まります。
:::

:::quiz match
22 -> SSH
25 -> SMTP
53 -> DNS
80 -> HTTP
110 -> POP3
143 -> IMAP
443 -> HTTPS
:::

# ステートレスとステートフル

接続は常に**2つの方向**から成り立っています。教師用PCがインターネット上のWebサーバーにリクエストを送り、Webサーバーがウェブページを返します。ホワイトリスト方式のファイアウォールは、リクエストを通すだけでなく、**応答**も通す必要があります。

そのためにパケットフィルターには2つの種類があります。

| | **ステートレス**（*stateless*） | **ステートフル**（*stateful*） |
|---|---|---|
| 動作方式 | 記憶を持たず、パケットを1つずつ個別に検査する | 許可された接続を**ステートテーブル**に記憶する |
| 応答 | 戻り方向用の専用ルールが必要 | 既知の接続に属しているため、自動的に通される |
| 用途 | 簡易的な機器、非常に高速なフィルター | 現在のほぼすべてのファイアウォール |

次の2つのセクションでは、ステートレスフィルターが応答の扱いでなぜ問題を抱えるのか、そしてステートフルファイアウォールがそれをどのように解決するのかを体験します。

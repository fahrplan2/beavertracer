# 複数のPCをスイッチに接続する

:::sim
url=/sims/lesson-3.1.1.btsim
:::

ワークスペースには、スイッチ1台とPC3台(**Anna**、**Ben**、**Clara**)があります。IPアドレスはすでに設定済みです(`192.168.0.10`、`.11`、`.12`)。足りないのはケーブルだけです。

## 配線する

1. :fa-pencil: **編集**モードに切り替えて、:fa-link: **Verbindung** ツールを選びます。
2. **Anna** をクリックし、続けて **Switch** をクリックします。スイッチのポート(1〜8)の選択肢が表示されるので、**1** を選びます。
3. もう一度 :fa-link: を選び、**Ben** をポート **2** に、**Clara** をポート **3** に接続します。

各ケーブルに小さな番号が表示されます。これは、そのケーブルが差さっているスイッチ側のポート番号です。

:::tip ポイント
**スイッチ**は、たくさんの接続口(**ポート**)を持つ中継装置です。1台のスイッチにつながっているすべての機器が、まとめて**ローカルネットワーク**(英語では *Local Area Network*、**LAN**)を構成します。
:::

## テストする

:fa-play: **実行**モードに切り替え、**Anna** で :fa-terminal: **ターミナル**を開いて Clara に ping を送ります。

```
$ ping 192.168.0.12
```

:::task
title: 3台すべてつながった?
3台のPCがお互いに通信できるか確認しましょう。そのためには、シミュレーションが実行モードで動いている必要があります。
check: pingOk(3, 5)
check: pingOk(3, 7)
check: pingOk(5, 7)
:::

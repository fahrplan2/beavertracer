# 静的ルートを登録する

:::sim
url=/sims/lesson-4.5.2.btsim
:::

今回は、会社Aと会社Bの間に**2台**のルーターがあります。2台は専用の小さなネットワーク、**中継ネットワーク** `10.0.0.0/30` で接続されています。

| ルーター | インターフェース | IPアドレス | ネットワーク |
|---|---|---|---|
| Router A | `eth0` | `192.168.0.1/24` | 会社A (Anna) |
| Router A | `eth1` | `10.0.0.1/30` | 中継ネットワーク |
| Router B | `eth0` | `10.0.0.2/30` | 中継ネットワーク |
| Router B | `eth1` | `172.16.0.1/24` | 会社B (Clara) |

:::note
`/30` のネットワークで使えるアドレスはちょうど2つです。ルーター2台をつなぐのに最適です (4.2.3節を参照)。
:::

## 問題

:fa-play: **実行**モードに切り替えて、**Anna** から Clara に ping を送ってみましょう (`ping 172.16.0.10`)。Clara からは応答がなく、代わりに Router A (`192.168.0.1`) から「ターゲットネットワークに到達できません」と通知されます。

**Router A** の**ルーティングテーブル IPv4** を見てみましょう。

:::quiz mc
Anna の ping が Clara に届かないのはなぜですか?
- [ ] Anna にゲートウェイが登録されていない
- [x] Router A はネットワーク `172.16.0.0/24` を知らない。このネットワークは Router A に直接接続されておらず、そこへ向かうルートもない
- [ ] 中継ネットワークが小さすぎる
:::

:::evaluate
答えを確認
:::

## ルートを登録する

Router A に次のことを教える必要があります。`172.16.0.0/24` 宛てのパケットは、`eth1` を通して Router B (`10.0.0.2`) に渡します。

1. **Router A** の**ルーティングテーブル IPv4** タブを開き、**+ 追加** をクリックします。
2. 新しい行に次のように入力します。**宛先** `172.16.0.0`、**サブネットマスク** `255.255.255.0`、**次ホップ** `10.0.0.2`、**Iface** `eth1`。
3. チェックマーク :fa-check: で行を確定します。**ソース**の列に**静的**と表示されます。

もう一度 Clara に ping を送ってみましょう。今度は応答が返ってきます。

:::note
ちなみに、Router B は会社Aへの戻り道をすでに知っています。Router B のルーティングテーブルには、`10.0.0.1` を経由する `192.168.0.0/24` 宛ての静的ルートが最初から登録されています。この戻り道がなぜ同じくらい重要なのかは、次のページで分かります。
:::

## 経路をたどる: traceroute

`traceroute` を使うと、パケットがどのルーターを通るかを表示できます。**Anna** で次のように入力しましょう。

```
$ traceroute 172.16.0.10
```

:::quiz short
Anna から Clara までのパケットは、何台のルーターを通りますか?
= 2
= 2台
= 二台
:::

:::quiz mc
`traceroute` は Router B のアドレスとしてどれを表示しますか?
- [x] `10.0.0.2` — 中継ネットワーク上の Router B のアドレスで、パケットはこちらから入ってくる
- [ ] `172.16.0.1` — 会社B側の Router B のアドレス
- [ ] `192.168.0.1`
:::

:::evaluate
答えを確認
:::

`traceroute` は、4.3.1節の **Time to Live** を利用した工夫で経路を調べます。まず TTL 1 のパケットを送ります。最初のルーターが 1 を引くと 0 になるので、パケットを破棄し、そのことを送信元に通知します。これで Anna は最初のルーターが分かります。次に 2 番目のルーターのために TTL 2 で送り、これを宛先が応答するまで繰り返します。

:::tip ポイント
**静的ルート**は、管理者が手作業で登録します。登録する項目は、宛先ネットワーク、サブネットマスク、次ホップ、インターフェースです。**traceroute** を使うと、パケットの経路をルーターごとにたどれます。
:::

:::task
title: ルートを登録できましたか?
Router A に会社Bへのルートがあり、Anna が Clara に到達できるかを確認します。そのためには、シミュレーションを実行モードで動かしておく必要があります。
check: hasRoute(3, "172.16.0.0/24")
check: pingOk(9, 11)
:::

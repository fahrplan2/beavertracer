# DNS: 数字ではなく名前で

:::goal
**学習目標:** DNSがどのように名前をIPアドレスに変換するのか、名前がどのように階層的に構成されているのかを説明でき、自分でレコードを作成して、よくあるDNSの障害を見つけられる。
:::

:::sim
url=/sims/lesson-6.2.btsim
:::

IPアドレスを覚えられる人はほとんどいませんが、`www.beaver-schule.de` のような名前なら覚えられます。この変換を行うのが**ドメインネームシステム**(**DNS**)で、いわばインターネット全体で使われる電話帳のようなものです。

ワークスペースには、少し大きめのネットワークが表示されています。**Client-PC** と **Webserver** のほかに、4台の**DNSサーバー**があります。なぜこんなに多いのかは、次の次のページで確認します。

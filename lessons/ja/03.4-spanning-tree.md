# ネットワーク内のループとスパニングツリー

:::goal
**学習目標:** ループのあるネットワークでブロードキャストストームがどのように発生するか、またスパニングツリープロトコル(STP)が冗長性を失うことなくどのようにループを防ぐかを説明できる。
:::

:::sim
url=/sims/lesson-3.4.1.btsim
:::

ネットワーク内のケーブルが1本壊れたら、何が起こるでしょうか。すべてが1本の回線につながっていると、ネットワークの一部が切り離されてしまいます。そのため、大きなネットワークではスイッチを**複数経路で**接続することがよくあります。ワークスペース上の3台のスイッチがリングを作っているのも、その一例です。ケーブルが1本使えなくなっても、迂回路があります。

よさそうに聞こえますが、このようなリングには危険な落とし穴があります。それは次のページで学びます。

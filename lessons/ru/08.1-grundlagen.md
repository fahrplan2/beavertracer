# Основы криптографии

**Криптография** — это наука о шифровании. Прежде чем начать, познакомимся с несколькими понятиями, которые будут постоянно встречаться в этой главе:

| Понятие | Значение |
|---|---|
| **Открытый текст** | Читаемое сообщение, например `Treffen um 10 Uhr` |
| **Шифртекст** | Зашифрованное сообщение, например `Wuhiihq xp 10 Xku` |
| **Шифрование** | Открытый текст → шифртекст |
| **Расшифрование** | Шифртекст → открытый текст |
| **Метод** (*алгоритм*) | Правило вычислений, по которому выполняется шифрование |
| **Ключ** | Секретная дополнительная информация, необходимая методу |

## Метод не секретен — секретен ключ

Можно подумать, что чем меньше людей знает метод, тем он надёжнее. На самом деле всё наоборот: все распространённые сегодня методы **публично** описаны, и специалисты по всему миру годами проверяли их на уязвимости. Секретным остаётся только **ключ**.

Этот принцип сформулировал голландец Огюст Керкгоффс ещё в 1883 году. Преимущество: если ключ стал известен посторонним, достаточно просто заменить ключ, а не весь метод.

В следующих разделах ты познакомишься с четырьмя составляющими, из которых строятся защищённые соединения:

1. **Симметричное шифрование** — быстрое, но с проблемой передачи ключа
2. **Асимметричное шифрование** — открытый и закрытый ключ
3. **Хеш-значения** — отпечаток данных
4. **Цифровые подписи** — электронные подписи

В конце ты увидишь, как эти составляющие работают вместе (**гибридное шифрование**).

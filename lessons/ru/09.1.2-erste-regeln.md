# Первые собственные правила

:::sim
url=/sims/lesson-9.btsim
:::

Теперь твоя очередь. Межсетевой экран пока пропускает всё. Настрой его так, чтобы из интернета были доступны только **веб-сайт (80)** и **приём почты (25)** школьного сервера. **SSH (22)**, **POP3 (110)** и **IMAP (143)** из интернета должны стать недоступны.

## Добавление правил

1. Щёлкни по **Firewall**. Политика по умолчанию пока остаётся **Alle zulassen**.
2. Удали существующее правило (оно всё равно разрешает всё) и с помощью **+ Regel hinzufügen** создай по правилу для каждого порта, который должен быть закрыт:
    - **Richtung** A → B (из интернета)
    - **Protokoll** TCP
    - **Ziel-Port** например `22`
    - **Aktion** Verwerfen
3. С **Internet-PC** проверь командой `nmap 198.51.100.10`, что открыты только нужные порты.

:::task
title: Только веб и почта снаружи?
Проверяется, что школьный сервер из интернета доступен только на портах 80 и 25 — и что Lehrer-PC по-прежнему может получать почту и пользоваться интернетом. Для этого симуляция должна работать в режиме выполнения.
check: tcpOpen(1, "198.51.100.10", 80)
check: tcpOpen(1, "198.51.100.10", 25)
check: tcpFails(1, "198.51.100.10", 22)
check: tcpFails(1, "198.51.100.10", 110)
check: tcpFails(1, "198.51.100.10", 143)
check: tcpOpen(8, "198.51.100.10", 110)
check: tcpOpen(8, "203.0.113.80", 80)
:::

:::quiz mc
Lehrer-PC по-прежнему может получать почту с школьного сервера по POP3 (110). Почему межсетевой экран ему не мешает?
- [ ] Потому что межсетевой экран распознаёт учителей
- [x] Потому что его пакеты вообще не проходят через межсетевой экран — Lehrer-PC и школьный сервер подключены к одному коммутатору за межсетевым экраном
- [ ] Потому что POP3 — безопасный протокол
:::

:::note
Межсетевой экран защищает только трафик, который проходит **через него**. Что происходит внутри школьной сети, он не видит. Поэтому заражённый компьютер в школьной сети всё равно может атаковать школьный сервер — именно этому посвящён раздел о DMZ.
:::

:::tip Запомни
Для каждой службы, которая не должна быть доступна снаружи, доступ закрывает правило с указанием **Richtung**, **Protokoll** и **Ziel-Port**. Действуют ли правила, проверяют снаружи с помощью **сканирования портов**.
:::

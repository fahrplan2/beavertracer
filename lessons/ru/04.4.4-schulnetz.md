# Разделение школьной сети

:::sim
url=/sims/lesson-4.4.2.btsim
:::

У школы есть диапазон адресов `192.168.10.0/24`. Администрация, учительская и компьютерный класс должны получить по отдельной подсети. Это три сети, но подсети одинакового размера бывают только в количестве, равном степени двойки. Поэтому ты делишь сеть на **четыре** подсети; четвёртая остаётся в резерве (например, для будущей сети Wi-Fi).

## Шаг 1: расчёт

:::quiz table
| Дополнительные биты | Длина префикса | Маска сети |
|---|---|---|
| {2} | /{26} | {255.255.255.192} |
:::

:::quiz table
| Подсеть | Назначение | Адрес сети | Широковещательный адрес |
|---|---|---|---|
| 1 | Администрация | {192.168.10.0} | {192.168.10.63} |
| 2 | Учительская | {192.168.10.64} | {192.168.10.127} |
| 3 | Компьютерный класс | {192.168.10.128} | {192.168.10.191} |
| 4 | Резерв | {192.168.10.192} | {192.168.10.255} |
:::

:::evaluate
Проверить ответы
:::

## Шаг 2: настройка

Маршрутизатор уже настроен: в каждой подсети у него **первый используемый адрес** (`192.168.10.1`, `192.168.10.65` и `192.168.10.129`).

Теперь настрой три ПК. Каждый ПК получает **второй используемый адрес** своей подсети, соответствующую длину префикса и в качестве шлюза адрес маршрутизатора в своей подсети.

1. Перейди в :fa-play: режим выполнения (**Запустить**).
2. У **PC Verwaltung** открой :fa-gear: **Параметры IP**, введи **IP**, **длину префикса** и **шлюз** и нажми **Применить**.
3. Сделай то же самое для **PC Lehrerzimmer** и **PC Computerraum**.
4. С помощью `ping` проверь, доступны ли ПК друг для друга.

:::task
title: Школьная сеть настроена?
Проверяет адреса трёх ПК и то, доступны ли они друг для друга через маршрутизатор. Для этого симуляция должна работать в режиме выполнения.
check: ip(9, "192.168.10.2/32")
check: ip(11, "192.168.10.66/32")
check: ip(13, "192.168.10.130/32")
check: pingOk(9, 11)
check: pingOk(9, 13)
check: pingOk(11, 13)
:::

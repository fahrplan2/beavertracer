## Эксперимент

1. Перейди в режим :fa-play: **Запустить**, нажми на **Anna** и открой приложение **E-Mail**.
2. Перейди на вкладку **Создать**. В поле **An** введи `ben@biber-mail.de`, укажи тему и короткий текст и нажми **Отправить**.
3. Подожди несколько секунд — письму сначала нужно дойти от почтового сервера до почтового сервера. Затем нажми на **Ben**, открой приложение **E-Mail** и нажми **Получить**. Письмо от Анны пришло.
4. В режиме :fa-magnifying-glass: **Трассировка** открой трассу для **Mailserver Schule**.

## Что за этим стоит

Электронное письмо проходит путь в несколько этапов — похоже на обычное письмо, которое идёт через два почтовых отделения:

1. Почтовая программа Анны передаёт письмо по протоколу **SMTP** почтовому серверу Анны.
2. Mailserver Schule видит: получатель относится к **чужому домену**. С помощью **DNS** он запрашивает **MX-запись** (*Mail Exchanger*) для `biber-mail.de` и получает `mail.biber-mail.de` — а затем ещё и его IP-адрес.
3. Он доставляет письмо по протоколу **SMTP** на Mailserver Biber. Там оно попадает в почтовый ящик Бена.
4. Бен забирает его со своего почтового сервера по протоколу **IMAP** (или **POP3**).

:::seq
mode: text
Mailserver Schule -> Mailserver Biber: SMTP: MAIL FROM | anna@beaver-schule.de
Mailserver Biber -> Mailserver Schule: 250 OK
Mailserver Schule -> Mailserver Biber: SMTP: RCPT TO | ben@biber-mail.de
Mailserver Biber -> Mailserver Schule: 250 OK
Mailserver Schule -> Mailserver Biber: SMTP: DATA | само письмо
Mailserver Biber -> Mailserver Schule: 250 OK queued
:::

:::tip Запомни
**SMTP** (порт 25) **отправляет** электронные письма: от почтовой программы на собственный почтовый сервер и оттуда на почтовый сервер получателя. Какой почтовый сервер отвечает за домен, указано в **MX-записи** в DNS. **POP3** (порт 110) и **IMAP** (порт 143) служат только для **получения** писем из собственного почтового ящика.
:::

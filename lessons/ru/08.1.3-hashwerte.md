# Хеш-значения: отпечаток данных

:::sim
url=/sims/lesson-8.1.3.btsim
:::

**Хеш-функция** вычисляет из любого объёма данных — предложения, документа, целого фильма — короткую последовательность символов фиксированной длины: **хеш-значение**. Оно работает как **отпечаток пальца**: одинаковые данные всегда дают одно и то же хеш-значение, а другие данные — другое.

Сегодня наиболее распространённая хеш-функция называется **SHA-256**. Её хеш-значение всегда имеет длину 256 бит, то есть в виде шестнадцатеричного числа — 64 символа.

## Эксперимент

На **PC** в каталоге `/home` лежат три файла с небольшим договором купли-продажи. Переключись в :fa-play: режим выполнения, открой на **PC** :fa-terminal: **Терминал** и введи:

```
$ cd /home
$ cat vertrag.txt vertrag-kopie.txt vertrag-neu.txt
$ sha256sum vertrag.txt vertrag-kopie.txt vertrag-neu.txt
```

## Свойства хеш-функции

| Свойство | Значение |
|---|---|
| **фиксированная длина** | Независимо от объёма данных хеш-значение всегда имеет одну и ту же длину. |
| **детерминированность** | Одинаковые данные всегда дают одно и то же хеш-значение. |
| **лавинный эффект** | Даже малейшее изменение даёт совершенно другое хеш-значение. |
| **односторонняя функция** | По хеш-значению данные **невозможно** восстановить вычислением. |
| **стойкость к коллизиям** | Практически невозможно найти два разных файла с одинаковым хеш-значением. |

Хеш-функция — **не шифрование**: в ней нет ключа и нет расшифрования. Она служит другой цели — **целостности**.

## Для чего это нужно?

- **Проверка загрузок:** многие сайты рядом с файлом указывают его значение SHA-256. Если хеш-значение скачанного тобой файла совпадает с ним, значит, файл не был изменён по пути.
- **Хранение паролей:** хорошие сайты хранят не твой пароль, а только его хеш-значение. При входе сравнивается хеш-значение того, что ты ввёл. Если базу данных украдут, вор всё равно не узнает пароли.
- **Цифровые подписи:** вместо всего документа подписывают только его хеш-значение — подробнее об этом в следующем разделе.

:::tip Запомни
**Хеш-функция** (например, **SHA-256**) вычисляет из любых данных **хеш-значение** фиксированной длины — **отпечаток**. Даже малейшее изменение даёт совершенно другое хеш-значение, а по хеш-значению данные восстановить невозможно. Хеш-значения обеспечивают **целостность** данных.
:::

# Применение моделей

Сопоставь протоколы из эксперимента в начале главы с их уровнем модели OSI:

:::quiz match
Ethernet -> Уровень 2 — канальный
IPv4 -> Уровень 3 — сетевой
TCP -> Уровень 4 — транспортный
HTTP -> Уровень 7 — прикладной
:::

:::evaluate
Проверить соответствия
:::

И в завершение — названия единиц данных:

:::quiz match
Фрейм -> Уровень 2 — канальный
Пакет -> Уровень 3 — сетевой
Сегмент -> Уровень 4 — транспортный
:::

:::evaluate
Проверить соответствия
:::

Теперь у тебя есть инструменты, чтобы в дальнейшем правильно относить протоколы к нужному уровню. Со следующей главы мы будем разбирать уровни по порядку — начнём с уровня 2 и вопроса о том, как коммутатор на самом деле узнаёт, куда ему нужно передать пакет.

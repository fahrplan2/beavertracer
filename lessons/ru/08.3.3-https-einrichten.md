# Настройка HTTPS

:::sim
url=/sims/lesson-8.3.3.btsim
:::

Здесь мы продолжаем с того места, где закончился раздел 8.2.2: на веб-сервере **www.beaver-schule.de** находятся **Schul-CA** и выданный ею сертификат сервера, а **Client-PC** доверяет Schul-CA. Но веб-сервер пока не поддерживает HTTPS.

## До настройки

Перейди в режим выполнения :fa-play: **Запустить** и открой на **Client-PC** в :fa-globe: **Браузер** адрес `https://www.beaver-schule.de/`.

:::quiz mc
Что произойдёт?
- [x] Соединение не установится — на порту 443 нет службы, которая принимала бы соединения
- [ ] Браузер предупредит о ненадёжном сертификате
- [ ] Страница отобразится без замка
:::

:::evaluate
Проверить ответ
:::

## Включение HTTPS

1. Открой на веб-сервере **HTTP-сервер** и нажми **Остановить** — пока сервер работает, настройки изменить нельзя.
2. Перейди на вкладку **HTTPS**:
    - Поставь галочку **Включить HTTPS**, **Порт HTTPS** `443`
    - В поле **Сертификат** выбери сертификат сервера `www.beaver-schule.de` — не Schul-CA!
    - Нажми **Использовать**
3. Нажми **Запустить**.

Открой страницу на Client-PC ещё раз, теперь через `https://`. Нажми на замок и проверь издателя и срок действия.

:::task
title: HTTPS настроен?
Проверяет, может ли Client-PC получить https://www.beaver-schule.de/ без предупреждения о сертификате. Для этого симуляция должна работать в режиме выполнения.
check: httpsOk(2, "https://www.beaver-schule.de/")
:::

:::quiz mc
Почему в HTTP-сервере нельзя выбирать сертификат **Schul-CA**?
- [ ] Потому что сертификаты CA не умеют шифровать
- [x] Потому что он выдан на имя `Schul-CA`, а не на `www.beaver-schule.de` — браузер выдал бы предупреждение
- [ ] Потому что у Schul-CA нет закрытого ключа
:::

:::quiz mc
Что увидит устройство, которое **не** доверяет Schul-CA, например телефон гостя?
- [ ] Страницу как обычно, с замком
- [x] Предупреждение о сертификате, потому что оно не может проследить цепочку доверия до известного центра сертификации (CA)
- [ ] Ничего, потому что соединение будет отклонено
:::

Проверить ответы

:::note
Для общедоступных сайтов нужен сертификат от CA, которая предустановлена во всех браузерах. С 2015 года существует **Let's Encrypt** — CA, которая выдаёт такие сертификаты бесплатно и автоматически. Это одна из главных причин того, что сегодня почти все сайты используют HTTPS.
:::

:::tip Запомни
Для **HTTPS** веб-серверу нужен **сертификат сервера с закрытым ключом**, имя в котором соответствует адресу, и он должен принимать соединения на **порту 443**. Клиент доверяет сайту только тогда, когда ему известен выдавший сертификат **центр сертификации (CA)**.
:::

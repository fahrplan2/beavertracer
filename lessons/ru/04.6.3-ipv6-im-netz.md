# IPv6 в сети

К коммутатору подключены Anna, Ben и маршрутизатор. У Anna и Ben для IPv6 выбран режим **SLAAC (автоматически)** — IPv6-адрес им никто не задавал. Маршрутизатор знает префикс `2001:db8:1::/64`.

## Откуда берётся адрес?

1. Перейди в режим выполнения :fa-play: **Запустить** и подожди несколько секунд.
2. Открой на **Anna** :fa-terminal: **Терминал** и введи `ip a`.

Помимо IPv4-адреса ты увидишь две строки с `inet6`: один адрес с `scope link` и один с `scope global`.

- [x] Тот, что начинается с `fe80::` (`scope link`)
- [ ] Тот, что начинается с `2001:db8:1:` (`scope global`)
:::

- [ ] Anna придумала его сама
- [x] От маршрутизатора — он объявляет префикс в сети
- [ ] От коммутатора

Сравни **Interface ID** (последние четыре блока) с **MAC-адресом** Anna — его можно найти в самом низу окна :fa-gear: **Параметры IP**. Например, из MAC-адреса `aa:28:39:e2:41:82` получается Interface ID `a828:39ff:fee2:4182`: посередине вставляется `ff:fe`, а один бит в начале инвертируется (поэтому из `aa` получается `a8`).

Этот способ называется **SLAAC** (*Stateless Address Autoconfiguration*): маршрутизатор объявляет префикс, а Interface ID каждое устройство формирует само.

:::note
Поскольку MAC-адрес однозначно идентифицирует устройство, по Interface ID его можно было бы узнать в любой точке интернета. Поэтому настоящие устройства обычно дополнительно используют случайные Interface ID, которые регулярно меняются (*Privacy Extensions*) — это небольшая защита персональных данных.
:::

## Поиск соседей — без ARP

1. Введи на **Ben** `ip a` и запомни его **глобальный** IPv6-адрес.
2. Отправь на него ping с **Anna**, например `ping 2001:db8:1:0:…` (с полным адресом Ben).
3. Перейди в режим :fa-magnifying-glass: **Трассировка** и открой трассу для **Anna**.

Посмотри на пакеты непосредственно перед первым `Echo (ping) request`.

:::quiz multi
Какие утверждения верны?

- [x] Ben отвечает сообщением **Neighbor Advertisement** и сообщает свой MAC-адрес
- [x] Запрос отправляется на multicast-адрес (`ff02::1:ff…`), а не всем по широковещанию
- [ ] Anna отправляет ARP-запрос, как в IPv4
- [x] Маршрутизатор регулярно рассылает **Router Advertisements** на `ff02::1` — в них содержится префикс
:::

:::tip Запомни
В IPv6 протокол **NDP** (*Neighbor Discovery Protocol*, часть ICMPv6) берёт на себя задачи ARP: с помощью **Neighbor Solicitation** и **Neighbor Advertisement** устройства узнают MAC-адреса своих соседей. С помощью **Router Advertisements** маршрутизатор объявляет префикс — из него устройства сами формируют свой адрес по **SLAAC**.
:::

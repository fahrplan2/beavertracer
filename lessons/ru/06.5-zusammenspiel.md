# Всё вместе: что происходит при открытии веб-страницы?

:::goal
**Цель обучения:** ты можешь шаг за шагом объяснить, какие протоколы на каких уровнях участвуют, когда только что включённый ноутбук открывает веб-страницу.
:::

:::sim
url=/sims/lesson-6.5.btsim
:::

Теперь соберём вместе всё, что ты узнал на этом курсе. К коммутатору подключены **DHCP-Server**, **DNS-Server**, **Webserver** и **Laptop**, который только что включили — у него ещё нет IP-адреса, и он настроен на DHCP.

## Эксперимент

1. Переключись в :fa-play: режим выполнения **Запустить** и подожди несколько секунд.
2. Нажми на **Laptop**, открой :fa-globe: **Браузер** и перейди по адресу `http://www.beaver-schule.de/`.
3. В :fa-magnifying-glass: режиме **Трассировка** открой трассу для **Laptop**. Здесь вся история — начиная с самого первого пакета.

Расставь шаги в правильном порядке, как они идут в трассе:

:::quiz match
1. Schritt -> DHCP: ноутбук получает IP-адрес, шлюз и DNS-сервер
2. Schritt -> ARP: ноутбук запрашивает MAC-адрес DNS-сервера
3. Schritt -> DNS: ноутбук запрашивает IP-адрес www.beaver-schule.de
4. Schritt -> ARP: ноутбук запрашивает MAC-адрес веб-сервера
5. Schritt -> TCP: трёхстороннее рукопожатие с веб-сервером
6. Schritt -> HTTP: GET / и ответ 200 OK
:::

:::evaluate
Проверить порядок
:::

А в основе всего лежат **IP** (уровень 3), который адресует каждый из этих пакетов, и **Ethernet** (уровень 2), который доставляет его до следующего устройства. Если бы веб-сервер находился в другой сети, добавился бы ещё **маршрутизатор**: тогда ноутбук запрашивал бы MAC-адрес своего **шлюза**, а не веб-сервера.

:::quiz mc
Почему ноутбук может отправить DNS-запрос только после DHCP?
- [ ] Потому что DNS работает только через TCP
- [x] Потому что только благодаря DHCP он получает собственный IP-адрес и узнаёт, какой DNS-сервер отвечает за разрешение имён
- [ ] Потому что DNS-сервер запускается только после DHCP-сервера
:::

:::quiz mc
Сколько TCP-соединений браузер устанавливает с веб-сервером — и почему?
- [ ] Одно, для всего сразу
- [x] Два — одно для страницы и одно для таблицы стилей
- [ ] Ни одного, HTTP не нуждается в TCP
:::

Проверить ответы

:::tip Запомни
За одним-единственным щелчком работают вместе все уровни: **DHCP** предоставляет базовые настройки, **ARP** находит MAC-адреса в локальной сети, **DNS** преобразует имя, **TCP** устанавливает надёжное соединение, а **HTTP** получает страницу — и всё это упаковано в **IP**-пакеты и **Ethernet**-кадры.
:::

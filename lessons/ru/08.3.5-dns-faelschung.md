# Атака: подмена DNS

:::sim
url=/sims/lesson-8.3.5.btsim
:::

Анна хочет открыть на **Client-PC** онлайн-банкинг **Biberbank**. Чего она не знает: кто-то получил доступ к **DNS-Server** и изменил одну запись.

На рабочей области ты видишь настоящий веб-сервер **www.biberbank.de** и компьютер **злоумышленника**. На нём работает копия сайта банка.

## Часть 1: без шифрования

Переключись в :fa-play: режим **Запустить** и открой на **Client-PC** в :fa-globe: **Браузер** адрес `http://www.biberbank.de/`.

:::quiz mc
Что ты видишь?
- [x] Страницу входа Biberbank без каких-либо предупреждений
- [ ] Предупреждение о том, что сайт поддельный
- [ ] Сообщение об ошибке
:::

:::evaluate
Проверить ответ
:::

Всё выглядит нормально. Но с каким сервером на самом деле разговаривает браузер? Открой на Client-PC :fa-terminal: **Терминал**:

```
$ nslookup www.biberbank.de
```

:::quiz short
Какой IP-адрес возвращает DNS-сервер для `www.biberbank.de`?
= 192.168.0.66
:::

:::quiz mc
Кому принадлежит этот адрес? (В режиме редактирования щёлкни по устройствам или посмотри их :fa-gear: **Параметры IP**.)
- [ ] Настоящему веб-серверу Biberbank
- [x] Злоумышленнику
- [ ] DNS-серверу
:::

:::evaluate
Проверить ответы
:::

Если бы Анна сейчас ввела номер счёта и PIN-код, они попали бы прямо к злоумышленнику. При **HTTP** у неё **нет шансов** заметить обман: в адресной строке правильное имя, страница выглядит настоящей.

## Часть 2: с HTTPS

Теперь открой `https://www.biberbank.de/`.

:::quiz mc
Что происходит?
- [ ] Появляется поддельная страница с замком
- [x] Браузер предупреждает: сертификат выдан для другого имени
- [ ] Появляется настоящая страница Biberbank
:::

:::quiz short
Для какого имени выдан сертификат злоумышленника (без `CN=`)?
= www.biber-gewinnspiel.de
:::

:::evaluate
Проверить ответы
:::

У злоумышленника есть даже **настоящий** сертификат доверенного удостоверяющего центра (CA) — но для его собственного домена `www.biber-gewinnspiel.de`. Сертификат для `www.biberbank.de` он не получит ни в одном CA, потому что этот домен ему не принадлежит. А без **закрытого ключа** Biberbank он не может использовать и её настоящий сертификат: при рукопожатии ему пришлось бы подписать им Server Key Exchange.

:::quiz multi
От чего HTTPS здесь защищает, а от чего нет?
- [x] HTTPS выявляет, что сервер не настоящий
- [ ] HTTPS не позволяет подменить DNS-сервер
- [x] HTTPS помогает, только если пользователь серьёзно относится к предупреждению
- [ ] При HTTPS поддельная страница вообще недоступна
:::

:::evaluate
Проверить ответы
:::

## Часть 3: починка DNS-сервера

Открой **DNS-Server** и исправь запись для `www.biberbank.de`. Правильный адрес ты найдёшь в :fa-gear: **Параметры IP** веб-сервера **www.biberbank.de**. Не забудь нажать **Сохранить**.

:::note
Client-PC запоминает ответы DNS на некоторое время, чтобы не запрашивать их заново при каждом обращении (**DNS-кэш**). Как долго, указано в столбце **TTL** (*Time to Live*) в секундах. Если `nslookup` сразу после твоего исправления всё ещё возвращает старый адрес, подожди, пока истечёт TTL, и попробуй снова.
:::

:::task
title: Biberbank снова настоящий?
Проверяет, что Client-PC разрешает www.biberbank.de в правильный адрес и может открыть страницу по HTTPS без предупреждения.
check: resolves(2, "www.biberbank.de", "192.168.0.30")
check: httpsOk(2, "https://www.biberbank.de/")
:::

:::note
В реальности злоумышленник редко подделывает сам DNS-сервер. Чаще он подсовывает свои ответы в общедоступной сети Wi-Fi, меняет настройки домашнего маршрутизатора или заманивает похожим адресом, например `www.biberbank-login.de` (**фишинг**). От похожего по звучанию имени HTTPS тоже не поможет — для него злоумышленник получит действительный сертификат. Поэтому: читай адрес внимательно!
:::

:::tip Запомни
При **подмене DNS** DNS-сервер возвращает для имени адрес злоумышленника. При **HTTP** этого не заметить. При **HTTPS** сертификат злоумышленника не соответствует запрошенному имени, и браузер **предупреждает** — ведь сертификат для чужих доменов ни один CA не выдаёт, а закрытого ключа настоящего сервера у злоумышленника нет.
:::

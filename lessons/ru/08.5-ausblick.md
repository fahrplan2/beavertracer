# Итоги и перспективы

## Обзор составных частей

| Компонент | Цель защиты | Пример |
|---|---|---|
| **Симметричное шифрование** | Конфиденциальность | AES шифрует данные HTTPS-соединения |
| **Асимметричное шифрование** | Конфиденциальность, обмен ключами | Diffie-Hellman, RSA |
| **Хеш-значения** | Целостность | Контрольная сумма SHA-256 загружаемого файла |
| **Цифровая подпись** | Аутентичность, целостность | Сервер подписывает свою долю Diffie-Hellman |
| **Сертификат** | Аутентичность | подтверждает: этот ключ принадлежит `www.biberbank.de` |

## Один и тот же принцип во многих местах

То, что ты узнал на примере HTTPS, используется и во многих других технологиях:

- **Wi-Fi (WPA2/WPA3):** В главе 3.3.2 любое устройство в зоне действия могло читать трафик. При использовании WPA2 или WPA3 каждый радиокадр шифруется с помощью AES; кроме того, WPA3 согласует ключ так, что даже зная пароль Wi-Fi, злоумышленник не сможет расшифровать старые перехваченные записи.
- **SSH:** Зашифрованное удалённое управление из главы 6.6. Вместо сертификатов клиент при первом подключении запоминает **отпечаток** ключа сервера и предупреждает, если позднее он изменится.
- **VPN:** Зашифрованный туннель через интернет, например в сеть школы или компании. Этому посвящена глава 10.
- **Мессенджеры:** Signal, WhatsApp и другие используют **сквозное шифрование**: даже оператор сервиса не может прочитать сообщения.

:::note
Мощные **квантовые компьютеры** когда-нибудь смогут взломать разложение больших чисел на простые множители — а вместе с ним RSA и Diffie-Hellman. Поэтому уже сегодня внедряются новые, **квантово-устойчивые** алгоритмы. Симметричные алгоритмы, такие как AES с длинными ключами, по-прежнему считаются безопасными.
:::

## Проверь себя

:::quiz mc
В HTTPS сами данные шифруются с помощью …
- [ ] RSA, потому что он самый надёжный
- [x] симметричного алгоритма, например AES, и согласованного сеансового ключа
- [ ] закрытого ключа сервера
:::

:::quiz mc
Ты открываешь `https://www.biberbank.de/`, и браузер сообщает: «Сертификат выдан для `www.gewinn-biber.de`». Что ты сделаешь?
- [ ] Нажму «Всё равно продолжить» — соединение ведь всё равно зашифровано
- [x] Прерву соединение — возможно, браузер вообще общается не с банком
- [ ] Открою страницу через `http://`, тогда предупреждения не будет
:::

:::quiz multi
Какие утверждения верны?
- [x] Хеш-значение полностью меняется, даже если данные изменились совсем незначительно
- [x] Подпись создаётся закрытым ключом, а проверяется открытым
- [x] Корневые центры сертификации (root CA) предустановлены в браузере или операционной системе
- [ ] При использовании HTTPS перехватчик не может увидеть даже IP-адрес сервера
- [ ] SMTPS шифрует письмо и на почтовом сервере
:::

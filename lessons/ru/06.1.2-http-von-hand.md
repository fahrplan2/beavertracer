# HTTP вручную

:::sim
url=/sims/lesson-6.1.btsim
:::

Если HTTP — это обычный текст, можно ли тогда самому «поговорить» с веб-сервером, вообще без браузера? Да: с помощью `telnet` ты устанавливаешь TCP-соединение с любым портом и сам набираешь текст.

## Эксперимент

1. Переключись в :fa-play: режим выполнения и открой на **Client-PC** :fa-terminal: **Терминал**.
2. Подключись к порту 80 сервера:
   ```
   $ telnet 192.168.0.20 80
   ```
3. Набери запрос строка за строкой — и закончи его **пустой строкой** (просто нажми **Enter** ещё раз):
   ```
   GET /kontakt.html HTTP/1.1
   Host: 192.168.0.20

   ```

Сервер отвечает строкой состояния, заголовками и страницей контактов — в виде текста, точно так же, как её получает браузер.

:::quiz mc
По чему сервер понимает, что твой запрос закончился?
- [ ] По специальной команде `END`
- [x] По пустой строке
- [ ] Спустя определённое время
:::

Какое значение указано в ответе в заголовке `Content-Type`? (только первая часть до `;`)
= text/html
:::

## Провоцируем ошибки

Более удобный инструмент — `curl`: он отправляет запрос за тебя. С параметром `-v` (*verbose*, подробный вывод) он показывает всё, что передаётся туда и обратно: строки с `>` отправил `curl`, строки с `<` пришли от сервера.

Попробуй:

```
$ curl -v http://192.168.0.20/gibtsnicht.html
$ curl -X POST -d name=Anna http://192.168.0.20/
```

:::quiz short
Какой код состояния ты получаешь для `/gibtsnicht.html`?
= 404
:::

:::quiz short
А какой — для запроса с методом `POST`?
= 405
:::

:::evaluate
Проверить ответы
:::

:::note
Веб-сервер в BeaverTracer умеет только отдавать файлы — поэтому он разрешает лишь `GET` и `HEAD`. Настоящие веб-серверы с помощью `POST` принимают, например, данные форм и передают их дальше в программу.
:::

:::tip Запомни
Многие протоколы прикладного уровня **текстовые** — HTTP, а также SMTP, POP3 и IMAP. Поэтому их можно «говорить» вручную через `telnet` и читать в трассировщике. Это удобно при поиске неисправностей, но это и проблема безопасности: любой, кто перехватывает трафик, может прочитать всё. Как помогает шифрование (HTTPS), ты узнаешь в главе 8.
:::

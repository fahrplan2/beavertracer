# Назначение IP-адресов

:::sim
url=/sims/lesson-1.2.2.btsim
:::

Чтобы два устройства могли общаться друг с другом, им нужен IP-адрес в одной сети. На рабочей области ты видишь два соединённых компьютера — точно такие же, как ты только что собрал сам.

1. Перейди в режим :fa-play: **Запустить** и щёлкни по **Computer 1**, чтобы открыть его.
2. Открой там :fa-gear: **Параметры IP**. У нового компьютера уже есть адрес `192.168.0.10` с маской сети `/24` — его можно оставить как есть.
3. Теперь открой **Computer 2**. У него *такой же* адрес `192.168.0.10` — так работать не будет, ведь каждый адрес может встречаться в сети только один раз. Измени его на `192.168.0.11` (маска сети `/24`).

:::tip Запомни
**IP-адрес** (например, `192.168.0.10`) — это адрес устройства в сети, его можно сравнить с номером дома. Каждый IP-адрес может встречаться в сети только **один раз**.
:::

:::task
title: Адреса назначены правильно?
Оставайся в режиме выполнения и проверь, что у обоих компьютеров подходящие адреса и что они доступны друг для друга.
check: ip(1, "192.168.0.10/32")
check: ip(3, "192.168.0.11/32")
check: pingOk(1, 3)
:::

:::note
Что именно означает `/24` и как разумно разделить сеть на части, мы подробно разберём в главе 4. Пока достаточно знать: оба адреса должны начинаться с `192.168.0.` и не должны повторяться.
:::

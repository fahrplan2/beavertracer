# Основные типы адресов

В IPv6 по началу адреса можно понять, для чего он предназначен:

| Тип адреса | как распознать | для чего |
|---|---|---|
| **Link-Local** | `fe80::` | Действует только в **собственной локальной сети**. Каждое устройство автоматически назначает себе такой адрес — маршрутизатор никогда его не пересылает. |
| **Global Unicast** | `2…` или `3…` (`2000::/3`) | Глобально уникальный адрес, доступный в интернете. Префикс выдаёт интернет-провайдер. |
| **Unique Local** | `fd…` (`fc00::/7`) | Для частных сетей, аналог `192.168.x.x` в IPv4. |
| **Loopback** | `::1` | Само устройство — как `127.0.0.1` в IPv4. |
| **Multicast** | `ff…` | Для **группы** устройств, например `ff02::1` = все устройства в локальной сети. |

:::note
Для примеров и учебных материалов зарезервирован диапазон `2001:db8::/32` — в настоящем интернете он никогда не встречается. Поэтому ты видишь его в этом курсе.
:::

Важное нововведение: **в IPv6 больше нет широковещательной рассылки (broadcast).** То, что в IPv4 было широковещательной рассылкой всем, в IPv6 выполняют **multicast**-адреса — сообщение попадает только тем устройствам, которых интересует эта группа.

:::tip Запомни
У каждого устройства с IPv6 есть как минимум один **Link-Local-адрес** (`fe80::…`) для собственной сети, а обычно ещё и **глобальный адрес** для интернета. Вместо broadcast в IPv6 используется **multicast** (`ff…`).
:::

:::quiz match
fe80::a828:39ff:fee2:4182 -> Link-Local — только в собственной сети
2001:db8:1::10 -> Global Unicast — глобально уникальный
::1 -> Loopback — само устройство
ff02::1 -> Multicast — все устройства в локальной сети
fd12:3456::1 -> Unique Local — для частных сетей
:::

# POP3 или IMAP?

:::sim
url=/sims/lesson-6.3.btsim
:::

Для получения почты есть два протокола. В этой симуляции **Anna использует POP3**, а **Ben — IMAP**.

## Эксперимент

1. В :fa-play: режиме выполнения отправь письмо от **Ben** на адрес `anna@beaver-schule.de`.
2. В приложении **E-Mail** на устройстве **Anna** нажми **Получить**.
3. Открой трассировки для **Anna** и для **Ben** и сравни команды при получении почты.

:::quiz match
USER / PASS -> POP3: вход с именем пользователя и паролем в два шага
RETR -> POP3: загрузить сообщение
LOGIN -> IMAP: вход с именем пользователя и паролем
SELECT INBOX -> IMAP: открыть папку на сервере
:::

Проверить соответствие
:::

## В чём разница

| | POP3 | IMAP |
|---|---|---|
| Порт | 110 | 143 |
| Основная идея | **загрузить** письма — после этого их обычно удаляют на сервере | письма **остаются на сервере** и управляются там |
| Папки, прочитано/не прочитано | только на собственном устройстве | на сервере — везде одинаково |
| Несколько устройств (телефон, ноутбук) | неудобно: на каждом устройстве своё состояние | идеально: все устройства видят один и тот же почтовый ящик |

:::note
Почтовая программа в BeaverTracer оставляет письма на сервере и при использовании POP3. Настоящие программы после загрузки часто удаляют их — или оставляют лишь на некоторое время.
:::

Лена читает свою почту на телефоне, планшете и школьном ноутбуке. Что ей следует использовать?

- [x] IMAP, потому что все устройства видят один и тот же почтовый ящик на сервере

:::tip Запомни
**POP3** загружает письма с сервера на **одно** устройство. **IMAP** управляет почтовым ящиком **на сервере** — с папками и статусом «прочитано» одновременно для всех устройств. Оба протокола служат только для **получения** почты; отправка всегда выполняется по **SMTP**.
:::

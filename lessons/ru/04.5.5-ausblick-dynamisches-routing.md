# Обзор: динамическая маршрутизация

В проекте ты вручную прописал двенадцать маршрутов для четырёх площадок. В крупной корпоративной сети сотни маршрутизаторов, в интернете — десятки тысяч, и постоянно где-то выходит из строя линия или добавляется новая. Вручную с этим уже не справиться.

Поэтому маршрутизаторы, как правило, обмениваются маршрутами друг с другом автоматически. Для этого существуют **протоколы маршрутизации**. Такой способ называют **динамической маршрутизацией** — в отличие от **статической маршрутизации**, при которой всё прописывается вручную.

Самые известные протоколы маршрутизации:

| Протокол | Идея | типичное применение |
|---|---|---|
| **RIP** (*Routing Information Protocol*) | Каждый маршрутизатор регулярно сообщает соседям, до каких сетей он может добраться и через сколько маршрутизаторов (*хопов*). | небольшие сети, учебный пример |
| **OSPF** (*Open Shortest Path First*) | Каждый маршрутизатор знает полную схему сети и сам вычисляет по ней кратчайший путь. | корпоративные сети |
| **BGP** (*Border Gateway Protocol*) | Крупные операторы связи (например, интернет-провайдеры) сообщают друг другу, до каких сетей они могут добраться. | интернет между провайдерами |

:::quiz match
RIP -> Маршрутизаторы сообщают соседям, через сколько хопов они могут добраться до сети
OSPF -> Каждый маршрутизатор знает всю схему сети и вычисляет кратчайший путь
BGP -> Соединяет сети крупных интернет-провайдеров
:::

:::tip Запомни
При **статической маршрутизации** администратор прописывает все маршруты вручную. При **динамической маршрутизации** маршрутизаторы автоматически обмениваются маршрутами с помощью **протоколов маршрутизации**, таких как RIP, OSPF или BGP, и сами подстраиваются, если соединение выходит из строя.
:::

:::note
BeaverTracer умеет симулировать RIP, OSPF и BGP — ты найдёшь их на одноимённых вкладках маршрутизатора. В этом курсе мы ограничимся обзором.
:::

# HTTP: веб-страницы

:::goal

:::

**Hypertext Transfer Protocol** (**HTTP**) — это язык, на котором браузеры и веб-серверы общаются друг с другом. На сервере находится веб-сайт **Beaver-Schule**: главная страница, страница с контактами и таблица стилей для оформления.

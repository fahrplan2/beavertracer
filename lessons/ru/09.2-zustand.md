# Без отслеживания состояния и с отслеживанием состояния

Соединение всегда состоит из **двух направлений**: компьютер учителя посылает запрос веб-серверу в интернете, а веб-сервер отправляет веб-страницу обратно. Межсетевой экран, работающий по принципу белого списка, должен пропускать не только запрос, но и **ответ**.

Для этого существуют два вида пакетных фильтров:

| | **Без отслеживания состояния** (*stateless*) | **С отслеживанием состояния** (*stateful*) |
|---|---|---|
| Принцип работы | проверяет каждый пакет отдельно, без «памяти» | запоминает разрешённые соединения в **таблице состояний** |
| Ответы | требуют отдельного правила для обратного направления | пропускаются автоматически, так как относятся к известному соединению |
| Применение | простые устройства, очень быстрые фильтры | практически любой современный межсетевой экран |

В следующих двух разделах ты увидишь, почему у фильтров без отслеживания состояния возникают проблемы с ответами и как с ними справляется межсетевой экран с отслеживанием состояния.

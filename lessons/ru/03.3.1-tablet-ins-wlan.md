# Подключение планшета к Wi-Fi

:::sim
url=/sims/lesson-3.3.1.btsim
:::

К коммутатору подключены **Schul-PC** (`192.168.0.10`) и **Точка доступа**. Планшет **Anna** (`192.168.0.30`) должен подключиться к школьной сети Wi-Fi.

## Поиск сети Wi-Fi

Переключись в режим выполнения :fa-play: **Запустить** и щёлкни по **Точке доступа**. Там указано имя её сети Wi-Fi — **SSID**: `Schule`.

Точка доступа работает как мост: всё, что приходит к ней по радио, она передаёт по кабелю на коммутатор — и наоборот. Благодаря этому Anna и Schul-PC оказываются в одной локальной сети.

## Подключение планшета

1. Щёлкни по **Anna**, открой :fa-gear: **Параметры IP** и там вкладку **WiFi**.
2. В поле **SSID** введи имя сети Wi-Fi: `Schule`, и нажми **Применить**.
3. Открой на Anna :fa-terminal: **Терминал** и отправь ping на Schul-PC:
   ```
   $ ping 192.168.0.10
   ```

Во время ping следи за рабочей областью: вокруг Anna и точки доступа распространяются радиоволны.

:::tip Запомни
**WLAN** (беспроводная локальная сеть) — это локальная сеть, работающая по радио. **Точка доступа** соединяет беспроводную сеть с проводной. У каждой сети Wi-Fi есть имя — **SSID** (*Service Set Identifier*): устройство должно знать правильный SSID, чтобы подключиться.
:::

:::quiz mc
Что произойдёт, если ввести на Anna в качестве SSID `schule` (строчными буквами)?
- [ ] Ничего — регистр букв не имеет значения
- [x] Anna больше не подключена — SSID должен совпадать точно
- [ ] Anna подключится к другой сети Wi-Fi
:::

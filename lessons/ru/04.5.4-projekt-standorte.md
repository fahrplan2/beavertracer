# Проект: фирма с четырьмя площадками

:::sim
url=/sims/lesson-4.5.4.btsim
:::

У фирмы головной офис находится в **Ханау**, а филиалы — в **Касселе**, **Гиссене** и **Дармштадте**. У каждой площадки есть собственная сеть и собственный маршрутизатор. Все маршрутизаторы соединены выделенными линиями с **центральной сетью**, в которой также находится главный сервер фирмы.

## План адресации

Администратор распределил адреса по следующей схеме — в симуляции они уже введены:

| Сеть | Диапазон адресов |
|---|---|
| Центральная сеть | `10.19.0.0/24` |
| Hanau | `10.19.1.0/24` |
| Kassel | `10.19.2.0/24` |
| Gießen | `10.19.3.0/24` |
| Darmstadt | `10.19.4.0/24` |

| Устройство | в центральной сети | в сети площадки |
|---|---|---|
| Server | `10.19.0.10` | — |
| Router Hanau | `10.19.0.1` | `10.19.1.1` |
| Router Kassel | `10.19.0.2` | `10.19.2.1` |
| Router Gießen | `10.19.0.3` | `10.19.3.1` |
| Router Darmstadt | `10.19.0.4` | `10.19.4.1` |
| PC на площадке | — | везде `.2` (например, PC Kassel `10.19.2.2`) |

У всех маршрутизаторов интерфейс `eth0` смотрит в центральную сеть, а `eth1` — в сеть площадки.

## Твоё задание

Чтобы все компьютеры фирмы могли связываться друг с другом и с сервером, не хватает ещё двух вещей:

1. **Шлюзы:** укажи шлюз на всех четырёх PC и на сервере. PC используют маршрутизатор своей площадки; сервер использует **Router Hanau**.
2. **Таблицы маршрутизации:** добавь на всех четырёх маршрутизаторах недостающие маршруты. Каждый маршрутизатор должен знать сети **трёх других** площадок.

Время от времени проверяй сеть с помощью `ping` и `traceroute`.

<details>
<summary>Подсказка: как здесь выглядит маршрут?</summary>

Пример для **Router Kassel**: пакеты для Gießen (`10.19.3.0/24`) отправляются на Router Gießen в его адрес в центральной сети — то есть **Следующий переход** `10.19.0.3`, **Iface** `eth0`. По этому образцу каждому маршрутизатору нужны три маршрута.
</details>

:::task
title: Сеть фирмы готова?
Проверь, достигают ли все площадки сервера и связаны ли площадки между собой. Для этого симуляция должна работать в режиме выполнения.
check: pingOk(11, 19)
check: pingOk(13, 19)
check: pingOk(15, 19)
check: pingOk(17, 19)
check: pingOk(13, 15)
check: pingOk(15, 17)
check: pingOk(17, 11)
check: pingOk(11, 13)
:::

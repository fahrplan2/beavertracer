# Пакетный фильтр: правила

Самый простой и самый важный вид межсетевого экрана — это **пакетный фильтр**. Он просматривает каждый пакет, который через него проходит, и по **списку правил** решает, можно ли его пропустить. Для этого он читает только заголовки уровней 3 и 4 — содержимое (например, веб-страницу) он не рассматривает.

## Из чего состоит правило

| Поле | Значение | Пример |
|---|---|---|
| **Направление** | С какой стороны приходит пакет? | A → B (из интернета в сеть школы) |
| **Протокол** | TCP, UDP, ICMP или любой | TCP |
| **IP источника** | адрес или сеть отправителя | любой |
| **Порт источника** | порт отправителя | любой |
| **IP назначения** | адрес или сеть получателя | `198.51.100.10` |
| **Порт назначения** | порт получателя, то есть служба | `80` |
| **Действие** | Что происходит с подходящими пакетами? | Разрешить |

Пустое поле означает «любой». Сети записываются в нотации CIDR, например `198.51.100.0/24`, диапазоны портов — через дефис, например `1024-65535`.

## Порядок имеет значение

Межсетевой экран проверяет правила **сверху вниз**. Решает **первое подходящее правило** — все последующие для этого пакета уже не рассматриваются. Если не подходит ни одно правило, действует **политика по умолчанию** (*Default Policy*).

## Три возможных действия

| Действие | Что делает межсетевой экран | Что замечает отправитель |
|---|---|---|
| **Разрешить** (*Allow*) | пакет пересылается дальше | — |
| **Отбросить** (*Drop*) | пакет молча отбрасывается | ничего — он ждёт, пока не истечёт тайм-аут |
| **Отклонить** (*Reject*) | пакет отбрасывается, отправитель получает отказ: для TCP — **RST**, иначе ICMP «недостижимо» | сразу получает сообщение об ошибке |

Что лучше? **Отбрасывание** выдаёт злоумышленнику меньше информации и отнимает у него время, потому что ему приходится ждать после каждой попытки. **Отклонение** удобнее для собственных пользователей: программа сразу получает сообщение об ошибке, а не зависает надолго. Поэтому на практике пакеты снаружи обычно отбрасывают, а пакеты из собственной сети отклоняют.

:::quiz match
Разрешить -> Пакет пересылается дальше
Отбросить -> Пакет исчезает, отправитель напрасно ждёт ответа
Отклонить -> Пакет не пересылается, но отправитель сразу получает отказ
Политика по умолчанию -> Действует, если не подходит ни одно правило
:::

:::tip Запомни
**Пакетный фильтр** проверяет каждый пакет по **списку правил**, учитывая направление, протокол, адреса и порты. Действие определяет **первое подходящее правило**: **разрешить**, **отбросить** (молча) или **отклонить** (с отказом). Если не подходит ни одно правило, действует **политика по умолчанию**.
:::

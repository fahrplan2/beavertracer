# Порядок правил и базовая политика

## Сначала исключение, потом правило

Поскольку срабатывает **первое подходящее правило**, порядок имеет значение. Посмотри на этот список правил (все правила действуют для направления A → B, политика по умолчанию: разрешить всё):

| № | Протокол | Порт назначения | Действие |
|---|---|---|---|
| 1 | TCP | любой | Отбросить |
| 2 | TCP | 80 | Разрешить |

- [x] Он будет отброшен, потому что подходит уже правило 1 — до правила 2 дело не доходит
- [ ] Межсетевой экран запросит решение у администратора

В общем случае действует правило: **специальные правила — наверх, общие — вниз.** Правило, которое охватывает много трафика, «затеняет» все правила под ним. Столбец **Совпадения** выдаёт такие «мёртвые» правила: у них значение остаётся равным 0.

## Чёрный список или белый список?

В разделе 9.1.2 ты **запрещал** отдельные порты, а всё остальное разрешал. Это называется **чёрный список** (*blacklist*). Противоположность — **белый список** (*whitelist*): **разрешается** только необходимое, а всё остальное запрещается — с помощью завершающего правила «отбросить всё» или политики по умолчанию **Отбросить всё**.

| | Чёрный список | Белый список |
|---|---|---|
| Базовая политика | всё разрешено, исключения запрещены | всё запрещено, исключения разрешены |
| Политика по умолчанию | Разрешить | Отбросить |
| Новая служба на сервере | сразу доступна снаружи | остаётся закрытой, пока кто-нибудь её не откроет |

Поэтому хорошие межсетевые экраны работают по **принципу белого списка** («Default Deny»): всё, что не разрешено явно, запрещено. Белый список для школьного сервера выглядел бы так:

| № | Направление | Протокол | Порт назначения | Действие |
|---|---|---|---|---|
| 1 | A → B | TCP | {80} | {Разрешить} |
| 2 | A → B | TCP | {25} | Разрешить |
| 3 | A → B | любой | любой | {Отбросить} |
:::

:::tip Запомни
Поскольку срабатывает **первое подходящее правило**, **специальные правила должны стоять выше**, а общие — ниже. Надёжнее, чем **чёрный список** (всё разрешено, кроме …), **белый список** (всё запрещено, кроме …, *Default Deny*): забытые или новые службы тогда автоматически остаются закрытыми.
:::

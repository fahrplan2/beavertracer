# Адрес сети, широковещательный адрес и хосты

В каждой сети две адреса выполняют особую роль:

- **Адрес сети** — это **наименьший** адрес сети: все биты в узловой части равны 0. Он обозначает сеть целиком, например, в таблицах маршрутизации.
- **Широковещательный адрес** — это **наибольший** адрес сети: все биты в узловой части равны 1. Всё, что отправляется на него, получают все устройства в сети.

Эти два адреса **не** назначаются устройствам. Все адреса между ними доступны для устройств (**хостов**).

## Простой пример

`192.168.0.12/24` — узловая часть — это последний октет:

| | Адрес |
|---|---|
| Адрес сети (узловая часть = 0) | `192.168.0.0` |
| Широковещательный адрес (узловая часть = 255) | `192.168.0.255` |
| Диапазон для хостов | `192.168.0.1` – `192.168.0.254` |
| Количество хостов | 254 |

## Когда граница проходит посередине октета

Сложнее, если длина префикса не кратна 8. Тогда нужный октет переводится в двоичную систему счисления. Пример: `194.9.190.12/27`.

Первые три октета целиком относятся к [[n|сетевой части]] (24 бита). Из последнего октета **3 бита** ещё относятся к сетевой части (24 + 3 = 27), остальные **5 бит** — к [[h|узловой части]]:

| | последний октет (двоичный) | десятичный |
|---|---|---|
| IP-адрес | [[n|000]][[h|01100]] | 12 |
| Маска сети (`/27`) | [[n|111]][[h|00000]] | 224 |
| Адрес сети: биты хоста в 0 | [[n|000]][[h|00000]] | **0** |
| Широковещательный адрес: биты хоста в 1 | [[n|000]][[h|11111]] | **31** |

Результат:

- Адрес сети: `194.9.190.0`
- Широковещательный адрес: `194.9.190.31`
- Диапазон для хостов: `194.9.190.1` – `194.9.190.30`
- Количество хостов: 2⁵ − 2 = **30**

:::tip Запомни
**Адрес сети:** все биты хоста равны 0 (наименьший адрес). **Широковещательный адрес:** все биты хоста равны 1 (наибольший адрес). Оба не назначаются устройствам. В сети с длиной префикса *n* имеется **2<sup>32 − n</sup> − 2** пригодных для хостов адресов.
:::

:::tip Совет: размер блока
Если ты понял(а) метод с двоичной системой, есть короткий путь: **256 минус октет маски** даёт размер сети в этом октете. Для `/27` (маска 224) это 256 − 224 = **32**. Сети тогда начинаются с 0, 32, 64, 96 … — адрес `.12` находится в сети, начинающейся с `.0`, а адрес `.70` — в сети, начинающейся с `.64`.
:::

## Самые важные размеры сетей

| Префикс | Маска сети | Хосты |
|---|---|---|
| `/8` | `255.0.0.0` | 16 777 214 |
| `/16` | `255.255.0.0` | 65 534 |
| `/24` | `255.255.255.0` | 254 |
| `/25` | `255.255.255.128` | 126 |
| `/26` | `255.255.255.192` | 62 |
| `/27` | `255.255.255.224` | 30 |
| `/28` | `255.255.255.240` | 14 |
| `/29` | `255.255.255.248` | 6 |
| `/30` | `255.255.255.252` | 2 |

:::note
Самая маленькая сеть, применяемая на практике, — `/30`: в ней ровно два пригодных адреса, и её часто используют для соединения двух маршрутизаторов. `/32` обозначает один-единственный адрес — как сеть он непригоден, но встречается в таблицах маршрутизации и правилах межсетевого экрана.
:::

## Ping снаружи

Переключись в :fa-play: режим **Запустить** и отправь с **Internet-PC** ping на школьный сервер:

```
$ ping -c 2 198.51.100.10
```

После этого открой в межсетевом экране вкладку **Protokoll**.

## Сканирование портов: отброшен или отклонён?

Теперь целенаправленно просканируй пять портов. Порт 3306 (база данных) на школьном сервере вообще не используется.

```
$ nmap -p 22,25,80,110,3306 198.51.100.10
```

:::quiz match
22 (отброшен) -> filtered
25 (разрешён, служба работает) -> open
110 (отклонён) -> closed
3306 (разрешён, службы нет) -> closed
:::

:::evaluate
Проверить соответствие
:::

:::quiz multi
Какие выводы может сделать злоумышленник из результата?
- [x] При `filtered` он знает: там стоит межсетевой экран, который «проглатывает» пакеты
- [x] При `closed` он не может отличить, отклоняет ли пакеты межсетевой экран или просто не работает никакая служба
- [ ] При `filtered` он знает, какая служба работает за этим портом
- [ ] При `closed` служба всё равно доступна
:::

:::evaluate
Проверить ответы
:::

В завершение посмотри на столбец **Treffer** в списке правил: в нём межсетевой экран считает, сколько пакетов уже обработало каждое правило. Значение рядом со **Standardrichtlinie** учитывает все пакеты, для которых не подошло ни одно правило.

:::tip Запомни
**Отброшенные** пакеты исчезают бесследно: `ping` сообщает о тайм-ауте, `nmap` — `filtered`. На **отклонённые** пакеты межсетевой экран отвечает отказом (в случае TCP — RST); снаружи это выглядит как закрытый порт. **Журнал** межсетевого экрана показывает, какие пакеты он задержал, а столбец **Treffer** — какое правило сработало.
:::

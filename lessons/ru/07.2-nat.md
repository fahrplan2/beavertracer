# NAT: много устройств, один адрес

:::goal
**Цель обучения:** Ты можешь показать в Трассировщике, как NAT подменяет адрес отправителя, прочитать таблицу NAT и объяснить, почему для соединений извне в домашнюю сеть нужен проброс портов.
:::

:::sim
url=/sims/lesson-7.1.btsim
:::

Провайдер обычно выдаёт для домашнего подключения только **один** публичный адрес IPv4 — WAN-адрес домашнего маршрутизатора. Все устройства в домашней сети должны делить его между собой. Этот механизм называется **NAT** (*Network Address Translation*, трансляция сетевых адресов).

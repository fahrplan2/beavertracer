# Кто получает какой пакет?

:::sim
url=/sims/lesson-3.1.2.btsim
:::

Теперь Anna, Ben и Clara подключены к коммутатору (порты 1, 2 и 3). Когда Anna отправляет пакет Ben, его получает только Ben — или Clara тоже?

Подумай немного, как, по-твоему, всё произойдёт. Потом проверь это на практике.

## Эксперимент

1. Перейди в режим выполнения :fa-play: **Запустить**, открой на **Anna** :fa-terminal: **Терминал** и пингуй Ben:
   ```
   $ ping 192.168.0.11
   ```
2. Перейди в режим :fa-magnifying-glass: **Трассировка** и с помощью **+** открой трассировку для **Clara**, порт `eth0`.
3. С помощью **+** открой вторую трассировку для **Ben**, порт `eth0`. Вверху можно переключаться между двумя трассировками.

:::

## Что за этим стоит

Назначение ARP-запроса — **широковещательный адрес**: он адресован *всем*. Поэтому коммутатор передал его на каждый порт, в том числе Clara. А ping-запросы были адресованы только Ben. Коммутатор отправил их исключительно на порт Ben — Clara об этом ничего не узнала.

:::tip Запомни
**Широковещательный** пакет адресован всем устройствам в локальной сети — коммутатор рассылает его на все порты. **Одноадресный** (unicast) пакет адресован ровно одному устройству — коммутатор отправляет его только на тот порт, к которому подключено это устройство.
:::

## Заглянем в коммутатор

Но откуда коммутатор знает, к какому порту подключён Ben? Вернись в режим :fa-play: **Запустить** и щёлкни по **коммутатору**. На вкладке **SAT** ты увидишь его таблицу адресов с двумя столбцами: **MAC** и **Port**.

:::

Коммутатор **обучается** по ходу работы: для каждого кадра (frame), который до него доходит, он смотрит на MAC-адрес **отправителя** и запоминает, к какому порту подключено это устройство. Когда пришёл ARP-запрос от Anna, он записал «Anna → порт 1», а при ответе от Ben — «Ben → порт 2». Clara ничего не отправляла — поэтому он её пока не знает.

:::tip Запомни
Коммутатор запоминает в своей **таблице адресов** (**SAT**, *Source Address Table*), по какому MAC-адресу какое устройство доступно на каком порту — он узнаёт это из адресов отправителей. Если ему известен получатель кадра, он отправляет кадр только на этот порт. Если неизвестен (или кадр широковещательный), он отправляет его на все порты.
:::

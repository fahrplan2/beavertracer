Веб-страница часто состоит из множества файлов: текста, таблиц стилей, изображений. Для каждого из них браузер отправляет отдельный запрос.

## Как выглядит запрос

Щёлкни в трассе на пакет `GET / HTTP/1.1` и разверни **Hypertext Transfer Protocol**. HTTP-запрос — это обычный текст:

```
GET / HTTP/1.1              ← Methode, Pfad, Version
Host: 192.168.0.20          ← Header: zusätzliche Angaben
…
                            ← Leerzeile: Ende der Anfrage
```

Ответ сервера устроен так же — со строкой состояния, заголовками, пустой строкой и затем самим файлом:

```
HTTP/1.1 200 OK             ← Version, Statuscode, Text
Content-Type: text/html     ← Header: Art der Datei
Content-Length: 301         ← Header: Größe in Byte
                            ← Leerzeile
<!doctype html> …           ← die Datei selbst
```

:::seq
mode: text
Client-PC -> Server: GET / | HTTP-запрос
Server -> Client-PC: 200 OK | index.html
Client-PC -> Server: GET /style.css | HTTP-запрос
Server -> Client-PC: 200 OK | style.css
:::

## Методы и коды состояния

**Метод** говорит о том, чего хочет клиент:

| Метод | Значение |
|---|---|
| **GET** | получить файл |
| **POST** | отправить данные на сервер, например заполненную форму |
| **HEAD** | получить только заголовки, без файла |

**Код состояния** говорит о том, как всё прошло. Первая цифра указывает на тип ответа:

| Код | Текст | Значение |
|---|---|---|
| **200** | OK | всё в порядке |
| **301** | Moved Permanently | страница окончательно перемещена |
| **404** | Not Found | такого файла нет |
| **405** | Method Not Allowed | этот метод здесь не разрешён |
| **500** | Internal Server Error | ошибка на сервере |

`2xx` означает успех, `3xx` — перенаправление, `4xx` — ошибку клиента (неверный запрос), `5xx` — ошибку сервера.

:::tip Запомни
**HTTP** работает по **принципу «запрос — ответ»**: клиент отправляет **запрос** (метод, например `GET`, путь, заголовки), сервер отвечает **кодом состояния** (например, `200 OK`, `404 Not Found`), заголовками и файлом. Для каждого файла веб-страницы отправляется отдельный запрос.
:::

# Запуск ping и разбор его в трассировщике

:::sim
url=/sims/lesson-1.2.3.btsim
:::

Теперь у обоих ПК есть адреса `192.168.0.10` и `192.168.0.11`. Пора провести первый тест: с помощью **ping** один ПК отправляет другому небольшой запрос и ждёт ответа.

## Запуск ping

Перейди в режим :fa-play: **Запустить**. На **Computer 1** открой :fa-terminal: **Терминал** и введи:

```
$ ping 192.168.0.11
```

Если другой ПК отвечает, ты увидишь для каждого отправленного пакета строку со временем ответа — твой первый успешный ping!

:::tip Запомни
**Ping** проверяет, доступно ли другое устройство: он отправляет запрос и измеряет, сколько времени занимает ответ.
:::

## Разбор в трассировщике

Теперь перейди в режим :fa-magnifying-glass: **Трассировка**. Пока здесь ничего не видно — нажми вверху слева рядом с **Traces:** на **+**, выбери **Computer 1**, а затем его порт `eth0`.

Теперь ты видишь список всех пакетов, прошедших через этот порт, — в том числе и только что отправленные ping. Щёлкни на одном из пакетов: ниже ты увидишь его точную структуру, уровень за уровнем.

:::tip Запомни
Данные в сети отправляются не целиком, а небольшими блоками — **пакетами**. Каждый пакет содержит отправителя, получателя и часть данных.
:::

:::tip
Ping всегда состоит из запроса (Echo Request) и ответа (Echo Reply) — найдёшь ли ты оба направления в столбце **Info**?
:::

## Кто спрашивает перед первым ping?

Самыми первыми в списке, ещё до первого ping, стоят два пакета с протоколом **ARP**. Прочитай их столбец **Info** — там написано примерно следующее:

```
Who has 192.168.0.11? Tell 192.168.0.10
192.168.0.11 is at aa:fd:9f:a5:d2:89
```

Computer 1 знал IP-адрес другого ПК, но ещё не знал его **аппаратный адрес** (*MAC-адрес* — у каждой сетевой карты он свой). Без него он ничего не может отправить. Поэтому сначала он кричит в сеть: *«У кого 192.168.0.11? Сообщи об этом 192.168.0.10!»* Нужный ПК отвечает своим аппаратным адресом. Именно в этом и состоит задача **ARP**.

После этого Computer 1 запоминает ответ — поэтому ARP появляется только перед первым ping, а не перед каждым.

:::tip Запомни
**ARP** находит для известного IP-адреса соответствующий аппаратный адрес (**MAC-адрес**): ПК спрашивает всех в сети, а отвечает только искомое устройство.
:::

Кому Computer 1 отправляет первый ARP-пакет? Посмотри в столбец **Ziel**.
- [ ] Только другому ПК
- [x] Всем устройствам в сети (широковещательно)

:::

На рабочей области ты видишь **Client-PC**, **DNS-Server** и веб-сервер школы `www.beaver-schule.de`. Веб-сервер предоставляет свои страницы также по **HTTPS**.

## Замок в браузере

1. Перейди в режим выполнения :fa-play: **Запустить**, щёлкни на **Client-PC** и открой :fa-globe: **Браузер**.
2. Открой `https://www.beaver-schule.de/` — обрати внимание на **https**.
3. Слева от адреса появится **замок**. Щёлкни на него.

:::quiz short
Для какого имени выдан сертификат (субъект без `CN=`)?
= www.beaver-schule.de
:::

:::quiz short

= Biber Root CA
:::

Проверить ответы
:::

## Почему Client-PC доверяет сертификату?

Открой на **Client-PC** :fa-shield-halved: **Zertifikatverwaltung** (управление сертификатами) и перейди на вкладку **Vertrauenswürdige CAs**.

:::quiz mc
Что ты там находишь?
- [x] Сертификат **Biber Root CA**
- [ ] Сертификат `www.beaver-schule.de`
- [ ] Записей нет
:::

:::quiz mc
Как понять, что Biber Root CA является корневым центром сертификации?
- [x] Он **самоподписанный**: субъект и издатель совпадают
- [ ] Его название заканчивается на «CA»
- [ ] У него нет открытого ключа
:::

:::quiz mc
Что указано у Client-PC в поле **Privater Schlüssel**: «Ja» или «Nein»?
- [ ] Ja — клиенту нужен закрытый ключ центра сертификации, чтобы проверять подписи
- [x] Nein — для проверки достаточно открытого ключа; закрытый ключ есть только у центра сертификации
:::

:::evaluate
Проверить ответы
:::

## Другая сторона: веб-сервер

Теперь открой на веб-сервере **www.beaver-schule.de** :fa-shield-halved: **Zertifikatverwaltung** (вкладка **Meine Zertifikate**) и посмотри его сертификат.

:::quiz multi
Что верно для сертификата на веб-сервере?
- [x] В поле **Privater Schlüssel** указано «Ja» — серверу он нужен для установления соединения
- [x] **Цепочка** выглядит так: `www.beaver-schule.de ← Biber Root CA`
- [x] **Отпечаток** такой же, как в окне замка в браузере
- [ ] Он самоподписанный
:::

:::evaluate
Проверить ответы
:::

:::note
**Отпечаток** — это хеш-значение сертификата. С его помощью можно быстро сравнить два сертификата, не проверяя по отдельности все поля.
:::

:::tip Запомни
**Веб-сервер** владеет своим сертификатом **вместе с закрытым ключом**. **Клиент** знает только **сертификат корневого центра сертификации** (без закрытого ключа) — этого достаточно, чтобы проверить подпись на сертификате сервера. Если щёлкнуть в браузере на **замок**, можно увидеть субъект, издателя, отпечаток и срок действия.
:::

# Поиск неисправностей: пропала страница контактов

:::sim
url=/sims/lesson-6.1.3.btsim
:::

Секретариат сообщает: «На нашем сайте ссылка **Kontakt** теперь ведёт только на сообщение об ошибке». Страница контактов должна открываться по адресу `http://192.168.0.20/kontakt.html`. Найди неисправность и устрани её.

<details>
<summary>Подсказка 1: Что сообщает сервер?</summary>

Открой страницу контактов в браузере или с помощью `curl -v`. Какой код состояния возвращается? Страница с ошибкой также показывает, где сервер искал файл.
</details>

<details>
<summary>Подсказка 2: Где лежат файлы?</summary>

Веб-сервер отдаёт только файлы из своего **корневого каталога документов** (*Document Root*) — он указан в приложении **HTTP-сервер**. Посмотри на **Server** в терминале с помощью `ls`, что там лежит, и поищи страницу контактов также в `/home`.
</details>

<details>
<summary>Подсказка 3: Перемещение файла</summary>

Командой `mv` ты перемещаешь файл: `mv <источник> <целевая папка>`.
</details>

:::task
title: Страница контактов исправлена?
Проверяет, лежит ли страница контактов в корневом каталоге документов веб-сервера.
check: fileExists(2, "/var/www/kontakt.html")
:::

## Что произошло?

:::quiz multi
Какие утверждения верны?
- [x] Сервер ответил `404 Not Found`
- [x] Файл лежал в `/home`, а не в корневом каталоге документов `/var/www`
- [ ] Веб-сервер вообще не был запущен
- [ ] Браузер использовал неверный IP-адрес
:::

:::evaluate
Проверить ответ
:::

:::tip Запомни
Код **404** означает: веб-сервер работает и доступен, но запрошенного **файла** по этому пути нет. Сервер ищет только в своём **корневом каталоге документов** (*Document Root*, здесь `/var/www`). Для сравнения: если сервер не отвечает вообще или отвечает `RST`, проблема глубже — в сети или в самой службе (глава 5.3.2).
:::

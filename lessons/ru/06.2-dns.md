# DNS: имена вместо номеров

:::goal
**Цель обучения:** Ты можешь объяснить, как DNS преобразует имена в IP-адреса, как иерархически организованы имена, самостоятельно создать запись и найти типичные ошибки DNS.
:::

:::sim
url=/sims/lesson-6.2.btsim
:::

IP-адреса почти никто не может запомнить, а вот имена вроде `www.beaver-schule.de` запоминаются легко. Преобразованием занимается **Domain Name System** (**DNS**) — своего рода всемирная телефонная книга интернета.

На рабочей области теперь находится сеть побольше: помимо **Client-PC** и **Webserver** в ней есть четыре **DNS-сервера**. Зачем нужно так много, ты увидишь через страницу.

# Один коммутатор, две сети

:::sim
url=/sims/lesson-3.2.1.btsim
:::

К коммутатору подключены четыре ПК: **Sekretariat** (порт 1) и **Schulleitung** (порт 2) из администрации, а также **Anna** (порт 3) и **Ben** (порт 4) из компьютерного класса. Все они находятся в одной сети `192.168.0.0/24`.

## Проблема

Переключись в :fa-play: режим выполнения, открой на **Anna** :fa-terminal: **Терминал** и отправь ping на Sekretariat:

```
$ ping 192.168.0.10
```

Anna без проблем достаёт до Sekretariat. Именно этого мы и хотим избежать.

## Настройка VLAN

**VLAN** (*Virtual LAN*) — это отдельная, изолированная сеть внутри коммутатора. У каждого VLAN есть номер — **VLAN ID**. Договоримся так: администрация попадает в **VLAN 10**, компьютерный класс — в **VLAN 20**.

1. В режиме выполнения щёлкни по **коммутатору** и открой вкладку **VLAN**.
2. Поставь галочку **включить VLAN**. Появится таблица с одной строкой на каждый порт.
3. В столбце **PVID** укажи VLAN ID: для **port 1** и **port 2** — `10`, для **port 3** и **port 4** — `20`. **Режим** оставь `untagged`.
4. Внизу нажми **Применить**.

:::note
**PVID** означает *Port VLAN ID*: всё, что приходит на этот порт, относится к этому VLAN. Режим `untagged` означает, что к этому порту подключён обычный ПК, которому не нужно ничего знать о VLAN.
:::

## Проверка

Ещё раз отправь ping на Sekretariat с **Anna**, а затем на Ben (`ping 192.168.0.21`).

:::quiz mc
Что происходит теперь?
- [ ] Anna достаёт до Sekretariat и до Ben
- [x] Anna достаёт до Ben, но больше не достаёт до Sekretariat
- [ ] Anna больше никого не достаёт
:::

:::evaluate
Проверить ответ
:::

В :fa-magnifying-glass: режиме **Трассировка** открой трассировку для **Sekretariat**: ARP-запросы Anna («Who has 192.168.0.10?») там вообще не появляются. Её широковещательный пакет остаётся в VLAN 20 — для коммутатора это теперь две отдельные сети, которые ничего не знают друг о друге.

:::tip Запомни
С помощью **VLAN** коммутатор делят на несколько логически разделённых сетей. Устройства в разных VLAN не могут напрямую достучаться друг до друга — даже широковещательные пакеты остаются в своём VLAN. У каждого VLAN есть номер — **VLAN ID**.
:::

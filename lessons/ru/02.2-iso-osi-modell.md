# Эталонная модель ISO/OSI

Модель ISO/OSI делит взаимодействие между двумя устройствами на семь уровней. Каждый уровень выполняет чётко очерченную задачу и использует только службы уровня, расположенного непосредственно под ним:

Из эксперимента на предыдущей странице ты уже знаешь четыре из этих уровней: Ethernet (2), IPv4 (3), TCP (4) и HTTP (7). Именно эти номера и цвета Трассировщик показывает тебе в дереве протоколов.

:::tip Мнемоническое правило
Начиная с уровня 7 и вниз: **П**ростой **П**рограммист **С**ам **Т**естирует **С**вои **К**од **Ф**ункции — **П**рикладной, **П**редставления, **С**еансовый, **Т**ранспортный, **С**етевой, **К**аналь­ный, **Ф**изический.
:::

:::note Пограничные случаи
Не каждый протокол точно вписывается в один уровень. Поэтому для таких протоколов Трассировщик показывает сразу несколько уровней:

- **ARP** — уровень 2/3: у него нет IP-заголовка, но он связывает IP-адреса (уровень 3) с аппаратными адресами (уровень 2).
- **TLS** — уровень 4/5: он работает непосредственно поверх TCP и управляет защищённым сеансом.
- **HTTPS** (HTTP внутри TLS) — уровни 5–7: классический прикладной уровень модели TCP/IP, с которой ты познакомишься на следующей странице.
:::

:::note
Уровень 1 описывает собственно передачу сигналов по кабелю или по радио. BeaverTracer не имитирует этот уровень — кабели всегда считаются подключёнными без ошибок, проблем с сигналом и коллизий нет. Поэтому в Трассировщике рассмотрение практически начинается с уровня 2.
:::

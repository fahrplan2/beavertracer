# Маршрутизатор

:::goal
**Цель обучения:** Ты можешь объяснить, как маршрутизатор соединяет две сети, настроить шлюз на ПК и обосновать, когда ПК доставляет пакет напрямую, а когда через шлюз.
:::

:::sim
url=/sims/lesson-4.3.1.btsim
:::

**Маршрутизатор** соединяет разные сети между собой. Для этого у него для каждой сети есть отдельный порт — и на каждом порту собственный IP-адрес именно из этой сети. На рабочей области ты снова видишь фирму A и фирму B, но на этот раз с маршрутизатором между ними.

# Таблица NAT

:::sim
url=/sims/lesson-7.1.btsim
:::

Когда ПК и планшет одновременно загружают одну и ту же веб-страницу, оба запроса приходят на веб-сервер с адреса `203.0.113.2`. Как домашний маршрутизатор узнаёт, кому предназначен ответ? Он ведёт учёт — в **таблице NAT**.

## Эксперимент

1. Перейди в режим выполнения :fa-play: **Запустить** и открой на **PC** и на **Tablet** адрес `http://www.beispiel.de/`.
2. Щёлкни по **Heimrouter** и открой вкладку **NAT**.

Каждая строка — это **соответствие**: протокол, LAN-IP и LAN-порт устройства в домашней сети — и **WAN-порт**, который маршрутизатор использует для него на своём публичном адресе.

:::quiz short
Какой WAN-IP указан над таблицей?
= 203.0.113.2
:::

:::quiz mc
ПК и планшет оба установили соединение с LAN-портом `49152`. Какой WAN-порт они получают?
- [ ] Оба один и тот же, `49152`
- [x] Каждый — свой, иначе маршрутизатор не знал бы, кому принадлежит ответ
- [ ] Никакого, NAT изменяет только IP-адрес
:::

:::quiz mc
Ответ веб-сервера приходит на `203.0.113.2` с определённым **портом назначения**. Что делает с ним домашний маршрутизатор?
- [x] Он ищет порт в таблице NAT и отправляет пакет на соответствующий LAN-IP и LAN-порт
- [ ] Он отправляет пакет всем устройствам в домашней сети
- [ ] Он отбрасывает пакет
:::

:::evaluate
Проверить ответы
:::

Здесь снова вступают в игру **порты** из главы 5: поскольку NAT переписывает и порты, сотни соединений могут использовать один адрес. Поэтому, строго говоря, это называется **PAT** (*Port Address Translation*) или *NAT с трансляцией портов* — но в повседневной речи всё равно говорят просто NAT.

Вот как, например, может выглядеть такая трансляция:

| | Пакет от ПК (в домашней сети) | тот же пакет в интернете |
|---|---|---|
| Отправитель | `192.168.178.20 : 49152` | `203.0.113.2 : 10001` |
| Получатель | `192.0.2.80 : 80` | `192.0.2.80 : 80` |

:::tip Запомни
В **таблице NAT** маршрутизатор запоминает для каждого соединения, какое устройство (**LAN-IP и LAN-порт**) скрывается за каким **WAN-портом**. Ответы из интернета он снова сопоставляет нужному устройству по порту назначения. Поскольку порты тоже переписываются, точнее говорить о **PAT**.
:::

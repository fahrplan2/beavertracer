# Двоичная система счисления

Внутри компьютер знает только два состояния: ток есть или тока нет. Для этого пишут **1** и **0**. Один такой разряд называется **битом**. Любой IP-адрес для компьютера тоже всего лишь последовательность нулей и единиц. Чтобы ты понимал, как работают маски сети, на этой странице ты научишься читать такие числа и самостоятельно переводить их.

## Как мы обычно считаем: десятичная система

В повседневной жизни мы считаем с помощью десяти цифр (от 0 до 9). Каждый разряд стоит в десять раз больше, чем разряд справа от него: единицы, десятки, сотни, тысячи. Число `305` означает:

| Вес разряда | 100 | 10 | 1 |
|---|---|---|---|
| Цифра | 3 | 0 | 5 |
| Значение | 300 | 0 | 5 |

300 + 0 + 5 = **305**

## Двоичная система счисления

В **двоичной системе счисления** есть только две цифры: 0 и 1. Каждый разряд стоит **вдвое** больше, чем разряд справа от него: 1, 2, 4, 8, 16, 32, 64, 128 …

Двоичное число `00001101` означает:

| Вес разряда | 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1 |
|---|---|---|---|---|---|---|---|---|
| Бит | 0 | 0 | 0 | 0 | 1 | 1 | 0 | 1 |
| Значение | | | | | 8 | 4 | | 1 |

8 + 4 + 1 = **13**

Ты просто складываешь веса тех разрядов, в которых стоит 1.

:::tip Запомни
**Бит** — это один разряд двоичной системы (0 или 1). **8 бит** составляют **байт**. В сетевой технике такую группу из 8 бит также называют **октетом**. Веса разрядов октета: **128, 64, 32, 16, 8, 4, 2, 1**.
:::

## Из десятичной системы в двоичную

В обратную сторону ты проходишь по весам разрядов слева направо и каждый раз спрашиваешь: **вмещается ли вес разряда в моё (оставшееся) число?** Если да, пишешь 1 и вычитаешь вес разряда. Если нет, пишешь 0.

Пример: `168`

| Вес разряда | вмещается в …? | Бит | Остаток |
|---|---|---|---|
| 128 | 168 → да | **1** | 40 |
| 64 | 40 → нет | **0** | 40 |
| 32 | 40 → да | **1** | 8 |
| 16 | 8 → нет | **0** | 8 |
| 8 | 8 → да | **1** | 0 |
| 4 | 0 → нет | **0** | 0 |
| 2 | 0 → нет | **0** | 0 |
| 1 | 0 → нет | **0** | 0 |

Если читать сверху вниз: 168 = **10101000**

:::tip Совет
Эти значения постоянно встречаются при работе с масками сети, поэтому их стоит запомнить: `10000000` = 128, `11000000` = 192, `11100000` = 224, `11110000` = 240, `11111000` = 248, `11111100` = 252, `11111110` = 254, `11111111` = 255.
:::

## IP-адреса в двоичной системе

IPv4-адрес состоит из **32 бит**, то есть из четырёх октетов. Поскольку никто не запомнит 32 нуля и единицы, каждый октет записывают в виде десятичного числа, а октеты разделяют точками:

```
11000000 . 10101000 . 10110010 . 00000001
   192   .   168    .   178    .    1
```

:::quiz short
Из скольких бит состоит IPv4-адрес?
= 32
:::

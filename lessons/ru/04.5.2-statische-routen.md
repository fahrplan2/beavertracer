# Добавление статических маршрутов

:::sim
url=/sims/lesson-4.5.2.btsim
:::

На этот раз между фирмой A и фирмой B находятся **два** маршрутизатора. Они соединены собственной небольшой сетью — **промежуточной сетью** `10.0.0.0/30`:

| Маршрутизатор | Интерфейс | IP-адрес | Сеть |
|---|---|---|---|
| Router A | `eth0` | `192.168.0.1/24` | Фирма A (Anna) |
| Router A | `eth1` | `10.0.0.1/30` | Промежуточная сеть |
| Router B | `eth0` | `10.0.0.2/30` | Промежуточная сеть |
| Router B | `eth1` | `172.16.0.1/24` | Фирма B (Clara) |

:::note
В сети `/30` ровно два пригодных для использования адреса — идеально для соединения двух маршрутизаторов (см. раздел 4.2.3).
:::

## Проблема

Переключись в режим :fa-play: **Запустить** и отправь с компьютера **Anna** ping на Clara (`ping 172.16.0.10`). Clara не отвечает — вместо неё отзывается Router A (`192.168.0.1`) с сообщением «Сеть назначения недостижима».

Посмотри **Таблица маршрутизации IPv4** на **Router A**.

:::quiz mc
Почему ping от Anna не доходит до Clara?
- [ ] У Anna не указан шлюз
- [x] Router A не знает сеть `172.16.0.0/24` — она не подключена к нему напрямую, и маршрута к ней нет
- [ ] Промежуточная сеть слишком мала
:::

:::evaluate
Проверить ответ
:::

## Добавление маршрута

Router A должен узнать: пакеты для `172.16.0.0/24` нужно отправлять на Router B (`10.0.0.2`) через `eth1`.

1. На **Router A** открой вкладку **Таблица маршрутизации IPv4** и нажми **+ hinzufügen**.
2. В новой строке укажи: **Ziel** `172.16.0.0`, **Netzmaske** `255.255.255.0`, **Следующий переход** `10.0.0.2`, **Iface** `eth1`.
3. Сохрани строку с помощью галочки :fa-check:. В столбце **Quelle** теперь стоит **Статический**.

Снова отправь ping на Clara — теперь ответ приходит.

:::note
Router B, кстати, уже знает обратный путь к фирме A: в его таблице маршрутизации уже есть статический маршрут для `192.168.0.0/24` через `10.0.0.1`. Почему этот обратный путь так же важен, ты увидишь на следующей странице.
:::

## Отслеживание пути: traceroute

С помощью `traceroute` можно узнать, через какие маршрутизаторы проходит пакет. Введи на **Anna**:

```
$ traceroute 172.16.0.10
```

:::quiz short
Через сколько маршрутизаторов проходит пакет от Anna к Clara?
= 2
= два
= две
:::

:::quiz mc
Какой адрес показывает `traceroute` для Router B?
- [x] `10.0.0.2` — его адрес в промежуточной сети, через который пакет поступает на маршрутизатор
- [ ] `172.16.0.1` — его адрес в сети фирмы B
- [ ] `192.168.0.1`
:::

:::evaluate
Проверить ответы
:::

`traceroute` использует хитрость со **временем жизни (Time to Live)** из раздела 4.3.1: сначала он отправляет пакет с TTL 1. Первый маршрутизатор вычитает 1, получает 0, отбрасывает пакет и сообщает об этом отправителю — так Anna узнаёт первый маршрутизатор. Затем TTL 2 для второго маршрутизатора и так далее, пока не ответит получатель.

:::tip Запомни
**Статический маршрут** администратор вносит вручную: сеть назначения, маска сети, следующий переход и интерфейс. С помощью **traceroute** можно проследить путь пакета маршрутизатор за маршрутизатором.
:::

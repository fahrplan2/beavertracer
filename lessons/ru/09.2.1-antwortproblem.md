# Проблема ответных пакетов

:::sim
url=/sims/lesson-9.2.btsim
:::

Теперь файрвол работает по принципу белого списка: политика по умолчанию — **Отбрасывать всё**. Единственное правило разрешает школьной сети выход в интернет: **B → A, TCP, порт назначения 80, Разрешить**. Режим установлен на **Stateless**.

## Эксперимент

1. Перейди в режим выполнения :fa-play: **Запустить** и открой на **Lehrer-PC** в :fa-globe: **Браузер** адрес `http://203.0.113.80/`.
2. Посмотри в **Firewall** **журнал** и **попадания**.

:::quiz mc
Что происходит в браузере?
- [ ] Появляется страница www.beispiel.de
- [x] Страница не загружается, браузер ждёт и в конце концов сообщает об ошибке
:::

:::quiz mc
Какие пакеты отмечены в журнале файрвола как отброшенные (`DROP`)?
- [ ] Запросы Lehrer-PC на порт 80
- [x] Ответы от `203.0.113.80` с **портом источника 80** к Lehrer-PC
- [ ] Никакие
:::

:::quiz short
В каком направлении (A→B или B→A) идут отброшенные пакеты?
= A→B
= A → B
= AtoB
:::

:::evaluate
Проверить ответы
:::

Запрос Lehrer-PC выходит наружу, но уже `SYN, ACK` от веб-сервера не возвращается: для направления A → B нет подходящего правила, поэтому действует **Отбрасывать всё**.

## Наивное решение

Можно добавить второе правило: **A → B, TCP, порт источника 80, Разрешить** — «всё, что приходит с порта 80, пропускается внутрь». Тогда веб-серфинг действительно заработает.

:::quiz mc
Почему это правило опасно?
- [ ] Потому что веб-серверы никогда не используют порт 80 в качестве порта источника
- [x] Злоумышленник может просто отправить свои пакеты с портом источника 80 — и тогда файрвол пропустит их на **любой** порт в школьной сети
- [ ] Потому что тогда веб-страницы загружаются медленнее
:::

:::evaluate
Проверить ответ
:::

Порт источника определяет сам отправитель, поэтому файрволу нельзя на него полагаться. Файрвол без отслеживания состояния не знает, является ли пакет **ответом на запрос** или **новой попыткой соединения** извне. Именно это меняет режим с отслеживанием состояния.

:::tip Запомни
**Пакетный фильтр без отслеживания состояния** проверяет каждый пакет по отдельности. Тогда для ответов нужны отдельные правила для обратного направления, а такие правила (например, «порт источника 80 пропускается внутрь») могут использовать злоумышленники, потому что отправитель может свободно выбирать порт источника.
:::

# VLAN на двух коммутаторах: транк

:::sim
url=/sims/lesson-3.2.2.btsim
:::

В школе два этажа, на каждом по одному коммутатору. Они соединены кабелем через **порт 8**:

| Коммутатор | Порт 1 (VLAN 10, администрация) | Порт 2 (VLAN 20, компьютерный класс) |
|---|---|---|
| **Switch EG** (первый этаж) | Sekretariat `192.168.0.10` | Anna `192.168.0.20` |
| **Switch OG** (второй этаж) | Schulleitung `192.168.0.11` | Ben `192.168.0.21` |

VLAN на портах компьютеров уже настроены.

## Проблема

Перейди в режим выполнения :fa-play: **Запустить** и отправь с компьютера **Anna** ping на Ben (`ping 192.168.0.21`). Оба находятся в VLAN 20, но ответа нет.

Посмотри на вкладке **VLAN** любого из коммутаторов строку **port 8**: там всё ещё стоит `untagged` и PVID `1`. Значит, по этому кабелю идёт только VLAN 1, а VLAN 10 и VLAN 20 не проходят.

Но по кабелю между коммутаторами должны проходить кадры из *обоих* VLAN. Для этого коммутатор «приклеивает» к каждому кадру маленькую бирку с идентификатором VLAN — это **тег VLAN**. Так коммутатор на другом конце знает, к какому VLAN относится кадр.

## Настройка транка

Сделай это на **обоих** коммутаторах:

1. Щёлкни по коммутатору и открой вкладку **VLAN**.
2. В строке **port 8** установи **режим** `tagged` и в поле **Разрешённые VLAN** введи `10,20`.
3. Нажми **Применить**.

Затем ещё раз отправь ping с **Anna** на Ben — и для сравнения на Schulleitung (`ping 192.168.0.11`).

:::quiz mc
Что происходит теперь?
- [x] Anna достигает Ben, но не достигает Schulleitung
- [ ] Anna достигает и Ben, и Schulleitung
- [ ] Anna по-прежнему никого не достигает
:::

## Тег VLAN в трассировщике

Перейди в режим :fa-magnifying-glass: **Трассировка** и с помощью **+** открой трассировку для **Switch EG**, порт **8** — это кабель между коммутаторами. Щёлкни по одному из ping-запросов Anna (`Echo (ping) request`).

В дереве протоколов появилась новая строка прямо под Ethernet: **802.1Q Virtual LAN**. Это и есть тег VLAN.

:::quiz short
Какой идентификатор VLAN указан в теге ping-запроса Anna?
= 20
:::

Для сравнения открой трассировку для **Ben** (`eth0`) и щёлкни там по тому же ping-запросу.

:::quiz mc
Что ты замечаешь у Ben?
- [ ] Там тот же тег с идентификатором 20
- [x] Строки 802.1Q там нет — коммутатор снова удалил тег перед портом Ben
- [ ] Ping до Ben вообще не доходит
:::

Проверить ответы
:::

:::tip Запомни
**Транк** — это соединение, по которому проходят кадры из нескольких VLAN, обычно между двумя коммутаторами. Для этого каждый кадр получает **тег VLAN** с идентификатором VLAN (стандарт **IEEE 802.1Q**). Такие порты называются **tagged**. К порту **untagged** подключается обычное устройство; коммутатор удаляет тег перед отправкой кадра туда.
:::

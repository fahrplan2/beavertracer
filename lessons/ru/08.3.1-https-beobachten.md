# Сравнение HTTP и HTTPS

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Веб-сервер **www.beaver-schule.de** предоставляет доступ к школьному порталу оценок как по HTTP, так и по HTTPS. Что увидит тот, кто прослушивает трафик?

## Эксперимент

1. Перейди в режим выполнения (:fa-play: **Запустить**) и на **Client-PC** в :fa-globe: **Браузер** сначала открой `http://www.beaver-schule.de/`, а затем `https://www.beaver-schule.de/`.
2. В режиме :fa-magnifying-glass: **Трассировка** открой трассу для **Client-PC**.
3. Сначала найди пакет `HTTP/1.1 200 OK` и щёлкни по нему. Внизу, в подробностях, ты найдёшь содержимое страницы.

:::quiz mc
Что может увидеть тот, кто прослушивает трафик, при использовании **HTTP**?
- [x] Всю веб-страницу целиком, в том числе оценки Анны
- [ ] Только адрес сервера
- [ ] Ничего, потому что HTTP работает поверх TCP
:::

:::quiz short
Какая оценка у Анны по математике?
= 2
:::

:::evaluate
Проверить ответы
:::

Теперь часть про HTTPS. Найди пакет `[SYN]`, с которого клиент начинает второе соединение.

:::quiz short
Какой порт назначения у HTTPS-соединения (столбец **Info**, `… → ???`)?
= 443
:::

Теперь введи вверху в поле фильтра трассы `tls` — тогда ты увидишь только TLS-пакеты.

:::quiz mc
Что указано в столбце **Info** у пакетов, содержащих веб-страницу?
- [ ] `HTTP/1.1 200 OK`
- [x] `Application Data`
- [ ] `Encrypted HTML`
:::

:::quiz multi
Что при использовании **HTTPS** тот, кто прослушивает трафик, всё же может увидеть?
- [x] IP-адреса клиента и сервера
- [x] Что используется порт 443, то есть, вероятно, HTTPS
- [x] Примерно сколько данных передаётся
- [ ] Какая страница была открыта и что на ней написано
:::

:::evaluate
Проверить ответы
:::

:::note
Щёлкни по пакету **Application Data**: полезные данные — это лишь последовательность внешне случайных байтов. Трассировщик не может их расшифровать — он знает ключ сеанса так же мало, как и злоумышленник.
:::

:::tip Запомни
При использовании **HTTP** любой, кто прослушивает трафик, может прочитать всю веб-страницу целиком. При использовании **HTTPS** он видит только то, **кто с кем** общается (IP-адреса, порт 443), и **сколько** данных передаётся — содержимое находится в зашифрованном виде в пакетах **Application Data**.
:::

# DMZ

:::sim
url=/sims/lesson-9.3.btsim
:::

До сих пор **Schulserver** находился в одной сети с **Lehrer-PC**. Это опасно: Schulserver доступен из интернета. Если злоумышленник найдёт уязвимость в веб-сервере и захватит компьютер, он окажется **прямо внутри школьной сети** — а межсетевой экран уже ничего не сможет сделать, ведь трафик от Schulserver к Lehrer-PC не проходит через него.

Решение: серверы, которые должны быть доступны из интернета, помещают в **отдельную сеть** между интернетом и внутренней сетью. Эта сеть называется **DMZ** (*демилитаризованная зона*, по названию нейтральной полосы между двумя границами).

## Структура

На рабочей области ты видишь классическую модель с **двумя межсетевыми экранами**:

```
Internet ──[ Firewall außen ]── Schulrouter ──── DMZ: Schulserver (198.51.100.10)
                                    │
                             [ Firewall innen ]
                                    │
                    LAN: Lehrer-PC (192.0.2.20), Schüler-PC (192.0.2.21)
```

- **Firewall außen** защищает всё от интернета. Порт A подключён к интернету, порт B — к Schulrouter.
- **Firewall innen** защищает локальную сеть (LAN) — в том числе от DMZ. Порт A подключён к Schulrouter, порт B — к LAN.

Сейчас оба межсетевых экрана пропускают всё.

## Задача: защитить DMZ

Переведи **оба** межсетевых экрана в режим **Stateful** и **Alle verwerfen** и добавь подходящие правила:

- **Firewall außen:** изнутри наружу (B → A) разрешено всё; снаружи (A → B) — только TCP 80 и 25 к Schulserver `198.51.100.10`.
- **Firewall innen:** из LAN (B → A) разрешено всё; в направлении LAN (A → B) правило не нужно — ответы возвращаются благодаря таблице состояний.

:::note
Многие межсетевые экраны имеют три и более интерфейса («зоны») и реализуют DMZ в одном устройстве. Принцип тот же: трафик между интернетом, DMZ и LAN всегда должен проходить через правила. У модели с двумя межсетевыми экранами есть преимущество: злоумышленнику нужно преодолеть **два** барьера — для этого часто используют устройства разных производителей, чтобы одна и та же уязвимость не открыла оба.
:::

:::tip Запомни
В **DMZ** помещают все серверы, которые должны быть доступны из интернета. Она находится между двумя межсетевыми экранами (или в отдельной зоне одного межсетевого экрана): из интернета разрешён доступ только к определённым службам в DMZ, из LAN разрешён доступ в DMZ и в интернет — но из DMZ и из интернета **нет пути в LAN**. Если сервер в DMZ захвачен, LAN остаётся защищённой.
:::

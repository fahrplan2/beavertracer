У Beaver-школы есть собственные публичные адреса (`198.51.100.…`): её **Schulserver** доступен прямо из интернета — без NAT, так, как скоро будет повсюду с IPv6 (глава 7.3). Между интернетом и **Schulrouter** стоит **межсетевой экран** (файрвол), который пока ещё пропускает всё.

Слева ты видишь «интернет»: **Internet-PC** и веб-сервер `www.beispiel.de`. Справа — школьная сеть со **Schulserver** и **Lehrer-PC**.

## Что видит злоумышленник?

Тот, кто хочет атаковать сервер, сначала ищет **открытые порты** — то есть службы, которые ожидают соединений. Инструмент для этого называется **сканер портов**; самый известный из них — `nmap`.

Переключись в режим выполнения :fa-play: **Запустить**, открой на **Internet-PC** :fa-terminal: **Терминал** и введи:

```
$ nmap 198.51.100.10
```

`nmap` пытается установить TCP-соединение с 20 самыми распространёнными портами и сообщает, какие из них открыты.

:::quiz multi
Какие порты на Schulserver открыты из интернета?
- [x] 22 (SSH, удалённое администрирование)
- [x] 25 (SMTP)
- [x] 80 (HTTP)
- [x] 110 (POP3)
- [x] 143 (IMAP)
- [ ] 443 (HTTPS)
:::

:::evaluate
Проверить ответ
:::

Веб-сайт (80) и приём электронной почты (25) должны быть доступны из интернета. Но **удалённое администрирование** (22) и получение почты (110, 143) нужны только школьной сети. Каждый открытый порт — это возможная поверхность атаки: если у службы есть уязвимость или слабый пароль, злоумышленник может воспользоваться ею из любой точки мира — а автоматические сканеры в интернете занимаются именно этим круглосуточно.

:::tip Запомни
**Межсетевой экран** контролирует трафик на границе между двумя сетями и пропускает только то, что явно разрешено. Так службы, которые нужны только внутри, остаются невидимыми для интернета.
:::

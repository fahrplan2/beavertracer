# Настройка домашнего маршрутизатора

:::sim
url=/sims/lesson-7.1.2.btsim
:::

Новый домашний маршрутизатор только что подключили, но пока никто не может выйти в интернет. От провайдера ты получил письмо с **данными для подключения**:

| Данные для подключения | Значение |
|---|---|
| WAN-IP-адрес | `203.0.113.2` |
| Длина префикса | `/30` |
| Шлюз (маршрутизатор провайдера) | `203.0.113.1` |
| DNS-сервер провайдера | `198.51.100.10` |

1. Перейди в режим выполнения :fa-play: **Запустить**, щёлкни на **Heimrouter** и открой вкладку **WAN**.
2. Введи данные для подключения и нажми **Применить**.
3. Подключи **Tablet** к Wi-Fi: :fa-gear: **Параметры IP**, вкладка **WiFi**, SSID `Biberbau`, **Применить**.
4. Проверь на ПК командой `ping 192.0.2.80` или в браузере по адресу `http://www.beispiel.de/`.

:::note
На практике домашний маршрутизатор обычно получает свой WAN-адрес от провайдера автоматически (по DHCP или при входе с именем пользователя и паролем). Фиксированные данные для подключения, как здесь, чаще встречаются при корпоративных подключениях.
:::

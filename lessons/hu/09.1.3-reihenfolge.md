# Sorrend és alapállás

## Először a kivétel, aztán a szabály

Mivel az **első illeszkedő szabály** érvényesül, a sorrend számít. Nézd meg ezt a szabálylistát (minden szabály az A → B irányra vonatkozik, alapértelmezett szabályzat: Mindent engedélyez):

| Sz. | Protokoll | Cél port | Művelet |
|---|---|---|---|
| 1 | TCP | bármely | Eldobás |
| 2 | TCP | 80 | Engedélyezés |

:::quiz mc
Az internetről egy csomag érkezik a 80-as TCP-portra. Mi történik?
- [ ] Engedélyezve lesz, mert a 2. szabály pontosan a 80-as portot engedi
- [x] Eldobásra kerül, mert már az 1. szabály illeszkedik — a 2. szabályhoz sosem jut el
- [ ] A tűzfal rákérdez a rendszergazdánál
:::

:::evaluate
Válasz ellenőrzése
:::

Általános szabály: **a speciális szabályok kerüljenek felülre, az általánosak alulra.** Az a szabály, amely sok mindent lefed, „beárnyékolja” az alatta lévő összes szabályt. Az ilyen halott szabályokat a **Találat** oszlop árulja el: náluk az érték 0 marad.

## Feketelista vagy fehérlista?

A 9.1.2 szakaszban egyes portokat **tiltottál le**, minden mást pedig engedélyeztél. Ezt nevezik **feketelistának** (*blacklist*). Ennek az ellentéte a **fehérlista** (*whitelist*): csak a szükségeset **engedélyezed**, minden mást pedig tiltasz — egy záró „mindent eldob” szabállyal vagy a **Mindent eldob** alapértelmezett szabályzattal.

| | Feketelista | Fehérlista |
|---|---|---|
| Alapállás | minden engedélyezett, a kivételek tiltottak | minden tiltott, a kivételek engedélyezettek |
| Alapértelmezett szabályzat | Engedélyezés | Eldobás |
| új szolgáltatás a szerveren | azonnal elérhető kívülről | zárolva marad, amíg valaki nem engedélyezi |

:::quiz mc
Egy tanár holnap telepít az iskolai szerverre egy adatbázist, amely a 3306-os porton figyel. Mi történik a 9.1.2 szakasz tűzfalával (feketelista)?
- [x] Az adatbázis azonnal elérhető az internetről
- [ ] Az adatbázis automatikusan le van zárva
- [ ] A tűzfal jelzi az új szolgáltatást
:::

:::evaluate
Válasz ellenőrzése
:::

Ezért a jó tűzfalak a **fehérlista-elv** szerint működnek („Default Deny”): minden, ami nincs kifejezetten engedélyezve, tiltott. Az iskolai szerver fehérlistája így nézne ki:

:::quiz table
| Sz. | Irány | Protokoll | Cél port | Művelet |
|---|---|---|---|---|
| 1 | A → B | TCP | {80} | {Engedélyezés} |
| 2 | A → B | TCP | {25} | Engedélyezés |
| 3 | A → B | bármely | bármely | {Eldobás} |
:::

:::evaluate
Táblázat ellenőrzése
:::

:::quiz mc
Mi történik, ha a 3. szabályt egészen felülre helyezzük?
- [ ] Semmi, a sorrend mindegy
- [x] Az internetről egyáltalán semmi sem jut át, sem a web, sem a levelezés
- [ ] Már csak a web és a levelezés jut át
:::

:::evaluate
Válasz ellenőrzése
:::

:::tip Jegyezd meg!
Mivel az **első illeszkedő szabály** érvényesül, a **speciális szabályok kerüljenek felülre**, az általánosak pedig alulra. A **feketelistánál** (minden engedélyezett, kivéve …) biztonságosabb a **fehérlista** (minden tiltott, kivéve …, *Default Deny*): az elfelejtett vagy új szolgáltatások így automatikusan zárolva maradnak.
:::

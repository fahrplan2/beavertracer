# IPv6 a hálózatban

:::sim
url=/sims/lesson-4.6.3.btsim
:::

A switchre Anna, Ben és egy router csatlakozik. Annánál és Bennél az IPv6 **SLAAC (automatisch)** beállításon van — IPv6-címet nem adott meg nekik senki. A router ismeri a `2001:db8:1::/64` prefixet.

## Honnan jön a cím?

1. Válts :fa-play: **Futtatás** módra, és várj néhány másodpercet.
2. Nyisd meg **Annán** a :fa-terminal: **Terminál**t, és add ki az `ip a` parancsot.

Az IPv4-cím mellett két `inet6` sort látsz: egy címet `scope link`, egyet pedig `scope global` értékkel.

:::quiz mc
A két IPv6-cím közül melyik a link-local cím?
- [x] Amelyik `fe80::`-val kezdődik (`scope link`)
- [ ] Amelyik `2001:db8:1:`-gyel kezdődik (`scope global`)
:::

:::quiz mc
Honnan származik a globális cím `2001:db8:1:0` prefixe?
- [ ] Anna maga találta ki
- [x] A routertől — ő hirdeti meg a prefixet a hálózatban
- [ ] A switchtől
:::

:::evaluate
Válaszok ellenőrzése
:::

Hasonlítsd össze az **interfész-azonosítót** (az utolsó négy blokkot) Anna **MAC-címével** — ezt az :fa-gear: **IP-beállítások** ablak legalján találod. A `aa:28:39:e2:41:82` MAC-címből például az `a828:39ff:fee2:4182` interfész-azonosító lesz: középre beszúródik az `ff:fe`, az elején pedig egy bit megfordul (ezért lesz az `aa`-ból `a8`).

Ezt az eljárást **SLAAC**-nak nevezzük (*Stateless Address Autoconfiguration*): a router meghirdeti a prefixet, az interfész-azonosítót pedig minden eszköz maga képezi.

:::note
Mivel a MAC-cím egyértelműen azonosít egy eszközt, az interfész-azonosítója alapján az eszköz az interneten bárhol felismerhető lenne. A valódi eszközök ezért általában emellett véletlenszerű interfész-azonosítókat is használnak, amelyek rendszeresen változnak (*Privacy Extensions*) — ez egy kis adatvédelem.
:::

## Szomszédok megkeresése — ARP nélkül

1. Add ki **Benen** az `ip a` parancsot, és jegyezd meg a **globális** IPv6-címét.
2. Pingeld meg **Annáról**, például így: `ping 2001:db8:1:0:…` (Ben teljes címével).
3. Válts :fa-magnifying-glass: **Nyomkövetés** módra, és nyiss egy nyomkövetést **Annához**.

Nézd meg a csomagokat közvetlenül az első `Echo (ping) request` előtt.

:::quiz multi
Mely állítások igazak?
- [x] ARP-kérés helyett Anna egy **Neighbor Solicitation** üzenetet küld („Kié ez a cím?”)
- [x] Ben egy **Neighbor Advertisement** üzenettel válaszol, és megadja a MAC-címét
- [x] A kérés egy multicast címre megy (`ff02::1:ff…`), nem broadcasttal mindenkinek
- [ ] Anna ARP-kérést küld, mint IPv4-nél
- [x] A router rendszeresen **Router Advertisement** üzeneteket küld az `ff02::1` címre — ezekben szerepel a prefix
:::

:::evaluate
Válaszok ellenőrzése
:::

:::tip Jegyezd meg!
IPv6-nál az **NDP** (*Neighbor Discovery Protocol*, az ICMPv6 része) veszi át az ARP feladatait: a **Neighbor Solicitation** és a **Neighbor Advertisement** üzenetekkel az eszközök megtalálják szomszédaik MAC-címét. A **Router Advertisement** üzenetekkel a router meghirdeti a prefixet — ebből az eszközök **SLAAC**-kal maguk képezik a címüket.
:::

# Az üzenetváltási diagram

:::sim
url=/sims/lesson-5.1.btsim
:::

Egy kapcsolat lefolyását **üzenetváltási diagrammal** ábrázoljuk: a kliens és a szerver egy-egy függőleges vonalat kap, az idő fentről lefelé telik. Minden nyíl egy csomag. Ferdén van rajzolva, mert minden csomag egy ideig úton van.

Így néz ki a kapcsolatod az előző oldalról — hasonlítsd össze sorról sorra a nyomkövetéssel:

:::seq
Client-PC -> Server: SYN
Server -> Client-PC: SYN, ACK
Client-PC -> Server: ACK
Client-PC -> Server: PSH, ACK "Hello World" len=13
Server -> Client-PC: ACK
Server -> Client-PC: PSH, ACK len=13
Client-PC -> Server: ACK
Client-PC -> Server: FIN, ACK
Server -> Client-PC: ACK
Server -> Client-PC: FIN, ACK
Client-PC -> Server: ACK
:::

Minden nyíl felett a **flagek** állnak, alatta a `SEQ` és `ACK` számok. A **DATA** a hasznos adatot tartalmazó csomagokat jelöli. A piros számok a klienshez tartoznak, a kékek a szerverhez — hogy mit jelentenek, azt a következő oldal tisztázza.

## A flagek

| Flag | jelentése | Funkció |
|---|---|---|
| **SYN** | *synchronize* | kapcsolat felépítése, kezdőszám meghatározása |
| **ACK** | *acknowledge* | a megkapott adatok nyugtázása |
| **PSH** | *push* | az adatok azonnali átadása a programnak |
| **FIN** | *finish* | „Végeztem“ — a kapcsolat lebontása |
| **RST** | *reset* | a kapcsolat megszakítása vagy elutasítása (erről többet az 5.3.2-ben) |

## Három fázis

**Felépítés:** a kliens `SYN` csomagot küld, a szerver `SYN, ACK`-val válaszol, a kliens `ACK`-val nyugtáz. Mivel pontosan három csomag szükséges hozzá, ezt **háromutas kézfogásnak** nevezzük.

**Adatok:** minden adatot tartalmazó csomagot a címzett egy `ACK`-val nyugtáz. Itt a szerver visszaküldi az echót — ezt is nyugtázza a kliens.

**Lebontás:** mindkét fél külön fejezi be a saját küldési irányát: `FIN` a klienstől, `ACK` a szervertől — majd `FIN` a szervertől, `ACK` a klienstől. Ez négy csomag.

:::tip Jegyezd meg!
Egy TCP-kapcsolat három fázisban zajlik: **felépítés** a **háromutas kézfogással** (`SYN` → `SYN, ACK` → `ACK`), **adatátvitel** (minden adatcsomagot `ACK`-val nyugtázunk) és **lebontás** (mindkét fél `FIN`-t küld, és `ACK`-t kap).
:::

## Most te jössz

A kliens ezúttal csak a `Hi` szöveget küldi (a sorvéggel együtt 4 bájt). Írd be a hiányzó flageket — egy mezőn belül a sorrend mindegy.

:::quiz seq
hide: counters
Client-PC -> Server: ? SYN
Server -> Client-PC: ? SYN, ACK
Client-PC -> Server: ? ACK
Client-PC -> Server: PSH, ACK "Hi" len=4
Server -> Client-PC: ? ACK
Client-PC -> Server: ? FIN, ACK
Server -> Client-PC: ? ACK
Server -> Client-PC: ? FIN, ACK
Client-PC -> Server: ? ACK
:::

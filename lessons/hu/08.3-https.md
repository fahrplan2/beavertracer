# HTTPS

:::osi 5
:::

A **HTTPS** (*HTTP Secure*) teljesen hétköznapi HTTP — csakhogy nem közvetlenül TCP-n fut, hanem közéjük kerül egy titkosított réteg: a **TLS** (*Transport Layer Security*). A TLS elődjét **SSL**-nek hívták; ezért beszélnek még ma is gyakran „SSL-tanúsítványokról“.

```
ohne Verschlüsselung:   HTTP  →  TCP  →  IP
mit Verschlüsselung:    HTTP  →  TLS  →  TCP  →  IP
```

A HTTP ebből semmit sem vesz észre: a kéréseit a megszokott módon küldi, a TLS titkosítja őket, a TCP pedig szállítja. Az OSI-modellben a TLS a szállítási és az alkalmazási réteg között helyezkedik el, tehát a 4/5. rétegben — a TCP-re épül, és egy védett munkamenetet kezel.

| | HTTP | HTTPS |
|---|---|---|
| Port | 80 | **443** |
| Cím | `http://…` | `https://…` |
| A tartalom olvasható a Tracerben? | igen | nem |
| A böngésző ezt mutatja | „nem biztonságos“ | lakat |

A TLS a kapcsolatfelépítés során elvégzi mindazt, amit ebben a fejezetben megtanultál:

- A szerver a **tanúsítványával** igazolja magát (**hitelesség**).
- A két fél **Diffie-Hellman** segítségével egyeztet egy **munkamenetkulcsot** — a szerver **aláírja** a saját részét.
- Ezután az összes adatot **AES**-sel titkosítják (**bizalmasság**), és védik a módosítás ellen (**sértetlenség**).

Az elv nem korlátozódik a webre: az e-mail (8.4. szakasz) és sok más protokoll is ugyanígy TLS-en keresztül működik.

# Az otthoni router beállítása

:::sim
url=/sims/lesson-7.1.2.btsim
:::

Egy új otthoni routert csatlakoztattak éppen — de még senki sem jut az internetre. A szolgáltatótól kaptál egy levelet a **hozzáférési adatokkal**:

| Hozzáférési adatok | Érték |
|---|---|
| WAN IP-cím | `203.0.113.2` |
| Prefixhossz | `/30` |
| Átjáró (a szolgáltató routere) | `203.0.113.1` |
| A szolgáltató DNS-szervere | `198.51.100.10` |

1. Válts :fa-play: **Futtatás** módra, kattints a **Heimrouter** eszközre, és nyisd meg a **WAN** fület.
2. Add meg a hozzáférési adatokat, majd kattints az **Alkalmaz** gombra.
3. Csatlakoztasd a **Tablet** eszközt a Wi-Fi-hálózathoz: :fa-gear: **IP-beállítások**, **WiFi** fül, SSID `Biberbau`, **Alkalmaz**.
4. Tesztelj a számítógépen a `ping 192.0.2.80` paranccsal, vagy a böngészőben a `http://www.beispiel.de/` címmel.

:::note
A gyakorlatban az otthoni router a WAN-címét többnyire automatikusan kapja a szolgáltatótól (DHCP-vel, vagy felhasználónévvel és jelszóval történő bejelentkezéssel). Az itt látotthoz hasonló rögzített hozzáférési adatok inkább a céges csatlakozásoknál szokásosak.
:::

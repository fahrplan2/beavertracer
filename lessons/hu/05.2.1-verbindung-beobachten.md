# Egy kapcsolat az elejétől a végéig

:::sim
url=/sims/lesson-5.1.btsim
:::

A **Server** gépen az Echo-szolgáltatás az `5000`-es porton fut: minden üzenetet azonnal visszaküld. Az **Egyszerű TCP kliens** segítségével lépésről lépésre irányíthatsz egy kapcsolatot — minden gomb egy fázist jelent.

## A kísérlet

1. Válts :fa-play: **Futtatás** módba, kattints a **Client-PC**-re, és nyisd meg az **Egyszerű TCP kliens**t.
2. A **Host** mezőbe írd be: `192.168.0.20`, a **Port** mezőbe pedig: `5000`.
3. Kattints a **Csatlakozás** gombra.
4. Írd be az üzenetmezőbe: `Hello World`, majd kattints a **Küldés** gombra. A csevegőablakban rögtön ezután látod a szerver visszhangját.
5. Kattints a **Leválasztás** gombra.
6. Válts :fa-magnifying-glass: **Nyomkövetés** módba, és a **+** gombbal nyiss egy trace-t a **Client-PC**-hez, `eth0` csatlakozóra.

:::note
A kezdeti két ARP-csomagot már ismered az 1. fejezetből. A TCP-csomagok **Info** oszlopában először `49152 → 5000` áll (melyik portról melyik portra), majd szögletes zárójelben a **flagek**, utána pedig olyan számok, mint a `Seq=`, `Ack=` és `Len=`. A számokról az 5.2.3. oldaltól lesz szó — itt a flagekre és a `Len` értékre figyelj.
:::

## 1. fázis: Csatlakozás

:::quiz short
Hány TCP-csomagot cseréltek ki, miután a **Csatlakozás** gombra kattintottál — még mielőtt az üzeneted elindult volna?
= 3
= három
:::

:::quiz mc
Ki küldi az első `[SYN]` csomagot?
- [x] A Client-PC
- [ ] A Server
:::

:::quiz mc
Milyen flagekkel válaszol rá a szerver?
- [ ] `[SYN]`
- [x] `[SYN, ACK]`
- [ ] `[ACK]`
- [ ] `[FIN, ACK]`
:::

## 2. fázis: Küldés

A `Len` azt adja meg, hány bájt felhasználói adatot hordoz egy csomag.

:::quiz short
Hány bájtot hordoz az üzenetedet tartalmazó csomag (`Len`)?
= 13
:::

:::note
A `Hello World` csak 11 karakter hosszú. A TCP kliens azonban sorvégjelet is hozzáfűz (2 bájt, `\r\n`) — sok internetes protokoll, például az SMTP vagy a HTTP is így várja.
:::

:::quiz mc
Mit küld vissza a szerver közvetlenül az üzeneted után — még a visszhang előtt?
- [x] Egy `[ACK]` és `Len=0` jelölésű csomagot — adat nélküli visszaigazolást
- [ ] Semmit
- [ ] Egy új `[SYN]` csomagot
:::

## 3. fázis: Leválasztás

:::quiz short
Hány csomag tartozik a lebontáshoz — az első `FIN` jelölésű csomagtól kezdve?
= 4
= négy
:::

:::quiz mc
Mit közöl az a fél, amelyik `FIN` csomagot küld?
- [x] „Végeztem” — nem küld több adatot
- [ ] „Hiba történt”
- [ ] „Itt jönnek az új adatok”
:::

## Hol van a négy feladat?

Párosítsd össze, hol találod meg az 5.1. szakasz feladatait a trace-ben:

:::quiz match
Kapcsolatfelépítés -> A három csomag: [SYN], [SYN, ACK] és [ACK]
Megbízható átvitel -> A [ACK] és Len=0 jelölésű csomagok, amelyek visszaigazolják a fogadást
Kapcsolatbontás -> A FIN jelölésű csomagok és azok visszaigazolásai
Multiplexelés -> A 49152 → 5000 portszámok a szögletes zárójelek előtt
:::

# POP3 vagy IMAP?

:::sim
url=/sims/lesson-6.3.btsim
:::

A levelek letöltésére két protokoll áll rendelkezésre. Ebben a szimulációban **Anna POP3-at** használ, **Ben pedig IMAP-ot**.

## A kísérlet

1. :fa-play: **Futtatás** módban küldj egy levelet **Ben** gépéről az `anna@beaver-schule.de` címre.
2. **Anna** **E-Mail** alkalmazásában kattints a **Letöltés** gombra.
3. Nyisd meg a nyomkövetéseket **Anna** és **Ben** számára, és hasonlítsd össze a letöltéskor használt parancsokat.

:::quiz match
USER / PASS -> POP3: bejelentkezés felhasználónévvel és jelszóval két lépésben
RETR -> POP3: egy üzenet letöltése
LOGIN -> IMAP: bejelentkezés felhasználónévvel és jelszóval
SELECT INBOX -> IMAP: egy mappa megnyitása a szerveren
:::

:::evaluate
Párosítás ellenőrzése
:::

## A különbség

| | POP3 | IMAP |
|---|---|---|
| Port | 110 | 143 |
| Alapötlet | a leveleket **letölti** — utána általában törli a szerverről | a levelek **a szerveren maradnak**, és ott kezelhetők |
| Mappák, olvasott/olvasatlan | csak a saját eszközön | a szerveren — mindenhol ugyanaz |
| Több eszköz (telefon, laptop) | kényelmetlen: minden eszköz más állapotot mutat | ideális: minden eszköz ugyanazt a postafiókot látja |

:::note
A BeaverTracer levelezőprogramja POP3 esetén is a szerveren hagyja a leveleket. A valódi programok letöltés után gyakran törlik őket — vagy csak egy ideig hagyják ott.
:::

:::quiz mc
Lena a telefonján, a tabletjén és az iskolai laptopján olvassa a leveleit. Mit érdemes használnia?
- [ ] POP3-at, mert egyszerűbb
- [x] IMAP-ot, mert minden eszköz ugyanazt a postafiókot látja a szerveren
- [ ] SMTP-t, mert az a letöltésre szolgál
:::

:::evaluate
Válasz ellenőrzése
:::

:::tip Jegyezd meg!
A **POP3** a leveleket a szerverről **egyetlen** eszközre tölti le. Az **IMAP** a postafiókot **a szerveren** kezeli — mappákkal és olvasottsági állapottal, egyszerre minden eszköz számára. Mindkettő csak a **letöltésre** szolgál; a küldés mindig **SMTP**-vel történik.
:::

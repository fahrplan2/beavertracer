## Hogyan néz ki egy kérés

Kattints a trace-ben a `GET / HTTP/1.1` csomagra, és nyisd ki a **Hypertext Transfer Protocol** részt. Egy HTTP-kérés egyszerű szöveg:

```
GET / HTTP/1.1              ← Methode, Pfad, Version
Host: 192.168.0.20          ← Header: zusätzliche Angaben
…
                            ← Leerzeile: Ende der Anfrage
```

A szerver válasza ugyanígy épül fel — egy állapotsorral, header-ekkel, egy üres sorral, majd magával a fájllal:

```
HTTP/1.1 200 OK             ← Version, Statuscode, Text
Content-Type: text/html     ← Header: Art der Datei
Content-Length: 301         ← Header: Größe in Byte
                            ← Leerzeile
<!doctype html> …           ← die Datei selbst
```

:::seq
mode: text
Client-PC -> Server: GET / | HTTP-kérés
Server -> Client-PC: 200 OK | index.html
Client-PC -> Server: GET /style.css | HTTP-kérés
Server -> Client-PC: 200 OK | style.css
:::

## Metódusok és állapotkódok

A **metódus** megmondja, mit akar a kliens:

| Metódus | Jelentés |
|---|---|
| **GET** | egy fájl lekérése |
| **POST** | adatok küldése a szervernek, pl. egy kitöltött űrlapé |
| **HEAD** | csak a header-ek lekérése, a fájl nélkül |

Az **állapotkód** megmondja, hogyan sikerült a kérés. Az első számjegy elárulja a válasz fajtáját:

| Kód | Szöveg | Jelentés |
|---|---|---|
| **200** | OK | minden rendben |
| **301** | Moved Permanently | az oldal véglegesen áthelyezték |
| **404** | Not Found | a fájl nem létezik |
| **405** | Method Not Allowed | ez a metódus itt nem engedélyezett |
| **500** | Internal Server Error | hiba a szerveren |

A `2xx` sikert, a `3xx` átirányítást, a `4xx` a kliens hibáját (hibás kérés), az `5xx` a szerver hibáját jelenti.

:::tip Jegyezd meg!
A **HTTP** a **kérés–válasz elv** szerint működik: a kliens egy **kérést** küld (metódus, például `GET`, elérési út, header-ek), a szerver pedig egy **állapotkóddal** (pl. `200 OK`, `404 Not Found`), header-ekkel és a fájllal válaszol. Egy weboldal minden fájljához külön kérés tartozik.
:::

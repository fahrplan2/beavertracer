# Modellek alkalmazása

Rendeld hozzá a fejezet elején szereplő kísérlet protokolljait a megfelelő OSI-réteghez:

:::quiz match
Ethernet -> 2. réteg — adatkapcsolati
IPv4 -> 3. réteg — hálózati
TCP -> 4. réteg — szállítási
HTTP -> 7. réteg — alkalmazási
:::

:::evaluate
Párosítás ellenőrzése
:::

És végül az adategységek nevei:

:::quiz match
Keret -> 2. réteg — adatkapcsolati
Csomag -> 3. réteg — hálózati
Szegmens -> 4. réteg — szállítási
:::

:::evaluate
Párosítás ellenőrzése
:::

Ezzel megvan az eszköztárad ahhoz, hogy a protokollokat a jövőben pontosan be tudd sorolni. A következő fejezettől sorban végigmegyünk a rétegeken — a 2. réteggel kezdve, és azzal a kérdéssel, hogy honnan tudja egy switch, merre kell továbbítania egy csomagot.

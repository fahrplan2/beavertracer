# HTTP kézzel

:::sim

:::

Ha a HTTP egyszerű szöveg, akkor vajon böngésző nélkül, saját magad is tudsz beszélgetni egy webszerverrel? Igen: a `telnet` segítségével TCP-kapcsolatot építesz ki egy tetszőleges porthoz, és magad gépeled be a szöveget.

## A kísérlet

1. Válts :fa-play: **Futtatás** módba, és nyisd meg a **Client-PC** :fa-terminal: **Terminál** ablakát.
2. Csatlakozz a szerver 80-as portjához:
   ```
   $ telnet 192.168.0.20 80
   ```
3. Írd be a kérést sorról sorra, és zárd le egy **üres sorral** (egyszerűen nyomd meg még egyszer az **Entert**):
   ```
   GET /kontakt.html HTTP/1.1
   Host: 192.168.0.20

   ```

A szerver állapotsorral, fejlécekkel és a kapcsolatoldallal válaszol, szövegként, pontosan úgy, ahogy a böngésző is megkapja.

## Hibák előidézése

Kényelmesebb eszköz a `curl`: elküldi helyetted a kérést. A `-v` kapcsolóval (*verbose*, részletes) mindent megmutat, ami oda-vissza megy. A `>` jelű sorokat a `curl` küldte, a `<` jelű sorok a szervertől érkeztek.

Próbáld ki:

```
$ curl -v http://192.168.0.20/gibtsnicht.html
$ curl -X POST -d name=Anna http://192.168.0.20/
```

:::note
A BeaverTracer webszervere csak fájlokat tud kiszolgálni, ezért csak a `GET` és a `HEAD` metódust engedi meg. A valódi webszerverek a `POST` metódussal például űrlapokat fogadnak, és az adatokat továbbadják egy programnak.
:::

:::tip Jegyezd meg!
Az alkalmazási réteg sok protokollja **szövegalapú**: a HTTP, de az SMTP, a POP3 és az IMAP is. Ezért kézzel is „beszélhetsz” velük a `telnet` segítségével, és a Tracerben végig is követheted őket. Ez hasznos a hibakeresésnél, de biztonsági probléma is: bárki, aki rögzíti a forgalmat, mindent elolvashat. A 8. fejezetben megtudod, hogyan segít ebben a titkosítás (HTTPS).
:::

# Sažetak i pogled unaprijed

## Vatrozidi na mnogo mjesta

Paketni filtar iz ovog poglavlja pronaći ćeš u mnogim uređajima:

- **Kućni usmjernik:** Svaki kućni usmjernik ujedno je i vatrozid sa stanjem (engl. *stateful*). Kod IPv4 dio toga preuzima NAT: izvana nitko ne može započeti vezu sve dok ne postoji preusmjeravanje porta (poglavlje 7). Kod IPv6 svi uređaji imaju javne adrese — tada istu zaštitu osigurava samo pravilo vatrozida „izvana ništa novo unutra“.
- **Osobni vatrozid:** I Windows, macOS i Linux imaju ugrađen vatrozid na samom računalu. On štiti uređaj i u tuđim mrežama, npr. u WLAN-u kafića, a može postavljati i pravila po programu.
- **Vatrozid nove generacije** (engl. *Next-Generation Firewall*) i **vatrozid za web aplikacije (WAF)**: ne gledaju samo adrese i portove, nego i sadržaj paketa — sve do aplikacijskog sloja. Tako npr. prepoznaju napade u HTTP zahtjevima. Kod HTTPS-a za to moraju razbiti enkripciju (poglavlje 8).
- **IDS/IPS:** *Intrusion Detection System* prepoznaje sumnjive obrasce u prometu i diže uzbunu; *Intrusion Prevention System* ih dodatno i sam blokira.

:::note
Vatrozid je samo **jedan** od elemenata sigurnosti. Ne pomaže ako sama dopuštena usluga (npr. web-poslužitelj) ima ranjivost, ako netko otvori zlonamjerni program iz e-pošte ili ako je lozinka slaba. Zato ažuriranja, sigurne lozinke, enkripcija i promišljena podjela mreže (DMZ, VLAN-ovi iz poglavlja 3) uvijek spadaju uz to.
:::

## Provjeri svoje znanje

:::quiz mc
Vatrozid radi sa zadanom politikom „Odbaci sve“ i jednim jedinim pravilom „A → B, TCP 443, Dopusti“. Paket A → B stiže na TCP port 22. Što se događa?
- [ ] Bit će dopušten
- [x] Bit će odbačen
- [ ] Bit će odbijen
:::

:::quiz mc
`nmap` za neki port javlja `filtered`. Što to znači?
- [ ] Na portu radi usluga
- [ ] Poslužitelj je odgovorio s RST
- [x] Nije stigao nikakav odgovor — vjerojatno vatrozid odbacuje pakete
:::

:::quiz multi
Koje su tvrdnje točne?
- [x] Kod vatrozida sa stanjem (stateful) odgovori na dopuštene veze automatski se vraćaju
- [x] Bijela lista sigurnija je od crne liste jer nove usluge automatski ostaju blokirane
- [x] Poslužitelji dostupni s interneta pripadaju u DMZ
- [ ] Vatrozid štiti i od napada između dva računala u istoj mreži iza njega
- [ ] Sva se pravila uvijek provjeravaju, a pobjeđuje najstrože
:::

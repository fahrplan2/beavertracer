Web-stranica se dakle često sastoji od mnogo datoteka: teksta, stylesheetova, slika. Za svaku od njih preglednik šalje zaseban zahtjev.

## Kako izgleda zahtjev

Klikni u traceu na paket `GET / HTTP/1.1` i otvori **Hypertext Transfer Protocol**. HTTP zahtjev je čisti tekst:

```
GET / HTTP/1.1              ← Methode, Pfad, Version
Host: 192.168.0.20          ← Header: zusätzliche Angaben
…
                            ← Leerzeile: Ende der Anfrage
```

Odgovor poslužitelja ima jednaku strukturu — sa statusnim retkom, headerima, praznim retkom i nakon toga samom datotekom:

```
HTTP/1.1 200 OK             ← Version, Statuscode, Text
Content-Type: text/html     ← Header: Art der Datei
Content-Length: 301         ← Header: Größe in Byte
                            ← Leerzeile
<!doctype html> …           ← die Datei selbst
```

:::seq
mode: text
Client-PC -> Server: GET / | HTTP-zahtjev
Server -> Client-PC: 200 OK | index.html
Client-PC -> Server: GET /style.css | HTTP-zahtjev
Server -> Client-PC: 200 OK | style.css
:::

## Metode i statusni kodovi

**Metoda** govori što klijent želi:

| Metoda | Značenje |
|---|---|
| **GET** | preuzeti datoteku |
| **POST** | poslati podatke poslužitelju, npr. ispunjen obrazac |
| **HEAD** | preuzeti samo headere, bez datoteke |

**Statusni kod** govori kako je prošlo. Prva znamenka otkriva vrstu odgovora:

| Kod | Tekst | Značenje |
|---|---|---|
| **200** | OK | sve je u redu |
| **301** | Moved Permanently | stranica se trajno preselila |
| **404** | Not Found | datoteka ne postoji |
| **405** | Method Not Allowed | ova metoda ovdje nije dopuštena |
| **500** | Internal Server Error | pogreška na poslužitelju |

`2xx` znači uspjeh, `3xx` preusmjeravanje, `4xx` pogrešku klijenta (neispravan zahtjev), `5xx` pogrešku poslužitelja.

:::tip Zapamti
**HTTP** radi prema **načelu zahtjev–odgovor**: klijent šalje **zahtjev** (metodu poput `GET`, putanju, headere), a poslužitelj odgovara **statusnim kodom** (npr. `200 OK`, `404 Not Found`), headerima i datotekom. Za svaku datoteku web-stranice postoji zaseban zahtjev.
:::

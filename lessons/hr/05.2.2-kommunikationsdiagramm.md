# Dijagram slijeda

:::sim
url=/sims/lesson-5.1.btsim
:::

Tijek veze crta se kao **dijagram slijeda**: klijent i poslužitelj dobivaju po jednu okomitu liniju, a vrijeme teče odozgo prema dolje. Svaka strelica je jedan paket. Nacrtana je koso jer je svaki paket neko vrijeme na putu.

Ovako izgleda tvoja veza s prethodne stranice — usporedi je redak po redak s trasom:

:::seq
Client-PC -> Server: SYN
Server -> Client-PC: SYN, ACK
Client-PC -> Server: ACK
Client-PC -> Server: PSH, ACK "Hello World" len=13
Server -> Client-PC: ACK
Server -> Client-PC: PSH, ACK len=13
Client-PC -> Server: ACK
Client-PC -> Server: FIN, ACK
Server -> Client-PC: ACK
Server -> Client-PC: FIN, ACK
Client-PC -> Server: ACK
:::

Iznad svake strelice nalaze se **zastavice** (flagovi), a ispod njih brojevi `SEQ` i `ACK`. **DATA** označava pakete s korisnim podacima. Crveni brojevi pripadaju klijentu, a plavi poslužitelju — što znače, objašnjava sljedeća stranica.

## Zastavice

| Zastavica | znači | Značenje |
|---|---|---|
| **SYN** | *synchronize* | uspostaviti vezu, odrediti početni broj |
| **ACK** | *acknowledge* | potvrđuje primljene podatke |
| **PSH** | *push* | odmah predati podatke programu |
| **FIN** | *finish* | „Gotov sam” — prekinuti vezu |
| **RST** | *reset* | prekinuti ili odbiti vezu (više o tome u 5.3.2) |

## Tri faze

**Uspostava:** klijent šalje `SYN`, poslužitelj odgovara s `SYN, ACK`, a klijent potvrđuje s `ACK`. Budući da su potrebna točno tri paketa, to se zove **trostrano rukovanje** (three-way handshake).

**Podaci:** primatelj potvrđuje svaki paket s podacima paketom `ACK`. Ovdje poslužitelj šalje natrag odjek (echo) — i njega klijent potvrđuje.

**Raskid:** svaka strana zasebno završava svoj smjer slanja: `FIN` od klijenta, `ACK` od poslužitelja — zatim `FIN` od poslužitelja, `ACK` od klijenta. To su četiri paketa.

:::tip Zapamti
TCP veza odvija se u tri faze: **uspostava** s **trostranim rukovanjem** (`SYN` → `SYN, ACK` → `ACK`), **prijenos podataka** (svaki paket s podacima potvrđuje se s `ACK`) i **raskid** (svaka strana šalje `FIN` i dobiva `ACK`).
:::

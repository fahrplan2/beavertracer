## Pokus

1. Prebaci se u :fa-play: način izvođenja (**Pokreni**), klikni na **Client-PC** i otvori :fa-globe: **Preglednik**.
2. Ovaj put otvori `http://www.beaver-schule.de/` — s imenom umjesto IP adrese.
3. Prebaci se u :fa-magnifying-glass: način **Praćenje** i otvori trace za **Client-PC**.

Tek nakon što Client-PC sazna IP adresu, uspostavlja TCP vezu s web poslužiteljem — točno kao u poglavlju 5.

:::seq
mode: text
Client-PC -> DNS-Resolver: DNS-Anfrage | A www.beaver-schule.de?
DNS-Resolver -> Client-PC: DNS-Antwort | A 192.168.0.20
:::

## Odakle računalo zna DNS poslužitelj?

Na **Client-PC**-ju otvori :fa-gear: **IP postavke**: u polju **DNS-Server** piše `192.168.0.53` — računalo **DNS-Resolver**. Računalo mu šalje svaki upit za imenom.

DNS poslužitelja možeš pitati i izravno, bez preglednika. Otvori :fa-terminal: **Terminal** i upiši:

```
$ nslookup www.beaver-schule.de
```

`nslookup` prvo prikazuje koji je poslužitelj pitao, a zatim odgovor. Za usporedbu pitaj za ime koje ne postoji, npr. `nslookup gibtsnicht.beaver-schule.de`.

:::quiz mc
Što DNS poslužitelj odgovara na nepoznato ime?
- [ ] Nasumičnu IP adresu
- [x] `NXDOMAIN` — to ime ne postoji
- [ ] Ništa
:::

:::evaluate
Provjeri odgovor
:::

:::tip Zapamti
**DNS** prevodi imena (npr. `www.beaver-schule.de`) u IP adrese. Prije nego što računalo može uspostaviti vezu prema imenu, pita **DNS poslužitelj** upisan u njegovim IP postavkama — najčešće putem **UDP-a, port 53**. Pomoću `nslookup` možeš ručno slati DNS upite.
:::

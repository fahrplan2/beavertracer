# Paketni filtar: pravila

Najjednostavnija i najvažnija vrsta vatrozida je **paketni filtar**. Pregledava svaki paket koji ga prolazi i na temelju **popisa pravila** odlučuje smije li proći. Pritom čita samo zaglavlja slojeva 3 i 4 — sadržaj (npr. web-stranicu) ne razmatra.

## Od čega se sastoji pravilo

| Polje | Značenje | Primjer |
|---|---|---|
| **Smjer** | S koje strane dolazi paket? | A → B (s interneta u školsku mrežu) |
| **Protokol** | TCP, UDP, ICMP ili bilo koji | TCP |
| **Izvorišna IP adresa** | adresa ili mreža pošiljatelja | bilo koja |
| **Izvorišni port** | port pošiljatelja | bilo koji |
| **Odredišna IP adresa** | adresa ili mreža primatelja | `198.51.100.10` |
| **Odredišni port** | port primatelja, dakle usluga | `80` |
| **Radnja** | Što se događa s paketima koji odgovaraju pravilu? | Dopusti |

Prazno polje znači „bilo koji“. Mreže se pišu u CIDR zapisu, npr. `198.51.100.0/24`, a rasponi portova s crticom, npr. `1024-65535`.

## Redoslijed je odlučujući

Vatrozid provjerava pravila **od vrha prema dnu**. Odlučuje **prvo pravilo koje odgovara** — sva sljedeća pravila se za taj paket više ne razmatraju. Ako nijedno pravilo ne odgovara, vrijedi **zadana politika** (*Default Policy*).

## Tri moguće radnje

| Radnja | Što vatrozid radi | Što pošiljatelj primijeti |
|---|---|---|
| **Dopusti** (*Allow*) | paket se prosljeđuje | — |
| **Odbaci** (*Drop*) | paket se bez ikakve poruke baca | baš ništa — čeka dok ne istekne timeout |
| **Odbij** (*Reject*) | paket se baca, a pošiljatelj dobiva odbijenicu: kod TCP-a **RST**, inače ICMP „nedostupno“ | odmah poruku o pogrešci |

Što je bolje? **Odbacivanje** napadaču odaje manje i oduzima mu vrijeme jer mora čekati nakon svakog pokušaja. **Odbijanje** je ljubaznije prema vlastitim korisnicima: program odmah dobiva poruku o pogrešci umjesto da dugo visi. U praksi se zato paketi izvana obično odbacuju, a paketi iz vlastite mreže odbijaju.

:::quiz match
Dopusti -> Paket se prosljeđuje
Odbaci -> Paket nestaje, pošiljatelj uzalud čeka odgovor
Odbij -> Paket se ne prosljeđuje, ali pošiljatelj odmah dobiva odbijenicu
Zadana politika -> Vrijedi ako nijedno pravilo ne odgovara
:::

:::tip Zapamti
**Paketni filtar** provjerava svaki paket prema smjeru, protokolu, adresama i portovima u odnosu na **popis pravila**. O radnji odlučuje **prvo pravilo koje odgovara**: **Dopusti**, **Odbaci** (bez poruke) ili **Odbij** (s odbijenicom). Ako nijedno pravilo ne odgovara, vrijedi **zadana politika**.
:::

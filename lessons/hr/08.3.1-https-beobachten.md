# Usporedba HTTP-a i HTTPS-a

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Web-poslužitelj **www.beaver-schule.de** nudi školski portal s ocjenama putem HTTP-a i putem HTTPS-a. Što vidi onaj tko prisluškuje?

## Pokus

1. Prebaci se u :fa-play: način izvođenja (**Pokreni**) i na **Client-PC** u :fa-globe: **Preglednik** prvo otvori `http://www.beaver-schule.de/`, a zatim `https://www.beaver-schule.de/`.
2. U načinu :fa-magnifying-glass: **Praćenje** otvori trace za **Client-PC**.
3. Prvo pronađi paket `HTTP/1.1 200 OK` i klikni na njega. Dolje u detaljima pronaći ćeš sadržaj stranice.

:::quiz mc
Što onaj tko prisluškuje može vidjeti kod **HTTP-a**?
- [x] Cijelu web-stranicu, uključujući Annine ocjene
- [ ] Samo adresu poslužitelja
- [ ] Ništa, jer HTTP radi preko TCP-a
:::

:::quiz short
Koju ocjenu iz matematike ima Anna?
= 2
:::

:::evaluate
Provjeri odgovore
:::

Sada slijedi HTTPS dio. Pronađi paket `[SYN]` kojim klijent započinje drugu vezu.

:::quiz short
Koji odredišni port ima HTTPS veza (stupac **Info**, `… → ???`)?
= 443
:::

Sada u gornje polje filtra u traceu upiši `tls` — tada ćeš vidjeti samo TLS pakete.

:::quiz mc
Što piše u stupcu **Info** kod paketa koji sadrže web-stranicu?
- [ ] `HTTP/1.1 200 OK`
- [x] `Application Data`
- [ ] `Encrypted HTML`
:::

:::quiz multi
Što onaj tko prisluškuje kod **HTTPS-a** ipak još uvijek može vidjeti?
- [x] IP adrese klijenta i poslužitelja
- [x] Da se koristi port 443, dakle vjerojatno HTTPS
- [x] Otprilike koliko se podataka prenosi
- [ ] Koja je stranica otvorena i što na njoj piše
:::

:::evaluate
Provjeri odgovore
:::

:::note
Klikni na paket **Application Data**: korisni podaci samo su niz naizgled nasumičnih bajtova. Tracer ih ne može dešifrirati — sesijski ključ ne poznaje ništa bolje od napadača.
:::

:::tip Zapamti
Kod **HTTP-a** svatko tko prisluškuje može pročitati cijelu web-stranicu. Kod **HTTPS-a** vidi samo **tko s kim** komunicira (IP adrese, port 443) i **koliko** podataka — sadržaj je šifriran unutar paketa **Application Data**.
:::

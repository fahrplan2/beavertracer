# Hash vrijednosti: otisak prsta podataka

:::sim
url=/sims/lesson-8.1.3.btsim
:::

**Hash funkcija** iz proizvoljno velike količine podataka — rečenice, dokumenta, cijelog filma — izračunava kratak niz znakova fiksne duljine: **hash vrijednost**. Ona funkcionira poput **otiska prsta**: isti podaci uvijek daju istu hash vrijednost, a drugačiji podaci drugačiju.

Danas uobičajena hash funkcija zove se **SHA-256**. Njezina hash vrijednost uvijek je duga 256 bitova, a kao heksadecimalni broj to je 64 znaka.

## Pokus

Na računalu **PC** u mapi `/home` nalaze se tri datoteke s malim kupoprodajnim ugovorom. Prijeđi u :fa-play: način izvođenja **Pokreni**, na računalu **PC** otvori :fa-terminal: **Terminal** i upiši:

```
$ cd /home
$ cat vertrag.txt vertrag-kopie.txt vertrag-neu.txt
$ sha256sum vertrag.txt vertrag-kopie.txt vertrag-neu.txt
```

## Svojstva hash funkcije

| Svojstvo | Značenje |
|---|---|
| **fiksna duljina** | Bez obzira na veličinu podataka — hash vrijednost uvijek ima istu duljinu. |
| **jednoznačnost** | Isti podaci uvijek daju istu hash vrijednost. |
| **lavinski efekt** | Već i najmanja promjena daje potpuno drugačiju hash vrijednost. |
| **jednosmjerna funkcija** | Iz hash vrijednosti podaci se **ne** mogu izračunati unatrag. |
| **otpornost na kolizije** | Praktički je nemoguće pronaći dvije različite datoteke s istom hash vrijednošću. |

Hash funkcija **nije šifriranje**: ne postoji ključ niti dešifriranje. Ona služi drugoj svrsi — **integritetu**.

## Čemu to služi?

- **Provjera preuzimanja:** Mnoge web stranice uz datoteku navode i njezinu SHA-256 vrijednost. Ako se hash vrijednost tvoje preuzete datoteke podudara s njom, datoteka se putem nije promijenila.
- **Spremanje lozinki:** Dobre web stranice ne spremaju tvoju lozinku, nego samo njezinu hash vrijednost. Pri prijavi uspoređuje se hash vrijednost onoga što upišeš. Ako se baza podataka ukrade, lopov ipak ne zna lozinke.
- **Digitalni potpisi:** Umjesto cijelog dokumenta potpisuje se samo njegova hash vrijednost — više o tome u sljedećem odjeljku.

:::tip Zapamti
**Hash funkcija** (npr. **SHA-256**) iz proizvoljnih podataka izračunava **hash vrijednost** fiksne duljine — **otisak prsta**. Već i najmanja promjena daje potpuno drugačiju hash vrijednost, a iz hash vrijednosti podaci se ne mogu izračunati unatrag. Hash vrijednosti osiguravaju **integritet** podataka.
:::

# HTTPS

:::osi 5
:::

**HTTPS** (*HTTP Secure*) je sasvim obični HTTP — samo što ne radi izravno preko TCP-a, nego kroz šifrirani sloj između: **TLS** (*Transport Layer Security*). Prethodnik TLS-a zvao se **SSL**; zato se još uvijek često govori o „SSL certifikatima“.

```
ohne Verschlüsselung:   HTTP  →  TCP  →  IP
mit Verschlüsselung:    HTTP  →  TLS  →  TCP  →  IP
```

HTTP od toga ništa ne primjećuje: šalje svoje zahtjeve kao i uvijek, TLS ih šifrira, TCP ih prenosi. U OSI modelu TLS se nalazi između transportnog i aplikacijskog sloja, dakle u sloju 4/5 — nadograđuje se na TCP i upravlja zaštićenom sesijom.

| | HTTP | HTTPS |
|---|---|---|
| Port | 80 | **443** |
| Adresa | `http://…` | `https://…` |
| Sadržaj čitljiv u Traceru? | da | ne |
| Preglednik prikazuje | „nije sigurno“ | lokot |

TLS pri uspostavi veze obavlja sve što si naučio/naučila u ovom poglavlju:

- Poslužitelj se predstavlja svojim **certifikatom** (**autentičnost**).
- Obje strane dogovaraju **Diffie-Hellmanom** **sesijski ključ** — poslužitelj **potpisuje** svoj dio.
- Nakon toga svi se podaci šifriraju pomoću **AES-a** (**povjerljivost**) i štite od izmjena (**integritet**).

Načelo nije ograničeno na web: i e-pošta (odjeljak 8.4) i mnogi drugi protokoli na isti način rade kroz TLS.

U sljedećim odjeljcima promatrat ćeš HTTPS u Traceru, sam/sama ga postaviti i istražiti kada preglednik upozorava — i zašto.

# NAT tablica

:::sim
url=/sims/lesson-7.1.btsim
:::

Kada PC i tablet istodobno učitavaju istu web-stranicu, oba zahtjeva stižu na web-poslužitelj s adrese `203.0.113.2`. Kako kućni usmjernik zna kome je odgovor namijenjen? On vodi evidenciju — u **NAT tablici**.

## Pokus

1. Prijeđi u :fa-play: način izvođenja (**Pokreni**) i na **PC-u** i na **Tabletu** otvori `http://www.beispiel.de/`.
2. Klikni na **Heimrouter** i otvori karticu **NAT**.

Svaki redak je jedno **pridruživanje**: protokol, LAN IP i LAN port uređaja u kućnoj mreži — te **WAN port** koji usmjernik za to koristi na svojoj javnoj adresi.

:::quiz short
Koja se WAN IP adresa nalazi iznad tablice?
= 203.0.113.2
:::

:::quiz mc
PC i tablet oba su uspostavili vezu s LAN portom `49152`. Koji WAN port dobivaju?
- [ ] Oba isti, `49152`
- [x] Svaki drugi — inače usmjernik ne bi znao kome odgovor pripada
- [ ] Nikakav, NAT mijenja samo IP adresu
:::

:::quiz mc
Odgovor web-poslužitelja stiže na `203.0.113.2` s određenim **odredišnim portom**. Što kućni usmjernik radi s njim?
- [x] Traži port u NAT tablici i šalje paket na pripadajuću LAN IP adresu i LAN port
- [ ] Šalje paket svim uređajima u kućnoj mreži
- [ ] Odbacuje paket
:::

:::evaluate
Provjeri odgovore
:::

Ovdje se ponovno javljaju **portovi** iz 5. poglavlja: budući da NAT prepisuje i portove, stotine veza mogu dijeliti jednu adresu. Strogo gledano, to se stoga zove **PAT** (*Port Address Translation*) ili *NAT s prevođenjem portova* — u svakodnevnom govoru ipak se jednostavno kaže NAT.

Ovako bi, na primjer, mogla izgledati takva zamjena:

| | Paket s PC-a (u kućnoj mreži) | isti paket na internetu |
|---|---|---|
| Pošiljatelj | `192.168.178.20 : 49152` | `203.0.113.2 : 10001` |
| Primatelj | `192.0.2.80 : 80` | `192.0.2.80 : 80` |

:::tip Zapamti
U **NAT tablici** usmjernik za svaku vezu bilježi koji se uređaj (**LAN IP i LAN port**) krije iza kojeg **WAN porta**. Odgovore s interneta pomoću odredišnog porta ponovno pridružuje pravom uređaju. Budući da se prepisuju i portovi, preciznije se govori o **PAT-u**.
:::

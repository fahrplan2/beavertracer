# Povezivanje dviju mreža

:::sim
url=/sims/lesson-4.3.1.btsim
:::

Usmjernik ima dva priključka:

| Priključak | IP adresa | Mreža |
|---|---|---|
| `eth0` | `192.168.0.1/24` | Firma A |
| `eth1` | `172.16.0.1/24` | Firma B |

Da bi računala koristila usmjernik, na svakom od njih upisan je **gateway**: kod Anne i Bena `192.168.0.1`, kod Clare i Davida `172.16.0.1`. Možeš ga pronaći u :fa-gear: **IP postavke** u polju **Gateway**.

:::tip Zapamti
**Gateway** (točnije: *zadani gateway*) je IP adresa usmjernika **u vlastitoj mreži**. Računalo na gateway šalje sve pakete čije se odredište nalazi u stranoj mreži.
:::

## Pokus

1. Prebaci se u :fa-play: način izvođenja (**Pokreni**) i pingaj s računala **Anna** računalo Clara (`ping 172.16.0.10`). Ovaj put uspijeva — obrati pažnju na vrijednost `ttl=` u ispisu.
2. Prebaci se u :fa-magnifying-glass: način **Praćenje** i otvori trace za **Annu**.

Pogledaj prvi paket (ARP zahtjev):

:::quiz multi
Koje su tvrdnje o prvom paketu točne?

- [ ] Anna traži MAC adresu računala Clara
- [x] Anna pita sve uređaje u mreži za MAC adresu usmjernika

:::

Sada klikni na prvi `Echo (ping) request` i otvori **Ethernet II** i **Internet Protocol Version 4**. Usporedi MAC adrese s ARP odgovorom prije njega.

## Što usmjernik radi s paketom

Usmjernik prima okvir od Anne, raspakira IP paket i pogleda **odredišnu IP adresu**. Po njoj prepoznaje: Clara se nalazi u mreži na `eth1`. Zato paket pakira u **novi** okvir — sa svojom MAC adresom kao pošiljatelja i Clarinom MAC adresom kao odredištem — i šalje ga tamo.

| Što se događa na usmjerniku s … | |
|---|---|
| MAC adresama (sloj 2)? | postavljaju se **ispočetka** — vrijede samo u pojedinoj mreži |
| IP adresama (sloj 3)? | **ostaju iste** — od Anne do Clare |
| Time to Live? | smanjuje se za **1** |

:::tip Zapamti
**Usmjernik** radi na **sloju 3**: prosljeđuje pakete u druge mreže na temelju **odredišne IP adrese**. IP adrese ostaju iste na cijelom putu, a MAC adrese postavljaju se ispočetka u svakoj mreži. Svaki usmjernik smanjuje **Time to Live (TTL)** za 1 — kad dosegne 0, paket se odbacuje. Tako paket ne može beskonačno kružiti.
:::

:::note
Sjećaš li se broadcast oluje iz poglavlja 3.4? Ethernet okviri nemaju TTL — IP paketi imaju.
:::

## Koga Anna poznaje? ARP cache

Sjećaš li se poglavlja 1.2.3? Tamo se ARP pojavio samo prije *prvog* pinga jer je računalo zapamtilo odgovor. Taj popis zapamćenih adresa zove se **ARP cache** (također *ARP tablica*). Upit se naziva **ARP-Request**, a odgovor **ARP-Reply** (ili *ARP-Response*).

Prebaci se u :fa-play: način izvođenja (**Pokreni**), na računalu **Anna** otvori :fa-terminal: **Terminal** i prikaži njezin ARP cache:

```
$ arp
```

:::quiz mc
Što piše u Anninu ARP cacheu?
- [x] Samo IP adresa usmjernika (`192.168.0.1`) s njegovom MAC adresom
- [ ] Clarina IP adresa s Clarinom MAC adresom
- [ ] Adrese usmjernika i Clare
:::

:::evaluate
Provjeri odgovor
:::

Anna nikada ne treba Clarinu MAC adresu: sve što je namijenjeno firmi B šalje usmjerniku. Clarinu MAC adresu poznaje samo usmjernik — on ju je na svojoj strani sam saznao putem ARP-a.

:::tip Zapamti
U **ARP cacheu** uređaj pamti koja MAC adresa pripada kojoj IP adresi — tako ne mora slati ARP zahtjev prije svakog paketa. Prikazuje se naredbom `arp`. Računalo poznaje samo MAC adrese iz **vlastite** mreže: za sva odredišta u stranim mrežama koristi MAC adresu usmjernika.
:::

:::note
U stvarnim mrežama unosi u ARP cacheu nakon nekog se vremena brišu i po potrebi ponovno traže — na primjer ako je uređaj u međuvremenu dobio drugu mrežnu karticu. U BeaverTraceru ostaju sačuvani sve dok simulacija traje.
:::

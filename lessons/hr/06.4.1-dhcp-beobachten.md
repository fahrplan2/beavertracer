# Automatsko dobivanje adrese

:::sim
url=/sims/lesson-6.4.btsim

Na switch su spojeni **DHCP Server** i dva prijenosnika. Prijenosnici još imaju fiksne adrese.

## Eksperiment

1. Prebaci se u :fa-play: **Pokreni** način izvođenja, klikni na **Laptop 1** i otvori :fa-gear: **IP postavke**.
2. Promijeni **Način** iz **Statički** u **DHCP** i klikni na **Primijeni**.
3. Pričekaj nekoliko sekundi: polja će se sama popuniti.
4. U načinu :fa-magnifying-glass: **Praćenje** otvori trace za **Laptop 1**.

| IP adresa | {192.168.0.100} |
| Gateway | {192.168.0.1} |
| DNS poslužitelj | {192.168.0.53} |

## Što se krije iza toga: DORA

Uređaj bez adrese ne zna gdje se nalazi DHCP poslužitelj, a nema ni vlastitu adresu pošiljatelja. Zato putem **broadcasta** doziva u mrežu. Postupak ima četiri koraka — prema njihovim početnim slovima zove se **DORA**:

:::seq
mode: text
Laptop 1 -> DHCP-Server: DHCP Discover | „Ima li ovdje DHCP poslužitelja?“
DHCP-Server -> Laptop 1: DHCP Offer | „Možeš dobiti 192.168.0.100.“
Laptop 1 -> DHCP-Server: DHCP Request | „Uzimam 192.168.0.100.“
DHCP-Server -> Laptop 1: DHCP ACK | „Potvrđeno — vrijedi 3600 sekundi.“
:::

Adresa je samo **posuđena** (engl. *lease*): nakon isteka **vremena posudbe (lease time)** uređaj je mora produljiti, inače je poslužitelj smije ponovno dodijeliti. Koje su adrese trenutačno posuđene, vidiš u **DHCP Serveru** na kartici **Leases**.

:::tip Isprobaj
Postavi i **Laptop 2** na DHCP. Koju adresu dobiva? Nakon toga pogledaj **Leases** DHCP poslužitelja.
:::

:::tip Zapamti
**DHCP** automatski dodjeljuje IP adresu, mrežnu masku, gateway i DNS poslužitelj. Postupak se zove **DORA**: **D**iscover (klijent traži putem broadcasta), **O**ffer (poslužitelj nudi), **R**equest (klijent prihvaća), **A**CK (poslužitelj potvrđuje). Adresa je posuđena na vrijeme posudbe (**lease time**). DHCP koristi **UDP**, port 67 (poslužitelj) i 68 (klijent).
:::

:::quiz match
Discover -> Klijent putem broadcasta traži DHCP poslužitelj
Offer -> Poslužitelj nudi adresu
Request -> Klijent zahtijeva ponuđenu adresu
ACK -> Poslužitelj potvrđuje dodjelu
:::

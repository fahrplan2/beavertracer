# POP3 ili IMAP?

:::sim
url=/sims/lesson-6.3.btsim
:::

Za preuzimanje pošte postoje dva protokola. U ovoj simulaciji **Anna koristi POP3**, a **Ben IMAP**.

## Eksperiment

1. U :fa-play: načinu izvođenja **Pokreni** pošalji e-poruku od **Bena** na `anna@beaver-schule.de`.
2. Kod **Anne** u aplikaciji **E-Mail** klikni na **Preuzmi**.
3. Otvori trace za **Annu** i za **Bena** i usporedi naredbe pri preuzimanju.

:::quiz match
USER / PASS -> POP3: prijava korisničkim imenom i lozinkom u dva koraka
RETR -> POP3: preuzimanje jedne poruke
LOGIN -> IMAP: prijava korisničkim imenom i lozinkom
SELECT INBOX -> IMAP: otvaranje mape na poslužitelju
:::

Provjeri pridruživanje

## Razlika

| | POP3 | IMAP |
|---|---|---|
| Port | 110 | 143 |
| Osnovna ideja | e-poruke se **preuzimaju** — nakon toga se obično brišu s poslužitelja | e-poruke **ostaju na poslužitelju** i tamo se njima upravlja |
| Mape, pročitano/nepročitano | samo na vlastitom uređaju | na poslužitelju — svugdje isto |
| Više uređaja (mobitel, prijenosno računalo) | nepraktično: svaki uređaj ima drukčije stanje | idealno: svi uređaji vide isti poštanski sandučić |

:::note
E-mail program u BeaverTraceru ostavlja poruke na poslužitelju i kod POP3. Pravi programi ih nakon preuzimanja često brišu — ili ih ostavljaju samo neko vrijeme.
:::

Lena čita svoju poštu na mobitelu, tabletu i školskom prijenosnom računalu. Što bi trebala koristiti?
- [ ] POP3, jer je jednostavniji
- [x] IMAP, jer svi uređaji vide isti poštanski sandučić na poslužitelju

:::tip Zapamti
**POP3** preuzima e-poruke s poslužitelja na **jedan** uređaj. **IMAP** upravlja poštanskim sandučićem **na poslužitelju** — s mapama i statusom pročitano za sve uređaje istodobno. Oba služe samo za **preuzimanje**; slanje se uvijek obavlja pomoću **SMTP**-a.
:::

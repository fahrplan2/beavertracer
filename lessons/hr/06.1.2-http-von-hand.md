# HTTP ručno

:::sim

:::

Ako je HTTP običan tekst — može li se onda i samostalno razgovarati s web-poslužiteljem, bez ikakvog preglednika? Da: pomoću `telnet` uspostavljaš TCP vezu s bilo kojim portom i sam upisuješ tekst.

## Pokus

1. Prebaci se u :fa-play: način izvođenja (**Pokreni**) i na **Client-PC** otvori :fa-terminal: **Terminal**.
2. Poveži se s portom 80 poslužitelja:
   ```
   $ telnet 192.168.0.20 80
   ```
3. Upiši zahtjev redak po redak — i završi ga **praznim retkom** (jednostavno još jednom pritisni **Enter**):
   ```
   GET /kontakt.html HTTP/1.1
   Host: 192.168.0.20

   ```

Poslužitelj odgovara statusnim retkom, zaglavljima i stranicom s kontaktom — kao tekst, baš kao što ga dobiva i preglednik.

:::quiz mc
Po čemu poslužitelj prepoznaje da je tvoj zahtjev završen?
- [ ] Po posebnoj naredbi `END`
- [x] Po praznom retku
- [ ] Nakon određenog vremena
:::

:::quiz short
Koja vrijednost stoji u odgovoru u zaglavlju `Content-Type`? (samo prvi dio prije `;`)
= text/html
:::

Provjeri odgovore
:::

## Izazivanje pogrešaka

Praktičniji alat je `curl`: on umjesto tebe šalje zahtjev. S opcijom `-v` (*verbose*, opširno) prikazuje sve što se razmjenjuje — retke s `>` poslao je `curl`, a retke s `<` poslao je poslužitelj.

Isprobaj:

```
$ curl -v http://192.168.0.20/gibtsnicht.html
$ curl -X POST -d name=Anna http://192.168.0.20/
```

:::quiz short
Koji statusni kod dobivaš za `/gibtsnicht.html`?
= 404
:::

:::quiz short
A koji za zahtjev s metodom `POST`?
= 405
:::

:::evaluate
Provjeri odgovore
:::

:::note
Web-poslužitelj u BeaverTraceru može isporučivati samo datoteke — zato dopušta samo `GET` i `HEAD`. Pravi web-poslužitelji pomoću `POST` primaju, primjerice, obrasce i proslijeđuju podatke nekom programu.
:::

:::tip Zapamti
Mnogi protokoli aplikacijskog sloja **temelje se na tekstu** — HTTP, ali i SMTP, POP3 i IMAP. Zato ih možeš ručno „govoriti“ pomoću `telnet` i čitati u alatu za praćenje. To je praktično za otklanjanje pogrešaka — ali i sigurnosni problem: svatko tko presreće promet može sve pročitati. Kako pomaže enkripcija (HTTPS), naučit ćeš u 8. poglavlju.
:::

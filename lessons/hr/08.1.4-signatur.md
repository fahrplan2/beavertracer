# Digitalni potpisi

Enkripcijom se postiže **povjerljivost**, a pomoću hash vrijednosti prepoznaju se promjene. No kako dokazati **tko je poslao** poruku? Na papiru se potpisuje. U mreži za to postoji **digitalni potpis**.

## Par ključeva upotrijebljen obrnuto

Pri šifriranju pošiljatelj koristi **javni** ključ primatelja. Kod potpisa je obrnuto: pošiljatelj koristi **vlastiti privatni** ključ. Budući da samo on posjeduje taj ključ, samo on može stvoriti taj potpis. Provjeriti ga, međutim, može svatko — pomoću **javnog** ključa pošiljatelja.

**Potpisivanje** (Anna potpisuje ugovor):

1. Anna izračunava **hash vrijednost** ugovora.
2. Tu hash vrijednost obrađuje svojim **privatnim ključem**. Rezultat je **potpis**.
3. Ugovor zajedno s potpisom šalje Benu.

**Provjera** (Ben kontrolira potpis):

1. Ben sam izračunava hash vrijednost primljenog ugovora.
2. Potpis provjerava Anninim **javnim ključem**: odgovara li on toj hash vrijednosti?
3. Ako odgovara, Ben zna dvije stvari:
    - Ugovor doista potječe od Anne — samo ona ima privatni ključ (**autentičnost**).
    - Ugovor nije promijenjen na putu — inače bi imao drukčiju hash vrijednost (**integritet**).

:::note
Zašto Anna potpisuje samo hash vrijednost, a ne cijeli ugovor? Asimetrični postupci su spori. Hash vrijednost je uvijek kratka — svejedno ima li ugovor jednu stranicu ili tisuću stranica.
:::

:::quiz mc
Kojim ključem Anna **stvara** svoj potpis?
- [x] Svojim privatnim ključem
- [ ] Svojim javnim ključem
- [ ] Benovim javnim ključem
:::

:::quiz mc
Kojim ključem Ben **provjerava** potpis?
- [ ] Svojim privatnim ključem
- [x] Anninim javnim ključem
- [ ] Anninim privatnim ključem
:::

:::quiz mc
Napadač presretne ugovor i promijeni iznos. Potpis ostavi kakav jest. Što se događa pri Benovoj provjeri?
- [x] Provjera ne uspijeva jer promijenjeni ugovor ima drukčiju hash vrijednost
- [ ] Provjera uspijeva jer je potpis ipak pravi
- [ ] Ben uopće ne može provjeriti potpis jer ne poznaje Annin privatni ključ
:::

:::evaluate
Provjeri odgovore
:::

:::quiz match
Povjerljivo pisati Benu -> šifrirati Benovim javnim ključem
Pročitati šifriranu poruku -> dešifrirati vlastitim privatnim ključem
Potpisati dokument -> vlastitim privatnim ključem
Provjeriti potpis -> javnim ključem pošiljatelja
:::

:::evaluate
Provjeri povezivanje
:::

:::tip Zapamti
**Digitalni potpis** pošiljatelj stvara iz **hash vrijednosti** poruke i svojeg **privatnog ključa**. Svatko ga može provjeriti **javnim ključem** pošiljatelja. Valjan potpis dokazuje **tko je poslao** poruku (**autentičnost**) i da **nije mijenjana** (**integritet**).
:::

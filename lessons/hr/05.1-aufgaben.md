# Što mora omogućiti transportni sloj?

:::sim
url=/sims/lesson-5.1.btsim
:::

Na **Serveru** istodobno rade dvije usluge: **web-poslužitelj** i mala **echo usluga**, koja odmah vraća svaku poruku koju primi. Pomoću dvaju eksperimenata otkrit ćeš što sam IP ne može.

## Eksperiment 1: Dva programa istodobno

1. Prijeđi u način izvođenja :fa-play: **Pokreni** i klikni na **Client-PC**.
2. Otvori :fa-globe: **Preglednik** i otvori `http://192.168.0.20/`.
3. Klikni na **Natrag** pri vrhu prozora i otvori **Jednostavni TCP klijent**. U polje **Host** upiši `192.168.0.20`, u polje **Port** upiši `5000` i klikni na **Poveži**.
4. Prijeđi u način :fa-magnifying-glass: **Praćenje** i pomoću **+** otvori trag za **Client-PC**, priključak `eth0`.

Klikni na jedan paket preglednika (npr. `GET /`) i na jedan paket TCP klijenta te u oba slučaja otvori **Internet Protocol Version 4**.

:::quiz mc
Koje IP adrese nose paketi preglednika i TCP klijenta?
- [x] Kod oba iste: od `192.168.0.10` do `192.168.0.20`
- [ ] Preglednik koristi drugu odredišnu IP adresu od TCP klijenta
- [ ] Paketi TCP klijenta nemaju IP adresu
:::

:::quiz mc
Je li dakle odredišna IP adresa dovoljna da server zna pripada li paket web-poslužitelju ili echo usluzi?
- [ ] Da
- [x] Ne — oba paketa imaju istu odredišnu IP adresu
:::

Nešto drugo mora razlikovati te dvije veze. Pogledaj stupac **Info** kod paketa s `[SYN]` — to je u oba slučaja prvi paket veze:

:::quiz short
Koji broj stoji iza strelice `→` kod **preglednika**?
= 80
:::

:::quiz short
A kod **TCP klijenta**?
= 5000
:::

:::evaluate
Provjeri odgovore
:::

Više o tim brojevima — **portovima** — saznat ćeš u odjeljku 5.3. Za sada je dovoljno znati: tek transportni sloj omogućuje da više programa istodobno komunicira preko *jedne* IP adrese i da svaki paket završi kod pravog programa. To se zove **multipleksiranje**.

## Eksperiment 2: Kad se paket izgubi

1. Prijeđi u način izvođenja :fa-play: **Pokreni** i klikni na **kabel** između Client-PC-a i Servera.
2. U prozoru **Veza** postavi **Konfigurirani gubitak paketa** na `25%`.
3. Na **Client-PC-u** otvori :fa-terminal: **Terminal** i pošalji šest pingova:
   ```
   $ ping -c 6 192.168.0.20
   ```
   To traje otprilike pola minute — pričekaj dok se ne pojavi statistika.

:::quiz mc
Što se događa?
- [ ] Na svih šest pingova stigne odgovor
- [x] Neki pingovi ostaju bez odgovora — i nitko ih ne šalje ponovno
- [ ] Izgubljeni pingovi automatski se ponavljaju dok ne stignu
:::

:::evaluate
Provjeri odgovor
:::

Kod pinga to nije problem — on upravo treba pokazati gubi li se nešto. No kod web-stranice, e-pošte ili preuzimanja nedostajući bi dio bio kobna pogreška: datoteka bi bila oštećena.

## Četiri zadaće transportnog sloja

| Zadaća | Što to znači |
|---|---|
| **Multipleksiranje** | Više programa i veza dijeli jednu IP adresu; svaki paket stiže do pravog programa. |
| **Uspostava veze** | Prije nego što podaci poteku, obje strane dogovore da će međusobno komunicirati. |
| **Pouzdani prijenos** | Primatelj potvrđuje što je stiglo. Ono što nedostaje šalje se ponovno, a redoslijed se uspostavlja. |
| **Prekid veze** | Na kraju obje strane uredno prekidaju vezu. |

:::tip Zapamti
**Transportni sloj** (sloj 4) osigurava da podaci stignu do pravog **programa** (**multipleksiranje**). Protokol **TCP** dodatno osigurava da stignu **u cijelosti** i **pravilnim redoslijedom** — uz uspostavu veze, potvrde, ponovno slanje i prekid veze.
:::

:::quiz match
Na jednom računalu istodobno rade preglednik, program za e-poštu i messenger. -> Multipleksiranje
Prije nego što podaci poteku, obje strane utvrde da je druga strana spremna. -> Uspostava veze
Dio datoteke ne stigne i šalje se još jednom. -> Pouzdani prijenos
Nakon preuzimanja obje strane ponovno oslobađaju vezu. -> Prekid veze
:::

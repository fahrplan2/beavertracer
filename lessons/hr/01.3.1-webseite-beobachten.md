# Pozivanje i promatranje web stranice

Za ovaj dio ništa ne gradiš sam: na radnoj površini nalazi se pripremljena simulacija s **Client-PC** i **Webserver**.

## Pozivanje stranice

1. Prebaci se u :fa-play: način izvođenja **Pokreni**.
2. Na **Client-PC** otvori aplikaciju :fa-globe: **Preglednik** i otvori adresu web poslužitelja: `http://192.168.0.20/`.
3. Prebaci se u :fa-magnifying-glass: način **Praćenje** i pomoću **+** otvori trace za **Client-PC**, priključak `eth0` — baš kao kod pinga.

:::note
Za jedno jedino otvaranje stranice to je iznenađujuće mnogo paketa — znatno više nego kod pinga. Preuzimanje web stranice višestupanjski je proces, a ne jedna jedina radnja.
:::

## Čitanje popisa paketa

Još ne moraš znati što točno pojedini protokoli rade. Sve što ti treba za sljedeća pitanja nalazi se u stupcima **Protokol** i **Info**.

:::quiz mc
Koji je protokol na samom vrhu popisa?
- [x] ARP
- [ ] TCP
- [ ] HTTP
:::

:::quiz short
Prebroji: koliko **TCP** paketa stoji prije prvog **HTTP** paketa?
= 3
= tri
:::

:::quiz mc
Što web poslužitelj odgovara na zahtjev preglednika? Pogledaj stupac Info drugog HTTP paketa.
- [ ] GET / HTTP/1.1
- [x] HTTP/1.1 200 OK
- [ ] 404 Not Found
:::

:::evaluate
Provjeri odgovore
:::

## Imenovanje sudjelujućih protokola

Iz svojih opažanja sada možeš iščitati koji je protokol za što bio zadužen.

:::tip Savjet
Još jednom pročitaj stupce **Info**: `Who has …?`, `[SYN]`, `[SYN, ACK]`, `[ACK]`, `GET /` i `200 OK` otkrivaju gotovo sve.
:::

:::quiz match
ARP -> Pita sve u mreži: „Tko ima IP adresu 192.168.0.20?“
TCP -> Uspostavlja vezu s tri kratka paketa prije nego što poteku podaci
HTTP -> Zahtijeva web stranicu (GET) i vraća je (200 OK)
:::

:::evaluate
Provjeri pridruživanje
:::

:::tip Zapamti
Otvaranje web stranice odvija se u fazama: prvo **pronaći** poslužitelj u mreži (ARP), zatim **uspostaviti** vezu (TCP), potom **zatražiti i isporučiti** stranicu (HTTP) — i na kraju vezu opet **prekinuti** (TCP paketi s `[FIN]` na kraju popisa).
:::

:::note
Ovaj put si IP adresu poslužitelja unio izravno, zato **DNS** („prevođenje“ imena poput `www.beispiel.de` u IP adresu) još nije bio u upotrebi. To ćemo nadoknaditi u 6. poglavlju.
:::

Jesi li primijetio da protokoli u strukturi paketa imaju obojene oznake s brojevima? Što to znači, objasnit ćemo u 2. poglavlju. Tamo ćemo pogledati kako se brojni protokoli sustavno razvrstavaju — pomoću OSI i TCP/IP referentnog modela. Time je 1. poglavlje završeno.

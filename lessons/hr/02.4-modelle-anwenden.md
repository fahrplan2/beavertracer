# Primjena modela

Pridruži protokole iz eksperimenta s početka poglavlja njihovu OSI sloju:

:::quiz match
Ethernet -> Sloj 2 — Podatkovni
IPv4 -> Sloj 3 — Mrežni
TCP -> Sloj 4 — Transportni
HTTP -> Sloj 7 — Aplikacijski
:::

:::evaluate
Provjeri pridruživanje
:::

I na kraju nazivi podatkovnih jedinica:

:::quiz match
Frame -> Sloj 2 — Podatkovni
Paket -> Sloj 3 — Mrežni
Segment -> Sloj 4 — Transportni
:::

:::evaluate
Provjeri pridruživanje
:::

Time si dobio/dobila alat za ispravno razvrstavanje protokola ubuduće. Od sljedećeg poglavlja prolazimo slojeve redom — počevši od sloja 2 i pitanja kako switch zapravo zna kamo mora proslijediti paket.

## Pokus

1. Prijeđi u način izvođenja :fa-play: **Pokreni**, klikni na **Client-PC** i otvori :fa-globe: **Preglednik**. Otvori `http://192.168.0.20/`.
2. Klikni na **Zurück** na vrhu prozora, otvori **Jednostavni TCP klijent** i poveži ga s `192.168.0.20`, port `5000`. Ostavi vezu otvorenom.
3. Prijeđi u način :fa-magnifying-glass: **Praćenje**, otvori trace za **Client-PC** i klikni na paket s `[SYN]`. Raširi **Transmission Control Protocol**.

Na samom vrhu TCP zaglavlja nalaze se dva porta: **Source Port** (izvorišni port) i **Destination Port** (odredišni port).

|---|---|---|
| Preglednik → web poslužitelj | {49152} | {80} |
| TCP klijent → echo usluga | {49153} | {5000} |

## Dvije vrste portova

**Odredišni port — usluga:** Poslužiteljski program čeka veze na fiksnom portu — kaže se da na njemu **osluškuje**. Za poznate usluge brojevi su određeni na globalnoj razini, to su **dobro poznati portovi** (engl. *well-known ports*, od 0 do 1023). Zato preglednik bez pitanja zna: web poslužitelji osluškuju na portu 80.

**Izvorišni port — pošiljatelj:** Port na strani klijenta operacijski sustav sam odabire za svaku novu vezu iz visokog raspona (u BeaverTraceru od 49152). Po njemu klijent prepoznaje kojoj od njegovih veza pripada odgovor.

Veza je dakle jednoznačno određena s četiri podatka: **IP adresom i portom na objema stranama**. Par IP adrese i porta naziva se **socket**, npr. `192.168.0.20:80`.

## Pogled na poslužitelj

Vrati se u način izvođenja :fa-play: **Pokreni**, na **Serveru** otvori :fa-terminal: **Terminal** i upiši:

```
$ ss
```

`ss` prikazuje sve sockete računala. Retci s `LISTEN` su programi koji osluškuju na nekom portu. Retci s `ESTABLISHED` su postojeće veze — s vlastitim socketom (*Local Address:Port*) i socketom druge strane (*Peer Address:Port*).

:::quiz multi

- [x] 80
- [x] 5000
- [ ] 49152
- [ ] 443
:::

:::quiz mc

- [ ] `192.168.0.20:80` s `192.168.0.10:49152` — veza preglednika
- [ ] Obje
:::

## Najvažniji dobro poznati portovi

| Port | Protokol | Usluga |
|---|---|---|
| 22 | SSH | sigurno daljinsko održavanje (šifrirana naredbena linija) |
| 25 | SMTP | slanje e-pošte |
| 53 | DNS | prevođenje imena u IP adrese (najčešće preko UDP-a) |
| 80 | HTTP | web stranice |
| 110 | POP3 | preuzimanje e-pošte |
| 143 | IMAP | upravljanje e-poštom na poslužitelju |
| 443 | HTTPS | šifrirane web stranice |

:::tip Zapamti
**Portovi** (od 0 do 65535) razdvajaju veze na računalu. Poslužiteljske usluge **osluškuju** na fiksnim **dobro poznatim portovima** (npr. HTTP 80, HTTPS 443), a klijenti za svaku vezu dobivaju slobodan visoki **izvorišni port**. Veza je jednoznačno određena **IP adresom i portom obiju strana**.
:::

:::quiz match
22 -> SSH
25 -> SMTP
53 -> DNS
80 -> HTTP
110 -> POP3
143 -> IMAP
443 -> HTTPS
:::

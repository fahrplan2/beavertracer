# UDP: velika pojednostavnjenja

:::goal
**Ishod učenja:** Možeš usporediti UDP s TCP-om i obrazložiti za koje je aplikacije UDP bolji izbor.
:::

:::sim
url=/sims/lesson-5.5.btsim
:::

TCP radi puno toga — uspostava veze, potvrde, ponovno slanje, redoslijed. No to košta vrijeme i dodatne pakete. Drugi važan protokol transportnog sloja odriče se gotovo svega toga: **User Datagram Protocol** (**UDP**). Njegovi se paketi zovu **datagrami**.

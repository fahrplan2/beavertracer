# Veza od početka do kraja

:::sim
url=/sims/lesson-5.1.btsim
:::

Na **Serveru** echo-usluga radi na portu `5000`: svaku poruku odmah šalje natrag. Pomoću **Jednostavnog TCP klijenta** možeš korak po korak upravljati vezom — svaki gumb je jedna faza.

## Eksperiment

1. Prijeđi u način izvođenja :fa-play: **Pokreni**, klikni na **Client-PC** i otvori **Jednostavni TCP klijent**.
2. U polje **Host** upiši `192.168.0.20`, a u polje **Port** `5000`.
3. Klikni na **Poveži**.
4. U polje za poruku upiši `Hello World` i klikni na **Pošalji**. U prozoru za chat odmah nakon toga vidiš odjek (echo) servera.
5. Klikni na **Prekini vezu**.
6. Prijeđi u način :fa-magnifying-glass: **Praćenje** i pomoću **+** otvori trace za **Client-PC**, priključak `eth0`.

:::note
Dva ARP paketa na početku već poznaješ iz 1. poglavlja. U stupcu **Info** TCP paketa prvo stoji `49152 → 5000` (s kojeg na koji port), zatim u uglatim zagradama **zastavice (flags)**, a nakon toga brojevi poput `Seq=`, `Ack=` i `Len=`. Brojevima se bavimo od stranice 5.2.3 — ovdje obraćaš pozornost na zastavice i `Len`.
:::

## Faza 1: Povezivanje

:::quiz short
Koliko je TCP paketa razmijenjeno nakon što si kliknuo/la na **Poveži** — prije nego što je tvoja poruka krenula?
= 3
= tri
:::

:::quiz mc
Tko šalje prvi paket sa `[SYN]`?
- [x] Client-PC
- [ ] Server
:::

:::quiz mc
S kojim zastavicama server odgovara na to?
- [ ] `[SYN]`
- [x] `[SYN, ACK]`
- [ ] `[ACK]`
- [ ] `[FIN, ACK]`
:::

## Faza 2: Slanje

`Len` označava koliko bajtova korisnih podataka paket nosi.

:::quiz short
Koliko bajtova nosi paket s tvojom porukom (`Len`)?
= 13
:::

:::note
`Hello World` ima samo 11 znakova. TCP klijent međutim dodaje kraj retka (2 bajta, `\r\n`) — tako to očekuju mnogi internetski protokoli poput SMTP-a ili HTTP-a.
:::

:::quiz mc
Što server šalje natrag odmah nakon tvoje poruke — još prije odjeka (echa)?
- [x] Paket s `[ACK]` i `Len=0` — potvrdu bez podataka
- [ ] Ništa
- [ ] Novi `[SYN]`
:::

## Faza 3: Prekid veze

:::quiz short
Koliko paketa pripada prekidu veze — od prvog paketa s `FIN`?
= 4
= četiri
:::

:::quiz mc
Što jedna strana priopćuje zastavicom `FIN`?
- [x] „Gotov sam” — više ne šalje podatke
- [ ] „Došlo je do pogreške”
- [ ] „Stižu novi podaci”
:::

Provjeri odgovore
:::

## Gdje se kriju četiri zadaće?

Pridruži gdje u traceu ponovno pronalaziš zadaće iz odjeljka 5.1:

:::quiz match
Uspostava veze -> Tri paketa [SYN], [SYN, ACK] i [ACK]
Pouzdani prijenos -> Paketi s [ACK] i Len=0 koji potvrđuju primitak
Prekid veze -> Paketi s FIN i njihove potvrde
Multipleksiranje -> Brojevi portova 49152 → 5000 ispred uglatih zagrada
:::

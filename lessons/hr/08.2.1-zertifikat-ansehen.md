# Pregled certifikata

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Na radnoj površini vidiš **Client-PC**, **DNS-Server** i web poslužitelj škole, `www.beaver-schule.de`. Web poslužitelj svoje stranice nudi i putem **HTTPS**-a.

## Lokot u pregledniku

1. Prijeđi u :fa-play: **Pokreni** način izvođenja, klikni na **Client-PC** i otvori :fa-globe: **Preglednik**.
2. Otvori `https://www.beaver-schule.de/` — obrati pozornost na **https**.
3. Lijevo od adrese pojavljuje se **lokot**. Klikni na njega.

:::quiz short
Za koje je ime izdan certifikat (subjekt bez `CN=`)?
= www.beaver-schule.de
:::

:::quiz short
Tko je izdao certifikat (izdavatelj bez `CN=`)?
= Biber Root CA
:::

:::evaluate
Provjeri odgovore
:::

## Zašto Client-PC vjeruje certifikatu?

Na **Client-PC**-u otvori :fa-shield-halved: **Zertifikatverwaltung** i prijeđi na karticu **Vertrauenswürdige CAs**.

:::quiz mc
Što tamo nalaziš?
- [x] Certifikat **Biber Root CA**
- [ ] Certifikat od `www.beaver-schule.de`
- [ ] Nema unosa
:::

:::quiz mc
Po čemu se vidi da je Biber Root CA korijenski CA (Root-CA)?
- [x] **Samopotpisan** je: subjekt i izdavatelj su isti
- [ ] Njegovo ime završava na „CA“
- [ ] Nema javni ključ
:::

:::quiz mc
Piše li kod Client-PC-a pod **Privater Schlüssel** „Ja“ ili „Nein“?
- [ ] Ja — klijent treba privatni ključ CA-a da bi provjeravao potpise
- [x] Nein — za provjeru je dovoljan javni ključ; privatni ključ ima samo CA
:::

:::evaluate
Provjeri odgovore
:::

## Druga strana: web poslužitelj

Sada na web poslužitelju **www.beaver-schule.de** otvori :fa-shield-halved: **Zertifikatverwaltung** (kartica **Meine Zertifikate**) i pogledaj njegov certifikat.

:::quiz multi
Što vrijedi za certifikat na web poslužitelju?
- [x] Pod **Privater Schlüssel** piše „Ja“ — poslužitelj ga treba za uspostavu veze
- [x] **Lanac** glasi `www.beaver-schule.de ← Biber Root CA`
- [x] **Otisak** je isti kao u prozoru lokota u pregledniku
- [ ] Samopotpisan je
:::

:::evaluate
Provjeri odgovore
:::

:::note
**Otisak** je hash vrijednost certifikata. Pomoću njega možeš brzo usporediti dva certifikata — bez provjere svakog polja zasebno.
:::

:::tip Zapamti
**Web poslužitelj** posjeduje svoj certifikat **s privatnim ključem**. **Klijent** poznaje samo **certifikat korijenskog CA-a** (bez privatnog ključa) — to mu je dovoljno da provjeri potpis na certifikatu poslužitelja. Kada u pregledniku klikneš na **lokot**, vidiš subjekt, izdavatelja, otisak i valjanost.
:::

# DHCP: automatski u mrežu

:::goal
**Ishod učenja:** Možeš objasniti kako uređaj putem DHCP-a automatski dobiva svoje IP postavke, postaviti DHCP server te prepoznati i otkloniti tipične DHCP pogreške (npr. adresu 169.254).
:::

:::sim
url=/sims/lesson-6.4.btsim
:::

Do sada si za svaki uređaj ručno upisivao IP adresu, mrežnu masku, pristupnik i DNS server. U školi sa stotinama prijenosnih računala, tableta i mobitela to bi bilo nemoguće — a svaka tipfeler-pogreška bila bi kvar u mreži.

Taj posao preuzima **Dynamic Host Configuration Protocol** (**DHCP**): **DHCP server** automatski dodjeljuje postavke svakom uređaju koji se spoji na mrežu.

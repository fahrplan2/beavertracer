# Een adres automatisch ophalen

:::sim
url=/sims/lesson-6.4.btsim
:::

Aan de switch hangen een **DHCP-server** en twee laptops. De laptops hebben nog vaste adressen.

## Het experiment

1. Schakel over naar de :fa-play: **Uitvoermodus**, klik op **Laptop 1** en open de :fa-gear: **IP-instellingen**.
2. Zet de **modus** van **Statisch** op **DHCP** en klik op **Toepassen**.
3. Wacht een paar seconden: de velden worden vanzelf ingevuld.
4. Open in de :fa-magnifying-glass: **Tracering**-modus een trace voor **Laptop 1**.

:::quiz table
| Instelling | gekregen van de DHCP-server |
|---|---|
| IP-adres | {192.168.0.100} |
| Gateway | {192.168.0.1} |
| DNS-server | {192.168.0.53} |
:::

:::quiz short
Hoeveel DHCP-pakketten vind je in de trace?
= 4
= vier
:::

:::quiz mc
Naar welk doel-IP-adres stuurt Laptop 1 zijn eerste pakket (`DHCP Discover`)?
- [ ] Naar de DHCP-server `192.168.0.2`
- [x] Naar `255.255.255.255` — naar iedereen (broadcast)
- [ ] Naar de gateway `192.168.0.1`
:::

## Wat erachter zit: DORA

Een apparaat zonder adres weet niet waar de DHCP-server is en heeft ook geen eigen afzenderadres. Daarom roept het via een **broadcast** het netwerk in. Het proces bestaat uit vier stappen — genoemd naar hun beginletters **DORA**:

:::seq
mode: text
Laptop 1 -> DHCP-Server: DHCP Discover | „Is hier een DHCP-server?”
DHCP-Server -> Laptop 1: DHCP Offer | „Je kunt 192.168.0.100 krijgen.”
Laptop 1 -> DHCP-Server: DHCP Request | „Ik neem 192.168.0.100.”
DHCP-Server -> Laptop 1: DHCP ACK | „Bevestigd — geldig voor 3600 seconden.”
:::

Het adres is slechts **geleend** (*lease*): na afloop van de **leasetijd** moet het apparaat het verlengen, anders mag de server het opnieuw uitgeven. Welke adressen op dit moment uitgeleend zijn, zie je in de **DHCP-server** op het tabblad **Leases**.

:::tip Probeer het uit
Zet ook **Laptop 2** op DHCP. Welk adres krijgt hij? Kijk daarna in de **Leases** van de DHCP-server.
:::

:::tip Onthoud
**DHCP** verdeelt IP-adres, netmasker, gateway en DNS-server automatisch. Het proces heet **DORA**: **D**iscover (client zoekt via broadcast), **O**ffer (server biedt aan), **R**equest (client accepteert), **A**CK (server bevestigt). Het adres is geleend voor de **leasetijd**. DHCP gebruikt **UDP**, poort 67 (server) en 68 (client).
:::

:::quiz match
Discover -> De client zoekt via broadcast naar een DHCP-server
Offer -> De server biedt een adres aan
Request -> De client vraagt het aangeboden adres aan
ACK -> De server bevestigt de toewijzing
:::

# POP3 of IMAP?

:::sim
url=/sims/lesson-6.3.btsim
:::

Voor het ophalen van e-mail zijn er twee protocollen. In deze simulatie gebruikt **Anna POP3** en **Ben IMAP**.

## Het experiment

1. Stuur in de :fa-play: **Uitvoeren**-modus een mail van **Ben** naar `anna@beaver-schule.de`.
2. Klik bij **Anna** in de app **E-Mail** op **Ophalen**.
3. Open traces voor **Anna** en voor **Ben** en vergelijk de opdrachten bij het ophalen.

:::quiz match
USER / PASS -> POP3: inloggen met gebruikersnaam en wachtwoord in twee stappen
RETR -> POP3: een bericht downloaden
LOGIN -> IMAP: inloggen met gebruikersnaam en wachtwoord
SELECT INBOX -> IMAP: een map op de server openen
:::

:::evaluate
Koppeling controleren
:::

## Het verschil

| | POP3 | IMAP |
|---|---|---|
| Poort | 110 | 143 |
| Basisidee | Mails **downloaden** — daarna meestal op de server verwijderen | Mails **blijven op de server** en worden daar beheerd |
| Mappen, gelezen/ongelezen | alleen op het eigen apparaat | op de server — overal hetzelfde |
| Meerdere apparaten (telefoon, laptop) | onpraktisch: elk apparaat heeft een andere stand | ideaal: alle apparaten zien hetzelfde postvak |

:::note
Het e-mailprogramma in BeaverTracer laat de mails ook bij POP3 op de server staan. Echte programma's verwijderen ze na het downloaden vaak — of laten ze maar een tijdje staan.
:::

:::quiz mc
Lena leest haar mails op haar telefoon, haar tablet en de laptop van school. Wat kan ze het beste gebruiken?
- [ ] POP3, omdat het eenvoudiger is
- [x] IMAP, omdat alle apparaten hetzelfde postvak op de server zien
- [ ] SMTP, omdat het bedoeld is voor het ophalen
:::

:::evaluate
Antwoord controleren
:::

:::tip Onthoud
**POP3** downloadt mails van de server naar **één** apparaat. **IMAP** beheert het postvak **op de server** — met mappen en de gelezen-status voor alle apparaten tegelijk. Beide dienen alleen om mail **op te halen**; verzenden gebeurt altijd met **SMTP**.
:::

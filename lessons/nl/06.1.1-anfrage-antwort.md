Een webpagina bestaat dus vaak uit veel bestanden: tekst, stylesheets, afbeeldingen. Voor elk bestand stuurt de browser een eigen verzoek.

## Hoe een verzoek eruitziet

Klik in de trace op het pakket `GET / HTTP/1.1` en klap **Hypertext Transfer Protocol** open. Een HTTP-verzoek is gewone tekst:

```
GET / HTTP/1.1              ← Methode, Pfad, Version
Host: 192.168.0.20          ← Header: zusätzliche Angaben
…
                            ← Leerzeile: Ende der Anfrage
```

Het antwoord van de server is op dezelfde manier opgebouwd — met een statusregel, headers, een lege regel en daarna het eigenlijke bestand:

```
HTTP/1.1 200 OK             ← Version, Statuscode, Text
Content-Type: text/html     ← Header: Art der Datei
Content-Length: 301         ← Header: Größe in Byte
                            ← Leerzeile
<!doctype html> …           ← die Datei selbst
```

:::seq
mode: text
Client-PC -> Server: GET / | HTTP-verzoek
Server -> Client-PC: 200 OK | index.html
Client-PC -> Server: GET /style.css | HTTP-verzoek
Server -> Client-PC: 200 OK | style.css
:::

## Methoden en statuscodes

De **methode** zegt wat de client wil:

| Methode | Betekenis |
|---|---|
| **GET** | een bestand ophalen |
| **POST** | gegevens naar de server sturen, bijv. een ingevuld formulier |
| **HEAD** | alleen de headers ophalen, zonder het bestand |

De **statuscode** zegt hoe het is gegaan. Het eerste cijfer verraadt het soort antwoord:

| Code | Tekst | Betekenis |
|---|---|---|
| **200** | OK | alles in orde |
| **301** | Moved Permanently | de pagina is permanent verhuisd |
| **404** | Not Found | het bestand bestaat niet |
| **405** | Method Not Allowed | deze methode is hier niet toegestaan |
| **500** | Internal Server Error | fout op de server |

`2xx` betekent succes, `3xx` omleiding, `4xx` een fout van de client (verkeerd verzoek), `5xx` een fout van de server.

:::tip Onthoud
**HTTP** werkt volgens het **verzoek-antwoordprincipe**: de client stuurt een **verzoek** (methode zoals `GET`, pad, headers), de server antwoordt met een **statuscode** (bijv. `200 OK`, `404 Not Found`), headers en het bestand. Voor elk bestand van een webpagina is er een eigen verzoek.
:::

:::

# Samenvatting en vooruitblik

## Firewalls op veel plekken

Het pakketfilter uit dit hoofdstuk kom je in veel apparaten tegen:

- **Thuisrouter:** Elke thuisrouter is ook een stateful firewall. Met IPv4 neemt NAT daar een deel van over: van buitenaf kan niemand een verbinding starten, zolang er geen poortdoorsturing is (hoofdstuk 7). Met IPv6 hebben alle apparaten openbare adressen — dan zorgt alleen de firewallregel "van buitenaf niets nieuws binnen" voor dezelfde bescherming.
- **Personal firewall:** Ook Windows, macOS en Linux hebben een ingebouwde firewall op de computer zelf. Die beschermt het apparaat ook in vreemde netwerken, bijvoorbeeld op de wifi van een café, en kan regels per programma instellen.
- **Next-generation firewall** en **Web Application Firewall (WAF):** Die kijken niet alleen naar adressen en poorten, maar ook naar de inhoud van de pakketten — tot aan de applicatielaag. Zo herkennen ze bijvoorbeeld aanvallen in HTTP-verzoeken. Bij HTTPS moeten ze daarvoor de versleuteling doorbreken (hoofdstuk 8).
- **IDS/IPS:** Een *Intrusion Detection System* herkent verdachte patronen in het dataverkeer en slaat alarm; een *Intrusion Prevention System* blokkeert ze bovendien zelf.

:::note
Een firewall is maar **één** bouwsteen van de beveiliging. Hij helpt niet als een toegestane dienst (bijvoorbeeld de webserver) zelf een lek heeft, als iemand een schadelijk programma via e-mail opent of als een wachtwoord zwak is. Daarom horen updates, veilige wachtwoorden, versleuteling en een slimme indeling van het netwerk (DMZ, VLAN's uit hoofdstuk 3) er altijd bij.
:::

## Test jezelf

:::quiz mc
Een firewall werkt met het standaardbeleid "Alles weggooien" en één enkele regel "A → B, TCP 443, Toestaan". Er komt een pakket A → B naar TCP-poort 22 binnen. Wat gebeurt er?
- [ ] Het wordt toegestaan
- [x] Het wordt weggegooid
- [ ] Het wordt geweigerd
:::

:::quiz mc
`nmap` meldt voor een poort `filtered`. Wat betekent dat?
- [ ] Op de poort draait een dienst
- [ ] De server heeft met een RST geantwoord
- [x] Er kwam helemaal geen antwoord — waarschijnlijk gooit een firewall de pakketten weg
:::

:::quiz multi
Welke uitspraken kloppen?
- [x] Bij een stateful firewall komen antwoorden op toegestane verbindingen automatisch terug
- [x] Een whitelist is veiliger dan een blacklist, omdat nieuwe diensten automatisch geblokkeerd blijven
- [x] Servers die vanaf het internet bereikbaar zijn, horen in een DMZ
- [ ] Een firewall beschermt ook tegen aanvallen tussen twee computers in hetzelfde netwerk achter de firewall
- [ ] Er worden altijd alle regels gecontroleerd, de strengste wint
:::

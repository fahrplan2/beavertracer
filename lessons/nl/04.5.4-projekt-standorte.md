# Project: een bedrijf met vier vestigingen

:::sim
url=/sims/lesson-4.5.4.btsim
:::

Een bedrijf heeft zijn hoofdkantoor in **Hanau** en filialen in **Kassel**, **Gießen** en **Darmstadt**. Elke vestiging heeft een eigen netwerk en een eigen router. Alle routers zijn via huurlijnen verbonden met een **centraal netwerk**, waarin ook de hoofdserver van het bedrijf staat.

## Het adresplan

De beheerder heeft de adressen volgens het volgende schema toegewezen — ze zijn in de simulatie al ingevuld:

| Netwerk | Adresbereik |
|---|---|
| Centraal netwerk | `10.19.0.0/24` |
| Hanau | `10.19.1.0/24` |
| Kassel | `10.19.2.0/24` |
| Gießen | `10.19.3.0/24` |
| Darmstadt | `10.19.4.0/24` |

| Apparaat | in het centrale netwerk | in het vestigingsnetwerk |
|---|---|---|
| Server | `10.19.0.10` | — |
| Router Hanau | `10.19.0.1` | `10.19.1.1` |
| Router Kassel | `10.19.0.2` | `10.19.2.1` |
| Router Gießen | `10.19.0.3` | `10.19.3.1` |
| Router Darmstadt | `10.19.0.4` | `10.19.4.1` |
| PC op de vestiging | — | telkens `.2` (bijv. PC Kassel `10.19.2.2`) |

Bij alle routers wijst `eth0` naar het centrale netwerk en `eth1` naar het vestigingsnetwerk.

## Jouw opdracht

Om ervoor te zorgen dat alle computers van het bedrijf elkaar en de server kunnen bereiken, ontbreken er nog twee dingen:

1. **Gateways:** Stel bij alle vier de PC's en bij de server een gateway in. De PC's gebruiken de router van hun vestiging; de server gebruikt de **Router Hanau**.
2. **Routeringstabellen:** Vul bij alle vier de routers de routes aan die nog ontbreken. Elke router moet de netwerken van de **drie andere** vestigingen kennen.

Test tussendoor met `ping` en `traceroute`.

<details>
<summary>Tip: Hoe ziet een route er hier uit?</summary>

Een voorbeeld voor **Router Kassel**: pakketten voor Gießen (`10.19.3.0/24`) gaan naar de router Gießen in zijn centrale netwerk — dus **Volgende hop** `10.19.0.3`, **Iface** `eth0`. Volgens dit patroon heeft elke router drie routes nodig.
</details>

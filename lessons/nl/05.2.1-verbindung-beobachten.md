# Een verbinding van begin tot eind

:::sim
url=/sims/lesson-5.1.btsim
:::

Op de **Server** draait de echodienst op poort `5000`: elk bericht stuurt hij direct terug. Met de **Eenvoudige TCP-client** kun je een verbinding stap voor stap aansturen — elke knop is een fase.

## Het experiment

1. Schakel over naar de :fa-play: **Uitvoeren**-modus (Uitvoermodus), klik op de **Client-PC** en open de **Eenvoudige TCP-client**.
2. Vul bij **Host** `192.168.0.20` in en bij **Port** `5000`.
3. Klik op **Verbinden**.
4. Typ `Hello World` in het berichtveld en klik op **Verzenden**. In het chatvenster zie je meteen daarna de echo van de server.
5. Klik op **Verbreken**.
6. Schakel over naar de :fa-magnifying-glass: **Tracering**-modus en open met **+** een trace voor de **Client-PC**, aansluiting `eth0`.

:::note
De twee ARP-pakketten aan het begin ken je al uit hoofdstuk 1. In de **Info**-kolom van de TCP-pakketten staat eerst `49152 → 5000` (van welke naar welke poort), daarna tussen rechte haken de **flags** en vervolgens getallen zoals `Seq=`, `Ack=` en `Len=`. Over die getallen gaat het vanaf pagina 5.2.3 — hier let je op de flags en `Len`.
:::

## Fase 1: Verbinden

:::quiz short
Hoeveel TCP-pakketten werden er uitgewisseld nadat je op **Verbinden** had geklikt — voordat jouw bericht werd verstuurd?
= 3
= drie
:::

:::quiz mc
Wie stuurt het eerste pakket met `[SYN]`?
- [x] De Client-PC
- [ ] De Server
:::

:::quiz mc
Met welke flags antwoordt de server daarop?
- [ ] `[SYN]`
- [x] `[SYN, ACK]`
- [ ] `[ACK]`
- [ ] `[FIN, ACK]`
:::

## Fase 2: Verzenden

`Len` geeft aan hoeveel bytes aan nuttige data een pakket bevat.

:::quiz short
Hoeveel bytes bevat het pakket met jouw bericht (`Len`)?
= 13
:::

:::note
`Hello World` heeft maar 11 tekens. De TCP-client voegt echter een regeleinde toe (2 byte, `\r\n`) — zo verwachten veel internetprotocollen zoals SMTP of HTTP het.
:::

:::quiz mc
Wat stuurt de server direct na jouw bericht terug — nog vóór de echo?
- [x] Een pakket met `[ACK]` en `Len=0` — een bevestiging zonder data
- [ ] Helemaal niets
- [ ] Een nieuwe `[SYN]`
:::

## Fase 3: Verbreken

:::quiz short
Hoeveel pakketten horen bij de afbouw — vanaf het eerste pakket met `FIN`?
= 4
= vier
:::

:::quiz mc
Wat deelt een kant mee met `FIN`?
- [x] "Ik ben klaar" — hij verstuurt geen data meer
- [ ] "Er is een fout opgetreden"
- [ ] "Hier komt nieuwe data"
:::

## Waar zitten de vier taken?

Koppel waar je de taken uit paragraaf 5.1 terugvindt in de trace:

:::quiz match
Verbindingsopbouw -> De drie pakketten [SYN], [SYN, ACK] en [ACK]
Betrouwbare overdracht -> Pakketten met [ACK] en Len=0 die de ontvangst bevestigen
Verbindingsafbouw -> De pakketten met FIN en hun bevestigingen
Multiplexen -> De poortnummers 49152 → 5000 vóór de rechte haken
:::

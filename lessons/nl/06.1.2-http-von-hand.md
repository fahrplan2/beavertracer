# HTTP met de hand

:::sim
url=/sims/lesson-6.1.btsim
:::

Als HTTP gewone tekst is — kun je dan ook zelf met een webserver praten, helemaal zonder browser? Ja: met `telnet` bouw je een TCP-verbinding op naar een willekeurige poort en typ je de tekst zelf in.

## Het experiment

1. Schakel over naar de :fa-play: **Uitvoeren**-modus en open op de **Client-PC** het :fa-terminal: **Terminal**.
2. Maak verbinding met poort 80 van de server:
   ```
   $ telnet 192.168.0.20 80
   ```
3. Typ de aanvraag regel voor regel in — en sluit af met een **lege regel** (gewoon nog een keer op **Enter** drukken):
   ```
   GET /kontakt.html HTTP/1.1
   Host: 192.168.0.20

   ```

De server antwoordt met een statusregel, headers en de contactpagina — als tekst, precies zoals de browser die ook krijgt.

Hoe herkent de server dat je aanvraag klaar is?
- [ ] Aan een speciaal commando `END`
- [x] Aan de lege regel
- [ ] Na een bepaalde tijd
:::

Welke waarde staat er in het antwoord bij de header `Content-Type`? (alleen het eerste deel vóór de `;`)

## Fouten uitlokken

Een handiger hulpmiddel is `curl`: dat doet de aanvraag voor je. Met `-v` (*verbose*, uitgebreid) laat het alles zien wat heen en weer gaat — regels met `>` heeft `curl` verzonden, regels met `<` kwamen van de server.

Probeer het uit:

```
$ curl -v http://192.168.0.20/gibtsnicht.html
$ curl -X POST -d name=Anna http://192.168.0.20/
```

:::quiz short
Welke statuscode krijg je voor `/gibtsnicht.html`?
= 404
:::

:::quiz short
En welke voor de aanvraag met de methode `POST`?
= 405
:::

:::note
De webserver in BeaverTracer kan alleen bestanden uitleveren — daarom staat hij alleen `GET` en `HEAD` toe. Echte webservers nemen met `POST` bijvoorbeeld formulieren in ontvangst en geven de gegevens door aan een programma.
:::

:::tip Onthoud
Veel protocollen van de applicatielaag zijn **tekstgebaseerd** — HTTP, maar ook SMTP, POP3 en IMAP. Je kunt ze daarom met `telnet` met de hand spreken en in de tracer meelezen. Dat is handig voor foutopsporing — maar ook een beveiligingsprobleem: iedereen die het verkeer opvangt, kan alles lezen. Hoe versleuteling (HTTPS) helpt, leer je in hoofdstuk 8.
:::

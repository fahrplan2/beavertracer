# Hashwaarden: de vingerafdruk van gegevens

:::sim
url=/sims/lesson-8.1.3.btsim
:::

Een **hashfunctie** berekent uit een willekeurige hoeveelheid gegevens — een zin, een document, een hele film — een korte tekenreeks van vaste lengte: de **hashwaarde**. Die werkt als een **vingerafdruk**: dezelfde gegevens geven altijd dezelfde hashwaarde, andere gegevens een andere.

De tegenwoordig gebruikelijke hashfunctie heet **SHA-256**. De hashwaarde is altijd 256 bit lang, als hexadecimaal getal dus 64 tekens.

## Het experiment

Op de **PC** staan in de map `/home` drie bestanden met een klein koopcontract. Schakel naar de :fa-play: **Uitvoeren**-modus, open op de **PC** het :fa-terminal: **Terminal** en voer in:

```
$ cd /home
$ cat vertrag.txt vertrag-kopie.txt vertrag-neu.txt
$ sha256sum vertrag.txt vertrag-kopie.txt vertrag-neu.txt
```

## Eigenschappen van een hashfunctie

| Eigenschap | Betekenis |
|---|---|
| **vaste lengte** | Hoe groot de gegevens ook zijn — de hashwaarde heeft altijd dezelfde lengte. |
| **eenduidig** | Dezelfde gegevens geven altijd dezelfde hashwaarde. |
| **lawine-effect** | Zelfs de kleinste wijziging geeft een totaal andere hashwaarde. |
| **eenrichtingsfunctie** | Uit de hashwaarde kunnen de gegevens **niet** worden teruggerekend. |
| **botsingsbestendig** | Het is praktisch onmogelijk om twee verschillende bestanden met dezelfde hashwaarde te vinden. |

Een hashfunctie is **geen versleuteling**: er is geen sleutel en er is geen ontsleuteling. Ze dient een ander doel — de **integriteit**.

## Waarvoor heb je dit nodig?

- **Downloads controleren:** Veel websites vermelden naast een bestand ook de SHA-256-waarde ervan. Komt de hashwaarde van je gedownloade bestand daarmee overeen, dan is het onderweg niet gewijzigd.
- **Wachtwoorden opslaan:** Goede websites slaan niet je wachtwoord op, maar alleen een hashwaarde ervan. Bij het inloggen wordt de hashwaarde van je invoer vergeleken. Als de database wordt gestolen, kent de dief de wachtwoorden toch niet.
- **Digitale handtekeningen:** In plaats van een heel document ondertekent men alleen de hashwaarde ervan — meer hierover in het volgende onderdeel.

:::tip Onthoud
Een **hashfunctie** (bijv. **SHA-256**) berekent uit willekeurige gegevens een **hashwaarde** van vaste lengte — een **vingerafdruk**. Zelfs de kleinste wijziging geeft een totaal andere hashwaarde, en uit de hashwaarde kunnen de gegevens niet worden teruggerekend. Hashwaarden waarborgen de **integriteit** van gegevens.

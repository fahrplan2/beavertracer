# DNS: namen in plaats van nummers

:::goal
**Leerdoel:** Je kunt uitleggen hoe DNS namen vertaalt naar IP-adressen, hoe de namen hiërarchisch zijn georganiseerd, zelf een record aanmaken en typische DNS-fouten opsporen.
:::

:::sim
url=/sims/lesson-6.2.btsim
:::

IP-adressen kan bijna niemand onthouden — namen zoals `www.beaver-schule.de` wel. De vertaling wordt gedaan door het **Domain Name System** (**DNS**), een soort wereldwijd telefoonboek van het internet.

Op de werkruimte staat nu een wat groter netwerk: naast de **Client-PC** en de **Webserver** zijn er vier **DNS-servers**. Waarom er zoveel zijn, zie je op de overnaastvolgende pagina.

# HTTP en HTTPS vergeleken

:::sim
url=/sims/lesson-8.2.1.btsim
:::

De webserver **www.beaver-schule.de** biedt het cijferportaal van de school zowel via HTTP als via HTTPS aan. Wat ziet iemand die meeluistert?

## Het experiment

1. Wissel naar de :fa-play: **Uitvoeren**-modus en open op de **Client-PC** in de :fa-globe: **Browser** eerst `http://www.beaver-schule.de/` en daarna `https://www.beaver-schule.de/`.
2. Open in de :fa-magnifying-glass: **Tracering**-modus een trace voor de **Client-PC**.
3. Zoek eerst het pakket `HTTP/1.1 200 OK` en klik erop. Onderaan in de details vind je de inhoud van de pagina.

:::quiz mc
Wat kan iemand die meeluistert zien bij **HTTP**?
- [x] De complete webpagina, ook de cijfers van Anna
- [ ] Alleen het adres van de server
- [ ] Niets, omdat HTTP via TCP loopt
:::

:::quiz short
Welk cijfer heeft Anna voor wiskunde?
= 2
:::

:::evaluate
Antwoorden controleren
:::

Nu het HTTPS-gedeelte. Zoek het `[SYN]`-pakket waarmee de client de tweede verbinding start.

:::quiz short
Welke doelpoort heeft de HTTPS-verbinding (kolom **Info**, `… → ???`)?
= 443
:::

Typ nu bovenaan in het filterveld van de trace `tls` — dan zie je alleen nog de TLS-pakketten.

:::quiz mc
Wat staat er in de kolom **Info** bij de pakketten die de webpagina bevatten?
- [ ] `HTTP/1.1 200 OK`
- [x] `Application Data`
- [ ] `Encrypted HTML`
:::

:::quiz multi
Wat kan iemand die meeluistert bij **HTTPS** nog steeds zien?
- [x] De IP-adressen van client en server
- [x] Dat poort 443 wordt gebruikt, dus waarschijnlijk HTTPS
- [x] Ongeveer hoeveel gegevens er worden verzonden
- [ ] Welke pagina is opgevraagd en wat erop staat
:::

:::evaluate
Antwoorden controleren
:::

:::note
Klik op een **Application Data**-pakket: de nuttige gegevens zijn slechts een reeks schijnbaar willekeurige bytes. De tracer kan ze niet ontsleutelen — hij kent de sessiesleutel net zomin als een aanvaller.
:::

:::tip Onthoud
Bij **HTTP** kan iedereen die meeluistert de complete webpagina lezen. Bij **HTTPS** ziet hij alleen nog **wie met wie** communiceert (IP-adressen, poort 443) en **hoeveel** — de inhoud zit versleuteld in **Application Data**-pakketten.
:::

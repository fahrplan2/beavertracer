# HTTP: webpagina's

:::goal
**Leerdoel:** Je kunt de opbouw van een HTTP-aanvraag en -antwoord beschrijven, belangrijke methoden en statuscodes uitleggen en zelf met de hand een HTTP-aanvraag versturen.
:::

Het **Hypertext Transfer Protocol** (**HTTP**) is de taal waarin browsers en webservers met elkaar communiceren. Op de server staat de website van de **Beaver-Schule**: een startpagina, een contactpagina en een stylesheet voor de opmaak.

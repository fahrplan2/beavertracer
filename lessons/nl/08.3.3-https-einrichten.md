# HTTPS instellen

:::sim
url=/sims/lesson-8.3.3.btsim
:::

Hier gaan we verder waar sectie 8.2.2 ophield: Op de webserver **www.beaver-schule.de** staan de **Schul-CA** en een door deze CA uitgegeven servercertificaat, en de **Client-PC** vertrouwt de Schul-CA. Alleen spreekt de webserver nog geen HTTPS.

## Vooraf

Schakel over naar de :fa-play: **Uitvoermodus** en open op de **Client-PC** in de :fa-globe: **Browser** `https://www.beaver-schule.de/`.

:::quiz mc
Wat gebeurt er?
- [x] De verbinding komt niet tot stand — op poort 443 luistert geen enkele service
- [ ] De browser waarschuwt voor een onveilig certificaat
- [ ] De pagina wordt weergegeven zonder slotje
:::

:::evaluate
Antwoord controleren
:::

## HTTPS inschakelen

1. Open op de webserver de **HTTP-server** en klik op **Stoppen** — zolang de server draait, kunnen de instellingen niet worden gewijzigd.
2. Ga naar het tabblad **HTTPS**:
    - Vink **HTTPS aktivieren** aan, **HTTPS-Port** `443`
    - Kies bij **Zertifikat** het servercertificaat `www.beaver-schule.de` — niet de Schul-CA!
    - Klik op **Verwenden**
3. Klik op **Starten**.

Open de pagina op de Client-PC opnieuw via `https://`. Klik op het slotje en controleer de uitgever en de geldigheid.

title: HTTPS ingesteld?
Controleert of de Client-PC https://www.beaver-schule.de/ zonder certificaatwaarschuwing kan ophalen. De simulatie moet hiervoor in de uitvoermodus draaien.
check: httpsOk(2, "https://www.beaver-schule.de/")
:::

:::quiz mc
Waarom mag je in de HTTP-server niet het certificaat van de **Schul-CA** kiezen?
- [ ] Omdat CA-certificaten niet kunnen versleutelen
- [x] Omdat het is uitgegeven voor de naam `Schul-CA`, niet voor `www.beaver-schule.de` — de browser zou waarschuwen
- [ ] Omdat de Schul-CA geen privésleutel heeft
:::

:::quiz mc
Wat zou een apparaat zien dat de Schul-CA **niet** vertrouwt, bijvoorbeeld de telefoon van een gast?
- [ ] De pagina gewoon met slotje
- [x] Een certificaatwaarschuwing, omdat het de vertrouwensketen niet kan terugvolgen tot een bekende CA
- [ ] Helemaal niets, omdat de verbinding wordt geweigerd
:::

:::evaluate
Antwoorden controleren
:::

:::note
Voor openbare websites heb je een certificaat nodig van een CA die in alle browsers vooraf is geïnstalleerd. Sinds 2015 is er met **Let's Encrypt** een CA die zulke certificaten gratis en automatisch uitgeeft — een belangrijke reden dat tegenwoordig bijna alle websites HTTPS gebruiken.
:::

:::tip Onthoud
Voor **HTTPS** heeft de webserver een **servercertificaat met privésleutel** nodig, waarvan de naam bij het adres past, en moet hij op **poort 443** luisteren. De client vertrouwt de website alleen als hij de uitgevende **CA** kent.
:::

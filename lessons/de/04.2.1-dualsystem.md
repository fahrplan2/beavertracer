# Das Dualsystem

Ein Computer kennt im Innersten nur zwei Zustände: Strom an oder Strom aus. Dafür schreibt man **1** und **0**. Eine solche Stelle heißt **Bit**. Auch jede IP-Adresse ist für den Computer nur eine Folge von Nullen und Einsen — damit du verstehst, wie Netzmasken funktionieren, lernst du auf dieser Seite, solche Zahlen zu lesen und selbst umzurechnen.

## Wie wir normalerweise zählen: das Dezimalsystem

Im Alltag rechnen wir mit zehn Ziffern (0 bis 9). Jede Stelle ist zehnmal so viel wert wie die Stelle rechts daneben: Einer, Zehner, Hunderter, Tausender. Die Zahl `305` bedeutet also:

| Stellenwert | 100 | 10 | 1 |
|---|---|---|---|
| Ziffer | 3 | 0 | 5 |
| Wert | 300 | 0 | 5 |

300 + 0 + 5 = **305**

## Das Dualsystem

Im **Dualsystem** (auch *Binärsystem*) gibt es nur zwei Ziffern: 0 und 1. Jede Stelle ist **doppelt** so viel wert wie die Stelle rechts daneben: 1, 2, 4, 8, 16, 32, 64, 128 …

Die Dualzahl `00001101` bedeutet also:

| Stellenwert | 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1 |
|---|---|---|---|---|---|---|---|---|
| Bit | 0 | 0 | 0 | 0 | 1 | 1 | 0 | 1 |
| Wert | | | | | 8 | 4 | | 1 |

8 + 4 + 1 = **13**

Du zählst also einfach die Stellenwerte zusammen, an denen eine 1 steht.

:::tip Merksatz
Ein **Bit** ist eine Stelle im Dualsystem (0 oder 1). **8 Bit** ergeben ein **Byte** — in der Netzwerktechnik nennt man so ein 8-Bit-Päckchen auch **Oktett**. Die Stellenwerte eines Oktetts sind **128, 64, 32, 16, 8, 4, 2, 1**.
:::

:::

## Von dezimal nach dual

Umgekehrt gehst du die Stellenwerte von links nach rechts durch und fragst jedes Mal: **Passt der Stellenwert noch in meine (Rest-)Zahl?** Wenn ja, schreibst du eine 1 und ziehst den Stellenwert ab. Wenn nein, schreibst du eine 0.

Beispiel: `168`

| Stellenwert | passt in …? | Bit | Rest |
|---|---|---|---|
| 128 | 168 → ja | **1** | 40 |
| 64 | 40 → nein | **0** | 40 |
| 32 | 40 → ja | **1** | 8 |
| 16 | 8 → nein | **0** | 8 |
| 8 | 8 → ja | **1** | 0 |
| 4 | 0 → nein | **0** | 0 |
| 2 | 0 → nein | **0** | 0 |
| 1 | 0 → nein | **0** | 0 |

Von oben nach unten gelesen: 168 = **10101000**

:::tip Tipp
Diese Werte begegnen dir bei Netzmasken immer wieder — es lohnt sich, sie zu kennen: `10000000` = 128, `11000000` = 192, `11100000` = 224, `11110000` = 240, `11111000` = 248, `11111100` = 252, `11111110` = 254, `11111111` = 255.
:::

## IP-Adressen im Dualsystem

Eine IPv4-Adresse besteht aus **32 Bit**, also vier Oktetten. Weil sich 32 Nullen und Einsen niemand merken kann, schreibt man jedes Oktett als Dezimalzahl und trennt sie durch Punkte:

```
11000000 . 10101000 . 10110010 . 00000001
   192   .   168    .   178    .    1
```

:::quiz short
Aus wie vielen Bit besteht eine IPv4-Adresse?
= 32
:::

:::quiz mc
Wie viele verschiedene IPv4-Adressen gibt es theoretisch?
- [ ] 256 × 4 = 1024
- [x] 2³² — rund 4,3 Milliarden
- [ ] Mehr als genug — für jeden Menschen auf der Erde mehrere
:::

:::evaluate
Antworten prüfen
:::

:::note
Rund 4,3 Milliarden klingt viel — es ist aber weniger als eine Adresse pro Mensch auf der Erde. Deshalb wird IPv4 schon lange knapp. Wie man damit umgeht, lernst du später bei NAT und IPv6.
:::

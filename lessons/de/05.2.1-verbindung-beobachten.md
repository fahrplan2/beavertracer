# Eine Verbindung von Anfang bis Ende

:::sim
url=/sims/lesson-5.1.btsim
:::

Auf dem **Server** läuft der Echo-Dienst auf Port `5000`: Jede Nachricht schickt er sofort zurück. Mit dem **Einfachen TCP-Client** kannst du eine Verbindung Schritt für Schritt steuern — jeder Knopf ist eine Phase.

## Das Experiment

1. Wechsle in den :fa-play: **Ausführen**-Modus, klicke auf den **Client-PC** und öffne den **Einfachen TCP-Client**.
2. Trage bei **Host** `192.168.0.20` und bei **Port** `5000` ein.
3. Klicke auf **Verbinden**.
4. Tippe `Hello World` ins Nachrichtenfeld und klicke auf **Senden**. Im Chat-Fenster siehst du gleich darauf das Echo des Servers.
5. Klicke auf **Trennen**.
6. Wechsle in den :fa-magnifying-glass: **Verfolgung**-Modus und öffne mit **+** einen Trace für den **Client-PC**, Anschluss `eth0`.

:::note
Die beiden ARP-Pakete am Anfang kennst du schon aus Kapitel 1. In der **Info**-Spalte der TCP-Pakete steht zuerst `49152 → 5000` (von welchem zu welchem Port), dann in eckigen Klammern die **Flags** und danach Zahlen wie `Seq=`, `Ack=` und `Len=`. Um die Zahlen geht es ab Seite 5.2.3 — hier achtest du auf Flags und `Len`.
:::

## Phase 1: Verbinden

:::quiz short
Wie viele TCP-Pakete wurden ausgetauscht, nachdem du auf **Verbinden** geklickt hast — bevor deine Nachricht losging?
= 3
= drei
:::

:::quiz mc
Wer schickt das erste Paket mit `[SYN]`?
- [x] Der Client-PC
- [ ] Der Server
:::

:::quiz mc
Mit welchen Flags antwortet der Server darauf?
- [ ] `[SYN]`
- [x] `[SYN, ACK]`
- [ ] `[ACK]`
- [ ] `[FIN, ACK]`
:::

## Phase 2: Senden

`Len` gibt an, wie viele Bytes Nutzdaten ein Paket trägt.

:::quiz short
Wie viele Bytes trägt das Paket mit deiner Nachricht (`Len`)?
= 13
:::

:::note
`Hello World` hat nur 11 Zeichen. Der TCP-Client hängt aber ein Zeilenende an (2 Byte, `\r\n`) — so erwarten es viele Internet-Protokolle wie SMTP oder HTTP.
:::

:::quiz mc
Was schickt der Server direkt nach deiner Nachricht zurück — noch vor dem Echo?
- [x] Ein Paket mit `[ACK]` und `Len=0` — eine Bestätigung ohne Daten
- [ ] Gar nichts
- [ ] Ein neues `[SYN]`
:::

## Wo stecken die vier Aufgaben?

Ordne zu, wo du die Aufgaben aus Abschnitt 5.1 im Trace wiederfindest:

:::quiz match
Verbindungsaufbau -> Die drei Pakete [SYN], [SYN, ACK] und [ACK]
Zuverlässige Übertragung -> Pakete mit [ACK] und Len=0, die den Empfang bestätigen
Verbindungsabbau -> Die Pakete mit FIN und ihre Bestätigungen
Multiplexen -> Die Portnummern 49152 → 5000 vor den eckigen Klammern
:::

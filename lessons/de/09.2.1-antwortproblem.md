# Das Antwortproblem

:::sim
url=/sims/lesson-9.2.btsim
:::

Die Firewall arbeitet jetzt nach dem Whitelist-Prinzip: Standardrichtlinie **Alle verwerfen**. Eine einzige Regel erlaubt dem Schulnetz das Surfen: **B → A, TCP, Ziel-Port 80, Zulassen**. Der Modus steht auf **Stateless**.

## Das Experiment

1. Wechsle in den :fa-play: **Ausführen**-Modus und rufe auf dem **Lehrer-PC** im :fa-globe: **Browser** `http://203.0.113.80/` auf.
2. Sieh dir in der **Firewall** das **Protokoll** und die **Treffer** an.

:::quiz mc
Was passiert im Browser?
- [ ] Die Seite von www.beispiel.de erscheint
- [x] Die Seite lädt nicht, der Browser wartet und meldet schließlich einen Fehler
:::

:::quiz mc
Welche Pakete stehen im Protokoll der Firewall als verworfen (`DROP`)?
- [ ] Die Anfragen des Lehrer-PCs an Port 80
- [x] Die Antworten von `203.0.113.80` mit **Quellport 80** an den Lehrer-PC
- [ ] Gar keine
:::

:::quiz short
In welcher Richtung (A→B oder B→A) laufen die verworfenen Pakete?
= A→B
= A → B
= AtoB
:::

:::evaluate
Antworten prüfen
:::

Die Anfrage des Lehrer-PCs darf hinaus — aber schon das `SYN, ACK` des Webservers kommt nicht zurück, denn für die Richtung A → B gibt es keine passende Regel, also gilt **Alle verwerfen**.

## Die naive Lösung

Man könnte eine zweite Regel eintragen: **A → B, TCP, Quell-Port 80, Zulassen** — „alles, was von Port 80 kommt, darf herein“. Dann klappt das Surfen tatsächlich.

:::quiz mc
Warum ist diese Regel gefährlich?
- [ ] Weil Webserver nie Port 80 als Quellport benutzen
- [x] Ein Angreifer kann seine Pakete einfach mit Quellport 80 losschicken — dann lässt die Firewall sie zu **jedem** Port im Schulnetz durch
- [ ] Weil dann die Webseiten langsamer laden
:::

:::evaluate
Antwort prüfen
:::

Den Quellport legt der Absender selbst fest — auf ihn darf sich eine Firewall nicht verlassen. Eine zustandslose Firewall weiß aber nicht, ob ein Paket die **Antwort auf eine Anfrage** ist oder ein **neuer Verbindungsversuch** von außen. Genau das ändert der zustandsbehaftete Modus.

:::tip Merksatz
Ein **zustandsloser** Paketfilter prüft jedes Paket einzeln. Antworten brauchen dann eigene Regeln für die Rückrichtung — und solche Regeln (z.B. „Quellport 80 darf herein“) lassen sich von Angreifern ausnutzen, weil der Absender den Quellport frei wählen kann.
:::

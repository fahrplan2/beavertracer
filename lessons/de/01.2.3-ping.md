# Ping ausführen und Ausgabe lesen

Wechsle in den :fa-play: **Ausführen**-Modus. Öffne auf einem der PCs das :fa-terminal: Terminal und tippe:

```
$ ping 192.168.0.11
```

(natürlich mit der IP-Adresse deines *zweiten* PCs).

Antwortet der andere PC, siehst du für jedes gesendete Paket eine Zeile mit Antwortzeit — dein erster erfolgreicher Ping!

:::warning
Kommt keine Antwort? Prüfe, ob beide PCs wirklich verbunden sind und im selben Netz liegen (siehe letzte Seite).
:::

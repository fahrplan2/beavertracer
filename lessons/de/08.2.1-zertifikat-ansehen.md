# Ein Zertifikat ansehen

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Auf der Arbeitsfläche siehst du den **Client-PC**, einen **DNS-Server** und den Webserver der Schule, `www.beaver-schule.de`. Der Webserver bietet seine Seiten auch über **HTTPS** an.

## Das Schloss im Browser

1. Wechsle in den :fa-play: **Ausführen**-Modus, klicke auf den **Client-PC** und öffne den :fa-globe: **Browser**.
2. Rufe `https://www.beaver-schule.de/` auf — achte auf das **https**.
3. Links neben der Adresse erscheint ein **Schloss**. Klicke darauf.

:::quiz short
Für welchen Namen wurde das Zertifikat ausgestellt (Betreff ohne `CN=`)?
= www.beaver-schule.de
:::

:::quiz short
Wer hat das Zertifikat ausgestellt (Aussteller ohne `CN=`)?
= Biber Root CA
:::

:::evaluate
Antworten prüfen
:::

## Warum vertraut der Client-PC dem Zertifikat?

Öffne auf dem **Client-PC** die :fa-shield-halved: **Zertifikatverwaltung** und wechsle in den Reiter **Vertrauenswürdige CAs**.

:::quiz mc
Was findest du dort?
- [x] Das Zertifikat der **Biber Root CA**
- [ ] Das Zertifikat von `www.beaver-schule.de`
- [ ] Keine Einträge
:::

:::quiz mc
Wie sieht man, dass die Biber Root CA eine Root-CA ist?
- [x] Sie ist **selbstsigniert**: Betreff und Aussteller sind gleich
- [ ] Ihr Name endet auf „CA“
- [ ] Sie hat keinen öffentlichen Schlüssel
:::

:::quiz mc
Steht beim Client-PC unter **Privater Schlüssel** „Ja“ oder „Nein“?
- [ ] Ja — der Client braucht den privaten Schlüssel der CA, um Signaturen zu prüfen
- [x] Nein — zum Prüfen reicht der öffentliche Schlüssel; den privaten Schlüssel hat nur die CA
:::

:::evaluate
Antworten prüfen
:::

## Die Gegenseite: der Webserver

Öffne jetzt auf dem Webserver **www.beaver-schule.de** die :fa-shield-halved: **Zertifikatverwaltung** (Reiter **Meine Zertifikate**) und sieh dir sein Zertifikat an.

:::quiz multi
Was stimmt für das Zertifikat auf dem Webserver?
- [x] Unter **Privater Schlüssel** steht „Ja“ — der Server braucht ihn für den Verbindungsaufbau
- [x] Die **Kette** lautet `www.beaver-schule.de ← Biber Root CA`
- [x] Der **Fingerabdruck** ist derselbe wie im Schloss-Fenster des Browsers
- [ ] Es ist selbstsigniert
:::

:::evaluate
Antworten prüfen
:::

:::note
Der **Fingerabdruck** ist ein Hashwert über das Zertifikat. Damit kann man zwei Zertifikate schnell vergleichen — ganz ohne alle Felder einzeln zu prüfen.
:::

:::tip Merksatz
Der **Webserver** besitzt sein Zertifikat **mit privatem Schlüssel**. Der **Client** kennt nur das **Zertifikat der Root-CA** (ohne privaten Schlüssel) — das reicht ihm, um die Signatur auf dem Server-Zertifikat zu prüfen. Klickt man im Browser auf das **Schloss**, sieht man Betreff, Aussteller, Fingerabdruck und Gültigkeit.
:::

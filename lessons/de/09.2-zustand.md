# Zustandslos oder zustandsbehaftet

Eine Verbindung besteht immer aus **zwei Richtungen**: Der Lehrer-PC schickt eine Anfrage an einen Webserver im Internet — und der Webserver schickt die Webseite zurück. Eine Firewall nach dem Whitelist-Prinzip muss also nicht nur die Anfrage durchlassen, sondern auch die **Antwort**.

Dafür gibt es zwei Arten von Paketfiltern:

| | **Zustandslos** (*stateless*) | **Zustandsbehaftet** (*stateful*) |
|---|---|---|
| Arbeitsweise | prüft jedes Paket einzeln, ohne Gedächtnis | merkt sich erlaubte Verbindungen in einer **Zustandstabelle** |
| Antworten | brauchen eine eigene Regel für die Rückrichtung | werden automatisch durchgelassen, weil sie zu einer bekannten Verbindung gehören |
| Einsatz | einfache Geräte, sehr schnelle Filter | praktisch jede heutige Firewall |

In den nächsten beiden Abschnitten erlebst du, warum zustandslose Filter mit Antworten Probleme haben — und wie eine zustandsbehaftete Firewall sie löst.

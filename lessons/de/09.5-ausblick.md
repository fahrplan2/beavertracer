# Zusammenfassung und Ausblick

## Firewalls an vielen Stellen

Den Paketfilter aus diesem Kapitel findest du in vielen Geräten wieder:

- **Heimrouter:** Jeder Heimrouter ist auch eine zustandsbehaftete Firewall. Mit IPv4 übernimmt NAT einen Teil davon: Von außen kann niemand eine Verbindung beginnen, solange es keine Portweiterleitung gibt (Kapitel 7). Mit IPv6 haben alle Geräte öffentliche Adressen — dann sorgt allein die Firewall-Regel „von außen nichts Neues herein“ für denselben Schutz.
- **Personal Firewall:** Auch Windows, macOS und Linux haben eine eingebaute Firewall auf dem Rechner selbst. Sie schützt das Gerät auch in fremden Netzen, z.B. im WLAN eines Cafés, und kann Regeln pro Programm aufstellen.
- **Next-Generation-Firewall** und **Web Application Firewall (WAF):** Sie schauen nicht nur auf Adressen und Ports, sondern in den Inhalt der Pakete — bis zur Anwendungsschicht. So erkennen sie z.B. Angriffe in HTTP-Anfragen. Bei HTTPS müssen sie dafür die Verschlüsselung aufbrechen (Kapitel 8).
- **IDS/IPS:** Ein *Intrusion Detection System* erkennt verdächtige Muster im Datenverkehr und schlägt Alarm; ein *Intrusion Prevention System* blockiert sie zusätzlich selbst.

:::note
Eine Firewall ist nur **ein** Baustein der Sicherheit. Sie hilft nicht, wenn ein erlaubter Dienst (z.B. der Webserver) selbst eine Lücke hat, wenn jemand ein Schadprogramm per E-Mail öffnet oder wenn ein Passwort schwach ist. Deshalb gehören Updates, sichere Passwörter, Verschlüsselung und eine kluge Aufteilung des Netzes (DMZ, VLANs aus Kapitel 3) immer dazu.
:::

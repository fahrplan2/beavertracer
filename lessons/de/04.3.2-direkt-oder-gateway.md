# Direkt oder über das Gateway?

:::sim
url=/sims/lesson-4.3.2.btsim
:::

Bevor ein PC ein Paket verschickt, entscheidet er: Liegt das Ziel im **eigenen Netz**? Dazu vergleicht er den Netzteil seiner eigenen Adresse mit dem Netzteil der Zieladresse — mit Hilfe seiner Netzmaske.

## Der Ablauf

1. **Liegt die Ziel-IP im eigenen Netz?**
   - **Ja:** Der PC schickt das Paket **direkt** an das Ziel. Er braucht die MAC-Adresse des Ziels.
   - **Nein:** Der PC schickt das Paket an das **Gateway**. Er braucht die MAC-Adresse des Routers. Ist kein Gateway eingetragen, kann er das Paket gar nicht verschicken.
2. **Kennt er die benötigte MAC-Adresse schon** (steht sie in seinem ARP-Cache)? Wenn nicht, fragt er per **ARP** danach.
3. Er schickt den Frame an diese MAC-Adresse. Die **Ziel-IP-Adresse** im Paket ist in beiden Fällen das eigentliche Ziel.

| | direkt (eigenes Netz) | über das Gateway (fremdes Netz) |
|---|---|---|
| ARP fragt nach … | der MAC des Ziels | der MAC des Routers |
| Ziel-MAC im Frame | Ziel | Router |
| Ziel-IP im Paket | Ziel | Ziel |

## Fehlersuche: Firma B ist nicht erreichbar

Seit gestern erreicht Anna die PCs in Firma B nicht mehr. So *soll* das Netz eingerichtet sein:

| Gerät | IP-Adresse | Gateway |
|---|---|---|
| Anna | `192.168.0.10/24` | `192.168.0.1` |
| Ben | `192.168.0.11/24` | `192.168.0.1` |
| Clara | `172.16.0.10/24` | `172.16.0.1` |
| David | `172.16.0.11/24` | `172.16.0.1` |

Finde die Fehler und behebe sie.

<details>
<summary>Tipp 1: Kommt Annas Ping überhaupt an?</summary>

Pinge von Anna aus Clara an und öffne einen Trace für **Clara**. Ist der Ping angekommen? Und hat Clara geantwortet?
</details>

<details>
<summary>Tipp 2: Was macht David?</summary>

Pinge von Anna aus David an und öffne einen Trace für **David**. Nach welcher IP-Adresse fragt David per ARP — und bekommt er eine Antwort?
</details>

:::tip Merksatz
Ein PC braucht das richtige Gateway nicht nur zum Senden, sondern auch zum **Antworten**: Ohne Gateway kommt der Ping zwar an, aber die Antwort findet keinen Weg zurück. Ist eine **falsche Gateway-Adresse** eingetragen, fragt der PC per ARP vergeblich nach einem Router, den es nicht gibt.
:::

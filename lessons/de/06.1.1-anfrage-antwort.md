Eine Webseite besteht also oft aus vielen Dateien: Text, Stylesheets, Bilder. Für jede schickt der Browser eine eigene Anfrage.

## Wie eine Anfrage aussieht

Klicke im Trace auf das Paket `GET / HTTP/1.1` und klappe **Hypertext Transfer Protocol** auf. Eine HTTP-Anfrage ist reiner Text:

```
GET / HTTP/1.1              ← Methode, Pfad, Version
Host: 192.168.0.20          ← Header: zusätzliche Angaben
…
                            ← Leerzeile: Ende der Anfrage
```

Die Antwort des Servers ist genauso aufgebaut — mit einer Statuszeile, Headern, einer Leerzeile und danach der eigentlichen Datei:

```
HTTP/1.1 200 OK             ← Version, Statuscode, Text
Content-Type: text/html     ← Header: Art der Datei
Content-Length: 301         ← Header: Größe in Byte
                            ← Leerzeile
<!doctype html> …           ← die Datei selbst
```

:::seq
mode: text
Client-PC -> Server: GET / | HTTP-Anfrage
Server -> Client-PC: 200 OK | index.html
Client-PC -> Server: GET /style.css | HTTP-Anfrage
Server -> Client-PC: 200 OK | style.css
:::

## Methoden und Statuscodes

Die **Methode** sagt, was der Client will:

| Methode | Bedeutung |
|---|---|
| **GET** | eine Datei abrufen |
| **POST** | Daten an den Server schicken, z.B. ein ausgefülltes Formular |
| **HEAD** | nur die Header abrufen, ohne die Datei |

Der **Statuscode** sagt, wie es gelaufen ist. Die erste Ziffer verrät die Art der Antwort:

| Code | Text | Bedeutung |
|---|---|---|
| **200** | OK | alles in Ordnung |
| **301** | Moved Permanently | die Seite ist dauerhaft umgezogen |
| **404** | Not Found | die Datei gibt es nicht |
| **405** | Method Not Allowed | diese Methode ist hier nicht erlaubt |
| **500** | Internal Server Error | Fehler auf dem Server |

`2xx` heißt Erfolg, `3xx` Umleitung, `4xx` ein Fehler des Clients (falsche Anfrage), `5xx` ein Fehler des Servers.

:::tip Merksatz
**HTTP** arbeitet nach dem **Anfrage-Antwort-Prinzip**: Der Client schickt eine **Anfrage** (Methode wie `GET`, Pfad, Header), der Server antwortet mit einem **Statuscode** (z.B. `200 OK`, `404 Not Found`), Headern und der Datei. Für jede Datei einer Webseite gibt es eine eigene Anfrage.
:::

301 -> Die Seite ist dauerhaft umgezogen
404 -> Die angefragte Datei gibt es nicht
500 -> Auf dem Server ist ein Fehler aufgetreten
:::

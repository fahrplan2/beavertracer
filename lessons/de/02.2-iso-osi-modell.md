# Das ISO/OSI-Referenzmodell

Das ISO/OSI-Modell unterteilt die Kommunikation zwischen zwei Geräten in sieben Schichten. Jede Schicht hat eine klar abgegrenzte Aufgabe und nutzt nur die Dienste der Schicht direkt darunter:

Aus dem Experiment auf der letzten Seite kennst du bereits vier dieser Schichten: Ethernet (2), IPv4 (3), TCP (4) und HTTP (7). Genau diese Nummern und Farben zeigt dir der Tracer im Protokollbaum an.

:::tip Eselsbrücke
Von Schicht 7 nach unten: **A**lle **D**eutschen **S**tudenten **T**rinken **V**erschiedene **S**orten **B**ier — **A**nwendung, **D**arstellung, **S**itzung, **T**ransport, **V**ermittlung, **S**icherung, **B**itübertragung.
:::

:::note Grenzfälle
Nicht jedes Protokoll passt genau in eine Schicht. Der Tracer zeigt bei diesen Protokollen deshalb mehrere Schichten an:

- **ARP** — Schicht 2/3: Es hat keinen IP-Kopf, verbindet aber IP-Adressen (Schicht 3) mit Hardware-Adressen (Schicht 2).
- **TLS** — Schicht 4/5: Es sitzt direkt auf TCP und verwaltet eine gesicherte Sitzung.
- **HTTPS** (HTTP innerhalb von TLS) — Schicht 5–7: die klassische Anwendungsschicht des TCP/IP-Modells, das du auf der nächsten Seite kennenlernst.
:::

:::note
Schicht 1 beschreibt die eigentliche Signalübertragung auf dem Kabel oder per Funk. BeaverTracer simuliert diese Ebene nicht — Kabel gelten immer als fehlerfrei verbunden, es gibt weder Signalprobleme noch Kollisionen. Im Tracer beginnt die Betrachtung deshalb praktisch bei Schicht 2.
:::

# Schleifen im Netz und Spanning Tree

:::goal
**Lernziel:** Du kannst erklären, wie in einem Netz mit Schleife ein Broadcast-Sturm entsteht und wie das Spanning Tree Protocol (STP) Schleifen verhindert, ohne auf Ausfallsicherheit zu verzichten.
:::

:::sim
url=/sims/lesson-3.4.1.btsim
:::

Was passiert, wenn in einem Netz ein Kabel kaputtgeht? Hängt alles an einer einzigen Leitung, ist ein Teil des Netzes abgeschnitten. Deshalb verbindet man Switches in größeren Netzen oft **mehrfach** — so wie die drei Switches auf der Arbeitsfläche, die einen Ring bilden. Fällt ein Kabel aus, gibt es einen Umweg.

Klingt gut — aber so ein Ring hat einen gefährlichen Haken. Den lernst du auf der nächsten Seite kennen.

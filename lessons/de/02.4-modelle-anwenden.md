# Modelle anwenden

Ordne die Protokolle aus dem Experiment vom Anfang des Kapitels ihrer OSI-Schicht zu:

:::quiz match
Ethernet -> Schicht 2 — Sicherung
IPv4 -> Schicht 3 — Vermittlung
TCP -> Schicht 4 — Transport
HTTP -> Schicht 7 — Anwendung
:::

:::evaluate
Zuordnung prüfen
:::

Und zum Schluss die Namen der Dateneinheiten:

:::quiz match
Frame -> Schicht 2 — Sicherung
Paket -> Schicht 3 — Vermittlung
Segment -> Schicht 4 — Transport
:::

:::evaluate
Zuordnung prüfen
:::

Damit hast du das Handwerkszeug, um Protokolle künftig sauber einzuordnen. Ab dem nächsten Kapitel gehen wir die Schichten der Reihe nach durch — beginnend mit Schicht 2 und der Frage, wie ein Switch eigentlich weiß, wohin er ein Paket weiterleiten muss.

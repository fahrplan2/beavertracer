# Hashwerte: der Fingerabdruck von Daten

:::sim
url=/sims/lesson-8.1.3.btsim
:::

Eine **Hashfunktion** berechnet aus beliebig vielen Daten — einem Satz, einem Dokument, einem ganzen Film — eine kurze Zeichenfolge fester Länge: den **Hashwert**. Er funktioniert wie ein **Fingerabdruck**: Gleiche Daten ergeben immer denselben Hashwert, andere Daten einen anderen.

Die heute übliche Hashfunktion heißt **SHA-256**. Ihr Hashwert ist immer 256 Bit lang, als Hexadezimalzahl also 64 Zeichen.

## Das Experiment

Auf dem **PC** liegen im Ordner `/home` drei Dateien mit einem kleinen Kaufvertrag. Wechsle in den :fa-play: **Ausführen**-Modus, öffne auf dem **PC** das :fa-terminal: **Terminal** und gib ein:

```
$ cd /home
$ cat vertrag.txt vertrag-kopie.txt vertrag-neu.txt
$ sha256sum vertrag.txt vertrag-kopie.txt vertrag-neu.txt
```

## Eigenschaften einer Hashfunktion

| Eigenschaft | Bedeutung |
|---|---|
| **feste Länge** | Egal wie groß die Daten sind — der Hashwert hat immer dieselbe Länge. |
| **eindeutig** | Gleiche Daten ergeben immer denselben Hashwert. |
| **Lawineneffekt** | Schon die kleinste Änderung ergibt einen völlig anderen Hashwert. |
| **Einwegfunktion** | Aus dem Hashwert lassen sich die Daten **nicht** zurückberechnen. |
| **kollisionsresistent** | Es ist praktisch unmöglich, zwei verschiedene Dateien mit demselben Hashwert zu finden. |

Eine Hashfunktion ist **keine Verschlüsselung**: Es gibt keinen Schlüssel und kein Entschlüsseln. Sie dient einem anderen Zweck — der **Integrität**.

## Wofür braucht man das?

- **Downloads prüfen:** Viele Webseiten geben neben einer Datei ihren SHA-256-Wert an. Stimmt der Hashwert deiner heruntergeladenen Datei damit überein, ist sie unterwegs nicht verändert worden.
- **Passwörter speichern:** Gute Webseiten speichern nicht dein Passwort, sondern nur einen Hashwert davon. Beim Anmelden wird der Hashwert deiner Eingabe verglichen. Wird die Datenbank gestohlen, kennt der Dieb die Passwörter trotzdem nicht.
- **Digitale Signaturen:** Statt eines ganzen Dokuments unterschreibt man nur seinen Hashwert — mehr dazu im nächsten Abschnitt.

:::tip Merksatz
Eine **Hashfunktion** (z.B. **SHA-256**) berechnet aus beliebigen Daten einen **Hashwert** fester Länge — einen **Fingerabdruck**. Schon die kleinste Änderung ergibt einen völlig anderen Hashwert, und aus dem Hashwert lassen sich die Daten nicht zurückberechnen. Hashwerte sichern die **Integrität** von Daten.
:::

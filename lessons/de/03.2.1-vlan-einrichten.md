# Ein Switch, zwei Netze

:::sim
url=/sims/lesson-3.2.1.btsim
:::

Am Switch hängen vier PCs: das **Sekretariat** (Port 1) und die **Schulleitung** (Port 2) aus der Verwaltung, dazu **Anna** (Port 3) und **Ben** (Port 4) aus dem Computerraum. Alle liegen im selben Netz `192.168.0.0/24`.

## Das Problem

Wechsle in den :fa-play: **Ausführen**-Modus, öffne auf **Anna** das :fa-terminal: **Terminal** und pinge das Sekretariat an:

```
$ ping 192.168.0.10
```

Anna erreicht das Sekretariat ohne Weiteres. Genau das wollen wir verhindern.

## VLANs einrichten

Ein **VLAN** (*Virtual LAN*) ist ein eigenes, abgetrenntes Netz innerhalb eines Switches. Jedes VLAN hat eine Nummer, die **VLAN-ID**. Wir legen fest: Die Verwaltung kommt in **VLAN 10**, der Computerraum in **VLAN 20**.

1. Klicke im Ausführen-Modus auf den **Switch** und öffne den Reiter **VLAN**.
2. Setze das Häkchen bei **VLAN aktivieren**. Es erscheint eine Tabelle mit einer Zeile pro Port.
3. Trage in der Spalte **PVID** die VLAN-ID ein — bei **port 1** und **port 2** jeweils `10`, bei **port 3** und **port 4** jeweils `20`. Den **Modus** lässt du auf `untagged`.
4. Klicke unten auf **Anwenden**.

:::note
**PVID** steht für *Port VLAN ID*: Alles, was an diesem Port ankommt, gehört zu diesem VLAN. Der Modus `untagged` bedeutet, dass an diesem Port ein ganz normaler PC hängt, der von VLANs nichts wissen muss.
:::

## Testen

Pinge von **Anna** aus noch einmal das Sekretariat an — und danach Ben (`ping 192.168.0.21`).

:::quiz mc
Was passiert jetzt?
- [ ] Anna erreicht das Sekretariat und Ben
- [x] Anna erreicht Ben, aber nicht mehr das Sekretariat
- [ ] Anna erreicht niemanden mehr
:::

:::evaluate
Antwort prüfen
:::

Öffne im :fa-magnifying-glass: **Verfolgung**-Modus einen Trace für das **Sekretariat**: Annas ARP-Anfragen („Who has 192.168.0.10?“) tauchen dort gar nicht auf. Ihr Broadcast bleibt in VLAN 20 — für den Switch sind das jetzt zwei getrennte Netze, die nichts voneinander mitbekommen.

:::tip Merksatz
Mit **VLANs** teilt man einen Switch in mehrere logisch getrennte Netze auf. Geräte in verschiedenen VLANs können sich nicht direkt erreichen — auch Broadcasts bleiben im eigenen VLAN. Jedes VLAN hat eine Nummer, die **VLAN-ID**.
:::

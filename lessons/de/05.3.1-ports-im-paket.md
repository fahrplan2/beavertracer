## Zwei Sorten Ports

**Ziel-Port — der Dienst:** Ein Server-Programm wartet an einem festen Port auf Verbindungen — man sagt, es **lauscht** dort. Für bekannte Dienste sind die Nummern weltweit festgelegt, die **Well-known Ports** (0 bis 1023). Ein Browser weiß deshalb ohne nachzufragen: Webserver lauschen an Port 80.

**Quell-Port — der Absender:** Den Port auf der Client-Seite wählt das Betriebssystem für jede neue Verbindung selbst aus einem hohen Bereich (in BeaverTracer ab 49152). An ihm erkennt der Client, zu welcher seiner Verbindungen eine Antwort gehört.

Eine Verbindung ist also eindeutig durch vier Angaben bestimmt: **IP-Adresse und Port auf beiden Seiten**. Das Paar aus IP-Adresse und Port nennt man **Socket**, z.B. `192.168.0.20:80`.

## Ein Blick auf den Server

Wechsle zurück in den :fa-play: **Ausführen**-Modus, öffne auf dem **Server** das :fa-terminal: **Terminal** und gib ein:

```
$ ss
```

`ss` zeigt alle Sockets des Rechners. Zeilen mit `LISTEN` sind Programme, die an einem Port lauschen. Zeilen mit `ESTABLISHED` sind bestehende Verbindungen — mit dem eigenen Socket (*Local Address:Port*) und dem Socket der Gegenseite (*Peer Address:Port*).

:::quiz multi
An welchen Ports lauscht der Server?
- [x] 80
- [x] 5000
- [ ] 49152
- [ ] 443
:::

:::quiz mc
Welche Verbindung zeigt `ss` als `ESTABLISHED`?
- [x] `192.168.0.20:5000` mit `192.168.0.10:49153` — die offene Verbindung des TCP-Clients
- [ ] `192.168.0.20:80` mit `192.168.0.10:49152` — die Verbindung des Browsers
- [ ] Beide
:::

:::note
Die Verbindung des Browsers ist schon wieder abgebaut — nach dem Laden der Seite wurde sie mit `FIN` beendet. `ss` zeigt sie noch kurz als `TIME-WAIT`: Der Server wartet eine Weile, ob noch verspätete Pakete dieser Verbindung eintreffen. Die Verbindung des TCP-Clients ist dagegen noch offen, weil du noch nicht auf **Trennen** geklickt hast.
:::

## Die wichtigsten Well-known Ports

| Port | Protokoll | Dienst |
|---|---|---|
| 22 | SSH | sichere Fernwartung (verschlüsselte Kommandozeile) |
| 25 | SMTP | E-Mails versenden |
| 53 | DNS | Namen in IP-Adressen übersetzen (meist über UDP) |
| 80 | HTTP | Webseiten |
| 110 | POP3 | E-Mails abholen |
| 143 | IMAP | E-Mails auf dem Server verwalten |
| 443 | HTTPS | verschlüsselte Webseiten |

:::tip Merksatz
**Ports** (0 bis 65535) halten die Verbindungen auf einem Rechner auseinander. Server-Dienste **lauschen** an festen **Well-known Ports** (z.B. HTTP 80, HTTPS 443), Clients bekommen für jede Verbindung einen freien hohen **Quell-Port**. Eine Verbindung ist eindeutig durch **IP-Adresse und Port beider Seiten** bestimmt.
:::

:::quiz match
22 -> SSH
25 -> SMTP
53 -> DNS
80 -> HTTP
110 -> POP3
143 -> IMAP
443 -> HTTPS
:::

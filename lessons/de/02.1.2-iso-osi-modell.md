# Das ISO/OSI-Referenzmodell

Das ISO/OSI-Modell unterteilt die Kommunikation zwischen zwei Geräten in sieben Schichten. Jede Schicht hat eine klar abgegrenzte Aufgabe und nutzt nur die Dienste der Schicht direkt darunter:

<table class="osi-table">
<thead>
<tr><th>Schicht</th><th>Name</th><th>Aufgabe</th><th>Beispielprotokolle</th></tr>
</thead>
<tbody>
<tr class="osi-l7"><td>7</td><td>Anwendung</td><td>Schnittstelle zur Anwendung</td><td>HTTP, DNS, SMTP</td></tr>
<tr class="osi-l6"><td>6</td><td>Darstellung</td><td>Datenformat, Verschlüsselung</td><td>TLS, JPEG, ASCII</td></tr>
<tr class="osi-l5"><td>5</td><td>Sitzung</td><td>Sitzungsverwaltung</td><td>RPC, NetBIOS</td></tr>
<tr class="osi-l4"><td>4</td><td>Transport</td><td>Ende-zu-Ende-Übertragung</td><td>TCP, UDP</td></tr>
<tr class="osi-l3"><td>3</td><td>Vermittlung</td><td>Wegewahl zwischen Netzen</td><td>IP, ICMP</td></tr>
<tr class="osi-l2"><td>2</td><td>Sicherung</td><td>Übertragung im lokalen Netz</td><td>Ethernet, ARP</td></tr>
<tr class="osi-l1"><td>1</td><td>Bitübertragung</td><td>Signale auf dem physischen Medium</td><td>Kupfer, Glasfaser, WLAN</td></tr>
</tbody>
</table>

Aus dem Experiment auf der letzten Seite kennst du bereits vier dieser Schichten: Ethernet (2), IPv4 (3), TCP (4) und HTTP (7).

:::note
Schicht 1 beschreibt die eigentliche Signalübertragung auf dem Kabel oder per Funk. BeaverTracer simuliert diese Ebene nicht — Kabel gelten immer als fehlerfrei verbunden, es gibt weder Signalprobleme noch Kollisionen. Im Tracer beginnt die Betrachtung deshalb praktisch bei Schicht 2.
:::

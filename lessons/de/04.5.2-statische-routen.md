# Statische Routen eintragen

:::sim
url=/sims/lesson-4.5.2.btsim
:::

Diesmal liegen zwischen Firma A und Firma B **zwei** Router. Sie sind über ein eigenes kleines Netz verbunden, das **Zwischennetz** `10.0.0.0/30`:

| Router | Schnittstelle | IP-Adresse | Netz |
|---|---|---|---|
| Router A | `eth0` | `192.168.0.1/24` | Firma A (Anna) |
| Router A | `eth1` | `10.0.0.1/30` | Zwischennetz |
| Router B | `eth0` | `10.0.0.2/30` | Zwischennetz |
| Router B | `eth1` | `172.16.0.1/24` | Firma B (Clara) |

:::note
Ein `/30`-Netz hat genau zwei nutzbare Adressen — perfekt für die Verbindung zweier Router (siehe Abschnitt 4.2.3).
:::

## Das Problem

Wechsle in den :fa-play: **Ausführen**-Modus und pinge von **Anna** aus Clara an (`ping 172.16.0.10`). Es kommt keine Antwort.

Schau dir die **Routingtabelle IPv4** von **Router A** an.

:::quiz mc
Warum kommt Annas Ping nicht bei Clara an?
- [ ] Anna hat kein Gateway eingetragen
- [x] Router A kennt das Netz `172.16.0.0/24` nicht — es ist nicht direkt an ihn angeschlossen, und es gibt keine Route dorthin
- [ ] Das Zwischennetz ist zu klein
:::

:::evaluate
Antwort prüfen
:::

## Die Route eintragen

Router A muss lernen: Pakete für `172.16.0.0/24` gehen an Router B (`10.0.0.2`), und zwar über `eth1`.

1. Öffne bei **Router A** den Reiter **Routingtabelle IPv4** und klicke auf **+ hinzufügen**.
2. Trage in die neue Zeile ein: **Ziel** `172.16.0.0`, **Netzmaske** `255.255.255.0`, **Nächster Hop** `10.0.0.2`, **Iface** `eth1`.
3. Speichere die Zeile mit dem Haken :fa-check:. In der Spalte **Quelle** steht jetzt **Statisch**.

Pinge Clara noch einmal an — jetzt kommt die Antwort.

:::note
Router B kennt den Weg zurück zu Firma A übrigens schon: In seiner Routing-Tabelle steht bereits eine statische Route für `192.168.0.0/24` über `10.0.0.1`. Warum dieser Rückweg genauso wichtig ist, siehst du auf der nächsten Seite.
:::

## Den Weg verfolgen: traceroute

Mit `traceroute` kannst du dir anzeigen lassen, über welche Router ein Paket läuft. Gib auf **Anna** ein:

```
$ traceroute 172.16.0.10
```

:::quiz short
Über wie viele Router läuft das Paket von Anna zu Clara?
= 2
= zwei
:::

:::quiz mc
Welche Adresse zeigt `traceroute` für Router B?
- [x] `10.0.0.2` — seine Adresse im Zwischennetz, über die das Paket hereinkommt
- [ ] `172.16.0.1` — seine Adresse in Firma B
- [ ] `192.168.0.1`
:::

:::evaluate
Antworten prüfen
:::

`traceroute` nutzt einen Trick mit der **Time to Live** aus Abschnitt 4.3.1: Es schickt zuerst ein Paket mit TTL 1. Der erste Router zieht 1 ab, kommt auf 0, verwirft das Paket und meldet das an den Absender zurück — damit kennt Anna den ersten Router. Dann TTL 2 für den zweiten Router, und so weiter, bis das Ziel antwortet.

:::tip Merksatz
Eine **statische Route** trägt der Administrator von Hand ein: Zielnetz, Netzmaske, nächster Hop und Schnittstelle. Mit **traceroute** lässt sich der Weg eines Pakets Router für Router verfolgen.
:::

# Bruk modellene

Plasser protokollene fra eksperimentet i starten av kapitlet i riktig OSI-lag:

:::quiz match
Ethernet -> Lag 2 — Linklag
IPv4 -> Lag 3 — Nettverkslag
TCP -> Lag 4 — Transportlag
HTTP -> Lag 7 — Applikasjonslag
:::

:::evaluate
Kontroller tilordning
:::

Og til slutt navnene på dataenhetene:

:::quiz match
Frame -> Lag 2 — Linklag
Pakke -> Lag 3 — Nettverkslag
Segment -> Lag 4 — Transportlag
:::

:::evaluate
Kontroller tilordning
:::

Nå har du verktøyene du trenger for å plassere protokoller riktig fremover. Fra og med neste kapittel går vi gjennom lagene ett for ett — vi begynner med lag 2 og spørsmålet om hvordan en switch egentlig vet hvor den skal sende en pakke videre.

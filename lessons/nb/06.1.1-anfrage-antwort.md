En nettside består altså ofte av mange filer: tekst, stilark, bilder. For hver av dem sender nettleseren en egen forespørsel.

## Slik ser en forespørsel ut

Klikk på pakken `GET / HTTP/1.1` i trace-en og åpne **Hypertext Transfer Protocol**. En HTTP-forespørsel er ren tekst:

```
GET / HTTP/1.1              ← Methode, Pfad, Version
Host: 192.168.0.20          ← Header: zusätzliche Angaben
…
                            ← Leerzeile: Ende der Anfrage
```

Svaret fra serveren er bygd opp på samme måte — med en statuslinje, headere, en tom linje og deretter selve filen:

```
HTTP/1.1 200 OK             ← Version, Statuscode, Text
Content-Type: text/html     ← Header: Art der Datei
Content-Length: 301         ← Header: Größe in Byte
                            ← Leerzeile
<!doctype html> …           ← die Datei selbst
```

:::seq
mode: text
Client-PC -> Server: GET / | HTTP-forespørsel
Server -> Client-PC: 200 OK | index.html
Client-PC -> Server: GET /style.css | HTTP-forespørsel
Server -> Client-PC: 200 OK | style.css
:::

## Metoder og statuskoder

**Metoden** sier hva klienten vil:

| Metode | Betydning |
|---|---|
| **GET** | hente en fil |
| **POST** | sende data til serveren, f.eks. et utfylt skjema |
| **HEAD** | hente bare headerne, uten filen |

**Statuskoden** sier hvordan det gikk. Det første sifferet forteller hva slags svar det er:

| Kode | Tekst | Betydning |
|---|---|---|
| **200** | OK | alt i orden |
| **301** | Moved Permanently | siden er flyttet permanent |
| **404** | Not Found | filen finnes ikke |
| **405** | Method Not Allowed | denne metoden er ikke tillatt her |
| **500** | Internal Server Error | feil på serveren |

`2xx` betyr suksess, `3xx` omdirigering, `4xx` en feil hos klienten (feil forespørsel), `5xx` en feil hos serveren.

:::tip Husk dette
**HTTP** fungerer etter **forespørsel-svar-prinsippet**: Klienten sender en **forespørsel** (metode som `GET`, sti, headere), og serveren svarer med en **statuskode** (f.eks. `200 OK`, `404 Not Found`), headere og filen. For hver fil på en nettside er det en egen forespørsel.
:::

:::

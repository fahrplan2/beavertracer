# Les e-post i sporingen

:::sim
url=/sims/lesson-6.3.btsim

Som HTTP er også SMTP en **tekstprotokoll**. Se på alt som går over linjen i klartekst.

## Eksperimentet

1. Send i :fa-play: **Kjør**-modus, som på forrige side, en e-post fra **Anna** til `ben@biber-mail.de`.
2. Åpne i :fa-magnifying-glass: **Sporing**-modus en trace for **Anna**. I kolonnen **Info** står SMTP-dialogen: Linjer med `C:` sendes av klienten, linjer med `S:` av serveren.

:::quiz short
Hvilken adresse står etter `MAIL FROM:`?
= anna@beaver-schule.de
= <anna@beaver-schule.de>
:::

:::quiz short
Og hvilken står etter `RCPT TO:`?
= ben@biber-mail.de
= <ben@biber-mail.de>
:::

:::quiz mc
Hvilken tallkode sender serveren når den godtar en kommando?
- [x] `250`
- [ ] `200`
- [ ] `404`
:::

:::evaluate
Kontroller svarene
:::

## Og passordet?

Før `MAIL FROM` logger Annas program seg på med `AUTH PLAIN` og en tegnstreng som `AGFubmEAZ2VoZWlt`. Det ser kryptert ut, men det er det ikke: Det er bare **Base64**, en koding som hvem som helst umiddelbart kan oversette tilbake — inni den ligger `anna` og passordet hennes `geheim`.

Hent nå posten hos **Ben** (**Hent**) og åpne en trace for **Ben**. Ved henting via IMAP står det enda tydeligere:

:::quiz short
Hvilket passord sender Bens e-postprogram i klartekst til serveren? (Se på linjen med `LOGIN`.)
= biber123
:::

:::evaluate
Kontroller svaret
:::

:::warning
Uten kryptering kan alle som avlytter trafikken lese **innhold, avsender, mottaker og passord**. Derfor bruker man i dag krypterte varianter (f.eks. SMTP med STARTTLS, IMAPS på port 993). Hvordan det fungerer, lærer du i kapittel 8.
:::

:::tip Husk dette
**SMTP**, **POP3** og **IMAP** er tekstprotokoller: Kommandoer som `MAIL FROM`, `RCPT TO`, `DATA` (SMTP) eller `LOGIN` (IMAP) og svarene er lesbare. Uten kryptering går også **passord** i klartekst (eller bare Base64-kodet) over linjen.
:::

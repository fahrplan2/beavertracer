# Observere TCP

:::goal
**Læringsmål:** Du finner i Tracer hvor TCP utfører de fire oppgavene til transportlaget, kan fremstille en TCP-forbindelse som sekvensdiagram og kan regne ut sekvensnummer og bekreftelsesnummer.
:::

:::sim
url=/sims/lesson-5.1.btsim
:::

**Transmission Control Protocol** (**TCP**) ligger bak nesten alt som må komme pålitelig frem på internett: nettsider, e-post, nedlastinger og fjernvedlikehold via SSH.

På de neste sidene observerer du én enkelt TCP-forbindelse fra start til slutt, og du leter selv etter hvor TCP gjør oppkobling, pålitelig overføring og nedkobling.

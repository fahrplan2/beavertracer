# HTTP for hånd

:::sim
url=/sims/lesson-6.1.btsim
:::

Hvis HTTP er ren tekst — kan man da også snakke med en webserver selv, helt uten nettleser? Ja: Med `telnet` setter du opp en TCP-forbindelse til en vilkårlig port og skriver teksten selv.

## Eksperimentet

1. Bytt til :fa-play: **Kjør**-modus og åpne :fa-terminal: **Terminal** på **Client-PC**.
2. Koble til port 80 på serveren:
   ```
   $ telnet 192.168.0.20 80
   ```
3. Skriv forespørselen linje for linje — og avslutt den med en **tom linje** (bare trykk **Enter** en gang til):
   ```
   GET /kontakt.html HTTP/1.1
   Host: 192.168.0.20

   ```

Serveren svarer med statuslinje, headere og kontaktsiden — som tekst, akkurat slik nettleseren også får den.

:::quiz mc
Hvordan vet serveren at forespørselen din er ferdig?
- [ ] Ved en spesiell kommando `END`
- [x] Ved den tomme linjen
- [ ] Etter en bestemt tid
:::

:::quiz short
Hvilken verdi står i svaret ved headeren `Content-Type`? (bare den første delen før `;`)
= text/html
:::

Kontroller svar
:::

## Framprovosere feil

Et mer praktisk verktøy er `curl`: Det sender forespørselen for deg. Med `-v` (*verbose*, utfyllende) viser det alt som går fram og tilbake — linjer med `>` har `curl` sendt, linjer med `<` kom fra serveren.

Prøv selv:

```
$ curl -v http://192.168.0.20/gibtsnicht.html
$ curl -X POST -d name=Anna http://192.168.0.20/
```

:::quiz short
Hvilken statuskode får du for `/gibtsnicht.html`?
= 404
:::

:::quiz short
Og hvilken får du for forespørselen med metoden `POST`?
= 405
:::

:::evaluate
Kontroller svar
:::

:::note
Webserveren i BeaverTracer kan bare levere filer — derfor tillater den bare `GET` og `HEAD`. Ekte webservere tar for eksempel imot skjemaer med `POST` og sender dataene videre til et program.
:::

:::tip Husk dette
Mange protokoller i applikasjonslaget er **tekstbaserte** — HTTP, men også SMTP, POP3 og IMAP. Derfor kan du snakke dem for hånd med `telnet` og lese dem med i Tracer. Det er praktisk ved feilsøking — men også et sikkerhetsproblem: Alle som tar opp trafikken, kan lese alt. Hvordan kryptering (HTTPS) hjelper, lærer du i kapittel 8.
:::

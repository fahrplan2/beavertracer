# Første egne regler

:::sim
url=/sims/lesson-9.btsim
:::

Nå er det din tur. Brannmuren slipper fortsatt alt gjennom. Sørg for at bare **nettsiden (80)** og **mottak av e-post (25)** på skoleserveren er tilgjengelige fra internett. **SSH (22)**, **POP3 (110)** og **IMAP (143)** skal ikke lenger være tilgjengelige fra internett.

## Legge inn regler

1. Klikk på **brannmuren**. Standardregelen forblir foreløpig satt til **Alle zulassen**.
2. Slett den eksisterende regelen (den tillater uansett alt), og opprett med **+ Regel hinzufügen** én regel for hver port som skal stenges:
    - **Richtung** A → B (fra internett)
    - **Protokoll** TCP
    - **Ziel-Port** f.eks. `22`
    - **Aktion** Verwerfen
3. Kontroller fra **Internet-PC-en** med `nmap 198.51.100.10` om bare de riktige portene er åpne.

:::task
title: Bare web og e-post utenfra?
Kontrollerer om skoleserveren bare er tilgjengelig fra internett på port 80 og 25 – og om lærer-PC-en fortsatt kan hente e-post og surfe på internett. Simuleringen må kjøre i Kjør-modus for dette.
check: tcpOpen(1, "198.51.100.10", 80)
check: tcpOpen(1, "198.51.100.10", 25)
check: tcpFails(1, "198.51.100.10", 22)
check: tcpFails(1, "198.51.100.10", 110)
check: tcpFails(1, "198.51.100.10", 143)
check: tcpOpen(8, "198.51.100.10", 110)
check: tcpOpen(8, "203.0.113.80", 80)
:::

:::quiz mc
Lærer-PC-en kan fortsatt hente e-post fra skoleserveren via POP3 (110). Hvorfor forstyrrer ikke brannmuren den?
- [ ] Fordi brannmuren gjenkjenner lærere
- [x] Fordi pakkene hans slett ikke passerer brannmuren – lærer-PC-en og skoleserveren er koblet til samme svitsj bak brannmuren
- [ ] Fordi POP3 er en sikker protokoll
:::

:::evaluate
Kontroller svar
:::

:::note
En brannmur beskytter bare trafikk som flyter **gjennom** den. Det som skjer inne i skolenettverket, ser den ikke. En infisert datamaskin i skolenettverket kan derfor likevel angripe skoleserveren – det handler avsnittet om DMZ om.
:::

:::tip Husk dette
For hver tjeneste som ikke skal være tilgjengelig utenfra, stenger en regel med **Richtung**, **Protokoll** og **Ziel-Port** tilgangen. Om reglene virker, kontrollerer man utenfra med en **portskanning**.
:::

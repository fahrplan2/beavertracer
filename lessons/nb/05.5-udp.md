# UDP: den store forenklingen

:::goal
**Læringsmål:** Du kan sammenligne UDP med TCP og begrunne hvilke applikasjoner UDP er det beste valget for.
:::

:::sim
url=/sims/lesson-5.5.btsim
:::

TCP gjør mye — oppkobling, bekreftelser, retransmisjon og riktig rekkefølge. Men det koster tid og ekstra pakker. Det andre viktige protokollen på transportlaget klarer seg uten nesten alt dette: **User Datagram Protocol** (**UDP**). Pakkene kalles **datagrammer**.

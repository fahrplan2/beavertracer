# HTTP og HTTPS sammenlignet

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Webserveren **www.beaver-schule.de** tilbyr skolens karakterportal både via HTTP og via HTTPS. Hva ser en som lytter på trafikken?

## Eksperimentet

1. Bytt til :fa-play: **Kjør**-modus og åpne først `http://www.beaver-schule.de/` på **Client-PC** i :fa-globe: **Nettleser**, deretter `https://www.beaver-schule.de/`.
2. Åpne en trace for **Client-PC** i :fa-magnifying-glass: **Sporing**-modus.
3. Finn først pakken `HTTP/1.1 200 OK` og klikk på den. Nederst i detaljene finner du innholdet på siden.

:::quiz mc
Hva kan en som lytter på trafikken se ved **HTTP**?
- [x] Hele nettsiden, også Annas karakterer
- [ ] Bare adressen til serveren
- [ ] Ingenting, fordi HTTP går over TCP
:::

:::quiz short
Hvilken karakter har Anna i matematikk?
= 2
:::

:::evaluate
Kontroller svarene
:::

Nå til HTTPS-delen. Finn `[SYN]`-pakken som klienten bruker til å starte den andre forbindelsen.

:::quiz short
Hvilken målport har HTTPS-forbindelsen (kolonnen **Info**, `… → ???`)?
= 443
:::

Skriv nå `tls` i filterfeltet øverst i tracen — da ser du bare TLS-pakkene.

:::quiz mc
Hva står i kolonnen **Info** for pakkene som inneholder nettsiden?
- [ ] `HTTP/1.1 200 OK`
- [x] `Application Data`
- [ ] `Encrypted HTML`
:::

:::quiz multi
Hva kan en som lytter på trafikken likevel se ved **HTTPS**?
- [x] IP-adressene til klient og server
- [x] At port 443 brukes, altså sannsynligvis HTTPS
- [x] Omtrent hvor mye data som overføres
- [ ] Hvilken side som ble åpnet og hva som står på den
:::

:::evaluate
Kontroller svarene
:::

:::note
Klikk på en **Application Data**-pakke: Nyttelasten er bare en rekke tilsynelatende tilfeldige byte. Traceren kan ikke dekryptere den – den kjenner øktnøkkelen like lite som en angriper gjør.
:::

:::tip Husk dette
Ved **HTTP** kan enhver som lytter på trafikken lese hele nettsiden. Ved **HTTPS** ser vedkommende bare **hvem som snakker med hvem** (IP-adresser, port 443) og **hvor mye** – innholdet ligger kryptert i **Application Data**-pakker.
:::

# POP3 eller IMAP?

:::sim
url=/sims/lesson-6.3.btsim
:::

Det finnes to protokoller for å hente e-post. I denne simuleringen bruker **Anna POP3** og **Ben IMAP**.

## Eksperimentet

1. Send en e-post fra **Ben** til `anna@beaver-schule.de` i :fa-play: **Kjør**-modus.
2. Klikk på **Hent** i appen **E-Mail** hos **Anna**.
3. Åpne traces for **Anna** og for **Ben**, og sammenlign kommandoene som brukes ved henting.

:::quiz match
USER / PASS -> POP3: pålogging med brukernavn og passord i to trinn
RETR -> POP3: laste ned en melding
LOGIN -> IMAP: pålogging med brukernavn og passord
SELECT INBOX -> IMAP: åpne en mappe på serveren
:::

:::evaluate
Kontroller sammenstillingen
:::

## Forskjellen

| | POP3 | IMAP |
|---|---|---|
| Port | 110 | 143 |
| Grunnidé | **Laste ned** e-post — deretter som regel slette den på serveren | E-post **blir liggende på serveren** og administreres der |
| Mapper, lest/ulest | bare på din egen enhet | på serveren — lik overalt |
| Flere enheter (mobil, bærbar PC) | upraktisk: hver enhet har ulik tilstand | ideelt: alle enheter ser den samme postboksen |

:::note
E-postprogrammet i BeaverTracer lar e-posten bli liggende på serveren også med POP3. Ekte programmer sletter den ofte etter nedlasting — eller lar den bare ligge en stund.
:::

:::quiz mc
Lena leser e-posten sin på mobilen, nettbrettet og skolens bærbare PC. Hva bør hun bruke?
- [ ] POP3, fordi det er enklere
- [x] IMAP, fordi alle enheter ser den samme postboksen på serveren
- [ ] SMTP, fordi det er laget for å hente e-post
:::

:::evaluate
Kontroller svar
:::

:::tip Husk dette
**POP3** laster ned e-post fra serveren til **én** enhet. **IMAP** administrerer postboksen **på serveren** — med mapper og lest-status for alle enheter samtidig. Begge brukes bare til å **hente** e-post; sending skjer alltid med **SMTP**.
:::

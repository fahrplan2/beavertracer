## Eksperimentet

1. Bytt til :fa-play: **Kjør**-modus, klikk på **Client-PC** og åpne :fa-globe: **Nettleser**.
2. Gå denne gangen til `http://www.beaver-schule.de/` — med navn i stedet for IP-adresse.
3. Bytt til :fa-magnifying-glass: **Sporing**-modus og åpne en trace for **Client-PC**.

Helt i begynnelsen — før oppkoblingen med `[SYN]` — står det to pakker med protokollen **DNS**.

:::

:::quiz short

:::

Først når Client-PC kjenner IP-adressen, setter den opp TCP-forbindelsen til webserveren — akkurat som i kapittel 5.

:::seq
mode: text
Client-PC -> DNS-Resolver: DNS-Anfrage | A www.beaver-schule.de?
DNS-Resolver -> Client-PC: DNS-Antwort | A 192.168.0.20
:::

## Hvordan kjenner PC-en DNS-serveren?

Åpne :fa-gear: **IP-innstillinger** på **Client-PC**: I feltet **DNS-Server** står `192.168.0.53` — maskinen **DNS-Resolver**. Dit sender PC-en alle navneforespørsler.

Du kan også spørre DNS-serveren direkte, uten nettleser. Åpne :fa-terminal: **Terminal** og skriv inn:

```
$ nslookup www.beaver-schule.de
```

`nslookup` viser først hvilken server den spurte, og deretter svaret. Spør til sammenligning etter et navn som ikke finnes, for eksempel `nslookup gibtsnicht.beaver-schule.de`.

:::quiz mc
Hva svarer DNS-serveren på det ukjente navnet?
- [ ] En tilfeldig IP-adresse
- [x] `NXDOMAIN` — dette navnet finnes ikke
- [ ] Ingenting i det hele tatt
:::

:::evaluate
Kontroller svaret
:::

:::tip Husk dette
**DNS** oversetter navn (for eksempel `www.beaver-schule.de`) til IP-adresser. Før en PC kan sette opp en forbindelse til et navn, spør den **DNS-serveren** som er registrert i IP-innstillingene — som oftest via **UDP, port 53**. Med `nslookup` kan du sende DNS-forespørsler manuelt.
:::

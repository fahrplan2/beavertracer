# Slik er DNS organisert

:::sim
url=/sims/lesson-6.2.btsim
:::

Ingen enkelt server kan kjenne alle navn i verden. DNS er derfor bygd opp **hierarkisk** — akkurat som navnene selv. Man leser dem fra høyre mot venstre:

```
www . beaver-schule . de . (Root)
 │          │         │      └─ Root-Server: kennen die Server aller Top-Level-Domains
 │          │         └─ Top-Level-Domain (TLD): der de-Server kennt alle .de-Domains
 │          └─ Domain: der Schul-DNS ist für beaver-schule.de zuständig
 └─ Rechnername innerhalb der Domain
```

Serveren som er ansvarlig for et domene og faktisk kjenner svaret, kalles **autoritativ**. Veien dit tar en **resolver** seg av for PC-en — her datamaskinen **DNS-Resolver**.

## Eksperimentet

1. Bytt til :fa-play: **Kjør**-modus og skriv inn følgende i :fa-terminal: **Terminal** på **Client-PC**:
   ```
   $ nslookup www.beaver-schule.de
   ```
2. Åpne en trace for **DNS-Resolver** i :fa-magnifying-glass: **Sporing**-modus.

Resolveren har sendt en hel rekke forespørsler for deg. Koble sammen hvem som ga hvilket svar:

:::quiz match
Root-Server (192.168.0.101) -> Henvisning: For .de er ns.nic.de ansvarlig
de-Server (192.168.0.102) -> Henvisning: For beaver-schule.de er ns.beaver-schule.de ansvarlig
Schul-DNS (192.168.0.103) -> Svar: www.beaver-schule.de har adressen 192.168.0.20
:::

:::quiz mc
Hvem spør resolveren først?
- [x] Root-serveren
- [ ] Schul-DNS
- [ ] Client-PC
:::

:::evaluate
Kontroller svar
:::

:::note
Underveis spør resolveren også etter adressene til serverne den ble henvist til (`A ns.nic.de`). Ekte DNS-servere sender vanligvis med disse adressene med en gang. Dessuten husker resolvere hvert svar en stund (**cache**) — neste forespørsel etter samme navn besvarer de umiddelbart selv. Hvor lenge, står i oppføringen som **TTL** (*Time to Live*) i sekunder.
:::

## De viktigste oppføringstypene

| Type | Betydning | Eksempel |
|---|---|---|
| **A** | navn → IPv4-adresse | `www.beaver-schule.de` → `192.168.0.20` |
| **AAAA** | navn → IPv6-adresse | `www.beaver-schule.de` → `2001:db8::20` |
| **CNAME** | navn → annet navn (alias) | `web.beaver-schule.de` → `www.beaver-schule.de` |
| **MX** | ansvarlig e-postserver for et domene | `beaver-schule.de` → `mail.beaver-schule.de` |
| **NS** | ansvarlig DNS-server for et domene | `beaver-schule.de` → `ns.beaver-schule.de` |

:::tip Husk dette
DNS er **hierarkisk**: **Root-servere** henviser til serverne for **toppdomenene** (Top-Level-Domains, f.eks. `.de`), og disse henviser videre til serverne for de enkelte **domenene**. Den ansvarlige **autoritative** serveren kjenner svaret. En **resolver** går denne veien for PC-en og husker svarene (**cache**). Viktige oppføringstyper: **A**, **AAAA**, **CNAME**, **MX**, **NS**.
:::

## Opprette en oppføring

Skolen ønsker at nettsiden sin også skal være tilgjengelig på `intranet.beaver-schule.de`.

1. Klikk på **Schul-DNS** i :fa-play: **Kjør**-modus og åpne appen **DNS-Server**.
2. Åpne fanen **A**. Klikk på **+** og skriv inn navnet `intranet.beaver-schule.de` og adressen `192.168.0.20` i den nye raden.
3. Test på Client-PC med `nslookup intranet.beaver-schule.de`.

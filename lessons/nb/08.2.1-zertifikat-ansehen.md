# Se på et sertifikat

:::sim
url=/sims/lesson-8.2.1.btsim
:::

På arbeidsområdet ser du **Client-PC**, en **DNS-Server** og webserveren til skolen, `www.beaver-schule.de`. Webserveren tilbyr sidene sine også via **HTTPS**.

## Låsen i nettleseren

1. Bytt til :fa-play: **Kjør**-modus, klikk på **Client-PC** og åpne :fa-globe: **Nettleser**.
2. Åpne `https://www.beaver-schule.de/` — legg merke til **https**.
3. Til venstre for adressen vises en **lås**. Klikk på den.

:::quiz short
Hvilket navn ble sertifikatet utstedt for (emne uten `CN=`)?
= www.beaver-schule.de
:::

:::quiz short
Hvem har utstedt sertifikatet (utsteder uten `CN=`)?
= Biber Root CA
:::

:::evaluate
Kontroller svarene
:::

## Hvorfor stoler Client-PC på sertifikatet?

Åpne :fa-shield-halved: **Zertifikatverwaltung** på **Client-PC** og bytt til fanen **Vertrauenswürdige CAs**.

:::quiz mc
Hva finner du der?
- [x] Sertifikatet til **Biber Root CA**
- [ ] Sertifikatet til `www.beaver-schule.de`
- [ ] Ingen oppføringer
:::

:::quiz mc
Hvordan ser man at Biber Root CA er en rot-CA?
- [x] Den er **selvsignert**: emne og utsteder er like
- [ ] Navnet slutter på «CA»
- [ ] Den har ingen offentlig nøkkel
:::

:::quiz mc
Står det «Ja» eller «Nei» under **Privater Schlüssel** på Client-PC?
- [ ] Ja — klienten trenger den private nøkkelen til CA-en for å kontrollere signaturer
- [x] Nei — for å kontrollere holder den offentlige nøkkelen; den private nøkkelen har bare CA-en
:::

:::evaluate
Kontroller svarene
:::

## Motparten: webserveren

Åpne nå :fa-shield-halved: **Zertifikatverwaltung** på webserveren **www.beaver-schule.de** (fanen **Meine Zertifikate**) og se på sertifikatet til serveren.

:::quiz multi
Hva stemmer for sertifikatet på webserveren?
- [x] Under **Privater Schlüssel** står det «Ja» — serveren trenger den for oppkoblingen
- [x] **Kjeden** er `www.beaver-schule.de ← Biber Root CA`
- [x] **Fingeravtrykket** er det samme som i lås-vinduet i nettleseren
- [ ] Det er selvsignert
:::

:::evaluate
Kontroller svarene
:::

:::note
**Fingeravtrykket** er en hashverdi over sertifikatet. Med den kan man raskt sammenligne to sertifikater — uten å kontrollere alle feltene enkeltvis.
:::

:::tip Husk dette
**Webserveren** har sertifikatet sitt **med privat nøkkel**. **Klienten** kjenner bare **sertifikatet til rot-CA-en** (uten privat nøkkel) — det er nok til å kontrollere signaturen på serversertifikatet. Når man klikker på **låsen** i nettleseren, ser man emne, utsteder, fingeravtrykk og gyldighet.
:::

# 疑難排解：服務沒有回應

:::sim
url=/sims/lesson-5.3.2.btsim
:::

更新之後，學校回報：「回顯服務拒絕所有連線，網頁也無法再載入。」依照規劃，**網頁伺服器**應該在連接埠 `80` 上監聽，**回顯服務**（TCP 回顯伺服器）應該在連接埠 `5000` 上監聽。找出錯誤並修正它們。

<details>
<summary>提示 1：伺服器如何回應？</summary>

嘗試用**簡單 TCP 用戶端**連線到 `192.168.0.20`、連接埠 `5000`，並為 Client-PC 開啟一個追蹤。伺服器用什麼回應你的 `[SYN]`？
</details>

<details>
<summary>提示 2：哪些連接埠是開啟的？</summary>

在 Client-PC 的終端機中輸入 `nmap -p 80,5000 192.168.0.20`。`nmap` 會依序探測這些連接埠，並顯示哪些是開啟的。在伺服器上使用 `ss`，你可以看到該處實際上有哪些連接埠正有程式在監聽。
</details>

<details>
<summary>提示 3：要在哪裡設定？</summary>

在 **Server** 上開啟 **TCP 回顯伺服器**和 **HTTP 伺服器**這兩個應用程式。服務有在執行嗎？它使用的是哪個連接埠？
</details>

:::task
title: 服務可以連線嗎？
檢查 Client-PC 是否能連到連接埠 5000 的回顯服務以及連接埠 80 的網頁伺服器。為此，模擬必須處於執行模式。
check: tcpOpen(1, 2, 5000)
check: tcpOpen(1, 2, 80)
:::

## 發生了什麼事？

:::quiz multi
下列哪些說法是正確的？
- [x] 對於傳到連接埠 5000 的 `[SYN]`，伺服器以 `[RST, ACK]` 回應
- [x] 回顯服務監聽的是連接埠 5050，而不是連接埠 5000
- [x] 網頁伺服器根本沒有啟動
- [ ] Client-PC 與 Server 之間的網路線損壞了
:::

:::evaluate
檢查答案
:::

:::tip 重點整理
如果對 `SYN` 的回應是 **`RST`**，表示該連接埠上**沒有任何程式**在監聽：電腦是可以連到的，但服務不行。常見原因：服務**沒有啟動**，或是監聽在**其他連接埠**。在伺服器上用 `ss` 查看，就能知道哪些連接埠實際上是開啟的。
:::

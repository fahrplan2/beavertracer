# 新增靜態路由

:::sim
url=/sims/lesson-4.5.2.btsim
:::

這次在 Firma A 和 Firma B 之間有**兩台**路由器。它們透過一個專屬的小型網路相連，也就是**中間網路** `10.0.0.0/30`：

| 路由器 | 介面 | IP 位址 | 網路 |
|---|---|---|---|
| Router A | `eth0` | `192.168.0.1/24` | Firma A (Anna) |
| Router A | `eth1` | `10.0.0.1/30` | Zwischennetz |
| Router B | `eth0` | `10.0.0.2/30` | Zwischennetz |
| Router B | `eth1` | `172.16.0.1/24` | Firma B (Clara) |

:::note
`/30` 網路正好有兩個可用位址——非常適合用來連接兩台路由器（參見 4.2.3 節）。
:::

## 問題

切換到 :fa-play: **執行**模式，從 **Anna** ping Clara（`ping 172.16.0.10`）。Clara 沒有回應——取而代之的是 Router A（`192.168.0.1`）回報「目的網路無法到達」。

查看 **Router A** 的**路由表 IPv4**。

:::quiz mc
為什麼 Anna 的 ping 無法到達 Clara？
- [ ] Anna 沒有設定閘道
- [x] Router A 不認識 `172.16.0.0/24` 這個網路——它沒有直接連接到該網路，也沒有通往該網路的路由
- [ ] 中間網路太小
:::

:::evaluate
檢查答案
:::

## 新增路由

Router A 必須學會：目的地為 `172.16.0.0/24` 的封包要交給 Router B（`10.0.0.2`），並且經由 `eth1` 傳送。

1. 在 **Router A** 開啟**路由表 IPv4**索引標籤，然後點選 **+ hinzufügen**。
2. 在新的一列中填入：**Ziel** `172.16.0.0`、**子網路遮罩** `255.255.255.0`、**下一跳** `10.0.0.2`、**Iface** `eth1`。
3. 用勾號 :fa-check: 保存這一列。在 **Quelle** 欄中現在會顯示**靜態**。

再 ping 一次 Clara——這次會收到回應了。

:::note
順帶一提，Router B 已經知道回到 Firma A 的路：它的路由表中已經有一條通往 `192.168.0.0/24`、經由 `10.0.0.1` 的靜態路由。為什麼這條回程路徑同樣重要，你會在下一頁看到。
:::

## 追蹤路徑：traceroute

使用 `traceroute` 可以顯示封包經過哪些路由器。在 **Anna** 上輸入：

```
$ traceroute 172.16.0.10
```

:::quiz short
從 Anna 到 Clara 的封包會經過幾台路由器？
= 2
= 兩台
= 兩
:::

:::quiz mc
`traceroute` 為 Router B 顯示哪個位址？
- [x] `10.0.0.2`——它在中間網路中的位址，封包由此進入
- [ ] `172.16.0.1`——它在 Firma B 中的位址
- [ ] `192.168.0.1`
:::

:::evaluate
檢查答案
:::

`traceroute` 利用了 4.3.1 節提到的**存活時間（Time to Live）**這個技巧：它會先傳送一個 TTL 為 1 的封包。第一台路由器將 TTL 減 1 後變成 0，便丟棄該封包，並向發送端回報這件事——這樣 Anna 就知道第一台路由器了。接著用 TTL 2 找出第二台路由器，依此類推，直到目的地回應為止。

:::tip 重點整理
**靜態路由**由管理員手動新增：目的網路、子網路遮罩、下一跳和介面。利用 **traceroute** 可以逐台路由器地追蹤封包的路徑。
:::

# DNS 的組織方式

:::sim
url=/sims/lesson-6.2.btsim
:::

沒有任何一台伺服器能知道全世界所有的名稱。因此 DNS 採用**階層式**架構——就像名稱本身一樣。名稱要從右往左讀：

```
www . beaver-schule . de . (Root)
 │          │         │      └─ Root-Server: kennen die Server aller Top-Level-Domains
 │          │         └─ Top-Level-Domain (TLD): der de-Server kennt alle .de-Domains
 │          └─ Domain: der Schul-DNS ist für beaver-schule.de zuständig
 └─ Rechnername innerhalb der Domain
```

負責某個網域並且真正知道答案的伺服器稱為**權威伺服器**（autoritativ）。替 PC 走完這段路的是**解析器**（Resolver）——在這裡就是電腦 **DNS-Resolver**。

## 實驗

1. 切換到 :fa-play: **執行**模式，在 **Client-PC** 的 :fa-terminal: **終端機**中輸入：
   ```
   $ nslookup www.beaver-schule.de
   ```
2. 在 :fa-magnifying-glass: **追蹤**模式中，為 **DNS-Resolver** 開啟一個追蹤。

解析器已經替你發出了一連串查詢。請配對出誰給了哪個回應：

:::quiz match
Root-Server (192.168.0.101) -> 轉介：.de 由 ns.nic.de 負責
de-Server (192.168.0.102) -> 轉介：beaver-schule.de 由 ns.beaver-schule.de 負責
Schul-DNS (192.168.0.103) -> 回應：www.beaver-schule.de 的位址是 192.168.0.20
:::

:::quiz mc
解析器最先詢問誰？
- [x] Root 伺服器
- [ ] Schul-DNS
- [ ] Client-PC
:::

:::evaluate
檢查答案
:::

:::note
在過程中，解析器也會查詢它被轉介到的那些伺服器的位址（`A ns.nic.de`）。真實的 DNS 伺服器通常會直接一併附上這些位址。此外，解析器會將每個回應記住一段時間（**快取**）——對於同一名稱的下一次查詢，它們會立刻自己回答。記住多久，會以 **TTL**（*Time to Live*，存活時間）的形式以秒為單位寫在記錄中。
:::

## 最重要的記錄類型

| 類型 | 意義 | 範例 |
|---|---|---|
| **A** | 名稱 → IPv4 位址 | `www.beaver-schule.de` → `192.168.0.20` |
| **AAAA** | 名稱 → IPv6 位址 | `www.beaver-schule.de` → `2001:db8::20` |
| **CNAME** | 名稱 → 另一個名稱（別名） | `web.beaver-schule.de` → `www.beaver-schule.de` |
| **MX** | 某網域負責的郵件伺服器 | `beaver-schule.de` → `mail.beaver-schule.de` |
| **NS** | 某網域負責的 DNS 伺服器 | `beaver-schule.de` → `ns.beaver-schule.de` |

:::tip 重點整理
DNS 是**階層式**的：**Root 伺服器**指向**頂級網域**（Top-Level-Domain，例如 `.de`）的伺服器，頂級網域伺服器再指向各個**網域**的伺服器。負責的**權威**伺服器知道答案。**解析器**會替 PC 走完這段路，並記住這些回應（**快取**）。重要的記錄類型：**A**、**AAAA**、**CNAME**、**MX**、**NS**。
:::

## 建立一筆記錄

學校希望它的網站也能透過 `intranet.beaver-schule.de` 存取。

1. 在 :fa-play: **執行**模式中，點選 **Schul-DNS**，並開啟 **DNS-Server** 應用程式。
2. 開啟 **A** 索引標籤。點選 **+**，並在新的一列中填入名稱 `intranet.beaver-schule.de` 和位址 `192.168.0.20`。
3. 在 Client-PC 上用 `nslookup intranet.beaver-schule.de` 進行測試。

:::task
title: 已填入新名稱了嗎？
檢查 Client-PC 是否能將名稱 intranet.beaver-schule.de 解析為網頁伺服器的位址。模擬必須在執行模式中運行才能檢查。
check: resolves(2, "intranet.beaver-schule.de", "192.168.0.20")
:::

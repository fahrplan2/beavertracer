# TCP/IP 參考模型

ISO/OSI 模型非常詳細,但純粹是從理論出發而產生的。在實務上——包括在網際網路中——真正普及的是只有四層、較為精簡的 **TCP/IP 模型**。它把數個 OSI 層合併為一層:

| TCP/IP 層 | 對應的 OSI 層 | 範例協定 |
|---|---|---|
| 應用 | 5、6、7(會議、表示、應用) | HTTP, DNS, SMTP |
| 傳輸 | 4(傳輸) | TCP, UDP |
| 網際網路 | 3(網路) | IP, ICMP |
| 網路存取 | 1、2(實體、資料連結) | Ethernet, WLAN |

ARP 位於網路存取層與網際網路層的交界處(OSI 第 2/3 層,參見最後一頁的邊界案例)。

會議層、表示層與應用層的劃分在實務上很少能清楚區分——大多數應用層協定(例如 HTTP)都自行完成這一切。TCP/IP 模型考量到這一點,因此把這三層合併為單一一層。

:::note
當你在接下來的章節讀到「第 2 層」、「第 3 層」或「第 4 層」時,指的一律是 ISO/OSI 模型的編號——在本課程中,這仍然是共同的參考基準,即使 BeaverTracer 和實務上往往更常以 TCP/IP 的分類來思考。
:::

# 讓平板連上 WLAN

:::sim
url=/sims/lesson-3.3.1.btsim
:::

交換器上連接著 **Schul-PC**（`192.168.0.10`）和一個**無線接取點**。平板 **Anna**（`192.168.0.30`）要連上學校的 WLAN。

## 找到 WLAN

切換到 :fa-play: **執行**模式，然後點選**無線接取點**。這裡會顯示它的 WLAN 名稱，也就是 **SSID**：`Schule`。

無線接取點的運作方式像一座橋：透過無線電傳到它這裡的資料，它會經由網路線轉送給交換器，反過來也一樣。這樣 Anna 和 Schul-PC 就位於同一個區域網路中。

## 連接平板

1. 點選 **Anna**，開啟 :fa-gear: **IP 設定**，然後切換到 **WiFi** 索引標籤。
2. 在 **SSID** 欄位輸入 WLAN 的名稱：`Schule`，然後點選**套用**。
3. 在 Anna 上開啟 :fa-terminal: **終端機**，並對 Schul-PC 執行 ping：
   ```
   $ ping 192.168.0.10
   ```

執行 ping 時請留意工作區：無線電波會從 Anna 和無線接取點向四周擴散。

:::tip 重點整理
**WLAN** 是透過無線電傳輸的區域網路。**無線接取點**把 WLAN 與有線網路連接起來。每個 WLAN 都有一個名稱，稱為 **SSID**（*Service Set Identifier*）——裝置必須知道正確的 SSID，才能連線。
:::

:::quiz mc
如果你在 Anna 上把 SSID 填成 `schule`（小寫），會發生什麼事？
- [ ] 什麼都不會發生——大小寫沒有影響
- [x] Anna 不再連線——SSID 必須完全一致
- [ ] Anna 會連上另一個 WLAN
:::

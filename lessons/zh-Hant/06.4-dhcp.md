# DHCP：自動加入網路

:::goal
**學習目標：** 你能說明裝置如何透過 DHCP 自動取得 IP 設定，能設定 DHCP 伺服器，並能辨識與排除常見的 DHCP 錯誤（例如 169.254 開頭的位址）。
:::

:::sim
url=/sims/lesson-6.4.btsim
:::

到目前為止，你都是手動為每個裝置輸入 IP 位址、子網路遮罩、閘道和 DNS 伺服器。在擁有數百台筆記型電腦、平板和手機的學校裡，這根本不可能完成——而且每一個輸入錯誤都會在網路中造成問題。

這項工作由**動態主機設定協定**（**DHCP**，Dynamic Host Configuration Protocol）來負責：**DHCP 伺服器**會自動把這些設定分發給每一個加入網路的裝置。

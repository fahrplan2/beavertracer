# 專案：一間擁有四個據點的公司

:::sim
url=/sims/lesson-4.5.4.btsim
:::

一間公司的總部位於 **Hanau**，分公司位於 **Kassel**、**Gießen** 和 **Darmstadt**。每個據點都有自己的網路和自己的路由器。所有路由器都透過專線連接到一個**中央網路**，公司的主伺服器也放在這個網路中。

## 位址規劃

管理員按照以下方案分配了位址——這些位址已經填入模擬中：

| 網路 | 位址範圍 |
|---|---|
| 中央網路 | `10.19.0.0/24` |
| Hanau | `10.19.1.0/24` |
| Kassel | `10.19.2.0/24` |
| Gießen | `10.19.3.0/24` |
| Darmstadt | `10.19.4.0/24` |

| 裝置 | 在中央網路中 | 在據點網路中 |
|---|---|---|
| Server | `10.19.0.10` | — |
| Router Hanau | `10.19.0.1` | `10.19.1.1` |
| Router Kassel | `10.19.0.2` | `10.19.2.1` |
| Router Gießen | `10.19.0.3` | `10.19.3.1` |
| Router Darmstadt | `10.19.0.4` | `10.19.4.1` |
| 據點的 PC | — | 各為 `.2`（例如 PC Kassel `10.19.2.2`） |

所有路由器的 `eth0` 都連向中央網路，`eth1` 則連向據點網路。

## 你的任務

為了讓公司所有電腦能互相連通，並能連到伺服器，還缺少兩件事：

1. **閘道：** 為四台 PC 和伺服器都設定閘道。PC 使用自己據點的路由器；伺服器使用 **Router Hanau**。
2. **路由表：** 為四台路由器補上尚缺的路由。每台路由器都必須認識**其他三個**據點的網路。

過程中請隨時用 `ping` 和 `traceroute` 測試。

<details>
<summary>提示：這裡的路由長什麼樣子？</summary>

以 **Router Kassel** 為例：要送往 Gießen（`10.19.3.0/24`）的封包，會送到 Router Gießen 在中央網路中的介面——也就是**下一跳** `10.19.0.3`，**Iface** `eth0`。照這個模式，每台路由器需要三條路由。
</details>

:::task
title: 公司網路完成了嗎？
檢查所有據點是否都能連到伺服器，以及各據點之間是否彼此連通。為此，模擬必須在執行模式下運行。
check: pingOk(11, 19)
check: pingOk(13, 19)
check: pingOk(15, 19)
check: pingOk(17, 19)
check: pingOk(13, 15)
check: pingOk(15, 17)
check: pingOk(17, 11)
check: pingOk(11, 13)
:::

:::evaluate
檢查答案
:::

你會發現：據點越多，手動設定就越費工——而且每一條被遺漏的路由都是一個錯誤。如何將這件事自動化，你可以在下一頁讀到。

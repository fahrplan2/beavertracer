HTTP、DNS、電子郵件和 DHCP 是你在日常生活中經常接觸到的協定。除此之外還有許多其他協定——以下簡要介紹其中最重要的幾個。其中有些你可以直接在 BeaverTracer 中親自試試：它們都標有 :fa-flask:。

| 協定 | 連接埠 | 傳輸 | 用途 |
|---|---|---|---|
| **SSH** | 22 | TCP | 加密的遠端維護 |
| **Telnet** :fa-flask: | 23 | TCP | 未加密的遠端維護（已過時） |
| **FTP** / **SFTP** | 21 / 22 | TCP | 傳輸檔案 |
| **NTP** :fa-flask: | 123 | UDP | 校準時間 |
| **IRC** :fa-flask: | 6667 | TCP | 文字聊天 |
| **SIP** / **RTP** :fa-flask: | 5060 / 不固定 | UDP | 網路電話 |
| **SNMP** | 161 | UDP | 監控網路設備 |
| **SMB** | 445 | TCP | 網路中的檔案共享 |
| **MQTT** | 1883 | TCP | 物聯網中的訊息傳遞 |
| **QUIC** / **HTTP/3** | 443 | UDP | 更快速、加密的網頁 |

## SSH 與 Telnet

透過 **SSH**（*Secure Shell*），你可以用命令列控制另一台電腦，就像坐在它面前一樣——管理員就是這樣維護伺服器和路由器的。所有內容，包括密碼，都是加密傳輸的。它的前身 **Telnet** 做的是同樣的事，但以明文進行，因此如今被視為不安全；不過作為測試文字協定的工具，它仍然很有用，就像你在 6.1.2 節中看到的那樣。

## FTP 與 SFTP

**檔案傳輸協定**（**FTP**，*File Transfer Protocol*）是最古老的網際網路協定之一，用於上傳和下載檔案。它以未加密的方式傳輸密碼和資料，因此使用得越來越少。它通常被 **SFTP** 取代，後者透過 SSH 連線來傳輸檔案。

## NTP

**網路時間協定**（**NTP**，*Network Time Protocol*）會讓電腦的時鐘與時間伺服器校準——精確到毫秒。這比聽起來更重要：憑證、日誌檔案和登入驗證程序，只有在所有設備的時間一致時才能正常運作。在 BeaverTracer 中，為此提供了 **NTP-Server** 和 **Uhrzeit** 這兩個應用程式，以及 `ntpdate` 指令。

## IRC

**網際網路中繼聊天**（**IRC**，*Internet Relay Chat*）是 1988 年問世的聊天協定：你連線到一台伺服器，加入像 `#schule` 這樣的頻道，並向頻道內的所有人傳送文字訊息。和 HTTP 與 SMTP 一樣，IRC 是純文字協定——在追蹤中你可以讀到每一則訊息。現今的即時通訊軟體遵循相同的基本原理，只不過是加密的。在 BeaverTracer 中：應用程式 **IRC-Server** 和 **IRC**。

## SIP 與 RTP

在**網路電話**（*Voice over IP*）中，有兩個協定協同運作：**SIP**（*Session Initiation Protocol*）負責建立和結束通話——它會讓對方的電話響起。語音本身則以許多小的 **RTP** 封包透過 UDP 傳送，因為在通話中每一毫秒都很重要（參見 5.5.2 節）。在 BeaverTracer 中：應用程式 **SIP-Server** 和 **Softphone**。

## SNMP

透過**簡單網路管理協定**（**SNMP**，*Simple Network Management Protocol*），監控程式可以查詢路由器、交換器和印表機：某個連接埠的負載有多高？某台設備是否故障？碳粉是否用完了？管理員就是這樣掌握即使是大型網路的狀況。

## SMB

**伺服器訊息區塊**協定（**SMB**，*Server Message Block*）是你在 Windows 網路中熟悉的網路磁碟機和共享資料夾背後的技術——例如學校的交換磁碟機。網路中的印表機也經常透過 SMB 來存取。

## MQTT

**MQTT** 是一種為**物聯網**設計的非常輕量的協定：感測器、智慧恆溫器或工廠中的機器把它們的測量值傳送給一個中央中介者（*Broker*），而每個對這些資料感興趣的程式都可以從那裡取得。它是為運算能力低的設備和不穩定的連線所設計的。

## QUIC 與 HTTP/3

**QUIC** 是一種較新的傳輸協定，由 Google 開發，如今許多大型網站都在使用。它建立在 **UDP** 之上，並自身就具備可靠性與加密功能——因此連線建立得比使用 TCP 和 TLS 更快。**HTTP/3** 是在 QUIC 上運行的 HTTP 版本。

:::quiz match
SSH -> 透過命令列以加密方式控制另一台電腦
NTP -> 與時間伺服器校準時間
SIP -> 透過網際網路建立電話通話
SNMP -> 監控路由器、交換器和印表機
MQTT -> 在物聯網中分發感測器的測量值
:::

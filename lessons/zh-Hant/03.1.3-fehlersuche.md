# 交換器網路的疑難排解

:::sim
url=/sims/lesson-3.1.3.btsim
:::

自從 **David** 加入網路後，就開始出現問題：沒有人連得到 Clara，而且 Ben 也有些不對勁。身為網路專家，你要把這些問題解決。

## 網路拓樸圖

網路*應該*是這樣的：

| 裝置 | IP 位址 | 交換器連接埠 |
|---|---|---|
| Anna | `192.168.0.10/24` | 1 |
| Ben | `192.168.0.11/24` | 2 |
| Clara | `192.168.0.12/24` | 3 |
| David | `192.168.0.13/24` | 4 |

把拓樸圖與模擬比較一下：有哪裡不一樣？請修正你找到的所有錯誤。

<details>
<summary>提示 1：我該從哪裡開始？</summary>

先看看網路線：每台電腦都接在正確的連接埠上嗎？接著檢查每台電腦的 IP 設定。
</details>

<details>
<summary>提示 2：Ben 明明有回應 ping …？</summary>

從 Anna 對 Ben 執行 ping（`ping 192.168.0.11`），並為 Anna 開啟一個追蹤。仔細看看 ARP 回應：有幾個回應？分別帶有哪些 MAC 位址？
</details>

:::task
title: 網路修好了嗎？
檢查所有裝置是否都使用網路拓樸圖中的位址，並且可以互相連通。為此，模擬必須在執行模式下運作。
check: ip(3, "192.168.0.10/32")
check: ip(5, "192.168.0.11/32")
check: ip(7, "192.168.0.12/32")
check: ip(11, "192.168.0.13/32")
check: pingOk(3, 7)
check: pingOk(3, 11)
check: pingOk(5, 7)
:::

## 剛才發生了什麼事？

:::quiz mc
在追蹤中，你如何看出兩個裝置使用相同的 IP 位址？
- [ ] ping 一律失敗
- [x] 一個 ARP 請求收到兩個帶有不同 MAC 位址的回應
- [ ] 交換器顯示錯誤訊息
:::

:::evaluate
檢查答案
:::

:::tip 重點整理
**疑難排解**時，你要把**應有狀態**（網路拓樸圖）與**實際狀態**（網路線、設定、追蹤）加以比較。請注意：ping 成功並不代表一切都正確——如果 IP 位址重複，也許只是錯誤的裝置在回應而已。
:::

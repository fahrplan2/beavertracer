# 將多台 PC 連接到一台交換器

:::sim
url=/sims/lesson-3.1.1.btsim
:::

工作區上有一台交換器和三台 PC：**Anna**、**Ben** 和 **Clara**。它們的 IP 位址已經設定好了（`192.168.0.10`、`.11` 和 `.12`），只缺少網路線。

## 接線

1. 切換到 :fa-pencil: **編輯**模式，並選擇 :fa-link: **Verbindung** 工具。
2. 點擊 **Anna**，再點擊 **Switch**。這時會出現交換器的連接埠選單（1 到 8），請選擇 **1**。
3. 再次選擇 :fa-link:，將 **Ben** 連接到連接埠 **2**，將 **Clara** 連接到連接埠 **3**。

現在每條網路線上都會看到一個小數字：表示它插在交換器的哪個連接埠上。

:::tip 重點整理
**交換器**（Switch）是一種具有許多接口的集線設備，這些接口稱為**連接埠**（**Port**）。所有連接在同一台交換器上的裝置，共同組成一個**區域網路**（英文 *Local Area Network*，**LAN**）。
:::

## 測試

切換到 :fa-play: **執行**模式，在 **Anna** 上開啟 :fa-terminal: **終端機**，然後 ping Clara：

```
$ ping 192.168.0.12
```

:::task
title: 三台都連上了嗎？
檢查三台 PC 是否都能互相連通。為此，模擬必須在執行模式下運行。
check: pingOk(3, 5)
check: pingOk(3, 7)
check: pingOk(5, 7)
:::

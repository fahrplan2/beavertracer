# 安全性：加密與憑證

:::goal
**學習目標：** 你能說明機密性、完整性與真實性這三個資安目標，區分對稱式加密與非對稱式加密，了解雜湊值與數位簽章的定位，讀懂並自行簽發憑證，設定 HTTPS，並解讀常見的憑證警告。
:::

在前面幾章中，你在 Tracer 裡幾乎可以讀到所有內容：

- **第 3.3.2 章：** 在 WLAN 中，範圍內的每個裝置都會收到所有無線電封包。
- **第 6.1.2 章：** 使用 HTTP 時，請求與網頁都以明文形式存在於封包中。
- **第 6.3.2 章：** 使用 SMTP 和 POP3 時，使用者名稱與密碼幾乎以明文在線路上傳輸——`AUTH PLAIN` 只是 Base64。

任何人只要在線路上或同一個 WLAN 中竊聽，就能看到密碼、成績、訊息和銀行資料。而且他還能做更多事：**竄改**封包，或**冒充**別人。

## 三個資安目標

密碼學可以幫助我們防範這些威脅。一般區分三個**資安目標**：

| 資安目標 | 問題 | 攻擊範例 |
|---|---|---|
| **機密性** | 只有正確的接收端才能讀取資料嗎？ | 有人在 WLAN 中竊取你的密碼。 |
| **完整性** | 資料抵達時沒有被更動嗎？ | 有人修改匯款單中的金額。 |
| **真實性** | 資料真的來自所聲稱的發送端嗎？ | 偽造的銀行網站要求你輸入 PIN。 |

在本章中，你會認識能達成這三個目標的工具——以及它們如何在 **HTTPS**（瀏覽器中的鎖頭圖示）中協同運作。

:::quiz match
有人在 WLAN 中竊取你的密碼 -> 機密性
有人在傳輸途中修改匯款金額 -> 完整性
偽造的網站假冒成你的銀行 -> 真實性
:::

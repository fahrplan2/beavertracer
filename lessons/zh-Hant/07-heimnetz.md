# 家用網路：路由器與 NAT

:::goal

在家裡，網路中很快就會有十個或更多的裝置：手機、筆電、電視、遊戲主機、喇叭。它們全都會取得像 `192.168.178.20` 這樣的位址——來自一個**私有**範圍，這個範圍在網際網路上根本不會被轉送（第 4.2.2 章）。儘管如此，這些裝置每一台都能連上網際網路。

這一切要歸功於一個不起眼的小盒子：**家用路由器**。在工作區的左側，你會看到一個家用網路，裡面有一台 PC 和一台平板；右側是「網際網路」——包含某個網路服務供應商的路由器、一台 DNS 伺服器，以及網頁伺服器 `www.beispiel.de`。

:::note
本章中的公用位址（`203.0.113.…`、`198.51.100.…`、`192.0.2.…`）是專門保留給範例與教材使用的——就像 IPv6 中的 `2001:db8::` 一樣。
:::

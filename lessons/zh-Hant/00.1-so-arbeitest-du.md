# 如何使用本課程

本課程直接在 BeaverTracer 中進行：左側是你建構和觀察網路的地方，右側的**課程面板**則是相應的操作說明。

## 翻頁

使用**上一頁**和**下一頁**，你可以一頁一頁地瀏覽課程。透過**目錄**（或課程面板頂端的 :fa-list:），你可以跳到任何一章。

## 每一頁都有對應的模擬

每次換頁時，BeaverTracer 都會自動載入屬於該頁的模擬——這樣你總是從一個可正常運作的狀態開始。

:::warning
你在某一頁中建構或更改的內容，到了下一頁就會消失。這是刻意的設計：每一頁都從乾淨的初始狀態開始。
:::

- 使用課程面板頂端的 :fa-rotate-left;，可以把模擬重設回目前這一頁的起點——當你搞得一團亂時非常方便。
- 如果你想在某個模擬的基礎上繼續自己建構，請點擊工具列中的 :fa-file-import: **採用**。課程面板會關閉，這個模擬就歸你了。

## 保存與載入

一個模擬就是一個單獨的檔案（`.btsim`），它描述了你完整的網路——所有裝置、纜線以及它們的設定。只要課程面板是開啟的，按鈕 :fa-file: **新增**、:fa-file-arrow-up: **載入** 和 :fa-file-arrow-down: **保存** 就會被隱藏。按下**採用**之後（或是用 **×** 關閉課程面板時），你可以在編輯模式下於工具列中模式按鈕的右側找到它們。

## 方塊、測驗與任務

:::goal
**學習目標** — 位於章節開頭：說明你在學完之後能做到什麼。
:::

:::tip 重點整理
簡短總結一個重要的專業術語或關聯——很適合用來準備考試。
:::

- **測驗題**直接在頁面上作答，並用下方的按鈕檢查。只要仔細觀察，幾乎所有答案都可以從你的螢幕上讀出來。
- 帶有**檢查任務**按鈕的**任務**會檢查你的模擬，看看所有設定是否正確——例如兩台電腦是否能互相連通。

# 網路中的迴圈與 Spanning Tree

:::goal
**學習目標：** 你能說明在有迴圈的網路中如何產生廣播風暴，以及 Spanning Tree Protocol（STP）如何在不放棄容錯能力的情況下防止迴圈。
:::

如果網路中的一條纜線壞了，會發生什麼事？如果所有設備都只靠一條線路連接，網路的一部分就會被切斷。因此在較大的網路中，通常會將交換器**多重**連接——就像工作區上的三台交換器，它們組成了一個環。如果一條纜線斷線，還有另一條路可以繞行。

聽起來不錯——但這樣的環有一個危險的陷阱。你會在下一頁認識它。

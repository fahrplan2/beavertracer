# 無狀態或有狀態

一條連線一定包含**兩個方向**：教師電腦向網際網路上的網頁伺服器傳送請求，而網頁伺服器再把網頁傳回來。因此，採用白名單原則的防火牆不僅要讓請求通過，也必須讓**回應**通過。

為此有兩種封包過濾器：

| | **無狀態**（*stateless*） | **有狀態**（*stateful*） |
|---|---|---|
| 運作方式 | 逐一檢查每個封包，沒有記憶 | 把允許的連線記錄在**狀態表**中 |
| 回應 | 回傳方向需要另外一條規則 | 因為屬於已知的連線，所以會自動放行 |
| 應用場合 | 簡單的設備、速度極快的過濾器 | 現今幾乎所有的防火牆 |

在接下來的兩個章節中，你會親身體驗無狀態過濾器為什麼在處理回應時會有問題，以及有狀態防火牆如何解決這個問題。

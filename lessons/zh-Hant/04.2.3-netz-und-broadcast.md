# 網路位址、廣播位址與主機

在每個網路中，有兩個位址具有特殊的用途：

- **網路位址**是該網路中**最小**的位址：主機部分的所有位元都是 0。它代表整個網路，例如用於路由表中。
- **廣播位址**是該網路中**最大**的位址：主機部分的所有位元都是 1。傳送到這個位址的資料會送到網路中的所有裝置。

這兩個位址**都不會**分配給裝置。介於兩者之間的所有位址都可供裝置（**主機**）使用。

## 一個簡單的例子

`192.168.0.12/24` — 主機部分是最後一個八位元組：

| | 位址 |
|---|---|
| 網路位址（主機部分 = 0） | `192.168.0.0` |
| 廣播位址（主機部分 = 255） | `192.168.0.255` |
| 主機範圍 | `192.168.0.1` – `192.168.0.254` |
| 主機數量 | 254 |

## 當分界線落在八位元組中間時

當前綴長度不是 8 的倍數時，就會比較困難。這時你要把受影響的那個八位元組換算成二進位系統。例如：`194.9.190.12/27`。

前三個八位元組完全屬於[[n|網路部分]]（24 位元）。最後一個八位元組中，還有 **3 位元**屬於網路部分（24 + 3 = 27），其餘 **5 位元**屬於[[h|主機部分]]：

| | 最後一個八位元組（二進位） | 十進位 |
|---|---|---|
| IP 位址 | [[n|000]][[h|01100]] | 12 |
| 子網路遮罩（`/27`） | [[n|111]][[h|00000]] | 224 |
| 網路位址：主機位元設為 0 | [[n|000]][[h|00000]] | **0** |
| 廣播位址：主機位元設為 1 | [[n|000]][[h|11111]] | **31** |

結果：

- 網路位址：`194.9.190.0`
- 廣播位址：`194.9.190.31`
- 主機範圍：`194.9.190.1` – `194.9.190.30`
- 主機數量：2⁵ − 2 = **30**

:::tip 重點整理
**網路位址：**所有主機位元設為 0（最小的位址）。**廣播位址：**所有主機位元設為 1（最大的位址）。兩者都不會分配給裝置。前綴長度為 *n* 的網路，有 **2<sup>32 − n</sup> − 2** 個可供主機使用的位址。
:::

:::tip 小技巧：區塊大小
如果你已經理解了二進位系統的做法，還有一個捷徑：**256 減去遮罩的八位元組**，就是網路在該八位元組中的大小。以 `/27`（遮罩 224）為例，就是 256 − 224 = **32**。網路會從 0、32、64、96 … 開始 — 位址 `.12` 位於從 `.0` 開始的網路中，位址 `.70` 位於從 `.64` 開始的網路中。
:::

## 最重要的網路大小

| 前綴 | 子網路遮罩 | 主機數 |
|---|---|---|
| `/8` | `255.0.0.0` | 16 777 214 |
| `/16` | `255.255.0.0` | 65 534 |
| `/24` | `255.255.255.0` | 254 |
| `/25` | `255.255.255.128` | 126 |
| `/26` | `255.255.255.192` | 62 |
| `/27` | `255.255.255.224` | 30 |
| `/28` | `255.255.255.240` | 14 |
| `/29` | `255.255.255.248` | 6 |
| `/30` | `255.255.255.252` | 2 |

:::note
實務上常見的最小網路是 `/30`：它剛好有兩個可用位址，常用於兩台路由器之間的連線。`/32` 代表單一位址 — 它無法當作網路使用，但會出現在路由表和防火牆規則中。
:::

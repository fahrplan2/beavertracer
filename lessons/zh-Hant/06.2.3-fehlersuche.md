# 疑難排解：名稱無法使用

:::sim
url=/sims/lesson-6.2.3.btsim
:::

一位老師回報：「`www.beaver-schule.de` 在我這裡無法載入。但用 `http://192.168.0.20` 就可以！」網路*應該*這樣設定：

| 項目 | 應有設定 |
|---|---|
| Client-PC 上的 DNS 伺服器 | `192.168.0.53`（DNS-Resolver） |
| Schul-DNS 中的記錄 | `www.beaver-schule.de` → `192.168.0.20` |

找出錯誤並加以修正。

<details>
<summary>提示 1：nslookup 顯示了什麼？</summary>

在 Client-PC 上輸入 `nslookup www.beaver-schule.de`。`nslookup` 詢問了哪一台伺服器？回傳了什麼結果？（回應需要幾秒鐘。）
</details>

<details>
<summary>提示 2：接下來呢？</summary>

如果你收到了回應，請將該位址與拓樸圖比對。這個名稱是在哪裡登錄的？
</details>

:::task
title: 名稱解析修復了嗎？
檢查 Client-PC 是否能將 www.beaver-schule.de 解析為正確的位址。為此，模擬必須在執行模式下運作。
check: resolves(2, "www.beaver-schule.de", "192.168.0.20")
:::

## 問題出在哪裡？

:::quiz multi
下列哪些敘述是正確的？
- [x] Client-PC 上設定的 DNS 伺服器是 `192.168.0.35`——那裡沒有任何裝置回應
- [x] 在 Schul-DNS 中，`www.beaver-schule.de` 指向 `192.168.0.21`，而不是 `192.168.0.20`
- [ ] 網頁伺服器被關閉了
- [ ] 根伺服器不認識網域 `.de`
:::

:::evaluate
檢查答案
:::

:::tip 重點整理
如果使用 **IP 位址**可以連線，但使用**名稱**卻不行，問題就出在 **DNS**。請先檢查**所設定的 DNS 伺服器**（它到底有沒有回應？），再檢查**記錄**本身（位址正確嗎？）。`nslookup` 兩者都會顯示：詢問了哪一台伺服器，以及它回應了什麼。
:::

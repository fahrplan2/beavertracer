# 分配 IP 位址

:::sim
url=/sims/lesson-1.2.2.btsim
:::

兩台裝置要能互相通訊，就需要在同一個網路中擁有 IP 位址。在工作區中，你會看到兩台已連接的 PC——就和你剛才親手建立的一模一樣。

1. 切換到 :fa-play: **執行**模式，然後點擊 **Computer 1** 將它開啟。
2. 在那裡開啟 :fa-gear: **IP 設定**。新的 PC 已經有位址 `192.168.0.10`，子網路遮罩為 `/24`——你可以保持不變。
3. 現在開啟 **Computer 2**。它擁有*相同*的位址 `192.168.0.10`——這是行不通的，因為每個位址在網路中只能出現一次。請將它改為 `192.168.0.11`（子網路遮罩 `/24`）。

:::tip 重點整理
**IP 位址**（例如 `192.168.0.10`）是裝置在網路中的位址——可以比喻為門牌號碼。每個 IP 位址在一個網路中只能出現**一次**。
:::

:::task
title: 位址分配正確嗎？
請停留在執行模式，並檢查兩台 PC 是否擁有合適的位址，且可以互相連通。
check: ip(1, "192.168.0.10/32")
check: ip(3, "192.168.0.11/32")
check: pingOk(1, 3)
:::

:::note
`/24` 究竟代表什麼，以及如何合理地劃分網路，我們會在第 4 章詳細說明。現在只需要知道：兩個位址都必須以 `192.168.0.` 開頭，而且不能重複。
:::

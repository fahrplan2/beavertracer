# DNS：用名稱取代數字

:::goal
**學習目標：** 你能夠說明 DNS 如何將名稱轉換為 IP 位址、這些名稱如何以階層方式組織，能自己建立一筆記錄，並找出常見的 DNS 錯誤。
:::

幾乎沒有人記得住 IP 位址，但像 `www.beaver-schule.de` 這樣的名稱就容易多了。負責轉換的是**網域名稱系統**（Domain Name System，**DNS**），它就像是網際網路上的全球電話簿。

工作區上現在有一個稍大的網路：除了 **Client-PC** 和 **Webserver** 之外，還有四台 **DNS-Server**。為什麼需要這麼多台，你會在下下一頁看到。

## 實驗

1. 切換到 :fa-play: **執行**模式，點選 **Anna**，並開啟 **E-Mail** 應用程式。
2. 切換到 **Verfassen** 索引標籤。在 **An** 欄位輸入 `ben@biber-mail.de`，再輸入主旨與一小段內文，然後點選 **傳送**。
3. 等待幾秒鐘——郵件必須先從一台郵件伺服器傳到另一台郵件伺服器。接著點選 **Ben**，開啟 **E-Mail** 應用程式並點選 **擷取**。Anna 寄出的郵件已經在那裡了。
4. 在 :fa-magnifying-glass: **追蹤**模式中，為 **Mailserver Schule** 開啟一筆追蹤記錄。

## 背後的原理

一封電子郵件會分成好幾個階段傳送——就像一封信經過兩間郵局一樣：

1. Anna 的電子郵件程式使用 **SMTP** 把郵件交給 Anna 的郵件伺服器。
2. Mailserver Schule 發現：接收端屬於一個**外部網域**。它透過 **DNS** 查詢 `biber-mail.de` 的 **MX 記錄**（*Mail Exchanger*），得到 `mail.biber-mail.de`——接著再查詢它的 IP 位址。
3. 它使用 **SMTP** 把郵件投遞給 Mailserver Biber。郵件會存放在 Ben 的信箱中。
4. Ben 使用 **IMAP**（或 **POP3**）從他的郵件伺服器取回郵件。

:::seq
mode: text
Mailserver Schule -> Mailserver Biber: SMTP: MAIL FROM | anna@beaver-schule.de
Mailserver Biber -> Mailserver Schule: 250 OK
Mailserver Schule -> Mailserver Biber: SMTP: RCPT TO | ben@biber-mail.de
Mailserver Biber -> Mailserver Schule: 250 OK
Mailserver Schule -> Mailserver Biber: SMTP: DATA | 郵件本身
Mailserver Biber -> Mailserver Schule: 250 OK queued
:::

:::tip 重點整理
**SMTP**（連接埠 25）負責**寄送**電子郵件：從電子郵件程式到自己的郵件伺服器，再從那裡到接收端的郵件伺服器。哪一台郵件伺服器負責某個網域，記錄在 DNS 的 **MX 記錄**中。**POP3**（連接埠 110）和 **IMAP**（連接埠 143）只用來從自己的信箱**取回**郵件。
:::

:::quiz match
SMTP -> 寄送電子郵件，並在郵件伺服器之間轉送
MX 記錄 -> 指出哪一台郵件伺服器負責某個網域
IMAP -> 從自己的信箱取回電子郵件
:::

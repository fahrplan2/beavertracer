# 第一批自訂規則

:::sim
url=/sims/lesson-9.btsim
:::

現在換你動手了。防火牆目前還會放行所有流量。請設定防火牆，讓網際網路上的使用者只能存取學校伺服器的 **Webseite (80)** 和 **Mail-Empfang (25)**。**SSH (22)**、**POP3 (110)** 和 **IMAP (143)** 則不應再能從網際網路存取。

## 加入規則

1. 點選 **Firewall**。預設政策先維持為 **Alle zulassen**。
2. 刪除現有的規則（它本來就允許所有流量），然後透過 **+ Regel hinzufügen** 為每個要封鎖的連接埠建立一條規則：
    - **Richtung** A → B（來自網際網路）
    - **Protokoll** TCP
    - **Ziel-Port** 例如 `22`
    - **Aktion** Verwerfen
3. 從 **Internet-PC** 使用 `nmap 198.51.100.10` 檢查，看看是否只剩下正確的連接埠是開放的。

:::task
title: 從外部只能存取網頁和郵件嗎？
檢查學校伺服器從網際網路是否只能透過連接埠 80 和 25 存取，以及教師電腦是否仍然可以收取郵件並瀏覽網際網路。模擬必須在執行模式下運作。
check: tcpOpen(1, "198.51.100.10", 80)
check: tcpOpen(1, "198.51.100.10", 25)
check: tcpFails(1, "198.51.100.10", 22)
check: tcpFails(1, "198.51.100.10", 110)
check: tcpFails(1, "198.51.100.10", 143)
check: tcpOpen(8, "198.51.100.10", 110)
check: tcpOpen(8, "203.0.113.80", 80)
:::

- [ ] 因為防火牆能辨識教師
- [x] 因為它的封包根本不會經過防火牆——教師電腦和學校伺服器連接在防火牆後方的同一台交換器上
- [ ] 因為 POP3 是安全的協定

:::note
防火牆只保護**經過它**的流量。學校網路內部發生的事情，它看不到。因此，學校網路中一台受感染的電腦仍然可以攻擊學校伺服器——這正是 DMZ 這一節要探討的內容。
:::

:::tip 重點整理
對於每一個不應從外部存取的服務，可以用一條包含**方向**、**協定**和**目的連接埠**的規則來封鎖存取。規則是否生效，可以從外部用**連接埠掃描**來檢查。
:::

Beaver 學校擁有自己的公用位址（`198.51.100.…`）：學校的 **Schulserver** 可以直接從網際網路存取——不需要 NAT，就像日後有了 IPv6 之後到處都會是的那樣（第 7.3 章）。在網際網路與 **Schulrouter** 之間有一台**防火牆**，不過它目前仍然放行所有流量。

左側是「網際網路」：一台 **Internet-PC** 和網頁伺服器 `www.beispiel.de`。右側是學校網路，包含 **Schulserver** 和 **Lehrer-PC**。

## 攻擊者看得到什麼？

想要攻擊伺服器的人，首先會尋找**開放的連接埠**——也就是正在等待連線的服務。用來做這件事的工具叫做**連接埠掃描器**；其中最有名的是 `nmap`。

切換到 :fa-play: **執行**模式，在 **Internet-PC** 上開啟 :fa-terminal: **終端機**，然後輸入：

```
$ nmap 198.51.100.10
```

`nmap` 會嘗試對最常見的 20 個連接埠建立 TCP 連線，並回報哪些連接埠是開放的。

:::quiz multi
從網際網路來看，Schulserver 上有哪些連接埠是開放的？
- [x] 22（SSH，遠端維護）
- [x] 25（SMTP）
- [x] 80（HTTP）
- [x] 110（POP3）
- [x] 143（IMAP）
- [ ] 443（HTTPS）
:::

:::evaluate
檢查答案
:::

網站（80）和電子郵件的接收（25）應該能從網際網路存取。但是**遠端維護**（22）以及收取郵件（110、143）只有學校網路需要。每一個開放的連接埠都是一個可能的攻擊面：如果該服務有安全漏洞或使用弱密碼，攻擊者就可以從世界上任何地方加以利用——而網際網路上的自動掃描器正是全天候不停地嘗試這件事。

:::tip 重點整理
**防火牆**會控制兩個網路交界處的資料流量，只放行明確允許的內容。這樣一來，只有內部需要的服務就不會暴露給網際網路。
:::

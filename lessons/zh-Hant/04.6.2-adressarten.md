# 最重要的位址類型

在 IPv6 中，從位址的開頭就能看出它的用途：

| 位址類型 | 辨識方式 | 用途 |
|---|---|---|
| **Link-Local（連結本地）** | `fe80::` | 只在**自己的區域網路**內有效。每個裝置都會自動給自己這個位址——路由器絕不會轉送它。 |
| **Global Unicast（全域單播）** | `2…` 或 `3…`（`2000::/3`） | 全球唯一的位址，可在網際網路上連線。前綴由網際網路服務供應商提供。 |
| **Unique Local（唯一本地）** | `fd…`（`fc00::/7`） | 用於私有網路，相當於 IPv4 的 `192.168.x.x`。 |
| **Loopback（迴路）** | `::1` | 指裝置本身——相當於 IPv4 的 `127.0.0.1`。 |
| **Multicast（多點傳播）** | `ff…` | 傳送給一個**群組**的裝置，例如 `ff02::1` = 區域網路中的所有裝置。 |

:::note
`2001:db8::/32` 這個範圍是保留給範例和教材使用的——它在真實的網際網路中絕不會出現。所以你會在本課程中看到它。
:::

一項重要的新變化：**IPv6 不再有廣播。** 在 IPv4 中傳給所有裝置的廣播，IPv6 改用 **Multicast** 位址來處理——訊息只會傳給對該群組感興趣的裝置。

:::tip 重點整理
每個 IPv6 裝置至少有一個用於自己網路的 **Link-Local 位址**（`fe80::…`），通常還有一個用於網際網路的**全域位址**。IPv6 不使用廣播，而是使用 **Multicast**（`ff…`）。
:::

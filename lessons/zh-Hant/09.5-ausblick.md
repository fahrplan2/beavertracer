# 總結與展望

## 無所不在的防火牆

你在本章學到的封包過濾器，在許多設備中都能再次看到：

- **家用路由器：** 每台家用路由器同時也是一個具狀態的防火牆。在 IPv4 中，NAT 負責其中一部分：只要沒有設定連接埠轉送，外部就無法主動發起連線（第 7 章）。在 IPv6 中，所有裝置都擁有公用位址——此時單靠防火牆規則「外部不得發起新連線」就能提供同樣的保護。
- **個人防火牆：** Windows、macOS 和 Linux 也在電腦本身內建了防火牆。它在陌生的網路中也能保護裝置，例如在咖啡店的 WLAN 中，並且可以針對各個程式設定規則。
- **新世代防火牆**和**網頁應用程式防火牆（WAF）：** 它們不僅檢查位址和連接埠，還會檢查封包的內容——一直到應用層。因此能夠偵測出例如 HTTP 請求中的攻擊。對於 HTTPS，它們必須為此破解加密（第 8 章）。
- **IDS/IPS：** *入侵偵測系統（Intrusion Detection System）*會在資料流量中辨識可疑的模式並發出警報；*入侵防禦系統（Intrusion Prevention System）*則會進一步自行將其封鎖。

:::note
防火牆只是安全性的**其中一個**環節。如果一個被允許的服務（例如網頁伺服器）本身有漏洞、有人透過電子郵件開啟了惡意程式，或是密碼強度不足，防火牆都無濟於事。因此，更新、安全的密碼、加密以及對網路的妥善劃分（DMZ、第 3 章的 VLAN）始終都是必要的。
:::

- [ ] 它會被允許通過
- [x] 它會被丟棄
- [ ] 它會被拒絕並回覆
:::

:::quiz mc
`nmap` 對某個連接埠回報 `filtered`。這代表什麼？
- [ ] 該連接埠上正在執行某個服務
- [ ] 伺服器以 RST 回應
- [x] 完全沒有收到任何回應——很可能是防火牆丟棄了封包
:::

- [x] 可從網際網路存取的伺服器應放在 DMZ 中
- [ ] 防火牆也能防範其後同一網路內兩台電腦之間的攻擊
- [ ] 所有規則都一定會被檢查，最嚴格的規則優先

## 背後的原理

家用路由器會把每個發往網際網路的封包中的私有發送端位址，換成它自己的**公有 WAN 位址**，通常連發送端連接埠也一併替換。對網頁伺服器來說，請求看起來就像是來自家用路由器。回應傳回來時，家用路由器會再把位址換回去，並把封包轉交給 PC。

這樣整個家用網路只需要一個公有位址就能連上網際網路，而且網際網路上的裝置永遠看不到這些私有位址。

## 通往網際網路的路徑

在 **PC** 的 :fa-terminal: **終端機**中輸入：

```
$ traceroute 192.0.2.80
```

:::quiz short
PC 與網頁伺服器之間有幾台路由器？（計算最後一行之前的所有行。）
= 4
= 四
:::

:::quiz mc
`traceroute` 顯示的第一台路由器是哪個位址？
- [x] `192.168.178.1`：家用路由器的 LAN 位址
- [ ] `203.0.113.2`：它的 WAN 位址
- [ ] `203.0.113.1`：業者的第一台路由器
:::

:::evaluate
檢查答案
:::

:::tip 重點整理
**NAT**（*Network Address Translation*，網路位址轉譯）會在裝置連往網際網路時，把裝置的**私有**發送端位址換成路由器的**公有 WAN 位址**，回應時則反向轉換。這樣家用網路中的所有裝置就共用**一個**公有 IPv4 位址。這既節省位址，也能向網際網路隱藏私有位址。
:::

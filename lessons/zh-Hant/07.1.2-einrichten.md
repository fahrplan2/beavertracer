# 設定家用路由器

:::sim
url=/sims/lesson-7.1.2.btsim
:::

一台新的家用路由器剛剛接上線，但目前還沒有任何裝置可以連上網際網路。你從網路業者那裡收到一封載有**連線資料**的信：

| 連線資料 | 值 |
|---|---|
| WAN IP 位址 | `203.0.113.2` |
| 前綴長度 | `/30` |
| 閘道（網路業者的路由器） | `203.0.113.1` |
| 網路業者的 DNS 伺服器 | `198.51.100.10` |

1. 切換到 :fa-play: **執行**模式，點選 **Heimrouter**，然後開啟 **WAN** 索引標籤。
2. 輸入連線資料，然後點選**套用**。
3. 將 **Tablet** 連上 WLAN：:fa-gear: **IP 設定**，**WiFi** 索引標籤，SSID 填入 `Biberbau`，按**套用**。
4. 在 PC 上用 `ping 192.0.2.80` 測試，或在瀏覽器中開啟 `http://www.beispiel.de/` 測試。

:::note
在實務上，家用路由器的 WAN 位址通常是由網路業者自動分配的（透過 DHCP，或以使用者名稱與密碼登入）。像這裡這樣使用固定連線資料的情況，比較常見於企業專線。
:::

check: ip(4, "192.168.178.0/24")

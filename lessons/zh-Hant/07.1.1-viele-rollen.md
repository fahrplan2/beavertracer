## 家用路由器裡包含了什麼

| 家用路由器中的角色 | 功能 | 你在哪裡學過 |
|---|---|---|
| **交換器** | 連接 LAN 插孔上的裝置 | 第 3.1 章 |
| **無線接取點** | 讓手機、平板和筆記型電腦透過 WLAN 連入網路 | 第 3.3 章 |
| **路由器** | 將家用網路與網路服務提供者的網路連接起來 — 它就是**閘道** | 第 4.3 章 |
| **DHCP 伺服器** | 分配位址、閘道和 DNS 伺服器 | 第 6.4 章 |
| **DNS** | 轉送名稱查詢，或告知提供者的 DNS 伺服器 | 第 6.2 章 |
| **NAT** | 讓所有裝置透過**一個**公用位址連上網際網路 | 新內容 — 第 7.2 節 |

**WAN**（*Wide Area Network*，廣域網路）連接埠通往網路服務提供者，**LAN** 連接埠和 WLAN 則通往家用網路。許多家用路由器還內建**數據機**（Modem）— 它會把資料轉換成適合線路傳輸的訊號（DSL、纜線、光纖）。BeaverTracer 不會模擬這一點；在這裡，WAN 連接埠直接接入提供者的網路。

:::quiz match
交換器 -> 連接 LAN 插孔上的裝置
無線接取點 -> 讓平板和手機透過 WLAN 連入網路
DHCP 伺服器 -> 為家用網路中的裝置分配位址
路由器 -> 將家用網路與網路服務提供者的網路連接起來
:::

:::evaluate
檢查配對

:::tip 重點整理
**家用路由器**整合了多種裝置：**交換器**、**WLAN 無線接取點**、**路由器**（通往網際網路的閘道）、**DHCP 伺服器**和 **DNS 轉送** — 另外還有 **NAT**。**WAN** 連接埠通往網路服務提供者，**LAN** 連接埠和 WLAN 則通往家用網路。
:::

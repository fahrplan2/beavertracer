# 建立自己的 CA

:::sim
url=/sims/lesson-8.2.2.btsim
:::

`www.beaver-schule.de` 目前還沒有憑證。學校不向商業 CA 申請，而是建立**自己的 CA**：**Schul-CA**。許多公司和學校都會為內部伺服器這麼做。

在實際環境中，Schul-CA 會運作在專屬且受到特別嚴密保護的電腦上。這裡由你在網頁伺服器上自己扮演所有角色。

## 步驟 1：建立 Schul-CA

1. 切換到 :fa-play: **執行**模式，在網頁伺服器 **www.beaver-schule.de** 上開啟 :fa-shield-halved: **Zertifikatverwaltung**。
2. 在**Generieren**索引標籤中：
    - **Common Name:** `Schul-CA`
    - **Typ:** Selbstsigniert
    - 勾選 **Dies ist ein CA-Zertifikat**
    - **Speichern unter:** `schul-ca.cert.json`
3. 點選 **Zertifikat generieren**。

這時會產生一組新的**金鑰對**。憑證中包含公開金鑰；私密金鑰則保留在網頁伺服器上的檔案中。

## 步驟 2：簽發伺服器憑證

同樣在**Generieren**索引標籤中：

- **Common Name:** `www.beaver-schule.de` — 正是在瀏覽器中輸入的名稱
- **Typ:** Von CA signiert，**Signierende CA:** Schul-CA
- **Speichern unter:** 例如 `www.beaver-schule.de.cert.json`

在**Meine Zertifikate**索引標籤中，你現在可以看到兩張憑證。點選新的伺服器憑證：

:::quiz short
伺服器憑證的**簽發者（Aussteller）**是誰（不含 `CN=`）？
= Schul-CA
:::

:::quiz mc
它的**憑證鏈（Kette）**是什麼？
- [x] `www.beaver-schule.de ← Schul-CA`
- [ ] `Schul-CA ← www.beaver-schule.de`
- [ ] `www.beaver-schule.de`（自簽）
:::

## 步驟 3：讓用戶端認識 Schul-CA

用戶端電腦還不認識 Schul-CA — 它的瀏覽器中沒有預先安裝這個 CA。你必須把 CA 的憑證交給它，而且是**不含私密金鑰**的憑證：

1. 在網頁伺服器的**Meine Zertifikate**中選取 **Schul-CA**，然後點選 **Kopieren**（不是 *Kopieren + Schlüssel*！）。
2. 在**用戶端電腦**上開啟 :fa-shield-halved: **Zertifikatverwaltung**，切換到**Vertrauenswürdige CAs**索引標籤。
3. 點選 **Einfügen: Schul-CA**。

:::warning
**CA 的私密金鑰**是整個系統中最有價值的機密：誰擁有它，就能為**任意**名稱簽發憑證，而所有用戶端都會信任這些憑證。它絕對不能離開 CA 電腦。
:::

:::task
title: 已建立 Schul-CA 了嗎？
Prüft, ob es auf dem Webserver ein von der Schul-CA ausgestelltes Zertifikat für www.beaver-schule.de gibt und ob der Client-PC der Schul-CA vertraut.
check: hasCert(4, "www.beaver-schule.de", "Schul-CA")
check: trusts(2, "Schul-CA")
:::

:::quiz mc
為什麼要給用戶端的是**不含**私密金鑰的憑證？
- [ ] 因為連同金鑰一起複製會花比較久的時間
- [x] 驗證簽章只需要公開金鑰；如果用戶端擁有私密金鑰，任何人都可以在用戶端自行簽發憑證
- [ ] 因為否則用戶端無法建立連線
:::

:::evaluate
檢查答案
:::

你還沒有調整網頁伺服器本身 — 它目前仍然只使用 HTTP。如何啟用 HTTPS，你會在 8.3.3 節學到。

:::tip 重點整理
**自己的 CA** 由一張帶有私密金鑰的**自簽 CA 憑證**組成。用它來簽發**伺服器憑證**，憑證的 Common Name 要與伺服器名稱一致。為了讓用戶端信任這些憑證，要把**不含私密金鑰的 CA 憑證**放入用戶端的**可信任 CA** 清單中。
:::

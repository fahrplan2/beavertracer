# 具狀態防火牆

:::sim
url=/sims/lesson-9.2.btsim
:::

**具狀態**（*stateful*）防火牆會把每一條曾經允許過的連線記錄在**狀態表**中：協定、雙方位址以及雙方連接埠。如果有封包符合其中一筆記錄——無論方向為何——防火牆都會不再另行檢查，直接放行。新的連線則必須通過規則的檢查。

## 觀察

1. 在**防火牆**中把**模式**設為 **Stateful**。
2. 在 **Lehrer-PC** 的 :fa-globe: **瀏覽器**中再次開啟 `http://203.0.113.80/`。
3. 立刻在防火牆中開啟 **Zustände** 索引標籤。

:::quiz mc
現在會發生什麼事？
- [x] 網頁可以載入，而且 **Zustände** 中會出現從 Lehrer-PC 到 `203.0.113.80:80` 的連線
- [ ] 網頁無法載入，因為回應封包仍然沒有對應的規則
:::

:::quiz short
狀態表中**目的**欄位顯示的是哪個連接埠？
= 80
:::

:::evaluate
檢查答案
:::

**Zustände** 中的記錄過一段時間後會再次消失（**Timeout** 欄位），前提是這條連線上已不再有任何流量。

## 任務：學校防火牆

現在請把防火牆設定成真正的學校所需要的樣子：

- **來自校內網路**的流量可以全部連到網際網路（方向 B → A，任何協定）。
- **來自網際網路**的流量只能存取學校伺服器的網頁（80）和郵件接收（25）。
- 其他一切都會被**丟棄**，模式為 **Stateful**。

:::task
title: 學校防火牆設定好了嗎？
檢查校內網路是否可以連到網際網路、從外部是否只能存取學校伺服器的網頁和郵件，以及 Lehrer-PC 是否無法從外部連到。
check: tcpOpen(8, "203.0.113.80", 80)
check: tcpOpen(1, "198.51.100.10", 80)
check: tcpOpen(1, "198.51.100.10", 25)
check: tcpFails(1, "198.51.100.10", 22)
check: pingFails(1, 8)
:::

:::quiz mc
Lehrer-PC 對 `203.0.113.80` 執行 ping。回應封包會回來嗎？
- [x] 會——這個 ping 已被 B → A 方向允許，回應屬於這筆狀態
- [ ] 不會——從外部傳來的 ICMP 沒有對應的規則
:::

:::evaluate
檢查答案
:::

:::tip 重點整理
**具狀態防火牆**會把每一條被允許的連線登錄到**狀態表**中，並讓這條連線的所有封包**雙向**通過。因此，只要針對**連線建立**制定規則就夠了：「內部可以連到外部」以及「外部只能連到特定服務」。從外部發起、連向校內網路的連線仍然會被阻擋。
:::

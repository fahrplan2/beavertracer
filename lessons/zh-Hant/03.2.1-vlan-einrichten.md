# 一個交換器，兩個網路

:::sim
url=/sims/lesson-3.2.1.btsim
:::

交換器上連接了四台 PC：行政部門的 **Sekretariat**（連接埠 1）和 **Schulleitung**（連接埠 2），以及電腦教室的 **Anna**（連接埠 3）和 **Ben**（連接埠 4）。它們全都位於同一個網路 `192.168.0.0/24` 中。

## 問題

切換到 :fa-play: **執行**模式，在 **Anna** 上開啟 :fa-terminal: **終端機**，然後 ping Sekretariat：

```
$ ping 192.168.0.10
```

Anna 毫無阻礙地就能連到 Sekretariat。而這正是我們想要避免的。

## 設定 VLAN

**VLAN**（*Virtual LAN*，虛擬區域網路）是在交換器內部獨立隔開的網路。每個 VLAN 都有一個編號，稱為 **VLAN-ID**。我們這樣規劃：行政部門放在 **VLAN 10**，電腦教室放在 **VLAN 20**。

1. 在執行模式下點選**交換器**，然後開啟 **VLAN** 索引標籤。
2. 勾選**啟用 VLAN**。這時會出現一個表格，每個連接埠一列。
3. 在 **PVID** 欄中填入 VLAN-ID——**port 1** 和 **port 2** 都填 `10`，**port 3** 和 **port 4** 都填 `20`。**模式**維持 `untagged`。
4. 點選下方的**套用**。

:::note
**PVID** 是 *Port VLAN ID* 的縮寫：所有到達這個連接埠的資料都屬於這個 VLAN。`untagged` 模式表示這個連接埠上接的是一般的 PC，它不需要知道任何與 VLAN 有關的事。
:::

## 測試

再從 **Anna** 對 Sekretariat 做一次 ping，接著再 ping Ben（`ping 192.168.0.21`）。

:::quiz mc
現在會發生什麼事？
- [ ] Anna 可以連到 Sekretariat 和 Ben
- [x] Anna 可以連到 Ben，但再也連不到 Sekretariat
- [ ] Anna 再也連不到任何人
:::

:::evaluate
檢查答案
:::

在 :fa-magnifying-glass: **追蹤**模式下，為 **Sekretariat** 開啟一個追蹤：Anna 的 ARP 請求（「Who has 192.168.0.10?」）根本不會出現在那裡。她的廣播停留在 VLAN 20 內——對交換器來說，這現在是兩個互相分離的網路，彼此完全察覺不到對方。

:::tip 重點整理
利用 **VLAN** 可以把一台交換器劃分成多個邏輯上分離的網路。位於不同 VLAN 的裝置無法直接互通——連廣播也只會留在自己的 VLAN 內。每個 VLAN 都有一個編號，稱為 **VLAN-ID**。
:::

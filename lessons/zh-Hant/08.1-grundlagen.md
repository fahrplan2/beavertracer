# 密碼學基礎

**密碼學**是研究加密的科學。在開始之前，先來認識幾個在本章中會不斷出現的名詞：

| 名詞 | 意義 |
|---|---|
| **明文** | 可閱讀的訊息，例如 `Treffen um 10 Uhr` |
| **密文** | 加密後的訊息，例如 `Wuhiihq xp 10 Xku` |
| **加密** | 明文 → 密文 |
| **解密** | 密文 → 明文 |
| **方法**（*演算法*） | 進行加密所依據的運算規則 |
| **金鑰** | 該方法所需的祕密附加資訊 |

## 方法不必保密，金鑰才需要保密

人們可能會以為，知道某種方法的人越少，它就越安全。事實正好相反：現今所有常用的方法都是**公開**說明的，並且多年來經過全世界專家檢驗是否存在弱點。只有**金鑰**才需要保密。

這項原則早在 1883 年就由荷蘭人 Auguste Kerckhoffs 提出。它的優點是：如果金鑰洩露了，只要更換金鑰即可，不必更換整個方法。

在接下來的章節中，你會認識組成安全連線的四個基本要素：

1. **對稱式加密**：速度快，但有金鑰交換的問題
2. **非對稱式加密**：公開金鑰與私密金鑰
3. **雜湊值**：資料的指紋
4. **數位簽章**：電子簽名

最後你會看到這些要素如何協同運作（**混合式加密**）。

# 手動操作 HTTP

:::sim
url=/sims/lesson-6.1.btsim
:::

如果 HTTP 只是純文字——那我們是不是也可以完全不用瀏覽器，自己直接和網頁伺服器對話？可以：使用 `telnet`，你可以與任意連接埠建立 TCP 連線，並自己輸入文字。

## 實驗

1. 切換到 :fa-play: **執行**模式，並在 **Client-PC** 上開啟 :fa-terminal: **終端機**。
2. 連線到伺服器的 80 連接埠：
   ```
   $ telnet 192.168.0.20 80
   ```
3. 逐行輸入請求，並以一個**空行**結束（只要再按一次 **Enter**）：
   ```
   GET /kontakt.html HTTP/1.1
   Host: 192.168.0.20

   ```

伺服器會回應狀態行、標頭（Header）以及聯絡頁面——都是文字，就和瀏覽器收到的內容一樣。

## 刻意製造錯誤

`curl` 是一個更方便的工具：它會替你發出請求。加上 `-v`（*verbose*，詳細模式）後，它會顯示所有來回傳送的內容——以 `>` 開頭的行是 `curl` 傳送的，以 `<` 開頭的行則來自伺服器。

試試看：

```
$ curl -v http://192.168.0.20/gibtsnicht.html
$ curl -X POST -d name=Anna http://192.168.0.20/
```

:::note
BeaverTracer 中的網頁伺服器只能提供檔案——因此它只允許 `GET` 和 `HEAD`。真正的網頁伺服器則會透過 `POST` 接收例如表單，並將資料交給程式處理。
:::

:::tip 重點整理
許多應用層協定都是**以文字為基礎**的——HTTP，還有 SMTP、POP3 和 IMAP 也是如此。因此你可以用 `telnet` 手動與它們對話，並在追蹤中讀取內容。這對疑難排解很實用——但同時也是安全問題：任何擷取封包的人都能讀到所有內容。加密（HTTPS）如何提供幫助，你會在第 8 章學到。
:::

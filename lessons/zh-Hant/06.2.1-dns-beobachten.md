## 實驗

1. 切換到 :fa-play: **執行**模式，點選 **Client-PC**，然後開啟 :fa-globe: **瀏覽器**。
2. 這次請開啟 `http://www.beaver-schule.de/`——使用名稱，而不是 IP 位址。
3. 切換到 :fa-magnifying-glass: **追蹤**模式，並為 **Client-PC** 開啟一個追蹤。

在最開始——甚至在以 `[SYN]` 進行連線建立之前——有兩個使用 **DNS** 協定的封包。

:::quiz short
Client-PC 將它的 DNS 查詢傳送到哪個 IP 位址？
= 192.168.0.53
:::

:::quiz short
在 `www.beaver-schule.de` 的回應中，出現的是哪個 IP 位址？
= 192.168.0.20
:::

:::quiz mc
點選 DNS 查詢，並展開協定樹。使用的是哪個傳輸協定和哪個目的連接埠？
- [ ] TCP，連接埠 80
- [x] UDP，連接埠 53
- [ ] UDP，連接埠 67
:::

:::evaluate
檢查答案
:::

Client-PC 要在得知 IP 位址之後，才會建立到網頁伺服器的 TCP 連線——就和第 5 章一樣。

:::seq
mode: text
Client-PC -> DNS-Resolver: DNS-Anfrage | A www.beaver-schule.de?
DNS-Resolver -> Client-PC: DNS-Antwort | A 192.168.0.20
:::

## PC 如何得知 DNS 伺服器？

在 **Client-PC** 上開啟 :fa-gear: **IP 設定**：在 **DNS-Server** 欄位中填的是 `192.168.0.53`——也就是電腦 **DNS-Resolver**。PC 會把每一個名稱查詢都傳送給它。

你也可以不透過瀏覽器，直接向 DNS 伺服器查詢。開啟 :fa-terminal: **終端機**並輸入：

```
$ nslookup www.beaver-schule.de
```

`nslookup` 會先顯示它查詢了哪個伺服器，然後顯示回應。為了比較，請再查詢一個不存在的名稱，例如 `nslookup gibtsnicht.beaver-schule.de`。

:::quiz mc
DNS 伺服器對這個未知的名稱會回應什麼？
- [ ] 一個隨機的 IP 位址
- [x] `NXDOMAIN`——沒有這個名稱
- [ ] 完全沒有回應
:::

:::evaluate
檢查答案
:::

:::tip 重點整理
**DNS** 會將名稱（例如 `www.beaver-schule.de`）轉換成 IP 位址。PC 在能夠建立到某個名稱的連線之前，會先詢問在其 IP 設定中所填入的 **DNS 伺服器**——通常是透過 **UDP，連接埠 53**。使用 `nslookup`，你可以手動發出 DNS 查詢。
:::

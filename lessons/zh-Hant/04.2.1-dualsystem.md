# 二進位系統

電腦在最底層只認得兩種狀態：通電或斷電。這兩種狀態用 **1** 和 **0** 來表示，這樣的一個位置稱為**位元**（Bit）。對電腦來說，每個 IP 位址也只是一串 0 和 1——為了讓你理解子網路遮罩如何運作，你會在這一頁學習如何讀懂這類數字並自己進行換算。

## 我們平常怎麼數數：十進位系統

在日常生活中，我們使用十個數字（0 到 9）來計算。每一位的值都是它右邊那一位的十倍：個位、十位、百位、千位。因此數字 `305` 的意思是：

| 位值 | 100 | 10 | 1 |
|---|---|---|---|
| 數字 | 3 | 0 | 5 |
| 值 | 300 | 0 | 5 |

300 + 0 + 5 = **305**

## 二進位系統

在**二進位系統**（也稱為*二進制*）中只有兩個數字：0 和 1。每一位的值都是它右邊那一位的**兩倍**：1、2、4、8、16、32、64、128 …

因此二進位數字 `00001101` 的意思是：

| 位值 | 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1 |
|---|---|---|---|---|---|---|---|---|
| 位元 | 0 | 0 | 0 | 0 | 1 | 1 | 0 | 1 |
| 值 | | | | | 8 | 4 | | 1 |

8 + 4 + 1 = **13**

也就是說，你只要把數字為 1 的那些位值加起來就可以了。

:::tip 重點整理
**位元**是二進位系統中的一個位置（0 或 1）。**8 個位元**組成一個**位元組**（Byte）——在網路技術中，這樣的 8 位元組合也稱為**八位元組**。一個八位元組的位值依序是 **128、64、32、16、8、4、2、1**。
:::

:::quiz short
`00000110` 是哪個十進位數字？
= 6
:::

:::quiz short
`10000001` 是哪個十進位數字？
= 129
:::

## 從十進位轉成二進位

反過來，你從左到右逐一檢視各個位值，並且每次都問自己：**這個位值還放得進我的（剩餘）數字嗎？** 如果可以，就寫下 1，並減去這個位值；如果不行，就寫下 0。

範例：`168`

| 位值 | 放得進…嗎？ | 位元 | 餘數 |
|---|---|---|---|
| 128 | 168 → 可以 | **1** | 40 |
| 64 | 40 → 不行 | **0** | 40 |
| 32 | 40 → 可以 | **1** | 8 |
| 16 | 8 → 不行 | **0** | 8 |
| 8 | 8 → 可以 | **1** | 0 |
| 4 | 0 → 不行 | **0** | 0 |
| 2 | 0 → 不行 | **0** | 0 |
| 1 | 0 → 不行 | **0** | 0 |

由上往下讀：168 = **10101000**

:::tip 小提示
這些值在子網路遮罩中會一再出現——值得把它們記起來：`10000000` = 128、`11000000` = 192、`11100000` = 224、`11110000` = 240、`11111000` = 248、`11111100` = 252、`11111110` = 254、`11111111` = 255。
:::

## 二進位系統中的 IP 位址

一個 IPv4 位址由 **32 位元**組成，也就是四個八位元組。因為沒有人記得住 32 個 0 和 1，所以人們把每個八位元組寫成十進位數字，並用點號分隔：

```
11000000 . 10101000 . 10110010 . 00000001
   192   .   168    .   178    .    1
```

:::quiz short
一個 IPv4 位址由多少位元組成？
= 32
:::

:::quiz mc
理論上有多少個不同的 IPv4 位址？
- [ ] 256 × 4 = 1024
- [x] 2³² — 約 43 億
- [ ] 綽綽有餘——地球上每個人都能分到好幾個
:::

:::

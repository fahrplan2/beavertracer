# 應用模型

請將本章開頭實驗中的協定對應到它們所屬的 OSI 層：

:::quiz match
Ethernet -> 第 2 層 — 資料連結
IPv4 -> 第 3 層 — 網路
TCP -> 第 4 層 — 傳輸
HTTP -> 第 7 層 — 應用
:::

:::evaluate
檢查配對
:::

最後再來對應資料單位的名稱：

:::quiz match
Frame -> 第 2 層 — 資料連結
封包 -> 第 3 層 — 網路
Segment -> 第 4 層 — 傳輸
:::

:::evaluate
檢查配對
:::

這樣你就有了工具，往後可以正確地歸類各種協定。從下一章開始，我們會依序介紹各層，首先是第 2 層，以及交換器究竟如何知道要把封包轉送到哪裡的問題。

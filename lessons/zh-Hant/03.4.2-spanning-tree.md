和剛才一樣的環狀網路——這次你要先啟用 **Spanning Tree Protocol**（**STP**，擴展樹協定）。

## 啟用 STP

請在**全部三台**交換器上進行以下操作：

1. 切換到 :fa-play: **執行**模式，然後點選該交換器。
2. 開啟 **STP** 索引標籤，在模式中選擇 **STP (802.1D)**。

接著等待約 **15 秒**。在這段時間內，交換器會互相交換小型訊息（稱為 *BPDU*），並協商出一個共同的結構。

## 交換器協商出的結果

在每台交換器上開啟 **STP** 索引標籤，查看表格：每個已連接的連接埠都有一個 **State**（狀態）。

現在從 **Anna** 對 Ben 執行 ping（`ping 192.168.0.11`）：這次 ping 成功送達，而且不會再有任何封包在環狀網路中不斷繞圈。

STP 選出一台交換器作為根，並以它為起點建立了一棵**樹**：通往每台交換器的路徑恰好只有一條。那條會形成迴圈的連線被**阻擋**了——纜線仍然插著，但交換器不會透過它傳送一般的訊框。

## 如果纜線斷了呢？

1. 切換到 :fa-pencil: **編輯**模式，選擇 :fa-ban: **Löschen** 工具，然後點選 **Switch A** 與 **Switch B** 之間的纜線。
2. 切換回 :fa-play: **執行**模式，再等待約 15 秒。
3. 查看 **Switch B** 的 **STP** 索引標籤，然後再從 Anna 對 Ben 執行一次 ping。

:::quiz mc

- [ ] 現在無法再連到 Ben
- [x] 之前被阻擋的 Switch B 連接埠現在開始轉送——ping 改走經由 Switch C 的迂迴路徑
- [ ] Switch B 現在是 Root
:::

檢查答案

:::tip 重點整理
**Spanning Tree Protocol**（**STP**）可防止交換器之間產生迴圈：交換器會選出一台 **Root Bridge**，並**阻擋**個別連接埠，使通往每台交換器的路徑恰好只有一條。若某條連線中斷，STP 會重新開放一個被阻擋的連接埠——因此即使發生故障，網路仍然可以連通。
:::

## 延伸：STP 還能做什麼

你在這裡看到的只是基本原理。在真實的網路中，背後還有更多內容：

- **不同的版本：**除了傳統的 STP，還有進一步發展的機制，例如 **RSTP**（*Rapid* STP），它在故障後能更快恢復運作，以及 **MSTP**（*Multiple* STP）。
- **STP 與 VLAN：**如果交換器上運行多個 VLAN，還必須額外規定如何為各個 VLAN 建立樹——這需要專屬的機制與設定。
- **Root Bridge 的選舉：**哪一台交換器成為 Root，遵循一套專屬且明確規定的程序。在這個範例中，我們事先做了設定，讓 Switch A 永遠勝出。

:::note
這些主題超出本課程的範圍——重要的只有一點：想在真實網路中設定 STP 的人，需要的知識遠多於本節所教的內容。
:::

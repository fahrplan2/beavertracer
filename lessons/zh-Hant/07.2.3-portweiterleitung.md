# 由外向內：連接埠轉送

:::sim
url=/sims/lesson-7.2.3.btsim
:::

家用網路中現在有一台專屬的 **Heim-Webserver**（`192.168.178.10`）。Clara 想在外出時存取這個網頁——她的筆記型電腦 **Clara** 位於右側的網際網路上。

## 問題

1. 切換到 :fa-play: **執行**模式，在 **Clara** 的 :fa-globe: **瀏覽器**中開啟 `http://203.0.113.2/`——這是家用網路的公用位址。
2. 瀏覽器一直在等待。幾秒鐘後，點擊 **Stopp**。
3. 在 :fa-magnifying-glass: **追蹤**模式下，為 **Heimrouter** 的 `wan0` 連接埠開啟一個追蹤。

:::quiz mc
Clara 的連線建立（傳送到連接埠 80 的 `[SYN]`）會發生什麼事？
- [x] 它抵達 Heimrouter——但路由器不會轉送它，也不會回應
- [ ] 它抵達 Heim-Webserver，後者以 RST 回應
- [ ] 它根本沒有抵達 Heimrouter
:::

:::evaluate
檢查答案
:::

對於從外部進來的封包，NAT 表中沒有對應的項目：家用網路中沒有任何人發起過這個連線。Heimrouter 不知道該把它送到哪一台裝置——於是將它丟棄。

## 設定連接埠轉送

透過**連接埠轉送**（某些路由器稱為*連接埠轉發*），你可以指定：所有抵達某個特定 WAN 連接埠的資料，都會送往家用網路中的某一台特定裝置。

1. 點擊 **Heimrouter**，開啟**連接埠轉發**索引標籤。
2. 新增一條規則：協定 `TCP`、WAN 連接埠 `80`、LAN IP `192.168.178.10`、LAN 連接埠 `80`，然後點擊 **+ Hinzufügen**。
3. 在 **Clara** 上再次開啟 `http://203.0.113.2/`。

:::task
title: 能否從外部連到家用網路的 Webserver？
檢查 Clara 是否能從網際網路連線到家用網路公用位址的連接埠 80。為此，模擬必須在執行模式下運作。
check: tcpOpen(12, "203.0.113.2", 80)
:::

:::warning
連接埠轉送會在內部開一個缺口：網際網路上的任何人都能存取其後方的裝置——包括會自動掃描開放連接埠的攻擊者。因此只轉送真正必要的服務，並讓裝置保持更新。更多內容請見第 9 章（防火牆）。
:::

:::tip 重點整理
從外部沒有人能對 NAT 後方的裝置發起連線——路由器不知道該把封包送到哪裡。**連接埠轉送**則規定：抵達某個特定 **WAN 連接埠**的封包，會送往某個特定的 **LAN IP**（以及某個 LAN 連接埠）。這樣，家用網路中的伺服器就能從網際網路存取。
:::

# 疑難排解：找不到聯絡頁面

:::sim
url=/sims/lesson-6.1.3.btsim
:::

秘書處回報：「我們網站上的 **Kontakt** 連結現在只會顯示錯誤訊息。」聯絡頁面應該可以透過 `http://192.168.0.20/kontakt.html` 存取。請找出問題並修復。

<details>
<summary>提示 1：伺服器回報了什麼？</summary>

在瀏覽器中或使用 `curl -v` 開啟聯絡頁面。回傳的狀態碼是什麼？錯誤頁面也會告訴你伺服器在哪裡尋找該檔案。
</details>

<details>
<summary>提示 2：檔案放在哪裡？</summary>

網頁伺服器只會提供其**文件根目錄**（*Document Root*）中的檔案——這個設定可在 **HTTP 伺服器** 應用程式中查看。在 **Server** 的終端機中用 `ls` 查看那裡有哪些檔案，並且也到 `/home` 裡找找聯絡頁面。
</details>

<details>
<summary>提示 3：移動檔案</summary>

使用 `mv` 可以移動檔案：`mv <來源> <目標資料夾>`。
</details>

:::task
title: 聯絡頁面修好了嗎？
檢查聯絡頁面是否位於網頁伺服器的文件根目錄中。
check: fileExists(2, "/var/www/kontakt.html")
:::

## 發生了什麼事？

:::quiz multi
下列哪些說法正確？
- [x] 伺服器回應了 `404 Not Found`
- [x] 檔案放在 `/home`，而不是文件根目錄 `/var/www`
- [ ] 網頁伺服器根本沒有啟動
- [ ] 瀏覽器使用了錯誤的 IP 位址
:::

:::evaluate
檢查答案
:::

:::tip 重點整理
**404** 表示：網頁伺服器正在運作且可以連線，但在這個路徑下沒有所請求的**檔案**。伺服器只會在其**文件根目錄**（*Document Root*，此處為 `/var/www`）中尋找。對照一下：如果伺服器完全沒有回應，或是以 `RST` 回應，問題就出在更底層——出在網路或服務本身（第 5.3.2 章）。
:::

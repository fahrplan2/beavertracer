# WLAN：沒有線路的網路

:::goal
**學習目標：** 你可以說明無線接取點如何將 WLAN 與有線網路連接起來，透過 SSID 讓裝置加入 WLAN，並說明為什麼 WLAN 必須加密。
:::

手機、平板和筆記型電腦大多已經沒有網路孔了——它們透過無線電波連線，也就是透過 **WLAN**（*Wireless LAN*，無線區域網路）。為了讓它們仍然能與接在網路線上的 PC 和伺服器通訊，需要一個能把無線與有線連接起來的裝置。

:::note
在現實中，WLAN 會受到訊號範圍、牆壁和干擾的影響。BeaverTracer 將這一點簡化了：所有使用相同 WLAN 名稱的裝置共用同一個無線網路——不論它們在工作區的什麼位置。
:::

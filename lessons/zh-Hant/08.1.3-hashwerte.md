# 雜湊值：資料的指紋

:::sim
url=/sims/lesson-8.1.3.btsim
:::

**雜湊函數**會把任意大小的資料——一個句子、一份文件，甚至一整部電影——計算成一串長度固定的短字元：**雜湊值**。它就像**指紋**一樣：相同的資料一定得到相同的雜湊值，不同的資料則得到不同的雜湊值。

目前常用的雜湊函數稱為 **SHA-256**。它的雜湊值長度固定為 256 位元，以十六進位表示就是 64 個字元。

## 實驗

在 **PC** 的 `/home` 資料夾中有三個檔案，內容是一份簡短的買賣合約。切換到 :fa-play: **執行**模式，在 **PC** 上開啟 :fa-terminal: **終端機**，然後輸入：

```
$ cd /home
$ cat vertrag.txt vertrag-kopie.txt vertrag-neu.txt
$ sha256sum vertrag.txt vertrag-kopie.txt vertrag-neu.txt
```

## 雜湊函數的特性

| 特性 | 意義 |
|---|---|
| **固定長度** | 無論資料多大，雜湊值的長度始終相同。 |
| **確定性** | 相同的資料一定得到相同的雜湊值。 |
| **雪崩效應** | 即使是最小的更動，也會產生完全不同的雜湊值。 |
| **單向函數** | 無法從雜湊值反推出原始資料。 |
| **抗碰撞性** | 實際上不可能找到兩個雜湊值相同的不同檔案。 |

雜湊函數**不是加密**：它沒有金鑰，也沒有解密。它的用途不同——確保**完整性**。

## 這有什麼用？

- **檢查下載檔案：**許多網站會在檔案旁附上它的 SHA-256 值。如果你下載的檔案的雜湊值與之相符，就表示檔案在傳輸途中沒有被更動。
- **儲存密碼：**好的網站不會儲存你的密碼，只會儲存密碼的雜湊值。登入時，系統會比對你輸入內容的雜湊值。即使資料庫被竊取，竊賊仍然不知道密碼。
- **數位簽章：**簽署時不需要對整份文件簽名，只需對它的雜湊值簽名——下一節會有更多說明。

:::tip 重點整理
**雜湊函數**（例如 **SHA-256**）會把任意資料計算成長度固定的**雜湊值**——也就是**指紋**。即使是最小的更動，也會產生完全不同的雜湊值，而且無法從雜湊值反推出資料。雜湊值用來確保資料的**完整性**。
:::

# POP3 還是 IMAP？

:::sim
url=/sims/lesson-6.3.btsim
:::

收取郵件有兩種協定。在這個模擬中，**Anna 使用 POP3**，**Ben 使用 IMAP**。

## 實驗

1. 在 :fa-play: **執行**模式下，從 **Ben** 寄一封郵件給 `anna@beaver-schule.de`。
2. 在 **Anna** 的 **E-Mail** 應用程式中點擊**擷取**。
3. 開啟 **Anna** 和 **Ben** 的追蹤記錄，並比較收取郵件時使用的指令。

:::quiz match
USER / PASS -> POP3：分兩個步驟以使用者名稱和密碼登入
RETR -> POP3：下載一封郵件
LOGIN -> IMAP：以使用者名稱和密碼登入
SELECT INBOX -> IMAP：在伺服器上開啟資料夾
:::

:::evaluate
檢查配對
:::

## 差異

| | POP3 | IMAP |
|---|---|---|
| 連接埠 | 110 | 143 |
| 基本概念 | **下載**郵件——之後通常會刪除伺服器上的郵件 | 郵件**保留在伺服器上**，並在伺服器上管理 |
| 資料夾、已讀／未讀 | 僅存在於自己的裝置上 | 存在於伺服器上——各處皆相同 |
| 多部裝置（手機、筆記型電腦） | 不方便：每部裝置的狀態都不同 | 理想：所有裝置看到的是同一個信箱 |

:::note
即使使用 POP3，BeaverTracer 中的電子郵件程式也會把郵件留在伺服器上。真正的郵件程式在下載後通常會將其刪除，或只讓郵件在伺服器上保留一段時間。
:::

:::quiz mc
Lena 在手機、平板和學校的筆記型電腦上讀取她的郵件。她應該使用什麼？
- [ ] POP3，因為它比較簡單
- [x] IMAP，因為所有裝置看到的都是伺服器上的同一個信箱
- [ ] SMTP，因為它是用來收取郵件的
:::

:::evaluate
檢查答案
:::

:::tip 重點整理
**POP3** 會把郵件從伺服器下載到**一部**裝置上。**IMAP** 則在**伺服器上**管理信箱——資料夾和已讀狀態會同時套用到所有裝置。兩者都只用於**收取**郵件；寄送郵件一律使用 **SMTP**。
:::

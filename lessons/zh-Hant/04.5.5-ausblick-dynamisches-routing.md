# 展望：動態路由

在專案中，你為四個據點手動輸入了十二條路由。大型企業網路有數百台路由器，網際網路則有數萬台——而且隨時都有某處的線路中斷，或是新增了新的線路。這已經無法再靠手動完成了。

因此，路由器通常會自動彼此交換路由。這要靠**路由協定**來完成。這種方式稱為**動態路由**——與之相對的是**靜態路由**，也就是所有路由都由人手動輸入。

最常見的路由協定：

| 協定 | 原理 | 典型應用 |
|---|---|---|
| **RIP**（*Routing Information Protocol*） | 每台路由器定期告訴相鄰的路由器，它能到達哪些網路，以及這些網路距離自己幾台路由器（*跳數*，Hops）。 | 小型網路、教學範例 |
| **OSPF**（*Open Shortest Path First*） | 每台路由器都掌握整個網路的完整拓樸，並據此自行計算最短路徑。 | 企業網路 |
| **BGP**（*Border Gateway Protocol*） | 大型網路營運商（例如網際網路服務供應商）彼此告知自己能到達哪些網路。 | 供應商之間的網際網路 |

:::quiz match
RIP -> 路由器告訴相鄰的路由器，它距離某個網路有幾跳
OSPF -> 每台路由器都掌握整個網路拓樸，並計算出最短路徑
BGP -> 連接大型網際網路服務供應商的網路
:::

:::tip 重點整理
**靜態路由**由管理員手動輸入所有路由。**動態路由**則是路由器藉助 RIP、OSPF 或 BGP 等**路由協定**自動交換路由——並且在連線中斷時自行調整。
:::

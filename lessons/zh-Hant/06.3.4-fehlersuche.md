# 疑難排解：郵件沒有送達

:::sim
url=/sims/lesson-6.3.4.btsim
:::

Anna 回報：「我沒辦法寄郵件給 Ben！」正確的設定*應該*是這樣：

| 項目 | 應有設定 |
|---|---|
| Anna 的寄件匣（SMTP） | `mail.beaver-schule.de`，連接埠 `25` |
| `biber-mail.de` 的 MX 記錄 | `mail.biber-mail.de`（優先順序 10） |

找出錯誤並加以修正。接著寄一封郵件給 `ben@biber-mail.de`，任務會檢查郵件是否已送達 Ben 的信箱。（郵件伺服器之間的轉送可能需要幾秒鐘。）

<details>
<summary>提示 1：Anna 的電子郵件程式說了什麼？</summary>

試著寄出一封郵件，並查看 **Protokoll** 索引標籤。伺服器回應了什麼？聽起來像是 SMTP 嗎？
</details>

<details>
<summary>提示 2：郵件以錯誤訊息的形式退回來了？</summary>

在 Anna 那裡收取郵件，並閱讀來自 `MAILER-DAEMON` 的訊息。投遞是因為什麼而失敗？請在 Anna 的 PC 上用 `nslookup -type=MX biber-mail.de` 檢查 DNS 伺服器是否知道負責的郵件伺服器。
</details>

<details>
<summary>提示 3：這要在哪裡設定？</summary>

寄件匣要在 Anna 的 **E-Mail** 應用程式中的 **Einstellungen** 下設定。MX 記錄可以在 **DNS-Server** 的 **MX** 索引標籤中找到。
</details>

:::task
title: 郵件送達了嗎？
檢查 Biber 郵件伺服器上 Ben 的信箱中是否有郵件。
check: fileExists(5, "/var/mail/ben.mbox")
:::

## 剛才出了什麼問題？

:::quiz multi
下列哪些敘述正確？
- [x] Anna 的寄件匣指向連接埠 110，那裡回應的是 POP3 服務，而不是 SMTP
- [x] `biber-mail.de` 缺少 MX 記錄，因此 Mailserver Schule 找不到負責的郵件伺服器
- [x] 無法投遞的郵件以錯誤訊息的形式從 `MAILER-DAEMON` 退了回來
- [ ] Ben 的密碼錯誤
:::

:::evaluate
檢查答案
:::

:::tip 重點整理
典型的電子郵件錯誤：電子郵件程式中的**伺服器或連接埠**設定錯誤（SMTP 使用連接埠 25，POP3 使用 110，IMAP 使用 143），以及 DNS 中缺少或錯誤的 **MX 記錄**。如果郵件伺服器無法投遞郵件，會把郵件連同錯誤訊息退回給發送端（**退信**，Bounce）。
:::

# 查看憑證

:::sim
url=/sims/lesson-8.2.1.btsim
:::

在工作區中,你會看到 **Client-PC**、一台 **DNS-Server** 以及學校的網頁伺服器 `www.beaver-schule.de`。這台網頁伺服器也透過 **HTTPS** 提供它的網頁。

## 瀏覽器中的鎖頭

1. 切換到 :fa-play: **執行**模式,點選 **Client-PC**,並開啟 :fa-globe: **瀏覽器**。
2. 開啟 `https://www.beaver-schule.de/` — 請注意是 **https**。
3. 網址左側會出現一個**鎖頭**。點選它。

:::quiz short
這張憑證是為哪個名稱簽發的(主體,不含 `CN=`)?
= www.beaver-schule.de
:::

:::quiz short
這張憑證是由誰簽發的(簽發者,不含 `CN=`)?
= Biber Root CA
:::

:::evaluate
檢查答案
:::

## 為什麼 Client-PC 信任這張憑證?

在 **Client-PC** 上開啟 :fa-shield-halved: **Zertifikatverwaltung**,並切換到 **Vertrauenswürdige CAs** 索引標籤。

:::quiz mc
你在那裡找到什麼?
- [x] **Biber Root CA** 的憑證
- [ ] `www.beaver-schule.de` 的憑證
- [ ] 沒有任何項目
:::

:::quiz mc
要如何看出 Biber Root CA 是一個根 CA?
- [x] 它是**自我簽署**的:主體與簽發者相同
- [ ] 它的名稱以「CA」結尾
- [ ] 它沒有公開金鑰
:::

:::quiz mc
在 Client-PC 的 **Privater Schlüssel** 下顯示的是「是」還是「否」?
- [ ] 是 — 用戶端需要 CA 的私密金鑰來驗證簽章
- [x] 否 — 驗證只需要公開金鑰;私密金鑰只有 CA 持有
:::

:::evaluate
檢查答案
:::

## 另一端:網頁伺服器

現在在網頁伺服器 **www.beaver-schule.de** 上開啟 :fa-shield-halved: **Zertifikatverwaltung**(**Meine Zertifikate** 索引標籤),並查看它的憑證。

:::quiz multi
下列關於網頁伺服器上的憑證,哪些說法正確?
- [x] 在 **Privater Schlüssel** 下顯示「是」 — 伺服器在連線建立時需要它
- [x] **憑證鏈**為 `www.beaver-schule.de ← Biber Root CA`
- [x] **指紋**與瀏覽器鎖頭視窗中顯示的相同
- [ ] 它是自我簽署的
:::

:::evaluate
檢查答案
:::

:::note
**指紋**是對憑證計算出的雜湊值。藉由它可以快速比較兩張憑證 — 完全不需要逐一檢查所有欄位。
:::

:::tip 重點整理
**網頁伺服器**擁有自己的憑證,**並持有私密金鑰**。**用戶端**只知道**根 CA 的憑證**(沒有私密金鑰) — 這已足以讓它驗證伺服器憑證上的簽章。在瀏覽器中點選**鎖頭**,就能看到主體、簽發者、指紋和有效期限。
:::

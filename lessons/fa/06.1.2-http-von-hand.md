# HTTP به‌صورت دستی

:::sim
url=/sims/lesson-6.1.btsim
:::

اگر HTTP متن ساده باشد، آیا می‌شود بدون هیچ مرورگری خودمان مستقیم با یک وب‌سرور صحبت کرد؟ بله: با `telnet` یک اتصال TCP به هر پورت دلخواه برقرار می‌کنی و متن را خودت تایپ می‌کنی.

## آزمایش

1. به حالت :fa-play: **اجرا** برو و روی **Client-PC** :fa-terminal: **ترمینال** را باز کن.
2. به پورت ۸۰ سرور متصل شو:
   ```
   $ telnet 192.168.0.20 80
   ```
3. درخواست را خط به خط تایپ کن و آن را با یک **خط خالی** تمام کن (فقط یک بار دیگر **Enter** را بزن):
   ```
   GET /kontakt.html HTTP/1.1
   Host: 192.168.0.20

   ```

سرور با یک خط وضعیت، هدرها و صفحه تماس پاسخ می‌دهد — به‌صورت متن، دقیقاً همان‌طور که مرورگر هم آن را دریافت می‌کند.

:::quiz mc
سرور از کجا می‌فهمد که درخواست تو تمام شده است؟
- [ ] از یک دستور ویژه به نام `END`
- [x] از خط خالی
- [ ] بعد از گذشت زمانی مشخص
:::

:::quiz short
در پاسخ، هدر `Content-Type` چه مقداری دارد؟ (فقط بخش اول قبل از `;`)
= text/html
:::

:::evaluate
بررسی پاسخ‌ها
:::

## ایجاد خطا به‌صورت عمدی

ابزار راحت‌تر `curl` است: درخواست را به‌جای تو می‌فرستد. با گزینه `-v` (*verbose*، یعنی مفصل) همه چیزهایی را که رد و بدل می‌شود نشان می‌دهد — خطوطی که با `>` شروع می‌شوند را `curl` فرستاده است و خطوطی که با `<` شروع می‌شوند از سرور آمده‌اند.

امتحان کن:

```
$ curl -v http://192.168.0.20/gibtsnicht.html
$ curl -X POST -d name=Anna http://192.168.0.20/
```

:::quiz short
برای `/gibtsnicht.html` چه کد وضعیتی دریافت می‌کنی؟
= 404
:::

:::quiz short
و برای درخواستی که با متد `POST` فرستاده شده است؟
= 405
:::

:::evaluate
بررسی پاسخ‌ها
:::

:::note
وب‌سرور در BeaverTracer فقط می‌تواند فایل‌ها را تحویل دهد — به همین دلیل فقط `GET` و `HEAD` را مجاز می‌داند. وب‌سرورهای واقعی با `POST` مثلاً فرم‌ها را دریافت می‌کنند و داده‌ها را به یک برنامه می‌سپارند.
:::

:::tip نکته کلیدی
بسیاری از پروتکل‌های لایه کاربرد **متنی** هستند — HTTP و همچنین SMTP، POP3 و IMAP. به همین دلیل می‌توان آن‌ها را با `telnet` به‌صورت دستی «صحبت» کرد و در ردیاب دنبال کرد. این برای عیب‌یابی مفید است — اما یک مشکل امنیتی هم هست: هر کسی که ترافیک را ضبط کند، می‌تواند همه چیز را بخواند. اینکه رمزنگاری (HTTPS) چگونه کمک می‌کند، در فصل ۸ یاد می‌گیری.
:::

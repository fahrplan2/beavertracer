# POP3 یا IMAP؟

:::sim
url=/sims/lesson-6.3.btsim
:::

برای دریافت ایمیل از سرور دو پروتکل وجود دارد. در این شبیه‌سازی **Anna از POP3** و **Ben از IMAP** استفاده می‌کند.

## آزمایش

1. در حالت :fa-play: **اجرا** یک ایمیل از **Ben** به `anna@beaver-schule.de` بفرست.
2. در **Anna** در برنامه **E-Mail** روی **دریافت** کلیک کن.
3. ردگیری‌ها (Traces) را برای **Anna** و برای **Ben** باز کن و دستورهای مربوط به دریافت ایمیل را با هم مقایسه کن.

:::quiz match
USER / PASS -> POP3: ورود با نام کاربری و گذرواژه در دو مرحله
RETR -> POP3: دانلود یک پیام
LOGIN -> IMAP: ورود با نام کاربری و گذرواژه
SELECT INBOX -> IMAP: باز کردن یک پوشه روی سرور
:::

## تفاوت

| | POP3 | IMAP |
|---|---|---|
| پورت | 110 | 143 |
| ایده اصلی | ایمیل‌ها **دانلود می‌شوند** — سپس معمولاً روی سرور حذف می‌شوند | ایمیل‌ها **روی سرور می‌مانند** و همان‌جا مدیریت می‌شوند |
| پوشه‌ها، خوانده‌شده/خوانده‌نشده | فقط روی دستگاه خودت | روی سرور — همه‌جا یکسان |
| چند دستگاه (گوشی، لپ‌تاپ) | نامناسب: هر دستگاه وضعیت متفاوتی دارد | ایده‌آل: همه دستگاه‌ها یک صندوق پست یکسان را می‌بینند |

:::note
برنامه ایمیل در BeaverTracer ایمیل‌ها را حتی با POP3 هم روی سرور نگه می‌دارد. برنامه‌های واقعی اغلب آن‌ها را پس از دانلود حذف می‌کنند — یا فقط مدتی نگه می‌دارند.
:::

:::tip نکته کلیدی
**POP3** ایمیل‌ها را از سرور روی **یک** دستگاه دانلود می‌کند. **IMAP** صندوق پست را **روی سرور** مدیریت می‌کند — با پوشه‌ها و وضعیت خوانده‌شدن برای همه دستگاه‌ها به‌طور همزمان. هر دو فقط برای **دریافت** هستند؛ ارسال همیشه با **SMTP** انجام می‌شود.
:::

# به‌کارگیری مدل‌ها

پروتکل‌های آزمایشِ ابتدای فصل را به لایهٔ OSI مربوط به خودشان وصل کن:

:::quiz match
Ethernet -> لایه ۲ — پیوند داده
IPv4 -> لایه ۳ — شبکه
TCP -> لایه ۴ — انتقال
HTTP -> لایه ۷ — کاربرد
:::

:::evaluate
بررسی تطبیق‌ها
:::

و در پایان، نام واحدهای داده:

:::quiz match
Frame -> لایه ۲ — پیوند داده
بسته -> لایه ۳ — شبکه
Segment -> لایه ۴ — انتقال
:::

:::evaluate
بررسی تطبیق‌ها
:::

با این کار ابزار لازم را داری تا از این به بعد پروتکل‌ها را درست دسته‌بندی کنی. از فصل بعد، لایه‌ها را یکی‌یکی و به ترتیب بررسی می‌کنیم — با لایهٔ ۲ شروع می‌کنیم و با این پرسش که یک سوییچ در واقع از کجا می‌داند باید یک بسته را به کدام سمت ارسال کند.

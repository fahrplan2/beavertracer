# چرا یک شبکه کافی نیست

:::sim
url=/sims/lesson-4.1.btsim
:::

روی فضای کار دو شبکه کوچک شرکتی می‌بینی: **Firma A** با Anna (`192.168.0.10`) و Ben (`192.168.0.11`) و **Firma B** با Clara (`172.16.0.10`) و David (`172.16.0.11`). دو سوئیچ حتی مستقیماً با یک کابل به هم وصل شده‌اند.

## یک پینگ در شبکه خودی

1. به حالت :fa-play: **اجرا** برو، روی **Anna** :fa-terminal: **ترمینال** را باز کن و Ben را پینگ کن:
   ```
   $ ping 192.168.0.11
   ```
2. به حالت :fa-magnifying-glass: **ردیابی** برو، یک Trace برای **Anna** باز کن و روی یک `Echo (ping) request` کلیک کن.
3. در درخت پروتکل، خط **Internet Protocol Version 4** را باز کن. این بخش IP بسته است — همان بخشی که موضوع این فصل است.

:::quiz match
Source Address -> آدرس IP فرستنده
Destination Address -> آدرس IP گیرنده
Time to Live -> بسته هنوز از چند مسیریاب می‌تواند عبور کند
Protocol -> چه پروتکلی درون بسته است (اینجا ICMP، یعنی همان پینگ)
:::

## یک پینگ به شبکه دیگر

به حالت :fa-play: **اجرا** برگرد و از **Anna** برای Clara پینگ بفرست (`ping 172.16.0.10`). سپس Trace مربوط به Anna را یک بار دیگر ببین.

:::quiz mc
چه اتفاقی می‌افتد؟
- [ ] پینگ موفق می‌شود — سوئیچ‌ها که به هم وصل‌اند
- [x] هیچ پینگی نمی‌رسد و در Trace مربوط به Anna حتی یک بسته به سمت Clara دیده نمی‌شود — حتی یک درخواست ARP هم نه
- [ ] Anna یک درخواست ARP می‌فرستد، اما Clara پاسخ نمی‌دهد
:::

:::quiz mc
چرا Anna اصلاً چیزی ارسال نمی‌کند؟
- [ ] کابل بین سوئیچ‌ها خراب است
- [ ] Clara خاموش است
- [x] Anna از روی آدرس IP مربوط به Clara تشخیص می‌دهد که Clara در شبکه دیگری قرار دارد — و راهی به آنجا نمی‌شناسد
:::

## پشت صحنه چه خبر است

آدرس IP تقریباً مثل نشانی پستی کار می‌کند: یک بخش مشخص می‌کند دستگاه در کدام **شبکه** قرار دارد (مثل خیابان) و بخش دیگر مشخص می‌کند منظور کدام **دستگاه** در آن شبکه است (مثل پلاک خانه). Anna در شبکه `192.168.0…` است و Clara در شبکه `172.16.0…` — دو «خیابان» متفاوت.

یک کامپیوتر بسته‌ها را به دستگاه‌های *شبکه خودش* مستقیم می‌فرستد (از طریق ARP و سوئیچ، همان‌طور که می‌شناسی). برای یک شبکه *بیگانه* به دستگاهی نیاز دارد که شبکه‌ها را به هم وصل کند و بسته‌ها را جلو ببرد: یک **مسیریاب**. اینجا هنوز مسیریابی وجود ندارد — برای همین کابل بین سوئیچ‌ها هم کمکی نمی‌کند.

:::tip نکته کلیدی
**پروتکل اینترنت** (**IP**) در لایه ۳ تضمین می‌کند که بسته‌ها حتی بین شبکه‌های مختلف هم برسند. یک **آدرس IP** از یک **بخش شبکه** (کدام شبکه؟) و یک **بخش میزبان** (کدام دستگاه؟) تشکیل شده است. دستگاه‌های یک شبکه مستقیماً به هم می‌رسند — برای شبکه‌های دیگر به یک **مسیریاب** نیاز است.
:::

با این کار دو پرسش پیش می‌آید که در بخش‌های بعدی به آن‌ها می‌پردازیم: کامپیوتر از کجا می‌داند بخش شبکه *دقیقاً کجای* آدرس تمام می‌شود؟ و مسیریاب چگونه کار می‌کند؟

# مشاهده یک گواهی

:::sim
url=/sims/lesson-8.2.1.btsim
:::

در فضای کار، **Client-PC**، یک **DNS-Server** و وب‌سرور مدرسه یعنی `www.beaver-schule.de` را می‌بینی. وب‌سرور صفحه‌های خود را از طریق **HTTPS** هم ارائه می‌دهد.

## قفل در مرورگر

1. به :fa-play: حالت **اجرا** برو، روی **Client-PC** کلیک کن و :fa-globe: **مرورگر** را باز کن.
2. آدرس `https://www.beaver-schule.de/` را باز کن — به **https** دقت کن.
3. در سمت چپ آدرس یک **قفل** ظاهر می‌شود. روی آن کلیک کن.

:::quiz short
گواهی برای چه نامی صادر شده است (Betreff بدون `CN=`)؟
= www.beaver-schule.de
:::

:::quiz short
چه کسی گواهی را صادر کرده است (Aussteller بدون `CN=`)؟
= Biber Root CA
:::

:::evaluate
بررسی پاسخ‌ها
:::

## چرا Client-PC به گواهی اعتماد می‌کند؟

در **Client-PC** :fa-shield-halved: **Zertifikatverwaltung** را باز کن و به زبانه **Vertrauenswürdige CAs** برو.

:::quiz mc
آنجا چه چیزی پیدا می‌کنی؟
- [x] گواهی **Biber Root CA**
- [ ] گواهی `www.beaver-schule.de`
- [ ] هیچ موردی وجود ندارد
:::

:::quiz mc
از کجا می‌توان فهمید که Biber Root CA یک Root-CA است؟
- [x] این گواهی **خودامضا** است: Betreff و Aussteller یکسان هستند
- [ ] نام آن به «CA» ختم می‌شود
- [ ] کلید عمومی ندارد
:::

:::quiz mc
در Client-PC زیر **Privater Schlüssel** «Ja» نوشته شده یا «Nein»؟
- [ ] Ja — کلاینت برای بررسی امضاها به کلید خصوصی CA نیاز دارد
- [x] Nein — برای بررسی، کلید عمومی کافی است؛ کلید خصوصی فقط نزد CA است
:::

:::evaluate
بررسی پاسخ‌ها
:::

## طرف مقابل: وب‌سرور

حالا در وب‌سرور **www.beaver-schule.de** :fa-shield-halved: **Zertifikatverwaltung** را باز کن (زبانه **Meine Zertifikate**) و گواهی آن را ببین.

:::quiz multi
کدام مورد درباره گواهی روی وب‌سرور درست است؟
- [x] زیر **Privater Schlüssel** «Ja» نوشته شده است — سرور برای برقراری اتصال به آن نیاز دارد
- [x] **زنجیره** به این صورت است: `www.beaver-schule.de ← Biber Root CA`
- [x] **اثر انگشت** با آنچه در پنجره قفل مرورگر دیده می‌شود یکسان است
- [ ] خودامضا است
:::

:::evaluate
بررسی پاسخ‌ها
:::

:::note
**اثر انگشت** (Fingerabdruck) یک مقدار هش از گواهی است. با آن می‌توان دو گواهی را سریع مقایسه کرد — بدون اینکه لازم باشد تک‌تک فیلدها را بررسی کنی.
:::

:::tip نکته کلیدی
**وب‌سرور** گواهی خود را **همراه با کلید خصوصی** دارد. **کلاینت** فقط **گواهی Root-CA** را می‌شناسد (بدون کلید خصوصی) — همین برای او کافی است تا امضای روی گواهی سرور را بررسی کند. اگر در مرورگر روی **قفل** کلیک کنی، Betreff، Aussteller، اثر انگشت و مدت اعتبار را می‌بینی.
:::

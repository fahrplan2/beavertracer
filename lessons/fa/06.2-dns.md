# DNS: نام به‌جای عدد

:::goal
**هدف یادگیری:** می‌توانی توضیح بدهی DNS چگونه نام‌ها را به آدرس‌های IP ترجمه می‌کند، نام‌ها چگونه به‌صورت سلسله‌مراتبی سازمان‌دهی شده‌اند، چطور خودت یک رکورد بسازی و خطاهای رایج DNS را پیدا کنی.
:::

:::sim
url=/sims/lesson-6.2.btsim
:::

تقریباً هیچ‌کس نمی‌تواند آدرس‌های IP را به خاطر بسپارد، اما نام‌هایی مانند `www.beaver-schule.de` را چرا. این ترجمه را **سیستم نام دامنه** (**DNS**) انجام می‌دهد؛ چیزی شبیه دفترچه تلفن جهانی اینترنت.

در فضای کار حالا یک شبکه‌ی کمی بزرگ‌تر قرار دارد: علاوه بر **Client-PC** و **Webserver**، چهار **سرور DNS** هم وجود دارد. اینکه چرا این‌همه سرور لازم است، دو صفحه بعد می‌بینی.

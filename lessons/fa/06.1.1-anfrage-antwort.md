پس یک صفحه وب اغلب از فایل‌های زیادی تشکیل می‌شود: متن، شیوه‌نامه‌ها، تصاویر. مرورگر برای هر کدام یک درخواست جداگانه می‌فرستد.

## یک درخواست چه شکلی دارد

در Trace روی بسته `GET / HTTP/1.1` کلیک کن و **Hypertext Transfer Protocol** را باز کن. یک درخواست HTTP متن ساده است:

```
GET / HTTP/1.1              ← Methode, Pfad, Version
Host: 192.168.0.20          ← Header: zusätzliche Angaben
…
                            ← Leerzeile: Ende der Anfrage
```

پاسخ سرور هم همین ساختار را دارد — با یک خط وضعیت، هدرها، یک خط خالی و سپس خود فایل:

```
HTTP/1.1 200 OK             ← Version, Statuscode, Text
Content-Type: text/html     ← Header: Art der Datei
Content-Length: 301         ← Header: Größe in Byte
                            ← Leerzeile
<!doctype html> …           ← die Datei selbst
```

:::seq
mode: text
Client-PC -> Server: GET / | درخواست HTTP
Server -> Client-PC: 200 OK | index.html
Client-PC -> Server: GET /style.css | درخواست HTTP
Server -> Client-PC: 200 OK | style.css
:::

## متدها و کدهای وضعیت

**متد** مشخص می‌کند که کلاینت چه می‌خواهد:

| متد | معنی |
|---|---|
| **GET** | دریافت یک فایل |
| **POST** | ارسال داده به سرور، مثلاً یک فرم پرشده |
| **HEAD** | دریافت فقط هدرها، بدون فایل |

**کد وضعیت** مشخص می‌کند که کار چگونه پیش رفته است. رقم اول نوع پاسخ را نشان می‌دهد:

| کد | متن | معنی |
|---|---|---|
| **200** | OK | همه‌چیز درست است |
| **301** | Moved Permanently | صفحه برای همیشه جابه‌جا شده است |
| **404** | Not Found | چنین فایلی وجود ندارد |
| **405** | Method Not Allowed | این متد اینجا مجاز نیست |
| **500** | Internal Server Error | خطا در سرور |

`2xx` یعنی موفقیت، `3xx` یعنی هدایت به آدرس دیگر، `4xx` یعنی خطای کلاینت (درخواست نادرست) و `5xx` یعنی خطای سرور.

:::tip نکته کلیدی
**HTTP** بر اساس **اصل درخواست و پاسخ** کار می‌کند: کلاینت یک **درخواست** می‌فرستد (متدی مانند `GET`، مسیر، هدرها) و سرور با یک **کد وضعیت** (مثلاً `200 OK` یا `404 Not Found`)، هدرها و فایل پاسخ می‌دهد. برای هر فایل از یک صفحه وب، یک درخواست جداگانه وجود دارد.
:::

:::quiz match
200 -> همه‌چیز درست است
301 -> صفحه برای همیشه جابه‌جا شده است
404 -> فایل درخواست‌شده وجود ندارد
500 -> در سرور خطایی رخ داده است
:::

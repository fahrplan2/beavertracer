# یک اتصال از ابتدا تا انتها

:::sim
url=/sims/lesson-5.1.btsim
:::

روی **Server** سرویس بازتاب (Echo) روی پورت `5000` اجرا می‌شود: هر پیامی را بلافاصله پس می‌فرستد. با **کلاینت TCP ساده** می‌توانی یک اتصال را گام‌به‌گام کنترل کنی — هر دکمه یک فاز است.

## آزمایش

1. به حالت :fa-play: **اجرا** برو، روی **Client-PC** کلیک کن و **کلاینت TCP ساده** را باز کن.
2. در قسمت **Host** مقدار `192.168.0.20` و در قسمت **Port** مقدار `5000` را وارد کن.
3. روی **اتصال** کلیک کن.
4. عبارت `Hello World` را در فیلد پیام بنویس و روی **ارسال** کلیک کن. بلافاصله بعد از آن در پنجره گفتگو بازتاب سرور را می‌بینی.
5. روی **قطع اتصال** کلیک کن.
6. به حالت :fa-magnifying-glass: **ردیابی** برو و با **+** یک Trace برای **Client-PC** و درگاه `eth0` باز کن.

:::note
دو بسته ARP ابتدای ردیابی را از فصل ۱ می‌شناسی. در ستون **Info** بسته‌های TCP ابتدا `49152 → 5000` آمده است (از کدام پورت به کدام پورت)، سپس **پرچم‌ها** (Flags) داخل کروشه و بعد از آن اعدادی مانند `Seq=`، `Ack=` و `Len=`. به این اعداد از صفحه ۵.۲.۳ به بعد پرداخته می‌شود — اینجا فقط به پرچم‌ها و `Len` دقت می‌کنی.
:::

## فاز ۱: اتصال

:::quiz short
پس از کلیک روی **اتصال** — پیش از ارسال پیامت — چند بسته TCP رد و بدل شد؟
= 3
= سه
:::

:::quiz mc
چه کسی اولین بسته با `[SYN]` را می‌فرستد؟
- [x] Client-PC
- [ ] Server
:::

:::quiz mc
سرور با کدام پرچم‌ها به آن پاسخ می‌دهد؟
- [ ] `[SYN]`
- [x] `[SYN, ACK]`
- [ ] `[ACK]`
- [ ] `[FIN, ACK]`
:::

## فاز ۲: ارسال

`Len` مشخص می‌کند یک بسته چند بایت داده مفید (Payload) حمل می‌کند.

:::quiz short
بسته‌ای که پیام تو را حمل می‌کند چند بایت دارد (`Len`)؟
= 13
:::

:::note
`Hello World` فقط ۱۱ نویسه دارد. اما کلاینت TCP یک پایان‌خط (۲ بایت، `\r\n`) به آن اضافه می‌کند — بسیاری از پروتکل‌های اینترنتی مانند SMTP یا HTTP این را انتظار دارند.
:::

:::quiz mc
سرور بلافاصله بعد از پیام تو — حتی پیش از بازتاب — چه چیزی پس می‌فرستد؟
- [x] یک بسته با `[ACK]` و `Len=0` — یک تصدیق بدون داده
- [ ] هیچ چیز
- [ ] یک `[SYN]` جدید
:::

:::

- [ ] «خطایی رخ داده است»
- [ ] «داده جدید می‌رسد»

## این چهار وظیفه کجا هستند؟

مشخص کن وظایف بخش ۵.۱ را در Trace کجا دوباره پیدا می‌کنی:

:::quiz match
برقراری اتصال -> سه بسته [SYN]، [SYN, ACK] و [ACK]
انتقال قابل اعتماد -> بسته‌هایی با [ACK] و Len=0 که دریافت را تأیید می‌کنند
قطع اتصال -> بسته‌های دارای FIN و تصدیق‌های آن‌ها
چندسازی -> شماره پورت‌های 49152 → 5000 پیش از کروشه‌ها
:::

# UDP: سادگی بسیار زیاد

:::goal
**هدف یادگیری:** می‌توانی UDP را با TCP مقایسه کنی و توضیح بدهی که UDP برای چه کاربردهایی انتخاب بهتری است.
:::

:::sim
url=/sims/lesson-5.5.btsim
:::

TCP کارهای زیادی انجام می‌دهد — برقراری اتصال، تصدیق‌ها، ارسال مجدد و حفظ ترتیب. اما این کارها زمان و بسته‌های اضافی هزینه دارند. دومین پروتکل مهم لایه انتقال تقریباً از همهٔ این‌ها صرف‌نظر می‌کند: **User Datagram Protocol** (**UDP**). بسته‌های آن **دیتاگرام** نامیده می‌شوند.

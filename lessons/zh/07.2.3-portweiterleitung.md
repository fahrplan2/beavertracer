# 从外到内：端口转发

:::sim
url=/sims/lesson-7.2.3.btsim
:::

家庭网络中现在有了一台自己的**Heim-Webserver**（`192.168.178.10`）。Clara 想在外出时访问这个网页——她的笔记本电脑 **Clara** 位于右侧的互联网上。

## 问题

1. 切换到 :fa-play: **运行**模式，在 **Clara** 的 :fa-globe: **浏览器**中访问 `http://203.0.113.2/`——这是家庭网络的公网地址。
2. 浏览器一直在等待。几秒钟后，点击**停止**。
3. 在 :fa-magnifying-glass: **追踪**模式下，为 **Heimrouter** 的 `wan0` 接口打开一个追踪。

:::quiz mc
Clara 的连接建立（发往 80 端口的 `[SYN]`）会怎么样？
- [x] 它到达了 Heimrouter——但路由器不转发它，也不作回应
- [ ] 它到达了 Heim-Webserver，后者以 RST 作为回应
- [ ] 它根本没有到达 Heimrouter
:::

:::evaluate
检查答案
:::

对于从外部进来的数据包，NAT 表中没有对应的条目：家庭网络里没有任何设备发起过这个连接。Heimrouter 不知道该把它发给哪台设备，于是将其丢弃。

## 设置端口转发

通过**端口转发**（有些路由器中称为*端口开放*），你可以规定：凡是到达某个特定 WAN 端口的数据，都转交给家庭网络中的某台特定设备。

1. 点击 **Heimrouter**，打开 **Port FW** 标签页。
2. 添加一条规则：协议 `TCP`，WAN 端口 `80`，LAN IP `192.168.178.10`，LAN 端口 `80`，然后点击 **+ 添加**。
3. 在 **Clara** 上再次访问 `http://203.0.113.2/`。

:::task
title: 能否从外部访问 Heim-Webserver？
检查 Clara 能否从互联网与家庭网络公网地址的 80 端口建立连接。为此，模拟必须在运行模式下运行。
check: tcpOpen(12, "203.0.113.2", 80)
:::

:::warning
端口转发会向内部打开一个缺口：互联网上的任何人都可以访问其后的设备——包括会自动扫描开放端口的攻击者。因此只转发真正必要的内容，并让设备保持最新状态。更多内容见第 9 章（防火墙）。
:::

:::tip 要点
从外部无法向 NAT 后面的设备发起连接——路由器不知道该把数据包送到哪里。**端口转发**规定：到达某个特定 **WAN 端口**的数据包，会被转交给某个特定的 **LAN IP**（及其 LAN 端口）。这样，家庭网络中的服务器就可以从互联网访问了。
:::

# 设置 DHCP 服务器

:::sim
url=/sims/lesson-6.4.2.btsim
:::

这次 DHCP 服务器还没有设置好。由你来决定它分发哪些设置：

| 设置 | 值 |
|---|---|
| 地址范围 | `192.168.0.100` 至 `192.168.0.120` |
| 网关 | `192.168.0.1` |
| DNS 服务器 | `192.168.0.53` |

1. 切换到 :fa-play: **运行**模式，点击 **DHCP-Server**，并打开 **DHCP 服务器**应用。
2. 填入**范围起始**、**范围结束**、**Gateway** 和 **DNS-Server**，点击**保存**，然后点击**启动**。
3. 在 **Laptop 1** 和 **Laptop 2** 的 :fa-gear: **IP设置**中，将模式设为 **DHCP**，并分别点击**应用**。
4. 在 DHCP 服务器的 **Leases** 标签页中查看，谁获得了哪个地址。

:::note
选择地址范围时，要避免它与固定地址发生冲突：服务器、路由器和打印机通常使用位于 DHCP 范围之外的固定地址——例如这里的 DHCP 服务器本身使用 `192.168.0.2`。
:::

:::task
title: DHCP 设置好了吗？
检查两台笔记本电脑是否都从 DHCP 范围中获得了地址，并且能够访问 DHCP 服务器。为此，模拟必须在运行模式下运行。
check: ip(3, "192.168.0.96/27")
check: ip(4, "192.168.0.96/27")
check: pingOk(3, 2)
check: pingOk(4, 2)
:::

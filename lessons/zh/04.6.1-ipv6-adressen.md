# 读写 IPv6 地址

## 十六进制

128 个 0 和 1 没人读得懂——写成 16 组十进制数也好不了多少。因此 IPv6 地址采用**十六进制**（简称 *hex*）来书写。它有 **16 个数字**：0 到 9，再加上 a 到 f，分别表示 10 到 15。

最大的优点是：一个十六进制数字恰好对应 **4 位**。

| 十进制 | 十六进制 | 二进制 | | 十进制 | 十六进制 | 二进制 |
|---|---|---|---|---|---|---|
| 0 | 0 | 0000 | | 8 | 8 | 1000 |
| 1 | 1 | 0001 | | 9 | 9 | 1001 |
| 2 | 2 | 0010 | | 10 | a | 1010 |
| 3 | 3 | 0011 | | 11 | b | 1011 |
| 4 | 4 | 0100 | | 12 | c | 1100 |
| 5 | 5 | 0101 | | 13 | d | 1101 |
| 6 | 6 | 0110 | | 14 | e | 1110 |
| 7 | 7 | 0111 | | 15 | f | 1111 |

因此一个字节（8 位）恰好是两个十六进制数字：`11111111` = `ff` = 255。其实你已经见过了：像 `aa:28:39:e2:41:82` 这样的 MAC 地址也是用十六进制书写的。

## IPv6 地址的结构

一个 IPv6 地址由**八个块**组成，每块 **16 位**（即四个十六进制数字），块与块之间用冒号分隔：

```
2001:0db8:0000:0000:0000:0000:0000:0001
```

和 IPv4 一样，IPv6 地址也分为网络部分和主机部分。在 IPv6 中，网络部分称为**前缀**，主机部分称为**接口 ID**。前缀几乎总是 **64 位**长（`/64`）——也就是前四个块：

<pre class="bits-block">
[[n|2001:0db8:0001:0000]]:[[h|a828:39ff:fee2:4182]]
[[n|前缀（64 位）]]      [[h|接口 ID（64 位）]]
</pre>

## 简写形式

由于 IPv6 地址很长，可以对其进行缩写。为此有两条规则：

1. **块中的前导零可以省略：** `0db8` → `db8`，`0001` → `1`，`0000` → `0`。
2. **一段连续的全零块**可以用 `::` 替换——但每个地址中**只能使用一次**。如果有多段连续全零块，就缩写最长的那一段。

示例：

```
2001:0db8:0000:0000:0000:0000:0000:0001   vollständig
2001:db8:0:0:0:0:0:1                      Regel 1
2001:db8::1                               Regel 2
```

为什么 `::` 只能用一次？对于 `2001::1::5`，没人能说清究竟在哪个位置缺了多少个全零块。只用一个 `::` 就没有歧义：缺失的块数恰好使总数重新凑成八个。

:::tip 要点
一个 **IPv6 地址**有 **128 位**，写成 **8 个块**，每块 **4 个十六进制数字**。前 64 位通常是**前缀**（网络部分），后 64 位是**接口 ID**（主机部分）。缩写方法：省略前导零，并用 `::` 替换**一段**全零块。
:::

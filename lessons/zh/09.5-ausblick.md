# 总结与展望

## 防火墙无处不在

你在本章学到的数据包过滤器,在很多设备中都能找到:

- **家用路由器:** 每台家用路由器同时也是一台有状态防火墙。在 IPv4 中,NAT 承担了其中一部分功能:只要没有端口转发(第 7 章),外部就无法主动发起连接。在 IPv6 中,所有设备都有公网地址——此时仅靠防火墙规则“外部不得发起新连接”来提供同样的保护。
- **个人防火墙:** Windows、macOS 和 Linux 也在计算机本身内置了防火墙。即使在陌生网络中,例如咖啡馆的 WLAN,它也能保护设备,并且可以按程序设置规则。
- **下一代防火墙**和 **Web 应用防火墙(WAF):** 它们不仅查看地址和端口,还会查看数据包的内容——直至应用层。这样它们就能识别出例如 HTTP 请求中的攻击。对于 HTTPS,它们为此必须破解加密(第 8 章)。
- **IDS/IPS:** *入侵检测系统(Intrusion Detection System)*会识别数据流量中的可疑模式并发出警报;*入侵防御系统(Intrusion Prevention System)*还会自行将其拦截。

:::note
防火墙只是安全体系中的**一个**组成部分。如果一个被允许的服务(例如 Web 服务器)本身存在漏洞,如果有人通过电子邮件打开了恶意程序,或者密码太弱,防火墙都无能为力。因此,更新、安全的密码、加密以及对网络的合理划分(DMZ、第 3 章中的 VLAN)始终必不可少。
:::

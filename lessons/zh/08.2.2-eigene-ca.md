# 搭建自己的 CA

:::sim
url=/sims/lesson-8.2.2.btsim
:::

`www.beaver-schule.de` 目前还没有证书。学校不向商业 CA 申请证书，而是搭建自己的 **CA**：**Schul-CA**。许多公司和学校都会为内部服务器这样做。

在真实环境中，Schul-CA 会运行在一台专用的、受到特别严密保护的计算机上。在这里，你要在 Web 服务器上亲自扮演所有角色。

## 步骤 1：生成 Schul-CA

1. 切换到 :fa-play: **运行**模式，在 Web 服务器 **www.beaver-schule.de** 上打开 :fa-shield-halved: **Zertifikatverwaltung**。
2. 在标签页 **Generieren** 中：
    - **Common Name:** `Schul-CA`
    - **Typ:** Selbstsigniert
    - 勾选 **Dies ist ein CA-Zertifikat**
    - **Speichern unter:** `schul-ca.cert.json`
3. 点击 **Zertifikat generieren**。

这样会生成一个新的**密钥对**。证书包含公钥；私钥保存在 Web 服务器上的文件中。

## 步骤 2：签发服务器证书

仍在标签页 **Generieren** 中：

- **Common Name:** `www.beaver-schule.de` — 正是你在浏览器中输入的名称
- **Typ:** Von CA signiert，**Signierende CA:** Schul-CA
- **Speichern unter:** 例如 `www.beaver-schule.de.cert.json`

在标签页 **Meine Zertifikate** 中，你现在可以看到两份证书。点击新的服务器证书：

:::quiz short
服务器证书的 **Aussteller**（颁发者）是谁（不含 `CN=`）？
= Schul-CA
:::

:::quiz mc
它的 **Kette**（证书链）是什么？
- [x] `www.beaver-schule.de ← Schul-CA`
- [ ] `Schul-CA ← www.beaver-schule.de`
- [ ] `www.beaver-schule.de`（自签名）
:::

:::evaluate
检查答案
:::

## 步骤 3：让客户端认识 Schul-CA

客户端 PC 还不认识 Schul-CA —— 它的浏览器中并没有预装这个 CA。你必须把 CA 的证书交给它，而且是**不含私钥**的证书：

1. 在 Web 服务器上的 **Meine Zertifikate** 中选中 **Schul-CA**，点击 **Kopieren**（不要点 *Kopieren + Schlüssel*！）。
2. 在**客户端 PC** 上打开 :fa-shield-halved: **Zertifikatverwaltung**，进入标签页 **Vertrauenswürdige CAs**。
3. 点击 **Einfügen: Schul-CA**。

:::warning
**CA 的私钥**是整个体系中最宝贵的机密：谁拥有它，就可以为**任意**名称签发证书，而所有客户端都会信任这些证书。它绝不能离开 CA 所在的计算机。
:::

:::task
title: Schul-CA 设置好了吗？
检查 Web 服务器上是否有一份由 Schul-CA 为 www.beaver-schule.de 签发的证书，以及客户端 PC 是否信任 Schul-CA。
check: hasCert(4, "www.beaver-schule.de", "Schul-CA")
check: trusts(2, "Schul-CA")
:::

:::quiz mc
为什么给客户端复制证书时只复制**不含**私钥的证书？
- [ ] 因为连同私钥一起复制耗时更长
- [x] 验证签名只需要公钥；如果客户端上有私钥，任何人都可以在客户端上自行签发证书
- [ ] 因为否则客户端无法建立连接
:::

:::evaluate
检查答案
:::

你还没有改动 Web 服务器本身 —— 它仍然只使用 HTTP。如何启用 HTTPS，你将在 8.3.3 节中学习。

:::tip 要点
**自己的 CA** 由一份带有私钥的**自签名 CA 证书**构成。用它来签发**服务器证书**，其 Common Name 与服务器名称一致。为了让客户端信任这些证书，要把**不含私钥的 CA 证书**放入客户端的**受信任 CA** 列表中。
:::

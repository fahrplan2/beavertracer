# 有状态防火墙

:::sim
url=/sims/lesson-9.2.btsim
:::

**有状态**（*stateful*）防火墙会把每一个曾被放行的连接记录在**状态表**中：协议、双方地址和双方端口。如果来了一个与表项匹配的数据包——无论方向如何——防火墙都会不再检查直接放行。新的连接则必须经过规则的检查。

## 观察

1. 在**防火墙**中把**模式**设为 **Stateful**。
2. 在**教师电脑**的 :fa-globe: **浏览器**中再次访问 `http://203.0.113.80/`。
3. 立即在防火墙中打开标签页 **Zustände**。

:::quiz mc
现在会发生什么？
- [x] 页面加载成功，并且在 **Zustände** 中可以看到从教师电脑到 `203.0.113.80:80` 的连接
- [ ] 页面无法加载，因为响应数据包仍然没有对应的规则
:::

:::quiz short
在状态表中，**Ziel** 一栏里的端口是多少？
= 80
:::

:::evaluate
检查答案
:::

如果连接上不再有数据传输，**Zustände** 中的表项过一段时间会自动消失（**Timeout** 列）。

## 任务：学校防火墙

现在请像真实的学校那样来配置防火墙：

- **来自校园网络**的流量可以随意访问互联网（方向 B → A，任意协议）。
- **来自互联网**的流量只能访问学校服务器的 Web（80）和邮件接收（25）。
- 其他一切都**丢弃**，模式为 **Stateful**。

:::task
title: 学校防火墙配置好了吗？
检查校园网络能否访问互联网，从外部是否只能访问学校服务器的 Web 和邮件，以及教师电脑是否无法从外部访问。
check: tcpOpen(8, "203.0.113.80", 80)
check: tcpOpen(1, "198.51.100.10", 80)
check: tcpOpen(1, "198.51.100.10", 25)
check: tcpFails(1, "198.51.100.10", 22)
check: pingFails(1, 8)
:::

:::quiz mc
教师电脑对 `203.0.113.80` 执行 ping。响应能返回吗？
- [x] 能——这个 ping 已被 B → A 方向的规则放行，响应属于该状态
- [ ] 不能——针对来自外部的 ICMP 没有规则
:::

:::evaluate
检查答案
:::

:::tip 要点
**有状态防火墙**会把每个被放行的连接登记到**状态表**中，并让该连接的所有数据包在**两个方向**上都通过。因此，只需针对**连接建立**制定规则即可：“内部可以访问外部”以及“外部只能访问特定服务”。由外部发起、进入校园网络的连接仍然被阻止。
:::

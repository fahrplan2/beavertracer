# 家庭网络：路由器与 NAT

:::goal
**学习目标：** 你能够说出家用路由器的各项任务，设置一台家用路由器，解释 NAT 如何让许多设备通过一个公网地址接入互联网，并设置和检查端口转发。
:::

在家里，网络中很快就会有十台甚至更多设备：手机、笔记本电脑、电视、游戏机、音箱。它们都会获得类似 `192.168.178.20` 的地址——这些地址来自一个**私有**地址范围，这个范围在互联网上根本不会被转发（第 4.2.2 章）。尽管如此，这些设备每一台都能上网。

这一切要归功于一个不起眼的小盒子：**家用路由器**。在工作区的左侧，你可以看到一个家庭网络，里面有一台 PC 和一台平板电脑；右侧是“互联网”——某个运营商的路由器、一台 DNS 服务器以及 Web 服务器 `www.beispiel.de`。

:::note
本章中的公网地址（`203.0.113.…`、`198.51.100.…`、`192.0.2.…`）是专门为示例和教学材料保留的——就像 IPv6 中的 `2001:db8::` 一样。
:::

## 家用路由器里都有什么

| 家用路由器中的角色 | 作用 | 你在哪里学过 |
|---|---|---|
| **交换机** | 连接 LAN 接口上的设备 | 第 3.1 章 |
| **接入点** | 让手机、平板和笔记本电脑通过 WLAN 接入网络 | 第 3.3 章 |
| **路由器** | 将家庭网络与运营商的网络相连——它就是**网关** | 第 4.3 章 |
| **DHCP 服务器** | 分配地址、网关和 DNS 服务器 | 第 6.4 章 |
| **DNS** | 转发域名查询请求，或指出运营商的 DNS 服务器 | 第 6.2 章 |
| **NAT** | 让所有设备通过**一个**公网地址接入互联网 | 新内容——第 7.2 节 |

**WAN**（*Wide Area Network*，广域网）接口通向运营商，**LAN** 接口和 WLAN 则通向家庭网络。许多家用路由器还内置**调制解调器**——它把数据转换成适合线路传输的信号（DSL、有线电视、光纤）。BeaverTracer 不模拟这一点；这里 WAN 接口直接连接在运营商的网络中。

:::quiz match
交换机 -> 连接 LAN 接口上的设备
接入点 -> 让平板和手机通过 WLAN 接入网络
DHCP 服务器 -> 为家庭网络中的设备分配地址
路由器 -> 将家庭网络与运营商的网络相连
:::

:::evaluate
检查配对
:::

:::tip 要点
**家用路由器**集成了多种设备：**交换机**、**WLAN 接入点**、**路由器**（通往互联网的网关）、**DHCP 服务器**和 **DNS 转发**——此外还有 **NAT**。**WAN** 接口通向运营商，**LAN** 接口和 WLAN 通向家庭网络。
:::

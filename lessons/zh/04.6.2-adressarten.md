# 最重要的地址类型

在 IPv6 中,从地址的开头就可以看出它的用途:

| 地址类型 | 识别特征 | 用途 |
|---|---|---|
| **链路本地地址(Link-Local)** | `fe80::` | 只在**自己的本地网络**中有效。每台设备都会自动给自己分配这个地址——路由器永远不会转发它。 |
| **全球单播地址(Global Unicast)** | `2…` 或 `3…`(`2000::/3`) | 全球唯一的地址,可在互联网上访问。前缀由互联网服务提供商分配。 |
| **唯一本地地址(Unique Local)** | `fd…`(`fc00::/7`) | 用于私有网络,相当于 IPv4 中的 `192.168.x.x`。 |
| **环回地址(Loopback)** | `::1` | 指本设备自身——相当于 IPv4 中的 `127.0.0.1`。 |
| **组播地址(Multicast)** | `ff…` | 发送给一个设备**组**,例如 `ff02::1` = 本地网络中的所有设备。 |

:::note
`2001:db8::/32` 这个范围是专门为示例和教学材料保留的——它不会出现在真实的互联网中。因此你会在本课程中看到它。
:::

一个重要的新变化:**IPv6 不再有广播。** 在 IPv4 中向所有设备发送的广播,在 IPv6 中由**组播**地址来完成——消息只会发送给对该组感兴趣的设备。

:::tip 要点
每台 IPv6 设备至少有一个用于自己所在网络的**链路本地地址**(`fe80::…`),通常还会有一个用于互联网的**全球地址**。IPv6 使用**组播**(`ff…`)来代替广播。
:::

# 设置家用路由器

:::sim
url=/sims/lesson-7.1.2.btsim
:::

一台新的家用路由器刚刚接好——但目前还没有人能上网。你从运营商那里收到了一封写有**接入信息**的信:

| 接入信息 | 值 |
|---|---|
| WAN IP 地址 | `203.0.113.2` |
| 前缀长度 | `/30` |
| 网关(运营商的路由器) | `203.0.113.1` |
| 运营商的 DNS 服务器 | `198.51.100.10` |

1. 切换到 :fa-play: **运行**模式,点击 **Heimrouter**,打开 **WAN** 标签页。
2. 填入接入信息,然后点击**应用**。
3. 将 **Tablet** 连接到 WLAN::fa-gear: **IP设置**,**WiFi** 标签页,SSID 填 `Biberbau`,点击**应用**。
4. 在 PC 上用 `ping 192.0.2.80` 测试,或在浏览器中访问 `http://www.beispiel.de/` 进行测试。

:::note
在实际使用中,家用路由器的 WAN 地址通常由运营商自动分配(通过 DHCP,或通过用户名和密码登录)。像这里这样的固定接入信息,更常见于企业专线。
:::

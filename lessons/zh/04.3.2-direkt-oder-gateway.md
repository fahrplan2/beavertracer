# 直接发送还是经由网关？

:::sim
url=/sims/lesson-4.3.2.btsim
:::

PC 在发送数据包之前，会先做一个判断：目标是否在**本网络**内？为此，它借助自己的子网掩码，将自身地址的网络部分与目标地址的网络部分进行比较。

## 流程

1. **目标 IP 是否在本网络内？**
   - **是：** PC 把数据包**直接**发送给目标。它需要目标的 MAC 地址。
   - **否：** PC 把数据包发送给**网关**。它需要路由器的 MAC 地址。如果没有配置网关，它根本无法发送这个数据包。
2. **它是否已经知道所需的 MAC 地址**（是否在它的 ARP 缓存中）？如果不知道，它就通过 **ARP** 来询问。
3. 它把帧发送到这个 MAC 地址。在这两种情况下，数据包中的**目标 IP 地址**都是真正的目标。

| | 直接发送（本网络） | 经由网关（其他网络） |
|---|---|---|
| ARP 询问 … | 目标的 MAC | 路由器的 MAC |
| 帧中的目标 MAC | 目标 | 路由器 |
| 数据包中的目标 IP | 目标 | 目标 |

## 故障排查：无法访问 B 公司

从昨天起，Anna 就无法访问 B 公司的 PC 了。网络本*应该*这样配置：

| 设备 | IP 地址 | 网关 |
|---|---|---|
| Anna | `192.168.0.10/24` | `192.168.0.1` |
| Ben | `192.168.0.11/24` | `192.168.0.1` |
| Clara | `172.16.0.10/24` | `172.16.0.1` |
| David | `172.16.0.11/24` | `172.16.0.1` |

找出错误并修复它们。

<details>
<summary>提示 1：Anna 的 ping 到底有没有到达？</summary>

从 Anna 去 ping Clara，并为 **Clara** 打开一个追踪。ping 到达了吗？Clara 有没有回复？
</details>

<details>
<summary>提示 2：David 在做什么？</summary>

从 Anna 去 ping David，并为 **David** 打开一个追踪。David 通过 ARP 询问的是哪个 IP 地址——它得到回应了吗？
</details>

## 刚才发生了什么？

:::quiz multi
你在故障排查时，在追踪器中看到了什么？
- [x] Anna 的 ping 到达了 Clara，但 Clara 没有回复
- [x] David 通过 ARP 询问了一个在网络中根本不存在的地址
- [ ] Anna 的 ping 从未离开过 A 公司
:::

:::evaluate
检查答案
:::

:::tip 要点
PC 不仅在发送时需要正确的网关，在**回复**时也需要：没有网关，ping 虽然能到达，但回复却找不到返回的路。如果配置了**错误的网关地址**，PC 就会通过 ARP 白白地去询问一个根本不存在的路由器。
:::

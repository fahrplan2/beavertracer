# HTTP 与 HTTPS 的比较

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Web 服务器 **www.beaver-schule.de** 同时通过 HTTP 和 HTTPS 提供学校的成绩门户。窃听者能看到什么？

## 实验

1. 切换到 :fa-play: **运行**模式，在 **Client-PC** 的 :fa-globe: **浏览器**中先访问 `http://www.beaver-schule.de/`，然后访问 `https://www.beaver-schule.de/`。
2. 在 :fa-magnifying-glass: **追踪**模式下为 **Client-PC** 打开一个 Trace。
3. 先找到数据包 `HTTP/1.1 200 OK` 并点击它。在下方的详情中你可以找到页面的内容。

:::quiz mc
窃听者在使用 **HTTP** 时能看到什么？
- [x] 完整的网页，包括 Anna 的成绩
- [ ] 只有服务器的地址
- [ ] 什么都看不到，因为 HTTP 运行在 TCP 之上
:::

:::quiz short
Anna 的数学成绩是多少？
= 2
:::

:::evaluate
检查答案
:::

现在进入 HTTPS 部分。找到客户端用来建立第二个连接的 `[SYN]` 数据包。

:::quiz short
HTTPS 连接的目标端口是多少（**Info** 列，`… → ???`）？
= 443
:::

现在在 Trace 上方的过滤框中输入 `tls`，这样你就只会看到 TLS 数据包。

:::quiz mc
在包含网页内容的数据包中，**Info** 列显示的是什么？
- [ ] `HTTP/1.1 200 OK`
- [x] `Application Data`
- [ ] `Encrypted HTML`
:::

:::quiz multi
窃听者在使用 **HTTPS** 时仍然能看到什么？
- [x] 客户端和服务器的 IP 地址
- [x] 使用的是 443 端口，因此很可能是 HTTPS
- [x] 大致传输了多少数据
- [ ] 访问了哪个页面以及页面上有什么内容
:::

:::evaluate
检查答案
:::

:::note
点击一个 **Application Data** 数据包：其中的有效载荷只是一串看似随机的字节。Tracer 无法解密它们——它和攻击者一样，并不知道会话密钥。
:::

:::tip 要点
使用 **HTTP** 时，任何窃听者都可以读取完整的网页。使用 **HTTPS** 时，窃听者只能看到**谁与谁**在通信（IP 地址、443 端口）以及**通信量有多大**——内容则以加密形式存放在 **Application Data** 数据包中。
:::

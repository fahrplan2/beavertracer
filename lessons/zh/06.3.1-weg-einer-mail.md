## 实验

1. 切换到 :fa-play: **运行**模式，点击 **Anna**，打开 **E-Mail** 应用。
2. 切换到 **Verfassen** 标签页。在 **An** 中输入 `ben@biber-mail.de`，填写主题和一小段正文，然后点击 **Senden**。
3. 等待几秒钟——邮件需要先在邮件服务器之间传递。然后点击 **Ben**，打开 **E-Mail** 应用，点击 **Abrufen**。Anna 发来的邮件已经到了。
4. 在 :fa-magnifying-glass: **追踪**模式下，为 **Mailserver Schule** 打开一次追踪。

## 背后的原理

一封电子邮件要分几个阶段传递——就像一封信要经过两个邮局：

1. Anna 的电子邮件程序通过 **SMTP** 把邮件交给 Anna 的邮件服务器。
2. Mailserver Schule 发现：收件人属于一个**其他域名**。它通过 **DNS** 查询 `biber-mail.de` 的 **MX 记录**（*Mail Exchanger*，邮件交换器），得到 `mail.biber-mail.de`，随后再查询该主机的 IP 地址。
3. 它通过 **SMTP** 把邮件投递到 Mailserver Biber。邮件在那里存放在 Ben 的邮箱中。
4. Ben 通过 **IMAP**（或 **POP3**）从他的邮件服务器取走邮件。

:::seq
mode: text
Mailserver Schule -> Mailserver Biber: SMTP: MAIL FROM | anna@beaver-schule.de
Mailserver Biber -> Mailserver Schule: 250 OK
Mailserver Schule -> Mailserver Biber: SMTP: RCPT TO | ben@biber-mail.de
Mailserver Biber -> Mailserver Schule: 250 OK
Mailserver Schule -> Mailserver Biber: SMTP: DATA | 邮件本身
Mailserver Biber -> Mailserver Schule: 250 OK queued
:::

:::tip 要点
**SMTP**（端口 25）用于**发送**电子邮件：从电子邮件程序发到自己的邮件服务器，再从那里发到收件人的邮件服务器。哪台邮件服务器负责某个域名，记录在 DNS 的 **MX 记录**中。**POP3**（端口 110）和 **IMAP**（端口 143）只用于从自己的邮箱中**收取**邮件。
:::

:::quiz match
SMTP -> 发送电子邮件，并在邮件服务器之间转发
MX 记录 -> 指明哪台邮件服务器负责某个域名
IMAP -> 从自己的邮箱中收取电子邮件
:::

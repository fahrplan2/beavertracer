# 故障排查：昨天还好好的

:::sim
url=/sims/lesson-7.2.4.btsim
:::

昨天还能从外部访问家庭网络中的 Web 服务器——端口转发 `TCP 80 → 192.168.178.10:80` 已经设置好。今天一早停电之后，Clara 就打不开这个页面了。找出故障并将其彻底解决。

<details>
<summary>提示 1：这条规则指向哪里？</summary>

将家用路由器 **Port FW** 中的 LAN IP，与 **Heim-Webserver** 当前实际使用的地址（:fa-gear: **IP设置**）进行比较。
</details>

<details>
<summary>提示 2：为什么它的地址不一样了？</summary>

Heim-Webserver 是否设置为 **DHCP**？如果是，每次重启后它都会从家用路由器的地址范围（在 **DHCP** 标签页中）获得任意一个空闲地址。你要怎样做才能让它始终使用同一个地址？
</details>

:::task
title: Heim-Webserver 又能访问了吗？
检查 Heim-Webserver 是否使用了固定地址，以及 Clara 是否能通过端口转发访问到它。为此，模拟必须处于运行模式。
check: ip(11, "192.168.178.10/32")
check: tcpOpen(12, "203.0.113.2", 80)
:::

## 发生了什么？

:::quiz multi
下列哪些说法是正确的？
- [x] Heim-Webserver 通过 DHCP 获取地址，重启后得到了另一个地址
- [x] 因此端口转发指向了一个已经没有服务器在运行的地址
- [x] 在 DHCP 范围之外使用固定地址可以彻底解决这个问题
- [ ] 服务提供商封锁了 WAN 地址
:::

:::evaluate
检查答案
:::

:::tip 要点
被**端口转发**指向的设备（服务器、打印机、摄像头）需要使用**固定地址**：要么以静态方式填写并位于 **DHCP 范围之外**，要么在路由器的 DHCP 服务器中做固定分配。否则它们在重启后可能会得到另一个地址——这条规则就会指向一个空地址。
:::

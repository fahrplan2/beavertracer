# 二进制

计算机在最底层只知道两种状态：通电或断电。这两种状态用 **1** 和 **0** 来表示。这样的一个位置称为**比特**（bit）。对计算机来说，每个 IP 地址也只是一串由 0 和 1 组成的序列——为了让你理解子网掩码是如何工作的，你将在本页学习如何读懂这样的数字，并自己进行换算。

## 我们平时如何计数：十进制

在日常生活中，我们使用十个数字（0 到 9）进行计算。每一位的权值是其右边一位的十倍：个位、十位、百位、千位。因此数字 `305` 的含义如下：

| 位权 | 100 | 10 | 1 |
|---|---|---|---|
| 数字 | 3 | 0 | 5 |
| 值 | 300 | 0 | 5 |

300 + 0 + 5 = **305**

## 二进制

在**二进制**（也称*二进位制*）中只有两个数字：0 和 1。每一位的权值是其右边一位的**两倍**：1、2、4、8、16、32、64、128 …

因此二进制数 `00001101` 的含义如下：

| 位权 | 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1 |
|---|---|---|---|---|---|---|---|---|
| 比特 | 0 | 0 | 0 | 0 | 1 | 1 | 0 | 1 |
| 值 | | | | | 8 | 4 | | 1 |

8 + 4 + 1 = **13**

也就是说，你只需把所有为 1 的位置对应的位权加起来即可。

:::tip 要点
**比特**是二进制中的一位（0 或 1）。**8 比特**构成一个**字节**——在网络技术中，这样的 8 位一组也称为**八位组**。一个八位组各位的位权依次为 **128、64、32、16、8、4、2、1**。
:::

## 从十进制转换为二进制

反过来，你从左到右依次检查各个位权，每次都问自己：**这个位权还能放进我的（剩余）数字里吗？** 如果可以，就写下 1，并减去该位权。如果不行，就写下 0。

示例：`168`

| 位权 | 能放进……吗？ | 比特 | 余数 |
|---|---|---|---|
| 128 | 168 → 能 | **1** | 40 |
| 64 | 40 → 不能 | **0** | 40 |
| 32 | 40 → 能 | **1** | 8 |
| 16 | 8 → 不能 | **0** | 8 |
| 8 | 8 → 能 | **1** | 0 |
| 4 | 0 → 不能 | **0** | 0 |
| 2 | 0 → 不能 | **0** | 0 |
| 1 | 0 → 不能 | **0** | 0 |

从上往下读：168 = **10101000**

:::tip 提示

:::

## 二进制中的 IP 地址

一个 IPv4 地址由 **32 比特**组成，也就是四个八位组。因为没有人能记住 32 个 0 和 1，所以人们把每个八位组写成十进制数，并用点号分隔：

```
11000000 . 10101000 . 10110010 . 00000001
   192   .   168    .   178    .    1
```

:::quiz short
一个 IPv4 地址由多少比特组成？
= 32
:::

:::quiz mc

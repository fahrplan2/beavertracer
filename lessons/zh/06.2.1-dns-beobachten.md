## 实验

1. 切换到 :fa-play: **运行**模式，点击 **Client-PC**，打开 :fa-globe: **浏览器**。
2. 这次访问 `http://www.beaver-schule.de/`——使用域名，而不是 IP 地址。
3. 切换到 :fa-magnifying-glass: **追踪**模式，为 **Client-PC** 打开一个 Trace。

在最开始——甚至在使用 `[SYN]` 进行连接建立之前——有两个协议为 **DNS** 的数据包。

:::quiz short
Client-PC 把它的 DNS 查询发送到哪个 IP 地址？
= 192.168.0.53
:::

:::quiz short
在 `www.beaver-schule.de` 的应答中，给出的 IP 地址是什么？
= 192.168.0.20
:::

:::quiz mc
点击 DNS 查询并展开协议树。使用的是哪种传输协议和哪个目的端口？
- [ ] TCP，端口 80
- [x] UDP，端口 53
- [ ] UDP，端口 67
:::

:::evaluate
检查答案
:::

只有当 Client-PC 知道了 IP 地址之后，它才会与 Web 服务器建立 TCP 连接——和第 5 章中完全一样。

:::seq
mode: text
Client-PC -> DNS-Resolver: DNS-Anfrage | A www.beaver-schule.de?
DNS-Resolver -> Client-PC: DNS-Antwort | A 192.168.0.20
:::

## PC 如何知道 DNS 服务器？

在 **Client-PC** 上打开 :fa-gear: **IP设置**：**DNS-Server** 字段中填写的是 `192.168.0.53`——即计算机 **DNS-Resolver**。PC 会把每一个域名查询都发送给它。

你也可以不通过浏览器，直接向 DNS 服务器查询。打开 :fa-terminal: **终端**，输入：

```
$ nslookup www.beaver-schule.de
```

`nslookup` 会先显示它查询的是哪台服务器，然后显示应答。作为对比，再查询一个不存在的域名，例如 `nslookup gibtsnicht.beaver-schule.de`。

:::quiz mc
对于这个未知的域名，DNS 服务器会如何应答？
- [ ] 一个随机的 IP 地址
- [x] `NXDOMAIN`——不存在这个域名
- [ ] 完全没有应答
:::

:::evaluate
检查答案
:::

:::tip 要点
**DNS** 把域名（例如 `www.beaver-schule.de`）转换为 IP 地址。PC 在能够与某个域名建立连接之前，会先询问其 IP 设置中配置的 **DNS 服务器**——通常通过 **UDP，端口 53**。使用 `nslookup`，你可以手动发起 DNS 查询。
:::

# WLAN：没有网线的网络

:::goal
**学习目标：** 你能够解释接入点如何将 WLAN 与有线网络连接起来，能够通过 SSID 让设备接入 WLAN，并能说明为什么 WLAN 必须加密。
:::

手机、平板电脑和笔记本电脑大多已经没有网络接口了——它们通过无线电波连接，也就是通过 **WLAN**（*Wireless LAN*，无线局域网）。要让它们仍然能与网线连接的 PC 和服务器通信，就需要一台把无线与有线连接起来的设备。

:::note
现实中，WLAN 会受到覆盖范围、墙壁和干扰的影响。BeaverTracer 对此做了简化：所有使用相同 WLAN 名称的设备共用同一个无线网络——无论它们在工作区中的位置如何。
:::

## 背后的原理

家用路由器会把每个发往互联网的数据包中的私有发送方地址替换为它自己的**公网 WAN 地址**——通常连发送方端口也会一并替换。对 Web 服务器来说,请求就像是来自家用路由器。当响应返回时,家用路由器再把地址换回来,并把数据包转发给 PC。

这样,整个家庭网络只需一个公网地址就能访问互联网——而互联网上的设备永远看不到这些私有地址。

## 通往互联网的路径

在 **PC** 的 :fa-terminal: **终端**中输入:

```
$ traceroute 192.0.2.80
```

:::quiz short
PC 与 Web 服务器之间有多少个路由器?(数一数最后一行之前的所有行。)
= 4
= 四
:::

:::quiz mc
`traceroute` 显示的第一个路由器的地址是什么?
- [x] `192.168.178.1` — 家用路由器的 LAN 地址
- [ ] `203.0.113.2` — 它的 WAN 地址
- [ ] `203.0.113.1` — 运营商的第一个路由器
:::

:::evaluate
检查答案
:::

:::tip 要点
**NAT**(*Network Address Translation*,网络地址转换)在数据包发往互联网时,把设备的**私有**发送方地址替换为路由器的**公网 WAN 地址**——对于响应数据包则反过来替换。这样,家庭网络中的所有设备共用**一个**公网 IPv4 地址。这既节省了地址,又向互联网隐藏了私有地址。
:::

# 第一批自己的规则

:::sim
url=/sims/lesson-9.btsim
:::

现在轮到你了。防火墙目前还放行所有流量。请确保从互联网只能访问学校服务器的 **Webseite (80)** 和 **Mail-Empfang (25)**。**SSH (22)**、**POP3 (110)** 和 **IMAP (143)** 不应再能从互联网访问。

## 添加规则

1. 点击**防火墙**。默认策略暂时保持为 **Alle zulassen**。
2. 删除现有规则（它本来就放行所有流量），然后用 **+ Regel hinzufügen** 为每个需要关闭的端口新建一条规则：
    - **Richtung** A → B（来自互联网）
    - **Protokoll** TCP
    - **Ziel-Port** 例如 `22`
    - **Aktion** Verwerfen
3. 在 **Internet-PC** 上用 `nmap 198.51.100.10` 检查，看是否只剩下正确的端口是开放的。

:::task
title: 从外部只能访问 Web 和邮件吗？
检查学校服务器从互联网是否只能通过端口 80 和 25 访问，并且教师电脑是否仍然可以收取邮件和上网。为此，模拟必须在运行模式下运行。
check: tcpOpen(1, "198.51.100.10", 80)
check: tcpOpen(1, "198.51.100.10", 25)
check: tcpFails(1, "198.51.100.10", 22)
check: tcpFails(1, "198.51.100.10", 110)
check: tcpFails(1, "198.51.100.10", 143)
check: tcpOpen(8, "198.51.100.10", 110)
check: tcpOpen(8, "203.0.113.80", 80)
:::

:::quiz mc
教师电脑仍然可以通过 POP3 (110) 从学校服务器收取邮件。为什么防火墙不会影响它？
- [ ] 因为防火墙能识别教师
- [x] 因为它的数据包根本不经过防火墙——教师电脑和学校服务器连接在防火墙后面的同一台交换机上
- [ ] 因为 POP3 是一种安全的协议
:::

:::evaluate
检查答案
:::

:::note
防火墙只保护**经过它**的流量。校园网络内部发生的事情，它看不到。因此，校园网络中一台被感染的电脑仍然可以攻击学校服务器——这正是 DMZ 一节要讨论的内容。
:::

:::tip 要点
对于每一个不应从外部访问的服务，都可以用一条包含**方向**、**协议**和**目标端口**的规则来阻止访问。规则是否生效，可以从外部用**端口扫描**来检验。
:::

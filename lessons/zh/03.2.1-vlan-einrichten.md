# 一个交换机，两个网络

:::sim
url=/sims/lesson-3.2.1.btsim
:::

交换机上连接着四台 PC：来自行政部门的 **Sekretariat**（端口 1）和 **Schulleitung**（端口 2），以及来自计算机教室的 **Anna**（端口 3）和 **Ben**（端口 4）。它们都处于同一个网络 `192.168.0.0/24` 中。

## 问题

切换到 :fa-play: **运行**模式，在 **Anna** 上打开 :fa-terminal: **终端**，然后 ping Sekretariat：

```
$ ping 192.168.0.10
```

Anna 毫无阻碍地就能访问 Sekretariat。而这正是我们想要避免的。

## 设置 VLAN

**VLAN**（*Virtual LAN*，虚拟局域网）是交换机内部一个独立的、被隔离开的网络。每个 VLAN 都有一个编号，称为 **VLAN ID**。我们这样规定：行政部门属于 **VLAN 10**，计算机教室属于 **VLAN 20**。

1. 在运行模式下点击 **Switch**，打开 **VLAN** 标签页。
2. 勾选**启用 VLAN**。随后会出现一张表格，每个端口占一行。
3. 在 **PVID** 列中填入 VLAN ID：**port 1** 和 **port 2** 都填 `10`，**port 3** 和 **port 4** 都填 `20`。**模式**保持为 `untagged`。
4. 点击底部的**应用**。

:::note
**PVID** 是 *Port VLAN ID* 的缩写：到达该端口的所有数据都属于这个 VLAN。模式 `untagged` 表示该端口上连接的是一台普通 PC，它不需要了解任何关于 VLAN 的信息。
:::

## 测试

再次从 **Anna** 出发 ping Sekretariat，然后再 ping Ben（`ping 192.168.0.21`）。

:::quiz mc
现在会发生什么？
- [ ] Anna 可以访问 Sekretariat 和 Ben
- [x] Anna 可以访问 Ben，但无法再访问 Sekretariat
- [ ] Anna 再也无法访问任何设备
:::

:::evaluate
检查答案
:::

在 :fa-magnifying-glass: **追踪**模式下，为 **Sekretariat** 打开一个追踪：Anna 的 ARP 请求（“Who has 192.168.0.10?”）根本不会出现在那里。她的广播留在了 VLAN 20 之内——对交换机来说，这现在是两个互相隔离的网络，彼此毫无察觉。

:::tip 要点
通过 **VLAN**，可以把一台交换机划分为多个逻辑上相互隔离的网络。处于不同 VLAN 的设备无法直接互相访问——广播也只会留在自己的 VLAN 内。每个 VLAN 都有一个编号，称为 **VLAN ID**。
:::

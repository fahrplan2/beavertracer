# ISO/OSI 参考模型

ISO/OSI 模型将两台设备之间的通信划分为七层。每一层都有明确划分的任务，并且只使用紧邻其下一层所提供的服务：

<thead>
<tr><th>层</th><th>名称</th><th>任务</th><th>示例协议</th></tr>
</thead>
<tbody>
<tr class="osi-l7"><td>7</td><td>应用层</td><td>与应用程序的接口</td><td>HTTP, DNS, SMTP</td></tr>
<tr class="osi-l6"><td>6</td><td>表示层</td><td>数据格式、加密</td><td>JPEG, ASCII, MIME</td></tr>
<tr class="osi-l5"><td>5</td><td>会话层</td><td>会话管理</td><td>RPC, NetBIOS</td></tr>
<tr class="osi-l4"><td>4</td><td>传输层</td><td>端到端传输</td><td>TCP, UDP</td></tr>
<tr class="osi-l3"><td>3</td><td>网络层</td><td>在不同网络之间选择路径</td><td>IP, ICMP</td></tr>
<tr class="osi-l2"><td>2</td><td>数据链路层</td><td>在本地网络中传输</td><td>Ethernet, ARP</td></tr>

通过上一页的实验，你已经认识了其中的四个层：Ethernet（第 2 层）、IPv4（第 3 层）、TCP（第 4 层）和 HTTP（第 7 层）。追踪器在协议树中显示的正是这些编号和颜色。

:::tip 记忆口诀
从第 7 层向下：**应**该**表**示**会**（话）**传**（输）**网**（络）**链**（路）**物**（理）——**应**用层、**表**示层、**会**话层、**传**输层、**网**络层、**数**据链路层、**物**理层。
:::

:::note 边界情况
并非每个协议都恰好属于某一层。因此，对于这些协议，追踪器会显示多个层：

- **ARP** — 第 2/3 层：它没有 IP 头部，但它把 IP 地址（第 3 层）与硬件地址（第 2 层）关联起来。
- **TLS** — 第 4/5 层：它直接位于 TCP 之上，并管理一个受保护的会话。
- **HTTPS**（TLS 内部的 HTTP）— 第 5–7 层：即 TCP/IP 模型中经典的应用层，你将在下一页学到它。
:::

:::note
第 1 层描述的是线缆上或无线方式下的实际信号传输。BeaverTracer 不模拟这一层——线缆始终被视为无故障连接，既没有信号问题，也没有冲突。因此在追踪器中，实际上是从第 2 层开始观察的。
:::

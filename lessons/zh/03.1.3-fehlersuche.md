# 交换网络中的故障排查

:::sim
url=/sims/lesson-3.1.3.btsim
:::

自从 **David** 加入网络以来,就出现了问题:谁也联系不上 Clara,而且 Ben 也有些不对劲。作为网络专家,你要把这些问题解决掉。

## 网络拓扑图

网络*应该*是这样的:

| 设备 | IP 地址 | 交换机端口 |
|---|---|---|
| Anna | `192.168.0.10/24` | 1 |
| Ben | `192.168.0.11/24` | 2 |
| Clara | `192.168.0.12/24` | 3 |
| David | `192.168.0.13/24` | 4 |

把拓扑图与仿真进行对比:有哪些不同?请排除你发现的所有故障。

<details>
<summary>提示 1:从哪里开始?</summary>

先看看网线:每台电脑都接在正确的端口上了吗?然后再检查每台电脑的 IP 设置。
</details>

<details>
<summary>提示 2:Ben 明明会响应 ping …?</summary>

从 Anna 去 ping Ben(`ping 192.168.0.11`),并为 Anna 打开一个追踪。仔细查看 ARP 应答:有几个?分别带有哪些 MAC 地址?
</details>

:::task
title: 网络修好了吗?
检查所有设备是否都使用了网络拓扑图中的地址,并且能够互相访问。为此,仿真必须在运行模式下运行。
check: ip(3, "192.168.0.10/32")
check: ip(5, "192.168.0.11/32")
check: ip(7, "192.168.0.12/32")
check: ip(11, "192.168.0.13/32")
check: pingOk(3, 7)
check: pingOk(3, 11)
check: pingOk(5, 7)
:::

## 刚才发生了什么?

:::quiz mc
在追踪器中,你如何发现两台设备使用了相同的 IP 地址?
- [ ] ping 总是失败
- [x] 一个 ARP 请求收到两个带有不同 MAC 地址的应答
- [ ] 交换机显示错误信息
:::

:::evaluate
检查答案
:::

:::tip 要点
在**故障排查**时,你要把**应有状态**(网络拓扑图)与**实际状态**(网线、设置、追踪)进行对比。注意:ping 成功并不代表一切正常——如果 IP 地址重复,可能只是错误的设备作出了应答。
:::

# 手动发送 HTTP

:::sim
url=/sims/lesson-6.1.btsim
:::

既然 HTTP 是纯文本——那么不用浏览器，自己直接和 Web 服务器"对话"可以吗？可以：用 `telnet` 与任意端口建立 TCP 连接，然后自己输入文本即可。

## 实验

1. 切换到 :fa-play: **运行**模式，在 **Client-PC** 上打开 :fa-terminal: **终端**。
2. 连接到服务器的 80 端口：
   ```
   $ telnet 192.168.0.20 80
   ```
3. 逐行输入请求——最后以一个**空行**结束（再按一次 **Enter** 即可）：
   ```
   GET /kontakt.html HTTP/1.1
   Host: 192.168.0.20

   ```

服务器会返回状态行、头部和联系页面——全部是文本，与浏览器收到的内容一样。

- [x] 通过空行
- [ ] 经过一段特定的时间之后
:::

## 制造错误

`curl` 是一个更方便的工具：它会替你发出请求。加上 `-v`（*verbose*，详细模式）后，它会显示来回传输的所有内容——以 `>` 开头的行是 `curl` 发送的，以 `<` 开头的行来自服务器。

试一试：

```
$ curl -v http://192.168.0.20/gibtsnicht.html
$ curl -X POST -d name=Anna http://192.168.0.20/
```

:::

:::note
BeaverTracer 中的 Web 服务器只能提供文件——因此它只允许 `GET` 和 `HEAD`。真实的 Web 服务器则可以通过 `POST` 接收表单等内容，并把数据交给某个程序处理。
:::

:::tip 要点
许多应用层协议都是**基于文本**的——HTTP，还有 SMTP、POP3 和 IMAP。因此你可以用 `telnet` 手动使用这些协议，并在追踪中读到它们的内容。这对故障排查很有帮助——但同时也是一个安全隐患：任何抓包的人都能读到全部内容。加密（HTTPS）如何提供帮助，你会在第 8 章学到。
:::

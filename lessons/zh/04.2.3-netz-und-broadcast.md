# 网络地址、广播地址和主机

在每个网络中，有两个地址承担着特殊的任务：

- **网络地址**是该网络中**最低**的地址：主机部分的所有位均为 0。它表示整个网络，例如用于路由表中。
- **广播地址**是该网络中**最高**的地址：主机部分的所有位均为 1。发送到该地址的数据会到达网络中的所有设备。

这两个地址都**不会**分配给设备。介于两者之间的所有地址都可供设备（**主机**）使用。

## 一个简单的例子

`192.168.0.12/24` — 主机部分是最后一个八位组：

| | 地址 |
|---|---|
| 网络地址（主机部分 = 0） | `192.168.0.0` |
| 广播地址（主机部分 = 255） | `192.168.0.255` |
| 主机范围 | `192.168.0.1` – `192.168.0.254` |
| 主机数量 | 254 |

## 当分界线位于八位组中间时

如果前缀长度不是 8 的倍数，就会变得比较难。这时你要把相关的八位组转换成二进制。例如：`194.9.190.12/27`。

前三个八位组完全属于[[n|网络部分]]（24 位）。最后一个八位组中还有 **3 位**属于网络部分（24 + 3 = 27），其余 **5 位**属于[[h|主机部分]]：

| | 最后一个八位组（二进制） | 十进制 |
|---|---|---|
| IP 地址 | [[n|000]][[h|01100]] | 12 |
| 子网掩码（`/27`） | [[n|111]][[h|00000]] | 224 |
| 网络地址：主机位置 0 | [[n|000]][[h|00000]] | **0** |
| 广播地址：主机位置 1 | [[n|000]][[h|11111]] | **31** |

结果：

- 网络地址：`194.9.190.0`
- 广播地址：`194.9.190.31`
- 主机范围：`194.9.190.1` – `194.9.190.30`
- 主机数量：2⁵ − 2 = **30**

:::tip 要点
**网络地址：**所有主机位均为 0（最低地址）。**广播地址：**所有主机位均为 1（最高地址）。这两者都不分配给设备。前缀长度为 *n* 的网络有 **2<sup>32 − n</sup> − 2** 个可供主机使用的地址。
:::

:::tip 小技巧：块大小
如果你已经理解了二进制的方法，还有一条捷径：**256 减去掩码所在的八位组**，就得到该八位组中一个网络的大小。对于 `/27`（掩码 224），即 256 − 224 = **32**。这样各个网络分别从 0、32、64、96 …… 开始——地址 `.12` 位于从 `.0` 开始的网络中，地址 `.70` 位于从 `.64` 开始的网络中。
:::

## 最重要的网络大小

| 前缀 | 子网掩码 | 主机数 |
|---|---|---|
| `/8` | `255.0.0.0` | 16 777 214 |
| `/16` | `255.255.0.0` | 65 534 |
| `/24` | `255.255.255.0` | 254 |
| `/25` | `255.255.255.128` | 126 |
| `/26` | `255.255.255.192` | 62 |
| `/27` | `255.255.255.224` | 30 |
| `/28` | `255.255.255.240` | 14 |
| `/29` | `255.255.255.248` | 6 |
| `/30` | `255.255.255.252` | 2 |

:::note
实践中常用的最小网络是 `/30`：它恰好有两个可用地址，常用于两台路由器之间的连接。`/32` 表示单个地址——它不能用作网络，但会出现在路由表和防火墙规则中。
:::

# DNS 是如何组织的

:::sim
url=/sims/lesson-6.2.btsim
:::

没有任何一台服务器能够知道世界上所有的域名。因此 DNS 采用**分层**结构——就像域名本身一样。阅读域名时要从右往左看:

```
www . beaver-schule . de . (Root)
 │          │         │      └─ Root-Server: kennen die Server aller Top-Level-Domains
 │          │         └─ Top-Level-Domain (TLD): der de-Server kennt alle .de-Domains
 │          └─ Domain: der Schul-DNS ist für beaver-schule.de zuständig
 └─ Rechnername innerhalb der Domain
```

负责某个域并且真正知道答案的服务器称为**权威服务器**。通往它的路径由**解析器**(Resolver)代替 PC 完成——在这里就是名为 **DNS-Resolver** 的计算机。

## 实验

1. 切换到 :fa-play: **运行**模式,在 **Client-PC** 的 :fa-terminal: **终端**中输入:
   ```
   $ nslookup www.beaver-schule.de
   ```
2. 在 :fa-magnifying-glass: **追踪**模式下,为 **DNS-Resolver** 打开一个追踪。

解析器为你发出了一系列请求。请将各个响应与给出它的服务器对应起来:

:::quiz match
Root-Server (192.168.0.101) -> 指引:.de 由 ns.nic.de 负责
de-Server (192.168.0.102) -> 指引:beaver-schule.de 由 ns.beaver-schule.de 负责
Schul-DNS (192.168.0.103) -> 回答:www.beaver-schule.de 的地址是 192.168.0.20
:::

:::quiz mc
解析器最先询问谁?
- [x] Root 服务器
- [ ] Schul-DNS
- [ ] Client-PC
:::

:::evaluate
检查答案
:::

:::note
在此过程中,解析器还会查询它被指引到的那些服务器的地址(`A ns.nic.de`)。真实的 DNS 服务器通常会直接把这些地址一并发送过来。此外,解析器会将每个响应记住一段时间(**缓存**)——对同一个名称的下一次请求,它会直接自己回答。记住多久,由记录中以秒为单位的 **TTL**(*Time to Live*,生存时间)给出。
:::

## 最重要的记录类型

| 类型 | 含义 | 示例 |
|---|---|---|
| **A** | 名称 → IPv4 地址 | `www.beaver-schule.de` → `192.168.0.20` |
| **AAAA** | 名称 → IPv6 地址 | `www.beaver-schule.de` → `2001:db8::20` |
| **CNAME** | 名称 → 另一个名称(别名) | `web.beaver-schule.de` → `www.beaver-schule.de` |
| **MX** | 某个域负责的邮件服务器 | `beaver-schule.de` → `mail.beaver-schule.de` |
| **NS** | 某个域负责的 DNS 服务器 | `beaver-schule.de` → `ns.beaver-schule.de` |

:::tip 要点
DNS 是**分层**的:**根服务器**指向**顶级域**(例如 `.de`)的服务器,顶级域服务器再指向各个**域**的服务器。负责该域的**权威**服务器知道答案。**解析器**代替 PC 走完这条路径,并记住这些响应(**缓存**)。重要的记录类型:**A**、**AAAA**、**CNAME**、**MX**、**NS**。
:::

## 创建一条记录

学校希望自己的网站除了原有名称外,还可以通过 `intranet.beaver-schule.de` 访问。

1. 在 :fa-play: **运行**模式下,点击 **Schul-DNS**,打开 **DNS-Server** 应用。
2. 打开 **A** 标签页。点击 **+**,在新增的一行中填入名称 `intranet.beaver-schule.de` 和地址 `192.168.0.20`。
3. 在 Client-PC 上用 `nslookup intranet.beaver-schule.de` 进行测试。

:::task
title: 新名称已添加?
检查 Client-PC 是否能将名称 intranet.beaver-schule.de 解析为 Web 服务器的地址。为此,模拟必须在运行模式下运行。
check: resolves(2, "intranet.beaver-schule.de", "192.168.0.20")
:::

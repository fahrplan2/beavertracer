# NAT 表

:::sim
url=/sims/lesson-7.1.btsim
:::

当 PC 和平板电脑同时加载同一个网页时，两个请求都会从 `203.0.113.2` 到达网络服务器。家用路由器如何知道一个响应该发给谁？它会做记录——记在 **NAT 表**中。

## 实验

1. 切换到 :fa-play: **运行**模式，在 **PC** 和 **Tablet** 上分别访问 `http://www.beispiel.de/`。
2. 点击 **Heimrouter**，打开 **NAT** 标签页。

每一行都是一条**映射**：协议、家庭网络中设备的 LAN IP 和 LAN 端口——以及路由器为此在其公网地址上使用的 **WAN 端口**。

:::quiz short
表格上方显示的 WAN IP 是什么？
= 203.0.113.2
:::

:::quiz mc
PC 和平板电脑都使用 LAN 端口 `49152` 建立了连接。它们会得到什么 WAN 端口？
- [ ] 两者都是 `49152`，完全相同
- [x] 各自不同——否则路由器就不知道响应属于谁
- [ ] 根本没有，NAT 只更改 IP 地址
:::

:::quiz mc
网络服务器的一个响应带着某个**目标端口**到达 `203.0.113.2`。家用路由器会如何处理它？
- [x] 它在 NAT 表中查找该端口，并把数据包发送到对应的 LAN IP 和 LAN 端口
- [ ] 它把数据包发送给家庭网络中的所有设备
- [ ] 它丢弃该数据包
:::

:::evaluate
检查答案
:::

这里又用到了第 5 章中的**端口**：因为 NAT 也会改写端口，成百上千个连接才能共用一个地址。严格来说，这因此称为 **PAT**（*Port Address Translation*，端口地址转换）或*带端口转换的 NAT*——不过日常中大家仍然简称为 NAT。

这样的转换例如可以是这样的：

| | 来自 PC 的数据包（在家庭网络中） | 同一个数据包在互联网中 |
|---|---|---|
| 发送方 | `192.168.178.20 : 49152` | `203.0.113.2 : 10001` |
| 接收方 | `192.0.2.80 : 80` | `192.0.2.80 : 80` |

:::tip 要点
路由器在 **NAT 表**中为每个连接记录：哪台设备（**LAN IP 和 LAN 端口**）对应哪个 **WAN 端口**。来自互联网的响应，它会通过目标端口重新匹配到正确的设备。由于端口也会被改写，更准确地说应称为 **PAT**。
:::

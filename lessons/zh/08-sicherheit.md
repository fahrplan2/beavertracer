在前面的章节中，你在追踪器里几乎可以读到所有内容：

- **第 3.3.2 章：** 在 WLAN 中，范围内的每台设备都会接收所有无线数据包。
- **第 6.1.2 章：** 使用 HTTP 时，请求和网页都以明文形式存在于数据包中。
- **第 6.3.2 章：** 使用 SMTP 和 POP3 时，用户名和密码几乎以明文形式在线路上传输——`AUTH PLAIN` 只是 Base64 编码。

因此，只要有人在线路上或同一个 WLAN 中监听，就能看到密码、成绩、消息和银行数据。而且他还能做得更多：**篡改**数据包，或者**冒充**他人。

## 三个安全目标

密码学就是用来抵御这些威胁的。人们区分三个**安全目标**：

| 安全目标 | 问题 | 攻击示例 |
|---|---|---|
| **机密性** | 只有正确的接收方才能读取数据吗？ | 有人在 WLAN 中窃取了你的密码。 |
| **完整性** | 数据是否未经改动地到达？ | 有人篡改了转账中的金额。 |
| **真实性** | 数据真的来自所声称的发送方吗？ | 一个伪造的银行网站索要你的 PIN 码。 |

在本章中，你将了解实现这三个目标的工具，以及它们如何在 **HTTPS**（浏览器中的锁形图标）中协同工作。

:::quiz match
有人在 WLAN 中窃取了你的密码 -> 机密性
有人在传输途中篡改了转账金额 -> 完整性
一个伪造的网站冒充你的银行 -> 真实性
:::

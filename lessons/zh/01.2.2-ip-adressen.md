# 分配 IP 地址

:::sim
url=/sims/lesson-1.2.2.btsim
:::

两台设备要相互通信，需要在同一个网络中拥有 IP 地址。在工作区中你可以看到两台已连接的电脑——就和你刚才亲手搭建的一样。

1. 切换到 :fa-play: **运行**模式，点击 **Computer 1** 将其打开。
2. 在其中打开 :fa-gear: **IP设置**。新电脑已经带有地址 `192.168.0.10`，子网掩码为 `/24`——你可以保持不变。
3. 现在打开 **Computer 2**。它拥有*相同*的地址 `192.168.0.10`——这样行不通，因为每个地址在网络中只能出现一次。把它改为 `192.168.0.11`（子网掩码 `/24`）。

:::tip 要点
**IP 地址**（例如 `192.168.0.10`）是设备在网络中的地址——就像门牌号一样。每个 IP 地址在一个网络中只能出现**一次**。
:::

:::task
title: 地址分配正确吗？
保持在运行模式，检查两台电脑的地址是否合适，并且能否相互访问。
check: ip(1, "192.168.0.10/32")
check: ip(3, "192.168.0.11/32")
check: pingOk(1, 3)
:::

:::note
`/24` 的具体含义，以及如何合理地划分网络，我们会在第 4 章详细讲解。现在只需记住：两个地址都必须以 `192.168.0.` 开头，并且不能重复。
:::

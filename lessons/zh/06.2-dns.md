# DNS：用名称代替数字

:::goal
**学习目标：** 你能够解释 DNS 如何把名称转换为 IP 地址，名称是如何按层次结构组织的，能够自己创建一条记录，并找出典型的 DNS 故障。
:::

:::sim
url=/sims/lesson-6.2.btsim
:::

几乎没有人能记住 IP 地址——但像 `www.beaver-schule.de` 这样的名称却很容易记住。负责这种转换的是**域名系统**（**DNS**，Domain Name System），它就像一本覆盖全球的互联网电话簿。

现在工作区上有一个稍大一些的网络：除了 **Client-PC** 和 **Webserver** 之外，还有四台 **DNS-Server**。为什么需要这么多，你会在下下页看到。

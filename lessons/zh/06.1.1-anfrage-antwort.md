可见,一个网页往往由许多文件组成:文本、样式表、图片。浏览器会为每个文件单独发送一个请求。

## 请求是什么样子

在追踪中点击数据包 `GET / HTTP/1.1`,并展开 **Hypertext Transfer Protocol**。HTTP 请求是纯文本:

```
GET / HTTP/1.1              ← Methode, Pfad, Version
Host: 192.168.0.20          ← Header: zusätzliche Angaben
…
                            ← Leerzeile: Ende der Anfrage
```

服务器的响应结构与此相同——先是状态行和若干 Header,然后是一个空行,最后才是文件本身:

```
HTTP/1.1 200 OK             ← Version, Statuscode, Text
Content-Type: text/html     ← Header: Art der Datei
Content-Length: 301         ← Header: Größe in Byte
                            ← Leerzeile
<!doctype html> …           ← die Datei selbst
```

:::seq
mode: text
Client-PC -> Server: GET / | HTTP-Anfrage
Server -> Client-PC: 200 OK | index.html
Client-PC -> Server: GET /style.css | HTTP-Anfrage
Server -> Client-PC: 200 OK | style.css
:::

## 方法与状态码

**方法**表示客户端想要做什么:

| 方法 | 含义 |
|---|---|
| **GET** | 获取一个文件 |
| **POST** | 向服务器发送数据,例如填写好的表单 |
| **HEAD** | 只获取 Header,不获取文件 |

**状态码**表示处理结果如何。第一位数字表明响应的类型:

| 状态码 | 文本 | 含义 |
|---|---|---|
| **200** | OK | 一切正常 |
| **301** | Moved Permanently | 页面已永久迁移 |
| **404** | Not Found | 该文件不存在 |
| **405** | Method Not Allowed | 此处不允许使用该方法 |
| **500** | Internal Server Error | 服务器出错 |

`2xx` 表示成功,`3xx` 表示重定向,`4xx` 表示客户端错误(错误的请求),`5xx` 表示服务器错误。

:::tip 要点
**HTTP** 遵循**请求-响应原则**:客户端发送一个**请求**(方法如 `GET`、路径、Header),服务器则以**状态码**(例如 `200 OK`、`404 Not Found`)、Header 和文件作为响应。网页中的每个文件都对应一个单独的请求。
:::

:::quiz match
200 -> 一切正常
301 -> 页面已永久迁移
404 -> 请求的文件不存在
500 -> 服务器上发生了错误
:::

# 哈希值：数据的指纹

:::sim
url=/sims/lesson-8.1.3.btsim
:::

**哈希函数**可以把任意数量的数据——一句话、一份文档、一整部电影——计算成一段长度固定的短字符串：**哈希值**。它就像**指纹**：相同的数据总是得到相同的哈希值，不同的数据则得到不同的哈希值。

目前常用的哈希函数是 **SHA-256**。它的哈希值始终为 256 位，用十六进制表示就是 64 个字符。

## 实验

在 **PC** 的 `/home` 文件夹中有三个文件，内容是一份简单的购买合同。切换到 :fa-play: **运行**模式，在 **PC** 上打开 :fa-terminal: **终端**，然后输入：

```
$ cd /home
$ cat vertrag.txt vertrag-kopie.txt vertrag-neu.txt
$ sha256sum vertrag.txt vertrag-kopie.txt vertrag-neu.txt
```

## 哈希函数的特性

| 特性 | 含义 |
|---|---|
| **长度固定** | 无论数据有多大，哈希值的长度始终相同。 |
| **确定性** | 相同的数据总是得到相同的哈希值。 |
| **雪崩效应** | 哪怕是最微小的改动，也会得到完全不同的哈希值。 |
| **单向函数** | 无法由哈希值反推出原始数据。 |
| **抗碰撞性** | 实际上不可能找到两个具有相同哈希值的不同文件。 |

哈希函数**不是加密**：它没有密钥，也没有解密。它的用途不同——保证**完整性**。

## 它有什么用？

- **校验下载文件：** 许多网站除了提供文件之外，还会给出它的 SHA-256 值。如果你下载的文件的哈希值与之一致，就说明它在传输途中没有被篡改。
- **存储密码：** 好的网站不会存储你的密码本身，而只存储它的哈希值。登录时，会比较你输入内容的哈希值。即使数据库被盗，窃贼也无法得知密码。
- **数字签名：** 人们不对整份文档签名，而只对它的哈希值签名——详见下一节。

:::tip 要点
**哈希函数**（例如 **SHA-256**）可以把任意数据计算成长度固定的**哈希值**——即**指纹**。哪怕是最微小的改动，也会得到完全不同的哈希值，而且无法由哈希值反推出数据。哈希值用来保证数据的**完整性**。
:::

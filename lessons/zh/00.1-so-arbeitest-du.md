# 如何使用本课程

本课程直接在 BeaverTracer 中进行:你在左侧搭建并观察网络,在右侧的**课程窗格**中阅读相应的操作指南。

## 翻页

通过**上一页**和**下一页**,你可以一页一页地学习课程。通过**目录**(或课程窗格顶部的 :fa-list:),你可以跳转到任意章节。

## 每一页都有对应的模拟

每次切换页面时,BeaverTracer 都会自动加载与该页面对应的模拟——这样你总是从一个可正常运行的状态开始。

:::warning
你在某一页上搭建或修改的内容,到下一页就会消失。这是有意为之:每一页都从一个干净的初始状态开始。
:::

- 点击课程窗格顶部的 :fa-rotate-left:,可以把模拟重置到当前页面的初始状态——当你搞乱了的时候很实用。
- 如果你想在某个模拟的基础上自己继续搭建,请点击工具栏中的 :fa-file-import: **采用**。课程窗格会关闭,这个模拟就归你所有了。

## 保存与加载

一个模拟就是一个单独的文件(`.btsim`),它描述了你完整的网络——所有设备、线缆及其设置。只要课程窗格处于打开状态,:fa-file: **新建**、:fa-file-arrow-up: **加载**和 :fa-file-arrow-down: **保存**这几个按钮就会被隐藏。点击**采用**之后(或者用 **×** 关闭课程窗格之后),你可以在工具栏中模式按钮的右侧找到它们——在编辑模式下。

## 提示框、测验与任务

:::goal
**学习目标**——位于一个章节的开头:学完之后你就能做到这些。
:::

:::tip 要点
简要概括一个重要的专业术语或知识关联——适合用来备考。
:::

- **测验题**直接在页面上作答,并用下方的按钮进行检查。只要仔细观察,几乎所有答案都可以从你的屏幕上读出来。
- 带有**检查任务**按钮的**任务**会查看你的模拟,检查是否一切设置正确——例如两台 PC 是否可以互相访问。

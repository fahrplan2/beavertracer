# 自动获取地址

:::sim
url=/sims/lesson-6.4.btsim
:::

交换机上连接了一台 **DHCP 服务器**和两台笔记本电脑。笔记本电脑目前仍使用固定地址。

## 实验

1. 切换到 :fa-play: **运行**模式，点击 **Laptop 1**，打开 :fa-gear: **IP设置**。
2. 将**模式**从**静态**改为 **DHCP**，然后点击**应用**。
3. 等待几秒钟：各个字段会自动填充。
4. 在 :fa-magnifying-glass: **追踪**模式下，为 **Laptop 1** 打开一个追踪。

:::quiz table
| 设置 | 从 DHCP 服务器获得 |
|---|---|
| IP 地址 | {192.168.0.100} |
| 网关 | {192.168.0.1} |
| DNS 服务器 | {192.168.0.53} |
:::

:::quiz short
你在追踪中能找到多少个 DHCP 数据包？
= 4
= 四
= 四个
:::

:::quiz mc

- [x] 发送到 `255.255.255.255` — 发给所有设备（广播）

## 背后的原理：DORA

没有地址的设备既不知道 DHCP 服务器在哪里，也没有属于自己的发送方地址。因此它通过**广播**向网络中呼叫。整个过程分为四个步骤，取其首字母，称为 **DORA**：

:::seq
mode: text
Laptop 1 -> DHCP-Server: DHCP Discover | „这里有 DHCP 服务器吗？“
DHCP-Server -> Laptop 1: DHCP Offer | „你可以使用 192.168.0.100。“
Laptop 1 -> DHCP-Server: DHCP Request | „我要使用 192.168.0.100。“
DHCP-Server -> Laptop 1: DHCP ACK | „已确认 — 有效期 3600 秒。“
:::

这个地址只是**租用**的（*Lease*）：**租约时间**到期后，设备必须续租，否则服务器可以将该地址重新分配出去。当前哪些地址已被租出，你可以在 **DHCP 服务器**的 **Leases** 标签页中看到。

:::tip 试一试
也把 **Laptop 2** 设置为 DHCP。它会得到哪个地址？然后查看 DHCP 服务器的 **Leases**。
:::

:::tip 要点
**DHCP** 自动分发 IP 地址、子网掩码、网关和 DNS 服务器。其过程称为 **DORA**：**D**iscover（客户端通过广播寻找服务器）、**O**ffer（服务器提供地址）、**R**equest（客户端接受地址）、**A**CK（服务器确认）。该地址在**租约时间**内被租用。DHCP 使用 **UDP**，端口为 67（服务器）和 68（客户端）。
:::

:::quiz match
Discover -> 客户端通过广播寻找 DHCP 服务器
Offer -> 服务器提供一个地址
Request -> 客户端请求所提供的地址
ACK -> 服务器确认地址分配
:::

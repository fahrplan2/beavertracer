# 为什么一个网络不够用

:::sim
url=/sims/lesson-4.1.btsim
:::

在工作区中,你可以看到两个小型公司网络:**Firma A** 有 Anna(`192.168.0.10`)和 Ben(`192.168.0.11`),**Firma B** 有 Clara(`172.16.0.10`)和 David(`172.16.0.11`)。两台交换机甚至直接用一根网线连接在一起。

## 在自己网络内 ping

1. 切换到 :fa-play: **运行**模式,在 **Anna** 上打开 :fa-terminal: **终端**,然后 ping Ben:
   ```
   $ ping 192.168.0.11
   ```
2. 切换到 :fa-magnifying-glass: **追踪**模式,为 **Anna** 打开一个追踪,然后点击一条 `Echo (ping) request`。
3. 在协议树中展开 **Internet Protocol Version 4** 这一行。这是数据包中的 IP 部分——也是本章要讲的内容。

:::quiz match
Source Address -> 发送方的 IP 地址
Destination Address -> 接收方的 IP 地址
Time to Live -> 数据包还可以经过多少个路由器
Protocol -> 数据包中封装的是哪种协议(这里是 ICMP,也就是 ping)
:::

:::evaluate
检查配对
:::

## ping 另一个网络

切换回 :fa-play: **运行**模式,从 **Anna** 出发 ping Clara(`ping 172.16.0.10`)。然后再看一下 Anna 的追踪。

:::quiz mc
会发生什么?
- [ ] ping 成功——交换机不是已经连接了吗
- [x] 没有 ping 到达,而且在 Anna 的追踪中没有出现任何发往 Clara 的数据包——甚至连 ARP 请求也没有
- [ ] Anna 发出了 ARP 请求,但 Clara 没有应答
:::

:::quiz mc
为什么 Anna 什么都没有发送?
- [ ] 交换机之间的网线坏了
- [ ] Clara 已关机
- [x] Anna 从 Clara 的 IP 地址看出 Clara 位于另一个网络——而且不知道通往那里的路径
:::

:::evaluate
检查答案
:::

## 背后的原理

IP 地址的作用类似于邮寄地址:一部分说明设备位于哪个**网络**(就像街道),另一部分说明指的是该网络中的哪台**设备**(就像门牌号)。Anna 位于网络 `192.168.0…`,Clara 位于网络 `172.16.0…`——是两条不同的"街道"。

对于*本*网络中的设备,PC 会直接发送数据包(通过 ARP 和交换机,就像你已经了解的那样)。而要到达*其他*网络,它需要一台能把各个网络连接起来并转发数据包的设备:**路由器**。这里还没有路由器——所以交换机之间的那根网线也无济于事。

:::tip 要点
第 3 层的**网际协议**(**IP**)负责让数据包也能在不同网络之间送达。**IP 地址**由一个**网络部分**(在哪个网络?)和一个**主机部分**(哪台设备?)组成。同一网络中的设备可以直接互相访问——要访问其他网络,则需要**路由器**。
:::

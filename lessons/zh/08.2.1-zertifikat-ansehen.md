# 查看证书

:::sim
url=/sims/lesson-8.2.1.btsim
:::

在工作区中,你可以看到**Client-PC**、一台**DNS-Server**以及学校的网站服务器 `www.beaver-schule.de`。这台网站服务器同时也通过 **HTTPS** 提供网页。

## 浏览器中的小锁

1. 切换到 :fa-play: **运行**模式,点击 **Client-PC**,并打开 :fa-globe: **浏览器**。
2. 访问 `https://www.beaver-schule.de/`——注意要使用 **https**。
3. 地址栏左侧会出现一个**小锁**。点击它。

:::quiz short
该证书是颁发给哪个名称的(使用者,不含 `CN=`)?
= www.beaver-schule.de
:::

:::quiz short
是谁颁发了该证书(颁发者,不含 `CN=`)?
= Biber Root CA
:::

:::evaluate
检查答案
:::

## 为什么 Client-PC 信任该证书?

在 **Client-PC** 上打开 :fa-shield-halved: **Zertifikatverwaltung**,并切换到**Vertrauenswürdige CAs**标签页。

:::quiz mc
你在那里发现了什么?
- [x] **Biber Root CA** 的证书
- [ ] `www.beaver-schule.de` 的证书
- [ ] 没有任何条目
:::

:::quiz mc
如何看出 Biber Root CA 是一个根 CA?
- [x] 它是**自签名**的:使用者和颁发者相同
- [ ] 它的名称以“CA”结尾
- [ ] 它没有公钥
:::

:::quiz mc
在 Client-PC 上,**Privater Schlüssel** 一栏显示的是“Ja”还是“Nein”?
- [ ] Ja——客户端需要 CA 的私钥来验证签名
- [x] Nein——验证时只需公钥即可;私钥只有 CA 持有
:::

:::evaluate
检查答案
:::

## 另一端:网站服务器

现在在网站服务器 **www.beaver-schule.de** 上打开 :fa-shield-halved: **Zertifikatverwaltung**(**Meine Zertifikate**标签页),并查看它的证书。

:::quiz multi
关于网站服务器上的证书,下列哪些说法是正确的?
- [x] **Privater Schlüssel** 一栏显示“Ja”——服务器在连接建立时需要它
- [x] **证书链**为 `www.beaver-schule.de ← Biber Root CA`
- [x] **指纹**与浏览器小锁窗口中的相同
- [ ] 它是自签名的
:::

:::evaluate
检查答案
:::

:::note
**指纹**是对证书计算得到的哈希值。借助它可以快速比较两个证书,而无需逐个检查所有字段。
:::

:::tip 要点
**网站服务器**持有自己的证书,**并且带有私钥**。**客户端**只知道**根 CA 的证书**(不含私钥)——这足以让它验证服务器证书上的签名。在浏览器中点击**小锁**,就可以看到使用者、颁发者、指纹和有效期。
:::

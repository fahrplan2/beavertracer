# POP3 还是 IMAP?

:::sim
url=/sims/lesson-6.3.btsim
:::

收取邮件有两种协议。在这个模拟中,**Anna 使用 POP3**,**Ben 使用 IMAP**。

## 实验

1. 在 :fa-play: **运行**模式下,从 **Ben** 向 `anna@beaver-schule.de` 发送一封邮件。
2. 在 **Anna** 的 **E-Mail** 应用中点击**获取**。
3. 打开 **Anna** 和 **Ben** 的追踪记录,比较收取邮件时使用的命令。

:::quiz match
USER / PASS -> POP3: 分两步使用用户名和密码登录
RETR -> POP3: 下载一封邮件
LOGIN -> IMAP: 使用用户名和密码登录
SELECT INBOX -> IMAP: 打开服务器上的一个文件夹
:::

:::evaluate
检查配对
:::

## 区别

| | POP3 | IMAP |
|---|---|---|
| 端口 | 110 | 143 |
| 基本思路 | 将邮件**下载**到本地——之后通常会在服务器上删除 | 邮件**保留在服务器上**,并在服务器上管理 |
| 文件夹、已读/未读 | 仅保存在自己的设备上 | 保存在服务器上——所有设备保持一致 |
| 多台设备(手机、笔记本电脑) | 不方便:每台设备的状态各不相同 | 理想:所有设备看到同一个邮箱 |

:::note
BeaverTracer 中的邮件程序即使使用 POP3,也会把邮件留在服务器上。真实的邮件程序下载后往往会将其删除,或者只在服务器上保留一段时间。
:::

:::quiz mc
Lena 在手机、平板电脑和学校的笔记本电脑上阅读邮件。她应该使用什么?
- [ ] POP3,因为它更简单
- [x] IMAP,因为所有设备看到的是服务器上的同一个邮箱
- [ ] SMTP,因为它是用来收取邮件的
:::

:::evaluate
检查答案
:::

:::tip 要点
**POP3** 把邮件从服务器下载到**一台**设备上。**IMAP** 则在**服务器上**管理邮箱——文件夹和已读状态会同时对所有设备生效。两者都只用于**收取**邮件;发送邮件始终使用 **SMTP**。
:::

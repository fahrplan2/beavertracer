# 添加静态路由

:::sim
url=/sims/lesson-4.5.2.btsim
:::

这次公司 A 和公司 B 之间有**两台**路由器。它们通过一个专用的小型网络相连，这个网络称为**中间网络**，即 `10.0.0.0/30`：

| 路由器 | 接口 | IP 地址 | 网络 |
|---|---|---|---|
| Router A | `eth0` | `192.168.0.1/24` | 公司 A（Anna） |
| Router A | `eth1` | `10.0.0.1/30` | 中间网络 |
| Router B | `eth0` | `10.0.0.2/30` | 中间网络 |
| Router B | `eth1` | `172.16.0.1/24` | 公司 B（Clara） |

:::note
一个 `/30` 网络恰好有两个可用地址，非常适合用来连接两台路由器（参见第 4.2.3 节）。
:::

## 问题所在

切换到 :fa-play: **运行**模式，从 **Anna** ping Clara（`ping 172.16.0.10`）。Clara 没有回应，而是 Router A（`192.168.0.1`）返回“目标网络不可达”。

看一看 **Router A** 的**路由表 IPv4**。

:::quiz mc
为什么 Anna 的 ping 无法到达 Clara？
- [ ] Anna 没有设置网关
- [x] Router A 不知道网络 `172.16.0.0/24`——该网络并未直接连接到它，而且也没有通往那里的路由
- [ ] 中间网络太小
:::

:::evaluate
检查答案
:::

## 添加路由

Router A 必须学会：发往 `172.16.0.0/24` 的数据包要交给 Router B（`10.0.0.2`），并且通过 `eth1` 发出。

1. 在 **Router A** 上打开**路由表 IPv4**标签页，点击 **+ hinzufügen**。
2. 在新增的一行中填写：**Ziel** `172.16.0.0`，**子网掩码** `255.255.255.0`，**下一跳** `10.0.0.2`，**Iface** `eth1`。
3. 点击对勾 :fa-check: 保存这一行。此时 **Quelle** 列中显示 **静态**。

再次 ping Clara——现在有回应了。

:::note
顺便说一下，Router B 已经知道返回公司 A 的路：它的路由表中已经有一条经由 `10.0.0.1`、指向 `192.168.0.0/24` 的静态路由。为什么这条回程路由同样重要，你会在下一页看到。
:::

## 追踪路径：traceroute

使用 `traceroute` 可以显示数据包经过了哪些路由器。在 **Anna** 上输入：

```
$ traceroute 172.16.0.10
```

:::quiz short
从 Anna 到 Clara 的数据包经过几台路由器？
= 2
= 两台
= 两
:::

:::quiz mc
`traceroute` 为 Router B 显示的是哪个地址？
- [x] `10.0.0.2`——它在中间网络中的地址，数据包就是从这里进入的
- [ ] `172.16.0.1`——它在公司 B 中的地址
- [ ] `192.168.0.1`
:::

:::evaluate
检查答案
:::

`traceroute` 利用了第 4.3.1 节中的**生存时间（TTL）**这一技巧：它首先发送一个 TTL 为 1 的数据包。第一台路由器将 TTL 减 1，结果变为 0，于是丢弃该数据包，并向发送方报告——这样 Anna 就知道了第一台路由器。接着用 TTL 2 探测第二台路由器，依此类推，直到目标主机作出响应。

:::tip 要点
**静态路由**由管理员手动添加：目标网络、子网掩码、下一跳和接口。使用 **traceroute** 可以逐台路由器地追踪数据包的路径。
:::

check: hasRoute(3, "172.16.0.0/24")

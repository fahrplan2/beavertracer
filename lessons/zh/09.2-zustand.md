# 无状态与有状态

一个连接总是包含**两个方向**:教师电脑向互联网上的 Web 服务器发送请求,Web 服务器再把网页发回来。因此,遵循白名单原则的防火墙不仅要放行请求,还必须放行**响应**。

为此有两种数据包过滤器:

| | **无状态**(*stateless*) | **有状态**(*stateful*) |
|---|---|---|
| 工作方式 | 逐个检查每个数据包,没有记忆 | 把允许的连接记录在**状态表**中 |
| 响应 | 需要为返回方向单独设置一条规则 | 因属于已知连接而被自动放行 |
| 应用场景 | 简单设备、速度极快的过滤器 | 如今几乎所有的防火墙 |

在接下来的两个小节中,你将体验到无状态过滤器为什么在处理响应时会出问题,以及有状态防火墙是如何解决这个问题的。

# 展望：动态路由

在项目中，你为四个站点手动配置了十二条路由。大型企业网络有数百台路由器，互联网则有数万台——而且总有某处的线路中断，或者有新的线路加入。靠手动配置已经无法应付了。

因此，路由器通常会自动相互交换路由信息。这要用到**路由协议**。这种方式称为**动态路由**，与之相对的是**静态路由**，即所有路由都由人工手动配置。

最常见的路由协议：

| 协议 | 基本思想 | 典型应用 |
|---|---|---|
| **RIP**（*Routing Information Protocol*） | 每台路由器定期告诉相邻路由器，自己能到达哪些网络，以及距离多少台路由器（*跳数*）。 | 小型网络、教学示例 |
| **OSPF**（*Open Shortest Path First*） | 每台路由器都掌握整个网络的完整拓扑，并据此自行计算最短路径。 | 企业网络 |
| **BGP**（*Border Gateway Protocol*） | 大型网络运营商（例如互联网服务提供商）相互通告自己能到达哪些网络。 | 互联网服务提供商之间的互联网 |

:::quiz match
RIP -> 路由器告诉相邻路由器，自己到达某个网络需要经过多少跳
OSPF -> 每台路由器都了解整个网络拓扑，并计算最短路径
BGP -> 连接大型互联网服务提供商的网络
:::

:::tip 要点
在**静态路由**中，管理员手动配置所有路由。在**动态路由**中，路由器借助 RIP、OSPF 或 BGP 等**路由协议**自动交换路由信息——并在连接中断时自行调整。
:::

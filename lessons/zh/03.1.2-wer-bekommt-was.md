# 谁会收到哪个数据包?

:::sim
url=/sims/lesson-3.1.2.btsim
:::

现在 Anna、Ben 和 Clara 都连接在交换机上(端口 1、2 和 3)。当 Anna 向 Ben 发送一个数据包时:只有 Ben 会收到,还是 Clara 也会收到?

先想一想你的猜测,然后再动手试一试。

## 实验

1. 切换到 :fa-play: **运行**模式,在 **Anna** 上打开 :fa-terminal: **终端**,ping Ben:
   ```
   $ ping 192.168.0.11
   ```
2. 切换到 :fa-magnifying-glass: **追踪**模式,点击 **+** 为 **Clara** 的端口 `eth0` 打开一个追踪。
3. 再次点击 **+**,为 **Ben** 的端口 `eth0` 打开第二个追踪。在顶部你可以在两个追踪之间来回切换。

:::

## 背后的原理

这个 ARP 请求的目标是**广播**——它是发给*所有*设备的。因此交换机把它转发到了每一个端口,也包括 Clara 的端口。而 ping 包只以 Ben 为目标地址。交换机只把它们发送到 Ben 的端口——Clara 对此毫无察觉。

:::tip 要点
**广播**是发给本地网络中所有设备的——交换机会把它分发到所有端口。**单播**只发给某一台设备——交换机只把它发送到该设备所连接的端口。
:::

## 看看交换机内部

但是交换机怎么知道 Ben 连接在哪个端口呢?切换回 :fa-play: **运行**模式,点击**交换机**。在 **SAT** 标签页中,你可以看到它的地址表,共有两列:**MAC** 和 **Port**。

:::quiz mc
地址表中有哪些设备?
- [ ] Anna、Ben 和 Clara
- [x] 只有 Anna 和 Ben
- [ ] 只有 Ben
:::

:::quiz short

= 2
= 端口 2
= port 2
:::

:::quiz mc
为什么表中没有 Clara?
- [ ] 她的网线坏了
- [x] 她还没有发送过任何数据包
- [ ] 交换机最多只能存储两个表项
:::

:::evaluate
检查答案
:::

交换机会不断**学习**:对于到达的每一个帧,它都会查看**发送方** MAC 地址,并记住这个设备连接在哪个端口上。当 Anna 的 ARP 请求到达时,它记下了“Anna → 端口 1”;收到 Ben 的应答时,记下了“Ben → 端口 2”。Clara 没有发送过任何内容,所以交换机还不认识她。

:::tip 要点
交换机在它的**地址表**(**SAT**,*Source Address Table*,源地址表)中记录:通过哪个 MAC 地址可以在哪个端口找到哪台设备——它从发送方地址中学习这些信息。如果它知道某个帧的目标,就只把该帧发送到对应的端口。如果它不知道(或者该帧是广播),就把它发送到所有端口。
:::

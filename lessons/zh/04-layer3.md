# 第 3 层：路由器、IP 地址与子网划分

:::goal
**学习目标：** 你能够以二进制形式读懂 IP 地址，计算网络地址和广播地址，把一个网络划分为大小相同的子网，并通过路由器和路由表把不同的网络连接起来。
:::

到目前为止，所有设备都位于*同一个*局域网中——通过交换机和接入点相互连接。但互联网是由数百万个这样的网络组成的：你的家庭网络、学校网络、移动运营商的网络，以及大型数据中心的网络。

数据包是如何从一个网络找到通往另一个网络的路径的呢？这正是**第 3 层**，即网络层的任务——它依靠**网际协议（Internet Protocol，IP）**、IP 地址，以及负责连接各个网络的设备：**路由器**。

:::note
自 1981 年起，IP 就由一项标准确定下来，即 **RFC 791**。本章主要讲的版本称为 **IPv4**。较新的版本 **IPv6** 你将在本章末尾学到。
:::

# 跨两台交换机的 VLAN：Trunk

:::sim
url=/sims/lesson-3.2.2.btsim
:::

学校有两层楼，每层一台交换机，两台交换机通过 **8 号端口**上的一根网线相连：

| 交换机 | 端口 1（VLAN 10，行政管理） | 端口 2（VLAN 20，机房） |
|---|---|---|
| **Switch EG**（一楼） | Sekretariat `192.168.0.10` | Anna `192.168.0.20` |
| **Switch OG**（二楼） | Schulleitung `192.168.0.11` | Ben `192.168.0.21` |

PC 端口上的 VLAN 已经配置好了。

## 问题

切换到 :fa-play: **运行**模式，从 **Anna** 去 ping Ben（`ping 192.168.0.21`）。两者都在 VLAN 20 中，却收不到任何回复。

在任意一台交换机的 **VLAN** 标签页中查看 **port 8** 这一行：它仍然是 `untagged`，PVID 为 `1`。也就是说，这根网线上只通行 VLAN 1，既不通行 VLAN 10，也不通行 VLAN 20。

但是，两台交换机之间的这根网线必须同时传输来自*两个* VLAN 的帧。为此，交换机会在每个帧上贴一张小标签，上面写着 VLAN ID，这就是 **VLAN 标记**（VLAN Tag）。这样，另一端的交换机就知道这个帧属于哪个 VLAN。

## 配置 Trunk

请在**两台**交换机上都这样做：

1. 点击交换机，打开 **VLAN** 标签页。
2. 在 **port 8** 这一行，将**模式**设为 `tagged`，并在**允许的 VLAN**中填入 `10,20`。
3. 点击**应用**。

然后再次从 **Anna** ping Ben，并且作为对比，也 ping 一下 Schulleitung（`ping 192.168.0.11`）。

:::quiz mc
现在会发生什么？
- [x] Anna 能访问 Ben，但访问不到 Schulleitung
- [ ] Anna 能访问 Ben 和 Schulleitung
- [ ] Anna 仍然访问不到任何人
:::

:::evaluate
检查答案
:::

## 追踪器中的 VLAN 标记

切换到 :fa-magnifying-glass: **追踪**模式，点击 **+**，为 **Switch EG** 的 **8** 号端口打开一个追踪，这正是两台交换机之间的那根网线。点击 Anna 的其中一个 ping（`Echo (ping) request`）。

在协议树中，紧挨着 Ethernet 下方多出了一行：**802.1Q Virtual LAN**。这就是 VLAN 标记。

:::quiz short
Anna 的 ping 的标记中，VLAN ID 是多少？
= 20
:::

作为对比，再为 **Ben**（`eth0`）打开一个追踪，并在那里点击同一个 ping。

:::quiz mc
你在 Ben 那里发现了什么？
- [ ] 那里有同样的标记，ID 为 20
- [x] 那里没有 802.1Q 这一行：交换机在到达 Ben 的端口之前已经把标记移除了
- [ ] 这个 ping 根本没有到达 Ben
:::

:::evaluate
检查答案
:::

:::tip 要点
**Trunk**（干道）是一种可以传输来自多个 VLAN 的帧的连接，通常用于两台交换机之间。为此，每个帧都会带上一个包含 VLAN ID 的 **VLAN 标记**（标准为 **IEEE 802.1Q**）。这类端口称为 **tagged** 端口。**untagged** 端口上连接的是普通设备；交换机在把帧发往该端口之前，会先移除标记。
:::

# 无线电波人人都能监听

:::sim
url=/sims/lesson-3.3.2.btsim
:::

现在 WLAN `Schule` 中有两台平板电脑：**Anna**（`192.168.0.30`）和 **Ben**（`192.168.0.31`）。

回想一下 3.1 章：当 Anna 通过交换机 ping Ben 时，Clara 对此毫无察觉——交换机只把 ping 数据包发到了 Ben 的端口。WLAN 中也是这样吗？先想一想，你的猜测是什么。

## 实验

1. 切换到 :fa-play: **运行**模式，从 **Anna** ping 学校电脑（`ping 192.168.0.10`）。
2. 切换到 :fa-magnifying-glass: **追踪**模式，点击 **+** 为 **Ben** 的 `wlan0` 接口打开一个追踪。

:::quiz mc
你在 Ben 那里看到了什么？
- [ ] 只有 Anna 的 ARP 请求——和交换机的情况一样
- [x] Anna 与学校电脑之间的所有数据包，包括 ping
- [ ] 什么都没有，ping 与 Ben 无关
:::

:::evaluate
检查答案
:::

## 背后的原理

无线电波会向四面八方传播。因此，Anna 发送的内容会到达附近的*每一台*设备——而不仅仅是接入点。无线电是一种**共享介质**。Ben 的平板电脑通常会忽略所有不是发给它的数据。但是，任何*想要*抓包的人，都可以读取所有内容。

| | 交换机（有线） | WLAN（无线） |
|---|---|---|
| 谁会收到单播？ | 只有接收方所在的端口 | 范围内的每一台设备 |
| 第三方能否窃听？ | 通常不能 | 可以，毫不费力 |

:::tip 要点
无线电是一种**共享介质**：在 WLAN 中发送的所有内容，范围内的每台设备都能接收到。因此 WLAN 必须**加密**（如今使用 **WPA2** 或 **WPA3**）——这样陌生人虽然能接收到数据，但无法读懂。
:::

:::note
BeaverTracer 不模拟 WLAN 加密——所以你在这里可以读取所有内容。加密是如何工作的，你将在第 8 章学到。
:::

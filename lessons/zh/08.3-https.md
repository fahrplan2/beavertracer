# HTTPS

:::osi 5
:::

**HTTPS**（*HTTP Secure*）就是普通的 HTTP——只不过它不是直接运行在 TCP 之上，而是中间多了一个加密层：**TLS**（*Transport Layer Security*）。TLS 的前身叫 **SSL**，所以人们至今仍常说“SSL 证书”。

```
ohne Verschlüsselung:   HTTP  →  TCP  →  IP
mit Verschlüsselung:    HTTP  →  TLS  →  TCP  →  IP
```

HTTP 对此毫无察觉：它照常发送请求，TLS 负责加密，TCP 负责传输。在 OSI 模型中，TLS 位于传输层和应用层之间，也就是第 4/5 层——它建立在 TCP 之上，并管理一个受保护的会话。

| | HTTP | HTTPS |
|---|---|---|
| 端口 | 80 | **443** |
| 地址 | `http://…` | `https://…` |
| 在追踪器中能读到内容？ | 能 | 不能 |
| 浏览器显示 | “不安全” | 锁形图标 |

TLS 在连接建立时完成了你在本章学到的所有事情：

- 服务器用自己的**证书**证明身份（**真实性**）。
- 双方通过 **Diffie-Hellman** 协商出一个**会话密钥**——服务器会对自己的那一部分进行**签名**。
- 之后所有数据都用 **AES** 加密（**机密性**），并受到防篡改保护（**完整性**）。

这一原理并不局限于 Web：电子邮件（第 8.4 节）和许多其他协议也以同样的方式通过 TLS 运行。

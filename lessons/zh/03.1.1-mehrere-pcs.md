# 将多台 PC 连接到交换机

:::sim
url=/sims/lesson-3.1.1.btsim
:::

工作区中有一台交换机和三台 PC：**Anna**、**Ben** 和 **Clara**。它们的 IP 地址已经设置好了（`192.168.0.10`、`.11` 和 `.12`）——现在只差连线了。

## 连线

1. 切换到 :fa-pencil: **编辑**模式，并选择 :fa-link: **Verbindung** 工具。
2. 点击 **Anna**，然后点击 **Switch**。会出现一个列有交换机端口（1 到 8）的选择框——选择 **1**。
3. 再次选择 :fa-link:，把 **Ben** 连接到端口 **2**，把 **Clara** 连接到端口 **3**。

现在每根线缆上都能看到一个小数字：它表示线缆插在交换机的哪个端口上。

:::tip 要点
**交换机**是一种带有许多接口的分配设备，这些接口称为**端口**（Port）。所有连接到同一台交换机上的设备共同组成一个**局域网**（英文 *Local Area Network*，**LAN**）。
:::

## 测试

切换到 :fa-play: **运行**模式，在 **Anna** 上打开 :fa-terminal: **终端**，然后 ping Clara：

```
$ ping 192.168.0.12
```

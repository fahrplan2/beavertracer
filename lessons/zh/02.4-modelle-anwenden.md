# 应用模型

请把本章开头实验中出现的协议对应到它们所属的 OSI 层：

:::quiz match
Ethernet -> 第 2 层 — 数据链路层
IPv4 -> 第 3 层 — 网络层
TCP -> 第 4 层 — 传输层
HTTP -> 第 7 层 — 应用层
:::

:::evaluate
检查匹配结果
:::

最后，再来匹配各层数据单元的名称：

:::quiz match
帧 -> 第 2 层 — 数据链路层
数据包 -> 第 3 层 — 网络层
段 -> 第 4 层 — 传输层
:::

:::evaluate
检查匹配结果
:::

这样你就掌握了今后准确归类协议的方法。从下一章开始，我们将按顺序逐层讲解——先从第 2 层讲起，看看交换机究竟是如何知道应该把数据包转发到哪里的。

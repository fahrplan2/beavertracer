# DHCP：自动接入网络

:::goal
**学习目标：** 你能够解释设备如何通过 DHCP 自动获取 IP 设置，能够配置 DHCP 服务器，并能识别和排除典型的 DHCP 故障（例如 169.254 开头的地址）。
:::

:::sim
url=/sims/lesson-6.4.btsim
:::

到目前为止，你都是手动为每台设备填写 IP 地址、子网掩码、网关和 DNS 服务器。在拥有数百台笔记本电脑、平板电脑和手机的学校里，这是不可能完成的——而且每一个输入错误都会成为网络中的故障。

这项工作由**动态主机配置协议**（**DHCP**，Dynamic Host Configuration Protocol）来完成：**DHCP 服务器**会把这些设置自动分发给每一台接入网络的设备。

# 故障排查：邮件发不出去

:::sim
url=/sims/lesson-6.3.4.btsim
:::

Anna 反映：“我没法给 Ben 发邮件！”正确的配置*应该*是这样的：

| 项目 | 应有配置 |
|---|---|
| Anna 的发件服务器（SMTP） | `mail.beaver-schule.de`，端口 `25` |
| `biber-mail.de` 的 MX 记录 | `mail.biber-mail.de`（优先级 10） |

找出错误并修复。然后让 Anna 给 `ben@biber-mail.de` 发一封邮件——任务会检查邮件是否已到达 Ben 的邮箱。（邮件服务器之间的转发可能需要几秒钟。）

<details>
<summary>提示 1：Anna 的邮件程序怎么说？</summary>

试着发送一封邮件，并查看 **Protokoll** 标签页。服务器是怎么回应的——这听起来像 SMTP 吗？
</details>

<details>
<summary>提示 2：邮件以错误消息的形式被退回了？</summary>

在 Anna 那里收取邮件，并阅读来自 `MAILER-DAEMON` 的消息。投递是因为什么而失败的？在 Anna 的电脑上用 `nslookup -type=MX biber-mail.de` 查看 DNS 服务器是否知道负责的邮件服务器。
</details>

<details>
<summary>提示 3：这个要在哪里设置？</summary>

发件服务器在 Anna 的 **E-Mail** 应用的 **Einstellungen** 中设置。MX 记录在 **DNS-Server** 的 **MX** 标签页中。
</details>

:::task
title: 邮件到了吗？
检查邮件服务器 Biber 上 Ben 的邮箱里是否有一封邮件。
check: fileExists(5, "/var/mail/ben.mbox")
:::

## 之前出了什么问题？

:::quiz multi
下列哪些说法是正确的？
- [x] Anna 的发件服务器指向了端口 110——那里响应的是 POP3 服务，而不是 SMTP
- [x] `biber-mail.de` 缺少 MX 记录——Mailserver Schule 找不到负责的邮件服务器
- [x] 无法投递的邮件以错误消息的形式从 `MAILER-DAEMON` 退了回来
- [ ] Ben 的密码错误
:::

:::evaluate
检查答案
:::

:::tip 要点
典型的电子邮件故障：邮件程序中的**服务器或端口**错误（SMTP 使用端口 25，POP3 使用 110，IMAP 使用 143），以及 DNS 中**MX 记录**缺失或错误。如果邮件服务器无法投递邮件，就会把邮件连同错误消息退回给发送方（**退信**，Bounce）。
:::

Beaver 学校拥有自己的公网地址（`198.51.100.…`）：它的 **Schulserver** 可以直接从互联网访问——没有 NAT，就像不久之后 IPv6 将在各处实现的那样（第 7.3 章）。在互联网与 **Schulrouter** 之间有一台**防火墙**，不过目前它还放行所有流量。

左侧是“互联网”：一台 **Internet-PC** 和 Web 服务器 `www.beispiel.de`。右侧是学校网络，包含 **Schulserver** 和 **Lehrer-PC**。

## 攻击者能看到什么？

想要攻击服务器的人，首先会寻找**开放端口**——也就是正在等待连接的服务。用于此目的的工具叫做**端口扫描器**；最著名的是 `nmap`。

切换到 :fa-play: **运行**模式，在 **Internet-PC** 上打开 :fa-terminal: **终端**，然后输入：

```
$ nmap 198.51.100.10
```

`nmap` 会尝试与最常见的 20 个端口建立 TCP 连接，并报告哪些端口是开放的。

:::quiz multi
从互联网上看，Schulserver 上有哪些端口是开放的？
- [x] 22（SSH，远程维护）
- [x] 25（SMTP）
- [x] 80（HTTP）
- [x] 110（POP3）
- [x] 143（IMAP）
- [ ] 443（HTTPS）
:::

:::evaluate
检查答案
:::

网站（80）和电子邮件接收（25）应当可以从互联网访问。但是**远程维护**（22）和收取邮件（110、143）只有学校网络内部才需要。每个开放的端口都是潜在的攻击面：如果该服务存在安全漏洞或密码太弱，攻击者可以从世界上任何地方利用它——而互联网上的自动扫描器正是在全天候地尝试这样做。

:::tip 要点
**防火墙**控制两个网络边界处的数据流量，只放行明确允许的内容。这样，仅供内部使用的服务对互联网就是不可见的。
:::

# 项目:一家有四个分支地点的公司

:::sim
url=/sims/lesson-4.5.4.btsim
:::

一家公司的总部在 **Hanau**,分公司位于 **Kassel**、**Gießen** 和 **Darmstadt**。每个地点都有自己的网络和自己的路由器。所有路由器通过专线与一个**中心网络**相连,公司的主服务器也位于这个中心网络中。

## 地址规划

管理员按照下面的方案分配了地址——它们已经填入模拟中:

| 网络 | 地址范围 |
|---|---|
| 中心网络 | `10.19.0.0/24` |
| Hanau | `10.19.1.0/24` |
| Kassel | `10.19.2.0/24` |
| Gießen | `10.19.3.0/24` |
| Darmstadt | `10.19.4.0/24` |

| 设备 | 在中心网络中 | 在地点网络中 |
|---|---|---|
| Server | `10.19.0.10` | — |
| Router Hanau | `10.19.0.1` | `10.19.1.1` |
| Router Kassel | `10.19.0.2` | `10.19.2.1` |
| Router Gießen | `10.19.0.3` | `10.19.3.1` |
| Router Darmstadt | `10.19.0.4` | `10.19.4.1` |
| 各地点的 PC | — | 均为 `.2`(例如 PC Kassel `10.19.2.2`) |

所有路由器上,`eth0` 连接中心网络,`eth1` 连接地点网络。

## 你的任务

要让公司的所有计算机能够互相访问并访问服务器,还缺少两件事:

1. **网关:** 为四台 PC 和服务器都设置网关。PC 使用各自地点的路由器;服务器使用 **Router Hanau**。
2. **路由表:** 为四台路由器补充仍然缺少的路由。每台路由器都必须知道**其他三个**地点的网络。

中途可以用 `ping` 和 `traceroute` 进行测试。

<details>
<summary>提示:这里的路由是什么样的?</summary>

以 **Router Kassel** 为例:发往 Gießen(`10.19.3.0/24`)的数据包要发给位于中心网络中的 Router Gießen——也就是**下一跳** `10.19.0.3`,**Iface** `eth0`。按照这个模式,每台路由器需要三条路由。
</details>

:::task

check: pingOk(13, 19)
check: pingOk(15, 19)
check: pingOk(17, 19)
check: pingOk(13, 15)
check: pingOk(15, 17)
check: pingOk(17, 11)
check: pingOk(11, 13)

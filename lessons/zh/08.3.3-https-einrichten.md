# 设置 HTTPS

:::sim
url=/sims/lesson-8.3.3.btsim
:::

这里接着第 8.2.2 节的内容继续：Web 服务器 **www.beaver-schule.de** 上有 **Schul-CA** 以及由它签发的服务器证书，而且 **Client-PC** 信任 Schul-CA。只是这台 Web 服务器目前还不支持 HTTPS。

## 之前

切换到 :fa-play: **运行**模式，在 **Client-PC** 上用 :fa-globe: **浏览器**访问 `https://www.beaver-schule.de/`。

:::quiz mc
会发生什么？
- [x] 无法建立连接——443 端口上没有任何服务在监听
- [ ] 浏览器警告证书不安全
- [ ] 页面显示出来，但没有锁图标
:::

:::evaluate
检查答案
:::

## 启用 HTTPS

1. 在 Web 服务器上打开 **HTTP 服务器**，点击**停止**——服务器运行期间无法更改设置。
2. 切换到 **HTTPS** 标签页：
    - 勾选**启用 HTTPS**，**HTTPS 端口**设为 `443`
    - 在**证书**中选择服务器证书 `www.beaver-schule.de`——不要选 Schul-CA！
    - 点击**使用**
3. 点击**启动**。

在 Client-PC 上再次通过 `https://` 访问该页面。点击锁图标，检查颁发者和有效期。

:::task
title: HTTPS 设置好了吗？
检查 Client-PC 能否在没有证书警告的情况下获取 https://www.beaver-schule.de/。为此，模拟必须处于运行模式。
check: httpsOk(2, "https://www.beaver-schule.de/")
:::

:::quiz mc
为什么在 HTTP 服务器中不能选择 **Schul-CA** 的证书？
- [ ] 因为 CA 证书不能用于加密
- [x] 因为它是为名称 `Schul-CA` 签发的，而不是为 `www.beaver-schule.de` 签发的——浏览器会发出警告
- [ ] 因为 Schul-CA 没有私钥
:::

:::quiz mc
如果设备**不**信任 Schul-CA（例如访客的手机），它会看到什么？
- [ ] 页面一切正常，并显示锁图标
- [x] 一个证书警告，因为它无法沿着信任链追溯到某个已知的 CA
- [ ] 什么都看不到，因为连接被拒绝
:::

:::evaluate
检查答案
:::

:::note
公开网站需要由所有浏览器都预装了的 CA 签发的证书。自 2015 年起出现了 **Let's Encrypt**，这是一个免费且自动签发此类证书的 CA——这也是如今几乎所有网站都使用 HTTPS 的主要原因之一。
:::

:::tip 要点
**HTTPS** 要求 Web 服务器拥有**带私钥的服务器证书**，且证书中的名称与访问地址一致，并且要在 **443 端口**上监听。只有当客户端认识签发证书的 **CA** 时，才会信任该网站。
:::

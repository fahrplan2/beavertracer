# 让平板接入 WLAN

:::sim
url=/sims/lesson-3.3.1.btsim
:::

交换机上连接着 **Schul-PC**(`192.168.0.10`)和一个**接入点**。平板 **Anna**(`192.168.0.30`)要接入学校的 WLAN。

## 找到 WLAN

切换到 :fa-play: **运行**模式,然后点击**接入点**。这里显示了它的 WLAN 名称,即 **SSID**:`Schule`。

接入点的工作方式类似网桥:通过无线电到达它的数据,它会经由网线转发给交换机,反过来也一样。这样 Anna 和 Schul-PC 就处在同一个局域网中了。

## 连接平板

1. 点击 **Anna**,打开 :fa-gear: **IP设置**,然后切换到 **WiFi** 标签页。
2. 在 **SSID** 处输入 WLAN 的名称 `Schule`,然后点击**应用**。
3. 在 Anna 上打开 :fa-terminal: **终端**,ping Schul-PC:
   ```
   $ ping 192.168.0.10
   ```

ping 的时候请留意工作区:Anna 和接入点周围会扩散出无线电波。

:::tip 要点
**WLAN** 是通过无线电实现的局域网。**接入点**把 WLAN 与有线网络连接起来。每个 WLAN 都有一个名称,即 **SSID**(*Service Set Identifier*,服务集标识符)——设备必须知道正确的 SSID 才能连接。
:::

:::quiz mc
如果你在 Anna 上把 SSID 填成 `schule`(小写),会发生什么?
- [ ] 什么也不会发生——大小写无关紧要
- [x] Anna 不再处于连接状态——SSID 必须完全一致
- [ ] Anna 连接到另一个 WLAN
:::

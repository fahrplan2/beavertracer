HTTP、DNS、电子邮件和 DHCP 是你在日常生活中经常遇到的协议。除此之外还有许多其他协议——这里简要介绍其中最重要的几个。其中一些你可以直接在 BeaverTracer 中亲自试一试：它们用 :fa-flask: 标记。

| 协议 | 端口 | 传输层协议 | 用途 |
|---|---|---|---|
| **SSH** | 22 | TCP | 加密的远程维护 |
| **Telnet** :fa-flask: | 23 | TCP | 未加密的远程维护（已过时） |
| **FTP** / **SFTP** | 21 / 22 | TCP | 传输文件 |
| **NTP** :fa-flask: | 123 | UDP | 校准时间 |
| **IRC** :fa-flask: | 6667 | TCP | 文字聊天 |
| **SIP** / **RTP** :fa-flask: | 5060 / 不固定 | UDP | 网络电话 |
| **SNMP** | 161 | UDP | 监控网络设备 |
| **SMB** | 445 | TCP | 网络中的文件共享 |
| **MQTT** | 1883 | TCP | 物联网中的消息传递 |
| **QUIC** / **HTTP/3** | 443 | UDP | 更快的加密网页访问 |

## SSH 和 Telnet

通过 **SSH**（*Secure Shell*，安全外壳协议），你可以通过命令行控制另一台计算机，就像坐在它面前一样——管理员就是这样维护服务器和路由器的。包括密码在内的所有内容都以加密方式传输。它的前身 **Telnet** 做的是同样的事，但以明文传输，因此如今被认为不安全；不过作为测试文本协议的工具，它仍然很有用，这一点你在 6.1.2 节中已经看到了。

## FTP 和 SFTP

**文件传输协议**（**FTP**，*File Transfer Protocol*）是最古老的互联网协议之一，用于上传和下载文件。它以未加密的方式传输密码和数据，因此使用得越来越少。它通常被 **SFTP** 取代，后者通过 SSH 连接传输文件。

## NTP

**网络时间协议**（**NTP**，*Network Time Protocol*）使计算机的时钟与时间服务器保持同步——精确到毫秒。这比听起来更重要：证书、日志文件和登录验证机制只有在所有设备时间一致时才能正常工作。在 BeaverTracer 中，为此提供了应用 **NTP-Server** 和 **Uhrzeit** 以及命令 `ntpdate`。

## IRC

**互联网中继聊天**（**IRC**，*Internet Relay Chat*）是 1988 年诞生的聊天协议：你连接到一台服务器，加入像 `#schule` 这样的频道，并向频道内的所有人发送文字消息。和 HTTP、SMTP 一样，IRC 是纯文本协议——在追踪中你可以读到每一条消息。如今的即时通讯软件基于相同的基本原理，只是经过了加密。在 BeaverTracer 中：应用 **IRC-Server** 和 **IRC**。

## SIP 和 RTP

在**网络电话**（*Voice over IP*）中，两个协议协同工作：**SIP**（*Session Initiation Protocol*，会话发起协议）负责建立和结束通话——它会让对方的电话响铃。语音本身则通过 UDP 以许多小的 **RTP** 数据包传输，因为打电话时每一毫秒都很重要（参见 5.5.2 节）。在 BeaverTracer 中：应用 **SIP-Server** 和 **Softphone**。

## SNMP

借助**简单网络管理协议**（**SNMP**，*Simple Network Management Protocol*），监控程序可以查询路由器、交换机和打印机：某个端口的负载有多高？某台设备是否出现故障？墨粉是否用完了？管理员就是这样掌握大型网络的运行状况的。

## SMB

**服务器消息块**协议（**SMB**，*Server Message Block*）是你在 Windows 网络中熟悉的网络驱动器和共享文件夹背后的协议——比如学校里的共享驱动器。网络打印机也常常通过 SMB 来访问。

## MQTT

**MQTT** 是一种非常轻量的**物联网**协议：传感器、智能恒温器或工厂中的机器把测量值发送给一个中央中介（*Broker*，代理），所有对这些数据感兴趣的程序都可以从那里获取。它专为计算能力较弱的设备和不可靠的连接而设计。

## QUIC 和 HTTP/3

**QUIC** 是一种较新的传输协议，由 Google 开发，如今许多大型网站都在使用。它建立在 **UDP** 之上，自身就带有可靠性和加密功能——因此连接建立得比使用 TCP 和 TLS 更快。**HTTP/3** 是运行在 QUIC 之上的 HTTP 版本。

NTP -> 与时间服务器校准时间

SNMP -> 监控路由器、交换机和打印机
MQTT -> 在物联网中分发传感器的测量值

## Як виглядає запит

Клікни в трасуванні на пакет `GET / HTTP/1.1` і розгорни **Hypertext Transfer Protocol**. HTTP-запит — це звичайний текст:

```
GET / HTTP/1.1              ← Methode, Pfad, Version
Host: 192.168.0.20          ← Header: zusätzliche Angaben
…
                            ← Leerzeile: Ende der Anfrage
```

Відповідь сервера побудована так само — з рядком стану, заголовками, порожнім рядком і далі самим файлом:

```
HTTP/1.1 200 OK             ← Version, Statuscode, Text
Content-Type: text/html     ← Header: Art der Datei
Content-Length: 301         ← Header: Größe in Byte
                            ← Leerzeile
<!doctype html> …           ← die Datei selbst
```

:::seq
mode: text
Client-PC -> Server: GET / | HTTP-запит
Server -> Client-PC: 200 OK | index.html
Client-PC -> Server: GET /style.css | HTTP-запит
Server -> Client-PC: 200 OK | style.css
:::

## Методи та коди стану

**Метод** вказує, чого хоче клієнт:

| Метод | Значення |
|---|---|
| **GET** | отримати файл |
| **POST** | надіслати дані на сервер, наприклад заповнену форму |
| **HEAD** | отримати лише заголовки, без файлу |

**Код стану** вказує, як усе минуло. Перша цифра визначає тип відповіді:

| Код | Текст | Значення |
|---|---|---|
| **200** | OK | усе гаразд |
| **301** | Moved Permanently | сторінку остаточно переміщено |
| **404** | Not Found | такого файлу немає |
| **405** | Method Not Allowed | цей метод тут не дозволений |
| **500** | Internal Server Error | помилка на сервері |

`2xx` означає успіх, `3xx` — перенаправлення, `4xx` — помилку клієнта (неправильний запит), `5xx` — помилку сервера.

:::tip Запам'ятай
**HTTP** працює за **принципом «запит — відповідь»**: клієнт надсилає **запит** (метод, наприклад `GET`, шлях, заголовки), сервер відповідає **кодом стану** (наприклад, `200 OK`, `404 Not Found`), заголовками та файлом. Для кожного файлу вебсторінки надсилається окремий запит.
:::

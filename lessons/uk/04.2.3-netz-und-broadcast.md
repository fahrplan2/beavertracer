# Адреса мережі, широкомовна адреса та хости

У кожній мережі дві адреси виконують особливу роль:

- **Адреса мережі** — це **найнижча** адреса мережі: усі біти в хостовій частині дорівнюють 0. Вона позначає мережу в цілому, наприклад у таблицях маршрутизації.
- **Широкомовна адреса** — це **найвища** адреса мережі: усі біти в хостовій частині дорівнюють 1. Усе, що надсилається на неї, надходить до всіх пристроїв у мережі.

Ці дві адреси **не** призначаються пристроям. Усі адреси між ними доступні для пристроїв (**хостів**).

## Простий приклад

`192.168.0.12/24` — хостова частина — це останній октет:

| | Адреса |
|---|---|
| Адреса мережі (хостова частина = 0) | `192.168.0.0` |
| Широкомовна адреса (хостова частина = 255) | `192.168.0.255` |
| Діапазон для хостів | `192.168.0.1` – `192.168.0.254` |
| Кількість хостів | 254 |

## Коли межа проходить посеред октета

Складніше стає, коли довжина префікса не кратна 8. Тоді ти переводиш відповідний октет у двійкову систему числення. Приклад: `194.9.190.12/27`.

Перші три октети повністю належать до [[n|мережевої частини]] (24 біти). З останнього октета ще **3 біти** належать до мережевої частини (24 + 3 = 27), а решта **5 бітів** — до [[h|хостової частини]]:

| | останній октет (двійковий) | десятковий |
|---|---|---|
| IP-адреса | [[n|000]][[h|01100]] | 12 |
| Маска мережі (`/27`) | [[n|111]][[h|00000]] | 224 |
| Адреса мережі: хостові біти в 0 | [[n|000]][[h|00000]] | **0** |
| Широкомовна адреса: хостові біти в 1 | [[n|000]][[h|11111]] | **31** |

Результат:

- Адреса мережі: `194.9.190.0`
- Широкомовна адреса: `194.9.190.31`
- Діапазон для хостів: `194.9.190.1` – `194.9.190.30`
- Кількість хостів: 2⁵ − 2 = **30**

:::tip Запам'ятай
**Адреса мережі:** усі хостові біти дорівнюють 0 (найнижча адреса). **Широкомовна адреса:** усі хостові біти дорівнюють 1 (найвища адреса). Обидві не призначаються пристроям. Мережа з довжиною префікса *n* має **2<sup>32 − n</sup> − 2** придатних для використання адрес для хостів.
:::

:::tip Порада: розмір блоку
Якщо ти зрозумів(-ла) метод у двійковій системі числення, є скорочений спосіб: **256 мінус октет маски** дає розмір мережі в цьому октеті. Для `/27` (маска 224) це 256 − 224 = **32**. Тоді мережі починаються з 0, 32, 64, 96 … — адреса `.12` належить до мережі, що починається з `.0`, а адреса `.70` — до мережі, що починається з `.64`.
:::

## Найважливіші розміри мереж

| Префікс | Маска мережі | Хости |
|---|---|---|
| `/8` | `255.0.0.0` | 16 777 214 |
| `/16` | `255.255.0.0` | 65 534 |
| `/24` | `255.255.255.0` | 254 |
| `/25` | `255.255.255.128` | 126 |
| `/26` | `255.255.255.192` | 62 |
| `/27` | `255.255.255.224` | 30 |
| `/28` | `255.255.255.240` | 14 |
| `/29` | `255.255.255.248` | 6 |
| `/30` | `255.255.255.252` | 2 |

:::note
Найменша мережа, що зазвичай використовується на практиці, — це `/30`: вона має рівно дві придатні для використання адреси й часто застосовується для з'єднання між двома маршрутизаторами. `/32` позначає окрему адресу — як мережа вона непридатна, але трапляється в таблицях маршрутизації та правилах брандмауера.
:::

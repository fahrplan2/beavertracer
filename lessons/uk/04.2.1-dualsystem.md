# Двійкова система числення

Комп'ютер у своїй основі знає лише два стани: струм є або струму немає. Для цього пишуть **1** і **0**. Одна така позиція називається **біт**. Будь-яка IP-адреса для комп'ютера теж є лише послідовністю нулів та одиниць — щоб ти зрозумів, як працюють маски мережі, на цій сторінці ти навчишся читати такі числа та самостійно їх перетворювати.

## Як ми зазвичай рахуємо: десяткова система

У повсякденному житті ми користуємося десятьма цифрами (від 0 до 9). Кожна позиція коштує вдесятеро більше, ніж сусідня позиція праворуч: одиниці, десятки, сотні, тисячі. Отже, число `305` означає:

| Розряд | 100 | 10 | 1 |
|---|---|---|---|
| Цифра | 3 | 0 | 5 |
| Значення | 300 | 0 | 5 |

300 + 0 + 5 = **305**

## Двійкова система числення

У **двійковій системі числення** (також *бінарній системі*) є лише дві цифри: 0 та 1. Кожна позиція коштує **вдвічі** більше, ніж сусідня позиція праворуч: 1, 2, 4, 8, 16, 32, 64, 128 …

Отже, двійкове число `00001101` означає:

| Розряд | 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1 |
|---|---|---|---|---|---|---|---|---|
| Біт | 0 | 0 | 0 | 0 | 1 | 1 | 0 | 1 |
| Значення | | | | | 8 | 4 | | 1 |

8 + 4 + 1 = **13**

Тобто ти просто додаєш значення тих розрядів, у яких стоїть 1.

:::tip Запам'ятай
**Біт** — це одна позиція у двійковій системі числення (0 або 1). **8 біт** утворюють **байт** — у мережевих технологіях таку 8-бітну групу також називають **октетом**. Значення розрядів октета: **128, 64, 32, 16, 8, 4, 2, 1**.
:::

Яке десяткове число відповідає `00000110`?

:::

## Із десяткової у двійкову

У зворотному напрямку ти проходиш розряди зліва направо й щоразу запитуєш: **чи вміщується значення розряду в моє (залишкове) число?** Якщо так, пишеш 1 і віднімаєш значення розряду. Якщо ні, пишеш 0.

Приклад: `168`

| Значення розряду | вміщується в …? | Біт | Залишок |
|---|---|---|---|
| 128 | 168 → так | **1** | 40 |
| 64 | 40 → ні | **0** | 40 |
| 32 | 40 → так | **1** | 8 |
| 16 | 8 → ні | **0** | 8 |
| 8 | 8 → так | **1** | 0 |
| 4 | 0 → ні | **0** | 0 |
| 2 | 0 → ні | **0** | 0 |
| 1 | 0 → ні | **0** | 0 |

Читаючи згори вниз: 168 = **10101000**

## Вправи

Тут при кожній спробі ти отримуєш нові числа — вправляйся, доки не засвоїш матеріал напевно.

:::quiz random dec2bin
count=3
:::

:::quiz random bin2dec
count=3
:::

:::evaluate
Перевірити відповіді
:::

:::tip Порада
Ці значення постійно зустрічатимуться тобі в масках мережі — їх варто знати: `10000000` = 128, `11000000` = 192, `11100000` = 224, `11110000` = 240, `11111000` = 248, `11111100` = 252, `11111110` = 254, `11111111` = 255.
:::

## IP-адреси у двійковій системі числення

IPv4-адреса складається з **32 біт**, тобто з чотирьох октетів. Оскільки ніхто не здатен запам'ятати 32 нулі та одиниці, кожен октет записують як десяткове число й розділяють їх крапками:

```
11000000 . 10101000 . 10110010 . 00000001
   192   .   168    .   178    .    1
```

:::quiz short
З скількох біт складається IPv4-адреса?
= 32
:::

:::quiz mc

:::

:::note

:::

# Автоматичне отримання адреси

:::sim
url=/sims/lesson-6.4.btsim
:::

До комутатора підключені **DHCP сервер** і два ноутбуки. Поки що ноутбуки мають статичні адреси.

## Експеримент

1. Перейди в :fa-play: режим виконання, клацни на **Laptop 1** і відкрий :fa-gear: **Параметри IP**.
2. Зміни **Режим** зі **Статична** на **DHCP** і клацни **Застосувати**.
3. Зачекай кілька секунд: поля заповняться самі.
4. У режимі :fa-magnifying-glass: **Трасування** відкрий трасу для **Laptop 1**.

:::quiz table
| Параметр | отримано від DHCP-сервера |
|---|---|
| IP-адреса | {192.168.0.100} |
| Шлюз | {192.168.0.1} |
| DNS-сервер | {192.168.0.53} |
:::

:::quiz short
Скільки DHCP-пакетів ти знаходиш у трасі?
= 4
= чотири
:::

:::quiz mc
На яку IP-адресу призначення Laptop 1 надсилає свій перший пакет (`DHCP Discover`)?

- [x] На `255.255.255.255` — усім (широкомовна розсилка)

## Що за цим стоїть: DORA

Пристрій без адреси не знає, де розташований DHCP-сервер, і не має власної адреси відправника. Тому він звертається до мережі через **широкомовну розсилку** (broadcast). Процес складається з чотирьох кроків — за їхніми початковими літерами він називається **DORA**:

:::seq
mode: text
Laptop 1 -> DHCP-Server: DHCP Discover | „Чи є тут DHCP-сервер?“
DHCP-Server -> Laptop 1: DHCP Offer | „Ти можеш отримати 192.168.0.100.“
Laptop 1 -> DHCP-Server: DHCP Request | „Беру 192.168.0.100.“
DHCP-Server -> Laptop 1: DHCP ACK | „Підтверджено — діє 3600 секунд.“
:::

Адреса лише **позичається** (*lease*): після завершення **терміну оренди** пристрій має її продовжити, інакше сервер може видати її знову. Які адреси зараз видані, ти бачиш у **DHCP сервері** на вкладці **Leases**.

:::tip Спробуй сам
Налаштуй **Laptop 2** також на DHCP. Яку адресу він отримає? Потім подивись у **Leases** DHCP-сервера.
:::

:::tip Запам'ятай
**DHCP** автоматично розподіляє IP-адресу, маску мережі, шлюз і DNS-сервер. Процес називається **DORA**: **D**iscover (клієнт шукає сервер через широкомовну розсилку), **O**ffer (сервер пропонує), **R**equest (клієнт приймає), **A**CK (сервер підтверджує). Адреса позичається на **термін оренди**. DHCP використовує **UDP**, порт 67 (сервер) і 68 (клієнт).
:::

:::quiz match
Discover -> Клієнт шукає DHCP-сервер через широкомовну розсилку
Offer -> Сервер пропонує адресу
Request -> Клієнт запитує запропоновану адресу
ACK -> Сервер підтверджує видачу
:::

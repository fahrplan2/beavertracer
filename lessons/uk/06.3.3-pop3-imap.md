# POP3 чи IMAP?

:::sim
url=/sims/lesson-6.3.btsim
:::

Для отримання пошти існує два протоколи. У цій симуляції **Anna використовує POP3**, а **Ben — IMAP**.

## Експеримент

1. У :fa-play: режимі **виконання** надішли листа від **Ben** на адресу `anna@beaver-schule.de`.
2. У застосунку **E-Mail** на **Anna** натисни **Отримати**.
3. Відкрий трасування для **Anna** та для **Ben** і порівняй команди під час отримання пошти.

:::quiz match
USER / PASS -> POP3: вхід за іменем користувача та паролем у два кроки
RETR -> POP3: завантаження повідомлення
LOGIN -> IMAP: вхід за іменем користувача та паролем
SELECT INBOX -> IMAP: відкриття папки на сервері
:::

:::evaluate
Перевірити відповідність
:::

## Різниця

| | POP3 | IMAP |
|---|---|---|
| Порт | 110 | 143 |
| Основна ідея | листи **завантажуються** — після цього їх зазвичай видаляють на сервері | листи **залишаються на сервері** й обробляються там |
| Папки, прочитані/непрочитані | лише на власному пристрої | на сервері — скрізь однакові |
| Кілька пристроїв (телефон, ноутбук) | незручно: кожен пристрій має різний стан | ідеально: усі пристрої бачать ту саму поштову скриньку |

:::note
Поштова програма в BeaverTracer залишає листи на сервері, навіть якщо використовується POP3. Справжні програми після завантаження часто видаляють їх — або залишають лише на деякий час.
:::

:::quiz mc
Лена читає свою пошту на телефоні, планшеті та шкільному ноутбуці. Що їй варто використовувати?
- [ ] POP3, бо він простіший
- [x] IMAP, бо всі пристрої бачать ту саму поштову скриньку на сервері
- [ ] SMTP, бо він призначений для отримання пошти
:::

:::evaluate
Перевірити відповідь
:::

:::tip Запам'ятай
**POP3** завантажує листи із сервера на **один** пристрій. **IMAP** керує поштовою скринькою **на сервері** — з папками та статусом «прочитано» одночасно для всіх пристроїв. Обидва протоколи призначені лише для **отримання** пошти; надсилання завжди виконується через **SMTP**.
:::

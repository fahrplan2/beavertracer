# Основні типи адрес

В IPv6 за початком адреси можна визначити, для чого вона призначена:

| Тип адреси | як розпізнати | для чого |
|---|---|---|
| **Link-Local** | `fe80::` | Діє лише у **власній локальній мережі**. Кожен пристрій автоматично призначає собі таку адресу — маршрутизатор її ніколи не пересилає далі. |
| **Global Unicast** | `2…` або `3…` (`2000::/3`) | Глобально унікальна адреса, доступна в інтернеті. Префікс надає інтернет-провайдер. |
| **Unique Local** | `fd…` (`fc00::/7`) | Для приватних мереж, аналог `192.168.x.x` в IPv4. |
| **Loopback** | `::1` | Власний пристрій — як `127.0.0.1` в IPv4. |
| **Multicast** | `ff…` | Для **групи** пристроїв, наприклад `ff02::1` = усі пристрої в локальній мережі. |

:::note
Діапазон `2001:db8::/32` зарезервований для прикладів і навчальних матеріалів — у справжньому інтернеті він ніколи не використовується. Саме тому ти бачиш його в цьому курсі.
:::

Важлива новинка: **в IPv6 більше немає широкомовлення (broadcast).** Те, що в IPv4 було широкомовним повідомленням для всіх, в IPv6 виконують **multicast**-адреси — повідомлення надходить лише на ті пристрої, які зацікавлені в цій групі.

:::tip Запам'ятай
Кожен пристрій з IPv6 має щонайменше одну **адресу Link-Local** (`fe80::…`) для власної мережі, а здебільшого ще й **глобальну адресу** для інтернету. Замість broadcast IPv6 використовує **multicast** (`ff…`).
:::

:::quiz match
fe80::a828:39ff:fee2:4182 -> Link-Local — лише у власній мережі
2001:db8:1::10 -> Global Unicast — глобально унікальна
::1 -> Loopback — власний пристрій
ff02::1 -> Multicast — усі пристрої в локальній мережі
fd12:3456::1 -> Unique Local — для приватних мереж
:::

# Перегляд сертифіката

:::sim
url=/sims/lesson-8.2.1.btsim
:::

На робочій області ти бачиш **Client-PC**, **DNS-Server** і вебсервер школи `www.beaver-schule.de`. Вебсервер пропонує свої сторінки також через **HTTPS**.

## Замок у браузері

1. Перейди в режим :fa-play: **Запустити** і клікни на **Client-PC**, потім відкрий :fa-globe: **Браузер**.
2. Відкрий `https://www.beaver-schule.de/` — зверни увагу на **https**.
3. Ліворуч від адреси з'явиться **замок**. Клікни на нього.

:::quiz short
Для якого імені видано сертифікат (суб'єкт без `CN=`)?
= www.beaver-schule.de
:::

:::quiz short
Хто видав сертифікат (емітент без `CN=`)?
= Biber Root CA
:::

:::evaluate
Перевірити відповіді
:::

## Чому Client-PC довіряє сертифікату?

Відкрий на **Client-PC** :fa-shield-halved: **Zertifikatverwaltung** і перейди на вкладку **Vertrauenswürdige CAs**.

:::quiz mc
Що ти там знаходиш?
- [x] Сертифікат **Biber Root CA**
- [ ] Сертифікат `www.beaver-schule.de`
- [ ] Записів немає
:::

:::quiz mc
Як можна побачити, що Biber Root CA є кореневим центром сертифікації?
- [x] Він **самопідписаний**: суб'єкт і емітент однакові
- [ ] Його назва закінчується на «CA»
- [ ] У нього немає відкритого ключа
:::

:::quiz mc
Що вказано в Client-PC у полі **Privater Schlüssel**: «Ja» чи «Nein»?
- [ ] «Ja» — клієнту потрібен приватний ключ центру сертифікації, щоб перевіряти підписи
- [x] «Nein» — для перевірки достатньо відкритого ключа; приватний ключ є лише в центру сертифікації
:::

:::evaluate
Перевірити відповіді
:::

## Протилежний бік: вебсервер

Тепер відкрий на вебсервері **www.beaver-schule.de** :fa-shield-halved: **Zertifikatverwaltung** (вкладка **Meine Zertifikate**) і подивися його сертифікат.

:::quiz multi
Що правильно щодо сертифіката на вебсервері?
- [x] У полі **Privater Schlüssel** вказано «Ja» — серверу він потрібен для встановлення з'єднання
- [x] **Ланцюжок** виглядає так: `www.beaver-schule.de ← Biber Root CA`
- [x] **Відбиток** такий самий, як у вікні із замком у браузері
- [ ] Він самопідписаний
:::

:::evaluate
Перевірити відповіді
:::

:::note
**Відбиток** — це хеш-значення сертифіката. За ним можна швидко порівняти два сертифікати, не перевіряючи окремо кожне поле.
:::

:::tip Запам'ятай
**Вебсервер** має свій сертифікат **разом із приватним ключем**. **Клієнт** знає лише **сертифікат кореневого центру сертифікації** (без приватного ключа) — цього йому достатньо, щоб перевірити підпис на сертифікаті сервера. Якщо клікнути в браузері на **замок**, можна побачити суб'єкт, емітента, відбиток і термін дії.
:::

# З'єднання від початку до кінця

:::sim
url=/sims/lesson-5.1.btsim
:::

На **Server** на порту `5000` працює служба echo: кожне повідомлення вона одразу надсилає назад. За допомогою **Простий TCP-клієнт** ти можеш керувати з'єднанням крок за кроком — кожна кнопка відповідає одній фазі.

## Експеримент

1. Перейди в режим :fa-play: **виконання**, клацни на **Client-PC** і відкрий **Простий TCP-клієнт**.
2. У полі **Host** введи `192.168.0.20`, а в полі **Port** — `5000`.
3. Натисни **Підключитися**.
4. Введи `Hello World` у поле повідомлення та натисни **Відправити**. У вікні чату одразу після цього ти побачиш відповідь сервера (echo).
5. Натисни **Відключитися**.
6. Перейди в режим :fa-magnifying-glass: **Трасування** і за допомогою **+** відкрий трасування для **Client-PC**, інтерфейс `eth0`.

:::note
Два ARP-пакети на початку ти вже знаєш із розділу 1. У стовпці **Info** TCP-пакетів спочатку стоїть `49152 → 5000` (з якого порту на який), потім у квадратних дужках — **прапорці**, а після них — числа на кшталт `Seq=`, `Ack=` і `Len=`. Про ці числа йтиметься зі сторінки 5.2.3 — тут зверни увагу на прапорці та `Len`.
:::

## Фаза 1: підключення

:::quiz short
Скільки TCP-пакетів було передано після того, як ти натиснув **Підключитися**, — до відправлення твого повідомлення?
= 3
= три
:::

:::quiz mc
Хто надсилає перший пакет із `[SYN]`?
- [x] Client-PC
- [ ] Server
:::

:::quiz mc
Якими прапорцями сервер відповідає на нього?
- [ ] `[SYN]`
- [x] `[SYN, ACK]`
- [ ] `[ACK]`
- [ ] `[FIN, ACK]`
:::

## Фаза 2: надсилання

`Len` вказує, скільки байтів корисних даних несе пакет.

:::quiz short
Скільки байтів несе пакет із твоїм повідомленням (`Len`)?
= 13
:::

:::note
`Hello World` має лише 11 символів. Проте TCP-клієнт додає в кінці символ завершення рядка (2 байти, `\r\n`) — саме цього очікують багато інтернет-протоколів, як-от SMTP або HTTP.
:::

:::quiz mc
Що сервер надсилає назад безпосередньо після твого повідомлення — ще до echo-відповіді?
- [x] Пакет із `[ACK]` і `Len=0` — підтвердження без даних
- [ ] Нічого
- [ ] Новий `[SYN]`
:::

## Де ховаються чотири завдання?

Визнач, де в трасуванні можна знайти завдання з розділу 5.1:

:::quiz match
Встановлення з'єднання -> Три пакети [SYN], [SYN, ACK] і [ACK]
Надійне передавання -> Пакети з [ACK] і Len=0, які підтверджують отримання
Розривання з'єднання -> Пакети з FIN та їхні підтвердження
Мультиплексування -> Номери портів 49152 → 5000 перед квадратними дужками
:::

Перевірити відповідність
:::

# Хеш-значення: відбиток даних

:::sim
url=/sims/lesson-8.1.3.btsim
:::

**Хеш-функція** обчислює з довільного обсягу даних — речення, документа, цілого фільму — короткий рядок символів фіксованої довжини: **хеш-значення**. Воно працює як **відбиток пальця**: однакові дані завжди дають те саме хеш-значення, а інші дані — інше.

Сьогодні поширена хеш-функція називається **SHA-256**. Її хеш-значення завжди має довжину 256 біт, тобто в шістнадцятковому записі це 64 символи.

## Експеримент

На **PC** у папці `/home` лежать три файли з невеликим договором купівлі-продажу. Перейди в :fa-play: режим виконання, відкрий на **PC** :fa-terminal: **Термінал** і введи:

```
$ cd /home
$ cat vertrag.txt vertrag-kopie.txt vertrag-neu.txt
$ sha256sum vertrag.txt vertrag-kopie.txt vertrag-neu.txt
```

## Властивості хеш-функції

| Властивість | Значення |
|---|---|
| **фіксована довжина** | Незалежно від обсягу даних хеш-значення завжди має однакову довжину. |
| **однозначність** | Однакові дані завжди дають те саме хеш-значення. |
| **лавинний ефект** | Навіть найменша зміна дає зовсім інше хеш-значення. |
| **одностороння функція** | З хеш-значення **не можна** обчислити дані назад. |
| **стійкість до колізій** | Практично неможливо знайти два різні файли з однаковим хеш-значенням. |

Хеш-функція — **не шифрування**: тут немає ключа і немає розшифрування. Вона служить іншій меті — **цілісності**.

## Для чого це потрібно?

- **Перевірка завантажень:** багато вебсайтів поряд із файлом указують його значення SHA-256. Якщо хеш-значення твого завантаженого файлу збігається з ним, файл дорогою не змінювався.
- **Зберігання паролів:** хороші вебсайти зберігають не твій пароль, а лише його хеш-значення. Під час входу порівнюється хеш-значення введеного тобою пароля. Якщо базу даних викрадуть, злодій все одно не знатиме паролів.
- **Цифрові підписи:** замість усього документа підписують лише його хеш-значення — докладніше про це в наступному розділі.

:::tip Запам'ятай
**Хеш-функція** (наприклад, **SHA-256**) обчислює з довільних даних **хеш-значення** фіксованої довжини — **відбиток пальця**. Навіть найменша зміна дає зовсім інше хеш-значення, а з хеш-значення неможливо обчислити дані назад. Хеш-значення забезпечують **цілісність** даних.
:::

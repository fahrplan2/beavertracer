# HTTP вручну

:::sim
url=/sims/lesson-6.1.btsim
:::

Якщо HTTP — це звичайний текст, то чи можна самому «поговорити» з вебсервером, зовсім без браузера? Так: за допомогою `telnet` ти встановлюєш TCP-з'єднання з будь-яким портом і набираєш текст самостійно.

## Експеримент

1. Перейди в режим :fa-play: **Запустити** і відкрий на **Client-PC** :fa-terminal: **Термінал**.
2. Підключися до порту 80 сервера:
   ```
   $ telnet 192.168.0.20 80
   ```
3. Набери запит рядок за рядком — і заверши його **порожнім рядком** (просто ще раз натисни **Enter**):
   ```
   GET /kontakt.html HTTP/1.1
   Host: 192.168.0.20

   ```

Сервер відповідає рядком стану, заголовками та сторінкою контактів — у вигляді тексту, так само як її отримує браузер.

:::quiz mc
Як сервер розуміє, що твій запит закінчився?
- [ ] За спеціальною командою `END`
- [x] За порожнім рядком
- [ ] Через певний час
:::

## Провокуємо помилки

Зручніший інструмент — `curl`: він формує запит за тебе. З параметром `-v` (*verbose*, докладний вивід) він показує все, що передається туди й назад: рядки з `>` надіслав `curl`, а рядки з `<` прийшли від сервера.

Спробуй:

```
$ curl -v http://192.168.0.20/gibtsnicht.html
$ curl -X POST -d name=Anna http://192.168.0.20/
```

:::quiz short
Який код стану ти отримуєш для `/gibtsnicht.html`?
= 404
:::

:::quiz short

:::

:::

:::note
Вебсервер у BeaverTracer може лише віддавати файли — тому він дозволяє тільки `GET` і `HEAD`. Справжні вебсервери за допомогою `POST` приймають, наприклад, дані форм і передають їх далі програмі.
:::

:::tip Запам'ятай
Багато протоколів прикладного рівня є **текстовими** — HTTP, а також SMTP, POP3 та IMAP. Тому з ними можна «спілкуватися» вручну через `telnet` і читати їх у трасуванні. Це зручно для пошуку і усунення несправностей, але водночас є проблемою безпеки: кожен, хто перехоплює трафік, може прочитати все. Як допомагає шифрування (HTTPS), ти дізнаєшся в розділі 8.
:::

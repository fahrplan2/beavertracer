## Що бачить зловмисник?

Той, хто хоче атакувати сервер, спочатку шукає **відкриті порти**, тобто служби, які очікують на з'єднання. Інструмент для цього називається **сканер портів**; найвідоміший із них — `nmap`.

Перейди в :fa-play: режим виконання, відкрий на **Internet-PC** :fa-terminal: **Термінал** і введи:

```
$ nmap 198.51.100.10
```

`nmap` намагається встановити TCP-з'єднання з 20 найпоширенішими портами й повідомляє, які з них відкриті.

:::quiz multi
Які порти на Schulserver відкриті з інтернету?
- [x] 22 (SSH, віддалене адміністрування)
- [x] 25 (SMTP)
- [x] 80 (HTTP)
- [x] 110 (POP3)
- [x] 143 (IMAP)
- [ ] 443 (HTTPS)
:::

:::evaluate
Перевірити відповідь
:::

Вебсайт (80) і отримання електронної пошти (25) мають бути доступні з інтернету. Але **віддалене адміністрування** (22) і отримання пошти (110, 143) потрібні лише шкільній мережі. Кожен відкритий порт — це потенційна поверхня атаки: якщо в служби є вразливість або слабкий пароль, зловмисник може скористатися цим з будь-якої точки світу, а автоматичні сканери в інтернеті роблять саме це цілодобово.

:::tip Запам'ятай
**Брандмауер** контролює трафік на межі між двома мережами й пропускає лише те, що прямо дозволено. Так служби, потрібні лише всередині, залишаються невидимими для інтернету.
:::

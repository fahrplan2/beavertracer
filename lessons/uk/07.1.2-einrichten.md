# Налаштування домашнього маршрутизатора

:::sim
url=/sims/lesson-7.1.2.btsim
:::

Новий домашній маршрутизатор щойно підключили — але в інтернет поки що ніхто не виходить. Від провайдера ти отримав(-ла) лист із **обліковими даними для підключення**:

| Дані для підключення | Значення |
|---|---|
| WAN IP-адреса | `203.0.113.2` |
| Довжина префікса | `/30` |
| Шлюз (маршрутизатор провайдера) | `203.0.113.1` |
| DNS-сервер провайдера | `198.51.100.10` |

1. Перейди в :fa-play: режим виконання, клацни на **Heimrouter** і відкрий вкладку **WAN**.
2. Введи дані для підключення та натисни **Застосувати**.
3. Підключи **Tablet** до Wi-Fi: :fa-gear: **Параметри IP**, вкладка **WiFi**, SSID `Biberbau`, **Застосувати**.
4. Перевір на ПК за допомогою `ping 192.0.2.80` або в браузері за адресою `http://www.beispiel.de/`.

:::note
На практиці домашній маршрутизатор зазвичай отримує свою WAN-адресу від провайдера автоматично (через DHCP або за допомогою входу з іменем користувача та паролем). Фіксовані дані для підключення, як тут, більш типові для корпоративних підключень.
:::

Коротко згадаймо розділ 4: **Internet Protocol** на рівні 3 доставляє пакет до потрібного *комп'ютера* — навіть через багато маршрутизаторів. Але більше IP нічого не обіцяє:

- На комп'ютері одночасно працює багато програм: браузер, поштова програма, месенджер. Для якої з них призначений пакет? Цього в заголовку IP немає.
- Якщо пакет загубиться дорогою, IP цього не помітить. Пакети також можуть надійти двічі або в неправильному порядку. Кажуть: IP доставляє лише за принципом «якнайкращих зусиль» (*best effort*).

Ці прогалини закриває **рівень 4** — транспортний рівень. На робочій області ти бачиш **Client-PC** і **Server** — на них у цьому розділі ти досліджуватимеш два найважливіші протоколи рівня 4: **TCP** і **UDP**.

:::note
TCP стандартизовано з 1981 року (**RFC 793**, нині **RFC 9293**), а UDP — ще з 1980 року (**RFC 768**).
:::

# Без стану чи зі станом

З'єднання завжди складається з **двох напрямків**: ПК вчителя надсилає запит до вебсервера в інтернеті — а вебсервер повертає вебсторінку. Тому брандмауер, що працює за принципом білого списку, має пропускати не лише запит, а й **відповідь**.

Для цього існують два види пакетних фільтрів:

| | **Без стану** (*stateless*) | **Зі станом** (*stateful*) |
|---|---|---|
| Принцип роботи | перевіряє кожен пакет окремо, без «пам'яті» | запам'ятовує дозволені з'єднання в **таблиці станів** |
| Відповіді | потребують окремого правила для зворотного напрямку | пропускаються автоматично, бо належать до відомого з'єднання |
| Застосування | прості пристрої, дуже швидкі фільтри | практично кожен сучасний брандмауер |

У наступних двох розділах ти побачиш, чому фільтри без стану мають проблеми з відповідями — і як їх розв'язує брандмауер зі станом.

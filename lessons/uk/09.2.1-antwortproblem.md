# Проблема відповідей

:::sim
url=/sims/lesson-9.2.btsim
:::

Брандмауер тепер працює за принципом білого списку: типова політика — **Alle verwerfen**. Єдине правило дозволяє шкільній мережі користуватися інтернетом: **B → A, TCP, цільовий порт 80, Zulassen**. Режим встановлено на **Stateless**.

## Експеримент

1. Перейди в :fa-play: режим виконання і відкрий на **Lehrer-PC** у :fa-globe: **Браузер** адресу `http://203.0.113.80/`.
2. Подивися в **Firewall** **Protokoll** і **Treffer**.

:::quiz mc
Що відбувається в браузері?
- [ ] З'являється сторінка www.beispiel.de
- [x] Сторінка не завантажується, браузер чекає і зрештою повідомляє про помилку
:::

:::quiz mc
Які пакети в журналі брандмауера відображаються як відкинуті (`DROP`)?
- [ ] Запити Lehrer-PC до порту 80
- [x] Відповіді від `203.0.113.80` з **вихідним портом 80** до Lehrer-PC
- [ ] Жодних
:::

:::quiz short
У якому напрямку (A→B чи B→A) проходять відкинуті пакети?
= A→B
= A → B
= AtoB
:::

:::evaluate
Перевірити відповіді
:::

Запит Lehrer-PC може вийти назовні — але вже `SYN, ACK` від вебсервера не повертається, адже для напрямку A → B немає відповідного правила, тому діє **Alle verwerfen**.

## Наївне рішення

Можна додати друге правило: **A → B, TCP, вихідний порт 80, Zulassen** — «усе, що надходить з порту 80, може заходити». Тоді перегляд вебсторінок справді запрацює.

:::quiz mc
Чому це правило небезпечне?
- [ ] Тому що вебсервери ніколи не використовують порт 80 як вихідний порт
- [x] Зловмисник може просто надіслати свої пакети з вихідним портом 80 — і тоді брандмауер пропустить їх на **будь-який** порт у шкільній мережі
- [ ] Тому що тоді вебсторінки завантажуються повільніше
:::

:::evaluate
Перевірити відповідь
:::

Вихідний порт визначає сам відправник — брандмауер не повинен на нього покладатися. Але брандмауер без відстеження стану не знає, чи пакет є **відповіддю на запит**, чи **новою спробою з'єднання** ззовні. Саме це змінює режим із відстеженням стану.

:::tip Запам'ятай
**Пакетний фільтр без відстеження стану** перевіряє кожен пакет окремо. Тоді для відповідей потрібні окремі правила для зворотного напрямку — а такі правила (наприклад, «вихідний порт 80 може заходити») можуть використати зловмисники, бо відправник може довільно вибирати вихідний порт.
:::

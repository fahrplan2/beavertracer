# Підсумок і перспективи

## Брандмауери в багатьох місцях

Фільтр пакетів з цього розділу ти знайдеш у багатьох пристроях:

- **Домашній маршрутизатор:** Кожен домашній маршрутизатор — це також брандмауер зі станом (stateful). З IPv4 частину цього захисту бере на себе NAT: ззовні ніхто не може ініціювати з'єднання, доки немає переадресації портів (розділ 7). З IPv6 усі пристрої мають публічні адреси — тоді такий самий захист забезпечує лише правило брандмауера «ззовні нічого нового всередину».
- **Персональний брандмауер:** Windows, macOS і Linux також мають вбудований брандмауер на самому комп'ютері. Він захищає пристрій і в чужих мережах, наприклад у Wi-Fi кафе, і може задавати правила для окремих програм.
- **Брандмауер наступного покоління (Next-Generation Firewall)** і **Web Application Firewall (WAF):** вони дивляться не лише на адреси та порти, а й на вміст пакетів — аж до прикладного рівня. Так вони розпізнають, наприклад, атаки в HTTP-запитах. У разі HTTPS для цього їм доводиться розкривати шифрування (розділ 8).
- **IDS/IPS:** *Intrusion Detection System* розпізнає підозрілі шаблони в трафіку та сигналізує про тривогу; *Intrusion Prevention System* додатково сама їх блокує.

:::note
Брандмауер — це лише **один** зі складників безпеки. Він не допоможе, якщо дозволена служба (наприклад, вебсервер) сама має вразливість, якщо хтось відкриє шкідливу програму з електронного листа або якщо пароль слабкий. Тому оновлення, надійні паролі, шифрування та продумане розділення мережі (DMZ, VLAN з розділу 3) завжди мають бути частиною захисту.
:::

- [ ] Його буде дозволено
- [x] Його буде відкинуто
- [ ] Його буде відхилено з повідомленням
:::

:::quiz mc
`nmap` повідомляє для порту `filtered`. Що це означає?

- [ ] Сервер відповів пакетом RST
- [x] Відповіді не було взагалі — ймовірно, брандмауер відкидає пакети
:::

:::quiz multi
Які твердження правильні?
- [x] У брандмауера зі станом (stateful) відповіді на дозволені з'єднання автоматично повертаються
- [x] Білий список безпечніший за чорний, бо нові служби автоматично залишаються заблокованими
- [x] Сервери, доступні з інтернету, належать до DMZ
- [ ] Брандмауер захищає також від атак між двома комп'ютерами в одній мережі за ним
- [ ] Усі правила завжди перевіряються, перемагає найсуворіше
:::

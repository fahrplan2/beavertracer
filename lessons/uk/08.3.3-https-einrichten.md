# Налаштування HTTPS

:::sim
url=/sims/lesson-8.3.3.btsim
:::

Тут ми продовжуємо з того місця, де закінчився розділ 8.2.2: на вебсервері **www.beaver-schule.de** розміщені **Schul-CA** та виданий нею сертифікат сервера, а **Client-PC** довіряє Schul-CA. Тільки вебсервер ще не підтримує HTTPS.

## До налаштування

Перейди в :fa-play: режим виконання і на **Client-PC** відкрий у :fa-globe: **Браузер** адресу `https://www.beaver-schule.de/`.

:::quiz mc
Що станеться?
- [x] З'єднання не буде встановлено — жодна служба не прослуховує порт 443
- [ ] Браузер попередить про небезпечний сертифікат
- [ ] Сторінка відобразиться без замка
:::

:::evaluate
Перевірити відповідь
:::

## Вмикання HTTPS

1. Відкрий на вебсервері **HTTP-сервер** і натисни **Stoppen** — доки сервер працює, налаштування змінити не можна.
2. Перейди на вкладку **HTTPS**:
    - Став позначку біля **HTTPS aktivieren**, **HTTPS-Port** `443`
    - У полі **Zertifikat** вибери сертифікат сервера `www.beaver-schule.de` — не Schul-CA!
    - Натисни **Verwenden**
3. Натисни **Запустити**.

Відкрий сторінку на Client-PC ще раз через `https://`. Натисни на замок і перевір видавця та термін дії.

:::task
title: HTTPS налаштовано?
Перевіряє, чи може Client-PC отримати https://www.beaver-schule.de/ без попередження про сертифікат. Для цього симуляція має працювати в режимі виконання.
check: httpsOk(2, "https://www.beaver-schule.de/")
:::

:::quiz mc
Чому в HTTP-сервері не можна вибирати сертифікат **Schul-CA**?
- [ ] Тому що сертифікати CA не можуть шифрувати
- [x] Тому що він виданий для імені `Schul-CA`, а не для `www.beaver-schule.de` — браузер видасть попередження
- [ ] Тому що Schul-CA не має приватного ключа
:::

:::quiz mc
Що побачить пристрій, який **не** довіряє Schul-CA, наприклад телефон гостя?
- [ ] Сторінку як зазвичай, із замком
- [x] Попередження про сертифікат, бо він не може простежити ланцюжок довіри до відомого центру сертифікації
- [ ] Нічого, бо з'єднання буде відхилено
:::

:::evaluate
Перевірити відповіді
:::

:::note
Для публічних вебсайтів потрібен сертифікат від центру сертифікації, попередньо встановленого в усіх браузерах. З 2015 року існує **Let's Encrypt** — центр сертифікації, який видає такі сертифікати безкоштовно й автоматично. Це одна з головних причин, чому сьогодні майже всі вебсайти використовують HTTPS.
:::

:::tip Запам'ятай
Для **HTTPS** вебсервер потребує **сертифікат сервера з приватним ключем**, ім'я в якому відповідає адресі, і має прослуховувати **порт 443**. Клієнт довіряє сторінці лише тоді, коли знає **центр сертифікації**, що видав сертифікат.
:::

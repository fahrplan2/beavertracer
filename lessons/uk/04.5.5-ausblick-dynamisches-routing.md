# Перспектива: динамічна маршрутизація

У проєкті ти вручну вніс дванадцять маршрутів для чотирьох локацій. Велика корпоративна мережа має сотні маршрутизаторів, а інтернет — десятки тисяч, і постійно десь обривається лінія або з'являється нова. Вручну з цим уже не впоратися.

Тому маршрутизатори здебільшого обмінюються маршрутами між собою автоматично. Для цього існують **протоколи маршрутизації**. Це називають **динамічною маршрутизацією** — на відміну від **статичної маршрутизації**, за якої все вносять уручну.

Найвідоміші протоколи маршрутизації:

| Протокол | Ідея | Типове застосування |
|---|---|---|
| **RIP** (*Routing Information Protocol*) | Кожен маршрутизатор регулярно повідомляє сусідам, до яких мереж він може дістатися і через скільки маршрутизаторів (*хопів*). | малі мережі, навчальний приклад |
| **OSPF** (*Open Shortest Path First*) | Кожен маршрутизатор знає повну схему мережі й сам обчислює з неї найкоротший шлях. | корпоративні мережі |
| **BGP** (*Border Gateway Protocol*) | Великі мережеві оператори (наприклад, інтернет-провайдери) повідомляють одне одному, до яких мереж вони мають доступ. | інтернет між провайдерами |

:::quiz match
RIP -> Маршрутизатори повідомляють сусідам, через скільки хопів вони можуть дістатися мережі
OSPF -> Кожен маршрутизатор знає всю схему мережі й обчислює найкоротший шлях
BGP -> З'єднує мережі великих інтернет-провайдерів
:::

:::evaluate
Перевірити відповідність
:::

:::tip Запам'ятай
За **статичної маршрутизації** адміністратор вносить усі маршрути вручну. За **динамічної маршрутизації** маршрутизатори автоматично обмінюються маршрутами за допомогою **протоколів маршрутизації**, таких як RIP, OSPF або BGP, і самі пристосовуються, якщо з'єднання обривається.
:::

:::note
BeaverTracer може симулювати RIP, OSPF і BGP — ти знайдеш їх на вкладках маршрутизатора з такими самими назвами. У цьому курсі ми обмежуємося оглядом.
:::

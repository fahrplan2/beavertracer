# Проєкт: компанія з чотирма філіями

:::sim
url=/sims/lesson-4.5.4.btsim
:::

Компанія має головний офіс у **Ганау** та філії в **Касселі**, **Гіссені** та **Дармштадті**. Кожна філія має власну мережу та власний маршрутизатор. Усі маршрутизатори під'єднані виділеними лініями до **центральної мережі**, у якій також розташований головний сервер компанії.

## План адресації

Адміністратор розподілив адреси за такою схемою — вони вже внесені в симуляцію:

| Мережа | Діапазон адрес |
|---|---|
| Центральна мережа | `10.19.0.0/24` |
| Hanau | `10.19.1.0/24` |
| Kassel | `10.19.2.0/24` |
| Gießen | `10.19.3.0/24` |
| Darmstadt | `10.19.4.0/24` |

| Пристрій | у центральній мережі | у мережі філії |
|---|---|---|
| Server | `10.19.0.10` | — |
| Router Hanau | `10.19.0.1` | `10.19.1.1` |
| Router Kassel | `10.19.0.2` | `10.19.2.1` |
| Router Gießen | `10.19.0.3` | `10.19.3.1` |
| Router Darmstadt | `10.19.0.4` | `10.19.4.1` |
| ПК у філії | — | завжди `.2` (напр. PC Kassel `10.19.2.2`) |

На всіх маршрутизаторах `eth0` дивиться в центральну мережу, а `eth1` — у мережу філії.

## Твоє завдання

Щоб усі комп'ютери компанії могли зв'язуватися один з одним і з сервером, бракує ще двох речей:

1. **Шлюзи:** вкажи шлюз на всіх чотирьох ПК та на сервері. ПК використовують маршрутизатор своєї філії; сервер використовує **Router Hanau**.
2. **Таблиці маршрутизації:** додай на всіх чотирьох маршрутизаторах маршрути, яких ще не вистачає. Кожен маршрутизатор має знати мережі **трьох інших** філій.

Час від часу перевіряй за допомогою `ping` та `traceroute`.

<details>
<summary>Підказка: як тут виглядає маршрут?</summary>

Приклад для **Router Kassel**: пакети для Гіссена (`10.19.3.0/24`) йдуть на Router Gießen в його центральній мережі — тобто **Наступний стрибок** `10.19.0.3`, **Iface** `eth0`. За цим зразком кожному маршрутизатору потрібно три маршрути.
</details>

:::task
title: Мережа компанії готова?
Перевіряє, чи всі філії досягають сервера та чи філії з'єднані між собою. Для цього симуляція має працювати в режимі виконання.
check: pingOk(11, 19)
check: pingOk(13, 19)
check: pingOk(15, 19)
check: pingOk(17, 19)
check: pingOk(13, 15)
check: pingOk(15, 17)
check: pingOk(17, 11)
check: pingOk(11, 13)
:::

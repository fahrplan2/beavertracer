# Порівняння HTTP і HTTPS

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Вебсервер **www.beaver-schule.de** надає доступ до шкільного порталу оцінок як через HTTP, так і через HTTPS. Що бачить той, хто прослуховує мережу?

## Експеримент

1. Перейди в :fa-play: режим виконання і на **Client-PC** у :fa-globe: **Браузер** спочатку відкрий `http://www.beaver-schule.de/`, а потім `https://www.beaver-schule.de/`.
2. Відкрий у режимі :fa-magnifying-glass: **Трасування** трасування для **Client-PC**.
3. Спочатку знайди пакет `HTTP/1.1 200 OK` і клікни на нього. Внизу в деталях ти знайдеш вміст сторінки.

- [x] Усю вебсторінку, зокрема й оцінки Анни
- [ ] Лише адресу сервера

:::

Тепер частина про HTTPS. Знайди пакет `[SYN]`, яким клієнт починає друге з'єднання.

:::quiz short
Який порт призначення має HTTPS-з'єднання (стовпець **Info**, `… → ???`)?
= 443
:::

Тепер введи вгорі в полі фільтра трасування `tls` — тоді ти побачиш лише TLS-пакети.

:::quiz mc
Що вказано в стовпці **Info** у пакетах, які містять вебсторінку?
- [ ] `HTTP/1.1 200 OK`
- [x] `Application Data`
- [ ] `Encrypted HTML`
:::

- [x] Що використовується порт 443, тобто, імовірно, HTTPS
- [x] Скільки приблизно даних передається
- [ ] Яку сторінку було відкрито і що на ній написано

:::evaluate
Перевірити відповіді
:::

:::note
Клікни на пакет **Application Data**: корисні дані — це лише послідовність начебто випадкових байтів. Tracer не може їх розшифрувати — він так само не знає ключа сеансу, як і зловмисник.
:::

:::tip Запам'ятай
У випадку **HTTP** будь-хто, хто прослуховує мережу, може прочитати всю вебсторінку. У випадку **HTTPS** він бачить лише те, **хто з ким** спілкується (IP-адреси, порт 443), і **скільки** даних передається — вміст прихований у зашифрованому вигляді в пакетах **Application Data**.
:::

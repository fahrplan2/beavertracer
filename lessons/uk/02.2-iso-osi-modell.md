# Еталонна модель ISO/OSI

Модель ISO/OSI поділяє обмін даними між двома пристроями на сім рівнів. Кожен рівень має чітко окреслене завдання й використовує лише послуги рівня, що розташований безпосередньо під ним:

З експерименту на попередній сторінці ти вже знаєш чотири з цих рівнів: Ethernet (2), IPv4 (3), TCP (4) і HTTP (7). Саме ці номери та кольори Tracer показує тобі в дереві протоколів.

:::tip Мнемонічне правило
Від рівня 7 донизу: **П**ішов **П**етро **С**ьогодні **Т**ренувати **М**іцні **К**улаки **Ф**утбольні — **П**рикладний, **П**редставлення, **С**еансовий, **Т**ранспортний, **М**ережевий, **К**аналь­ний, **Ф**ізичний.
:::

:::note Граничні випадки
Не кожен протокол точно вписується в один рівень. Тому для таких протоколів Tracer показує кілька рівнів:

- **ARP** — рівень 2/3: він не має IP-заголовка, але зіставляє IP-адреси (рівень 3) з апаратними адресами (рівень 2).
- **TLS** — рівень 4/5: він працює безпосередньо поверх TCP і керує захищеним сеансом.
- **HTTPS** (HTTP усередині TLS) — рівні 5–7: класичний прикладний рівень моделі TCP/IP, з якою ти познайомишся на наступній сторінці.
:::

:::note
Рівень 1 описує саме передавання сигналів кабелем або радіоканалом. BeaverTracer не імітує цей рівень — кабелі завжди вважаються справними й підключеними, проблем із сигналом і колізій немає. Тому в Tracer розгляд практично починається з рівня 2.
:::

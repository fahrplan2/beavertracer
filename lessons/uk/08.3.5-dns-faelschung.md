# Атака: підміна DNS

:::sim
url=/sims/lesson-8.3.5.btsim
:::

Анна хоче відкрити на **Client-PC** свій онлайн-банкінг у **Biberbank**. Вона не знає одного: хтось отримав доступ до **DNS-Server** і змінив один із записів.

На робочій області ти бачиш справжній вебсервер **www.biberbank.de** та комп'ютер **зловмисника**. На ньому працює копія вебсторінки банку.

## Частина 1: Без шифрування

Перейди в :fa-play: режим виконання, відкрий на **Client-PC** у :fa-globe: **Браузер** адресу `http://www.biberbank.de/`.

:::quiz mc
Що ти бачиш?
- [x] Сторінку входу Biberbank без жодного попередження
- [ ] Попередження про те, що сторінка підроблена
- [ ] Повідомлення про помилку
:::

:::evaluate
Перевірити відповідь
:::

Усе виглядає нормально. Але з яким сервером браузер спілкується насправді? Відкрий на Client-PC :fa-terminal: **Термінал**:

```
$ nslookup www.biberbank.de
```

:::quiz short
Яку IP-адресу повертає DNS-сервер для `www.biberbank.de`?
= 192.168.0.66
:::

:::quiz mc
Кому належить ця адреса? (У режимі редагування клацни на пристрої або переглянь їхні :fa-gear: **Параметри IP**.)
- [ ] Справжньому вебсерверу Biberbank
- [x] Зловмиснику
- [ ] DNS-серверу
:::

:::evaluate
Перевірити відповіді
:::

Якби Анна зараз ввела номер рахунку та PIN-код, вони б одразу потрапили до зловмисника. У випадку **HTTP** вона **не має жодних шансів** помітити шахрайство: адресний рядок показує правильне ім'я, а сторінка виглядає справжньою.

## Частина 2: З HTTPS

Тепер відкрий `https://www.biberbank.de/`.

:::quiz mc
Що відбувається?
- [ ] З'являється підроблена сторінка із замком
- [x] Браузер попереджає: сертифікат видано для іншого імені
- [ ] З'являється справжня сторінка Biberbank
:::

:::quiz short
Для якого імені видано сертифікат зловмисника (без `CN=`)?
= www.biber-gewinnspiel.de
:::

:::evaluate
Перевірити відповіді
:::

Зловмисник має навіть **справжній** сертифікат довіреного центру сертифікації (CA), але для власного домену `www.biber-gewinnspiel.de`. Сертифікат для `www.biberbank.de` він не отримає в жодного CA, адже цей домен йому не належить. А без **приватного ключа** Biberbank він не може використати і її справжній сертифікат: під час handshake йому довелося б підписати ним Server Key Exchange.

:::quiz multi
Від чого HTTPS тут захищає, а від чого ні?
- [x] HTTPS виявляє, що сервер не справжній
- [ ] HTTPS запобігає підміні DNS-сервера
- [x] HTTPS допомагає, лише якщо користувач серйозно сприймає попередження
- [ ] З HTTPS підроблена сторінка взагалі недоступна
:::

:::evaluate
Перевірити відповіді
:::

## Частина 3: Виправлення DNS-сервера

Відкрий **DNS-Server** і виправ запис для `www.biberbank.de`. Правильну адресу ти знайдеш у :fa-gear: **Параметрах IP** вебсервера **www.biberbank.de**. Не забудь натиснути **Зберегти**.

:::note
Client-PC запам'ятовує відповіді DNS на деякий час, щоб не запитувати їх заново при кожному зверненні (**DNS-кеш**). Як довго, вказано в стовпці **TTL** (*Time to Live*) у секундах. Якщо `nslookup` одразу після твого виправлення ще повертає стару адресу, дочекайся спливу TTL і спробуй ще раз.
:::

:::task
title: Biberbank знову справжній?
Перевіряє, чи Client-PC розпізнає www.biberbank.de за правильною адресою і чи може відкрити сторінку через HTTPS без попередження.
check: resolves(2, "www.biberbank.de", "192.168.0.30")
check: httpsOk(2, "https://www.biberbank.de/")
:::

:::note
У реальному житті зловмисник рідко підробляє сам DNS-сервер. Частіше він підсовує свої відповіді в публічній мережі Wi-Fi, змінює налаштування домашнього маршрутизатора або заманює схожою на справжню адресою, наприклад `www.biberbank-login.de` (**фішинг**). Проти схожого за звучанням імені HTTPS також не допоможе: для нього зловмисник отримає дійсний сертифікат. Тому уважно читай адресу!
:::

:::tip Запам'ятай
У разі **підміни DNS** DNS-сервер повертає для імені адресу зловмисника. При **HTTP** цього не помітити. При **HTTPS** сертифікат зловмисника не відповідає запитаному імені, і браузер **попереджає**: адже сертифікат для чужих доменів жоден CA не видає, а приватного ключа справжнього сервера зловмисник не має.
:::

# UDP: суттєве спрощення

:::goal
**Навчальна мета:** Ти вмієш порівнювати UDP із TCP та можеш обґрунтувати, для яких застосунків UDP є кращим вибором.
:::

:::sim
url=/sims/lesson-5.5.btsim
:::

TCP робить багато: встановлення з'єднання, підтвердження, повторне передавання, дотримання порядку. Але це коштує часу та додаткових пакетів. Другий важливий протокол транспортного рівня відмовляється майже від усього цього: це **User Datagram Protocol** (**UDP**). Його пакети називаються **датаграмами**.

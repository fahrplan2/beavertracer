# Stateful-брандмауер

:::sim
url=/sims/lesson-9.2.btsim
:::

**Stateful-брандмауер** (*stateful*, «із відстеженням стану») запам'ятовує кожне з'єднання, яке він колись дозволив, у **таблиці станів**: протокол, обидві адреси та обидва порти. Якщо надходить пакет, що відповідає запису, — незалежно від напрямку, — він пропускає його без додаткової перевірки. Нові з'єднання, навпаки, мають пройти через правила.

## Спостереження

1. У **брандмауері** встанови **режим** **Stateful**.
2. На **ПК вчителя** у :fa-globe: **Браузер** знову відкрий `http://203.0.113.80/`.
3. Одразу відкрий у брандмауері вкладку **Zustände**.

:::quiz mc
Що відбувається тепер?
- [x] Сторінка завантажується, а в **Zustände** є з'єднання від ПК вчителя до `203.0.113.80:80`
- [ ] Сторінка не завантажується, бо для відповідей досі немає правила
:::

:::quiz short
Який порт указано в таблиці станів у стовпці **Ziel**?
= 80
:::

:::evaluate
Перевірити відповіді
:::

Записи в **Zustände** через деякий час зникають (стовпець **Timeout**), якщо з'єднанням більше нічого не передається.

## Завдання: шкільний брандмауер

Налаштуй брандмауер так, як це потрібно справжній школі:

- **Зі шкільної мережі** дозволено все в інтернет (напрямок B → A, будь-який протокол).
- **З інтернету** доступні лише веб (80) та приймання пошти (25) шкільного сервера.
- Усе інше **відкидається**, режим — **Stateful**.

:::task
title: Шкільний брандмауер налаштовано?
Перевіряє, чи шкільна мережа має доступ до інтернету, чи ззовні доступні лише веб і пошта шкільного сервера та чи ПК вчителя недоступний ззовні.
check: tcpOpen(8, "203.0.113.80", 80)
check: tcpOpen(1, "198.51.100.10", 80)
check: tcpOpen(1, "198.51.100.10", 25)
check: tcpFails(1, "198.51.100.10", 22)
check: pingFails(1, 8)
:::

:::quiz mc
ПК вчителя виконує ping до `203.0.113.80`. Чи повертаються відповіді?
- [x] Так — ping було дозволено правилом B → A, відповідь належить до цього стану
- [ ] Ні — для ICMP ззовні немає правила
:::

:::evaluate
Перевірити відповідь
:::

:::tip Запам'ятай
**Stateful-брандмауер** заносить кожне дозволене з'єднання до **таблиці станів** і пропускає всі пакети цього з'єднання в **обох напрямках**. Тому достатньо правил для **встановлення з'єднання**: «Зсередини можна назовні» і «ззовні — лише до певних служб». З'єднання, ініційовані ззовні до шкільної мережі, залишаються заблокованими.
:::

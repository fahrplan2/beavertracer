# Розділення шкільної мережі на підмережі

:::sim
url=/sims/lesson-4.4.2.btsim
:::

Школа має діапазон адрес `192.168.10.0/24`. Адміністрація, вчительська та комп'ютерний клас мають отримати по окремій підмережі. Це три мережі, але підмережі однакового розміру бувають лише в кількості, що дорівнює степеню двійки. Тому ти ділиш на **чотири** підмережі; четверта залишається в резерві (наприклад, для майбутньої бездротової мережі).

## Крок 1: Обчислення

:::quiz table
| Біти розширення | Довжина префікса | Маска мережі |
|---|---|---|
| {2} | /{26} | {255.255.255.192} |
:::

:::quiz table
| Підмережа | Призначення | Адреса мережі | Широкомовна адреса |
|---|---|---|---|
| 1 | Адміністрація | {192.168.10.0} | {192.168.10.63} |
| 2 | Вчительська | {192.168.10.64} | {192.168.10.127} |
| 3 | Комп'ютерний клас | {192.168.10.128} | {192.168.10.191} |
| 4 | Резерв | {192.168.10.192} | {192.168.10.255} |
:::

:::evaluate
Перевірити відповіді
:::

## Крок 2: Налаштування

Маршрутизатор уже налаштований: у кожній підмережі він має **першу придатну для використання адресу** (`192.168.10.1`, `192.168.10.65` та `192.168.10.129`).

Тепер налаштуй три ПК. Кожен ПК отримує **другу придатну для використання адресу** своєї підмережі, відповідну довжину префікса та як шлюз адресу маршрутизатора у своїй підмережі.

1. Перейди в :fa-play: режим виконання.
2. Відкрий у **PC Verwaltung** :fa-gear: **Параметри IP**, введи **IP**, **довжину префікса** та **шлюз** і натисни **Застосувати**.
3. Зроби те саме для **PC Lehrerzimmer** та **PC Computerraum**.
4. Перевір за допомогою `ping`, чи ПК доступні одне для одного.

:::task
title: Шкільну мережу налаштовано?
Перевіряє адреси трьох ПК і те, чи вони доступні одне для одного через маршрутизатор. Для цього симуляція має працювати в режимі виконання.
check: ip(9, "192.168.10.2/32")
check: ip(11, "192.168.10.66/32")
check: ip(13, "192.168.10.130/32")
check: pingOk(9, 11)
check: pingOk(9, 13)
check: pingOk(11, 13)
:::

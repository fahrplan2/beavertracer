# Problém s odpověďmi

:::sim

Firewall nyní pracuje podle principu whitelistu: výchozí politika je **Zahodit vše**. Jediné pravidlo povoluje školní síti surfování: **B → A, TCP, cílový port 80, Povolit**. Režim je nastaven na **Stateless**.

## Experiment

1. Přepni do režimu :fa-play: **Spustit** a na **Lehrer-PC** otevři v :fa-globe: **Prohlížeči** adresu `http://203.0.113.80/`.
2. Ve **Firewallu** si prohlédni **Protokol** a **Zásahy**.

:::quiz mc
Co se stane v prohlížeči?
- [ ] Zobrazí se stránka www.beispiel.de
- [x] Stránka se nenačte, prohlížeč čeká a nakonec ohlásí chybu
:::

:::quiz mc
Které pakety jsou v protokolu firewallu uvedeny jako zahozené (`DROP`)?
- [ ] Požadavky Lehrer-PC na port 80
- [x] Odpovědi z `203.0.113.80` se **zdrojovým portem 80** směrem k Lehrer-PC
- [ ] Žádné
:::

:::quiz short
Jakým směrem (A→B, nebo B→A) putují zahozené pakety?
= A→B
= A → B
= AtoB
:::

:::evaluate
Zkontrolovat odpovědi
:::

Požadavek z Lehrer-PC smí ven, ale už `SYN, ACK` webového serveru se nevrátí, protože pro směr A → B neexistuje žádné odpovídající pravidlo, a platí tedy **Zahodit vše**.

## Naivní řešení

Mohli bychom přidat druhé pravidlo: **A → B, TCP, zdrojový port 80, Povolit**, tedy „všechno, co přichází z portu 80, smí dovnitř“. Surfování pak skutečně funguje.

:::quiz mc
Proč je toto pravidlo nebezpečné?
- [ ] Protože webové servery nikdy nepoužívají port 80 jako zdrojový port
- [x] Útočník může své pakety jednoduše odeslat se zdrojovým portem 80, a firewall je pak propustí na **jakýkoli** port ve školní síti
- [ ] Protože se pak webové stránky načítají pomaleji
:::

:::evaluate
Zkontrolovat odpověď
:::

Zdrojový port určuje odesílatel sám, a firewall se proto nesmí na tento údaj spoléhat. Bezstavový firewall ale neví, zda je paket **odpovědí na požadavek**, nebo **novým pokusem o spojení** zvenčí. Právě to mění stavový režim.

:::tip Zapamatuj si
**Bezstavový** paketový filtr kontroluje každý paket zvlášť. Odpovědi pak potřebují vlastní pravidla pro opačný směr, a taková pravidla (např. „zdrojový port 80 smí dovnitř“) mohou útočníci zneužít, protože odesílatel si zdrojový port může zvolit libovolně.
:::

## Co za tím stojí

E-mail putuje v několika etapách — podobně jako dopis přes dvě pošty:

1. Annin e-mailový program předá e-mail pomocí **SMTP** Anninu mailovému serveru.
2. Mailserver Schule zjistí: Příjemce patří do **cizí domény**. Pomocí **DNS** se zeptá na **MX záznam** (*Mail Exchanger*) domény `biber-mail.de` a dostane `mail.biber-mail.de` — poté ještě jeho IP adresu.
3. Pomocí **SMTP** e-mail doručí Mailserveru Biber. Tam leží v poštovní schránce Bena.
4. Ben si ho vyzvedne ze svého mailového serveru pomocí **IMAP** (nebo **POP3**).

:::seq
mode: text
Mailserver Schule -> Mailserver Biber: SMTP: MAIL FROM | anna@beaver-schule.de
Mailserver Biber -> Mailserver Schule: 250 OK
Mailserver Schule -> Mailserver Biber: SMTP: RCPT TO | ben@biber-mail.de
Mailserver Biber -> Mailserver Schule: 250 OK
Mailserver Schule -> Mailserver Biber: SMTP: DATA | samotný e-mail
Mailserver Biber -> Mailserver Schule: 250 OK queued
:::

:::tip Zapamatuj si
**SMTP** (port 25) **odesílá** e-maily: z e-mailového programu na vlastní mailový server a odtud na mailový server příjemce. Který mailový server je zodpovědný za doménu, je uvedeno v **MX záznamu** v DNS. **POP3** (port 110) a **IMAP** (port 143) slouží pouze k **vyzvedávání** z vlastní poštovní schránky.
:::

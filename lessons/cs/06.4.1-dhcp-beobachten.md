# Automatické získání adresy

:::sim
url=/sims/lesson-6.4.btsim

K switchi jsou připojeny **DHCP Server** a dva laptopy. Laptopy mají zatím pevné adresy.

## Experiment

1. Přepni se do :fa-play: režimu spuštění, klikni na **Laptop 1** a otevři :fa-gear: **Nastavení IP**.
2. Změň **Režim** ze **Statické** na **DHCP** a klikni na **Aplikovat**.
3. Počkej pár sekund: pole se vyplní sama.
4. V :fa-magnifying-glass: režimu **Trasování** otevři trace pro **Laptop 1**.

:::quiz table
| Nastavení | získáno od DHCP serveru |
|---|---|
| IP adresa | {192.168.0.100} |
| Gateway | {192.168.0.1} |
| DNS server | {192.168.0.53} |
:::

= 4
= čtyři
:::

:::quiz mc

- [ ] Na DHCP server `192.168.0.2`

## Co za tím stojí: DORA

Zařízení bez adresy neví, kde je DHCP server, a nemá ani vlastní adresu odesílatele. Proto volá do sítě pomocí **broadcastu**. Průběh má čtyři kroky — podle jejich počátečních písmen se nazývá **DORA**:

:::seq
mode: text
Laptop 1 -> DHCP-Server: DHCP Discover | „Je tady nějaký DHCP server?“
DHCP-Server -> Laptop 1: DHCP Offer | „Můžeš dostat 192.168.0.100.“
Laptop 1 -> DHCP-Server: DHCP Request | „Beru 192.168.0.100.“
DHCP-Server -> Laptop 1: DHCP ACK | „Potvrzeno — platí 3600 sekund.“
:::

Adresa je pouze **zapůjčená** (*lease*): po uplynutí **doby zápůjčky** (*lease time*) ji musí zařízení obnovit, jinak ji smí server přidělit znovu. Které adresy jsou právě zapůjčené, uvidíš v **DHCP Serveru** na kartě **Leases**.

:::tip Vyzkoušej si to
Nastav na DHCP i **Laptop 2**. Jakou adresu dostane? Potom se podívej do **Leases** DHCP serveru.
:::

:::tip Zapamatuj si
**DHCP** automaticky přiděluje IP adresu, masku sítě, gateway a DNS server. Průběh se nazývá **DORA**: **D**iscover (klient hledá pomocí broadcastu), **O**ffer (server nabízí), **R**equest (klient přijímá), **A**CK (server potvrzuje). Adresa je zapůjčená na dobu **lease time**. DHCP používá **UDP**, port 67 (server) a 68 (klient).
:::

:::quiz match
Discover -> Klient hledá pomocí broadcastu DHCP server
Offer -> Server nabízí adresu
Request -> Klient si vyžádá nabízenou adresu
ACK -> Server potvrzuje přidělení
:::

# První vlastní pravidla

:::sim
url=/sims/lesson-9.btsim

Teď je řada na tobě. Firewall zatím propouští všechno. Zajisti, aby z internetu byly dostupné jen **web (80)** a **příjem pošty (25)** školního serveru. **SSH (22)**, **POP3 (110)** a **IMAP (143)** už z internetu dostupné být nemají.

## Zadání pravidel

1. Klikni na **Firewall**. Výchozí politika zatím zůstane nastavená na **Povolit vše**.
2. Smaž stávající pravidlo (stejně povoluje všechno) a pomocí **+ Přidat pravidlo** vytvoř pravidlo pro každý port, který má být zavřený:
    - **Směr** A → B (z internetu)
    - **Protokol** TCP
    - **Cílový port** např. `22`
    - **Akce** Zahodit
3. Z **Internet-PC** pomocí `nmap 198.51.100.10` ověř, že zůstaly otevřené jen správné porty.

:::task
title: Jen web a pošta zvenčí?
Kontroluje, zda je školní server z internetu dostupný už jen na portu 80 a 25 – a zda si učitelský počítač může dál stahovat poštu a surfovat na internetu. Simulace musí běžet v režimu spuštění.
check: tcpOpen(1, "198.51.100.10", 80)
check: tcpOpen(1, "198.51.100.10", 25)
check: tcpFails(1, "198.51.100.10", 22)
check: tcpFails(1, "198.51.100.10", 110)
check: tcpFails(1, "198.51.100.10", 143)
check: tcpOpen(8, "198.51.100.10", 110)
check: tcpOpen(8, "203.0.113.80", 80)
:::

:::quiz mc
Učitelský počítač si může dál stahovat poštu ze školního serveru přes POP3 (110). Proč mu firewall nevadí?
- [ ] Protože firewall pozná učitele
- [x] Protože jeho pakety firewallem vůbec neprocházejí – učitelský počítač a školní server jsou připojeny ke stejnému switchi za firewallem
- [ ] Protože POP3 je bezpečný protokol
:::

:::evaluate
Zkontrolovat odpověď
:::

:::note
Firewall chrání jen provoz, který **jím prochází**. To, co se děje uvnitř školní sítě, nevidí. Infikovaný počítač ve školní síti tak může školní server přesto napadnout – právě o tom je část věnovaná DMZ.
:::

:::tip Zapamatuj si
Pro každou službu, která nemá být zvenčí dostupná, zablokuje přístup pravidlo se **směrem**, **protokolem** a **cílovým portem**. Zda pravidla fungují, ověříš zvenčí pomocí **skenování portů**.
:::

# Jak je organizován DNS

:::sim
url=/sims/lesson-6.2.btsim
:::

Žádný jednotlivý server nemůže znát všechna jména na světě. DNS je proto vystavěn **hierarchicky** — stejně jako samotná jména. Čtou se zprava doleva:

```
www . beaver-schule . de . (Root)
 │          │         │      └─ Root-Server: kennen die Server aller Top-Level-Domains
 │          │         └─ Top-Level-Domain (TLD): der de-Server kennt alle .de-Domains
 │          └─ Domain: der Schul-DNS ist für beaver-schule.de zuständig
 └─ Rechnername innerhalb der Domain
```

Server, který je za doménu zodpovědný a odpověď opravdu zná, se nazývá **autoritativní**. Cestu k němu za PC zajišťuje **resolver** — tady počítač **DNS-Resolver**.

## Experiment

1. Přepni se do režimu :fa-play: **Spustit** a na počítači **Client-PC** zadej v :fa-terminal: **Terminál**u:
   ```
   $ nslookup www.beaver-schule.de
   ```
2. V režimu :fa-magnifying-glass: **Trasování** otevři trace pro **DNS-Resolver**.

Resolver za tebe odeslal celou řadu dotazů. Přiřaď, kdo dal kterou odpověď:

:::quiz match
Root-Server (192.168.0.101) -> Odkaz: Za .de je zodpovědný ns.nic.de
de-Server (192.168.0.102) -> Odkaz: Za beaver-schule.de je zodpovědný ns.beaver-schule.de
Schul-DNS (192.168.0.103) -> Odpověď: www.beaver-schule.de má adresu 192.168.0.20
:::

:::quiz mc
Koho se resolver zeptá jako prvního?
- [x] Root serveru
- [ ] Schul-DNS
- [ ] Client-PC
:::

:::evaluate
Zkontrolovat odpovědi
:::

:::note
Mezitím se resolver ptá i na adresy serverů, na které byl odkázán (`A ns.nic.de`). Skutečné DNS servery tyto adresy obvykle pošlou rovnou s odpovědí. Resolvery si navíc každou odpověď na nějakou dobu zapamatují (**cache**) — na další dotaz na stejné jméno pak odpoví hned samy. Jak dlouho, je uvedeno v záznamu jako **TTL** (*Time to Live*) v sekundách.
:::

## Nejdůležitější typy záznamů

| Typ | Význam | Příklad |
|---|---|---|
| **A** | jméno → adresa IPv4 | `www.beaver-schule.de` → `192.168.0.20` |
| **AAAA** | jméno → adresa IPv6 | `www.beaver-schule.de` → `2001:db8::20` |
| **CNAME** | jméno → jiné jméno (alias) | `web.beaver-schule.de` → `www.beaver-schule.de` |
| **MX** | zodpovědný poštovní server domény | `beaver-schule.de` → `mail.beaver-schule.de` |
| **NS** | zodpovědný DNS server domény | `beaver-schule.de` → `ns.beaver-schule.de` |

:::tip Zapamatuj si
DNS je **hierarchický**: **Root servery** odkazují na servery **domén nejvyšší úrovně** (např. `.de`), ty pak na servery jednotlivých **domén**. Zodpovědný **autoritativní** server zná odpověď. **Resolver** projde tuto cestu za PC a odpovědi si zapamatuje (**cache**). Důležité typy záznamů: **A**, **AAAA**, **CNAME**, **MX**, **NS**.
:::

## Vytvoření záznamu

Škola chce, aby její web byl dostupný také na adrese `intranet.beaver-schule.de`.

1. V režimu :fa-play: **Spustit** klikni na **Schul-DNS** a otevři aplikaci **DNS-Server**.
2. Otevři kartu **A**. Klikni na **+** a do nového řádku zadej jméno `intranet.beaver-schule.de` a adresu `192.168.0.20`.
3. Na Client-PC otestuj pomocí `nslookup intranet.beaver-schule.de`.

:::task
title: Je nové jméno zadáno?
Zkontroluje, zda Client-PC přeloží jméno intranet.beaver-schule.de na adresu webového serveru. Simulace musí být přitom spuštěna v režimu spuštění.
check: resolves(2, "intranet.beaver-schule.de", "192.168.0.20")
:::

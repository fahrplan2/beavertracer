# Výhled: dynamické směrování

V projektu jsi pro čtyři pobočky ručně zadal(a) dvanáct tras. Velká firemní síť má stovky routerů, internet desetitisíce — a neustále někde vypadne linka nebo přibude nová. Ručně už se to zvládnout nedá.

Proto si routery své trasy většinou vyměňují mezi sebou automaticky. K tomu slouží **směrovací protokoly**. Mluvíme pak o **dynamickém směrování** — na rozdíl od **statického směrování**, při kterém se všechno zadává ručně.

Nejznámější směrovací protokoly:

| Protokol | Myšlenka | typické nasazení |
|---|---|---|
| **RIP** (*Routing Information Protocol*) | Každý router pravidelně sděluje svým sousedům, do jakých sítí se dostane a přes kolik routerů (*hopů*). | malé sítě, výukový příklad |
| **OSPF** (*Open Shortest Path First*) | Každý router zná kompletní plán sítě a sám z něj vypočítá nejkratší cestu. | firemní sítě |
| **BGP** (*Border Gateway Protocol*) | Velcí provozovatelé sítí (např. poskytovatelé internetu) si navzájem sdělují, do kterých sítí se dostanou. | internet mezi poskytovateli |

:::quiz match
RIP -> Routery sdělují svým sousedům, přes kolik hopů se dostanou do sítě
OSPF -> Každý router zná celé schéma sítě a vypočítá nejkratší cestu
BGP -> Propojuje sítě velkých poskytovatelů internetu
:::

:::tip Zapamatuj si
Při **statickém směrování** zadává správce všechny trasy ručně. Při **dynamickém směrování** si routery vyměňují své trasy automaticky pomocí **směrovacích protokolů** jako RIP, OSPF nebo BGP — a samy se přizpůsobí, když spojení vypadne.
:::

:::note
BeaverTracer umí simulovat RIP, OSPF i BGP — najdeš je na stejnojmenných kartách routeru. V tomto kurzu zůstáváme jen u výhledu.
:::

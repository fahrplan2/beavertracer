# Proč jedna síť nestačí

:::sim
url=/sims/lesson-4.1.btsim
:::

Na pracovní ploše vidíš dvě malé firemní sítě: **Firma A** s Annou (`192.168.0.10`) a Benem (`192.168.0.11`), **Firma B** s Clarou (`172.16.0.10`) a Davidem (`172.16.0.11`). Oba switche jsou dokonce propojené přímo kabelem.

## Ping ve vlastní síti

1. Přepni se do režimu spuštění :fa-play: **Spustit**, na **Anna** otevři :fa-terminal: **Terminál** a pošli ping na Bena:
   ```
   $ ping 192.168.0.11
   ```
2. Přepni se do režimu :fa-magnifying-glass: **Trasování**, otevři trace pro **Anna** a klikni na `Echo (ping) request`.
3. Ve stromu protokolů rozbal řádek **Internet Protocol Version 4**. To je IP část paketu — část, o které je tato kapitola.

:::quiz match
Source Address -> IP adresa odesílatele
Destination Address -> IP adresa příjemce
Time to Live -> Kolika routery může paket ještě projít
Protocol -> Jaký protokol je uvnitř paketu (zde ICMP, tedy ping)
:::

:::evaluate
Zkontrolovat přiřazení
:::

## Ping do jiné sítě

Přepni se zpět do režimu spuštění :fa-play: **Spustit** a pošli z **Anna** ping na Claru (`ping 172.16.0.10`). Poté se znovu podívej na trace Anny.

:::quiz mc

- [ ] Ping projde — switche přece jsou propojené

- [ ] Anna pošle ARP dotaz, ale Clara neodpoví

## Co za tím stojí

IP adresa funguje podobně jako poštovní adresa: jedna část říká, ve které **síti** se zařízení nachází (jako ulice), druhá část, o které **zařízení** v této síti jde (jako číslo domu). Anna je v síti `192.168.0…`, Clara v síti `172.16.0…` — dvě různé „ulice“.

Zařízením ve *vlastní* síti posílá počítač pakety přímo (přes ARP a switch, jak už víš). Pro *cizí* síť potřebuje zařízení, které sítě navzájem propojuje a předává pakety dál: **router**. Ten tu zatím není — proto nepomůže ani kabel mezi switchi.

:::tip Zapamatuj si
**Internet Protocol** (**IP**) na vrstvě 3 zajišťuje, aby pakety docházely i mezi různými sítěmi. **IP adresa** se skládá ze **síťové části adresy** (v jaké síti?) a **hostitelské části adresy** (které zařízení?). Zařízení ve stejné síti se dosáhnou přímo — pro jiné sítě je potřeba **router**.
:::

Tím vyvstávají dvě otázky, kterým se budeme věnovat v dalších částech: Jak počítač pozná, *kde přesně* v adrese končí síťová část? A jak funguje router?

# DNS: názvy místo čísel

:::goal
**Cíl výuky:** Dokážeš vysvětlit, jak DNS překládá názvy na IP adresy a jak jsou názvy hierarchicky uspořádány. Sám si vytvoříš záznam a najdeš typické chyby DNS.
:::

:::sim
url=/sims/lesson-6.2.btsim
:::

IP adresy si skoro nikdo nezapamatuje, ale názvy jako `www.beaver-schule.de` ano. Překlad zajišťuje **Domain Name System** (**DNS**), jakýsi celosvětový telefonní seznam internetu.

Na pracovní ploše je teď o něco větší síť: kromě **Client-PC** a **Webserveru** v ní jsou čtyři **DNS servery**. K čemu je jich tolik, uvidíš o dvě stránky dál.

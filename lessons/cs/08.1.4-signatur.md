# Digitální podpisy

Šifrováním dosáhneme **důvěrnosti**, pomocí hashů poznáme změny. Ale jak dokázat, **od koho** zpráva pochází? Na papíře se podepisujeme. V síti k tomu slouží **digitální podpis**.

## Dvojice klíčů použitá obráceně

Při šifrování používá odesílatel **veřejný** klíč příjemce. U podpisu je to naopak: odesílatel použije svůj **vlastní soukromý** klíč. Protože tento klíč má jen on, může podpis vytvořit také jen on. Ověřit ho naproti tomu může kdokoli — pomocí **veřejného** klíče odesílatele.

**Podepisování** (Anna podepisuje smlouvu):

1. Anna vypočítá **hash** smlouvy.
2. Hash zpracuje se svým **soukromým klíčem**. Výsledkem je **podpis**.
3. Smlouvu spolu s podpisem pošle Benovi.

**Ověřování** (Ben kontroluje podpis):

1. Ben sám vypočítá hash přijaté smlouvy.
2. Ověří podpis pomocí Annina **veřejného klíče**: Odpovídá podpis tomuto hashi?
3. Pokud odpovídá, Ben ví dvě věci:
    - Smlouva skutečně pochází od Anny — soukromý klíč má jen ona (**autenticita**).
    - Smlouva nebyla cestou změněna — jinak by měla jiný hash (**integrita**).

:::note
Proč Anna podepisuje jen hash a ne celou smlouvu? Asymetrické metody jsou pomalé. Hash je vždy krátký — ať už má smlouva jednu stranu, nebo tisíc stran.
:::

:::quiz mc
Jakým klíčem Anna svůj podpis **vytváří**?
- [x] Svým soukromým klíčem
- [ ] Svým veřejným klíčem
- [ ] Benovým veřejným klíčem
:::

:::quiz mc
Jakým klíčem Ben podpis **ověřuje**?
- [ ] Svým soukromým klíčem
- [x] Anniným veřejným klíčem
- [ ] Anniným soukromým klíčem
:::

:::quiz mc
Útočník zachytí smlouvu a změní částku. Podpis ponechá tak, jak je. Co se stane při Benově ověření?
- [x] Ověření selže, protože změněná smlouva má jiný hash
- [ ] Ověření uspěje, protože podpis je přece pravý
- [ ] Ben podpis vůbec nemůže ověřit, protože nezná Annin soukromý klíč
:::

:::tip Zapamatuj si
**Digitální podpis** vytvoří odesílatel z **hashe** zprávy a svého **soukromého klíče**. Každý ho může ověřit pomocí **veřejného klíče** odesílatele. Platný podpis dokazuje, **od koho** zpráva pochází (**autenticita**) a že **nebyla změněna** (**integrita**).
:::

# POP3 nebo IMAP?

:::sim
url=/sims/lesson-6.3.btsim
:::

Pro stahování pošty existují dva protokoly. V této simulaci používá **Anna POP3** a **Ben IMAP**.

## Experiment

1. V :fa-play: režimu **spuštění** pošli e-mail od **Bena** na adresu `anna@beaver-schule.de`.
2. U **Anny** klikni v aplikaci **E-Mail** na **Načíst**.
3. Otevři trasování (traces) pro **Annu** a pro **Bena** a porovnej příkazy při stahování pošty.

:::quiz match
USER / PASS -> POP3: přihlášení pomocí uživatelského jména a hesla ve dvou krocích
RETR -> POP3: stažení zprávy
LOGIN -> IMAP: přihlášení pomocí uživatelského jména a hesla
SELECT INBOX -> IMAP: otevření složky na serveru
:::

## Rozdíl

| | POP3 | IMAP |
|---|---|---|
| Port | 110 | 143 |
| Základní myšlenka | e-maily se **stáhnou** — poté se obvykle na serveru smažou | e-maily **zůstávají na serveru** a spravují se tam |
| Složky, přečtené/nepřečtené | pouze na vlastním zařízení | na serveru — všude stejné |
| Více zařízení (mobil, notebook) | nepraktické: každé zařízení má jiný stav | ideální: všechna zařízení vidí stejnou poštovní schránku |

:::note
E-mailový program v BeaverTraceru nechává e-maily na serveru i při POP3. Skutečné programy je po stažení často mažou — nebo je tam nechají jen nějakou dobu.
:::

:::quiz mc
Lena čte e-maily v mobilu, v tabletu a ve školním notebooku. Co by měla použít?
- [ ] POP3, protože je jednodušší
- [x] IMAP, protože všechna zařízení vidí stejnou poštovní schránku na serveru
- [ ] SMTP, protože je určeno ke stahování pošty
:::

:::tip Zapamatuj si
**POP3** stahuje e-maily ze serveru do **jednoho** zařízení. **IMAP** spravuje poštovní schránku **na serveru** — se složkami a stavem přečtení pro všechna zařízení současně. Oba protokoly slouží pouze ke **stahování pošty**; odesílá se vždy pomocí **SMTP**.
:::

## Jak vypadá požadavek

Klikni v trace na paket `GET / HTTP/1.1` a rozbal **Hypertext Transfer Protocol**. HTTP požadavek je čistý text:

```
GET / HTTP/1.1              ← Methode, Pfad, Version
Host: 192.168.0.20          ← Header: zusätzliche Angaben
…
                            ← Leerzeile: Ende der Anfrage
```

Odpověď serveru je postavená stejně — se stavovým řádkem, hlavičkami, prázdným řádkem a poté samotným souborem:

```
HTTP/1.1 200 OK             ← Version, Statuscode, Text
Content-Type: text/html     ← Header: Art der Datei
Content-Length: 301         ← Header: Größe in Byte
                            ← Leerzeile
<!doctype html> …           ← die Datei selbst
```

:::seq
mode: text
Client-PC -> Server: GET / | HTTP požadavek
Server -> Client-PC: 200 OK | index.html
Client-PC -> Server: GET /style.css | HTTP požadavek
Server -> Client-PC: 200 OK | style.css
:::

## Metody a stavové kódy

**Metoda** říká, co klient chce:

| Metoda | Význam |
|---|---|
| **GET** | načíst soubor |
| **POST** | poslat serveru data, např. vyplněný formulář |
| **HEAD** | načíst jen hlavičky, bez souboru |

**Stavový kód** říká, jak to dopadlo. První číslice prozrazuje druh odpovědi:

| Kód | Text | Význam |
|---|---|---|
| **200** | OK | vše v pořádku |
| **301** | Moved Permanently | stránka se trvale přestěhovala |
| **404** | Not Found | soubor neexistuje |
| **405** | Method Not Allowed | tato metoda zde není povolena |
| **500** | Internal Server Error | chyba na serveru |

`2xx` znamená úspěch, `3xx` přesměrování, `4xx` chybu klienta (chybný požadavek), `5xx` chybu serveru.

:::tip Zapamatuj si
**HTTP** pracuje podle principu **požadavek–odpověď**: Klient pošle **požadavek** (metoda jako `GET`, cesta, hlavičky), server odpoví **stavovým kódem** (např. `200 OK`, `404 Not Found`), hlavičkami a souborem. Pro každý soubor webové stránky existuje samostatný požadavek.
:::

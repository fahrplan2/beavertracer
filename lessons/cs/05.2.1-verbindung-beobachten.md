# Spojení od začátku do konce

:::sim
url=/sims/lesson-5.1.btsim
:::

Na **serveru** běží služba echo na portu `5000`: každou zprávu okamžitě pošle zpět. Pomocí **Jednoduchého TCP klienta** můžeš řídit spojení krok za krokem — každé tlačítko je jedna fáze.

## Experiment

1. Přepni se do režimu :fa-play: **Spustit**, klikni na **Client-PC** a otevři **Jednoduchý TCP klient**.
2. Do pole **Host** zadej `192.168.0.20` a do pole **Port** `5000`.
3. Klikni na **Připojit**.
4. Napiš `Hello World` do pole pro zprávu a klikni na **Odeslat**. V okně chatu hned potom uvidíš echo serveru.
5. Klikni na **Odpojit**.
6. Přepni se do režimu :fa-magnifying-glass: **Trasování** a pomocí **+** otevři trace pro **Client-PC**, rozhraní `eth0`.

:::note
Oba ARP pakety na začátku už znáš z kapitoly 1. Ve sloupci **Info** u TCP paketů je nejprve `49152 → 5000` (z kterého portu na který), pak v hranatých závorkách **příznaky** (flags) a potom čísla jako `Seq=`, `Ack=` a `Len=`. Čísly se budeme zabývat od strany 5.2.3 — tady si všímáš příznaků a `Len`.
:::

## Fáze 1: Připojit

:::quiz short
Kolik TCP paketů bylo vyměněno poté, co jsi klikl(a) na **Připojit** — než byla odeslána tvoje zpráva?
= 3
= tři
:::

:::quiz mc
Kdo posílá první paket s `[SYN]`?
- [x] Client-PC
- [ ] Server
:::

:::quiz mc
Jakými příznaky na to server odpoví?
- [ ] `[SYN]`
- [x] `[SYN, ACK]`
- [ ] `[ACK]`
- [ ] `[FIN, ACK]`
:::

## Fáze 2: Odeslat

`Len` udává, kolik bajtů užitečných dat paket nese.

:::quiz short
Kolik bajtů nese paket s tvou zprávou (`Len`)?
= 13
:::

:::note
`Hello World` má jen 11 znaků. TCP klient ale připojí konec řádku (2 bajty, `\r\n`) — tak to očekávají mnohé internetové protokoly, například SMTP nebo HTTP.
:::

:::quiz mc
Co server pošle zpět hned po tvé zprávě — ještě před echem?
- [x] Paket s `[ACK]` a `Len=0` — potvrzení bez dat
- [ ] Vůbec nic
- [ ] Nový `[SYN]`
:::

## Kde se skrývají čtyři úkoly?

Přiřaď, kde v trace najdeš úkoly z oddílu 5.1:

:::quiz match
Navázání spojení -> Tři pakety [SYN], [SYN, ACK] a [ACK]
Spolehlivý přenos -> Pakety s [ACK] a Len=0, které potvrzují přijetí
Ukončení spojení -> Pakety s FIN a jejich potvrzení
Multiplexování -> Čísla portů 49152 → 5000 před hranatými závorkami
:::

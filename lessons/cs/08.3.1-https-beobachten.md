# Porovnání HTTP a HTTPS

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Webový server **www.beaver-schule.de** nabízí školní portál s hodnocením přes HTTP i přes HTTPS. Co vidí odposlouchávající útočník?

## Experiment

1. Přepni do :fa-play: režimu spuštění (**Spustit**) a na **Client-PC** v :fa-globe: **Prohlížeči** otevři nejprve `http://www.beaver-schule.de/`, potom `https://www.beaver-schule.de/`.
2. V :fa-magnifying-glass: režimu **Trasování** otevři trace pro **Client-PC**.
3. Najdi nejprve paket `HTTP/1.1 200 OK` a klikni na něj. Dole v detailech najdeš obsah stránky.

:::quiz mc
Co může odposlouchávající útočník vidět u **HTTP**?
- [x] Celou webovou stránku, včetně Aniných známek
- [ ] Jen adresu serveru
- [ ] Nic, protože HTTP běží přes TCP
:::

:::quiz short
Jakou známku má Anna z matematiky?
= 2
:::

:::evaluate
Zkontrolovat odpovědi
:::

Nyní část o HTTPS. Najdi paket `[SYN]`, kterým klient zahajuje druhé spojení.

:::quiz short
Jaký cílový port má spojení HTTPS (sloupec **Info**, `… → ???`)?
= 443
:::

Teď nahoře do pole filtru trasování zadej `tls` — uvidíš už jen pakety TLS.

:::quiz mc
Co je ve sloupci **Info** u paketů, které obsahují webovou stránku?
- [ ] `HTTP/1.1 200 OK`
- [x] `Application Data`
- [ ] `Encrypted HTML`
:::

:::quiz multi
Co může odposlouchávající útočník vidět i u **HTTPS**?
- [x] IP adresy klienta a serveru
- [x] Že se používá port 443, tedy pravděpodobně HTTPS
- [x] Přibližně kolik dat se přenáší
- [ ] Jaká stránka byla otevřena a co na ní je
:::

:::evaluate
Zkontrolovat odpovědi
:::

:::note
Klikni na paket **Application Data**: Užitečná data jsou jen posloupnost zdánlivě náhodných bajtů. Tracer je nedokáže dešifrovat — relační klíč zná stejně málo jako útočník.
:::

:::tip Zapamatuj si
U **HTTP** může každý odposlouchávající útočník přečíst celou webovou stránku. U **HTTPS** vidí už jen to, **kdo s kým** komunikuje (IP adresy, port 443) a **kolik** dat se přenáší — obsah je zašifrovaný v paketech **Application Data**.
:::

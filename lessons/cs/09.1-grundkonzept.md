# Paketový filtr: pravidla

Nejjednodušším a nejdůležitějším druhem firewallu je **paketový filtr**. Prohlíží si každý paket, který jím prochází, a podle **seznamu pravidel** rozhoduje, zda ho propustí. Čte přitom jen hlavičky vrstev 3 a 4 — obsah (např. webovou stránku) nezkoumá.

## Z čeho se pravidlo skládá

| Pole | Význam | Příklad |
|---|---|---|
| **Směr** | Z které strany paket přichází? | A → B (z internetu do školní sítě) |
| **Protokol** | TCP, UDP, ICMP nebo libovolný | TCP |
| **Zdrojová IP** | adresa nebo síť odesílatele | libovolná |
| **Zdrojový port** | port odesílatele | libovolný |
| **Cílová IP** | adresa nebo síť příjemce | `198.51.100.10` |
| **Cílový port** | port příjemce, tedy služba | `80` |
| **Akce** | Co se stane s odpovídajícími pakety? | Povolit |

Prázdné pole znamená „libovolný“. Sítě se zapisují v notaci CIDR, např. `198.51.100.0/24`, rozsahy portů s pomlčkou, např. `1024-65535`.

## Záleží na pořadí

Firewall kontroluje pravidla **shora dolů**. Rozhoduje **první pravidlo, které odpovídá** — všechna následující se pro tento paket už nezkoumají. Pokud neodpovídá žádné pravidlo, platí **výchozí politika** (*Default Policy*).

## Tři možné akce

| Akce | Co firewall dělá | Co si odesílatel všimne |
|---|---|---|
| **Povolit** (*Allow*) | paket se přepošle dál | — |
| **Zahodit** (*Drop*) | paket se bez komentáře zahodí | vůbec nic — čeká, dokud neuplyne časový limit |
| **Odmítnout** (*Reject*) | paket se zahodí, odesílatel dostane odmítnutí: u TCP **RST**, jinak ICMP „nedosažitelné“ | okamžitě chybovou zprávu |

Co je lepší? **Zahození** prozrazuje útočníkovi méně a stojí ho čas, protože musí čekat na každý pokus. **Odmítnutí** je přívětivější k vlastním uživatelům: program dostane okamžitě chybovou zprávu, místo aby dlouho visel. V praxi se proto pakety zvenčí většinou zahazují a pakety z vlastní sítě se odmítají.

:::quiz match
Povolit -> Paket se přepošle dál
Zahodit -> Paket zmizí, odesílatel marně čeká na odpověď
Odmítnout -> Paket se nepřepošle, ale odesílatel okamžitě dostane odmítnutí
Výchozí politika -> Platí, pokud neodpovídá žádné pravidlo
:::

:::tip Zapamatuj si
**Paketový filtr** kontroluje každý paket podle směru, protokolu, adres a portů proti **seznamu pravidel**. O akci rozhoduje **první odpovídající pravidlo**: **Povolit**, **Zahodit** (tiše) nebo **Odmítnout** (s odmítnutím). Pokud neodpovídá žádné pravidlo, platí **výchozí politika**.
:::

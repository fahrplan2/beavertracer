# HTTP ručně

:::sim
url=/sims/lesson-6.1.btsim
:::

Pokud je HTTP čistý text — dá se pak s webovým serverem mluvit i bez prohlížeče? Ano: pomocí `telnet` navážeš TCP spojení na libovolný port a text napíšeš sám.

## Experiment

1. Přepni do :fa-play: režimu **Spustit** a na **Client-PC** otevři :fa-terminal: **Terminál**.
2. Připoj se na port 80 serveru:
   ```
   $ telnet 192.168.0.20 80
   ```
3. Napiš požadavek řádek po řádku — a ukonči ho **prázdným řádkem** (stačí ještě jednou stisknout **Enter**):
   ```
   GET /kontakt.html HTTP/1.1
   Host: 192.168.0.20

   ```

Server odpoví stavovým řádkem, hlavičkami a stránkou s kontaktem — jako text, přesně tak, jak ji dostane i prohlížeč.

:::quiz mc
Podle čeho server pozná, že tvůj požadavek skončil?
- [ ] Podle zvláštního příkazu `END`
- [x] Podle prázdného řádku
- [ ] Po uplynutí určité doby
:::

:::quiz short
Jaká hodnota je v odpovědi v hlavičce `Content-Type`? (jen první část před `;`)
= text/html
:::

## Vyvolání chyb

Pohodlnější nástroj je `curl`: požadavek vytvoří za tebe. S přepínačem `-v` (*verbose*, podrobný výpis) zobrazí vše, co putuje tam a zpět — řádky se znakem `>` odeslal `curl`, řádky se znakem `<` přišly ze serveru.

Vyzkoušej si:

```
$ curl -v http://192.168.0.20/gibtsnicht.html
$ curl -X POST -d name=Anna http://192.168.0.20/
```

:::quiz short
Jaký stavový kód dostaneš pro `/gibtsnicht.html`?
= 404
:::

:::quiz short
A jaký pro požadavek s metodou `POST`?
= 405
:::

:::evaluate
Zkontrolovat odpovědi
:::

:::note
Webový server v BeaverTraceru umí pouze poskytovat soubory — proto povoluje jen `GET` a `HEAD`. Skutečné webové servery přijímají pomocí `POST` například formuláře a data předávají dál nějakému programu.
:::

:::tip Zapamatuj si
Mnoho protokolů aplikační vrstvy je **textových** — HTTP, ale také SMTP, POP3 a IMAP. Proto s nimi můžeš pomocí `telnet` komunikovat ručně a v Trasování je číst. To je praktické při hledání chyb — ale také bezpečnostní problém: Kdokoli, kdo provoz zachytává, může všechno přečíst. Jak pomáhá šifrování (HTTPS), se dozvíš v kapitole 8.
:::

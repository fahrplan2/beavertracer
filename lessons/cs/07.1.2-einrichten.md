# Nastavení domácího routeru

:::sim
url=/sims/lesson-7.1.2.btsim
:::

Nový domácí router byl právě připojen — ale zatím se nikdo nedostane na internet. Od poskytovatele jsi dostal dopis s **přístupovými údaji**:

| Přístupové údaje | Hodnota |
|---|---|
| WAN IP adresa | `203.0.113.2` |
| Délka prefixu | `/30` |
| Brána (router poskytovatele) | `203.0.113.1` |
| DNS server poskytovatele | `198.51.100.10` |

1. Přepni do režimu :fa-play: **Spustit**, klikni na **Heimrouter** a otevři kartu **WAN**.
2. Zadej přístupové údaje a klikni na **Aplikovat**.
3. Připoj **Tablet** k WiFi: :fa-gear: **Nastavení IP**, karta **WiFi**, SSID `Biberbau`, **Aplikovat**.
4. Otestuj na PC pomocí `ping 192.0.2.80` nebo v prohlížeči pomocí `http://www.beispiel.de/`.

:::note
V praxi získává domácí router svou WAN adresu většinou automaticky od poskytovatele (pomocí DHCP nebo přihlášením pomocí uživatelského jména a hesla). Pevné přístupové údaje jako zde jsou běžnější spíše u firemních připojení.
:::

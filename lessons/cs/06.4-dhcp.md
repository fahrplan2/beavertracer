# DHCP: automaticky do sítě

:::goal
**Cíl výuky:** Dokážeš vysvětlit, jak zařízení pomocí DHCP automaticky získá svá nastavení IP, nastavit DHCP server a rozpoznat a odstranit typické chyby DHCP (např. adresu 169.254).
:::

:::sim
url=/sims/lesson-6.4.btsim
:::

Dosud jsi každému zařízení ručně zadával IP adresu, masku sítě, bránu a DNS server. Ve škole se stovkami notebooků, tabletů a mobilů by to bylo nemožné – a každý překlep by znamenal chybu v síti.

Tuto práci převezme **Dynamic Host Configuration Protocol** (**DHCP**): **DHCP server** automaticky rozdá nastavení každému zařízení, které se připojí do sítě.

# Používání modelů

Přiřaď protokoly z experimentu ze začátku kapitoly k jejich vrstvě OSI:

:::quiz match
Ethernet -> Vrstva 2 — linková
IPv4 -> Vrstva 3 — síťová
TCP -> Vrstva 4 — transportní
HTTP -> Vrstva 7 — aplikační
:::

:::evaluate
Zkontrolovat přiřazení
:::

A nakonec názvy datových jednotek:

:::quiz match
Rámec -> Vrstva 2 — linková
Paket -> Vrstva 3 — síťová
Segment -> Vrstva 4 — transportní
:::

:::evaluate
Zkontrolovat přiřazení
:::

Tím získáváš nástroje, s nimiž budeš protokoly od teď správně zařazovat. Od další kapitoly projdeme vrstvy postupně, jednu po druhé — začneme vrstvou 2 a otázkou, jak vlastně switch ví, kam má paket přeposlat.

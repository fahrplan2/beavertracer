# Zobrazení certifikátu

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Na pracovní ploše vidíš **Client-PC**, **DNS-Server** a webový server školy `www.beaver-schule.de`. Webový server nabízí své stránky také přes **HTTPS**.

## Zámek v prohlížeči

1. Přepni do :fa-play: režimu spuštění, klikni na **Client-PC** a otevři :fa-globe: **Prohlížeč**.
2. Zadej adresu `https://www.beaver-schule.de/` — dávej pozor na **https**.
3. Vlevo vedle adresy se objeví **zámek**. Klikni na něj.

:::quiz short
Pro jaké jméno byl certifikát vydán (předmět bez `CN=`)?
= www.beaver-schule.de
:::

:::quiz short
Kdo certifikát vydal (vydavatel bez `CN=`)?
= Biber Root CA
:::

:::evaluate
Zkontrolovat odpovědi
:::

## Proč Client-PC certifikátu důvěřuje?

Na **Client-PC** otevři :fa-shield-halved: **Zertifikatverwaltung** a přepni se na kartu **Vertrauenswürdige CAs**.

:::quiz mc
Co tam najdeš?
- [x] Certifikát **Biber Root CA**
- [ ] Certifikát `www.beaver-schule.de`
- [ ] Žádné položky
:::

:::quiz mc
Podle čeho poznáš, že Biber Root CA je kořenová CA?
- [x] Je **自podepsaná**: předmět a vydavatel jsou stejné
- [ ] Její název končí na „CA“
- [ ] Nemá veřejný klíč
:::

:::quiz mc
Je u Client-PC pod **Privater Schlüssel** uvedeno „Ja“, nebo „Nein“?
- [ ] Ano — klient potřebuje soukromý klíč CA, aby mohl ověřovat podpisy
- [x] Ne — k ověření stačí veřejný klíč; soukromý klíč má pouze CA
:::

:::evaluate
Zkontrolovat odpovědi
:::

## Druhá strana: webový server

Nyní na webovém serveru **www.beaver-schule.de** otevři :fa-shield-halved: **Zertifikatverwaltung** (karta **Meine Zertifikate**) a prohlédni si jeho certifikát.

:::quiz multi
Co platí pro certifikát na webovém serveru?
- [x] Pod **Privater Schlüssel** je uvedeno „Ja“ — server ho potřebuje pro navázání spojení
- [x] **Řetězec** zní `www.beaver-schule.de ← Biber Root CA`
- [x] **Otisk** je stejný jako v okně zámku v prohlížeči
- [ ] Je samopodepsaný
:::

:::evaluate
Zkontrolovat odpovědi
:::

:::note
**Otisk** je hashová hodnota vypočtená z certifikátu. Pomocí ní lze rychle porovnat dva certifikáty — aniž bys musel kontrolovat všechna pole zvlášť.
:::

:::tip Zapamatuj si
**Webový server** má svůj certifikát **se soukromým klíčem**. **Klient** zná pouze **certifikát kořenové CA** (bez soukromého klíče) — to mu stačí k ověření podpisu na certifikátu serveru. Když v prohlížeči klikneš na **zámek**, uvidíš předmět, vydavatele, otisk a platnost.
:::

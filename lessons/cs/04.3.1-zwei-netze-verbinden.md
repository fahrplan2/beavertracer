# Propojení dvou sítí

:::sim
url=/sims/lesson-4.3.1.btsim
:::

Router má dvě připojení:

| Připojení | IP adresa | Síť |
|---|---|---|
| `eth0` | `192.168.0.1/24` | Firma A |
| `eth1` | `172.16.0.1/24` | Firma B |

Aby PC router používaly, je u každého z nich zadaná **brána** (Gateway): u Anny a Bena `192.168.0.1`, u Clary a Davida `172.16.0.1`. Najdeš ji v :fa-gear: **Nastavení IP** v poli **Gateway**.

:::tip Zapamatuj si
**Brána** (přesněji: *výchozí brána*, anglicky *default gateway*) je IP adresa routeru **ve vlastní síti**. Na bránu posílá PC všechny pakety, jejichž cíl leží v cizí síti.
:::

## Co router s paketem udělá

Router přijme rámec od Anny, vybalí z něj IP paket a podívá se na **cílovou IP adresu**. Podle ní pozná: Clara leží v síti na `eth1`. Paket tedy zabalí do **nového** rámce — se svou vlastní MAC adresou jako odesílatelem a MAC adresou Clary jako cílem — a odešle ho tam.

| Co se děje na routeru s … | |
|---|---|
| MAC adresami (vrstva 2)? | nastavují se **znovu** — platí jen v dané síti |
| IP adresami (vrstva 3)? | **zůstávají stejné** — od Anny až ke Claře |
| Time to Live? | **sníží se o 1** |

:::tip Zapamatuj si
**Router** pracuje na **vrstvě 3**: předává pakety do jiných sítí podle **cílové IP adresy**. IP adresy zůstávají po celé cestě stejné, MAC adresy se v každé síti nastavují znovu. Každý router sníží **Time to Live (TTL)** o 1 — když dosáhne 0, paket se zahodí. Díky tomu paket nemůže donekonečna kroužit dokola.
:::

:::note
Pamatuješ si na broadcastovou bouři z kapitoly 3.4? Ethernetové rámce nemají TTL — IP pakety ano.
:::

## Koho Anna zná? ARP cache

Pamatuješ si na kapitolu 1.2.3? ARP se tam objevilo jen před *prvním* pingem, protože si PC odpověď zapamatovalo. Tento seznam si PC pamatuje v tzv. **ARP cache** (také *ARP tabulka*). Dotaz se nazývá **ARP Request**, odpověď **ARP Reply** (nebo *ARP Response*).

Přepni se do :fa-play: režimu spuštění (**Spustit**), na **Anna** otevři :fa-terminal: **Terminál** a nech si zobrazit její ARP cache:

```
$ arp
```

:::quiz mc
Co je v ARP cache Anny?
- [x] Jen IP adresa routeru (`192.168.0.1`) s jeho MAC adresou
- [ ] IP adresa Clary s MAC adresou Clary
- [ ] Adresy routeru a Clary
:::

:::evaluate
Zkontrolovat odpověď
:::

Anna MAC adresu Clary nikdy nepotřebuje: vše, co je určeno pro firmu B, posílá routeru. MAC adresu Clary zná jen router — na své straně se na ni sám zeptal pomocí ARP.

:::tip Zapamatuj si
V **ARP cache** si zařízení pamatuje, která MAC adresa patří ke které IP adrese — díky tomu nemusí před každým paketem posílat ARP Request. Zobrazit ji lze příkazem `arp`. PC zná jen MAC adresy z **vlastní** sítě: pro všechny cíle v cizích sítích používá MAC adresu routeru.
:::

:::note
V reálných sítích se záznamy v ARP cache po nějaké době opět mažou a podle potřeby se zjišťují znovu — například když má zařízení mezitím jinou síťovou kartu. V BeaverTraceru zůstávají zachovány, dokud simulace běží.
:::

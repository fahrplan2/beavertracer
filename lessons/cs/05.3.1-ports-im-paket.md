## Experiment

1. Přepni se do režimu spuštění (:fa-play: **Spustit**), klikni na **Client-PC** a otevři :fa-globe: **Prohlížeč**. Načti `http://192.168.0.20/`.
2. Klikni nahoře v okně na **Zpět**, otevři **Jednoduchý TCP klient** a připoj ho (**Připojit**) k `192.168.0.20`, port `5000`. Nech spojení otevřené.
3. Přepni se do režimu :fa-magnifying-glass: **Trasování**, otevři trace pro **Client-PC** a klikni na paket s `[SYN]`. Rozbal **Transmission Control Protocol**.

Úplně nahoře v hlavičce TCP jsou dva porty: **Source Port** (zdrojový port) a **Destination Port** (cílový port).

:::quiz table
| Spojení | Zdrojový port | Cílový port |
|---|---|---|
| Prohlížeč → webový server | {49152} | {80} |
| TCP klient → echo služba | {49153} | {5000} |
:::

## Dva druhy portů

**Cílový port — služba:** Serverový program čeká na spojení na pevném portu — říká se, že tam **naslouchá**. Pro známé služby jsou čísla určena celosvětově, jde o tzv. **well-known porty** (0 až 1023). Prohlížeč proto bez ptaní ví: webové servery naslouchají na portu 80.

**Zdrojový port — odesílatel:** Port na straně klienta si operační systém pro každé nové spojení sám vybere z vysokého rozsahu (v BeaverTraceru od 49152). Podle něj klient pozná, ke kterému z jeho spojení odpověď patří.

Spojení je tedy jednoznačně určeno čtyřmi údaji: **IP adresou a portem na obou stranách**. Dvojice IP adresy a portu se nazývá **socket**, např. `192.168.0.20:80`.

## Pohled na server

Přepni se zpět do režimu spuštění (:fa-play: **Spustit**), na **Serveru** otevři :fa-terminal: **Terminál** a zadej:

```
$ ss
```

`ss` zobrazí všechny sockety počítače. Řádky s `LISTEN` jsou programy, které naslouchají na nějakém portu. Řádky s `ESTABLISHED` jsou existující spojení — s vlastním socketem (*Local Address:Port*) a socketem protější strany (*Peer Address:Port*).

:::quiz multi
Na kterých portech server naslouchá?
- [x] 80
- [x] 5000
- [ ] 49152
- [ ] 443
:::

:::quiz mc
Které spojení zobrazí `ss` jako `ESTABLISHED`?
- [x] `192.168.0.20:5000` s `192.168.0.10:49153` — otevřené spojení TCP klienta
- [ ] `192.168.0.20:80` s `192.168.0.10:49152` — spojení prohlížeče
- [ ] Obě
:::

Zkontrolovat odpovědi

:::note
Spojení prohlížeče je už zase ukončeno — po načtení stránky bylo ukončeno pomocí `FIN`. `ss` ho ještě krátce zobrazuje jako `TIME-WAIT`: Server chvíli čeká, zda ještě nedorazí opožděné pakety tohoto spojení. Spojení TCP klienta je naproti tomu stále otevřené, protože jsi ještě neklikl na **Odpojit**.
:::

## Nejdůležitější well-known porty

| Port | Protokol | Služba |
|---|---|---|
| 22 | SSH | zabezpečená vzdálená správa (šifrovaný příkazový řádek) |
| 25 | SMTP | odesílání e-mailů |
| 53 | DNS | překlad jmen na IP adresy (většinou přes UDP) |
| 80 | HTTP | webové stránky |
| 110 | POP3 | stahování e-mailů |
| 143 | IMAP | správa e-mailů na serveru |
| 443 | HTTPS | šifrované webové stránky |

:::tip Zapamatuj si
**Porty** (0 až 65535) rozlišují spojení na jednom počítači. Serverové služby **naslouchají** na pevných **well-known portech** (např. HTTP 80, HTTPS 443), klienti dostávají pro každé spojení volný vysoký **zdrojový port**. Spojení je jednoznačně určeno **IP adresou a portem obou stran**.
:::

:::quiz match
22 -> SSH
25 -> SMTP
53 -> DNS
80 -> HTTP
110 -> POP3
143 -> IMAP
443 -> HTTPS
:::

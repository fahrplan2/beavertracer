# Zadání statických tras

:::sim
url=/sims/lesson-4.5.2.btsim
:::

Tentokrát jsou mezi firmou A a firmou B **dva** routery. Jsou propojeny vlastní malou sítí, tzv. **přechodovou sítí** `10.0.0.0/30`:

| Router | Rozhraní | IP adresa | Síť |
|---|---|---|---|
| Router A | `eth0` | `192.168.0.1/24` | Firma A (Anna) |
| Router A | `eth1` | `10.0.0.1/30` | Přechodová síť |
| Router B | `eth0` | `10.0.0.2/30` | Přechodová síť |
| Router B | `eth1` | `172.16.0.1/24` | Firma B (Clara) |

:::note
Síť `/30` má přesně dvě použitelné adresy — ideální pro propojení dvou routerů (viz část 4.2.3).
:::

## Problém

Přepni se do :fa-play: **režimu spuštění** a pošli z **Anny** ping na Claru (`ping 172.16.0.10`). Clara neodpovídá — místo toho se ozve Router A (`192.168.0.1`) hlášením „Zielnetz nicht erreichbar“.

Podívej se na **Směrovací tabulku IPv4** u **Routeru A**.

:::quiz mc
Proč Annin ping nedorazí ke Claře?
- [ ] Anna nemá nastavenou bránu
- [x] Router A nezná síť `172.16.0.0/24` — není k němu přímo připojená a neexistuje žádná trasa, která by tam vedla
- [ ] Přechodová síť je příliš malá
:::

:::evaluate
Zkontrolovat odpověď
:::

## Zadání trasy

Router A se musí naučit: pakety pro `172.16.0.0/24` patří routeru B (`10.0.0.2`), a to přes `eth1`.

1. U **Routeru A** otevři kartu **Směrovací tabulka IPv4** a klikni na **+ hinzufügen**.
2. Do nového řádku zadej: **Ziel** `172.16.0.0`, **Netzmaske** `255.255.255.0`, **Další skok** `10.0.0.2`, **Iface** `eth1`.
3. Řádek ulož pomocí fajfky :fa-check:. Ve sloupci **Quelle** je nyní **Statické**.

Pošli znovu ping na Claru — teď už odpověď přijde.

:::note
Router B mimochodem cestu zpět do firmy A už zná: v jeho směrovací tabulce je již statická trasa pro `192.168.0.0/24` přes `10.0.0.1`. Proč je tato zpáteční cesta stejně důležitá, uvidíš na další stránce.
:::

## Sledování cesty: traceroute

Pomocí `traceroute` si můžeš zobrazit, přes které routery paket prochází. Zadej na **Anně**:

```
$ traceroute 172.16.0.10
```

:::quiz short
Přes kolik routerů prochází paket od Anny ke Claře?
= 2
= dva
:::

:::quiz mc
Jakou adresu zobrazí `traceroute` pro router B?
- [x] `10.0.0.2` — jeho adresu v přechodové síti, kterou paket přichází
- [ ] `172.16.0.1` — jeho adresu ve firmě B
- [ ] `192.168.0.1`
:::

:::evaluate
Zkontrolovat odpovědi
:::

`traceroute` využívá trik s **Time to Live** z části 4.3.1: Nejprve odešle paket s TTL 1. První router odečte 1, dostane se na 0, paket zahodí a oznámí to odesílateli — Anna tak zná první router. Poté následuje TTL 2 pro druhý router a tak dále, dokud neodpoví cíl.

:::tip Zapamatuj si
**Statickou trasu** zadává administrátor ručně: cílovou síť, masku sítě, další skok a rozhraní. Pomocí **traceroute** lze sledovat cestu paketu router po routeru.
:::

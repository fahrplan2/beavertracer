# Zobrazení webové stránky a její pozorování

V této části nic sám nestavíš: na pracovní ploše je připravená simulace s **Client-PC** a **Webserver**.

## Zobrazení stránky

1. Přepni do režimu :fa-play: **Spustit**.
2. Na **Client-PC** otevři aplikaci :fa-globe: **Prohlížeč** a zadej adresu webového serveru: `http://192.168.0.20/`.
3. Přepni do režimu :fa-magnifying-glass: **Trasování** a pomocí **+** otevři trace pro **Client-PC**, rozhraní `eth0` — úplně stejně jako u pingu.

:::note
Na jediné zobrazení stránky je to překvapivě mnoho paketů — výrazně více než u pingu. Načtení webové stránky je vícestupňový proces, ne jediná akce.
:::

## Čtení seznamu paketů

Zatím nemusíš přesně vědět, co jednotlivé protokoly dělají. Vše, co potřebuješ pro následující otázky, najdeš ve sloupcích **Protocol** a **Info**.

:::quiz mc
Který protokol je úplně nahoře v seznamu?
- [x] ARP
- [ ] TCP
- [ ] HTTP
:::

:::quiz short
Spočítej: Kolik paketů **TCP** je před prvním paketem **HTTP**?
= 3
= tři
:::

:::quiz mc
Co odpoví webový server na požadavek prohlížeče? Podívej se do sloupce Info u druhého paketu HTTP.
- [ ] GET / HTTP/1.1
- [x] HTTP/1.1 200 OK
- [ ] 404 Not Found
:::

:::evaluate
Zkontrolovat odpovědi
:::

## Pojmenování zúčastněných protokolů

Z tvých pozorování teď můžeš vyčíst, který protokol za co odpovídal.

:::tip Tip
Přečti si ještě jednou sloupce **Info**: `Who has …?`, `[SYN]`, `[SYN, ACK]`, `[ACK]`, `GET /` a `200 OK` už prozradí téměř všechno.
:::

:::quiz match
ARP -> Ptá se všech v síti: „Kdo má IP adresu 192.168.0.20?“
TCP -> Naváže spojení třemi krátkými pakety, než začnou proudit data
HTTP -> Vyžádá si webovou stránku (GET) a vrátí ji (200 OK)
:::

:::evaluate
Zkontrolovat přiřazení
:::

:::tip Zapamatuj si
Zobrazení webové stránky probíhá po stupních: nejprve server v síti **najít** (ARP), potom **navázat** spojení (TCP), potom stránku **vyžádat a doručit** (HTTP) — a nakonec spojení opět **ukončit** (pakety TCP s `[FIN]` na konci seznamu).
:::

:::note
Tentokrát jsi IP adresu serveru zadal přímo, proto se ještě nepoužil **DNS** („překlad“ jmen jako `www.beispiel.de` na IP adresu). To doženeme v kapitole 6.
:::

Všiml sis, že protokoly ve struktuře paketu mají barevné značky s čísly? Co to znamená, objasníme v kapitole 2. Tam se podíváme, jak se všechny ty protokoly systematicky zařazují — pomocí referenčních modelů OSI a TCP/IP. Tím je kapitola 1 hotová.

# Hledání chyb: Chybí stránka s kontakty

:::sim
url=/sims/lesson-6.1.3.btsim
:::

Sekretariát hlásí: „Na našem webu vede odkaz **Kontakt** už jen na chybové hlášení.“ Stránka s kontakty má být dostupná na adrese `http://192.168.0.20/kontakt.html`. Najdi chybu a oprav ji.

<details>
<summary>Nápověda 1: Co hlásí server?</summary>

Otevři stránku s kontakty v prohlížeči nebo pomocí `curl -v`. Jaký stavový kód se vrátí? Chybová stránka také prozradí, kde server soubor hledal.
</details>

<details>
<summary>Nápověda 2: Kde jsou soubory?</summary>

Webový server poskytuje jen soubory ze svého **kořene dokumentů** (*Document Root*) — ten najdeš v aplikaci **HTTP Server**. Na **Serveru** si v terminálu pomocí `ls` zobraz, co tam leží, a stránku s kontakty hledej také v `/home`.
</details>

<details>
<summary>Nápověda 3: Přesunutí souboru</summary>

Příkazem `mv` přesuneš soubor: `mv <zdroj> <cílová složka>`.
</details>

:::task
title: Je stránka s kontakty opravená?
Kontroluje, zda stránka s kontakty leží v kořeni dokumentů webového serveru.
check: fileExists(2, "/var/www/kontakt.html")
:::

## Co se stalo?

:::quiz multi
Která tvrzení jsou pravdivá?
- [x] Server odpověděl `404 Not Found`
- [x] Soubor ležel v `/home` místo v kořeni dokumentů `/var/www`
- [ ] Webový server vůbec nebyl spuštěný
- [ ] Prohlížeč použil špatnou IP adresu
:::

:::evaluate
Zkontrolovat odpověď
:::

:::tip Zapamatuj si
**404** znamená: Webový server běží a je dostupný, ale požadovaný **soubor** na této cestě neexistuje. Server hledá jen ve svém **kořeni dokumentů** (*Document Root*, zde `/var/www`). Porovnej: Pokud server neodpovídá vůbec nebo odpoví `RST`, je problém hlouběji — v síti nebo v samotné službě (kapitola 5.3.2).
:::

# HTTPS

:::osi 5
:::

**HTTPS** (*HTTP Secure*) je úplně normální HTTP — jen neběží přímo nad TCP, ale přes šifrovanou vrstvu mezi nimi: **TLS** (*Transport Layer Security*). Předchůdce TLS se jmenoval **SSL**; proto se stále často mluví o „SSL certifikátech“.

```
ohne Verschlüsselung:   HTTP  →  TCP  →  IP
mit Verschlüsselung:    HTTP  →  TLS  →  TCP  →  IP
```

HTTP si toho nevšimne: posílá své požadavky jako obvykle, TLS je zašifruje a TCP je přenese. V modelu OSI leží TLS mezi transportní a aplikační vrstvou, tedy ve vrstvě 4/5 — staví na TCP a spravuje zabezpečenou relaci.

| | HTTP | HTTPS |
|---|---|---|
| Port | 80 | **443** |
| Adresa | `http://…` | `https://…` |
| Obsah čitelný v Ttraceru? | ano | ne |
| Prohlížeč zobrazuje | „nezabezpečeno“ | zámek |

TLS při navázání spojení zajišťuje vše, co ses naučil(a) v této kapitole:

- Server se prokazuje svým **certifikátem** (**autentičnost**).
- Obě strany si pomocí **Diffie-Hellmana** dohodnou **klíč relace** — server svůj podíl **podepíše**.
- Poté jsou všechna data zašifrována pomocí **AES** (**důvěrnost**) a chráněna proti změně (**integrita**).

Princip se neomezuje jen na web: také e-mail (oddíl 8.4) a mnoho dalších protokolů běží přes TLS stejným způsobem.

## Co všechno je v domácím routeru

| Role v domácím routeru | Co dělá | znáš z |
|---|---|---|
| **Switch** | propojuje zařízení na portech LAN | kapitola 3.1 |
| **Přístupový bod** | připojuje mobily, tablety a notebooky do sítě přes Wi-Fi | kapitola 3.3 |
| **Router** | propojuje domácí síť se sítí poskytovatele — je to **gateway** | kapitola 4.3 |
| **DHCP Server** | rozděluje adresy, gateway a DNS servery | kapitola 6.4 |
| **DNS** | přeposílá dotazy na jména nebo uvádí DNS server poskytovatele | kapitola 6.2 |
| **NAT** | připojuje všechna zařízení k internetu přes **jednu** veřejnou adresu | nové — oddíl 7.2 |

Port **WAN** (*Wide Area Network*) vede k poskytovateli, porty **LAN** a Wi-Fi do domácí sítě. Mnoho domácích routerů navíc obsahuje **modem** — ten převádí data pro linku (DSL, kabel, optické vlákno). BeaverTracer to nesimuluje; port WAN je zde zapojený přímo do sítě poskytovatele.

:::quiz match
Switch -> Propojuje zařízení na portech LAN
Přístupový bod -> Připojuje tablety a mobily do sítě přes Wi-Fi
DHCP Server -> Rozděluje adresy zařízením v domácí síti
Router -> Propojuje domácí síť se sítí poskytovatele
:::

:::tip Zapamatuj si
**Domácí router** spojuje několik zařízení: **switch**, **Wi-Fi přístupový bod**, **router** (gateway do internetu), **DHCP Server** a **přeposílání DNS** — a k tomu **NAT**. Port **WAN** vede k poskytovateli, porty **LAN** a Wi-Fi do domácí sítě.
:::

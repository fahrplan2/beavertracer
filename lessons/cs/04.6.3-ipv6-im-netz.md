# IPv6 v síti

:::sim
url=/sims/lesson-4.6.3.btsim
:::

K switchi jsou připojeni Anna, Ben a router. U Anny a Bena je IPv6 nastaveno na **SLAAC (automaticky)** — žádnou IPv6 adresu jim nikdo nezadal. Router zná prefix `2001:db8:1::/64`.

## Odkud se adresa bere?

1. Přepni do :fa-play: režimu **Spustit** a počkej pár sekund.
2. Na **Anně** otevři :fa-terminal: **Terminál** a zadej `ip a`.

Kromě IPv4 adresy uvidíš dva řádky s `inet6`: jednu adresu s `scope link` a jednu s `scope global`.

:::quiz mc
Která z obou IPv6 adres je link-local adresa?
- [x] Ta, která začíná `fe80::` (`scope link`)
- [ ] Ta, která začíná `2001:db8:1:` (`scope global`)
:::

:::quiz mc
Odkud se bere prefix `2001:db8:1:0` globální adresy?
- [ ] Anna si ho sama vymyslela
- [x] Od routeru — ten prefix v síti oznamuje
- [ ] Od switche
:::

:::evaluate
Zkontrolovat odpovědi
:::

Porovnej **Interface ID** (poslední čtyři bloky) s **MAC adresou** Anny — najdeš ji v :fa-gear: **Nastavení IP** úplně dole. Z MAC adresy `aa:28:39:e2:41:82` se například stane Interface ID `a828:39ff:fee2:4182`: doprostřed se vloží `ff:fe` a jeden bit na začátku se otočí (proto se z `aa` stane `a8`).

Tento postup se nazývá **SLAAC** (*Stateless Address Autoconfiguration*): Router oznamuje prefix, Interface ID si každé zařízení vytvoří samo.

:::note
Protože MAC adresa zařízení jednoznačně identifikuje, dalo by se zařízení podle Interface ID znovu rozpoznat kdekoli na internetu. Skutečná zařízení proto obvykle navíc používají náhodná Interface ID, která se pravidelně mění (*Privacy Extensions*) — kousek ochrany soukromí.
:::

## Hledání sousedů — bez ARP

1. Na **Benovi** zadej `ip a` a zapamatuj si jeho **globální** IPv6 adresu.
2. Pošli na ni z **Anny** ping, například `ping 2001:db8:1:0:…` (s Benovou úplnou adresou).
3. Přepni do :fa-magnifying-glass: režimu **Trasování** a otevři trace pro **Annu**.

Podívej se na pakety přímo před prvním `Echo (ping) request`.

:::quiz multi
Která tvrzení jsou pravdivá?
- [x] Místo ARP dotazu posílá Anna **Neighbor Solicitation** („Kdo má tuto adresu?“)
- [x] Ben odpovídá **Neighbor Advertisement** a uvádí svou MAC adresu
- [x] Dotaz jde na multicastovou adresu (`ff02::1:ff…`), ne všem pomocí broadcastu
- [ ] Anna posílá ARP dotaz jako u IPv4
- [x] Router pravidelně rozesílá **Router Advertisements** na `ff02::1` — obsahují prefix
:::

:::evaluate
Zkontrolovat odpovědi
:::

:::tip Zapamatuj si
U IPv6 přebírá úlohy ARP protokol **NDP** (*Neighbor Discovery Protocol*, součást ICMPv6): Pomocí **Neighbor Solicitation** a **Neighbor Advertisement** zařízení zjišťují MAC adresy svých sousedů. Pomocí **Router Advertisements** router oznamuje prefix — z něj si zařízení pomocí **SLAAC** samy vytvoří svou adresu.
:::

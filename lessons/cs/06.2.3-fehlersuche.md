# Hledání chyb: Jméno nefunguje

:::sim
url=/sims/lesson-6.2.3.btsim
:::

Jedna učitelka hlásí: „`www.beaver-schule.de` se mi nenačítá. S `http://192.168.0.20` to ale funguje!“ Takto má být síť nastavená:

| Co | Správně |
|---|---|
| DNS server na Client-PC | `192.168.0.53` (DNS-Resolver) |
| Záznam v Schul-DNS | `www.beaver-schule.de` → `192.168.0.20` |

Najdi chyby a oprav je.

<details>
<summary>Nápověda 1: Co říká nslookup?</summary>

Na Client-PC zadej `nslookup www.beaver-schule.de`. Na jaký server se `nslookup` ptal — a co přišlo zpět? (Odpověď trvá několik sekund.)
</details>

<details>
<summary>Nápověda 2: A co dál?</summary>

Pokud dostaneš odpověď, porovnej adresu se schématem sítě. Kde je toto jméno zapsáno?
</details>

:::task
title: Je překlad jmen opravený?
Zkontroluje, zda Client-PC přeloží www.beaver-schule.de na správnou adresu. Simulace musí být přitom spuštěná v režimu spuštění.
check: resolves(2, "www.beaver-schule.de", "192.168.0.20")
:::

## Co se dělo?

:::quiz multi
Která tvrzení jsou pravdivá?
- [x] Na Client-PC byla jako DNS server nastavena adresa `192.168.0.35` — tam nikdo neodpovídá
- [x] V Schul-DNS ukazovalo `www.beaver-schule.de` na `192.168.0.21` místo na `192.168.0.20`
- [ ] Webový server byl vypnutý
- [ ] Kořenový server neznal doménu `.de`
:::

:::evaluate
Zkontrolovat odpověď
:::

:::tip Zapamatuj si
Pokud spojení funguje s **IP adresou**, ale ne s **jménem**, je problém v **DNS**. Nejdřív zkontroluj **nastavený DNS server** (odpovídá vůbec?), potom samotný **záznam** (souhlasí adresa?). `nslookup` ukáže obojí: na jaký server se ptal a co odpověděl.
:::

## Experiment

1. Přepni do režimu spuštění :fa-play: **Spustit**, klikni na **Client-PC** a otevři :fa-globe: **Prohlížeč**.
2. Tentokrát zadej `http://www.beaver-schule.de/` — se jménem místo IP adresy.
3. Přepni do :fa-magnifying-glass: **Trasování** a otevři trace pro **Client-PC**.

Úplně na začátku — ještě před navázáním spojení pomocí `[SYN]` — jsou dva pakety s protokolem **DNS**.

Teprve poté, co Client-PC zná IP adresu, nanaváže TCP spojení s webovým serverem — úplně stejně jako v kapitole 5.

## Odkud PC zná DNS server?

Otevři na **Client-PC** :fa-gear: **Nastavení IP**: V poli **DNS-Server** je `192.168.0.53` — počítač **DNS-Resolver**. Na něj PC posílá každý dotaz na jméno.

DNS server se můžeš zeptat i přímo, bez prohlížeče. Otevři :fa-terminal: **Terminál** a zadej:

```
$ nslookup www.beaver-schule.de
```

`nslookup` nejdřív zobrazí, kterého serveru se ptal, a potom odpověď. Pro srovnání se zeptej na jméno, které neexistuje, např. `nslookup gibtsnicht.beaver-schule.de`.

:::quiz mc
Co odpoví DNS server na neznámé jméno?
- [ ] Náhodnou IP adresu
- [x] `NXDOMAIN` — toto jméno neexistuje
- [ ] Vůbec nic
:::

:::evaluate
Zkontrolovat odpověď
:::

:::tip Zapamatuj si
**DNS** překládá jména (např. `www.beaver-schule.de`) na IP adresy. Než může PC navázat spojení se jménem, zeptá se **DNS serveru**, který je zapsaný v jeho nastavení IP — většinou přes **UDP, port 53**. Pomocí `nslookup` můžeš DNS dotazy zadávat ručně.
:::

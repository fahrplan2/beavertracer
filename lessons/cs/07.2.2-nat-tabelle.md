# Tabulka NAT

:::sim
url=/sims/lesson-7.1.btsim
:::

Když PC a tablet načítají současně stejnou webovou stránku, oba požadavky dorazí na webový server z adresy `203.0.113.2`. Jak domácí router pozná, komu je odpověď určena? Vede si evidenci — v **tabulce NAT**.

## Experiment

1. Přepni se do :fa-play: režimu spuštění a na **PC** i na **Tabletu** otevři `http://www.beispiel.de/`.
2. Klikni na **Heimrouter** a otevři kartu **NAT**.

Každý řádek je jedno **přiřazení**: protokol, LAN IP adresa a LAN port zařízení v domácí síti — a **WAN port**, který pro něj router používá na své veřejné adrese.

:::quiz short
Jaká WAN IP adresa je uvedena nad tabulkou?
= 203.0.113.2
:::

:::quiz mc
PC i tablet navázaly spojení s LAN portem `49152`. Jaký WAN port dostanou?
- [ ] Oba stejný, `49152`
- [x] Každý jiný — jinak by router nevěděl, komu odpověď patří
- [ ] Žádný, NAT mění jen IP adresu
:::

:::quiz mc
Odpověď webového serveru dorazí na `203.0.113.2` s určitým **cílovým portem**. Co s ní domácí router udělá?
- [x] Vyhledá port v tabulce NAT a odešle paket na příslušnou LAN IP adresu a LAN port
- [ ] Odešle paket všem zařízením v domácí síti
- [ ] Paket zahodí
:::

:::evaluate
Zkontrolovat odpovědi
:::

Tady se znovu uplatní **porty** z kapitoly 5: protože NAT přepisuje také porty, mohou si stovky spojení sdílet jednu adresu. Přesně vzato se proto tomu říká **PAT** (*Port Address Translation*) neboli *NAT s překladem portů* — v běžné řeči se ale přesto říká prostě NAT.

Takový překlad může vypadat například takto:

| | Paket z PC (v domácí síti) | stejný paket v internetu |
|---|---|---|
| Odesílatel | `192.168.178.20 : 49152` | `203.0.113.2 : 10001` |
| Příjemce | `192.0.2.80 : 80` | `192.0.2.80 : 80` |

:::tip Zapamatuj si
V **tabulce NAT** si router pro každé spojení pamatuje, které zařízení (**LAN IP adresa a LAN port**) se skrývá za kterým **WAN portem**. Odpovědi z internetu pak podle cílového portu přiřadí zpět správnému zařízení. Protože se přepisují i porty, přesněji se mluví o **PAT**.
:::

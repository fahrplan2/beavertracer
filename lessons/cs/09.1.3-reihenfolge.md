# Pořadí pravidel a základní přístup

## Nejdřív výjimka, potom pravidlo

Protože vyhrává **první odpovídající pravidlo**, záleží na pořadí. Prohlédni si tento seznam pravidel (všechna pravidla platí pro směr A → B, výchozí politika: Povolit vše):

| Č. | Protokol | Cílový port | Akce |
|---|---|---|---|
| 1 | TCP | libovolný | Zahodit |
| 2 | TCP | 80 | Povolit |

:::quiz mc
Z internetu dorazí paket na TCP port 80. Co se stane?
- [ ] Bude povolen, protože pravidlo 2 povoluje právě port 80
- [x] Bude zahozen, protože už pravidlo 1 odpovídá — k pravidlu 2 se nikdy nedojde
- [ ] Firewall se zeptá administrátora
:::

:::evaluate
Zkontrolovat odpověď
:::

Obecně platí: **Speciální pravidla nahoru, obecná dolů.** Pravidlo, které pokrývá hodně, „zastíní“ všechna pravidla pod sebou. Sloupec **Shody** prozradí taková mrtvá pravidla: zůstávají na 0.

## Blacklist, nebo whitelist?

V části 9.1.2 jsi jednotlivé porty **zakázal/a** a všechno ostatní povolil/a. Tomu se říká **blacklist** („černá listina“). Opakem je **whitelist**: **povolíš** jen to nezbytné a všechno ostatní zakážeš — závěrečným pravidlem „zahodit vše“ nebo výchozí politikou **Zahodit vše**.

| | Blacklist | Whitelist |
|---|---|---|
| Základní přístup | všechno povoleno, výjimky zakázány | všechno zakázáno, výjimky povoleny |
| Výchozí politika | Povolit | Zahodit |
| nová služba na serveru | je ihned dostupná zvenčí | zůstává blokovaná, dokud ji někdo nepovolí |

:::quiz mc
Učitel zítra nainstaluje na školní server databázi, která naslouchá na portu 3306. Co se stane s firewallem z části 9.1.2 (blacklist)?
- [x] Databáze je okamžitě dostupná z internetu
- [ ] Databáze je automaticky blokována
- [ ] Firewall novou službu ohlásí
:::

:::evaluate
Zkontrolovat odpověď
:::

Proto dobré firewally pracují podle **principu whitelistu** („Default Deny“): Všechno, co není výslovně povoleno, je zakázáno. Whitelist pro školní server by vypadal takto:

:::quiz table
| Č. | Směr | Protokol | Cílový port | Akce |
|---|---|---|---|---|
| 1 | A → B | TCP | {80} | {Povolit} |
| 2 | A → B | TCP | {25} | Povolit |
| 3 | A → B | libovolný | libovolný | {Zahodit} |
:::

:::evaluate
Zkontrolovat tabulku
:::

- [x] Z internetu neprojde vůbec nic, ani web a e-mail
- [ ] Projde jen web a e-mail
:::

:::

:::tip Zapamatuj si
Protože vyhrává **první odpovídající pravidlo**, patří **speciální pravidla nahoru** a obecná dolů. Bezpečnější než **blacklist** (všechno povoleno kromě …) je **whitelist** (všechno zakázáno kromě …, *Default Deny*): Zapomenuté nebo nové služby pak zůstanou automaticky blokované.
:::

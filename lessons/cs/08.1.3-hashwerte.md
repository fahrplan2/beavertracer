# Hashe: otisk prstu dat

:::sim
url=/sims/lesson-8.1.3.btsim
:::

**Hashovací funkce** vypočítá z libovolně velkého množství dat — z věty, dokumentu i celého filmu — krátký řetězec znaků pevné délky: **hash**. Funguje jako **otisk prstu**: stejná data dají vždy stejný hash, jiná data dají jiný.

Dnes běžně používaná hashovací funkce se jmenuje **SHA-256**. Její hash je vždy dlouhý 256 bitů, jako hexadecimální číslo tedy 64 znaků.

## Experiment

Na **PC** jsou ve složce `/home` tři soubory s malou kupní smlouvou. Přepni se do :fa-play: režimu **Spustit**, otevři na **PC** :fa-terminal: **Terminál** a zadej:

```
$ cd /home
$ cat vertrag.txt vertrag-kopie.txt vertrag-neu.txt
$ sha256sum vertrag.txt vertrag-kopie.txt vertrag-neu.txt
```

## Vlastnosti hashovací funkce

| Vlastnost | Význam |
|---|---|
| **pevná délka** | Bez ohledu na velikost dat má hash vždy stejnou délku. |
| **jednoznačnost** | Stejná data dají vždy stejný hash. |
| **lavinový efekt** | I sebemenší změna dá úplně jiný hash. |
| **jednosměrná funkce** | Z hashe **nelze** data zpětně vypočítat. |
| **odolnost proti kolizím** | Je prakticky nemožné najít dva různé soubory se stejným hashem. |

Hashovací funkce **není šifrování**: neexistuje žádný klíč ani dešifrování. Slouží jinému účelu — **integritě**.

## K čemu se to používá?

- **Kontrola stažených souborů:** Mnoho webových stránek uvádí vedle souboru i jeho hodnotu SHA-256. Pokud hash tvého staženého souboru s touto hodnotou souhlasí, nebyl soubor cestou změněn.
- **Ukládání hesel:** Dobré webové stránky neukládají tvé heslo, ale jen jeho hash. Při přihlášení se porovnává hash toho, co zadáš. Pokud někdo databázi ukradne, hesla přesto nezná.
- **Digitální podpisy:** Místo celého dokumentu se podepisuje jen jeho hash — více v další části.

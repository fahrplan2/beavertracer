# HTTP: web pages

:::goal
**Learning goal:** You can describe the structure of an HTTP request and response, explain important methods and status codes, and make an HTTP request yourself by hand.
:::

The **Hypertext Transfer Protocol** (**HTTP**) is the language in which browsers and web servers talk to each other. The website of the **Beaver-Schule** (Beaver School) is on the server: a home page, a contact page and a stylesheet for the look.

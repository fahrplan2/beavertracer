Now it's your turn. The firewall still lets everything through. Make sure that from the internet only the school server's **website (80)** and **mail reception (25)** can be reached. **SSH (22)**, **POP3 (110)** and **IMAP (143)** should no longer be reachable from the internet.

## Entering rules

1. Click the **Firewall**. Leave the default policy at **Allow all** for now.
2. Delete the existing rule (it allows everything anyway) and use **+ Add rule** to create a rule for each port that should be closed:
    - **Direction** A → B (from the internet)
    - **Protocol** TCP
    - **Dst Port** e.g. `22`
    - **Action** Drop
3. From the **Internet-PC**, check with `nmap 198.51.100.10` that only the right ports are still open.

:::note
A firewall only protects traffic that flows **through it**. It doesn't see what happens inside the school network. An infected computer in the school network can therefore still attack the school server — that's what the DMZ section is about.
:::

:::tip Key point
For each service that should not be reachable from outside, a rule with **direction**, **protocol** and **destination port** blocks access. Whether the rules work is checked from outside with a **port scan**.
:::

# NAT: many devices, one address

:::goal
**Learning goal:** You can show in the tracer how NAT replaces the source address, read the NAT table and explain why connections from outside into the home network need a port forward.
:::

:::sim
url=/sims/lesson-7.1.btsim
:::

A provider normally gives a home connection only **one** public IPv4 address — the home router's WAN address. All devices in the home network have to share it. How this works is called **NAT** (*Network Address Translation*).

# DNS: names instead of numbers

:::goal
**Learning goal:** You can explain how DNS translates names into IP addresses and how names are organised hierarchically, create an entry yourself and find typical DNS faults.
:::

:::sim
url=/sims/lesson-6.2.btsim
:::

Hardly anyone can remember IP addresses — but names like `www.beaver-schule.de` they can. The translation is done by the **Domain Name System** (**DNS**), a kind of worldwide phone book of the internet.

On the workspace there's now a somewhat larger network: besides the **Client-PC** and the **Webserver** there are four **DNS servers**. What so many are for you'll see on the page after next.

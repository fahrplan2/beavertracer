# The NAT table

:::sim
url=/sims/lesson-7.1.btsim
:::

When the PC and the tablet load the same web page at the same time, both requests reach the web server from `203.0.113.2`. How does the home router know who a reply is meant for? It keeps records — in the **NAT table**.

## The experiment

1. Switch to :fa-play: **Run** mode and load `http://www.beispiel.de/` on the **PC** and on the **Tablet**.
2. Click the **Heimrouter** and open the **NAT** tab.

Every row is a **mapping**: protocol, LAN IP and LAN port of the device in the home network — and the **WAN port** the router uses for it on its public address.

:::quiz short
Which WAN IP is shown above the table?
= 203.0.113.2
:::

:::quiz mc
The PC and the tablet have both set up a connection with LAN port `49152`. Which WAN port do they get?

- [x] Each a different one — otherwise the router wouldn't know who the reply belongs to
- [ ] None at all, NAT only changes the IP address
:::

:::quiz mc

- [x] It looks up the port in the NAT table and sends the packet to the matching LAN IP and LAN port
- [ ] It sends the packet to all devices in the home network
- [ ] It discards the packet
:::

This is where the **ports** from chapter 5 come back into play: because NAT also rewrites the ports, hundreds of connections can share one address. Strictly speaking this is therefore called **PAT** (*Port Address Translation*) or *NAT with port translation* — in everyday speech people still just say NAT.

This is what such a translation could look like, for example:

| | Packet from the PC (in the home network) | the same packet on the internet |
|---|---|---|
| Sender | `192.168.178.20 : 49152` | `203.0.113.2 : 10001` |
| Receiver | `192.0.2.80 : 80` | `192.0.2.80 : 80` |

:::tip Key point
In the **NAT table** the router remembers for every connection which device (**LAN IP and LAN port**) is behind which **WAN port**. It matches replies from the internet back to the right device via the destination port. Because ports are rewritten too, it's more precisely called **PAT**.
:::

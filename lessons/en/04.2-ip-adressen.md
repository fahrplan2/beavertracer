# IP addresses and netmask

:::goal
**Learning goal:** You can convert numbers between the decimal and the binary system, determine the network and host part of an IP address with the netmask, and calculate the network address, the broadcast address and the number of hosts of a network.
:::

:::sim
empty
:::

A PC doesn't decide whether an address is in its own network using decimal numbers like `192.168.0.10`, but bit by bit. To follow that, you need the **binary system** — that's where this section starts.

## Everything inside the home router

| Role in the home router | What it does | you know it from |
|---|---|---|
| **Switch** | connects the devices on the LAN sockets | chapter 3.1 |
| **Access point** | brings phones, tablets and laptops into the network via Wi-Fi | chapter 3.3 |
| **Router** | connects the home network with the provider's network — it is the **gateway** | chapter 4.3 |
| **DHCP server** | hands out addresses, gateway and DNS server | chapter 6.4 |
| **DNS** | forwards name requests or names the provider's DNS server | chapter 6.2 |
| **NAT** | brings all devices onto the internet via **one** public address | new — section 7.2 |

The **WAN** port (*Wide Area Network*) leads to the provider, the **LAN** ports and the Wi-Fi into the home network. Many home routers also contain a **modem** — it translates the data for the line (DSL, cable, fibre). BeaverTracer doesn't simulate that; here the WAN port sits directly in the provider's network.

:::

:::tip Key point
A **home router** combines several devices: **switch**, **Wi-Fi access point**, **router** (gateway to the internet), **DHCP server** and **DNS forwarding** — plus **NAT**. The **WAN** port leads to the provider, the **LAN** ports and the Wi-Fi into the home network.
:::

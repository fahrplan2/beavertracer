# Applying the models

Match the protocols from the experiment at the start of the chapter to their OSI layer:

:::quiz match
Ethernet -> Layer 2 — Data Link
IPv4 -> Layer 3 — Network
TCP -> Layer 4 — Transport
HTTP -> Layer 7 — Application
:::

:::evaluate
Check matches
:::

And finally the names of the data units:

:::quiz match
Frame -> Layer 2 — Data Link
Packet -> Layer 3 — Network
Segment -> Layer 4 — Transport
:::

:::evaluate
Check matches
:::

Now you have the tools to sort protocols properly from here on. From the next chapter on we go through the layers one by one — starting with layer 2 and the question of how a switch actually knows where to forward a packet.

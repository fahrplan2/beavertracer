# The switch

:::goal
**Learning goal:** You can connect several PCs via a switch and explain how the switch knows which port to send a frame to.
:::

A PC usually has only one network port. So to connect three, ten or a hundred devices, you need a distributor with many ports: the **switch**.

On the next pages you first connect PCs to a switch yourself, then watch which packets arrive where — and finally look for faults in a network that doesn't work the way it should.

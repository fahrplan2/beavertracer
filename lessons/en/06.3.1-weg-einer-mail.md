## The experiment

1. Switch to :fa-play: **Run** mode, click **Anna** and open the **Mail** app.
2. Switch to the **Compose** tab. Enter `ben@biber-mail.de` under **To**, add a subject and a short text and click **Send**.
3. Wait a few seconds — the mail first has to get from mail server to mail server. Then click **Ben**, open the **Mail** app and click **Fetch**. Anna's mail is there.
4. In :fa-magnifying-glass: **Trace** mode, open a trace for the **Mailserver Schule**.

## What's behind it

An e-mail travels in several stages — similar to a letter via two post offices:

1. Anna's mail program hands the mail to Anna's mail server with **SMTP**.
2. The Mailserver Schule sees: the recipient belongs to a **foreign domain**. Via **DNS** it asks for the **MX entry** (*mail exchanger*) of `biber-mail.de` and gets `mail.biber-mail.de` — then also its IP address.
3. It delivers the mail to the Mailserver Biber with **SMTP**. There it lands in Ben's mailbox.
4. Ben collects it from his mail server with **IMAP** (or **POP3**).

:::seq
mode: text
Mailserver Schule -> Mailserver Biber: SMTP: MAIL FROM | anna@beaver-schule.de
Mailserver Biber -> Mailserver Schule: 250 OK
Mailserver Schule -> Mailserver Biber: SMTP: RCPT TO | ben@biber-mail.de
Mailserver Biber -> Mailserver Schule: 250 OK
Mailserver Schule -> Mailserver Biber: SMTP: DATA | the mail itself
Mailserver Biber -> Mailserver Schule: 250 OK queued
:::

:::tip Key point
**SMTP** (port 25) **sends** e-mails: from the mail program to your own mail server and from there to the recipient's mail server. Which mail server is responsible for a domain is in the **MX entry** in the DNS. **POP3** (port 110) and **IMAP** (port 143) are only for **collecting** from your own mailbox.
:::

# Troubleshooting: no network for the laptops

:::sim
url=/sims/lesson-6.4.3.btsim
:::

After the holidays, the teachers report: "Our laptops can't get into the network any more!" Both laptops are set to **DHCP**. According to the plan, the DHCP server is supposed to hand out addresses from `192.168.0.100` to `192.168.0.120`, with gateway `192.168.0.1` and DNS server `192.168.0.53`.

Find the faults and fix them.

<details>
<summary>Tip 1: Which address do the laptops have?</summary>

Look at the :fa-gear: **IP Settings** of a laptop. An address starting with `169.254` was given to the device **by itself** — because no DHCP server answered.
</details>

<details>
<summary>Tip 2: Does the DHCP server answer?</summary>

Open a trace for a laptop. Do you only see `DHCP Discover` — or an answer too? Then look at the **DHCP Server** app: is it running? And which range does it hand out?
</details>

<details>
<summary>Tip 3: Getting a new address</summary>

If you changed something on the server, briefly set the laptop's mode in the IP settings to **Static** and back to **DHCP** and click **Apply** — then it asks again.
</details>

:::task
title: Laptops back in the network?
Checks whether both laptops have an address from the planned range and can reach the DHCP server. The simulation has to be running in Run mode for this.
check: ip(3, "192.168.0.96/27")
check: ip(4, "192.168.0.96/27")
check: pingOk(3, 2)
check: pingOk(4, 2)
:::

## What was going on?

:::quiz multi
Which statements are true?
- [x] The DHCP server wasn't started — the laptops gave themselves a `169.254` address
- [x] The address range was in the wrong network (`192.168.1.…` instead of `192.168.0.…`)
- [ ] The laptops were set to fixed addresses
- [ ] The gateway was missing on the switch
:::

:::evaluate
Check answer
:::

:::tip Key point
If a device has an address from **`169.254.0.0/16`**, it got **no answer from a DHCP server** and gave itself an address (**APIPA**). With it, it only reaches other devices in the same situation. Then check: is the DHCP server running? Can it be reached? And does it hand out addresses from the **right network**?
:::

# The interface

A quick tour before we get started:

- **Toolbar at the top** — this is where you switch modes, control the simulation speed, and find project functions like saving.
- **Toolbox on the left** — only visible in edit mode. Here you choose which device to place next (PC, switch, router, …) or whether you want to draw cables.
- **Canvas in the middle** — your actual network. You can zoom in and pan by holding the spacebar or using the middle mouse button.

:::tip
That's all you need to know for now — you'll learn the rest best by trying it out yourself right away.
:::

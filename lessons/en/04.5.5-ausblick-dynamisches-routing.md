# Outlook: dynamic routing

In the project you entered twelve routes by hand for four sites. A large company network has hundreds of routers, the internet tens of thousands — and somewhere a line is constantly failing or a new one is being added. That can no longer be managed by hand.

That's why routers usually exchange their routes with each other automatically. There are **routing protocols** for this. This is called **dynamic routing** — as opposed to **static routing**, where everything is entered by hand.

The best-known routing protocols:

| Protocol | Idea | typical use |
|---|---|---|
| **RIP** (*Routing Information Protocol*) | Every router regularly tells its neighbours which networks it can reach, and how many routers (*hops*) away. | small networks, textbook example |
| **OSPF** (*Open Shortest Path First*) | Every router knows the complete map of the network and calculates the shortest path from it itself. | company networks |
| **BGP** (*Border Gateway Protocol*) | Large network operators (e.g. internet providers) tell each other which networks they can reach. | the internet between the providers |

:::quiz match
RIP -> Routers tell their neighbours how many hops away they can reach a network
OSPF -> Every router knows the whole network map and calculates the shortest path
BGP -> Connects the networks of the large internet providers
:::

:::evaluate
Check matches
:::

:::tip Key point
With **static routing**, an administrator enters all routes by hand. With **dynamic routing**, routers exchange their routes automatically with the help of **routing protocols** like RIP, OSPF or BGP — and adapt by themselves when a connection fails.
:::

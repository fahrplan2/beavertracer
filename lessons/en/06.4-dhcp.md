# DHCP: into the network automatically

:::goal
**Learning goal:** You can explain how a device gets its IP settings automatically via DHCP, set up a DHCP server and recognise and fix typical DHCP faults (e.g. a 169.254 address).
:::

:::sim
url=/sims/lesson-6.4.btsim
:::

So far you entered every device's IP address, netmask, gateway and DNS server by hand. At a school with hundreds of laptops, tablets and phones that would be impossible — and every typo a fault in the network.

This work is done by the **Dynamic Host Configuration Protocol** (**DHCP**): a **DHCP server** hands out the settings automatically to every device that joins the network.

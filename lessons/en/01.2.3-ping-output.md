# Running ping and reading the output

Switch to :fa-play: **Run** mode. Open the :fa-terminal: terminal on one of the PCs and type:

```
$ ping 192.168.0.11
```

(of course using the IP address of your *second* PC).

If the other PC responds, you'll see a line with a response time for each packet sent — your first successful ping!

:::warning
No response? Check whether both PCs are really connected and on the same network (see the previous page).
:::

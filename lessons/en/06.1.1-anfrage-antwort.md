So a web page often consists of many files: text, stylesheets, images. The browser sends a request of its own for each one.

## What a request looks like

Click the packet `GET / HTTP/1.1` in the trace and expand **Hypertext Transfer Protocol**. An HTTP request is pure text:

```
GET / HTTP/1.1              ← method, path, version
Host: 192.168.0.20          ← header: additional details
…
                            ← empty line: end of the request
```

The server's response is built the same way — with a status line, headers, an empty line and then the actual file:

```
HTTP/1.1 200 OK             ← version, status code, text
Content-Type: text/html     ← header: type of file
Content-Length: 301         ← header: size in bytes
                            ← empty line
<!doctype html> …           ← the file itself
```

:::seq
mode: text
Client-PC -> Server: GET / | HTTP request
Server -> Client-PC: 200 OK | index.html
Client-PC -> Server: GET /style.css | HTTP request
Server -> Client-PC: 200 OK | style.css
:::

## Methods and status codes

The **method** says what the client wants:

| Method | Meaning |
|---|---|
| **GET** | fetch a file |
| **POST** | send data to the server, e.g. a filled-in form |
| **HEAD** | fetch only the headers, without the file |

The **status code** says how it went. The first digit tells you the kind of response:

| Code | Text | Meaning |
|---|---|---|
| **200** | OK | everything fine |
| **301** | Moved Permanently | the page has moved permanently |
| **404** | Not Found | the file doesn't exist |
| **405** | Method Not Allowed | this method isn't allowed here |
| **500** | Internal Server Error | error on the server |

`2xx` means success, `3xx` redirection, `4xx` an error of the client (wrong request), `5xx` an error of the server.

:::tip Key point
**HTTP** works on the **request–response principle**: the client sends a **request** (a method like `GET`, path, headers), the server answers with a **status code** (e.g. `200 OK`, `404 Not Found`), headers and the file. Every file of a web page gets a request of its own.
:::

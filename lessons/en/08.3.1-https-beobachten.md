# HTTP and HTTPS Compared

:::sim
url=/sims/lesson-8.2.1.btsim
:::

The web server **www.beaver-schule.de** offers the school's grade portal over both HTTP and HTTPS. What does an eavesdropper see?

## The experiment

1. Switch to :fa-play: **Run** mode and, on the **Client-PC**, first load `http://www.beaver-schule.de/` in the :fa-globe: **Browser**, then `https://www.beaver-schule.de/`.
2. In :fa-magnifying-glass: **Trace** mode, open a trace for the **Client-PC**.
3. First find the packet `HTTP/1.1 200 OK` and click it. The page content is shown in the details below.

:::quiz mc
What can an eavesdropper see with **HTTP**?
- [x] The complete web page, including Anna's grades
- [ ] Only the server's address
- [ ] Nothing, because HTTP runs over TCP
:::

:::quiz short
Which grade does Anna have in maths (*Mathematik*)?
= 2
:::

:::evaluate
Check answers
:::

Now the HTTPS part. Find the `[SYN]` packet with which the client starts the second connection.

:::quiz short
Which destination port does the HTTPS connection use (column **Info**, `… → ???`)?
= 443
:::

Now enter `tls` in the trace's filter field at the top — then you only see the TLS packets.

:::quiz mc
What does the **Info** column say for the packets that contain the web page?
- [ ] `HTTP/1.1 200 OK`
- [x] `Application Data`
- [ ] `Encrypted HTML`
:::

:::quiz multi
What can an eavesdropper still see with **HTTPS**?
- [x] The IP addresses of client and server
- [x] That port 443 is used, so probably HTTPS
- [x] Roughly how much data is transferred
- [ ] Which page was requested and what's on it
:::

:::evaluate
Check answers
:::

:::note
Click an **Application Data** packet: the payload is just a sequence of seemingly random bytes. The tracer can't decrypt it — it doesn't know the session key any more than an attacker does.
:::

:::tip Key point
With **HTTP**, any eavesdropper can read the complete web page. With **HTTPS** they only see **who talks to whom** (IP addresses, port 443) and **how much** — the content is encrypted inside **Application Data** packets.
:::

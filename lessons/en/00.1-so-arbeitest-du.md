# How to work with the course

This course takes place right inside BeaverTracer: on the left you build and observe networks, on the right in the **lessons panel** you read the instructions.

## Turning pages

With **Back** and **Next** you go through the course page by page. With **Overview** (or :fa-list: at the top of the lessons panel) you can jump to any chapter.

## The right simulation for every page

Every time you change pages, BeaverTracer automatically loads the simulation that belongs to that page — so you always start from a working state.

:::warning
Whatever you build or change on one page is gone on the next page. That is on purpose: every page starts from a clean initial state.
:::

- With :fa-rotate-left: at the top of the lessons panel you reset the simulation to the start of the current page — handy if you got lost.
- If you want to keep building on a simulation yourself, click :fa-file-import: **Adopt** in the toolbar. The lessons panel closes and the simulation is yours.

## Saving and loading

A simulation is a single file (`.btsim`) that describes your complete network — all devices, cables and their settings. While the lessons panel is open, the buttons :fa-file: **New**, :fa-file-arrow-up: **Load** and :fa-file-arrow-down: **Save** are hidden. After **Adopt** (or when you close the lessons panel with **×**) you find them in the toolbar under "Project" — in Edit mode.

## Boxes, quizzes and tasks

:::goal
**Learning goal** — at the start of a section: this is what you can do afterwards.
:::

:::tip Key point
Briefly sums up an important technical term or relationship — good for revising for exams.
:::

- You answer **quiz questions** right on the page and check them with the button below. You can read almost every answer off your screen if you look closely.
- **Tasks** with the **Check task** button look into your simulation to see whether everything is set up correctly — e.g. whether two PCs can reach each other.

## The experiment

1. Switch to :fa-play: **Run** mode, click the **Client-PC** and open the :fa-globe: **Browser**.
2. This time load `http://www.beaver-schule.de/` — with a name instead of an IP address.
3. Switch to :fa-magnifying-glass: **Trace** mode and open a trace for the **Client-PC**.

Right at the start — even before the connection setup with `[SYN]` — there are two packets with the protocol **DNS**.

:::quiz short
To which IP address does the Client-PC send its DNS request?
= 192.168.0.53
:::

:::quiz short
Which IP address is in the answer for `www.beaver-schule.de`?
= 192.168.0.20
:::

:::quiz mc
Click the DNS request and expand the protocol tree. Which transport protocol and which destination port are used?
- [ ] TCP, port 80
- [x] UDP, port 53
- [ ] UDP, port 67
:::

:::evaluate
Check answers
:::

Only after the Client-PC knows the IP address does it set up the TCP connection to the web server — just like in chapter 5.

:::seq
mode: text
Client-PC -> DNS-Resolver: DNS request | A www.beaver-schule.de?
DNS-Resolver -> Client-PC: DNS answer | A 192.168.0.20
:::

## How does the PC know the DNS server?

Open the :fa-gear: **IP Settings** on the **Client-PC**: the **DNS server** field contains `192.168.0.53` — the computer **DNS-Resolver**. The PC sends every name request to it.

You can also ask the DNS server directly, without a browser. Open the :fa-terminal: **Terminal** and enter:

```
$ nslookup www.beaver-schule.de
```

`nslookup` first shows which server it asked, then the answer. For comparison, ask for a name that doesn't exist, e.g. `nslookup gibtsnicht.beaver-schule.de`.

:::quiz mc
What does the DNS server answer for the unknown name?
- [ ] A random IP address
- [x] `NXDOMAIN` — this name doesn't exist
- [ ] Nothing at all
:::

:::evaluate
Check answer
:::

:::tip Key point
**DNS** translates names (e.g. `www.beaver-schule.de`) into IP addresses. Before a PC can set up a connection to a name, it asks the **DNS server** entered in its IP settings — mostly via **UDP, port 53**. With `nslookup` you can make DNS requests by hand.
:::

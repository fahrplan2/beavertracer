# IPv6 in the network

:::sim
url=/sims/lesson-4.6.3.btsim
:::

Anna, Ben and a router are connected to the switch. On Anna and Ben, IPv6 is set to **SLAAC (auto)** — nobody entered an IPv6 address for them. The router knows the prefix `2001:db8:1::/64`.

## Where does the address come from?

1. Switch to :fa-play: **Run** mode and wait a few seconds.
2. Open the :fa-terminal: **Terminal** on **Anna** and enter `ip a`.

Besides the IPv4 address you see two lines with `inet6`: one address with `scope link` and one with `scope global`.

:::quiz mc
Which of the two IPv6 addresses is the link-local address?
- [x] The one starting with `fe80::` (`scope link`)
- [ ] The one starting with `2001:db8:1:` (`scope global`)
:::

:::quiz mc
Where does the prefix `2001:db8:1:0` of the global address come from?
- [ ] Anna made it up herself
- [x] From the router — it announces the prefix in the network
- [ ] From the switch
:::

:::evaluate
Check answers
:::

Compare the **interface ID** (the last four blocks) with Anna's **MAC address** — you find it at the very bottom of the :fa-gear: **IP Settings**. The MAC address `aa:28:39:e2:41:82`, for example, becomes the interface ID `a828:39ff:fee2:4182`: `ff:fe` is inserted in the middle, and one bit at the start is flipped (that's why `aa` becomes `a8`).

This procedure is called **SLAAC** (*Stateless Address Autoconfiguration*): the router announces the prefix, every device forms the interface ID itself.

:::note
Because the MAC address uniquely identifies a device, it could be recognised anywhere on the internet by its interface ID. That's why real devices usually also use random interface IDs that change regularly (*privacy extensions*) — a bit of data protection.
:::

## Finding neighbours — without ARP

1. Enter `ip a` on **Ben** and note his **global** IPv6 address.
2. Ping it from **Anna**, for example `ping 2001:db8:1:0:…` (with Ben's full address).
3. Switch to :fa-magnifying-glass: **Trace** mode and open a trace for **Anna**.

Look at the packets directly before the first `Echo (ping) request`.

:::quiz multi
Which statements are true?
- [x] Instead of an ARP request, Anna sends a **Neighbor Solicitation** ("Who has this address?")
- [x] Ben answers with a **Neighbor Advertisement** and states his MAC address
- [x] The request goes to a multicast address (`ff02::1:ff…`), not to everyone via broadcast
- [ ] Anna sends an ARP request like with IPv4
- [x] The router regularly sends **Router Advertisements** to `ff02::1` — they contain the prefix
:::

:::evaluate
Check answers
:::

:::tip Key point
With IPv6, **NDP** (*Neighbor Discovery Protocol*, part of ICMPv6) takes over the jobs of ARP: with **Neighbor Solicitation** and **Neighbor Advertisement**, devices find the MAC addresses of their neighbours. With **Router Advertisements** the router announces the prefix — from it, the devices form their own address via **SLAAC**.
:::

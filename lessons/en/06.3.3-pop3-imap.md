# POP3 or IMAP?

:::sim
url=/sims/lesson-6.3.btsim
:::

There are two protocols for collecting mail. In this simulation, **Anna uses POP3** and **Ben uses IMAP**.

## The experiment

1. In :fa-play: **Run** mode, send a mail from **Ben** to `anna@beaver-schule.de`.
2. Click **Fetch** in **Anna**'s **Mail** app.
3. Open traces for **Anna** and for **Ben** and compare the commands used for collecting.

:::quiz match
USER / PASS -> POP3: logging in with user name and password in two steps
RETR -> POP3: downloading a message
LOGIN -> IMAP: logging in with user name and password
SELECT INBOX -> IMAP: opening a folder on the server
:::

:::evaluate
Check matches
:::

## The difference

| | POP3 | IMAP |
|---|---|---|
| Port | 110 | 143 |
| Basic idea | **download** mails — usually deleting them on the server afterwards | mails **stay on the server** and are managed there |
| Folders, read/unread | only on your own device | on the server — the same everywhere |
| Several devices (phone, laptop) | impractical: every device has a different state | ideal: all devices see the same mailbox |

:::note
The mail program in BeaverTracer leaves the mails on the server even with POP3. Real programs often delete them after downloading — or only leave them there for a while.
:::

:::quiz mc
Lena reads her mails on her phone, her tablet and the school laptop. What should she use?
- [ ] POP3, because it's simpler
- [x] IMAP, because all devices see the same mailbox on the server
- [ ] SMTP, because it's meant for collecting
:::

:::evaluate
Check answer
:::

:::tip Key point
**POP3** downloads mails from the server onto **one** device. **IMAP** manages the mailbox **on the server** — with folders and read status for all devices at once. Both are only for **collecting**; sending is always done with **SMTP**.
:::

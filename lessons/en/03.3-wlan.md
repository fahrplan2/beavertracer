# Wi-Fi: a network without cables

:::goal
**Learning goal:** You can explain how an access point connects a Wi-Fi network to the wired network, bring a device into the Wi-Fi via its SSID and explain why a Wi-Fi network has to be encrypted.
:::

Phones, tablets and laptops usually don't even have a network port any more — they're connected over the air, via a **WLAN** (*Wireless LAN*, a wireless local network, usually just called Wi-Fi). For them to still be able to talk to the PCs and servers on the cable, you need a device that connects radio and cable.

:::note
In reality, Wi-Fi depends on range, walls and interference. BeaverTracer simplifies this: all devices with the same Wi-Fi name share one common radio network — no matter where they are on the workspace.
:::

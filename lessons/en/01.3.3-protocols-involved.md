# Name the protocols involved

Take another look at the packet list and match up which protocol was responsible for what:

:::quiz match
ARP -> Determines the MAC address of the web server before the first packet can be sent
TCP -> Establishes the connection to the web server (handshake) before data can flow
HTTP -> Requests the actual web page and delivers it back
:::

:::evaluate
Check matching
:::

:::note
This time you entered the server's IP address directly, so **DNS** (the "translation" of names like `www.beispiel.de` into an IP address) wasn't used yet. We'll cover that in chapter 6.
:::

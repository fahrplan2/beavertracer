# Subnetting step by step

In this section the bits are colour-coded: [[n|network part]] · [[e|extension]] · [[h|host part]]

## The idea

Imagine a large plot of land that is to be divided into equal-sized parcels. In subnetting, the large plot is the original network, the parcels are the subnets.

Technically, this is what happens: a network consists of a network part and a host part. In subnetting, you take some bits from the **start of the host part** and add them to the **network part**. These additional bits are called the **extension** (or *subnet bits*). Every possible combination of the extension bits gives a subnet of its own.

<pre class="bits-block">
before (/24):  [[n|NNNNNNNN.NNNNNNNN.NNNNNNNN]].[[h|HHHHHHHH]]
after  (/26):  [[n|NNNNNNNN.NNNNNNNN.NNNNNNNN]].[[e|EE]][[h|HHHHHH]]
</pre>

## How many bits do you need?

With *n* extension bits there are 2*ⁿ* combinations — so 2*ⁿ* subnets:

| Extension bits | Combinations | Subnets |
|---|---|---|
| 1 | 0, 1 | 2 |
| 2 | 00, 01, 10, 11 | 4 |
| 3 | 000, 001, … 111 | 8 |
| 4 | 0000 … 1111 | 16 |

If, for example, **three** subnets are needed, 1 bit (only 2 networks) isn't enough — you take 2 bits and get **four** subnets. One is left over as a reserve.

## Example 1: two subnets, in full detail

The network `192.168.42.0/24` is to be divided into **two** equal-sized subnets.

**Step 1 — How many bits?** For 2 subnets, **1 bit** is enough (2¹ = 2).

**Step 2 — New prefix length and netmask.** `/24` becomes `/24 + 1 = /25`. The mask now has 25 ones:

<pre class="bits-block">
[[n|11111111.11111111.11111111]].[[e|1]][[h|0000000]]   →   255.255.255.128
</pre>

**Step 3 — Write the network address in binary and mark it.** The first three octets don't change. In the last octet, the first bit is the extension (E), the rest is host part (H):

<pre class="bits-block">
[[n|192.168.42.]] [[e|0]] [[h|0 0 0 0 0 0 0]]
            [[e|E]] [[h|H H H H H H H]]
</pre>

**Step 4 — For every combination of the extension, determine the network and broadcast address.** The extension is set once to 0 and once to 1. For the network address all host bits are 0, for the broadcast address all are 1:

| Subnet | E | Host bits | last octet | Address |
|---|---|---|---|---|
| 1 — network address | [[e|0]] | [[h|0000000]] | 0 | `192.168.42.0` |
| 1 — broadcast address | [[e|0]] | [[h|1111111]] | 127 | `192.168.42.127` |
| 2 — network address | [[e|1]] | [[h|0000000]] | 128 | `192.168.42.128` |
| 2 — broadcast address | [[e|1]] | [[h|1111111]] | 255 | `192.168.42.255` |

**Step 5 — Write down the result:**

| Subnet | Network address | Broadcast address | Range for hosts | Hosts |
|---|---|---|---|---|
| 1 | `192.168.42.0/25` | `192.168.42.127` | `.1` – `.126` | 126 |
| 2 | `192.168.42.128/25` | `192.168.42.255` | `.129` – `.254` | 126 |

## Example 2: four subnets

The same network `192.168.42.0/24`, this time into **four** subnets.

**Step 1:** 4 subnets → **2 bits** (2² = 4).

**Step 2:** `/24 + 2 = /26`, mask [[n|11111111.11111111.11111111]].[[e|11]][[h|000000]] = `255.255.255.192`.

**Step 3:** In the last octet, the first **two** bits are now the extension: [[e|EE]][[h|HHHHHH]].

**Step 4:** The extension counts up in binary: 00, 01, 10, 11. For every combination you set the host bits once to 0 and once to 1:

| Subnet | EE | Network address (host bits 0) | Broadcast address (host bits 1) |
|---|---|---|---|
| 1 | [[e|00]] | [[e|00]][[h|000000]] = **0** | [[e|00]][[h|111111]] = **63** |
| 2 | [[e|01]] | [[e|01]][[h|000000]] = **64** | [[e|01]][[h|111111]] = **127** |
| 3 | [[e|10]] | [[e|10]][[h|000000]] = **128** | [[e|10]][[h|111111]] = **191** |
| 4 | [[e|11]] | [[e|11]][[h|000000]] = **192** | [[e|11]][[h|111111]] = **255** |

**Step 5 — Result:**

| Subnet | Network address | Broadcast address | Range for hosts |
|---|---|---|---|
| 1 | `192.168.42.0/26` | `192.168.42.63` | `.1` – `.62` |
| 2 | `192.168.42.64/26` | `192.168.42.127` | `.65` – `.126` |
| 3 | `192.168.42.128/26` | `192.168.42.191` | `.129` – `.190` |
| 4 | `192.168.42.192/26` | `192.168.42.255` | `.193` – `.254` |

Every subnet has 2⁶ = 64 addresses, 62 of them for hosts.

Notice something? The subnets lie **back to back without gaps**: each starts directly after the broadcast address of the previous one. And the broadcast address of the last subnet is exactly the broadcast address of the original network — that's how you can check your result.

:::tip Key point: subnetting in five steps
1. **How many subnets?** Round up to the next power of two → *n* extension bits.
2. **New prefix length** = old prefix length + *n*; from that, the new **netmask**.
3. Write the **network address in binary** and mark the network part, extension and host part.
4. **Count up the extension** (00, 01, 10, …): host bits to 0 → network address, host bits to 1 → broadcast address.
5. **Check:** the subnets lie back to back without gaps, the last one ends with the broadcast address of the original network.
:::

# Assigning IP addresses

For two devices to talk to each other, they need an IP address on the same network.

1. Click on one of your PCs to open it.
2. Open the :fa-gear: network settings there and assign a fixed IP address, e.g. `192.168.0.10` with the netmask `/24`.
3. Repeat this for the second PC with a different address on the same network, e.g. `192.168.0.11`.

:::note
We'll discuss what `/24` actually means and how to sensibly divide up a network in detail in chapter 4. For now, it's enough to know: both addresses must start with `192.168.0.` and must not be repeated.
:::

# Looking at a packet in layers

Load the same simulation as in chapter 1.3 again:

:::sim
url=/sims/lesson-1.3-webrequest.btsim
:::

Start the simulation, open the website in the Sparktail browser, and switch to :fa-magnifying-glass: **Trace** mode. Click on the HTTP GET packet there and look at the protocol tree on the right.

:::note
The protocol tree is built from bottom to top: **Ethernet** at the very bottom, **IPv4** above that, **TCP** above that, and **HTTP** at the very top. Each layer "wraps" the one above it — this is exactly the principle that the models on the following pages illustrate.
:::

:::quiz short
Which protocol is at the very top of the protocol tree, directly above TCP?
= HTTP
:::

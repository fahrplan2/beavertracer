# Network address, broadcast address and hosts

In every network, two addresses have a special job:

- The **network address** is the **lowest** address of the network: all bits in the host part are 0. It refers to the network as a whole, e.g. in routing tables.
- The **broadcast address** is the **highest** address of the network: all bits in the host part are 1. Whatever is sent to it goes to all devices in the network.

Neither address is **assigned** to devices. All addresses in between are available for devices (**hosts**).

## A simple example

`192.168.0.12/24` — the host part is the last octet:

| | Address |
|---|---|
| Network address (host part = 0) | `192.168.0.0` |
| Broadcast address (host part = 255) | `192.168.0.255` |
| Range for hosts | `192.168.0.1` – `192.168.0.254` |
| Number of hosts | 254 |

## When the boundary is in the middle of an octet

It gets trickier when the prefix length isn't a multiple of 8. Then you convert the octet in question into binary. Example: `194.9.190.12/27`.

The first three octets belong entirely to the [[n|network part]] (24 bits). Of the last octet, **3 bits** still belong to the network part (24 + 3 = 27), the remaining **5 bits** to the [[h|host part]]:

| | last octet (binary) | decimal |
|---|---|---|
| IP address | [[n|000]][[h|01100]] | 12 |
| Netmask (`/27`) | [[n|111]][[h|00000]] | 224 |
| Network address: host bits to 0 | [[n|000]][[h|00000]] | **0** |
| Broadcast address: host bits to 1 | [[n|000]][[h|11111]] | **31** |

Result:

- Network address: `194.9.190.0`
- Broadcast address: `194.9.190.31`
- Range for hosts: `194.9.190.1` – `194.9.190.30`
- Number of hosts: 2⁵ − 2 = **30**

:::tip Key point
**Network address:** all host bits set to 0 (lowest address). **Broadcast address:** all host bits set to 1 (highest address). Neither is assigned to devices. A network with prefix length *n* has **2<sup>32 − n</sup> − 2** usable addresses for hosts.
:::

:::tip Tip: the block size
Once you've understood the method in binary, there's a shortcut: **256 minus the mask octet** gives the size of a network in that octet. With `/27` (mask 224) that's 256 − 224 = **32**. Networks then start at 0, 32, 64, 96 … — the address `.12` is in the network starting at `.0`, the address `.70` in the network starting at `.64`.
:::

## The most important network sizes

| Prefix | Netmask | Hosts |
|---|---|---|
| `/8` | `255.0.0.0` | 16,777,214 |
| `/16` | `255.255.0.0` | 65,534 |
| `/24` | `255.255.255.0` | 254 |
| `/25` | `255.255.255.128` | 126 |
| `/26` | `255.255.255.192` | 62 |
| `/27` | `255.255.255.224` | 30 |
| `/28` | `255.255.255.240` | 14 |
| `/29` | `255.255.255.248` | 6 |
| `/30` | `255.255.255.252` | 2 |

:::note
The smallest network common in practice is `/30`: it has exactly two usable addresses and is often used for the connection between two routers. A `/32` refers to a single address — it can't be used as a network, but it does appear in routing tables and firewall rules.
:::

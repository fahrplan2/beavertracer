# Assigning IP addresses

:::sim
url=/sims/lesson-1.2.2.btsim
:::

For two devices to talk to each other, they need an IP address in the same network. On the workspace you see two connected PCs — exactly as you just built them yourself.

1. Switch to :fa-play: **Run** mode and click **Computer 1** to open it.
2. Open the :fa-gear: **IP Settings** there. A new PC already has the address `192.168.0.10` with the netmask `/24` — you can leave it like that.
3. Now open **Computer 2**. It has the *same* address `192.168.0.10` — that can't work, because every address may appear only once in a network. Change it to `192.168.0.11` (netmask `/24`).

:::tip Key point
An **IP address** (e.g. `192.168.0.10`) is the address of a device in the network — comparable to a house number. Every IP address may appear only **once** in a network.
:::

:::task
title: Addresses assigned correctly?
Stay in Run mode and check whether both PCs have matching addresses and can reach each other.
check: ip(1, "192.168.0.10/32")
check: ip(3, "192.168.0.11/32")
check: pingOk(1, 3)
:::

:::note
What exactly `/24` means and how to divide a network sensibly is covered in detail in chapter 4. For now it's enough that both addresses must start with `192.168.0.` and must not repeat.
:::

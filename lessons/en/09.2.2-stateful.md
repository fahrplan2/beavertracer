# The Stateful Firewall

:::sim
url=/sims/lesson-9.2.btsim
:::

A **stateful** firewall remembers every connection it has allowed once in a **state table**: protocol, both addresses and both ports. If a packet arrives that matches an entry — in either direction — it lets it through without further checks. New connections, on the other hand, have to pass the rules.

## Observing

1. Set the **Mode** in the **Firewall** to **Stateful**.
2. Load `http://203.0.113.80/` again in the :fa-globe: **Browser** on the **Lehrer-PC**.
3. Immediately open the firewall's **States** tab.

:::quiz mc
What happens now?
- [x] The page loads, and **States** lists the connection from the Lehrer-PC to `203.0.113.80:80`
- [ ] The page doesn't load, because the replies still have no rule
:::

:::quiz short

= 80
:::

Check answers
:::

The entries in **States** disappear again after a while (column **Timeout**) when nothing more runs over the connection.

## Task: the school firewall

Now set up the firewall the way a real school needs it:

- **From the school network** everything may go to the internet (direction B → A, any protocol).
- **From the internet** only web (80) and mail reception (25) of the school server can be reached.
- Everything else is **dropped**, the mode is **Stateful**.

:::task
title: School firewall set up?
Checks whether the school network gets to the internet, whether only web and mail of the school server can be reached from outside and whether the Lehrer-PC is unreachable from outside.
check: tcpOpen(8, "203.0.113.80", 80)
check: tcpOpen(1, "198.51.100.10", 80)
check: tcpOpen(1, "198.51.100.10", 25)
check: tcpFails(1, "198.51.100.10", 22)
check: pingFails(1, 8)
:::

:::quiz mc
The Lehrer-PC pings `203.0.113.80`. Do the replies come back?
- [x] Yes — the ping was allowed B → A, the reply belongs to this state
- [ ] No — there's no rule for ICMP from outside
:::

:::

:::tip Key point
A **stateful firewall** enters every allowed connection into a **state table** and lets all packets of that connection through in **both directions**. So rules for **setting up connections** are enough: "inside may go out" and "from outside only to certain services". Connections started from outside into the school network stay blocked.
:::

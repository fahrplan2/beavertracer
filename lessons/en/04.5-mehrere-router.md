# Several routers

:::goal
**Learning goal:** You can read routing tables, enter static routes, follow a packet's path with `traceroute` and find typical routing faults.
:::

:::sim
url=/sims/lesson-4.5.2.btsim
:::

So far there was always exactly one router between two networks — and it knew both networks because it was directly connected to them. On the internet, though, there are often many routers one after another between sender and destination. How does each one of them know where to send a packet next?

The answer is in its **routing table**. How to read it and add to it yourself you'll learn in this section.

## Expanding layer by layer

Click the small triangle in front of **Ethernet**, **Internet Protocol Version 4**, **Transmission Control Protocol** and **Hypertext Transfer Protocol**. Every layer brings its own details:

| Layer in the tree | What you find in it | What for |
|---|---|---|
| Ethernet | `Source` and `Destination`: MAC addresses like `aa:57:28:…` | which network card in the local network |
| IPv4 | `Source Address` `192.168.0.10`, `Destination Address` `192.168.0.20` | which computer — even across network boundaries |
| TCP | `Source Port` `49152`, `Destination Port` `80` | which program on the computer |
| HTTP | `GET / HTTP/1.1`, `Host: 192.168.0.20` | the browser's actual message |

Also look at these two lines: Ethernet says `Type: IPv4`, IPv4 says `Protocol: TCP`. So every layer tells you *what's inside it* — that's how the receiver knows how to keep unpacking.

## An envelope inside an envelope

What you just saw is created at the sender like this:

1. The browser writes the actual message: `GET / HTTP/1.1` (**HTTP**).
2. **TCP** wraps it and puts the ports in front — so it reaches the right program.
3. **IP** wraps the whole thing and puts the IP addresses in front — so it reaches the right computer.
4. **Ethernet** puts everything into a frame with the MAC addresses — so it reaches the right network card in the local network.

At the receiver it works exactly the other way round: every layer takes off its part and passes the rest up. It's like a letter put into several envelopes — the message inside, and on the outside of each envelope the address for whoever opens it next.

:::tip Key point
Every layer puts its own control information — the **header** — in front of the data of the layer above. This wrapping and unwrapping is called **encapsulation**.
:::

Depending on the layer, the "parcel" has its own name:

| Layer | Protocol in the example | Name of the data unit |
|---|---|---|
| Layer 2 | Ethernet | **Frame** |
| Layer 3 | IPv4 | **Packet** |
| Layer 4 | TCP | **Segment** |

:::note
In everyday speech — and in this course too — people often just say "packet", no matter which layer. When precision matters, use the names from the table.
:::

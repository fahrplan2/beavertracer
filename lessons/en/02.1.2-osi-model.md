# The ISO/OSI reference model

The ISO/OSI model divides communication between two devices into seven layers. Each layer has a clearly defined task and only uses the services of the layer directly below it:

<table class="osi-table">
<thead>
<tr><th>Layer</th><th>Name</th><th>Task</th><th>Example protocols</th></tr>
</thead>
<tbody>
<tr class="osi-l7"><td>7</td><td>Application</td><td>Interface to the application</td><td>HTTP, DNS, SMTP</td></tr>
<tr class="osi-l6"><td>6</td><td>Presentation</td><td>Data format, encryption</td><td>TLS, JPEG, ASCII</td></tr>
<tr class="osi-l5"><td>5</td><td>Session</td><td>Session management</td><td>RPC, NetBIOS</td></tr>
<tr class="osi-l4"><td>4</td><td>Transport</td><td>End-to-end transmission</td><td>TCP, UDP</td></tr>
<tr class="osi-l3"><td>3</td><td>Network</td><td>Routing between networks</td><td>IP, ICMP</td></tr>
<tr class="osi-l2"><td>2</td><td>Data link</td><td>Transmission within the local network</td><td>Ethernet, ARP</td></tr>
<tr class="osi-l1"><td>1</td><td>Physical</td><td>Signals on the physical medium</td><td>Copper, fiber optic, Wi-Fi</td></tr>
</tbody>
</table>

From the experiment on the previous page, you already know four of these layers: Ethernet (2), IPv4 (3), TCP (4), and HTTP (7).

:::note
Layer 1 describes the actual transmission of signals over cable or radio. BeaverTracer does not simulate this layer — cables are always considered to be connected without errors, and there are neither signal problems nor collisions. In the Tracer, the view therefore effectively starts at layer 2.
:::

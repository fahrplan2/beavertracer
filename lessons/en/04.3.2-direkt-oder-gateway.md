# Directly or via the gateway?

:::sim
url=/sims/lesson-4.3.2.btsim
:::

Before a PC sends a packet, it decides: is the destination in its **own network**? To find out, it compares the network part of its own address with the network part of the destination address — with the help of its netmask.

## The procedure

1. **Is the destination IP in your own network?**
   - **Yes:** the PC sends the packet **directly** to the destination. It needs the destination's MAC address.
   - **No:** the PC sends the packet to the **gateway**. It needs the router's MAC address. If no gateway is entered, it can't send the packet at all.
2. **Does it already know the MAC address it needs** (is it in its ARP cache)? If not, it asks for it via **ARP**.
3. It sends the frame to this MAC address. In both cases, the **destination IP address** in the packet is the actual destination.

| | directly (own network) | via the gateway (foreign network) |
|---|---|---|
| ARP asks for … | the destination's MAC | the router's MAC |
| Destination MAC in the frame | destination | router |
| Destination IP in the packet | destination | destination |

## Troubleshooting: company B can't be reached

Since yesterday, Anna can no longer reach the PCs in company B. This is how the network is *supposed* to be set up:

| Device | IP address | Gateway |
|---|---|---|
| Anna | `192.168.0.10/24` | `192.168.0.1` |
| Ben | `192.168.0.11/24` | `192.168.0.1` |
| Clara | `172.16.0.10/24` | `172.16.0.1` |
| David | `172.16.0.11/24` | `172.16.0.1` |

Find the faults and fix them.

<details>
<summary>Tip 1: Does Anna's ping arrive at all?</summary>

Ping Clara from Anna and open a trace for **Clara**. Did the ping arrive? And did Clara answer?
</details>

<details>
<summary>Tip 2: What is David doing?</summary>

Ping David from Anna and open a trace for **David**. Which IP address does David ask for via ARP — and does he get an answer?
</details>

## What was going on?

:::quiz multi
What did you see in the tracer while troubleshooting?
- [x] Anna's ping arrived at Clara, but Clara didn't answer
- [x] David asked via ARP for an address that doesn't even exist in the network
- [ ] Anna's ping never left company A
:::

:::evaluate
Check answer
:::

:::tip Key point
A PC needs the right gateway not only for sending, but also for **answering**: without a gateway the ping does arrive, but the reply finds no way back. If a **wrong gateway address** is entered, the PC asks in vain via ARP for a router that doesn't exist.
:::

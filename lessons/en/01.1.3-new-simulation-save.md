# Create and save a new simulation

In the toolbar, under "Project", you'll find the buttons :fa-file: **New**, :fa-file-arrow-up: **Open**, and :fa-file-arrow-down: **Save**.

A simulation is a single file (`.btsim`) that describes your entire network — all devices, cables, and their configuration. You can save it locally at any time and load it again later, just like a document in a word processor.

:::tip
Go ahead and create a new, empty simulation now — in the next chapter, you'll build directly on it.
:::

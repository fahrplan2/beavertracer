# Hashes: the Fingerprint of Data

:::sim
url=/sims/lesson-8.1.3.btsim
:::

A **hash function** calculates a short string of fixed length from any amount of data — a sentence, a document, a whole film: the **hash**. It works like a **fingerprint**: the same data always gives the same hash, different data a different one.

Today's usual hash function is called **SHA-256**. Its hash is always 256 bits long, so 64 characters as a hexadecimal number.

## The experiment

On the **PC**, the folder `/home` contains three files with a small purchase contract (in German: *"I sell my bike to Ben for 100 euros."*). Switch to :fa-play: **Run** mode, open the :fa-terminal: **Terminal** on the **PC** and enter:

```
$ cd /home
$ cat vertrag.txt vertrag-kopie.txt vertrag-neu.txt
$ sha256sum vertrag.txt vertrag-kopie.txt vertrag-neu.txt
```

## Properties of a hash function

| Property | Meaning |
|---|---|
| **fixed length** | No matter how large the data is — the hash always has the same length. |
| **deterministic** | The same data always gives the same hash. |
| **avalanche effect** | Even the smallest change gives a completely different hash. |
| **one-way function** | The data **cannot** be calculated back from the hash. |
| **collision resistant** | It is practically impossible to find two different files with the same hash. |

A hash function is **not encryption**: there's no key and no decryption. It serves a different purpose — **integrity**.

## What is it used for?

- **Checking downloads:** many websites state a file's SHA-256 value next to it. If the hash of your downloaded file matches, it wasn't changed on the way.
- **Storing passwords:** good websites don't store your password, only a hash of it. When you log in, the hash of your input is compared. If the database is stolen, the thief still doesn't know the passwords.
- **Digital signatures:** instead of a whole document, you only sign its hash — more on that in the next section.

:::tip Key point
A **hash function** (e.g. **SHA-256**) calculates a **hash** of fixed length from any data — a **fingerprint**. Even the smallest change gives a completely different hash, and the data cannot be calculated back from the hash. Hashes secure the **integrity** of data.
:::

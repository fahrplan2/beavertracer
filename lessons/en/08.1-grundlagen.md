# Cryptography Basics

**Cryptography** is the science of encryption. Before we start, a few terms that come up again and again in this chapter:

| Term | Meaning |
|---|---|
| **Plaintext** | The readable message, e.g. `Meet at 10 am` |
| **Ciphertext** | The encrypted message, e.g. `Phhw dw 10 dp` |
| **Encrypt** | plaintext → ciphertext |
| **Decrypt** | ciphertext → plaintext |
| **Cipher** (*algorithm*) | The procedure used for encrypting |
| **Key** | The secret extra information the cipher needs |

## The cipher isn't secret — the key is

You might think a cipher is safer the fewer people know it. The opposite is true: all ciphers used today are **publicly** described and have been checked for weaknesses by experts around the world for years. Only the **key** stays secret.

The Dutchman Auguste Kerckhoffs stated this principle as early as 1883. The advantage: if a key is leaked, you simply replace the key — not the whole cipher.

In the following sections you get to know the four building blocks that secure connections are made of:

1. **Symmetric encryption** — fast, but with a key problem
2. **Asymmetric encryption** — public and private key
3. **Hashes** — the fingerprint of data
4. **Digital signatures** — electronic signatures

Finally you'll see how these building blocks work together (**hybrid encryption**).

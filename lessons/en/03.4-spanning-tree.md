# Loops in the network and Spanning Tree

:::goal
**Learning goal:** You can explain how a broadcast storm arises in a network with a loop and how the Spanning Tree Protocol (STP) prevents loops without giving up redundancy.
:::

:::sim
url=/sims/lesson-3.4.1.btsim

What happens when a cable in a network breaks? If everything hangs on a single line, part of the network is cut off. That's why in larger networks switches are often connected **more than once** — like the three switches on the workspace, which form a ring. If one cable fails, there's a detour.

Sounds good — but such a ring has a dangerous catch. You'll get to know it on the next page.

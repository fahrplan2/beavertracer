# Load the page, keep the Tracer open in parallel

:::task
title: Check the connection
Before continuing: is the loaded simulation set up correctly?
check: ip(1, "192.168.0.0/24")
check: pingOk(1, 2)
:::

On the **Client PC**, open the app :fa-globe: **Browser** and go to your web server's address (`http://192.168.0.20/`).

Then switch to :fa-magnifying-glass: **Trace** mode. If no connection is shown yet: click **+** in the top right and select it. Take a look at the packet list.

:::note
For a single page load, that's a surprisingly large number of packets — more than for a simple ping just now. That's intentional: loading a web page is a multi-step process, not a single action.
:::

# Summary and Outlook

## Firewalls in many places

You'll find the packet filter from this chapter in many devices:

- **Home router:** every home router is also a stateful firewall. With IPv4, NAT takes over part of this: nobody can start a connection from outside as long as there's no port forwarding (chapter 7). With IPv6 all devices have public addresses — then the firewall rule "nothing new from outside" alone provides the same protection.
- **Personal firewall:** Windows, macOS and Linux also have a built-in firewall on the computer itself. It protects the device in other networks too, e.g. on a café's Wi-Fi, and can set rules per program.
- **Next-generation firewall** and **web application firewall (WAF):** they don't only look at addresses and ports but into the packets' content — up to the application layer. That way they recognise e.g. attacks in HTTP requests. With HTTPS they have to break the encryption to do so (chapter 8).
- **IDS/IPS:** an *intrusion detection system* recognises suspicious patterns in traffic and raises an alarm; an *intrusion prevention system* also blocks them itself.

:::note
A firewall is only **one** building block of security. It doesn't help if an allowed service (e.g. the web server) has a hole itself, if someone opens malware from an e-mail or if a password is weak. That's why updates, strong passwords, encryption and a smart division of the network (DMZ, VLANs from chapter 3) always belong to it.
:::

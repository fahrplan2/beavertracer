# Setting up the home router

:::sim
url=/sims/lesson-7.1.2.btsim
:::

A new home router has just been connected — but nobody gets onto the internet yet. From the provider you've received a letter with the **access data**:

| Access data | Value |
|---|---|
| WAN IP address | `203.0.113.2` |
| Prefix length | `/30` |
| Gateway (the provider's router) | `203.0.113.1` |
| The provider's DNS server | `198.51.100.10` |

1. Switch to :fa-play: **Run** mode, click the **Heimrouter** and open the **WAN** tab.
2. Enter the access data and click **Apply**.
3. Connect the **Tablet** to the Wi-Fi: :fa-gear: **IP Settings**, **WiFi** tab, SSID `Biberbau`, **Apply**.
4. Test on the PC with `ping 192.0.2.80` or in the browser with `http://www.beispiel.de/`.

:::note
In practice the home router usually gets its WAN address automatically from the provider (via DHCP or a login with user name and password). Fixed access data like here are more common for business connections.
:::

# Setting Up HTTPS

:::sim
url=/sims/lesson-8.3.3.btsim
:::

This continues where section 8.2.2 left off: the web server **www.beaver-schule.de** holds the **Schul-CA** and a server certificate issued by it, and the **Client-PC** trusts the Schul-CA. But the web server doesn't speak HTTPS yet.

## Before

Switch to :fa-play: **Run** mode and load `https://www.beaver-schule.de/` in the :fa-globe: **Browser** on the **Client-PC**.

:::quiz mc
What happens?
- [x] The connection fails — no service is listening on port 443
- [ ] The browser warns about an insecure certificate
- [ ] The page is shown without a padlock
:::

:::evaluate
Check answer
:::

## Turning on HTTPS

1. On the web server, open the **HTTP-Server** and click **Stop** — the settings can't be changed while the server is running.
2. Switch to the **HTTPS** tab:
    - Tick **Enable HTTPS**, **HTTPS Port** `443`
    - Under **Certificate**, select the server certificate `www.beaver-schule.de` — not the Schul-CA!
    - Click **Use**
3. Click **Start**.

Load the page on the Client-PC again via `https://`. Click the padlock and check issuer and validity.

:::note
Public websites need a certificate from a CA that is pre-installed in all browsers. Since 2015, **Let's Encrypt** has been issuing such certificates for free and automatically — one of the main reasons why almost all websites use HTTPS today.
:::

:::tip Key point
For **HTTPS**, the web server needs a **server certificate with private key** whose name matches the address, and it has to listen on **port 443**. The client only trusts the site if it knows the issuing **CA**.
:::

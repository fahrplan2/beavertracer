# Setting up a DHCP server

:::sim
url=/sims/lesson-6.4.2.btsim
:::

This time the DHCP server isn't set up yet. You decide which settings it hands out:

| Setting | Value |
|---|---|
| Address range | `192.168.0.100` to `192.168.0.120` |
| Gateway | `192.168.0.1` |
| DNS server | `192.168.0.53` |

1. Switch to :fa-play: **Run** mode, click the **DHCP-Server** and open the **DHCP Server** app.
2. Enter **Range start**, **Range end**, **Gateway** and **DNS servers**, click **Save** and then **Start**.
3. On **Laptop 1** and **Laptop 2**, set the mode in the :fa-gear: **IP Settings** to **DHCP** and click **Apply** each time.
4. Check in the DHCP server's **Leases** tab who got which address.

:::note
The address range is chosen so that it doesn't collide with fixed addresses: servers, routers and printers often get fixed addresses outside the DHCP range — here, for example, the DHCP server itself with `192.168.0.2`.
:::

# The router

:::goal
**Learning goal:** You can explain how a router connects two networks, set the gateway on a PC and explain when a PC delivers a packet directly and when via the gateway.
:::

:::sim
url=/sims/lesson-4.3.1.btsim
:::

A **router** connects different networks with each other. For this it has a separate port for every network — and on every port its own IP address from exactly that network. On the workspace you see company A and company B again, this time with a router in between.

# The binary system

Deep down, a computer only knows two states: power on or power off. These are written as **1** and **0**. Such a digit is called a **bit**. Every IP address, too, is just a sequence of zeros and ones for the computer — so that you understand how netmasks work, on this page you learn to read such numbers and convert them yourself.

## How we normally count: the decimal system

In everyday life we calculate with ten digits (0 to 9). Every position is worth ten times as much as the position to its right: ones, tens, hundreds, thousands. So the number `305` means:

| Place value | 100 | 10 | 1 |
|---|---|---|---|
| Digit | 3 | 0 | 5 |
| Value | 300 | 0 | 5 |

300 + 0 + 5 = **305**

## The binary system

In the **binary system** there are only two digits: 0 and 1. Every position is worth **twice** as much as the position to its right: 1, 2, 4, 8, 16, 32, 64, 128 …

So the binary number `00001101` means:

| Place value | 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1 |
|---|---|---|---|---|---|---|---|---|
| Bit | 0 | 0 | 0 | 0 | 1 | 1 | 0 | 1 |
| Value | | | | | 8 | 4 | | 1 |

8 + 4 + 1 = **13**

So you simply add up the place values where there's a 1.

:::tip Key point
A **bit** is one digit in the binary system (0 or 1). **8 bits** make a **byte** — in networking, such an 8-bit group is also called an **octet**. The place values of an octet are **128, 64, 32, 16, 8, 4, 2, 1**.
:::

## From decimal to binary

The other way round, you go through the place values from left to right and ask each time: **does the place value still fit into my (remaining) number?** If yes, you write a 1 and subtract the place value. If no, you write a 0.

Example: `168`

| Place value | fits into …? | Bit | Remainder |
|---|---|---|---|
| 128 | 168 → yes | **1** | 40 |
| 64 | 40 → no | **0** | 40 |
| 32 | 40 → yes | **1** | 8 |
| 16 | 8 → no | **0** | 8 |
| 8 | 8 → yes | **1** | 0 |
| 4 | 0 → no | **0** | 0 |
| 2 | 0 → no | **0** | 0 |
| 1 | 0 → no | **0** | 0 |

Read from top to bottom: 168 = **10101000**

## IP addresses in binary

An IPv4 address consists of **32 bits**, i.e. four octets. Because nobody can remember 32 zeros and ones, each octet is written as a decimal number and they're separated by dots:

```
11000000 . 10101000 . 10110010 . 00000001
   192   .   168    .   178    .    1
```

:::quiz short

= 32
:::

:::

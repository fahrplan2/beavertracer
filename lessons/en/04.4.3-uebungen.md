# Subnetting exercises

Work out the tasks on paper first — with the method from 4.4.1 — and then enter your results in the tables. In tests and exams you have to be able to do this without any aids.

## Task 1

Divide the network `10.25.58.0/24` into **two** equal-sized subnets.

:::quiz table
| Prefix length | Netmask |
|---|---|
| /{25} | {255.255.255.128} |
:::

:::quiz table
| Subnet | Network address | Broadcast address | first host | last host |
|---|---|---|---|---|
| 1 | {10.25.58.0} | {10.25.58.127} | {10.25.58.1} | {10.25.58.126} |
| 2 | {10.25.58.128} | {10.25.58.255} | {10.25.58.129} | {10.25.58.254} |
:::

Check task 1

# Troubleshooting: the mail doesn't arrive

:::sim
url=/sims/lesson-6.3.4.btsim
:::

Anna reports: "I can't send Ben a mail!" This is how it's *supposed* to be set up:

| What | Target |
|---|---|
| Anna's outgoing server (SMTP) | `mail.beaver-schule.de`, port `25` |
| MX entry of `biber-mail.de` | `mail.biber-mail.de` (priority 10) |

Find the faults and fix them. Then have Anna send a mail to `ben@biber-mail.de` — the task checks whether it has arrived in Ben's mailbox. (Passing it on between the mail servers can take a few seconds.)

<details>
<summary>Tip 1: What does Anna's mail program say?</summary>

Try to send a mail and look at the **Log** tab. What does the server answer — does that sound like SMTP?
</details>

<details>
<summary>Tip 2: The mail comes back as an error message?</summary>

Collect Anna's mail and read the message from `MAILER-DAEMON`. Why did the delivery fail? On Anna's PC, use `nslookup -type=MX biber-mail.de` to check whether the DNS server knows the responsible mail server.
</details>

<details>
<summary>Tip 3: Where is this set?</summary>

You set the outgoing server in Anna's **Mail** app under **Settings**. MX entries are in the **DNS-Server** app in the **MX** tab.
</details>

:::task
title: Mail arrived?
Checks whether there's a mail in Ben's mailbox on the Mailserver Biber.
check: fileExists(5, "/var/mail/ben.mbox")
:::

## What was going on?

:::quiz multi
Which statements are true?
- [x] Anna's outgoing server pointed to port 110 — the POP3 service answers there, not SMTP
- [x] The MX entry for `biber-mail.de` was missing — the Mailserver Schule found no responsible mail server
- [x] The undeliverable mail came back as an error message from `MAILER-DAEMON`
- [ ] Ben's password was wrong
:::

:::evaluate
Check answer
:::

:::tip Key point
Typical e-mail faults: a wrong **server or port** in the mail program (SMTP runs on port 25, POP3 on 110, IMAP on 143) and a missing or wrong **MX entry** in the DNS. If a mail server can't deliver a mail, it sends it back to the sender with an error message (**bounce**).
:::

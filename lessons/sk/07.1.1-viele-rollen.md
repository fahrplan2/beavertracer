## Čo všetko sa skrýva v domácom smerovači

| Rola v domácom smerovači | Čo robí | pozná ju z |
|---|---|---|
| **Switch** | prepája zariadenia na LAN portoch | kapitola 3.1 |
| **Prístupový bod** | pripája mobily, tablety a laptopy do siete cez WLAN | kapitola 3.3 |
| **Smerovač** | prepája domácu sieť so sieťou poskytovateľa — je to **gateway** | kapitola 4.3 |
| **DHCP Server** | prideľuje adresy, gateway a DNS server | kapitola 6.4 |
| **DNS** | preposiela požiadavky na mená alebo oznamuje DNS server poskytovateľa | kapitola 6.2 |
| **NAT** | pripája všetky zariadenia do internetu cez **jednu** verejnú adresu | nové — oddiel 7.2 |

Port **WAN** (*Wide Area Network*) vedie k poskytovateľovi, porty **LAN** a WLAN do domácej siete. Mnohé domáce smerovače obsahujú navyše **modem** — ten prekladá dáta pre vedenie (DSL, kábel, optické vlákno). BeaverTracer to nesimuluje; port WAN je tu zapojený priamo do siete poskytovateľa.

:::quiz match

Prístupový bod -> Pripája tablety a mobily do siete cez WLAN
DHCP Server -> Prideľuje adresy zariadeniam v domácej sieti
Smerovač -> Prepája domácu sieť so sieťou poskytovateľa
:::

:::tip Zapamätaj si
**Domáci smerovač** spája viacero zariadení: **switch**, **WLAN prístupový bod**, **smerovač** (gateway do internetu), **DHCP server** a **preposielanie DNS** — k tomu **NAT**. Port **WAN** vedie k poskytovateľovi, porty **LAN** a WLAN do domácej siete.

# Projekt: firma so štyrmi pobočkami

:::sim
url=/sims/lesson-4.5.4.btsim
:::

Firma má svoje ústredie v meste **Hanau** a pobočky v mestách **Kassel**, **Gießen** a **Darmstadt**. Každá pobočka má vlastnú sieť a vlastný smerovač. Všetky smerovače sú prenajatými linkami pripojené k **centrálnej sieti**, v ktorej stojí aj hlavný server firmy.

## Plán adries

Administrátor pridelil adresy podľa nasledujúcej schémy — v simulácii sú už zadané:

| Sieť | Rozsah adries |
|---|---|
| Centrálna sieť | `10.19.0.0/24` |
| Hanau | `10.19.1.0/24` |
| Kassel | `10.19.2.0/24` |
| Gießen | `10.19.3.0/24` |
| Darmstadt | `10.19.4.0/24` |

| Zariadenie | v centrálnej sieti | v sieti pobočky |
|---|---|---|
| Server | `10.19.0.10` | — |
| Router Hanau | `10.19.0.1` | `10.19.1.1` |
| Router Kassel | `10.19.0.2` | `10.19.2.1` |
| Router Gießen | `10.19.0.3` | `10.19.3.1` |
| Router Darmstadt | `10.19.0.4` | `10.19.4.1` |
| PC na pobočke | — | vždy `.2` (napr. PC Kassel `10.19.2.2`) |

Pri všetkých smerovačoch smeruje `eth0` do centrálnej siete a `eth1` do siete pobočky.

## Tvoja úloha

Aby sa všetky počítače vo firme navzájom videli a dosiahli aj server, chýbajú ešte dve veci:

1. **Brány:** Nastav bránu na všetkých štyroch PC aj na serveri. PC používajú smerovač svojej pobočky; server používa **Router Hanau**.
2. **Smerovacie tabuľky:** Doplň na všetkých štyroch smerovačoch trasy, ktoré ešte chýbajú. Každý smerovač musí poznať siete **troch ostatných** pobočiek.

Medzitým testuj pomocou `ping` a `traceroute`.

<details>
<summary>Tip: Ako vyzerá trasa v tomto prípade?</summary>

Príklad pre **Router Kassel**: Pakety pre Gießen (`10.19.3.0/24`) idú na Router Gießen v jeho centrálnej sieti — teda **Ďalší hop** `10.19.0.3`, **Iface** `eth0`. Podľa tohto vzoru potrebuje každý smerovač tri trasy.
</details>

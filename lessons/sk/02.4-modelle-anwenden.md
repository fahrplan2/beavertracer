# Použitie modelov

Priraď protokoly z experimentu na začiatku kapitoly k ich vrstve OSI:

:::quiz match
Ethernet -> Vrstva 2 — Linková
IPv4 -> Vrstva 3 — Sieťová
TCP -> Vrstva 4 — Transportná
HTTP -> Vrstva 7 — Aplikačná
:::

:::evaluate
Skontrolovať priradenie
:::

A nakoniec názvy dátových jednotiek:

:::quiz match
Rámec -> Vrstva 2 — Linková
Paket -> Vrstva 3 — Sieťová
Segment -> Vrstva 4 — Transportná
:::

:::evaluate
Skontrolovať priradenie
:::

Teraz máš nástroje na to, aby si protokoly odteraz správne zaraďoval. Od ďalšej kapitoly prejdeme vrstvy postupne — začneme vrstvou 2 a otázkou, ako switch vlastne vie, kam má paket preposlať.

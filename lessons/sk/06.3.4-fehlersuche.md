# Hľadanie chýb: Mail nedorazí

:::sim
url=/sims/lesson-6.3.4.btsim
:::

Anna hlási: „Nemôžem poslať Benovi mail!“ Takto *má* byť všetko nastavené:

| Čo | Má byť |
|---|---|
| Annin odchádzajúci server (SMTP) | `mail.beaver-schule.de`, port `25` |
| MX záznam domény `biber-mail.de` | `mail.biber-mail.de` (priorita 10) |

Nájdi chyby a oprav ich. Potom pošli Anne mail na adresu `ben@biber-mail.de` — úloha skontroluje, či dorazil do Benovej poštovej schránky. (Preposielanie medzi poštovými servermi môže trvať niekoľko sekúnd.)

<details>
<summary>Tip 1: Čo hovorí Annin e-mailový program?</summary>

Skús odoslať mail a pozri sa na kartu **Protokol**. Čo odpovedá server — znie to ako SMTP?
</details>

<details>
<summary>Tip 2: Mail sa vráti ako chybové hlásenie?</summary>

Stiahni u Anny poštu a prečítaj si správu od `MAILER-DAEMON`. Prečo zlyhalo doručenie? Pomocou `nslookup -type=MX biber-mail.de` na Annin PC zisti, či DNS server pozná príslušný poštový server.
</details>

<details>
<summary>Tip 3: Kde sa to nastavuje?</summary>

Odchádzajúci server nastavíš v Annej aplikácii **E-Mail** v časti **Einstellungen**. MX záznamy nájdeš v **DNS-Server** na karte **MX**.
</details>

:::task
title: Mail dorazil?
Skontroluje, či sa v Benovej poštovej schránke na Mailserver Biber nachádza mail.
check: fileExists(5, "/var/mail/ben.mbox")
:::

## Čo sa dialo?

:::quiz multi
Ktoré tvrdenia sú pravdivé?
- [x] Annin odchádzajúci server mieril na port 110 — tam odpovedá služba POP3, nie SMTP
- [x] Pre `biber-mail.de` chýbal MX záznam — Mailserver Schule nenašiel príslušný poštový server
- [x] Nedoručiteľný mail sa vrátil ako chybové hlásenie od `MAILER-DAEMON`
- [ ] Benovo heslo bolo nesprávne
:::

:::evaluate
Skontrolovať odpoveď
:::

:::tip Zapamätaj si
Typické chyby pri e-maile: nesprávny **server alebo port** v e-mailovom programe (SMTP beží na porte 25, POP3 na 110, IMAP na 143) a chýbajúci alebo nesprávny **MX záznam** v DNS. Ak poštový server nemôže mail doručiť, pošle ho späť odosielateľovi s chybovým hlásením (**bounce**).
:::

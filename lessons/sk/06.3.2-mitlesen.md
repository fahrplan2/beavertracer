# Čítanie e-mailu v tracere

:::sim
url=/sims/lesson-6.3.btsim
:::

Rovnako ako HTTP je aj SMTP **textový protokol**. Pozri sa, čo všetko putuje po linke v čistom texte.

## Experiment

1. V :fa-play: režime **Spustiť** pošli, rovnako ako na predchádzajúcej stránke, e-mail od **Anna** na adresu `ben@biber-mail.de`.
2. V :fa-magnifying-glass: režime **Stopa** otvor trace pre **Anna**. V stĺpci **Info** nájdeš SMTP dialóg: riadky s `C:` posiela klient, riadky s `S:` server.

:::quiz short
Aká adresa je za `MAIL FROM:`?
= anna@beaver-schule.de
= <anna@beaver-schule.de>
:::

:::quiz short
A aká je za `RCPT TO:`?
= ben@biber-mail.de
= <ben@biber-mail.de>
:::

:::quiz mc
Aký číselný kód pošle server, keď príkaz prijme?
- [x] `250`
- [ ] `200`
- [ ] `404`
:::

:::evaluate
Skontrolovať odpovede
:::

## A heslo?

Pred `MAIL FROM` sa program Annu prihlási pomocou `AUTH PLAIN` a reťazca znakov ako `AGFubmEAZ2VoZWlt`. Vyzerá to zašifrovane, ale nie je: je to len **Base64**, kódovanie, ktoré dokáže ktokoľvek okamžite previesť späť — je v ňom ukryté `anna` a jej heslo `geheim`.

Teraz si pri **Ben** vyzdvihni poštu (**Stiahnuť**) a otvor trace pre **Ben**. Pri vyzdvihnutí cez IMAP je to vidieť ešte zreteľnejšie:

:::quiz short
Aké heslo posiela e-mailový program Bena na server v čistom texte? (Pozri sa na riadok s `LOGIN`.)
= biber123
:::

:::evaluate
Skontrolovať odpoveď
:::

:::warning
Bez šifrovania môže každý, kto zachytáva dátovú prevádzku, čítať **obsah, odosielateľa, príjemcu a heslá**. Preto sa dnes používajú šifrované varianty (napr. SMTP so STARTTLS, IMAPS na porte 993). Ako to funguje, sa dozvieš v kapitole 8.
:::

:::tip Zapamätaj si
**SMTP**, **POP3** a **IMAP** sú textové protokoly: príkazy ako `MAIL FROM`, `RCPT TO`, `DATA` (SMTP) alebo `LOGIN` (IMAP) a odpovede sú čitateľné. Bez šifrovania putujú po linke v čistom texte (alebo len zakódované pomocou Base64) aj **heslá**.
:::

# Digitálne podpisy

Šifrovaním dosiahneme **dôvernosť**, pomocou hashov rozpoznáme zmeny. Ako však dokázať, **od koho** správa pochádza? Na papieri sa podpisujeme. V sieti na to slúži **digitálny podpis**.

## Pár kľúčov použitý naopak

Pri šifrovaní používa odosielateľ **verejný** kľúč príjemcu. Pri podpise je to naopak: odosielateľ používa **svoj vlastný súkromný** kľúč. Keďže tento kľúč vlastní len on, len on môže vytvoriť tento podpis. Overiť ho však môže každý — pomocou **verejného** kľúča odosielateľa.

**Podpisovanie** (Anna podpisuje zmluvu):

1. Anna vypočíta **hash** zmluvy.
2. Hash spracuje so svojím **súkromným kľúčom**. Výsledkom je **podpis**.
3. Zmluvu spolu s podpisom pošle Benovi.

**Overovanie** (Ben kontroluje podpis):

1. Ben si sám vypočíta hash prijatej zmluvy.
2. Skontroluje podpis pomocou Anninho **verejného kľúča**: Zodpovedá tento podpis danému hashu?
3. Ak zodpovedá, Ben vie dve veci:
    - Zmluva skutočne pochádza od Anny — súkromný kľúč má iba ona (**autenticita**).
    - Zmluva sa počas prenosu nezmenila — inak by mala iný hash (**integrita**).

:::note
Prečo Anna podpisuje iba hash a nie celú zmluvu? Asymetrické postupy sú pomalé. Hash je vždy krátky — bez ohľadu na to, či má zmluva jednu stranu alebo tisíc strán.
:::

:::quiz mc
Akým kľúčom Anna **vytvára** svoj podpis?
- [x] Svojím súkromným kľúčom
- [ ] Svojím verejným kľúčom
- [ ] Benovým verejným kľúčom
:::

:::quiz mc
Akým kľúčom Ben **overuje** podpis?
- [ ] Svojím súkromným kľúčom
- [x] Anniným verejným kľúčom
- [ ] Anniným súkromným kľúčom
:::

:::quiz mc
Útočník zachytí zmluvu a zmení sumu. Podpis nechá tak, ako je. Čo sa stane pri Benovej kontrole?
- [x] Overenie zlyhá, pretože zmenená zmluva má iný hash
- [ ] Overenie prebehne úspešne, pretože podpis je predsa pravý
- [ ] Ben podpis vôbec nemôže overiť, pretože nepozná Annin súkromný kľúč
:::

:::quiz match
Napísať Benovi dôverne -> zašifrovať Benovým verejným kľúčom
Prečítať zašifrovanú správu -> dešifrovať vlastným súkromným kľúčom
Podpísať dokument -> vlastným súkromným kľúčom
Overiť podpis -> verejným kľúčom odosielateľa
:::

Skontrolovať priradenie
:::

:::tip Zapamätaj si
**Digitálny podpis** vytvorí odosielateľ z **hashu** správy a svojho **súkromného kľúča**. Každý ho môže overiť pomocou **verejného kľúča** odosielateľa. Platný podpis dokazuje, **od koho** správa pochádza (**autenticita**) a že **nebola zmenená** (**integrita**).
:::

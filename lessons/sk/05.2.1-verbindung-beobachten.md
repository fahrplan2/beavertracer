# Spojenie od začiatku do konca

:::sim
url=/sims/lesson-5.1.btsim
:::

Na **Serveri** beží služba Echo na porte `5000`: každú správu okamžite pošle späť. Pomocou **Jednoduchého TCP klienta** môžeš riadiť spojenie krok za krokom — každé tlačidlo je jedna fáza.

## Experiment

1. Prepni sa do režimu :fa-play: **Spustiť**, klikni na **Client-PC** a otvor **Jednoduchý TCP klient**.
2. Do poľa **Host** zadaj `192.168.0.20` a do poľa **Port** zadaj `5000`.
3. Klikni na **Pripojiť**.
4. Do poľa pre správu napíš `Hello World` a klikni na **Odoslať**. V okne chatu hneď potom uvidíš echo servera.
5. Klikni na **Odpojiť**.
6. Prepni sa do režimu :fa-magnifying-glass: **Stopa** a pomocou **+** otvor trace pre **Client-PC**, rozhranie `eth0`.

:::note
Dva ARP pakety na začiatku už poznáš z kapitoly 1. V stĺpci **Info** pri paketoch TCP je najprv `49152 → 5000` (z ktorého portu na ktorý port), potom v hranatých zátvorkách **flagy** a za nimi čísla ako `Seq=`, `Ack=` a `Len=`. Číslam sa budeme venovať od strany 5.2.3 — tu sa sústreď na flagy a `Len`.
:::

## Fáza 1: Pripojiť

:::quiz short
Koľko TCP paketov sa vymenilo po tom, čo si klikol na **Pripojiť** — predtým, než sa odoslala tvoja správa?
= 3
= tri
:::

:::quiz mc
Kto posiela prvý paket s `[SYN]`?
- [x] Client-PC
- [ ] Server
:::

:::quiz mc
S akými flagmi na to server odpovie?
- [ ] `[SYN]`
- [x] `[SYN, ACK]`
- [ ] `[ACK]`
- [ ] `[FIN, ACK]`
:::

## Fáza 2: Odoslať

`Len` udáva, koľko bajtov užitočných dát paket nesie.

:::quiz short
Koľko bajtov nesie paket s tvojou správou (`Len`)?
= 13
:::

:::note
`Hello World` má len 11 znakov. TCP klient však pripojí koniec riadka (2 bajty, `\r\n`) — tak to očakáva veľa internetových protokolov, napríklad SMTP alebo HTTP.
:::

:::quiz mc
Čo server pošle späť hneď po tvojej správe — ešte pred echom?
- [x] Paket s `[ACK]` a `Len=0` — potvrdenie bez dát
- [ ] Vôbec nič
- [ ] Nový `[SYN]`
:::

## Fáza 3: Odpojiť

:::quiz short
Koľko paketov patrí k ukončeniu spojenia — od prvého paketu s `FIN`?
= 4
= štyri
:::

:::quiz mc
Čo oznamuje strana pomocou `FIN`?
- [x] „Som hotová“ — už neposiela žiadne dáta
- [ ] „Vyskytla sa chyba“
- [ ] „Prichádzajú nové dáta“
:::

:::evaluate
Skontrolovať odpovede
:::

## Kde sa skrývajú štyri úlohy?

Priraď, kde v trace nájdeš úlohy z oddielu 5.1:

:::quiz match
Nadviazanie spojenia -> Tri pakety [SYN], [SYN, ACK] a [ACK]
Spoľahlivý prenos -> Pakety s [ACK] a Len=0, ktoré potvrdzujú prijatie
Ukončenie spojenia -> Pakety s FIN a ich potvrdenia
Multiplexovanie -> Čísla portov 49152 → 5000 pred hranatými zátvorkami
:::

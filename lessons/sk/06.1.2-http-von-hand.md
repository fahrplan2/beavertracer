# HTTP ručne

:::sim
url=/sims/lesson-6.1.btsim
:::

Ak je HTTP čistý text — dá sa potom rozprávať s webovým serverom aj sám, úplne bez prehliadača? Áno: pomocou `telnet` nadviažeš TCP spojenie s ľubovoľným portom a text napíšeš sám.

## Experiment

1. Prepni do :fa-play: režimu spustenia **Spustiť** a na **Client-PC** otvor :fa-terminal: **Terminál**.
2. Pripoj sa k portu 80 servera:
   ```
   $ telnet 192.168.0.20 80
   ```
3. Napíš požiadavku riadok po riadku — a ukonči ju **prázdnym riadkom** (stačí ešte raz stlačiť **Enter**):
   ```
   GET /kontakt.html HTTP/1.1
   Host: 192.168.0.20

   ```

Server odpovie stavovým riadkom, hlavičkami a stránkou s kontaktmi — ako text, presne tak, ako ho dostane prehliadač.

:::quiz mc
Podľa čoho server pozná, že tvoja požiadavka skončila?
- [ ] Podľa špeciálneho príkazu `END`
- [x] Podľa prázdneho riadka
- [ ] Po uplynutí určitého času
:::

:::quiz short
Aká hodnota je v odpovedi v hlavičke `Content-Type`? (len prvá časť pred `;`)
= text/html
:::

Skontrolovať odpovede
:::

## Vyvolanie chýb

Pohodlnejší nástroj je `curl`: požiadavku vytvorí za teba. S prepínačom `-v` (*verbose*, podrobne) pritom zobrazí všetko, čo sa posiela tam a späť — riadky so znakom `>` odoslal `curl`, riadky so znakom `<` prišli zo servera.

Vyskúšaj:

```
$ curl -v http://192.168.0.20/gibtsnicht.html
$ curl -X POST -d name=Anna http://192.168.0.20/
```

:::quiz short
Aký stavový kód dostaneš pre `/gibtsnicht.html`?
= 404
:::

:::quiz short
A aký pre požiadavku s metódou `POST`?
= 405
:::

:::evaluate
Skontrolovať odpovede
:::

:::note
Webový server v BeaverTracer vie iba odovzdávať súbory — preto povoľuje len `GET` a `HEAD`. Skutočné webové servery prijímajú pomocou `POST` napríklad formuláre a dáta posúvajú ďalej programu.
:::

:::tip Zapamätaj si
Mnohé protokoly aplikačnej vrstvy sú **textové** — HTTP, ale aj SMTP, POP3 a IMAP. Preto sa s nimi dá rozprávať ručne pomocou `telnet` a v Tracer ich môžeš čítať. Je to praktické pri hľadaní chýb — ale aj bezpečnostný problém: Každý, kto komunikáciu odchytáva, si môže prečítať všetko. Ako pomáha šifrovanie (HTTPS), sa dozvieš v kapitole 8.
:::

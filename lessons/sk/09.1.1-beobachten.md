# Pozorovanie firewallu

:::sim
url=/sims/lesson-9.1.1.btsim

V tejto simulácii už niekto zadal do firewallu tri pravidlá. Klikni na **Firewall** a pozri si kartu **Regeln**. **Port A** firewallu je pripojený k internetu, **Port B** k školskému smerovaču — „A → B“ teda znamená „z internetu do školskej siete“.

:::quiz table
| Pravidlo | Smer | Protokol | Cieľový port | Akcia |
|---|---|---|---|---|
| 1 | A → B | {TCP} | {22} | {Zahodiť} |
| 2 | A → B | TCP | {110} | {Odmietnuť} |
| 3 | A → B | {ICMP} | ľubovoľný | Zahodiť |
:::

:::evaluate
Skontrolovať tabuľku
:::

## Ping zvonku

Prepni sa do režimu :fa-play: **Spustiť** a z **Internet-PC** pošli ping na školský server:

```
$ ping -c 2 198.51.100.10
```

Potom vo firewalle otvor kartu **Protokoll**.

:::quiz mc
Čo hlási `ping`?
- [x] `Anfrage abgelaufen` — nevráti sa vôbec nič
- [ ] `Paket gefiltert`
- [ ] Dve odpovede od školského servera
:::

:::quiz short
Akým slovom začínajú nové riadky v protokole firewallu?
= DROP
:::

:::evaluate
Skontrolovať odpovede
:::

## Skenovanie portov: zahodené alebo odmietnuté?

Teraz cielene naskenuj päť portov. Port 3306 (databáza) na školskom serveri vôbec nebeží.

```
$ nmap -p 22,25,80,110,3306 198.51.100.10
```

:::quiz match
22 (zahodený) -> filtered
25 (povolený, služba beží) -> open
110 (odmietnutý) -> closed
3306 (povolený, žiadna služba) -> closed
:::

:::evaluate
Skontrolovať priradenie
:::

:::quiz multi
Čo môže útočník vyvodiť z výsledku?
- [x] Pri `filtered` vie: Je tam firewall, ktorý pakety pohlcuje
- [x] Pri `closed` nedokáže rozlíšiť, či firewall odmieta, alebo jednoducho nebeží žiadna služba
- [ ] Pri `filtered` vie, aká služba beží za portom
- [ ] Pri `closed` je služba napriek tomu dostupná
:::

:::evaluate
Skontrolovať odpovede
:::

Nakoniec si pozri stĺpec **Treffer** v zozname pravidiel: Firewall tam počíta, koľko paketov už každé pravidlo rozhodlo. Hodnota vedľa **Standardrichtlinie** počíta všetky pakety, na ktoré nepasovalo žiadne pravidlo.

:::tip Zapamätaj si
**Zahodené** pakety zmiznú bez stopy: `ping` hlási timeout, `nmap` hlási `filtered`. **Odmietnuté** pakety firewall zodpovie odmietnutím (pri TCP je to RST) — zvonku to vyzerá ako zatvorený port. **Protokoll** firewallu ukazuje, ktoré pakety zastavil, stĺpec **Treffer**, ktoré pravidlo zabralo.
:::

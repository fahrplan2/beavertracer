## Ako vyzerá požiadavka

V trace klikni na paket `GET / HTTP/1.1` a rozbaľ **Hypertext Transfer Protocol**. HTTP požiadavka je čistý text:

```
GET / HTTP/1.1              ← Methode, Pfad, Version
Host: 192.168.0.20          ← Header: zusätzliche Angaben
…
                            ← Leerzeile: Ende der Anfrage
```

Odpoveď servera je postavená rovnako — so stavovým riadkom, hlavičkami, prázdnym riadkom a potom samotným súborom:

```
HTTP/1.1 200 OK             ← Version, Statuscode, Text
Content-Type: text/html     ← Header: Art der Datei
Content-Length: 301         ← Header: Größe in Byte
                            ← Leerzeile
<!doctype html> …           ← die Datei selbst
```

:::seq
mode: text
Client-PC -> Server: GET / | HTTP-Anfrage
Server -> Client-PC: 200 OK | index.html
Client-PC -> Server: GET /style.css | HTTP-Anfrage
Server -> Client-PC: 200 OK | style.css
:::

## Metódy a stavové kódy

**Metóda** hovorí, čo klient chce:

| Metóda | Význam |
|---|---|
| **GET** | stiahnuť súbor |
| **POST** | poslať dáta na server, napr. vyplnený formulár |
| **HEAD** | stiahnuť iba hlavičky, bez súboru |

**Stavový kód** hovorí, ako to dopadlo. Prvá číslica prezrádza druh odpovede:

| Kód | Text | Význam |
|---|---|---|
| **200** | OK | všetko v poriadku |
| **301** | Moved Permanently | stránka sa trvalo presťahovala |
| **404** | Not Found | súbor neexistuje |
| **405** | Method Not Allowed | táto metóda tu nie je povolená |
| **500** | Internal Server Error | chyba na serveri |

`2xx` znamená úspech, `3xx` presmerovanie, `4xx` chybu klienta (nesprávna požiadavka), `5xx` chybu servera.

:::tip Zapamätaj si
**HTTP** pracuje podľa **princípu požiadavky a odpovede**: Klient pošle **požiadavku** (metóda ako `GET`, cesta, hlavičky), server odpovie **stavovým kódom** (napr. `200 OK`, `404 Not Found`), hlavičkami a súborom. Pre každý súbor webovej stránky existuje samostatná požiadavka.
:::

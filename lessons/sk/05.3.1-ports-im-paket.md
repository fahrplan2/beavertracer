## Experiment

1. Prepni sa do režimu spustenia (:fa-play: **Spustiť**), klikni na **Client-PC** a otvor :fa-globe: **Prehliadač**. Zadaj adresu `http://192.168.0.20/`.
2. Klikni hore v okne na **Zurück**, otvor **Jednoduchý TCP klient** a pripoj ho k `192.168.0.20`, port `5000`. Spojenie nechaj otvorené.
3. Prepni sa do režimu :fa-magnifying-glass: **Stopa**, otvor trace pre **Client-PC** a klikni na paket s `[SYN]`. Rozbaľ **Transmission Control Protocol**.

Úplne hore v hlavičke TCP sú dva porty: **Source Port** (zdrojový port) a **Destination Port** (cieľový port).

| Spojenie | Zdrojový port | Cieľový port |
|---|---|---|
| Prehliadač → webový server | {49152} | {80} |
| TCP klient → služba Echo | {49153} | {5000} |
:::

## Dva druhy portov

**Cieľový port — služba:** Serverový program čaká na spojenia na pevnom porte — hovorí sa, že na ňom **počúva**. Pre známe služby sú čísla určené celosvetovo, ide o **well-known porty** (0 až 1023). Prehliadač preto vie bez pýtania: webové servery počúvajú na porte 80.

**Zdrojový port — odosielateľ:** Port na strane klienta si pre každé nové spojenie sám vyberie operačný systém z vysokého rozsahu (v BeaverTracer od 49152). Podľa neho klient pozná, ku ktorému z jeho spojení patrí odpoveď.

Spojenie je teda jednoznačne určené štyrmi údajmi: **IP adresou a portom na oboch stranách**. Dvojica IP adresy a portu sa nazýva **socket**, napr. `192.168.0.20:80`.

## Pohľad na server

Prepni sa späť do režimu spustenia (:fa-play: **Spustiť**), na **Server** otvor :fa-terminal: **Terminál** a zadaj:

```
$ ss
```

`ss` zobrazí všetky sockety počítača. Riadky s `LISTEN` sú programy, ktoré počúvajú na nejakom porte. Riadky s `ESTABLISHED` sú existujúce spojenia — s vlastným socketom (*Local Address:Port*) a socketom protistrany (*Peer Address:Port*).

:::quiz multi
Na ktorých portoch počúva server?
- [x] 80
- [x] 5000
- [ ] 49152
- [ ] 443
:::

:::quiz mc
Ktoré spojenie zobrazuje `ss` ako `ESTABLISHED`?
- [x] `192.168.0.20:5000` s `192.168.0.10:49153` — otvorené spojenie TCP klienta
- [ ] `192.168.0.20:80` s `192.168.0.10:49152` — spojenie prehliadača
- [ ] Obe
:::

:::note
Spojenie prehliadača je už zrušené — po načítaní stránky bolo ukončené pomocou `FIN`. `ss` ho ešte chvíľu zobrazuje ako `TIME-WAIT`: server nejaký čas čaká, či ešte nedorazia oneskorené pakety tohto spojenia. Spojenie TCP klienta je naopak ešte otvorené, pretože si zatiaľ neklikol na **Odpojiť**.
:::

## Najdôležitejšie well-known porty

| Port | Protokol | Služba |
|---|---|---|
| 22 | SSH | zabezpečená vzdialená správa (šifrovaný príkazový riadok) |
| 25 | SMTP | odosielanie e-mailov |
| 53 | DNS | prekladanie mien na IP adresy (väčšinou cez UDP) |
| 80 | HTTP | webové stránky |
| 110 | POP3 | sťahovanie e-mailov |
| 143 | IMAP | správa e-mailov na serveri |
| 443 | HTTPS | šifrované webové stránky |

:::tip Zapamätaj si
**Porty** (0 až 65535) rozlišujú spojenia na jednom počítači. Serverové služby **počúvajú** na pevných **well-known portoch** (napr. HTTP 80, HTTPS 443), klienti dostanú pre každé spojenie voľný vysoký **zdrojový port**. Spojenie je jednoznačne určené **IP adresou a portom oboch strán**.
:::

:::quiz match

:::

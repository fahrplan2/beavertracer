# Hľadanie chýb: Kontaktná stránka chýba

:::sim
url=/sims/lesson-6.1.3.btsim
:::

Sekretariát hlási: „Na našej webovej stránke vedie odkaz **Kontakt** už iba na chybové hlásenie.“ Kontaktná stránka má byť dostupná na adrese `http://192.168.0.20/kontakt.html`. Nájdi chybu a odstráň ju.

<details>
<summary>Tip 1: Čo hlási server?</summary>

Otvor kontaktnú stránku v prehliadači alebo pomocou `curl -v`. Aký stavový kód sa vráti? Chybová stránka prezrádza aj to, kde server súbor hľadal.
</details>

<details>
<summary>Tip 2: Kde sú súbory?</summary>

Webový server poskytuje iba súbory zo svojho **koreňa dokumentov** (*Document Root*) — nájdeš ho v aplikácii **HTTP server**. Na **Serveri** si v termináli pomocou `ls` pozri, čo sa tam nachádza, a kontaktnú stránku hľadaj aj v `/home`.
</details>

<details>
<summary>Tip 3: Presunutie súboru</summary>

Pomocou `mv` presunieš súbor: `mv <zdroj> <cieľový priečinok>`.
</details>

:::task
title: Je kontaktná stránka opravená?
Kontroluje, či sa kontaktná stránka nachádza v koreni dokumentov webového servera.
check: fileExists(2, "/var/www/kontakt.html")
:::

## Čo sa stalo?

:::quiz multi
Ktoré tvrdenia sú pravdivé?
- [x] Server odpovedal `404 Not Found`
- [x] Súbor bol v `/home` namiesto v koreni dokumentov `/var/www`
- [ ] Webový server vôbec nebol spustený
- [ ] Prehliadač použil nesprávnu IP adresu
:::

:::evaluate
Skontrolovať odpoveď
:::

:::tip Zapamätaj si
**404** znamená: webový server beží a je dostupný, ale požadovaný **súbor** na tejto ceste neexistuje. Server hľadá iba vo svojom **koreni dokumentov** (*Document Root*, tu `/var/www`). Porovnaj: ak server neodpovedá vôbec alebo odpovedá `RST`, problém je hlbšie — v sieti alebo v samotnej službe (kapitola 5.3.2).
:::

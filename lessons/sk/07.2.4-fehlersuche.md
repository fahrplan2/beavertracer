# Hľadanie chýb: Včera to ešte fungovalo

:::sim
url=/sims/lesson-7.2.4.btsim
:::

Včera bol domáci webový server dostupný zvonku — presmerovanie portov `TCP 80 → 192.168.178.10:80` je nastavené. Po dnešnom ranajšom výpadku prúdu sa Clara na stránku už nedostane. Nájdi chybu a oprav ju natrvalo.

<details>
<summary>Tip 1: Kam ukazuje pravidlo?</summary>

Porovnaj LAN IP v **Port FW** domáceho smerovača s adresou, ktorú má **Heim-Webserver** práve teraz (:fa-gear: **Nastavenia IP**).
</details>

<details>
<summary>Tip 2: Prečo má inú adresu?</summary>

Je Heim-Webserver nastavený na **DHCP**? Potom po každom reštarte dostane nejakú voľnú adresu z rozsahu domáceho smerovača (na karte **DHCP**). Ako zabezpečíš, aby mal vždy rovnakú adresu?
</details>

:::task
title: Je domáci webový server opäť dostupný?
Skontroluje, či má domáci webový server svoju pevnú adresu a či sa k nemu Clara dostane cez presmerovanie portov. Simulácia musí na to bežať v režime spustenia.
check: ip(11, "192.168.178.10/32")
check: tcpOpen(12, "203.0.113.2", 80)
:::

## Čo sa stalo?

:::quiz multi
Ktoré tvrdenia sú pravdivé?
- [x] Domáci webový server získal adresu cez DHCP a po reštarte mal inú
- [x] Presmerovanie portov preto ukazovalo na adresu, na ktorej už žiadny server nebežal
- [x] Pevná adresa mimo rozsahu DHCP rieši problém natrvalo
- [ ] Poskytovateľ zablokoval WAN adresu
:::

:::evaluate
Skontrolovať odpoveď
:::

:::tip Zapamätaj si
Zariadenia, na ktoré ukazuje **presmerovanie portov** (servery, tlačiarne, kamery), potrebujú **pevnú adresu**: buď zadanú staticky a **mimo rozsahu DHCP**, alebo ako pevné priradenie v DHCP serveri smerovača. Inak môžu po reštarte dostať inú adresu — a pravidlo skončí v prázdne.
:::

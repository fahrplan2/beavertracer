# Zobrazenie certifikátu

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Na pracovnej ploche vidíš **Client-PC**, **DNS-Server** a webový server školy `www.beaver-schule.de`. Webový server ponúka svoje stránky aj cez **HTTPS**.

## Zámok v prehliadači

1. Prepni sa do :fa-play: režimu spustenia, klikni na **Client-PC** a otvor :fa-globe: **Prehliadač**.
2. Otvor `https://www.beaver-schule.de/` — všimni si **https**.
3. Vľavo vedľa adresy sa zobrazí **zámok**. Klikni naň.

:::quiz short
Pre aké meno bol certifikát vystavený (predmet bez `CN=`)?
= www.beaver-schule.de
:::

:::quiz short
Kto certifikát vystavil (vydavateľ bez `CN=`)?
= Biber Root CA
:::

:::evaluate
Skontrolovať odpovede
:::

## Prečo Client-PC certifikátu dôveruje?

Na **Client-PC** otvor :fa-shield-halved: **Správu certifikátov** a prepni sa na kartu **Dôveryhodné CA**.

:::quiz mc
Čo tam nájdeš?
- [x] Certifikát **Biber Root CA**
- [ ] Certifikát `www.beaver-schule.de`
- [ ] Žiadne záznamy
:::

:::quiz mc
Ako poznáš, že Biber Root CA je koreňová CA (Root-CA)?
- [x] Je **self-signed** (podpísaná sama sebou): predmet a vydavateľ sú rovnaké
- [ ] Jej názov končí na „CA“
- [ ] Nemá verejný kľúč
:::

:::quiz mc
Je pri Client-PC pod položkou **Súkromný kľúč** uvedené „Áno“ alebo „Nie“?
- [ ] Áno — klient potrebuje súkromný kľúč CA na overovanie podpisov
- [x] Nie — na overenie stačí verejný kľúč; súkromný kľúč má iba CA
:::

:::evaluate
Skontrolovať odpovede
:::

## Druhá strana: webový server

Teraz na webovom serveri **www.beaver-schule.de** otvor :fa-shield-halved: **Správu certifikátov** (karta **Moje certifikáty**) a pozri si jeho certifikát.

:::quiz multi
Čo platí pre certifikát na webovom serveri?
- [x] Pod položkou **Súkromný kľúč** je uvedené „Áno“ — server ho potrebuje na nadviazanie spojenia
- [x] **Reťazec** znie `www.beaver-schule.de ← Biber Root CA`
- [x] **Odtlačok** je rovnaký ako v okne zámku v prehliadači
- [ ] Je self-signed (podpísaný sám sebou)
:::

:::evaluate
Skontrolovať odpovede
:::

:::note
**Odtlačok** je hašová hodnota certifikátu. Vďaka nemu možno dva certifikáty rýchlo porovnať — bez toho, aby si musel kontrolovať každé pole zvlášť.
:::

:::tip Zapamätaj si
**Webový server** má svoj certifikát **so súkromným kľúčom**. **Klient** pozná iba **certifikát koreňovej CA** (bez súkromného kľúča) — to mu stačí na overenie podpisu na certifikáte servera. Keď v prehliadači klikneš na **zámok**, uvidíš predmet, vydavateľa, odtlačok a platnosť.
:::

# HTTP a HTTPS v porovnaní

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Webový server **www.beaver-schule.de** ponúka školský portál so známkami cez HTTP aj cez HTTPS. Čo vidí odpočúvač?

## Experiment

1. Prepni sa do :fa-play: režimu spustenia (**Spustiť**) a na **Client-PC** v :fa-globe: **Prehliadači** najprv otvor `http://www.beaver-schule.de/`, potom `https://www.beaver-schule.de/`.
2. V režime :fa-magnifying-glass: **Stopa** otvor trace pre **Client-PC**.
3. Najprv nájdi paket `HTTP/1.1 200 OK` a klikni naň. Dole v detailoch nájdeš obsah stránky.

:::quiz mc
Čo môže odpočúvač vidieť pri **HTTP**?
- [x] Celú webovú stránku vrátane Anninych známok
- [ ] Iba adresu servera
- [ ] Nič, pretože HTTP beží cez TCP
:::

:::quiz short
Akú známku má Anna z matematiky?
= 2
:::

:::evaluate
Skontrolovať odpovede
:::

Teraz časť s HTTPS. Nájdi paket `[SYN]`, ktorým klient začína druhé spojenie.

:::quiz short
Aký cieľový port má spojenie HTTPS (stĺpec **Info**, `… → ???`)?
= 443
:::

Teraz zadaj hore do poľa filtra v trace `tls` — potom uvidíš už iba pakety TLS.

:::quiz mc
Čo je v stĺpci **Info** pri paketoch, ktoré obsahujú webovú stránku?
- [ ] `HTTP/1.1 200 OK`
- [x] `Application Data`
- [ ] `Encrypted HTML`
:::

:::quiz multi
Čo môže odpočúvač pri **HTTPS** napriek tomu stále vidieť?
- [x] IP adresy klienta a servera
- [x] Že sa používa port 443, teda pravdepodobne HTTPS
- [x] Približne koľko dát sa prenáša
- [ ] Ktorá stránka bola otvorená a čo na nej je
:::

:::evaluate
Skontrolovať odpovede
:::

:::note
Klikni na paket **Application Data**: Užitočné dáta sú len postupnosťou zdanlivo náhodných bajtov. Tracer ich nedokáže dešifrovať — relačný kľúč pozná rovnako málo ako útočník.
:::

:::tip Zapamätaj si
Pri **HTTP** môže každý odpočúvač prečítať celú webovú stránku. Pri **HTTPS** vidí už len to, **kto s kým** komunikuje (IP adresy, port 443) a **koľko** dát sa prenáša — obsah je zašifrovaný v paketoch **Application Data**.
:::

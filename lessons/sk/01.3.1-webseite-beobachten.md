# Otvorenie webovej stránky a jej pozorovanie

V tejto časti si nič nestavaš sám: na pracovnej ploche je pripravená simulácia s **Client-PC** a **Webserver**.

## Otvorenie stránky

1. Prepni sa do režimu :fa-play: **Spustiť**.
2. Na **Client-PC** otvor aplikáciu :fa-globe: **Prehliadač** a zadaj adresu webservera: `http://192.168.0.20/`.
3. Prepni sa do režimu :fa-magnifying-glass: **Stopa** a pomocou **+** otvor trace pre **Client-PC**, port `eth0` — presne ako pri príkaze ping.

:::note
Na jedno jediné otvorenie stránky je to prekvapivo veľa paketov — výrazne viac ako pri príkaze ping. Načítanie webovej stránky je viacstupňový proces, nie jedna samostatná akcia.
:::

## Čítanie zoznamu paketov

Zatiaľ nemusíš presne vedieť, čo jednotlivé protokoly robia. Všetko, čo potrebuješ na nasledujúce otázky, nájdeš v stĺpcoch **Protokol** a **Info**.

:::quiz mc
Ktorý protokol je úplne hore v zozname?
- [x] ARP
- [ ] TCP
- [ ] HTTP
:::

:::quiz short
Spočítaj: Koľko paketov **TCP** je pred prvým paketom **HTTP**?
= 3
= tri
:::

:::quiz mc
Čo odpovedá webový server na požiadavku prehliadača? Pozri sa do stĺpca Info druhého paketu HTTP.
- [ ] GET / HTTP/1.1
- [x] HTTP/1.1 200 OK
- [ ] 404 Not Found
:::

:::evaluate
Skontrolovať odpovede
:::

## Pomenovanie zúčastnených protokolov

Z tvojich pozorovaní sa teraz dá vyčítať, ktorý protokol bol za čo zodpovedný.

:::tip Tip
Prečítaj si ešte raz stĺpce **Info**: `Who has …?`, `[SYN]`, `[SYN, ACK]`, `[ACK]`, `GET /` a `200 OK` už prezrádzajú takmer všetko.
:::

:::quiz match
ARP -> Pýta sa všetkých v sieti: „Kto má IP adresu 192.168.0.20?“
TCP -> Pomocou troch krátkych paketov nadviaže spojenie skôr, ako začnú prúdiť dáta
HTTP -> Vyžiada webovú stránku (GET) a pošle ju späť (200 OK)
:::

:::evaluate
Skontrolovať priradenie
:::

:::tip Zapamätaj si
Otvorenie webovej stránky prebieha v krokoch: najprv server v sieti **nájsť** (ARP), potom **nadviazať** spojenie (TCP), potom stránku **vyžiadať a doručiť** (HTTP) — a nakoniec spojenie zase **ukončiť** (pakety TCP s `[FIN]` na konci zoznamu).
:::

:::note
Tentoraz si zadal IP adresu servera priamo, preto sa **DNS** („preklad“ mien ako `www.beispiel.de` na IP adresu) zatiaľ nepoužilo. Doženieme to v kapitole 6.
:::

Všimol si, že protokoly v štruktúre paketu majú farebné značky s číslami? Čo to znamená, objasníme v kapitole 2. Tam sa pozrieme na to, ako sa dajú mnohé protokoly systematicky zaradiť — pomocou referenčných modelov OSI a TCP/IP. Tým je kapitola 1 hotová.

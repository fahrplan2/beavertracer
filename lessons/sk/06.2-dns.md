# DNS: názvy namiesto čísel

:::goal
**Cieľ učenia:** Vieš vysvetliť, ako DNS prekladá názvy na IP adresy, ako sú názvy hierarchicky usporiadané, vieš si sám vytvoriť záznam a nájsť typické chyby DNS.
:::

:::sim
url=/sims/lesson-6.2.btsim
:::

IP adresy si dokáže zapamätať len málokto — názvy ako `www.beaver-schule.de` však áno. Preklad zabezpečuje **Domain Name System** (**DNS**), akýsi celosvetový telefónny zoznam internetu.

Na pracovnej ploche je teraz o niečo väčšia sieť: okrem **Client-PC** a **Webserver** tu nájdeš štyri **DNS-Server**y. Načo je ich toľko, uvidíš o stranu ďalej.

# IPv6 v sieti

:::sim
url=/sims/lesson-4.6.3.btsim
:::

Na switchi sú pripojení Anna, Ben a smerovač. Na Anne a Benovi je IPv6 nastavené na **SLAAC (automaticky)** — IPv6 adresu im nikto nezadal. Smerovač pozná prefix `2001:db8:1::/64`.

## Odkiaľ sa berie adresa?

1. Prepni sa do režimu :fa-play: **Spustiť** a počkaj niekoľko sekúnd.
2. Na **Anne** otvor :fa-terminal: **Terminál** a zadaj `ip a`.

Okrem IPv4 adresy uvidíš dva riadky s `inet6`: jednu adresu so `scope link` a jednu so `scope global`.

:::quiz mc
Ktorá z týchto dvoch IPv6 adries je link-local adresa?
- [x] Tá, ktorá začína `fe80::` (`scope link`)
- [ ] Tá, ktorá začína `2001:db8:1:` (`scope global`)
:::

:::quiz mc
Odkiaľ pochádza prefix `2001:db8:1:0` globálnej adresy?
- [ ] Anna si ho vymyslela sama
- [x] Od smerovača — oznamuje prefix v sieti
- [ ] Od switchu
:::

:::evaluate
Skontrolovať odpovede
:::

Porovnaj **Interface ID** (posledné štyri bloky) s **MAC adresou** Anny — nájdeš ju celkom dole v :fa-gear: **Nastavenia IP**. Z MAC adresy `aa:28:39:e2:41:82` sa napríklad stane Interface ID `a828:39ff:fee2:4182`: do stredu sa vloží `ff:fe` a jeden bit na začiatku sa prevráti (preto sa z `aa` stane `a8`).

Tento postup sa volá **SLAAC** (*Stateless Address Autoconfiguration*): smerovač oznamuje prefix, Interface ID si vytvorí každé zariadenie samo.

:::note
Keďže MAC adresa jednoznačne identifikuje zariadenie, dalo by sa podľa Interface ID spoznať kdekoľvek na internete. Skutočné zariadenia preto väčšinou používajú navyše náhodné Interface ID, ktoré sa pravidelne menia (*Privacy Extensions*) — kúsok ochrany súkromia.
:::

## Hľadanie susedov — bez ARP

1. Na **Benovi** zadaj `ip a` a zapamätaj si jeho **globálnu** IPv6 adresu.
2. Pingni ju z **Anny**, napríklad `ping 2001:db8:1:0:…` (s úplnou adresou Bena).
3. Prepni sa do režimu :fa-magnifying-glass: **Stopa** a otvor trace pre **Annu**.

Pozri sa na pakety bezprostredne pred prvým `Echo (ping) request`.

:::quiz multi
Ktoré tvrdenia sú pravdivé?
- [x] Namiesto ARP požiadavky posiela Anna **Neighbor Solicitation** („Kto má túto adresu?“)
- [x] Ben odpovie **Neighbor Advertisement** a uvedie svoju MAC adresu
- [x] Požiadavka ide na multicastovú adresu (`ff02::1:ff…`), nie na všetkých pomocou broadcastu
- [ ] Anna posiela ARP požiadavku ako pri IPv4
- [x] Smerovač pravidelne rozosiela **Router Advertisements** na `ff02::1` — obsahujú prefix
:::

:::evaluate
Skontrolovať odpovede
:::

:::tip Zapamätaj si
Pri IPv6 preberá úlohy ARP protokol **NDP** (*Neighbor Discovery Protocol*, súčasť ICMPv6): pomocou **Neighbor Solicitation** a **Neighbor Advertisement** zariadenia zisťujú MAC adresy svojich susedov. Pomocou **Router Advertisements** smerovač oznamuje prefix — z neho si zariadenia pomocou **SLAAC** samy vytvoria svoju adresu.
:::

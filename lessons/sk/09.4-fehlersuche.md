# Hľadanie chýb: Odkedy platia nové pravidlá, nič nefunguje

:::sim
url=/sims/lesson-9.4.btsim
:::

Pán Biber, správca školy Beaver-Schule, včera prestavil firewall na princíp whitelistu. Odvtedy sa sťažujú všetci: **Webová stránka školy** nie je zvonku dostupná a z internetu už nechodia **žiadne e-maily**. Aspoň SSH je teraz zvonku zablokované, ako sa chcelo.

Nájdi chyby v pravidlách **firewallu** a oprav ich.

<details>
<summary>Tip 1: Dostane sa paket vôbec k správnemu pravidlu?</summary>

Otestuj z **Internet-PC** pomocou `nmap -p 22,25,80 198.51.100.10` a potom si vo firewalle pozri stĺpec **Treffer**. Pravidlo, ktoré zostáva na 0, hoci by preň mali prichádzať pakety, je zakryté iným pravidlom — alebo nikdy nesedí.
</details>

<details>
<summary>Tip 2: Pozri sa poriadne</summary>

Porovnaj každé číslo v pravidlách s portami z kapitoly 5: Ktorý port patrí k HTTP a ktorý k SMTP? A mysli na poradie: Vyhráva prvé vyhovujúce pravidlo.
</details>

:::task
title: Je web a e-mail opäť dostupný?
Skontroluj, či sú web a e-mail školského servera dostupné z internetu a či zostáva SSH zablokované.
check: tcpOpen(1, "198.51.100.10", 80)
check: tcpOpen(1, "198.51.100.10", 25)
check: tcpFails(1, "198.51.100.10", 22)
:::

## Čo sa stalo?

:::quiz multi
Aké chyby sa skrývali v pravidlách?
- [x] Pravidlo pre web povoľovalo port 8080 namiesto 80
- [x] Pravidlo pre e-mail stálo pod pravidlom „zahodiť všetko“ a nikdy sa neuplatnilo
- [ ] Firewall bol nastavený na Stateful
- [ ] Port 25 je pre e-mail nesprávny port
:::

Skontrolovať odpovede
:::

:::tip Zapamätaj si
Typické chyby vo firewallových pravidlách: **preklep v čísle** portu, nesprávny **smer** a nesprávne **poradie**, pri ktorom všeobecné pravidlo zakrýva špeciálne. Pri hľadaní chýb pomáhajú **skenovanie portov** zvonku, **protokol** firewallu a **počítadlá zásahov** pravidiel.
:::

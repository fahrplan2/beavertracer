# Útok: sfalšovanie DNS

:::sim
url=/sims/lesson-8.3.5.btsim
:::

Anna chce na **Client-PC** otvoriť svoje internetové bankovníctvo v **Biberbank**. Nevie však, že niekto získal prístup k **DNS-Server** a zmenil jeden záznam.

Na pracovnej ploche vidíš skutočný webový server **www.biberbank.de** a počítač **útočníka**. Na ňom beží kópia webovej stránky banky.

## Časť 1: Bez šifrovania

Prepni sa do :fa-play: **Spustiť** režimu spustenia a na **Client-PC** otvor v :fa-globe: **Prehliadač** adresu `http://www.biberbank.de/`.

:::quiz mc
Čo vidíš?
- [x] Prihlasovaciu stránku Biberbank bez akéhokoľvek varovania
- [ ] Varovanie, že stránka je sfalšovaná
- [ ] Chybové hlásenie
:::

:::evaluate
Skontrolovať odpoveď
:::

Všetko vyzerá normálne. Ale s ktorým serverom prehliadač skutočne komunikuje? Otvor na Client-PC :fa-terminal: **Terminál**:

```
$ nslookup www.biberbank.de
```

:::quiz short
Akú IP adresu vráti DNS-Server pre `www.biberbank.de`?
= 192.168.0.66
:::

:::quiz mc
Komu patrí táto adresa? (V režime úprav klikni na zariadenia alebo si pozri ich :fa-gear: **Nastavenia IP**.)
- [ ] Skutočnému webovému serveru Biberbank
- [x] Útočníkovi
- [ ] DNS-Server
:::

:::evaluate
Skontrolovať odpovede
:::

Keby Anna teraz zadala číslo účtu a PIN, skončili by priamo u útočníka. Pri **HTTP** nemá **žiadnu šancu** si podvod všimnúť: Adresný riadok zobrazuje správny názov a stránka vyzerá pravá.

## Časť 2: S HTTPS

Teraz otvor `https://www.biberbank.de/`.

:::quiz mc
Čo sa stane?
- [ ] Zobrazí sa sfalšovaná stránka so zámkom
- [x] Prehliadač varuje: Certifikát bol vydaný pre iný názov
- [ ] Zobrazí sa skutočná stránka Biberbank
:::

:::quiz short
Pre aký názov je vydaný certifikát útočníka (bez `CN=`)?
= www.biber-gewinnspiel.de
:::

:::evaluate
Skontrolovať odpovede
:::

Útočník má dokonca **skutočný** certifikát od dôveryhodnej CA — ale pre svoju vlastnú doménu `www.biber-gewinnspiel.de`. Certifikát pre `www.biberbank.de` od žiadnej CA nedostane, pretože táto doména mu nepatrí. A bez **súkromného kľúča** Biberbank nemôže použiť ani jej skutočný certifikát: V handshaku by s ním musel podpísať Server Key Exchange.

:::quiz multi
Pred čím HTTPS v tomto prípade chráni — a pred čím nie?
- [x] HTTPS odhalí, že server nie je ten pravý
- [ ] HTTPS zabráni sfalšovaniu DNS-Server
- [x] HTTPS pomôže len vtedy, keď používateľ berie varovanie vážne
- [ ] S HTTPS nie je sfalšovaná stránka vôbec dostupná
:::

:::evaluate
Skontrolovať odpovede
:::

## Časť 3: Oprava DNS-Server

Otvor **DNS-Server** a oprav záznam pre `www.biberbank.de`. Správnu adresu nájdeš v :fa-gear: **Nastavenia IP** webového servera **www.biberbank.de**. Nezabudni kliknúť na **Uložiť**.

:::note
Client-PC si odpovede DNS na chvíľu pamätá, aby sa nemusel pri každom otvorení stránky pýtať znova (**DNS cache**). Ako dlho, je uvedené v stĺpci **TTL** (*Time to Live*) v sekundách. Ak `nslookup` hneď po tvojej oprave stále vracia starú adresu, počkaj, kým uplynie TTL, a skús to znova.
:::

:::task
title: Je Biberbank opäť pravá?
Skontroluje, či Client-PC preloží www.biberbank.de na správnu adresu a či dokáže stránku cez HTTPS otvoriť bez varovania.
check: resolves(2, "www.biberbank.de", "192.168.0.30")
check: httpsOk(2, "https://www.biberbank.de/")
:::

:::note
V skutočnosti útočník len zriedka falšuje samotný DNS-Server. Častejšie podstrčí svoje odpovede vo verejnej sieti WiFi, zmení nastavenia domáceho smerovača alebo láka na podobne vyzerajúcu adresu ako `www.biberbank-login.de` (**phishing**). Proti podobne znejúcemu názvu nepomôže ani HTTPS — útočník preň získa platný certifikát. Preto: Adresu si čítaj pozorne!
:::

:::tip Zapamätaj si
Pri **sfalšovaní DNS** vráti DNS-Server pre nejaký názov adresu útočníka. Pri **HTTP** si to nevšimneš. Pri **HTTPS** certifikát útočníka nezodpovedá zadanému názvu a prehliadač **varuje** — pretože certifikát pre cudzie domény nevydá žiadna CA a súkromný kľúč skutočného servera útočník nemá.
:::

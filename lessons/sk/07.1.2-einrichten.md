# Nastavenie domáceho smerovača

:::sim
url=/sims/lesson-7.1.2.btsim
:::

Nový domáci smerovač je práve pripojený — ale zatiaľ sa nikto nedostane na internet. Od poskytovateľa si dostal list s **prístupovými údajmi**:

| Prístupové údaje | Hodnota |
|---|---|
| WAN IP adresa | `203.0.113.2` |
| Dĺžka prefixu | `/30` |
| Gateway (smerovač poskytovateľa) | `203.0.113.1` |
| DNS server poskytovateľa | `198.51.100.10` |

1. Prepni sa do :fa-play: režimu **Spustiť**, klikni na **Heimrouter** a otvor kartu **WAN**.
2. Zadaj prístupové údaje a klikni na **Použiť**.
3. Pripoj **Tablet** k WiFi: :fa-gear: **Nastavenia IP**, karta **WiFi**, SSID `Biberbau`, **Použiť**.
4. Otestuj na PC pomocou `ping 192.0.2.80` alebo v prehliadači pomocou `http://www.beispiel.de/`.

:::note
V praxi dostane domáci smerovač svoju WAN adresu zvyčajne automaticky od poskytovateľa (cez DHCP alebo prihlásením pomocou používateľského mena a hesla). Pevné prístupové údaje ako tu sú bežnejšie pri firemných pripojeniach.
:::

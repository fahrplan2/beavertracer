# Ako je DNS organizovaný

:::sim
url=/sims/lesson-6.2.btsim
:::

Žiadny jednotlivý server nemôže poznať všetky názvy na svete. DNS je preto postavený **hierarchicky** — rovnako ako samotné názvy. Čítajú sa sprava doľava:

```
www . beaver-schule . de . (Root)
 │          │         │      └─ Root-Server: kennen die Server aller Top-Level-Domains
 │          │         └─ Top-Level-Domain (TLD): der de-Server kennt alle .de-Domains
 │          └─ Domain: der Schul-DNS ist für beaver-schule.de zuständig
 └─ Rechnername innerhalb der Domain
```

Server, ktorý je zodpovedný za doménu a odpoveď naozaj pozná, sa nazýva **autoritatívny**. Cestu k nemu za PC zabezpečuje **resolver** — tu je to počítač **DNS-Resolver**.

## Experiment

1. Prepni sa do :fa-play: **režimu spustenia** a na **Client-PC** zadaj v :fa-terminal: **Terminál**i:
   ```
   $ nslookup www.beaver-schule.de
   ```
2. V :fa-magnifying-glass: režime **Stopa** otvor trace pre **DNS-Resolver**.

Resolver za teba vykonal celý rad dotazov. Priraď, kto dal ktorú odpoveď:

:::quiz match
Root-Server (192.168.0.101) -> Odkaz: Za .de je zodpovedný ns.nic.de
de-Server (192.168.0.102) -> Odkaz: Za beaver-schule.de je zodpovedný ns.beaver-schule.de
Schul-DNS (192.168.0.103) -> Odpoveď: www.beaver-schule.de má adresu 192.168.0.20
:::

:::quiz mc
Koho sa resolver pýta ako prvého?
- [x] Root server
- [ ] Schul-DNS
- [ ] Client-PC
:::

:::evaluate
Skontrolovať odpovede
:::

:::note
Medzitým sa resolver pýta aj na adresy serverov, na ktoré bol odkázaný (`A ns.nic.de`). Skutočné DNS servery tieto adresy väčšinou pošlú hneď spolu s odpoveďou. Okrem toho si resolvery každú odpoveď na chvíľu zapamätajú (**cache**) — na ďalší dotaz na rovnaký názov odpovedia hneď samy. Ako dlho, je uvedené v zázname ako **TTL** (*Time to Live*) v sekundách.
:::

## Najdôležitejšie typy záznamov

| Typ | Význam | Príklad |
|---|---|---|
| **A** | názov → adresa IPv4 | `www.beaver-schule.de` → `192.168.0.20` |
| **AAAA** | názov → adresa IPv6 | `www.beaver-schule.de` → `2001:db8::20` |
| **CNAME** | názov → iný názov (alias) | `web.beaver-schule.de` → `www.beaver-schule.de` |
| **MX** | zodpovedný poštový server domény | `beaver-schule.de` → `mail.beaver-schule.de` |
| **NS** | zodpovedný DNS server domény | `beaver-schule.de` → `ns.beaver-schule.de` |

:::tip Zapamätaj si
DNS je **hierarchický**: **Root servery** odkazujú na servery **domén najvyššej úrovne** (napr. `.de`), tie na servery jednotlivých **domén**. Zodpovedný **autoritatívny** server pozná odpoveď. **Resolver** ide touto cestou za PC a zapamätáva si odpovede (**cache**). Dôležité typy záznamov: **A**, **AAAA**, **CNAME**, **MX**, **NS**.
:::

## Vytvorenie záznamu

Škola chce, aby bola jej webová stránka dostupná aj na `intranet.beaver-schule.de`.

1. V :fa-play: **režime spustenia** klikni na **Schul-DNS** a otvor aplikáciu **DNS-Server**.
2. Otvor kartu **A**. Klikni na **+** a do nového riadka zadaj názov `intranet.beaver-schule.de` a adresu `192.168.0.20`.
3. Otestuj na Client-PC pomocou `nslookup intranet.beaver-schule.de`.

:::task
title: Je nový názov zapísaný?
Skontroluje, či Client-PC preloží názov intranet.beaver-schule.de na adresu webservera. Simulácia musí byť na to spustená v režime spustenia.
check: resolves(2, "intranet.beaver-schule.de", "192.168.0.20")
:::

## Experiment

1. Prepni sa do režimu :fa-play: **Spustiť**, klikni na **Client-PC** a otvor :fa-globe: **Prehliadač**.
2. Tentoraz zadaj `http://www.beaver-schule.de/` — s menom namiesto IP adresy.
3. Prepni sa do režimu :fa-magnifying-glass: **Stopa** a otvor trace pre **Client-PC**.

Úplne na začiatku — ešte pred nadviazaním spojenia pomocou `[SYN]` — sú dva pakety s protokolom **DNS**.

Až keď Client-PC pozná IP adresu, nadviaže TCP spojenie s webovým serverom — presne ako v kapitole 5.

:::seq
mode: text
Client-PC -> DNS-Resolver: DNS-Anfrage | A www.beaver-schule.de?
DNS-Resolver -> Client-PC: DNS-Antwort | A 192.168.0.20
:::

## Odkiaľ pozná PC DNS server?

Otvor na **Client-PC** :fa-gear: **Nastavenia IP**: V poli **DNS-Server** je `192.168.0.53` — počítač **DNS-Resolver**. Naň posiela PC každú požiadavku na preklad mena.

DNS server sa môžeš opýtať aj priamo, bez prehliadača. Otvor :fa-terminal: **Terminál** a zadaj:

```
$ nslookup www.beaver-schule.de
```

`nslookup` najprv zobrazí, ktorého servera sa opýtal, potom odpoveď. Na porovnanie sa opýtaj na meno, ktoré neexistuje, napr. `nslookup gibtsnicht.beaver-schule.de`.

:::quiz mc
Čo odpovie DNS server na neznáme meno?
- [ ] Náhodnú IP adresu
- [x] `NXDOMAIN` — toto meno neexistuje
- [ ] Vôbec nič
:::

:::evaluate
Skontrolovať odpoveď
:::

:::tip Zapamätaj si
**DNS** prekladá mená (napr. `www.beaver-schule.de`) na IP adresy. Predtým, ako PC môže nadviazať spojenie s menom, opýta sa **DNS servera**, ktorý je zapísaný v jeho nastaveniach IP — väčšinou cez **UDP, port 53**. Pomocou `nslookup` môžeš klásť DNS požiadavky ručne.
:::

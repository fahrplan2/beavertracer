# Hľadanie chýb: Názov nefunguje

:::sim
url=/sims/lesson-6.2.3.btsim
:::

Učiteľka hlási: „`www.beaver-schule.de` sa mi nenačíta. S `http://192.168.0.20` to ale funguje!“ Takto *má* byť všetko nastavené:

| Čo | Má byť |
|---|---|
| DNS server na Client-PC | `192.168.0.53` (DNS-Resolver) |
| Záznam v Schul-DNS | `www.beaver-schule.de` → `192.168.0.20` |

Nájdi chyby a oprav ich.

<details>
<summary>Tip 1: Čo hovorí nslookup?</summary>

Na Client-PC zadaj `nslookup www.beaver-schule.de`. Ktorý server sa `nslookup` pýtal — a čo prišlo späť? (Odpoveď trvá niekoľko sekúnd.)
</details>

<details>
<summary>Tip 2: A čo teraz?</summary>

Ak dostaneš odpoveď, porovnaj adresu so schémou. Kde je tento názov zapísaný?
</details>

:::task
title: Je rozlíšenie názvu opravené?
Skontroluje, či Client-PC rozlíši www.beaver-schule.de na správnu adresu. Simulácia musí na to bežať v režime spustenia.
check: resolves(2, "www.beaver-schule.de", "192.168.0.20")
:::

## Čo sa stalo?

:::quiz multi
Ktoré tvrdenia sú pravdivé?
- [x] Na Client-PC bola ako DNS server zadaná `192.168.0.35` — tam nikto neodpovedá
- [x] V Schul-DNS ukazoval `www.beaver-schule.de` na `192.168.0.21` namiesto `192.168.0.20`
- [ ] Webový server bol vypnutý
- [ ] Root server nepoznal doménu `.de`
:::

:::evaluate
Skontrolovať odpoveď
:::

:::tip Zapamätaj si
Ak spojenie funguje s **IP adresou**, ale nie s **názvom**, problém je v **DNS**. Najprv skontroluj **zadaný DNS server** (odpovedá vôbec?), potom samotný **záznam** (sedí adresa?). `nslookup` ukáže oboje: ktorý server sa pýtal a čo odpovedal.
:::

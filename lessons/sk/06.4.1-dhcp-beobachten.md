# Automatické získanie adresy

:::sim
url=/sims/lesson-6.4.btsim
:::

K switchu sú pripojené **DHCP Server** a dva laptopy. Laptopy majú zatiaľ pevné adresy.

## Experiment

1. Prepni sa do :fa-play: režimu spustenia (**Spustiť**), klikni na **Laptop 1** a otvor :fa-gear: **Nastavenia IP**.
2. Zmeň **Režim** zo **Statické** na **DHCP** a klikni na **Použiť**.
3. Počkaj niekoľko sekúnd: polia sa vyplnia samy.
4. V režime :fa-magnifying-glass: **Stopa** otvor trace pre **Laptop 1**.

:::quiz table
| Nastavenie | získané od DHCP servera |
|---|---|
| IP adresa | {192.168.0.100} |
| Brána | {192.168.0.1} |
| DNS server | {192.168.0.53} |
:::

:::quiz short
Koľko DHCP paketov nájdeš v trace?
= 4
= štyri
:::

:::quiz mc
Na akú cieľovú IP adresu posiela Laptop 1 svoj prvý paket (`DHCP Discover`)?
- [ ] Na DHCP server `192.168.0.2`

## Čo za tým stojí: DORA

Zariadenie bez adresy nevie, kde je DHCP server, a nemá ani vlastnú adresu odosielateľa. Preto volá do siete pomocou **broadcastu**. Priebeh má štyri kroky — podľa ich začiatočných písmen **DORA**:

:::seq
mode: text
Laptop 1 -> DHCP-Server: DHCP Discover | „Je tu nejaký DHCP server?“
DHCP-Server -> Laptop 1: DHCP Offer | „Môžeš dostať 192.168.0.100.“
Laptop 1 -> DHCP-Server: DHCP Request | „Beriem 192.168.0.100.“
DHCP-Server -> Laptop 1: DHCP ACK | „Potvrdené — platí 3600 sekúnd.“
:::

Adresa je len **požičaná** (*lease*): po uplynutí **doby prenájmu (lease time)** ju musí zariadenie obnoviť, inak ju server smie prideliť znova. Ktoré adresy sú práve požičané, vidíš v **DHCP Server** na karte **Leases**.

:::tip Vyskúšaj si to
Nastav na DHCP aj **Laptop 2**. Akú adresu dostane? Potom sa pozri do **Leases** DHCP servera.
:::

:::tip Zapamätaj si
**DHCP** automaticky prideľuje IP adresu, sieťovú masku, bránu a DNS server. Priebeh sa volá **DORA**: **D**iscover (klient hľadá pomocou broadcastu), **O**ffer (server ponúka), **R**equest (klient prijíma), **A**CK (server potvrdzuje). Adresa je požičaná na **dobu prenájmu (lease time)**. DHCP používa **UDP**, port 67 (server) a 68 (klient).
:::

:::quiz match
Discover -> Klient hľadá DHCP server pomocou broadcastu
Offer -> Server ponúka adresu
Request -> Klient si vyžiada ponúknutú adresu
ACK -> Server potvrdzuje pridelenie
:::

# HTTPS

:::osi 5
:::

**HTTPS** (*HTTP Secure*) je úplne bežný HTTP — len nebeží priamo nad TCP, ale cez šifrovanú vrstvu medzi nimi: **TLS** (*Transport Layer Security*). Predchodca TLS sa volal **SSL**; preto sa ešte často hovorí o „SSL certifikátoch“.

```
ohne Verschlüsselung:   HTTP  →  TCP  →  IP
mit Verschlüsselung:    HTTP  →  TLS  →  TCP  →  IP
```

HTTP si z toho nevšimne nič: posiela svoje požiadavky ako zvyčajne, TLS ich zašifruje, TCP ich prenesie. V modeli OSI sa TLS nachádza medzi transportnou a aplikačnou vrstvou, teda vo vrstve 4/5 — stavia na TCP a spravuje zabezpečenú reláciu.

| | HTTP | HTTPS |
|---|---|---|
| Port | 80 | **443** |
| Adresa | `http://…` | `https://…` |
| Obsah čitateľný v Tracer-i? | áno | nie |
| Prehliadač zobrazuje | „nezabezpečené“ | zámok |

TLS pri nadviazaní spojenia zabezpečí všetko, čo si sa naučil v tejto kapitole:

- Server sa preukáže svojím **certifikátom** (**autentickosť**).
- Obe strany si pomocou **Diffie-Hellmana** dohodnú **kľúč relácie** — server svoj podiel **podpíše**.
- Potom sa všetky údaje zašifrujú pomocou **AES** (**dôvernosť**) a zabezpečia sa proti zmene (**integrita**).

Princíp sa neobmedzuje len na web: aj e-mail (časť 8.4) a mnohé ďalšie protokoly fungujú cez TLS rovnakým spôsobom.

V nasledujúcich častiach budeš pozorovať HTTPS v Tracer-i, sám si ho nastavíš a preskúmaš, kedy prehliadač varuje — a prečo.

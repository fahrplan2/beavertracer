# DHCP: automaticky do siete

:::goal
**Cieľ učenia:** Vieš vysvetliť, ako zariadenie automaticky získa svoje nastavenia IP pomocou DHCP, vieš nastaviť DHCP server a rozpoznať a odstrániť typické chyby DHCP (napr. adresu 169.254).
:::

:::sim
url=/sims/lesson-6.4.btsim
:::

Doteraz si každému zariadeniu zadával IP adresu, sieťovú masku, bránu a DNS server ručne. V škole so stovkami notebookov, tabletov a mobilov by to bolo nemožné — a každá preklepnutá hodnota by znamenala chybu v sieti.

Túto prácu preberá **Dynamic Host Configuration Protocol** (**DHCP**): **DHCP server** automaticky rozdeľuje nastavenia každému zariadeniu, ktoré sa pripojí do siete.

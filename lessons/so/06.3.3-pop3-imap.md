# POP3 ama IMAP?

:::sim
url=/sims/lesson-6.3.btsim
:::

Waxaa jira laba protocol oo loo isticmaalo soo qaadista mail-ka. Simulation-kan, **Anna waxay isticmaashaa POP3** **Ben** na waxa uu isticmaalaa **IMAP**.

## Tijaabada

1. Marka aad ku jirto :fa-play: **Run** (Habka Socodsiinta), mail ka dir **Ben** una dir `anna@beaver-schule.de`.
2. Gudaha app-ka **E-Mail** ee **Anna**, guji **Soo qaad**.
3. Fur traces-ka **Anna** iyo kan **Ben**, kuna barbar dhig command-yada loo isticmaalay soo qaadista.

:::quiz match
USER / PASS -> POP3: gelitaan (login) leh username iyo password oo laba tallaabo ah
RETR -> POP3: soo dejinta fariin
LOGIN -> IMAP: gelitaan (login) leh username iyo password
SELECT INBOX -> IMAP: furidda folder ku jira server-ka
:::

:::evaluate
Hubi isku xidhka
:::

## Farqiga

| | POP3 | IMAP |
|---|---|---|
| Port | 110 | 143 |
| Fikradda aasaasiga ah | mail-ka **soo dejiso** — kadibna inta badan server-ka ka tirtir | mail-ku **wuxuu ku sii jiraa server-ka** halkaasna waa lagu maamulaa |
| Folders, la akhriyay/lama akhriyin | kaliya qalabkaaga | server-ka ayay ku jiraan — meel walba waa isku mid |
| Dhowr qalab (taleefan, laptop) | ma habboona: qalab kasta wuxuu leeyahay xaalad kale | aad u fiican: qalab walba wuxuu arkaa isla mailbox-ka |

:::note
Barnaamijka mail-ka ee BeaverTracer wuxuu mail-ka ku daayaa server-ka xitaa marka POP3 la isticmaalo. Barnaamijyada dhabta ahi inta badan way tirtiraan kadib marka la soo dejiyo — ama waxay u daayaan wax yar oo muddo ah.
:::

:::quiz mc
Lena waxay mail-keeda ka akhrisaa taleefankeeda, tablet-keeda iyo laptop-ka dugsiga. Maxay isticmaashaa?
- [ ] POP3, sababtoo ah way ka fudud tahay
- [x] IMAP, sababtoo ah qalab walba wuxuu arkaa isla mailbox-ka server-ka ku jira
- [ ] SMTP, sababtoo ah waxaa loogu talagalay soo qaadista
:::

:::evaluate
Hubi jawaabta
:::

:::tip Qodob muhiim ah
**POP3** wuxuu mail-ka server-ka ka soo dejiyaa **hal** qalab. **IMAP** wuxuu mailbox-ka ku maamulaa **server-ka** — isagoo leh folders iyo xaaladda la akhriyay oo qalab walba isla mar u muuqda. Labaduba waxay u adeegaan oo keliya **soo qaadista**; dirista had iyo jeer waxaa lagu sameeyaa **SMTP**.
:::

# Wareegyada (loops) ee network-ka iyo Spanning Tree

:::goal
**Hadafka waxbarashada:** Waad sharixi kartaa sida broadcast storm uga dhasho network leh loop iyo sida Spanning Tree Protocol (STP) uga hortagto loops iyadoo aan ka tanaasulin ammaanka shaqada joogtada ah (redundancy).
:::

Maxaa dhacaya haddii fiilo ku jira network uu dhaco? Haddii wax walba ay ku xidhan yihiin hal fiilo oo keliya, qayb ka mid ah network-ka waa go'aysaa. Sidaas darteed, network-yada waaweyn, switches waxaa inta badan lagu xidhaa **marar badan** — sida saddexda switches ee Goobta shaqada, kuwaas oo samaysa goobo (ring). Haddii hal fiilo ka go'o, waxaa jira wado kale.

Wuu fiicanyahay — laakiin ring-kan wuxuu leeyahay cilad khatar ah. Waxaad ka baran doontaa bogga xiga.

# Duufaanta broadcast-ka

:::sim
url=/sims/lesson-3.4.1.btsim
:::

Saddex switch (A, B, C) ayaa lagu xiray qaab goobaabin ah (ring). **Anna** (`192.168.0.10`) waxay ku xiran tahay switch A, **Ben** (`192.168.0.11`) wuxuu ku xiran yahay switch B.

## Tijaabada

1. U gudub habka :fa-play: **Run** (Habka Socodsiinta), ku fur :fa-terminal: **Terminal** **Anna** oo ping u dir Ben:
   ```
   $ ping 192.168.0.11
   ```
2. Xir daaqadda Anna oo muddo ku fiiri Goobta shaqada: packets-ku waxay si joogto ah ugu wareegayaan ring-ga.
3. U gudub habka :fa-magnifying-glass: **Raad** oo adigoo isticmaalaya **+** u fur trace **Ben**, port-ka `eth0`. Dusha midig ee sare waxaad ku arkaysaa inta packets ee la duubay ilaa hadda.
4. Dhawr jeer u beddel **Run** iyo **Raad** oo indho ku hay tirada.

:::quiz mc
Maxaad ku aragtaa liiska packet-yada Ben?
- [ ] Ping-yada Anna iyo jawaabaha Ben, sidii caadiga ahayd
- [x] Isla codsiga ARP "Who has 192.168.0.11?" oo mar kasta soo noqnoqda — tirada packets-ku si joogto ah ayay u kordhaysaa
- [ ] Waxba, ring-gu wax walba wuu xannibaa
:::

:::quiz mc
Oo muxuu Terminal-ka Anna sheegayaa?
- [ ] Ping-yada oo dhan way gaadhayaan
- [x] Ping midna ma gaadho
:::

:::evaluate
Hubi jawaabaha

## Waxa ka dambeeya

Codsiga ARP ee Anna waa broadcast. Switch A wuxuu u diraa dhammaan port-yada — sidaas darteed switch B *iyo* switch C labadaba. Labadooduba mar kale ayay u gudbiyaan dhammaan port-yadooda, sidaas darteed switch kale iyo dib ugu noqoshada A. A mar kale ayuu u gudbiyaa … Broadcast-ku wuxuu si aan dhammaad lahayn ugu wareegaa ring-ga, codsi kasta oo cusubna wuxuu ku daraa nuqulo dheeraad ah.

Maadaama frames-kii isku midka ahaa ay si joogto ah uga imanayaan jihooyin kala duwan switches-ka, jadwallada cinwaannadooda (address tables) ayaa sidoo kale isku qasma: mararka qaarkood Anna waxay ku taal port-kan, mararka kalena kaas. Taasi waa sababta xitaa ping-yadu u gaadhi waayaan.

:::tip Qodob muhiim ah
Haddii switches-ka u dhexeeyo **loop**, broadcasts-ku waxay si aan dhammaad lahayn ugu wareegaan network-ka oo way ku badanayaan — **broadcast storm**. Wuxuu network-ka ka dhigaa mid shaqeyn waayay. Si ka duwan IP packets, Ethernet frames ma laha "taariikh dhicitaan" oo ugu dambeyn joojin lahayd.
:::

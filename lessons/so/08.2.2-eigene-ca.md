# Samaynta CA u gaar ah

:::sim
url=/sims/lesson-8.2.2.btsim
:::

`www.beaver-schule.de` weli ma laha certificate. Halkii ay ka codsan lahayd CA ganacsi, dugsigu wuxuu dhisaa **CA u gaar ah**: **Schul-CA**. Shirkado iyo dugsiyo badan ayaa taas u sameeya server-radooda gudaha.

Dhab ahaantii, Schul-CA waxay ka shaqayn lahayd kombuyuutar u gaar ah oo si gaar ah loo ilaaliyo. Halkan, adigaa door walba ku cayaaraya web server-ka laftiisa.

## Tallaabada 1: Samee Schul-CA

1. U beddel :fa-play: **Ausführen** — habka **Habka Socodsiinta**, kuna fur web server-ka **www.beaver-schule.de** :fa-shield-halved: **Zertifikatverwaltung**.
2. Gudaha **Tab**-ka **Generieren**:
    - **Common Name:** `Schul-CA`
    - **Typ:** Selbstsigniert
    - Calaamadi **Dies ist ein CA-Zertifikat**
    - **Speichern unter:** `schul-ca.cert.json`
3. Guji **Zertifikat generieren**.

Intaas waxaa abuurma **key pair** cusub. Certificate-ku wuxuu ka kooban yahay public key; private key-ga wuxuu ku jiraa faylka web server-ka.

## Tallaabada 2: Bixi certificate-ka server-ka

Mar kale **Tab**-ka **Generieren**:

- **Common Name:** `www.beaver-schule.de` — sida saxda ah magaca lagu qoro Browser-ka
- **Typ:** Von CA signiert, **Signierende CA:** Schul-CA
- **Speichern unter:** tusaale ahaan `www.beaver-schule.de.cert.json`

Gudaha **Tab**-ka **Meine Zertifikate** hadda waxaad arkaysaa labada certificate. Guji certificate-ka cusub ee server-ka:

:::quiz short
Yaa ah **Aussteller**-ka certificate-ka server-ka (`CN=` la'aan)?
= Schul-CA
:::

:::quiz mc
Waa maxay **Kette**-ddiisa?
- [x] `www.beaver-schule.de ← Schul-CA`
- [ ] `Schul-CA ← www.beaver-schule.de`
- [ ] `www.beaver-schule.de` (selbstsigniert)
:::

:::evaluate
Hubi jawaabaha
:::

## Tallaabada 3: Ku baro client-ka Schul-CA

Client-PC-gu weli ma yaqaan Schul-CA — Browser-kiisa kuma jirto mid hore loo rakibay. Waa inaad siisaa certificate-keeda, **adigoon private key la socon**:

1. Web server-ka, gudaha **Meine Zertifikate**, dooro **Schul-CA** oo guji **Kopieren** (ha gujin *Kopieren + Schlüssel*!).
2. **Client-PC**-ga ku fur :fa-shield-halved: **Zertifikatverwaltung**, **Tab**-ka **Vertrauenswürdige CAs**.
3. Guji **Einfügen: Schul-CA**.

:::warning
**Private key-ga CA-da** waa sirta ugu qiimaha badan nidaamka oo dhan: ruuxii haysta wuxuu awoodaa inuu bixiyo certificate-yo magac **kasta** u ah, kuwaas oo client-yada oo dhami aamini doonaan. Waa inaanu weligiis ka bixin kombuyuutarka CA-da.
:::

:::task
title: Schul-CA ma la dhisay?
Hubi in web server-ka ku jiro certificate loogu talagalay www.beaver-schule.de oo Schul-CA bixisay, iyo in Client-PC-gu aamino Schul-CA.
check: hasCert(4, "www.beaver-schule.de", "Schul-CA")
check: trusts(2, "Schul-CA")
:::

:::quiz mc
Muxuu client-ka ugu koobiyeynayaa certificate-ka **iyada oo aan** private key la socon?
- [ ] Sababtoo ah koobiyeynta key-ga la socda waxay qaadataa waqti dheer
- [x] Si loo hubiyo signature-yada public key ayaa ku filan; haddii private key la haysto, qof kasta oo client-ka joogaa ayaa laftiisa bixin kara certificate-yo
- [ ] Sababtoo ah haddii kale client-ku ma samayn karo connection
:::

:::evaluate
Hubi jawaabta
:::

Web server-ka laftiisa weli ma beddelin — wuxuu wali ku hadlaa HTTP oo keliya. Sida HTTPS loo daarayo waxaad ka baran doontaa qaybta 8.3.3.

:::tip Qodob muhiim ah
**CA u gaar ah** waxay ka kooban tahay **CA certificate is-saxiixay** oo leh private key. Waxaa lagu bixiyaa **certificate-yada server-ka**, kuwaas oo Common Name-kooduna la mid yahay magaca server-ka. Si client-yadu u aamino certificate-yadan, waxay liistada **vertrauenswürdige CAs** ku helaan **CA certificate-ka private key la'aanteed**.
:::

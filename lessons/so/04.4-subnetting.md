# Subnetting

:::goal
**Hadafka waxbarashada:** Waxaad awooddaa inaad sharaxdo sababta loo kala qaybiyo networks, inaad network u kala qaybiso subnets cabbir isku mid ah leh, oo aad subnets-ka ku hirgeliso network leh router.
:::

Dugsi ayaa network-giisa u helay address range-ka `192.168.10.0/24` — kaas oo ku filan 254 qalab. Waxaad *dhigi kartaa* dhammaan qalabka network keliya kan. Laakiin badanaa waa ka fiicnaan lahayd in loo kala qaybiyo dhowr network oo yaryar. Habkan waxaa la yiraahdaa **Subnetting**, networks-ka yaryarna waa **subnets** (*Subnetze*).

Maxay tahay sababta ay faa'iido u leedahay?

- **Amni:** Maamulka, macallimiintu iyo ardaydu waxay ku sugan yihiin networks kala duwan. Inta u dhaxaysa networks-ka waxaa taaganaya router — halkaas ayaa lagu go'aamin karaa si sax ah cidda meel kasta tagi karta.
- **Broadcasts yar:** Broadcast kasta (tusaale ahaan codsi ARP kasta) wuxuu gaadhaa *dhammaan* qalabka ku jira network-gaas. Networks yaryar macnaheedu waa taraafiko aan loo baahnayn oo yar.
- **Muuqaal fudud:** Address-ka ayaad ka garan kartaa isla markiiba meesha qalabku ka tirsan yahay.

:::note
Ma xasuusataa VLANs-ka laga soo qaaday cutubka 3.2? VLANs waxay networks kala saaraan **layer 2**, Subnetting-na wuxuu kala saaraa **layer 3**. Dhaqanka, labadaba badanaa way isla socdaan: VLAN kasta wuxuu helaa subnet u gaar ah.
:::

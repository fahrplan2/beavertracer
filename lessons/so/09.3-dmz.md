# DMZ

:::sim
url=/sims/lesson-9.3.btsim
:::

Hore, **Schulserver** wuxuu ku jiray isla network-ka **Lehrer-PC**. Taasi waa khatar: Schulserver waxaa laga heli karaa internet-ka. Haddii weeraryahan helo nuqsaan ku jira webserver-ka oo uu kontoroolo kombiyuutarka, wuxuu isagu noqonayaa **dhexda network-ka dugsiga** — firewall-kuna wax kale ma qaban karo, maxaa yeelay isu-socodka Schulserver ilaa Lehrer-PC firewall-ka kuma dhex maro.

Xalka: Server-yada ay tahay in laga heli karo internet-ka waxaa la geliyaa **network u gaar ah** oo ka dhex jira internet-ka iyo network-ka gudaha. Network-kan waxaa loo yaqaan **DMZ** (*demilitarisierte Zone*, oo ku salaysan xariijinta dhexdhexaadka ah ee u dhaxeysa laba xuduud).

## Dhismaha

Goobta shaqada waxaad ka arkaysaa moodelka caadiga ah ee leh **laba firewalls**:

```
Internet ──[ Firewall außen ]── Schulrouter ──── DMZ: Schulserver (198.51.100.10)
                                    │
                             [ Firewall innen ]
                                    │
                    LAN: Lehrer-PC (192.0.2.20), Schüler-PC (192.0.2.21)
```

- **Firewall außen** wuxuu wax walba ka ilaaliyaa internet-ka. Port A wuxuu ku xiran yahay internet-ka, Port B wuxuu ku xiran yahay Schulrouter.
- **Firewall innen** wuxuu ilaaliyaa LAN-ka — xitaa DMZ-ga. Port A wuxuu ku xiran yahay Schulrouter, Port B wuxuu ku xiran yahay LAN-ka.

Labada firewalls hadda wax walba way ogolaadaan.

:::quiz multi
Xidhiidhada soo socda kuwee ayaa macquul ah oo ay tahay in la oggolaado?
- [x] Internet → DMZ: Web (80) iyo Mail (25) ee Schulserver
- [x] LAN → DMZ: tusaale ahaan soo qaadista email-ka (110)
- [x] LAN → Internet: baadhitaanka webka
- [ ] Internet → LAN
- [ ] DMZ → LAN
:::

## Hawl: DMZ ammaan geli

Labada firewalls **labadaba** u dhig **Stateful** iyo **Alle verwerfen**, kuna qor xeerar ku habboon:

- **Firewall außen:** Gudaha ilaa dibadda (B → A) wax walba waa la ogol yahay; dibadda ilaa gudaha (A → B) kaliya TCP 80 iyo 25 ee loo socda Schulserver `198.51.100.10`.
- **Firewall innen:** Ka imaanshaha LAN (B → A) wax walba waa la ogol yahay; jihada LAN (A → B) xeer looma baahna — jawaabuhu waxay soo laabanayaan iyagoo mara state table-ka.

:::note
Firewalls badan waxay leeyihiin saddex ama ka badan oo ports ah („zones“) oo waxay DMZ ku dhisaan hal qalab oo keliya. Mabda'ku waa isku mid: isu-socodka u dhexeeya Internet, DMZ iyo LAN waa inuu mar walba maraa xeerar. Moodelka leh laba firewalls wuxuu leeyahay faa'iido: Weeraryahanku waa inuu jebiyaa **laba** caqabad — badanaa waxaa xitaa loo isticmaalaa qalab ka yimid soo saarayaal kala duwan, si isla nuqsaan amni uusan labadaba u furin.
:::

:::tip Qodob muhiim ah
**DMZ**-ga waxaa la geliyaa server-yada oo dhan ee ay tahay in laga heli karo internet-ka. Waxay ku jirtaa u dhexeysa laba firewalls (ama zone u gaar ah oo firewall ka mid ah): Internet-ku wuxuu u gudbi karaa kaliya adeegyo gaar ah oo ku jira DMZ, LAN-kuna wuxuu gali karaa DMZ iyo internet-ka — laakiin DMZ-ga iyo internet-ka **wax jid ah oo LAN loo maro ma jiro**. Haddii server ku jira DMZ la kontoroolo, LAN-ku wuu ammaan ahaanayaa.
:::

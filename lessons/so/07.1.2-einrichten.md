# Dejinta home router-ka

:::sim
url=/sims/lesson-7.1.2.btsim
:::

Home router cusub ayaa hadda la xiriiriyay — laakiin weli ma jiro qof internet-ka geli kara. Provider-ka waxaad ka heshay warqad ay ku qoran yihiin **xogta gelitaanka**:

| Xogta gelitaanka | Qiimaha |
|---|---|
| WAN IP address | `203.0.113.2` |
| Prefix length | `/30` |
| Gateway (router-ka provider-ka) | `203.0.113.1` |
| DNS server-ka provider-ka | `198.51.100.10` |

1. U gudub habka :fa-play: **Run**, guji **Heimrouter**, kuna fur Tab-ka **WAN**.
2. Geli xogta gelitaanka, kadibna guji **Apply**.
3. Ku xidh **Tablet**-ka WLAN-ka: :fa-gear: **IP Settings**, Tab-ka **WiFi**, SSID `Biberbau`, **Apply**.
4. Ku tijaabi PC-ga `ping 192.0.2.80`, ama browser-ka ku tijaabi `http://www.beispiel.de/`.

:::note
Marka la fiiriyo xaqiiqada, home router-ku badanaa wuxuu WAN address-kiisa ka helaa provider-ka si toos ah (iyada oo loo marayo DHCP ama gelid leh magac isticmaale iyo password). Xogta gelitaanka go'an sida halkan oo kale ah waxay badanaa caadi u tahay xidhiidhada shirkadaha.
:::

# Ku xidhidhka PC badan switch ku

:::sim
url=/sims/lesson-3.1.1.btsim
:::

Goobta shaqada waxa ku yaal switch iyo saddex PC: **Anna**, **Ben** iyo **Clara**. IP address-yadooda horeyba waa la dejiyay (`192.168.0.10`, `.11` iyo `.12`) — waxa kaliya oo ka maqan fiilooyinka.

## Fiilo ku xidhidhka

1. U gudub Habka Tafatirka :fa-pencil: **Wax ka badal**, kuna dooro qalabka :fa-link: **Verbindung**.
2. Guji **Anna** kadibna guji **Switch**. Waxa soo muuqan doona liis ay ku jiraan ports-yada switch-ka (1 ilaa 8) — dooro **1**.
3. Mar kale dooro :fa-link: oo ku xidh **Ben** port **2** iyo **Clara** port **3**.

Fiilo kasta hadda waxa ka muuqda lambar yar: port-ka switch-ka ee lagu dhejiyay.

:::tip Qodob muhiim ah
**Switch** waa qalab qaybiya oo leh isku xidhayaal badan, kuwaas oo la yiraahdo **ports**. Qalab kasta oo switch ku dhegan waxay wada sameeyaan **local network** (Ingiriisi: *Local Area Network*, **LAN**).
:::

## Tijaabi

U gudub Habka Socodsiinta :fa-play: **Run**, ka fur :fa-terminal: **Terminal** **Anna** oo ping u dir Clara:

```
$ ping 192.168.0.12
```

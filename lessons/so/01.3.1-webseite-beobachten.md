# Furista boggan webka iyo kormeerkiisa

Qaybtan waxba naftaada ma dhisaysid: **Goobta shaqada** waxaa ku jira simulation horay loo diyaariyey oo ay ku jiraan **Client-PC** iyo **Webserver**.

## Furista boggga

1. U gudub habka :fa-play: **Habka Socodsiinta** (**Run**).
2. Marka hore **Client-PC** ku fur app-ka :fa-globe: **Browser** oo geli cinwaanka webserver-ka: `http://192.168.0.20/`.
3. U gudub habka :fa-magnifying-glass: **Raad** oo adigoo isticmaalaya **+** ku fur trace **Client-PC**, port-ka `eth0` — sida ping-ka oo kale.

:::note
Hal bog oo la furo, packets tiradooda way yaab leedahay — aad bay uga badan yihiin kuwii ping-ka. Soo qaadista boggga webka waa hawl dhowr marxaladood leh, ma aha hal tallaabo oo keliya.
:::

## Magacaabista protocols-ka ku lugta leh

Marka laga eego wixii aad arkday, hadda waad akhriyi kartaa protocol-ka mid walba wuxuu mas'uul ka ahaa maxay.

:::tip Talo
Mar kale dib u akhri tiirarka **Info**: `Who has …?`, `[SYN]`, `[SYN, ACK]`, `[ACK]`, `GET /` iyo `200 OK` ku dhawaad wax walba way muujinayaan.
:::

:::quiz match
ARP -> Wuxuu weydiiyaa dhammaan network-ka ku jira: „Yaa haysta IP address 192.168.0.20?“
TCP -> Wuxuu dhisaa xidhiidh isagoo adeegsanaya saddex packet oo gaagaaban, kahor intaan xogtu socon
HTTP -> Wuxuu codsadaa boggga webka (GET) wuuna soo celiyaa (200 OK)
:::

:::evaluate
Hubi isku xidhka
:::

:::tip Qodob muhiim ah
Furista boggga webka waxay u socotaa marxalado: marka hore server-ka network-ka ku jira **hel** (ARP), kadib xidhiidh **dhis** (TCP), kadib boggga **codso oo soo qaad** (HTTP) — ugu dambayntiina xidhiidhka mar kale **jaree** (packets-ka TCP ee leh `[FIN]` dhammaadka liiska).
:::

:::note
Markan adigaa si toos ah u geliyey IP address-ka server-ka, sidaas darteed **DNS** (“tarjumaadda” magacyada sida `www.beispiel.de` una beddelka IP address) weli lama isticmaalin. Taas waxaan ka hadli doonnaa cutubka 6.
:::

Miyaad dareentay in protocols-ka qaab-dhismeedka packet-ka ay ku leeyihiin calaamado midab leh oo tirooyin wata? Macnaha taas waxaan ka bayaamin doonaa cutubka 2. Halkaas waxaan ku eegi doonaa sida protocols-ka badan si nidaamsan loogu kala saaro — iyadoo la isticmaalayo qaababka tixraaca OSI iyo TCP/IP. Taasi waxay dhammaystirtay cutubka 1.

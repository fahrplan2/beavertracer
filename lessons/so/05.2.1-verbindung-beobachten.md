# Isku xidhka ugu horreeya ilaa ugu dambeeya

:::sim
url=/sims/lesson-5.1.btsim
:::

Ee **Server**-ka waxaa ka shaqeeya adeegga echo ee port `5000`: Fariin kasta isla markiiba ayuu dib u soo celiyaa. Adigoo isticmaalaya **Simple TCP Client** waxaad xakameyn kartaa isku xidhka tallaabo tallaabo — badhan kasta waa marxalad.

## Tijaabada

1. U gudub habka :fa-play: **Run**, riix **Client-PC** oo fur **Simple TCP Client**.
2. Meesha **Host** geli `192.168.0.20`, meesha **Port** geli `5000`.
3. Riix **Ku xidhiidh**.
4. Ku qor `Hello World` goobta fariinta oo riix **Dir**. Daaqadda sheekada waxaad isla markiiba ku arkaysaa echo-ga server-ka.
5. Riix **Ka xir**.
6. U gudub habka :fa-magnifying-glass: **Raad** oo adigoo isticmaalaya **+** fur trace u dhigan **Client-PC**, isku xidhka `eth0`.

:::note
Labada packet ee ARP ee bilowga ah waad ka taqaanaa cutubka 1. Tiirka **Info** ee packets-ka TCP waxaa marka hore ka muuqda `49152 → 5000` (port-ka laga bilaabo ilaa port-ka loo socdo), kadibna qaybaha laba geesoodka ah dhexdooda waxaa ku jira **flags**, ka dib na tirooyin sida `Seq=`, `Ack=` iyo `Len=`. Tirooyinka waxaa laga hadlayaa laga bilaabo bogga 5.2.3 — halkan waxaad fiiro gaar ah u yeelanaysaa flags iyo `Len`.
:::

## Marxaladda 1: Ku xidhiidh

:::quiz short
Immisa packet oo TCP ah ayaa la isweydaarsaday kadib markaad riixday **Ku xidhiidh** — ka hor inta aan fariintaadu bixin?
= 3
= saddex
:::

:::quiz mc
Yaa soo diraya packet-ka ugu horreeya ee leh `[SYN]`?
- [x] Client-PC
- [ ] Server-ka
:::

:::quiz mc
Server-ku flags-kee ayuu ku jawaabaa?
- [ ] `[SYN]`
- [x] `[SYN, ACK]`
- [ ] `[ACK]`
- [ ] `[FIN, ACK]`
:::

## Marxaladda 2: Dir

`Len` waxay muujisaa imisa bytes oo xog ah ayaa packet-ku sidaa.

:::quiz short
Imisa bytes ayuu sidaa packet-ka ay fariintaadu ku jirto (`Len`)?
= 13
:::

:::note
`Hello World` waxay leedahay 11 xaraf oo keliya. Laakiin TCP client-ku wuxuu ku daraa dhammaadka safka (2 byte, `\r\n`) — sidaas ayaa protocols-ka internet-ka badan sida SMTP ama HTTP ay u filayaan.
:::

:::quiz mc
Muxuu server-ku isla markiiba soo celiyaa fariintaada kadib — xataa ka hor echo-ga?
- [x] Packet leh `[ACK]` iyo `Len=0` — xaqiijin aan xog lahayn
- [ ] Waxba
- [ ] `[SYN]` cusub
:::

## Marxaladda 3: Ka xir

:::quiz short
Immisa packet ayaa ka tirsan jaridda isku xidhka — laga bilaabo packet-ka ugu horreeya ee leh `FIN`?
= 4
= afar
:::

:::quiz mc
Maxay dhinac ku sheegayaa `FIN`?
- [x] „Waan dhammeeyay“ — mar dambe xog ma dirayso
- [ ] „Khalad ayaa dhacay“
- [ ] „Waa kan xog cusub oo imanaysa“
:::

:::evaluate
Hubi jawaabaha
:::

## Halkee ku jiraan afartan hawlood?

Isku xidh halka aad ka heli karto hawlaha qaybta 5.1 ee trace-ka:

:::quiz match
Connection setup -> Saddexda packet ee [SYN], [SYN, ACK] iyo [ACK]
Gudbin la isku halleyn karo -> Packets-ka leh [ACK] iyo Len=0 ee xaqiijiya helitaanka
Jaridda isku xidhka -> Packets-ka leh FIN iyo xaqiijintooda
Multiplexing -> Lambarrada port-ka 49152 → 5000 ka hor qaybaha laba geesoodka ah
:::

:::evaluate
Hubi isku xidhka
:::

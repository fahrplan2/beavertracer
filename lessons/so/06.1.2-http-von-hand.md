# HTTP gacanta

:::sim
url=/sims/lesson-6.1.btsim
:::

Haddii HTTP uu yahay qoraal saafi ah — miyaad adigu si toos ah ula hadli kartaa web server, adigoon isticmaalin browser? Haa: adigoo isticmaalaya `telnet` waxaad furtaa TCP connection ilaa port kasta oo aad doorato, kadibna adigu qudhaadu qoraalka ayaad ku qortaa.

## Tijaabada

1. U gudub habka :fa-play: **Ausführen** — waa **Run** — kadibna **Client-PC** ku fur :fa-terminal: **Terminal**.
2. Ku xidhiidh port 80 ee server-ka:
   ```
   $ telnet 192.168.0.20 80
   ```
3. Qor codsiga sadar sadar — kuna dhamee **sadar madhan** (mar kale taabo **Enter**):
   ```
   GET /kontakt.html HTTP/1.1
   Host: 192.168.0.20

   ```

Server-ku wuxuu ku jawaabayaa status line, headers iyo bogga xiriirka — qaab qoraal ah, sida uu browser-ku u helo oo kale.

:::quiz mc
Sidee server-ku u garanayaa in codsigaagu dhammaaday?
- [ ] Amar gaar ah oo `END` ah
- [x] Sadarka madhan
- [ ] Ka dib waqti gaar ah
:::

:::quiz short
Qiimaha noocee ah ayaa ku jira jawaabta header-ka `Content-Type`? (kaliya qaybta hore ee ka horreysa `;`)
= text/html
:::

:::evaluate
Hubi jawaabaha
:::

## Qalad abuur

Qalab ka raaxo badan waa `curl`: wuxuu codsiga kuu sameeyaa. Isagoo la socda `-v` (*verbose*, faahfaahin) wuxuu muujiyaa wax kasta oo ku socda labada dhinac — sadarrada leh `>` waxaa diray `curl`, sadarrada leh `<` waxay ka yimaadeen server-ka.

Tijaabi:

```
$ curl -v http://192.168.0.20/gibtsnicht.html
$ curl -X POST -d name=Anna http://192.168.0.20/
```

:::quiz short
Muxuu yahay status code-ka aad helayso `/gibtsnicht.html`?
= 404
:::

:::quiz short
Oo muxuu yahay midka codsiga leh method-ka `POST`?
= 405
:::

:::evaluate
Hubi jawaabaha
:::

:::note
Web server-ka ku jira BeaverTracer wuxuu bixin karaa oo keliya files — sidaas darteed wuxuu oggol yahay oo keliya `GET` iyo `HEAD`. Web servers dhab ah waxay `POST` ku helaan tusaale ahaan foomam, kadibna xogta u gudbiyaan barnaamij.
:::

:::tip Qodob muhiim ah
Protocols badan oo application layer ah waa kuwo **qoraal ku salaysan** — HTTP, iyo sidoo kale SMTP, POP3 iyo IMAP. Sidaas darteed waxaad ku hadli kartaa gacanta adigoo isticmaalaya `telnet`, oo waxaad ku akhrisan kartaa Tracer-ka. Tani waxay faa'iido u leedahay cilad-raadin — laakiin waa dhibaato amni sidoo kale: qof kasta oo duubaya traffic-ga wuu akhrin karaa wax kasta. Sida encryption (HTTPS) u caawiyo waxaad ku baran doontaa cutubka 8.
:::

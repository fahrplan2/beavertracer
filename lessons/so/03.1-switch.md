# Switch-ka

:::goal
**Hadafka waxbarashada:** Waxaad awoodaa inaad ku xidhto dhowr PC ah switch, oo aad sharaxdo sida switch-ku u ogaado port-ka uu frame u dirayo.
:::

PC badanaa wuxuu leeyahay hal network port oo keliya. Si loo xidho saddex, toban ama boqol qalab, waxaa loo baahan yahay qalab qaybiya oo leh port badan: **switch**-ka.

Bogagga soo socda waxaad marka hore laftaadu ku xidhi doontaa PC-yo switch, kaddib waxaad fiirin doontaa packets-ka yimaada qofkasta — ugu dambaynna waxaad ka raadin doontaa cilado network aan u shaqaynayn sidii loogu talagalay.

# Router-ka

:::goal
**Hadafka waxbarashada:** Waad sharixi kartaa sida router uu ugu xidho laba network, waad dejin kartaa gateway-ga PC-ga, waadna sababeyn kartaa goorta PC uu packet si toos ah u geeyo iyo goorta uu u marsiiyo gateway-ga.
:::

**Router** wuxuu isku xidhaa network-yo kala duwan. Sidaas awgeed, network kasta wuxuu u leeyahay port u gaar ah — port kastana wuxuu leeyahay IP address u gaar ah oo ka timid network-kaas oo kali ah. Goobta shaqada waxaad mar kale ku aragtaa Firma A iyo Firma B, markan iyadoo router u dhexeeyo.

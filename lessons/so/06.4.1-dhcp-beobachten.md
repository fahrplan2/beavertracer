# Si toos ah u hel cinwaan

:::sim
url=/sims/lesson-6.4.btsim
:::

Switch-ka waxaa ku xidhan **DHCP Server** iyo laba laptop. Laptop-yadu weli waxay haystaan cinwaano go'an.

## Tijaabada

1. U gudub habka :fa-play: **Run**, guji **Laptop 1** oo fur :fa-gear: **IP Settings**.
2. Beddel **Modus** laga bilaabo **Static** una beddel **DHCP**, kaddibna guji **Apply**.
3. Sug dhowr ilbiriqsi: goobaha way is-buuxinayaan.
4. Habka :fa-magnifying-glass: **Raad** ku fur trace u dhigma **Laptop 1**.

:::quiz table
| Dejin | laga helay DHCP Server |
|---|---|
| IP address | {192.168.0.100} |
| Gateway | {192.168.0.1} |
| DNS server | {192.168.0.53} |
:::

:::quiz short
Imisa DHCP packet ayaad ka heshaa trace-ka?
= 4
= afar
:::

:::quiz mc
Muxuu yahay IP address-ka loo socdo ee Laptop 1 u diro packet-kiisii ugu horreeyay (`DHCP Discover`)?
- [ ] DHCP Server-ka `192.168.0.2`
- [x] `255.255.255.255` — dhammaan (broadcast)
- [ ] Gateway-ga `192.168.0.1`
:::

:::quiz mc
Muxuu yahay IP address-ka sender-ka ee packet-kan ugu horreeya — maxaana loo isticmaalay?
- [x] `0.0.0.0` — laptop-ku weli ma lahan cinwaan
- [ ] `192.168.0.10` — cinwaankiisii hore
- [ ] `192.168.0.100` — cinwaankiisa cusub
:::

## Waxa ka dambeeya: DORA

Qalab aan cinwaan lahayn ma yaqaan meesha DHCP Server-ku yaal, mana haysto cinwaan sender ah oo u gaar ah. Sidaas darteed wuxuu network-ka ku wacaa **broadcast**. Habka wuxuu leeyahay afar tallaabo — oo loogu magac daray xarfahooda hore **DORA**:

:::seq
mode: text
Laptop 1 -> DHCP-Server: DHCP Discover | „Ma jiraa DHCP Server halkan?“
DHCP-Server -> Laptop 1: DHCP Offer | „Waxaad heli kartaa 192.168.0.100.“
Laptop 1 -> DHCP-Server: DHCP Request | „Waxaan qaadanayaa 192.168.0.100.“
DHCP-Server -> Laptop 1: DHCP ACK | „La xaqiijiyay — waxay shaqaynaysaa 3600 ilbiriqsi.“
:::

Cinwaanku waa **amaah** uun (*Lease*): marka **Lease-time** dhammaado, qalabku waa inuu cusbooneysiiyaa, haddii kale server-ku mar kale ayuu bixin karaa. Cinwaannada hadda la amaahiyay waxaad ka arki kartaa **DHCP Server** ee Tab-ka **Leases**.

:::tip Isku day
**Laptop 2** sidoo kale u deji DHCP. Cinwaan noocee ah ayuu helayaa? Ka dib eeg **Leases** ee DHCP Server-ka.
:::

:::tip Qodob muhiim ah
**DHCP** wuxuu si toos ah u qaybiyaa IP address, netmask, gateway iyo DNS server. Habka waxaa la yiraahdaa **DORA**: **D**iscover (client-ku wuxuu ku raadiyaa broadcast), **O**ffer (server-ku wuu soo bandhigaa), **R**equest (client-ku wuu aqbalaa), **A**CK (server-ku wuu xaqiijiyaa). Cinwaanka waxaa lagu amaahdaa **Lease-time**. DHCP wuxuu isticmaalaa **UDP**, port 67 (server) iyo 68 (client).
:::

:::quiz match
Discover -> Client-ku wuxuu ku raadiyaa DHCP Server isagoo isticmaalaya broadcast
Offer -> Server-ku wuxuu soo bandhigaa cinwaan
Request -> Client-ku wuxuu codsadaa cinwaanka la soo bandhigay
ACK -> Server-ku wuxuu xaqiijiyaa qoondaynta
:::

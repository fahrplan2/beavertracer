# Barashada qaababka (models)

Ku xidh protocols-ka tijaabadii bilowga cutubka ku jirtay layer-kooda OSI:

:::quiz match
Ethernet -> Layer 2 — Sicherung
IPv4 -> Layer 3 — Vermittlung
TCP -> Layer 4 — Transport
HTTP -> Layer 7 — Anwendung
:::

:::evaluate
Hubi isku xidhka
:::

Ugu dambayn, magacyada unugyada xogta:

:::quiz match
Frame -> Layer 2 — Sicherung
Paket -> Layer 3 — Vermittlung
Segment -> Layer 4 — Transport
:::

:::evaluate
Hubi isku xidhka
:::

Haddaba waxaad haysataa aalaabta aad si habboon ugu kala saari karto protocols-ka mustaqbalka. Laga bilaabo cutubka xiga, layer-yada waxaan ku dhex mari doonaa si isku xigta — annagoo ka bilaabayna layer 2 iyo su'aasha ah sida switch-ku runtii u ogaado halka uu packet-ka u gudbinayo.

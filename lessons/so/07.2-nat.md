# NAT: qalab badan, hal address

:::goal
**Hadafka waxbarashada:** Waxaad ku muujin kartaa Tracer-ka sida NAT u bedelo source address-ka, waxaad akhrin kartaa NAT table, waxaadna sharixi kartaa sababta xidhiidhada ka imaanaya dibadda una socda home network ay u baahan yihiin port forward.
:::

:::sim
url=/sims/lesson-7.1.btsim
:::

Provider-ku guud ahaan wuxuu xidhiidhka guriga siiyaa **hal** public IPv4 address oo keliya — WAN address-ka home router-ka. Qalabka oo dhan ee ku jira home network-ka waa inay wada isticmaalaan. Habkan sida uu u shaqeeyo waxaa la yiraahdaa **NAT** (*Network Address Translation*, bedelka address-ka).

# IPv6

:::goal
**Hadafka waxbarashada:** Waxaad awoodaa inaad sharaxdo sababta IPv6 u jiro, inaad akhrido IPv6 addresses oo aad u qorto qaab gaaban, inaad kala saartid noocyada address-ka ugu muhiimsan, oo aad sharaxdo sida device uu IPv6 ku helo address si automatic ah uuna ku helo deriskiisa (neighbours).

Qaybta 4.2.1 waxaad ku xisaabisay: 32 bit waxay bixiyaan ilaa **4,3 bilyan** IPv4 addresses — wax ka yar mid qof walba, in kasta oo maanta qof kastaa leeyahay dhowr device. Sidaas darteed IPv4 addresses bannaan waa ka dhammaadeen muddo hore. Hab-dhaqamo sida NAT (cutubka 7) ayaa muddo yar xalliya dhibaatadan.

Xalka dhabta ah waa **IPv6**. IPv6 address waa **128 bit** dhererkiisu. Sidaas darteed waxaa jira 2¹²⁸ addresses — tiro leh 39 lambar, ilaa 340 sextillion. Device kasta oo dhulka ku yaal wuxuu heli karaa inta uu u baahan yahay.

Maanta IPv4 iyo IPv6 inta badan waxay shaqeeyaan **isku mar (parallel)**: taleefankaaga ama router-ka gurigaaga ku jira aad bay u badan tahay inuu mar horeba labadaba haysto.

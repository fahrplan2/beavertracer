# Jadwalka NAT

:::sim
url=/sims/lesson-7.1.btsim
:::

Marka PC-ga iyo tablet-ku isku mar soo raraan isla bog web ah, labada codsi waxay ka yimaadaan webserver-ka `203.0.113.2`. Sidee home router-ku u ogaadaa cidda jawaabtu u socoto? Wuxuu qoraal ka haystaa — **NAT table** dhexdeeda.

## Tijaabada

1. U gudub habka :fa-play: **Ausführen** — waxaa la odhan karaa Habka Socodsiinta — kuna fur `http://www.beispiel.de/` **PC** iyo **Tablet** labadaba.
2. Guji **Heimrouter** oo fur tab-ka **NAT**.

Safaf kasta waa **mapping**: protocol, LAN IP iyo LAN port ee qalabka ku jira home network — iyo **WAN port** ee router-ku u isticmaalo cinwaanka dadweynaha ee uu leeyahay.

:::quiz short
Which WAN IP ayaa ka sarreeya jadwalka?
= 203.0.113.2
:::

:::quiz mc
PC-ga iyo tablet-ku labadaba waxay xidhiidh la sameeyeen LAN port `49152`. Which WAN port ayay helayaan?
- [ ] Labadaba isku mid, `49152`
- [x] Mid kasta mid kale — haddii kale router-ku ma ogaan lahayn cidda jawaabtu leedahay
- [ ] Midna, NAT wuxuu bedelaa IP address oo keliya
:::

:::quiz mc
Jawaab ka timid webserver-ka ayaa gaadhay `203.0.113.2` iyadoo leh **destination port** gaar ah. Maxay home router-ku la qabtaa?
- [x] Wuxuu ka raadiyaa port-ka NAT table, wuxuuna packet-ka u dirayaa LAN IP iyo LAN port-ka ku habboon
- [ ] Wuxuu packet-ka u dirayaa dhammaan qalabka ku jira home network
- [ ] Wuu tuuraa packet-ka
:::

:::evaluate
Hubi jawaabaha
:::

Halkan ayaa **ports**-kii cutubka 5 dib ugu soo noqonaya: maadaama NAT uu ports-ka sidoo kale dib u qoro, boqolaal xidhiidh ayaa wada isticmaali kara hal cinwaan. Si sax ah, waxaa loo yaqaan **PAT** (*Port Address Translation*) ama *NAT with port translation* — laakiin maalin kasta dadku waxay mar walba oranayaan NAT.

Tusaale ahaan, tarjumaadda noocaas ahi sidan ayay u eegi kartaa:

| | Packet ka yimid PC-ga (ku jira home network) | isla packet-kii internet-ka |
|---|---|---|
| Sender | `192.168.178.20 : 49152` | `203.0.113.2 : 10001` |
| Receiver | `192.0.2.80 : 80` | `192.0.2.80 : 80` |

:::tip Qodob muhiim ah
**NAT table** dhexdeeda, router-ku wuxuu xidhiidh kasta u xasuustaa qalabka (**LAN IP iyo LAN port**) ee ku jira gadaasha **WAN port** kee ah. Jawaabaha ka yimaadda internet-ka wuxuu ku celiyaa qalabka saxda ah isagoo adeegsanaya destination port-ka. Maadaama ports-ka sidoo kale la dib u qoro, si sax ah waxaa loo yiraahdaa **PAT**.
:::

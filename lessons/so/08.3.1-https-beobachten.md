# HTTP iyo HTTPS: is-barbardhig

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Webserver-ka **www.beaver-schule.de** wuxuu bixiyaa portal-ka dhibcaha ee dugsiga isagoo adeegsanaya HTTP iyo HTTPS labadaba. Maxay arkaysaa qof dhegeysanaya isgaarsiinta?

## Tijaabada

1. U gudub :fa-play: **Run** (Habka Socodsiinta), kadibna **Client-PC** ku fur :fa-globe: **Browser**, marka hore `http://www.beaver-schule.de/` kadibna `https://www.beaver-schule.de/`.
2. Ku fur trace u gaar ah **Client-PC** habka :fa-magnifying-glass: **Raad**.
3. Marka hore raadi packet-ka `HTTP/1.1 200 OK` oo gujis. Hoosta, qaybta faahfaahinta, waxaad ka heli doontaa nuxurka bogga.

:::quiz mc
Maxay arki karaan dhegeystayaashu marka la isticmaalayo **HTTP**?
- [x] Bogga webka oo dhan, oo ay ku jiraan dhibcaha Anna
- [ ] Kaliya cinwaanka server-ka
- [ ] Waxba, maxaa yeelay HTTP wuxuu ku shaqeeyaa TCP
:::

:::quiz short
Immisa dhibcood ayay Anna ka heshay xisaabta (Mathematik)?
= 2
:::

:::evaluate
Hubi jawaabaha
:::

Hadda waa qaybta HTTPS. Raadi packet-ka `[SYN]` ee uu client-ku ku bilaabayo xiriirka labaad.

:::quiz short
Maxay tahay port-ka loo socdo (destination port) ee xiriirka HTTPS (tiirka **Info**, `… → ???`)?
= 443
:::

Hadda gal `tls` goobta shaandhaynta (filter) ee ku taal sare ee trace-ka. Markaas waxaad arki doontaa kaliya packets-ka TLS.

:::quiz mc
Maxaa ku qoran tiirka **Info** ee packets-ka ka kooban bogga webka?
- [ ] `HTTP/1.1 200 OK`
- [x] `Application Data`
- [ ] `Encrypted HTML`
:::

:::quiz multi
Maxay weli arki karaan dhegeystayaashu marka la isticmaalayo **HTTPS**?
- [x] IP address-yada client-ka iyo server-ka
- [x] In port 443 la isticmaalayo, sidaas darteed laga yaabo inuu yahay HTTPS
- [x] Qiyaas ahaan inta xog ah ee la wareejinayo
- [ ] Bogga la furay iyo waxa ku qoran
:::

:::evaluate
Hubi jawaabaha
:::

:::note
Gujis packet-ka **Application Data**: xogta dhabta ah waa oo kaliya xariiq bytes ah oo u egaanaya kuwo random ah. Tracer-ku ma furi karo (decrypt), maadaama uusan aqoon session key-ga, sida uu u aqoon waayo weeraryahanku.
:::

:::tip Qodob muhiim ah
Marka la isticmaalayo **HTTP**, qof kasta oo dhegeysanaya wuxuu akhrin karaa bogga webka oo dhan. Marka la isticmaalayo **HTTPS**, wuxuu arkaa kaliya **yaa la hadlaya yaa** (IP address-yada, port 443) iyo **inta la hadlay**. Nuxurka waxaa ku jira si sir ah (encrypted) packets-ka **Application Data**.
:::

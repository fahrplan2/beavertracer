# Ports: isku xidhiidho badan isla markaas

:::goal
**Hadafka waxbarashada:** Waxaad awoodaa inaad sharaxdo sida ports ay u kala saaraan isku xidhiidho badan oo ku dhex jira hal kombiyuutar, inaad magacowdo well-known ports-ka ugu muhiimsan, iyo inaad hesho khaladaadka caadiga ah ee port-ka.
:::

Qaybta 5.1 waxaad ku aragtay: Browser-ka iyo TCP client-ku waxay packets-kooda u dirayaan isla IP address-kii — haddana mid kasta wuxuu gaadhayaa adeegga saxda ah. Farqiga waxa sameeyay lambarrada `80` iyo `5000`, kuwaas oo ah **ports**. Hadda si dhow ayaad u eegaysaa sida ay u shaqeeyaan.

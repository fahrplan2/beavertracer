# VLANs: hal switch, dhowr network

:::goal
**Hadafka waxbarashada:** Waxaad awooddaa inaad sharaxdo waxa VLANs loogu adeegsado, inaad switch ku samayso VLANs, oo aad VLANs ku xidhiidhiso dhowr switch adigoo isticmaalaya trunk.
:::

Dugsiyada badankood, PCs-ka maamulka waxay inta badan ku xiran yihiin switch-ka PCs-ka qolka kombiyuutarka ku xiran yihiin. Waa fudud yahay — laakiin ma dhab baa in ardaydu si toos ah u gaadhi karaan kombiyuutarka xafiiska xoghayaha, halkaas oo lagu kaydiyo dhibcaha imtixaanka iyo cinwaannada?

Waxaad iibsan kartaa switch gooni ah oo maamulka loogu talagalay, oo aad dhigtaa fiilooyin gooni ah. Laakiin waxaa jira hab ka fudud: waxaad *hal* switch u qaybisaa dhowr network oo is-ka go'an — kuwaas oo ah **VLANs**.

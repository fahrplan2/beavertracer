# Qaabka ISO/OSI Reference Model

Qaabka ISO/OSI wuxuu isgaarsiinta u dhexaysa laba qalab u qaybiyaa todoba layer. Layer kasta waxay leedahay hawl si cad loo qeexay, waxayna isticmaashaa oo keliya adeegyada layer-ka tooska hoostiisa ah:

Tijaabada bogga hore waxaad hore u taqaanaa afar ka mid ah layer-kan: Ethernet (2), IPv4 (3), TCP (4) iyo HTTP (7). Tirooyinkaas iyo midabadaas ayaa Tracer-ku kuugu muujiyaa protocol tree.

:::tip Xaqiijin xasuus
Laga bilaabo layer 7 hoos u socota: **A**pplication, **P**resentation, **S**ession, **T**ransport, **N**etwork, **D**ata Link, **P**hysical — xasuuso xarafka hore ee eray kasta.
:::

:::note Xaaladaha xadka ah
Protocol kasta si sax ah layer keliya uma gelayo. Sidaas darteed Tracer-ku wuxuu protocol-kan qaar ku muujiyaa dhawr layer:

- **ARP** — layer 2/3: IP header ma laha, laakiin wuxuu isku xidhaa IP address-yada (layer 3) iyo hardware address-yada (layer 2).
- **TLS** — layer 4/5: wuxuu si toos ah ugu fadhiyaa TCP, wuxuuna maareeyaa session la ammaanay.
- **HTTPS** (HTTP gudaha TLS) — layer 5–7: application layer-ka caadiga ah ee TCP/IP model-ka, kaas oo aad ka baran doonto bogga xiga.
:::

:::note
Layer 1 wuxuu qeexaa gudbinta dhabta ah ee calaamadaha ee ku socota fiilada ama hawada. Sidaas darteed Tracer-ka, falanqaynta waxay dhab ahaan ka bilaabmaysaa layer 2.
:::

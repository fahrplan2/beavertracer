# Layer 3: Router, IP address iyo subnetting

:::goal
**Hadafka waxbarashada:** Waxaad awooddaa inaad IP address ku akhrisid binary, inaad xisaabiso network address iyo broadcast address, inaad network u qaybiso subnet isle'eg, oo aad network-yada ku xidhid router iyo routing table.
:::

Ilaa hadda qalabka oo dhan wuxuu ku jiray *hal* network oo local ah — waxaa isku xidhay switch iyo Access Point. Laakiin internetku wuxuu ka kooban yahay malaayiin network oo noocaas ah: home network-kaaga, network-ka dugsiga, network-ka shirkadda isgaarsiinta moobilka, iyo network-yada xarumaha waaweyn ee xogta (data centers).

Sidee bay packet u helaa jidka laga bilaabo network ilaa network kale? Taas waxay masuul ka tahay **layer 3**, ee ah network layer — iyadoo la adeegsanayo **Internet Protocol (IP)**, IP address-yada, iyo qalabka isku xidha network-yada: **router-yada**.

:::note
IP wuxuu ku qeexan yahay heer (standard) laga soo bilaabo 1981, kaas oo ah **RFC 791**. Nooca ugu muhiimsan ee cutubkan laga hadlayo waxaa la yiraahdaa **IPv4**. Nooca cusub ee **IPv6** waxaad ka baran doontaa dhammaadka cutubka.
:::

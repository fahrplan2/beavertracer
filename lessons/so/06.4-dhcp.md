# DHCP: ku xidhiidhid network si otomaatig ah

:::goal
**Hadafka waxbarashada:** Waxaad awoodaa inaad sharaxdo sida qalab uu ugu helo IP settings-kiisa si otomaatig ah iyadoo la adeegsanayo DHCP, inaad dejiso DHCP Server, oo aad aqoonsato oo aad saxdo cilladaha DHCP ee caadiga ah (tusaale ahaan cinwaan 169.254).
:::

:::sim
url=/sims/lesson-6.4.btsim
:::

Ilaa hadda waxaad gacanta ku gelinaysay qalab kasta IP address-kiisa, netmask-kiisa, gateway-giisa iyo DNS server-kiisa. Dugsi leh boqolaal laptop, tablet iyo taleefan, taasi suurtagal ma aha — qalad kasta oo higgaadda ahna wuxuu noqonayaa cillad ku jirta network-ka.

Shaqadan waxaa qabta **Dynamic Host Configuration Protocol** (**DHCP**): **DHCP Server** wuxuu si otomaatig ah u qaybiyaa settings-ka qalab kasta oo ku soo biira network-ka.

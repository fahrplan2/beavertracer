# Cilad-raadin: Adeegga ma jawaabayo

:::sim
url=/sims/lesson-5.3.2.btsim
:::

Kadib update, iskuulku wuxuu soo sheegayaa: „Echo service wuxuu diidayaa xidhiidh kasta, boggii webka na mar dambe ma soo baxo.“ Sida ku jirta qorshaha, **web server** waa inuu dhegeystaa port `80`, **echo service** (TCP Echo-Server) na port `5000`. Raadi khaladaadka oo hagaaji.

<details>
<summary>Tilmaanta 1: Maxay server-ku ku jawaabayaa?</summary>

Isku day inaad ku xidhiidhto `192.168.0.20`, port `5000` adigoo adeegsanaya **Simple TCP Client**, kuna fur trace Client-PC. Maxay server-ku ku jawaabayaa `[SYN]` aad dirtay?
</details>

<details>
<summary>Tilmaanta 2: Which ports ayaa furan?</summary>

Gudaha Terminal-ka ee Client-PC ku qor `nmap -p 80,5000 192.168.0.20`. `nmap` wuxuu isku dayaa port-yada midba midka kale ka dambeeya, wuxuuna muujiyaa kuwa furan. Adigoo server-ka ku isticmaalaya `ss` waxaad arkaysaa port-yada uu barnaamij runtii dhegeysanayo.
</details>

<details>
<summary>Tilmaanta 3: Xaggee lagu dejiyaa?</summary>

Gudaha **Server**-ka fur apps-ka **TCP Echo-Server** iyo **HTTP-Server**. Adeegga ma socdaa? Port kee ayuu dhegeysanayaa?
</details>

:::task
title: Adeegyada ma la gaari karaa?
Hubi in Client-PC uu gaari karo echo service ee port 5000 iyo web server-ka ee port 80. Simulation-ku waa inuu sidaas awgeed ku socdaa Habka Socodsiinta.
check: tcpOpen(1, 2, 5000)
check: tcpOpen(1, 2, 80)
:::

## Maxaa dhacay?

:::quiz multi
Which hadallo ayaa sax ah?
- [x] `[SYN]` ee loo diray port 5000 server-ku wuxuu ku jawaabay `[RST, ACK]`
- [x] Echo service wuxuu dhegeysanayay port 5050 halkii uu ka ahaan lahaa port 5000
- [x] Web server-ku gabi ahaanba lama bilaabin
- [ ] Kaabalka u dhexeeya Client-PC iyo Server-ka wuu jabnaa
:::

:::evaluate
Hubi jawaabta
:::

:::tip Qodob muhiim ah
Haddii `SYN` lagu jawaabo **`RST`**, port-kaas **ma jiro barnaamij** dhegeysanaya: kombiyuutarka waa la gaari karaa, laakiin adeegga lama gaari karo. Sababaha caadiga ah: adeegga **lama bilaabin** ama wuxuu dhegeysanayaa **port kale**. Eegis lagu sameeyo server-ka adoo isticmaalaya `ss` wuxuu muujinayaa port-yada runtii furan.
:::

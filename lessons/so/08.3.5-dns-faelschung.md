# Weerar: DNS-ga been abuurka

:::sim
url=/sims/lesson-8.3.5.btsim
:::

Anna waxay doonaysaa inay **Client-PC** ka furto bangigeeda online-ka ah ee **Biberbank**. Wixii ayna garanayn: qof ayaa gaadhay **DNS-Server**-ka oo beddelay hal gelin (entry).

Goobta shaqada waxaad ku arkaysaa web server-ka dhabta ah **www.biberbank.de** iyo kombuyuutarka **weeraryahanka**. Kombuyuutarkaas waxaa ku shaqeeya nuqul ka mid ah bogga web-ka ee bangiga.

## Qaybta 1: Iyada oo aan sir-gelin jirin

U beddel :fa-play: **Ausführen**-habka, kadibna **Client-PC** ka ku fur `http://www.biberbank.de/` :fa-globe: **Browser**-ka.

:::quiz mc
Maxaad aragtaa?
- [x] Bogga galitaanka ee Biberbank, iyada oo aan wax digniin ah jirin
- [ ] Digniin sheegaysa in bogga been abuur yahay
- [ ] Fariin khalad ah
:::

:::evaluate
Hubi jawaabta
:::

Wax walba waxay u muuqdaan caadi. Laakiin browser-ku server kee ayuu runtii la hadlayaa? Ku fur :fa-terminal: **Terminal** ka Client-PC:

```
$ nslookup www.biberbank.de
```

:::quiz short
Fadlan sheeg IP address-ka uu DNS-Server-ku u soo celiyo `www.biberbank.de`?
= 192.168.0.66
:::

:::quiz mc
Cidda leh cinwaankan? (Habka Wax ka badal ku dhufo aaladaha ama eeg :fa-gear: **IP Settings** ooda.)
- [ ] Web server-ka dhabta ah ee Biberbank
- [x] Weeraryahanka
- [ ] DNS-Server-ka
:::

:::evaluate
Hubi jawaabaha
:::

Haddii Anna hadda gelisay lambarka akoonka iyo PIN-ka, waxay si toos ah ugu tegi lahaayeen weeraryahanka. Marka la isticmaalayo **HTTP**, **fursad uma lahan** inay ogaato khiyaanada: khadka cinwaanka wuxuu muujinayaa magaca saxda ah, bogguna wuu u egyahay mid dhab ah.

## Qaybta 2: Iyadoo la isticmaalayo HTTPS

Hadda ku fur `https://www.biberbank.de/`.

:::quiz mc
Maxaa dhacaya?
- [ ] Bogga been abuurka ah wuxuu soo muuqdaa isagoo leh quful
- [x] Browser-ku wuu digayaa: certificate-ka waxaa loo bixiyay magac kale
- [ ] Bogga dhabta ah ee Biberbank ayaa soo muuqda
:::

:::quiz short
Magaca ma loo bixiyay certificate-ka weeraryahanka (`CN=` la'aanteed)?
= www.biber-gewinnspiel.de
:::

:::evaluate
Hubi jawaabaha
:::

Weeraryahanku wuxuu xitaa haystaa certificate **dhab ah** oo ka timid CA la aamini karo — laakiin waxaa loo bixiyay domain-kiisa u gaarka ah `www.biber-gewinnspiel.de`. Certificate loogu talagalay `www.biberbank.de` CA kuma siinayso, maxaa yeelay domain-kaas isagu ma leh. Haddii uu haysan waayo **furaha gaarka ah** (private key) ee Biberbank, wuxuu sidoo kale u isticmaali kari waayo certificate-kooda dhabta ah: handshake-ka wuxuu u baahan lahaa inuu Server Key Exchange-ka kula saxiixo.

:::quiz multi
Maxay HTTPS halkan kaa ilaalisaa — maxayse kaa ilaalin weydo?
- [x] HTTPS wuxuu daaha ka qaadaa in server-ku uusan ahayn kan dhabta ah
- [ ] HTTPS wuxuu ka hortagaa in DNS-Server-ka la been abuuro
- [x] HTTPS wuxuu wax tara oo kaliya haddii isticmaaluhu si dhab ah u qaato digniinta
- [ ] Marka HTTPS la isticmaalo, bogga been abuurka ah gabi ahaanba lama gaari karo
:::

:::evaluate
Hubi jawaabaha
:::

## Qaybta 3: Dayactirka DNS-Server-ka

Fur **DNS-Server**-ka oo sax gelinta `www.biberbank.de`. Cinwaanka saxda ah waxaad ka heli doontaa :fa-gear: **IP Settings** ee web server-ka **www.biberbank.de**. Ha ilaawin inaad gujiso **Kaydi**.

:::note
Client-PC wuxuu xasuustaa jawaabaha DNS muddo, si uusan mar kasta dib u weydiin (**DNS-Cache**). Intee in le'eg ayaa lagu sheegay tiirka **TTL** (*Time to Live*) ee ah ilbiriqsiyo. Haddii `nslookup` isla marka aad sixiddo weli soo celiyo cinwaankii hore, sug TTL-ka oo mar kale isku day.
:::

:::task
title: Biberbank ma mar kale ayay dhab tahay?
Waxay hubisaa in Client-PC u xalliyo www.biberbank.de cinwaanka saxda ah oo uu bogga ku soo qaadi karo HTTPS iyada oo aan digniin jirin.
check: resolves(2, "www.biberbank.de", "192.168.0.30")
check: httpsOk(2, "https://www.biberbank.de/")
:::

:::note
Nolosha dhabta ah, weeraryahanku marar badan ma been abuuro DNS-Server-ka laftiisa. Inta badan wuxuu jawaabihiisa ku dhex tuuraa WiFi dadweyne, wuxuu beddelaa settings-ka home router, ama wuxuu ku jiito cinwaan u eg kan sida `www.biberbank-login.de` (**Phishing**). Magac isku mid ah ama isu dhow HTTPS ma caawiyo — weeraryahanku wuxuu u helayaa certificate sax ah. Sidaa darteed: cinwaanka si dhab ah u akhri!
:::

:::tip Qodob muhiim ah
Marka **DNS-ka la been abuuro**, DNS-Server-ku wuxuu magac u soo celiyaa cinwaanka weeraryahan. Marka la isticmaalo **HTTP**, wax lagama dareemo. Marka la isticmaalo **HTTPS**, certificate-ka weeraryahanku kuma habboona magaca la furay, browser-kuna wuu **digayaa** — maxaa yeelay CA ma bixiso certificate loogu talagalay domain shisheeye, weeraryahankuna ma haysto furaha gaarka ah ee server-ka dhabta ah.
:::

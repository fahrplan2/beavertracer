# Dhinaca hore: IPv6 iyo Carrier-Grade-NAT

empty
:::

NAT waa xal degdeg ah oo caqli badan oo loo helay yaraanta IPv4 addresses — laakiin weli waa xal degdeg ah. Waxaa jira laba horumar oo aad ogaanaysaa inaad ogaato.

## IPv6: NAT lama oga loo baahna

Marka la eego **IPv6**, addresses waa ay badan yihiin (cutubka 4.6). Sidaas darteed provider-ku home router-ka uma siiyo hal address oo keliya, laakiin **prefix** dhan — inta badan `/56` ama `/48`, taas oo ah bilyanno addresses ah. Tan waxaa la yidhaa **prefix delegation** (DHCPv6-PD). Home router-ku wuxuu intaas ka qaybiyaa, isagoo adeegsanaya SLAAC, qalab kasta address u gaar ah oo **adduunka oo dhan ku gaar ah**.

Markaas NAT mar dambe looma baahna: qalab kasta si toos ah ayaa loo address-gareyn karaa. Tani waa mid habboon, laakiin waxay u baahan tahay **firewall** wanaagsan oo ku jira router-ka — maxaa yeelay "saameynta dhinaca" ee NAT, taas oo ah in qofna dibadda kala bilaabi karin xidhiidh, way baabba'daa. Tan ayaa ah mawduuca cutubka 9.

## Carrier-Grade-NAT: NAT ee provider-ka

Provider-yo badan ayaa laftooda ku filan IPv4 addresses. Markaas xitaa home router-ku ma helo public address, laakiin wuxuu helaa mid kaliya oo ka mid ah aag gaar ah (`100.64.0.0/10`), provider-kuna wuxuu **mar kale NAT sameeyaa** macaamiil badan isku mar. Tan waxaa la yidhaa **Carrier-Grade-NAT** (CGNAT); inta badan markaas IPv4 waxaa ka harsan oo keliya jidkan, halka IPv6 ay leedahay public addresses dhab ah (*DS-Lite*).

Natiijadu waa: **port forward** ku jira router-kaaga ma faa'iidaysto IPv4 — packets-ka dibadda ka imaanaya way ku istaagaan provider-ka agtiisa. Qofka guriga ka rabo inuu server ka shaqeysiiyo wuxuu u baahan yahay IPv6 ama xidhiidh kale.

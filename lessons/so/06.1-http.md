**Hypertext Transfer Protocol** (**HTTP**) waa luqadda ay browsers iyo web servers isugu hadlaan. Web server-ka waxaa ku jira bogga web-ka ee **Beaver-Schule**: bog hore (home page), bog xiriir iyo stylesheet loogu talagalay muuqaalka.

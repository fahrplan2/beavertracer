# Firewall-ka stateful

:::sim
url=/sims/lesson-9.2.btsim
:::

Firewall **stateful** ah (*stateful*) waxay xasuusataa xiriir kasta oo ay mar allowed ka dhigtay, waxayna ku kaydisaa **Zustandstabelle** (state table): protocol, labada address iyo labada port. Haddii packet yimaado oo ku habboon gelitaan (entry), si kasta oo jihadu tahay, waxay u gudbisaa iyada oo aan hubin dheeraad ah samayn. Xiriirrada cusub, si kastaba ha ahaatee, waa inay maraan rules-ka.

## Daawasho

1. Gudaha **Firewall**-ka, **Modus**-ka u dhig **Stateful**.
2. Ku fur **Lehrer-PC** gudahiisa :fa-globe: **Browser** mar kale `http://203.0.113.80/`.
3. Firewall-ka gudihiisa isla markiiba fur tab-ka **Zustände**.

:::quiz mc
Maxaa hadda dhaca?
- [x] Bogga wuu furmayaa, **Zustände** gudihiisana waxaa ku jira xiriirka ka socda Lehrer-PC ilaa `203.0.113.80:80`
- [ ] Bogga ma furmayo, maxaa yeelay jawaabuhu wali ma laha rule

:::

:::

:::evaluate

:::

Gelitaannada **Zustände** gudihiisa way baaba'aan wax yar ka dib (tiirka **Timeout**), haddii xiriirka wax ka socdaa joojiyaan.

## Hawl: Schul-Firewall

Hadda u habee firewall-ka sidii dugsi dhab ah uu u baahan yahay:

- **Laga bilaabo Schulnetz** wax walba waxay u bixi karaan internet-ka (jihada B → A, protocol kasta).
- **Laga bilaabo internet-ka** waxaa laga gaari karaa oo keliya Web (80) iyo helitaanka Mail (25) ee Schulserver-ka.
- Wax kasta oo kale waa la **tuuraa** (drop), modus-kuna waa **Stateful**.

:::task
title: Schul-Firewall ma la habeeyay?
Waxay hubisaa in Schulnetz-ku gaari karo internet-ka, in dibadda laga gaari karo oo keliya Web iyo Mail ee Schulserver-ka, iyo in Lehrer-PC dibadda laga gaari waayo.
check: tcpOpen(8, "203.0.113.80", 80)
check: tcpOpen(1, "198.51.100.10", 80)
check: tcpOpen(1, "198.51.100.10", 25)
check: tcpFails(1, "198.51.100.10", 22)
check: pingFails(1, 8)
:::

:::quiz mc
Lehrer-PC wuxuu ping u diraa `203.0.113.80`. Jawaabuhu ma soo noqonayaan?
- [x] Haa — ping-ga waxaa laga ogolaaday B → A, jawaabtuna waxay ka tirsan tahay state-kan
- [ ] Maya — ICMP ka imaanaysa dibadda rule uma jirto

:::

:::evaluate
Hubi jawaabta
:::

:::tip Qodob muhiim ah
**Firewall stateful ah** wuxuu xiriir kasta oo la ogolaaday ku qoraa **state table**, wuxuuna u gudbiyaa packets-ka xiriirkaas oo dhan **labada jihood**. Sidaas darteed rules-ka **connection setup** (Verbindungsaufbau) ayaa ku filan: “Gudaha wuxuu u bixi karaa dibadda” iyo “dibaddu waxay gaari kartaa oo keliya adeegyo gaar ah”. Xiriirrada dibadda laga bilaabo ee gala Schulnetz way xiran yihiin.
:::

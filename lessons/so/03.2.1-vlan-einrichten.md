# Switch hal, laba network

:::sim
url=/sims/lesson-3.2.1.btsim
:::

Switch-ka waxaa ku xiran afar PC: **Sekretariat** (Port 1) iyo **Schulleitung** (Port 2) oo ka tirsan maamulka, iyo sidoo kale **Anna** (Port 3) iyo **Ben** (Port 4) oo ka tirsan qolka kombiyuutarada. Dhammaantood waxay ku jiraan isla network-ka `192.168.0.0/24`.

## Dhibaatada

U beddel :fa-play: **Run** habka Habka Socodsiinta, ka fur :fa-terminal: **Terminal** **Anna**, kuna ping garee Sekretariat:

```
$ ping 192.168.0.10
```

Anna wuxuu gaadhaa Sekretariat si fudud. Taasi waa waxa aan rabno inaan ka hortagno.

## Dejinta VLANs

**VLAN** (*Virtual LAN*) waa network gooni ah oo go'doonsan oo ku dhex jira switch. VLAN kasta wuxuu leeyahay lambar, kaasoo ah **VLAN-ID**. Waxaan go'aamineynaa: Maamulku wuxuu galayaa **VLAN 10**, qolka kombiyuutarada wuxuu galayaa **VLAN 20**.

1. Habka Socodsiinta ku dhufo **Switch**-ka, kana fur Tab-ka **VLAN**.
2. Calaamadi **enable VLAN**. Waxay soo baxaysaa miis leh hal saf port kasta.
3. Tiirka **PVID** ku qor VLAN-ID — **port 1** iyo **port 2** mid kasta `10`, **port 3** iyo **port 4** mid kasta `20`. **Mode** u daa `untagged`.
4. Hoose ku dhufo **Apply**.

:::note
**PVID** waxay u taagan tahay *Port VLAN ID*: wax kasta oo ku yimaada port-kan wuxuu ka tirsan yahay VLAN-kan. Mode-ka `untagged` wuxuu macnaheedu yahay in port-kan ku xiran yahay PC caadi ah oo aan u baahnayn inuu wax ka ogaado VLANs.
:::

## Tijaabinta

Mar kale ka ping garee Sekretariat **Anna** — kadibna Ben (`ping 192.168.0.21`).

:::quiz mc
Maxaa hadda dhacaya?
- [ ] Anna wuxuu gaadhaa Sekretariat iyo Ben
- [x] Anna wuxuu gaadhaa Ben, laakiin mar dambe ma gaadho Sekretariat
- [ ] Anna ma gaadho cidna mar dambe
:::

:::evaluate
Hubi jawaabta
:::

Habka :fa-magnifying-glass: **Raad** ku fur trace u gaar ah **Sekretariat**: codsiyada ARP ee Anna („Who has 192.168.0.10?“) halkaas gabi ahaanba kuma muuqdaan. Broadcast-kiisu wuxuu ku harayaa VLAN 20 — switch-ka ayaa u arka kuwan hadda laba network oo kala go'an oo midba midka kale waxba ka ogayn.

:::tip Qodob muhiim ah
**VLANs** waxay switch u kala qaybiyaan dhowr network oo si macquul ah loo kala saaray. Aaladaha ku jira VLANs kala duwan si toos ah isu gaadhi karin — xataa broadcasts waxay ku hadhaan VLAN-kooda. VLAN kasta wuxuu leeyahay lambar, kaasoo ah **VLAN-ID**.
:::

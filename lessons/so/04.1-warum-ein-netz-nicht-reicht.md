# Sababta shabakad keliya aysan u filnayn

Goobta shaqada waxaad ku arkaysaa laba network oo yaryar oo shirkado: **Firma A** oo ay ku jiraan Anna (`192.168.0.10`) iyo Ben (`192.168.0.11`), iyo **Firma B** oo ay ku jiraan Clara (`172.16.0.10`) iyo David (`172.16.0.11`). Labada switch xitaa si toos ah ayaa isugu xiran fiilo.

## Ping ku jira network-kaaga

1. U beddel :fa-play: ** Run** — Habka Socodsiinta, ka fur :fa-terminal: **Terminal** **Anna**, kuna ping garee Ben:
   ```
   $ ping 192.168.0.11
   ```
2. U beddel :fa-magnifying-glass: **Raad** — habka raadka, ka fur trace **Anna**, kuna dhufo `Echo (ping) request`.
3. Ka fur protocol tree safka **Internet Protocol Version 4**. Kani waa qaybta IP ee packet-ka — qaybta cutubkan ku saabsan yahay.

:::quiz match
Source Address -> IP address-ka sender-ka
Destination Address -> IP address-ka receiver-ka
Time to Live -> Imisa router ayuu packet-ku weli maari karaa
Protocol -> Protocol-ka packet-ka ku jira (halkan ICMP, taasoo ah ping-ga)
:::

:::evaluate
Hubi isku-xirka
:::

## Ping gaaraya network kale

Ku noqo :fa-play: **Run** — Habka Socodsiinta, kuna ping garee Clara adigoo ka isticmaalaya **Anna** (`ping 172.16.0.10`). Ka dib mar kale eeg trace-ka Anna.

:::quiz mc
Maxaa dhaca?
- [ ] Ping-gu wuu shaqeeyaa — switches-ku waa isku xiran yihiin
- [x] Ping ma gaaro, trace-ka Anna-na ma ka muuqdo xitaa hal packet oo loo diray Clara — xitaa ARP request ma jiro
- [ ] Anna waxay dirtaa ARP request, laakiin Clara ma jawaabto
:::

:::quiz mc
Maxay Anna waxba u dirin?
- [ ] Fiilada u dhexeysa switches-ka waa jabantahay
- [ ] Clara waa damisan tahay
- [x] Anna waxay ka garanaysaa IP address-ka Clara in Clara ku jirto network kale — mana yaqaan wadada halkaas loo maro
:::

:::evaluate
Hubi jawaabaha
:::

## Waxa ka dambeeya

IP address waxay u shaqeysaa si la mid ah cinwaanka boostada: qayb waxay sheegtaa **network**-ka uu qalabku ku jiro (sida waddada), qaybta kalena waxay sheegtaa **qalabka** network-kaas ku jira ee la qabsanayo (sida lambarka guriga). Anna waxay ku jirtaa network-ka `192.168.0…`, Clara-na network-ka `172.16.0…` — laba "waddo" oo kala duwan.

Qalabyada ku jira network-gaaga *gaarka ah*, PC wuxuu packets u diraa si toos ah (iyada oo loo marayo ARP iyo switch, sidaad hore u taqaanay). Network *shisheeye* wuxuu u baahan yahay qalab isku xiraya networks-ka oo packets sii gudbiya: **router**. Halkan weli ma jiro — sidaas darteed fiilada u dhexeysa switches-ka waxba kama taraan.

:::tip Qodob muhiim ah
**Internet Protocol** (**IP**) ee layer 3 wuxuu hubiyaa in packets-ku gaaraan xitaa networks kala duwan dhexdooda. **IP address** waxay ka kooban tahay **network part** (network kee?) iyo **host part** (qalab kee?). Qalabyada isku network ah si toos ah ayay isu gaaraan — networks kale waxay u baahan yihiin **router**.
:::

Tani waxay keenaysaa laba su'aalood, kuwaas oo qaybaha soo socda ku saabsan yihiin: Sidee PC u ogaadaa *meesha saxda ah* ee cinwaanka ee network part-ku ku dhammaado? Router-kuna sidee buu u shaqeeyaa?

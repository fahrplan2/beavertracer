# Akhrinta iyo qorista IPv6 addresses

## Hexadecimal system

128 eber iyo hal ah qofna ma akhriyi karo — oo haddii loo qoro decimal numbers 16 kooxood ah, wax badan ma fiicnaan lahayn. Sidaas darteed, IPv6 addresses waxaa lagu qoraa **hexadecimal system** (oo loo soo gaabiyo *hex*). Waxay leedahay **16 lambar**: 0 ilaa 9, kadibna a ilaa f oo matalaya qiimaha 10 ilaa 15.

Faa'iidada weyn: hal hex digit waxay matashaa si sax ah **4 bit**.

| decimal | hex | binary | | decimal | hex | binary |
|---|---|---|---|---|---|---|
| 0 | 0 | 0000 | | 8 | 8 | 1000 |
| 1 | 1 | 0001 | | 9 | 9 | 1001 |
| 2 | 2 | 0010 | | 10 | a | 1010 |
| 3 | 3 | 0011 | | 11 | b | 1011 |
| 4 | 4 | 0100 | | 12 | c | 1100 |
| 5 | 5 | 0101 | | 13 | d | 1101 |
| 6 | 6 | 0110 | | 14 | e | 1110 |
| 7 | 7 | 0111 | | 15 | f | 1111 |

Haddaba hal byte (8 bit) waa laba hex digits oo sax ah: `11111111` = `ff` = 255. Tan hore ayaad u taqaannay: MAC addresses sida `aa:28:39:e2:41:82` iyaguna waxay ku qoran yihiin hex.

## Qaabka IPv6 address

IPv6 address waxay ka kooban tahay **sideed block**, mid kastaana leeyahay **16 bit** — taasi waa afar hex digits mid kasta —, oo ay kala soocaan labo dhibcood (colons):

```
2001:0db8:0000:0000:0000:0000:0000:0001
```

Sida IPv4 oo kale, waxaa jira network part iyo host part. Gudaha IPv6, network part waxaa la yiraahdaa **prefix**, host part-kana **Interface-ID**. Ku dhawaad had iyo jeer prefix-ku waa **64 bit** oo dheer (`/64`) — afarta block ee hore:

## Qoraalka gaaban

Sababtoo ah IPv6 addresses aad bay u dhaqaan, waa la soo gaabin karaa. Waxaa jira laba xeerar oo taas loogu talagalay:

1. **Eber hore oo ku jira block waa la saari karaa:** `0db8` → `db8`, `0001` → `1`, `0000` → `0`.
2. **Isku xigxiga blocks eber ah** waxaa lagu bedeli karaa `::` — laakiin **hal mar oo kaliya** address kasta. Haddii ay jiraan dhowr isku xigxig, midka ugu dheer ayaa la soo gaabiyaa.

Tusaale:

```
2001:0db8:0000:0000:0000:0000:0000:0001   vollständig
2001:db8:0:0:0:0:0:1                      Regel 1
2001:db8::1                               Regel 2
```

Maxay `::` hal mar kaliya u tahay? Marka la eego `2001::1::5`, qofna ma sheegi karo imisa eber-blocks ayaa maqan iyo meesha ay ku maqan yihiin. Hal `::` oo keliya waa cad yahay: waxaa maqan blocks tiradoodu tahay inta ay isku noqonayaan sideed guud ahaan.

:::tip Qodob muhiim ah
**IPv6 address** waxay leedahay **128 bit**, waxaana loo qoraa **8 blocks** oo mid kastaa leeyahay **4 hex digits**. 64-ka bit ee hore badiyaa waa **prefix** (network part), 64-ka bit ee dambe waa **Interface-ID** (host part). Soo gaabinta: ka dhaaf eber-yada hore oo **hal** isku xigxig oo eber-blocks ah ku bedel `::`.
:::

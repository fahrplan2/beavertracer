# Ka fiirsashada hore: Dynamic routing

Mashruuca, waxaad gacanta ku gelisay laba iyo toban routes oo loogu talagalay afar goobood. Network weyn oo shirkad leh wuxuu leeyahay boqollaal routers, internetkuna wuxuu leeyahay tobanaan kun — mar walbana meel baa xariiq ka go'da ama mid cusub lagu darayaa. Gacanta lagama maareyn karo mar dambe.

Sidaas darteed routers badanaa routes-kooda si toos ah ayay isu weydaarsadaan. Waxaa loo isticmaalaa **routing protocols**. Markaas waxaa la yiraahdaa **dynamic routing** — taas oo ka duwan **static routing**, halkaas oo wax walba gacanta lagu galiyo.

Routing protocols-ka ugu caansan:

| Protocol | Fikrad | Isticmaal caadi ah |
|---|---|---|
| **RIP** (*Routing Information Protocol*) | Router kasta wuxuu si joogto ah jaarkiisa (neighbours) u sheegaa networks-ka uu gaari karo iyo imisa routers (*hops*) ayuu u jiraa. | networks yar yar, tusaale wax-barasho |
| **OSPF** (*Open Shortest Path First*) | Router kasta wuxuu garanayaa khariidadda oo dhan ee network-ka, wuxuuna ka xisaabiyaa jidka ugu gaaban naftiisa. | networks-ka shirkadaha |
| **BGP** (*Border Gateway Protocol*) | Hawlgalayaasha networks-ka waaweyn (tusaale: internet providers) way isu sheegaan networks-ka ay gaari karaan. | internetka u dhexeeya providers-ka |

:::quiz match
RIP -> Routers waxay jaarkooda u sheegaan imisa hops ayay network ka fog yihiin
OSPF -> Router kasta wuxuu garanayaa network plan-ka oo dhan wuxuuna xisaabiyaa jidka ugu gaaban
BGP -> Wuxuu isku xiraa networks-ka internet providers-ka waaweyn
:::

:::tip Qodob muhiim ah
**Static routing** marka loo isticmaalo, administrator wuxuu gacanta ku galiyaa routes-ka oo dhan. **Dynamic routing** marka loo isticmaalo, routers waxay routes-kooda si toos ah isu weydaarsadaan iyagoo isticmaalaya **routing protocols** sida RIP, OSPF ama BGP — waxayna naftooda la qabsadaan marka xiriir go'o.
:::

BeaverTracer wuxuu simulate-gareyn karaa RIP, OSPF iyo BGP — waxaad ka heli doontaa Tab-yada router-ka ee magacyadaas wata. Koorsadan waxaan ku joogsanaynaa ka fiirsashada hore oo keliya.
:::

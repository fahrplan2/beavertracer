# Sequence diagram-ka

:::sim
url=/sims/lesson-5.1.btsim
:::

Socodka isku xidhiidh waxaa loo sawiraa **sequence diagram**: client iyo server mid walba waxay helaan xariiq toosan, wakhtiguna wuxuu ka socdaa kor ilaa hoos. Fallaar kasta waa hal packet. Waxaa loo sawiray si dalool ah (jiif), maxaa yeelay packet kasta wuxuu wakhti yar ku jiraa jidka.

Sidan ayuu u eg yahay xidhiidhkaagii bogga hore — la barbar dhig safar safar raadka (trace):

:::seq
Client-PC -> Server: SYN
Server -> Client-PC: SYN, ACK
Client-PC -> Server: ACK
Client-PC -> Server: PSH, ACK "Hello World" len=13
Server -> Client-PC: ACK
Server -> Client-PC: PSH, ACK len=13
Client-PC -> Server: ACK
Client-PC -> Server: FIN, ACK
Server -> Client-PC: ACK
Server -> Client-PC: FIN, ACK
Client-PC -> Server: ACK
:::

Fallaar kasta waxaa ka sarreeya **flags**, waxaa ka hooseeya lambarrada `SEQ` iyo `ACK`. **DATA** waxay calaamadisaa packets leh xog dhabta ah (payload). Lambarrada casaanka ah waxay u dhaxaan client-ka, kuwa buluugga ah server-ka — macnahooda waxaa lagu sharaxayaa bogga xiga.

## Flags-ka

| Flag | waxay u taagan tahay | Macnaha |
|---|---|---|
| **SYN** | *synchronize* | xidhiidh dhis, lambarka bilowga go'aami |
| **ACK** | *acknowledge* | xogta la helay xaqiijisa |
| **PSH** | *push* | xogta isla markiiba u gudbi barnaamijka |
| **FIN** | *finish* | „Waan dhammeeyay“ — xidhiidhka jooji |
| **RST** | *reset* | xidhiidh jooji ama diid (faahfaahin dheeraad ah 5.3.2) |

## Saddex marxaladood

**Dhisid:** Client-ku wuxuu diraa `SYN`, server-ku wuxuu ku jawaabaa `SYN, ACK`, client-kuna wuxuu xaqiijiyaa `ACK`. Maadaama saddex packet oo kaliya loo baahan yahay, waxaa la yiraahdaa **three-way handshake**.

**Xog:** Packet kasta oo xog leh waxaa receiver-ku xaqiijiyaa `ACK`. Halkan server-ku wuxuu soo celiyaa echo-ga — kaas oo client-kuna xaqiijiyo.

**Furfurid (xidhid):** Dhinac kastaa wuxuu si gooni ah u soo afjaraa jihada dirista: `FIN` ka timaadda client-ka, `ACK` ka timaadda server-ka — kadibna `FIN` ka timaadda server-ka, `ACK` ka timaadda client-ka. Kuwaas waa afar packet.

:::tip Qodob muhiim ah
Xidhiidhka TCP wuxuu socdaa saddex marxaladood: **dhisid** oo leh **three-way handshake** (`SYN` → `SYN, ACK` → `ACK`), **gudbinta xogta** (packet xog leh kasta waxaa lagu xaqiijiyaa `ACK`) iyo **furfurid** (dhinac kastaa wuxuu diraa `FIN` wuxuuna helaa `ACK`).
:::

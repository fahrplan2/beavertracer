# Soo koobid iyo wax xiga

## Qaybaha muhiimka ah oo kooban

| Qayb | Ujeeddada ilaalinta | Tusaale |
|---|---|---|
| **Symmetric encryption** | Qarsoodinimo (confidentiality) | AES waxay encrypt gareysaa xogta isku xidhka HTTPS |
| **Asymmetric encryption** | Qarsoodinimo, isweydaarsiga furayaasha | Diffie-Hellman, RSA |
| **Hash values** | Sax-ahaansho (integrity) | SHA-256 checksum ee download |
| **Digital signature** | Rasmi-ahaansho (authenticity), sax-ahaansho | Server-ku wuxuu saxiixaa qaybtiisa Diffie-Hellman |
| **Certificate** | Rasmi-ahaansho (authenticity) | wuxuu xaqiijiyaa: Furahan waxaa leh `www.biberbank.de` |

## Mabda' isku mid ah oo meelo badan ka jira

Wixii aad ka baratay HTTPS waxay ku jiraan farsamooyin kale oo badan:

- **WLAN (WPA2/WPA3):** Cutubka 3.3.2 qalab kasta oo ku jiray masaafada ayaa akhrin kari jiray xogta. Marka la isticmaalo WPA2 ama WPA3, frame kasta oo raadio ah waxaa lagu encrypt gareeyaa AES; WPA3 waxa kale oo uu furaha ku heshiiyaa si gaar ah, si qofka dhegeysanaya, xataa haddii uu haysto password-ka WLAN, uusan u decrypt gareyn karin duubisyadii hore.
- **SSH:** Maaraynta fogaanta ee la encrypt gareeyay ee Cutubka 6.6. Halkii uu isticmaali lahaa certificates, client-ku markii ugu horreysay ee uu ku xidhmo wuxuu xasuustaa **faraha-gacmeedka (fingerprint)** furaha server-ka, wuxuuna digniin bixiyaa haddii uu markii dambe isbeddelo.
- **VPN:** Tunnel la encrypt gareeyay oo internetka ku dhex maraya, tusaale ahaan ilaa network-ka dugsiga ama shirkadda. Tan waxaa lagu daaweeyaa Cutubka 10.
- **Messenger:** Signal, WhatsApp iyo kuwo kale waxay encrypt gareeyaan **Ende-zu-Ende (end-to-end)**: xataa qofka maamula adeegga ma akhriyi karo fariimaha.

:::note
**Quantum computers** waaweyn ayaa maalin uun jebin kara kala jajabinta tirooyinka waaweyn ee ah prime factors — sidaas darteed RSA iyo Diffie-Hellman. Sidaa darteed, maanta horeba waxaa la soo bandhigayaa habab cusub oo **quantum-safe** ah. Habab symmetric ah sida AES oo leh furayaal dhaadheer weli waa la rumaysan yahay inay badbaadsan yihiin.
:::

## Isku imtixaan

:::quiz mc
Marka la isticmaalo HTTPS, xogta dhabta ah waxaa lagu encrypt gareeyaa …
- [ ] RSA, sababtoo ah waa tan ugu badbaadsan
- [x] habka symmetric sida AES iyo furaha session-ka oo lagu heshiiyay
- [ ] furaha gaarka ah (private key) ee server-ka
:::

:::quiz mc
Waxaad furtay `https://www.biberbank.de/`, Browser-kuna wuxuu sheegayaa “Certificate-ka waxaa loo bixiyay `www.gewinn-biber.de`”. Maxaad samaynaysaa?
- [ ] Riix “Sii wad si kastaba” — isku xidhku weli waa encrypted
- [x] Jooji — waxaa laga yaabaa in Browser-ku uusan la hadlayn bangiga
- [ ] Bogga ka fur `http://`, markaas digniin ma imaan doonto
:::

:::quiz multi
Muuqaallada soo socda kuwee ayaa sax ah?
- [x] Hash value gebi ahaanba wuu isbeddelaa marka xogta xitaa wax yar isbeddesho
- [x] Signature waxaa lagu sameeyaa furaha gaarka ah (private key), waxaana lagu hubiyaa kan guud (public key)
- [x] Root-CAs waxay horay ugu rakiban yihiin Browser-ka ama nidaamka hawlgalka
- [ ] Marka la isticmaalo HTTPS, qofka dhegeysanaya xataa ma arki karo IP address-ka server-ka
- [ ] SMTPS waxay encrypt gareysaa mailka xataa mail server-ka gudahiisa
:::

:::quiz fill
HTTPS waa HTTP oo ku shaqeeya {TLS} wuxuuna caadi ahaan isticmaalaa port {443}. Server-ku wuxuu is-caddeeyaa {certificate} uu saxiixay {CA|Certificate Authority}.
:::

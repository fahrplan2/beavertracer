# Router badan

:::goal
**Hadafka waxbarashada:** Waxaad awoodaa inaad akhrido routing tables, geliso static routes, raacdo jidka packet adigoo isticmaalaya `traceroute`, oo aad hesho cilladaha caadiga ah ee routing.
:::

Ilaa hadda, labada network dhexdooda had iyo jeer waxaa ku jiray hal router oo keliya — wuxuuna aqoonay labada network, maxaa yeelay si toos ah ayuu ugu xirnaa. Laakiin internetka, sender iyo meesha loo socdo dhexdooda inta badan waxaa ku jira router badan oo isku xigta. Sidee mid kasta uga ogaadaa halka uu packet ku soo diro marka xigta?

Jawaabtu waxay ku jirtaa **routing table** -kiisa. Sida loo akhriyo iyo sida adigu naftaadu ugu dari lahayd, waxaad ku baranaysaa qaybtan.

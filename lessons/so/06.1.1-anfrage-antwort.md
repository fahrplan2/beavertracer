## Sida codsigu u eg yahay

Ku guji trace-ka packet-ka `GET / HTTP/1.1` oo fur **Hypertext Transfer Protocol**. Codsiga HTTP waa qoraal saafi ah:

```
GET / HTTP/1.1              ← Methode, Pfad, Version
Host: 192.168.0.20          ← Header: zusätzliche Angaben
…
                            ← Leerzeile: Ende der Anfrage
```

Jawaabta server-ku sidaas oo kale ayay u dhisan tahay — waxay leedahay safka xaaladda (status line), header-yo, sadar madhan, ka dibna faylka laftiisa:

```
HTTP/1.1 200 OK             ← Version, Statuscode, Text
Content-Type: text/html     ← Header: Art der Datei
Content-Length: 301         ← Header: Größe in Byte
                            ← Leerzeile
<!doctype html> …           ← die Datei selbst
```

:::seq
mode: text
Client-PC -> Server: GET / | HTTP-codsi
Server -> Client-PC: 200 OK | index.html
Client-PC -> Server: GET /style.css | HTTP-codsi
Server -> Client-PC: 200 OK | style.css
:::

## Methods iyo status codes

**Method**-ku wuxuu sheegayaa waxa client-ku rabo:

| Method | Macnaha |
|---|---|
| **GET** | soo qaad fayl |
| **POST** | data u dir server-ka, tusaale foom la buuxiyey |
| **HEAD** | soo qaad kaliya header-yada, la'aanta faylka |

**Status code**-ku wuxuu sheegayaa sida wax u socdeen. Lambarka ugu horreeya wuxuu muujiyaa nooca jawaabta:

| Code | Qoraal | Macnaha |
|---|---|---|
| **200** | OK | wax walba way hagaagsan yihiin |
| **301** | Moved Permanently | bogga si joogto ah ayuu u guuray |
| **404** | Not Found | faylkaas ma jiro |
| **405** | Method Not Allowed | method-kan halkan lagama ogola |
| **500** | Internal Server Error | khalad ka jira server-ka |

`2xx` waxay macnaheedu yahay guul, `3xx` jihaynta dib (redirection), `4xx` khalad ka yimid client-ka (codsi khaldan), `5xx` khalad ka yimid server-ka.

:::tip Qodob muhiim ah
**HTTP** wuxuu u shaqeeyaa **mabda'a codsi-jawaab**: client-ku wuxuu diraa **codsi** (method sida `GET`, path, header-yo), server-ku wuxuu ku jawaabaa **status code** (tusaale `200 OK`, `404 Not Found`), header-yo iyo faylka. Fayl kasta oo bog web ah wuxuu leeyahay codsi gaar ah.
:::

:::

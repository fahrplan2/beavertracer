# Network address, broadcast address iyo hosts

Network kasta waxaa ku jira laba cinwaan oo shaqo gaar ah leh:

- **Network address** waa cinwaanka **ugu hooseeya** ee network-ka: dhammaan bits-ka ku jira host part waa 0. Waxay tilmaamaysaa network-ka oo dhan, tusaale ahaan routing tables dhexdooda.
- **Broadcast address** waa cinwaanka **ugu sarreeya** ee network-ka: dhammaan bits-ka ku jira host part waa 1. Wax kasta oo loo diro waxay aadaan dhammaan aaladaha network-ka ku jira.

Labadan cinwaan midna **looma qoondeeyo** aaladaha. Dhammaan cinwaannada u dhexeeya waxaa loo heli karaa aaladaha (**hosts**).

## Tusaale fudud

`192.168.0.12/24` — host part waa octet-ka ugu dambeeya:

| | Cinwaan |
|---|---|
| Network address (host part = 0) | `192.168.0.0` |
| Broadcast address (host part = 255) | `192.168.0.255` |
| Xadka loogu talagalay hosts | `192.168.0.1` – `192.168.0.254` |
| Tirada hosts | 254 |

## Marka xadku dhexda octet-ka ku yaal

Waxay noqotaa wax ka adag marka prefix length aanay ahayn jibaar ah 8. Markaas octet-ka khuseeya u beddel binary system. Tusaale: `194.9.190.12/27`.

Saddexda octet ee ugu horreeya gabi ahaanba waxay ka tirsan yihiin [[n|network part]] (24 bit). Octet-ka ugu dambeeya, **3 bit** ayaa weli ka tirsan network part (24 + 3 = 27), **5 bit** ee harayna waxay ka tirsan yihiin [[h|host part]]:

| | octet-ka ugu dambeeya (binary) | decimal |
|---|---|---|
| IP address | [[n|000]][[h|01100]] | 12 |
| Netmask (`/27`) | [[n|111]][[h|00000]] | 224 |
| Network address: host bits u beddel 0 | [[n|000]][[h|00000]] | **0** |
| Broadcast address: host bits u beddel 1 | [[n|000]][[h|11111]] | **31** |

Natiijo:

- Network address: `194.9.190.0`
- Broadcast address: `194.9.190.31`
- Xadka loogu talagalay hosts: `194.9.190.1` – `194.9.190.30`
- Tirada hosts: 2⁵ − 2 = **30**

:::tip Qodob muhiim ah
**Network address:** dhammaan host bits waa 0 (cinwaanka ugu hooseeya). **Broadcast address:** dhammaan host bits waa 1 (cinwaanka ugu sarreeya). Midna looma qoondeeyo aaladaha. Network leh prefix length *n* wuxuu leeyahay **2<sup>32 − n</sup> − 2** cinwaan oo loo isticmaali karo hosts.
:::

:::tip Talo: cabbirka block-ga
Haddiiaad fahantay habka binary system, waxaa jira jid gaaban: **256 oo laga jaray octet-ka mask-ga** wuxuu bixiyaa cabbirka network-ka octet-kaas dhexdiisa. Marka uu yahay `/27` (mask 224) waa 256 − 224 = **32**. Network-yadu markaas waxay bilaabmaan 0, 32, 64, 96 … — cinwaanka `.12` wuxuu ku jiraa network-ka ka bilaabma `.0`, cinwaanka `.70` wuxuu ku jiraa network-ka ka bilaabma `.64`.
:::

## Cabbirrada network ee ugu muhiimsan

| Prefix | Netmask | Hosts |
|---|---|---|
| `/8` | `255.0.0.0` | 16 777 214 |
| `/16` | `255.255.0.0` | 65 534 |
| `/24` | `255.255.255.0` | 254 |
| `/25` | `255.255.255.128` | 126 |
| `/26` | `255.255.255.192` | 62 |
| `/27` | `255.255.255.224` | 30 |
| `/28` | `255.255.255.240` | 14 |
| `/29` | `255.255.255.248` | 6 |
| `/30` | `255.255.255.252` | 2 |

:::note
Network-ga ugu yar ee caadi ka ah dhaqanka waa `/30`: wuxuu leeyahay saxan laba cinwaan oo la isticmaali karo, waxaana inta badan loo adeegsadaa isku xidhka u dhexeeya laba router. `/32` wuxuu tilmaamaa hal cinwaan oo keliya — sida network looma isticmaali karo, laakiin wuxuu ka muuqdaa routing tables iyo xeerarka firewall.
:::

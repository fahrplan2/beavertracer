# Subnetting tallaabo-tallaabo

Qaybtan, bits-ka waxaa lagu calaamadeeyay midabo: [[n|network part]] · [[e|kordhin]] · [[h|host part]]

## Fikradda

Male dhul weyn oo loo qaybinayo qaybo isku cabbir ah. Subnetting-ka, dhulka weyn waa network-gii asalka ahaa, qaybahuna waa subnets.

Farsamo ahaan waxa dhacaya waa kan: network wuxuu ka kooban yahay network part iyo host part. Subnetting-ka, waxaad qaadataa dhawr bit oo ka mid ah **bilowga host part**, oo ku dartaa **network part**. Bits-kan dheeraadka ah waxaa la yiraahdaa **kordhin** (ama *subnet bits*). Isku-darka suurtagalka ah ee bits-ka kordhinta kasta wuxuu keenaa subnet u gaar ah.

<pre class="bits-block">
ka hor (/24):  [[n|NNNNNNNN.NNNNNNNN.NNNNNNNN]].[[h|HHHHHHHH]]
ka dib (/26):  [[n|NNNNNNNN.NNNNNNNN.NNNNNNNN]].[[e|EE]][[h|HHHHHH]]
</pre>

## Immisa bit ayaa loo baahan yahay?

Marka ay jiraan *n* bits oo kordhin ah, waxaa jira 2*ⁿ* isku-darro — sidaas darteed 2*ⁿ* subnets:

| Bits-ka kordhinta | Isku-darrada | Subnets |
|---|---|---|
| 1 | 0, 1 | 2 |
| 2 | 00, 01, 10, 11 | 4 |
| 3 | 000, 001, … 111 | 8 |
| 4 | 0000 … 1111 | 16 |

Tusaale ahaan, haddii loo baahan yahay **saddex** subnets, 1 bit (kaliya 2 networks) kuma filna — waxaad qaadanaysaa 2 bits oo helaysaa **afar** subnets. Mid waxaa loo hayaa keydka.

## Tusaale 1: Laba subnet, si faahfaahsan

Network-ga `192.168.42.0/24` waa in loo qaybiyaa **laba** subnets oo isku cabbir ah.

**Tallaabo 1 — Immisa bits?** Laba subnets waxaa ku filan **1 bit** (2¹ = 2).

**Tallaabo 2 — Prefix length cusub iyo netmask.** `/24` wuxuu noqonayaa `/24 + 1 = /25`. Mask-gu hadda wuxuu leeyahay 25 ones:

<pre class="bits-block">
[[n|11111111.11111111.11111111]].[[e|1]][[h|0000000]]   →   255.255.255.128
</pre>

**Tallaabo 3 — Network address ku qor binary system oo calaamadee.** Saddexda octet ee ugu horreeya ma isbeddelaan. Octet-ka ugu dambeeya, bit-ka ugu horreeya waa kordhinta (E), inta kale waa host part (H):

<pre class="bits-block">
[[n|192.168.42.]] [[e|0]] [[h|0 0 0 0 0 0 0]]
            [[e|E]] [[h|H H H H H H H]]
</pre>

**Tallaabo 4 — Isku-darro kasta oo kordhinta ah, ka dhig network address iyo broadcast address.** Kordhinta mar waxaa loo dhigaa 0 mar kalena 1. Network address-ka, host bits-ka oo dhan waa 0, broadcast address-ka oo dhan waa 1:

| Subnet | E | Host bits | octet-ka ugu dambeeya | Address |
|---|---|---|---|---|
| 1 — network address | [[e|0]] | [[h|0000000]] | 0 | `192.168.42.0` |
| 1 — broadcast address | [[e|0]] | [[h|1111111]] | 127 | `192.168.42.127` |
| 2 — network address | [[e|1]] | [[h|0000000]] | 128 | `192.168.42.128` |
| 2 — broadcast address | [[e|1]] | [[h|1111111]] | 255 | `192.168.42.255` |

**Tallaabo 5 — Natiijada qor:**

| Subnet | Network address | Broadcast address | Xadka hosts-ka | Hosts |
|---|---|---|---|---|
| 1 | `192.168.42.0/25` | `192.168.42.127` | `.1` – `.126` | 126 |
| 2 | `192.168.42.128/25` | `192.168.42.255` | `.129` – `.254` | 126 |

## Tusaale 2: Afar subnet

Isla network-ga `192.168.42.0/24`, markan **afar** subnets.

**Tallaabo 1:** 4 subnets → **2 bits** (2² = 4).

**Tallaabo 2:** `/24 + 2 = /26`, mask [[n|11111111.11111111.11111111]].[[e|11]][[h|000000]] = `255.255.255.192`.

**Tallaabo 3:** Octet-ka ugu dambeeya, hadda labada bit ee ugu horreeya waa **kordhinta**: [[e|EE]][[h|HHHHHH]].

**Tallaabo 4:** Kordhintu waxay binary system-ka ku tirtirtaa kor: 00, 01, 10, 11. Isku-darro kasta, host bits-ka mar ka dhig 0 mar kalena 1:

| Subnet | EE | Network address (host bits 0) | Broadcast address (host bits 1) |
|---|---|---|---|
| 1 | [[e|00]] | [[e|00]][[h|000000]] = **0** | [[e|00]][[h|111111]] = **63** |
| 2 | [[e|01]] | [[e|01]][[h|000000]] = **64** | [[e|01]][[h|111111]] = **127** |
| 3 | [[e|10]] | [[e|10]][[h|000000]] = **128** | [[e|10]][[h|111111]] = **191** |
| 4 | [[e|11]] | [[e|11]][[h|000000]] = **192** | [[e|11]][[h|111111]] = **255** |

**Tallaabo 5 — Natiijada:**

| Subnet | Network address | Broadcast address | Xadka hosts-ka |
|---|---|---|---|
| 1 | `192.168.42.0/26` | `192.168.42.63` | `.1` – `.62` |
| 2 | `192.168.42.64/26` | `192.168.42.127` | `.65` – `.126` |
| 3 | `192.168.42.128/26` | `192.168.42.191` | `.129` – `.190` |
| 4 | `192.168.42.192/26` | `192.168.42.255` | `.193` – `.254` |

Subnet kasta wuxuu leeyahay 2⁶ = 64 addresses, kuwaas oo 62 loogu talagalay hosts.

Wax ma ogaatay? Subnets-ku waxay isku xigaan **iyada oo aan farqi jirin**: mid kastaa wuxuu bilaabmaa isla marka uu dhammaado broadcast address-kii kii ka horreeyay. Broadcast address-ka subnet-ka ugu dambeeya waa sida saxda ah broadcast address-ka network-gii asalka ahaa — sidaas ayaad natiijadaada ku hubin kartaa.

:::tip Qodob muhiim ah: Subnetting shan tallaabo ah
1. **Immisa subnets?** U kor qaad awoodda 2-da ee ugu dhow → *n* bits oo kordhin ah.
2. **Prefix length cusub** = prefix length hore + *n*; kaas ka soo saar **netmask** cusub.
3. **Network address ku qor binary system** oo calaamadee network part, kordhinta iyo host part.
4. **Kordhinta kor u tirtir** (00, 01, 10, …): host bits 0 → network address, host bits 1 → broadcast address.
5. **Hubin:** Subnets-ku waxay isku xigaan iyada oo aan farqi jirin, kan ugu dambeeya wuxuu ku dhammaadaa broadcast address-ka network-gii asalka ahaa.
:::

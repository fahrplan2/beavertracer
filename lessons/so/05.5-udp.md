# UDP: fududeyn weyn

:::goal
**Hadafka waxbarashada:** Waxaad karaysaa inaad UDP la barbar dhigto TCP, oo aad sharaxdo codsiyada UDP u tahay doorashada ugu fiican.
:::

:::sim
url=/sims/lesson-5.5.btsim
:::

TCP wuxuu qabtaa shaqo badan — connection setup, xaqiijinno (acknowledgements), retransmission, iyo habaynta isku xigga. Laakiin tani waxay qaadataa waqti iyo packets dheeraad ah. Borotokoolka labaad ee muhiimka ah ee transport layer wuxuu iska dhaafaa ku dhawaad wax walba oo taas ka mid ah: **User Datagram Protocol** (**UDP**). Packets-kiisa waxaa la yiraahdaa **datagrams**.

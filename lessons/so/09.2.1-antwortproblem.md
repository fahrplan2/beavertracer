# Dhibaatada jawaabta

:::sim
url=/sims/lesson-9.2.btsim
:::

Firewall-ku hadda wuxuu u shaqeynayaa sida whitelist: siyaasadda caadiga ah waa **Alle verwerfen**. Hal xeer ayaa u ogolaanaya shabakadda dugsiga inay browse sameyso: **B → A, TCP, Ziel-Port 80, Zulassen**. Habka waa **Stateless**.

## Tijaabada

1. U gudub habka :fa-play: **Habka Socodsiinta** oo **Lehrer-PC** ku fur :fa-globe: **Browser** `http://203.0.113.80/`.
2. Gudaha **Firewall** eeg **Protokoll** iyo **Treffer**.

:::quiz mc
Maxaa ka dhaca browser-ka?
- [ ] Bogga www.beispiel.de ayaa soo muuqda
- [x] Bogga ma soo dhacayo, browser-ku wuu sugayaa dhammaadkana wuxuu soo sheegayaa cilad
:::

:::quiz mc
Which packets ayaa ku jira protocol-ka firewall-ka sida la tuuray (`DROP`)?
- [ ] Codsiyada Lehrer-PC ee port 80
- [x] Jawaabaha `203.0.113.80` ee leh **Quellport 80** oo loo diray Lehrer-PC
- [ ] Mid kaliya ma jiro
:::

:::quiz short
Jihada muxuu u socdaa packets-ka la tuuray (A→B mise B→A)?
= A→B
= A → B
= AtoB
:::

:::evaluate
Hubi jawaabaha
:::

Codsiga Lehrer-PC wuu bixi karaa — laakiin `SYN, ACK` ee web server-ka xataa ma soo laaban karo, sababtoo ah jihada A → B xeer ku habboon ma jiro, sidaas darteed waxaa shaqeynaya **Alle verwerfen**.

## Xalka fudud

Qofku wuxuu geli karaa xeer labaad: **A → B, TCP, Quell-Port 80, Zulassen** — „wax kasta oo ka imanaya port 80 waa laga soo geli karaa“. Markaas browse-ku runtii wuu shaqeynayaa.

:::quiz mc
Why ayay xeerkani khatar u yahay?
- [ ] Sababtoo ah web server-yadu weligood ma isticmaalaan port 80 sida source port
- [x] Weeraryahanku wuxuu si fudud u diri karaa packets-kiisa isagoo adeegsanaya source port 80 — kadibna firewall-ku wuxuu u ogolaanayaa inay maraan **port kasta** oo ku jira shabakadda dugsiga
- [ ] Sababtoo ah markaas bogagga webka way gaabis noqonayaan
:::

:::evaluate
Hubi jawaabta
:::

Source port-ka wuxuu go'aamiyaa sender-ka laftiisa — firewall ma talo saari karo. Firewall aan xaaladda xasuusan (stateless) ma ogo in packet uu yahay **jawaab codsi ah** mise **isku day cusub oo xidhiidh ah** oo debadda ka yimid. Habka xaaladda xasuusta (stateful) ayaa taas bedelaya.

:::tip Qodob muhiim ah
Packet filter **stateless** ah wuxuu hubiyaa packet kasta si gooni ah. Jawaabuhu markaas waxay u baahan yihiin xeerar u gaar ah jihada dambe — xeerarkaas oo kale (tusaale: „Quellport 80 waa laga soo geli karaa“) weeraryahanku wuu si xun u adeegsan karaa, sababtoo ah sender-ku wuxuu si xor ah u dooran karaa source port-ka.
:::

# HTTPS

:::osi 5
:::

**HTTPS** (*HTTP Secure*) waa HTTP caadi ah — marka laga reebo inaanu si toos ah ugu socon TCP, ee uu marayo layer sir-qarsoodi ah oo u dhexeeya: **TLS** (*Transport Layer Security*). Kii ka horreeyay TLS waxaa la odhon jiray **SSL**; sidaas darteed dad badan ayaa wali ku hadla "SSL certificates".

```
ohne Verschlüsselung:   HTTP  →  TCP  →  IP
mit Verschlüsselung:    HTTP  →  TLS  →  TCP  →  IP
```

HTTP wax ka ogaan maayo arrintan: wuxuu soo diraa codsiyadiisa sidii caadiga ahayd, TLS ayaa sir-qarsoodiyeysa, TCP-na wuu qaadaa. Qaabka OSI gudahiisa TLS wuxuu u dhexeeyaa transport layer iyo application layer, sidaa awgeed wuxuu ku jiraa layer 4/5 — wuxuu ku dhisan yahay TCP wuxuuna maareeyaa session la xaqiijiyay.

| | HTTP | HTTPS |
|---|---|---|
| Port | 80 | **443** |
| Cinwaan | `http://…` | `https://…` |
| Nuxurka ma lagu akhrin karaa Tracer-ka? | haa | maya |
| Browser wuxuu muujiyaa | "ma ammaan ah" | quful |

TLS wuxuu xilligii connection setup sameeyaa wax walba oo aad cutubkan ku baratay:

- Server-ku wuxuu isku caddeeyaa **certificate**-kiisa (**xaqiijinta aqoonsiga**).
- Labada dhinac waxay isla qorsheeyaan **furaha session-ka** iyagoo adeegsanaya **Diffie-Hellman** — server-ku wuxuu **saxiixaa** qaybtiisa.
- Kadib, xogta oo dhan waxaa lagu sir-qarsoodiyaa **AES** (**sirnimada**) waxaana laga ilaaliyaa isbeddel (**sugnaanta xogta**).

Mabda'a looma xaddidin webka: E-mail (qaybta 8.4) iyo borotokoolal kale oo badan ayaa sidoo kale ku shaqeeya TLS si isku mid ah.

Qaybaha soo socda waxaad ku dhex-eegi doontaa HTTPS Tracer-ka, adigaa dhisi doona, waxaadna baari doontaa goorta uu browser-ku digayo — iyo sababta.

# Cilad-raadin: Laptop-yada network ma heli karaan

:::sim
url=/sims/lesson-6.4.3.btsim
:::

Ka dib fasaxa, macallimiintu waxay soo wargeliyaan: „Laptop-yadayadu mar dambe network-ka ma galaan!“ Labada laptop waa la dhigay **DHCP**. Sida qorshaha ku xusan, DHCP server-ku wuxuu qaybin lahaa cinwaannada laga bilaabo `192.168.0.100` ilaa `192.168.0.120`, isagoo la socda gateway `192.168.0.1` iyo DNS server `192.168.0.53`.

Raadi khaladaadka oo hagaaji.

<details>
<summary>Talo 1: Cinwaanno noocee ah ayay laptop-yadu haystaan?</summary>

Eeg :fa-gear: **IP Settings** ee laptop-ka. Cinwaan ku bilaabma `169.254` waa mid qalabku **isagu is siiyay** — sababtoo ah DHCP server ma jawaabin.
</details>

<details>
<summary>Talo 2: DHCP server-ku ma jawaabayaa?</summary>

Fur trace laptop-ka. Ma arkaysaa kaliya `DHCP Discover` — mise jawaab ayaa sidoo kale jirta? Kadib eeg app-ka **DHCP Server**: ma socdaa? Oo muxuu bartilmaameed (range) qaybiyaa?
</details>

<details>
<summary>Talo 3: Cinwaan cusub ka soo qaad</summary>

Haddii aad server-ka wax ka badashay, habka laptop-ka ee IP Settings si kooban ugu beddel **Static** kadibna dib ugu celi **DHCP**, kadibna riix **Apply** — markaas wuxuu mar kale weydiin doonaa.
</details>

:::task
title: Laptop-yadu ma network-ka ku soo noqdeen?
Hubi in labada laptop ay leeyihiin cinwaan ka mid ah range-ka la qorsheeyay oo ay gaari karaan DHCP server-ka. Simulation-ku waa inuu u socdaa Habka Socodsiinta.
check: ip(3, "192.168.0.96/27")
check: ip(4, "192.168.0.96/27")
check: pingOk(3, 2)
check: pingOk(4, 2)
:::

## Maxaa dhacay?

:::quiz multi
Hadalada soo socda kuwee ayaa sax ah?
- [x] DHCP server-ku ma bilaaban — laptop-yadu waxay is siiyeen cinwaan `169.254`
- [x] Range-ka cinwaannada wuxuu ku jiray network khaldan (`192.168.1.…` halkii uu ka ahaan lahaa `192.168.0.…`)
- [ ] Laptop-yada waxaa loo dhigay cinwaanno go'an
- [ ] Gateway wuxuu ka maqnaa switch-ka
:::

:::evaluate
Hubi jawaabta
:::

:::tip Qodob muhiim ah
Haddii qalab leeyahay cinwaan ka mid ah **`169.254.0.0/16`**, wuxuu ka helay **jawaab la'aan DHCP server** oo wuxuu is siiyay cinwaan (**APIPA**). Kaliya wuxuu la xiriiri karaa qalab kale oo isla xaalad ah. Kadib hubi: DHCP server-ku ma socdaa? Ma la gaari karaa? Oo ma qaybiyaa cinwaanno ka mid ah **network-ka saxda ah**?
:::

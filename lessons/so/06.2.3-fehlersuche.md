# Cilad-raadin: Magacu ma shaqeeyo

:::sim
url=/sims/lesson-6.2.3.btsim
:::

Macallimad ayaa wargelisay: „`www.beaver-schule.de` ma furmo. Laakiin `http://192.168.0.20` way shaqaysaa!“ Sidan ayaa loo *dejiyay* inay u habaysan tahay:

| Maxay tahay | Habaynta saxda ah |
|---|---|
| DNS server-ka ee Client-PC | `192.168.0.53` (DNS-Resolver) |
| Gelitaanka ku jira Schul-DNS | `www.beaver-schule.de` → `192.168.0.20` |

Raadi khaladaadka oo hagaaji.

<details>
<summary>Tilmaan 1: Maxay nslookup leedahay?</summary>

Ku qor Client-PC `nslookup www.beaver-schule.de`. Which server ayuu `nslookup` weydiiyay — oo maxaa dib u soo noqday? (Jawaabtu waxay qaadataa dhowr ilbiriqsi.)
</details>

<details>
<summary>Tilmaan 2: Haddeynu hadda?</summary>

Haddii aad jawaab hesho, barbar dhig cinwaanka iyo qorshaha. Magacan xaggee lagu galiyay?
</details>

:::task
title: Magac-xalinta ma la hagaajiyay?
Waxay hubisaa in Client-PC uu www.beaver-schule.de u xalliyo cinwaanka saxda ah. Simulation-ku waa inuu u socdaa Habka Socodsiinta.
check: resolves(2, "www.beaver-schule.de", "192.168.0.20")
:::

## Maxaa dhacay?

:::quiz multi
Which hadallada ayaa sax ah?
- [x] Client-PC waxaa loo geliyay `192.168.0.35` sidii DNS server — halkaas cidina uma jawaabto
- [x] Gudaha Schul-DNS, `www.beaver-schule.de` wuxuu tilmaamayay `192.168.0.21` halkii uu ka ahaan lahaa `192.168.0.20`
- [ ] Web server-ka waa la damiyay
- [ ] Root server-ku ma garanayn domain-ka `.de`
:::

:::evaluate
Hubi jawaabta
:::

:::tip Qodob muhiim ah
Haddii xiriirku ku shaqeeyo **IP address** laakiin uusan ku shaqayn **magaca**, dhibaatadu waxay ku jirtaa **DNS**. Marka hore hubi **DNS server-ka la geliyay** (ma jawaabaa xitaa?), kadibna hubi **gelitaanka** laftiisa (cinwaanku ma sax baa?). `nslookup` wuxuu muujiyaa labadaba: server-ka la weydiiyay iyo wixii uu ku jawaabay.
:::

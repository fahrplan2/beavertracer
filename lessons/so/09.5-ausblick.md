# Soo koobid iyo ujeedada xigta

## Firewalls meelo badan

Packet filter-ka cutubkan waxaad ka heli doontaa qalab badan:

- **Home router:** Home router kasta waa sidoo kale stateful firewall. Marka la isticmaalayo IPv4, NAT wuxuu qayb ka mid ah shaqadan qaataa: Dibadda ka dhex ma jiro qof bilaabi kara xidhiidh, ilaa uu jiro port forward (Cutubka 7). Marka la isticmaalayo IPv6, qalab kasta wuxuu leeyahay cinwaan dadweyne — markaas qaanuunka firewall-ka ee „dibadda waxba cusub ha soo gelin“ keligiis ayaa bixiya ilaalin isku mid ah.
- **Personal Firewall:** Windows, macOS iyo Linux dhammaantood waxay leeyihiin firewall ku dhex dhisan kombuyuutarka laftiisa. Waxay ilaaliyaan qalabka xitaa network shisheeye, tusaale ahaan WLAN-ka makhaayad, waxayna samayn kartaa xeerar barnaamij kasta u gaar ah.
- **Next-Generation-Firewall** iyo **Web Application Firewall (WAF):** Kuma eegaan oo keliya cinwaannada iyo ports-ka, laakiin waxay eegaan nuxurka packets-ka — ilaa application layer. Sidaas ayay u ogaadaan tusaale ahaan weeraro ku jira codsiyada HTTP. Marka HTTPS la isticmaalayo, waa inay jebiyaan encryption-ka si ay tan u sameeyaan (Cutubka 8).
- **IDS/IPS:** *Intrusion Detection System* wuxuu ogaadaa qaabab shaki leh oo ku jira data traffic-ka wuxuuna bixiyaa digniin; *Intrusion Prevention System* wuxuu dheeraad ahaan laftiisa xannibaa.

:::note
Firewall waa **hal** dhisme oo ammaanka ka mid ah. Ma caawiyo haddii adeeg la oggol yahay (tusaale ahaan web server-ka) laftiisu leeyahay daloolo, haddii qof furo barnaamij xun oo e-mail ah, ama haddii password-ku daciif yahay. Sidaa darteed updates, passwords ammaan ah, encryption iyo qaybin caqli leh oo network-ka ah (DMZ, VLANs ee Cutubka 3) had iyo jeer way ka mid yihiin.
:::

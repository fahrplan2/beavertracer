## Layer-layer u fur

Guji saddexagalka yar ee ka horreeya **Ethernet**, **Internet Protocol Version 4**, **Transmission Control Protocol** iyo **Hypertext Transfer Protocol**. Layer kasta wuxuu keenaa macluumaadkiisa u gaarka ah:

| Layer-ka geedka ku jira | Waxa ku ogaan karto | Waxa loogu talagalay |
|---|---|---|
| Ethernet | `Source` iyo `Destination`: MAC addresses sida `aa:57:28:…` | network card-ka kuwee ee ku jira local network |
| IPv4 | `Source Address` `192.168.0.10`, `Destination Address` `192.168.0.20` | kombuyuutarkee — xitaa marka network xuduudihiisa laga gudbo |
| TCP | `Source Port` `49152`, `Destination Port` `80` | barnaamijkee ee kombuyuutarka ku jira |
| HTTP | `GET / HTTP/1.1`, `Host: 192.168.0.20` | fariinta dhabta ah ee browser-ka |

Sidoo kale fiiri labadan sadar: Ethernet wuxuu leeyahay `Type: IPv4`, IPv4 wuxuu leeyahay `Protocol: TCP`. Sidaas darteed layer kasta wuxuu muujiyaa *waxa ku jira gudaheeda* — sidaas ayuu receiver-ku u ogaadaa sida uu u sii furfuri lahaa.

## Baqshad ku dhex jirta baqshad

Waxa aad hadda aragtay waxay sender-ka ugu abuurmaan sidan:

1. Browser-ku wuxuu qoraa fariinta dhabta ah: `GET / HTTP/1.1` (**HTTP**).
2. **TCP** wuu duubaa oo wuxuu hortiisa ku qoraa ports — si ay u gaarto barnaamijka saxda ah.
3. **IP** wuxuu duubaa wax walba oo wuxuu hortooda ku qoraa IP addresses — si ay u gaarto kombuyuutarka saxda ah.
4. **Ethernet** wuxuu wax walba geliyaa frame leh MAC addresses — si ay ugu gaarto network card-ka saxda ah ee local network-ga.

Receiver-ka, wax walba waxay u shaqeeyaan si ka duwan: layer kasta wuxuu qaataa qaybtiisa oo inta kale kor ugu gudbiyaa. Waa sida warqad lagu dhex geliyey dhawr baqshadood — gudaha fariinta, dibadda baqshad kasta waxaa ku qoran cinwaanka qofka xiga ee furi doona.

:::tip Qodob muhiim ah
Layer kasta wuxuu xogta layer-ka ka sarreeya hortiisa ku dhejiyaa macluumaadkiisa xakamaynta — **header**-ka. Duubiddan iyo furfurkan waxaa la yiraahdaa **encapsulation**.
:::

Layer-ka ku xiran, “baqshadda” waxay leedahay magac u gaar ah:

| Layer | Protocol-ka tusaalaha | Magaca unugga xogta |
|---|---|---|
| Layer 2 | Ethernet | **Frame** |
| Layer 3 | IPv4 | **Packet** |
| Layer 4 | TCP | **Segment** |

:::note
Maalin kasta — iyo koorsadan sidoo kale — dadku badanaa waxay si fudud u yiraahdaan “packet”, iyadoo aan loo eegin layer-ka. Marka saxnaanta lagama maarmaan tahay, isticmaal magacyada jaantuska.
:::

# Moodooyin

:::goal
**Hadafka waxbarashada:** Waxaad awoodaa inaad sharaxdo sida packet loogu dhiso layers (encapsulation), inaad magacowdo layers-ka ku jira tracer-ka, oo aad sharaxdo oo isbarbar dhigto moodooyinka tixraaca ee ISO/OSI iyo TCP/IP.
:::

Cutubka 1 waxaad ku aragtay in hal gujin oo link ah ka dambeeyaan protocols badan oo kala duwan: ARP, TCP, HTTP — mid kastaa wuxuu leeyahay hawl u gaar ah. Si protocols-kan badan loogu kala saaro habsami leh, farsamada network-yada waxay adeegsataa moodooyin layers ah.

Cutubkan waxaad marka hore kala furfurtaa hal packet, kadibna waxaad barataa labada moodel ee ugu muhiimsan: moodelka tixraaca ee ISO/OSI oo leh toddobo layers, iyo moodelka TCP/IP oo wax yar ka dhaqan-gal badan oo leh afar. Labadaba waxaad la kulmi doontaa cutubyada soo socda mar ka mar — waa erayada guud ee aan hadda ka bilaabo ku hadalno network-yada.

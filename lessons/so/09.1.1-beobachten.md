# Firewall-ka fiiri

:::sim
url=/sims/lesson-9.1.1.btsim
:::

Simulation-kan, qof ayaa hore saddex xeer ugu galiyay firewall-ka. Guji **Firewall** oo fiiri Tab-ka **Regeln**. **Port A** ee firewall-ka wuxuu ku xiran yahay Internet-ka, **Port B** wuxuu ku xiran yahay router-ka dugsiga. "A → B" sidaas darteed waxay ka dhigan tahay "Internet-ka ka soo gala school network-ka".

:::quiz table
| Xeer | Jihada | Protocol | Destination port | Ficil |
|---|---|---|---|---|
| 1 | A → B | {TCP} | {22} | {Drop} |
| 2 | A → B | TCP | {110} | {Reject} |
| 3 | A → B | {ICMP} | mid kasta | Drop |
:::

:::evaluate
Hubi shaxda
:::

## Ping dibadda ka timaada

U beddel :fa-play: **Habka Socodsiinta** oo ka ping-garee server-ka dugsiga **Internet-PC**-ga:

```
$ ping -c 2 198.51.100.10
```

Kadib, ku fur firewall-ka Tab-ka **Protokoll**.

:::quiz mc
Maxay `ping` soo sheegaysaa?
- [x] `Anfrage abgelaufen` — waxba ma soo noqdaan
- [ ] `Paket gefiltert`
- [ ] Laba jawaab oo ka yimid server-ka dugsiga
:::

## Portscan: drop mise reject?

Hadda si gaar ah u scan-garee shan port. Port 3306 (database) server-ka dugsiga kuma shaqeeyo gabi ahaanba.

```
$ nmap -p 22,25,80,110,3306 198.51.100.10
```

:::quiz match
22 (drop la sameeyay) -> filtered
25 (la ogolyahay, adeegga wuu shaqeynayaa) -> open
110 (reject la sameeyay) -> closed
3306 (la ogolyahay, adeeg ma jiro) -> closed
:::

:::evaluate
Hubi isku xigxiga
:::

:::quiz multi
Maxaa weeraryahanku ka gaari karaa natiijada?
- [x] Marka uu arko `filtered`, wuu ogaadaa: halkaas waxaa jira firewall packet-yada liqaya
- [x] Marka uu arko `closed`, ma kala saari karo in firewall-ku reject sameeyay iyo in adeeg uusan shaqeyneynin
- [ ] Marka uu arko `filtered`, wuu ogaadaa adeegga port-kaas ka dambeeya
- [ ] Marka uu arko `closed`, adeegga weli waa la gaari karaa
:::

:::evaluate
Hubi jawaabaha
:::

Ugu dambayn, fiiri tiirka **Treffer** ee liiska xeerarka: halkaas firewall-ku wuxuu ku tiriyaa inta packet ee xeer kasta go'aan ka gaadhay. Qiimaha ku xiga **Standardrichtlinie** wuxuu tiriyaa dhammaan packet-yada aan xeer kuwada jirin.

:::tip Qodob muhiim ah
Packet-yada **la drop-gareeyay** raad la'aan ayay u lumaan: `ping` wuxuu soo sheegaa timeout, `nmap` wuxuu soo sheegaa `filtered`. Packet-yada **la reject-gareeyay**, firewall-ku wuxuu ku jawaabaa diidmo (TCP-ga waa RST) — dibadda waxay u egtahay port xiran. **Protokoll**-ka firewall-ku wuxuu muujiyaa packet-yada uu joojiyay, tiirka **Treffer** wuxuu muujiyaa xeerka shaqeeyay.
:::

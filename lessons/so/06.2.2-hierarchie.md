# Sida DNS loo habeeyay

:::sim
url=/sims/lesson-6.2.btsim
:::

Hal server ma aqaan karo dhammaan magacyada adduunka. Sidaas darteed DNS waxa uu u dhisan yahay si **hierarchical** ah — sida magacyada qudhooda oo kale. Waxaad ku akhrisaa midig ilaa bidix:

```
www . beaver-schule . de . (Root)
 │          │         │      └─ Root-Server: kennen die Server aller Top-Level-Domains
 │          │         └─ Top-Level-Domain (TLD): der de-Server kennt alle .de-Domains
 │          └─ Domain: der Schul-DNS ist für beaver-schule.de zuständig
 └─ Rechnername innerhalb der Domain
```

Server-ka mas'uulka ka ah domain oo run ahaantii jawaabta og waxaa la yiraahdaa **authoritative**. Jidka loo maro si loo gaaro waxaa PC-ga u qabta **resolver** — halkan kombuyuutarka **DNS-Resolver**.

## Tijaabada

1. U gudub habka :fa-play: **Habka Socodsiinta** oo ku qor **Client-PC** gudahiisa :fa-terminal: **Terminal**:
   ```
   $ nslookup www.beaver-schule.de
   ```
2. Gudaha habka :fa-magnifying-glass: **Raad** fur trace u socda **DNS-Resolver**.

Resolver-ku wuxuu kuu sameeyay weydiimo badan. Isku xidh yaa jawaab kasta bixiyay:

:::quiz match
Root-Server (192.168.0.101) -> Tilmaan: Für .de ist ns.nic.de zuständig
de-Server (192.168.0.102) -> Tilmaan: Für beaver-schule.de ist ns.beaver-schule.de zuständig
Schul-DNS (192.168.0.103) -> Jawaab: www.beaver-schule.de hat die Adresse 192.168.0.20
:::

:::quiz mc
Resolver-ku yaa marka hore weydiiyaa?
- [x] Root server-ka
- [ ] Schul-DNS
- [ ] Client-PC
:::

:::evaluate
Hubi jawaabaha
:::

:::note
Inta u dhaxaysa, resolver-ku wuxuu kaloo weydiiyaa cinwaannada server-yada loo gudbiyay (`A ns.nic.de`). DNS server-yada dhabta ah badanaa cinwaannadaas isla markiiba ayay la soo diraan. Intaas ka sokow, resolver-yadu waxay xusuustaan jawaab kasta muddo ah (**Cache**) — weydiinta xigta ee isla magacaas ah ayay isla markiiba naftooda ka jawaabaan. Intee in le'eg ayaa lagu qoraa gelitaanka sida **TTL** (*Time to Live*) ee ah ilbiriqsiyo.
:::

## Noocyada gelitaannada ugu muhiimsan

| Nooca | Macnaha | Tusaale |
|---|---|---|
| **A** | Magac → IPv4 address | `www.beaver-schule.de` → `192.168.0.20` |
| **AAAA** | Magac → IPv6 address | `www.beaver-schule.de` → `2001:db8::20` |
| **CNAME** | Magac → magac kale (alias) | `web.beaver-schule.de` → `www.beaver-schule.de` |
| **MX** | mail server-ka mas'uulka ka ah domain | `beaver-schule.de` → `mail.beaver-schule.de` |
| **NS** | DNS server-ka mas'uulka ka ah domain | `beaver-schule.de` → `ns.beaver-schule.de` |

:::tip Qodob muhiim ah
DNS waa **hierarchical**: **Root server-yadu** waxay tilmaamaan server-yada **top-level domain-yada** (tusaale `.de`), kuwaasna waxay tilmaamaan server-yada **domain-yada** gaarka ah. Server-ka **authoritative** ee mas'uulka ah ayaa jawaabta yaqaan. **Resolver** wuxuu jidkan u maraa PC-ga oo wuxuu xusuustaa jawaabaha (**Cache**). Noocyada gelitaannada muhiimka ah: **A**, **AAAA**, **CNAME**, **MX**, **NS**.
:::

## Samaynta gelitaan

Dugsigu wuxuu rabaa in websaydkiisa lagu gaari karo sidoo kale `intranet.beaver-schule.de`.

1. Gudaha habka :fa-play: **Habka Socodsiinta** guji **Schul-DNS** oo fur app-ka **DNS-Server**.
2. Fur tab-ka **A**. Guji **+** oo gudaha safka cusub ku qor magaca `intranet.beaver-schule.de` iyo cinwaanka `192.168.0.20`.
3. Ku tijaabi Client-PC adigoo isticmaalaya `nslookup intranet.beaver-schule.de`.

:::task
title: Magaca cusub ma la geliyay?
Prüft, ob der Client-PC den Namen intranet.beaver-schule.de zur Adresse des Webservers auflöst. Die Simulation muss dafür im Ausführen-Modus laufen.
check: resolves(2, "intranet.beaver-schule.de", "192.168.0.20")
:::

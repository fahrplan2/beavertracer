# Ku qorista static routes

:::sim
url=/sims/lesson-4.5.2.btsim
:::

Markan waxaa u dhexeeya Firma A iyo Firma B **laba** router. Waxay isku xiran yihiin network yar oo u gaar ah, kaas oo ah **Zwischennetz** `10.0.0.0/30` (network dhexe):

| Router | Interface | IP address | Network |
|---|---|---|---|
| Router A | `eth0` | `192.168.0.1/24` | Firma A (Anna) |
| Router A | `eth1` | `10.0.0.1/30` | Zwischennetz |
| Router B | `eth0` | `10.0.0.2/30` | Zwischennetz |
| Router B | `eth1` | `172.16.0.1/24` | Firma B (Clara) |

:::note
Network `/30` wuxuu leeyahay laba cinwaan oo keliya oo la isticmaali karo — waa kuwo ku habboon isku xirka laba router (eeg qaybta 4.2.3).
:::

## Dhibaatada

U beddel :fa-play: habka **Run**, kadibna **Anna** ka ping u dir Clara (`ping 172.16.0.10`). Clara ma jawaabto — halkii, Router A (`192.168.0.1`) wuxuu soo sheegayaa "Zielnetz nicht erreichbar" (network-ga bartilmaameedka lama gaari karo).

Fiiri **Routing table IPv4** ee **Router A**.

:::quiz mc
Maxaa ka dhigan in ping-ka Anna uusan gaarin Clara?
- [ ] Anna ma gelin gateway
- [x] Router A ma garanayo network-ga `172.16.0.0/24` — si toos ah looma xirin, route ka sii gudubna ma jirto
- [ ] Zwischennetz aad buu u yar yahay
:::

:::evaluate
Hubi jawaabta
:::

## Ku qorista route-ka

Router A waa inuu bartaa: packets-ka loogu talagalay `172.16.0.0/24` waxay aadaan Router B (`10.0.0.2`), iyagoo marayo `eth1`.

1. Kaga fur **Router A** Tab-ka **Routing table IPv4**, kadibna riix **+ hinzufügen**.
2. Safka cusub ku qor: **Ziel** `172.16.0.0`, **Netzmaske** `255.255.255.0`, **Next Hop** `10.0.0.2`, **Iface** `eth1`.
3. Safka ku kaydi calaamadda :fa-check:. Tiirka **Quelle** hadda wuxuu muujinayaa **Static**.

Mar kale Clara ping u dir — hadda jawaabtu way imanaysaa.

:::note
Router B wuxuu hore u yaqaannaa jidka dib ugu laabanaya Firma A: routing table-kiisa wuxuu horeba ugu leeyahay static route `192.168.0.0/24` oo marta `10.0.0.1`. Sababta jidkan dib-u-laabashada uu u muhiim yahay waxaad ka arki doontaa bogga xiga.
:::

## Raadraaca jidka: traceroute

Adigoo isticmaalaya `traceroute`, waxaad ka arki kartaa router-yada uu packet maro. Ku qor **Anna**:

```
$ traceroute 172.16.0.10
```

:::quiz short
Immisa router ayuu packet-ka ka socda Anna ee u socda Clara maraa?
= 2
= laba
:::

:::quiz mc
Cinwaanka noocee ah ayuu `traceroute` u muujiyaa Router B?
- [x] `10.0.0.2` — cinwaankiisa ku jira Zwischennetz, kaas oo packet-ku ka soo gelayo
- [ ] `172.16.0.1` — cinwaankiisa ku jira Firma B
- [ ] `192.168.0.1`
:::

:::evaluate
Hubi jawaabaha
:::

`traceroute` wuxuu adeegsadaa khiyaano la xiriirta **Time to Live** ee qaybta 4.3.1: marka hore wuxuu dirayaa packet leh TTL 1. Router-ka ugu horreeya wuu ka jaraa 1, wuxuu gaarayaa 0, packet-ka wuu tuuraa, kadibna sender-ka ayuu u soo sheegayaa — sidaas ayuu Anna ku bartaa router-ka koowaad. Kadib TTL 2 router-ka labaad, iyo wixii ka danbeeya, ilaa ay bartilmaameedku jawaabayso.

:::tip Qodob muhiim ah
**Static route** waxaa gacanta ku gelisa administrator-ka: network-ga bartilmaameedka, netmask, next hop iyo interface. Adigoo isticmaalaya **traceroute**, waxaad raadraaci kartaa jidka packet router-ka ka dib router.
:::

# Samaynta DHCP server

:::sim
url=/sims/lesson-6.4.2.btsim
:::

Markan DHCP server weli lama dejin. Adigaa go'aamiya settings-ka uu qaybiyo:

| Setting | Qiimaha |
|---|---|
| Address range | `192.168.0.100` ilaa `192.168.0.120` |
| Gateway | `192.168.0.1` |
| DNS server | `192.168.0.53` |

1. U gudub :fa-play: **Run** (Habka Socodsiinta), guji **DHCP-Server** oo fur app-ka **DHCP Server**.
2. Geli **Bilowga furanaya**, **Dhamaadka furanaya**, **Gateway** iyo **DNS-Server**, guji **Kaydi** kadibna guji **Bilow**.
3. Ee **Laptop 1** iyo **Laptop 2**, gudaha :fa-gear: **IP Settings** ka dhig habka **DHCP** oo mar kasta guji **Apply**.
4. Ka hubi DHCP server-ka, gudaha Tab-ka **Leases**, cidda helay cinwaan kasta.

:::note
Address range-ka waxaa loo doortaa si uusan ugu dhicin isku dhac la leh cinwaannada joogtada ah: server-yada, router-yada iyo printer-yada waxay inta badan helaan cinwaan joogto ah oo ka baxsan DHCP range-ka — halkan tusaale ahaan DHCP server-ka laftiisa oo ah `192.168.0.2`.
:::

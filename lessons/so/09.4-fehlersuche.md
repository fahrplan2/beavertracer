# Cilad-raadin: Tan iyo xeerarka cusub waxba ma shaqeeyaan

:::sim
url=/sims/lesson-9.4.btsim
:::

Herr Biber, maamulaha Beaver-Schule, shalay wuxuu firewall-ka u bedelay mabda'a whitelist. Tan iyo markaas qof walba ayaa cabanaya: **Webseite der Schule** laga ma gaari karo dibadda, **mail kasta oo Internetka ka yimaada** ma soo gaadho. Hase ahaatee: SSH hadda dibadda ayaa laga xiray, sida loo doonayay.

Raadi khaladaadka ku jira xeerarka **firewall-ka** oo saxo.

<details>
<summary>Talo 1: Miyuu packet-ku xitaa gaadhayaa xeerka saxda ah?</summary>

Ka tijaabi **Internet-PC** adigoo isticmaalaya `nmap -p 22,25,80 198.51.100.10`, kadibna fiiri tiirka **Treffer** ee firewall-ka. Xeer weli 0 ah inkastoo packets loogu imaan lahaa, waxaa qarinaya xeer kale — ama marna ma ku habboona.
</details>

<details>
<summary>Talo 2: Si fiican u fiiri</summary>

Isbarbar dhig lambar kasta oo xeerarka ku jirta iyo ports-ka Cutubka 5: Port kee ayaa HTTP leh, kuwee ayaa SMTP leh? Oo xasuuso isku xigga: xeerka ugu horreeya ee ku habboon ayaa guulaysta.
</details>

:::task
title: Web iyo mail miyaa mar kale la gaari karaa?
Prüft, ob Web und Mail des Schulservers aus dem Internet erreichbar sind und SSH gesperrt bleibt.
check: tcpOpen(1, "198.51.100.10", 80)
check: tcpOpen(1, "198.51.100.10", 25)
check: tcpFails(1, "198.51.100.10", 22)
:::

## Maxaa dhacay?

:::quiz multi
Khaladaadkee ayaa ku jiray xeerarka?
- [x] Xeerka web-ka wuxuu ogolaaday port 8080 halkii uu ahaan lahaa 80
- [x] Xeerka mail-ka wuxuu ka hooseeyay xeerka „dhammaan ka tuur“, sidaas darteed marna lagama gaadhin
- [ ] Firewall-ku wuxuu ku jiray Stateful
- [ ] Port 25 waa port khaldan oo mail ah
:::

Hubi jawaabaha

:::tip Qodob muhiim ah
Khaladaadka caadiga ah ee xeerarka firewall-ka: **lambar is-bedelay** oo port-ka ku jirta, **jihada** khaldan, iyo **isku xigga** khaldan, halkaas oo xeer guud uu qariyo xeer gaar ah. Cilad-raadinta waxaa caawiya **port scan** dibadda ka imaanaya, **log-ka** firewall-ka, iyo **tiriyeyaasha hit-ka** ee xeerarka.
:::

# TCP mise UDP?

| | TCP | UDP |
|---|---|---|
| Xidhiidh (Verbindung) | dhisid ku saleysan three-way handshake, xidhid habaysan | ma jiro — datagram kasta waa isaga keligiis |
| Xaqiijinno (Bestätigungen) | haa (`ACK`) | maya |
| Xogta lumay | dib ayaa loo diraa | way lumaysaa |
| Isku xigga | dib ayaa loo soo celiyaa | lama dammaanad qaado |
| Header | ugu yaraan 20 byte | 8 byte |
| Xawaaraha | in yar ayuu gaabiya, packets badan | degdeg, hawl yar |

Goorma ayay yaraantu ka wanaagsan tahay?

- **Real time:** Marka lagu jiro video call, telefoonka internetka ama ciyaaraha online-ka ah, millisecond kasta way muhiim tahay. Qayb codka ka mid ah oo lumay oo ka dib hal ilbiriqsi la soo gaarsiiyo ma anfaceyso qofna — ka roon waa dhawaaq gaaban oo kackackaya intii dib-u-dhac ahaan lahayd.
- **Codsiyo gaaban:** Codsi **DNS** ah ("Waa maxay IP address-ka `www.beispiel.de`?") wuxuu ku jiraa hal datagram oo keliya, jawaabtuna sidoo kale. Connection setup wuxuu hawsha ka dhigi lahaa saddex jeer ka badan. Haddii jawaab timaaddo, barnaamijku si fudud ayuu mar kale u weydiiyaa.

Meel kasta oo byte kasta uu gaari waayo — bogagga web-ka, e-mail-ada, downloads-ka —, halkaas TCP ayaa ah doorashada saxda ah.

:::tip Qodob muhiim ah
**TCP** waa la isku halayn karaa, laakiin hawl badan ayuu u baahan yahay — wax kasta oo u baahan inay **dhammaystiran** u gaaraan (web, e-mail, faylal). **UDP** waa dagdag oo fudud, laakiin damaanad la'aan — waxaa loogu talagalay **real time** (telefoon, video, ciyaaro) iyo **codsiyo gaaban** sida DNS.
:::

Hadda waxaad taqaanaa qalabka transport layer. Cutubka xiga waxaad eegi doontaa protocols-ka ku dhisan: HTTP, DNS, e-mail iyo DHCP.

# Wax walba isku keen: Maxaa dhacaya marka bog web ah la furo?

:::goal
**Hadafka waxbarashada:** Waxaad awoodaa inaad tallaabo-tallaabo ku sharaxdo protocols-kee ayaa ku lug leh, iyo layer-kee, marka laptop cusub la shiday uu furo bog web ah.
:::

:::sim
url=/sims/lesson-6.5.btsim
:::

Hadda wax kasta oo aad koorsadan ku baratay ayaa halkan isugu yimaada. Switch-ka waxaa ku xiran **DHCP-Server**, **DNS-Server**, **Webserver** iyo **Laptop** hadda la shiday — wali IP address ma haysto oo wuxuu ku dhex jiraa DHCP.

## Tijaabada

1. U beddel habka :fa-play: **Ausführen** ee Habka Socodsiinta oo sug dhowr ilbiriqsi.
2. Guji **Laptop**, fur :fa-globe: **Browser** oo fur `http://www.beaver-schule.de/`.
3. Habka :fa-magnifying-glass: **Raad** ku fur trace u dhiganta **Laptop**. Halkan waxaa ku jira sheekada oo dhan — min packet-kii ugu horreeyay.

Tallaabooyinka u dhig sida ay ugu qoran yihiin trace-ka:

:::quiz match
1. Schritt -> DHCP: Laptop-ku wuxuu helaa IP address, gateway iyo DNS server
2. Schritt -> ARP: Laptop-ku wuxuu weydiiyaa MAC address-ka DNS server-ka
3. Schritt -> DNS: Laptop-ku wuxuu weydiiyaa IP address-ka www.beaver-schule.de
4. Schritt -> ARP: Laptop-ku wuxuu weydiiyaa MAC address-ka web server-ka
5. Schritt -> TCP: Three-way handshake oo lala sameeyo web server-ka
6. Schritt -> HTTP: GET / iyo jawaabta 200 OK
:::

Hubi isku-xigga
:::

Wax walba hoostooda waxaa yaal **IP** (layer 3), kaas oo cinwaan u dhiga packet kasta oo kuwan ah, iyo **Ethernet** (layer 2), kaas oo geeya qalabka xiga. Haddii web server-ku ku jiri lahaa network kale, **router**-ku sidoo kale wuu ku lug yeelan lahaa: markaas laptop-ku wuxuu weydiin lahaa MAC address-ka **gateway**-giisa, ma aha kan web server-ka.

:::quiz mc
Maxaa laptop-ku u samayn karaa codsiga DNS kaliya kadib DHCP?
- [ ] Sababtoo ah DNS wuxuu ku shaqeeyaa TCP oo keliya
- [x] Sababtoo ah DHCP ayaa u siinaya IP address u gaar ah oo wuxuu ka ogaadaa DNS server-ka mas'uulka ah
- [ ] Sababtoo ah DNS server-ku wuxuu bilaabmaa kadib DHCP server-ka
:::

:::quiz mc
Immisa TCP connection ayuu browser-ku la sameeyaa web server-ka — maxaase u sabab ah?
- [ ] Hal, wax walba oo wadajira
- [x] Laba — mid bogga ah iyo mid stylesheet-ka ah
- [ ] Meelna, HTTP uma baahna TCP
:::

:::tip Qodob muhiim ah
Gadaasha hal gujin, layers-ka oo dhan ayaa wada shaqeeya: **DHCP** wuxuu bixiyaa dejinta aasaasiga ah, **ARP** wuxuu helaa MAC addresses-ka ku jira network-ga deegaanka, **DNS** wuxuu turjumaa magaca, **TCP** wuxuu dhisaa xidhiidh la aamini karo, **HTTP** wuxuu soo qaadaa bogga — wax walba waxay ku duudduubanyihiin **IP** packets iyo **Ethernet** frames.
:::

Taasi waxay kuu suurtagelinaysaa inaad sharaxdo furitaanka bog web ah min packet-kii ugu horreeyay ilaa kii u dambeeyay. Dhamaadka cutubka waxaa ku xiga dulmar kooban oo ku saabsan protocols kale. Cutubyada soo socda waxay ku saabsan yihiin home network oo leh NAT, amniga iyo sirta (encryption) — sidaas darteed waxay ka hadlayaan su'aasha ah sida looga hortagi karo in qof akhriyo packets-kan oo dhan.

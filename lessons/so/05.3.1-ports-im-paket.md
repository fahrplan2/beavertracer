## Tijaabada

1. U gudub :fa-play: **Habka Socodsiinta**, riix **Client-PC** oo fur :fa-globe: **Browser**. Fur `http://192.168.0.20/`.
2. Riix **Dib u noqo** xagga sare ee daaqadda, fur **Simple TCP Client** oo ku xidh `192.168.0.20`, port `5000`. Xidhiidhka ha furnaado.
3. U gudub :fa-magnifying-glass: habka **Raad**, fur trace u dhigan **Client-PC** oo riix packet ka kooban `[SYN]`. Fur **Transmission Control Protocol**.

Meesha ugu sarraysa ee TCP header-ka waxaa ku jira laba ports: **Source Port** (port-ka isha) iyo **Destination Port** (port-ka beegsiga).

:::quiz table
| Xidhiidh | Source port | Destination port |
|---|---|---|
| Browser → web server | {49152} | {80} |
| TCP-Client → adeegga Echo | {49153} | {5000} |
:::

## Laba nooc oo ports ah

**Destination port — adeegga:** Barnaamijka server-ka wuxuu ku sugayaa xidhiidhada port go'an — waxaa la yiraahdaa wuxuu halkaas **dhegaysanayaa** (listen). Adeegyada caanka ah, lambarrada waa la go'aamiyay caalamka oo dhan, kuwaasoo ah **Well-known Ports** (0 ilaa 1023). Sidaas darteed browser wuxuu ogyahay isagoo aan weydiin: web server-yadu waxay dhegaystaan port 80.

**Source port — qofka diraya (sender):** Port-ka dhanka client-ka waxaa xidhiidh kasta oo cusub ka dooranaya nidaamka hawlgalka (operating system) laftiisa, isagoo ka soo qaadanaya aag sare (gudaha BeaverTracer laga bilaabo 49152). Port-kaas ayaa client-ku ku garanayaa xidhiidhkiisa kee ka mid ah ayuu jawaabtu u dhigantahay.

Marka xidhiidh waxaa si gaar ah u go'aamiya afar xog: **IP address iyo port labada dhinac**. Labada isku-dhafka ah ee IP address iyo port waxaa la yiraahdaa **socket**, tusaale ahaan `192.168.0.20:80`.

## Eegis server-ka

Ku laabo :fa-play: **Habka Socodsiinta**, **Server** ka fur :fa-terminal: **Terminal** oo geli:

```
$ ss
```

`ss` wuxuu muujiyaa dhammaan sockets-ka kombiyuutarka. Safafka leh `LISTEN` waa barnaamijyo port ku dhegaysanaya. Safafka leh `ESTABLISHED` waa xidhiidho hadda jira — iyadoo la tusayo socket-ka gaarka ah (*Local Address:Port*) iyo socket-ka dhinaca kale (*Peer Address:Port*).

:::quiz multi
Server-ku ports-kee ayuu ku dhegaystaa?
- [x] 80
- [x] 5000
- [ ] 49152
- [ ] 443
:::

:::quiz mc
Xidhiidhkee ayuu `ss` ku muujiyaa `ESTABLISHED`?
- [x] `192.168.0.20:5000` oo la `192.168.0.10:49153` — xidhiidhka furan ee TCP-Client
- [ ] `192.168.0.20:80` oo la `192.168.0.10:49152` — xidhiidhka browser-ka
- [ ] Labadaba
:::

:::note
Xidhiidhka browser-ka mar hore ayaa la jaray — marka bogga la soo rarey, waxaa lagu soo afjaray `FIN`. `ss` wuxuu weli si kooban u muujiyaa `TIME-WAIT`: server-ku wuxuu muddo sugayaa si uu u arko haddii packets daahay oo xidhiidhkaas ka tirsan weli yimaaddaan. Xidhiidhka TCP-Client wuu weli furan yahay, sababtoo ah weli ma riixin **Ka xir**.

## Well-known Ports-ka ugu muhiimsan

| Port | Protocol | Adeeg |
|---|---|---|
| 22 | SSH | maamulka fogaan ee ammaan ah (command line sir ah) |
| 25 | SMTP | dirista e-mails |
| 53 | DNS | u tarjumida magacyada IP address (inta badan UDP) |
| 80 | HTTP | bogagga web-ka |
| 110 | POP3 | soo qaadista e-mails |
| 143 | IMAP | maamulka e-mails ee server-ka |
| 443 | HTTPS | bogagga web-ka ee sir ah |

:::tip Qodob muhiim ah
**Ports** (0 ilaa 65535) waxay kala sooci jiraan xidhiidhada kombiyuutar ku jira. Adeegyada server-ka waxay **dhegaystaan** **Well-known Ports** go'an (tusaale ahaan HTTP 80, HTTPS 443), client-yaduna xidhiidh kasta waxay helaan **source port** sare oo bannaan. Xidhiidh waxaa si gaar ah u go'aamiya **IP address iyo port labada dhinac**.
:::

:::

# Stateless iyo stateful

Isku xidhka (connection) had iyo jeer wuxuu leeyahay **laba jihood**: Lehrer-PC wuxuu codsi u diraa web server ku yaal internetka — web server-kuna wuxuu dib u soo celiyaa bogga webka. Firewall ku dhisan mabda'a Whitelist sidaas darteed ma oggolaan karto codsiga oo keliya, laakiin waa inay oggolaataa **jawaabta** sidoo kale.

Taas awgeed waxaa jira laba nooc oo packet filter ah:

| | **Stateless** (*stateless*) | **Stateful** (*stateful*) |
|---|---|---|
| Habka shaqada | wuxuu hubiyaa packet kasta si gooni ah, isagoo aan xusuus lahayn | wuxuu xusuustaa isku xidhka la oggolaaday isagoo ku kaydinaya **state table** |
| Jawaabaha | waxay u baahan yihiin xeer u gaar ah jihada dambe | si toos ah ayaa loo oggolaadaa, maxaa yeelay waxay ka tirsan yihiin isku xidh la yaqaan |
| Isticmaalka | aalado fudud, filters aad u dhakhso badan | dhammaan firewall-yada maanta isticmaalka ku jira |

Labada qaybood ee soo socda waxaad ku arki doontaa sababta filters-ka stateless ay dhibaato ula kulmaan jawaabaha — iyo sida firewall stateful ay u xalliso.

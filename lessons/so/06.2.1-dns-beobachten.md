## Tijaabada

1. U gudub habka :fa-play: **Run** — **Habka Socodsiinta**, guji **Client-PC** oo fur :fa-globe: **Browser**.
2. Markan fur `http://www.beaver-schule.de/` — adigoo isticmaalaya magac halkii aad ka isticmaali lahayd IP address.
3. U gudub habka :fa-magnifying-glass: **Raad** oo fur trace u gaar ah **Client-PC**.

Bilowga bilowga ah — xitaa ka hor connection setup-ka `[SYN]` — waxaa jira laba packet oo isticmaala protocol-ka **DNS**.

:::quiz short
Which IP address does the Client-PC send its DNS request to?
= 192.168.0.53
:::

:::quiz short
Which IP address is in the answer for `www.beaver-schule.de`?

:::

Kaliya markii Client-PC uu og yahay IP address-ka ayuu dhisaa TCP connection-ka u dhexeeya iyo web server-ka — sida saxda ah ee ku jirta cutubka 5.

:::seq
mode: text
Client-PC -> DNS-Resolver: DNS-Anfrage | A www.beaver-schule.de?
DNS-Resolver -> Client-PC: DNS-Antwort | A 192.168.0.20
:::

## Sidee PC-gu u yaqaan DNS server-ka?

Ku fur **Client-PC** :fa-gear: **IP Settings**: goobta **DNS-Server** waxaa ku jira `192.168.0.53` — kombiyuutarka **DNS-Resolver**. PC-gu wuxuu u diraa codsi kasta oo magac ah.

Waxaad weydiin kartaa DNS server-ka si toos ah, adigoon isticmaalin browser. Fur :fa-terminal: **Terminal** oo geli:

```
$ nslookup www.beaver-schule.de
```

`nslookup` wuxuu marka hore muujiyaa server-ka uu weydiiyay, kaddibna jawaabta. Si aad isbarbar dhigto, weydii magac aan jirin, tusaale `nslookup gibtsnicht.beaver-schule.de`.

:::quiz mc
What does the DNS server answer for the unknown name?
- [ ] A random IP address
- [x] `NXDOMAIN` — this name does not exist
- [ ] Nothing at all
:::

:::evaluate
Hubi jawaabta
:::

:::tip Qodob muhiim ah
**DNS** wuxuu magacyada (tusaale `www.beaver-schule.de`) u turjumaa IP address-yo. Kahor intaan PC-gu ku dhisin connection magac, wuxuu weydiiyaa **DNS server-ka** ku qoran IP settings-kiisa — inta badan iyadoo la adeegsanayo **UDP, port 53**. Adigoo isticmaalaya `nslookup` waxaad gacanta ku samayn kartaa codsiyada DNS.
:::

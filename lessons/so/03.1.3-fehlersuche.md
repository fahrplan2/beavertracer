Tan iyo markii **David** network-ga ku soo biiray, waxaa jira dhibaatooyin: Clara qofna kuma gaari karo, waxaana jira wax khaldan oo Ben ku jira. Adigoo ah khabiir network ah, waa inaad dhibaatadan hagaajisaa.

## Network plan

Sidan ayuu network-ga *u baahan yahay* inuu u ekaado:

| Qalab | IP address | Switch port |
|---|---|---|
| Anna | `192.168.0.10/24` | 1 |
| Ben | `192.168.0.11/24` | 2 |
| Clara | `192.168.0.12/24` | 3 |
| David | `192.168.0.13/24` | 4 |

Barbardhig plan-ka iyo simulation-ka: Maxaa ku kala duwan? Hagaaji dhammaan khaladaadka aad hesho.

<details>
<summary>Tilmaanta 1: Xagee ka bilaabaa?</summary>

Marka hore eeg kaabalada: Miyuu PC kasta ku xiran yahay port-ka saxda ah? Kadibna hubi IP settings-ka PC kasta.
</details>

<details>
<summary>Tilmaanta 2: Ben wuu ka jawaabaa ping-yada, mase …?</summary>

Anna ka ping u dir Ben (`ping 192.168.0.11`) oo fur trace u gaar ah Anna. Si fiican u eeg jawaabaha ARP: Immisa ayaa jira — oo MAC address-yo noocee ah ayay wataan?
</details>

:::task
title: Network-gii ma la hagaajiyey?
Waxay hubisaa in dhammaan qalabku leeyihiin cinwaannada ku jira network plan-ka oo ay is gaari karaan. Simulation-ku waa inuu u socdaa Habka Socodsiinta.
check: ip(3, "192.168.0.10/32")
check: ip(5, "192.168.0.11/32")
check: ip(7, "192.168.0.12/32")
check: ip(11, "192.168.0.13/32")
check: pingOk(3, 7)
check: pingOk(3, 11)
check: pingOk(5, 7)
:::

## Maxaa dhacay?

:::quiz mc
Sidee ugu garanaysaa Tracer-ka in laba qalab ay isku IP address leeyihiin?
- [ ] Ping-gu mar walba wuu fashilmaa
- [x] ARP request mid ah waxaa ka jawaaba laba jawaab oo leh MAC address-yo kala duwan
- [ ] Switch-ku wuxuu muujiyaa fariin khalad ah
:::

:::evaluate
Hubi jawaabta
:::

:::tip Qodob muhiim ah
Marka aad **cilad-raadinta** samaynayso, waxaad barbardhigtaa **xaaladda la rabo** (network plan) iyo **xaaladda dhabta ah** (kaabalada, settings-ka, Tracer-ka). Feeraha: ping guulaysta macnaheedu maaha si toos ah in wax walba sax yihiin — haddii IP address laba jeer jirto, malaha qalabka khaldan ayaa si fudud uga jawaabaya.
:::

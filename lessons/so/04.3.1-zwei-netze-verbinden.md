Router-ku wuxuu leeyahay laba port:

| Port | IP address | Network |
|---|---|---|
| `eth0` | `192.168.0.1/24` | Shirkadda A |
| `eth1` | `172.16.0.1/24` | Shirkadda B |

Si PC-yadu u isticmaalaan router-ka, mid kasta waxaa ku qoran **gateway**: Anna iyo Ben waxay haystaan `192.168.0.1`, Clara iyo David-na `172.16.0.1`. Waxaad ka heli kartaa :fa-gear: **IP Settings** gudaheeda, goobta **Gateway**.

:::tip Qodob muhiim ah
**Gateway** (si sax ah: *default gateway*) waa IP address-ka router-ka **ee network-gaaga**. PC-gu wuxuu gateway-ga u dirayaa dhammaan packet-yada ujeeddadoodu ku jirto network shisheeye.
:::

:::quiz multi

## Wuxuu router-ku packet-ka ku sameeyo

Router-ku wuxuu qaataa frame-ka Anna, wuxuu furaa IP packet-ka, wuxuuna eegaa **IP address-ka ujeeddada**. Taas wuxuu ka garanayaa: Clara waxay ku jirtaa network-ka `eth1`. Sidaa darteed wuxuu packet-ka ku duubaa frame **cusub** — isagoo MAC address-kiisa u adeegsanaya sender iyo MAC address-ka Clara u adeegsanaya ujeeddo — wuxuuna halkaas u dirayaa.

| Maxaa router-ka ka dhaca … | |
|---|---|
| MAC address-yada (layer 2)? | waxaa **dib loo dhigaa** — waxay ansax yihiin oo kaliya network-ka ay ku jiraan |
| IP address-yada (layer 3)? | **isma beddelaan** — min Anna ilaa Clara |
| Time to Live? | wuxuu **1 hoos u dhacaa** |

:::tip Qodob muhiim ah
**Router**-ku wuxuu ka shaqeeyaa **layer 3**: wuxuu packet-yada ugu gudbiyaa network-yo kale isagoo ku saleysan **IP address-ka ujeeddada**. IP address-yadu way isku mid yihiin dhammaan jidka, MAC address-yadana waxaa network kasta lagu dhigaa mid cusub. Router kasta wuxuu **Time to Live (TTL)** ka dhimaa 1 — haddii ay gaarto 0, packet-ka waa la tuuraa. Sidaas ayaa packet-ku uga baxayaa inuu si aan dhammaad lahayn goobaaro.
:::

:::note
Ma xasuusataa duufaanta broadcast ee cutubka 3.4? Ethernet frame-yadu TTL ma laha — IP packet-yaduse way leeyihiin.
:::

## Yaa Anna taqaan? ARP-cache

Ma xasuusataa cutubka 1.2.3? Halkaas ARP wuxuu ka muuqday oo kaliya kahor ping-gii *ugu horreeyay*, maxaa yeelay PC-gu wuu xasuustay jawaabta. Liistadan xusuusta waxaa la yiraahdaa **ARP-cache** (sidoo kale *ARP-table*). Codsiga waxaa la yiraahdaa **ARP-Request**, jawaabta **ARP-Reply** (ama *ARP-Response*).

U beddel habka :fa-play: **Habka Socodsiinta**, ka fur :fa-terminal: **Terminal** **Anna**, oo muuji ARP-cache-keeda:

```
$ arp
```

:::quiz mc
Muxuu ku jiraa ARP-cache-ka Anna?
- [x] Kaliya IP address-ka router-ka (`192.168.0.1`) iyo MAC address-kiisa
- [ ] IP address-ka Clara iyo MAC address-ka Clara
- [ ] Address-yada router-ka iyo Clara
:::

:::evaluate
Hubi jawaabta
:::

Anna weligeed uma baahna MAC address-ka Clara: wax kasta oo loogu talagalay Shirkadda B waxay u dirtaa router-ka. MAC address-ka Clara waxaa yaqaan oo kaliya router-ka — isagaa dhinaciisa iskiis ugu weydiiyay iyada oo loo marayo ARP.

:::tip Qodob muhiim ah
**ARP-cache** gudahiisa, aaladdu waxay xasuusataa MAC address-ka u dhigma IP address kasta — sidaas darteed uma baahna inay ARP-Request dirto kahor packet kasta. Waxaa lagu muujin karaa amarka `arp`. PC-gu wuxuu yaqaan oo kaliya MAC address-yada **network-giisa** ka tirsan: ujeeddo kasta oo ku jirta network shisheeye wuxuu u isticmaalaa MAC address-ka router-ka.
:::

:::note
Network-yada dhabta ah, qoraallada ARP-cache waa la tirtiraa muddo ka dib, markii loo baahdona mar kale ayaa la weydiiyaa — tusaale ahaan haddii aaladdu hadda leedahay network card kale. BeaverTracer-ka, waxay sii jiraan inta simulation-ku socdo.
:::

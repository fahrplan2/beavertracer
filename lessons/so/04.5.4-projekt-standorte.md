# Mashruuc: Shirkad leh afar goobood

:::sim
url=/sims/lesson-4.5.4.btsim
:::

Shirkad waxay xarunteeda dhexe ku leedahay **Hanau**, waxayna laanta ku leedahay **Kassel**, **Gießen** iyo **Darmstadt**. Goob kasta waxay leedahay network u gaar ah iyo router u gaar ah. Dhammaan router-yadu waxay Standleitung (khadad kiro ah oo joogto ah) ku xiran yihiin **network dhexe**, halkaas oo uu ku yaal server-ka ugu muhiimsan ee shirkadda.

## Qorshaha ciwaannada

Maamuluhu wuxuu ciwaannada u qaybiyay sida qorshahan hoose ee muujinayo — waxay horeba ugu qoran yihiin simulation-ka:

| Network | Xadka ciwaannada |
|---|---|
| Network dhexe | `10.19.0.0/24` |
| Hanau | `10.19.1.0/24` |
| Kassel | `10.19.2.0/24` |
| Gießen | `10.19.3.0/24` |
| Darmstadt | `10.19.4.0/24` |

| Qalab | network-ka dhexe | network-ka goobta |
|---|---|---|
| Server | `10.19.0.10` | — |
| Router Hanau | `10.19.0.1` | `10.19.1.1` |
| Router Kassel | `10.19.0.2` | `10.19.2.1` |
| Router Gießen | `10.19.0.3` | `10.19.3.1` |
| Router Darmstadt | `10.19.0.4` | `10.19.4.1` |
| PC-ga goobta | — | mid kasta `.2` (tusaale PC Kassel `10.19.2.2`) |

Dhammaan router-yada, `eth0` wuxuu u jeedaa network-ka dhexe, `eth1`-na wuxuu u jeedaa network-ka goobta.

## Shaqadaada

Si dhammaan kombiyuutarrada shirkaddu ay isu gaadhaan iyo server-kana ay u gaadhaan, weli waxaa maqan laba shay:

1. **Gateways:** Ku qor gateway afarta PC dhammaantood iyo server-ka. PC-yadu waxay isticmaalaan router-ka goobtooda; server-ku wuxuu isticmaalaa **Router Hanau**.
2. **Routing tables:** Ku dar afarta router dhammaantood routes-ka weli maqan. Router kasta waa inuu aqoonsadaa network-yada **saddexda kale** ee goobood.

Inta aad shaqeynayso, ku tijaabi `ping` iyo `traceroute`.

<details>
<summary>Talo: Route-ku halkan sidee u eg yahay?</summary>

Tusaale ku saabsan **Router Kassel**: packets-ka loogu talagalay Gießen (`10.19.3.0/24`) waxay u socdaan Router Gießen ee network-kiisa dhexe — sidaa darteed **Next Hop** waa `10.19.0.3`, **Iface** waa `eth0`. Qaabkan ayaa router kasta u baahan yahay saddex routes.
</details>

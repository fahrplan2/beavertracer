# WLAN: network la'aan fiilooyin

:::goal
**Hadafka waxbarashada:** Waad sharixi kartaa sida Access Point ugu xidho WLAN network-ka fiilooyinka leh, waad geli kartaa qalab WLAN-ka adigoo isticmaalaya SSID, waadna sababayn kartaa waxa ay tahay in WLAN la xaqiijiyo (encrypt).
:::

Taleefannada gacanta, tablets-ka iyo laptop-yada badanaa ma laha meel network-ka lagu xidho (network port) — waxay ku xidhan yihiin hawada, iyagoo isticmaalaya **WLAN** (*Wireless LAN*, network maxalli ah oo aan fiilo lahayn). Si ay weli ula hadli karaan PC-yada iyo server-yada fiilada ku xidhan, waxaa loo baahan yahay qalab isku xidha hawada (wireless) iyo fiilada.

:::note
Xaqiiqada, WLAN wuxuu ku xiran yahay masaafada, darbiyada iyo carqaladaha. BeaverTracer wuu fududeeyaa: dhammaan qalabka leh isla magaca WLAN-ka waxay wadaagaan hal network hawada ah — si kasta oo ay u yaalliin **Goobta shaqada**.
:::

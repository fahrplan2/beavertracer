# Home network: router iyo NAT

:::goal
**Hadafka waxbarashada:** Waxaad awooddaa inaad magacowdo shaqooyinka home router-ka, inaad dejiso home router, inaad sharaxdo sida NAT ugu geliyo qalab badan internet-ka iyada oo la adeegsanayo hal ciwaan oo guud (public address), iyo inaad dejiso oo tijaabiso port forward.
:::

Guriga waxaa si dhakhso ah ugu jira toban qalab ama ka badan network-ka: taleefannada, laptop-yada, TV-ga, console-ka ciyaaraha, iyo dhawaaqyada. Dhamaantood waxay helaan ciwaanno sida `192.168.178.20` — oo ka yimaada xad **private** ah oo internet-ka gebi ahaanba lagu gudbin (cutubka 4.2.2). Hase yeeshee qalab kasta oo kuwan ka mid ah wuu gaadhaa internet-ka.

Sanduuq yar oo aan muuqaal weyn lahayn ayaa taas suurtageliya: **home router-ka**. Goobta shaqada waxaad bidix ka aragtaa home network oo leh PC iyo tablet, midig-na "internet-ka" — router-yada provider-ka, DNS server, iyo web server-ka `www.beispiel.de`.

:::note
Ciwaannada guud (public) ee cutubkan (`203.0.113.…`, `198.51.100.…`, `192.0.2.…`) waxaa loo kaydiyay tusaalooyin iyo agabka waxbarashada — sida uu `2001:db8::` ugu kaydsan yahay IPv6.
:::

# Indha UDP

:::sim
url=/sims/lesson-5.5.btsim
:::

Markan **Server**-ka waxaa ku shaqaynaya **UDP Echo-Server** oo ku jira port `5000`. Halkan sidoo kale xadhigga waa la diyaariyey: **datagram-ka labaad** ee ka socda Client-PC ilaa Server-ka waa lumayaa.

## Tijaabada

1. U gudub habka :fa-play: **Habka Socodsiinta** (**Run**) oo ka fur :fa-terminal: **Terminal** ka **Client-PC**.
2. Adigoo isticmaalaya `nc` bilow "xidhiidh" UDP ah oo ku wajahan server-ka (`-u` waxay u taagan tahay UDP):
   ```
   $ nc -u 192.168.0.20 5000
   ```
3. Midba midka kale ka dambeeya ku qor `eins`, `zwei` iyo `drei`, mar kasta ka dibna riix **Enter**. Sadar kasta oo soo laabata waa echo ka timid server-ka.
4. Sug dhowr ilbiriqsi, ka dibna adigoo ku jira habka :fa-magnifying-glass: **Raad** fur trace ka **Client-PC**.

:::quiz mc
Echo-yadee ayaa soo laabta?
- [ ] Dhammaan saddexda, `zwei` waxoogaa ayay ka daahdaa
- [x] Kaliya `eins` iyo `drei` — `zwei` waa maqan yahay lamana dirin mar kale
- [ ] Mid ma soo laabto
:::

:::quiz multi
Which packets ee aad ka taqaanid TCP ayaa gabi ahaanba ka maqan UDP?
- [x] Connection setup (`SYN`)
- [x] Xaqiijinaha (`ACK`)
- [x] Xidhitaanka xidhiidhka (`FIN`)
- [ ] Packets leh lambarrada port
:::

:::evaluate
Hubi jawaabaha
:::

Guji mid ka mid ah packets-ka UDP oo fur **User Datagram Protocol**. Marka lala barbardhigo header-ka TCP, header-ka UDP aad buu u yar yahay: **Source Port**, **Destination Port**, **Length** (dhererka) iyo **Checksum** (lambarka hubinta) — wadar ahaan kaliya 8 byte. Header-ka TCP waxaa ugu yaraan ah 20 byte, oo leh sequence number iyo acknowledgement number, flags iyo cabbirka daaqadda.

:::quiz mc
Hawshakee ee ka mid ah qaybta 5.1 ayuu UDP weli qabtaa?
- [x] Multiplexing — iyada oo loo marayo ports
- [ ] Connection setup
- [ ] Gudbin la isku halleyn karo
:::

:::evaluate
Hubi jawaabta
:::

:::tip Qodob muhiim ah
**UDP** waa **connectionless**: ma jiro bilow xidhiidh, ma jiro xaqiijin, ma jiro retransmission, ma jiro isku xigxiga. Wuxuu bixiyaa kaliya **ports** (multiplexing) iyo **checksum**. Beddelkeeda waa degdeg oo fudud — header-ka UDP waa 8 byte oo keliya. Haddii datagram lumo, barnaamijka ayaa laftiisu ka masuul ah — ama wax uu ka dhigan yahay ma leh.
:::

# Layer 2: Switches iyo local networks

:::goal
**Hadafka waxbarashada:** Waxaad awoodaa inaad sharaxdo sida switch uga gudbiyo frames iyadoo la adeegsanayo MAC addresses, iyo inaad hesho oo aad saxdo cilladaha caadiga ah ee ku jira local network.
:::

Ilaa hadda, mar walba waxaa kaliya laba qalab oo si toos ah isugu xidhnaa cable. Laakiin network dhab ah — guriga, dugsiga, ama shirkad — wuxuu leeyahay qalab badan: PCs, laptops, printers, servers. Goobta shaqada waxaad ku arkaysaa tusaale yar oo caadi ah: saddex PCs oo dhammaantood ku xidhan hal **switch**.

Cutubkan wuxuu ku saabsan yahay **layer 2**, ee ah data link layer: local network, MAC addresses iyo qalabka frames ku qaybiya gudaheeda.

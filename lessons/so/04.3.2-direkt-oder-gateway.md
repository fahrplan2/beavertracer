# Si toos ah mise gateway-ga ayaa loo marayaa?

:::sim
url=/sims/lesson-4.3.2.btsim
:::

Kahor inta PC uusan packet dirin, wuxuu go'aamiyaa: Ma ku jirtaa meeshii loo socdo **network-kiisa**? Taas oo uu ku sameeyo isagoo isbarbardhigaya network part-ka cinwaankiisa iyo network part-ka cinwaanka meesha loo socdo — isagoo adeegsanaya netmask-kiisa.

## Habka u dhaqmidda

1. **Ma ku jirtaa destination IP-ga network-kaaga?**
   - **Haa:** PC-gu wuxuu packet-ka u diraa **si toos ah** meesha loo socdo. Wuxuu u baahan yahay MAC address-ka meesha loo socdo.
   - **Maya:** PC-gu wuxuu packet-ka u diraa **gateway-ga**. Wuxuu u baahan yahay MAC address-ka router-ka. Haddii gateway la gelin, packet-ka dirin karo ma jiro gabi ahaanba.
2. **Ma og yahay MAC address-ka uu u baahan yahay** (ma ku jiraa ARP cache-kiisa)? Haddii kale, wuxuu ku weydiiyaa **ARP**.
3. Wuxuu frame-ka u diraa MAC address-kaas. **Destination IP address-ka** ku jira packet-ka waa meesha runta ah ee loo socdo labada xaaladood labadaba.

| | si toos ah (network-ka gaarka ah) | gateway-ga dhexdiisa (network shisheeye) |
|---|---|---|
| ARP wuxuu weydiiyaa … | MAC-ga meesha loo socdo | MAC-ga router-ka |
| Destination MAC ee frame-ka | meesha loo socdo | router |
| Destination IP ee packet-ka | meesha loo socdo | meesha loo socdo |

## Cilad-raadin: Shirkadda B lama gaari karo

Tan iyo shalay, Anna ma gaari karto PC-yada ku jira Shirkadda B. Sidan ayuu network-ku *u habboonaan lahaa*:

| Qalab | IP address | Gateway |
|---|---|---|
| Anna | `192.168.0.10/24` | `192.168.0.1` |
| Ben | `192.168.0.11/24` | `192.168.0.1` |
| Clara | `172.16.0.10/24` | `172.16.0.1` |
| David | `172.16.0.11/24` | `172.16.0.1` |

Hel khaladaadka oo saxo.

<details>
<summary>Talo 1: Ping-ka Anna ma gaarayaa gabi ahaanba?</summary>

Anna ka ping garee Clara oo fur trace u dhigan **Clara**. Ping-ku ma yimid? Clara ma jawaabtay?
</details>

<details>
<summary>Talo 2: David maxuu sameynayaa?</summary>

Anna ka ping garee David oo fur trace u dhigan **David**. IP address-kee ayuu David ku weydiinayaa ARP — jawaab ma helayaa?
</details>

:::tip Qodob muhiim ah
PC-gu wuxuu u baahan yahay gateway-ga saxda ah ma aha oo kaliya marka uu dirayo, laakiin sidoo kale marka uu **jawaabayo**: Gateway la'aan, ping-ku wuu imanayaa, laakiin jawaabtu waddo ay ku soo laabato ma hesho. Haddii **gateway address khaldan** la geliyo, PC-gu wuxuu ARP ku weydiiyaa wax aan natiijo lahayn router aan jirin.
:::

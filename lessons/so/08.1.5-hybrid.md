# Hybrid encryption (Sirta isku-dhafan)

Aan soo koobno:

| | symmetric (tusaale AES) | asymmetric (tusaale RSA) |
|---|---|---|
| Key | hal key sir ah oo la wadaago | Key pair: public + private |
| Xawaare | aad u dhaqso badan | gaabis |
| Key exchange | Dhibaato: Sidee ayuu key-gu u gaadhaa receiver-ka? | dhibaato ma jirto: public key waa la diri karaa si furan |

Habkasta waxa uu leeyahay xoog uusan habka kale lahayn. Xalku waa: labadaba isku dar. Tan waxaa la yiraahdaa **hybrid encryption**.

1. Bilowga xidhiidhka, labada dhinac waxay isku afgarteen iyagoo isticmaalaya habka **asymmetric** key sir ah oo wadaag ah, kaas oo la yiraahdo **session key**. Tani waxay qaadataa wax yar, laakiin waxay dhacdaa **hal mar** oo keliya.
2. Kadib, xogta oo dhan waxaa lagu sir-geliyaa habka **symmetric** iyadoo la isticmaalayo session key — si dhaqso ah.
3. Dhamaadka xidhiidhka, session key waa la tuuraa. Xidhiidhka xiga wuxuu helayaa mid cusub.

Sidaas ayay u shaqeeyaan **HTTPS**, xidhiidhada e-mail ee la sir-geliyay, **WLAN** oo leh WPA3, **SSH** iyo **VPN**.

## Sir wadaag ah oo laga helo isku-darka midabada

Hab qurux badan oo loo isku afgaro session key waa **Diffie-Hellman key exchange** (1976). Waxaad ku male awaali kartaa midabada. Qoritaanku waa kan: midabada isku-darkooda way fududahay, laakiin midab isku dhafan dib loogu kala saaro qaybihiisa waa ku dhawaad macquul la\'aan.

1. Anna iyo Ben waxay **si furan** isugu raacaan midab aasaasi ah oo wadaag ah, tusaale **Huruud**. Qof kasta wuu og yahay.
2. Mid kasta wuxuu si qarsoodi ah u doortaa **midab sir ah**: Anna **Cas**, Ben **Buluug**.
3. Mid kasta wuxuu midabkiisa sirta ah ku dhex daraa midabka aasaasiga ah, natiijadana **si furan** ayuu ugu diraa kan kale: Anna waxay dirtaa **Huruud + Cas** (Oranji), Ben wuxuu dirayaa **Huruud + Buluug** (Cagaar).
4. Hadda mid kasta wuxuu midabkiisa sirta ah ku dhex daraa isku-darka kan kale:
    - Anna: Cagaar + Cas = **Huruud + Buluug + Cas**
    - Ben: Oranji + Buluug = **Huruud + Cas + Buluug**
5. Labadooduba hadda waxay heystaan midab **isku mid ah** (Bunni) — key-ga wadaagga ah.

Qofka dhegaysta wuxuu arkay Huruud, Oranji iyo Cagaar. Si uu u gaadho Bunni, wuxuu u baahan lahaa Cas ama Buluug — kuwaas oo Anna iyo Ben waligood aanay dirin.

Hubi jawaabta

Dhabtii, lama xisaabiyo midabbo, laakiin waxaa la isticmaalaa tirooyin aad u waaweyn. Goobta Tracer waxaad mar dhow dib ugu arki doontaa isweydaarsigan sida **Server Key Exchange** iyo **Client Key Exchange** — "**DHE**" ee ku jira **ECDHE** waxay ka yimaadaa *Diffie-Hellman Ephemeral*, taas oo ah Diffie-Hellman oo leh key-yo la tuuro.

:::warning
Diffie-Hellman keligiis ma ilaaliyo in weeraryahan dhexda ka galo oo la heshiiyo key u gaar ah isaga iyo Anna **iyo** isaga iyo Ben. Anna sidaas daraaddeed waa inay hubtaa inay runtii la hadlayso Ben. Taas waxaa loo baahan yahay **signatures** iyo **certificates** — mawduuca xiga.
:::

:::quiz fill
Hybrid encryption-ka, labada dhinac marka hore waxay isku afgartaan habka {asymmetric} key sir ah oo wadaag ah, kaas oo la yiraahdo {session key}. Xogta dhabta ah kadib waxaa lagu sir-geliyaa habka {symmetric}, sababtoo ah tani aad bay u dhaqso badan tahay.
:::

:::tip Qodob muhiim ah
**Hybrid encryption** waxay isku daraysaa labada dunidoodaba: habka **asymmetric** (tusaale Diffie-Hellman) ayay labada dhinac ku isku afgartaan **session key** sir ah; xogta lafteeda kadib waxaa lagu sir-geliyaa habka **symmetric** (tusaale AES). Sidaas ayay u shaqeeyaan HTTPS, WLAN encryption, SSH iyo VPN.
:::

# DNS: Magacyo halkii lambaro

:::goal
**Hadafka waxbarashada:** Waxaad awoodi doontaa inaad sharaxdo sida DNS u rogo magacyada IP address, sida magacyada loogu abaabulay heerarka (hierarchy), inaad adigu samayso hal entry, oo aad hesho cilladaha DNS ee caadiga ah.
:::

:::sim

:::

IP address-yada si dhib yar ayuu qofna u xasuustaa — laakiin magacyada sida `www.beaver-schule.de` waa la xasuustaa. Tarjumaadda waxaa qabta **Domain Name System** (**DNS**), oo ah nooc buug-telefoon ah oo caalami ah oo internetka u adeega.

Goobta shaqada hadda waxaa ku yaal network wax yar ka weyn: marka laga reebo **Client-PC** iyo **Webserver**, waxaa jira afar **DNS server**. Sababta ay u yihiin kuwo badan waxaad ka arki doontaa bogga ka danbeeya bogga soo socda.

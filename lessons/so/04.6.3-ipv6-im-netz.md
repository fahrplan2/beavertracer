# IPv6 ee network-ga

:::sim
url=/sims/lesson-4.6.3.btsim
:::

Switch-ka waxaa ku xiran Anna, Ben iyo router. Anna iyo Ben, IPv6 waxaa loo dejiyey **SLAAC (automatisch)** — qofna uma qorin IPv6 address. Router-ku wuxuu garanayaa prefix-ka `2001:db8:1::/64`.

## Address-ku xaardee ka yimaadaa?

1. U gudub habka :fa-play: **Ausführen** (Habka Socodsiinta) oo sug in yar oo ilbiriqsi ah.
2. Ka fur **Anna** :fa-terminal: **Terminal** oo geli `ip a`.

Marka lagu daro IPv4 address-ka, waxaad arkaysaa laba sadar oo ay ku jirto `inet6`: address mid ah oo leh `scope link` iyo mid kale oo leh `scope global`.

:::quiz mc
Kuwan labada IPv6 address ah, kee ayaa ah link-local address?
- [x] Kan ku bilaabma `fe80::` (`scope link`)
- [ ] Kan ku bilaabma `2001:db8:1:` (`scope global`)
:::

:::quiz mc
Prefix-ka `2001:db8:1:0` ee global address-ka xaardee ka yimid?
- [ ] Anna ayaa naftiisa ka sameysatay
- [x] Waxaa ka yimid router-ka — wuxuu prefix-ka ku wargeliyaa network-ga
- [ ] Waxaa ka yimid switch-ka
:::

:::evaluate
Hubi jawaabaha
:::

Is-bar-bar dhig **Interface-ID** (afarta block ee ugu dambeeya) iyo **MAC address** ka Anna — waxaad ka heli doontaa :fa-gear: **IP Settings** hoosteeda ugu hooseysa. Tusaale ahaan, MAC address-ka `aa:28:39:e2:41:82` wuxuu noqonayaa Interface-ID `a828:39ff:fee2:4182`: badhkiisa dhexe waxaa lagu dhex xiraa `ff:fe`, bit-ka ugu horreeya waxaa la rogaa (sidaa darteed `aa` wuxuu noqdaa `a8`).

Habkan waxaa la yiraahdaa **SLAAC** (*Stateless Address Autoconfiguration*): router-ku wuxuu ku dhawaaqaa prefix-ka, Interface-ID-na qalab kasta ayaa naftiisa sameysta.

:::note
Sababtoo ah MAC address-ku wuxuu qalabka si gaar ah u aqoonsadaa, waxaa suurtagal ah in Interface-ID-ga laga garto qalabka meel kasta oo internet-ka ah. Sidaa darteed qalabka dhabta ah badanaa wuxuu sidoo kale isticmaalaa Interface-ID random ah oo si joogto ah isu beddela (*Privacy Extensions*) — qayb ka mid ah ilaalinta xogta gaarka ah.
:::

## Helitaanka deriska — ARP la'aan

1. Ku geli `ip a` **Ben** oo xusuuso **global** IPv6 address-kiisa.
2. Ka ping garee **Anna**, tusaale ahaan `ping 2001:db8:1:0:…` (adigoo isticmaalaya address-ka buuxa ee Ben).
3. U gudub habka :fa-magnifying-glass: **Verfolgung** (Raad) oo fur trace u dhigma **Anna**.

Eeg packets-ka si toos ah ka horreeya `Echo (ping) request` ugu horreeya.

:::quiz multi
Which statements are true? Kuwee ayaa sax ah?
- [x] Halkii ay ka dirto ARP request, Anna waxay dirtaa **Neighbor Solicitation** („Yaa haysta address-kan?“)
- [x] Ben wuxuu ku jawaabaa **Neighbor Advertisement** wuxuuna sheegaa MAC address-kiisa
- [x] Codsigu wuxuu aadaa multicast address (`ff02::1:ff…`), ma aha broadcast loo diro dhammaan
- [ ] Anna waxay dirtaa ARP request sida IPv4
- [x] Router-ku wuxuu si joogto ah u diraa **Router Advertisements** `ff02::1` — waxaa ku jira prefix-ka
:::

:::evaluate
Hubi jawaabaha
:::

:::tip Qodob muhiim ah
IPv6 waxaa shaqooyinka ARP qaata **NDP** (*Neighbor Discovery Protocol*, qayb ka mid ah ICMPv6): **Neighbor Solicitation** iyo **Neighbor Advertisement** waxay qalabku ku helaan MAC address-yada deriskooda. **Router Advertisements** waxay router-ku ku wargeliyaa prefix-ka — taas ayay qalabku ka sameystaan address-kooda iyagoo isticmaalaya **SLAAC**.
:::

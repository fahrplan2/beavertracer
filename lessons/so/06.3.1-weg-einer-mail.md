## Tijaabada

1. U gudub habka :fa-play: **Run** (Habka Socodsiinta), guji **Anna** oo fur app-ka **E-Mail**.
2. U gudub Tab-ka **Qor**. Meesha **An** ku qor `ben@biber-mail.de`, geli mawduuc (subject) iyo qoraal gaaban, kadibna guji **Dir**.
3. Sug dhowr ilbiriqsi — E-mail-ka waa inuu marka hore ka gudbaa mailserver una gudbaa mailserver kale. Kadib guji **Ben**, fur app-ka **E-Mail** oo guji **Soo qaad**. E-mail-kii Anna halkaas ayuu ku jiraa.
4. Habka :fa-magnifying-glass: **Raad** ku fur trace u gaar ah **Mailserver Schule**.

:::quiz mc
Xagee ayuu barnaamijka E-mail-ka ee Anna u dirayaa E-mail-ka?
- [ ] Si toos ah ugu dir PC-ga Ben
- [x] U dir mail server-keeda u gaarka ah (Mailserver Schule)
- [ ] U dir Mailserver Biber
:::

:::quiz mc
Kadib markii Mailserver Schule aqbalay E-mail-ka, wuxuu sameeyaa DNS request. Maxuu weydiiyaa? (nooca iyo magaca)
- [ ] `A ben@biber-mail.de`
- [x] `MX biber-mail.de` — which mail server ayaa mas'uul ka ah biber-mail.de?
- [ ] `A www.beaver-schule.de`
:::

## Waxa ka dambeeya

E-mail wuxuu u safraa dhowr marxaladood — sida warqad laba xafiis boosteed mara:

1. Barnaamijka E-mail-ka ee Anna wuxuu E-mail-ka ku gudbiyaa mail server-ka Anna isagoo isticmaalaya **SMTP**.
2. Mailserver Schule wuxuu arkaa: qofka helaya wuxuu ka tirsan yahay **domain shisheeye**. Isagoo adeegsanaya **DNS**, wuxuu weydiiyaa **MX record** (*Mail Exchanger*) ee `biber-mail.de` wuxuuna helaa `mail.biber-mail.de` — kadibna IP address-kiisa.
3. Wuxuu E-mail-ka ku geeyaa Mailserver Biber isagoo isticmaalaya **SMTP**. Halkaas wuxuu ku jiraa mailbox-ka Ben.
4. Ben wuxuu ka soo qaataa mail server-kiisa isagoo adeegsanaya **IMAP** (ama **POP3**).

:::seq
mode: text
Mailserver Schule -> Mailserver Biber: SMTP: MAIL FROM | anna@beaver-schule.de
Mailserver Biber -> Mailserver Schule: 250 OK
Mailserver Schule -> Mailserver Biber: SMTP: RCPT TO | ben@biber-mail.de
Mailserver Biber -> Mailserver Schule: 250 OK
Mailserver Schule -> Mailserver Biber: SMTP: DATA | E-mail-ka laftiisa
Mailserver Biber -> Mailserver Schule: 250 OK queued
:::

:::tip Qodob muhiim ah
**SMTP** (port 25) wuxuu **dirayaa** E-mail-yada: laga bilaabo barnaamijka E-mail-ka ilaa mail server-kaaga, iyo halkaas ilaa mail server-ka qofka helaya. Mail server-ka mas'uulka ka ah domain waxaa lagu qoraa **MX record** ee ku jira DNS. **POP3** (port 110) iyo **IMAP** (port 143) waxay u adeegaan oo keliya **soo qaadista** E-mail-yada mailbox-kaaga.
:::

:::quiz match
SMTP -> Dirista E-mail-yada iyo u gudbinta mail server-yada dhexdooda
MX record -> Muujiyaa mail server-ka mas'uulka ka ah domain
IMAP -> Soo qaadista E-mail-yada mailbox-kaaga
:::

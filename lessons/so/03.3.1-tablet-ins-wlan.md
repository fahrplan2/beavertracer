# Ku xirka tablet WLAN-ka

:::sim
url=/sims/lesson-3.3.1.btsim
:::

Switch-ka waxaa ku xiran **Schul-PC** (`192.168.0.10`) iyo **Access Point**. Tablet-ka **Anna** (`192.168.0.30`) waa in uu ku biiro WLAN-ka dugsiga.

## Helidda WLAN-ka

U gudub habka :fa-play: **Run** oo guji **Access Point**. Halkan waxaa ka muuqda magaca WLAN-kiisa, ee la yiraahdo **SSID**: `Schule`.

Access Point-ku wuxuu u shaqeeyaa sidii buundo: wixii hawada (raadio) uu ku helo, wuxuu u gudbiyaa switch-ka siddeeda (cable-kiisa) — iyo sidoo kale kan kale. Sidaas darteed Anna iyo Schul-PC waxay ku jiraan isla local network-ka.

## Ku xirka tablet-ka

1. Guji **Anna**, fur :fa-gear: **IP Settings**, ka dibna Tab-ka **WiFi**.
2. Meesha **SSID** ku qor magaca WLAN-ka: `Schule`, kuna dhufo **Apply**.
3. Anna ku fur :fa-terminal: **Terminal** oo ping u dir Schul-PC:
   ```
   $ ping 192.168.0.10
   ```

Markaad ping-ka sameynayso, indha ku hay Goobta shaqada: Anna iyo Access Point agtooda waxaa ku fidaya mowjado raadio.

:::tip Qodob muhiim ah
**WLAN** waa local network raadio ku shaqeeya. **Access Point** wuxuu WLAN-ka ku xidhaa network-ka cable-ka leh. WLAN kasta wuxuu leeyahay magac, kaas oo ah **SSID** (*Service Set Identifier*) — qalab waa inuu garanayaa SSID-ka saxda ah si uu ugu xidhmo.
:::

:::quiz mc
Maxaa dhacaya haddii aad Anna u gelisid SSID `schule` (xarfo yaryar)?
- [ ] Waxba — farqiga xarfaha waaweyn iyo kuwa yaryar muhiim ma aha
- [x] Anna mar dambe ma xidhna — SSID-ku waa inuu si sax ah isu waafaqaa
- [ ] Anna wuxuu ku xidhmayaa WLAN kale
:::

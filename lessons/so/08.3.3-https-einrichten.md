# Hagaajinta HTTPS

:::sim
url=/sims/lesson-8.3.3.btsim
:::

Halkan waxaan ka sii wadaynaa meeshii qaybta 8.2.2 ku dhammaatay: Webserver-ka **www.beaver-schule.de** wuxuu hayaa **Schul-CA** iyo server certificate uu soo saaray, **Client-PC**-gana wuxuu aaminsan yahay Schul-CA. Laakiin webserver-ku wali HTTPS ma hadlo.

## Hore

U beddel habka :fa-play: **Habka Socodsiinta** oo **Client-PC** ku fur :fa-globe: **Browser** `https://www.beaver-schule.de/`.

:::quiz mc
Maxaa dhaca?
- [x] Xiriirku ma dhismo — port 443 wax adeeg ah ma dhegaysto
- [ ] Browser-ku wuxuu ka digayaa certificate aan ammaan ahayn
- [ ] Bogga waxaa lagu soo bandhigaa iyadoo aan quful lahayn
:::

:::evaluate
Hubi jawaabta
:::

## Daar HTTPS

1. Webserver-ka ku fur **HTTP-Server** oo riix **Jooji** — inta server-ku shaqeynayo, goobaha lama beddeli karo.
2. U gudub **Tab**-ka **HTTPS**:
    - Calaamadi **Daar HTTPS**, **HTTPS-Port** `443`
    - Gaar ahaan **Certificate** dooro server certificate-ka `www.beaver-schule.de` — maaha Schul-CA!
    - Riix **Isticmaal**
3. Riix **Bilow**.

Bogga mar kale ka fur Client-PC adigoo adeegsanaya `https://`. Riix qufulka oo hubi cidda soo saartay iyo mudada ansax ahaanta.

:::task
title: HTTPS ma la hagaajiyay?
Waxay hubisaa in Client-PC uu u soo qaadi karo https://www.beaver-schule.de/ iyada oo aan digniin certificate ah jirin. Simulation-ku waa inuu u shaqeeyaa Habka Socodsiinta.
check: httpsOk(2, "https://www.beaver-schule.de/")
:::

:::quiz mc
Maxaad ugu doorankari weyday HTTP-Server in aad dooratid certificate-ka **Schul-CA**?
- [ ] Sababtoo ah CA certificates ma sirayn karaan
- [x] Sababtoo ah waxaa loo bixiyay magaca `Schul-CA`, ee ma aha `www.beaver-schule.de` — browser-ku wuu digi lahaa
- [ ] Sababtoo ah Schul-CA ma laha private key
:::

:::quiz mc
Maxay arki lahayd qalab aan **aaminsanayn** Schul-CA, tusaale ahaan taleefanka mid marti ah?
- [ ] Bogga si caadi ah iyo quful
- [x] Digniin certificate, sababtoo ah ma raaci karo silsiladda aaminaadda ilaa CA la yaqaan
- [ ] Waxba, sababtoo ah xiriirka waa la didiayaa
:::

:::note
Bogagga webka ee dadweynaha waxay u baahan yihiin certificate laga helay CA horay loogu rakibay dhammaan browser-yada. Laga bilaabo 2015, **Let's Encrypt** waa CA bixisa certificates noocaas ah oo bilaash ah una shaqeeya si toos ah — waana sabab weyn oo maanta ka dhigtay inta badan bogagga webka inay isticmaalaan HTTPS.
:::

:::tip Qodob muhiim ah
**HTTPS** waxay u baahan tahay in webserver-ku leeyahay **server certificate oo leh private key**, magaciisuna ku habboon yahay cinwaanka, oo uu dhegaysto **port 443**. Client-ku bogga wuu aaminayaa kaliya haddii uu yaqaan **CA** soo saartay.
:::

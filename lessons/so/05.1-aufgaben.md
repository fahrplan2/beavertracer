# Maxaa looga baahan yahay transport layer-ka?

:::sim
url=/sims/lesson-5.1.btsim
:::

Isla mar ahaan, **Server**-ka waxa ku shaqeeya laba adeeg: **web server** iyo **echo service** yar oo isla markiiba dib u soo celiya fariin kasta oo uu helo. Laba tijaabo ayaad ku ogaanaysaa waxa IP keligiis qaban kari waayo.

## Tijaabo 1: Laba barnaamij oo isla mar shaqeeya

1. U beddel habka :fa-play: **Run** oo guji **Client-PC**.
2. Fur :fa-globe: **Browser** oo fur `http://192.168.0.20/`.
3. Guji **Back** oo ku yaal sare daaqadda, kadibna fur **Simple TCP Client**. Meesha **Host** ku qor `192.168.0.20`, meesha **Port** ku qor `5000`, kadibna guji **Ku xidhiidh**.
4. U beddel habka :fa-magnifying-glass: **Raad** oo adigoo isticmaalaya **+** u fur trace **Client-PC**, port-ka `eth0`.

Guji packet ka tirsan Browser-ka (tusaale `GET /`) iyo mid ka tirsan TCP client-ka, mar kasta fur **Internet Protocol Version 4**.

:::quiz mc
Muxuu IP address yahay kan ay wataan packet-yada Browser-ka iyo TCP client-ka?
- [x] Labadaba isku mid: laga soo bilaabo `192.168.0.10` ilaa `192.168.0.20`
- [ ] Browser-ku wuxuu isticmaalaa destination IP address kale marka loo eego TCP client-ka
- [ ] Packet-yada TCP client-ku IP address ma laha
:::

:::quiz mc
Haddaba, destination IP address ma ku filan yahay in server-ku ogaado in packet uu ka tirsan yahay web server-ka mise echo service-ka?
- [ ] Haa
- [x] Maya — labada packet waxay haystaan isla destination IP address
:::

Wax kale ayaa mesha ka dhigaya labada xidhiidh. Eeg tiirka **Info** ee packet-yada leh `[SYN]` — kuwaas waa packet-ka ugu horreeya ee xidhiidh kasta:

:::quiz short
Which lambar ayaa ku taal **Browser**-ka gadaashiisa fallaadha `→`?
= 80
:::

:::quiz short
Oo **TCP client**-ka?
= 5000
:::

:::evaluate
Hubi jawaabaha
:::

Lambarradan — **port**-yada — waxaad wax badan ka baran doontaa qaybta 5.3. Hadda waxa ku filan in la ogaado: transport layer ayaa keliya hubiya in dhowr barnaamij ay isla mar isku IP address *keliya* isku xidhiidhin karaan, iyo in packet kasta uu gaadho barnaamijka saxda ah. Tan waxaa loo yaqaan **multiplexing**.

## Tijaabo 2: Marka packet lumo

1. U beddel habka :fa-play: **Run** oo guji **cable**-ka u dhexeeya Client-PC iyo Server.
2. Daaqadda **Connection** ku dhex dhig **Configured packet loss** `25%`.
3. Ka fur :fa-terminal: **Terminal** **Client-PC**-ga oo u dir lix ping:
   ```
   $ ping -c 6 192.168.0.20
   ```
   Tani waxay qaadanaysaa qiyaastii nus daqiiqo — sug ilaa istaatistigu soo muuqdo.

:::quiz mc
Maxaa dhacaya?
- [ ] Lixdaba ping waa la jawaabayaa
- [x] Qaar ka mid ah ping-yada looma jawaabo — oo cidina mar kale uma dirto
- [ ] Ping-yada lumay si toos ah ayaa loo soo celinayaa ilaa ay gaadhaan
:::

:::evaluate
Hubi jawaabta
:::

Ping-ka dhibaato ma aha — waayo waxaa loogu talagalay inuu muujiyo haddii wax lumaan. Laakiin bog web ah, e-mail ama download, qayb maqan waxay noqon lahayd musiibo: faylku wuu jabnaan lahaa.

## Afarta hawlood ee transport layer-ka

| Hawsha | Macnaheedu waa maxay |
|---|---|
| **Multiplexing** | Dhowr barnaamij iyo xidhiidh ayaa wadaaga hal IP address; packet kasta wuxuu gaadhaa barnaamijka saxda ah. |
| **Connection setup** | Intaan xogtu socon, labada dhinac way heshiiyaan inay is la hadlayaan. |
| **Reliable transmission** | Receiver-ku wuxuu xaqiijiyaa waxa yimid. Waxa maqan dib ayaa loo dirayaa, oo isku xigga waa la soo celiyaa. |
| **Connection teardown** | Dhammaadka, labada dhinac xidhiidhka si habsami leh ayay u joojiyaan. |

:::tip Qodob muhiim ah
**Transport layer** (layer 4) wuxuu hubiyaa in xogtu gaadho **barnaamijka** saxda ah (**multiplexing**). Protocol-ka **TCP** wuxuu intaas dheer hubiyaa in ay timaaddo **dhammaystiran** iyo **isku xigga saxda ah** — isagoo adeegsanaya connection setup, xaqiijin (acknowledgements), retransmission iyo connection teardown.
:::

:::quiz match
PC-ga ayaa isla mar ku shaqeeya Browser, barnaamij mail ah iyo messenger. -> Multiplexing
Intaan xogtu socon, labada dhinac way hubiyaan in kan kale diyaar yahay. -> Connection setup
Qayb ka mid ah fayl ma gaadhin oo mar kale ayaa loo diray. -> Reliable transmission
Kadib download-ka, labada dhinac xidhiidhka mar kale way sii daayaan. -> Connection teardown
:::

:::evaluate
Hubi isku-xidhka
:::

# Digital signatures

Marka la isticmaalo encryption waxaa la gaaraa **sirnimo** (confidentiality), hash value-na waxay muujisaa isbeddel kasta oo ku dhaca xogta. Laakiin sidee loo caddeeyaa **cidda** fariinta soo dirtay? Warqad dhanka ah waa la saxiixaa. Network-ga, waxaa taas loo isticmaalaa **digital signature**.

## Isticmaalka key pair dhanka kale

Marka wax la encrypt gareeynayo, sender wuxuu isticmaalaa **public key** ka receiver-ka. Signature-ka waa ka duwan yahay: sender wuxuu isticmaalaa **private key** ka **isaga u gaar ah**. Maadaama uu keligiis haysto key-gaas, keligiis ayaa sameyn kara signature-kan. Si kastaba ha ahaatee, qof walba wuu hubin karaa — isagoo isticmaalaya **public key** ka sender-ka.

**Signing** (Anna waxay saxiixaysaa heshiis):

1. Anna waxay xisaabisaa **hash value** ka heshiiska.
2. Waxay hash value-ga ku shaqaysaa **private key** keeda. Natiijadu waa **signature**.
3. Waxay heshiiska u dirtaa Ben iyo signature-ka isla markaa.

**Hubinta** (Ben wuxuu hubinayaa saxiixa):

1. Ben laftiisa ayaa xisaabiya hash value ka heshiiska uu helay.
2. Wuxuu signature-ka ku hubiyaa **public key** ka Anna: Ma la jaanqaadaa hash value-gan?
3. Haddii ay is waafaqdo, Ben wuxuu ogaanayaa laba arrimood:
    - Heshiiska runtii wuxuu ka yimid Anna — kaliya iyadaa haysata private key-ga (**Authenticity**).
    - Heshiiska waddada lagama beddelin — haddii kale hash value kale ayuu yeelan lahaa (**Integrity**).

:::note
Maxay Anna u saxiixdaa hash value-ga oo keliya, oo aysan u saxiixin heshiiska oo dhan? Habab asymmetric ah way gaabiyaan. Hash value-gu mar walba waa gaaban yahay — haba ahaado heshiisku hal bog ama kun bog.
:::

:::quiz mc
Key kee ayay Anna ku **abuurtaa** signature-keeda?
- [x] Private key-ga iyada u gaarka ah
- [ ] Public key-ga iyada u gaarka ah
- [ ] Public key-ga Ben
:::

:::quiz mc
Key kee ayuu Ben ku **hubiyaa** signature-ka?
- [ ] Private key-ga isaga u gaarka ah
- [x] Public key-ga Anna
- [ ] Private key-ga Anna
:::

:::quiz mc
Weeraryahan ayaa heshiiska qabsaday oo wuxuu badalay qaddarka lacagta. Signature-ka sidiisii ayuu ka tegay. Maxaa dhacaya markii Ben hubiyo?
- [x] Hubintu way fashilantaa, maxaa yeelay heshiiska la bedelay wuxuu leeyahay hash value kale
- [ ] Hubintu way guulaysataa, maxaa yeelay signature-ku runtii waa sax
- [ ] Ben ma hubin karo signature-ka gabi ahaanba, maxaa yeelay ma yaqaan private key-ga Anna
:::

:::tip Qodob muhiim ah
**Digital signature** waxaa sameeya sender-ka isagoo isticmaalaya **hash value** ka fariinta iyo **private key** keeda. Qof kasta wuu hubin karaa isagoo isticmaalaya **public key** ka sender-ka. Signature sax ah waxay caddaynaysaa **cidda** fariinta soo dirtay (**Authenticity**) iyo in **aan la bedelin** (**Integrity**).
:::

# Qaabka tixraaca ee TCP/IP

Qaabka ISO/OSI aad buu faahfaahsan yahay, laakiin wuxuu ka dhashay aragti kaliya (theory). Xaqiiqada dhabta ah — iyo internetka dhexdiisa — waxaa beddelkeeda ku guulaystay **qaabka TCP/IP** ee ka fudud, kaas oo leh afar layer oo kaliya. Wuxuu layer-ro OSI ah oo dhawr ah ka dhigaa mid keliya:

| TCP/IP layer | waxay u dhigantaa OSI layer(s) | Protocols tusaale ah |
|---|---|---|
| Application | 5, 6, 7 (Session, Presentation, Application) | HTTP, DNS, SMTP |
| Transport | 4 (Transport) | TCP, UDP |
| Internet | 3 (Network) | IP, ICMP |
| Network access | 1, 2 (Physical, Data Link) | Ethernet, WLAN |

ARP wuxuu ku yaal xadka u dhexeeya network access iyo internet (OSI 2/3, eeg xaaladaha xadka ah ee bogga ugu dambeeya).

Kala qaybinta session/presentation/application marar badan ma kala cadda xaqiiqada dhabta ah — inta badan application protocols-ka sida HTTP waxay wax kasta u qabtaan laftooda. Qaabka TCP/IP wuxuu tan tixgeliyaa isagoo saddexdan layer ka dhigaya mid keliya.

:::note
Marka aad cutubyada soo socda ka akhrisato "layer 2", "layer 3" ama "layer 4", had iyo jeer waxaa loola jeedaa tirinta qaabka ISO/OSI — tani waa tixraaca guud ee casharkan, inkastoo BeaverTracer iyo xaqiiqada dhabta ah inta badan ay ku fekeraan qaybaha TCP/IP.
:::

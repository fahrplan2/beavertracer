# Eeg shahaado (certificate)

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Goobta shaqada waxaad ka arkaysaa **Client-PC**, **DNS-Server** iyo web server-ka dugsiga, `www.beaver-schule.de`. Web server-ku wuxuu bogagiisa ku bixiyaa **HTTPS** sidoo kale.

## Quful-ka ku jira Browser-ka

1. U beddel habka :fa-play: **Habka Socodsiinta**, riix **Client-PC** kadibna fur :fa-globe: **Browser**.
2. Fur `https://www.beaver-schule.de/` — fiiro gaar ah u yeelo **https**.
3. Dhinaca bidix ee ciwaanka waxaa ka muuqda **quful**. Riix.

:::quiz short
Magaca ay shahaadada (certificate) loo bixiyay waa kuwee (Betreff, oo aan lahayn `CN=`)?
= www.beaver-schule.de
:::

:::quiz short
Yaa bixiyay shahaadada (certificate) (Aussteller, oo aan lahayn `CN=`)?
= Biber Root CA
:::

:::evaluate
Hubi jawaabaha
:::

## Maxaa Client-PC u aamminaa shahaadada (certificate)?

Client-PC-ga ku fur :fa-shield-halved: **Zertifikatverwaltung** kadibna u gudub **Tab**-ka **Vertrauenswürdige CAs**.

:::quiz mc
Maxaad halkaas ka heleysaa?
- [x] Shahaadada (certificate) **Biber Root CA**
- [ ] Shahaadada (certificate) `www.beaver-schule.de`
- [ ] Wax gelitaan ah ma jiro
:::

:::quiz mc
Sidee loo arkaa in Biber Root CA ay tahay Root-CA?
- [x] Waa **selbstsigniert** (is-saxiixday): Betreff iyo Aussteller waa isku mid
- [ ] Magaceeda wuxuu ku dhammaadaa „CA“
- [ ] Ma laha furaha dadweynaha (public key)
:::

:::quiz mc
Marka la eego Client-PC, hoosta **Privater Schlüssel** ma ku qoran yahay „Ja“ mise „Nein“?
- [ ] Ja — client-ku wuxuu u baahan yahay furaha gaarka ah (private key) ee CA si uu u hubiyo saxiixyada
- [x] Nein — hubinta waxaa ku filan furaha dadweynaha (public key); furaha gaarka ah (private key) waxaa haysta CA oo keliya
:::

:::evaluate
Hubi jawaabaha
:::

## Dhinaca kale: web server-ka

Hadda web server-ka **www.beaver-schule.de** ku fur :fa-shield-halved: **Zertifikatverwaltung** (Tab-ka **Meine Zertifikate**) oo eeg shahaadadiisa (certificate).

:::quiz multi
Maxay run tahay ku saabsan shahaadada (certificate) ku jirta web server-ka?
- [x] Hoosta **Privater Schlüssel** waxaa ku qoran „Ja“ — server-ku wuxuu u baahan yahay connection setup-ka
- [x] **Kette** (silsiladda) waa `www.beaver-schule.de ← Biber Root CA`
- [x] **Fingerabdruck**-ku wuxuu la mid yahay kan ku jira daaqadda quful-ka ee Browser-ka
- [ ] Waa selbstsigniert (is-saxiixday)
:::

:::evaluate
Hubi jawaabaha
:::

:::note
**Fingerabdruck** waa hash value ka dhisan shahaadada (certificate). Waxaa lagu barbardhigi karaa laba shahaadooyin si degdeg ah — iyadoon la hubin goobaha oo dhan mid mid.
:::

:::tip Qodob muhiim ah
**Web server-ku** wuxuu haystaa shahaadadiisa (certificate) **isagoo leh furaha gaarka ah (private key)**. **Client-ku** wuxuu garanayaa oo kaliya **shahaadada Root-CA** (furaha gaarka ah la'aan) — taasi waxay ku filan tahay inuu hubiyo saxiixa ku jira shahaadada server-ka. Marka Browser-ka lagu riixo **qufulka**, waxaa la arkaa Betreff, Aussteller, Fingerabdruck iyo muddada ansaxnimada.
:::

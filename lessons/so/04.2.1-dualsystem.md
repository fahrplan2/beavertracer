# Nidaamka binary

Gudaha dhabta ah, kombiyuutarku wuxuu yaqaan oo kaliya laba xaaladood: koronto shidan ama koronto dansan. Tan waxaa loo qoraa **1** iyo **0**. Meel noocan ah waxaa la yiraahdaa **bit**. IP address kasta, kombiyuutarka u ahaan, waa oo kaliya taxane eber iyo mid ah — si aad u fahamto sida netmask-yadu u shaqeeyaan, boggan waxaad ku baranaysaa inaad akhrisato tirooyinkaas oo aad naftaadu u beddesho.

## Sida caadiga ah ee aan u tirinno: nidaamka decimal

Maalin kasta waxaan xisaabinnaa annagoo adeegsanayna toban lambar (0 ilaa 9). Meel kasta waxay u qiimo badan tahay toban jeer meesha ku xigta dhinaceeda midig: kunka, boqolaalka, tobanaadka, keliyaha. Sidaas darteed lambarka `305` waxaa uu ka dhigan yahay:

| Qiimaha meesha | 100 | 10 | 1 |
|---|---|---|---|
| Lambarka | 3 | 0 | 5 |
| Qiimaha | 300 | 0 | 5 |

300 + 0 + 5 = **305**

## Nidaamka binary

Gudaha **nidaamka binary** waxaa jira oo kaliya laba lambar: 0 iyo 1. Meel kasta waxay u qiimo leedahay **laba jeer** meesha ku xigta dhinaceeda midig: 1, 2, 4, 8, 16, 32, 64, 128 …

Sidaas darteed lambarka binary ee `00001101` waxaa uu ka dhigan yahay:

| Qiimaha meesha | 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1 |
|---|---|---|---|---|---|---|---|---|
| Bit | 0 | 0 | 0 | 0 | 1 | 1 | 0 | 1 |
| Qiimaha | | | | | 8 | 4 | | 1 |

8 + 4 + 1 = **13**

Sidaas darteed waxaad si fudud isugu darsataa qiimaha meelaha uu 1 ku yaal.

:::tip Qodob muhiim ah
**Bit** waa hal meel oo nidaamka binary ah (0 ama 1). **8 bit** waxay sameeyaan hal **byte** — farsamada networking-ka, koox 8-bit ah noocaas ah waxaa sidoo kale la yiraahdaa **octet**. Qiimaha meelaha octet-ku waa **128, 64, 32, 16, 8, 4, 2, 1**.
:::

## Laga bilaabo decimal ilaa binary

Dhanka kale, waxaad qiimaha meelaha ka dhex socotaa bidix ilaa midig, mar kastana waxaad is weydiisaa: **Miyuu qiimaha meeshu ku soo ekaanayaa lambarkayga (inta hadhay)?** Haddii haa, waxaad qortaa 1 oo waxaad ka jartaa qiimaha meesha. Haddii maya, waxaad qortaa 0.

Tusaale: `168`

| Qiimaha meesha | ma ku soo ekaadaa …? | Bit | Hadhaaga |
|---|---|---|---|
| 128 | 168 → haa | **1** | 40 |
| 64 | 40 → maya | **0** | 40 |
| 32 | 40 → haa | **1** | 8 |
| 16 | 8 → maya | **0** | 8 |
| 8 | 8 → haa | **1** | 0 |
| 4 | 0 → maya | **0** | 0 |
| 2 | 0 → maya | **0** | 0 |
| 1 | 0 → maya | **0** | 0 |

Marka laga akhriyo kor ilaa hoos: 168 = **10101000**

:::tip Talo
Qiimahan waxaad la kulmi doontaa netmask-yada mar kasta — way ku habboon tahay inaad aqaanto: `10000000` = 128, `11000000` = 192, `11100000` = 224, `11110000` = 240, `11111000` = 248, `11111100` = 252, `11111110` = 254, `11111111` = 255.
:::

## IP address-yada nidaamka binary

IPv4 address wuxuu ka kooban yahay **32 bit**, taas oo ah afar octet. Maadaama aysan cidina xasuusan karin 32 eber iyo mid ah, octet kasta waxaa loo qoraa lambar decimal ah oo waxaa lagu kala saaraa dhibco:

```
11000000 . 10101000 . 10110010 . 00000001
   192   .   168    .   178    .    1
```

:::quiz short
IPv4 address wuxuu ka kooban yahay imisa bit?
= 32
:::

:::quiz mc
Aragti ahaan, imisa IPv4 address oo kala duwan ayaa jira?
- [ ] 256 × 4 = 1024
- [x] 2³² — qiyaastii 4.3 bilyan
- [ ] In ka badan oo ku filan — qof kasta oo dhulka ku nool in badan
:::

:::evaluate
Hubi jawaabaha
:::

:::note
Qiyaastii 4.3 bilyan waxay u muuqataa mid badan — laakiin way ka yar tahay hal address qof kasta oo dhulka ku nool. Sidaas darteed IPv4 address-yadu waxay ku yaryihiin muddo dheer. Sida wax looga qabto waxaad baran doontaa mar dambe marka aad barato NAT iyo IPv6.
:::

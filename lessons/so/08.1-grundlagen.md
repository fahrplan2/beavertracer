# Aasaaska cryptography

**Cryptography** waa cilmiga sirta-gelinta (encryption). Kahor intaan bilaabin, halkan waxaa ku jira qaar ka mid ah erayada ku soo noqnoqda cutubkan:

| Eray | Macne |
|---|---|
| **Plaintext** | Fariinta la akhrin karo, tusaale `Treffen um 10 Uhr` |
| **Ciphertext** | Fariinta la sir-geliyey, tusaale `Wuhiihq xp 10 Xku` |
| **Encrypt** | Plaintext → Ciphertext |
| **Decrypt** | Ciphertext → Plaintext |
| **Habka** (*Algorithm*) | Xeerka xisaabeed ee sir-gelintu ku dhacdo |
| **Key** | Macluumaadka dheeriga ah ee sirta ah ee habku u baahan yahay |

## Habku ma aha mid sir ah — key-ga ayaa sir ah

Waxaa laga yaabaa inaad moodo in habku ammaan badan yahay marka dadka yaqaan ay yar yihiin. Taas lid bay tahay: dhammaan habab-yada maanta caadiga ah waa kuwo **bayaan ah** (public) oo la sharaxay, waxaana sannado badan baadhay khubaro adduunka oo dhan ah si ay u helaan nugaylaha. Waxa sir ah oo kaliya waa **key-ga**.

Mabda'an waxaa hore u dejiyey Nederlandka ah Auguste Kerckhoffs sannadkii 1883. Faa'iidadu waa: haddii key la daaha qaado, si fudud ayaa key-ga loo beddelaa — ma aha habka oo dhan.

Qaybaha soo socda waxaad ka baran doontaa afarta dhisme ee lagu dhiso xidhiidhada ammaanka ah:

1. **Symmetric encryption** — degdeg ah, laakiin leh dhibaato key ah
2. **Asymmetric encryption** — public key iyo private key
3. **Hash values** — faraha-calaamadda xogta
4. **Digital signatures** — saxiixyo elektaroonig ah

Dhammaadka waxaad arki doontaa sida dhismayaashan wada shaqeeyaan (**hybrid encryption**).

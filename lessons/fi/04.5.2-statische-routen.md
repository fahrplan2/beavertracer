# Staattisten reittien lisääminen

:::sim
url=/sims/lesson-4.5.2.btsim
:::

Tällä kertaa Yritys A:n ja Yritys B:n välissä on **kaksi** reititintä. Ne on yhdistetty toisiinsa omalla pienellä verkollaan, **väliverkolla** `10.0.0.0/30`:

| Reititin | Liitäntä | IP-osoite | Verkko |
|---|---|---|---|
| Router A | `eth0` | `192.168.0.1/24` | Yritys A (Anna) |
| Router A | `eth1` | `10.0.0.1/30` | Väliverkko |
| Router B | `eth0` | `10.0.0.2/30` | Väliverkko |
| Router B | `eth1` | `172.16.0.1/24` | Yritys B (Clara) |

:::note
`/30`-verkossa on täsmälleen kaksi käyttökelpoista osoitetta, joten se sopii täydellisesti kahden reitittimen yhdistämiseen (katso luku 4.2.3).
:::

## Ongelma

Siirry :fa-play: **Suorita**-tilaan ja pingaa **Annalta** Claraa (`ping 172.16.0.10`). Clara ei vastaa. Sen sijaan Router A (`192.168.0.1`) ilmoittaa: "Kohdeverkko ei ole tavoitettavissa".

Katso **Router A**:n **Reititystaulukko IPv4** -välilehteä.

:::quiz mc
Miksi Annan ping ei saavu perille Claralle?
- [ ] Annalle ei ole määritetty yhdyskäytävää
- [x] Router A ei tunne verkkoa `172.16.0.0/24`. Se ei ole suoraan kytketty siihen, eikä sinne ole reittiä
- [ ] Väliverkko on liian pieni
:::

:::evaluate
Tarkista vastaus
:::

## Reitin lisääminen

Router A:n täytyy oppia, että verkkoon `172.16.0.0/24` menevät paketit lähetetään Router B:lle (`10.0.0.2`) liitännän `eth1` kautta.

1. Avaa **Router A**:lla **Reititystaulukko IPv4** -välilehti ja napsauta **+ lisää**.
2. Syötä uudelle riville: **Kohde** `172.16.0.0`, **Verkkomaski** `255.255.255.0`, **Seuraava hyppypiste** `10.0.0.2`, **Iface** `eth1`.
3. Tallenna rivi valintamerkillä :fa-check:. **Lähde**-sarakkeessa lukee nyt **Staattinen**.

Pingaa Claraa uudelleen. Nyt vastaus tulee.

:::note
Router B tuntee muuten jo paluureitin Yritys A:n verkkoon: sen reititystaulussa on valmiiksi staattinen reitti verkkoon `192.168.0.0/24` osoitteen `10.0.0.1` kautta. Miksi tämä paluureitti on yhtä tärkeä, näet seuraavalla sivulla.
:::

## Reitin seuraaminen: traceroute

Komennolla `traceroute` voit näyttää, minkä reitittimien kautta paketti kulkee. Anna **Annalla** komento:

```
$ traceroute 172.16.0.10
```

:::quiz short
Kuinka monen reitittimen kautta paketti kulkee Annalta Claralle?
= 2
= kaksi
:::

:::quiz mc
Minkä osoitteen `traceroute` näyttää Router B:lle?
- [x] `10.0.0.2`, eli sen osoite väliverkossa, jonka kautta paketti saapuu
- [ ] `172.16.0.1`, eli sen osoite Yritys B:n verkossa
- [ ] `192.168.0.1`
:::

:::evaluate
Tarkista vastaukset
:::

`traceroute` hyödyntää temppua, joka perustuu luvun 4.3.1 **Time to Live** -kenttään: se lähettää ensin paketin, jonka TTL on 1. Ensimmäinen reititin vähentää arvoa yhdellä, arvo on 0, reititin hylkää paketin ja ilmoittaa siitä lähettäjälle. Näin Anna tuntee ensimmäisen reitittimen. Sitten lähetetään paketti, jonka TTL on 2, toista reititintä varten, ja niin edelleen, kunnes kohde vastaa.

:::tip Muista
**Staattisen reitin** ylläpitäjä lisää käsin: kohdeverkko, verkkomaski, seuraava hyppypiste ja liitäntä. **traceroute**-komennolla paketin reittiä voi seurata reititin kerrallaan.
:::

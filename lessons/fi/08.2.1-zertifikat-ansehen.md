# Varmenteen tarkastelu

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Työtilassa näet **Client-PC**:n, **DNS-Server**in ja koulun verkkopalvelimen `www.beaver-schule.de`. Verkkopalvelin tarjoaa sivunsa myös **HTTPS**-yhteydellä.

## Lukko selaimessa

1. Siirry :fa-play: **Suorita**-tilaan (Suoritustila), napsauta **Client-PC**:tä ja avaa :fa-globe: **Selain**.
2. Avaa `https://www.beaver-schule.de/` — kiinnitä huomiota **https**-alkuun.
3. Osoitteen vasemmalle puolelle ilmestyy **lukko**. Napsauta sitä.

:::quiz short
Minkä nimelle varmenne on myönnetty (kohde ilman `CN=`)?
= www.beaver-schule.de
:::

:::quiz short
Kuka on myöntänyt varmenteen (myöntäjä ilman `CN=`)?
= Biber Root CA
:::

:::evaluate
Tarkista vastaukset
:::

## Miksi Client-PC luottaa varmenteeseen?

Avaa **Client-PC**:llä :fa-shield-halved: **Zertifikatverwaltung** ja siirry välilehdelle **Vertrauenswürdige CAs**.

:::quiz mc
Mitä löydät sieltä?
- [x] **Biber Root CA** -varmenteen
- [ ] Varmenteen `www.beaver-schule.de`
- [ ] Ei yhtään merkintää
:::

:::quiz mc
Mistä näkee, että Biber Root CA on juuri-CA?
- [x] Se on **itseallekirjoitettu**: kohde ja myöntäjä ovat samat
- [ ] Sen nimi päättyy sanaan "CA"
- [ ] Sillä ei ole julkista avainta
:::

:::quiz mc
Onko Client-PC:llä kohdassa **Privater Schlüssel** "Ja" vai "Nein"?
- [ ] Ja — asiakas tarvitsee CA:n yksityisen avaimen allekirjoitusten tarkistamiseen
- [x] Nein — tarkistamiseen riittää julkinen avain; yksityinen avain on vain CA:lla
:::

:::evaluate
Tarkista vastaukset
:::

## Vastapuoli: verkkopalvelin

Avaa nyt verkkopalvelimella **www.beaver-schule.de** :fa-shield-halved: **Zertifikatverwaltung** (välilehti **Meine Zertifikate**) ja tarkastele sen varmennetta.

:::quiz multi
Mitkä väitteet pitävät paikkansa verkkopalvelimen varmenteesta?
- [x] Kohdassa **Privater Schlüssel** lukee "Ja" — palvelin tarvitsee sitä yhteyden muodostukseen
- [x] **Kette** on `www.beaver-schule.de ← Biber Root CA`
- [x] **Fingerabdruck** on sama kuin selaimen lukkoikkunassa
- [ ] Se on itseallekirjoitettu
:::

:::evaluate
Tarkista vastaukset
:::

:::note
**Sormenjälki** on varmenteesta laskettu tiivisteen arvo. Sen avulla kaksi varmennetta voi verrata nopeasti — tarvitsematta tarkistaa kaikkia kenttiä yksitellen.
:::

:::tip Muista
**Verkkopalvelimella** on varmenteensa **yksityisen avaimen kanssa**. **Asiakas** tuntee vain **juuri-CA:n varmenteen** (ilman yksityistä avainta) — se riittää palvelimen varmenteen allekirjoituksen tarkistamiseen. Kun selaimessa napsauttaa **lukkoa**, näkee kohteen, myöntäjän, sormenjäljen ja voimassaoloajan.
:::

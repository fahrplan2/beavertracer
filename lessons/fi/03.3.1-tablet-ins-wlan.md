# Tabletin liittäminen WLAN-verkkoon

:::sim
url=/sims/lesson-3.3.1.btsim
:::

Kytkimeen on liitetty **Schul-PC** (`192.168.0.10`) ja **Langaton Reititin**. Tabletti **Anna** (`192.168.0.30`) halutaan liittää koulun WLAN-verkkoon.

## WLAN-verkon löytäminen

Siirry :fa-play: **Suorita**-tilaan eli Suoritustilaan ja napsauta **Langaton Reititin** -laitetta. Siinä näkyy sen WLAN-verkon nimi, **SSID**: `Schule`.

Langaton Reititin toimii kuin silta: mitä se vastaanottaa radioteitse, sen se välittää kaapelia pitkin kytkimelle — ja päinvastoin. Näin Anna ja Schul-PC päätyvät samaan lähiverkkoon.

## Tabletin yhdistäminen

1. Napsauta **Anna**-laitetta, avaa :fa-gear: **IP-asetukset** ja siellä välilehti **WiFi**.
2. Kirjoita kohtaan **SSID** WLAN-verkon nimi: `Schule`, ja napsauta **Käytä**.
3. Avaa Annan :fa-terminal: **Pääte** ja lähetä pingi Schul-PC:lle:
   ```
   $ ping 192.168.0.10
   ```

Seuraa pingin aikana työtilaa: Annan ja Langattoman Reitittimen ympärille leviää radioaaltoja.

:::tip Muista
**WLAN** on radioteitse toimiva lähiverkko. **Langaton Reititin** yhdistää WLAN-verkon kaapeloituun verkkoon. Jokaisella WLAN-verkolla on nimi, **SSID** (*Service Set Identifier*) — laitteen täytyy tietää oikea SSID, jotta se voi yhdistää verkkoon.
:::

:::quiz mc
Mitä tapahtuu, jos kirjoitat Annan SSID:ksi `schule` (pienillä kirjaimilla)?
- [ ] Ei mitään — isoilla ja pienillä kirjaimilla ei ole merkitystä
- [x] Anna ei ole enää yhteydessä — SSID:n täytyy täsmätä täsmälleen
- [ ] Anna yhdistää toiseen WLAN-verkkoon
:::

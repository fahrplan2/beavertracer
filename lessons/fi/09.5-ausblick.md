# Yhteenveto ja katsaus eteenpäin

## Palomuurit monessa paikassa

Tämän luvun pakettisuodattimen löydät monista laitteista:

- **Kotireititin:** Jokainen kotireititin on myös tilallinen palomuuri. IPv4:llä NAT hoitaa osan tästä: ulkopuolelta kukaan ei voi aloittaa yhteyttä, ellei porttiohjausta ole määritetty (luku 7). IPv6:lla kaikilla laitteilla on julkiset osoitteet — silloin sama suoja syntyy pelkästään palomuurisäännöstä ”ulkoa ei päästetä sisään mitään uutta”.
- **Henkilökohtainen palomuuri:** Myös Windowsissa, macOS:ssä ja Linuxissa on sisäänrakennettu palomuuri itse tietokoneessa. Se suojaa laitetta myös vieraissa verkoissa, esim. kahvilan WLAN-verkossa, ja voi määrittää sääntöjä ohjelmakohtaisesti.
- **Seuraavan sukupolven palomuuri (Next-Generation Firewall)** ja **Web Application Firewall (WAF):** Ne katsovat osoitteiden ja porttien lisäksi pakettien sisältöä — aina sovelluskerrokseen asti. Näin ne tunnistavat esim. hyökkäyksiä HTTP-pyynnöissä. HTTPS:n kohdalla niiden täytyy tätä varten purkaa salaus (luku 8).
- **IDS/IPS:** *Intrusion Detection System* tunnistaa epäilyttäviä kuvioita tietoliikenteessä ja antaa hälytyksen; *Intrusion Prevention System* estää ne lisäksi itse.

:::note
Palomuuri on vain **yksi** osa tietoturvaa. Se ei auta, jos sallitussa palvelussa (esim. verkkopalvelimessa) itsessään on haavoittuvuus, jos joku avaa haittaohjelman sähköpostista tai jos salasana on heikko. Siksi päivitykset, turvalliset salasanat, salaus ja verkon järkevä jako osiin (DMZ, VLAN:it luvusta 3) kuuluvat aina mukaan.
:::

## Testaa itsesi

:::quiz mc
Palomuuri toimii oletuskäytännöllä ”Hylkää kaikki” ja yhdellä säännöllä ”A → B, TCP 443, Salli”. Paketti A → B TCP-porttiin 22 saapuu. Mitä tapahtuu?
- [ ] Se sallitaan
- [x] Se hylätään
- [ ] Se torjutaan
:::

:::quiz mc
`nmap` ilmoittaa portille tilan `filtered`. Mitä se tarkoittaa?
- [ ] Portissa on käynnissä palvelu
- [ ] Palvelin vastasi RST-paketilla
- [x] Vastausta ei tullut lainkaan — palomuuri todennäköisesti hylkää paketit
:::

:::quiz multi
Mitkä väittämät pitävät paikkansa?
- [x] Tilallisessa palomuurissa vastaukset sallittuihin yhteyksiin pääsevät automaattisesti takaisin
- [x] Sallittujen lista (whitelist) on turvallisempi kuin estolista (blacklist), koska uudet palvelut pysyvät automaattisesti estettyinä
- [x] Internetistä tavoitettavat palvelimet kuuluvat DMZ:hon
- [ ] Palomuuri suojaa myös hyökkäyksiltä kahden samassa sen takana olevassa verkossa olevan tietokoneen välillä
- [ ] Kaikki säännöt tarkistetaan aina, ja tiukin voittaa
:::

# Yhteenveto ja jatko

## Rakennuspalikat yhdellä silmäyksellä

| Rakennuspalikka | Tietoturvatavoite | Esimerkki |
|---|---|---|
| **Symmetrinen salaus** | Luottamuksellisuus | AES salaa HTTPS-yhteyden datan |
| **Asymmetrinen salaus** | Luottamuksellisuus, avaimenvaihto | Diffie-Hellman, RSA |
| **Tiivisteet** | Eheys | Latauksen SHA-256-tarkistussumma |
| **Digitaalinen allekirjoitus** | Aitous, eheys | Palvelin allekirjoittaa oman Diffie-Hellman-osuutensa |
| **Varmenne** | Aitous | vahvistaa: tämä avain kuuluu osoitteelle `www.biberbank.de` |

## Sama periaate monessa paikassa

Se, minkä opit HTTPS:stä, on mukana myös monessa muussa tekniikassa:

- **WLAN (WPA2/WPA3):** Luvussa 3.3.2 jokainen kantoalueella oleva laite pystyi lukemaan liikennettä mukana. WPA2:ssa tai WPA3:ssa jokainen radiokehys salataan AES:llä. WPA3 lisäksi sopii avaimesta niin, ettei salakuuntelija pysty purkamaan vanhoja tallenteita, vaikka tietäisi WLAN-salasanan.
- **SSH:** Salattu etähallinta luvusta 6.6. Varmenteiden sijaan asiakas tallentaa ensimmäisellä yhteydenotolla palvelimen avaimen **sormenjäljen** ja varoittaa, jos se muuttuu myöhemmin.
- **VPN:** Salattu tunneli internetin läpi, esimerkiksi koulun tai yrityksen verkkoon. Siitä kerrotaan luvussa 10.
- **Viestisovellukset:** Signal, WhatsApp ja muut salaavat viestit **päästä päähän**: edes palvelun ylläpitäjä ei voi lukea viestejä.

:::note
Suuret **kvanttitietokoneet** voisivat jonain päivänä pystyä jakamaan suuria lukuja alkutekijöihin ja siten murtamaan RSA:n ja Diffie-Hellmanin. Siksi uusia, **kvanttiturvallisia** menetelmiä otetaan käyttöön jo nyt. Symmetriset menetelmät, kuten AES pitkillä avaimilla, katsotaan edelleen turvallisiksi.
:::

## Testaa itsesi

:::quiz mc
HTTPS:ssä varsinainen data salataan …
- [ ] RSA:lla, koska se on turvallisin
- [x] symmetrisellä menetelmällä, kuten AES:llä, ja yhteisesti sovitulla istuntoavaimella
- [ ] palvelimen yksityisellä avaimella
:::

:::quiz mc
Avaat osoitteen `https://www.biberbank.de/` ja selain ilmoittaa: ”Varmenne on myönnetty osoitteelle `www.gewinn-biber.de`”. Mitä teet?
- [ ] Klikkaan ”Jatka silti” – yhteys on kuitenkin salattu
- [x] Keskeytän – selain ei ehkä puhu lainkaan pankin kanssa
- [ ] Avaan sivun osoitteella `http://`, jolloin varoitusta ei tule
:::

:::quiz multi
Mitkä väitteet pitävät paikkansa?
- [x] Tiivisteen arvo muuttuu täysin, vaikka data muuttuisi vain hieman
- [x] Allekirjoitus luodaan yksityisellä avaimella ja tarkistetaan julkisella avaimella
- [x] Juurivarmentajat (root-CA:t) on esiasennettu selaimeen tai käyttöjärjestelmään
- [ ] HTTPS:ssä salakuuntelija ei näe edes palvelimen IP-osoitetta
- [ ] SMTPS salaa viestin myös postipalvelimella
:::

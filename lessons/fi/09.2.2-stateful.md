# Tilallinen palomuuri

:::sim
url=/sims/lesson-9.2.btsim
:::

**Tilallinen** (*stateful*) palomuuri muistaa jokaisen yhteyden, jonka se on kerran sallinut, **tilataulukkoon**: protokolla, molemmat osoitteet ja molemmat portit. Jos saapuu paketti, joka vastaa jotakin merkintää — suunnasta riippumatta —, palomuuri päästää sen läpi ilman lisätarkistusta. Uusien yhteyksien on sen sijaan läpäistävä säännöt.

## Havainnointi

1. Aseta **palomuurin** **tilaksi** **Stateful**.
2. Avaa **opettajan tietokoneella** :fa-globe: **Selain**-sovelluksessa jälleen `http://203.0.113.80/`.
3. Avaa palomuurissa heti välilehti **Tilat**.

:::quiz mc
Mitä nyt tapahtuu?
- [x] Sivu latautuu, ja kohdassa **Tilat** näkyy yhteys opettajan tietokoneelta osoitteeseen `203.0.113.80:80`
- [ ] Sivu ei lataudu, koska vastauksille ei edelleenkään ole sääntöä
:::

:::quiz short
Mikä portti on tilataulukossa **kohteen** kohdalla?
= 80
:::

:::evaluate
Tarkista vastaukset
:::

Kohdan **Tilat** merkinnät katoavat jonkin ajan kuluttua (sarake **Timeout**), jos yhteydellä ei enää liiku mitään.

## Tehtävä: Koulun palomuuri

Määritä palomuuri nyt niin, kuin oikea koulu sitä tarvitsee:

- **Koulun verkosta** saa mennä kaikki internetiin (suunta B → A, mikä tahansa protokolla).
- **Internetistä** ovat tavoitettavissa vain koulupalvelimen web (80) ja sähköpostin vastaanotto (25).
- Kaikki muu **hylätään**, tilana on **Stateful**.

:::task
title: Onko koulun palomuuri määritetty?
Tarkistaa, pääseekö koulun verkosta internetiin, ovatko ulkopuolelta tavoitettavissa vain koulupalvelimen web ja sähköposti, ja onko opettajan tietokone tavoittamattomissa ulkopuolelta.
check: tcpOpen(8, "203.0.113.80", 80)
check: tcpOpen(1, "198.51.100.10", 80)
check: tcpOpen(1, "198.51.100.10", 25)
check: tcpFails(1, "198.51.100.10", 22)
check: pingFails(1, 8)
:::

:::quiz mc
Opettajan tietokone lähettää ping-kyselyn osoitteeseen `203.0.113.80`. Tulevatko vastaukset takaisin?
- [x] Kyllä — ping sallittiin suunnassa B → A, ja vastaus kuuluu tähän tilaan
- [ ] Ei — ulkopuolelta tulevalle ICMP-liikenteelle ei ole sääntöä
:::

:::evaluate
Tarkista vastaus
:::

:::tip Muista
**Tilallinen palomuuri** kirjaa jokaisen sallitun yhteyden **tilataulukkoon** ja päästää kaikki tämän yhteyden paketit läpi **molempiin suuntiin**. Näin **yhteyden muodostusta** koskevat säännöt riittävät: ”Sisältä saa mennä ulos” ja ”ulkoa vain tiettyihin palveluihin”. Ulkopuolelta aloitetut yhteydet koulun verkkoon pysyvät estettyinä.
:::

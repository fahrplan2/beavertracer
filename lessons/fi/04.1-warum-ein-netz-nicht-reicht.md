# Miksi yksi verkko ei riitä

:::sim
url=/sims/lesson-4.1.btsim
:::

Työtilassa näet kaksi pientä yritysverkkoa: **Firma A**, jossa ovat Anna (`192.168.0.10`) ja Ben (`192.168.0.11`), sekä **Firma B**, jossa ovat Clara (`172.16.0.10`) ja David (`172.16.0.11`). Molemmat kytkimet on jopa yhdistetty suoraan toisiinsa kaapelilla.

## Ping omassa verkossa

1. Siirry :fa-play: **Suorita**-tilaan (Suoritustila), avaa **Annan** :fa-terminal: **Pääte** ja pingaa Beniä:
   ```
   $ ping 192.168.0.11
   ```
2. Siirry :fa-magnifying-glass: **Jäljitys**-tilaan, avaa **Annan** jäljitys (trace) ja klikkaa riviä `Echo (ping) request`.
3. Avaa protokollapuussa rivi **Internet Protocol Version 4**. Tämä on paketin IP-osa — se osa, josta tässä luvussa on kyse.

:::quiz match
Source Address -> Lähettäjän IP-osoite
Destination Address -> Vastaanottajan IP-osoite
Time to Live -> Kuinka monen reitittimen kautta paketti saa vielä kulkea
Protocol -> Mikä protokolla paketin sisällä on (tässä ICMP eli ping)
:::

Tarkista yhdistelyt
:::

## Ping toiseen verkkoon

Siirry takaisin :fa-play: **Suorita**-tilaan ja pingaa **Annalta** Claraa (`ping 172.16.0.10`). Katso sen jälkeen Annan jäljitystä uudelleen.

## Mitä taustalla on

IP-osoite toimii samaan tapaan kuin postiosoite: yksi osa kertoo, missä **verkossa** laite on (kuten katu), toinen osa kertoo, mikä **laite** kyseisessä verkossa on kyseessä (kuten talon numero). Anna on verkossa `192.168.0…`, Clara verkossa `172.16.0…` — kaksi eri "katua".

Oman verkon laitteille tietokone lähettää paketit suoraan (ARPin ja kytkimen kautta, kuten jo tiedät). Vieraaseen verkkoon se tarvitsee laitteen, joka yhdistää verkot toisiinsa ja välittää paketteja eteenpäin: **reitittimen**. Sellaista ei vielä ole — siksi kytkinten välinen kaapelikaan ei auta.

:::tip Muista
**Internet Protocol** (**IP**) kerroksessa 3 huolehtii siitä, että paketit pääsevät perille myös eri verkkojen välillä. **IP-osoite** koostuu **verkko-osasta** (missä verkossa?) ja **isäntäosasta** (mikä laite?). Samassa verkossa olevat laitteet tavoittavat toisensa suoraan — muihin verkkoihin tarvitaan **reititin**.
:::

Tästä syntyy kaksi kysymystä, joita seuraavat osiot käsittelevät: mistä tietokone tietää, *missä kohtaa* osoitetta verkko-osa päättyy? Ja miten reititin toimii?

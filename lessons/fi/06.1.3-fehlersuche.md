# Vianmääritys: yhteystietosivu puuttuu

:::sim
url=/sims/lesson-6.1.3.btsim
:::

Sihteeristö ilmoittaa: ”Verkkosivustomme **Kontakt**-linkki johtaa enää vain virheilmoitukseen.” Yhteystietosivun pitäisi olla saatavilla osoitteessa `http://192.168.0.20/kontakt.html`. Etsi vika ja korjaa se.

<details>
<summary>Vihje 1: Mitä palvelin ilmoittaa?</summary>

Avaa yhteystietosivu selaimessa tai komennolla `curl -v`. Mikä tilakoodi palautuu? Virhesivu paljastaa myös, mistä palvelin etsi tiedostoa.
</details>

<details>
<summary>Vihje 2: Missä tiedostot ovat?</summary>

Verkkopalvelin tarjoaa vain tiedostoja **asiakirjakansiostaan** (*Document Root*) – se näkyy **HTTP-palvelin**-sovelluksessa. Katso **Server**-laitteen **Pääte**-ikkunassa komennolla `ls`, mitä siellä on, ja etsi yhteystietosivua myös hakemistosta `/home`.
</details>

<details>
<summary>Vihje 3: Tiedoston siirtäminen</summary>

Komennolla `mv` siirrät tiedoston: `mv <lähde> <kohdekansio>`.
</details>

:::task
title: Onko yhteystietosivu korjattu?
Tarkistaa, onko yhteystietosivu verkkopalvelimen asiakirjakansiossa.
check: fileExists(2, "/var/www/kontakt.html")
:::

## Mitä tapahtui?

:::quiz multi
Mitkä väitteet pitävät paikkansa?
- [x] Palvelin vastasi `404 Not Found`
- [x] Tiedosto oli hakemistossa `/home` eikä asiakirjakansiossa `/var/www`
- [ ] Verkkopalvelinta ei ollut käynnistetty lainkaan
- [ ] Selain käytti väärää IP-osoitetta
:::

:::evaluate
Tarkista vastaus
:::

:::tip Muista
**404** tarkoittaa: verkkopalvelin on käynnissä ja tavoitettavissa, mutta pyydettyä **tiedostoa** ei ole kyseisessä polussa. Palvelin etsii vain **asiakirjakansiostaan** (*Document Root*, tässä `/var/www`). Vertaa: jos palvelin ei vastaa lainkaan tai vastaa `RST`-paketilla, ongelma on syvemmällä – verkossa tai itse palvelussa (luku 5.3.2).
:::

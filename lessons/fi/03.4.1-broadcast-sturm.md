# Broadcast-myrsky

:::sim
url=/sims/lesson-3.4.1.btsim
:::

Kolme kytkintä (A, B, C) on yhdistetty renkaaksi. Kytkimeen A on liitetty **Anna** (`192.168.0.10`) ja kytkimeen B **Ben** (`192.168.0.11`).

## Koe

1. Siirry :fa-play: **Suorita**-tilaan (Suoritustila), avaa **Annan** :fa-terminal: **Pääte** ja pingaa Beniä:
   ```
   $ ping 192.168.0.11
   ```
2. Sulje Annan ikkuna ja tarkkaile työtilaa hetken: paketit kiertävät renkaassa taukoamatta.
3. Siirry :fa-magnifying-glass: **Jäljitys**-tilaan ja avaa **+**-painikkeella jäljitys **Benille**, liitäntään `eth0`. Oikeassa yläkulmassa näet, kuinka monta pakettia on jo tallennettu.
4. Vaihda muutaman kerran edestakaisin tilojen **Suorita** ja **Jäljitys** välillä ja pidä silmällä lukumäärää.

:::quiz mc
Mitä näet Benin pakettiluettelossa?
- [ ] Annan pingit ja Benin vastaukset, kuten tavallisesti
- [x] Yhä uudelleen sama ARP-kysely "Who has 192.168.0.11?" — ja pakettien määrä kasvaa jatkuvasti
- [ ] Ei mitään, rengas estää kaiken
:::

:::quiz mc
Entä mitä Annan pääte ilmoittaa?
- [ ] Kaikki pingit menevät perille
- [x] Yksikään ping ei mene perille
:::

:::evaluate
Tarkista vastaukset
:::

## Mitä taustalla tapahtuu

Annan ARP-kysely on yleislähetys (broadcast). Kytkin A lähettää sen kaikkiin portteihinsa — siis kytkimelle B *ja* kytkimelle C. Molemmat välittävät sen taas eteenpäin kaikkiin portteihinsa, siis myös toiselle kytkimelle ja takaisin A:lle. A välittää sen jälleen eteenpäin … Yleislähetys kiertää renkaassa loputtomasti, ja jokaisen uuden kyselyn myötä kopioita tulee lisää.

Koska samat kehykset saapuvat kytkimille jatkuvasti eri suunnista, myös niiden osoitetaulukot menevät sekaisin: välillä Anna on tässä portissa, välillä toisessa. Siksi edes pingit eivät enää mene perille.

:::tip Muista
Jos kytkinten välillä on **silmukka**, yleislähetykset kiertävät verkossa loputtomasti ja lisääntyvät — syntyy **broadcast-myrsky**. Se lamauttaa verkon. Toisin kuin IP-paketeilla, Ethernet-kehyksillä ei ole "viimeistä käyttöpäivää", joka lopulta pysäyttäisi ne.
:::

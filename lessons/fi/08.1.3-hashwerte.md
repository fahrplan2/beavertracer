# Tiivisteet: datan sormenjälki

:::sim
url=/sims/lesson-8.1.3.btsim
:::

**Tiivistefunktio** laskee mielivaltaisen määrän dataa — yhdestä lauseesta, asiakirjasta tai kokonaisesta elokuvasta — lyhyen, kiinteän mittaisen merkkijonon: **tiivisteen**. Se toimii kuin **sormenjälki**: samasta datasta syntyy aina sama tiiviste, eri datasta eri tiiviste.

Nykyisin yleisesti käytetty tiivistefunktio on nimeltään **SHA-256**. Sen tiiviste on aina 256 bitin pituinen eli heksadesimaalilukuna 64 merkkiä.

## Koe

**PC**:n kansiossa `/home` on kolme tiedostoa, joissa on pieni kauppasopimus. Siirry :fa-play: **Suorita**-tilaan, avaa **PC**:llä :fa-terminal: **Pääte** ja kirjoita:

```
$ cd /home
$ cat vertrag.txt vertrag-kopie.txt vertrag-neu.txt
$ sha256sum vertrag.txt vertrag-kopie.txt vertrag-neu.txt
```

## Tiivistefunktion ominaisuudet

| Ominaisuus | Merkitys |
|---|---|
| **kiinteä pituus** | Datan koosta riippumatta tiivisteen pituus on aina sama. |
| **yksiselitteinen** | Sama data tuottaa aina saman tiivisteen. |
| **lumivyöryilmiö** | Pienikin muutos tuottaa täysin erilaisen tiivisteen. |
| **yksisuuntainen funktio** | Tiivisteestä dataa **ei** voi laskea takaisin. |
| **törmäyksenkestävä** | Käytännössä on mahdotonta löytää kaksi eri tiedostoa, joilla on sama tiiviste. |

Tiivistefunktio **ei ole salaus**: siinä ei ole avainta eikä salauksen purkua. Sillä on eri tarkoitus — **eheys**.

## Mihin tätä tarvitaan?

- **Latausten tarkistaminen:** Monet verkkosivut ilmoittavat tiedoston vieressä sen SHA-256-arvon. Jos lataamasi tiedoston tiiviste vastaa sitä, tiedostoa ei ole muutettu matkan aikana.
- **Salasanojen tallentaminen:** Hyvät verkkosivut eivät tallenna salasanaasi, vaan ainoastaan sen tiivisteen. Kirjautuessa verrataan syöttämäsi salasanan tiivistettä. Jos tietokanta varastetaan, varas ei silti tiedä salasanoja.
- **Digitaaliset allekirjoitukset:** Koko asiakirjan sijaan allekirjoitetaan vain sen tiiviste — lisää tästä seuraavassa osiossa.

:::tip Muista
**Tiivistefunktio** (esim. **SHA-256**) laskee mielivaltaisesta datasta kiinteän mittaisen **tiivisteen** — **sormenjäljen**. Pienikin muutos tuottaa täysin erilaisen tiivisteen, eikä tiivisteestä voi laskea dataa takaisin. Tiivisteet turvaavat datan **eheyden**.
:::

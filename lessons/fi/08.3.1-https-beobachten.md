# HTTP ja HTTPS vertailussa

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Verkkopalvelin **www.beaver-schule.de** tarjoaa koulun arvosanaportaalin sekä HTTP:n että HTTPS:n kautta. Mitä salakuuntelija näkee?

## Koe

1. Siirry :fa-play: **Suorita**-tilaan ja avaa **Client-PC**:n :fa-globe: **Selain**-sovelluksessa ensin `http://www.beaver-schule.de/` ja sen jälkeen `https://www.beaver-schule.de/`.
2. Avaa :fa-magnifying-glass: **Jäljitys**-tilassa **Client-PC**:n jäljitys.
3. Etsi ensin paketti `HTTP/1.1 200 OK` ja napsauta sitä. Alhaalla tiedoissa näet sivun sisällön.

:::quiz mc
Mitä salakuuntelija voi nähdä **HTTP**:n yhteydessä?
- [x] Koko verkkosivun, myös Annan arvosanat
- [ ] Vain palvelimen osoitteen
- [ ] Ei mitään, koska HTTP toimii TCP:n päällä
:::

:::quiz short
Mikä arvosana Annalla on matematiikassa?
= 2
:::

:::evaluate
Tarkista vastaukset
:::

Nyt HTTPS-osuus. Etsi `[SYN]`-paketti, jolla asiakas aloittaa toisen yhteyden.

:::quiz short
Mikä on HTTPS-yhteyden kohdeportti (sarake **Info**, `… → ???`)?
= 443
:::

Kirjoita nyt jäljityksen yläreunan suodatuskenttään `tls`. Silloin näet enää vain TLS-paketit.

:::quiz mc
Mitä sarakkeessa **Info** lukee niiden pakettien kohdalla, jotka sisältävät verkkosivun?
- [ ] `HTTP/1.1 200 OK`
- [x] `Application Data`
- [ ] `Encrypted HTML`
:::

:::quiz multi
Mitä salakuuntelija voi **HTTPS**:n yhteydessä silti nähdä?
- [x] Asiakkaan ja palvelimen IP-osoitteet
- [x] Että käytössä on portti 443, eli todennäköisesti HTTPS
- [x] Kuinka paljon dataa suunnilleen siirretään
- [ ] Mitä sivua pyydettiin ja mitä siinä lukee
:::

:::evaluate
Tarkista vastaukset
:::

:::note
Napsauta **Application Data** -pakettia: hyötykuorma on vain jono näennäisen satunnaisia tavuja. Jäljittäjä ei pysty purkamaan salausta, sillä se ei tunne istuntoavainta sen paremmin kuin hyökkääjäkään.
:::

:::tip Muista
**HTTP**:ssä jokainen salakuuntelija voi lukea koko verkkosivun. **HTTPS**:ssä hän näkee enää vain, **kuka puhuu kenelle** (IP-osoitteet, portti 443) ja **kuinka paljon**. Sisältö on salattuna **Application Data** -paketeissa.
:::

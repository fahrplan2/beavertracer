# Verkkosivun avaaminen ja tarkkailu

Tässä osassa et rakenna mitään itse: työtilassa on valmis simulaatio, jossa on **Client-PC** ja **Webserver**.

## Sivun avaaminen

1. Siirry :fa-play: **Suorita**-tilaan.
2. Avaa **Client-PC**:llä :fa-globe: **Selain**-sovellus ja avaa verkkopalvelimen osoite: `http://192.168.0.20/`.
3. Siirry :fa-magnifying-glass: **Jäljitys**-tilaan ja avaa **+**-painikkeella jäljitys **Client-PC**:lle, liitäntä `eth0` — aivan kuten ping-komennon kanssa.

:::note
Yhdelle sivunlataukselle pakettien määrä on yllättävän suuri — selvästi suurempi kuin pingissä. Verkkosivun noutaminen on monivaiheinen tapahtuma, ei yksittäinen toiminto.
:::

## Pakettiluettelon lukeminen

Sinun ei vielä tarvitse tietää, mitä kukin protokolla tarkalleen tekee. Kaikki, mitä seuraaviin kysymyksiin tarvitset, löytyy sarakkeista **Protokolla** ja **Info**.

:::quiz mc
Mikä protokolla on luettelon ylimpänä?
- [x] ARP
- [ ] TCP
- [ ] HTTP
:::

:::quiz short
Laske: kuinka monta **TCP**-pakettia on ennen ensimmäistä **HTTP**-pakettia?
= 3
= kolme
:::

:::quiz mc
Mitä verkkopalvelin vastaa selaimen pyyntöön? Katso toisen HTTP-paketin Info-saraketta.
- [ ] GET / HTTP/1.1
- [x] HTTP/1.1 200 OK
- [ ] 404 Not Found
:::

:::evaluate
Tarkista vastaukset
:::

## Mukana olevien protokollien nimeäminen

Havaintojesi perusteella voit nyt päätellä, mikä protokolla vastasi mistäkin.

:::tip Vinkki
Lue **Info**-sarakkeet vielä kerran läpi: `Who has …?`, `[SYN]`, `[SYN, ACK]`, `[ACK]`, `GET /` ja `200 OK` paljastavat jo lähes kaiken.
:::

:::quiz match
ARP -> Kysyy kaikilta verkossa: ”Kenellä on IP-osoite 192.168.0.20?”
TCP -> Muodostaa yhteyden kolmella lyhyellä paketilla ennen kuin data kulkee
HTTP -> Pyytää verkkosivun (GET) ja palauttaa sen (200 OK)
:::

:::evaluate
Tarkista yhdistelmät
:::

:::tip Muista
Verkkosivun avaaminen etenee vaiheittain: ensin palvelin **löydetään** verkosta (ARP), sitten **muodostetaan** yhteys (TCP), sitten sivu **pyydetään ja toimitetaan** (HTTP) — ja lopuksi yhteys **puretaan** (luettelon lopussa olevat TCP-paketit, joissa on `[FIN]`).
:::

:::note
Syötit tällä kertaa palvelimen IP-osoitteen suoraan, joten **DNS** (nimien, kuten `www.beispiel.de`, "kääntäminen" IP-osoitteeksi) ei vielä ollut käytössä. Palaamme siihen luvussa 6.
:::

Huomasitko, että paketin rakenteessa protokollilla on värillisiä merkintöjä, joissa on numeroita? Mistä niissä on kyse, selviää luvussa 2. Siellä tarkastelemme, miten monet protokollat voidaan luokitella järjestelmällisesti — OSI- ja TCP/IP-viitemallin avulla. Sillä luku 1 on suoritettu.

## Koe

1. Siirry :fa-play: **Suorita**-tilaan, klikkaa **Client-PC**:tä ja avaa :fa-globe: **Selain**. Avaa osoite `http://192.168.0.20/`.
2. Klikkaa ikkunan yläreunasta **Takaisin**, avaa **Yksinkertainen TCP-asiakas** ja yhdistä se osoitteeseen `192.168.0.20`, porttiin `5000`. Jätä yhteys auki.
3. Siirry :fa-magnifying-glass: **Jäljitys**-tilaan, avaa jäljitys **Client-PC**:lle ja klikkaa pakettia, jossa on `[SYN]`. Avaa **Transmission Control Protocol**.

TCP-otsikon alussa on kaksi porttia: **Source Port** (lähdeportti) ja **Destination Port** (kohdeportti).

:::quiz table
| Yhteys | Lähdeportti | Kohdeportti |
|---|---|---|
| Selain → Web-palvelin | {49152} | {80} |
| TCP-asiakas → Kaiupalvelu | {49153} | {5000} |
:::

## Kaksi porttityyppiä

**Kohdeportti – palvelu:** Palvelinohjelma odottaa yhteyksiä kiinteässä portissa – sanotaan, että se **kuuntelee** siellä. Tunnettujen palvelujen numerot on määritelty maailmanlaajuisesti, ne ovat **well-known-portteja** (0–1023). Siksi selain tietää kysymättä: web-palvelimet kuuntelevat porttia 80.

**Lähdeportti – lähettäjä:** Asiakaspuolen portin valitsee käyttöjärjestelmä itse jokaiselle uudelle yhteydelle korkeasta numeroalueesta (BeaverTracerissa alkaen 49152). Sen perusteella asiakas tunnistaa, mihin sen yhteyksistä vastaus kuuluu.

Yhteys määräytyy siis yksiselitteisesti neljästä tiedosta: **IP-osoite ja portti kummallakin puolella**. IP-osoitteen ja portin paria kutsutaan **socketiksi**, esim. `192.168.0.20:80`.

## Katsaus palvelimeen

Siirry takaisin :fa-play: **Suorita**-tilaan, avaa **Server**-koneella :fa-terminal: **Pääte** ja kirjoita:

```
$ ss
```

`ss` näyttää koneen kaikki socketit. Rivit, joilla on `LISTEN`, ovat ohjelmia, jotka kuuntelevat porttia. Rivit, joilla on `ESTABLISHED`, ovat muodostettuja yhteyksiä – niissä näkyvät oma socket (*Local Address:Port*) ja vastapuolen socket (*Peer Address:Port*).

:::quiz multi
Mitä portteja palvelin kuuntelee?
- [x] 80
- [x] 5000
- [ ] 49152
- [ ] 443
:::

:::quiz mc
Minkä yhteyden `ss` näyttää tilassa `ESTABLISHED`?
- [x] `192.168.0.20:5000` ja `192.168.0.10:49153` – TCP-asiakkaan avoin yhteys
- [ ] `192.168.0.20:80` ja `192.168.0.10:49152` – selaimen yhteys
- [ ] Molemmat
:::

:::note
Selaimen yhteys on jo purettu – sivun latauksen jälkeen se päätettiin `FIN`-paketilla. `ss` näyttää sen vielä hetken tilassa `TIME-WAIT`: palvelin odottaa jonkin aikaa, saapuuko tämän yhteyden myöhästyneitä paketteja. TCP-asiakkaan yhteys sen sijaan on yhä auki, koska et ole vielä klikannut **Katkaise yhteys**.

## Tärkeimmät well-known-portit

| Portti | Protokolla | Palvelu |
|---|---|---|
| 22 | SSH | turvallinen etähallinta (salattu komentorivi) |
| 25 | SMTP | sähköpostien lähettäminen |
| 53 | DNS | nimien muuntaminen IP-osoitteiksi (yleensä UDP:n yli) |
| 80 | HTTP | verkkosivut |
| 110 | POP3 | sähköpostien nouto |
| 143 | IMAP | sähköpostien hallinta palvelimella |
| 443 | HTTPS | salatut verkkosivut |

:::tip Muista
**Portit** (0–65535) erottavat koneen yhteydet toisistaan. Palvelinpalvelut **kuuntelevat** kiinteitä **well-known-portteja** (esim. HTTP 80, HTTPS 443), asiakkaat saavat jokaiselle yhteydelle vapaan korkean **lähdeportin**. Yhteys määräytyy yksiselitteisesti **molempien osapuolten IP-osoitteesta ja portista**.
:::

:::quiz match
22 -> SSH
25 -> SMTP
53 -> DNS
80 -> HTTP
110 -> POP3
143 -> IMAP
443 -> HTTPS
:::

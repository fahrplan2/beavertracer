# NAT: monta laitetta, yksi osoite

:::goal
**Oppimistavoite:** Osaat näyttää Tracerissa, miten NAT vaihtaa lähettäjän osoitteen, lukea NAT-taulukkoa ja selittää, miksi yhteydet ulkopuolelta kotiverkkoon tarvitsevat porttiohjauksen.
:::

:::sim
url=/sims/lesson-7.1.btsim
:::

Internetoperaattori antaa kotiliittymälle yleensä vain **yhden** julkisen IPv4-osoitteen — kotireititimen WAN-osoitteen. Kaikkien kotiverkon laitteiden täytyy jakaa se keskenään. Tätä toimintatapaa kutsutaan nimellä **NAT** (*Network Address Translation*, osoitteenmuunnos).

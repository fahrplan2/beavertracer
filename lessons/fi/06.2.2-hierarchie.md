# Miten DNS on organisoitu

:::sim
url=/sims/lesson-6.2.btsim
:::

Mikään yksittäinen palvelin ei voi tuntea kaikkia maailman nimiä. Siksi DNS on rakennettu **hierarkkisesti** — aivan kuten nimet itsekin. Ne luetaan oikealta vasemmalle:

```
www . beaver-schule . de . (Root)
 │          │         │      └─ Root-Server: kennen die Server aller Top-Level-Domains
 │          │         └─ Top-Level-Domain (TLD): der de-Server kennt alle .de-Domains
 │          └─ Domain: der Schul-DNS ist für beaver-schule.de zuständig
 └─ Rechnername innerhalb der Domain
```

Palvelinta, joka vastaa jostakin verkkotunnuksesta ja todella tuntee vastauksen, kutsutaan **auktoritatiiviseksi**. Tien sinne kulkee tietokoneen puolesta **resolveri** — tässä tietokone **DNS-Resolver**.

## Koe

1. Siirry :fa-play: **Suorita**-tilaan (Suoritustila) ja kirjoita **Client-PC**:n :fa-terminal: **Pääte**-sovelluksessa:
   ```
   $ nslookup www.beaver-schule.de
   ```
2. Avaa :fa-magnifying-glass: **Jäljitys**-tilassa jäljitys **DNS-Resolver**-tietokoneelle.

Resolveri on tehnyt puolestasi kokonaisen joukon kyselyitä. Yhdistä, kuka antoi minkä vastauksen:

:::quiz match
Root-Server (192.168.0.101) -> Ohjaus: .de:stä vastaa ns.nic.de
de-Server (192.168.0.102) -> Ohjaus: beaver-schule.de:stä vastaa ns.beaver-schule.de
Schul-DNS (192.168.0.103) -> Vastaus: www.beaver-schule.de:n osoite on 192.168.0.20
:::

:::quiz mc
Ketä resolveri kysyy ensimmäisenä?
- [x] Root-palvelinta
- [ ] Koulun DNS-palvelinta
- [ ] Asiakas-PC:tä
:::

:::evaluate
Tarkista vastaukset
:::

:::note
Välillä resolveri kysyy myös niiden palvelinten osoitteita, joihin se ohjattiin (`A ns.nic.de`). Oikeat DNS-palvelimet lähettävät nämä osoitteet yleensä heti mukana. Lisäksi resolverit muistavat jokaisen vastauksen jonkin aikaa (**välimuisti**) — seuraavaan samaa nimeä koskevaan kyselyyn ne vastaavat heti itse. Kuinka kauan, näkyy merkinnässä **TTL**-arvona (*Time to Live*) sekunteina.
:::

## Tärkeimmät tietuetyypit

| Tyyppi | Merkitys | Esimerkki |
|---|---|---|
| **A** | nimi → IPv4-osoite | `www.beaver-schule.de` → `192.168.0.20` |
| **AAAA** | nimi → IPv6-osoite | `www.beaver-schule.de` → `2001:db8::20` |
| **CNAME** | nimi → toinen nimi (alias) | `web.beaver-schule.de` → `www.beaver-schule.de` |
| **MX** | verkkotunnuksesta vastaava postipalvelin | `beaver-schule.de` → `mail.beaver-schule.de` |
| **NS** | verkkotunnuksesta vastaava DNS-palvelin | `beaver-schule.de` → `ns.beaver-schule.de` |

:::tip Muista
DNS on **hierarkkinen**: **Root-palvelimet** ohjaavat **ylätason verkkotunnusten** (esim. `.de`) palvelimille, nämä taas yksittäisten **verkkotunnusten** palvelimille. Vastaava **auktoritatiivinen** palvelin tuntee vastauksen. **Resolveri** kulkee tämän tien tietokoneen puolesta ja muistaa vastaukset (**välimuisti**). Tärkeät tietuetyypit: **A**, **AAAA**, **CNAME**, **MX**, **NS**.
:::

## Tietueen luominen

Koulu haluaa, että sen verkkosivusto on tavoitettavissa myös osoitteessa `intranet.beaver-schule.de`.

1. Napsauta :fa-play: **Suorita**-tilassa **Schul-DNS**-tietokonetta ja avaa sovellus **DNS-Server**.
2. Avaa välilehti **A**. Napsauta **+** ja kirjoita uudelle riville nimi `intranet.beaver-schule.de` ja osoite `192.168.0.20`.
3. Testaa Client-PC:llä komennolla `nslookup intranet.beaver-schule.de`.

# Mallien soveltaminen

Yhdistä luvun alun kokeilussa esiintyneet protokollat niiden OSI-kerrokseen:

:::quiz match
Ethernet -> Kerros 2 — siirtokerros
IPv4 -> Kerros 3 — verkkokerros
TCP -> Kerros 4 — kuljetuskerros
HTTP -> Kerros 7 — sovelluskerros
:::

:::evaluate
Tarkista yhdistelmät
:::

Ja lopuksi tietoyksiköiden nimet:

:::quiz match
Kehys -> Kerros 2 — siirtokerros
Paketti -> Kerros 3 — verkkokerros
Segmentti -> Kerros 4 — kuljetuskerros
:::

:::evaluate
Tarkista yhdistelmät
:::

Nyt sinulla on työkalut, joilla voit jatkossa luokitella protokollat oikein. Seuraavasta luvusta alkaen käymme kerrokset läpi yksi kerrallaan — aloitamme kerroksesta 2 ja kysymyksestä, mistä kytkin oikeastaan tietää, minne sen pitää välittää paketti.

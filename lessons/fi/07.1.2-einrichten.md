# Kotireitittimen määrittäminen

:::sim
url=/sims/lesson-7.1.2.btsim
:::

Uusi kotireititin on juuri kytketty — mutta kukaan ei vielä pääse internetiin. Palveluntarjoajalta olet saanut kirjeen, jossa on **liittymätiedot**:

| Liittymätiedot | Arvo |
|---|---|
| WAN-IP-osoite | `203.0.113.2` |
| Etuliitteen pituus | `/30` |
| Yhdyskäytävä (palveluntarjoajan reititin) | `203.0.113.1` |
| Palveluntarjoajan DNS-palvelin | `198.51.100.10` |

1. Siirry :fa-play: **Suorita**-tilaan, napsauta **Heimrouter**-laitetta ja avaa **WAN**-välilehti.
2. Syötä liittymätiedot ja napsauta **Käytä**.
3. Yhdistä **Tablet** WLAN-verkkoon: :fa-gear: **IP-asetukset**, **WiFi**-välilehti, SSID `Biberbau`, **Käytä**.
4. Testaa PC:llä komennolla `ping 192.0.2.80` tai selaimessa osoitteella `http://www.beispiel.de/`.

:::note
Käytännössä kotireititin saa WAN-osoitteensa yleensä automaattisesti palveluntarjoajalta (DHCP:n avulla tai kirjautumalla käyttäjätunnuksella ja salasanalla). Kiinteät liittymätiedot, kuten tässä, ovat tavallisempia yritysliittymissä.
:::

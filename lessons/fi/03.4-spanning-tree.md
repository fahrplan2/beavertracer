# Silmukat verkossa ja Spanning Tree

:::goal
**Oppimistavoite:** Osaat selittää, miten silmukallisessa verkossa syntyy yleislähetysmyrsky (broadcast storm) ja miten Spanning Tree Protocol (STP) estää silmukat luopumatta vikasietoisuudesta.
:::

:::

Mitä tapahtuu, kun verkossa kaapeli menee rikki? Jos kaikki riippuu yhdestä ainoasta johdosta, osa verkosta katkeaa muusta verkosta. Siksi suuremmissa verkoissa kytkimet yhdistetään usein **useammalla kuin yhdellä yhteydellä** — kuten työtilan kolme kytkintä, jotka muodostavat renkaan. Jos yksi kaapeli lakkaa toimimasta, käytettävissä on kiertotie.

Kuulostaa hyvältä — mutta tällaisessa renkaassa on vaarallinen koukku. Tutustut siihen seuraavalla sivulla.

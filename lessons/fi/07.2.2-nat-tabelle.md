# NAT-taulukko

:::sim
url=/sims/lesson-7.1.btsim
:::

Kun PC ja tabletti lataavat samanaikaisesti saman verkkosivun, molemmat pyynnöt saapuvat verkkopalvelimelle osoitteesta `203.0.113.2`. Mistä kotireititin tietää, kenelle vastaus on tarkoitettu? Se pitää kirjaa — **NAT-taulukossa**.

## Kokeilu

1. Siirry :fa-play: **Suorita**-tilaan (Suoritustila) ja avaa **PC**:llä ja **Tabletilla** kummallakin osoite `http://www.beispiel.de/`.
2. Napsauta **Heimrouteria** ja avaa **NAT**-välilehti.

Jokainen rivi on yksi **vastaavuus**: protokolla, kotiverkon laitteen LAN-IP ja LAN-portti — sekä **WAN-portti**, jota reititin käyttää sitä varten julkisessa osoitteessaan.

:::quiz short
Mikä WAN-IP näkyy taulukon yläpuolella?
= 203.0.113.2
:::

:::quiz mc
PC ja tabletti ovat molemmat muodostaneet yhteyden LAN-portilla `49152`. Minkä WAN-portin ne saavat?
- [ ] Molemmat saavat saman, `49152`
- [x] Kumpikin eri portin — muuten reititin ei tietäisi, kenelle vastaus kuuluu
- [ ] Ei lainkaan, NAT muuttaa vain IP-osoitetta
:::

:::quiz mc
Verkkopalvelimen vastaus saapuu osoitteeseen `203.0.113.2` tietyllä **kohdeportilla**. Mitä kotireititin tekee sille?
- [x] Se etsii portin NAT-taulukosta ja lähettää paketin vastaavaan LAN-IP-osoitteeseen ja LAN-porttiin
- [ ] Se lähettää paketin kaikille kotiverkon laitteille
- [ ] Se hylkää paketin
:::

:::evaluate
Tarkista vastaukset
:::

Tässä kohtaa luvun 5 **portit** tulevat taas mukaan kuvaan: koska NAT kirjoittaa myös portit uudelleen, sadat yhteydet voivat jakaa yhden osoitteen. Tarkkaan ottaen tätä kutsutaan siksi **PAT:ksi** (*Port Address Translation*) eli *NAT:ksi porttimuunnoksella* — arjessa puhutaan silti yleensä vain NAT:sta.

Tällainen muunnos voisi näyttää esimerkiksi tältä:

| | Paketti PC:ltä (kotiverkossa) | sama paketti internetissä |
|---|---|---|
| Lähettäjä | `192.168.178.20 : 49152` | `203.0.113.2 : 10001` |
| Vastaanottaja | `192.0.2.80 : 80` | `192.0.2.80 : 80` |

:::tip Muista
**NAT-taulukossa** reititin muistaa jokaisen yhteyden kohdalla, mikä laite (**LAN-IP ja LAN-portti**) on minkä **WAN-portin** takana. Internetistä tulevat vastaukset se yhdistää kohdeportin avulla takaisin oikealle laitteelle. Koska myös portit kirjoitetaan uudelleen, tarkemmin puhutaan **PAT:sta**.
:::

# HTTP käsin

:::sim

Jos HTTP on pelkkää tekstiä — voiko webpalvelimen kanssa silloin keskustella myös itse, ilman selainta? Voi: `telnet`-komennolla muodostat TCP-yhteyden mihin tahansa porttiin ja kirjoitat tekstin itse.

## Kokeilu

1. Siirry :fa-play: **Suorita**-tilaan eli Suoritustilaan ja avaa **Client-PC**:llä :fa-terminal: **Pääte**.
2. Muodosta yhteys palvelimen porttiin 80:
   ```
   $ telnet 192.168.0.20 80
   ```
3. Kirjoita pyyntö rivi riviltä — ja päätä se **tyhjään riviin** (paina vielä kerran **Enter**):
   ```
   GET /kontakt.html HTTP/1.1
   Host: 192.168.0.20

   ```

Palvelin vastaa tilarivillä, otsakkeilla ja yhteystietosivulla — tekstinä, aivan samoin kuin selain ne saa.

## Virheiden aiheuttaminen

Kätevämpi työkalu on `curl`: se tekee pyynnön puolestasi. Valitsimella `-v` (*verbose*, yksityiskohtainen) se näyttää kaiken, mitä välillä kulkee — `>`-merkillä alkavat rivit `curl` on lähettänyt ja `<`-merkillä alkavat rivit tulivat palvelimelta.

Kokeile:

```
$ curl -v http://192.168.0.20/gibtsnicht.html
$ curl -X POST -d name=Anna http://192.168.0.20/
```

:::note
BeaverTracerin webpalvelin osaa vain toimittaa tiedostoja — siksi se sallii vain `GET`- ja `HEAD`-menetelmät. Oikeat webpalvelimet ottavat `POST`-menetelmällä vastaan esimerkiksi lomakkeita ja välittävät tiedot edelleen ohjelmalle.
:::

:::tip Muista
Monet sovelluskerroksen protokollat ovat **tekstipohjaisia** — HTTP, mutta myös SMTP, POP3 ja IMAP. Siksi niitä voi käyttää käsin `telnet`-komennolla ja seurata Jäljittäjässä. Se on käytännöllistä vianmäärityksessä — mutta myös tietoturvaongelma: jokainen, joka tallentaa liikennettä, voi lukea kaiken. Kuinka salaus (HTTPS) auttaa, opit luvussa 8.
:::

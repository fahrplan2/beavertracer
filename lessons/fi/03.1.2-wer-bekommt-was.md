# Kuka saa minkä paketin?

:::sim
url=/sims/lesson-3.1.2.btsim
:::

Nyt Anna, Ben ja Clara on yhdistetty kytkimeen (portit 1, 2 ja 3). Kun Anna lähettää paketin Benille: saako sen vain Ben — vai myös Clara?

Mieti hetki, mitä arvelet. Kokeile sitten itse.

## Koe

1. Siirry :fa-play: **Suorita**-tilaan (Suoritustila), avaa koneella **Anna** :fa-terminal: **Pääte** ja pingaa Beniä:
   ```
   $ ping 192.168.0.11
   ```
2. Siirry :fa-magnifying-glass: **Jäljitys**-tilaan ja avaa **+**-painikkeella jäljitys koneelle **Clara**, portti `eth0`.
3. Avaa **+**-painikkeella toinen jäljitys koneelle **Ben**, portti `eth0`. Ylhäältä voit vaihtaa edestakaisin näiden kahden jäljityksen välillä.

:::quiz short
Kuinka monta pakettia saapui koneelle **Clara**?
= 1
= yksi
:::

:::

## Mitä taustalla tapahtuu

ARP-kyselyn kohteena on **yleislähetys** (broadcast) — se on osoitettu *kaikille*. Siksi kytkin välitti sen jokaiseen porttiin, myös Claralle. Pingit sen sijaan oli osoitettu vain Benille. Kytkin lähetti ne ainoastaan Benin porttiin — Clara ei huomannut niistä mitään.

:::tip Muista
**Yleislähetys** (broadcast) on osoitettu kaikille paikallisen verkon laitteille — kytkin jakaa sen kaikkiin portteihin. **Yksilähetys** (unicast) on osoitettu täsmälleen yhdelle laitteelle — kytkin lähettää sen vain siihen porttiin, johon kyseinen laite on yhdistetty.
:::

## Katsaus kytkimen sisälle

Mutta mistä kytkin tietää, mihin porttiin Ben on yhdistetty? Siirry takaisin :fa-play: **Suorita**-tilaan ja napsauta **kytkintä** (**Switch**). **SAT**-välilehdellä näet sen osoitetaulukon, jossa on kaksi saraketta: **MAC** ja **Port**.

:::quiz mc
Mitkä laitteet ovat osoitetaulukossa?
- [ ] Anna, Ben ja Clara
- [x] Vain Anna ja Ben
- [ ] Vain Ben
:::

:::quiz short
Mihin porttiin Ben on taulukon mukaan yhdistetty? Vihje: Benin MAC-osoitteen löydät Tracerista hänen ARP-vastauksestaan `192.168.0.11 is at …`.
= 2
= portti 2
:::

:::quiz mc
Miksi Clara puuttuu taulukosta?
- [ ] Hänen kaapelinsa on rikki
- [x] Hän ei ole vielä lähettänyt yhtäkään pakettia
- [ ] Kytkin tallentaa enintään kaksi merkintää
:::

:::evaluate
Tarkista vastaukset
:::

Kytkin **oppii** lisää: jokaisesta sille saapuvasta kehyksestä se katsoo **lähettäjän** MAC-osoitteen ja painaa mieleensä, mihin porttiin kyseinen laite on yhdistetty. Kun Annan ARP-kysely saapui, se kirjasi "Anna → portti 1", ja Benin vastauksen kohdalla "Ben → portti 2". Clara ei ole lähettänyt mitään — joten kytkin ei vielä tunne häntä.

:::tip Muista
Kytkin muistaa **osoitetaulukossaan** (**SAT**, *Source Address Table*), minkä MAC-osoitteen laite on tavoitettavissa missäkin portissa — se oppii tämän lähettäjäosoitteista. Jos se tuntee kehyksen kohteen, se lähettää kehyksen vain siihen porttiin. Jos se ei tunne kohdetta (tai kyseessä on yleislähetys), se lähettää kehyksen kaikkiin portteihin.
:::

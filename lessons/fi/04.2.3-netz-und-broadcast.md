# Verkko-osoite, yleislähetysosoite ja isännät

Jokaisessa verkossa kahdella osoitteella on erityistehtävä:

- **Verkko-osoite** on verkon **pienin** osoite: kaikki isäntäosan bitit ovat 0. Se tarkoittaa verkkoa kokonaisuutena, esim. reititystauluissa.
- **Yleislähetysosoite** on verkon **suurin** osoite: kaikki isäntäosan bitit ovat 1. Mitä tahansa sille lähetetään, menee kaikille verkon laitteille.

Kumpaakaan osoitetta **ei** anneta laitteille. Kaikki niiden väliset osoitteet ovat laitteiden (**isäntien**) käytettävissä.

## Yksinkertainen esimerkki

`192.168.0.12/24` — isäntäosa on viimeinen oktetti:

| | Osoite |
|---|---|
| Verkko-osoite (isäntäosa = 0) | `192.168.0.0` |
| Yleislähetysosoite (isäntäosa = 255) | `192.168.0.255` |
| Isäntien osoitealue | `192.168.0.1` – `192.168.0.254` |
| Isäntien määrä | 254 |

## Kun raja on oktetin keskellä

Vaikeammaksi menee, kun etuliitteen pituus ei ole 8:n monikerta. Silloin muunnat kyseisen oktetin kahdenjärjestelmään. Esimerkki: `194.9.190.12/27`.

Kolme ensimmäistä oktettia kuuluvat kokonaan [[n|verkko-osaan]] (24 bittiä). Viimeisestä oktetista vielä **3 bittiä** kuuluu verkko-osaan (24 + 3 = 27), loput **5 bittiä** [[h|isäntäosaan]]:

| | viimeinen oktetti (binääri) | desimaali |
|---|---|---|
| IP-osoite | [[n|000]][[h|01100]] | 12 |
| Verkkomaski (`/27`) | [[n|111]][[h|00000]] | 224 |
| Verkko-osoite: isäntäbitit nollaksi | [[n|000]][[h|00000]] | **0** |
| Yleislähetysosoite: isäntäbitit ykkösiksi | [[n|000]][[h|11111]] | **31** |

Tulos:

- Verkko-osoite: `194.9.190.0`
- Yleislähetysosoite: `194.9.190.31`
- Isäntien osoitealue: `194.9.190.1` – `194.9.190.30`
- Isäntien määrä: 2⁵ − 2 = **30**

:::tip Muista
**Verkko-osoite:** kaikki isäntäbitit 0 (pienin osoite). **Yleislähetysosoite:** kaikki isäntäbitit 1 (suurin osoite). Kumpaakaan ei anneta laitteille. Verkossa, jonka etuliitteen pituus on *n*, on **2<sup>32 − n</sup> − 2** käytettävissä olevaa osoitetta isännille.
:::

:::tip Vinkki: lohkokoko
Kun olet ymmärtänyt menetelmän kahdenjärjestelmässä, on olemassa oikotie: **256 miinus maskin oktetti** antaa verkon koon kyseisessä oktetissa. Kun kyseessä on `/27` (maski 224), se on 256 − 224 = **32**. Verkot alkavat silloin kohdista 0, 32, 64, 96 … — osoite `.12` on verkossa, joka alkaa kohdasta `.0`, ja osoite `.70` verkossa, joka alkaa kohdasta `.64`.
:::

## Tärkeimmät verkkokoot

| Etuliite | Verkkomaski | Isännät |
|---|---|---|
| `/8` | `255.0.0.0` | 16 777 214 |
| `/16` | `255.255.0.0` | 65 534 |
| `/24` | `255.255.255.0` | 254 |
| `/25` | `255.255.255.128` | 126 |
| `/26` | `255.255.255.192` | 62 |
| `/27` | `255.255.255.224` | 30 |
| `/28` | `255.255.255.240` | 14 |
| `/29` | `255.255.255.248` | 6 |
| `/30` | `255.255.255.252` | 2 |

:::note
Käytännössä pienin yleinen verkko on `/30`: siinä on täsmälleen kaksi käytettävää osoitetta, ja sitä käytetään usein kahden reitittimen väliseen yhteyteen. `/32` tarkoittaa yksittäistä osoitetta — verkkona sitä ei voi käyttää, mutta sitä esiintyy reititystauluissa ja palomuurisäännöissä.
:::

# HTTPS

:::osi 5
:::

**HTTPS** (*HTTP Secure*) on ihan tavallista HTTP:tä — paitsi että se ei kulje suoraan TCP:n yli, vaan välissä on salattu kerros: **TLS** (*Transport Layer Security*). TLS:n edeltäjä oli nimeltään **SSL**; siksi puhutaan yhä usein ”SSL-varmenteista”.

```
ohne Verschlüsselung:   HTTP  →  TCP  →  IP
mit Verschlüsselung:    HTTP  →  TLS  →  TCP  →  IP
```

HTTP ei huomaa tästä mitään: se lähettää pyyntönsä tavalliseen tapaan, TLS salaa ne ja TCP kuljettaa ne. OSI-mallissa TLS sijaitsee kuljetuskerroksen ja sovelluskerroksen välissä, eli kerroksessa 4/5 — se rakentuu TCP:n päälle ja ylläpitää suojattua istuntoa.

| | HTTP | HTTPS |
|---|---|---|
| Portti | 80 | **443** |
| Osoite | `http://…` | `https://…` |
| Sisältö luettavissa jäljittimessä? | kyllä | ei |
| Selain näyttää | ”ei turvallinen” | lukon |

TLS hoitaa yhteyden muodostuksen yhteydessä kaiken, minkä olet oppinut tässä luvussa:

- Palvelin tunnistautuu **varmenteellaan** (**aitous**).
- Molemmat osapuolet sopivat **Diffie-Hellman**-menetelmällä **istuntoavaimesta** — palvelin **allekirjoittaa** oman osuutensa.
- Sen jälkeen kaikki data salataan **AES**:llä (**luottamuksellisuus**) ja suojataan muuttamiselta (**eheys**).

Periaate ei rajoitu web-liikenteeseen: myös sähköposti (kohta 8.4) ja monet muut protokollat kulkevat TLS:n kautta samalla tavalla.

Seuraavissa kohdissa tarkkailet HTTPS:ää jäljittimessä, otat sen itse käyttöön ja tutkit, milloin selain varoittaa — ja miksi.

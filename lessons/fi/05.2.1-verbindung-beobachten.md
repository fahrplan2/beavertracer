# Yhteys alusta loppuun

:::sim
url=/sims/lesson-5.1.btsim
:::

**Server**-laitteella kaiutuspalvelu toimii portissa `5000`: se lähettää jokaisen viestin heti takaisin. **Yksinkertaisella TCP-asiakkaalla** voit ohjata yhteyttä vaihe vaiheelta — jokainen painike on yksi vaihe.

## Koe

1. Siirry :fa-play: **Suoritustilaan**, napsauta **Client-PC**:tä ja avaa **Yksinkertainen TCP-asiakas**.
2. Kirjoita kohtaan **Host** `192.168.0.20` ja kohtaan **Port** `5000`.
3. Napsauta **Yhdistä**.
4. Kirjoita viestikenttään `Hello World` ja napsauta **Lähetä**. Chat-ikkunassa näet heti perään palvelimen kaiun.
5. Napsauta **Katkaise yhteys**.
6. Siirry :fa-magnifying-glass: **Jäljitys**-tilaan ja avaa **+**-painikkeella jäljitys **Client-PC**:lle, liitäntä `eth0`.

:::note
Alun kaksi ARP-pakettia tunnet jo luvusta 1. TCP-pakettien **Info**-sarakkeessa on ensin `49152 → 5000` (mistä portista mihin porttiin), sitten hakasulkeissa **liput** ja sen jälkeen lukuja, kuten `Seq=`, `Ack=` ja `Len=`. Lukuihin paneudutaan sivulta 5.2.3 alkaen — tässä keskity lippuihin ja `Len`-arvoon.
:::

## Vaihe 1: Yhdistä

:::quiz short
Montako TCP-pakettia vaihdettiin sen jälkeen, kun napsautit **Yhdistä** — ennen kuin viestisi lähti?
= 3
= kolme
:::

:::quiz mc
Kuka lähettää ensimmäisen paketin, jossa on `[SYN]`?
- [x] Client-PC
- [ ] Server
:::

:::quiz mc
Millä lipuilla palvelin vastaa siihen?
- [ ] `[SYN]`
- [x] `[SYN, ACK]`
- [ ] `[ACK]`
- [ ] `[FIN, ACK]`
:::

## Vaihe 2: Lähetä

`Len` kertoo, kuinka monta tavua hyötykuormaa paketti sisältää.

:::quiz short
Montako tavua viestisi sisältävä paketti kuljettaa (`Len`)?
= 13
:::

:::note
`Hello World` on vain 11 merkkiä pitkä. TCP-asiakas lisää kuitenkin loppuun rivinvaihdon (2 tavua, `\r\n`) — niin monet internet-protokollat, kuten SMTP tai HTTP, sen odottavat.
:::

:::quiz mc
Mitä palvelin lähettää takaisin heti viestisi jälkeen — jo ennen kaikua?
- [x] Paketin, jossa on `[ACK]` ja `Len=0` — kuittauksen ilman dataa
- [ ] Ei mitään
- [ ] Uuden `[SYN]`-paketin
:::

## Missä neljä tehtävää piilevät?

Yhdistä, mistä löydät kohdan 5.1 tehtävät jäljityksestä:

:::quiz match
Yhteyden muodostus -> Kolme pakettia [SYN], [SYN, ACK] ja [ACK]
Luotettava siirto -> Paketit, joissa on [ACK] ja Len=0 ja jotka kuittaavat vastaanoton
Yhteyden purku -> Paketit, joissa on FIN, ja niiden kuittaukset
Multipleksaus -> Porttinumerot 49152 → 5000 hakasulkeiden edessä
:::

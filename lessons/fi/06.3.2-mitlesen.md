# Sähköpostin lukeminen jäljittäjällä

:::sim
url=/sims/lesson-6.3.btsim
:::

Kuten HTTP, myös SMTP on **tekstipohjainen protokolla**. Katso, mitä kaikkea siirtyy johtoa pitkin selkokielisenä.

## Kokeilu

1. Lähetä :fa-play: **Suorita**-tilassa kuten edellisellä sivulla sähköposti **Annalta** osoitteeseen `ben@biber-mail.de`.
2. Avaa :fa-magnifying-glass: **Jäljitys**-tilassa jäljitys **Annalle**. **Info**-sarakkeessa näkyy SMTP-dialogi: `C:`-alkuiset rivit lähettää asiakas (client) ja `S:`-alkuiset rivit palvelin (server).

:::quiz short
Mikä osoite on kohdan `MAIL FROM:` perässä?
= anna@beaver-schule.de
= <anna@beaver-schule.de>
:::

:::quiz short
Entä kohdan `RCPT TO:` perässä?
= ben@biber-mail.de
= <ben@biber-mail.de>
:::

:::quiz mc
Minkä numerokoodin palvelin lähettää, kun se hyväksyy komennon?
- [x] `250`
- [ ] `200`
- [ ] `404`
:::

:::evaluate
Tarkista vastaukset
:::

## Entä salasana?

Ennen `MAIL FROM` -komentoa Annan ohjelma kirjautuu sisään komennolla `AUTH PLAIN` ja merkkijonolla, kuten `AGFubmEAZ2VoZWlt`. Se näyttää salatulta, mutta ei ole: se on vain **Base64**-koodausta, jonka kuka tahansa voi muuntaa heti takaisin — siinä on `anna` ja hänen salasanansa `geheim`.

Nouda nyt **Benin** posti (**Nouda**) ja avaa jäljitys **Benille**. Kun posti noudetaan IMAP:lla, se näkyy vielä selvemmin:

:::quiz short
Minkä salasanan Benin sähköpostiohjelma lähettää palvelimelle selkokielisenä? (Katso riviä, jossa on `LOGIN`.)
= biber123
:::

:::evaluate
Tarkista vastaus
:::

:::warning
Ilman salausta jokainen, joka tallentaa tietoliikennettä, voi lukea **sisällön, lähettäjän, vastaanottajan ja salasanat**. Siksi nykyään käytetään salattuja variantteja (esim. SMTP STARTTLS:llä, IMAPS portissa 993). Miten tämä toimii, opit luvussa 8.
:::

:::tip Muista
**SMTP**, **POP3** ja **IMAP** ovat tekstipohjaisia protokollia: komennot kuten `MAIL FROM`, `RCPT TO`, `DATA` (SMTP) tai `LOGIN` (IMAP) sekä vastaukset ovat luettavissa. Ilman salausta myös **salasanat** kulkevat johdossa selkokielisinä (tai vain Base64-koodattuina).
:::

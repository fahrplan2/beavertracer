# Järjestys ja perusajattelutapa

## Ensin poikkeus, sitten sääntö

Koska **ensimmäinen sopiva sääntö** voittaa, järjestyksellä on väliä. Tutki tätä sääntölistaa (kaikki säännöt koskevat suuntaa A → B, oletuskäytäntö: Salli kaikki):

| Nro | Protokolla | Kohdeportti | Toiminto |
|---|---|---|---|
| 1 | TCP | mikä tahansa | Hylkää |
| 2 | TCP | 80 | Salli |

:::quiz mc
Internetistä saapuu paketti TCP-porttiin 80. Mitä tapahtuu?
- [ ] Se sallitaan, koska sääntö 2 sallii nimenomaan portin 80
- [x] Se hylätään, koska jo sääntö 1 sopii — sääntöön 2 ei koskaan päästä
- [ ] Palomuuri kysyy ylläpitäjältä
:::

:::evaluate
Tarkista vastaus
:::

Yleisesti pätee: **Erityiset säännöt ylös, yleiset alas.** Sääntö, joka kattaa paljon, „varjostaa“ kaikki sen alapuolella olevat säännöt. Sarake **Osumat** paljastaa tällaiset kuolleet säännöt: niiden arvo pysyy nollassa.

## Musta lista vai valkoinen lista?

Kohdassa 9.1.2 **kielsit** yksittäisiä portteja ja sallit kaiken muun. Tätä kutsutaan **mustaksi listaksi** (*blacklist*). Vastakohta on **valkoinen lista** (*whitelist*): **sallitaan** vain välttämätön ja kielletään kaikki muu — päättävällä säännöllä „hylkää kaikki“ tai oletuskäytännöllä **Hylkää kaikki**.

| | Musta lista | Valkoinen lista |
|---|---|---|
| Perusajattelutapa | kaikki sallittu, poikkeukset kielletty | kaikki kielletty, poikkeukset sallittu |
| Oletuskäytäntö | Salli | Hylkää |
| uusi palvelu palvelimella | on heti tavoitettavissa ulkoa | pysyy estettynä, kunnes joku avaa sen |

:::quiz mc
Opettaja asentaa huomenna koulun palvelimelle tietokannan, joka kuuntelee porttia 3306. Mitä tapahtuu kohdan 9.1.2 palomuurille (musta lista)?
- [x] Tietokanta on heti tavoitettavissa internetistä
- [ ] Tietokanta on automaattisesti estetty
- [ ] Palomuuri ilmoittaa uudesta palvelusta
:::

:::evaluate
Tarkista vastaus
:::

Siksi hyvät palomuurit toimivat **valkoisen listan periaatteella** („Default Deny“): kaikki, mitä ei ole nimenomaisesti sallittu, on kielletty. Koulun palvelimen valkoinen lista näyttäisi tältä:

:::quiz table
| Nro | Suunta | Protokolla | Kohdeportti | Toiminto |
|---|---|---|---|---|
| 1 | A → B | TCP | {80} | {Salli} |
| 2 | A → B | TCP | {25} | Salli |
| 3 | A → B | mikä tahansa | mikä tahansa | {Hylkää} |
:::

:::evaluate
Tarkista taulukko
:::

:::quiz mc
Mitä tapahtuu, jos sääntö 3 siirretään aivan ylimmäiseksi?
- [ ] Ei mitään, järjestyksellä ei ole väliä
- [x] Internetistä ei pääse enää läpi mitään, ei myöskään verkkosivuja eikä sähköpostia
- [ ] Vain verkkosivut ja sähköposti pääsevät läpi
:::

:::evaluate
Tarkista vastaus
:::

:::tip Muista
Koska **ensimmäinen sopiva sääntö** voittaa, **erityiset säännöt kuuluvat ylös** ja yleiset alas. **Mustaa listaa** (kaikki sallittu paitsi …) turvallisempi on **valkoinen lista** (kaikki kielletty paitsi …, *Default Deny*): unohdetut tai uudet palvelut pysyvät silloin automaattisesti estettyinä.
:::

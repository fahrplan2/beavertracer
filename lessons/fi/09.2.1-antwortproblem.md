# Vastausongelma

:::sim

Palomuuri toimii nyt sallittujen listan periaatteella: oletuskäytäntönä on **Hylkää kaikki**. Yksi ainoa sääntö sallii koulun verkon selaamisen: **B → A, TCP, kohdeportti 80, Salli**. Tilaksi on asetettu **Stateless**.

## Koe

1. Siirry :fa-play: **Suorita**-tilaan ja avaa **Lehrer-PC**:n :fa-globe: **Selain**-sovelluksessa osoite `http://203.0.113.80/`.
2. Tarkastele **Firewall**-laitteen **Protokoll**-lokia ja **Treffer**-lukuja.

:::quiz mc
Mitä selaimessa tapahtuu?
- [ ] Sivu www.beispiel.de ilmestyy näkyviin
- [x] Sivu ei lataudu, selain odottaa ja ilmoittaa lopulta virheestä
:::

:::quiz mc
Mitkä paketit näkyvät palomuurin lokissa hylättyinä (`DROP`)?
- [ ] Lehrer-PC:n pyynnöt porttiin 80
- [x] Osoitteen `203.0.113.80` vastaukset, joiden **lähdeportti on 80**, Lehrer-PC:lle
- [ ] Ei yhtään
:::

:::quiz short
Mihin suuntaan (A→B vai B→A) hylätyt paketit kulkevat?
= A→B
= A → B
= AtoB
:::

:::evaluate
Tarkista vastaukset
:::

Lehrer-PC:n pyyntö pääsee ulos — mutta jo verkkopalvelimen `SYN, ACK` ei pääse takaisin, koska suunnalle A → B ei ole sopivaa sääntöä, joten voimaan tulee **Hylkää kaikki**.

## Naiivi ratkaisu

Voisi lisätä toisen säännön: **A → B, TCP, lähdeportti 80, Salli** – "kaikki, mikä tulee portista 80, saa tulla sisään". Silloin selaaminen todella toimii.

:::quiz mc
Miksi tämä sääntö on vaarallinen?
- [ ] Koska verkkopalvelimet eivät koskaan käytä porttia 80 lähdeporttina
- [x] Hyökkääjä voi yksinkertaisesti lähettää pakettinsa lähdeportilla 80 — silloin palomuuri päästää ne läpi **mihin tahansa** porttiin koulun verkossa
- [ ] Koska silloin verkkosivut latautuvat hitaammin
:::

:::evaluate
Tarkista vastaus
:::

Lähdeportin määrittää lähettäjä itse — palomuuri ei saa luottaa siihen. Tilaton palomuuri ei kuitenkaan tiedä, onko paketti **vastaus pyyntöön** vai **uusi yhteydenottoyritys** ulkopuolelta. Juuri tämän tilallinen tila muuttaa.

:::tip Muista
**Tilaton** pakettisuodatin tarkistaa jokaisen paketin erikseen. Vastauksia varten tarvitaan silloin omat säännöt paluusuunnalle — ja tällaisia sääntöjä (esim. "lähdeportti 80 saa tulla sisään") hyökkääjät voivat hyödyntää, koska lähettäjä voi valita lähdeportin vapaasti.
:::

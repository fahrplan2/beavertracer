# POP3 vai IMAP?

:::sim
url=/sims/lesson-6.3.btsim
:::

Viestien noutamiseen on kaksi protokollaa. Tässä simulaatiossa **Anna käyttää POP3:a** ja **Ben IMAP:ia**.

## Koe

1. Lähetä :fa-play: **Suorita**-tilassa sähköpostiviesti **Benilta** osoitteeseen `anna@beaver-schule.de`.
2. Napsauta **Annan** **E-Mail**-sovelluksessa kohtaa **Nouda**.
3. Avaa **Annan** ja **Benin** jäljet (trace) ja vertaa noudon aikana käytettyjä komentoja.

:::quiz match
USER / PASS -> POP3: Kirjautuminen käyttäjänimellä ja salasanalla kahdessa vaiheessa
RETR -> POP3: yhden viestin lataaminen
LOGIN -> IMAP: Kirjautuminen käyttäjänimellä ja salasanalla
SELECT INBOX -> IMAP: kansion avaaminen palvelimella
:::

## Ero

| | POP3 | IMAP |
|---|---|---|
| Portti | 110 | 143 |
| Perusajatus | Viestit **ladataan** — sen jälkeen ne yleensä poistetaan palvelimelta | Viestit **pysyvät palvelimella** ja niitä hallitaan siellä |
| Kansiot, luettu/lukematon | vain omalla laitteella | palvelimella — kaikkialla samanlaiset |
| Useita laitteita (puhelin, kannettava) | epäkäytännöllistä: jokaisella laitteella on eri tilanne | ihanteellista: kaikki laitteet näkevät saman postilaatikon |

:::note
BeaverTracerin sähköpostiohjelma jättää viestit palvelimelle myös POP3:a käytettäessä. Oikeat ohjelmat poistavat ne usein latauksen jälkeen — tai jättävät ne palvelimelle vain jonkin aikaa.
:::

:::quiz mc
Lena lukee sähköpostinsa puhelimella, tabletilla ja koulun kannettavalla. Mitä hänen pitäisi käyttää?
- [ ] POP3:a, koska se on yksinkertaisempi
- [x] IMAP:ia, koska kaikki laitteet näkevät saman postilaatikon palvelimella
- [ ] SMTP:tä, koska se on tarkoitettu noutamiseen
:::

:::evaluate
Tarkista vastaus

:::tip Muista
**POP3** lataa viestit palvelimelta **yhdelle** laitteelle. **IMAP** hallitsee postilaatikkoa **palvelimella** — kansioineen ja luettu-tiloineen kaikille laitteille samanaikaisesti. Molemmat on tarkoitettu vain **noutamiseen**; lähettämiseen käytetään aina **SMTP:tä**.
:::

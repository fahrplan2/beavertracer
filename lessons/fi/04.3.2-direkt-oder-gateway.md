# Suoraan vai yhdyskäytävän kautta?

:::sim
url=/sims/lesson-4.3.2.btsim
:::

Ennen kuin tietokone lähettää paketin, se päättää: onko kohde **omassa verkossa**? Tätä varten se vertaa oman osoitteensa verkko-osaa kohdeosoitteen verkko-osaan — verkkomaskinsa avulla.

## Toimintatapa

1. **Onko kohde-IP omassa verkossa?**
   - **Kyllä:** Tietokone lähettää paketin **suoraan** kohteelle. Se tarvitsee kohteen MAC-osoitteen.
   - **Ei:** Tietokone lähettää paketin **yhdyskäytävälle**. Se tarvitsee reitittimen MAC-osoitteen. Jos yhdyskäytävää ei ole määritetty, se ei voi lähettää pakettia lainkaan.
2. **Tietääkö se jo tarvitsemansa MAC-osoitteen** (onko se sen ARP-välimuistissa)? Jos ei, se kysyy sitä **ARP:n** avulla.
3. Se lähettää kehyksen tähän MAC-osoitteeseen. Paketin **kohde-IP-osoite** on molemmissa tapauksissa varsinainen kohde.

| | suoraan (oma verkko) | yhdyskäytävän kautta (vieras verkko) |
|---|---|---|
| ARP kysyy … | kohteen MAC-osoitetta | reitittimen MAC-osoitetta |
| Kehyksen kohde-MAC | kohde | reititin |
| Paketin kohde-IP | kohde | kohde |

## Vianmääritys: yritys B ei ole tavoitettavissa

Eilisestä lähtien Anna ei ole tavoittanut yrityksen B tietokoneita. Verkko *pitäisi* olla määritetty näin:

| Laite | IP-osoite | Yhdyskäytävä |
|---|---|---|
| Anna | `192.168.0.10/24` | `192.168.0.1` |
| Ben | `192.168.0.11/24` | `192.168.0.1` |
| Clara | `172.16.0.10/24` | `172.16.0.1` |
| David | `172.16.0.11/24` | `172.16.0.1` |

Etsi virheet ja korjaa ne.

<details>
<summary>Vinkki 1: Pääseekö Annan ping edes perille?</summary>

Pingaa Claraa Annalta ja avaa jäljitys **Claralle**. Saapuiko ping perille? Ja vastasiko Clara?
</details>

<details>
<summary>Vinkki 2: Mitä David tekee?</summary>

Pingaa Davidia Annalta ja avaa jäljitys **Davidille**. Mitä IP-osoitetta David kysyy ARP:n avulla — ja saako hän vastauksen?
</details>

:::tip Muista
Tietokone tarvitsee oikean yhdyskäytävän paitsi lähettämiseen myös **vastaamiseen**: ilman yhdyskäytävää ping kyllä saapuu perille, mutta vastaus ei löydä tietä takaisin. Jos määritetty **yhdyskäytäväosoite on väärä**, tietokone kysyy ARP:n avulla turhaan reititintä, jota ei ole olemassa.
:::

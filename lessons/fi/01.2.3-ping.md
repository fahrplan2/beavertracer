# Pingin suorittaminen ja sen seuraaminen jäljittimessä

:::sim
url=/sims/lesson-1.2.3.btsim
:::

Molemmilla tietokoneilla on nyt osoitteet `192.168.0.10` ja `192.168.0.11`. On aika ensimmäiselle testille: **Pingillä** tietokone lähettää toiselle pienen pyynnön ja odottaa vastausta.

## Pingin suorittaminen

Siirry :fa-play: **Suorita**-tilaan. Avaa **Computer 1** -koneella :fa-terminal: **Pääte** ja kirjoita:

```
$ ping 192.168.0.11
```

Jos toinen tietokone vastaa, näet jokaisesta lähetetystä paketista rivin, jolla on vasteaika — ensimmäinen onnistunut pingisi!

:::tip Muista
**Ping** tarkistaa, onko toinen laite tavoitettavissa: se lähettää pyynnön ja mittaa, kuinka kauan vastaus kestää.
:::

## Seuraaminen jäljittimessä

Siirry nyt :fa-magnifying-glass: **Jäljitys**-tilaan. Täällä ei vielä näy mitään — napsauta vasemmassa yläkulmassa **Traces:**-tekstin vieressä **+**, valitse **Computer 1** ja sen jälkeen sen liitäntä `eth0`.

Nyt näet luettelon kaikista paketeista, jotka ovat kulkeneet tämän liitännän kautta — myös äskeiset pingit. Napsauta yhtä paketeista: sen alapuolella näet paketin tarkan rakenteen kerros kerrokselta.

:::tip Muista
Dataa ei lähetetä verkossa yhtenä kokonaisuutena, vaan pieninä yksikköinä, **paketteina**. Jokaisessa paketissa on lähettäjä, vastaanottaja ja osa datasta.
:::

:::tip
Ping koostuu aina pyynnöstä (Echo Request) ja vastauksesta (Echo Reply) — löydätkö molemmat suunnat **Info**-sarakkeesta?
:::

## Kuka kysyy ennen ensimmäistä pingiä?

Aivan luettelon alussa, jo ennen ensimmäistä pingiä, on kaksi pakettia, joiden protokolla on **ARP**. Lue niiden **Info**-sarake — siinä lukee suunnilleen näin:

```
Who has 192.168.0.11? Tell 192.168.0.10
192.168.0.11 is at aa:fd:9f:a5:d2:89
```

Computer 1 tiesi kyllä toisen tietokoneen IP-osoitteen, mutta ei vielä sen **laiteosoitetta** (*MAC-osoitetta* — jokaisella verkkokortilla on omansa). Ilman sitä se ei voi lähettää mitään. Niinpä se huutaa ensin verkkoon: *”Kenellä on 192.168.0.11? Kerro osoitteelle 192.168.0.10!”* Etsitty tietokone vastaa laiteosoitteellaan. Juuri tämä on **ARP**:n tehtävä.

Tämän jälkeen Computer 1 muistaa vastauksen — siksi ARP näkyy vain ennen ensimmäistä pingiä eikä jokaisen pingin edellä.

:::tip Muista
**ARP** selvittää tunnetulle IP-osoitteelle sitä vastaavan laiteosoitteen (**MAC-osoitteen**): tietokone kysyy kaikilta verkossa, ja vain etsitty laite vastaa.
:::

- [ ] Vain toiselle tietokoneelle
- [x] Kaikille verkon laitteille (yleislähetys)
- [ ] Internetissä olevalle palvelimelle
:::

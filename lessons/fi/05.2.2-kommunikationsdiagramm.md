# Sekvenssikaavio

:::sim
url=/sims/lesson-5.1.btsim
:::

Yhteyden kulku piirretään **sekvenssikaaviona**: asiakkaalle ja palvelimelle piirretään kummallekin pystysuora elinviiva, ja aika kulkee ylhäältä alas. Jokainen nuoli on yksi paketti. Nuoli on piirretty vinoon, koska jokainen paketti on hetken matkalla.

Tältä edellisen sivun yhteytesi näyttää — vertaa sitä rivi riviltä jälkeen (trace):

:::seq
Client-PC -> Server: SYN
Server -> Client-PC: SYN, ACK
Client-PC -> Server: ACK
Client-PC -> Server: PSH, ACK "Hello World" len=13
Server -> Client-PC: ACK
Server -> Client-PC: PSH, ACK len=13
Client-PC -> Server: ACK
Client-PC -> Server: FIN, ACK
Server -> Client-PC: ACK
Server -> Client-PC: FIN, ACK
Client-PC -> Server: ACK
:::

Jokaisen nuolen yläpuolella ovat **liput** (flags) ja sen alapuolella numerot `SEQ` ja `ACK`. **DATA** merkitsee paketit, jotka sisältävät hyötykuormaa. Punaiset numerot kuuluvat asiakkaalle ja siniset palvelimelle — mitä ne tarkoittavat, selviää seuraavalla sivulla.

## Liput

| Lippu | tulee sanoista | Merkitys |
|---|---|---|
| **SYN** | *synchronize* | muodostaa yhteyden, määrittää alkunumeron |
| **ACK** | *acknowledge* | kuittaa vastaanotetut tiedot |
| **PSH** | *push* | välittää tiedot heti ohjelmalle |
| **FIN** | *finish* | "Olen valmis" — purkaa yhteyden |
| **RST** | *reset* | katkaisee yhteyden äkillisesti tai hylkää sen (lisää kohdassa 5.3.2) |

## Kolme vaihetta

**Muodostus:** Asiakas lähettää `SYN`-paketin, palvelin vastaa `SYN, ACK`-paketilla ja asiakas kuittaa `ACK`-paketilla. Koska tarvitaan täsmälleen kolme pakettia, tätä kutsutaan **kolmivaiheiseksi kättelyksi** (three-way handshake).

**Data:** Vastaanottaja kuittaa jokaisen dataa sisältävän paketin `ACK`-paketilla. Tässä palvelin lähettää kaiun takaisin — myös sen asiakas kuittaa.

**Purku:** Kumpikin osapuoli lopettaa oman lähetyssuuntansa erikseen: asiakkaalta `FIN`, palvelimelta `ACK` — sitten palvelimelta `FIN` ja asiakkaalta `ACK`. Paketteja on siis neljä.

:::tip Muista
TCP-yhteys etenee kolmessa vaiheessa: **muodostus** kolmivaiheisella kädenpuristuksella (`SYN` → `SYN, ACK` → `ACK`), **tiedonsiirto** (jokainen datapaketti kuitataan `ACK`-paketilla) ja **purku** (kumpikin osapuoli lähettää `FIN`-paketin ja saa `ACK`-kuittauksen).
:::

## Nyt sinun vuorosi

Tällä kertaa asiakas lähettää vain `Hi` (rivinvaihto mukaan lukien 4 tavua). Täytä puuttuvat liput — järjestyksellä yhden kentän sisällä ei ole väliä.

:::quiz seq
hide: counters
Client-PC -> Server: ? SYN
Server -> Client-PC: ? SYN, ACK
Client-PC -> Server: ? ACK
Client-PC -> Server: PSH, ACK "Hi" len=4
Server -> Client-PC: ? ACK
Client-PC -> Server: ? FIN, ACK
Server -> Client-PC: ? ACK
Server -> Client-PC: ? FIN, ACK
Client-PC -> Server: ? ACK
:::

# Mengamati UDP

:::sim
url=/sims/lesson-5.5.btsim
:::

Kali ini di **Server** berjalan sebuah **Server Echo UDP** pada port `5000`. Di sini pun kabelnya sudah dimanipulasi: **datagram kedua** dari Client-PC ke Server hilang.

## Eksperimen

1. Beralihlah ke :fa-play: **Mode Jalankan** dan buka :fa-terminal: **Terminal** di **Client-PC**.
2. Mulai "koneksi" UDP ke server dengan `nc` (`-u` berarti UDP):
   ```
   $ nc -u 192.168.0.20 5000
   ```
3. Ketik `eins`, `zwei`, dan `drei` secara berurutan, lalu tekan **Enter** setiap kali. Setiap baris yang kembali adalah echo dari server.
4. Tunggu beberapa detik, lalu buka trace untuk **Client-PC** dalam mode :fa-magnifying-glass: **Jejak**.

:::quiz mc

- [x] Hanya `eins` dan `drei` — `zwei` tidak ada dan juga tidak dikirim ulang

:::evaluate
Periksa jawaban
:::

Klik salah satu paket UDP lalu buka **User Datagram Protocol**. Dibandingkan dengan header TCP, header UDP sangat kecil: **Source Port**, **Destination Port**, **Length** (panjang), dan **Checksum** (checksum pemeriksa) — totalnya hanya 8 byte. Header TCP minimal 20 byte, dengan nomor urut dan nomor konfirmasi, flag, serta ukuran window.

:::tip Poin penting
**UDP** bersifat **tanpa koneksi**: tanpa pembentukan koneksi, tanpa konfirmasi, tanpa pengiriman ulang, tanpa urutan. UDP hanya menyediakan **port** (multiplexing) dan **checksum**. Sebagai gantinya, UDP cepat dan ringkas — header UDP hanya 8 byte. Jika sebuah datagram hilang, program harus menanganinya sendiri — atau tidak peduli sama sekali.
:::

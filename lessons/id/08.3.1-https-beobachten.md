# Perbandingan HTTP dan HTTPS

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Server web **www.beaver-schule.de** menyediakan portal nilai sekolah melalui HTTP maupun HTTPS. Apa yang dilihat oleh pihak yang menyadap?

## Eksperimen

1. Beralihlah ke :fa-play: **Jalankan**-Mode Jalankan dan buka di **Client-PC** pada :fa-globe: **Peramban** terlebih dahulu `http://www.beaver-schule.de/`, kemudian `https://www.beaver-schule.de/`.
2. Di :fa-magnifying-glass: **Jejak**-Mode, buka sebuah trace untuk **Client-PC**.
3. Cari dahulu paket `HTTP/1.1 200 OK` dan klik paket tersebut. Di bagian bawah pada detail, kamu akan menemukan isi halaman.

:::quiz mc
Apa yang dapat dilihat oleh penyadap pada **HTTP**?
- [x] Seluruh halaman web, termasuk nilai Anna
- [ ] Hanya alamat server
- [ ] Tidak ada, karena HTTP berjalan di atas TCP
:::

:::quiz short
Berapa nilai Anna dalam pelajaran Matematika?
= 2
:::

Sekarang bagian HTTPS. Cari paket `[SYN]` yang digunakan klien untuk memulai koneksi kedua.

:::quiz short
Port tujuan berapa yang digunakan koneksi HTTPS (kolom **Info**, `… → ???`)?
= 443
:::

Sekarang ketik `tls` di kolom filter di bagian atas trace — maka kamu hanya akan melihat paket TLS.

:::quiz mc
Apa yang tertulis di kolom **Info** pada paket-paket yang berisi halaman web?
- [ ] `HTTP/1.1 200 OK`
- [x] `Application Data`
- [ ] `Encrypted HTML`
:::

:::quiz multi
Apa saja yang tetap dapat dilihat oleh penyadap pada **HTTPS**?
- [x] Alamat IP klien dan server
- [x] Bahwa port 443 digunakan, jadi kemungkinan besar HTTPS
- [x] Kira-kira berapa banyak data yang dikirim
- [ ] Halaman mana yang dibuka dan apa isinya
:::

:::evaluate
Periksa jawaban
:::

:::note
Klik sebuah paket **Application Data**: data isinya hanyalah rangkaian byte yang tampak acak. Tracer tidak dapat mendekripsinya — ia tidak mengetahui kunci sesi, sama seperti seorang penyerang.
:::

:::tip Poin penting
Pada **HTTP**, setiap penyadap dapat membaca seluruh halaman web. Pada **HTTPS**, ia hanya melihat **siapa berbicara dengan siapa** (alamat IP, port 443) dan **seberapa banyak** — isinya tersimpan terenkripsi di dalam paket **Application Data**.
:::

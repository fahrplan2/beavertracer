# NAT: banyak perangkat, satu alamat

:::goal
**Tujuan pembelajaran:** Kamu dapat menunjukkan di Tracer bagaimana NAT menukar alamat pengirim, membaca tabel NAT, dan menjelaskan mengapa koneksi dari luar ke jaringan rumah membutuhkan penerusan port.
:::

:::sim
url=/sims/lesson-7.1.btsim
:::

Penyedia layanan internet biasanya hanya memberikan **satu** alamat IPv4 publik untuk sambungan rumah — yaitu alamat WAN milik router rumah. Semua perangkat di jaringan rumah harus berbagi alamat itu. Cara kerjanya disebut **NAT** (*Network Address Translation*, penerjemahan alamat).

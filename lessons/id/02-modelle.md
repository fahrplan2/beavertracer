# Model

:::goal
**Tujuan pembelajaran:** Kamu dapat menjelaskan bagaimana sebuah paket tersusun dalam lapisan-lapisan (enkapsulasi), menyebutkan lapisan-lapisan tersebut di Tracer, serta menjelaskan dan membandingkan model referensi ISO/OSI dengan model referensi TCP/IP.
:::

Di Bab 1 kamu sudah melihat bahwa di balik satu klik pada sebuah tautan terdapat berbagai protokol yang bekerja: ARP, TCP, HTTP — masing-masing dengan tugasnya sendiri. Agar banyaknya protokol ini dapat dikelompokkan dengan masuk akal, dalam teknik jaringan digunakan model berlapis.

Di bab ini, pertama-tama kamu akan membedah satu paket, lalu mengenal dua model terpenting: model referensi ISO/OSI dengan tujuh lapisannya dan model TCP/IP yang sedikit lebih pragmatis dengan empat lapisan. Keduanya akan sering kamu temui di bab-bab berikutnya — keduanya adalah kosakata bersama yang kita gunakan mulai sekarang untuk membicarakan jaringan.

# Pengantar BeaverTracer

BeaverTracer adalah simulasi yang memungkinkanmu membangun jaringan sendiri, menjalankannya, dan menelusuri lalu lintas datanya paket demi paket — tanpa perangkat keras sungguhan.

Di bab pertama ini kamu akan mengenal alatnya: antarmuka, tiga mode kerja, lalu kamu membangun simulasi kecilmu yang pertama. Di akhir, kamu membuka sebuah halaman web dan melihat betapa banyak yang sebenarnya terjadi di balik layar — titik awal untuk semua materi berikutnya.

:::note
Bab-bab ini saling berkaitan. Luangkan waktu untuk bab pertama ini — cara menggunakan alat ini adalah dasar untuk semua materi selanjutnya.
:::

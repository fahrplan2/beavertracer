# IPv6 di jaringan

:::sim
url=/sims/lesson-4.6.3.btsim
:::

Anna, Ben, dan sebuah router terhubung ke switch. Pada Anna dan Ben, IPv6 diatur ke **SLAAC (automatisch)** — tidak ada yang memasukkan alamat IPv6 untuk mereka. Router mengenal prefiks `2001:db8:1::/64`.

## Dari mana alamat itu berasal?

1. Beralihlah ke Mode Jalankan :fa-play: **Jalankan** dan tunggu beberapa detik.
2. Buka :fa-terminal: **Terminal** pada **Anna** dan ketik `ip a`.

Selain alamat IPv4, kamu akan melihat dua baris dengan `inet6`: satu alamat dengan `scope link` dan satu dengan `scope global`.

:::quiz mc
Manakah dari kedua alamat IPv6 tersebut yang merupakan alamat link-local?
- [x] Yang diawali `fe80::` (`scope link`)
- [ ] Yang diawali `2001:db8:1:` (`scope global`)
:::

:::quiz mc
Dari mana prefiks `2001:db8:1:0` pada alamat global berasal?
- [ ] Anna menentukannya sendiri
- [x] Dari router — router mengumumkan prefiks tersebut di jaringan
- [ ] Dari switch
:::

:::evaluate
Periksa jawaban
:::

Bandingkan **Interface ID** (empat blok terakhir) dengan **alamat MAC** Anna — kamu bisa menemukannya di bagian paling bawah :fa-gear: **Pengaturan IP**. Dari alamat MAC `aa:28:39:e2:41:82`, misalnya, terbentuk Interface ID `a828:39ff:fee2:4182`: `ff:fe` disisipkan di tengah, dan satu bit di awal dibalik (itulah sebabnya `aa` menjadi `a8`).

Prosedur ini disebut **SLAAC** (*Stateless Address Autoconfiguration*): router mengumumkan prefiks, sedangkan Interface ID dibentuk sendiri oleh setiap perangkat.

:::note
Karena alamat MAC mengidentifikasi sebuah perangkat secara unik, perangkat itu bisa dikenali di mana pun di internet lewat Interface ID-nya. Karena itu, perangkat sungguhan biasanya juga menggunakan Interface ID acak yang berubah secara berkala (*Privacy Extensions*) — sedikit perlindungan privasi.
:::

## Menemukan tetangga — tanpa ARP

1. Ketik `ip a` pada **Ben** dan catat alamat IPv6 **global**-nya.
2. Lakukan ping ke alamat itu dari **Anna**, misalnya `ping 2001:db8:1:0:…` (dengan alamat lengkap Ben).
3. Beralihlah ke mode :fa-magnifying-glass: **Jejak** dan buka sebuah trace untuk **Anna**.

Perhatikan paket-paket tepat sebelum `Echo (ping) request` yang pertama.

:::quiz multi
Pernyataan mana yang benar?
- [x] Sebagai ganti permintaan ARP, Anna mengirim **Neighbor Solicitation** („Siapa yang memiliki alamat ini?“)
- [x] Ben menjawab dengan **Neighbor Advertisement** dan menyebutkan alamat MAC-nya
- [x] Permintaan ditujukan ke alamat multicast (`ff02::1:ff…`), bukan ke semua perangkat lewat broadcast
- [ ] Anna mengirim permintaan ARP seperti pada IPv4
- [x] Router secara berkala mengirim **Router Advertisement** ke `ff02::1` — di dalamnya terdapat prefiks
:::

:::evaluate
Periksa jawaban
:::

:::tip Poin penting
Pada IPv6, **NDP** (*Neighbor Discovery Protocol*, bagian dari ICMPv6) mengambil alih tugas ARP: dengan **Neighbor Solicitation** dan **Neighbor Advertisement**, perangkat menemukan alamat MAC tetangganya. Dengan **Router Advertisement**, router mengumumkan prefiks — dari situ perangkat membentuk sendiri alamatnya lewat **SLAAC**.
:::

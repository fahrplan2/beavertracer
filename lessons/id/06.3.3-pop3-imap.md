# POP3 atau IMAP?

:::sim
url=/sims/lesson-6.3.btsim
:::

Ada dua protokol untuk mengambil email. Dalam simulasi ini, **Anna menggunakan POP3** dan **Ben menggunakan IMAP**.

## Eksperimen

1. Di :fa-play: Mode Jalankan, kirim email dari **Ben** ke `anna@beaver-schule.de`.
2. Pada **Anna**, klik **Ambil** di aplikasi **E-Mail**.
3. Buka trace untuk **Anna** dan untuk **Ben**, lalu bandingkan perintah yang digunakan saat pengambilan email.

:::quiz match
USER / PASS -> POP3: login dengan nama pengguna dan kata sandi dalam dua langkah
RETR -> POP3: mengunduh satu pesan
LOGIN -> IMAP: login dengan nama pengguna dan kata sandi
SELECT INBOX -> IMAP: membuka folder di server
:::

## Perbedaannya

| | POP3 | IMAP |
|---|---|---|
| Port | 110 | 143 |
| Gagasan dasar | email **diunduh** — setelah itu biasanya dihapus dari server | email **tetap berada di server** dan dikelola di sana |
| Folder, sudah dibaca/belum dibaca | hanya di perangkat sendiri | di server — sama di mana pun |
| Beberapa perangkat (ponsel, laptop) | tidak praktis: setiap perangkat memiliki kondisi yang berbeda | ideal: semua perangkat melihat kotak surat yang sama |

:::note
Program email di BeaverTracer membiarkan email tetap berada di server, bahkan pada POP3. Program sungguhan sering menghapusnya setelah diunduh — atau hanya membiarkannya untuk sementara waktu.
:::

:::quiz mc
Lena membaca emailnya di ponsel, tablet, dan laptop sekolah. Apa yang sebaiknya ia gunakan?
- [ ] POP3, karena lebih sederhana
- [x] IMAP, karena semua perangkat melihat kotak surat yang sama di server
- [ ] SMTP, karena dimaksudkan untuk mengambil email
:::

:::tip Poin penting
**POP3** mengunduh email dari server ke **satu** perangkat. **IMAP** mengelola kotak surat **di server** — dengan folder dan status sudah dibaca untuk semua perangkat sekaligus. Keduanya hanya untuk **mengambil** email; pengiriman selalu dilakukan dengan **SMTP**.
:::

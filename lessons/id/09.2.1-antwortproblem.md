# Masalah balasan

:::sim
url=/sims/lesson-9.2.btsim
:::

Firewall sekarang bekerja dengan prinsip whitelist: kebijakan standar **Alle verwerfen**. Satu-satunya aturan mengizinkan jaringan sekolah untuk berselancar: **B → A, TCP, port tujuan 80, Zulassen**. Mode diatur ke **Stateless**.

## Eksperimen

1. Beralihlah ke :fa-play: Mode Jalankan dan buka `http://203.0.113.80/` di :fa-globe: **Peramban** pada **Lehrer-PC**.
2. Lihat **Protokoll** dan **Treffer** di **Firewall**.

:::quiz mc
Apa yang terjadi di peramban?
- [ ] Halaman dari www.beispiel.de muncul
- [x] Halaman tidak termuat, peramban menunggu dan akhirnya menampilkan pesan kesalahan
:::

:::quiz mc
Paket mana yang tercatat di log firewall sebagai dibuang (`DROP`)?
- [ ] Permintaan Lehrer-PC ke port 80
- [x] Balasan dari `203.0.113.80` dengan **port sumber 80** ke Lehrer-PC
- [ ] Tidak ada sama sekali
:::

:::quiz short
Ke arah mana (A→B atau B→A) paket-paket yang dibuang itu berjalan?
= A→B
= A → B
= AtoB
:::

:::evaluate
Periksa jawaban
:::

Permintaan dari Lehrer-PC boleh keluar — tetapi `SYN, ACK` dari server web pun tidak bisa kembali, karena untuk arah A → B tidak ada aturan yang cocok, sehingga berlaku **Alle verwerfen**.

## Solusi naif

Orang bisa saja menambahkan aturan kedua: **A → B, TCP, port sumber 80, Zulassen** — "semua yang datang dari port 80 boleh masuk". Dengan begitu, berselancar memang berhasil.

:::quiz mc
Mengapa aturan ini berbahaya?
- [ ] Karena server web tidak pernah memakai port 80 sebagai port sumber
- [x] Penyerang cukup mengirim paketnya dengan port sumber 80 — maka firewall akan meloloskannya ke **port mana pun** di jaringan sekolah
- [ ] Karena halaman web jadi dimuat lebih lambat
:::

:::evaluate
Periksa jawaban
:::

Port sumber ditentukan sendiri oleh pengirim — firewall tidak boleh mengandalkannya. Namun, firewall stateless tidak tahu apakah suatu paket adalah **balasan atas sebuah permintaan** atau **upaya koneksi baru** dari luar. Persis inilah yang diubah oleh mode stateful.

:::tip Poin penting
Packet filter **stateless** memeriksa setiap paket satu per satu. Balasan lalu memerlukan aturan tersendiri untuk arah sebaliknya — dan aturan semacam itu (misalnya "port sumber 80 boleh masuk") bisa dimanfaatkan oleh penyerang, karena pengirim bebas memilih port sumber.
:::

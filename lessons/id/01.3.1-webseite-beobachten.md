# Membuka dan mengamati halaman web

Untuk bagian ini kamu tidak perlu membangun apa pun sendiri: di Area kerja sudah ada simulasi yang disiapkan dengan sebuah **Client-PC** dan sebuah **Webserver**.

## Membuka halaman

1. Beralihlah ke Mode Jalankan :fa-play: **Jalankan**.
2. Di **Client-PC**, buka aplikasi :fa-globe: **Peramban** lalu akses alamat web server: `http://192.168.0.20/`.
3. Beralihlah ke mode :fa-magnifying-glass: **Jejak** dan buka trace untuk **Client-PC** dengan **+**, port `eth0` — sama seperti pada ping.

:::note
Untuk satu kali pembukaan halaman, jumlah paketnya mengejutkan banyak — jauh lebih banyak daripada pada ping. Mengambil sebuah halaman web adalah proses bertahap, bukan satu tindakan tunggal.
:::

## Membaca daftar paket

Kamu belum perlu tahu persis apa yang dilakukan masing-masing protokol. Semua yang kamu butuhkan untuk pertanyaan berikut ada di kolom **Protokol** dan **Info**.

:::quiz mc
Protokol apa yang berada paling atas dalam daftar?
- [x] ARP
- [ ] TCP
- [ ] HTTP
:::

:::quiz short
Hitung: Berapa paket **TCP** yang ada sebelum paket **HTTP** pertama?
= 3
= tiga
:::

:::quiz mc
Apa jawaban web server atas permintaan peramban? Lihat kolom Info pada paket HTTP kedua.
- [ ] GET / HTTP/1.1
- [x] HTTP/1.1 200 OK
- [ ] 404 Not Found
:::

## Menyebutkan protokol yang terlibat

Dari pengamatanmu, sekarang kamu bisa menyimpulkan protokol mana yang bertugas untuk apa.

:::tip Tips
Bacalah kolom **Info** sekali lagi: `Who has …?`, `[SYN]`, `[SYN, ACK]`, `[ACK]`, `GET /` dan `200 OK` hampir sudah mengungkap semuanya.
:::

:::quiz match
ARP -> Bertanya kepada semua perangkat di jaringan: "Siapa yang memiliki alamat IP 192.168.0.20?"
TCP -> Membentuk koneksi dengan tiga paket singkat sebelum data mengalir
HTTP -> Meminta halaman web (GET) dan mengirimkannya kembali (200 OK)
:::

:::evaluate
Periksa pasangan
:::

:::tip Poin penting
Pembukaan halaman web berlangsung bertahap: pertama **menemukan** server di jaringan (ARP), lalu **membentuk** koneksi (TCP), kemudian **meminta dan mengirimkan** halaman (HTTP) — dan terakhir **mengakhiri** koneksi kembali (paket TCP dengan `[FIN]` di akhir daftar).
:::

:::note
Kali ini kamu langsung memasukkan alamat IP server, sehingga **DNS** ("penerjemahan" nama seperti `www.beispiel.de` menjadi alamat IP) belum digunakan. Hal itu akan kita bahas di Bab 6.
:::

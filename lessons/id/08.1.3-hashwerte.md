# Nilai hash: sidik jari data

:::sim
url=/sims/lesson-8.1.3.btsim
:::

Sebuah **fungsi hash** menghitung dari data dengan ukuran berapa pun — satu kalimat, satu dokumen, bahkan satu film utuh — sebuah rangkaian karakter pendek dengan panjang tetap: **nilai hash**. Nilai ini berfungsi seperti **sidik jari**: data yang sama selalu menghasilkan nilai hash yang sama, data yang berbeda menghasilkan nilai hash yang berbeda.

Fungsi hash yang umum digunakan saat ini disebut **SHA-256**. Nilai hash-nya selalu sepanjang 256 bit, atau 64 karakter jika ditulis sebagai bilangan heksadesimal.

## Eksperimen

Di **PC**, pada folder `/home` terdapat tiga file berisi sebuah perjanjian jual beli kecil. Beralihlah ke :fa-play: Mode **Jalankan**, buka :fa-terminal: **Terminal** di **PC**, lalu ketik:

```
$ cd /home
$ cat vertrag.txt vertrag-kopie.txt vertrag-neu.txt
$ sha256sum vertrag.txt vertrag-kopie.txt vertrag-neu.txt
```

## Sifat-sifat fungsi hash

| Sifat | Arti |
|---|---|
| **panjang tetap** | Sebesar apa pun datanya — nilai hash selalu memiliki panjang yang sama. |
| **deterministik** | Data yang sama selalu menghasilkan nilai hash yang sama. |
| **efek longsor** | Perubahan sekecil apa pun menghasilkan nilai hash yang sama sekali berbeda. |
| **fungsi satu arah** | Data **tidak** dapat dihitung kembali dari nilai hash. |
| **tahan terhadap tabrakan** | Secara praktis mustahil menemukan dua file berbeda dengan nilai hash yang sama. |

Fungsi hash **bukan enkripsi**: tidak ada kunci dan tidak ada dekripsi. Fungsi ini punya tujuan lain — yaitu **integritas**.

## Untuk apa ini dibutuhkan?

- **Memeriksa unduhan:** Banyak situs web mencantumkan nilai SHA-256 di samping sebuah file. Jika nilai hash file yang kamu unduh cocok dengan nilai tersebut, berarti file itu tidak berubah selama perjalanan.
- **Menyimpan kata sandi:** Situs web yang baik tidak menyimpan kata sandimu, melainkan hanya nilai hash-nya. Saat login, nilai hash dari yang kamu ketik dibandingkan. Jika basis data dicuri, pencuri tetap tidak mengetahui kata sandinya.
- **Tanda tangan digital:** Alih-alih menandatangani seluruh dokumen, orang hanya menandatangani nilai hash-nya — penjelasan lebih lanjut ada di bagian berikutnya.

:::tip Poin penting
Sebuah **fungsi hash** (misalnya **SHA-256**) menghitung **nilai hash** dengan panjang tetap dari data apa pun — sebuah **sidik jari**. Perubahan sekecil apa pun menghasilkan nilai hash yang sama sekali berbeda, dan data tidak dapat dihitung kembali dari nilai hash. Nilai hash menjamin **integritas** data.
:::

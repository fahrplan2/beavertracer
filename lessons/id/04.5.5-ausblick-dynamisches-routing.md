# Pandangan ke depan: routing dinamis

Dalam proyek, kamu memasukkan dua belas rute secara manual untuk empat lokasi. Jaringan perusahaan besar memiliki ratusan router, sedangkan internet memiliki puluhan ribu — dan terus-menerus ada saja koneksi yang putus atau yang baru ditambahkan. Mengelolanya secara manual sudah tidak mungkin lagi.

Karena itu, router biasanya saling bertukar rute secara otomatis. Untuk itu ada **protokol routing**. Hal ini disebut **routing dinamis** — berbeda dengan **routing statis**, di mana semuanya dimasukkan secara manual.

Protokol routing yang paling dikenal:

| Protokol | Ide | Penggunaan umum |
|---|---|---|
| **RIP** (*Routing Information Protocol*) | Setiap router secara berkala memberi tahu router tetangganya jaringan mana saja yang dapat dijangkaunya dan berapa router (*hop*) jaraknya. | jaringan kecil, contoh pembelajaran |
| **OSPF** (*Open Shortest Path First*) | Setiap router mengetahui peta lengkap jaringan dan menghitung sendiri jalur terpendek dari peta tersebut. | jaringan perusahaan |
| **BGP** (*Border Gateway Protocol*) | Operator jaringan besar (misalnya penyedia layanan internet) saling memberi tahu jaringan mana saja yang dapat mereka jangkau. | internet antarpenyedia layanan |

:::quiz match
RIP -> Router memberi tahu tetangganya berapa hop jarak untuk menjangkau suatu jaringan
OSPF -> Setiap router mengetahui seluruh denah jaringan dan menghitung jalur terpendek
BGP -> Menghubungkan jaringan para penyedia layanan internet besar
:::

:::evaluate
Periksa pasangan
:::

:::tip Poin penting
Pada **routing statis**, administrator memasukkan semua rute secara manual. Pada **routing dinamis**, router bertukar rute secara otomatis dengan bantuan **protokol routing** seperti RIP, OSPF, atau BGP — dan menyesuaikan diri sendiri ketika suatu koneksi terputus.
:::

:::note
BeaverTracer dapat menyimulasikan RIP, OSPF, dan BGP — kamu dapat menemukannya di tab router dengan nama yang sama. Dalam kursus ini, pembahasannya hanya sampai pada pandangan ke depan ini.
:::

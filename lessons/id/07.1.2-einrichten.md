# Menyiapkan router rumah

:::sim
url=/sims/lesson-7.1.2.btsim
:::

Sebuah router rumah baru saja dipasang — tetapi belum ada yang bisa terhubung ke internet. Dari penyedia layanan, kamu mendapat sebuah surat berisi **data akses**:

| Data akses | Nilai |
|---|---|
| Alamat IP WAN | `203.0.113.2` |
| Panjang prefiks | `/30` |
| Gateway (router penyedia layanan) | `203.0.113.1` |
| Server DNS penyedia layanan | `198.51.100.10` |

1. Beralihlah ke Mode Jalankan :fa-play: **Jalankan**, klik **Heimrouter**, lalu buka Tab **WAN**.
2. Masukkan data akses, lalu klik **Terapkan**.
3. Hubungkan **Tablet** ke WLAN: :fa-gear: **Pengaturan IP**, Tab **WiFi**, SSID `Biberbau`, **Terapkan**.
4. Uji di PC dengan `ping 192.0.2.80` atau di peramban dengan `http://www.beispiel.de/`.

:::note
Dalam praktiknya, router rumah biasanya memperoleh alamat WAN-nya secara otomatis dari penyedia layanan (melalui DHCP atau login dengan nama pengguna dan kata sandi). Data akses tetap seperti di sini lebih umum untuk sambungan perusahaan.
:::

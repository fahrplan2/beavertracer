# Melihat sertifikat

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Di Area kerja kamu melihat **Client-PC**, sebuah **DNS-Server**, dan server web sekolah, `www.beaver-schule.de`. Server web ini juga menyediakan halamannya melalui **HTTPS**.

## Ikon gembok di peramban

1. Beralihlah ke Mode Jalankan (:fa-play: **Jalankan**), klik **Client-PC**, lalu buka :fa-globe: **Peramban**.
2. Buka `https://www.beaver-schule.de/` — perhatikan bagian **https**.
3. Di sebelah kiri alamat muncul sebuah **gembok**. Klik gembok tersebut.

:::quiz short
Untuk nama apa sertifikat ini diterbitkan (subjek tanpa `CN=`)?
= www.beaver-schule.de
:::

:::quiz short
Siapa yang menerbitkan sertifikat ini (penerbit tanpa `CN=`)?
= Biber Root CA
:::

:::evaluate
Periksa jawaban
:::

## Mengapa Client-PC memercayai sertifikat ini?

Di **Client-PC**, buka :fa-shield-halved: **Zertifikatverwaltung** lalu beralihlah ke Tab **Vertrauenswürdige CAs**.

:::quiz mc
Apa yang kamu temukan di sana?
- [x] Sertifikat **Biber Root CA**
- [ ] Sertifikat `www.beaver-schule.de`
- [ ] Tidak ada entri
:::

:::quiz mc
Bagaimana cara mengetahui bahwa Biber Root CA adalah sebuah Root CA?
- [x] Sertifikatnya **ditandatangani sendiri**: subjek dan penerbit sama
- [ ] Namanya berakhiran „CA“
- [ ] Sertifikatnya tidak memiliki kunci publik
:::

:::quiz mc
Pada Client-PC, di bagian **Privater Schlüssel** tertulis „Ja“ atau „Nein“?
- [ ] Ja — klien membutuhkan kunci privat CA untuk memeriksa tanda tangan
- [x] Nein — untuk memeriksa cukup dengan kunci publik; kunci privat hanya dimiliki oleh CA
:::

:::evaluate
Periksa jawaban
:::

## Sisi lainnya: server web

Sekarang buka :fa-shield-halved: **Zertifikatverwaltung** pada server web **www.beaver-schule.de** (Tab **Meine Zertifikate**) dan lihat sertifikatnya.

:::quiz multi
Pernyataan mana yang benar untuk sertifikat pada server web?
- [x] Pada **Privater Schlüssel** tertulis „Ja“ — server membutuhkannya untuk Pembentukan koneksi
- [x] **Rantai**-nya berbunyi `www.beaver-schule.de ← Biber Root CA`
- [x] **Sidik jari**-nya sama dengan yang ada di jendela gembok pada peramban
- [ ] Sertifikatnya ditandatangani sendiri
:::

:::evaluate
Periksa jawaban
:::

:::note
**Sidik jari** adalah nilai hash dari sertifikat. Dengan itu, dua sertifikat dapat dibandingkan dengan cepat — tanpa perlu memeriksa semua kolomnya satu per satu.
:::

:::tip Poin penting
**Server web** memiliki sertifikatnya **beserta kunci privat**. **Klien** hanya mengenal **sertifikat Root CA** (tanpa kunci privat) — itu cukup baginya untuk memeriksa tanda tangan pada sertifikat server. Jika kamu mengklik **gembok** di peramban, kamu dapat melihat subjek, penerbit, sidik jari, dan masa berlaku.
:::

# Alamat jaringan, alamat broadcast, dan host

Di setiap jaringan, ada dua alamat yang memiliki tugas khusus:

- **Alamat jaringan** adalah alamat **terendah** dalam jaringan: semua bit di bagian host bernilai 0. Alamat ini menunjuk ke jaringan secara keseluruhan, misalnya di tabel routing.
- **Alamat broadcast** adalah alamat **tertinggi** dalam jaringan: semua bit di bagian host bernilai 1. Apa pun yang dikirim ke alamat ini akan diterima oleh semua perangkat di jaringan.

Kedua alamat ini **tidak** diberikan kepada perangkat. Semua alamat di antaranya tersedia untuk perangkat (**host**).

## Contoh sederhana

`192.168.0.12/24` — bagian host adalah oktet terakhir:

| | Alamat |
|---|---|
| Alamat jaringan (bagian host = 0) | `192.168.0.0` |
| Alamat broadcast (bagian host = 255) | `192.168.0.255` |
| Rentang untuk host | `192.168.0.1` – `192.168.0.254` |
| Jumlah host | 254 |

## Jika batasnya berada di tengah oktet

Hal ini menjadi lebih sulit jika panjang prefiks bukan kelipatan 8. Dalam kasus itu, kamu mengubah oktet yang bersangkutan ke sistem biner. Contoh: `194.9.190.12/27`.

Tiga oktet pertama seluruhnya termasuk [[n|Bagian jaringan]] (24 bit). Dari oktet terakhir, **3 bit** masih termasuk bagian jaringan (24 + 3 = 27), sedangkan **5 bit** sisanya termasuk [[h|Bagian host]]:

| | oktet terakhir (biner) | desimal |
|---|---|---|
| Alamat IP | [[n|000]][[h|01100]] | 12 |
| Netmask (`/27`) | [[n|111]][[h|00000]] | 224 |
| Alamat jaringan: bit host diubah menjadi 0 | [[n|000]][[h|00000]] | **0** |
| Alamat broadcast: bit host diubah menjadi 1 | [[n|000]][[h|11111]] | **31** |

Hasil:

- Alamat jaringan: `194.9.190.0`
- Alamat broadcast: `194.9.190.31`
- Rentang untuk host: `194.9.190.1` – `194.9.190.30`
- Jumlah host: 2⁵ − 2 = **30**

:::tip Poin penting
**Alamat jaringan:** semua bit host diubah menjadi 0 (alamat terendah). **Alamat broadcast:** semua bit host diubah menjadi 1 (alamat tertinggi). Keduanya tidak diberikan kepada perangkat. Jaringan dengan panjang prefiks *n* memiliki **2<sup>32 − n</sup> − 2** alamat yang dapat dipakai untuk host.
:::

:::tip Tips: ukuran blok
Jika kamu sudah memahami cara di sistem biner, ada jalan pintas: **256 dikurangi oktet netmask** menghasilkan ukuran sebuah jaringan pada oktet tersebut. Pada `/27` (netmask 224) hasilnya 256 − 224 = **32**. Jaringan-jaringan tersebut dimulai dari 0, 32, 64, 96 … — alamat `.12` berada di jaringan yang dimulai dari `.0`, alamat `.70` berada di jaringan yang dimulai dari `.64`.
:::

## Ukuran jaringan yang terpenting

| Prefiks | Netmask | Host |
|---|---|---|
| `/8` | `255.0.0.0` | 16.777.214 |
| `/16` | `255.255.0.0` | 65.534 |
| `/24` | `255.255.255.0` | 254 |
| `/25` | `255.255.255.128` | 126 |
| `/26` | `255.255.255.192` | 62 |
| `/27` | `255.255.255.224` | 30 |
| `/28` | `255.255.255.240` | 14 |
| `/29` | `255.255.255.248` | 6 |
| `/30` | `255.255.255.252` | 2 |

:::note
Jaringan terkecil yang lazim dipakai dalam praktik adalah `/30`: jaringan ini memiliki tepat dua alamat yang dapat dipakai dan sering digunakan untuk koneksi antara dua router. `/32` menunjuk satu alamat tunggal — sebagai jaringan, ini tidak dapat dipakai, tetapi muncul di tabel routing dan aturan firewall.
:::

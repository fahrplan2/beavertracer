# Siapa mendapat paket yang mana?

:::sim
url=/sims/lesson-3.1.2.btsim
:::

Sekarang Anna, Ben, dan Clara terhubung ke switch (port 1, 2, dan 3). Ketika Anna mengirim paket ke Ben: apakah hanya Ben yang menerimanya — atau Clara juga?

Pikirkan sebentar, apa dugaanmu. Setelah itu, coba sendiri.

## Eksperimen

1. Beralihlah ke :fa-play: Mode **Jalankan**, buka :fa-terminal: **Terminal** pada **Anna**, lalu ping Ben:
   ```
   $ ping 192.168.0.11
   ```
2. Beralihlah ke :fa-magnifying-glass: Mode **Jejak** dan buka trace untuk **Clara**, port `eth0`, dengan **+**.
3. Buka trace kedua untuk **Ben**, port `eth0`, dengan **+**. Di bagian atas kamu bisa berpindah bolak-balik antara kedua trace.

## Apa yang terjadi di baliknya

Permintaan ARP memiliki tujuan **broadcast** — permintaan itu ditujukan kepada *semua* perangkat. Karena itu switch meneruskannya ke setiap port, termasuk ke Clara. Sebaliknya, ping hanya dialamatkan ke Ben. Switch mengirimkannya hanya ke port Ben — Clara sama sekali tidak mengetahuinya.

:::tip Poin penting
**Broadcast** ditujukan ke semua perangkat di jaringan lokal — switch mendistribusikannya ke semua port. **Unicast** ditujukan ke tepat satu perangkat — switch hanya mengirimkannya ke port tempat perangkat itu terhubung.
:::

## Mengintip ke dalam switch

Tetapi dari mana switch tahu di port mana Ben terhubung? Kembalilah ke :fa-play: Mode **Jalankan** dan klik **Switch**. Di Tab **SAT** kamu melihat tabel alamatnya dengan dua kolom: **MAC** dan **Port**.

:::quiz mc
Perangkat apa saja yang ada di tabel alamat?
- [ ] Anna, Ben, dan Clara
- [x] Hanya Anna dan Ben
- [ ] Hanya Ben
:::

:::quiz short
Di port berapa Ben terhubung menurut tabel? Petunjuk: alamat MAC Ben bisa kamu temukan di Tracer pada balasan ARP-nya `192.168.0.11 is at …`.
= 2
= port 2
:::

:::quiz mc
Mengapa Clara tidak ada di tabel?
- [ ] Kabelnya rusak
- [x] Ia belum mengirim satu paket pun
- [ ] Switch menyimpan paling banyak dua entri
:::

:::evaluate
Periksa jawaban
:::

Switch **belajar** sambil bekerja: pada setiap frame yang tiba, ia melihat alamat MAC **pengirim** dan mencatat di port mana perangkat itu terhubung. Ketika permintaan ARP Anna tiba, ia mencatat "Anna → port 1", dan pada balasan Ben "Ben → port 2". Clara belum mengirim apa pun — jadi switch belum mengenalnya.

:::tip Poin penting
Dalam **tabel alamat**-nya (**SAT**, *Source Address Table*), switch mengingat perangkat mana yang dapat dijangkau di port mana dengan alamat MAC tertentu — ia mempelajarinya dari alamat pengirim. Jika ia mengetahui tujuan sebuah frame, ia hanya mengirimkannya ke port itu. Jika tidak (atau jika berupa broadcast), ia mengirimkannya ke semua port.
:::

# Diagram urutan

:::sim
url=/sims/lesson-5.1.btsim
:::

Alur sebuah koneksi digambar sebagai **diagram urutan**: client dan server masing-masing mendapat satu garis vertikal, dan waktu berjalan dari atas ke bawah. Setiap panah adalah satu paket. Panah digambar miring karena setiap paket butuh waktu sebentar di perjalanan.

Beginilah koneksimu dari halaman sebelumnya — bandingkan baris demi baris dengan trace:

:::seq
Client-PC -> Server: SYN
Server -> Client-PC: SYN, ACK
Client-PC -> Server: ACK
Client-PC -> Server: PSH, ACK "Hello World" len=13
Server -> Client-PC: ACK
Server -> Client-PC: PSH, ACK len=13
Client-PC -> Server: ACK
Client-PC -> Server: FIN, ACK
Server -> Client-PC: ACK
Server -> Client-PC: FIN, ACK
Client-PC -> Server: ACK
:::

Di atas setiap panah tertulis **flag**, di bawahnya nomor `SEQ` dan `ACK`. **DATA** menandai paket yang berisi data muatan. Angka merah milik client, angka biru milik server — artinya dijelaskan di halaman berikutnya.

## Flag

| Flag | singkatan dari | Arti |
|---|---|---|
| **SYN** | *synchronize* | membentuk koneksi, menetapkan nomor awal |
| **ACK** | *acknowledge* | mengonfirmasi data yang diterima |
| **PSH** | *push* | langsung meneruskan data ke program |
| **FIN** | *finish* | „Aku sudah selesai“ — mengakhiri koneksi |
| **RST** | *reset* | membatalkan atau menolak koneksi (selengkapnya di 5.3.2) |

## Tiga fase

**Pembentukan:** Client mengirim `SYN`, server menjawab dengan `SYN, ACK`, client mengonfirmasi dengan `ACK`. Karena tepat tiga paket yang diperlukan, proses ini disebut **three-way handshake**.

**Data:** Setiap paket yang berisi data dikonfirmasi oleh penerima dengan sebuah `ACK`. Di sini server mengirim kembali echo — itu pun dikonfirmasi oleh client.

**Pengakhiran:** Setiap sisi mengakhiri arah pengirimannya sendiri-sendiri: `FIN` dari client, `ACK` dari server — lalu `FIN` dari server, `ACK` dari client. Jadi totalnya empat paket.

:::tip Poin penting
Sebuah koneksi TCP berlangsung dalam tiga fase: **pembentukan** dengan **three-way handshake** (`SYN` → `SYN, ACK` → `ACK`), **transfer data** (setiap paket data dikonfirmasi dengan `ACK`), dan **pengakhiran** (setiap sisi mengirim `FIN` dan mendapat `ACK`).
:::

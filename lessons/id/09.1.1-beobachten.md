## Ping dari luar

Beralihlah ke :fa-play: Mode **Jalankan** dan lakukan ping ke server sekolah dari **Internet-PC**:

```
$ ping -c 2 198.51.100.10
```

Setelah itu, buka Tab **Protokoll** pada firewall.

:::quiz mc
Apa yang dilaporkan `ping`?
- [x] `Anfrage abgelaufen` — sama sekali tidak ada balasan yang kembali
- [ ] `Paket gefiltert`
- [ ] Dua balasan dari server sekolah
:::

## Pemindaian port: dibuang atau ditolak?

Sekarang pindai lima port secara terarah. Port 3306 (sebuah basis data) sama sekali tidak berjalan di server sekolah.

```
$ nmap -p 22,25,80,110,3306 198.51.100.10
```

:::quiz match
22 (dibuang) -> filtered
25 (diizinkan, layanan berjalan) -> open
110 (ditolak) -> closed
3306 (diizinkan, tidak ada layanan) -> closed
:::

:::evaluate
Periksa pencocokan
:::

:::quiz multi
Apa yang dapat disimpulkan penyerang dari hasil tersebut?
- [x] Pada `filtered` ia tahu: di sana ada firewall yang menelan paket
- [x] Pada `closed` ia tidak dapat membedakan apakah firewall menolak atau memang tidak ada layanan yang berjalan
- [ ] Pada `filtered` ia tahu layanan apa yang berjalan di balik port tersebut
- [ ] Pada `closed` layanan tersebut tetap dapat dijangkau
:::

:::evaluate
Periksa jawaban
:::

Terakhir, lihat kolom **Treffer** pada daftar aturan: di sana firewall menghitung berapa banyak paket yang sudah diputuskan oleh setiap aturan. Nilai di samping **Standardrichtlinie** menghitung semua paket yang tidak cocok dengan aturan mana pun.

:::tip Poin penting
Paket yang **dibuang** menghilang tanpa jejak: `ping` melaporkan timeout, `nmap` melaporkan `filtered`. Paket yang **ditolak** dijawab firewall dengan penolakan (pada TCP berupa RST) — dari luar, hal ini terlihat seperti port yang tertutup. **Protokoll** firewall menunjukkan paket mana yang telah dihentikannya, kolom **Treffer** menunjukkan aturan mana yang berlaku.
:::

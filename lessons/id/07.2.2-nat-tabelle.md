# Tabel NAT

:::sim
url=/sims/lesson-7.1.btsim
:::

Ketika PC dan tablet memuat halaman web yang sama pada waktu yang bersamaan, kedua permintaan itu sampai ke server web dari `203.0.113.2`. Bagaimana router rumah tahu untuk siapa sebuah balasan ditujukan? Ia mencatatnya — di dalam **tabel NAT**.

## Eksperimen

1. Beralihlah ke :fa-play: Mode **Jalankan** dan buka `http://www.beispiel.de/` di **PC** dan di **Tablet**.
2. Klik **Heimrouter** dan buka Tab **NAT**.

Setiap baris adalah sebuah **pemetaan**: protokol, IP LAN dan port LAN perangkat di jaringan rumah — serta **port WAN** yang digunakan router untuk itu pada alamat publiknya.

:::quiz short
IP WAN mana yang tertera di atas tabel?
= 203.0.113.2
:::

:::quiz mc
PC dan tablet sama-sama membentuk koneksi dengan port LAN `49152`. Port WAN apa yang mereka dapatkan?
- [ ] Keduanya sama, yaitu `49152`
- [x] Masing-masing berbeda — jika tidak, router tidak akan tahu balasan itu milik siapa
- [ ] Tidak ada sama sekali, NAT hanya mengubah alamat IP
:::

:::quiz mc
Sebuah balasan dari server web tiba di `203.0.113.2` dengan **port tujuan** tertentu. Apa yang dilakukan router rumah dengannya?
- [x] Ia mencari port itu di tabel NAT dan mengirim paket ke IP LAN dan port LAN yang sesuai
- [ ] Ia mengirim paket ke semua perangkat di jaringan rumah
- [ ] Ia membuang paket tersebut
:::

:::evaluate
Periksa jawaban
:::

Di sinilah **port** dari bab 5 berperan kembali: karena NAT juga menulis ulang port, ratusan koneksi dapat berbagi satu alamat. Tepatnya, hal ini karenanya disebut **PAT** (*Port Address Translation*) atau *NAT dengan penerjemahan port* — dalam keseharian orang tetap menyebutnya NAT saja.

Berikut contoh bagaimana penerjemahan semacam itu bisa terlihat:

| | Paket dari PC (di jaringan rumah) | paket yang sama di internet |
|---|---|---|
| Pengirim | `192.168.178.20 : 49152` | `203.0.113.2 : 10001` |
| Penerima | `192.0.2.80 : 80` | `192.0.2.80 : 80` |

:::tip Poin penting
Di dalam **tabel NAT**, router mencatat untuk setiap koneksi perangkat mana (**IP LAN dan port LAN**) yang berada di balik **port WAN** tertentu. Balasan dari internet dicocokkan kembali ke perangkat yang tepat melalui port tujuan. Karena port juga ditulis ulang, secara lebih tepat disebut **PAT**.
:::

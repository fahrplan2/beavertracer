# Menyiapkan HTTPS

:::sim
url=/sims/lesson-8.3.3.btsim
:::

Di sini kita melanjutkan dari bagian 8.2.2: Di server web **www.beaver-schule.de** terdapat **Schul-CA** dan sebuah sertifikat server yang diterbitkannya, dan **Client-PC** memercayai Schul-CA. Hanya saja, server web tersebut belum mendukung HTTPS.

## Sebelumnya

Beralihlah ke Mode Jalankan :fa-play: **Jalankan** dan buka `https://www.beaver-schule.de/` di :fa-globe: **Peramban** pada **Client-PC**.

:::quiz mc
Apa yang terjadi?
- [x] Koneksi tidak terbentuk — tidak ada layanan yang mendengarkan di port 443
- [ ] Peramban memperingatkan adanya sertifikat yang tidak aman
- [ ] Halaman ditampilkan tanpa ikon gembok
:::

:::evaluate
Periksa jawaban
:::

## Mengaktifkan HTTPS

1. Di server web, buka **Server HTTP** lalu klik **Stoppen** — selama server berjalan, pengaturan tidak dapat diubah.
2. Beralihlah ke Tab **HTTPS**:
    - Centang **HTTPS aktivieren**, **HTTPS-Port** `443`
    - Pada **Sertifikat**, pilih sertifikat server `www.beaver-schule.de` — bukan Schul-CA!
    - Klik **Verwenden**
3. Klik **Mulai**.

Buka kembali halaman tersebut di Client-PC melalui `https://`. Klik ikon gembok dan periksa penerbit serta masa berlakunya.

:::quiz mc
Mengapa di Server HTTP kamu tidak boleh memilih sertifikat **Schul-CA**?
- [ ] Karena sertifikat CA tidak dapat mengenkripsi
- [x] Karena sertifikat itu diterbitkan untuk nama `Schul-CA`, bukan untuk `www.beaver-schule.de` — peramban akan memberi peringatan
- [ ] Karena Schul-CA tidak memiliki kunci privat
:::

:::quiz mc
Apa yang akan dilihat oleh perangkat yang **tidak** memercayai Schul-CA, misalnya ponsel milik tamu?
- [ ] Halaman tampil seperti biasa dengan ikon gembok
- [x] Peringatan sertifikat, karena perangkat tidak dapat menelusuri rantai kepercayaan hingga ke CA yang dikenal
- [ ] Tidak ada sama sekali, karena koneksi ditolak
:::

:::note
Untuk situs web publik, diperlukan sertifikat dari CA yang sudah terpasang sebelumnya di semua peramban. Sejak 2015 ada **Let's Encrypt**, sebuah CA yang menerbitkan sertifikat semacam itu secara gratis dan otomatis — salah satu alasan utama mengapa kini hampir semua situs web menggunakan HTTPS.
:::

:::tip Poin penting
Untuk **HTTPS**, server web membutuhkan **sertifikat server beserta kunci privat** yang namanya sesuai dengan alamat, dan harus mendengarkan di **port 443**. Klien hanya memercayai situs tersebut jika ia mengenal **CA** yang menerbitkannya.
:::

## Eksperimen

1. Beralihlah ke Mode Jalankan (:fa-play: **Jalankan**), klik **Client-PC**, lalu buka :fa-globe: **Peramban**. Akses `http://192.168.0.20/`.
2. Klik **Zurück** di bagian atas jendela, buka **Klien TCP Sederhana**, lalu hubungkan ke `192.168.0.20`, port `5000`. Biarkan koneksi tetap terbuka.
3. Beralihlah ke Mode :fa-magnifying-glass: **Jejak**, buka trace untuk **Client-PC**, lalu klik sebuah paket dengan `[SYN]`. Buka **Transmission Control Protocol**.

Di bagian paling atas header TCP terdapat dua port: **Source Port** (port sumber) dan **Destination Port** (port tujuan).

|---|---|---|

| TCP-Client → Layanan Echo | {49153} | {5000} |

## Dua jenis port

**Port tujuan — layanannya:** Sebuah program server menunggu koneksi pada port yang tetap — dikatakan program itu **mendengarkan** (*listen*) di sana. Untuk layanan yang umum dikenal, nomornya ditetapkan secara global, yaitu **Well-known Port** (0 sampai 1023). Karena itu, peramban tahu tanpa perlu bertanya: webserver mendengarkan di port 80.

**Port sumber — pengirimnya:** Port di sisi klien dipilih sendiri oleh sistem operasi untuk setiap koneksi baru dari rentang yang tinggi (di BeaverTracer mulai dari 49152). Dari port itulah klien mengetahui balasan tersebut termasuk ke koneksi yang mana.

Jadi, sebuah koneksi ditentukan secara unik oleh empat informasi: **alamat IP dan port di kedua sisi**. Pasangan alamat IP dan port disebut **socket**, misalnya `192.168.0.20:80`.

## Melihat ke sisi server

Kembali ke Mode :fa-play: **Jalankan**, buka :fa-terminal: **Terminal** pada **Server**, lalu ketik:

```
$ ss
```

`ss` menampilkan semua socket pada komputer. Baris dengan `LISTEN` adalah program yang mendengarkan di sebuah port. Baris dengan `ESTABLISHED` adalah koneksi yang sedang berlangsung — lengkap dengan socket sendiri (*Local Address:Port*) dan socket pihak lawan (*Peer Address:Port*).

:::quiz multi
Di port mana saja server mendengarkan?
- [x] 80
- [x] 5000
- [ ] 49152
- [ ] 443
:::

:::quiz mc

- [ ] `192.168.0.20:80` dengan `192.168.0.10:49152` — koneksi peramban
- [ ] Keduanya
:::

## Well-known Port yang terpenting

| Port | Protokol | Layanan |
|---|---|---|
| 22 | SSH | administrasi jarak jauh yang aman (command line terenkripsi) |
| 25 | SMTP | mengirim e-mail |
| 53 | DNS | menerjemahkan nama menjadi alamat IP (umumnya lewat UDP) |
| 80 | HTTP | halaman web |
| 110 | POP3 | mengambil e-mail |
| 143 | IMAP | mengelola e-mail di server |
| 443 | HTTPS | halaman web terenkripsi |

:::tip Poin penting
**Port** (0 sampai 65535) membedakan koneksi-koneksi pada sebuah komputer. Layanan server **mendengarkan** di **Well-known Port** yang tetap (misalnya HTTP 80, HTTPS 443), sedangkan klien mendapatkan **port sumber** tinggi yang bebas untuk setiap koneksi. Sebuah koneksi ditentukan secara unik oleh **alamat IP dan port dari kedua sisi**.
:::

:::

## Eksperimen

1. Beralihlah ke :fa-play: **Jalankan** (Mode Jalankan), klik **Anna**, lalu buka aplikasi **E-Mail**.
2. Pindah ke Tab **Tulis**. Pada kolom **An** isikan `ben@biber-mail.de`, masukkan subjek dan teks singkat, lalu klik **Kirim**.
3. Tunggu beberapa detik — e-mail harus berpindah dulu dari server e-mail ke server e-mail lainnya. Setelah itu klik **Ben**, buka aplikasi **E-Mail**, lalu klik **Ambil**. E-mail dari Anna sudah ada.
4. Pada :fa-magnifying-glass: **Jejak**, buka sebuah trace untuk **Mailserver Schule**.

## Apa yang terjadi di baliknya

Sebuah e-mail menempuh perjalanan dalam beberapa tahap — mirip surat yang melewati dua kantor pos:

1. Program e-mail Anna menyerahkan e-mail ke server e-mail Anna dengan **SMTP**.
2. Mailserver Schule melihat bahwa penerimanya berasal dari **domain lain**. Melalui **DNS**, ia menanyakan **rekaman MX** (*Mail Exchanger*) dari `biber-mail.de` dan mendapat `mail.biber-mail.de` — lalu setelah itu juga alamat IP-nya.
3. Ia mengantarkan e-mail tersebut ke Mailserver Biber dengan **SMTP**. Di sana e-mail masuk ke Kotak surat Ben.
4. Ben mengambilnya dari server e-mailnya dengan **IMAP** (atau **POP3**).

:::seq
mode: text
Mailserver Schule -> Mailserver Biber: SMTP: MAIL FROM | anna@beaver-schule.de
Mailserver Biber -> Mailserver Schule: 250 OK
Mailserver Schule -> Mailserver Biber: SMTP: RCPT TO | ben@biber-mail.de
Mailserver Biber -> Mailserver Schule: 250 OK
Mailserver Schule -> Mailserver Biber: SMTP: DATA | e-mail itu sendiri
Mailserver Biber -> Mailserver Schule: 250 OK queued
:::

:::tip Poin penting
**SMTP** (port 25) **mengirim** e-mail: dari program e-mail ke server e-mail sendiri, dan dari sana ke server e-mail penerima. Server e-mail mana yang bertanggung jawab untuk suatu domain tercantum dalam **rekaman MX** di DNS. **POP3** (port 110) dan **IMAP** (port 143) hanya berfungsi untuk **mengambil** e-mail dari Kotak surat sendiri.
:::

:::quiz match

Rekaman MX -> Menunjukkan server e-mail mana yang bertanggung jawab untuk suatu domain
IMAP -> Mengambil e-mail dari Kotak surat sendiri
:::

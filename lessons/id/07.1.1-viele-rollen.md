## Apa saja yang ada di dalam router rumah

| Peran di router rumah | Fungsinya | kamu mengenalnya dari |
|---|---|---|
| **Switch** | menghubungkan perangkat pada soket LAN | Bab 3.1 |
| **Access Point** | menghubungkan ponsel, tablet, dan laptop ke jaringan lewat WLAN | Bab 3.3 |
| **Router** | menghubungkan jaringan rumah dengan jaringan provider — ia adalah **gateway** | Bab 4.3 |
| **Server DHCP** | membagikan alamat, gateway, dan server DNS | Bab 6.4 |
| **DNS** | meneruskan permintaan nama atau menyebutkan server DNS milik provider | Bab 6.2 |
| **NAT** | menghubungkan semua perangkat ke internet lewat **satu** alamat publik | baru — Bagian 7.2 |

Port **WAN** (*Wide Area Network*) mengarah ke provider, sedangkan port **LAN** dan WLAN mengarah ke jaringan rumah. Banyak router rumah juga memiliki **modem** — modem menerjemahkan data untuk saluran (DSL, kabel, serat optik). BeaverTracer tidak mensimulasikan hal itu; di sini port WAN langsung terhubung ke jaringan provider.

:::quiz match

Access Point -> Menghubungkan tablet dan ponsel ke jaringan lewat WLAN
Server DHCP -> Membagikan alamat ke perangkat di jaringan rumah
Router -> Menghubungkan jaringan rumah dengan jaringan provider
:::

:::tip Poin penting
Sebuah **router rumah** menyatukan beberapa perangkat: **switch**, **access point WLAN**, **router** (gateway ke internet), **server DHCP**, dan **penerusan DNS** — ditambah **NAT**. Port **WAN** mengarah ke provider, sedangkan port **LAN** dan WLAN mengarah ke jaringan rumah.
:::

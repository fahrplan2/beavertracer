# Pemecahan masalah: halaman kontak hilang

:::sim
url=/sims/lesson-6.1.3.btsim
:::

Sekretariat melaporkan: "Di situs web kami, tautan **Kontak** hanya mengarah ke pesan kesalahan." Halaman kontak seharusnya dapat diakses di `http://192.168.0.20/kontakt.html`. Temukan kesalahannya dan perbaiki.

<details>
<summary>Petunjuk 1: Apa yang dilaporkan server?</summary>

Buka halaman kontak di peramban atau dengan `curl -v`. Kode status apa yang dikembalikan? Halaman kesalahan juga menunjukkan di mana server mencari file tersebut.
</details>

<details>
<summary>Petunjuk 2: Di mana file-file berada?</summary>

Server web hanya menyajikan file dari **Akar Dokumen** (*Document Root*)-nya — pengaturan ini ada di aplikasi **Server HTTP**. Di **Server**, lihat isinya dengan `ls` di Terminal, dan cari juga halaman kontak di `/home`.
</details>

<details>
<summary>Petunjuk 3: Memindahkan file</summary>

Dengan `mv` kamu memindahkan file: `mv <sumber> <folder tujuan>`.
</details>

:::task
title: Halaman kontak sudah diperbaiki?
Memeriksa apakah halaman kontak berada di Akar Dokumen server web.
check: fileExists(2, "/var/www/kontakt.html")
:::

## Apa yang terjadi?

:::quiz multi
Pernyataan mana yang benar?
- [x] Server menjawab dengan `404 Not Found`
- [x] File berada di `/home`, bukan di Akar Dokumen `/var/www`
- [ ] Server web sama sekali belum dimulai
- [ ] Peramban menggunakan alamat IP yang salah
:::

:::evaluate
Periksa jawaban
:::

:::tip Poin penting
**404** berarti: server web berjalan dan dapat dijangkau, tetapi **file** yang diminta tidak ada di jalur tersebut. Server hanya mencari di **Akar Dokumen**-nya (*Document Root*, di sini `/var/www`). Bandingkan: jika server sama sekali tidak menjawab atau menjawab dengan `RST`, masalahnya lebih dalam — pada jaringan atau pada layanan itu sendiri (bab 5.3.2).
:::

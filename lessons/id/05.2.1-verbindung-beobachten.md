# Satu koneksi dari awal sampai akhir

:::sim
url=/sims/lesson-5.1.btsim
:::

Di **Server** berjalan layanan echo pada port `5000`: setiap pesan langsung dikirimkannya kembali. Dengan **Klien TCP Sederhana** kamu bisa mengendalikan sebuah koneksi langkah demi langkah — setiap tombol adalah satu fase.

## Eksperimen

1. Beralihlah ke Mode :fa-play: **Jalankan**, klik **Client-PC**, lalu buka **Klien TCP Sederhana**.
2. Isi **Host** dengan `192.168.0.20` dan **Port** dengan `5000`.
3. Klik **Hubungkan**.
4. Ketik `Hello World` di kolom pesan, lalu klik **Kirim**. Di jendela chat kamu akan langsung melihat echo dari server.
5. Klik **Putus Hubungan**.
6. Beralihlah ke Mode :fa-magnifying-glass: **Jejak** dan buka trace untuk **Client-PC** dengan **+**, antarmuka `eth0`.

:::note
Kedua paket ARP di awal sudah kamu kenal dari bab 1. Pada kolom **Info** paket TCP, yang tertulis pertama adalah `49152 → 5000` (dari port mana ke port mana), lalu **flag** dalam tanda kurung siku, dan setelahnya angka-angka seperti `Seq=`, `Ack=`, dan `Len=`. Angka-angka itu dibahas mulai halaman 5.2.3 — di sini kamu cukup memperhatikan flag dan `Len`.
:::

## Fase 1: Hubungkan

:::quiz short
Berapa paket TCP yang dipertukarkan setelah kamu mengklik **Hubungkan** — sebelum pesanmu dikirim?
= 3
= tiga
:::

:::quiz mc
Siapa yang mengirim paket pertama dengan `[SYN]`?
- [x] Client-PC
- [ ] Server
:::

:::quiz mc
Dengan flag apa server menjawabnya?
- [ ] `[SYN]`
- [x] `[SYN, ACK]`
- [ ] `[ACK]`
- [ ] `[FIN, ACK]`
:::

## Fase 2: Kirim

`Len` menunjukkan berapa byte data muatan yang dibawa sebuah paket.

:::quiz short
Berapa byte yang dibawa paket dengan pesanmu (`Len`)?
= 13
:::

:::note
`Hello World` hanya terdiri dari 11 karakter. Namun, klien TCP menambahkan akhir baris (2 byte, `\r\n`) — begitulah yang diharapkan banyak protokol internet seperti SMTP atau HTTP.
:::

:::quiz mc
Apa yang dikirim server kembali tepat setelah pesanmu — bahkan sebelum echo?
- [x] Sebuah paket dengan `[ACK]` dan `Len=0` — konfirmasi tanpa data
- [ ] Tidak ada sama sekali
- [ ] Sebuah `[SYN]` baru
:::

## Fase 3: Putus Hubungan

:::quiz short
Berapa paket yang termasuk dalam pemutusan koneksi — mulai dari paket pertama dengan `FIN`?
= 4
= empat
:::

:::quiz mc
Apa yang disampaikan satu pihak dengan `FIN`?
- [x] "Aku sudah selesai" — pihak itu tidak mengirim data lagi
- [ ] "Terjadi kesalahan"
- [ ] "Ini ada data baru"
:::

## Di mana keempat tugas itu?

Cocokkan di mana kamu menemukan tugas-tugas dari bagian 5.1 dalam trace:

:::quiz match
Pembentukan koneksi -> Tiga paket [SYN], [SYN, ACK], dan [ACK]
Transmisi yang andal -> Paket dengan [ACK] dan Len=0 yang mengonfirmasi penerimaan
Pemutusan koneksi -> Paket dengan FIN beserta konfirmasinya
Multiplexing -> Nomor port 49152 → 5000 sebelum tanda kurung siku
:::

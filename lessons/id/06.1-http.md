# HTTP: halaman web

**Hypertext Transfer Protocol** (**HTTP**) adalah bahasa yang digunakan peramban dan server web untuk saling berkomunikasi. Di server terdapat halaman web **Beaver-Schule**: sebuah halaman beranda, sebuah halaman kontak, dan sebuah stylesheet untuk tampilannya.

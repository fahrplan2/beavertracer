# DMZ

:::sim
url=/sims/lesson-9.3.btsim
:::

Sebelumnya, **Schulserver** berada di jaringan yang sama dengan **Lehrer-PC**. Ini berbahaya: Schulserver dapat dijangkau dari internet. Jika penyerang menemukan celah di server web dan mengambil alih komputer tersebut, ia berada **di tengah jaringan sekolah** — dan firewall tidak dapat berbuat apa-apa lagi, karena lalu lintas dari Schulserver ke Lehrer-PC tidak melewatinya.

Solusinya: server yang harus dapat dijangkau dari internet ditempatkan di **jaringan tersendiri** di antara internet dan jaringan internal. Jaringan ini disebut **DMZ** (*demilitarized zone*, dinamai dari jalur netral di antara dua perbatasan).

## Susunannya

Di Area kerja kamu melihat model klasik dengan **dua firewall**:

```
Internet ──[ Firewall außen ]── Schulrouter ──── DMZ: Schulserver (198.51.100.10)
                                    │
                             [ Firewall innen ]
                                    │
                    LAN: Lehrer-PC (192.0.2.20), Schüler-PC (192.0.2.21)
```

- **Firewall außen** melindungi semuanya dari internet. Port A terhubung ke internet, port B ke Schulrouter.
- **Firewall innen** melindungi LAN — termasuk dari DMZ. Port A terhubung ke Schulrouter, port B ke LAN.

Saat ini kedua firewall masih meloloskan semuanya.

## Tugas: mengamankan DMZ

Atur **kedua** firewall ke **Stateful** dan **Alle verwerfen**, lalu masukkan aturan yang sesuai:

- **Firewall außen:** Dari dalam ke luar (B → A) semuanya diizinkan; dari luar (A → B) hanya TCP 80 dan 25 ke Schulserver `198.51.100.10`.
- **Firewall innen:** Dari LAN (B → A) semuanya diizinkan; ke arah LAN (A → B) tidak perlu aturan — balasan kembali melalui tabel status.

:::note
Banyak firewall memiliki tiga atau lebih antarmuka ("zona") dan membentuk DMZ dalam satu perangkat. Prinsipnya sama: lalu lintas antara internet, DMZ, dan LAN selalu harus melewati aturan. Model dengan dua firewall memiliki satu keuntungan: penyerang harus melewati **dua** rintangan — sering kali bahkan digunakan perangkat dari produsen yang berbeda, agar celah keamanan yang sama tidak membuka keduanya.
:::

:::tip Poin penting
Di dalam **DMZ** ditempatkan semua server yang harus dapat dijangkau dari internet. DMZ berada di antara dua firewall (atau di zona tersendiri pada sebuah firewall): internet hanya boleh mengakses layanan tertentu di DMZ, LAN boleh masuk ke DMZ dan ke internet — tetapi dari DMZ dan dari internet **tidak ada jalan menuju LAN**. Jika sebuah server di DMZ diambil alih, LAN tetap terlindungi.
:::

# Router

:::goal
**Tujuan pembelajaran:** Kamu dapat menjelaskan bagaimana sebuah router menghubungkan dua jaringan, mengatur gateway pada sebuah PC, dan menjelaskan kapan sebuah PC mengirimkan paket secara langsung dan kapan melalui gateway.
:::

:::sim
url=/sims/lesson-4.3.1.btsim
:::

Sebuah **router** menghubungkan jaringan-jaringan yang berbeda satu sama lain. Untuk itu, router memiliki antarmuka tersendiri untuk setiap jaringan — dan pada setiap antarmuka terdapat alamat IP tersendiri dari jaringan tersebut. Di Area kerja kamu kembali melihat Firma A dan Firma B, kali ini dengan sebuah router di antara keduanya.

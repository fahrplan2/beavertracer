# Menerapkan model

Cocokkan protokol dari eksperimen di awal bab dengan lapisan OSI-nya:

:::quiz match
Ethernet -> Lapisan 2 — Tautan data
IPv4 -> Lapisan 3 — Jaringan
TCP -> Lapisan 4 — Transport
HTTP -> Lapisan 7 — Aplikasi
:::

:::evaluate
Periksa pencocokan
:::

Dan terakhir, nama-nama satuan data:

:::quiz match
Frame -> Lapisan 2 — Tautan data
Paket -> Lapisan 3 — Jaringan
Segmen -> Lapisan 4 — Transport
:::

:::evaluate
Periksa pencocokan
:::

Dengan begitu, kamu sudah punya bekal untuk mengelompokkan protokol dengan benar ke depannya. Mulai bab berikutnya, kita akan membahas lapisan-lapisan itu satu per satu — dimulai dari Lapisan 2 dan pertanyaan tentang bagaimana sebenarnya sebuah switch tahu ke mana ia harus meneruskan paket.

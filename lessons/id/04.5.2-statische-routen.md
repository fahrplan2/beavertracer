# Menambahkan rute statis

:::sim
url=/sims/lesson-4.5.2.btsim
:::

Kali ini ada **dua** router di antara Firma A dan Firma B. Keduanya terhubung lewat jaringan kecil tersendiri, yaitu **jaringan perantara** `10.0.0.0/30`:

| Router | Antarmuka | Alamat IP | Jaringan |
|---|---|---|---|
| Router A | `eth0` | `192.168.0.1/24` | Firma A (Anna) |
| Router A | `eth1` | `10.0.0.1/30` | Jaringan perantara |
| Router B | `eth0` | `10.0.0.2/30` | Jaringan perantara |
| Router B | `eth1` | `172.16.0.1/24` | Firma B (Clara) |

:::note
Jaringan `/30` memiliki tepat dua alamat yang dapat dipakai — sempurna untuk menghubungkan dua router (lihat subbab 4.2.3).
:::

## Masalahnya

Beralihlah ke :fa-play: Mode **Jalankan** lalu lakukan ping dari **Anna** ke Clara (`ping 172.16.0.10`). Clara tidak menjawab — sebaliknya, Router A (`192.168.0.1`) melaporkan "Zielnetz nicht erreichbar".

Lihat **Tabel Routing IPv4** milik **Router A**.

:::quiz mc
Mengapa ping Anna tidak sampai ke Clara?
- [ ] Anna belum mengisi gateway
- [x] Router A tidak mengenal jaringan `172.16.0.0/24` — jaringan itu tidak terhubung langsung ke Router A, dan tidak ada rute ke sana
- [ ] Jaringan perantara terlalu kecil
:::

:::evaluate
Periksa jawaban
:::

## Menambahkan rute

Router A perlu belajar: paket untuk `172.16.0.0/24` dikirim ke Router B (`10.0.0.2`), melalui `eth1`.

1. Pada **Router A**, buka tab **Tabel Routing IPv4** lalu klik **+ hinzufügen**.
2. Isi baris baru: **Ziel** `172.16.0.0`, **Netzmaske** `255.255.255.0`, **Next Hop** `10.0.0.2`, **Iface** `eth1`.
3. Simpan baris tersebut dengan tanda centang :fa-check:. Pada kolom **Quelle** sekarang tertulis **Statis**.

Ping Clara sekali lagi — sekarang balasan datang.

:::note
Omong-omong, Router B sebenarnya sudah mengetahui jalan kembali ke Firma A: di tabel routing-nya sudah ada rute statis untuk `192.168.0.0/24` melalui `10.0.0.1`. Mengapa jalur kembali ini sama pentingnya, kamu akan melihatnya di halaman berikutnya.
:::

## Menelusuri jalur: traceroute

Dengan `traceroute` kamu dapat menampilkan router mana saja yang dilewati sebuah paket. Ketik pada **Anna**:

```
$ traceroute 172.16.0.10
```

:::quiz short
Berapa banyak router yang dilewati paket dari Anna ke Clara?
= 2
= dua
:::

:::quiz mc
Alamat mana yang ditampilkan `traceroute` untuk Router B?
- [x] `10.0.0.2` — alamatnya di jaringan perantara, tempat paket masuk
- [ ] `172.16.0.1` — alamatnya di Firma B
- [ ] `192.168.0.1`
:::

:::evaluate
Periksa jawaban
:::

`traceroute` memanfaatkan trik dengan **Time to Live** dari subbab 4.3.1: mula-mula ia mengirim paket dengan TTL 1. Router pertama mengurangi 1, nilainya menjadi 0, lalu membuang paket itu dan melaporkannya kembali ke pengirim — dengan begitu Anna mengetahui router pertama. Lalu TTL 2 untuk router kedua, dan seterusnya, sampai tujuan menjawab.

:::tip Poin penting
**Rute statis** ditambahkan secara manual oleh administrator: jaringan tujuan, netmask, next hop, dan antarmuka. Dengan **traceroute**, jalur sebuah paket dapat ditelusuri router demi router.
:::

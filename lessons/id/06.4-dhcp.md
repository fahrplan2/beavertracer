# DHCP: masuk ke jaringan secara otomatis

:::goal
**Tujuan pembelajaran:** Kamu dapat menjelaskan bagaimana sebuah perangkat mendapatkan pengaturan IP-nya secara otomatis melalui DHCP, mengatur sebuah server DHCP, serta mengenali dan memperbaiki kesalahan DHCP yang umum (misalnya alamat 169.254).
:::

:::sim
url=/sims/lesson-6.4.btsim
:::

Sampai sekarang kamu memasukkan alamat IP, netmask, gateway, dan server DNS ke setiap perangkat secara manual. Di sekolah dengan ratusan laptop, tablet, dan ponsel, hal itu mustahil dilakukan — dan setiap salah ketik menjadi kesalahan di jaringan.

Pekerjaan ini diambil alih oleh **Dynamic Host Configuration Protocol** (**DHCP**): sebuah **server DHCP** membagikan pengaturan tersebut secara otomatis ke setiap perangkat yang masuk ke jaringan.

# Model referensi ISO/OSI

Model ISO/OSI membagi komunikasi antara dua perangkat menjadi tujuh lapisan. Setiap lapisan memiliki tugas yang jelas batasannya dan hanya menggunakan layanan dari lapisan tepat di bawahnya:

Dari eksperimen di halaman sebelumnya, kamu sudah mengenal empat dari lapisan ini: Ethernet (2), IPv4 (3), TCP (4), dan HTTP (7). Persis nomor dan warna inilah yang ditampilkan Tracer kepadamu di Pohon protokol.

:::tip Jembatan keledai
Dari lapisan 7 ke bawah: **A**ku **P**ergi **S**ekolah **T**iap **J**am **T**ujuh **F**ajar — **A**plikasi, **P**resentasi, **S**esi, **T**ransport, **J**aringan, **T**autan data, **F**isik.
:::

:::note Kasus batas
Tidak setiap protokol pas masuk ke tepat satu lapisan. Karena itu, Tracer menampilkan beberapa lapisan untuk protokol-protokol berikut:

- **ARP** — lapisan 2/3: ARP tidak memiliki header IP, tetapi menghubungkan alamat IP (lapisan 3) dengan alamat perangkat keras (lapisan 2).
- **TLS** — lapisan 4/5: TLS berada tepat di atas TCP dan mengelola sesi yang diamankan.
- **HTTPS** (HTTP di dalam TLS) — lapisan 5–7: Lapisan aplikasi klasik dari model TCP/IP, yang akan kamu pelajari di halaman berikutnya.
:::

:::note
Lapisan 1 menjelaskan pengiriman sinyal yang sebenarnya melalui kabel atau nirkabel. BeaverTracer tidak mensimulasikan tingkat ini — kabel selalu dianggap terhubung tanpa gangguan, tidak ada masalah sinyal maupun tabrakan. Karena itu, di Tracer pengamatan praktis dimulai dari lapisan 2.
:::

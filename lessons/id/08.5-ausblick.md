# Ringkasan dan prospek

## Gambaran umum komponen

| Komponen | Tujuan keamanan | Contoh |
|---|---|---|
| **Enkripsi simetris** | Kerahasiaan | AES mengenkripsi data sebuah koneksi HTTPS |
| **Enkripsi asimetris** | Kerahasiaan, pertukaran kunci | Diffie-Hellman, RSA |
| **Nilai hash** | Integritas | Checksum SHA-256 dari sebuah unduhan |
| **Tanda tangan digital** | Autentisitas, integritas | Server menandatangani bagian Diffie-Hellman miliknya |
| **Sertifikat** | Autentisitas | menegaskan: Kunci ini milik `www.biberbank.de` |

## Prinsip yang sama di banyak tempat

Apa yang sudah kamu pelajari tentang HTTPS juga terdapat di banyak teknik lain:

- **WLAN (WPA2/WPA3):** Di bab 3.3.2, setiap perangkat dalam jangkauan bisa ikut membaca lalu lintas data. Dengan WPA2 atau WPA3, setiap frame nirkabel dienkripsi dengan AES; selain itu WPA3 menyepakati kunci sedemikian rupa sehingga penyadap, meskipun mengetahui kata sandi WLAN, tidak dapat mendekripsi rekaman lama.
- **SSH:** Akses jarak jauh terenkripsi dari bab 6.6. Alih-alih sertifikat, klien mengingat **sidik jari** kunci server saat pertama kali terhubung, dan memberi peringatan jika sidik jari itu berubah di kemudian hari.
- **VPN:** Terowongan terenkripsi melintasi internet, misalnya menuju jaringan sekolah atau perusahaan. Hal ini dibahas di bab 10.
- **Aplikasi pesan:** Signal, WhatsApp, dan lainnya mengenkripsi secara **end-to-end**: Bahkan penyedia layanan pun tidak dapat membaca pesannya.

:::note
**Komputer kuantum** berskala besar suatu hari nanti mungkin dapat memecahkan pemfaktoran bilangan besar menjadi faktor prima — dan dengan demikian juga RSA dan Diffie-Hellman. Karena itu, metode baru yang **tahan kuantum** sudah mulai diperkenalkan sekarang. Metode simetris seperti AES dengan kunci yang panjang tetap dianggap aman.
:::

## Uji dirimu

:::quiz mc
Pada HTTPS, data yang sebenarnya dienkripsi dengan …
- [ ] RSA, karena paling aman
- [x] metode simetris seperti AES dan sebuah kunci sesi yang telah disepakati
- [ ] kunci privat server
:::

:::quiz mc
Kamu membuka `https://www.biberbank.de/` dan peramban melaporkan "Sertifikat ini diterbitkan untuk `www.gewinn-biber.de`". Apa yang kamu lakukan?
- [ ] Klik "Tetap lanjutkan" — toh koneksinya tetap terenkripsi
- [x] Batalkan — mungkin peramban sama sekali tidak sedang berkomunikasi dengan bank
- [ ] Membuka halaman melalui `http://`, maka peringatan tidak akan muncul
:::

:::quiz multi
Pernyataan mana yang benar?
- [x] Nilai hash berubah total jika data berubah sedikit saja
- [x] Tanda tangan dibuat dengan kunci privat dan diperiksa dengan kunci publik
- [x] Root CA sudah terpasang sebelumnya di peramban atau sistem operasi
- [ ] Pada HTTPS, penyadap bahkan tidak dapat melihat alamat IP server
- [ ] SMTPS juga mengenkripsi email di dalam server email
:::

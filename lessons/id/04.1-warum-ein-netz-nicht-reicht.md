# Mengapa satu jaringan tidak cukup

:::sim
url=/sims/lesson-4.1.btsim
:::

Di Area kerja kamu melihat dua jaringan perusahaan kecil: **Firma A** dengan Anna (`192.168.0.10`) dan Ben (`192.168.0.11`), serta **Firma B** dengan Clara (`172.16.0.10`) dan David (`172.16.0.11`). Kedua switch itu bahkan terhubung langsung dengan satu kabel.

## Ping di jaringan sendiri

1. Beralihlah ke Mode Jalankan :fa-play: **Jalankan**, buka :fa-terminal: **Terminal** di **Anna**, lalu ping Ben:
   ```
   $ ping 192.168.0.11
   ```
2. Beralihlah ke Mode :fa-magnifying-glass: **Jejak**, buka sebuah trace untuk **Anna**, lalu klik salah satu `Echo (ping) request`.
3. Buka baris **Internet Protocol Version 4** di Pohon protokol. Itu adalah bagian IP dari paket — bagian yang menjadi topik bab ini.

:::quiz match
Source Address -> Alamat IP pengirim
Destination Address -> Alamat IP penerima
Time to Live -> Berapa banyak router yang masih boleh dilewati paket
Protocol -> Protokol mana yang ada di dalam paket (di sini ICMP, yaitu ping)
:::

Periksa pasangan
:::

## Ping ke jaringan lain

Beralihlah kembali ke Mode Jalankan :fa-play: **Jalankan**, lalu ping Clara dari **Anna** (`ping 172.16.0.10`). Setelah itu, lihat sekali lagi trace milik Anna.

:::quiz mc
Apa yang terjadi?
- [ ] Ping berhasil — bukankah kedua switch itu terhubung
- [x] Tidak ada ping yang sampai, dan di trace Anna tidak muncul satu pun paket ke Clara — bahkan tidak ada permintaan ARP
- [ ] Anna mengirim permintaan ARP, tetapi Clara tidak membalas
:::

:::quiz mc
Mengapa Anna sama sekali tidak mengirim apa pun?
- [ ] Kabel di antara kedua switch rusak
- [ ] Clara dimatikan
- [x] Anna dapat mengetahui dari alamat IP Clara bahwa Clara berada di jaringan lain — dan tidak tahu jalan ke sana
:::

## Apa yang ada di baliknya

Alamat IP bekerja mirip dengan alamat pos: satu bagian menyatakan di **jaringan** mana sebuah perangkat berada (seperti nama jalan), bagian lainnya menyatakan **perangkat** mana di jaringan itu yang dimaksud (seperti nomor rumah). Anna berada di jaringan `192.168.0…`, Clara di jaringan `172.16.0…` — dua "jalan" yang berbeda.

Ke perangkat di jaringan *sendiri*, sebuah PC mengirim paket secara langsung (melalui ARP dan switch, seperti yang sudah kamu kenal). Untuk jaringan *lain*, ia membutuhkan perangkat yang menghubungkan jaringan-jaringan itu dan meneruskan paket: sebuah **router**. Di sini belum ada router — karena itu kabel di antara kedua switch pun tidak membantu.

:::tip Poin penting
**Internet Protocol** (**IP**) di Lapisan 3 memastikan paket dapat sampai, bahkan di antara jaringan yang berbeda. Sebuah **alamat IP** terdiri dari **Bagian jaringan** (di jaringan mana?) dan **Bagian host** (perangkat mana?). Perangkat di jaringan yang sama saling menjangkau secara langsung — untuk jaringan lain diperlukan sebuah **router**.
:::

Dengan demikian muncul dua pertanyaan yang akan dibahas di bagian-bagian berikutnya: dari mana sebuah PC tahu *di mana tepatnya* dalam alamat itu Bagian jaringan berakhir? Dan bagaimana cara kerja sebuah router?

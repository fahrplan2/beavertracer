# Menyiapkan server DHCP

:::sim
url=/sims/lesson-6.4.2.btsim
:::

Kali ini server DHCP belum disiapkan. Kamu yang menentukan pengaturan apa saja yang dibagikannya:

| Pengaturan | Nilai |
|---|---|
| Rentang alamat | `192.168.0.100` sampai `192.168.0.120` |
| Gateway | `192.168.0.1` |
| Server DNS | `192.168.0.53` |

1. Beralihlah ke :fa-play: **Jalankan**-Mode, klik **DHCP-Server**, lalu buka aplikasi **DHCP-Server**.
2. Isi **Awal rentang**, **Akhir rentang**, **Gateway**, dan **DNS-Server**, klik **Simpan**, lalu klik **Mulai**.
3. Pada **Laptop 1** dan **Laptop 2**, atur mode di :fa-gear: **Pengaturan IP** menjadi **DHCP**, lalu klik **Terapkan** pada masing-masing laptop.
4. Periksa di server DHCP pada Tab **Leases** siapa yang mendapat alamat yang mana.

:::note
Rentang alamat dipilih agar tidak bertabrakan dengan alamat tetap: server, router, dan printer sering kali mendapat alamat tetap di luar rentang DHCP — di sini misalnya server DHCP itu sendiri dengan `192.168.0.2`.
:::

:::task
title: DHCP sudah disiapkan?
Memeriksa apakah kedua laptop mendapat alamat dari rentang DHCP dan dapat menjangkau server DHCP. Untuk itu, simulasi harus berjalan di Mode Jalankan.
check: ip(3, "192.168.0.96/27")
check: ip(4, "192.168.0.96/27")
check: pingOk(3, 2)
check: pingOk(4, 2)
:::

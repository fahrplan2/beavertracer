# Pemanggilan halaman web

:::goal
**Tujuan pembelajaran:** Kamu akan merasakan betapa kompleksnya proses membuka sebuah halaman web dan dapat menyebutkan protokol apa saja yang terlibat serta urutannya.
:::

Membuka halaman web terasa bagi kita seperti satu kali klik saja. Di halaman berikutnya kamu akan bekerja dengan simulasi yang sudah disiapkan, mengamati di Tracer betapa banyak proses yang terjadi di baliknya, dan menyusun protokol-protokol yang terlibat.

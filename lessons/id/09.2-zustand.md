# Stateless atau stateful

Sebuah koneksi selalu terdiri dari **dua arah**: PC guru mengirim permintaan ke server web di internet — dan server web mengirim kembali halaman webnya. Jadi, firewall dengan prinsip whitelist tidak hanya harus mengizinkan permintaan lewat, tetapi juga **balasannya**.

Untuk itu ada dua jenis penyaring paket:

| | **Stateless** (*tanpa status*) | **Stateful** (*dengan status*) |
|---|---|---|
| Cara kerja | memeriksa setiap paket satu per satu, tanpa memori | mengingat koneksi yang diizinkan dalam **tabel status** |
| Balasan | membutuhkan aturan tersendiri untuk arah sebaliknya | otomatis diizinkan lewat, karena termasuk dalam koneksi yang dikenal |
| Penggunaan | perangkat sederhana, penyaring yang sangat cepat | hampir setiap firewall zaman sekarang |

Pada dua bagian berikutnya, kamu akan mengalami sendiri mengapa penyaring stateless mengalami masalah dengan balasan — dan bagaimana firewall stateful mengatasinya.

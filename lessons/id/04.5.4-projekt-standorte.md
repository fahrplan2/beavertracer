# Proyek: perusahaan dengan empat lokasi

:::sim
url=/sims/lesson-4.5.4.btsim
:::

Sebuah perusahaan memiliki kantor pusat di **Hanau** dan cabang di **Kassel**, **Gießen**, dan **Darmstadt**. Setiap lokasi memiliki jaringan sendiri dan router sendiri. Semua router terhubung melalui jalur sewa (leased line) ke sebuah **jaringan pusat**, tempat server utama perusahaan juga berada.

## Rencana alamat

Administrator telah memberikan alamat sesuai skema berikut — alamat-alamat itu sudah dimasukkan di dalam simulasi:

| Jaringan | Rentang alamat |
|---|---|
| Jaringan pusat | `10.19.0.0/24` |
| Hanau | `10.19.1.0/24` |
| Kassel | `10.19.2.0/24` |
| Gießen | `10.19.3.0/24` |
| Darmstadt | `10.19.4.0/24` |

| Perangkat | di jaringan pusat | di jaringan lokasi |
|---|---|---|
| Server | `10.19.0.10` | — |
| Router Hanau | `10.19.0.1` | `10.19.1.1` |
| Router Kassel | `10.19.0.2` | `10.19.2.1` |
| Router Gießen | `10.19.0.3` | `10.19.3.1` |
| Router Darmstadt | `10.19.0.4` | `10.19.4.1` |
| PC di lokasi | — | masing-masing `.2` (misalnya PC Kassel `10.19.2.2`) |

Pada semua router, `eth0` mengarah ke jaringan pusat dan `eth1` ke jaringan lokasi.

## Tugasmu

Agar semua komputer perusahaan dapat saling terhubung dan menjangkau server, masih ada dua hal yang kurang:

1. **Gateway:** Isikan gateway pada keempat PC dan pada server. PC memakai router lokasinya masing-masing; server memakai **Router Hanau**.
2. **Tabel routing:** Lengkapi pada keempat router rute-rute yang masih kurang. Setiap router harus mengenal jaringan dari **tiga lokasi lainnya**.

Uji di sela-sela pekerjaan dengan `ping` dan `traceroute`.

<details>
<summary>Petunjuk: Seperti apa bentuk sebuah rute di sini?</summary>

Contoh untuk **Router Kassel**: Paket untuk Gießen (`10.19.3.0/24`) dikirim ke Router Gießen di jaringan pusatnya — jadi **Next Hop** `10.19.0.3`, **Iface** `eth0`. Dengan pola ini, setiap router membutuhkan tiga rute.
</details>

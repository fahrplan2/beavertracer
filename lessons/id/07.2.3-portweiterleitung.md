# Dari luar ke dalam: penerusan port

:::sim
url=/sims/lesson-7.2.3.btsim
:::

Di jaringan rumah sekarang ada **Heim-Webserver** sendiri (`192.168.178.10`). Clara ingin membuka halamannya saat sedang bepergian — laptopnya, **Clara**, terhubung ke internet di sisi kanan.

## Masalahnya

1. Pindah ke :fa-play: **Jalankan** (Mode Jalankan), lalu buka `http://203.0.113.2/` di :fa-globe: **Peramban** pada **Clara** — alamat publik jaringan rumah.
2. Peramban menunggu terus tanpa hasil. Setelah beberapa detik, klik **Stopp**.
3. Di Mode :fa-magnifying-glass: **Jejak**, buka sebuah trace untuk **Heimrouter**, antarmuka `wan0`.

:::quiz mc
Apa yang terjadi dengan pembentukan koneksi Clara (`[SYN]` ke port 80)?
- [x] Paket itu sampai di router rumah — tetapi router tidak meneruskannya dan tidak membalas
- [ ] Paket itu sampai di server web rumah, yang membalas dengan RST
- [ ] Paket itu bahkan tidak sampai di router rumah
:::

:::evaluate
Periksa jawaban
:::

Untuk paket yang datang dari luar, tidak ada entri di tabel NAT: tidak ada seorang pun di jaringan rumah yang memulai koneksi ini. Router rumah tidak tahu ke perangkat mana paket itu harus dikirim — lalu membuangnya.

## Mengatur penerusan port

Dengan **penerusan port** (di beberapa router disebut *Port FW*) kamu menentukan: semua yang tiba di port WAN tertentu diteruskan ke perangkat tertentu di jaringan rumah.

1. Klik **Heimrouter** dan buka Tab **Port FW**.
2. Buat sebuah aturan: protokol `TCP`, port WAN `80`, IP LAN `192.168.178.10`, port LAN `80`, lalu klik **+ Hinzufügen**.
3. Buka `http://203.0.113.2/` sekali lagi di **Clara**.

:::task
title: Server web rumah bisa dijangkau dari luar?
Memeriksa apakah Clara dari internet dapat membentuk koneksi ke port 80 pada alamat publik jaringan rumah. Untuk itu, simulasi harus berjalan di Mode Jalankan.
check: tcpOpen(12, "203.0.113.2", 80)
:::

:::warning
Penerusan port membuka celah ke dalam: siapa pun di internet dapat menjangkau perangkat di baliknya — termasuk penyerang yang secara otomatis mencari port terbuka. Karena itu, teruskan hanya yang benar-benar diperlukan, dan jaga agar perangkat selalu diperbarui. Selengkapnya di bab 9 (firewall).
:::

:::tip Poin penting
Dari luar, tidak ada yang bisa memulai koneksi ke perangkat di balik NAT — router tidak tahu harus meneruskannya ke mana. **Penerusan port** menentukan: paket pada **port WAN** tertentu diteruskan ke **IP LAN** tertentu (dan port LAN). Dengan begitu, server di jaringan rumah dapat dijangkau dari internet.
:::

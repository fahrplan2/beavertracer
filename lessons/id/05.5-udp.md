# UDP: penyederhanaan besar-besaran

:::goal
**Tujuan pembelajaran:** Kamu dapat membandingkan UDP dengan TCP dan menjelaskan untuk aplikasi apa UDP menjadi pilihan yang lebih baik.
:::

:::sim
url=/sims/lesson-5.5.btsim
:::

TCP melakukan banyak hal — pembentukan koneksi, konfirmasi, pengiriman ulang, dan pengurutan. Namun, semua itu memakan waktu dan membutuhkan paket tambahan. Protokol penting kedua pada lapisan transport meninggalkan hampir semuanya: **User Datagram Protocol** (**UDP**). Paketnya disebut **datagram**.

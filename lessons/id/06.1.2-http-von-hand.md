# HTTP secara manual

:::sim

:::

Kalau HTTP hanyalah teks biasa — apakah kita juga bisa berbicara sendiri dengan server web, tanpa peramban sama sekali? Bisa: dengan `telnet` kamu membuat koneksi TCP ke port mana pun dan mengetik teksnya sendiri.

## Eksperimen

1. Beralihlah ke Mode Jalankan :fa-play: **Jalankan** dan buka :fa-terminal: **Terminal** pada **Client-PC**.
2. Hubungkan ke port 80 pada server:
   ```
   $ telnet 192.168.0.20 80
   ```
3. Ketik permintaan baris demi baris — lalu akhiri dengan **baris kosong** (cukup tekan **Enter** sekali lagi):
   ```
   GET /kontakt.html HTTP/1.1
   Host: 192.168.0.20

   ```

Server menjawab dengan baris status, header, dan halaman kontak — sebagai teks, persis seperti yang diterima peramban.

:::quiz mc
Dari mana server tahu bahwa permintaanmu sudah selesai?
- [ ] Dari perintah khusus `END`
- [x] Dari baris kosong
- [ ] Setelah waktu tertentu
:::

:::quiz short
Nilai apa yang ada pada header `Content-Type` di dalam respons? (hanya bagian pertama sebelum `;`)
= text/html
:::

## Memancing kesalahan

Alat yang lebih praktis adalah `curl`: alat ini membuatkan permintaan untukmu. Dengan `-v` (*verbose*, rinci) alat ini menampilkan semua yang dikirim bolak-balik — baris dengan `>` dikirim oleh `curl`, baris dengan `<` datang dari server.

Cobalah:

```
$ curl -v http://192.168.0.20/gibtsnicht.html
$ curl -X POST -d name=Anna http://192.168.0.20/
```

:::quiz short
Kode status apa yang kamu dapatkan untuk `/gibtsnicht.html`?
= 404
:::

:::quiz short
Dan kode status apa untuk permintaan dengan metode `POST`?
= 405
:::

:::note
Server web di BeaverTracer hanya bisa menyajikan file — karena itu server ini hanya mengizinkan `GET` dan `HEAD`. Server web sungguhan menerima, misalnya, formulir dengan `POST` dan meneruskan datanya ke sebuah program.
:::

:::tip Poin penting
Banyak protokol Lapisan aplikasi bersifat **berbasis teks** — HTTP, tetapi juga SMTP, POP3, dan IMAP. Karena itu, protokol-protokol ini bisa dijalankan secara manual dengan `telnet` dan dibaca di Tracer. Ini praktis untuk pemecahan masalah — tetapi juga masalah keamanan: siapa pun yang merekam lalu lintas data dapat membaca semuanya. Bagaimana enkripsi (HTTPS) membantu, akan kamu pelajari di bab 8.
:::

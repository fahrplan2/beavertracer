# Mendapatkan alamat secara otomatis

:::sim
url=/sims/lesson-6.4.btsim
:::

Pada switch terhubung sebuah **Server DHCP** dan dua laptop. Laptop-laptop tersebut masih memakai alamat tetap.

## Eksperimen

1. Beralih ke :fa-play: Mode Jalankan, klik **Laptop 1**, lalu buka :fa-gear: **Pengaturan IP**.
2. Ubah **Mode** dari **Statis** menjadi **DHCP**, lalu klik **Terapkan**.
3. Tunggu beberapa detik: kolom-kolomnya terisi dengan sendirinya.
4. Di mode :fa-magnifying-glass: **Jejak**, buka sebuah trace untuk **Laptop 1**.

:::quiz table
| Pengaturan | diterima dari Server DHCP |
|---|---|
| Alamat IP | {192.168.0.100} |
| Gateway | {192.168.0.1} |
| Server DNS | {192.168.0.53} |
:::

:::quiz short
Berapa banyak paket DHCP yang kamu temukan di trace?
= 4
= empat
:::

:::quiz mc
Ke alamat IP tujuan mana Laptop 1 mengirim paket pertamanya (`DHCP Discover`)?
- [ ] Ke Server DHCP `192.168.0.2`
- [x] Ke `255.255.255.255` — ke semua perangkat (broadcast)
- [ ] Ke gateway `192.168.0.1`
:::

:::quiz mc
Alamat IP pengirim apa yang dimiliki paket pertama ini — dan mengapa?
- [x] `0.0.0.0` — laptop belum punya alamat sama sekali
- [ ] `192.168.0.10` — alamat lamanya
- [ ] `192.168.0.100` — alamat barunya
:::

## Di balik proses ini: DORA

Perangkat tanpa alamat tidak tahu di mana Server DHCP berada, dan ia juga belum punya alamat pengirim sendiri. Karena itu, ia berteriak ke dalam jaringan lewat **broadcast**. Prosesnya terdiri dari empat langkah — dinamai menurut huruf awalnya, yaitu **DORA**:

:::seq
mode: text
Laptop 1 -> DHCP-Server: DHCP Discover | „Apakah ada Server DHCP di sini?“
DHCP-Server -> Laptop 1: DHCP Offer | „Kamu bisa memakai 192.168.0.100.“
Laptop 1 -> DHCP-Server: DHCP Request | „Aku ambil 192.168.0.100.“
DHCP-Server -> Laptop 1: DHCP ACK | „Dikonfirmasi — berlaku selama 3600 detik.“
:::

Alamat tersebut hanya **dipinjam** (*lease*): setelah **waktu lease** habis, perangkat harus memperpanjangnya, jika tidak server boleh memberikannya kembali kepada perangkat lain. Alamat mana saja yang sedang dipinjamkan dapat kamu lihat di **Server DHCP** pada tab **Leases**.

:::tip Coba sendiri
Atur **Laptop 2** juga ke DHCP. Alamat apa yang ia dapatkan? Setelah itu, lihat **Leases** pada Server DHCP.
:::

:::tip Poin penting
**DHCP** membagikan alamat IP, netmask, gateway, dan server DNS secara otomatis. Prosesnya disebut **DORA**: **D**iscover (klien mencari lewat broadcast), **O**ffer (server menawarkan), **R**equest (klien menerima), **A**CK (server mengonfirmasi). Alamat dipinjam selama **waktu lease**. DHCP menggunakan **UDP**, port 67 (server) dan 68 (klien).
:::

:::quiz match
Discover -> Klien mencari Server DHCP lewat broadcast
Offer -> Server menawarkan sebuah alamat
Request -> Klien meminta alamat yang ditawarkan
ACK -> Server mengonfirmasi pemberian alamat
:::

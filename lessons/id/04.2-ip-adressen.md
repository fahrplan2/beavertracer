# Alamat IP dan netmask

:::goal
**Tujuan pembelajaran:** Kamu dapat mengonversi bilangan antara sistem desimal dan sistem biner, menentukan bagian jaringan dan bagian host dari sebuah alamat IP dengan netmask, serta menghitung alamat jaringan, alamat broadcast, dan jumlah host dalam sebuah jaringan.
:::

:::sim
empty
:::

Apakah sebuah alamat berada di jaringan sendiri atau tidak, tidak ditentukan oleh PC menggunakan bilangan desimal seperti `192.168.0.10`, melainkan bit demi bit. Agar kamu dapat memahaminya, kamu membutuhkan **sistem biner** — dan di sinilah bagian ini dimulai.

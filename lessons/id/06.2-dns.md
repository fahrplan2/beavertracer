# DNS: nama, bukan angka

:::goal
**Tujuan pembelajaran:** Kamu dapat menjelaskan bagaimana DNS menerjemahkan nama menjadi alamat IP, bagaimana nama-nama tersebut diorganisasi secara hierarkis, membuat sebuah entri sendiri, dan menemukan kesalahan DNS yang umum.
:::

:::sim
url=/sims/lesson-6.2.btsim
:::

Hampir tidak ada orang yang bisa mengingat alamat IP — tetapi nama seperti `www.beaver-schule.de` pasti bisa. Penerjemahannya dilakukan oleh **Domain Name System** (**DNS**), semacam buku telepon dunia untuk internet.

Di Area kerja sekarang ada jaringan yang sedikit lebih besar: selain **Client-PC** dan **Webserver**, ada empat **DNS-Server**. Untuk apa server sebanyak itu, kamu akan melihatnya dua halaman setelah ini.

2. Di Mode :fa-magnifying-glass: **Jejak**, buka satu trace untuk **PC** dan satu trace lagi untuk server web **www.beispiel.de**.

## Apa yang terjadi di baliknya

Router rumah menukar alamat pengirim privat di setiap paket yang menuju ke internet dengan **alamat WAN publik** miliknya sendiri — dan biasanya port pengirimnya juga. Bagi server web, tampaknya permintaan itu berasal dari router rumah. Ketika balasan kembali, router rumah menukar alamatnya lagi dan meneruskan paket ke PC.

Dengan begitu, seluruh jaringan rumah dapat terhubung ke internet dengan satu alamat publik saja — dan perangkat di internet tidak pernah melihat alamat privatnya.

## Jalur menuju internet

Ketik di **PC** pada :fa-terminal: **Terminal**:

```
$ traceroute 192.0.2.80
```

:::quiz short

= 4
= empat
:::

:::tip Poin penting
**NAT** (*Network Address Translation*) mengganti alamat pengirim **privat** milik suatu perangkat dengan **alamat WAN publik** router saat menuju internet — dan sebaliknya pada balasan. Dengan begitu, semua perangkat di jaringan rumah berbagi **satu** alamat IPv4 publik. Ini menghemat alamat dan menyembunyikan alamat privat dari internet.
:::

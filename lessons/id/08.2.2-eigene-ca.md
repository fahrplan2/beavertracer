# Membangun CA sendiri

:::sim
url=/sims/lesson-8.2.2.btsim
:::

Untuk `www.beaver-schule.de` belum ada sertifikat. Daripada mengajukannya ke CA komersial, sekolah membangun **CA sendiri**: yaitu **Schul-CA**. Hal ini dilakukan banyak perusahaan dan sekolah untuk server internal mereka.

Pada kenyataannya, Schul-CA akan berjalan di komputer tersendiri yang dilindungi dengan sangat baik. Di sini kamu memainkan semua peran langsung di server web.

## Langkah 1: membuat Schul-CA

1. Beralihlah ke :fa-play: Mode **Jalankan** lalu buka :fa-shield-halved: **Zertifikatverwaltung** di server web **www.beaver-schule.de**.
2. Di Tab **Generieren**:
    - **Common Name:** `Schul-CA`
    - **Typ:** Selbstsigniert
    - Centang **Dies ist ein CA-Zertifikat**
    - **Speichern unter:** `schul-ca.cert.json`
3. Klik **Zertifikat generieren**.

Dengan begitu terbentuk sebuah **pasangan kunci** baru. Sertifikat berisi kunci publik; kunci privat tetap berada di dalam berkas pada server web.

## Langkah 2: menerbitkan sertifikat server

Kembali di Tab **Generieren**:

- **Common Name:** `www.beaver-schule.de` — persis nama yang diketik di peramban
- **Typ:** Von CA signiert, **Signierende CA:** Schul-CA
- **Speichern unter:** misalnya `www.beaver-schule.de.cert.json`

Di Tab **Meine Zertifikate** kamu sekarang melihat kedua sertifikat. Klik sertifikat server yang baru:

:::quiz short
Siapa **Aussteller** (penerbit) dari sertifikat server (tanpa `CN=`)?
= Schul-CA
:::

:::quiz mc
Bagaimana bunyi **Kette** (rantai)-nya?
- [x] `www.beaver-schule.de ← Schul-CA`
- [ ] `Schul-CA ← www.beaver-schule.de`
- [ ] `www.beaver-schule.de` (selbstsigniert)
:::

:::evaluate
Periksa jawaban
:::

## Langkah 3: memperkenalkan Schul-CA ke klien

PC klien belum mengenal Schul-CA — di peramban miliknya, CA ini tidak terpasang sebelumnya. Kamu harus memberinya sertifikat CA tersebut, dan itu **tanpa kunci privat**:

1. Di server web, pilih **Schul-CA** pada **Meine Zertifikate** lalu klik **Kopieren** (bukan *Kopieren + Schlüssel*!).
2. Di **PC klien**, buka :fa-shield-halved: **Zertifikatverwaltung**, Tab **Vertrauenswürdige CAs**.
3. Klik **Einfügen: Schul-CA**.

:::warning
**Kunci privat CA** adalah rahasia paling berharga dari seluruh sistem: siapa pun yang memilikinya dapat menerbitkan sertifikat untuk nama **apa saja**, dan semua klien akan memercayainya. Kunci ini tidak boleh pernah meninggalkan komputer CA.
:::

:::task
title: Schul-CA sudah disiapkan?
Periksa apakah di server web ada sertifikat untuk www.beaver-schule.de yang diterbitkan oleh Schul-CA dan apakah PC klien memercayai Schul-CA.
check: hasCert(4, "www.beaver-schule.de", "Schul-CA")
check: trusts(2, "Schul-CA")
:::

:::quiz mc
Mengapa untuk klien kamu hanya menyalin sertifikat **tanpa** kunci privat?
- [ ] Karena menyalin dengan kunci memakan waktu lebih lama
- [x] Untuk memeriksa tanda tangan, kunci publik sudah cukup; dengan kunci privat, siapa pun di klien dapat menerbitkan sertifikat sendiri
- [ ] Karena klien tidak dapat membentuk koneksi jika tidak demikian
:::

Periksa jawaban
:::

Server web itu sendiri belum kamu ubah — ia masih hanya berbicara HTTP. Cara mengaktifkan HTTPS akan kamu pelajari di bagian 8.3.3.

:::tip Poin penting
**CA sendiri** terdiri dari **sertifikat CA yang ditandatangani sendiri** beserta kunci privat. Dengannya orang menerbitkan **sertifikat server** yang Common Name-nya sesuai dengan nama server. Agar klien memercayai sertifikat-sertifikat ini, mereka diberi **sertifikat CA tanpa kunci privat** dalam daftar **CA tepercaya** mereka.
:::

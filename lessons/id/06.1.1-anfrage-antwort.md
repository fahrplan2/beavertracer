## Seperti apa bentuk sebuah permintaan

Klik paket `GET / HTTP/1.1` di trace, lalu buka **Hypertext Transfer Protocol**. Sebuah permintaan HTTP berupa teks biasa:

```
GET / HTTP/1.1              ← Methode, Pfad, Version
Host: 192.168.0.20          ← Header: zusätzliche Angaben
…
                            ← Leerzeile: Ende der Anfrage
```

Respons dari server memiliki struktur yang sama — dengan baris status, header, baris kosong, dan setelah itu berkas yang sebenarnya:

```
HTTP/1.1 200 OK             ← Version, Statuscode, Text
Content-Type: text/html     ← Header: Art der Datei
Content-Length: 301         ← Header: Größe in Byte
                            ← Leerzeile
<!doctype html> …           ← die Datei selbst
```

:::seq
mode: text
Client-PC -> Server: GET / | Permintaan HTTP
Server -> Client-PC: 200 OK | index.html
Client-PC -> Server: GET /style.css | Permintaan HTTP
Server -> Client-PC: 200 OK | style.css
:::

## Metode dan kode status

**Metode** menyatakan apa yang diinginkan klien:

| Metode | Arti |
|---|---|
| **GET** | mengambil sebuah berkas |
| **POST** | mengirim data ke server, misalnya formulir yang sudah diisi |
| **HEAD** | hanya mengambil header, tanpa berkasnya |

**Kode status** menyatakan bagaimana hasilnya. Angka pertama menunjukkan jenis respons:

| Kode | Teks | Arti |
|---|---|---|
| **200** | OK | semuanya baik-baik saja |
| **301** | Moved Permanently | halaman telah dipindahkan secara permanen |
| **404** | Not Found | berkas tersebut tidak ada |
| **405** | Method Not Allowed | metode ini tidak diizinkan di sini |
| **500** | Internal Server Error | terjadi kesalahan pada server |

`2xx` berarti berhasil, `3xx` pengalihan, `4xx` kesalahan pada klien (permintaan salah), `5xx` kesalahan pada server.

:::tip Poin penting
**HTTP** bekerja menurut **prinsip permintaan–respons**: klien mengirim sebuah **permintaan** (metode seperti `GET`, path, header), server menjawab dengan **kode status** (misalnya `200 OK`, `404 Not Found`), header, dan berkasnya. Untuk setiap berkas dari sebuah halaman web ada permintaan tersendiri.
:::

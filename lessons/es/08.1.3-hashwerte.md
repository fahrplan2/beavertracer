# Valores hash: la huella digital de los datos

:::sim
url=/sims/lesson-8.1.3.btsim
:::

Una **función hash** calcula, a partir de una cantidad cualquiera de datos (una frase, un documento, una película entera), una cadena corta de caracteres de longitud fija: el **valor hash**. Funciona como una **huella digital**: los mismos datos dan siempre el mismo valor hash, y datos distintos dan un valor hash distinto.

La función hash más utilizada hoy en día se llama **SHA-256**. Su valor hash siempre tiene 256 bits de longitud, es decir, 64 caracteres como número hexadecimal.

## El experimento

En el **PC** hay tres archivos con un pequeño contrato de compraventa en la carpeta `/home`. Cambia al modo de ejecución :fa-play: **Ejecutar**, abre en el **PC** el :fa-terminal: **Terminal** e introduce:

```
$ cd /home
$ cat vertrag.txt vertrag-kopie.txt vertrag-neu.txt
$ sha256sum vertrag.txt vertrag-kopie.txt vertrag-neu.txt
```

## Propiedades de una función hash

| Propiedad | Significado |
|---|---|
| **longitud fija** | Sin importar el tamaño de los datos, el valor hash siempre tiene la misma longitud. |
| **determinista** | Los mismos datos dan siempre el mismo valor hash. |
| **efecto avalancha** | Incluso el cambio más pequeño produce un valor hash completamente distinto. |
| **función unidireccional** | A partir del valor hash **no** se pueden recalcular los datos. |
| **resistente a colisiones** | Es prácticamente imposible encontrar dos archivos distintos con el mismo valor hash. |

Una función hash **no es un cifrado**: no hay clave ni descifrado. Sirve para otro propósito: la **integridad**.

## ¿Para qué sirve?

- **Comprobar descargas:** Muchas páginas web indican, junto a un archivo, su valor SHA-256. Si el valor hash de tu archivo descargado coincide con él, el archivo no ha sido modificado por el camino.
- **Almacenar contraseñas:** Las buenas páginas web no guardan tu contraseña, sino solo un valor hash de ella. Al iniciar sesión se compara el valor hash de lo que introduces. Si la base de datos es robada, el ladrón no conoce las contraseñas de todos modos.
- **Firmas digitales:** En lugar de firmar un documento entero, se firma solo su valor hash; más sobre esto en la siguiente sección.

:::tip Recuerda
Una **función hash** (p. ej. **SHA-256**) calcula a partir de datos cualesquiera un **valor hash** de longitud fija: una **huella digital**. Incluso el cambio más pequeño produce un valor hash completamente distinto, y a partir del valor hash no se pueden recalcular los datos. Los valores hash garantizan la **integridad** de los datos.
:::

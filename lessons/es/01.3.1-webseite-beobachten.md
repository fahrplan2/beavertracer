# Abrir y observar una página web

Para esta parte no construyes nada tú mismo: en el área de trabajo hay una simulación preparada con un **Client-PC** y un **Webserver**.

## Abrir la página

1. Cambia al modo de ejecución :fa-play: **Ejecutar**.
2. En el **Client-PC**, abre la aplicación :fa-globe: **Navegador** y accede a la dirección del servidor web: `http://192.168.0.20/`.
3. Cambia al modo :fa-magnifying-glass: **Rastreo** y abre con **+** un trace para el **Client-PC**, conexión `eth0` — exactamente igual que con el ping.

:::note
Para una sola visita a una página son sorprendentemente muchos paquetes — bastantes más que con el ping. Obtener una página web es un proceso de varias etapas, no una acción única.
:::

## Leer la lista de paquetes

Todavía no tienes que saber qué hace exactamente cada protocolo. Todo lo que necesitas para las siguientes preguntas está en las columnas **Protocolo** e **Info**.

:::quiz mc
¿Qué protocolo aparece en la parte más alta de la lista?
- [x] ARP
- [ ] TCP
- [ ] HTTP
:::

:::quiz short
Cuenta: ¿cuántos paquetes **TCP** hay antes del primer paquete **HTTP**?
= 3
= tres
:::

:::quiz mc
¿Qué responde el servidor web a la solicitud del navegador? Mira la columna Info del segundo paquete HTTP.
- [ ] GET / HTTP/1.1
- [x] HTTP/1.1 200 OK
- [ ] 404 Not Found
:::

:::evaluate
Comprobar respuestas
:::

## Nombrar los protocolos implicados

A partir de tus observaciones ya puedes deducir qué protocolo se encargó de qué.

:::tip Consejo
Vuelve a leer las columnas **Info**: `Who has …?`, `[SYN]`, `[SYN, ACK]`, `[ACK]`, `GET /` y `200 OK` casi lo dicen todo.
:::

:::quiz match
ARP -> Pregunta a todos en la red: «¿Quién tiene la dirección IP 192.168.0.20?»
TCP -> Establece una conexión con tres paquetes cortos antes de que fluyan los datos
HTTP -> Solicita la página web (GET) y la devuelve (200 OK)
:::

:::evaluate
Comprobar asignación
:::

:::tip Recuerda
Abrir una página web transcurre en etapas: primero **encontrar** el servidor en la red (ARP), después **establecer** una conexión (TCP), luego **solicitar y entregar** la página (HTTP) — y al final **cerrar** de nuevo la conexión (los paquetes TCP con `[FIN]` al final de la lista).
:::

:::note
Esta vez has introducido directamente la dirección IP del servidor, por eso **DNS** (la «traducción» de nombres como `www.beispiel.de` a una dirección IP) todavía no ha entrado en juego. Lo veremos en el capítulo 6.
:::

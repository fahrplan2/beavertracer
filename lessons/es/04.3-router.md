# El router

:::goal
**Objetivo de aprendizaje:** Puedes explicar cómo un router conecta dos redes, configurar la puerta de enlace en un PC y justificar cuándo un PC entrega un paquete directamente y cuándo lo hace a través de la puerta de enlace.
:::

:::sim
url=/sims/lesson-4.3.1.btsim
:::

Un **router** conecta distintas redes entre sí. Para ello tiene una interfaz propia para cada red, y en cada interfaz una dirección IP propia perteneciente exactamente a esa red. En el área de trabajo ves de nuevo la Firma A y la Firma B, esta vez con un router entre ellas.

# NAT: muchos dispositivos, una sola dirección

:::goal
**Objetivo de aprendizaje:** Eres capaz de mostrar en el Tracer cómo NAT sustituye la dirección del remitente, de leer la tabla NAT y de explicar por qué las conexiones desde el exterior hacia la red doméstica necesitan un reenvío de puertos.
:::

:::sim
url=/sims/lesson-7.1.btsim
:::

Normalmente, el proveedor solo asigna a una conexión doméstica **una** dirección IPv4 pública: la dirección WAN del router doméstico. Todos los dispositivos de la red doméstica tienen que compartirla. Este mecanismo se llama **NAT** (*Network Address Translation*, traducción de direcciones de red).

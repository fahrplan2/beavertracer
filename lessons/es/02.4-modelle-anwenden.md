# Aplicar los modelos

Asigna los protocolos del experimento del comienzo del capítulo a su capa OSI:

:::quiz match
Ethernet -> Capa 2 — Enlace de datos
IPv4 -> Capa 3 — Red
TCP -> Capa 4 — Transporte
HTTP -> Capa 7 — Aplicación
:::

:::evaluate
Comprobar asignación
:::

Y para terminar, los nombres de las unidades de datos:

:::quiz match
Trama -> Capa 2 — Enlace de datos
Paquete -> Capa 3 — Red
Segmento -> Capa 4 — Transporte
:::

:::evaluate
Comprobar asignación
:::

Con esto ya tienes las herramientas para clasificar los protocolos correctamente a partir de ahora. A partir del próximo capítulo repasaremos las capas una por una, empezando por la capa 2 y la pregunta de cómo sabe realmente un switch hacia dónde debe reenviar un paquete.

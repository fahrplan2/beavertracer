# El sistema binario

En lo más profundo, un ordenador solo conoce dos estados: corriente encendida o corriente apagada. Para ello se escribe **1** y **0**. Cada una de estas posiciones se llama **bit**. También cada dirección IP es para el ordenador solo una sucesión de ceros y unos. Para que entiendas cómo funcionan las máscaras de red, en esta página aprenderás a leer estos números y a convertirlos tú mismo.

## Cómo contamos normalmente: el sistema decimal

En la vida diaria calculamos con diez cifras (de 0 a 9). Cada posición vale diez veces más que la posición situada a su derecha: unidades, decenas, centenas, millares. El número `305` significa, por tanto:

| Valor posicional | 100 | 10 | 1 |
|---|---|---|---|
| Cifra | 3 | 0 | 5 |
| Valor | 300 | 0 | 5 |

300 + 0 + 5 = **305**

## El sistema binario

En el **sistema binario** solo hay dos cifras: 0 y 1. Cada posición vale **el doble** que la posición situada a su derecha: 1, 2, 4, 8, 16, 32, 64, 128 …

El número binario `00001101` significa, por tanto:

| Valor posicional | 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1 |
|---|---|---|---|---|---|---|---|---|
| Bit | 0 | 0 | 0 | 0 | 1 | 1 | 0 | 1 |
| Valor | | | | | 8 | 4 | | 1 |

8 + 4 + 1 = **13**

Es decir, simplemente sumas los valores posicionales en los que hay un 1.

:::tip Recuerda
Un **bit** es una posición en el sistema binario (0 o 1). **8 bits** forman un **byte**; en redes, a este grupo de 8 bits también se le llama **octeto**. Los valores posicionales de un octeto son **128, 64, 32, 16, 8, 4, 2, 1**.
:::

## De decimal a binario

A la inversa, recorres los valores posicionales de izquierda a derecha y te preguntas cada vez: **¿cabe el valor posicional en mi número (restante)?** Si es así, escribes un 1 y restas el valor posicional. Si no, escribes un 0.

Ejemplo: `168`

| Valor posicional | ¿cabe en …? | Bit | Resto |
|---|---|---|---|
| 128 | 168 → sí | **1** | 40 |
| 64 | 40 → no | **0** | 40 |
| 32 | 40 → sí | **1** | 8 |
| 16 | 8 → no | **0** | 8 |
| 8 | 8 → sí | **1** | 0 |
| 4 | 0 → no | **0** | 0 |
| 2 | 0 → no | **0** | 0 |
| 1 | 0 → no | **0** | 0 |

Leído de arriba abajo: 168 = **10101000**

## Direcciones IP en el sistema binario

Una dirección IPv4 consta de **32 bits**, es decir, cuatro octetos. Como nadie puede memorizar 32 ceros y unos, cada octeto se escribe como un número decimal y se separan con puntos:

```
11000000 . 10101000 . 10110010 . 00000001
   192   .   168    .   178    .    1
```

:::quiz short

= 32
:::

:::quiz mc

:::

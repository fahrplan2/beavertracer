# Comparación entre HTTP y HTTPS

:::sim
url=/sims/lesson-8.2.1.btsim
:::

El servidor web **www.beaver-schule.de** ofrece el portal de notas del colegio tanto por HTTP como por HTTPS. ¿Qué ve alguien que esté escuchando la comunicación?

## El experimento

1. Cambia al :fa-play: modo de ejecución **Ejecutar** y, en el **Client-PC**, abre en el :fa-globe: **Navegador** primero `http://www.beaver-schule.de/` y después `https://www.beaver-schule.de/`.
2. En el :fa-magnifying-glass: modo **Rastreo**, abre un trace para el **Client-PC**.
3. Busca primero el paquete `HTTP/1.1 200 OK` y haz clic en él. Abajo, en los detalles, encontrarás el contenido de la página.

:::quiz mc
¿Qué puede ver alguien que escucha la comunicación con **HTTP**?
- [x] La página web completa, incluidas las notas de Anna
- [ ] Solo la dirección del servidor
- [ ] Nada, porque HTTP funciona sobre TCP
:::

:::quiz short
¿Qué nota tiene Anna en Matemáticas?
= 2
:::

:::evaluate
Verificar respuestas
:::

Ahora la parte de HTTPS. Busca el paquete `[SYN]` con el que el cliente inicia la segunda conexión.

:::quiz short
¿Cuál es el puerto de destino de la conexión HTTPS (columna **Info**, `… → ???`)?
= 443
:::

Ahora escribe `tls` arriba, en el campo de filtro del trace; así verás solo los paquetes TLS.

:::quiz mc
¿Qué aparece en la columna **Info** en los paquetes que contienen la página web?
- [ ] `HTTP/1.1 200 OK`
- [x] `Application Data`
- [ ] `Encrypted HTML`
:::

:::quiz multi
¿Qué puede seguir viendo, aun así, alguien que escucha la comunicación con **HTTPS**?
- [x] Las direcciones IP del cliente y del servidor
- [x] Que se usa el puerto 443, por lo que probablemente es HTTPS
- [x] Aproximadamente cuántos datos se transmiten
- [ ] Qué página se ha abierto y qué contiene
:::

:::evaluate
Verificar respuestas
:::

:::note
Haz clic en un paquete **Application Data**: los datos útiles son solo una secuencia de bytes aparentemente aleatorios. El Tracer no puede descifrarlos: conoce la clave de sesión tan poco como un atacante.
:::

:::tip Recuerda
Con **HTTP**, cualquiera que escuche la comunicación puede leer la página web completa. Con **HTTPS**, solo ve **quién habla con quién** (direcciones IP, puerto 443) y **cuántos datos** se intercambian; el contenido va cifrado dentro de paquetes **Application Data**.
:::

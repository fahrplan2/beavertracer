# Los tipos de direcciones más importantes

En IPv6 se puede reconocer por el comienzo de una dirección para qué sirve:

| Tipo de dirección | se reconoce por | para qué |
|---|---|---|
| **Link-local** | `fe80::` | Solo es válida en tu **propia red local**. Cada dispositivo se asigna esta dirección automáticamente — un router nunca la reenvía. |
| **Unicast global** | `2…` o `3…` (`2000::/3`) | Dirección única en todo el mundo, accesible en internet. El prefijo lo proporciona el proveedor de internet. |
| **Unique local** | `fd…` (`fc00::/7`) | Para redes privadas, comparable a `192.168.x.x` en IPv4. |
| **Loopback** | `::1` | El propio dispositivo — como `127.0.0.1` en IPv4. |
| **Multicast** | `ff…` | A un **grupo** de dispositivos, p. ej. `ff02::1` = todos los dispositivos de la red local. |

:::note
El rango `2001:db8::/32` está reservado para ejemplos y material didáctico — nunca aparece en el internet real. Por eso lo ves en este curso.
:::

Una novedad importante: **IPv6 ya no tiene broadcast.** Lo que en IPv4 era un broadcast a todos, en IPv6 se resuelve con direcciones **multicast** — el mensaje solo llega a los dispositivos interesados en ese grupo.

:::tip Recuerda
Todo dispositivo IPv6 tiene al menos una **dirección link-local** (`fe80::…`) para su propia red y, normalmente, además una **dirección global** para internet. En lugar de broadcast, IPv6 usa **multicast** (`ff…`).
:::

:::quiz match
fe80::a828:39ff:fee2:4182 -> Link-local — solo en la propia red
2001:db8:1::10 -> Unicast global — única en todo el mundo
::1 -> Loopback — el propio dispositivo
ff02::1 -> Multicast — todos los dispositivos de la red local
fd12:3456::1 -> Unique local — para redes privadas
:::

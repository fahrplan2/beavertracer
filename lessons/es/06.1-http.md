# HTTP: páginas web

:::goal
**Objetivo de aprendizaje:** Puedes describir la estructura de una solicitud y una respuesta HTTP, explicar los métodos y códigos de estado más importantes y realizar tú mismo una solicitud HTTP a mano.
:::

:::sim

:::

El **Hypertext Transfer Protocol** (**HTTP**) es el lenguaje con el que se comunican los navegadores y los servidores web. En el servidor se encuentra la página web de la **Beaver-Schule**: una página de inicio, una página de contacto y una hoja de estilos para el aspecto.

# La tabla NAT

:::sim
url=/sims/lesson-7.1.btsim
:::

Cuando el PC y la tableta cargan al mismo tiempo la misma página web, ambas solicitudes llegan al servidor web desde `203.0.113.2`. ¿Cómo sabe el router doméstico a quién va dirigida una respuesta? Lleva un registro: en la **tabla NAT**.

## El experimento

1. Cambia al modo de ejecución :fa-play: **Ejecutar** y abre `http://www.beispiel.de/` en el **PC** y en la **Tablet**.
2. Haz clic en el **Heimrouter** y abre la pestaña **NAT**.

Cada fila es una **asignación**: protocolo, IP LAN y puerto LAN del dispositivo en la red doméstica, y el **puerto WAN** que el router utiliza para ello en su dirección pública.

:::quiz short
¿Qué IP WAN aparece encima de la tabla?
= 203.0.113.2
:::

:::quiz mc
El PC y la tableta han establecido ambos una conexión con el puerto LAN `49152`. ¿Qué puerto WAN reciben?
- [ ] Ambos el mismo, `49152`
- [x] Cada uno uno distinto: de lo contrario, el router no sabría a quién pertenece la respuesta
- [ ] Ninguno, NAT solo cambia la dirección IP
:::

:::quiz mc
Una respuesta del servidor web llega a `203.0.113.2` con un **puerto de destino** concreto. ¿Qué hace el router doméstico con ella?
- [x] Busca el puerto en la tabla NAT y envía el paquete a la IP LAN y al puerto LAN correspondientes
- [ ] Envía el paquete a todos los dispositivos de la red doméstica
- [ ] Descarta el paquete
:::

:::evaluate
Comprobar respuestas
:::

Aquí vuelven a entrar en juego los **puertos** del capítulo 5: como NAT también reescribe los puertos, cientos de conexiones pueden compartir una misma dirección. Por eso, en sentido estricto, se habla de **PAT** (*Port Address Translation*) o de *NAT con traducción de puertos*; en el día a día, aun así, se dice simplemente NAT.

Así podría verse, por ejemplo, una traducción de este tipo:

| | Paquete del PC (en la red doméstica) | el mismo paquete en Internet |
|---|---|---|
| Remitente | `192.168.178.20 : 49152` | `203.0.113.2 : 10001` |
| Destinatario | `192.0.2.80 : 80` | `192.0.2.80 : 80` |

:::tip Recuerda
En la **tabla NAT**, el router anota para cada conexión qué dispositivo (**IP LAN y puerto LAN**) se encuentra detrás de qué **puerto WAN**. Las respuestas de Internet las asigna de nuevo al dispositivo correcto mediante el puerto de destino. Como también se reescriben los puertos, hablando con más precisión se trata de **PAT**.
:::

# DNS: nombres en lugar de números

:::goal
**Objetivo de aprendizaje:** Puedes explicar cómo DNS traduce nombres en direcciones IP, cómo están organizados jerárquicamente los nombres, crear tú mismo una entrada y encontrar errores típicos de DNS.
:::

:::sim
url=/sims/lesson-6.2.btsim
:::

Casi nadie puede recordar direcciones IP, pero nombres como `www.beaver-schule.de` sí. De la traducción se encarga el **Domain Name System** (**DNS**), una especie de guía telefónica mundial de internet.

En el área de trabajo hay ahora una red algo más grande: además del **Client-PC** y del **Webserver** hay cuatro **DNS-Server**. Para qué sirven tantos, lo verás dentro de dos páginas.

# Subnetting paso a paso

En esta sección los bits están marcados con colores: [[n|parte de red]] · [[e|extensión]] · [[h|parte de host]]

## La idea

Imagina un terreno grande que se va a dividir en parcelas del mismo tamaño. En el subnetting, el terreno grande es la red original y las parcelas son las subredes.

Técnicamente ocurre lo siguiente: una red consta de una parte de red y una parte de host. En el subnetting se toman algunos bits del **comienzo de la parte de host** y se añaden a la **parte de red**. Estos bits adicionales se llaman **extensión** (o *bits de subred*). Cada combinación posible de los bits de extensión da como resultado una subred propia.

<pre class="bits-block">
antes   (/24):  [[n|NNNNNNNN.NNNNNNNN.NNNNNNNN]].[[h|HHHHHHHH]]
después (/26):  [[n|NNNNNNNN.NNNNNNNN.NNNNNNNN]].[[e|EE]][[h|HHHHHH]]
</pre>

## ¿Cuántos bits se necesitan?

Con *n* bits de extensión hay 2*ⁿ* combinaciones, es decir, 2*ⁿ* subredes:

| Bits de extensión | Combinaciones | Subredes |
|---|---|---|
| 1 | 0, 1 | 2 |
| 2 | 00, 01, 10, 11 | 4 |
| 3 | 000, 001, … 111 | 8 |
| 4 | 0000 … 1111 | 16 |

Si, por ejemplo, se necesitan **tres** subredes, 1 bit (solo 2 redes) no es suficiente: se toman 2 bits y se obtienen **cuatro** subredes. Una queda como reserva.

## Ejemplo 1: dos subredes, con todo detalle

La red `192.168.42.0/24` se va a dividir en **dos** subredes del mismo tamaño.

**Paso 1 — ¿Cuántos bits?** Para 2 subredes basta con **1 bit** (2¹ = 2).

**Paso 2 — Nueva longitud de prefijo y máscara de red.** De `/24` se pasa a `/24 + 1 = /25`. Ahora la máscara tiene 25 unos:

<pre class="bits-block">
[[n|11111111.11111111.11111111]].[[e|1]][[h|0000000]]   →   255.255.255.128
</pre>

**Paso 3 — Escribir la dirección de red en sistema binario y marcarla.** Los tres primeros octetos no cambian. En el último octeto, el primer bit es la extensión (E) y el resto es la parte de host (H):

<pre class="bits-block">
[[n|192.168.42.]] [[e|0]] [[h|0 0 0 0 0 0 0]]
            [[e|E]] [[h|H H H H H H H]]
</pre>

**Paso 4 — Determinar la dirección de red y la dirección de broadcast para cada combinación de la extensión.** La extensión se pone una vez a 0 y otra vez a 1. Para la dirección de red todos los bits de host son 0; para la dirección de broadcast, todos son 1:

| Subred | E | Bits de host | último octeto | Dirección |
|---|---|---|---|---|
| 1 — dirección de red | [[e|0]] | [[h|0000000]] | 0 | `192.168.42.0` |
| 1 — dirección de broadcast | [[e|0]] | [[h|1111111]] | 127 | `192.168.42.127` |
| 2 — dirección de red | [[e|1]] | [[h|0000000]] | 128 | `192.168.42.128` |
| 2 — dirección de broadcast | [[e|1]] | [[h|1111111]] | 255 | `192.168.42.255` |

**Paso 5 — Anotar el resultado:**

| Subred | Dirección de red | Dirección de broadcast | Rango para hosts | Hosts |
|---|---|---|---|---|
| 1 | `192.168.42.0/25` | `192.168.42.127` | `.1` – `.126` | 126 |
| 2 | `192.168.42.128/25` | `192.168.42.255` | `.129` – `.254` | 126 |

## Ejemplo 2: cuatro subredes

La misma red `192.168.42.0/24`, esta vez en **cuatro** subredes.

**Paso 1:** 4 subredes → **2 bits** (2² = 4).

**Paso 2:** `/24 + 2 = /26`, máscara [[n|11111111.11111111.11111111]].[[e|11]][[h|000000]] = `255.255.255.192`.

**Paso 3:** En el último octeto, los primeros **dos** bits son ahora la extensión: [[e|EE]][[h|HHHHHH]].

**Paso 4:** La extensión cuenta hacia arriba en sistema binario: 00, 01, 10, 11. Para cada combinación pones los bits de host una vez a 0 y otra vez a 1:

| Subred | EE | Dirección de red (bits de host 0) | Dirección de broadcast (bits de host 1) |
|---|---|---|---|
| 1 | [[e|00]] | [[e|00]][[h|000000]] = **0** | [[e|00]][[h|111111]] = **63** |
| 2 | [[e|01]] | [[e|01]][[h|000000]] = **64** | [[e|01]][[h|111111]] = **127** |
| 3 | [[e|10]] | [[e|10]][[h|000000]] = **128** | [[e|10]][[h|111111]] = **191** |
| 4 | [[e|11]] | [[e|11]][[h|000000]] = **192** | [[e|11]][[h|111111]] = **255** |

**Paso 5 — Resultado:**

| Subred | Dirección de red | Dirección de broadcast | Rango para hosts |
|---|---|---|---|
| 1 | `192.168.42.0/26` | `192.168.42.63` | `.1` – `.62` |
| 2 | `192.168.42.64/26` | `192.168.42.127` | `.65` – `.126` |
| 3 | `192.168.42.128/26` | `192.168.42.191` | `.129` – `.190` |
| 4 | `192.168.42.192/26` | `192.168.42.255` | `.193` – `.254` |

Cada subred tiene 2⁶ = 64 direcciones, de las cuales 62 son para hosts.

¿Notas algo? Las subredes se suceden **una tras otra sin huecos**: cada una comienza justo después de la dirección de broadcast de la anterior. Y la dirección de broadcast de la última subred es exactamente la dirección de broadcast de la red original; así puedes comprobar tu resultado.

:::tip Recuerda: subnetting en cinco pasos
1. **¿Cuántas subredes?** Redondea hacia arriba a la siguiente potencia de dos → *n* bits de extensión.
2. **Nueva longitud de prefijo** = longitud de prefijo anterior + *n*; a partir de ella, la nueva **máscara de red**.
3. Escribe la **dirección de red en binario** y marca la parte de red, la extensión y la parte de host.
4. **Cuenta hacia arriba la extensión** (00, 01, 10, …): bits de host a 0 → dirección de red; bits de host a 1 → dirección de broadcast.
5. **Comprobación:** las subredes se suceden sin huecos y la última termina con la dirección de broadcast de la red original.
:::

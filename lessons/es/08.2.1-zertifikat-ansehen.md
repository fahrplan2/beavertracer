# Ver un certificado

:::sim
url=/sims/lesson-8.2.1.btsim
:::

En el área de trabajo ves el **Client-PC**, un **DNS-Server** y el servidor web de la escuela, `www.beaver-schule.de`. El servidor web también ofrece sus páginas mediante **HTTPS**.

## El candado en el navegador

1. Cambia al modo de ejecución :fa-play: **Ejecutar**, haz clic en el **Client-PC** y abre el :fa-globe: **Navegador**.
2. Abre `https://www.beaver-schule.de/` — fíjate en el **https**.
3. A la izquierda de la dirección aparece un **candado**. Haz clic en él.

:::quiz short
¿Para qué nombre se emitió el certificado (sujeto sin `CN=`)?
= www.beaver-schule.de
:::

:::quiz short
¿Quién emitió el certificado (emisor sin `CN=`)?
= Biber Root CA
:::

:::evaluate
Comprobar respuestas
:::

## ¿Por qué confía el Client-PC en el certificado?

En el **Client-PC**, abre la :fa-shield-halved: **Zertifikatverwaltung** y cambia a la pestaña **Vertrauenswürdige CAs**.

:::quiz mc
¿Qué encuentras allí?
- [x] El certificado de la **Biber Root CA**
- [ ] El certificado de `www.beaver-schule.de`
- [ ] Ninguna entrada
:::

:::quiz mc
¿Cómo se puede ver que la Biber Root CA es una CA raíz?
- [x] Está **autofirmada**: el sujeto y el emisor son iguales
- [ ] Su nombre termina en «CA»
- [ ] No tiene clave pública
:::

:::quiz mc
En el Client-PC, bajo **Privater Schlüssel**, ¿aparece «Ja» o «Nein»?
- [ ] «Ja»: el cliente necesita la clave privada de la CA para verificar firmas
- [x] «Nein»: para verificar basta con la clave pública; la clave privada solo la tiene la CA
:::

:::evaluate
Comprobar respuestas
:::

## La otra parte: el servidor web

Ahora abre en el servidor web **www.beaver-schule.de** la :fa-shield-halved: **Zertifikatverwaltung** (pestaña **Meine Zertifikate**) y observa su certificado.

:::quiz multi
¿Qué es correcto sobre el certificado del servidor web?
- [x] Bajo **Privater Schlüssel** aparece «Ja»: el servidor lo necesita para el establecimiento de conexión
- [x] La **cadena** es `www.beaver-schule.de ← Biber Root CA`
- [x] La **huella digital** es la misma que en la ventana del candado del navegador
- [ ] Está autofirmado
:::

:::evaluate
Comprobar respuestas
:::

:::note
La **huella digital** es un valor hash del certificado. Con ella se pueden comparar dos certificados rápidamente, sin tener que revisar uno por uno todos los campos.
:::

:::tip Recuerda
El **servidor web** posee su certificado **con clave privada**. El **cliente** solo conoce el **certificado de la CA raíz** (sin clave privada); eso le basta para verificar la firma del certificado del servidor. Al hacer clic en el **candado** del navegador se ven el sujeto, el emisor, la huella digital y la validez.
:::

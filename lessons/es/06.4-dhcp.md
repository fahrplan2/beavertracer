# DHCP: conectarse a la red automáticamente

:::goal
**Objetivo de aprendizaje:** Puedes explicar cómo un dispositivo obtiene automáticamente su configuración IP mediante DHCP, configurar un servidor DHCP y reconocer y solucionar errores típicos de DHCP (p. ej., una dirección 169.254).
:::

:::sim
url=/sims/lesson-6.4.btsim
:::

Hasta ahora has introducido a mano en cada dispositivo su dirección IP, la máscara de red, la puerta de enlace y el servidor DNS. En un colegio con cientos de portátiles, tablets y móviles eso sería imposible, y cada error de escritura sería un error en la red.

De este trabajo se encarga el **Dynamic Host Configuration Protocol** (**DHCP**): un **Servidor DHCP** distribuye automáticamente la configuración a cada dispositivo que entra en la red.

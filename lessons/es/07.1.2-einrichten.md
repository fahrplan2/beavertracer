# Configurar el router doméstico

:::sim
url=/sims/lesson-7.1.2.btsim
:::

Se acaba de conectar un router doméstico nuevo, pero todavía nadie puede acceder a Internet. Del proveedor has recibido una carta con los **datos de acceso**:

| Datos de acceso | Valor |
|---|---|
| Dirección IP WAN | `203.0.113.2` |
| Longitud de prefijo | `/30` |
| Gateway (router del proveedor) | `203.0.113.1` |
| Servidor DNS del proveedor | `198.51.100.10` |

1. Cambia al modo de ejecución :fa-play: **Ejecutar**, haz clic en el **Heimrouter** y abre la pestaña **WAN**.
2. Introduce los datos de acceso y haz clic en **Aplicar**.
3. Conecta la **Tablet** a la red WiFi: :fa-gear: **Configuración IP**, pestaña **WiFi**, SSID `Biberbau`, **Aplicar**.
4. Haz una prueba en el PC con `ping 192.0.2.80` o en el navegador con `http://www.beispiel.de/`.

:::note
En la práctica, el router doméstico suele recibir su dirección WAN automáticamente del proveedor (mediante DHCP o con un inicio de sesión con nombre de usuario y contraseña). Los datos de acceso fijos como aquí son más habituales en las conexiones de empresa.
:::

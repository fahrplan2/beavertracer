# ¿POP3 o IMAP?

:::sim
url=/sims/lesson-6.3.btsim
:::

Existen dos protocolos para recuperar el correo. En esta simulación, **Anna usa POP3** y **Ben usa IMAP**.

## El experimento

1. En el :fa-play: modo de ejecución (**Ejecutar**), envía un correo de **Ben** a `anna@beaver-schule.de`.
2. En **Anna**, en la aplicación **E-Mail**, haz clic en **Obtener**.
3. Abre los traces de **Anna** y de **Ben** y compara los comandos al recuperar el correo.

:::quiz match
USER / PASS -> POP3: iniciar sesión con nombre de usuario y contraseña en dos pasos
RETR -> POP3: descargar un mensaje
LOGIN -> IMAP: iniciar sesión con nombre de usuario y contraseña
SELECT INBOX -> IMAP: abrir una carpeta en el servidor
:::

Verificar asociación

## La diferencia

| | POP3 | IMAP |
|---|---|---|
| Puerto | 110 | 143 |
| Idea básica | **Descargar** los correos — después, normalmente se eliminan del servidor | Los correos **permanecen en el servidor** y se gestionan allí |
| Carpetas, leído/no leído | solo en el propio dispositivo | en el servidor — igual en todas partes |
| Varios dispositivos (móvil, portátil) | poco práctico: cada dispositivo tiene un estado distinto | ideal: todos los dispositivos ven el mismo buzón de correo |

:::note
El programa de correo de BeaverTracer deja los correos en el servidor también con POP3. Los programas reales suelen eliminarlos después de la descarga — o los dejan allí solo durante un tiempo.
:::

:::tip Recuerda
**POP3** descarga los correos del servidor a **un** dispositivo. **IMAP** gestiona el buzón de correo **en el servidor**, con carpetas y estado de lectura para todos los dispositivos a la vez. Ambos sirven solo para **recuperar** el correo; el envío se realiza siempre con **SMTP**.
:::

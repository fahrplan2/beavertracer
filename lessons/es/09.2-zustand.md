# Sin estado o con estado

Una conexión siempre consta de **dos direcciones**: el PC del profesor envía una solicitud a un servidor web en Internet, y el servidor web devuelve la página web. Por tanto, un firewall basado en el principio de la lista blanca no solo debe dejar pasar la solicitud, sino también la **respuesta**.

Para ello existen dos tipos de filtros de paquetes:

| | **Sin estado** (*stateless*) | **Con estado** (*stateful*) |
|---|---|---|
| Funcionamiento | examina cada paquete por separado, sin memoria | recuerda las conexiones permitidas en una **tabla de estados** |
| Respuestas | necesitan una regla propia para el sentido de retorno | se dejan pasar automáticamente, porque pertenecen a una conexión conocida |
| Uso | dispositivos sencillos, filtros muy rápidos | prácticamente todos los firewalls actuales |

En las dos secciones siguientes comprobarás por qué los filtros sin estado tienen problemas con las respuestas y cómo los resuelve un firewall con estado.

# Configurar HTTPS

:::sim
url=/sims/lesson-8.3.3.btsim

Aquí continuamos donde terminó la sección 8.2.2: en el servidor web **www.beaver-schule.de** están la **Schul-CA** y un certificado de servidor emitido por ella, y el **Client-PC** confía en la Schul-CA. Pero el servidor web todavía no habla HTTPS.

## Antes

Cambia al modo de ejecución :fa-play: **Ejecutar** y abre en el **Client-PC**, en el :fa-globe: **Navegador**, la dirección `https://www.beaver-schule.de/`.

:::quiz mc
¿Qué ocurre?
- [x] La conexión no se establece: ningún servicio escucha en el puerto 443
- [ ] El navegador avisa de un certificado no seguro
- [ ] La página se muestra sin candado
:::

Verificar respuesta

## Activar HTTPS

1. En el servidor web, abre el **Servidor HTTP** y haz clic en **Detener**: mientras el servidor esté en funcionamiento, no se pueden cambiar los ajustes.
2. Cambia a la pestaña **HTTPS**:
    - Marca la casilla **Activar HTTPS** y establece **Puerto HTTPS** `443`
    - En **Certificado**, selecciona el certificado de servidor `www.beaver-schule.de`, ¡no la Schul-CA!
    - Haz clic en **Usar**
3. Haz clic en **Iniciar**.

Vuelve a abrir la página en el Client-PC mediante `https://`. Haz clic en el candado y comprueba el emisor y la validez.

:::quiz mc
¿Por qué no debes seleccionar en el Servidor HTTP el certificado de la **Schul-CA**?
- [ ] Porque los certificados de CA no pueden cifrar
- [x] Porque está emitido para el nombre `Schul-CA`, no para `www.beaver-schule.de`: el navegador mostraría una advertencia
- [ ] Porque la Schul-CA no tiene clave privada

- [x] Una advertencia de certificado, porque no puede seguir la cadena de confianza hasta una CA conocida
- [ ] Nada en absoluto, porque la conexión es rechazada

:::note
Para los sitios web públicos se necesita un certificado de una CA que esté preinstalada en todos los navegadores. Desde 2015 existe **Let's Encrypt**, una CA que emite estos certificados de forma gratuita y automática, una de las razones principales por las que hoy casi todos los sitios web utilizan HTTPS.
:::

:::tip Recuerda
Para **HTTPS**, el servidor web necesita un **certificado de servidor con clave privada** cuyo nombre coincida con la dirección y debe escuchar en el **puerto 443**. El cliente solo confía en el sitio si conoce la **CA** emisora.
:::

# Dirección de red, dirección de broadcast y hosts

En cada red, dos direcciones tienen una función especial:

- La **dirección de red** es la dirección **más baja** de la red: todos los bits de la parte de host son 0. Designa la red en su conjunto, p. ej. en tablas de enrutamiento.
- La **dirección de broadcast** es la dirección **más alta** de la red: todos los bits de la parte de host son 1. Lo que se envía a ella llega a todos los dispositivos de la red.

Ninguna de las dos direcciones se **asigna** a dispositivos. Todas las direcciones intermedias están disponibles para dispositivos (**hosts**).

## Un ejemplo sencillo

`192.168.0.12/24` — la parte de host es el último octeto:

| | Dirección |
|---|---|
| Dirección de red (parte de host = 0) | `192.168.0.0` |
| Dirección de broadcast (parte de host = 255) | `192.168.0.255` |
| Rango para hosts | `192.168.0.1` – `192.168.0.254` |
| Número de hosts | 254 |

## Cuando el límite está en medio de un octeto

Se complica cuando la longitud de prefijo no es un múltiplo de 8. Entonces conviertes el octeto afectado al sistema binario. Ejemplo: `194.9.190.12/27`.

Los tres primeros octetos pertenecen por completo a la [[n|parte de red]] (24 bits). Del último octeto, **3 bits** pertenecen todavía a la parte de red (24 + 3 = 27) y los **5 bits** restantes a la [[h|parte de host]]:

| | último octeto (binario) | decimal |
|---|---|---|
| Dirección IP | [[n|000]][[h|01100]] | 12 |
| Máscara de red (`/27`) | [[n|111]][[h|00000]] | 224 |
| Dirección de red: bits de host a 0 | [[n|000]][[h|00000]] | **0** |
| Dirección de broadcast: bits de host a 1 | [[n|000]][[h|11111]] | **31** |

Resultado:

- Dirección de red: `194.9.190.0`
- Dirección de broadcast: `194.9.190.31`
- Rango para hosts: `194.9.190.1` – `194.9.190.30`
- Número de hosts: 2⁵ − 2 = **30**

:::tip Recuerda
**Dirección de red:** todos los bits de host a 0 (dirección más baja). **Dirección de broadcast:** todos los bits de host a 1 (dirección más alta). Ninguna de las dos se asigna a dispositivos. Una red con longitud de prefijo *n* tiene **2<sup>32 − n</sup> − 2** direcciones utilizables para hosts.
:::

:::tip Consejo: el tamaño de bloque
Si has entendido el procedimiento en sistema binario, hay un atajo: **256 menos el octeto de la máscara** da el tamaño de una red en ese octeto. Con `/27` (máscara 224) es 256 − 224 = **32**. Las redes empiezan entonces en 0, 32, 64, 96 … — la dirección `.12` está en la red que empieza en `.0`, la dirección `.70` en la red que empieza en `.64`.
:::

## Los tamaños de red más importantes

| Prefijo | Máscara de red | Hosts |
|---|---|---|
| `/8` | `255.0.0.0` | 16 777 214 |
| `/16` | `255.255.0.0` | 65 534 |
| `/24` | `255.255.255.0` | 254 |
| `/25` | `255.255.255.128` | 126 |
| `/26` | `255.255.255.192` | 62 |
| `/27` | `255.255.255.224` | 30 |
| `/28` | `255.255.255.240` | 14 |
| `/29` | `255.255.255.248` | 6 |
| `/30` | `255.255.255.252` | 2 |

:::note
La red más pequeña habitual en la práctica es `/30`: tiene exactamente dos direcciones utilizables y se usa con frecuencia para la conexión entre dos routers. Un `/32` designa una única dirección: como red no es utilizable, pero aparece en tablas de enrutamiento y en reglas de firewall.
:::

## Dos tipos de puertos

**Puerto de destino — el servicio:** un programa servidor espera conexiones en un puerto fijo; se dice que **escucha** allí. Para los servicios conocidos, los números están establecidos a nivel mundial: son los **puertos bien conocidos** (*well-known ports*, del 0 al 1023). Por eso un navegador sabe sin preguntar que los servidores web escuchan en el puerto 80.

**Puerto de origen — el remitente:** el puerto del lado del cliente lo elige el sistema operativo por sí mismo para cada nueva conexión, dentro de un rango alto (en BeaverTracer a partir del 49152). Gracias a él, el cliente reconoce a cuál de sus conexiones pertenece una respuesta.

Así pues, una conexión queda determinada de forma unívoca por cuatro datos: **la dirección IP y el puerto de ambos lados**. El par formado por dirección IP y puerto se llama **socket**, p. ej. `192.168.0.20:80`.

## Una mirada al servidor

Vuelve al modo de ejecución :fa-play: **Ejecutar**, abre en el **Server** el :fa-terminal: **Terminal** e introduce:

```
$ ss
```

`ss` muestra todos los sockets del equipo. Las líneas con `LISTEN` son programas que escuchan en un puerto. Las líneas con `ESTABLISHED` son conexiones establecidas, con el socket propio (*Local Address:Port*) y el socket del otro lado (*Peer Address:Port*).

:::

## Los puertos bien conocidos más importantes

| Puerto | Protocolo | Servicio |
|---|---|---|
| 22 | SSH | mantenimiento remoto seguro (línea de comandos cifrada) |
| 25 | SMTP | enviar correos electrónicos |
| 53 | DNS | traducir nombres a direcciones IP (normalmente mediante UDP) |
| 80 | HTTP | páginas web |
| 110 | POP3 | descargar correos electrónicos |
| 143 | IMAP | gestionar correos electrónicos en el servidor |
| 443 | HTTPS | páginas web cifradas |

:::tip Recuerda
Los **puertos** (del 0 al 65535) mantienen separadas las conexiones dentro de un equipo. Los servicios del servidor **escuchan** en **puertos bien conocidos** fijos (p. ej. HTTP 80, HTTPS 443); los clientes reciben para cada conexión un **puerto de origen** alto que esté libre. Una conexión queda determinada de forma unívoca por la **dirección IP y el puerto de ambos lados**.
:::

:::quiz match
22 -> SSH
25 -> SMTP
53 -> DNS
80 -> HTTP
110 -> POP3
143 -> IMAP
443 -> HTTPS
:::

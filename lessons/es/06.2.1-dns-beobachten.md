## El experimento

1. Cambia al modo de ejecución :fa-play: **Ejecutar**, haz clic en el **Client-PC** y abre el :fa-globe: **Navegador**.
2. Esta vez accede a `http://www.beaver-schule.de/`, es decir, con nombre en lugar de dirección IP.
3. Cambia al modo :fa-magnifying-glass: **Rastreo** y abre un trace para el **Client-PC**.

Justo al principio, incluso antes del establecimiento de conexión con `[SYN]`, aparecen dos paquetes con el protocolo **DNS**.

:::quiz short
¿A qué dirección IP envía el Client-PC su consulta DNS?
= 192.168.0.53
:::

:::quiz short
¿Qué dirección IP aparece en la respuesta para `www.beaver-schule.de`?
= 192.168.0.20
:::

:::quiz mc
Haz clic en la consulta DNS y despliega el árbol de protocolos. ¿Qué protocolo de transporte y qué puerto de destino se utilizan?
- [ ] TCP, puerto 80
- [x] UDP, puerto 53
- [ ] UDP, puerto 67
:::

:::evaluate
Comprobar respuestas
:::

Solo después de que el Client-PC conoce la dirección IP, establece la conexión TCP con el servidor web, igual que en el capítulo 5.

:::seq
mode: text
Client-PC -> DNS-Resolver: DNS-Anfrage | A www.beaver-schule.de?
DNS-Resolver -> Client-PC: DNS-Antwort | A 192.168.0.20
:::

## ¿Cómo conoce el PC el servidor DNS?

Abre en el **Client-PC** la :fa-gear: **Configuración IP**: en el campo **DNS-Server** aparece `192.168.0.53`, el equipo **DNS-Resolver**. A él envía el PC todas las consultas de nombres.

También puedes preguntar directamente al servidor DNS, sin navegador. Abre el :fa-terminal: **Terminal** e introduce:

```
$ nslookup www.beaver-schule.de
```

`nslookup` muestra primero a qué servidor ha preguntado y después la respuesta. Para comparar, pregunta por un nombre que no existe, p. ej. `nslookup gibtsnicht.beaver-schule.de`.

:::quiz mc
¿Qué responde el servidor DNS al nombre desconocido?
- [ ] Una dirección IP aleatoria
- [x] `NXDOMAIN`: este nombre no existe
- [ ] Nada en absoluto
:::

:::evaluate
Comprobar respuesta
:::

:::tip Recuerda
El **DNS** traduce nombres (p. ej. `www.beaver-schule.de`) en direcciones IP. Antes de que un PC pueda establecer una conexión con un nombre, consulta al **servidor DNS** que tiene configurado en su configuración IP, normalmente mediante **UDP, puerto 53**. Con `nslookup` puedes hacer consultas DNS manualmente.
:::

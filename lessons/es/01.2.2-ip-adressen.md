# Asignar direcciones IP

:::sim
url=/sims/lesson-1.2.2.btsim
:::

Para que dos dispositivos puedan comunicarse entre sí, necesitan una dirección IP en la misma red. En el área de trabajo ves dos PCs conectados, exactamente como los has construido tú mismo hace un momento.

1. Cambia al :fa-play: modo de ejecución (**Ejecutar**) y haz clic en **Computer 1** para abrirlo.
2. Abre allí la :fa-gear: **Configuración IP**. Un PC nuevo ya tiene la dirección `192.168.0.10` con la máscara de red `/24`; puedes dejarla así.
3. Abre ahora **Computer 2**. Tiene la *misma* dirección `192.168.0.10`, y eso no puede funcionar, porque cada dirección solo puede aparecer una vez en la red. Cámbiala a `192.168.0.11` (máscara de red `/24`).

:::tip Recuerda
Una **dirección IP** (p. ej. `192.168.0.10`) es la dirección de un dispositivo en la red, comparable a un número de casa. Cada dirección IP solo puede aparecer **una vez** en una red.
:::

:::task
title: ¿Direcciones asignadas correctamente?
Permanece en el modo de ejecución y comprueba si ambos PCs tienen direcciones adecuadas y si pueden alcanzarse.
check: ip(1, "192.168.0.10/32")
check: ip(3, "192.168.0.11/32")
check: pingOk(1, 3)
:::

:::note
Qué significa exactamente `/24` y cómo dividir una red de forma adecuada lo veremos con detalle en el capítulo 4. Por ahora basta con esto: ambas direcciones deben empezar por `192.168.0.` y no deben repetirse.
:::

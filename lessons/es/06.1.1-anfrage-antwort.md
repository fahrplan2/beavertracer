Así pues, una página web suele constar de muchos archivos: texto, hojas de estilo, imágenes. Para cada uno de ellos el navegador envía una solicitud propia.

## Cómo es una solicitud

Haz clic en el trace en el paquete `GET / HTTP/1.1` y despliega **Hypertext Transfer Protocol**. Una solicitud HTTP es texto plano:

```
GET / HTTP/1.1              ← Methode, Pfad, Version
Host: 192.168.0.20          ← Header: zusätzliche Angaben
…
                            ← Leerzeile: Ende der Anfrage
```

La respuesta del servidor tiene la misma estructura: con una línea de estado, encabezados, una línea vacía y, después, el archivo propiamente dicho:

```
HTTP/1.1 200 OK             ← Version, Statuscode, Text
Content-Type: text/html     ← Header: Art der Datei
Content-Length: 301         ← Header: Größe in Byte
                            ← Leerzeile
<!doctype html> …           ← die Datei selbst
```

:::seq
mode: text
Client-PC -> Server: GET / | Solicitud HTTP
Server -> Client-PC: 200 OK | index.html
Client-PC -> Server: GET /style.css | Solicitud HTTP
Server -> Client-PC: 200 OK | style.css
:::

## Métodos y códigos de estado

El **método** indica lo que quiere el cliente:

| Método | Significado |
|---|---|
| **GET** | obtener un archivo |
| **POST** | enviar datos al servidor, p. ej. un formulario rellenado |
| **HEAD** | obtener solo los encabezados, sin el archivo |

El **código de estado** indica cómo ha ido. La primera cifra revela el tipo de respuesta:

| Código | Texto | Significado |
|---|---|---|
| **200** | OK | todo en orden |
| **301** | Moved Permanently | la página se ha trasladado de forma permanente |
| **404** | Not Found | el archivo no existe |
| **405** | Method Not Allowed | este método no está permitido aquí |
| **500** | Internal Server Error | error en el servidor |

`2xx` significa éxito, `3xx` redirección, `4xx` un error del cliente (solicitud incorrecta), `5xx` un error del servidor.

:::tip Recuerda
**HTTP** funciona según el **principio de solicitud y respuesta**: el cliente envía una **solicitud** (método como `GET`, ruta, encabezados) y el servidor responde con un **código de estado** (p. ej. `200 OK`, `404 Not Found`), encabezados y el archivo. Para cada archivo de una página web hay una solicitud propia.
:::

500 -> Se ha producido un error en el servidor
:::

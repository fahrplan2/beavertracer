# Problem odgovora

:::sim
url=/sims/lesson-9.2.btsim
:::

Firewall sada radi po principu whitelist: standardna politika je **Odbaci sve**. Jedno jedino pravilo dozvoljava školskoj mreži surfanje: **B → A, TCP, odredišni port 80, Dozvoli**. Način rada je postavljen na **Stateless**.

## Eksperiment

1. Prebaci se u način rada :fa-play: **Pokretanje** i na **Lehrer-PC** u :fa-globe: **Preglednik** otvori `http://203.0.113.80/`.
2. U **Firewall** pogledaj **Protokoll** i **Treffer**.

:::quiz mc
Šta se događa u pregledniku?
- [ ] Pojavljuje se stranica www.beispiel.de
- [x] Stranica se ne učitava, preglednik čeka i na kraju prijavljuje grešku
:::

:::quiz mc
Koji paketi su u zapisniku firewalla navedeni kao odbačeni (`DROP`)?
- [ ] Zahtjevi računara Lehrer-PC prema portu 80
- [x] Odgovori sa `203.0.113.80` s **izvornim portom 80** prema računaru Lehrer-PC
- [ ] Nikakvi
:::

:::quiz short
U kojem smjeru (A→B ili B→A) idu odbačeni paketi?
= A→B
= A → B
= AtoB
:::

:::evaluate
Provjeri odgovore
:::

Zahtjev računara Lehrer-PC smije izaći, ali već `SYN, ACK` web servera ne dolazi nazad, jer za smjer A → B ne postoji odgovarajuće pravilo, pa vrijedi **Odbaci sve**.

## Naivno rješenje

Mogло bi se dodati drugo pravilo: **A → B, TCP, izvorni port 80, Dozvoli**, tj. „sve što dolazi s porta 80 smije ući". Tada surfanje zaista radi.

:::quiz mc
Zašto je ovo pravilo opasno?
- [ ] Jer web serveri nikada ne koriste port 80 kao izvorni port
- [x] Napadač jednostavno može poslati svoje pakete s izvornim portom 80, pa ih firewall propušta na **bilo koji** port u školskoj mreži
- [ ] Jer se tada web stranice sporije učitavaju
:::

:::evaluate
Provjeri odgovor
:::

Izvorni port određuje sam pošiljalac, pa se firewall na njega ne smije oslanjati. Firewall bez stanja, međutim, ne zna je li paket **odgovor na zahtjev** ili **novi pokušaj uspostavljanja veze** izvana. Upravo to mijenja način rada sa stanjem.

:::tip Zapamti
Paketni filter **bez stanja** provjerava svaki paket zasebno. Odgovori tada trebaju vlastita pravila za povratni smjer, a takva pravila (npr. „izvorni port 80 smije ući") napadači mogu iskoristiti, jer pošiljalac slobodno bira izvorni port.
:::

## Šta sve ima u kućnom ruteru

| Uloga u kućnom ruteru | Šta radi | poznato ti je iz |
|---|---|---|
| **Switch** | povezuje uređaje na LAN priključke | poglavlja 3.1 |
| **Pristupna tačka** | povezuje mobitele, tablete i laptope s mrežom putem WLAN-a | poglavlja 3.3 |
| **Ruter** | povezuje kućnu mrežu s mrežom provajdera — on je **gateway** | poglavlja 4.3 |
| **DHCP server** | dodjeljuje adrese, gateway i DNS server | poglavlja 6.4 |
| **DNS** | prosljeđuje upite za imena ili navodi DNS server provajdera | poglavlja 6.2 |
| **NAT** | povezuje sve uređaje s internetom preko **jedne** javne adrese | novo — odjeljak 7.2 |

Priključak **WAN** (*Wide Area Network*) vodi do provajdera, a priključci **LAN** i WLAN vode u kućnu mrežu. Mnogi kućni ruteri osim toga sadrže i **modem** — on prilagođava podatke za liniju (DSL, kabl, optika). BeaverTracer to ne simulira; ovdje je WAN priključak direktno u mreži provajdera.

:::quiz match

Pristupna tačka -> Povezuje tablete i mobitele s mrežom putem WLAN-a
DHCP server -> Dodjeljuje adrese uređajima u kućnoj mreži
Ruter -> Povezuje kućnu mrežu s mrežom provajdera
:::

:::tip Zapamti
**Kućni ruter** objedinjuje više uređaja: **switch**, **WLAN pristupnu tačku**, **ruter** (gateway prema internetu), **DHCP server** i **DNS prosljeđivanje** — uz to i **NAT**. Priključak **WAN** vodi do provajdera, a priključci **LAN** i WLAN vode u kućnu mrežu.
:::

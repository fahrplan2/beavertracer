# Automatsko dobijanje adrese

:::sim
url=/sims/lesson-6.4.btsim
:::

Na switch su spojeni **DHCP server** i dva laptopa. Laptopi za sada još imaju fiksne adrese.

## Eksperiment

1. Prebaci se u :fa-play: način rada **Pokretanje**, klikni na **Laptop 1** i otvori :fa-gear: **IP Postavke**.
2. Promijeni **Način rada** sa **Statički** na **DHCP** i klikni na **Primijeni**.
3. Pričekaj nekoliko sekundi: polja će se popuniti sama.
4. U načinu rada :fa-magnifying-glass: **Trag** otvori trag za **Laptop 1**.

:::quiz table
| Postavka | dobijeno od DHCP servera |
|---|---|
| IP adresa | {192.168.0.100} |
| Gateway | {192.168.0.1} |
| DNS server | {192.168.0.53} |
:::

:::

## Šta se krije iza toga: DORA

Uređaj bez adrese ne zna gdje se nalazi DHCP server, a nema ni vlastitu adresu pošiljaoca. Zato se **broadcastom** javlja u mrežu. Postupak ima četiri koraka — po početnim slovima nazvan **DORA**:

:::seq
mode: text
Laptop 1 -> DHCP-Server: DHCP Discover | „Ima li ovdje DHCP servera?“
DHCP-Server -> Laptop 1: DHCP Offer | „Možeš dobiti 192.168.0.100.“
Laptop 1 -> DHCP-Server: DHCP Request | „Uzimam 192.168.0.100.“
DHCP-Server -> Laptop 1: DHCP ACK | „Potvrđeno — vrijedi 3600 sekundi.“
:::

Adresa je samo **posuđena** (*lease*): nakon isteka **lease vremena** uređaj je mora produžiti, inače je server smije ponovo dodijeliti. Koje su adrese trenutno iznajmljene, vidiš u **DHCP serveru** na kartici **Leases**.

:::tip Probaj sam
Postavi i **Laptop 2** na DHCP. Koju adresu dobija? Zatim pogledaj **Leases** DHCP servera.
:::

:::tip Zapamti
**DHCP** automatski dodjeljuje IP adresu, mrežnu masku, gateway i DNS server. Postupak se zove **DORA**: **D**iscover (klijent traži putem broadcasta), **O**ffer (server nudi), **R**equest (klijent prihvata), **A**CK (server potvrđuje). Adresa je posuđena na **lease vrijeme**. DHCP koristi **UDP**, port 67 (server) i 68 (klijent).
:::

:::quiz match
Discover -> Klijent putem broadcasta traži DHCP server
Offer -> Server nudi adresu
Request -> Klijent traži ponuđenu adresu
ACK -> Server potvrđuje dodjelu
:::

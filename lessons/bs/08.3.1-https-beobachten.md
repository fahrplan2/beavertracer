# Poređenje HTTP-a i HTTPS-a

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Web server **www.beaver-schule.de** nudi školski portal za ocjene i preko HTTP-a i preko HTTPS-a. Šta vidi neko ko prisluškuje?

## Eksperiment

1. Prebaci se u :fa-play: **Način rada Pokretanje** i na **Client-PC** u :fa-globe: **Preglednik** prvo otvori `http://www.beaver-schule.de/`, a zatim `https://www.beaver-schule.de/`.
2. U :fa-magnifying-glass: **Način rada Trag** otvori trag (trace) za **Client-PC**.
3. Prvo pronađi paket `HTTP/1.1 200 OK` i klikni na njega. Dolje u detaljima ćeš pronaći sadržaj stranice.

:::quiz mc
Šta neko ko prisluškuje može vidjeti kod **HTTP-a**?
- [x] Cijelu web stranicu, uključujući i Annine ocjene
- [ ] Samo adresu servera
- [ ] Ništa, jer HTTP radi preko TCP-a
:::

:::quiz short
Koju ocjenu Anna ima iz matematike?
= 2
:::

:::evaluate
Provjeri odgovore
:::

Sada slijedi HTTPS dio. Pronađi paket `[SYN]` kojim klijent započinje drugu vezu.

:::quiz short
Koji odredišni port ima HTTPS veza (kolona **Info**, `… → ???`)?
= 443
:::

Sada u polje za filtriranje na vrhu traga upiši `tls` — tada ćeš vidjeti samo TLS pakete.

:::quiz mc
Šta piše u koloni **Info** kod paketa koji sadrže web stranicu?
- [ ] `HTTP/1.1 200 OK`
- [x] `Application Data`
- [ ] `Encrypted HTML`
:::

:::quiz multi
Šta neko ko prisluškuje i kod **HTTPS-a** ipak može vidjeti?
- [x] IP adrese klijenta i servera
- [x] Da se koristi port 443, dakle vjerovatno HTTPS
- [x] Otprilike koliko se podataka prenosi
- [ ] Koja je stranica otvorena i šta se na njoj nalazi
:::

:::evaluate
Provjeri odgovore
:::

:::note
Klikni na paket **Application Data**: korisni podaci su samo niz naizgled nasumičnih bajtova. Tracer ih ne može dešifrovati — on ne poznaje ključ sesije ništa bolje nego napadač.
:::

:::tip Zapamti
Kod **HTTP-a** svako ko prisluškuje može pročitati cijelu web stranicu. Kod **HTTPS-a** vidi samo **ko s kim** komunicira (IP adrese, port 443) i **koliko** podataka se razmjenjuje — sadržaj je šifrovan unutar paketa **Application Data**.
:::

# HTTPS

:::osi 5
:::

**HTTPS** (*HTTP Secure*) je sasvim običan HTTP — samo što ne radi direktno preko TCP-a, nego kroz šifrirani sloj između: **TLS** (*Transport Layer Security*). Prethodnik TLS-a zvao se **SSL**; zato se i danas često govori o „SSL certifikatima“.

```
ohne Verschlüsselung:   HTTP  →  TCP  →  IP
mit Verschlüsselung:    HTTP  →  TLS  →  TCP  →  IP
```

HTTP od toga ništa ne primjećuje: šalje svoje zahtjeve kao i obično, TLS ih šifrira, a TCP ih prenosi. U OSI modelu TLS se nalazi između transportnog i aplikacijskog sloja, dakle u sloju 4/5 — nadograđuje se na TCP i upravlja zaštićenom sesijom.

| | HTTP | HTTPS |
|---|---|---|
| Port | 80 | **443** |
| Adresa | `http://…` | `https://…` |
| Sadržaj čitljiv u Traceru? | da | ne |
| Preglednik prikazuje | „nije sigurno“ | lokot |

TLS pri uspostavljanju veze obavlja sve što si naučio/naučila u ovom poglavlju:

- Server se predstavlja svojim **certifikatom** (**autentičnost**).
- Obje strane pomoću **Diffie-Hellmana** dogovaraju **sesijski ključ** — server **potpisuje** svoj dio.
- Nakon toga se svi podaci šifriraju pomoću **AES-a** (**povjerljivost**) i štite od izmjene (**integritet**).

Princip nije ograničen na web: i e-pošta (odjeljak 8.4) i mnogi drugi protokoli na isti način rade kroz TLS.

U sljedećim odjeljcima posmatraš HTTPS u Traceru, sam/sama ga postavljaš i istražuješ kada preglednik upozorava — i zašto.

# Pozivanje i posmatranje web stranice

Za ovaj dio ništa ne gradiš sam: na radnoj površini nalazi se pripremljena simulacija s jednim **Client-PC** i jednim **Webserver**.

## Pozivanje stranice

1. Prebaci se u :fa-play: **Pokreni** način rada Pokretanje.
2. Na **Client-PC** otvori aplikaciju :fa-globe: **Preglednik** i pozovi adresu web servera: `http://192.168.0.20/`.
3. Prebaci se u način rada :fa-magnifying-glass: **Trag** i pomoću **+** otvori trag za **Client-PC**, priključak `eth0` — baš kao kod pinga.

:::note
Za jedno jedino pozivanje stranice to je iznenađujuće mnogo paketa — znatno više nego kod pinga. Preuzimanje web stranice je višestepen proces, a ne jedna jedina radnja.
:::

## Čitanje liste paketa

Još ne moraš znati šta tačno rade pojedini protokoli. Sve što ti treba za sljedeća pitanja nalazi se u kolonama **Protokol** i **Info**.

:::quiz mc
Koji protokol je na samom vrhu liste?
- [x] ARP
- [ ] TCP
- [ ] HTTP
:::

:::quiz short
Prebroj: koliko **TCP** paketa stoji prije prvog **HTTP** paketa?
= 3
= tri
:::

:::quiz mc
Šta web server odgovara na zahtjev preglednika? Pogledaj kolonu Info drugog HTTP paketa.
- [ ] GET / HTTP/1.1
- [x] HTTP/1.1 200 OK
- [ ] 404 Not Found
:::

Provjeri odgovore
:::

## Imenovanje uključenih protokola

Iz svojih zapažanja sada možeš iščitati koji je protokol bio zadužen za šta.

:::tip Savjet
Još jednom pročitaj kolone **Info**: `Who has …?`, `[SYN]`, `[SYN, ACK]`, `[ACK]`, `GET /` i `200 OK` već gotovo sve odaju.
:::

:::quiz match
ARP -> Pita sve u mreži: „Ko ima IP adresu 192.168.0.20?“
TCP -> Uspostavlja vezu pomoću tri kratka paketa prije nego što podaci počnu teći
HTTP -> Zahtijeva web stranicu (GET) i vraća je (200 OK)
:::

:::evaluate
Provjeri pridruživanje
:::

:::tip Zapamti
Pozivanje web stranice odvija se u stepenima: prvo **pronaći** server u mreži (ARP), zatim **uspostaviti** vezu (TCP), zatim **zatražiti i isporučiti** stranicu (HTTP) — i na kraju vezu ponovo **raskinuti** (TCP paketi s `[FIN]` na kraju liste).
:::

:::note
Ovaj put si IP adresu servera unio direktno, zato **DNS** („prevođenje“ imena kao što je `www.beispiel.de` u IP adresu) još nije došao do izražaja. To ćemo nadoknaditi u poglavlju 6.
:::

Jesi li primijetio da protokoli u strukturi paketa nose obojene oznake s brojevima? Šta je s tim, objasnit ćemo u poglavlju 2. Tamo ćemo pogledati kako se brojni protokoli sistematski razvrstavaju — pomoću OSI i TCP/IP referentnog modela. Time je poglavlje 1 završeno.

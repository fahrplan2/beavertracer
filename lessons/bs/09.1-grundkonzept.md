# Paketni filter: pravila

Najjednostavnija i najvažnija vrsta firewalla je **paketni filter**. On pregleda svaki paket koji prolazi kroz njega i na osnovu **liste pravila** odlučuje smije li proći. Pritom čita samo zaglavlja sloja 3 i 4 — sadržaj (npr. web-stranicu) ne razmatra.

## Od čega se sastoji pravilo

| Polje | Značenje | Primjer |
|---|---|---|
| **Smjer** | S koje strane dolazi paket? | A → B (s interneta u školsku mrežu) |
| **Protokol** | TCP, UDP, ICMP ili bilo koji | TCP |
| **Izvorišni IP** | adresa ili mreža pošiljaoca | bilo koji |
| **Izvorišni port** | port pošiljaoca | bilo koji |
| **Odredišni IP** | adresa ili mreža primaoca | `198.51.100.10` |
| **Odredišni port** | port primaoca, dakle usluga | `80` |
| **Akcija** | Šta se dešava s paketima koji odgovaraju pravilu? | Dozvoli |

Prazno polje znači „bilo koji“. Mreže se pišu u CIDR notaciji, npr. `198.51.100.0/24`, a rasponi portova s crticom, npr. `1024-65535`.

## Redoslijed je presudan

Firewall provjerava pravila **od vrha prema dnu**. Odlučuje **prvo pravilo koje odgovara** — sva sljedeća se za taj paket više ne razmatraju. Ako nijedno pravilo ne odgovara, vrijedi **podrazumijevana politika** (*Default Policy*).

## Tri moguće akcije

| Akcija | Šta firewall radi | Šta pošiljalac primijeti |
|---|---|---|
| **Dozvoli** (*Allow*) | Paket se prosljeđuje | — |
| **Odbaci** (*Drop*) | Paket se odbacuje bez ikakvog komentara | uopće ništa — čeka dok ne istekne timeout |
| **Odbij** (*Reject*) | Paket se odbacuje, a pošiljalac dobija odbijenicu: kod TCP-a **RST**, inače ICMP „nedostupno“ | odmah poruku o grešci |

Šta je bolje? **Odbacivanje** otkriva napadaču manje i oduzima mu vrijeme, jer mora čekati nakon svakog pokušaja. **Odbijanje** je ljubaznije prema vlastitim korisnicima: program odmah dobija poruku o grešci umjesto da dugo čeka. U praksi se zato paketi izvana obično odbacuju, a paketi iz vlastite mreže odbijaju.

:::quiz match
Dozvoli -> Paket se prosljeđuje
Odbaci -> Paket nestaje, pošiljalac uzaludno čeka odgovor
Odbij -> Paket se ne prosljeđuje, ali pošiljalac odmah dobija odbijenicu
Podrazumijevana politika -> Vrijedi ako nijedno pravilo ne odgovara
:::

:::tip Zapamti
**Paketni filter** provjerava svaki paket prema **listi pravila** na osnovu smjera, protokola, adresa i portova. **Prvo pravilo koje odgovara** odlučuje o akciji: **dozvoli**, **odbaci** (tiho) ili **odbij** (s odbijenicom). Ako nijedno pravilo ne odgovara, vrijedi **podrazumijevana politika**.
:::

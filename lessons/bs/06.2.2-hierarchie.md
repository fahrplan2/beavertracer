# Kako je organizovan DNS

:::sim
url=/sims/lesson-6.2.btsim
:::

Nijedan pojedinačni server ne može poznavati sva imena na svijetu. Zato je DNS izgrađen **hijerarhijski** — baš kao i sama imena. Čitaju se s desna na lijevo:

```
www . beaver-schule . de . (Root)
 │          │         │      └─ Root-Server: kennen die Server aller Top-Level-Domains
 │          │         └─ Top-Level-Domain (TLD): der de-Server kennt alle .de-Domains
 │          └─ Domain: der Schul-DNS ist für beaver-schule.de zuständig
 └─ Rechnername innerhalb der Domain
```

Server koji je nadležan za neku domenu i zaista zna odgovor naziva se **autoritativni** server. Put do njega umjesto PC-ja preuzima **resolver** — ovdje je to računar **DNS-Resolver**.

## Eksperiment

1. Prebaci se u :fa-play: **Način rada Pokretanje** i na računaru **Client-PC** upiši u :fa-terminal: **Terminal**:
   ```
   $ nslookup www.beaver-schule.de
   ```
2. U :fa-magnifying-glass: načinu rada **Trag** otvori trag (trace) za **DNS-Resolver**.

Resolver je za tebe postavio cijeli niz upita. Poveži ko je dao koji odgovor:

:::quiz match
Root-Server (192.168.0.101) -> Upućivanje: Za .de je nadležan ns.nic.de
de-Server (192.168.0.102) -> Upućivanje: Za beaver-schule.de je nadležan ns.beaver-schule.de
Schul-DNS (192.168.0.103) -> Odgovor: www.beaver-schule.de ima adresu 192.168.0.20
:::

:::quiz mc
Koga resolver pita prvog?
- [x] Root-Server
- [ ] Schul-DNS
- [ ] Client-PC
:::

:::evaluate
Provjeri odgovore
:::

:::note
Usput resolver pita i za adrese servera na koje je upućen (`A ns.nic.de`). Pravi DNS serveri te adrese najčešće odmah pošalju zajedno s odgovorom. Osim toga, resolveri neko vrijeme pamte svaki odgovor (**cache**) — na sljedeći upit za isto ime odgovaraju odmah sami. Koliko dugo, piše u zapisu kao **TTL** (*Time to Live*) u sekundama.
:::

## Najvažniji tipovi zapisa

| Tip | Značenje | Primjer |
|---|---|---|
| **A** | ime → IPv4 adresa | `www.beaver-schule.de` → `192.168.0.20` |
| **AAAA** | ime → IPv6 adresa | `www.beaver-schule.de` → `2001:db8::20` |
| **CNAME** | ime → drugo ime (alias) | `web.beaver-schule.de` → `www.beaver-schule.de` |
| **MX** | nadležni mail server domene | `beaver-schule.de` → `mail.beaver-schule.de` |
| **NS** | nadležni DNS server domene | `beaver-schule.de` → `ns.beaver-schule.de` |

:::tip Zapamti
DNS je **hijerarhijski**: **root serveri** upućuju na servere **domena najvišeg nivoa** (npr. `.de`), a oni na servere pojedinačnih **domena**. Nadležni **autoritativni** server zna odgovor. **Resolver** prelazi taj put umjesto PC-ja i pamti odgovore (**cache**). Važni tipovi zapisa: **A**, **AAAA**, **CNAME**, **MX**, **NS**.
:::

## Kreiranje zapisa

Škola želi da njena web stranica bude dostupna i pod adresom `intranet.beaver-schule.de`.

1. U :fa-play: **načinu rada Pokretanje** klikni na **Schul-DNS** i otvori aplikaciju **DNS-Server**.
2. Otvori karticu **A**. Klikni na **+** i u novi red upiši ime `intranet.beaver-schule.de` i adresu `192.168.0.20`.
3. Testiraj na računaru Client-PC pomoću `nslookup intranet.beaver-schule.de`.

check: resolves(2, "intranet.beaver-schule.de", "192.168.0.20")

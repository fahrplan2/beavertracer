## Šta se krije iza toga

Kućni ruter u svakom paketu koji ide prema internetu zamjenjuje privatnu adresu pošiljaoca svojom vlastitom **javnom WAN adresom** — a najčešće i port pošiljaoca. Web serveru izgleda kao da zahtjev dolazi od kućnog rutera. Kada odgovor stigne nazad, kućni ruter ponovo zamijeni adresu i proslijedi paket PC-u.

Tako cijela kućna mreža može izaći na internet s jednom jedinom javnom adresom — a uređaji na internetu nikada ne vide privatne adrese.

## Put do interneta

Na **PC-u** u :fa-terminal: **Terminal**-u unesi:

```
$ traceroute 192.0.2.80
```

:::quiz short
Koliko rutera se nalazi između PC-a i web servera? (Izbroji sve redove prije posljednjeg.)
= 4
= četiri
:::

:::quiz mc
Koju adresu `traceroute` prikazuje za prvi ruter?
- [x] `192.168.178.1` — LAN adresu kućnog rutera
- [ ] `203.0.113.2` — njegovu WAN adresu
- [ ] `203.0.113.1` — prvi ruter provajdera
:::

:::

:::tip Zapamti
**NAT** (*Network Address Translation*) pri putu prema internetu zamjenjuje **privatnu** adresu pošiljaoca uređaja **javnom WAN adresom** rutera — a kod odgovora obrnuto. Tako svi uređaji u kućnoj mreži dijele **jednu** javnu IPv4 adresu. To štedi adrese i skriva privatne adrese od interneta.
:::

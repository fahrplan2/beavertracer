# Otklanjanje grešaka: Mejl ne stiže

:::sim
url=/sims/lesson-6.3.4.btsim
:::

Anna javlja: „Ne mogu poslati mejl Benu!“ Ovako *treba* biti podešeno:

| Šta | Treba biti |
|---|---|
| Annin odlazni server (SMTP) | `mail.beaver-schule.de`, port `25` |
| MX zapis za `biber-mail.de` | `mail.biber-mail.de` (prioritet 10) |

Pronađi greške i otkloni ih. Zatim pošalji Anni mejl na adresu `ben@biber-mail.de` — zadatak provjerava je li stigao u Benovo poštansko sanduče. (Prosljeđivanje između mail servera može potrajati nekoliko sekundi.)

<details>
<summary>Savjet 1: Šta kaže Annin program za e-poštu?</summary>

Pokušaj poslati mejl i pogledaj karticu **Protokol**. Šta odgovara server — zvuči li to kao SMTP?
</details>

<details>
<summary>Savjet 2: Mejl se vraća kao poruka o grešci?</summary>

Preuzmi poštu na Anninom računaru i pročitaj poruku od `MAILER-DAEMON`. Zbog čega nije uspjela isporuka? Pomoću `nslookup -type=MX biber-mail.de` na Anninom PC-ju provjeri zna li DNS server nadležni mail server.
</details>

<details>
<summary>Savjet 3: Gdje se to unosi?</summary>

Odlazni server podešavaš u Anninoj aplikaciji **E-Mail** pod **Einstellungen**. MX zapise pronaći ćeš u **DNS-Server** na kartici **MX**.
</details>

:::task
title: Je li mejl stigao?
Provjerava postoji li mejl u Benovom poštanskom sandučetu na serveru Mailserver Biber.
check: fileExists(5, "/var/mail/ben.mbox")
:::

## Šta je bilo pogrešno?

:::quiz multi
Koje tvrdnje su tačne?
- [x] Annin odlazni server pokazivao je na port 110 — tamo odgovara POP3 usluga, a ne SMTP
- [x] Za `biber-mail.de` nedostajao je MX zapis — Mailserver Schule nije pronašao nadležni mail server
- [x] Mejl koji nije mogao biti isporučen vratio se kao poruka o grešci od `MAILER-DAEMON`
- [ ] Benova lozinka je bila pogrešna
:::

:::evaluate
Provjeri odgovor
:::

:::tip Zapamti
Tipične greške kod e-pošte: pogrešan **server ili port** u programu za e-poštu (SMTP radi na portu 25, POP3 na 110, IMAP na 143) i nedostajući ili pogrešan **MX zapis** u DNS-u. Ako mail server ne može isporučiti mejl, vraća ga pošiljaocu s porukom o grešci (**bounce**).
:::

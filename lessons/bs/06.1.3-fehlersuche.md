# Otklanjanje grešaka: nedostaje stranica s kontaktom

:::sim
url=/sims/lesson-6.1.3.btsim
:::

Sekretarijat javlja: „Na našoj web-stranici link **Kontakt** vodi samo do poruke o grešci.“ Stranica s kontaktom treba biti dostupna na adresi `http://192.168.0.20/kontakt.html`. Pronađi grešku i otkloni je.

<details>
<summary>Savjet 1: Šta javlja server?</summary>

Otvori stranicu s kontaktom u pregledniku ili pomoću `curl -v`. Koji statusni kod stiže kao odgovor? Stranica s greškom otkriva i gdje je server tražio datoteku.
</details>

<details>
<summary>Savjet 2: Gdje se nalaze datoteke?</summary>

Web-server isporučuje samo datoteke iz svog **korijenskog direktorija dokumenata** (*Document Root*) — to piše u aplikaciji **HTTP-Server**. Na **Serveru** u terminalu pomoću `ls` pogledaj šta se tamo nalazi, a stranicu s kontaktom potraži i u `/home`.
</details>

<details>
<summary>Savjet 3: Premještanje datoteke</summary>

Pomoću `mv` premještaš datoteku: `mv <izvor> <odredišni direktorij>`.
</details>

:::task
title: Je li stranica s kontaktom popravljena?
Provjerava se nalazi li se stranica s kontaktom u korijenskom direktoriju dokumenata web-servera.
check: fileExists(2, "/var/www/kontakt.html")
:::

## Šta se desilo?

:::quiz multi
Koje tvrdnje su tačne?
- [x] Server je odgovorio sa `404 Not Found`
- [x] Datoteka se nalazila u `/home` umjesto u korijenskom direktoriju dokumenata `/var/www`
- [ ] Web-server uopće nije bio pokrenut
- [ ] Preglednik je koristio pogrešnu IP adresu
:::

:::evaluate
Provjeri odgovor
:::

:::tip Zapamti
**404** znači: web-server radi i dostupan je, ali tražena **datoteka** ne postoji na toj putanji. Server traži samo u svom **korijenskom direktoriju dokumenata** (*Document Root*, ovdje `/var/www`). Usporedi: ako server uopće ne odgovara ili odgovori sa `RST`, problem je dublje — u mreži ili u samoj usluzi (poglavlje 5.3.2).
:::

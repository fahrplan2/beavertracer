# Primjena modela

Pridruži protokole iz eksperimenta s početka poglavlja njihovom OSI sloju:

:::quiz match
Ethernet -> Sloj 2 — Podatkovna veza
IPv4 -> Sloj 3 — Mrežni sloj
TCP -> Sloj 4 — Transport
HTTP -> Sloj 7 — Aplikacija
:::

:::evaluate
Provjeri pridruživanje
:::

I na kraju nazivi jedinica podataka:

:::quiz match
Frame -> Sloj 2 — Podatkovna veza
Paket -> Sloj 3 — Mrežni sloj
Segment -> Sloj 4 — Transport
:::

:::evaluate
Provjeri pridruživanje
:::

Time si dobio/la alat da ubuduće pravilno razvrstavaš protokole. Od sljedećeg poglavlja prolazimo kroz slojeve redom — počevši od sloja 2 i pitanja kako switch zapravo zna kamo mora proslijediti paket.

# Postavljanje kućnog rutera

:::sim
url=/sims/lesson-7.1.2.btsim
:::

Novi kućni ruter je upravo priključen, ali još niko ne može na internet. Od provajdera si dobio pismo s **pristupnim podacima**:

| Pristupni podaci | Vrijednost |
|---|---|
| WAN IP adresa | `203.0.113.2` |
| Dužina prefiksa | `/30` |
| Gateway (ruter provajdera) | `203.0.113.1` |
| DNS server provajdera | `198.51.100.10` |

1. Prebaci se u :fa-play: način rada **Pokretanje**, klikni na **Heimrouter** i otvori karticu **WAN**.
2. Unesi pristupne podatke i klikni na **Primijeni**.
3. Poveži **Tablet** s WLAN-om: :fa-gear: **IP Postavke**, kartica **WiFi**, SSID `Biberbau`, **Primijeni**.
4. Testiraj na računaru pomoću `ping 192.0.2.80` ili u pregledniku pomoću `http://www.beispiel.de/`.

:::note
U praksi kućni ruter svoju WAN adresu najčešće dobija automatski od provajdera (putem DHCP-a ili prijave s korisničkim imenom i lozinkom). Fiksni pristupni podaci, kao ovdje, češći su kod poslovnih priključaka.
:::

# Bez stanja ili sa stanjem

Veza se uvijek sastoji od **dva smjera**: Nastavnički PC šalje zahtjev web serveru na internetu — a web server šalje web stranicu natrag. Firewall koji radi po principu whiteliste, dakle, ne smije propustiti samo zahtjev, nego i **odgovor**.

Za to postoje dvije vrste paketskih filtera:

| | **Bez stanja** (*stateless*) | **Sa stanjem** (*stateful*) |
|---|---|---|
| Način rada | provjerava svaki paket pojedinačno, bez pamćenja | pamti dozvoljene veze u **tabeli stanja** |
| Odgovori | trebaju vlastito pravilo za povratni smjer | automatski se propuštaju jer pripadaju poznatoj vezi |
| Primjena | jednostavni uređaji, vrlo brzi filteri | praktički svaki današnji firewall |

U naredna dva odjeljka ćeš doživjeti zašto filteri bez stanja imaju problema s odgovorima — i kako ih firewall sa stanjem rješava.

Ovdje nastavljamo tamo gdje je stao odjeljak 8.2.2: na web serveru **www.beaver-schule.de** nalaze se **Schul-CA** i serverski certifikat koji je ona izdala, a **Client-PC** vjeruje Schul-CA. Samo što web server još ne govori HTTPS.

## Prije

Prebaci se u način rada :fa-play: **Pokretanje** i na **Client-PC**-ju u :fa-globe: **Preglednik**-u otvori `https://www.beaver-schule.de/`.

- [ ] Preglednik upozorava na nesigurni certifikat
- [ ] Stranica se prikazuje bez katanca
:::

Provjeri odgovor

## Uključivanje HTTPS-a

1. Na web serveru otvori **HTTP-Server** i klikni na **Zaustavi** — dok server radi, postavke se ne mogu mijenjati.
2. Prebaci se na karticu **HTTPS**:
    - Označi **Omogući HTTPS**, **HTTPS port** `443`
    - Kod **Certifikat** odaberi serverski certifikat `www.beaver-schule.de` — ne Schul-CA!
    - Klikni na **Koristi**
3. Klikni na **Pokreni**.

Ponovo otvori stranicu na Client-PC-ju putem `https://`. Klikni na katanac i provjeri izdavaoca i valjanost.

:::task
title: HTTPS postavljen?
Provjerava može li Client-PC preuzeti https://www.beaver-schule.de/ bez upozorenja o certifikatu. Simulacija mora biti pokrenuta u načinu rada Pokretanje.
check: httpsOk(2, "https://www.beaver-schule.de/")
:::

:::quiz mc

- [x] Upozorenje o certifikatu, jer ne može pratiti lanac povjerenja do poznate CA
- [ ] Ništa, jer se veza odbija
:::

:::note
Za javne web stranice potreban je certifikat CA koja je unaprijed instalirana u svim preglednicima. Od 2015. postoji **Let's Encrypt**, CA koja takve certifikate izdaje besplatno i automatski — jedan od glavnih razloga zašto danas gotovo sve web stranice koriste HTTPS.
:::

:::tip Zapamti
Za **HTTPS** web server treba **serverski certifikat s privatnim ključem** čije ime odgovara adresi, i mora osluškivati na **portu 443**. Klijent vjeruje stranici samo ako poznaje **CA** koja je izdala certifikat.
:::

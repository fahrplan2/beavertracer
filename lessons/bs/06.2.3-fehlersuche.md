# Otklanjanje grešaka: Ime ne funkcioniše

:::sim
url=/sims/lesson-6.2.3.btsim
:::

Nastavnica javlja: „`www.beaver-schule.de` mi se ne učitava. Ali sa `http://192.168.0.20` radi!“ Ovako *treba* biti podešeno:

| Šta | Treba biti |
|---|---|
| DNS server na Client-PC | `192.168.0.53` (DNS-Resolver) |
| Unos u Schul-DNS | `www.beaver-schule.de` → `192.168.0.20` |

Pronađi greške i otkloni ih.

<details>
<summary>Savjet 1: Šta kaže nslookup?</summary>

Na Client-PC unesi `nslookup www.beaver-schule.de`. Koji server je `nslookup` pitao — i šta je vratio? (Odgovor stiže nakon nekoliko sekundi.)
</details>

<details>
<summary>Savjet 2: A sada?</summary>

Ako dobiješ odgovor, uporedi adresu s planom. Gdje je ovo ime uneseno?
</details>

:::task
title: Je li razrješavanje imena popravljeno?
Provjerava razrješava li Client-PC www.beaver-schule.de na ispravnu adresu. Simulacija za to mora raditi u načinu rada Pokretanje.
check: resolves(2, "www.beaver-schule.de", "192.168.0.20")
:::

## Šta se dešavalo?

:::quiz multi
Koje tvrdnje su tačne?
- [x] Na Client-PC je kao DNS server bila unesena `192.168.0.35` — tamo niko ne odgovara
- [x] U Schul-DNS je `www.beaver-schule.de` pokazivao na `192.168.0.21` umjesto na `192.168.0.20`
- [ ] Web server je bio isključen
- [ ] Root server nije poznavao domenu `.de`
:::

:::evaluate
Provjeri odgovor
:::

:::tip Zapamti
Ako veza radi s **IP adresom**, ali ne i s **imenom**, problem je u **DNS-u**. Prvo provjeri **uneseni DNS server** (odgovara li uopće?), a zatim sam **unos** (je li adresa ispravna?). `nslookup` prikazuje oboje: koji je server pitan i šta je odgovorio.
:::

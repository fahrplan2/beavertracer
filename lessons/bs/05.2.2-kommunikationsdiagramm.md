# Dijagram komunikacije

:::sim
url=/sims/lesson-5.1.btsim
:::

Tok jedne veze crta se kao **dijagram komunikacije**: klijent i server dobiju po jednu okomitu liniju (liniju života), a vrijeme teče odozgo prema dolje. Svaka strelica je jedan paket. Nacrtana je koso zato što je svaki paket neko vrijeme na putu.

Ovako izgleda tvoja veza sa prethodne stranice — uporedi je red po red sa trasom:

:::seq
Client-PC -> Server: SYN
Server -> Client-PC: SYN, ACK
Client-PC -> Server: ACK
Client-PC -> Server: PSH, ACK "Hello World" len=13
Server -> Client-PC: ACK
Server -> Client-PC: PSH, ACK len=13
Client-PC -> Server: ACK
Client-PC -> Server: FIN, ACK
Server -> Client-PC: ACK
Server -> Client-PC: FIN, ACK
Client-PC -> Server: ACK
:::

Iznad svake strelice nalaze se **flagovi**, a ispod njih brojevi `SEQ` i `ACK`. **DATA** označava pakete s korisnim podacima. Crveni brojevi pripadaju klijentu, a plavi serveru — šta znače, objašnjava sljedeća stranica.

## Flagovi

| Flag | skraćenica od | Značenje |
|---|---|---|
| **SYN** | *synchronize* | uspostaviti vezu, odrediti početni broj |
| **ACK** | *acknowledge* | potvrđuje primljene podatke |
| **PSH** | *push* | podatke odmah proslijediti programu |
| **FIN** | *finish* | „Završio sam“ — prekinuti vezu |
| **RST** | *reset* | prekinuti ili odbiti vezu (više o tome u 5.3.2) |

## Tri faze

**Uspostavljanje:** klijent šalje `SYN`, server odgovara sa `SYN, ACK`, a klijent potvrđuje sa `ACK`. Zato što su potrebna tačno tri paketa, to se zove **trostruki handshake** (three-way handshake).

**Podaci:** primalac potvrđuje svaki paket s podacima paketom `ACK`. Ovdje server šalje eho nazad — i to klijent potvrđuje.

**Prekid veze:** svaka strana zasebno završava svoj smjer slanja: `FIN` od klijenta, `ACK` od servera — zatim `FIN` od servera, `ACK` od klijenta. To su četiri paketa.

:::tip Zapamti
TCP veza se odvija u tri faze: **uspostavljanje** pomoću **trostrukog handshakea** (`SYN` → `SYN, ACK` → `ACK`), **prijenos podataka** (svaki paket s podacima potvrđuje se sa `ACK`) i **prekid veze** (svaka strana šalje `FIN` i dobija `ACK`).
:::

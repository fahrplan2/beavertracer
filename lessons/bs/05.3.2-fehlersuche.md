# Otklanjanje grešaka: usluga ne odgovara

:::sim
url=/sims/lesson-5.3.2.btsim
:::

Nakon ažuriranja škola javlja: „Echo usluga odbija svaku vezu, a ni web stranica se više ne učitava.“ Prema planu, **web server** treba slušati na portu `80`, a **Echo usluga** (TCP Echo-Server) na portu `5000`. Pronađi greške i otkloni ih.

<details>
<summary>Savjet 1: Šta server odgovara?</summary>

Pokušaj se pomoću **Jednostavni TCP klijent** povezati na `192.168.0.20`, port `5000`, i otvori trag (trace) za klijentski PC. Čime server odgovara na tvoj `[SYN]`?
</details>

<details>
<summary>Savjet 2: Koji su portovi otvoreni?</summary>

Na klijentskom PC-u u terminalu upiši `nmap -p 80,5000 192.168.0.20`. `nmap` redom provjerava portove i prikazuje koji su otvoreni. Pomoću `ss` na serveru vidiš na kojim portovima tamo zaista sluša neki program.
</details>

<details>
<summary>Savjet 3: Gdje se to postavlja?</summary>

Na **serveru** otvori aplikacije **TCP Echo-Server** i **HTTP-Server**. Radi li usluga? I na kojem portu?
</details>

:::task
title: Jesu li usluge dostupne?
Provjerava da li klijentski PC doseže Echo uslugu na portu 5000 i web server na portu 80. Simulacija za to mora raditi u načinu rada Pokretanje.
check: tcpOpen(1, 2, 5000)
check: tcpOpen(1, 2, 80)
:::

## Šta se dešavalo?

:::quiz multi
Koje su tvrdnje tačne?
- [x] Na `[SYN]` prema portu 5000 server je odgovorio sa `[RST, ACK]`
- [x] Echo usluga je slušala na portu 5050 umjesto na portu 5000
- [x] Web server uopće nije bio pokrenut
- [ ] Kabl između klijentskog PC-a i servera bio je neispravan
:::

:::evaluate
Provjeri odgovor
:::

:::tip Zapamti
Ako na `SYN` stigne **`RST`**, na tom portu **ne sluša nijedan program**: računar je dostupan, ali usluga nije. Tipični uzroci: usluga **nije pokrenuta** ili sluša na **drugom portu**. Pogled na server pomoću `ss` pokazuje koji su portovi zaista otvoreni.
:::

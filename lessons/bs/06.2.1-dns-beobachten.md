## Eksperiment

1. Prebaci se u :fa-play: način rada **Pokretanje**, klikni na **Client-PC** i otvori :fa-globe: **Preglednik**.
2. Ovaj put pozovi `http://www.beaver-schule.de/` — s imenom umjesto IP adrese.
3. Prebaci se u :fa-magnifying-glass: način rada **Trag** i otvori trag za **Client-PC**.

Na samom početku — prije uspostavljanja veze pomoću `[SYN]` — nalaze se dva paketa s protokolom **DNS**.

:::quiz short
Na koju IP adresu Client-PC šalje svoj DNS upit?
= 192.168.0.53
:::

:::quiz short
Koja se IP adresa nalazi u odgovoru za `www.beaver-schule.de`?
= 192.168.0.20
:::

:::quiz mc
Klikni na DNS upit i otvori stablo protokola. Koji transportni protokol i koji odredišni port se koriste?
- [ ] TCP, port 80
- [x] UDP, port 53

:::

:::evaluate
Provjeri odgovore
:::

Tek nakon što Client-PC sazna IP adresu, uspostavlja TCP vezu s web serverom — baš kao u poglavlju 5.

:::seq
mode: text
Client-PC -> DNS-Resolver: DNS-Anfrage | A www.beaver-schule.de?
DNS-Resolver -> Client-PC: DNS-Antwort | A 192.168.0.20
:::

## Odakle PC zna DNS server?

Otvori na **Client-PC** :fa-gear: **IP Postavke**: u polju **DNS-Server** stoji `192.168.0.53` — računar **DNS-Resolver**. Njemu PC šalje svaki upit za ime.

DNS server možeš pitati i direktno, bez preglednika. Otvori :fa-terminal: **Terminal** i unesi:

```
$ nslookup www.beaver-schule.de
```

`nslookup` prvo prikazuje koji server je pitao, a zatim odgovor. Za usporedbu pitaj za ime koje ne postoji, npr. `nslookup gibtsnicht.beaver-schule.de`.

:::quiz mc
Šta DNS server odgovara na nepoznato ime?
- [ ] Nasumičnu IP adresu
- [x] `NXDOMAIN` — to ime ne postoji
- [ ] Ništa
:::

:::evaluate
Provjeri odgovor
:::

:::tip Zapamti
**DNS** prevodi imena (npr. `www.beaver-schule.de`) u IP adrese. Prije nego što PC može uspostaviti vezu prema imenu, pita **DNS server** koji je upisan u njegovim IP postavkama — najčešće putem **UDP-a, port 53**. Pomoću `nslookup` možeš ručno postavljati DNS upite.
:::

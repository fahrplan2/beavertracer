# Sažetak i pogled naprijed

## Pregled gradivnih elemenata

| Element | Zaštitni cilj | Primjer |
|---|---|---|
| **Simetrična enkripcija** | Povjerljivost | AES šifrira podatke HTTPS veze |
| **Asimetrična enkripcija** | Povjerljivost, razmjena ključeva | Diffie-Hellman, RSA |
| **Hash vrijednosti** | Integritet | SHA-256 kontrolna suma preuzete datoteke |
| **Digitalni potpis** | Autentičnost, integritet | Server potpisuje svoj Diffie-Hellman dio |
| **Certifikat** | Autentičnost | potvrđuje: Ovaj ključ pripada `www.biberbank.de` |

## Isti princip na mnogo mjesta

Ono što si naučio/la na primjeru HTTPS-a nalazi se i u mnogim drugim tehnologijama:

- **WLAN (WPA2/WPA3):** U poglavlju 3.3.2 svaki uređaj u dometu mogao je čitati promet. Kod WPA2 ili WPA3 svaki radijski okvir šifrira se pomoću AES-a; WPA3 osim toga dogovara ključ tako da prisluškivač čak ni uz WLAN lozinku ne može dešifrirati stare snimljene podatke.
- **SSH:** Šifrirano daljinsko upravljanje iz poglavlja 6.6. Umjesto certifikata klijent pri prvom povezivanju pamti **otisak prsta** (fingerprint) serverskog ključa i upozorava ako se kasnije promijeni.
- **VPN:** Šifrirani tunel kroz internet, npr. do školske ili firminske mreže. O tome se radi u poglavlju 10.
- **Messenger aplikacije:** Signal, WhatsApp i druge šifriraju **s kraja na kraj** (end-to-end): čak ni operater usluge ne može čitati poruke.

:::note
Veliki **kvantni računari** mogli bi jednog dana razbiti rastavljanje velikih brojeva na proste faktore — a time i RSA i Diffie-Hellman. Zato se već danas uvode novi, **kvantno sigurni** postupci. Simetrični postupci poput AES-a s dugim ključevima i dalje se smatraju sigurnima.
:::

## Testiraj se

:::quiz mc
Kod HTTPS-a se stvarni podaci šifriraju pomoću …
- [ ] RSA, jer je najsigurniji
- [x] simetričnog postupka poput AES-a i dogovorenog sesijskog ključa
- [ ] privatnog ključa servera
:::

:::quiz mc
Otvaraš `https://www.biberbank.de/`, a preglednik javlja „Certifikat je izdat za `www.gewinn-biber.de`“. Šta radiš?
- [ ] Klikneš na „Ipak nastavi“ — veza je ionako šifrirana
- [x] Prekineš — moguće je da preglednik uopće ne komunicira s bankom
- [ ] Otvoriš stranicu preko `http://`, tada nema upozorenja
:::

:::quiz multi
Koje su tvrdnje tačne?
- [x] Hash vrijednost se potpuno promijeni čak i kad se podaci promijene samo minimalno
- [x] Potpis se generiše privatnim ključem, a provjerava javnim
- [x] Root CA-ovi su unaprijed instalirani u pregledniku odnosno operativnom sistemu
- [ ] Kod HTTPS-a prisluškivač ne može vidjeti čak ni IP adresu servera
- [ ] SMTPS šifrira poštu i na mail serveru
:::

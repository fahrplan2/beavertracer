## Eksperiment

1. Prebaci se u :fa-play: **Pokreni** način rada (Način rada Pokretanje), klikni na **Client-PC** i otvori :fa-globe: **Preglednik**. Otvori `http://192.168.0.20/`.
2. Klikni na **Zurück** na vrhu prozora, otvori **Jednostavni TCP klijent** i poveži ga s `192.168.0.20`, port `5000`. Ostavi vezu otvorenom.
3. Prebaci se u :fa-magnifying-glass: **Trag** način rada, otvori trag za **Client-PC** i klikni na paket sa `[SYN]`. Otvori **Transmission Control Protocol**.

Na samom vrhu TCP zaglavlja nalaze se dva porta: **Source Port** (izvorni port) i **Destination Port** (odredišni port).

:::quiz table
| Veza | Izvorni port | Odredišni port |
|---|---|---|
| Preglednik → web server | {49152} | {80} |
| TCP klijent → Echo servis | {49153} | {5000} |
:::

## Dvije vrste portova

**Odredišni port — servis:** Serverski program čeka veze na fiksnom portu — kaže se da na njemu **osluškuje**. Za poznate servise brojevi su utvrđeni širom svijeta, to su **Well-known portovi** (0 do 1023). Preglednik zato bez pitanja zna: web serveri osluškuju na portu 80.

**Izvorni port — pošiljalac:** Port na strani klijenta operativni sistem za svaku novu vezu sam bira iz visokog raspona (u BeaverTraceru od 49152). Po njemu klijent prepoznaje kojoj od njegovih veza pripada odgovor.

Veza je dakle jednoznačno određena sa četiri podatka: **IP adresa i port na obje strane**. Par koji čine IP adresa i port naziva se **socket**, npr. `192.168.0.20:80`.

## Pogled na server

Vrati se u :fa-play: **Pokreni** način rada, na **Serveru** otvori :fa-terminal: **Terminal** i unesi:

```
$ ss
```

`ss` prikazuje sve sockete računara. Redovi sa `LISTEN` su programi koji osluškuju na nekom portu. Redovi sa `ESTABLISHED` su postojeće veze — s vlastitim socketom (*Local Address:Port*) i socketom druge strane (*Peer Address:Port*).

:::quiz multi
Na kojim portovima server osluškuje?
- [x] 80
- [x] 5000
- [ ] 49152
- [ ] 443
:::

:::quiz mc
Koju vezu `ss` prikazuje kao `ESTABLISHED`?
- [x] `192.168.0.20:5000` sa `192.168.0.10:49153` — otvorena veza TCP klijenta
- [ ] `192.168.0.20:80` sa `192.168.0.10:49152` — veza preglednika
- [ ] Obje
:::

:::note
Veza preglednika je već prekinuta — nakon učitavanja stranice završena je sa `FIN`. `ss` je još kratko prikazuje kao `TIME-WAIT`: server neko vrijeme čeka da li će stići zakašnjeli paketi te veze. Veza TCP klijenta je, nasuprot tome, još otvorena jer još nisi kliknuo na **Prekini vezu**.
:::

## Najvažniji well-known portovi

| Port | Protokol | Servis |
|---|---|---|
| 22 | SSH | sigurno daljinsko održavanje (šifrirana komandna linija) |
| 25 | SMTP | slanje e-mailova |
| 53 | DNS | prevođenje imena u IP adrese (uglavnom preko UDP-a) |
| 80 | HTTP | web stranice |
| 110 | POP3 | preuzimanje e-mailova |
| 143 | IMAP | upravljanje e-mailovima na serveru |
| 443 | HTTPS | šifrirane web stranice |

:::tip Zapamti
**Portovi** (0 do 65535) razdvajaju veze na jednom računaru. Serverski servisi **osluškuju** na fiksnim **well-known portovima** (npr. HTTP 80, HTTPS 443), a klijenti za svaku vezu dobijaju slobodan visoki **izvorni port**. Veza je jednoznačno određena **IP adresom i portom obje strane**.
:::

:::quiz match
22 -> SSH
25 -> SMTP
53 -> DNS
80 -> HTTP
110 -> POP3
143 -> IMAP
443 -> HTTPS
:::

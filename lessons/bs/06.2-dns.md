# DNS: nazivi umjesto brojeva

:::goal
**Ishod učenja:** Možeš objasniti kako DNS prevodi nazive u IP adrese, kako su nazivi hijerarhijski organizirani, sam kreirati unos i pronaći tipične DNS greške.
:::

:::sim
url=/sims/lesson-6.2.btsim
:::

IP adrese jedva da neko može zapamtiti — nazive poput `www.beaver-schule.de` ipak može. Prevođenje obavlja **Domain Name System** (**DNS**), nešto poput svjetskog telefonskog imenika interneta.

Na radnoj površini sada se nalazi nešto veća mreža: pored **Client-PC** i **Webserver** postoje i četiri **DNS-Server**a. Čemu služi toliko njih, vidjet ćeš na stranici nakon sljedeće.

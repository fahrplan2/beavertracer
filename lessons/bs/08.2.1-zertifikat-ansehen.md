# Pregled certifikata

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Na radnoj površini vidiš **Client-PC**, jedan **DNS-Server** i web server škole, `www.beaver-schule.de`. Web server svoje stranice nudi i putem **HTTPS**-a.

## Katanac u pregledniku

1. Pređi u :fa-play: način rada **Pokretanje**, klikni na **Client-PC** i otvori :fa-globe: **Preglednik**.
2. Otvori `https://www.beaver-schule.de/` — obrati pažnju na **https**.
3. Lijevo od adrese pojavljuje se **katanac**. Klikni na njega.

:::quiz short
Za koje ime je certifikat izdat (subjekt bez `CN=`)?
= www.beaver-schule.de
:::

:::quiz short
Ko je izdao certifikat (izdavalac bez `CN=`)?
= Biber Root CA
:::

:::evaluate
Provjeri odgovore
:::

## Zašto Client-PC vjeruje certifikatu?

Na **Client-PC**-u otvori :fa-shield-halved: **Zertifikatverwaltung** i pređi na karticu **Vertrauenswürdige CAs**.

:::quiz mc
Šta tamo pronalaziš?
- [x] Certifikat **Biber Root CA**
- [ ] Certifikat za `www.beaver-schule.de`
- [ ] Nema unosa
:::

:::quiz mc
Po čemu se vidi da je Biber Root CA korijensko tijelo za certifikate (Root-CA)?
- [x] Samopotpisana je (**selbstsigniert**): subjekt i izdavalac su isti
- [ ] Njeno ime završava na „CA“
- [ ] Nema javni ključ
:::

:::quiz mc
Piše li kod Client-PC-a pod **Privater Schlüssel** „Ja“ ili „Nein“?
- [ ] Ja — klijent treba privatni ključ CA da bi provjerio potpise
- [x] Nein — za provjeru je dovoljan javni ključ; privatni ključ ima samo CA
:::

:::evaluate
Provjeri odgovore
:::

## Druga strana: web server

Sada na web serveru **www.beaver-schule.de** otvori :fa-shield-halved: **Zertifikatverwaltung** (kartica **Meine Zertifikate**) i pogledaj njegov certifikat.

:::quiz multi
Šta vrijedi za certifikat na web serveru?
- [x] Pod **Privater Schlüssel** piše „Ja“ — server ga treba za uspostavljanje veze
- [x] **Lanac** glasi `www.beaver-schule.de ← Biber Root CA`
- [x] **Otisak** je isti kao u prozoru s katancem u pregledniku
- [ ] Samopotpisan je
:::

:::evaluate
Provjeri odgovore
:::

:::note
**Otisak** je hash vrijednost certifikata. Pomoću njega se dva certifikata mogu brzo uporediti — bez pojedinačne provjere svih polja.
:::

:::tip Zapamti
**Web server** posjeduje svoj certifikat **s privatnim ključem**. **Klijent** poznaje samo **certifikat korijenskog CA** (bez privatnog ključa) — to mu je dovoljno da provjeri potpis na certifikatu servera. Klikom na **katanac** u pregledniku vide se subjekt, izdavalac, otisak i period važenja.
:::

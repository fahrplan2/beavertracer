# Hash vrijednosti: otisak prsta podataka

:::sim
url=/sims/lesson-8.1.3.btsim
:::

**Hash funkcija** iz proizvoljno velike količine podataka — rečenice, dokumenta, cijelog filma — izračunava kratak niz znakova fiksne dužine: **hash vrijednost**. Ona funkcioniše kao **otisak prsta**: isti podaci uvijek daju istu hash vrijednost, a drugačiji podaci drugačiju.

Danas uobičajena hash funkcija zove se **SHA-256**. Njena hash vrijednost uvijek je dugačka 256 bita, odnosno 64 znaka kao heksadecimalni broj.

## Eksperiment

Na računaru **PC** u direktoriju `/home` nalaze se tri datoteke s malim kupoprodajnim ugovorom. Pređi u :fa-play: način rada **Pokretanje**, otvori na računaru **PC** :fa-terminal: **Terminal** i unesi:

```
$ cd /home
$ cat vertrag.txt vertrag-kopie.txt vertrag-neu.txt
$ sha256sum vertrag.txt vertrag-kopie.txt vertrag-neu.txt
```

## Svojstva hash funkcije

| Svojstvo | Značenje |
|---|---|
| **fiksna dužina** | Bez obzira na veličinu podataka, hash vrijednost uvijek ima istu dužinu. |
| **jednoznačnost** | Isti podaci uvijek daju istu hash vrijednost. |
| **lavinski efekat** | Već i najmanja promjena daje potpuno drugačiju hash vrijednost. |
| **jednosmjerna funkcija** | Iz hash vrijednosti se podaci **ne mogu** ponovo izračunati. |
| **otpornost na kolizije** | Praktično je nemoguće pronaći dvije različite datoteke s istom hash vrijednošću. |

Hash funkcija **nije šifriranje**: nema ključa niti dešifriranja. Ona služi drugoj svrsi — **integritetu**.

## Čemu to služi?

- **Provjera preuzimanja:** Mnoge web stranice pored datoteke navode i njenu SHA-256 vrijednost. Ako se hash vrijednost tvoje preuzete datoteke podudara s njom, datoteka nije izmijenjena na putu.
- **Spremanje lozinki:** Dobre web stranice ne spremaju tvoju lozinku, nego samo njenu hash vrijednost. Pri prijavi se uspoređuje hash vrijednost onoga što si unio. Ako se baza podataka ukrade, lopov ipak ne zna lozinke.
- **Digitalni potpisi:** Umjesto cijelog dokumenta potpisuje se samo njegova hash vrijednost — više o tome u sljedećem odjeljku.

:::tip Zapamti
**Hash funkcija** (npr. **SHA-256**) iz proizvoljnih podataka izračunava **hash vrijednost** fiksne dužine — **otisak prsta**. Već i najmanja promjena daje potpuno drugačiju hash vrijednost, a iz hash vrijednosti se podaci ne mogu ponovo izračunati. Hash vrijednosti osiguravaju **integritet** podataka.
:::

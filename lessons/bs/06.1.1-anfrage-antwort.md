## Kako izgleda zahtjev

Klikni u tragu na paket `GET / HTTP/1.1` i raširi **Hypertext Transfer Protocol**. HTTP zahtjev je čisti tekst:

```
GET / HTTP/1.1              ← Methode, Pfad, Version
Host: 192.168.0.20          ← Header: zusätzliche Angaben
…
                            ← Leerzeile: Ende der Anfrage
```

Odgovor servera je građen na isti način — sa statusnom linijom, headerima, praznim redom i zatim samom datotekom:

```
HTTP/1.1 200 OK             ← Version, Statuscode, Text
Content-Type: text/html     ← Header: Art der Datei
Content-Length: 301         ← Header: Größe in Byte
                            ← Leerzeile
<!doctype html> …           ← die Datei selbst
```

:::seq
mode: text
Client-PC -> Server: GET / | HTTP-zahtjev
Server -> Client-PC: 200 OK | index.html
Client-PC -> Server: GET /style.css | HTTP-zahtjev
Server -> Client-PC: 200 OK | style.css
:::

## Metode i statusni kodovi

**Metoda** govori šta klijent želi:

| Metoda | Značenje |
|---|---|
| **GET** | preuzeti datoteku |
| **POST** | poslati podatke serveru, npr. popunjen obrazac |
| **HEAD** | preuzeti samo headere, bez datoteke |

**Statusni kod** govori kako je prošlo. Prva cifra otkriva vrstu odgovora:

| Kod | Tekst | Značenje |
|---|---|---|
| **200** | OK | sve je u redu |
| **301** | Moved Permanently | stranica je trajno premještena |
| **404** | Not Found | datoteka ne postoji |
| **405** | Method Not Allowed | ova metoda ovdje nije dozvoljena |
| **500** | Internal Server Error | greška na serveru |

`2xx` znači uspjeh, `3xx` preusmjeravanje, `4xx` grešku klijenta (pogrešan zahtjev), `5xx` grešku servera.

:::tip Zapamti
**HTTP** radi po **principu zahtjev-odgovor**: klijent šalje **zahtjev** (metodu poput `GET`, putanju, headere), a server odgovara **statusnim kodom** (npr. `200 OK`, `404 Not Found`), headerima i datotekom. Za svaku datoteku web stranice postoji poseban zahtjev.
:::

# Veza od početka do kraja

:::sim
url=/sims/lesson-5.1.btsim
:::

Na **serveru** radi Echo usluga na portu `5000`: svaku poruku odmah šalje nazad. Pomoću **Jednostavnog TCP klijenta** možeš korak po korak kontrolisati vezu — svako dugme je jedna faza.

## Eksperiment

1. Prebaci se u :fa-play: način rada **Pokreni**, klikni na **Client-PC** i otvori **Jednostavni TCP klijent**.
2. U polje **Host** upiši `192.168.0.20`, a u polje **Port** upiši `5000`.
3. Klikni na **Poveži se**.
4. Upiši `Hello World` u polje za poruku i klikni na **Pošalji**. U prozoru za chat odmah zatim vidiš echo servera.
5. Klikni na **Prekini vezu**.
6. Prebaci se u :fa-magnifying-glass: način rada **Trag** i pomoću **+** otvori trag za **Client-PC**, priključak `eth0`.

:::note
Dva ARP paketa na početku već poznaješ iz poglavlja 1. U koloni **Info** TCP paketa prvo stoji `49152 → 5000` (sa kojeg na koji port), zatim u uglastim zagradama **flagovi**, a poslije toga brojevi poput `Seq=`, `Ack=` i `Len=`. Brojevima se bavimo od stranice 5.2.3 — ovdje obraćaš pažnju na flagove i `Len`.
:::

## Faza 1: Povezivanje

:::quiz short
Koliko je TCP paketa razmijenjeno nakon što si kliknuo/la na **Poveži se** — prije nego što je tvoja poruka poslana?
= 3
= tri
:::

:::quiz mc
Ko šalje prvi paket sa `[SYN]`?
- [x] Client-PC
- [ ] Server
:::

:::quiz mc
Kojim flagovima server odgovara na to?
- [ ] `[SYN]`
- [x] `[SYN, ACK]`
- [ ] `[ACK]`
- [ ] `[FIN, ACK]`
:::

## Faza 2: Slanje

`Len` označava koliko bajtova korisnih podataka nosi paket.

:::quiz short
Koliko bajtova nosi paket s tvojom porukom (`Len`)?
= 13
:::

:::note
`Hello World` ima samo 11 znakova. TCP klijent međutim dodaje kraj reda (2 bajta, `\r\n`) — to očekuju mnogi internetski protokoli poput SMTP-a ili HTTP-a.
:::

:::quiz mc
Šta server šalje nazad direktno nakon tvoje poruke — još prije echa?
- [x] Paket sa `[ACK]` i `Len=0` — potvrdu bez podataka
- [ ] Ništa
- [ ] Novi `[SYN]`
:::

## Faza 3: Prekidanje veze

:::quiz short
Koliko paketa pripada prekidanju veze — počevši od prvog paketa sa `FIN`?
= 4
= četiri
:::

:::quiz mc
Šta jedna strana saopćava sa `FIN`?
- [x] „Završio/la sam“ — više ne šalje podatke
- [ ] „Došlo je do greške“
- [ ] „Evo novih podataka“
:::

:::evaluate
Provjeri odgovore
:::

## Gdje se kriju četiri zadatka?

Poveži gdje u tragu pronalaziš zadatke iz odjeljka 5.1:

:::quiz match
Uspostavljanje veze -> Tri paketa [SYN], [SYN, ACK] i [ACK]
Pouzdan prijenos -> Paketi sa [ACK] i Len=0 koji potvrđuju prijem
Prekidanje veze -> Paketi sa FIN i njihove potvrde
Multipleksiranje -> Brojevi portova 49152 → 5000 ispred uglastih zagrada
:::

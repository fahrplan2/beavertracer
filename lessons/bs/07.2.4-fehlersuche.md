# Otklanjanje grešaka: jučer je još radilo

:::sim
url=/sims/lesson-7.2.4.btsim
:::

Jučer je kućni web server bio dostupan izvana — prosljeđivanje porta `TCP 80 → 192.168.178.10:80` je podešeno. Nakon nestanka struje jutros Clara više ne može otvoriti stranicu. Pronađi grešku i otkloni je trajno.

<details>
<summary>Savjet 1: Na šta pokazuje pravilo?</summary>

Uporedi LAN IP adresu u **Port FW** kućnog rutera s adresom koju **Heim-Webserver** trenutno zaista ima (:fa-gear: **IP Postavke**).
</details>

<details>
<summary>Savjet 2: Zašto ima drugu adresu?</summary>

Je li Heim-Webserver postavljen na **DHCP**? Tada nakon svakog ponovnog pokretanja dobije neku slobodnu adresu iz raspona kućnog rutera (na kartici **DHCP**). Kako ćeš osigurati da uvijek ima istu adresu?
</details>

:::task
title: Je li kućni web server ponovo dostupan?
Provjerava ima li kućni web server svoju fiksnu adresu i može li ga Clara dosegnuti putem prosljeđivanja porta. Simulacija za to mora raditi u načinu rada Pokretanje.
check: ip(11, "192.168.178.10/32")
check: tcpOpen(12, "203.0.113.2", 80)
:::

## Šta se desilo?

:::quiz multi
Koje tvrdnje su tačne?
- [x] Kućni web server je dobio adresu putem DHCP-a i nakon ponovnog pokretanja imao je drugu
- [x] Prosljeđivanje porta je zato pokazivalo na adresu na kojoj više nije radio nijedan server
- [x] Fiksna adresa izvan DHCP raspona trajno rješava problem
- [ ] Provajder je blokirao WAN adresu
:::

:::evaluate
Provjeri odgovor
:::

:::tip Zapamti
Uređaji na koje pokazuje **prosljeđivanje porta** (serveri, štampači, kamere) trebaju **fiksnu adresu**: ili statički unesenu i **izvan DHCP raspona**, ili kao fiksnu dodjelu u DHCP serveru rutera. Inače nakon ponovnog pokretanja možda dobiju drugu adresu — i pravilo vodi u prazno.
:::

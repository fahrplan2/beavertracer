# Sve zajedno: šta se događa kada otvoriš web stranicu?

:::goal
**Ishod učenja:** Možeš korak po korak objasniti koji su protokoli na kojem sloju uključeni kada tek uključeni laptop otvori web stranicu.
:::

:::sim
url=/sims/lesson-6.5.btsim
:::

Sada se spaja sve što si naučio/naučila u ovom kursu. Na switch su spojeni **DHCP-Server**, **DNS-Server**, **Webserver** i **Laptop** koji je upravo uključen — još nema IP adresu i podešen je na DHCP.

## Eksperiment

1. Prebaci se u :fa-play: način rada **Pokretanje** i pričekaj nekoliko sekundi.
2. Klikni na **Laptop**, otvori :fa-globe: **Preglednik** i otvori `http://www.beaver-schule.de/`.
3. U načinu rada :fa-magnifying-glass: **Trag** otvori trag za **Laptop**. Ovdje je cijela priča — od prvog paketa.

Poredaj korake u pravilnom redoslijedu, onako kako stoje u tragu:

:::quiz match
1. korak -> DHCP: Laptop dobiva IP adresu, gateway i DNS server
2. korak -> ARP: Laptop pita za MAC adresu DNS servera
3. korak -> DNS: Laptop pita za IP adresu www.beaver-schule.de
4. korak -> ARP: Laptop pita za MAC adresu web servera
5. korak -> TCP: Trostruko rukovanje (three-way handshake) s web serverom
6. korak -> HTTP: GET / i odgovor 200 OK
:::

A ispod svega nalaze se **IP** (sloj 3), koji adresira svaki od ovih paketa, i **Ethernet** (sloj 2), koji ga dostavlja do sljedećeg uređaja. Da se web server nalazi u drugoj mreži, pridružio bi se i **ruter**: tada bi laptop pitao za MAC adresu svog **gatewaya**, a ne za MAC adresu web servera.

:::tip Zapamti
Iza jednog jedinog klika zajedno rade svi slojevi: **DHCP** isporučuje osnovne postavke, **ARP** pronalazi MAC adrese u lokalnoj mreži, **DNS** prevodi ime, **TCP** uspostavlja pouzdanu vezu, a **HTTP** preuzima stranicu — sve upakovano u **IP** pakete i **Ethernet** okvire.
:::

Time možeš objasniti otvaranje web stranice od prvog do posljednjeg paketa. Za kraj poglavlja slijedi kratak pogled na dodatne protokole. U sljedećim poglavljima bavimo se kućnom mrežom s NAT-om, sigurnošću i šifriranjem — a time i pitanjem kako spriječiti da neko može pročitati sve ove pakete.

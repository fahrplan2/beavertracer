# Kućna mreža: ruter i NAT

:::goal
**Ishod učenja:** Možeš navesti zadatke kućnog rutera, podesiti kućni ruter, objasniti kako NAT omogućava da mnogo uređaja pristupi internetu preko jedne javne adrese te podesiti i provjeriti prosljeđivanje porta.
:::

Kod kuće se u mreži brzo nađe deset ili više uređaja: mobiteli, laptopi, televizor, igraća konzola, zvučnici. Svi dobijaju adrese poput `192.168.178.20` — iz **privatnog** raspona koji se na internetu uopće ne prosljeđuje (poglavlje 4.2.2).A ipak svaki od tih uređaja ima pristup internetu.

To omogućava jedna neugledna kutijica: **kućni ruter**. Na radnoj površini lijevo vidiš kućnu mrežu s jednim računarom i jednim tabletom, a desno „internet“ — rutere jednog provajdera, DNS server i web server `www.beispiel.de`.

:::note
Javne adrese u ovom poglavlju (`203.0.113.…`, `198.51.100.…`, `192.0.2.…`) rezervirane su za primjere i nastavni materijal — baš kao `2001:db8::` kod IPv6.
:::

# HTTP ručno

:::sim
url=/sims/lesson-6.1.btsim
:::

Ako je HTTP običan tekst — može li se onda i sam razgovarati s web serverom, bez ikakvog preglednika? Da: pomoću `telnet` uspostavljaš TCP vezu s bilo kojim portom i sam ukucavaš tekst.

## Eksperiment

1. Pređi u :fa-play: način rada **Pokretanje** i na **Client-PC** otvori :fa-terminal: **Terminal**.
2. Poveži se s portom 80 servera:
   ```
   $ telnet 192.168.0.20 80
   ```
3. Ukucaj zahtjev red po red — i završi ga **praznim redom** (jednostavno još jednom pritisni **Enter**):
   ```
   GET /kontakt.html HTTP/1.1
   Host: 192.168.0.20

   ```

Server odgovara statusnom linijom, zaglavljima i stranicom s kontaktom — kao tekst, baš onako kako je dobija i preglednik.

:::quiz mc
Po čemu server prepoznaje da je tvoj zahtjev završen?
- [ ] Po posebnoj naredbi `END`
- [x] Po praznom redu
- [ ] Nakon određenog vremena
:::

:::quiz short
Koja vrijednost stoji u odgovoru kod zaglavlja `Content-Type`? (samo prvi dio prije `;`)
= text/html
:::

## Izazivanje grešaka

Praktičniji alat je `curl`: on umjesto tebe šalje zahtjev. S opcijom `-v` (*verbose*, detaljan ispis) prikazuje sve što se razmjenjuje — linije s `>` poslao je `curl`, linije s `<` stigle su od servera.

Isprobaj:

```
$ curl -v http://192.168.0.20/gibtsnicht.html
$ curl -X POST -d name=Anna http://192.168.0.20/
```

:::quiz short
Koji statusni kod dobiješ za `/gibtsnicht.html`?
= 404
:::

:::quiz short
A koji za zahtjev s metodom `POST`?
= 405
:::

:::evaluate
Provjeri odgovore
:::

:::note
Web server u BeaverTraceru može samo isporučivati datoteke — zato dozvoljava samo `GET` i `HEAD`. Pravi web serveri pomoću `POST` primaju, na primjer, obrasce i prosljeđuju podatke nekom programu.
:::

:::tip Zapamti
Mnogi protokoli aplikacijskog sloja su **tekstualni** — HTTP, ali i SMTP, POP3 i IMAP. Zato se s njima može razgovarati ručno pomoću `telnet` i pratiti ih u Tragu. To je praktično za otklanjanje grešaka — ali i sigurnosni problem: svako ko snima saobraćaj može sve pročitati. Kako pomaže šifriranje (HTTPS), naučit ćeš u poglavlju 8.
:::

# Posmatranje UDP-a

:::sim

Na **Serveru** ovaj put radi **UDP Echo Server** na portu `5000`. I ovdje je kabel prepravljen: **drugi datagram** od Client-PC-ja prema serveru se gubi.

## Eksperiment

1. Pređi u :fa-play: način rada **Pokreni** i na **Client-PC-ju** otvori :fa-terminal: **Terminal**.
2. Pomoću `nc` pokreni UDP „vezu“ prema serveru (`-u` označava UDP):
   ```
   $ nc -u 192.168.0.20 5000
   ```
3. Redom upiši `eins`, `zwei` i `drei` i svaki put pritisni **Enter**. Svaki red koji se vrati je eho servera.
4. Pričekaj nekoliko sekundi, a zatim u načinu rada :fa-magnifying-glass: **Trag** otvori trag za **Client-PC**.

:::quiz mc
Koji se ehoi vraćaju?
- [ ] Sva tri, `zwei` nešto kasnije
- [x] Samo `eins` i `drei` — `zwei` nedostaje i ne šalje se ponovo
- [ ] Nijedan
:::

:::quiz multi
Koji paketi koje poznaješ iz TCP-a potpuno izostaju kod UDP-a?
- [x] Uspostavljanje veze (`SYN`)
- [x] Potvrde (`ACK`)
- [x] Prekid veze (`FIN`)
- [ ] Paketi s brojevima portova
:::

:::evaluate
Provjeri odgovore
:::

Klikni na jedan od UDP paketa i otvori **User Datagram Protocol**. U poređenju s TCP zaglavljem, UDP zaglavlje je sićušno: **Source Port**, **Destination Port**, **Length** (dužina) i **Checksum** (kontrolni zbir) — zajedno samo 8 bajta. TCP zaglavlje ima najmanje 20 bajta, sa sekvencijskim brojem i brojem potvrde, zastavicama i veličinom prozora.

Koji zadatak iz odjeljka 5.1 UDP ipak obavlja?
- [x] Multipleksiranje — putem portova
- [ ] Uspostavljanje veze
- [ ] Pouzdan prijenos
:::

:::evaluate
Provjeri odgovor

:::tip Zapamti
**UDP** je **bez uspostavljanja veze**: nema uspostavljanja, nema potvrde, nema ponovnog slanja, nema redoslijeda. Nudi samo **portove** (multipleksiranje) i **kontrolni zbir**. Zato je brz i lagan — UDP zaglavlje ima samo 8 bajta. Ako se datagram izgubi, program se mora sam pobrinuti za to — ili mu je svejedno.
:::

## Ping izvana

Prebaci se u :fa-play: način rada **Pokretanje** i pošalji ping sa **Internet-PC** na školski server:

```
$ ping -c 2 198.51.100.10
```

Zatim u firewallu otvori karticu **Protokoll**.

## Skeniranje portova: odbačeno ili odbijeno?

Sada ciljano skeniraj pet portova. Port 3306 (baza podataka) uopće nije u upotrebi na školskom serveru.

```
$ nmap -p 22,25,80,110,3306 198.51.100.10
```

:::quiz match
22 (odbačen) -> filtered
25 (dozvoljen, usluga radi) -> open
110 (odbijen) -> closed
3306 (dozvoljen, nema usluge) -> closed
:::

:::evaluate
Provjeri pridruživanje
:::

:::quiz multi
Šta napadač može zaključiti iz rezultata?
- [x] Kod `filtered` zna: tu se nalazi firewall koji "guta" pakete
- [x] Kod `closed` ne može razlikovati odbija li firewall pakete ili jednostavno nijedna usluga ne radi
- [ ] Kod `filtered` zna koja usluga radi iza porta
- [ ] Kod `closed` je usluga ipak dostupna
:::

:::evaluate
Provjeri odgovore
:::

Na kraju pogledaj kolonu **Treffer** u listi pravila: tu firewall broji koliko je paketa svako pravilo već obradilo. Vrijednost pored **Standardrichtlinie** broji sve pakete za koje nije odgovaralo nijedno pravilo.

:::tip Zapamti
**Odbačeni** paketi nestaju bez traga: `ping` prijavljuje istek vremena, `nmap` prijavljuje `filtered`. Na **odbijene** pakete firewall odgovara odbijanjem (kod TCP-a to je RST) — izvana to izgleda kao zatvoren port. **Zapisnik** firewalla pokazuje koje je pakete zaustavio, a kolona **Treffer** koje je pravilo djelovalo.
:::

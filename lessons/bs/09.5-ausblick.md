# Sažetak i pogled naprijed

## Firewalli na mnogo mjesta

Paketski filter iz ovog poglavlja pronaći ćeš u mnogim uređajima:

- **Kućni ruter:** Svaki kućni ruter je ujedno i firewall sa praćenjem stanja. Kod IPv4 dio toga preuzima NAT: izvana niko ne može započeti vezu sve dok ne postoji prosljeđivanje porta (poglavlje 7). Kod IPv6 svi uređaji imaju javne adrese — tada isti nivo zaštite osigurava samo pravilo firewalla „izvana ništa novo unutra“.
- **Personal Firewall:** I Windows, macOS i Linux imaju ugrađeni firewall na samom računaru. On štiti uređaj i u tuđim mrežama, npr. u WLAN-u nekog kafića, i može postavljati pravila po programu.
- **Next-Generation-Firewall** i **Web Application Firewall (WAF):** Oni ne gledaju samo adrese i portove, nego i sadržaj paketa — sve do aplikacijskog sloja. Tako, na primjer, prepoznaju napade u HTTP zahtjevima. Kod HTTPS-a za to moraju razbiti enkripciju (poglavlje 8).
- **IDS/IPS:** *Intrusion Detection System* prepoznaje sumnjive obrasce u saobraćaju podataka i podiže alarm; *Intrusion Prevention System* ih dodatno i sam blokira.

:::note
Firewall je samo **jedan** element sigurnosti. Ne pomaže ako dozvoljena usluga (npr. web server) sama ima sigurnosnu rupu, ako neko otvori zlonamjerni program iz e-pošte ili ako je lozinka slaba. Zato ažuriranja, sigurne lozinke, enkripcija i pametna podjela mreže (DMZ, VLAN-ovi iz poglavlja 3) uvijek spadaju u cjelinu.
:::

## Testiraj se

:::quiz mc
Firewall radi sa standardnom politikom „Odbaci sve“ i jednim jedinim pravilom „A → B, TCP 443, Dozvoli“. Paket A → B na TCP port 22 stiže do firewalla. Šta se dešava?
- [ ] Bit će dozvoljen
- [x] Bit će odbačen
- [ ] Bit će odbijen
:::

:::quiz mc
`nmap` za neki port javlja `filtered`. Šta to znači?
- [ ] Na portu radi neka usluga
- [ ] Server je odgovorio sa RST
- [x] Nije stigao nikakav odgovor — vjerovatno firewall odbacuje pakete
:::

:::quiz multi
Koje tvrdnje su tačne?
- [x] Kod stateful firewalla odgovori na dozvoljene veze automatski se vraćaju
- [x] Whitelist je sigurnija od blacklista, jer nove usluge automatski ostaju blokirane
- [x] Serveri koji su dostupni s interneta spadaju u DMZ
- [ ] Firewall štiti i od napada između dva računara u istoj mreži iza njega
- [ ] Sva pravila se uvijek provjeravaju, a pobjeđuje najstrože
:::

:::

# DHCP: automatski u mrežu

:::goal
**Ishod učenja:** Možeš objasniti kako uređaj putem DHCP-a automatski dobija svoje IP postavke, podesiti DHCP server te prepoznati i otkloniti tipične DHCP greške (npr. adresu 169.254).
:::

:::sim
url=/sims/lesson-6.4.btsim
:::

Do sada si svakom uređaju ručno upisivao IP adresu, mrežnu masku, gateway i DNS server. U školi sa stotinama laptopa, tableta i mobitela to bi bilo nemoguće — a svaka greška pri kucanju bila bi greška u mreži.

Taj posao preuzima **Dynamic Host Configuration Protocol** (**DHCP**): **DHCP server** automatski dijeli postavke svakom uređaju koji se priključi na mrežu.

# NAT tabela

:::sim
url=/sims/lesson-7.1.btsim
:::

Kada PC i tablet istovremeno učitaju istu web-stranicu, oba zahtjeva stižu do web servera s adrese `203.0.113.2`. Kako kućni ruter zna kome je odgovor namijenjen? On vodi evidenciju — u **NAT tabeli**.

## Eksperiment

1. Prebaci se u :fa-play: način rada **Pokretanje** i na **PC**-u i na **Tablet**-u otvori `http://www.beispiel.de/`.
2. Klikni na **Heimrouter** i otvori karticu **NAT**.

Svaki red je jedno **preslikavanje**: protokol, LAN IP adresa i LAN port uređaja u kućnoj mreži — te **WAN port** koji ruter za to koristi na svojoj javnoj adresi.

:::quiz short
Koja WAN IP adresa piše iznad tabele?
= 203.0.113.2
:::

:::quiz mc
PC i tablet su oba uspostavili vezu s LAN portom `49152`. Koji WAN port dobijaju?
- [ ] Oba isti, `49152`
- [x] Svaki drugi — inače ruter ne bi znao kome pripada odgovor
- [ ] Nikakav, NAT mijenja samo IP adresu
:::

:::quiz mc
Odgovor web servera stiže na `203.0.113.2` s određenim **odredišnim portom**. Šta kućni ruter radi s njim?
- [x] Traži port u NAT tabeli i šalje paket na odgovarajuću LAN IP adresu i LAN port
- [ ] Šalje paket svim uređajima u kućnoj mreži
- [ ] Odbacuje paket
:::

:::evaluate
Provjeri odgovore
:::

Ovdje se ponovo pojavljuju **portovi** iz poglavlja 5: budući da NAT prepisuje i portove, stotine veza mogu dijeliti jednu adresu. Strogo uzevši, ovo se zato zove **PAT** (*Port Address Translation*) ili *NAT s prevođenjem portova* — u svakodnevnom govoru ipak se kaže jednostavno NAT.

Ovako bi, na primjer, mogло izgledati jedno takvo prevođenje:

| | Paket s PC-a (u kućnoj mreži) | isti paket na internetu |
|---|---|---|
| Pošiljalac | `192.168.178.20 : 49152` | `203.0.113.2 : 10001` |
| Primalac | `192.0.2.80 : 80` | `192.0.2.80 : 80` |

:::tip Zapamti
U **NAT tabeli** ruter za svaku vezu pamti koji se uređaj (**LAN IP i LAN port**) krije iza kojeg **WAN porta**. Odgovore s interneta pomoću odredišnog porta ponovo dodjeljuje pravom uređaju. Pošto se prepisuju i portovi, preciznije se govori o **PAT**-u.
:::

# Άνοιγμα και παρατήρηση μιας ιστοσελίδας

Σε αυτό το μέρος δεν φτιάχνεις τίποτα μόνος σου: στον χώρο εργασίας υπάρχει μια έτοιμη προσομοίωση με έναν **Client-PC** και έναν **Webserver**.

## Άνοιγμα της σελίδας

1. Πέρασε στη λειτουργία :fa-play: **Εκτέλεση**.
2. Στον **Client-PC** άνοιξε την εφαρμογή :fa-globe: **Περιηγητής** και πήγαινε στη διεύθυνση του web server: `http://192.168.0.20/`.
3. Πέρασε στη λειτουργία :fa-magnifying-glass: **Ίχνος** και άνοιξε με το **+** ένα trace για τον **Client-PC**, θύρα `eth0`, ακριβώς όπως και με το ping.

:::note
Για ένα μόνο άνοιγμα σελίδας, τα πακέτα είναι εκπληκτικά πολλά, πολύ περισσότερα από ό,τι στο ping. Η λήψη μιας ιστοσελίδας είναι μια διαδικασία πολλών βημάτων, όχι μια μεμονωμένη ενέργεια.
:::

## Ανάγνωση της λίστας πακέτων

Δεν χρειάζεται να ξέρεις ακόμη τι ακριβώς κάνει το κάθε πρωτόκολλο. Ό,τι χρειάζεσαι για τις παρακάτω ερωτήσεις βρίσκεται στις στήλες **Πρωτόκολλο** και **Info**.

:::quiz mc
Ποιο πρωτόκολλο βρίσκεται στην κορυφή της λίστας;
- [x] ARP
- [ ] TCP
- [ ] HTTP
:::

:::quiz short
Μέτρησε: πόσα πακέτα **TCP** υπάρχουν πριν από το πρώτο πακέτο **HTTP**;
= 3
= τρία
:::

:::quiz mc
Τι απαντά ο web server στο αίτημα του περιηγητή; Κοίτα τη στήλη Info του δεύτερου πακέτου HTTP.
- [ ] GET / HTTP/1.1
- [x] HTTP/1.1 200 OK
- [ ] 404 Not Found
:::

:::evaluate
Έλεγχος απαντήσεων
:::

## Ονομασία των πρωτοκόλλων που συμμετέχουν

Από τις παρατηρήσεις σου μπορείς τώρα να καταλάβεις ποιο πρωτόκολλο ήταν υπεύθυνο για τι.

:::tip Συμβουλή
Διάβασε ξανά τις στήλες **Info**: τα `Who has …?`, `[SYN]`, `[SYN, ACK]`, `[ACK]`, `GET /` και `200 OK` σχεδόν τα προδίδουν όλα.
:::

:::quiz match
ARP -> Ρωτά όλους στο δίκτυο: «Ποιος έχει τη διεύθυνση IP 192.168.0.20;»
TCP -> Εγκαθιστά σύνδεση με τρία σύντομα πακέτα πριν αρχίσουν να ρέουν δεδομένα
HTTP -> Ζητά την ιστοσελίδα (GET) και την παραδίδει πίσω (200 OK)
:::

:::evaluate
Έλεγχος αντιστοίχισης
:::

:::tip Βασικό σημείο
Το άνοιγμα μιας ιστοσελίδας γίνεται σε στάδια: πρώτα **εντοπίζεται** ο server στο δίκτυο (ARP), μετά **εγκαθίσταται** μια σύνδεση (TCP), μετά η σελίδα **ζητείται και παραδίδεται** (HTTP) και στο τέλος η σύνδεση **τερματίζεται** ξανά (τα πακέτα TCP με `[FIN]` στο τέλος της λίστας).
:::

:::note
Αυτή τη φορά πληκτρολόγησες απευθείας τη διεύθυνση IP του server, γι' αυτό το **DNS** (η «μετάφραση» ονομάτων όπως `www.beispiel.de` σε διεύθυνση IP) δεν χρησιμοποιήθηκε ακόμη. Θα το δούμε στο κεφάλαιο 6.
:::

Πρόσεξες ότι τα πρωτόκολλα στη δομή του πακέτου φέρουν χρωματιστές σημάνσεις με αριθμούς; Τι σημαίνουν αυτές θα το εξηγήσουμε στο κεφάλαιο 2. Εκεί θα δούμε πώς κατατάσσουμε συστηματικά τα πολλά πρωτόκολλα, με το μοντέλο αναφοράς OSI και το μοντέλο αναφοράς TCP/IP. Και με αυτό, το κεφάλαιο 1 ολοκληρώθηκε.

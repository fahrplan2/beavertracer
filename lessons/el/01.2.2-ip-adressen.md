# Εκχώρηση διευθύνσεων IP

:::sim
url=/sims/lesson-1.2.2.btsim
:::

Για να μπορούν δύο συσκευές να επικοινωνούν μεταξύ τους, χρειάζονται μια διεύθυνση IP στο ίδιο δίκτυο. Στον χώρο εργασίας βλέπεις δύο συνδεδεμένα PC, ακριβώς όπως τα έφτιαξες μόλις μόνος σου.

1. Πέρασε στη λειτουργία :fa-play: **Εκτέλεση** και κάνε κλικ στο **Computer 1** για να το ανοίξεις.
2. Άνοιξε εκεί τις :fa-gear: **Ρυθμίσεις IP**. Ένα καινούργιο PC έχει ήδη τη διεύθυνση `192.168.0.10` με μάσκα δικτύου `/24`. Μπορείς να την αφήσεις όπως είναι.
3. Άνοιξε τώρα το **Computer 2**. Έχει την *ίδια* διεύθυνση `192.168.0.10`. Αυτό δεν μπορεί να λειτουργήσει, γιατί κάθε διεύθυνση επιτρέπεται να εμφανίζεται μόνο μία φορά στο δίκτυο. Άλλαξέ τη σε `192.168.0.11` (μάσκα δικτύου `/24`).

:::tip Βασικό σημείο
Μια **διεύθυνση IP** (π.χ. `192.168.0.10`) είναι η διεύθυνση μιας συσκευής στο δίκτυο, κάτι σαν τον αριθμό ενός σπιτιού. Κάθε διεύθυνση IP επιτρέπεται να εμφανίζεται σε ένα δίκτυο μόνο **μία φορά**.
:::

:::task
title: Σωστή εκχώρηση διευθύνσεων;
Μείνε στη λειτουργία εκτέλεσης και έλεγξε αν και τα δύο PC έχουν κατάλληλες διευθύνσεις και αν επικοινωνούν μεταξύ τους.
check: ip(1, "192.168.0.10/32")
check: ip(3, "192.168.0.11/32")
check: pingOk(1, 3)
:::

:::note
Τι ακριβώς σημαίνει το `/24` και πώς χωρίζουμε σωστά ένα δίκτυο θα το συζητήσουμε αναλυτικά στο κεφάλαιο 4. Προς το παρόν αρκεί να ξέρεις ότι και οι δύο διευθύνσεις πρέπει να ξεκινούν με `192.168.0.` και δεν πρέπει να επαναλαμβάνονται.
:::

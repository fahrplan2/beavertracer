# Σειρά και βασική φιλοσοφία

## Πρώτα η εξαίρεση, μετά ο κανόνας

Επειδή κερδίζει ο **πρώτος κανόνας που ταιριάζει**, η σειρά έχει σημασία. Δες αυτή τη λίστα κανόνων (όλοι οι κανόνες ισχύουν για την κατεύθυνση A → B, προεπιλεγμένη πολιτική: Αποδοχή όλων):

| Αρ. | Πρωτόκολλο | Θύρα προορισμού | Ενέργεια |
|---|---|---|---|
| 1 | TCP | οποιαδήποτε | Απόρριψη |
| 2 | TCP | 80 | Αποδοχή |

:::quiz mc
Φτάνει ένα πακέτο από το Internet στη θύρα TCP 80. Τι συμβαίνει;
- [ ] Γίνεται δεκτό, επειδή ο κανόνας 2 επιτρέπει ακριβώς τη θύρα 80
- [x] Απορρίπτεται, επειδή ταιριάζει ήδη ο κανόνας 1 — ο κανόνας 2 δεν εξετάζεται ποτέ
- [ ] Το firewall ρωτάει τον διαχειριστή
:::

:::evaluate
Έλεγχος απάντησης
:::

Γενικά ισχύει: **Οι ειδικοί κανόνες πάνε πάνω, οι γενικοί κάτω.** Ένας κανόνας που καλύπτει πολλά «επισκιάζει» όλους τους κανόνες κάτω από αυτόν. Η στήλη **Αντιστοιχίσεις** αποκαλύπτει τέτοιους νεκρούς κανόνες: Μένουν στο 0.

## Blacklist ή Whitelist;

Στην ενότητα 9.1.2 **απαγόρευσες** μεμονωμένες θύρες και επέτρεψες όλα τα υπόλοιπα. Αυτό ονομάζεται **Blacklist** («μαύρη λίστα»). Το αντίθετο είναι η **Whitelist**: **Επιτρέπεις** μόνο τα απαραίτητα και απαγορεύεις όλα τα υπόλοιπα — με έναν τελικό κανόνα «απόρριψη όλων» ή με την προεπιλεγμένη πολιτική **Απόρριψη όλων**.

| | Blacklist | Whitelist |
|---|---|---|
| Βασική φιλοσοφία | όλα επιτρέπονται, οι εξαιρέσεις απαγορεύονται | όλα απαγορεύονται, οι εξαιρέσεις επιτρέπονται |
| Προεπιλεγμένη πολιτική | Αποδοχή | Απόρριψη |
| νέα υπηρεσία στον server | είναι αμέσως προσβάσιμη απ' έξω | παραμένει μπλοκαρισμένη, μέχρι κάποιος να την επιτρέψει |

:::quiz mc
Ένας καθηγητής εγκαθιστά αύριο στον server του σχολείου μια βάση δεδομένων που ακούει στη θύρα 3306. Τι συμβαίνει με το firewall της ενότητας 9.1.2 (Blacklist);
- [x] Η βάση δεδομένων είναι αμέσως προσβάσιμη από το Internet
- [ ] Η βάση δεδομένων μπλοκάρεται αυτόματα
- [ ] Το firewall αναφέρει τη νέα υπηρεσία
:::

:::evaluate
Έλεγχος απάντησης
:::

Γι' αυτό τα καλά firewalls λειτουργούν με την **αρχή της Whitelist** («Default Deny»): Ό,τι δεν επιτρέπεται ρητά, απαγορεύεται. Μια Whitelist για τον server του σχολείου θα έμοιαζε έτσι:

:::quiz table
| Αρ. | Κατεύθυνση | Πρωτόκολλο | Θύρα προορισμού | Ενέργεια |
|---|---|---|---|---|
| 1 | A → B | TCP | {80} | {Αποδοχή} |
| 2 | A → B | TCP | {25} | Αποδοχή |
| 3 | A → B | οποιοδήποτε | οποιαδήποτε | {Απόρριψη} |
:::

:::evaluate
Έλεγχος πίνακα
:::

:::quiz mc
Τι συμβαίνει αν μετακινήσεις τον κανόνα 3 τελείως στην κορυφή;
- [ ] Τίποτα, η σειρά δεν έχει σημασία
- [x] Από το Internet δεν περνάει πια τίποτα, ούτε web ούτε mail
- [ ] Περνούν μόνο web και mail
:::

:::evaluate
Έλεγχος απάντησης
:::

:::tip Βασικό σημείο
Επειδή κερδίζει ο **πρώτος κανόνας που ταιριάζει**, οι **ειδικοί κανόνες πάνε πάνω** και οι γενικοί κάτω. Πιο ασφαλής από μια **Blacklist** (όλα επιτρέπονται εκτός από …) είναι μια **Whitelist** (όλα απαγορεύονται εκτός από …, *Default Deny*): Έτσι, ξεχασμένες ή νέες υπηρεσίες παραμένουν αυτόματα μπλοκαρισμένες.
:::

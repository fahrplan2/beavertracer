# Υποδικτύωση

:::goal
**Μαθησιακός στόχος:** Μπορείς να αιτιολογήσεις γιατί χωρίζουμε τα δίκτυα, να χωρίσεις ένα δίκτυο σε ισομεγέθη υποδίκτυα και να υλοποιήσεις τα υποδίκτυα σε ένα δίκτυο με δρομολογητή.
:::

:::sim
url=/sims/lesson-4.4.2.btsim
:::

Ένα σχολείο παίρνει για το δίκτυό του την περιοχή διευθύνσεων `192.168.10.0/24`, που αρκεί για 254 συσκευές. *Θα μπορούσε* κανείς να βάλει όλες τις συσκευές σε αυτό το ένα δίκτυο. Συνήθως όμως είναι καλύτερο να το χωρίσεις σε περισσότερα μικρότερα δίκτυα. Αυτή η διαδικασία ονομάζεται **υποδικτύωση** (subnetting) και τα μικρότερα δίκτυα **υποδίκτυα** (*subnets*).

Γιατί αξίζει τον κόπο;

- **Ασφάλεια:** Η διοίκηση, οι εκπαιδευτικοί και οι μαθητές και μαθήτριες βρίσκονται σε ξεχωριστά δίκτυα. Ανάμεσα στα δίκτυα υπάρχει ένας δρομολογητής. Εκεί μπορείς να ορίσεις με ακρίβεια ποιος επιτρέπεται να πάει πού.
- **Λιγότερες γενικές εκπομπές:** Κάθε γενική εκπομπή (broadcast, π.χ. κάθε αίτημα ARP) φτάνει σε *όλες* τις συσκευές του ίδιου δικτύου. Μικρότερα δίκτυα σημαίνουν λιγότερη περιττή κίνηση.
- **Εποπτεία:** Από τη διεύθυνση καταλαβαίνεις αμέσως πού ανήκει μια συσκευή.

:::note
Θυμάσαι τα VLANs από το κεφάλαιο 3.2; Τα VLANs διαχωρίζουν τα δίκτυα στο **επίπεδο 2**, ενώ η υποδικτύωση τα διαχωρίζει στο **επίπεδο 3**. Στην πράξη συνήθως πάνε μαζί: κάθε VLAN παίρνει το δικό του υποδίκτυο.
:::

# Το δυαδικό σύστημα

Στο εσωτερικό του, ένας υπολογιστής γνωρίζει μόνο δύο καταστάσεις: ρεύμα ή καθόλου ρεύμα. Τις γράφουμε ως **1** και **0**. Ένα τέτοιο ψηφίο λέγεται **bit**. Και κάθε διεύθυνση IP είναι για τον υπολογιστή απλώς μια σειρά από μηδενικά και άσσους. Για να καταλάβεις πώς λειτουργούν οι μάσκες δικτύου, σε αυτή τη σελίδα μαθαίνεις να διαβάζεις τέτοιους αριθμούς και να τους μετατρέπεις μόνος σου.

## Πώς μετράμε συνήθως: το δεκαδικό σύστημα

Στην καθημερινότητα υπολογίζουμε με δέκα ψηφία (0 έως 9). Κάθε θέση αξίζει δέκα φορές περισσότερο από τη θέση στα δεξιά της: μονάδες, δεκάδες, εκατοντάδες, χιλιάδες. Ο αριθμός `305` σημαίνει λοιπόν:

| Αξία θέσης | 100 | 10 | 1 |
|---|---|---|---|
| Ψηφίο | 3 | 0 | 5 |
| Τιμή | 300 | 0 | 5 |

300 + 0 + 5 = **305**

## Το δυαδικό σύστημα

Στο **δυαδικό σύστημα** (αγγλ. *binary*) υπάρχουν μόνο δύο ψηφία: 0 και 1. Κάθε θέση αξίζει τα **διπλάσια** από τη θέση στα δεξιά της: 1, 2, 4, 8, 16, 32, 64, 128 …

Ο δυαδικός αριθμός `00001101` σημαίνει λοιπόν:

| Αξία θέσης | 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1 |
|---|---|---|---|---|---|---|---|---|
| Bit | 0 | 0 | 0 | 0 | 1 | 1 | 0 | 1 |
| Τιμή | | | | | 8 | 4 | | 1 |

8 + 4 + 1 = **13**

Απλώς προσθέτεις τις αξίες θέσης στις οποίες υπάρχει 1.

:::tip Βασικό σημείο
Ένα **bit** είναι ένα ψηφίο στο δυαδικό σύστημα (0 ή 1). **8 bit** αποτελούν ένα **byte**. Στα δίκτυα, μια τέτοια ομάδα των 8 bit λέγεται και **οκτάδα**. Οι αξίες θέσης μιας οκτάδας είναι **128, 64, 32, 16, 8, 4, 2, 1**.
:::

:::quiz short
Ποιος δεκαδικός αριθμός είναι το `00000110`;
= 6
:::

:::quiz short
Ποιος δεκαδικός αριθμός είναι το `10000001`;
= 129
:::

:::quiz fill
Με μία οκτάδα (8 bit) μπορείς να αναπαραστήσεις τους αριθμούς από {0} έως {255}.
:::

## Από δεκαδικό σε δυαδικό

Για την αντίστροφη μετατροπή, περνάς τις αξίες θέσης από αριστερά προς τα δεξιά και ρωτάς κάθε φορά: **Χωράει ακόμα η αξία θέσης στον (εναπομείναντα) αριθμό μου;** Αν ναι, γράφεις 1 και αφαιρείς την αξία θέσης. Αν όχι, γράφεις 0.

Παράδειγμα: `168`

| Αξία θέσης | χωράει στο …; | Bit | Υπόλοιπο |
|---|---|---|---|
| 128 | 168 → ναι | **1** | 40 |
| 64 | 40 → όχι | **0** | 40 |
| 32 | 40 → ναι | **1** | 8 |
| 16 | 8 → όχι | **0** | 8 |
| 8 | 8 → ναι | **1** | 0 |
| 4 | 0 → όχι | **0** | 0 |
| 2 | 0 → όχι | **0** | 0 |
| 1 | 0 → όχι | **0** | 0 |

Διαβάζοντας από πάνω προς τα κάτω: 168 = **10101000**

## Εξάσκηση

Εδώ παίρνεις καινούργιους αριθμούς σε κάθε προσπάθεια. Εξασκήσου μέχρι να το έχεις κατακτήσει.

:::quiz random dec2bin
count=3
:::

:::quiz random bin2dec
count=3
:::

:::evaluate
Έλεγχος απαντήσεων
:::

:::tip Συμβουλή
Αυτές τις τιμές θα τις συναντάς ξανά και ξανά στις μάσκες δικτύου, γι' αυτό αξίζει να τις ξέρεις: `10000000` = 128, `11000000` = 192, `11100000` = 224, `11110000` = 240, `11111000` = 248, `11111100` = 252, `11111110` = 254, `11111111` = 255.
:::

## Διευθύνσεις IP στο δυαδικό σύστημα

Μια διεύθυνση IPv4 αποτελείται από **32 bit**, δηλαδή τέσσερις οκτάδες. Επειδή κανείς δεν μπορεί να θυμάται 32 μηδενικά και άσσους, γράφουμε κάθε οκτάδα ως δεκαδικό αριθμό και τις χωρίζουμε με τελείες:

```
11000000 . 10101000 . 10110010 . 00000001
   192   .   168    .   178    .    1
```

:::quiz short
Από πόσα bit αποτελείται μια διεύθυνση IPv4;
= 32
:::

:::quiz mc
Πόσες διαφορετικές διευθύνσεις IPv4 υπάρχουν θεωρητικά;
- [ ] 256 × 4 = 1024
- [x] 2³², περίπου 4,3 δισεκατομμύρια
- [ ] Υπεραρκετές: μερικές για κάθε άνθρωπο στη Γη
:::

:::evaluate
Έλεγχος απαντήσεων
:::

:::note
Τα 4,3 δισεκατομμύρια περίπου ακούγονται πολλά, όμως είναι λιγότερα από μία διεύθυνση ανά άνθρωπο στη Γη. Γι' αυτό οι διευθύνσεις IPv4 σπανίζουν εδώ και πολύ καιρό. Πώς αντιμετωπίζεται αυτό θα το μάθεις αργότερα, με το NAT και το IPv6.
:::

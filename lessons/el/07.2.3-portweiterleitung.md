# Από έξω προς τα μέσα: προώθηση θύρας

:::sim
url=/sims/lesson-7.2.3.btsim
:::

Στο οικιακό δίκτυο υπάρχει τώρα ένας δικός του **Heim-Webserver** (`192.168.178.10`). Η Clara θέλει να ανοίγει τη σελίδα όταν είναι εκτός σπιτιού. Το λάπτοπ της, **Clara**, βρίσκεται δεξιά στο διαδίκτυο.

## Το πρόβλημα

1. Πέρασε στη λειτουργία :fa-play: **Εκτέλεση**. Στο **Clara**, άνοιξε στην εφαρμογή :fa-globe: **Περιηγητής** τη διεύθυνση `http://203.0.113.2/`, δηλαδή τη δημόσια διεύθυνση του οικιακού δικτύου.
2. Ο περιηγητής περιμένει και περιμένει. Μετά από μερικά δευτερόλεπτα, κάνε κλικ στο **Διακοπή**.
3. Στη λειτουργία :fa-magnifying-glass: **Ίχνος**, άνοιξε ένα ίχνος για τον **Heimrouter**, διεπαφή `wan0`.

:::quiz mc
Τι συμβαίνει με την εγκατάσταση σύνδεσης της Clara (`[SYN]` προς τη θύρα 80);
- [x] Φτάνει στον οικιακό δρομολογητή, αλλά αυτός δεν την προωθεί και δεν απαντά
- [ ] Φτάνει στον οικιακό διακομιστή ιστού, ο οποίος απαντά με RST
- [ ] Δεν φτάνει καν στον οικιακό δρομολογητή
:::

:::evaluate
Έλεγχος απάντησης
:::

Για ένα πακέτο που έρχεται από έξω δεν υπάρχει καταχώριση στον πίνακα NAT, γιατί κανείς στο οικιακό δίκτυο δεν ξεκίνησε αυτή τη σύνδεση. Ο οικιακός δρομολογητής δεν ξέρει σε ποια συσκευή να το στείλει και το απορρίπτει.

## Ρύθμιση της προώθησης θύρας

Με μια **προώθηση θύρας** (σε ορισμένους δρομολογητές λέγεται *άνοιγμα θύρας*) ορίζεις ότι ό,τι φτάνει σε μια συγκεκριμένη θύρα WAN πηγαίνει σε μια συγκεκριμένη συσκευή στο οικιακό δίκτυο.

1. Κάνε κλικ στον **Heimrouter** και άνοιξε την καρτέλα **Port FW**.
2. Δημιούργησε έναν κανόνα: πρωτόκολλο `TCP`, θύρα WAN `80`, IP LAN `192.168.178.10`, θύρα LAN `80`. Μετά κάνε κλικ στο **+ Προσθήκη**.
3. Άνοιξε ξανά στο **Clara** τη διεύθυνση `http://203.0.113.2/`.

:::task
title: Είναι ο Heim-Webserver προσβάσιμος από έξω;
Ελέγχει αν η Clara μπορεί να εγκαταστήσει από το διαδίκτυο σύνδεση με τη θύρα 80 της δημόσιας διεύθυνσης του οικιακού δικτύου. Για τον έλεγχο αυτό, η προσομοίωση πρέπει να τρέχει σε Λειτουργία εκτέλεσης.
check: tcpOpen(12, "203.0.113.2", 80)
:::

:::warning
Μια προώθηση θύρας ανοίγει μια τρύπα προς τα μέσα. Οποιοσδήποτε στο διαδίκτυο μπορεί να φτάσει στη συσκευή που βρίσκεται πίσω της, ακόμα και επιτιθέμενοι που ψάχνουν αυτόματα για ανοιχτές θύρες. Γι' αυτό προώθησε μόνο ό,τι είναι πραγματικά απαραίτητο και κράτα τη συσκευή ενημερωμένη. Περισσότερα θα βρεις στο κεφάλαιο 9 (τείχος προστασίας).
:::

:::tip Βασικό σημείο
Από έξω κανείς δεν μπορεί να ξεκινήσει σύνδεση προς μια συσκευή πίσω από NAT, γιατί ο δρομολογητής δεν ξέρει πού να τη στείλει. Μια **προώθηση θύρας** ορίζει ότι τα πακέτα που φτάνουν σε μια συγκεκριμένη **θύρα WAN** πηγαίνουν σε μια συγκεκριμένη **IP LAN** (και μια θύρα LAN). Έτσι ένας διακομιστής στο οικιακό δίκτυο γίνεται προσβάσιμος από το διαδίκτυο.
:::

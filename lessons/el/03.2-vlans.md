# VLANs: ένας switch, πολλά δίκτυα

:::goal
**Μαθησιακός στόχος:** Μπορείς να εξηγήσεις σε τι χρησιμεύουν τα VLANs, να ρυθμίσεις VLANs σε έναν switch και να συνδέσεις VLANs σε πολλούς switches μέσω ενός trunk.
:::

Σε ένα σχολείο, οι υπολογιστές της διοίκησης είναι συχνά συνδεδεμένοι στον ίδιο switch με τους υπολογιστές της αίθουσας υπολογιστών. Πρακτικό — αλλά πρέπει πραγματικά οι μαθητές και οι μαθήτριες να έχουν άμεση πρόσβαση στον υπολογιστή της γραμματείας, όπου είναι αποθηκευμένοι βαθμοί και διευθύνσεις;

Θα μπορούσε κανείς να αγοράσει έναν ξεχωριστό switch για τη διοίκηση και να περάσει ξεχωριστά καλώδια. Υπάρχει όμως και πιο απλός τρόπος: χωρίζεις *έναν* switch σε πολλά δίκτυα, ξεχωριστά μεταξύ τους — σε **VLANs**.

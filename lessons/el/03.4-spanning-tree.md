# Βρόχοι στο δίκτυο και Spanning Tree

:::goal
**Μαθησιακός στόχος:** Μπορείς να εξηγήσεις πώς δημιουργείται μια καταιγίδα γενικής εκπομπής (broadcast storm) σε ένα δίκτυο με βρόχο και πώς το Spanning Tree Protocol (STP) αποτρέπει τους βρόχους χωρίς να θυσιάζει την ανοχή σε σφάλματα.
:::

:::sim
url=/sims/lesson-3.4.1.btsim
:::

Τι συμβαίνει όταν χαλάσει ένα καλώδιο σε ένα δίκτυο; Αν όλα εξαρτώνται από μία μόνο γραμμή, ένα μέρος του δικτύου αποκόπτεται. Γι' αυτό, σε μεγαλύτερα δίκτυα τα switches συνδέονται συχνά **περισσότερες από μία φορές**, όπως τα τρία switches στον χώρο εργασίας, που σχηματίζουν έναν δακτύλιο. Αν ένα καλώδιο σταματήσει να λειτουργεί, υπάρχει εναλλακτική διαδρομή.

Ακούγεται καλό, όμως ένας τέτοιος δακτύλιος κρύβει μια επικίνδυνη παγίδα. Θα τη γνωρίσεις στην επόμενη σελίδα.

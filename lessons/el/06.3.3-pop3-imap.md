# POP3 ή IMAP;

:::sim
url=/sims/lesson-6.3.btsim
:::

Για τη λήψη της αλληλογραφίας υπάρχουν δύο πρωτόκολλα. Σε αυτή την προσομοίωση, η **Anna χρησιμοποιεί POP3** και ο **Ben IMAP**.

## Το πείραμα

1. Στη :fa-play: λειτουργία **Εκτέλεση**, στείλε ένα e-mail από τον **Ben** στη διεύθυνση `anna@beaver-schule.de`.
2. Στην εφαρμογή **E-Mail** της **Anna**, κάνε κλικ στο **Λήψη**.
3. Άνοιξε ίχνη για την **Anna** και για τον **Ben** και σύγκρινε τις εντολές που χρησιμοποιούνται κατά τη λήψη.

:::quiz match
USER / PASS -> POP3: σύνδεση με όνομα χρήστη και κωδικό πρόσβασης σε δύο βήματα
RETR -> POP3: λήψη ενός μηνύματος
LOGIN -> IMAP: σύνδεση με όνομα χρήστη και κωδικό πρόσβασης
SELECT INBOX -> IMAP: άνοιγμα ενός φακέλου στον server
:::

Έλεγχος αντιστοίχισης
:::

## Η διαφορά

| | POP3 | IMAP |
|---|---|---|
| Θύρα | 110 | 143 |
| Βασική ιδέα | Τα e-mail **κατεβαίνουν** στη συσκευή — μετά συνήθως διαγράφονται από τον server | Τα e-mail **παραμένουν στον server** και η διαχείρισή τους γίνεται εκεί |
| Φάκελοι, αναγνωσμένα/μη αναγνωσμένα | μόνο στη δική σου συσκευή | στον server — ίδια παντού |
| Πολλές συσκευές (κινητό, laptop) | μη πρακτικό: κάθε συσκευή έχει διαφορετική κατάσταση | ιδανικό: όλες οι συσκευές βλέπουν το ίδιο γραμματοκιβώτιο |

:::note
Το πρόγραμμα e-mail του BeaverTracer αφήνει τα e-mail στον server ακόμη και με POP3. Τα πραγματικά προγράμματα συχνά τα διαγράφουν μετά τη λήψη — ή τα αφήνουν εκεί μόνο για λίγο καιρό.
:::

:::quiz mc
Η Lena διαβάζει τα e-mail της στο κινητό, στο tablet και στο σχολικό laptop. Τι πρέπει να χρησιμοποιήσει;
- [ ] POP3, επειδή είναι πιο απλό
- [x] IMAP, επειδή όλες οι συσκευές βλέπουν το ίδιο γραμματοκιβώτιο στον server
- [ ] SMTP, επειδή προορίζεται για τη λήψη
:::

:::evaluate
Έλεγχος απάντησης
:::

:::tip Βασικό σημείο
Το **POP3** κατεβάζει τα e-mail από τον server σε **μία** συσκευή. Το **IMAP** διαχειρίζεται το γραμματοκιβώτιο **στον server** — με φακέλους και κατάσταση ανάγνωσης για όλες τις συσκευές ταυτόχρονα. Και τα δύο χρησιμεύουν μόνο για τη **λήψη**· η αποστολή γίνεται πάντα με **SMTP**.
:::

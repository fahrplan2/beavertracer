# Ρύθμιση HTTPS

:::sim
url=/sims/lesson-8.3.3.btsim
:::

Εδώ συνεχίζουμε από εκεί που σταμάτησε η ενότητα 8.2.2: Στον web server **www.beaver-schule.de** βρίσκονται η **Schul-CA** και ένα πιστοποιητικό διακομιστή που έχει εκδώσει αυτή, και ο **Client-PC** εμπιστεύεται τη Schul-CA. Ο web server όμως δεν υποστηρίζει ακόμη HTTPS.

## Πριν

Πέρασε στη λειτουργία :fa-play: **Εκτέλεση** και άνοιξε στον **Client-PC** στον :fa-globe: **Περιηγητής** τη διεύθυνση `https://www.beaver-schule.de/`.

:::quiz mc
Τι συμβαίνει;
- [x] Η σύνδεση δεν πραγματοποιείται — καμία υπηρεσία δεν ακούει στη θύρα 443
- [ ] Ο περιηγητής προειδοποιεί για μη ασφαλές πιστοποιητικό
- [ ] Η σελίδα εμφανίζεται χωρίς λουκέτο
:::

:::evaluate
Έλεγχος απάντησης
:::

## Ενεργοποίηση HTTPS

1. Άνοιξε στον web server το **HTTP-Server** και κάνε κλικ στο **Διακοπή** — όσο ο server λειτουργεί, οι ρυθμίσεις δεν μπορούν να αλλάξουν.
2. Μετάβαση στην καρτέλα **HTTPS**:
    - Τσέκαρε το **Ενεργοποίηση HTTPS**, **Θύρα HTTPS** `443`
    - Στο **Πιστοποιητικό** επίλεξε το πιστοποιητικό διακομιστή `www.beaver-schule.de` — όχι τη Schul-CA!
    - Κάνε κλικ στο **Χρήση**
3. Κάνε κλικ στο **Έναρξη**.

Άνοιξε ξανά τη σελίδα στον Client-PC μέσω `https://`. Κάνε κλικ στο λουκέτο και έλεγξε τον εκδότη και την περίοδο ισχύος.

:::task
title: Ρυθμίστηκε το HTTPS;
Ελέγχει αν ο Client-PC μπορεί να ανοίξει τη https://www.beaver-schule.de/ χωρίς προειδοποίηση πιστοποιητικού. Για αυτό η προσομοίωση πρέπει να τρέχει σε λειτουργία εκτέλεσης.
check: httpsOk(2, "https://www.beaver-schule.de/")
:::

:::quiz mc
Γιατί δεν πρέπει να επιλέξεις στο HTTP-Server το πιστοποιητικό της **Schul-CA**;
- [ ] Επειδή τα πιστοποιητικά CA δεν μπορούν να κρυπτογραφήσουν
- [x] Επειδή έχει εκδοθεί για το όνομα `Schul-CA` και όχι για το `www.beaver-schule.de` — ο περιηγητής θα έβγαζε προειδοποίηση
- [ ] Επειδή η Schul-CA δεν έχει ιδιωτικό κλειδί
:::

:::quiz mc
Τι θα έβλεπε μια συσκευή που **δεν** εμπιστεύεται τη Schul-CA, π.χ. το κινητό ενός επισκέπτη;
- [ ] Τη σελίδα κανονικά με λουκέτο
- [x] Μια προειδοποίηση πιστοποιητικού, επειδή δεν μπορεί να ακολουθήσει την αλυσίδα εμπιστοσύνης μέχρι μια γνωστή CA
- [ ] Τίποτα απολύτως, επειδή η σύνδεση απορρίπτεται
:::

:::evaluate
Έλεγχος απαντήσεων
:::

:::note
Για δημόσιες ιστοσελίδες χρειάζεται πιστοποιητικό από μια CA που είναι προεγκατεστημένη σε όλους τους περιηγητές. Από το 2015 υπάρχει η **Let's Encrypt**, μια CA που εκδίδει τέτοια πιστοποιητικά δωρεάν και αυτόματα — ένας από τους βασικούς λόγους που σήμερα σχεδόν όλες οι ιστοσελίδες χρησιμοποιούν HTTPS.
:::

:::tip Βασικό σημείο
Για το **HTTPS** ο web server χρειάζεται ένα **πιστοποιητικό διακομιστή με ιδιωτικό κλειδί**, του οποίου το όνομα ταιριάζει με τη διεύθυνση, και πρέπει να ακούει στη **θύρα 443**. Ο client εμπιστεύεται τη σελίδα μόνο αν γνωρίζει την **CA** που την εξέδωσε.
:::

# Στον αέρα ακούνε όλοι

:::sim

Τώρα υπάρχουν δύο tablet στο Wi-Fi `Schule`: η **Anna** (`192.168.0.30`) και ο **Ben** (`192.168.0.31`).

Θυμήσου το κεφάλαιο 3.1: Όταν η Anna έκανε ping στον Ben μέσω του switch, η Clara δεν πήρε είδηση τίποτα — το switch έστειλε τα ping μόνο στη θύρα του Ben. Ισχύει το ίδιο και στο Wi-Fi; Σκέψου για λίγο τι περιμένεις.

## Το πείραμα

1. Πέρασε στη λειτουργία :fa-play: **Εκτέλεση** και κάνε ping από την **Anna** στον υπολογιστή του σχολείου (`ping 192.168.0.10`).
2. Πέρασε στη λειτουργία :fa-magnifying-glass: **Ίχνος** και άνοιξε με το **+** ένα ίχνος για τον **Ben**, θύρα `wlan0`.

:::quiz mc
Τι βλέπεις στον Ben;
- [ ] Μόνο το αίτημα ARP της Anna — όπως και με το switch
- [x] Όλα τα πακέτα μεταξύ της Anna και του υπολογιστή του σχολείου, ακόμα και τα ping
- [ ] Απολύτως τίποτα, τα ping δεν αφορούν τον Ben
:::

## Τι κρύβεται από πίσω

Τα ραδιοκύματα διαδίδονται προς όλες τις κατευθύνσεις. Γι' αυτό, ό,τι στέλνει η Anna φτάνει σε *κάθε* συσκευή που βρίσκεται κοντά — όχι μόνο στο σημείο πρόσβασης. Η ασύρματη μετάδοση είναι ένα **κοινόχρηστο μέσο**. Το tablet του Ben κανονικά αγνοεί ό,τι δεν απευθύνεται σε αυτό. Όμως όποιος *θέλει* να καταγράψει την κίνηση μπορεί να διαβάσει τα πάντα.

| | Switch (καλώδιο) | Wi-Fi (ασύρματο) |
|---|---|---|
| Ποιος λαμβάνει ένα unicast; | μόνο η θύρα του παραλήπτη | κάθε συσκευή εντός εμβέλειας |
| Μπορεί ένας τρίτος να διαβάσει την κίνηση; | κανονικά όχι | ναι, χωρίς δυσκολία |

:::tip Βασικό σημείο
Η ασύρματη μετάδοση είναι ένα **κοινόχρηστο μέσο**: Ό,τι στέλνεται στο Wi-Fi μπορεί να το λάβει κάθε συσκευή εντός εμβέλειας. Γι' αυτό ένα Wi-Fi πρέπει να είναι **κρυπτογραφημένο** (σήμερα με **WPA2** ή **WPA3**) — έτσι οι ξένοι μπορούν μεν να λάβουν τα δεδομένα, αλλά όχι να τα διαβάσουν.
:::

:::note
Το BeaverTracer δεν προσομοιώνει κρυπτογράφηση Wi-Fi — γι' αυτό εδώ μπορείς να διαβάσεις τα πάντα. Πώς λειτουργεί η κρυπτογράφηση θα το μάθεις στο κεφάλαιο 8.
:::

:::quiz mc
Γιατί είναι επικίνδυνο να χρησιμοποιείς σε ένα καφέ ένα ανοιχτό Wi-Fi χωρίς κωδικό;
- [ ] Το Wi-Fi είναι τότε πιο αργό
- [x] Οποιοσδήποτε βρίσκεται κοντά μπορεί να διαβάσει ό,τι μεταδίδεται χωρίς κρυπτογράφηση
- [ ] Το σημείο πρόσβασης δεν μπορεί να εμφανίσει το SSID
:::

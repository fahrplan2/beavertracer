# Ο δρομολογητής

:::goal
**Μαθησιακός στόχος:** Μπορείς να εξηγήσεις πώς ένας δρομολογητής συνδέει δύο δίκτυα, να ρυθμίσεις την πύλη (gateway) σε έναν υπολογιστή και να αιτιολογήσεις πότε ένας υπολογιστής παραδίδει ένα πακέτο απευθείας και πότε μέσω της πύλης.
:::

:::sim
url=/sims/lesson-4.3.1.btsim
:::

Ένας **δρομολογητής** (router) συνδέει διαφορετικά δίκτυα μεταξύ τους. Για τον σκοπό αυτό διαθέτει ξεχωριστή θύρα για κάθε δίκτυο — και σε κάθε θύρα μια δική του διεύθυνση IP από ακριβώς αυτό το δίκτυο. Στον χώρο εργασίας βλέπεις ξανά τις εταιρείες Firma A και Firma B, αυτή τη φορά με έναν δρομολογητή ανάμεσά τους.

# Αντιμετώπιση προβλημάτων: Χωρίς δίκτυο για τους φορητούς υπολογιστές

:::sim
url=/sims/lesson-6.4.3.btsim
:::

Μετά τις διακοπές, οι εκπαιδευτικοί αναφέρουν: «Οι φορητοί μας υπολογιστές δεν μπαίνουν πια στο δίκτυο!» Και οι δύο φορητοί υπολογιστές είναι ρυθμισμένοι σε **DHCP**. Σύμφωνα με το σχέδιο, ο DHCP server πρέπει να μοιράζει διευθύνσεις από `192.168.0.100` έως `192.168.0.120`, με πύλη `192.168.0.1` και DNS server `192.168.0.53`.

Βρες τα σφάλματα και διόρθωσέ τα.

<details>
<summary>Συμβουλή 1: Ποια διεύθυνση έχουν οι φορητοί υπολογιστές;</summary>

Κοίτα στις :fa-gear: **Ρυθμίσεις IP** ενός φορητού υπολογιστή. Μια διεύθυνση που ξεκινά με `169.254` την έδωσε η συσκευή **στον εαυτό της**, επειδή δεν απάντησε κανένας DHCP server.
</details>

<details>
<summary>Συμβουλή 2: Απαντά ο DHCP server;</summary>

Άνοιξε ένα ίχνος για έναν φορητό υπολογιστή. Βλέπεις μόνο `DHCP Discover` ή και κάποια απάντηση; Μετά κοίτα την εφαρμογή **DHCP Server**: Τρέχει; Και ποιο εύρος διευθύνσεων μοιράζει;
</details>

<details>
<summary>Συμβουλή 3: Λήψη νέας διεύθυνσης</summary>

Αν άλλαξες κάτι στον server, γύρισε για λίγο τη λειτουργία του φορητού υπολογιστή στις Ρυθμίσεις IP σε **Στατική** και ξανά σε **DHCP** και κάνε κλικ στο **Εφαρμογή**. Τότε θα ζητήσει ξανά διεύθυνση.
</details>

:::task
title: Είναι οι φορητοί υπολογιστές ξανά στο δίκτυο;
Ελέγχει αν και οι δύο φορητοί υπολογιστές έχουν διεύθυνση από το προγραμματισμένο εύρος και αν μπορούν να φτάσουν τον DHCP server. Για τον έλεγχο, η προσομοίωση πρέπει να τρέχει σε λειτουργία εκτέλεσης.
check: ip(3, "192.168.0.96/27")
check: ip(4, "192.168.0.96/27")
check: pingOk(3, 2)
check: pingOk(4, 2)
:::

## Τι συνέβαινε;

:::quiz multi
Ποιες προτάσεις είναι σωστές;
- [x] Ο DHCP server δεν είχε ξεκινήσει, οπότε οι φορητοί υπολογιστές έδωσαν στον εαυτό τους μια διεύθυνση `169.254`
- [x] Το εύρος διευθύνσεων βρισκόταν σε λάθος δίκτυο (`192.168.1.…` αντί για `192.168.0.…`)
- [ ] Οι φορητοί υπολογιστές ήταν ρυθμισμένοι με σταθερές διευθύνσεις
- [ ] Έλειπε η πύλη στον μεταγωγέα
:::

:::evaluate
Έλεγχος απάντησης
:::

:::tip Βασικό σημείο
Αν μια συσκευή έχει διεύθυνση από το **`169.254.0.0/16`**, **δεν πήρε απάντηση από DHCP server** και έδωσε μόνη της στον εαυτό της μια διεύθυνση (**APIPA**). Με αυτήν φτάνει μόνο άλλες συσκευές που βρίσκονται στην ίδια κατάσταση. Τότε έλεγξε: Τρέχει ο DHCP server; Είναι προσβάσιμος; Και μοιράζει διευθύνσεις από το **σωστό δίκτυο**;
:::

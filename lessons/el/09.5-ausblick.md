# Σύνοψη και προοπτικές

## Τείχη προστασίας παντού

Το φίλτρο πακέτων αυτού του κεφαλαίου θα το συναντήσεις σε πολλές συσκευές:

- **Οικιακός δρομολογητής:** Κάθε οικιακός δρομολογητής είναι και τείχος προστασίας με διατήρηση κατάστασης (stateful). Με το IPv4, ένα μέρος αυτής της δουλειάς το αναλαμβάνει το NAT: Κανείς από έξω δεν μπορεί να ξεκινήσει μια σύνδεση, εφόσον δεν υπάρχει προώθηση θύρας (Κεφάλαιο 7). Με το IPv6 όλες οι συσκευές έχουν δημόσιες διευθύνσεις — τότε μόνο ο κανόνας του τείχους προστασίας «από έξω δεν μπαίνει τίποτα καινούργιο» εξασφαλίζει την ίδια προστασία.
- **Προσωπικό τείχος προστασίας (Personal Firewall):** Και τα Windows, macOS και Linux διαθέτουν ενσωματωμένο τείχος προστασίας πάνω στον ίδιο τον υπολογιστή. Προστατεύει τη συσκευή και σε ξένα δίκτυα, π.χ. στο WLAN μιας καφετέριας, και μπορεί να ορίζει κανόνες ανά πρόγραμμα.
- **Τείχος προστασίας νέας γενιάς (Next-Generation Firewall)** και **Web Application Firewall (WAF):** Δεν εξετάζουν μόνο διευθύνσεις και θύρες, αλλά και το περιεχόμενο των πακέτων — μέχρι το επίπεδο εφαρμογής. Έτσι αναγνωρίζουν π.χ. επιθέσεις μέσα σε αιτήματα HTTP. Στο HTTPS πρέπει γι' αυτό να «σπάσουν» την κρυπτογράφηση (Κεφάλαιο 8).
- **IDS/IPS:** Ένα *Intrusion Detection System* (σύστημα ανίχνευσης εισβολών) αναγνωρίζει ύποπτα μοτίβα στην κίνηση δεδομένων και σημαίνει συναγερμό· ένα *Intrusion Prevention System* (σύστημα αποτροπής εισβολών) επιπλέον τα μπλοκάρει το ίδιο.

:::note
Ένα τείχος προστασίας είναι μόνο **ένα** δομικό στοιχείο της ασφάλειας. Δεν βοηθά όταν μια επιτρεπόμενη υπηρεσία (π.χ. ο web server) έχει η ίδια κάποιο κενό ασφαλείας, όταν κάποιος ανοίγει ένα κακόβουλο πρόγραμμα από ένα e-mail ή όταν ένας κωδικός πρόσβασης είναι αδύναμος. Γι' αυτό πάντα χρειάζονται επίσης ενημερώσεις, ισχυροί κωδικοί πρόσβασης, κρυπτογράφηση και έξυπνος διαχωρισμός του δικτύου (DMZ, VLANs από το Κεφάλαιο 3).
:::

## Έλεγξε τις γνώσεις σου

:::quiz mc
Ένα τείχος προστασίας λειτουργεί με προεπιλεγμένη πολιτική «Απόρριψη όλων» και έναν μόνο κανόνα «A → B, TCP 443, Αποδοχή». Φτάνει ένα πακέτο A → B προς τη θύρα TCP 22. Τι συμβαίνει;
- [ ] Γίνεται αποδεκτό
- [x] Απορρίπτεται σιωπηλά (drop)
- [ ] Απορρίπτεται με ειδοποίηση του αποστολέα (reject)
:::

:::quiz mc
Το `nmap` αναφέρει για μια θύρα `filtered`. Τι σημαίνει αυτό;
- [ ] Στη θύρα τρέχει μια υπηρεσία
- [ ] Ο server απάντησε με ένα RST
- [x] Δεν ήρθε καμία απάντηση — πιθανότατα ένα τείχος προστασίας απορρίπτει τα πακέτα
:::

:::quiz multi
Ποιες προτάσεις είναι σωστές;
- [x] Σε ένα stateful τείχος προστασίας οι απαντήσεις σε επιτρεπόμενες συνδέσεις επιστρέφουν αυτόματα
- [x] Μια λευκή λίστα (whitelist) είναι ασφαλέστερη από μια μαύρη λίστα (blacklist), επειδή οι νέες υπηρεσίες παραμένουν αυτόματα αποκλεισμένες
- [x] Οι servers που είναι προσβάσιμοι από το Internet ανήκουν σε μια DMZ
- [ ] Ένα τείχος προστασίας προστατεύει και από επιθέσεις μεταξύ δύο υπολογιστών στο ίδιο δίκτυο πίσω από αυτό
- [ ] Ελέγχονται πάντα όλοι οι κανόνες και επικρατεί ο αυστηρότερος
:::

:::quiz fill
Το τείχος προστασίας ελέγχει τους κανόνες από {πάνω} προς τα κάτω· αποφασίζει ο {πρώτος} κανόνας που ταιριάζει. Αν δεν ταιριάζει κανένας κανόνας, ισχύει η {προεπιλεγμένη πολιτική}.
:::

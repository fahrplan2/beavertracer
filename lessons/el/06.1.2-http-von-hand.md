# HTTP με το χέρι

:::sim
url=/sims/lesson-6.1.btsim
:::

Αν το HTTP είναι καθαρό κείμενο, μπορείς να μιλήσεις μόνος σου με έναν web server, χωρίς καθόλου περιηγητή; Ναι: με το `telnet` δημιουργείς μια σύνδεση TCP σε οποιαδήποτε θύρα και πληκτρολογείς μόνος σου το κείμενο.

## Το πείραμα

1. Πέρασε στη λειτουργία :fa-play: **Εκτέλεση** και άνοιξε στον **Client-PC** το :fa-terminal: **Terminal**.
2. Συνδέσου στη θύρα 80 του server:
   ```
   $ telnet 192.168.0.20 80
   ```
3. Πληκτρολόγησε το αίτημα γραμμή προς γραμμή και ολοκλήρωσέ το με μια **κενή γραμμή** (απλώς πάτα **Enter** άλλη μία φορά):
   ```
   GET /kontakt.html HTTP/1.1
   Host: 192.168.0.20

   ```

Ο server απαντά με γραμμή κατάστασης, κεφαλίδες και τη σελίδα επικοινωνίας, σε μορφή κειμένου, ακριβώς όπως τη λαμβάνει και ο περιηγητής.

:::quiz mc
Από τι καταλαβαίνει ο server ότι το αίτημά σου τελείωσε;
- [ ] Από μια ειδική εντολή `END`
- [x] Από την κενή γραμμή
- [ ] Μετά από ένα ορισμένο χρονικό διάστημα
:::

:::quiz short
Ποια τιμή υπάρχει στην απάντηση στην κεφαλίδα `Content-Type`; (μόνο το πρώτο μέρος πριν από το `;`)
= text/html
:::

## Προκαλώντας σφάλματα

Ένα πιο βολικό εργαλείο είναι το `curl`: κάνει το αίτημα για σένα. Με την επιλογή `-v` (*verbose*, αναλυτικά) δείχνει όλα όσα πηγαινοέρχονται: τις γραμμές με `>` τις έστειλε το `curl`, ενώ οι γραμμές με `<` ήρθαν από τον server.

Δοκίμασε:

```
$ curl -v http://192.168.0.20/gibtsnicht.html
$ curl -X POST -d name=Anna http://192.168.0.20/
```

:::quiz short
Ποιον κωδικό κατάστασης παίρνεις για το `/gibtsnicht.html`;
= 404
:::

:::quiz short
Και ποιον για το αίτημα με τη μέθοδο `POST`;
= 405
:::

:::evaluate
Έλεγχος απαντήσεων

:::note
Ο web server στο BeaverTracer μπορεί μόνο να παραδίδει αρχεία. Γι' αυτό επιτρέπει μόνο τις μεθόδους `GET` και `HEAD`. Οι πραγματικοί web servers δέχονται με `POST`, για παράδειγμα, φόρμες και προωθούν τα δεδομένα σε ένα πρόγραμμα.
:::

:::tip Βασικό σημείο
Πολλά πρωτόκολλα του επιπέδου εφαρμογής είναι **βασισμένα σε κείμενο**: το HTTP, αλλά και τα SMTP, POP3 και IMAP. Γι' αυτό μπορείς να τα «μιλήσεις» με το χέρι μέσω `telnet` και να τα διαβάσεις στην ανίχνευση. Αυτό είναι πρακτικό για την αντιμετώπιση προβλημάτων, αλλά αποτελεί και πρόβλημα ασφάλειας: όποιος καταγράφει την κίνηση μπορεί να διαβάσει τα πάντα. Πώς βοηθά η κρυπτογράφηση (HTTPS) θα το μάθεις στο κεφάλαιο 8.
:::

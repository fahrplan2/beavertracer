# Παρακολούθηση μιας επίλυσης ονόματος

:::sim
url=/sims/lesson-6.2.btsim
:::

## Το πείραμα

1. Πέρασε στη λειτουργία :fa-play: **Εκτέλεση**, κάνε κλικ στον **Client-PC** και άνοιξε τον :fa-globe: **Περιηγητής**.
2. Αυτή τη φορά άνοιξε τη διεύθυνση `http://www.beaver-schule.de/`, δηλαδή με όνομα αντί για διεύθυνση IP.
3. Πέρασε στη λειτουργία :fa-magnifying-glass: **Ίχνος** και άνοιξε ένα ίχνος για τον **Client-PC**.

Στην αρχή, πριν ακόμη από την εγκατάσταση σύνδεσης με `[SYN]`, υπάρχουν δύο πακέτα με το πρωτόκολλο **DNS**.

:::quiz short
Σε ποια διεύθυνση IP στέλνει ο Client-PC το αίτημα DNS του;
= 192.168.0.53
:::

:::quiz short
Ποια διεύθυνση IP περιέχει η απάντηση για το `www.beaver-schule.de`;
= 192.168.0.20
:::

:::quiz mc
Κάνε κλικ στο αίτημα DNS και ανάπτυξε το δέντρο πρωτοκόλλων. Ποιο πρωτόκολλο μεταφοράς και ποια θύρα προορισμού χρησιμοποιούνται;
- [ ] TCP, θύρα 80
- [x] UDP, θύρα 53
- [ ] UDP, θύρα 67
:::

:::evaluate
Έλεγχος απαντήσεων
:::

Μόνο αφού ο Client-PC μάθει τη διεύθυνση IP, εγκαθιστά τη σύνδεση TCP με τον web server, όπως ακριβώς στο κεφάλαιο 5.

:::seq
mode: text
Client-PC -> DNS-Resolver: Αίτημα DNS | A www.beaver-schule.de?
DNS-Resolver -> Client-PC: Απάντηση DNS | A 192.168.0.20
:::

## Πώς γνωρίζει ο υπολογιστής τον DNS server;

Άνοιξε στον **Client-PC** τις :fa-gear: **Ρυθμίσεις IP**: στο πεδίο **DNS Server** υπάρχει η τιμή `192.168.0.53`, δηλαδή ο υπολογιστής **DNS-Resolver**. Σε αυτόν στέλνει ο υπολογιστής κάθε αίτημα ονόματος.

Μπορείς επίσης να ρωτήσεις απευθείας τον DNS server, χωρίς περιηγητή. Άνοιξε το :fa-terminal: **Terminal** και πληκτρολόγησε:

```
$ nslookup www.beaver-schule.de
```

Το `nslookup` δείχνει πρώτα ποιον server ρώτησε και μετά την απάντηση. Για σύγκριση, ρώτησε για ένα όνομα που δεν υπάρχει, π.χ. `nslookup gibtsnicht.beaver-schule.de`.

:::quiz mc
Τι απαντά ο DNS server για το άγνωστο όνομα;
- [ ] Μια τυχαία διεύθυνση IP
- [x] `NXDOMAIN`: αυτό το όνομα δεν υπάρχει
- [ ] Τίποτα απολύτως
:::

:::evaluate
Έλεγχος απάντησης
:::

:::tip Βασικό σημείο
Το **DNS** μεταφράζει ονόματα (π.χ. `www.beaver-schule.de`) σε διευθύνσεις IP. Πριν ένας υπολογιστής εγκαταστήσει σύνδεση με ένα όνομα, ρωτά τον **DNS server** που έχει οριστεί στις ρυθμίσεις IP του, συνήθως μέσω **UDP, θύρα 53**. Με το `nslookup` μπορείς να κάνεις αιτήματα DNS χειροκίνητα.
:::

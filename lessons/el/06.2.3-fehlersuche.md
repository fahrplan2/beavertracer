# Αντιμετώπιση προβλημάτων: το όνομα δεν λειτουργεί

:::sim
url=/sims/lesson-6.2.3.btsim
:::

Μια καθηγήτρια αναφέρει: «Το `www.beaver-schule.de` δεν φορτώνει σε μένα. Με το `http://192.168.0.20` όμως δουλεύει!» Έτσι *πρέπει* να είναι ρυθμισμένο:

| Τι | Επιθυμητή ρύθμιση |
|---|---|
| DNS server στον Client-PC | `192.168.0.53` (DNS-Resolver) |
| Εγγραφή στον Schul-DNS | `www.beaver-schule.de` → `192.168.0.20` |

Βρες τα σφάλματα και διόρθωσέ τα.

<details>
<summary>Συμβουλή 1: Τι λέει το nslookup;</summary>

Πληκτρολόγησε στον Client-PC `nslookup www.beaver-schule.de`. Ποιον server ρώτησε το `nslookup` — και τι απάντηση πήρε; (Η απάντηση χρειάζεται μερικά δευτερόλεπτα.)
</details>

<details>
<summary>Συμβουλή 2: Και τώρα;</summary>

Αν πάρεις απάντηση, σύγκρινε τη διεύθυνση με το σχέδιο. Πού είναι καταχωρισμένο αυτό το όνομα;
</details>

:::task
title: Επισκευάστηκε η επίλυση ονομάτων;
Ελέγχει αν ο Client-PC επιλύει το www.beaver-schule.de στη σωστή διεύθυνση. Για αυτό, η προσομοίωση πρέπει να εκτελείται σε Λειτουργία εκτέλεσης.
check: resolves(2, "www.beaver-schule.de", "192.168.0.20")
:::

## Τι συνέβαινε;

:::quiz multi
Ποιες προτάσεις είναι σωστές;
- [x] Στον Client-PC ήταν καταχωρισμένος ως DNS server ο `192.168.0.35` — εκεί δεν απαντά κανείς
- [x] Στον Schul-DNS το `www.beaver-schule.de` έδειχνε στο `192.168.0.21` αντί για το `192.168.0.20`
- [ ] Ο web server ήταν απενεργοποιημένος
- [ ] Ο root server δεν γνώριζε τον τομέα `.de`
:::

:::evaluate
Έλεγχος απάντησης
:::

:::tip Βασικό σημείο
Αν μια σύνδεση λειτουργεί με τη **διεύθυνση IP** αλλά όχι με το **όνομα**, το πρόβλημα βρίσκεται στο **DNS**. Έλεγξε πρώτα τον **καταχωρισμένο DNS server** (απαντά καθόλου;) και μετά την ίδια την **εγγραφή** (είναι σωστή η διεύθυνση;). Το `nslookup` δείχνει και τα δύο: ποιος server ρωτήθηκε και τι απάντησε.
:::

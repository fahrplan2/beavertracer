# Μια σύνδεση από την αρχή ως το τέλος

:::sim
url=/sims/lesson-5.1.btsim
:::

Στον **Server** τρέχει η υπηρεσία echo στη θύρα `5000`: στέλνει αμέσως πίσω κάθε μήνυμα. Με το **Απλό TCP Client** μπορείς να ελέγχεις μια σύνδεση βήμα προς βήμα: κάθε κουμπί είναι μία φάση.

## Το πείραμα

1. Πέρασε στη :fa-play: λειτουργία **Εκτέλεση**, κάνε κλικ στον **Client-PC** και άνοιξε το **Απλό TCP Client**.
2. Συμπλήρωσε στο **Host** `192.168.0.20` και στο **Port** `5000`.
3. Κάνε κλικ στο **Connect**.
4. Πληκτρολόγησε `Hello World` στο πεδίο μηνύματος και κάνε κλικ στο **Send**. Αμέσως μετά βλέπεις στο παράθυρο συνομιλίας το echo του server.
5. Κάνε κλικ στο **Disconnect**.
6. Πέρασε στη :fa-magnifying-glass: λειτουργία **Ίχνος** και άνοιξε με το **+** ένα ίχνος για τον **Client-PC**, διεπαφή `eth0`.

:::note
Τα δύο πακέτα ARP στην αρχή τα ξέρεις ήδη από το κεφάλαιο 1. Στη στήλη **Info** των πακέτων TCP εμφανίζεται πρώτα το `49152 → 5000` (από ποια θύρα προς ποια), μετά σε αγκύλες οι **σημαίες** (flags) και έπειτα αριθμοί όπως `Seq=`, `Ack=` και `Len=`. Με τους αριθμούς θα ασχοληθούμε από τη σελίδα 5.2.3 και μετά. Εδώ προσέχεις τις σημαίες και το `Len`.
:::

## Φάση 1: Σύνδεση

:::quiz short
Πόσα πακέτα TCP ανταλλάχθηκαν αφού έκανες κλικ στο **Connect**, πριν σταλεί το μήνυμά σου;
= 3
= τρία
:::

:::quiz mc
Ποιος στέλνει το πρώτο πακέτο με `[SYN]`;
- [x] Ο Client-PC
- [ ] Ο Server
:::

:::quiz mc
Με ποιες σημαίες απαντά ο server σε αυτό;
- [ ] `[SYN]`
- [x] `[SYN, ACK]`
- [ ] `[ACK]`
- [ ] `[FIN, ACK]`
:::

## Φάση 2: Αποστολή

Το `Len` δείχνει πόσα bytes ωφέλιμου φορτίου μεταφέρει ένα πακέτο.

:::quiz short
Πόσα bytes μεταφέρει το πακέτο με το μήνυμά σου (`Len`);
= 13
:::

:::note
Το `Hello World` έχει μόνο 11 χαρακτήρες. Όμως το TCP Client προσθέτει στο τέλος έναν χαρακτήρα τέλους γραμμής (2 byte, `\r\n`), όπως το περιμένουν πολλά πρωτόκολλα του Διαδικτύου, π.χ. το SMTP ή το HTTP.
:::

:::quiz mc
Τι στέλνει πίσω ο server αμέσως μετά το μήνυμά σου, ακόμη και πριν από το echo;
- [x] Ένα πακέτο με `[ACK]` και `Len=0`, δηλαδή μια επιβεβαίωση χωρίς δεδομένα
- [ ] Τίποτα απολύτως
- [ ] Ένα νέο `[SYN]`
:::

## Φάση 3: Αποσύνδεση

:::quiz short
Πόσα πακέτα ανήκουν στον τερματισμό, από το πρώτο πακέτο με `FIN` και μετά;
= 4
= τέσσερα
:::

:::quiz mc
Τι γνωστοποιεί μια πλευρά με το `FIN`;
- [x] «Τελείωσα»: δεν στέλνει άλλα δεδομένα
- [ ] «Παρουσιάστηκε σφάλμα»
- [ ] «Έρχονται νέα δεδομένα»
:::

## Πού βρίσκονται οι τέσσερις αρμοδιότητες;

Αντιστοίχισε πού ξαναβρίσκεις στο ίχνος τις αρμοδιότητες από την ενότητα 5.1:

:::quiz match
Εγκατάσταση σύνδεσης -> Τα τρία πακέτα [SYN], [SYN, ACK] και [ACK]
Αξιόπιστη μετάδοση -> Πακέτα με [ACK] και Len=0 που επιβεβαιώνουν τη λήψη
Τερματισμός σύνδεσης -> Τα πακέτα με FIN και οι επιβεβαιώσεις τους
Πολυπλεξία -> Οι αριθμοί θυρών 49152 → 5000 πριν από τις αγκύλες
:::

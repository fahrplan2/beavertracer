# DHCP: αυτόματα στο δίκτυο

:::goal
**Μαθησιακός στόχος:** Μπορείς να εξηγήσεις πώς μια συσκευή παίρνει αυτόματα τις ρυθμίσεις IP της μέσω DHCP, να ρυθμίσεις έναν διακομιστή DHCP και να αναγνωρίζεις και να διορθώνεις τυπικά σφάλματα DHCP (π.χ. μια διεύθυνση 169.254).
:::

:::sim
url=/sims/lesson-6.4.btsim
:::

Μέχρι τώρα καταχωρούσες με το χέρι σε κάθε συσκευή τη διεύθυνση IP, τη μάσκα δικτύου, την πύλη (gateway) και τον διακομιστή DNS. Σε ένα σχολείο με εκατοντάδες φορητούς υπολογιστές, tablet και κινητά αυτό θα ήταν αδύνατο — και κάθε τυπογραφικό λάθος θα σήμαινε ένα σφάλμα στο δίκτυο.

Αυτή τη δουλειά την αναλαμβάνει το **Dynamic Host Configuration Protocol** (**DHCP**): ένας **διακομιστής DHCP** μοιράζει αυτόματα τις ρυθμίσεις σε κάθε συσκευή που συνδέεται στο δίκτυο.

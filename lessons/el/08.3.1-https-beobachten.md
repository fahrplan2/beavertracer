# Σύγκριση HTTP και HTTPS

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Ο web server **www.beaver-schule.de** προσφέρει την πύλη βαθμολογιών του σχολείου τόσο μέσω HTTP όσο και μέσω HTTPS. Τι βλέπει ένας ωτακουστής;

## Το πείραμα

1. Πέρασε στη λειτουργία :fa-play: **Εκτέλεση** και άνοιξε στον **Client-PC**, στην εφαρμογή :fa-globe: **Περιηγητής**, πρώτα το `http://www.beaver-schule.de/` και μετά το `https://www.beaver-schule.de/`.
2. Άνοιξε στη λειτουργία :fa-magnifying-glass: **Ίχνος** ένα trace για τον **Client-PC**.
3. Βρες πρώτα το πακέτο `HTTP/1.1 200 OK` και κάνε κλικ πάνω του. Κάτω, στις λεπτομέρειες, θα βρεις το περιεχόμενο της σελίδας.

:::quiz mc
Τι μπορεί να δει ένας ωτακουστής με **HTTP**;
- [x] Ολόκληρη την ιστοσελίδα, ακόμα και τους βαθμούς της Anna
- [ ] Μόνο τη διεύθυνση του server
- [ ] Τίποτα, επειδή το HTTP λειτουργεί πάνω από TCP
:::

:::quiz short
Τι βαθμό έχει η Anna στα Μαθηματικά;
= 2
:::

:::evaluate
Έλεγχος απαντήσεων
:::

Τώρα το κομμάτι του HTTPS. Βρες το πακέτο `[SYN]` με το οποίο ο client ξεκινά τη δεύτερη σύνδεση.

:::quiz short
Ποια θύρα προορισμού έχει η σύνδεση HTTPS (στήλη **Info**, `… → ???`);
= 443
:::

Πληκτρολόγησε τώρα `tls` στο πεδίο φίλτρου στο πάνω μέρος του trace — έτσι θα βλέπεις μόνο τα πακέτα TLS.

:::quiz mc
Τι γράφει η στήλη **Info** στα πακέτα που περιέχουν την ιστοσελίδα;
- [ ] `HTTP/1.1 200 OK`
- [x] `Application Data`
- [ ] `Encrypted HTML`
:::

:::quiz multi
Τι μπορεί να δει ένας ωτακουστής με **HTTPS** παρ' όλα αυτά;
- [x] Τις διευθύνσεις IP του client και του server
- [x] Ότι χρησιμοποιείται η θύρα 443, άρα πιθανότατα HTTPS
- [x] Πόσα δεδομένα μεταφέρονται περίπου
- [ ] Ποια σελίδα ανοίχτηκε και τι γράφει
:::

:::evaluate
Έλεγχος απαντήσεων
:::

:::note
Κάνε κλικ σε ένα πακέτο **Application Data**: τα ωφέλιμα δεδομένα είναι απλώς μια σειρά από φαινομενικά τυχαία bytes. Το εργαλείο ιχνηλάτησης δεν μπορεί να τα αποκρυπτογραφήσει — δεν γνωρίζει το κλειδί συνεδρίας, ακριβώς όπως και ένας επιτιθέμενος.
:::

:::tip Βασικό σημείο
Με **HTTP** κάθε ωτακουστής μπορεί να διαβάσει ολόκληρη την ιστοσελίδα. Με **HTTPS** βλέπει πλέον μόνο **ποιος μιλάει με ποιον** (διευθύνσεις IP, θύρα 443) και **πόσα** — το περιεχόμενο βρίσκεται κρυπτογραφημένο μέσα σε πακέτα **Application Data**.
:::

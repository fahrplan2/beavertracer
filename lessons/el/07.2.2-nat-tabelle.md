# Ο πίνακας NAT

:::sim
url=/sims/lesson-7.1.btsim
:::

Όταν το PC και το tablet φορτώνουν ταυτόχρονα την ίδια ιστοσελίδα, και τα δύο αιτήματα φτάνουν στον web server από τη διεύθυνση `203.0.113.2`. Πώς ξέρει ο οικιακός δρομολογητής για ποιον προορίζεται μια απάντηση; Κρατάει αρχείο — στον **πίνακα NAT**.

## Το πείραμα

1. Πέρασε στη λειτουργία :fa-play: **Εκτέλεση** και άνοιξε τη διεύθυνση `http://www.beispiel.de/` τόσο στο **PC** όσο και στο **Tablet**.
2. Κάνε κλικ στον **Heimrouter** και άνοιξε την καρτέλα **NAT**.

Κάθε γραμμή είναι μια **αντιστοίχιση**: πρωτόκολλο, LAN IP και θύρα LAN της συσκευής στο οικιακό δίκτυο — και η **θύρα WAN** που χρησιμοποιεί ο δρομολογητής γι' αυτήν στη δημόσια διεύθυνσή του.

:::quiz short
Ποια WAN IP εμφανίζεται πάνω από τον πίνακα;
= 203.0.113.2
:::

:::quiz mc
Το PC και το tablet έχουν δημιουργήσει και τα δύο μια σύνδεση με τη θύρα LAN `49152`. Ποια θύρα WAN παίρνουν;
- [ ] Και τα δύο την ίδια, την `49152`
- [x] Το καθένα διαφορετική — αλλιώς ο δρομολογητής δεν θα ήξερε σε ποιον ανήκει η απάντηση
- [ ] Καμία, το NAT αλλάζει μόνο τη διεύθυνση IP
:::

:::quiz mc
Μια απάντηση του web server φτάνει στη διεύθυνση `203.0.113.2` με μια συγκεκριμένη **θύρα προορισμού**. Τι κάνει ο οικιακός δρομολογητής με αυτήν;
- [x] Αναζητά τη θύρα στον πίνακα NAT και στέλνει το πακέτο στην αντίστοιχη LAN IP και θύρα LAN
- [ ] Στέλνει το πακέτο σε όλες τις συσκευές του οικιακού δικτύου
- [ ] Απορρίπτει το πακέτο
:::

:::evaluate
Έλεγχος απαντήσεων
:::

Εδώ ξαναμπαίνουν στο παιχνίδι οι **θύρες** από το κεφάλαιο 5: Επειδή το NAT ξαναγράφει και τις θύρες, εκατοντάδες συνδέσεις μπορούν να μοιράζονται μία διεύθυνση. Για την ακρίβεια, γι' αυτό ονομάζεται **PAT** (*Port Address Translation*) ή *NAT με μετάφραση θυρών* — στην καθημερινότητα, ωστόσο, λέμε απλώς NAT.

Έτσι θα μπορούσε, για παράδειγμα, να μοιάζει μια τέτοια μετάφραση:

| | Πακέτο από το PC (στο οικιακό δίκτυο) | το ίδιο πακέτο στο διαδίκτυο |
|---|---|---|
| Αποστολέας | `192.168.178.20 : 49152` | `203.0.113.2 : 10001` |
| Παραλήπτης | `192.0.2.80 : 80` | `192.0.2.80 : 80` |

:::tip Βασικό σημείο
Στον **πίνακα NAT** ο δρομολογητής καταγράφει για κάθε σύνδεση ποια συσκευή (**LAN IP και θύρα LAN**) βρίσκεται πίσω από ποια **θύρα WAN**. Τις απαντήσεις από το διαδίκτυο τις αντιστοιχίζει ξανά στη σωστή συσκευή μέσω της θύρας προορισμού. Επειδή ξαναγράφονται και οι θύρες, ο ακριβέστερος όρος είναι **PAT**.
:::

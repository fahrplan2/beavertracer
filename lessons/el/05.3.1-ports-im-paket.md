## Το πείραμα

1. Πέρασε στη λειτουργία :fa-play: **Εκτέλεση**, κάνε κλικ στον **Client-PC** και άνοιξε τον :fa-globe: **Περιηγητής**. Άνοιξε τη διεύθυνση `http://192.168.0.20/`.
2. Κάνε κλικ στο **Πίσω** στο πάνω μέρος του παραθύρου, άνοιξε το **Απλό TCP Client** και σύνδεσέ το με τη διεύθυνση `192.168.0.20`, θύρα `5000`. Άφησε τη σύνδεση ανοιχτή.
3. Πέρασε στη λειτουργία :fa-magnifying-glass: **Ίχνος**, άνοιξε ένα ίχνος για τον **Client-PC** και κάνε κλικ σε ένα πακέτο με `[SYN]`. Ανάπτυξε το **Transmission Control Protocol**.

Στην κορυφή της κεφαλίδας TCP υπάρχουν δύο θύρες: **Source Port** (θύρα προέλευσης) και **Destination Port** (θύρα προορισμού).

:::quiz table
| Σύνδεση | Θύρα προέλευσης | Θύρα προορισμού |
|---|---|---|
| Περιηγητής → διακομιστής ιστού | {49152} | {80} |
| TCP Client → υπηρεσία Echo | {49153} | {5000} |
:::

## Δύο είδη θυρών

**Θύρα προορισμού — η υπηρεσία:** Ένα πρόγραμμα διακομιστή περιμένει συνδέσεις σε μια σταθερή θύρα — λέμε ότι **ακούει** εκεί. Για γνωστές υπηρεσίες οι αριθμοί είναι καθορισμένοι παγκοσμίως: είναι οι **γνωστές θύρες (well-known ports)** (0 έως 1023). Γι' αυτό ένας περιηγητής ξέρει χωρίς να ρωτήσει: οι διακομιστές ιστού ακούνε στη θύρα 80.

**Θύρα προέλευσης — ο αποστολέας:** Τη θύρα στην πλευρά του πελάτη την επιλέγει μόνο του το λειτουργικό σύστημα για κάθε νέα σύνδεση, από ένα υψηλό εύρος (στο BeaverTracer από 49152 και πάνω). Από αυτήν ο πελάτης αναγνωρίζει σε ποια από τις συνδέσεις του ανήκει μια απάντηση.

Μια σύνδεση, επομένως, ορίζεται μονοσήμαντα από τέσσερα στοιχεία: **διεύθυνση IP και θύρα και στις δύο πλευρές**. Το ζεύγος διεύθυνσης IP και θύρας ονομάζεται **socket**, π.χ. `192.168.0.20:80`.

## Μια ματιά στον διακομιστή

Γύρισε πίσω στη λειτουργία :fa-play: **Εκτέλεση**, άνοιξε στον **Server** το :fa-terminal: **Terminal** και πληκτρολόγησε:

```
$ ss
```

Η εντολή `ss` εμφανίζει όλα τα sockets του υπολογιστή. Οι γραμμές με `LISTEN` είναι προγράμματα που ακούνε σε μια θύρα. Οι γραμμές με `ESTABLISHED` είναι υπάρχουσες συνδέσεις — με το δικό του socket (*Local Address:Port*) και το socket της άλλης πλευράς (*Peer Address:Port*).

:::quiz multi
Σε ποιες θύρες ακούει ο διακομιστής;
- [x] 80
- [x] 5000
- [ ] 49152
- [ ] 443
:::

:::quiz mc
Ποια σύνδεση εμφανίζει η `ss` ως `ESTABLISHED`;
- [x] `192.168.0.20:5000` με `192.168.0.10:49153` — η ανοιχτή σύνδεση του TCP Client
- [ ] `192.168.0.20:80` με `192.168.0.10:49152` — η σύνδεση του περιηγητή
- [ ] Και οι δύο
:::

:::evaluate
Έλεγχος απαντήσεων
:::

:::note
Η σύνδεση του περιηγητή έχει ήδη τερματιστεί — μετά τη φόρτωση της σελίδας έκλεισε με `FIN`. Η `ss` την εμφανίζει ακόμα για λίγο ως `TIME-WAIT`: ο διακομιστής περιμένει για λίγο μήπως φτάσουν ακόμα καθυστερημένα πακέτα αυτής της σύνδεσης. Η σύνδεση του TCP Client, αντίθετα, είναι ακόμα ανοιχτή, επειδή δεν έχεις κάνει ακόμα κλικ στο **Disconnect**.
:::

## Οι σημαντικότερες γνωστές θύρες

| Θύρα | Πρωτόκολλο | Υπηρεσία |
|---|---|---|
| 22 | SSH | ασφαλής απομακρυσμένη διαχείριση (κρυπτογραφημένη γραμμή εντολών) |
| 25 | SMTP | αποστολή e-mail |
| 53 | DNS | μετάφραση ονομάτων σε διευθύνσεις IP (συνήθως μέσω UDP) |
| 80 | HTTP | ιστοσελίδες |
| 110 | POP3 | λήψη e-mail |
| 143 | IMAP | διαχείριση e-mail στον διακομιστή |
| 443 | HTTPS | κρυπτογραφημένες ιστοσελίδες |

:::tip Βασικό σημείο
Οι **θύρες** (0 έως 65535) ξεχωρίζουν τις συνδέσεις σε έναν υπολογιστή. Οι υπηρεσίες διακομιστή **ακούνε** σε σταθερές **γνωστές θύρες (well-known ports)** (π.χ. HTTP 80, HTTPS 443), ενώ οι πελάτες παίρνουν για κάθε σύνδεση μια ελεύθερη υψηλή **θύρα προέλευσης**. Μια σύνδεση ορίζεται μονοσήμαντα από τη **διεύθυνση IP και τη θύρα και των δύο πλευρών**.
:::

:::quiz match
22 -> SSH
25 -> SMTP
53 -> DNS
80 -> HTTP
110 -> POP3
143 -> IMAP
443 -> HTTPS
:::

- [ ] Από τη διεύθυνση IP του πελάτη
- [ ] Από τη θύρα προορισμού
- [x] Από τη θύρα προέλευσης του πελάτη
:::

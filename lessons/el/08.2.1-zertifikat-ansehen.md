# Προβολή ενός πιστοποιητικού

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Στον χώρο εργασίας βλέπεις τον **Client-PC**, έναν **DNS-Server** και τον web server του σχολείου, `www.beaver-schule.de`. Ο web server προσφέρει τις σελίδες του και μέσω **HTTPS**.

## Η κλειδαριά στον περιηγητή

1. Πέρασε στη λειτουργία :fa-play: **Εκτέλεση**, κάνε κλικ στον **Client-PC** και άνοιξε την εφαρμογή :fa-globe: **Περιηγητής**.
2. Άνοιξε τη διεύθυνση `https://www.beaver-schule.de/` — πρόσεξε το **https**.
3. Αριστερά από τη διεύθυνση εμφανίζεται μια **κλειδαριά**. Κάνε κλικ πάνω της.

:::quiz short
Για ποιο όνομα εκδόθηκε το πιστοποιητικό (Υποκείμενο χωρίς `CN=`);
= www.beaver-schule.de
:::

:::quiz short
Ποιος εξέδωσε το πιστοποιητικό (Εκδότης χωρίς `CN=`);
= Biber Root CA
:::

:::evaluate
Έλεγχος απαντήσεων
:::

## Γιατί ο Client-PC εμπιστεύεται το πιστοποιητικό;

Άνοιξε στον **Client-PC** τη :fa-shield-halved: **Διαχείριση πιστοποιητικών** και πήγαινε στην καρτέλα **Αξιόπιστες CA**.

:::quiz mc
Τι βρίσκεις εκεί;
- [x] Το πιστοποιητικό της **Biber Root CA**
- [ ] Το πιστοποιητικό του `www.beaver-schule.de`
- [ ] Καμία εγγραφή
:::

:::quiz mc
Πώς φαίνεται ότι η Biber Root CA είναι Root CA;
- [x] Είναι **αυτοϋπογεγραμμένη**: Υποκείμενο και Εκδότης είναι ίδιοι
- [ ] Το όνομά της τελειώνει σε «CA»
- [ ] Δεν έχει δημόσιο κλειδί
:::

:::quiz mc
Στον Client-PC, στο πεδίο **Ιδιωτικό κλειδί** γράφει «Ναι» ή «Όχι»;
- [ ] Ναι — ο client χρειάζεται το ιδιωτικό κλειδί της CA για να ελέγχει υπογραφές
- [x] Όχι — για τον έλεγχο αρκεί το δημόσιο κλειδί· το ιδιωτικό κλειδί το έχει μόνο η CA
:::

:::

## Η άλλη πλευρά: ο web server

Άνοιξε τώρα στον web server **www.beaver-schule.de** τη :fa-shield-halved: **Διαχείριση πιστοποιητικών** (καρτέλα **Τα πιστοποιητικά μου**) και δες το πιστοποιητικό του.

:::quiz multi
Τι ισχύει για το πιστοποιητικό στον web server;
- [x] Στο πεδίο **Ιδιωτικό κλειδί** γράφει «Ναι» — ο server το χρειάζεται για την εγκατάσταση σύνδεσης
- [x] Η **Αλυσίδα** είναι `www.beaver-schule.de ← Biber Root CA`
- [x] Το **Αποτύπωμα** είναι το ίδιο με αυτό στο παράθυρο της κλειδαριάς του περιηγητή
- [ ] Είναι αυτοϋπογεγραμμένο
:::

:::evaluate
Έλεγχος απαντήσεων
:::

:::note
Το **αποτύπωμα** είναι μια τιμή κατακερματισμού (hash) του πιστοποιητικού. Με αυτό μπορείς να συγκρίνεις γρήγορα δύο πιστοποιητικά — χωρίς να ελέγχεις ένα-ένα όλα τα πεδία.
:::

:::tip Βασικό σημείο
Ο **web server** διαθέτει το πιστοποιητικό του **μαζί με το ιδιωτικό κλειδί**. Ο **client** γνωρίζει μόνο το **πιστοποιητικό της Root CA** (χωρίς ιδιωτικό κλειδί) — αυτό του αρκεί για να ελέγξει την υπογραφή στο πιστοποιητικό του server. Αν κάνεις κλικ στην **κλειδαριά** του περιηγητή, βλέπεις Υποκείμενο, Εκδότη, Αποτύπωμα και Ισχύ.
:::

# Αυτόματη απόκτηση διεύθυνσης

:::sim
url=/sims/lesson-6.4.btsim
:::

Στο switch είναι συνδεδεμένοι ένας **DHCP-Server** και δύο laptop. Προς το παρόν τα laptop έχουν σταθερές διευθύνσεις.

## Το πείραμα

1. Πέρασε στη λειτουργία :fa-play: **Εκτέλεση**, κάνε κλικ στο **Laptop 1** και άνοιξε τις :fa-gear: **Ρυθμίσεις IP**.
2. Άλλαξε τη **Λειτουργία** από **Στατική** σε **DHCP** και κάνε κλικ στην **Εφαρμογή**.
3. Περίμενε λίγα δευτερόλεπτα: τα πεδία συμπληρώνονται από μόνα τους.
4. Στη λειτουργία :fa-magnifying-glass: **Ίχνος** άνοιξε ένα ίχνος (trace) για το **Laptop 1**.

:::quiz table
| Ρύθμιση | λήφθηκε από τον DHCP server |
|---|---|
| Διεύθυνση IP | {192.168.0.100} |
| Πύλη (Gateway) | {192.168.0.1} |
| DNS server | {192.168.0.53} |
:::

:::quiz short
Πόσα πακέτα DHCP βρίσκεις στο ίχνος;
= 4
= τέσσερα
:::

:::quiz mc
Σε ποια διεύθυνση IP προορισμού στέλνει το Laptop 1 το πρώτο του πακέτο (`DHCP Discover`);
- [ ] Στον DHCP server `192.168.0.2`
- [x] Στη `255.255.255.255` — σε όλους (γενική εκπομπή)
- [ ] Στην πύλη `192.168.0.1`
:::

:::quiz mc
Ποια διεύθυνση IP αποστολέα έχει αυτό το πρώτο πακέτο — και γιατί;
- [x] `0.0.0.0` — το laptop δεν έχει ακόμα καμία διεύθυνση
- [ ] `192.168.0.10` — η παλιά του διεύθυνση
- [ ] `192.168.0.100` — η νέα του διεύθυνση
:::

## Τι κρύβεται από πίσω: DORA

Μια συσκευή χωρίς διεύθυνση ούτε ξέρει πού βρίσκεται ο DHCP server ούτε έχει δική της διεύθυνση αποστολέα. Γι' αυτό «φωνάζει» στο δίκτυο μέσω **γενικής εκπομπής (broadcast)**. Η διαδικασία έχει τέσσερα βήματα — από τα αρχικά τους γράμματα ονομάζεται **DORA**:

:::seq
mode: text
Laptop 1 -> DHCP-Server: DHCP Discover | «Υπάρχει εδώ κάποιος DHCP server;»
DHCP-Server -> Laptop 1: DHCP Offer | «Μπορείς να πάρεις την 192.168.0.100.»
Laptop 1 -> DHCP-Server: DHCP Request | «Παίρνω την 192.168.0.100.»
DHCP-Server -> Laptop 1: DHCP ACK | «Επιβεβαιώνεται — ισχύει για 3600 δευτερόλεπτα.»
:::

Η διεύθυνση είναι μόνο **δανεική** (*Lease*): μόλις λήξει ο **χρόνος μίσθωσης** (lease time), η συσκευή πρέπει να την ανανεώσει, αλλιώς ο server μπορεί να τη δώσει ξανά σε άλλη συσκευή. Ποιες διευθύνσεις είναι αυτή τη στιγμή δανεισμένες, μπορείς να το δεις στην εφαρμογή **DHCP Server** στην καρτέλα **Leases**.

:::tip Δοκίμασέ το
Βάλε και το **Laptop 2** σε DHCP. Ποια διεύθυνση παίρνει; Μετά κοίτα στα **Leases** του DHCP server.
:::

:::tip Βασικό σημείο
Το **DHCP** μοιράζει αυτόματα διεύθυνση IP, μάσκα δικτύου, πύλη και DNS server. Η διαδικασία ονομάζεται **DORA**: **D**iscover (ο client ψάχνει μέσω γενικής εκπομπής), **O**ffer (ο server προσφέρει), **R**equest (ο client αποδέχεται), **A**CK (ο server επιβεβαιώνει). Η διεύθυνση δανείζεται για τον **χρόνο μίσθωσης**. Το DHCP χρησιμοποιεί **UDP**, θύρα 67 (server) και 68 (client).
:::

:::quiz match
Discover -> Ο client ψάχνει για DHCP server μέσω γενικής εκπομπής
Offer -> Ο server προσφέρει μια διεύθυνση
Request -> Ο client ζητά τη διεύθυνση που του προσφέρθηκε
ACK -> Ο server επιβεβαιώνει την εκχώρηση
:::

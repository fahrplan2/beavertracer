# Εφαρμογή των μοντέλων

Αντιστοίχισε τα πρωτόκολλα από το πείραμα της αρχής του κεφαλαίου με το επίπεδο OSI στο οποίο ανήκουν:

:::quiz match
Ethernet -> Επίπεδο 2 — Ζεύξη δεδομένων
IPv4 -> Επίπεδο 3 — Δίκτυο
TCP -> Επίπεδο 4 — Μεταφορά
HTTP -> Επίπεδο 7 — Εφαρμογή
:::

:::evaluate
Έλεγχος αντιστοιχίσεων
:::

Και τέλος, τα ονόματα των μονάδων δεδομένων:

:::quiz match
Πλαίσιο (Frame) -> Επίπεδο 2 — Ζεύξη δεδομένων
Πακέτο -> Επίπεδο 3 — Δίκτυο
Τμήμα (Segment) -> Επίπεδο 4 — Μεταφορά
:::

:::evaluate
Έλεγχος αντιστοιχίσεων
:::

Τώρα έχεις τα εργαλεία για να κατατάσσεις σωστά τα πρωτόκολλα από εδώ και πέρα. Από το επόμενο κεφάλαιο θα εξετάσουμε τα επίπεδα με τη σειρά, ξεκινώντας από το επίπεδο 2 και το ερώτημα πώς ακριβώς ένας μεταγωγέας (switch) ξέρει πού πρέπει να προωθήσει ένα πακέτο.

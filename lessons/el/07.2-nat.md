# NAT: πολλές συσκευές, μία διεύθυνση

:::goal
**Μαθησιακός στόχος:** Μπορείς να δείξεις στο Tracer πώς το NAT αντικαθιστά τη διεύθυνση αποστολέα, να διαβάσεις τον πίνακα NAT και να εξηγήσεις γιατί οι συνδέσεις από έξω προς το οικιακό δίκτυο χρειάζονται προώθηση θύρας.
:::

:::sim
url=/sims/lesson-7.1.btsim
:::

Ο πάροχος δίνει συνήθως σε μια οικιακή σύνδεση μόνο **μία** δημόσια διεύθυνση IPv4, τη διεύθυνση WAN του οικιακού δρομολογητή. Όλες οι συσκευές στο οικιακό δίκτυο πρέπει να τη μοιράζονται. Ο τρόπος με τον οποίο λειτουργεί αυτό ονομάζεται **NAT** (*Network Address Translation*, μετάφραση διευθύνσεων).

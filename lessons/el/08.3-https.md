# HTTPS

:::osi 5
:::

Το **HTTPS** (*HTTP Secure*) είναι κανονικό HTTP. Η μόνη διαφορά είναι ότι δεν τρέχει απευθείας πάνω από το TCP, αλλά περνά ενδιάμεσα από ένα κρυπτογραφημένο επίπεδο: το **TLS** (*Transport Layer Security*). Ο προκάτοχος του TLS ονομαζόταν **SSL**. Γι' αυτό συχνά μιλάμε ακόμη για «πιστοποιητικά SSL».

```
ohne Verschlüsselung:   HTTP  →  TCP  →  IP
mit Verschlüsselung:    HTTP  →  TLS  →  TCP  →  IP
```

Το HTTP δεν το αντιλαμβάνεται καθόλου αυτό: στέλνει τα αιτήματά του όπως πάντα, το TLS τα κρυπτογραφεί και το TCP τα μεταφέρει. Στο μοντέλο OSI το TLS βρίσκεται ανάμεσα στο επίπεδο μεταφοράς και στο επίπεδο εφαρμογής, δηλαδή στο επίπεδο 4/5. Στηρίζεται στο TCP και διαχειρίζεται μια ασφαλή συνεδρία.

| | HTTP | HTTPS |
|---|---|---|
| Θύρα | 80 | **443** |
| Διεύθυνση | `http://…` | `https://…` |
| Είναι το περιεχόμενο αναγνώσιμο στον Tracer; | ναι | όχι |
| Ο περιηγητής δείχνει | «μη ασφαλές» | λουκέτο |

Κατά την εγκατάσταση σύνδεσης, το TLS κάνει όλα όσα έμαθες σε αυτό το κεφάλαιο:

- Ο server αποδεικνύει την ταυτότητά του με το **πιστοποιητικό** του (**αυθεντικότητα**).
- Οι δύο πλευρές συμφωνούν ένα **κλειδί συνεδρίας** με **Diffie-Hellman** και ο server **υπογράφει** το δικό του μέρος.
- Στη συνέχεια όλα τα δεδομένα κρυπτογραφούνται με **AES** (**εμπιστευτικότητα**) και προστατεύονται από αλλοιώσεις (**ακεραιότητα**).

Η αρχή αυτή δεν περιορίζεται στον παγκόσμιο ιστό: και το e-mail (Ενότητα 8.4) και πολλά άλλα πρωτόκολλα περνούν με τον ίδιο τρόπο μέσα από το TLS.

Στις επόμενες ενότητες θα παρατηρήσεις το HTTPS στον Tracer, θα το ρυθμίσεις μόνος σου και θα εξετάσεις πότε ο περιηγητής εμφανίζει προειδοποίηση και γιατί.

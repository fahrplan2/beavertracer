# Το πρόβλημα των απαντήσεων

:::sim
url=/sims/lesson-9.2.btsim
:::

Το τείχος προστασίας λειτουργεί τώρα με βάση την αρχή της λίστας επιτρεπόμενων (whitelist): προεπιλεγμένη πολιτική **Απόρριψη όλων**. Ένας μόνο κανόνας επιτρέπει στο σχολικό δίκτυο την περιήγηση στο διαδίκτυο: **B → A, TCP, θύρα προορισμού 80, Αποδοχή**. Η λειτουργία είναι ρυθμισμένη σε **Stateless**.

## Το πείραμα

1. Πήγαινε στη :fa-play: **Εκτέλεση** και άνοιξε στον **Lehrer-PC** στον :fa-globe: **Περιηγητής** τη διεύθυνση `http://203.0.113.80/`.
2. Δες στο **Firewall** το **Αρχείο καταγραφής** και τις **Αντιστοιχίσεις**.

:::quiz mc
Τι συμβαίνει στον περιηγητή;
- [ ] Εμφανίζεται η σελίδα του www.beispiel.de
- [x] Η σελίδα δεν φορτώνει, ο περιηγητής περιμένει και τελικά εμφανίζει σφάλμα
:::

:::quiz mc
Ποια πακέτα εμφανίζονται στο αρχείο καταγραφής του τείχους προστασίας ως απορριφθέντα (`DROP`);
- [ ] Τα αιτήματα του Lehrer-PC προς τη θύρα 80
- [x] Οι απαντήσεις από τη `203.0.113.80` με **θύρα προέλευσης 80** προς τον Lehrer-PC
- [ ] Κανένα
:::

:::quiz short
Προς ποια κατεύθυνση (A→B ή B→A) κινούνται τα πακέτα που απορρίπτονται;
= A→B
= A → B
= AtoB
:::

:::evaluate
Έλεγχος απαντήσεων
:::

Το αίτημα του Lehrer-PC επιτρέπεται να βγει — όμως ήδη το `SYN, ACK` του web server δεν επιστρέφει, επειδή για την κατεύθυνση A → B δεν υπάρχει κατάλληλος κανόνας, οπότε ισχύει η **Απόρριψη όλων**.

## Η αφελής λύση

Θα μπορούσες να προσθέσεις έναν δεύτερο κανόνα: **A → B, TCP, θύρα προέλευσης 80, Αποδοχή** — «ό,τι έρχεται από τη θύρα 80 επιτρέπεται να μπει». Τότε η περιήγηση πράγματι λειτουργεί.

:::quiz mc
Γιατί είναι επικίνδυνος αυτός ο κανόνας;
- [ ] Επειδή οι web servers δεν χρησιμοποιούν ποτέ τη θύρα 80 ως θύρα προέλευσης
- [x] Ένας επιτιθέμενος μπορεί απλώς να στέλνει τα πακέτα του με θύρα προέλευσης 80 — τότε το τείχος προστασίας τα αφήνει να περάσουν προς **οποιαδήποτε** θύρα στο σχολικό δίκτυο
- [ ] Επειδή τότε οι ιστοσελίδες φορτώνουν πιο αργά
:::

:::evaluate
Έλεγχος απάντησης
:::

Τη θύρα προέλευσης την καθορίζει ο ίδιος ο αποστολέας — ένα τείχος προστασίας δεν πρέπει να βασίζεται σε αυτήν. Ένα τείχος προστασίας χωρίς κατάσταση όμως δεν ξέρει αν ένα πακέτο είναι η **απάντηση σε ένα αίτημα** ή μια **νέα απόπειρα σύνδεσης** από έξω. Ακριβώς αυτό αλλάζει η λειτουργία με διατήρηση κατάστασης (stateful).

:::tip Βασικό σημείο
Ένα φίλτρο πακέτων **χωρίς κατάσταση** (stateless) ελέγχει κάθε πακέτο ξεχωριστά. Οι απαντήσεις χρειάζονται τότε δικούς τους κανόνες για την αντίστροφη κατεύθυνση — και τέτοιοι κανόνες (π.χ. «η θύρα προέλευσης 80 επιτρέπεται να μπει») μπορούν να γίνουν αντικείμενο εκμετάλλευσης από επιτιθέμενους, επειδή ο αποστολέας μπορεί να επιλέξει ελεύθερα τη θύρα προέλευσης.
:::

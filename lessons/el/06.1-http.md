# HTTP: ιστοσελίδες

:::goal
**Μαθησιακός στόχος:** Μπορείς να περιγράψεις τη δομή ενός αιτήματος και μιας απόκρισης HTTP, να εξηγήσεις σημαντικές μεθόδους και κωδικούς κατάστασης και να στείλεις μόνος σου ένα αίτημα HTTP με το χέρι.
:::

Το **Hypertext Transfer Protocol** (**HTTP**) είναι η γλώσσα με την οποία επικοινωνούν μεταξύ τους οι περιηγητές και οι διακομιστές ιστού. Στον διακομιστή βρίσκεται ο ιστότοπος του σχολείου **Beaver-Schule**: μια αρχική σελίδα, μια σελίδα επικοινωνίας και ένα φύλλο στυλ (stylesheet) για την εμφάνιση.

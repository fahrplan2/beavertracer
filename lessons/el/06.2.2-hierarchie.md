# Πώς είναι οργανωμένο το DNS

:::sim
url=/sims/lesson-6.2.btsim
:::

Κανένας διακομιστής από μόνος του δεν μπορεί να γνωρίζει όλα τα ονόματα του κόσμου. Γι' αυτό το DNS είναι οργανωμένο **ιεραρχικά**, όπως και τα ίδια τα ονόματα. Τα διαβάζεις από τα δεξιά προς τα αριστερά:

```
www . beaver-schule . de . (Root)
 │          │         │      └─ Root-Server: kennen die Server aller Top-Level-Domains
 │          │         └─ Top-Level-Domain (TLD): der de-Server kennt alle .de-Domains
 │          └─ Domain: der Schul-DNS ist für beaver-schule.de zuständig
 └─ Rechnername innerhalb der Domain
```

Ο διακομιστής που είναι υπεύθυνος για έναν τομέα (domain) και γνωρίζει πραγματικά την απάντηση ονομάζεται **αυθεντικός** (authoritative). Τη διαδρομή μέχρι εκεί την αναλαμβάνει για τον PC ένας **επιλυτής** (resolver). Εδώ αυτός είναι ο υπολογιστής **DNS-Resolver**.

## Το πείραμα

1. Πέρασε στη λειτουργία :fa-play: **Εκτέλεση** και πληκτρολόγησε στο :fa-terminal: **Terminal** του **Client-PC**:
   ```
   $ nslookup www.beaver-schule.de
   ```
2. Στη λειτουργία :fa-magnifying-glass: **Ίχνος**, άνοιξε ένα ίχνος για τον **DNS-Resolver**.

Ο επιλυτής έστειλε για λογαριασμό σου μια ολόκληρη σειρά από ερωτήματα. Αντιστοίχισε ποιος έδωσε ποια απάντηση:

:::quiz match
Root-Server (192.168.0.101) -> Παραπομπή: Για το .de είναι υπεύθυνος ο ns.nic.de
de-Server (192.168.0.102) -> Παραπομπή: Για το beaver-schule.de είναι υπεύθυνος ο ns.beaver-schule.de
Schul-DNS (192.168.0.103) -> Απάντηση: Το www.beaver-schule.de έχει τη διεύθυνση 192.168.0.20
:::

:::quiz mc
Ποιον ρωτά πρώτα ο επιλυτής;
- [x] Τον διακομιστή ρίζας (Root-Server)
- [ ] Τον Schul-DNS
- [ ] Τον Client-PC
:::

:::evaluate
Έλεγχος απαντήσεων
:::

:::note
Ενδιάμεσα, ο επιλυτής ρωτά επίσης τις διευθύνσεις των διακομιστών στους οποίους παραπέμφθηκε (`A ns.nic.de`). Οι πραγματικοί διακομιστές DNS συνήθως στέλνουν αυτές τις διευθύνσεις μαζί με την απάντηση. Επιπλέον, οι επιλυτές θυμούνται κάθε απάντηση για κάποιο χρονικό διάστημα (**κρυφή μνήμη**, cache). Έτσι, το επόμενο ερώτημα για το ίδιο όνομα το απαντούν αμέσως οι ίδιοι. Το πόσο διαρκεί αυτό αναγράφεται στην εγγραφή ως **TTL** (*Time to Live*), σε δευτερόλεπτα.
:::

## Οι σημαντικότεροι τύποι εγγραφών

| Τύπος | Σημασία | Παράδειγμα |
|---|---|---|
| **A** | Όνομα → διεύθυνση IPv4 | `www.beaver-schule.de` → `192.168.0.20` |
| **AAAA** | Όνομα → διεύθυνση IPv6 | `www.beaver-schule.de` → `2001:db8::20` |
| **CNAME** | Όνομα → άλλο όνομα (ψευδώνυμο) | `web.beaver-schule.de` → `www.beaver-schule.de` |
| **MX** | Υπεύθυνος διακομιστής αλληλογραφίας ενός τομέα | `beaver-schule.de` → `mail.beaver-schule.de` |
| **NS** | Υπεύθυνος διακομιστής DNS ενός τομέα | `beaver-schule.de` → `ns.beaver-schule.de` |

:::tip Βασικό σημείο
Το DNS είναι **ιεραρχικό**: Οι **διακομιστές ρίζας** παραπέμπουν στους διακομιστές των **τομέων ανωτάτου επιπέδου** (π.χ. `.de`), κι αυτοί με τη σειρά τους στους διακομιστές των επιμέρους **τομέων**. Ο υπεύθυνος **αυθεντικός** διακομιστής γνωρίζει την απάντηση. Ένας **επιλυτής** ακολουθεί αυτή τη διαδρομή για λογαριασμό του PC και θυμάται τις απαντήσεις (**κρυφή μνήμη**). Σημαντικοί τύποι εγγραφών: **A**, **AAAA**, **CNAME**, **MX**, **NS**.
:::

## Δημιουργία εγγραφής

Το σχολείο θέλει η ιστοσελίδα του να είναι προσβάσιμη και στη διεύθυνση `intranet.beaver-schule.de`.

1. Στη λειτουργία :fa-play: **Εκτέλεση**, κάνε κλικ στον **Schul-DNS** και άνοιξε την εφαρμογή **DNS-Server**.
2. Άνοιξε την καρτέλα **A**. Κάνε κλικ στο **+** και συμπλήρωσε στη νέα γραμμή το όνομα `intranet.beaver-schule.de` και τη διεύθυνση `192.168.0.20`.
3. Κάνε δοκιμή στον Client-PC με την εντολή `nslookup intranet.beaver-schule.de`.

:::task
title: Καταχωρίστηκε το νέο όνομα;
Ελέγχει αν ο Client-PC επιλύει το όνομα intranet.beaver-schule.de στη διεύθυνση του διακομιστή ιστού. Για τον έλεγχο, η προσομοίωση πρέπει να τρέχει σε λειτουργία εκτέλεσης.
check: resolves(2, "intranet.beaver-schule.de", "192.168.0.20")
:::

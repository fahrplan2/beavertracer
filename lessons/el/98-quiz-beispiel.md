## Ενότητα 4: Πολλαπλή επιλογή και τυχαίες ασκήσεις

- [ ] Το ARP βρίσκει τη διεύθυνση IP που αντιστοιχεί σε ένα όνομα

## Ενότητα 5: Χρωματισμός bit

Για τα κεφάλαια IP και υποδικτύωσης: `[[n|…]]` = τμήμα δικτύου, `[[e|…]]` = επέκταση, `[[h|…]]` = τμήμα υπολογιστή — μέσα στο κείμενο και σε πίνακες:

[[n|11111111.11111111.11111111]].[[e|11]][[h|000000]] = `255.255.255.192`

Για αναπαραστάσεις σε πολλές γραμμές χρησιμοποίησε ένα μπλοκ `<pre class="bits-block">` αντί για ``` (σε μπλοκ κώδικα τα χρώματα δεν θα εμφανίζονταν):

<pre class="bits-block">
πριν  (/24):  [[n|NNNNNNNN.NNNNNNNN.NNNNNNNN]].[[h|HHHHHHHH]]
μετά  (/26):  [[n|NNNNNNNN.NNNNNNNN.NNNNNNNN]].[[e|EE]][[h|HHHHHH]]
</pre>

## Ενότητα 6: Διάγραμμα ακολουθίας

Το `:::seq` σχεδιάζει ένα διάγραμμα με δύο γραμμές ζωής. Οι αριθμοί SEQ και ACK καθώς και οι μετρητές στις γραμμές ζωής υπολογίζονται από τις σημαίες και τα ωφέλιμα δεδομένα (`"…"`). Το `-x` αντί για `->` κάνει ένα τμήμα να χαθεί, ενώ το `seq=…` αντικαθιστά έναν αριθμό (π.χ. σε μια επαναμετάδοση).

:::seq
Client -> Server: SYN
Server -> Client: SYN, ACK
Client -> Server: ACK
Client -> Server: PSH, ACK "Hello World"
Server -> Client: ACK
Client -x Server: PSH, ACK "Hallo"
Client -> Server: PSH, ACK "Hallo" seq=12
Server -> Client: ACK
Client -> Server: FIN, ACK
Server -> Client: ACK
Server -> Client: FIN, ACK
Client -> Server: ACK
:::

Με το `:::quiz seq`, τα `?` (πριν από τις σημαίες ή ως `seq=?` / `ack=?`) γίνονται πεδία εισαγωγής· το `hide: counters` κρύβει τους μετρητές:

:::quiz seq
Client -> Server: SYN
Server -> Client: ? SYN, ACK ack=?
Client -> Server: ? ACK ack=?
Client -> Server: PSH, ACK "Hello World"
Server -> Client: ACK ack=?
:::

:::

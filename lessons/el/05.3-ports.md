# Θύρες: πολλές συνδέσεις ταυτόχρονα

:::goal
**Μαθησιακός στόχος:** Μπορείς να εξηγήσεις πώς οι θύρες ξεχωρίζουν πολλές συνδέσεις σε έναν υπολογιστή, να αναφέρεις τις πιο σημαντικές γνωστές θύρες (well-known ports) και να εντοπίζεις τυπικά σφάλματα θυρών.
:::

:::sim
url=/sims/lesson-5.1.btsim
:::

Στην ενότητα 5.1 είδες ότι ο περιηγητής και το TCP Client στέλνουν τα πακέτα τους στην ίδια διεύθυνση IP, κι όμως το καθένα καταλήγει στη σωστή υπηρεσία. Τη διαφορά την έκαναν οι αριθμοί `80` και `5000`, οι **θύρες** (ports). Τώρα θα δεις πιο αναλυτικά πώς λειτουργούν.

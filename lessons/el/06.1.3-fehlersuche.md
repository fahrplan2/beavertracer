# Αντιμετώπιση προβλημάτων: Η σελίδα επικοινωνίας λείπει

:::sim
url=/sims/lesson-6.1.3.btsim
:::

Η γραμματεία αναφέρει: «Στον ιστότοπό μας, ο σύνδεσμος **Kontakt** (Επικοινωνία) οδηγεί πλέον μόνο σε ένα μήνυμα σφάλματος.» Η σελίδα επικοινωνίας πρέπει να είναι προσβάσιμη στη διεύθυνση `http://192.168.0.20/kontakt.html`. Βρες το σφάλμα και διόρθωσέ το.

<details>
<summary>Συμβουλή 1: Τι αναφέρει ο server;</summary>

Άνοιξε τη σελίδα επικοινωνίας στον Περιηγητή ή με `curl -v`. Ποιος κωδικός κατάστασης επιστρέφεται; Η σελίδα σφάλματος σού δείχνει επίσης πού έψαξε ο server για το αρχείο.
</details>

<details>
<summary>Συμβουλή 2: Πού βρίσκονται τα αρχεία;</summary>

Ο web server παραδίδει μόνο αρχεία από τη **Ρίζα Εγγράφων** του (*Document Root*). Αυτή αναγράφεται στην εφαρμογή **HTTP-Server**. Στον **Server**, δες με `ls` στο Terminal τι υπάρχει εκεί και ψάξε τη σελίδα επικοινωνίας και στο `/home`.
</details>

<details>
<summary>Συμβουλή 3: Μετακίνηση αρχείου</summary>

Με την εντολή `mv` μετακινείς ένα αρχείο: `mv <Quelle> <Zielordner>` (Quelle = πηγή, Zielordner = φάκελος προορισμού).
</details>

:::task
title: Επιδιορθώθηκε η σελίδα επικοινωνίας;
Ελέγχει αν η σελίδα επικοινωνίας βρίσκεται στη Ρίζα Εγγράφων του web server.
check: fileExists(2, "/var/www/kontakt.html")
:::

## Τι συνέβαινε;

:::quiz multi
Ποιες προτάσεις είναι σωστές;
- [x] Ο server απάντησε με `404 Not Found`
- [x] Το αρχείο βρισκόταν στο `/home` αντί για τη Ρίζα Εγγράφων `/var/www`
- [ ] Ο web server δεν είχε καν ξεκινήσει
- [ ] Ο περιηγητής χρησιμοποίησε λάθος διεύθυνση IP
:::

:::evaluate
Έλεγχος απάντησης
:::

:::tip Βασικό σημείο
Ένα **404** σημαίνει: ο web server λειτουργεί και είναι προσβάσιμος, αλλά το ζητούμενο **αρχείο** δεν υπάρχει σε αυτή τη διαδρομή. Ο server ψάχνει μόνο στη **Ρίζα Εγγράφων** του (*Document Root*, εδώ `/var/www`). Σύγκρινε: αν ο server δεν απαντά καθόλου ή απαντά με `RST`, το πρόβλημα βρίσκεται βαθύτερα, στο δίκτυο ή στην ίδια την υπηρεσία (κεφάλαιο 5.3.2).
:::

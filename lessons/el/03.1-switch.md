# Ο μεταγωγέας (switch)

:::goal
**Μαθησιακός στόχος:** Μπορείς να συνδέσεις πολλούς υπολογιστές μέσω ενός μεταγωγέα (switch) και να εξηγήσεις πώς ξέρει ο μεταγωγέας σε ποια θύρα πρέπει να στείλει ένα πλαίσιο.
:::

Ένας υπολογιστής έχει συνήθως μόνο μία θύρα δικτύου. Για να συνδέσεις λοιπόν τρεις, δέκα ή εκατό συσκευές μεταξύ τους, χρειάζεσαι έναν κατανεμητή με πολλές θύρες: τον **μεταγωγέα (switch)**.

Στις επόμενες σελίδες θα συνδέσεις πρώτα μόνος σου υπολογιστές σε έναν μεταγωγέα, μετά θα παρατηρήσεις ποια πακέτα φτάνουν σε ποιον, και στο τέλος θα αναζητήσεις σφάλματα σε ένα δίκτυο που δεν λειτουργεί όπως θα έπρεπε.

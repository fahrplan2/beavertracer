# Πιστοποιητικά: σε ποιον ανήκει αυτό το κλειδί;

Με την ασύμμετρη κρυπτογράφηση και τις υπογραφές όλα μοιάζουν να έχουν λυθεί: ο web server της τράπεζάς σου σού στέλνει το δημόσιο κλειδί του, και ξεκινάμε. Πώς όμως ξέρεις ότι αυτό το δημόσιο κλειδί **ανήκει πραγματικά στην τράπεζα**;

Ένας επιτιθέμενος που ανακατευθύνει τη σύνδεσή σου θα μπορούσε απλώς να σου στείλει το **δικό του** δημόσιο κλειδί και να ισχυριστεί ότι είναι η τράπεζα. Ο περιηγητής σου θα κρυπτογραφούσε τότε υπάκουα για τον επιτιθέμενο — κι εκείνος θα διάβαζε τα πάντα. Ένας τέτοιος επιτιθέμενος στη μέση ονομάζεται **Man-in-the-Middle**.

## Το πιστοποιητικό: μια ταυτότητα για κλειδιά

Στην πραγματική ζωή δείχνεις το **δελτίο ταυτότητάς** σου για να αποδείξεις ποιος είσαι. Η ταυτότητα γίνεται πιστευτή επειδή την έχει εκδώσει μια **αξιόπιστη αρχή** — η δημοτική αρχή — και επειδή είναι δύσκολο να πλαστογραφηθεί.

Στο δίκτυο αυτόν τον ρόλο τον αναλαμβάνει ένα **πιστοποιητικό**. Περιέχει μεταξύ άλλων:

| Πεδίο | Σημασία | στο δελτίο ταυτότητας |
|---|---|---|
| **Υποκείμενο** (*Subject*, συχνά `CN=…`) | Για ποιον είναι το πιστοποιητικό; Στους web servers: το όνομα, π.χ. `CN=www.biberbank.de` | Όνομα του κατόχου |
| **Δημόσιο κλειδί** | Το κλειδί του κατόχου | Φωτογραφία |
| **Εκδότης** (*Issuer*) | Ποιος εξέδωσε το πιστοποιητικό; | εκδούσα αρχή |
| **Ισχύς** | από … έως … | ισχύει έως |
| **Υπογραφή** του εκδότη | Αποδεικνύει ότι ο εκδότης εξέδωσε πράγματι το πιστοποιητικό έτσι | Σφραγίδα, ολόγραμμα |

Το `CN` σημαίνει *Common Name*.

Ο φορέας που εκδίδει πιστοποιητικά ονομάζεται **Αρχή Πιστοποίησης** (*Certificate Authority*, εν συντομία **CA**). Πριν υπογράψει ένα πιστοποιητικό για το `www.biberbank.de`, ελέγχει ότι ο αιτών κατέχει πράγματι αυτό το domain.

## Σε ποιον εμπιστεύεται ο περιηγητής;

Ο περιηγητής σου ελέγχει σε κάθε πιστοποιητικό:

1. Είναι γνήσια η **υπογραφή** της CA; (Γι' αυτό χρειάζεται το δημόσιο κλειδί της CA.)
2. Είναι το πιστοποιητικό ακόμα **σε ισχύ**;
3. Ταιριάζει το **όνομα** στο πιστοποιητικό με τη διεύθυνση που άνοιξες;

Πώς όμως γνωρίζει ο περιηγητής την CA; Σε κάθε λειτουργικό σύστημα και περιηγητή υπάρχει **προεγκατεστημένη** μια λίστα με περίπου 150 **ριζικές CA** (*Root-CAs*). Τα πιστοποιητικά τους είναι **αυτοϋπογεγραμμένα** — επιβεβαιώνουν τον εαυτό τους· τις εμπιστευόμαστε επειδή παραδίδονται μαζί με το λογισμικό.

Συχνά μια Root-CA δεν υπογράφει απευθείας, αλλά μέσω μιας **ενδιάμεσης CA**. Έτσι δημιουργείται μια **αλυσίδα εμπιστοσύνης**:

```
Root-CA (vorinstalliert, vertraut)
  └─ signiert → Zwischen-CA
                  └─ signiert → www.biberbank.de
```

Ο περιηγητής ακολουθεί την αλυσίδα από κάτω προς τα πάνω, μέχρι να φτάσει σε μια Root-CA που εμπιστεύεται. Αν αυτό δεν πετύχει — ή αν δεν ισχύει η ισχύς ή το όνομα —, εμφανίζει μια **προειδοποίηση**.

:::quiz match
Υποκείμενο (CN) -> Για ποιο όνομα ισχύει το πιστοποιητικό
Εκδότης -> Ποια CA υπέγραψε το πιστοποιητικό
Δημόσιο κλειδί -> Χρειάζεται για τον έλεγχο των υπογραφών του server
Root-CA -> Είναι προεγκατεστημένη στον περιηγητή και αποτελεί την αρχή της αλυσίδας εμπιστοσύνης
:::

:::tip Βασικό σημείο
Ένα **πιστοποιητικό** επιβεβαιώνει ότι ένα **δημόσιο κλειδί** ανήκει σε ένα συγκεκριμένο **όνομα**. Υπογράφεται από μια **Αρχή Πιστοποίησης (CA)**. Ο περιηγητής εμπιστεύεται ένα πιστοποιητικό όταν μέσω μιας **αλυσίδας εμπιστοσύνης** φτάνει σε μια προεγκατεστημένη **Root-CA**, το πιστοποιητικό είναι **σε ισχύ** και το **όνομα** ταιριάζει με τη διεύθυνση.
:::

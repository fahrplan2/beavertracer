Μια ιστοσελίδα, λοιπόν, αποτελείται συχνά από πολλά αρχεία: κείμενο, φύλλα στυλ, εικόνες. Για καθένα από αυτά ο περιηγητής στέλνει ξεχωριστό αίτημα.

## Πώς μοιάζει ένα αίτημα

Κάνε κλικ στο ίχνος στο πακέτο `GET / HTTP/1.1` και ανάπτυξε το **Hypertext Transfer Protocol**. Ένα αίτημα HTTP είναι καθαρό κείμενο:

```
GET / HTTP/1.1              ← Methode, Pfad, Version
Host: 192.168.0.20          ← Header: zusätzliche Angaben
…
                            ← Leerzeile: Ende der Anfrage
```

Η απάντηση του διακομιστή έχει ακριβώς την ίδια δομή — με μια γραμμή κατάστασης, κεφαλίδες, μια κενή γραμμή και στη συνέχεια το ίδιο το αρχείο:

```
HTTP/1.1 200 OK             ← Version, Statuscode, Text
Content-Type: text/html     ← Header: Art der Datei
Content-Length: 301         ← Header: Größe in Byte
                            ← Leerzeile
<!doctype html> …           ← die Datei selbst
```

:::seq
mode: text
Client-PC -> Server: GET / | Αίτημα HTTP
Server -> Client-PC: 200 OK | index.html
Client-PC -> Server: GET /style.css | Αίτημα HTTP
Server -> Client-PC: 200 OK | style.css
:::

## Μέθοδοι και κωδικοί κατάστασης

Η **μέθοδος** δείχνει τι θέλει ο πελάτης:

| Μέθοδος | Σημασία |
|---|---|
| **GET** | λήψη ενός αρχείου |
| **POST** | αποστολή δεδομένων στον διακομιστή, π.χ. μιας συμπληρωμένης φόρμας |
| **HEAD** | λήψη μόνο των κεφαλίδων, χωρίς το αρχείο |

Ο **κωδικός κατάστασης** δείχνει πώς πήγε το αίτημα. Το πρώτο ψηφίο φανερώνει το είδος της απάντησης:

| Κωδικός | Κείμενο | Σημασία |
|---|---|---|
| **200** | OK | όλα εντάξει |
| **301** | Moved Permanently | η σελίδα μεταφέρθηκε μόνιμα |
| **404** | Not Found | το αρχείο δεν υπάρχει |
| **405** | Method Not Allowed | αυτή η μέθοδος δεν επιτρέπεται εδώ |
| **500** | Internal Server Error | σφάλμα στον διακομιστή |

`2xx` σημαίνει επιτυχία, `3xx` ανακατεύθυνση, `4xx` σφάλμα του πελάτη (λανθασμένο αίτημα), `5xx` σφάλμα του διακομιστή.

:::tip Βασικό σημείο
Το **HTTP** λειτουργεί με την **αρχή αιτήματος-απάντησης**: ο πελάτης στέλνει ένα **αίτημα** (μέθοδο όπως `GET`, διαδρομή, κεφαλίδες) και ο διακομιστής απαντά με έναν **κωδικό κατάστασης** (π.χ. `200 OK`, `404 Not Found`), κεφαλίδες και το αρχείο. Για κάθε αρχείο μιας ιστοσελίδας υπάρχει ξεχωριστό αίτημα.
:::

:::quiz match
200 -> Όλα εντάξει
301 -> Η σελίδα μεταφέρθηκε μόνιμα

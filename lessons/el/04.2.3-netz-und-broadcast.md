# Διεύθυνση δικτύου, διεύθυνση γενικής εκπομπής και hosts

Σε κάθε δίκτυο, δύο διευθύνσεις έχουν ειδικό ρόλο:

- Η **διεύθυνση δικτύου** είναι η **χαμηλότερη** διεύθυνση του δικτύου: όλα τα bit στο τμήμα υπολογιστή είναι 0. Προσδιορίζει το δίκτυο ως σύνολο, π.χ. σε πίνακες δρομολόγησης.
- Η **διεύθυνση γενικής εκπομπής** είναι η **υψηλότερη** διεύθυνση του δικτύου: όλα τα bit στο τμήμα υπολογιστή είναι 1. Ό,τι αποστέλλεται σε αυτήν φτάνει σε όλες τις συσκευές του δικτύου.

Καμία από τις δύο διευθύνσεις **δεν** εκχωρείται σε συσκευές. Όλες οι διευθύνσεις ανάμεσά τους είναι διαθέσιμες για συσκευές (**hosts**).

## Ένα απλό παράδειγμα

`192.168.0.12/24` — το τμήμα υπολογιστή είναι η τελευταία οκτάδα:

| | Διεύθυνση |
|---|---|
| Διεύθυνση δικτύου (τμήμα υπολογιστή = 0) | `192.168.0.0` |
| Διεύθυνση γενικής εκπομπής (τμήμα υπολογιστή = 255) | `192.168.0.255` |
| Εύρος για hosts | `192.168.0.1` – `192.168.0.254` |
| Πλήθος hosts | 254 |

## Όταν το όριο βρίσκεται στη μέση μιας οκτάδας

Τα πράγματα δυσκολεύουν όταν το μήκος προθέματος δεν είναι πολλαπλάσιο του 8. Τότε μετατρέπεις την αντίστοιχη οκτάδα στο δυαδικό σύστημα. Παράδειγμα: `194.9.190.12/27`.

Οι τρεις πρώτες οκτάδες ανήκουν εξ ολοκλήρου στο [[n|τμήμα δικτύου]] (24 bit). Από την τελευταία οκτάδα, **3 bit** ανήκουν ακόμη στο τμήμα δικτύου (24 + 3 = 27) και τα υπόλοιπα **5 bit** στο [[h|τμήμα υπολογιστή]]:

| | τελευταία οκτάδα (δυαδικά) | δεκαδικά |
|---|---|---|
| Διεύθυνση IP | [[n|000]][[h|01100]] | 12 |
| Μάσκα δικτύου (`/27`) | [[n|111]][[h|00000]] | 224 |
| Διεύθυνση δικτύου: bit υπολογιστή σε 0 | [[n|000]][[h|00000]] | **0** |
| Διεύθυνση γενικής εκπομπής: bit υπολογιστή σε 1 | [[n|000]][[h|11111]] | **31** |

Αποτέλεσμα:

- Διεύθυνση δικτύου: `194.9.190.0`
- Διεύθυνση γενικής εκπομπής: `194.9.190.31`
- Εύρος για hosts: `194.9.190.1` – `194.9.190.30`
- Πλήθος hosts: 2⁵ − 2 = **30**

:::tip Βασικό σημείο
**Διεύθυνση δικτύου:** όλα τα bit υπολογιστή σε 0 (χαμηλότερη διεύθυνση). **Διεύθυνση γενικής εκπομπής:** όλα τα bit υπολογιστή σε 1 (υψηλότερη διεύθυνση). Καμία από τις δύο δεν εκχωρείται σε συσκευές. Ένα δίκτυο με μήκος προθέματος *n* έχει **2<sup>32 − n</sup> − 2** αξιοποιήσιμες διευθύνσεις για hosts.
:::

:::tip Συμβουλή: το μέγεθος μπλοκ
Αφού κατανοήσεις τη μέθοδο στο δυαδικό σύστημα, υπάρχει μια συντόμευση: **256 μείον την οκτάδα της μάσκας** δίνει το μέγεθος ενός δικτύου σε αυτή την οκτάδα. Για `/27` (μάσκα 224) αυτό είναι 256 − 224 = **32**. Τα δίκτυα ξεκινούν τότε στο 0, 32, 64, 96 … — η διεύθυνση `.12` βρίσκεται στο δίκτυο που ξεκινά από `.0`, η διεύθυνση `.70` στο δίκτυο που ξεκινά από `.64`.
:::

## Τα σημαντικότερα μεγέθη δικτύων

| Πρόθεμα | Μάσκα δικτύου | Hosts |
|---|---|---|
| `/8` | `255.0.0.0` | 16.777.214 |
| `/16` | `255.255.0.0` | 65.534 |
| `/24` | `255.255.255.0` | 254 |
| `/25` | `255.255.255.128` | 126 |
| `/26` | `255.255.255.192` | 62 |
| `/27` | `255.255.255.224` | 30 |
| `/28` | `255.255.255.240` | 14 |
| `/29` | `255.255.255.248` | 6 |
| `/30` | `255.255.255.252` | 2 |

:::note
Το μικρότερο δίκτυο που χρησιμοποιείται συνήθως στην πράξη είναι το `/30`: έχει ακριβώς δύο αξιοποιήσιμες διευθύνσεις και χρησιμοποιείται συχνά για τη σύνδεση μεταξύ δύο δρομολογητών. Ένα `/32` προσδιορίζει μία μεμονωμένη διεύθυνση — δεν μπορεί να χρησιμοποιηθεί ως δίκτυο, εμφανίζεται όμως σε πίνακες δρομολόγησης και κανόνες firewall.
:::

# Το διάγραμμα ακολουθίας

:::sim
url=/sims/lesson-5.1.btsim
:::

Την πορεία μιας σύνδεσης τη σχεδιάζουμε ως **διάγραμμα ακολουθίας**: ο client και ο server έχουν ο καθένας μια κατακόρυφη γραμμή, και ο χρόνος κυλά από πάνω προς τα κάτω. Κάθε βέλος είναι ένα πακέτο. Σχεδιάζεται πλάγια, επειδή κάθε πακέτο χρειάζεται λίγο χρόνο για να φτάσει.

Έτσι φαίνεται η σύνδεσή σου από την προηγούμενη σελίδα. Σύγκρινέ τη γραμμή προς γραμμή με το ίχνος (trace):

:::seq
Client-PC -> Server: SYN
Server -> Client-PC: SYN, ACK
Client-PC -> Server: ACK
Client-PC -> Server: PSH, ACK "Hello World" len=13
Server -> Client-PC: ACK
Server -> Client-PC: PSH, ACK len=13
Client-PC -> Server: ACK
Client-PC -> Server: FIN, ACK
Server -> Client-PC: ACK
Server -> Client-PC: FIN, ACK
Client-PC -> Server: ACK
:::

Πάνω από κάθε βέλος βρίσκονται οι **σημαίες (flags)** και από κάτω οι αριθμοί `SEQ` και `ACK`. Η ένδειξη **DATA** σημειώνει πακέτα με ωφέλιμα δεδομένα. Οι κόκκινοι αριθμοί ανήκουν στον client και οι μπλε στον server. Τι σημαίνουν θα το δεις στην επόμενη σελίδα.

## Οι σημαίες

| Σημαία | προέρχεται από | Σημασία |
|---|---|---|
| **SYN** | *synchronize* | εγκατάσταση σύνδεσης, καθορισμός αρχικού αριθμού |
| **ACK** | *acknowledge* | επιβεβαιώνει τα δεδομένα που λήφθηκαν |
| **PSH** | *push* | άμεση παράδοση των δεδομένων στο πρόγραμμα |
| **FIN** | *finish* | «Τελείωσα» — τερματισμός της σύνδεσης |
| **RST** | *reset* | διακοπή ή απόρριψη της σύνδεσης (περισσότερα στο 5.3.2) |

## Τρεις φάσεις

**Εγκατάσταση:** Ο client στέλνει `SYN`, ο server απαντά με `SYN, ACK` και ο client επιβεβαιώνει με `ACK`. Επειδή χρειάζονται ακριβώς τρία πακέτα, η διαδικασία αυτή ονομάζεται **χειραψία τριών βημάτων** (three-way handshake).

**Δεδομένα:** Ο παραλήπτης επιβεβαιώνει κάθε πακέτο με δεδομένα με ένα `ACK`. Εδώ ο server στέλνει πίσω την ηχώ (echo), και ο client την επιβεβαιώνει κι αυτή.

**Τερματισμός:** Κάθε πλευρά κλείνει χωριστά τη δική της κατεύθυνση αποστολής: `FIN` από τον client, `ACK` από τον server, και έπειτα `FIN` από τον server, `ACK` από τον client. Συνολικά τέσσερα πακέτα.

:::tip Βασικό σημείο
Μια σύνδεση TCP περνά από τρεις φάσεις: **εγκατάσταση** με τη **χειραψία τριών βημάτων** (`SYN` → `SYN, ACK` → `ACK`), **μεταφορά δεδομένων** (κάθε πακέτο δεδομένων επιβεβαιώνεται με `ACK`) και **τερματισμό** (κάθε πλευρά στέλνει `FIN` και λαμβάνει ένα `ACK`).
:::

## Σειρά σου

Αυτή τη φορά ο client στέλνει μόνο `Hi` (4 byte μαζί με τον χαρακτήρα τέλους γραμμής). Συμπλήρωσε τις σημαίες που λείπουν. Η σειρά μέσα σε ένα πεδίο δεν έχει σημασία.

:::quiz seq
hide: counters

Server -> Client-PC: ? SYN, ACK
Client-PC -> Server: ? ACK

Server -> Client-PC: ? ACK
Client-PC -> Server: ? FIN, ACK
Server -> Client-PC: ? ACK
Server -> Client-PC: ? FIN, ACK
Client-PC -> Server: ? ACK

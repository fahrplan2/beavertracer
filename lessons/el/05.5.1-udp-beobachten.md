# Παρατήρηση του UDP

:::sim
url=/sims/lesson-5.5.btsim
:::

Αυτή τη φορά στον **Server** τρέχει ένας **UDP Echo-Server** στη θύρα `5000`. Και εδώ το καλώδιο έχει προετοιμαστεί: το **δεύτερο datagram** από τον Client-PC προς τον Server χάνεται.

## Το πείραμα

1. Πέρασε στη λειτουργία :fa-play: **Εκτέλεση** και άνοιξε στον **Client-PC** το :fa-terminal: **Terminal**.
2. Ξεκίνα με το `nc` μια UDP «σύνδεση» προς τον Server (το `-u` σημαίνει UDP):
   ```
   $ nc -u 192.168.0.20 5000
   ```
3. Πληκτρολόγησε διαδοχικά `eins`, `zwei` και `drei` και πάτα κάθε φορά **Enter**. Κάθε γραμμή που επιστρέφει είναι ηχώ του Server.
4. Περίμενε μερικά δευτερόλεπτα και μετά, στη λειτουργία :fa-magnifying-glass: **Ίχνος**, άνοιξε ένα ίχνος για τον **Client-PC**.

:::quiz mc
Ποιες ηχώ επιστρέφουν;
- [ ] Και οι τρεις, το `zwei` λίγο αργότερα
- [x] Μόνο το `eins` και το `drei` — το `zwei` λείπει και δεν αποστέλλεται ξανά
- [ ] Καμία
:::

:::quiz multi
Ποια πακέτα που γνωρίζεις από το TCP λείπουν εντελώς στο UDP;
- [x] Εγκατάσταση σύνδεσης (`SYN`)
- [x] Επιβεβαιώσεις (`ACK`)
- [x] Τερματισμός σύνδεσης (`FIN`)
- [ ] Πακέτα με αριθμούς θυρών
:::

:::evaluate
Έλεγχος απαντήσεων
:::

Κάνε κλικ σε ένα από τα πακέτα UDP και ανάπτυξε το **User Datagram Protocol**. Σε σύγκριση με την επικεφαλίδα TCP, η επικεφαλίδα UDP είναι μικροσκοπική: **Source Port**, **Destination Port**, **Length** (μήκος) και **Checksum** (άθροισμα ελέγχου) — όλα μαζί μόνο 8 byte. Μια επικεφαλίδα TCP έχει τουλάχιστον 20 byte, με αριθμό ακολουθίας και αριθμό επιβεβαίωσης, σημαίες (flags) και μέγεθος παραθύρου.

:::quiz mc
Ποια λειτουργία από την ενότητα 5.1 επιτελεί παρ' όλα αυτά το UDP;
- [x] Πολυπλεξία — μέσω των θυρών
- [ ] Εγκατάσταση σύνδεσης
- [ ] Αξιόπιστη μετάδοση
:::

:::evaluate
Έλεγχος απάντησης
:::

:::tip Βασικό σημείο
Το **UDP** είναι **χωρίς σύνδεση**: χωρίς εγκατάσταση σύνδεσης, χωρίς επιβεβαίωση, χωρίς επαναμετάδοση, χωρίς σειρά. Προσφέρει μόνο **θύρες** (πολυπλεξία) και ένα **άθροισμα ελέγχου**. Σε αντάλλαγμα είναι γρήγορο και λιτό — η επικεφαλίδα UDP έχει μόνο 8 byte. Αν χαθεί ένα datagram, πρέπει να το χειριστεί το ίδιο το πρόγραμμα — ή απλώς δεν το ενδιαφέρει.
:::

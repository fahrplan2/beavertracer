## Το πείραμα

1. Πέρασε στη λειτουργία :fa-play: **Εκτέλεση**, κάνε κλικ στον **PC** και άνοιξε στον :fa-globe: **Περιηγητής** τη διεύθυνση `http://www.beispiel.de/`.
2. Στη λειτουργία :fa-magnifying-glass: **Ίχνος**, άνοιξε ένα trace για τον **PC** και ένα δεύτερο για τον web server **www.beispiel.de**.
3. Σύγκρινε και στα δύο traces το πακέτο `GET / HTTP/1.1`: ποιος αναγράφεται ως αποστολέας (**πηγή**);

:::quiz mc
Ποια διεύθυνση αποστολέα έχει το `GET` στο trace του **PC**;
- [x] Η ιδιωτική διεύθυνση του PC (`192.168.178.…`)
- [ ] `203.0.113.2`
- [ ] `192.0.2.80`
:::

:::quiz short
Και ποια διεύθυνση αποστολέα βλέπει ο **web server**;
= 203.0.113.2
:::

:::quiz mc
Ποια διεύθυνση είναι η `203.0.113.2`;
- [ ] Η διεύθυνση του web server
- [x] Η διεύθυνση WAN του οικιακού δρομολογητή
- [ ] Η διεύθυνση του DNS του παρόχου
:::

:::evaluate
Έλεγχος απαντήσεων

## Τι κρύβεται από πίσω

Ο οικιακός δρομολογητής αντικαθιστά σε κάθε πακέτο που βγαίνει στο διαδίκτυο την ιδιωτική διεύθυνση του αποστολέα με τη δική του **δημόσια διεύθυνση WAN** — και συνήθως και τη θύρα του αποστολέα. Για τον web server φαίνεται σαν το αίτημα να προέρχεται από τον οικιακό δρομολογητή. Όταν επιστρέψει η απάντηση, ο οικιακός δρομολογητής αλλάζει ξανά τη διεύθυνση και προωθεί το πακέτο στον PC.

Έτσι ολόκληρο το οικιακό δίκτυο μπορεί να βγει στο διαδίκτυο με μία μόνο δημόσια διεύθυνση — και οι συσκευές στο διαδίκτυο δεν βλέπουν ποτέ τις ιδιωτικές διευθύνσεις.

## Η διαδρομή προς το διαδίκτυο

Πληκτρολόγησε στον **PC** στο :fa-terminal: **Terminal**:

```
$ traceroute 192.0.2.80
```

:::quiz short
Πόσοι δρομολογητές βρίσκονται ανάμεσα στον PC και στον web server; (Μέτρησε όλες τις γραμμές πριν από την τελευταία.)
= 4
= τέσσερις
:::

:::quiz mc
Ποια διεύθυνση δείχνει το `traceroute` για τον πρώτο δρομολογητή;
- [x] `192.168.178.1` — τη διεύθυνση LAN του οικιακού δρομολογητή
- [ ] `203.0.113.2` — τη διεύθυνση WAN του
- [ ] `203.0.113.1` — τον πρώτο δρομολογητή του παρόχου
:::

:::evaluate
Έλεγχος απαντήσεων
:::

:::tip Βασικό σημείο
Το **NAT** (*Network Address Translation*) αντικαθιστά, στη διαδρομή προς το διαδίκτυο, την **ιδιωτική** διεύθυνση αποστολέα μιας συσκευής με τη **δημόσια διεύθυνση WAN** του δρομολογητή — και στις απαντήσεις το αντίστροφο. Έτσι όλες οι συσκευές του οικιακού δικτύου μοιράζονται **μία** δημόσια διεύθυνση IPv4. Αυτό εξοικονομεί διευθύνσεις και κρύβει τις ιδιωτικές διευθύνσεις από το διαδίκτυο.
:::

# DNS: ονόματα αντί για αριθμούς

:::goal
**Μαθησιακός στόχος:** Μπορείς να εξηγήσεις πώς το DNS μεταφράζει ονόματα σε διευθύνσεις IP και πώς οργανώνονται ιεραρχικά τα ονόματα, να δημιουργήσεις μόνος σου μια εγγραφή και να εντοπίζεις τυπικά σφάλματα DNS.
:::

:::sim
url=/sims/lesson-6.2.btsim
:::

Τις διευθύνσεις IP σχεδόν κανείς δεν μπορεί να τις θυμηθεί, ονόματα όμως όπως το `www.beaver-schule.de` τα θυμόμαστε εύκολα. Τη μετάφραση την αναλαμβάνει το **Domain Name System** (**DNS**), ένα είδος παγκόσμιου τηλεφωνικού καταλόγου του διαδικτύου.

Στον χώρο εργασίας υπάρχει τώρα ένα κάπως μεγαλύτερο δίκτυο: εκτός από τον **Client-PC** και τον **Webserver** υπάρχουν τέσσερις **διακομιστές DNS**. Γιατί χρειάζονται τόσοι πολλοί, θα το δεις στη μεθεπόμενη σελίδα.

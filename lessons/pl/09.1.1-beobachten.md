W tej symulacji ktoś już wpisał do zapory sieciowej trzy reguły. Kliknij **Firewall** i przyjrzyj się karcie **Regeln**. **Port A** zapory jest podłączony do internetu, a **Port B** do routera szkolnego — „A → B” oznacza więc „z internetu do sieci szkolnej”.

:::quiz table
| Reguła | Kierunek | Protokół | Port docelowy | Akcja |
|---|---|---|---|---|
| 1 | A → B | {TCP} | {22} | {Odrzucenie} |
| 2 | A → B | TCP | {110} | {Odrzucenie z odpowiedzią} |
| 3 | A → B | {ICMP} | dowolny | Odrzucenie |
:::

:::evaluate
Sprawdź tabelę
:::

## Ping z zewnątrz

Przełącz się do trybu :fa-play: **Uruchom** i wyślij ping z **Internet-PC** do serwera szkolnego:

```
$ ping -c 2 198.51.100.10
```

Następnie otwórz w zaporze kartę **Protokoll**.

:::quiz mc
Co zgłasza `ping`?
- [x] `Anfrage abgelaufen` — nic nie wraca
- [ ] `Paket gefiltert`
- [ ] Dwie odpowiedzi od serwera szkolnego
:::

## Skanowanie portów: odrzucone czy odesłane z odmową?

Przeskanuj teraz celowo pięć portów. Port 3306 (baza danych) nie jest na serwerze szkolnym w ogóle uruchomiony.

```
$ nmap -p 22,25,80,110,3306 198.51.100.10
```

:::quiz match
22 (odrzucony) -> filtered
25 (dozwolony, usługa działa) -> open
110 (odrzucony z odpowiedzią) -> closed
3306 (dozwolony, brak usługi) -> closed
:::

:::evaluate
Sprawdź dopasowanie
:::

:::quiz multi
Co atakujący może wywnioskować z wyniku?
- [x] Przy `filtered` wie: jest tam zapora, która pochłania pakiety
- [x] Przy `closed` nie potrafi odróżnić, czy zapora odsyła odmowę, czy po prostu nie działa żadna usługa
- [ ] Przy `filtered` wie, jaka usługa działa za danym portem
- [ ] Przy `closed` usługa jest mimo to osiągalna
:::

:::evaluate
Sprawdź odpowiedzi
:::

Na koniec przyjrzyj się kolumnie **Treffer** na liście reguł: zapora zlicza tam, ile pakietów rozstrzygnęła każda reguła. Wartość obok **Standardrichtlinie** zlicza wszystkie pakiety, do których nie pasowała żadna reguła.

:::tip Zapamiętaj
**Odrzucone** pakiety znikają bez śladu: `ping` zgłasza przekroczenie czasu, `nmap` zgłasza `filtered`. Na **odrzucone z odpowiedzią** pakiety zapora odpowiada odmową (w TCP jest to RST) — z zewnątrz wygląda to jak zamknięty port. **Protokoll** zapory pokazuje, które pakiety zatrzymała, a kolumna **Treffer** — która reguła zadziałała.
:::

# DNS: nazwy zamiast liczb

:::goal
**Cel lekcji:** Potrafisz wyjaśnić, jak DNS tłumaczy nazwy na adresy IP i jak hierarchicznie zorganizowane są nazwy, samodzielnie utworzyć wpis oraz znaleźć typowe błędy DNS.
:::

:::sim
url=/sims/lesson-6.2.btsim
:::

Adresów IP prawie nikt nie jest w stanie zapamiętać — nazwy takie jak `www.beaver-schule.de` już tak. Tłumaczeniem zajmuje się **Domain Name System** (**DNS**), rodzaj światowej książki telefonicznej internetu.

Na obszarze roboczym jest teraz nieco większa sieć: oprócz **Client-PC** i **Webserver** znajdują się w niej cztery **serwery DNS**. Po co aż tyle, zobaczysz dwie strony dalej.

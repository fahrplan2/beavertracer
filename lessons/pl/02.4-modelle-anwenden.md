# Stosowanie modeli

Przyporządkuj protokoły z eksperymentu z początku rozdziału do ich warstwy OSI:

:::quiz match
Ethernet -> Warstwa 2 — łącza danych
IPv4 -> Warstwa 3 — sieciowa
TCP -> Warstwa 4 — transportowa
HTTP -> Warstwa 7 — aplikacji
:::

:::evaluate
Sprawdź przyporządkowanie
:::

I na koniec nazwy jednostek danych:

:::quiz match
Ramka -> Warstwa 2 — łącza danych
Pakiet -> Warstwa 3 — sieciowa
Segment -> Warstwa 4 — transportowa
:::

:::evaluate
Sprawdź przyporządkowanie
:::

Dzięki temu masz już narzędzia, by w przyszłości poprawnie klasyfikować protokoły. Od następnego rozdziału będziemy omawiać kolejne warstwy po kolei — zaczynając od warstwy 2 i pytania, skąd właściwie switch wie, dokąd ma przekazać pakiet.

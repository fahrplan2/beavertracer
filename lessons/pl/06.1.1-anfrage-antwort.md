Strona internetowa składa się więc często z wielu plików: tekstu, arkuszy stylów, obrazów. Dla każdego z nich przeglądarka wysyła osobne żądanie.

## Jak wygląda żądanie

Kliknij w śladzie pakiet `GET / HTTP/1.1` i rozwiń **Hypertext Transfer Protocol**. Żądanie HTTP to zwykły tekst:

```
GET / HTTP/1.1              ← Methode, Pfad, Version
Host: 192.168.0.20          ← Header: zusätzliche Angaben
…
                            ← Leerzeile: Ende der Anfrage
```

Odpowiedź serwera jest zbudowana tak samo — z wiersza statusu, nagłówków, pustego wiersza, a po nim właściwego pliku:

```
HTTP/1.1 200 OK             ← Version, Statuscode, Text
Content-Type: text/html     ← Header: Art der Datei
Content-Length: 301         ← Header: Größe in Byte
                            ← Leerzeile
<!doctype html> …           ← die Datei selbst
```

:::seq
mode: text
Client-PC -> Server: GET / | Żądanie HTTP
Server -> Client-PC: 200 OK | index.html
Client-PC -> Server: GET /style.css | Żądanie HTTP
Server -> Client-PC: 200 OK | style.css
:::

## Metody i kody statusu

**Metoda** mówi, czego chce klient:

| Metoda | Znaczenie |
|---|---|
| **GET** | pobranie pliku |
| **POST** | wysłanie danych do serwera, np. wypełnionego formularza |
| **HEAD** | pobranie samych nagłówków, bez pliku |

**Kod statusu** mówi, jak poszło. Pierwsza cyfra zdradza rodzaj odpowiedzi:

| Kod | Tekst | Znaczenie |
|---|---|---|
| **200** | OK | wszystko w porządku |
| **301** | Moved Permanently | strona została trwale przeniesiona |
| **404** | Not Found | takiego pliku nie ma |
| **405** | Method Not Allowed | ta metoda nie jest tu dozwolona |
| **500** | Internal Server Error | błąd na serwerze |

`2xx` oznacza sukces, `3xx` przekierowanie, `4xx` błąd po stronie klienta (błędne żądanie), a `5xx` błąd po stronie serwera.

:::tip Zapamiętaj
**HTTP** działa według **zasady żądanie–odpowiedź**: klient wysyła **żądanie** (metodę, np. `GET`, ścieżkę, nagłówki), a serwer odpowiada **kodem statusu** (np. `200 OK`, `404 Not Found`), nagłówkami i plikiem. Dla każdego pliku strony internetowej wysyłane jest osobne żądanie.
:::

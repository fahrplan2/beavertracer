# Dlaczego jedna sieć nie wystarcza

:::sim

Na obszarze roboczym widzisz dwie małe sieci firmowe: **Firma A** z Anną (`192.168.0.10`) i Benem (`192.168.0.11`) oraz **Firma B** z Clarą (`172.16.0.10`) i Davidem (`172.16.0.11`). Oba przełączniki są nawet połączone bezpośrednio kablem.

## Ping w sieci lokalnej

1. Przełącz się w tryb uruchamiania :fa-play: **Uruchom**, otwórz na **Anna** :fa-terminal: **Terminal** i wyślij ping do Bena:
   ```
   $ ping 192.168.0.11
   ```
2. Przełącz się w tryb :fa-magnifying-glass: **Ślad**, otwórz trace dla **Anna** i kliknij `Echo (ping) request`.
3. Rozwiń w drzewie protokołów wiersz **Internet Protocol Version 4**. To jest część IP pakietu — ta, której dotyczy ten rozdział.

:::quiz match
Source Address -> adres IP nadawcy
Destination Address -> adres IP odbiorcy
Time to Live -> przez ile routerów pakiet może jeszcze przejść
Protocol -> jaki protokół jest zawarty w pakiecie (tutaj ICMP, czyli ping)
:::

Sprawdź dopasowanie

## Ping do innej sieci

Wróć do trybu uruchamiania :fa-play: **Uruchom** i wyślij ping z **Anna** do Clary (`ping 172.16.0.10`). Następnie jeszcze raz przyjrzyj się śladowi Anny.

:::quiz mc
Co się dzieje?
- [ ] Ping działa — przecież przełączniki są połączone
- [x] Ping nie dociera, a w śladzie Anny nie pojawia się ani jeden pakiet do Clary — nawet zapytanie ARP
- [ ] Anna wysyła zapytanie ARP, ale Clara nie odpowiada
:::

:::quiz mc
Dlaczego Anna w ogóle nic nie wysyła?
- [ ] Kabel między przełącznikami jest uszkodzony
- [ ] Clara jest wyłączona
- [x] Anna po adresie IP Clary rozpoznaje, że Clara znajduje się w innej sieci — i nie zna drogi do niej

## Co za tym stoi

Adres IP działa podobnie jak adres pocztowy: jedna część mówi, w której **sieci** znajduje się urządzenie (jak ulica), a druga — o które **urządzenie** w tej sieci chodzi (jak numer domu). Anna jest w sieci `192.168.0…`, Clara w sieci `172.16.0…` — to dwie różne „ulice”.

Do urządzeń we *własnej* sieci komputer wysyła pakiety bezpośrednio (przez ARP i przełącznik, tak jak już znasz). Do *obcej* sieci potrzebuje urządzenia, które łączy sieci ze sobą i przekazuje pakiety dalej: **routera**. Tutaj jeszcze go nie ma — dlatego nie pomaga też kabel między przełącznikami.

:::tip Zapamiętaj
**Internet Protocol** (**IP**) w warstwie 3 sprawia, że pakiety docierają również między różnymi sieciami. **Adres IP** składa się z **części sieciowej** (w której sieci?) i **części hosta** (które urządzenie?). Urządzenia w tej samej sieci komunikują się bezpośrednio — do innych sieci potrzebny jest **router**.
:::

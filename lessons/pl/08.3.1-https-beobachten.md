# HTTP i HTTPS w porównaniu

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Serwer WWW **www.beaver-schule.de** udostępnia szkolny portal z ocenami zarówno przez HTTP, jak i przez HTTPS. Co widzi osoba podsłuchująca?

## Eksperyment

1. Przełącz się w :fa-play: tryb uruchamiania (**Uruchom**) i na **Client-PC** w :fa-globe: **Przeglądarce** otwórz najpierw `http://www.beaver-schule.de/`, a potem `https://www.beaver-schule.de/`.
2. W :fa-magnifying-glass: trybie **Ślad** otwórz trace dla **Client-PC**.
3. Najpierw znajdź pakiet `HTTP/1.1 200 OK` i kliknij go. Na dole w szczegółach znajdziesz zawartość strony.

:::quiz mc

- [x] Całą stronę internetową, także oceny Anny
- [ ] Tylko adres serwera
- [ ] Nic, ponieważ HTTP działa przez TCP
:::

Teraz część dotycząca HTTPS. Znajdź pakiet `[SYN]`, którym klient rozpoczyna drugie połączenie.

:::quiz short
Jaki port docelowy ma połączenie HTTPS (kolumna **Info**, `… → ???`)?
= 443
:::

Wpisz teraz u góry w polu filtra śladu `tls` — wtedy zobaczysz już tylko pakiety TLS.

:::quiz mc
Co znajduje się w kolumnie **Info** przy pakietach zawierających stronę internetową?
- [ ] `HTTP/1.1 200 OK`
- [x] `Application Data`
- [ ] `Encrypted HTML`
:::

:::quiz multi

- [x] Adresy IP klienta i serwera
- [x] Że używany jest port 443, czyli prawdopodobnie HTTPS
- [x] Ile mniej więcej danych jest przesyłanych
- [ ] Jaka strona została otwarta i co się na niej znajduje
:::

:::note
Kliknij pakiet **Application Data**: dane użytkowe to tylko ciąg pozornie losowych bajtów. Tracer nie potrafi ich odszyfrować — klucza sesji nie zna tak samo, jak nie zna go atakujący.
:::

:::tip Zapamiętaj
Przy **HTTP** każdy podsłuchujący może przeczytać całą stronę internetową. Przy **HTTPS** widzi już tylko, **kto z kim** rozmawia (adresy IP, port 443) i **ile** danych jest przesyłanych — zawartość jest zaszyfrowana w pakietach **Application Data**.
:::

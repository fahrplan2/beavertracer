# Veaotsing: teenus ei vasta

:::sim
url=/sims/lesson-5.3.2.btsim
:::

Pärast uuendust teatab kool: „Echo-teenus lükkab iga ühenduse tagasi ja veebileht ei lae enam ka.“ Plaani järgi peab **veebiserver** kuulama porti `80` ja **echo-teenus** (TCP Echo-server) porti `5000`. Leia vead ja paranda need.

<details>
<summary>Vihje 1: Mida server vastab?</summary>

Proovi **Lihtne TCP klient** abil ühenduda aadressiga `192.168.0.20`, port `5000`, ja ava kliendi-arvuti jaoks jälg. Mida server vastab sinu `[SYN]`-ile?
</details>

<details>
<summary>Vihje 2: Millised pordid on avatud?</summary>

Sisesta kliendi-arvutis terminalis `nmap -p 80,5000 192.168.0.20`. `nmap` proovib porte ükshaaval läbi ja näitab, millised on avatud. Käsuga `ss` näed serveris, milliseid porte tegelikult mõni programm kuulab.
</details>

<details>
<summary>Vihje 3: Kus seda seadistatakse?</summary>

Ava **serveris** rakendused **TCP Echo-server** ja **HTTP-server**. Kas teenus töötab? Ja millisel pordil?
</details>

:::task
title: Kas teenused on kättesaadavad?
Kontrolli, kas kliendi-arvuti jõuab echo-teenuseni pordil 5000 ja veebiserverini pordil 80. Selleks peab simulatsioon töötama käivitusrežiimis.
check: tcpOpen(1, 2, 5000)
check: tcpOpen(1, 2, 80)
:::

## Mis juhtus?

:::quiz multi
Millised väited vastavad tõele?
- [x] Server vastas `[SYN]`-ile pordile 5000 paketiga `[RST, ACK]`
- [x] Echo-teenus kuulas porti 5050 port 5000 asemel
- [x] Veebiserver polnud üldse käivitatud
- [ ] Kaabel kliendi-arvuti ja serveri vahel oli katki
:::

:::evaluate
Kontrolli vastust
:::

:::tip Pea meeles
Kui `SYN`-ile tuleb vastuseks **`RST`**, siis sellel pordil **ei kuula ükski programm**: arvuti on kättesaadav, aga teenus mitte. Tüüpilised põhjused: teenus **pole käivitatud** või kuulab **teist porti**. Pilk serverisse käsuga `ss` näitab, millised pordid on tegelikult avatud.
:::

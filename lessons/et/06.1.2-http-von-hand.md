# HTTP käsitsi

:::sim

:::

Kui HTTP on puhas tekst — kas siis saab veebiserveriga ka ise rääkida, täiesti ilma brauserita? Jah: `telnet`iga lood TCP-ühenduse suvalise pordiga ja trükid teksti ise.

## Katse

1. Lülitu :fa-play: **Käivita** režiimi (käivitusrežiimi) ja ava **Client-PC** peal :fa-terminal: **Terminalis**.
2. Ühendu serveri pordiga 80:
   ```
   $ telnet 192.168.0.20 80
   ```
3. Trüki päring rida realt — ja lõpeta see **tühja reaga** (vajuta lihtsalt veel kord **Enter**):
   ```
   GET /kontakt.html HTTP/1.1
   Host: 192.168.0.20

   ```

Server vastab olekurea, päiste ja kontaktilehega — tekstina, täpselt nii, nagu brauser selle saab.

- [x] Tühja rea järgi
- [ ] Teatud aja möödumise järel
:::

## Vigade esilekutsumine

Mugavam tööriist on `curl`: see esitab päringu sinu eest. Võtmega `-v` (*verbose*, üksikasjalik) näitab see kõike, mis edasi-tagasi liigub — read märgiga `>` saatis `curl`, read märgiga `<` tulid serverilt.

Proovi:

```
$ curl -v http://192.168.0.20/gibtsnicht.html
$ curl -X POST -d name=Anna http://192.168.0.20/
```

:::note
BeaverTraceri veebiserver oskab ainult faile edastada — seetõttu lubab ta vaid `GET` ja `HEAD`. Päris veebiserverid võtavad `POST`iga vastu näiteks vorme ja annavad andmed edasi mõnele programmile.
:::

:::tip Pea meeles
Paljud rakenduskihi protokollid on **tekstipõhised** — HTTP, aga ka SMTP, POP3 ja IMAP. Seetõttu saab neid `telnet`iga käsitsi "rääkida" ja jälgijas kaasa lugeda. See on veaotsinguks praktiline — aga ka turvaprobleem: igaüks, kes andmeliiklust pealt salvestab, saab kõike lugeda. Kuidas krüptimine (HTTPS) aitab, õpid 8. peatükis.
:::

## Katse

1. Lülitu :fa-play: **Käivita** režiimi (käivitusrežiim), klõpsa **Client-PC** peal ja ava :fa-globe: **Brauser**. Ava `http://192.168.0.20/`.
2. Klõpsa akna ülaosas nupul **Tagasi**, ava **Lihtne TCP klient** ja ühenda see aadressiga `192.168.0.20`, port `5000`. Jäta ühendus avatuks.
3. Lülitu :fa-magnifying-glass: **Jälgi** režiimi, ava **Client-PC** jaoks jälg ja klõpsa paketil, millel on `[SYN]`. Ava **Transmission Control Protocol**.

TCP päise päris alguses on kaks porti: **Source Port** (lähteport) ja **Destination Port** (sihtport).

| Ühendus | Lähteport | Sihtport |
|---|---|---|
| Brauser → veebiserver | {49152} | {80} |
| TCP klient → Echo-teenus | {49153} | {5000} |
:::

## Kaks sorti porte

**Sihtport — teenus:** serveriprogramm ootab ühendusi kindlal pordil — öeldakse, et ta **kuulab** seal. Tuntud teenuste numbrid on kogu maailmas fikseeritud, need on **tuntud pordid** (*well-known ports*, 0 kuni 1023). Brauser teab seetõttu ilma küsimata: veebiserverid kuulavad porti 80.

**Lähteport — saatja:** kliendipoolse pordi valib operatsioonisüsteem iga uue ühenduse jaoks ise kõrgest vahemikust (BeaverTraceris alates 49152). Selle järgi tunneb klient ära, millise tema ühenduse vastus see on.

Ühendus on seega üheselt määratud nelja andmega: **IP-aadress ja port mõlemal poolel**. IP-aadressi ja pordi paari nimetatakse **socketiks**, nt `192.168.0.20:80`.

## Pilk serverile

Lülitu tagasi :fa-play: **Käivita** režiimi, ava **Server**-i peal :fa-terminal: **Terminalis** ja sisesta:

```
$ ss
```

`ss` näitab arvuti kõiki socketeid. Read, kus on `LISTEN`, on programmid, mis kuulavad mingit porti. Read, kus on `ESTABLISHED`, on olemasolevad ühendused — oma socketiga (*Local Address:Port*) ja vastaspoole socketiga (*Peer Address:Port*).

:::quiz multi
Milliseid porte server kuulab?
- [x] 80
- [x] 5000
- [ ] 49152
- [ ] 443
:::

:::quiz mc
Millise ühenduse näitab `ss` olekuga `ESTABLISHED`?
- [x] `192.168.0.20:5000` ja `192.168.0.10:49153` — TCP kliendi avatud ühendus
- [ ] `192.168.0.20:80` ja `192.168.0.10:49152` — brauseri ühendus
- [ ] Mõlemad
:::

:::note
Brauseri ühendus on juba lõpetatud — pärast lehe laadimist suleti see `FIN`-iga. `ss` näitab seda veel korraks olekuga `TIME-WAIT`: server ootab mõnda aega, kas selle ühenduse hilinenud pakette veel saabub. TCP kliendi ühendus on seevastu veel avatud, sest sa ei ole veel klõpsanud nupul **Lahuta ühendus**.
:::

## Olulisemad tuntud pordid

| Port | Protokoll | Teenus |
|---|---|---|
| 22 | SSH | turvaline kaughaldus (krüptitud käsurida) |
| 25 | SMTP | e-kirjade saatmine |
| 53 | DNS | nimede tõlkimine IP-aadressideks (enamasti UDP kaudu) |
| 80 | HTTP | veebilehed |
| 110 | POP3 | e-kirjade allalaadimine |
| 143 | IMAP | e-kirjade haldamine serveris |
| 443 | HTTPS | krüptitud veebilehed |

:::tip Pea meeles
**Pordid** (0 kuni 65535) hoiavad ühe arvuti ühendused üksteisest lahus. Serveriteenused **kuulavad** kindlatel **tuntud portidel** (nt HTTP 80, HTTPS 443), kliendid saavad iga ühenduse jaoks vaba kõrge **lähtepordi**. Ühendus on üheselt määratud **mõlema poole IP-aadressi ja pordiga**.
:::

:::quiz match
22 -> SSH
25 -> SMTP
53 -> DNS
80 -> HTTP
110 -> POP3
143 -> IMAP
443 -> HTTPS
:::

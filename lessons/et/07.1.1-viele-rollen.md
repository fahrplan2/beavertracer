## Mida kõike kodune ruuter sisaldab

| Roll koduses ruuteris | Mida see teeb | tuttav peatükist |
|---|---|---|
| **Switch** | ühendab seadmed LAN-pesades | peatükk 3.1 |
| **Juurdepääsupunkt** | toob telefonid, tahvelarvutid ja sülearvutid WiFi kaudu võrku | peatükk 3.3 |
| **Ruuter** | ühendab kodune võrgu teenusepakkuja võrguga — see on **lüüs** | peatükk 4.3 |
| **DHCP-server** | jagab aadresse, lüüsi ja DNS-serverit | peatükk 6.4 |
| **DNS** | suunab nimepäringud edasi või nimetab teenusepakkuja DNS-serveri | peatükk 6.2 |
| **NAT** | viib kõik seadmed internetti **ühe** avaliku aadressi kaudu | uus — jaotis 7.2 |

Port **WAN** (*Wide Area Network*) viib teenusepakkuja juurde, pordid **LAN** ja WiFi koduvõrku. Paljud koduruuterid sisaldavad lisaks **modemit** — see tõlgib andmed liini jaoks (DSL, kaabel, valguskaabel). BeaverTracer seda ei simuleeri; siin on WAN-port ühendatud otse teenusepakkuja võrku.

:::quiz match
Switch -> Ühendab seadmed LAN-pesades
Juurdepääsupunkt -> Toob tahvelarvutid ja telefonid WiFi kaudu võrku
DHCP-server -> Jagab aadresse koduse võrgu seadmetele
Ruuter -> Ühendab kodune võrgu teenusepakkuja võrguga
:::

:::tip Pea meeles
**Kodune ruuter** ühendab endas mitu seadet: **switch**, **WiFi-juurdepääsupunkt**, **ruuter** (lüüs internetti), **DHCP-server** ja **DNS-i edasisuunamine** — lisaks **NAT**. Port **WAN** viib teenusepakkuja juurde, pordid **LAN** ja WiFi koduvõrku.
:::

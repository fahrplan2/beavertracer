Tööalal näed **Client-PC**-d, **DNS-serverit** ja kooli veebiserverit `www.beaver-schule.de`. Veebiserver pakub oma lehti ka **HTTPS**-i kaudu.

## Lukk brauseris

1. Lülitu :fa-play: **Käivita**-režiimi (käivitusrežiim), klõpsa **Client-PC** peal ja ava :fa-globe: **Brauser**.
2. Ava `https://www.beaver-schule.de/` — pööra tähelepanu sellele, et aadress algab **https**-iga.
3. Aadressi vasakul küljel ilmub **lukk**. Klõpsa sellel.

:::quiz short
Millise nime jaoks sertifikaat välja anti (subjekt ilma `CN=`-ita)?
= www.beaver-schule.de
:::

:::quiz short
Kes sertifikaadi välja andis (väljaandja ilma `CN=`-ita)?
= Biber Root CA
:::

:::evaluate
Kontrolli vastuseid
:::

## Miks Client-PC sertifikaati usaldab?

Ava **Client-PC** peal :fa-shield-halved: **Zertifikatverwaltung** ja vaheta vahelehele **Vertrauenswürdige CAs**.

:::quiz mc
Mida sa seal leiad?
- [x] **Biber Root CA** sertifikaadi
- [ ] `www.beaver-schule.de` sertifikaadi
- [ ] Kirjeid ei ole
:::

:::quiz mc
Kuidas on näha, et Biber Root CA on juur-CA?
- [x] See on **iseallkirjastatud**: subjekt ja väljaandja on samad
- [ ] Tema nimi lõpeb „CA“-ga
- [ ] Tal ei ole avalikku võtit
:::

:::quiz mc
Kas Client-PC juures on **Privater Schlüssel** all „Ja“ või „Nein“?
- [ ] Ja — klient vajab allkirjade kontrollimiseks CA privaatvõtit
- [x] Nein — kontrollimiseks piisab avalikust võtmest; privaatvõti on ainult CA-l
:::

:::evaluate
Kontrolli vastuseid
:::

## Vastaspool: veebiserver

Ava nüüd veebiserveri **www.beaver-schule.de** peal :fa-shield-halved: **Zertifikatverwaltung** (vaheleht **Meine Zertifikate**) ja vaata tema sertifikaati.

:::quiz multi
Mis kehtib veebiserveri sertifikaadi kohta?
- [x] **Privater Schlüssel** juures on „Ja“ — server vajab seda ühenduse loomiseks
- [x] **Kette** on `www.beaver-schule.de ← Biber Root CA`
- [x] **Sõrmejälg** on sama mis brauseri lukuaknas
- [ ] See on iseallkirjastatud
:::

:::evaluate
Kontrolli vastuseid
:::

:::note
**Sõrmejälg** on sertifikaadist arvutatud räsiväärtus. Selle abil saab kaht sertifikaati kiiresti võrrelda — ilma et peaks kõiki välju eraldi kontrollima.
:::

:::tip Pea meeles
**Veebiserveril** on oma sertifikaat **koos privaatvõtmega**. **Klient** tunneb ainult **juur-CA sertifikaati** (ilma privaatvõtmeta) — see piisab, et kontrollida allkirja serveri sertifikaadil. Kui brauseris klõpsata **lukul**, näeb subjekti, väljaandjat, sõrmejälge ja kehtivusaega.
:::

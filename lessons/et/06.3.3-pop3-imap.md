# POP3 või IMAP?

:::sim
url=/sims/lesson-6.3.btsim
:::

Meilide kättesaamiseks on kaks protokolli. Selles simulatsioonis kasutab **Anna POP3** ja **Ben IMAP-i**.

## Katse

1. Saada :fa-play: **Käivita**-režiimis **Benilt** kiri aadressile `anna@beaver-schule.de`.
2. Klõpsa **Anna** juures rakenduses **E-Mail** nupul **Laadi**.
3. Ava **Anna** ja **Beni** jäljed (trace'id) ning võrdle meilide kättesaamisel kasutatud käske.

:::quiz match
USER / PASS -> POP3: sisselogimine kasutajanime ja parooliga kahes etapis
RETR -> POP3: ühe sõnumi allalaadimine
LOGIN -> IMAP: sisselogimine kasutajanime ja parooliga
SELECT INBOX -> IMAP: kausta avamine serveris
:::

:::evaluate
Kontrolli vastavust
:::

## Erinevus

| | POP3 | IMAP |
|---|---|---|
| Port | 110 | 143 |
| Põhiidee | Meilid **laaditakse alla** — pärast seda tavaliselt serverist kustutatakse | Meilid **jäävad serverisse** ja neid hallatakse seal |
| Kaustad, loetud/lugemata | ainult oma seadmes | serveris — kõikjal ühesugused |
| Mitu seadet (telefon, sülearvuti) | ebamugav: igal seadmel on erinev seis | ideaalne: kõik seadmed näevad sama postkasti |

:::note
BeaverTraceri meiliprogramm jätab meilid POP3 puhul samuti serverisse. Päris programmid kustutavad need pärast allalaadimist sageli ära — või jätavad need serverisse vaid mõneks ajaks.
:::

:::quiz mc
Lena loeb oma meile telefonis, tahvelarvutis ja kooli sülearvutis. Mida peaks ta kasutama?
- [ ] POP3, sest see on lihtsam
- [x] IMAP-i, sest kõik seadmed näevad serveris sama postkasti
- [ ] SMTP-d, sest see on mõeldud meilide kättesaamiseks
:::

:::evaluate
Kontrolli vastust
:::

:::tip Pea meeles
**POP3** laeb meilid serverist alla **ühte** seadmesse. **IMAP** haldab postkasti **serveris** — kaustade ja loetud-olekuga kõigi seadmete jaoks korraga. Mõlemad on mõeldud ainult **kättesaamiseks**; saatmiseks kasutatakse alati **SMTP-d**.
:::

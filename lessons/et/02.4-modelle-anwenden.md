# Mudelite rakendamine

Seo katses, mida tegid peatüki alguses, kasutatud protokollid vastava OSI kihiga:

:::quiz match
Ethernet -> Kiht 2 — Lülikiht
IPv4 -> Kiht 3 — Võrgukiht
TCP -> Kiht 4 — Transpordikiht
HTTP -> Kiht 7 — Rakenduskiht
:::

:::evaluate
Kontrolli vastavust
:::

Ja lõpuks andmeühikute nimetused:

:::quiz match
Raam -> Kiht 2 — Lülikiht
Pakett -> Kiht 3 — Võrgukiht
Segment -> Kiht 4 — Transpordikiht
:::

:::evaluate
Kontrolli vastavust
:::

Nüüd on sul vajalik tööriistakast, et protokolle edaspidi korrektselt kihtidesse paigutada. Järgmisest peatükist alates käime kihid ükshaaval läbi — alustades kihist 2 ja küsimusest, kuidas switch õigupoolest teab, kuhu ta paketi edasi peab saatma.

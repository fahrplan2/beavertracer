# Kuidas DNS on korraldatud

:::sim
url=/sims/lesson-6.2.btsim
:::

Ükski üksik server ei saa teada kõiki maailma nimesid. Seepärast on DNS üles ehitatud **hierarhiliselt** — nagu nimed ise. Neid loetakse paremalt vasakule:

```
www . beaver-schule . de . (Root)
 │          │         │      └─ Root-Server: kennen die Server aller Top-Level-Domains
 │          │         └─ Top-Level-Domain (TLD): der de-Server kennt alle .de-Domains
 │          └─ Domain: der Schul-DNS ist für beaver-schule.de zuständig
 └─ Rechnername innerhalb der Domain
```

Serverit, mis vastutab domeeni eest ja teab vastust tõesti, nimetatakse **autoriteetseks**. Tee selleni läbib arvuti eest **resolver** — siin arvuti **DNS-Resolver**.

## Katse

1. Lülitu :fa-play: **Käivita**-režiimi ja sisesta **Client-PC** :fa-terminal: **Terminalis**:
   ```
   $ nslookup www.beaver-schule.de
   ```
2. Ava :fa-magnifying-glass: **Jälgi**-režiimis **DNS-Resolver**i jälg.

Resolver esitas sinu eest terve rea päringuid. Seo kokku, kes millise vastuse andis:

:::quiz match
Root-Server (192.168.0.101) -> Viide: .de eest vastutab ns.nic.de
de-Server (192.168.0.102) -> Viide: beaver-schule.de eest vastutab ns.beaver-schule.de
Schul-DNS (192.168.0.103) -> Vastus: www.beaver-schule.de aadress on 192.168.0.20
:::

:::quiz mc
Keda resolver kõigepealt küsib?
- [x] Root-serverit
- [ ] Schul-DNS-i
- [ ] Client-PC-d
:::

:::evaluate
Kontrolli vastuseid
:::

:::note
Vahepeal küsib resolver ka nende serverite aadresse, millele ta suunati (`A ns.nic.de`). Päris DNS-serverid saadavad need aadressid tavaliselt kohe kaasa. Peale selle jätavad resolverid iga vastuse mõneks ajaks meelde (**cache**) — sama nime järgmisele päringule vastavad nad kohe ise. Kui kauaks, on kirjes näidatud **TTL**-ina (*Time to Live*) sekundites.
:::

## Tähtsamad kirjetüübid

| Tüüp | Tähendus | Näide |
|---|---|---|
| **A** | nimi → IPv4-aadress | `www.beaver-schule.de` → `192.168.0.20` |
| **AAAA** | nimi → IPv6-aadress | `www.beaver-schule.de` → `2001:db8::20` |
| **CNAME** | nimi → teine nimi (alias) | `web.beaver-schule.de` → `www.beaver-schule.de` |
| **MX** | domeeni eest vastutav meiliserver | `beaver-schule.de` → `mail.beaver-schule.de` |
| **NS** | domeeni eest vastutav DNS-server | `beaver-schule.de` → `ns.beaver-schule.de` |

:::tip Pea meeles
DNS on **hierarhiline**: **root-serverid** viitavad **ülataseme domeenide** (nt `.de`) serveritele, need omakorda üksikute **domeenide** serveritele. Vastutav **autoriteetne** server teab vastust. **Resolver** käib selle tee arvuti eest läbi ja jätab vastused meelde (**cache**). Olulised kirjetüübid: **A**, **AAAA**, **CNAME**, **MX**, **NS**.
:::

## Kirje lisamine

Kool soovib, et selle veebilehele pääseks ligi ka aadressil `intranet.beaver-schule.de`.

1. Klõpsa :fa-play: **Käivita**-režiimis **Schul-DNS**-il ja ava rakendus **DNS-Server**.
2. Ava vaheleht **A**. Klõpsa **+** ja sisesta uude ritta nimi `intranet.beaver-schule.de` ning aadress `192.168.0.20`.
3. Testi Client-PC-l käsuga `nslookup intranet.beaver-schule.de`.

:::task

check: resolves(2, "intranet.beaver-schule.de", "192.168.0.20")
:::

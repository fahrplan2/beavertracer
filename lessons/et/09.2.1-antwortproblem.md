# Vastuseprobleem

:::sim

Tulemüür töötab nüüd lubatud nimekirja (whitelist) põhimõttel: vaikepoliitika on **Alle verwerfen**. Üksainus reegel lubab koolivõrgul veebis surfata: **B → A, TCP, Ziel-Port 80, Zulassen**. Režiim on **Stateless**.

## Katse

1. Lülitu :fa-play: **Käivita**-režiimi ja ava **Lehrer-PC** arvutis :fa-globe: **Brauser** `http://203.0.113.80/`.
2. Vaata **Firewall** seadmes **Protokoll** ja **Treffer** andmeid.

:::quiz mc
Mis juhtub brauseris?
- [ ] Ilmub lehekülg www.beispiel.de
- [x] Leht ei lae, brauser ootab ja teatab lõpuks veast
:::

:::quiz mc
Millised paketid on tulemüüri protokollis märgitud kui verworfen (`DROP`)?
- [ ] Lehrer-PC päringud pordile 80
- [x] Aadressilt `203.0.113.80` tulevad vastused **lähtepordiga 80** Lehrer-PC suunas
- [ ] Mitte ühtegi
:::

:::quiz short
Millises suunas (A→B või B→A) liiguvad tõrjutud paketid?
= A→B
= A → B
= AtoB
:::

:::evaluate
Kontrolli vastuseid
:::

Lehrer-PC päring pääseb välja — kuid juba veebiserveri `SYN, ACK` ei jõua tagasi, sest suuna A → B jaoks puudub sobiv reegel, seega kehtib **Alle verwerfen**.

## Naiivne lahendus

Võiks lisada teise reegli: **A → B, TCP, Quell-Port 80, Zulassen** — „kõik, mis tuleb pordilt 80, võib sisse tulla“. Siis surfamine tõepoolest toimib.

:::quiz mc
Miks on see reegel ohtlik?
- [ ] Sest veebiserverid ei kasuta kunagi lähtepordina porti 80
- [x] Ründaja saab oma paketid lihtsalt lähtepordiga 80 teele saata — siis laseb tulemüür need läbi **igale** koolivõrgu pordile
- [ ] Sest siis laevad veebilehed aeglasemalt
:::

:::evaluate
Kontrolli vastust
:::

Lähtepordi määrab saatja ise — tulemüür ei tohi selle peale tugineda. Olekuta tulemüür aga ei tea, kas pakett on **vastus päringule** või **uus ühendusekatse** väljastpoolt. Just seda muudab olekupõhine režiim.

:::tip Pea meeles
**Olekuta** pakettfilter kontrollib iga paketti eraldi. Vastused vajavad siis tagasisuuna jaoks eraldi reegleid — ja selliseid reegleid (nt „lähtepordilt 80 tohib sisse tulla“) saavad ründajad ära kasutada, sest saatja võib lähtepordi vabalt valida.
:::

# Võrguaadress, leviaadress ja hostid

Igas võrgus on kahel aadressil eriline ülesanne:

- **Võrguaadress** on võrgu **madalaim** aadress: kõik hostiosa bitid on 0. See tähistab võrku tervikuna, nt marsruutimistabelites.
- **Leviaadress** on võrgu **kõrgeim** aadress: kõik hostiosa bitid on 1. Kõik, mis sinna saadetakse, jõuab kõigi võrgu seadmeteni.

Neid kahte aadressi **ei** anta seadmetele. Kõik nende vahele jäävad aadressid on mõeldud seadmetele (**hostidele**).

## Lihtne näide

`192.168.0.12/24` — hostiosa on viimane oktett:

| | Aadress |
|---|---|
| Võrguaadress (hostiosa = 0) | `192.168.0.0` |
| Leviaadress (hostiosa = 255) | `192.168.0.255` |
| Hostide vahemik | `192.168.0.1` – `192.168.0.254` |
| Hostide arv | 254 |

## Kui piir jääb oktetti keskele

Keerulisemaks läheb siis, kui prefiksi pikkus ei ole 8 kordne. Siis teisendad asjaomase okteti kahendsüsteemi. Näide: `194.9.190.12/27`.

Esimesed kolm oktetti kuuluvad täielikult [[n|võrguosasse]] (24 bitti). Viimasest oktetist kuulub veel **3 bitti** võrguosasse (24 + 3 = 27), ülejäänud **5 bitti** [[h|hostiosasse]]:

| | viimane oktett (kahendsüsteemis) | kümnendsüsteemis |
|---|---|---|
| IP-aadress | [[n|000]][[h|01100]] | 12 |
| Võrgumask (`/27`) | [[n|111]][[h|00000]] | 224 |
| Võrguaadress: hostibitid 0-ks | [[n|000]][[h|00000]] | **0** |
| Leviaadress: hostibitid 1-ks | [[n|000]][[h|11111]] | **31** |

Tulemus:

- Võrguaadress: `194.9.190.0`
- Leviaadress: `194.9.190.31`
- Hostide vahemik: `194.9.190.1` – `194.9.190.30`
- Hostide arv: 2⁵ − 2 = **30**

:::tip Pea meeles
**Võrguaadress:** kõik hostibitid on 0 (madalaim aadress). **Leviaadress:** kõik hostibitid on 1 (kõrgeim aadress). Neid kahte ei anta seadmetele. Võrgul, mille prefiksi pikkus on *n*, on hostide jaoks **2<sup>32 − n</sup> − 2** kasutatavat aadressi.
:::

:::tip Näpunäide: ploki suurus
Kui oled kahendsüsteemis arvutamise selgeks saanud, on olemas otsetee: **256 miinus maski oktett** annab võrgu suuruse selles oktetis. `/27` korral (mask 224) on see 256 − 224 = **32**. Võrgud algavad siis numbritest 0, 32, 64, 96 … — aadress `.12` asub võrgus, mis algab aadressist `.0`, aadress `.70` võrgus, mis algab aadressist `.64`.
:::

## Olulisimad võrgusuurused

| Prefiks | Võrgumask | Hostid |
|---|---|---|
| `/8` | `255.0.0.0` | 16 777 214 |
| `/16` | `255.255.0.0` | 65 534 |
| `/24` | `255.255.255.0` | 254 |
| `/25` | `255.255.255.128` | 126 |
| `/26` | `255.255.255.192` | 62 |
| `/27` | `255.255.255.224` | 30 |
| `/28` | `255.255.255.240` | 14 |
| `/29` | `255.255.255.248` | 6 |
| `/30` | `255.255.255.252` | 2 |

:::note
Praktikas kasutatav väikseim võrk on `/30`: sellel on täpselt kaks kasutatavat aadressi ja seda kasutatakse meelsasti kahe ruuteri vaheliseks ühenduseks. `/32` tähistab üksikut aadressi — võrguna seda kasutada ei saa, kuid see esineb marsruutimistabelites ja tulemüürireeglites.
:::

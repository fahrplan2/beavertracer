# Projekt: firma nelja asukohaga

:::sim
url=/sims/lesson-4.5.4.btsim
:::

Firma peakorter asub **Hanaus** ning filiaalid asuvad **Kassel'is**, **Gießenis** ja **Darmstadtis**. Igal asukohal on oma võrk ja oma ruuter. Kõik ruuterid on rendiliinide kaudu ühendatud **keskse võrguga**, kus asub ka firma peaserver.

## Aadressiplaan

Administraator jagas aadressid välja järgmise skeemi järgi — need on simulatsioonis juba sisestatud:

| Võrk | Aadressivahemik |
|---|---|
| Keskne võrk | `10.19.0.0/24` |
| Hanau | `10.19.1.0/24` |
| Kassel | `10.19.2.0/24` |
| Gießen | `10.19.3.0/24` |
| Darmstadt | `10.19.4.0/24` |

| Seade | keskses võrgus | asukoha võrgus |
|---|---|---|
| Server | `10.19.0.10` | — |
| Router Hanau | `10.19.0.1` | `10.19.1.1` |
| Router Kassel | `10.19.0.2` | `10.19.2.1` |
| Router Gießen | `10.19.0.3` | `10.19.3.1` |
| Router Darmstadt | `10.19.0.4` | `10.19.4.1` |
| PC asukohas | — | igaühel `.2` (nt PC Kassel `10.19.2.2`) |

Kõigil ruuteritel osutab `eth0` keskse võrku ja `eth1` asukoha võrku.

## Sinu ülesanne

Selleks et kõik firma arvutid jõuaksid üksteiseni ja serverini, puudub veel kaks asja:

1. **Lüüsid:** Sisesta kõigile neljale arvutile ja serverile lüüs. Arvutid kasutavad oma asukoha ruuterit; server kasutab **ruuterit Hanau**.
2. **Marsruutimistabelid:** Lisa kõigile neljale ruuterile need marsruudid, mis veel puuduvad. Iga ruuter peab tundma **kolme teise** asukoha võrke.

Testi vahepeal käskudega `ping` ja `traceroute`.

<details>
<summary>Vihje: Milline marsruut siin välja näeb?</summary>

Näide **ruuteri Kassel** jaoks: Gießeni (`10.19.3.0/24`) pakettid lähevad ruuterile Gießen tema keskses võrgus — seega **Järgmine hüpe** `10.19.0.3`, **Iface** `eth0`. Selle eeskuju järgi vajab iga ruuter kolme marsruuti.
</details>

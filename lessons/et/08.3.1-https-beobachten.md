# HTTP ja HTTPS võrdlus

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Veebiserver **www.beaver-schule.de** pakub kooli hinnete portaali nii HTTP kui ka HTTPS kaudu. Mida näeb pealtkuulaja?

## Katse

1. Lülitu :fa-play: **Käivita**-režiimi (Käivitusrežiim) ja ava **Client-PC** :fa-globe: **Brauser**-is esmalt `http://www.beaver-schule.de/` ning seejärel `https://www.beaver-schule.de/`.
2. Ava :fa-magnifying-glass: **Jälgi**-režiimis jälg (trace) seadme **Client-PC** jaoks.
3. Otsi esmalt üles pakett `HTTP/1.1 200 OK` ja klõpsa sellel. All detailide alas leiad lehe sisu.

:::quiz mc
Mida saab pealtkuulaja **HTTP** puhul näha?
- [x] Kogu veebilehte, ka Anna hindeid
- [ ] Ainult serveri aadressi
- [ ] Mitte midagi, sest HTTP töötab TCP peal
:::

:::quiz short
Mis hinne on Annal matemaatikas?
= 2
:::

:::evaluate
Kontrolli vastuseid
:::

Nüüd HTTPS-i osa. Otsi üles `[SYN]`-pakett, millega klient alustab teist ühendust.

:::quiz short
Mis on HTTPS-ühenduse sihtport (veerg **Info**, `… → ???`)?
= 443
:::

Sisesta nüüd jälje ülemisse filtriväljale `tls` – siis näed ainult TLS-pakette.

:::quiz mc
Mis on veerus **Info** nende pakettide juures, mis sisaldavad veebilehte?
- [ ] `HTTP/1.1 200 OK`
- [x] `Application Data`
- [ ] `Encrypted HTML`
:::

:::quiz multi
Mida saab pealtkuulaja **HTTPS** puhul siiski veel näha?

- [x] Et kasutatakse porti 443, seega tõenäoliselt HTTPS-i
- [x] Ligikaudu kui palju andmeid edastatakse
- [ ] Millist lehte avati ja mis sellel on
:::

:::evaluate
Kontrolli vastuseid
:::

:::note
Klõpsa mõnel **Application Data**-paketil: andmeväli on vaid näiliselt juhuslike baitide jada. Tracer ei saa seda dekrüpteerida – tal ei ole seansivõtit sama vähe kui ründajalgi.
:::

:::tip Pea meeles
**HTTP** puhul saab iga pealtkuulaja lugeda kogu veebilehte. **HTTPS** puhul näeb ta enam vaid seda, **kes kellega** suhtleb (IP-aadressid, port 443) ja **kui palju** – sisu on krüpteeritult **Application Data**-pakettides.
:::

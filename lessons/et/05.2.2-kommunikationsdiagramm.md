# Järjestusdiagramm

:::sim
url=/sims/lesson-5.1.btsim
:::

Ühenduse kulgu joonistatakse **järjestusdiagrammina**: kliendile ja serverile antakse kummalegi üks püstjoon ning aeg kulgeb ülalt alla. Iga nool on üks pakett. Nool on joonistatud viltu, sest iga pakett on veidi aega teel.

Siin on sinu ühendus eelmiselt lehelt — võrdle seda rida realt jäljega:

:::seq
Client-PC -> Server: SYN
Server -> Client-PC: SYN, ACK
Client-PC -> Server: ACK
Client-PC -> Server: PSH, ACK "Hello World" len=13
Server -> Client-PC: ACK
Server -> Client-PC: PSH, ACK len=13
Client-PC -> Server: ACK
Client-PC -> Server: FIN, ACK
Server -> Client-PC: ACK
Server -> Client-PC: FIN, ACK
Client-PC -> Server: ACK
:::

Iga noole kohal on **lipud** (*flags*) ja all numbrid `SEQ` ja `ACK`. **DATA** tähistab pakette, milles on kasulikud andmed. Punased numbrid kuuluvad kliendile, sinised serverile — mida need tähendavad, selgitab järgmine leht.

## Lipud

| Lipp | tähendab | Tähendus |
|---|---|---|
| **SYN** | *synchronize* | luua ühendus, määrata algusnumber |
| **ACK** | *acknowledge* | kinnitab saadud andmed |
| **PSH** | *push* | anda andmed kohe programmile edasi |
| **FIN** | *finish* | „Ma olen valmis“ — ühendus lõpetada |
| **RST** | *reset* | ühendus katkestada või tagasi lükata (rohkem selle kohta peatükis 5.3.2) |

## Kolm faasi

**Loomine:** klient saadab `SYN`, server vastab `SYN, ACK`, klient kinnitab `ACK`-ga. Kuna vaja on täpselt kolme paketti, nimetatakse seda **kolmesammuliseks kätlemiseks** (*three-way handshake*).

**Andmed:** vastuvõtja kinnitab iga andmetega paketi `ACK`-ga. Siin saadab server kaja tagasi — ka seda kinnitab klient.

**Lõpetamine:** kumbki pool lõpetab oma saatmissuuna eraldi: `FIN` kliendilt, `ACK` serverilt — seejärel `FIN` serverilt, `ACK` kliendilt. Need on neli paketti.

:::tip Pea meeles
TCP-ühendus kulgeb kolmes faasis: **loomine** **kolmesammulise kätlemisega** (`SYN` → `SYN, ACK` → `ACK`), **andmeedastus** (iga andmepakett kinnitatakse `ACK`-ga) ja **lõpetamine** (kumbki pool saadab `FIN` ja saab `ACK` vastuseks).
:::

# Ühendus algusest lõpuni

:::sim
url=/sims/lesson-5.1.btsim
:::

**Serveris** töötab Echo-teenus pordil `5000`: iga sõnumi saadab see kohe tagasi. **Lihtsa TCP kliendiga** saad ühendust samm-sammult juhtida — iga nupp on üks etapp.

## Katse

1. Lülitu :fa-play: **Käivita**-režiimi (käivitusrežiimi), klõpsa **Client-PC** peal ja ava **Lihtne TCP klient**.
2. Sisesta väljale **Host** `192.168.0.20` ja väljale **Port** `5000`.
3. Klõpsa nuppu **Ühenda**.
4. Kirjuta sõnumiväljale `Hello World` ja klõpsa nuppu **Saada**. Vestlusaknas näed varsti pärast seda serveri kaja.
5. Klõpsa nuppu **Lahuta ühendus**.
6. Lülitu :fa-magnifying-glass: **Jälgi**-režiimi ja ava **+** abil **Client-PC** jaoks jälg, port `eth0`.

:::note
Kaht ARP-paketti alguses tead juba 1. peatükist. TCP-pakettide veerus **Info** on kõigepealt `49152 → 5000` (millisest pordist millisesse), seejärel nurksulgudes **lipud** ning pärast seda numbrid nagu `Seq=`, `Ack=` ja `Len=`. Numbritega tegeleme alates leheküljest 5.2.3 — siin pööra tähelepanu lippudele ja `Len` väärtusele.
:::

## 1. etapp: ühenduse loomine

:::quiz short
Mitu TCP-paketti vahetati pärast seda, kui klõpsasid nuppu **Ühenda** — enne kui sinu sõnum teele läks?
= 3
= kolm
:::

:::quiz mc
Kes saadab esimese paketi lipuga `[SYN]`?
- [x] Client-PC
- [ ] Server
:::

:::quiz mc
Milliste lippudega server sellele vastab?
- [ ] `[SYN]`
- [x] `[SYN, ACK]`
- [ ] `[ACK]`
- [ ] `[FIN, ACK]`
:::

## 2. etapp: saatmine

`Len` näitab, mitu baiti kasulikku andmemahtu pakett kannab.

:::quiz short
Mitu baiti kannab pakett sinu sõnumiga (`Len`)?
= 13
:::

:::note
`Hello World` on ainult 11 märki pikk. TCP klient lisab aga lõppu reavahetuse (2 baiti, `\r\n`) — nii ootavad seda paljud internetiprotokollid, näiteks SMTP või HTTP.
:::

:::quiz mc
Mida server saadab sinu sõnumi järel otsekohe tagasi — veel enne kaja?
- [x] Paketi lipuga `[ACK]` ja `Len=0` — kinnituse ilma andmeteta
- [ ] Mitte midagi
- [ ] Uue `[SYN]`-paketi
:::

## 3. etapp: ühenduse lahutamine

:::quiz short

= neli
:::

## Kus need neli ülesannet peituvad?

Seo kokku, kust leiad jälgimisest üles lõigu 5.1 ülesanded:

:::quiz match
Ühenduse loomine -> Kolm paketti [SYN], [SYN, ACK] ja [ACK]
Usaldusväärne edastus -> Paketid lipuga [ACK] ja Len=0, mis kinnitavad vastuvõttu
Ühenduse lõpetamine -> Paketid lipuga FIN ja nende kinnitused
Multipleksimine -> Pordinumbrid 49152 → 5000 enne nurksulge
:::

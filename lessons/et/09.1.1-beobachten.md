Selles simulatsioonis on keegi tulemüürile juba kolm reeglit lisanud. Klõpsa **tulemüürile** ja ava vaheleht **Reeglid**. Tulemüüri **Port A** on ühendatud internetiga ja **Port B** seadmega Schulrouter. „A → B“ tähendab seega „internetist kooli võrku“.

:::quiz table
| Reegel | Suund | Protokoll | Sihtport | Toiming |
|---|---|---|---|---|
| 1 | A → B | {TCP} | {22} | {Hülga} |
| 2 | A → B | TCP | {110} | {Lükka tagasi} |
| 3 | A → B | {ICMP} | suvaline | Hülga |
:::

## Ping väljastpoolt

Lülitu :fa-play: **Käivitusrežiimi** ja tee seadmest **Internet-PC** ping seadmele Schulserver:

```
$ ping -c 2 198.51.100.10
```

Ava seejärel tulemüüris vaheleht **Logi**.

- [ ] `Paket gefiltert`

:::

## Pordiskannimine: hüljatud või tagasi lükatud?

Skanni nüüd sihipäraselt viit porti. Port 3306 (andmebaas) ei ole seadmel Schulserver üldse kasutusel.

```
$ nmap -p 22,25,80,110,3306 198.51.100.10
```

:::quiz match
22 (hüljatud) -> filtered
25 (lubatud, teenus töötab) -> open
110 (tagasi lükatud) -> closed
3306 (lubatud, teenust pole) -> closed
:::

:::evaluate
Kontrolli vastavust
:::

:::quiz multi
Mida saab ründaja tulemusest järeldada?
- [x] Tulemuse `filtered` korral teab ta: seal on tulemüür, mis neelab pakette
- [x] Tulemuse `closed` korral ei oska ta eristada, kas tulemüür lükkab tagasi või lihtsalt ei tööta ühtegi teenust
- [ ] Tulemuse `filtered` korral teab ta, milline teenus pordi taga töötab
- [ ] Tulemuse `closed` korral on teenus siiski kättesaadav
:::

:::evaluate
Kontrolli vastuseid
:::

Vaata lõpuks reeglite loendis veergu **Tabamused**. Seal loendab tulemüür, mitu pakketti iga reegel on juba otsustanud. **Vaikepoliitika** kõrval olev väärtus loendab kõik paketid, millele ükski reegel ei sobinud.

:::tip Pea meeles
**Hüljatud** paketid kaovad jäljetult: `ping` teatab ajalõpust ja `nmap` teatab `filtered`. **Tagasi lükatud** pakettidele vastab tulemüür keeldumisega (TCP korral RST). Väljastpoolt näeb see välja nagu suletud port. Tulemüüri **logi** näitab, milliseid pakette tulemüür peatas, ja veerg **Tabamused** näitab, milline reegel rakendus.
:::

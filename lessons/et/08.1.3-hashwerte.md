# Räsid: andmete sõrmejälg

:::sim
url=/sims/lesson-8.1.3.btsim
:::

**Räsifunktsioon** arvutab suvaliselt suurest andmehulgast — lausest, dokumendist, tervest filmist — lühikese kindla pikkusega märgijada: **räsi** (**räsiväärtuse**). See toimib nagu **sõrmejälg**: samad andmed annavad alati sama räsiväärtuse, erinevad andmed teistsuguse.

Tänapäeval tavaliselt kasutatav räsifunktsioon on **SHA-256**. Selle räsiväärtus on alati 256 bitti pikk, kuueteistkümnendsüsteemi arvuna seega 64 märki.

## Katse

Arvutis **PC** on kaustas `/home` kolm faili väikese ostulepinguga. Lülitu :fa-play: **Käivitusrežiimi**, ava arvutis **PC** :fa-terminal: **Terminalis** ja sisesta:

```
$ cd /home
$ cat vertrag.txt vertrag-kopie.txt vertrag-neu.txt
$ sha256sum vertrag.txt vertrag-kopie.txt vertrag-neu.txt
```

## Räsifunktsiooni omadused

| Omadus | Tähendus |
|---|---|
| **kindel pikkus** | Olenemata andmete suurusest on räsiväärtus alati sama pikk. |
| **üheselt määratud** | Samad andmed annavad alati sama räsiväärtuse. |
| **laviinefekt** | Isegi väikseim muudatus annab täiesti teistsuguse räsiväärtuse. |
| **ühesuunaline funktsioon** | Räsiväärtusest **ei saa** andmeid tagasi arvutada. |
| **kollisioonikindel** | Praktiliselt on võimatu leida kahte erinevat faili, millel on sama räsiväärtus. |

Räsifunktsioon **ei ole krüpteerimine**: võtit ega dekrüpteerimist pole. See teenib hoopis teist eesmärki — **terviklikkust**.

## Milleks seda vaja on?

- **Allalaadimiste kontrollimine:** Paljud veebilehed annavad faili kõrval ka selle SHA-256 väärtuse. Kui sinu allalaaditud faili räsiväärtus sellega ühtib, ei ole faili teel muudetud.
- **Paroolide salvestamine:** Head veebilehed ei salvesta sinu parooli, vaid ainult selle räsiväärtuse. Sisselogimisel võrreldakse sinu sisestatud parooli räsiväärtust. Kui andmebaas varastatakse, ei tea varas paroole ikkagi.
- **Digiallkirjad:** Kogu dokumendi asemel allkirjastatakse ainult selle räsiväärtus — rohkem sellest järgmises peatükis.

:::tip Pea meeles
**Räsifunktsioon** (nt **SHA-256**) arvutab suvalistest andmetest kindla pikkusega **räsiväärtuse** — **sõrmejälje**. Isegi väikseim muudatus annab täiesti teistsuguse räsiväärtuse ning räsiväärtusest ei saa andmeid tagasi arvutada. Räsiväärtused tagavad andmete **terviklikkuse**.
:::

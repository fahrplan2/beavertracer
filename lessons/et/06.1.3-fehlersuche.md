# Veaotsing: kontaktileht puudub

:::sim
url=/sims/lesson-6.1.3.btsim
:::

Sekretariaat teatab: „Meie veebilehel viib link **Kontakt** nüüd ainult veateateni.“ Kontaktileht peaks olema kättesaadav aadressil `http://192.168.0.20/kontakt.html`. Leia viga ja paranda see.

<details>
<summary>Vihje 1: Mida server teatab?</summary>

Ava kontaktileht brauseris või käsuga `curl -v`. Milline olekukood tagasi tuleb? Veateade näitab ka, kust server faili otsis.
</details>

<details>
<summary>Vihje 2: Kus failid asuvad?</summary>

Veebiserver annab kätte ainult faile oma **dokumentide juurkaustast** (*Document Root*) — see on näha rakenduses **HTTP-server**. Vaata **Serveris** terminalis käsuga `ls`, mis seal asub, ja otsi kontaktilehte ka kaustast `/home`.
</details>

<details>
<summary>Vihje 3: Faili teisaldamine</summary>

Käsuga `mv` teisaldad faili: `mv <allikas> <sihtkaust>`.
</details>

:::task
title: Kontaktileht parandatud?
Kontrollib, kas kontaktileht asub veebiserveri dokumentide juurkaustas.
check: fileExists(2, "/var/www/kontakt.html")
:::

## Mis juhtus?

:::quiz multi
Millised väited on õiged?
- [x] Server vastas olekukoodiga `404 Not Found`
- [x] Fail asus kaustas `/home`, mitte dokumentide juurkaustas `/var/www`
- [ ] Veebiserver polnud üldse käivitatud
- [ ] Brauser kasutas valet IP-aadressi
:::

:::evaluate
Kontrolli vastust
:::

:::tip Pea meeles
**404** tähendab: veebiserver töötab ja on kättesaadav, kuid soovitud **faili** selle tee all ei ole. Server otsib ainult oma **dokumentide juurkaustast** (*Document Root*, siin `/var/www`). Võrdle: kui server ei vasta üldse või vastab `RST`-ga, on probleem sügavamal — **võrgus** või teenuses endas (peatükk 5.3.2).
:::

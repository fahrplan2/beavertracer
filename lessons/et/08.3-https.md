# HTTPS

:::osi 5
:::

**HTTPS** (*HTTP Secure*) on täiesti tavaline HTTP — ainult et see ei tööta otse TCP peal, vaid läbi vahepealse krüptitud kihi: **TLS** (*Transport Layer Security*). TLS-i eelkäija nimi oli **SSL**; seepärast räägitakse sageli ikka veel „SSL-sertifikaatidest“.

```
ohne Verschlüsselung:   HTTP  →  TCP  →  IP
mit Verschlüsselung:    HTTP  →  TLS  →  TCP  →  IP
```

HTTP ei märka sellest midagi: ta saadab oma päringud nagu tavaliselt, TLS krüpteerib need, TCP transpordib need. OSI mudelis asub TLS transpordikihi ja rakenduskihi vahel, ehk kihis 4/5 — see tugineb TCP-le ja haldab turvatud seanssi.

| | HTTP | HTTPS |
|---|---|---|
| Port | 80 | **443** |
| Aadress | `http://…` | `https://…` |
| Sisu loetav jälgijas? | jah | ei |
| Brauser näitab | „pole turvaline“ | lukku |

TLS teeb ühenduse loomisel ära kõik, mida sa selles peatükis õppisid:

- Server tõendab end oma **sertifikaadiga** (**autentsus**).
- Mõlemad pooled lepivad **Diffie-Hellmani** abil kokku **seansivõtmes** — server **allkirjastab** oma osa.
- Pärast seda krüpteeritakse kõik andmed **AES**-iga (**konfidentsiaalsus**) ja kaitstakse muutmise eest (**terviklus**).

See põhimõte ei piirdu veebiga: ka e-post (jaotis 8.4) ja paljud teised protokollid töötavad samal viisil läbi TLS-i.

Järgmistes jaotistes jälgid sa HTTPS-i jälgijas, seadistad selle ise ja uurid, millal brauser hoiatab — ja miks.

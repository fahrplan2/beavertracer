# Staatiliste marsruutide lisamine

:::sim
url=/sims/lesson-4.5.2.btsim
:::

Seekord asub ettevõtte A ja ettevõtte B vahel **kaks** ruuterit. Need on omavahel ühendatud oma väikese võrgu kaudu, **vahevõrgu** `10.0.0.0/30` kaudu:

| Ruuter | Liides | IP-aadress | Võrk |
|---|---|---|---|
| Router A | `eth0` | `192.168.0.1/24` | Firma A (Anna) |
| Router A | `eth1` | `10.0.0.1/30` | Zwischennetz |
| Router B | `eth0` | `10.0.0.2/30` | Zwischennetz |
| Router B | `eth1` | `172.16.0.1/24` | Firma B (Clara) |

:::note
`/30`-võrgus on täpselt kaks kasutatavat aadressi — see sobib suurepäraselt kahe ruuteri ühendamiseks (vt jaotis 4.2.3).
:::

## Probleem

Lülitu :fa-play: **Käivita**-režiimi ja tee **Annast** Clarale ping (`ping 172.16.0.10`). Clara ei vasta — selle asemel teatab Router A (`192.168.0.1`): „Zielnetz nicht erreichbar“.

Vaata **Router A** **Marsruutimistabel IPv4** tabelit.

:::quiz mc
Miks Anna ping Clarani ei jõua?
- [ ] Annal pole lüüsi sisestatud
- [x] Router A ei tunne võrku `172.16.0.0/24` — see ei ole temaga otse ühendatud ja sinna ei ole marsruuti
- [ ] Vahevõrk on liiga väike
:::

:::evaluate
Kontrolli vastust
:::

## Marsruudi lisamine

Router A peab õppima: paketid võrku `172.16.0.0/24` lähevad Router B-le (`10.0.0.2`), ja seda läbi liidese `eth1`.

1. Ava **Router A** juures vaheleht **Marsruutimistabel IPv4** ja klõpsa nupul **+ hinzufügen**.
2. Sisesta uude ritta: **Ziel** `172.16.0.0`, **Netzmaske** `255.255.255.0`, **Järgmine hüpe** `10.0.0.2`, **Iface** `eth1`.
3. Salvesta rida linnukesega :fa-check:. Veerus **Quelle** on nüüd **Staatiline**.

Tee Clarale uuesti ping — nüüd tuleb vastus.

:::note
Router B teab tee tagasi ettevõtte A juurde muide juba: tema marsruutimistabelis on juba staatiline marsruut võrku `192.168.0.0/24` läbi `10.0.0.1`. Miks see tagasitee on sama oluline, näed järgmisel lehel.
:::

## Tee jälgimine: traceroute

Käsuga `traceroute` saad kuvada, milliste ruuterite kaudu pakett liigub. Sisesta **Annal**:

```
$ traceroute 172.16.0.10
```

:::quiz short
Mitme ruuteri kaudu liigub pakett Annalt Clarale?
= 2
= kaks
:::

:::quiz mc
Millise aadressi näitab `traceroute` Router B jaoks?
- [x] `10.0.0.2` — tema aadress vahevõrgus, mille kaudu pakett sisse tuleb
- [ ] `172.16.0.1` — tema aadress ettevõttes B
- [ ] `192.168.0.1`
:::

:::evaluate
Kontrolli vastuseid
:::

`traceroute` kasutab ära nippi, mis põhineb jaotises 4.3.1 käsitletud **elueal (Time to Live)**: kõigepealt saadab see paketi TTL-iga 1. Esimene ruuter lahutab 1, saab tulemuseks 0, hülgab paketi ja teatab sellest saatjale — nii tunneb Anna ära esimese ruuteri. Seejärel TTL 2 teise ruuteri jaoks ja nii edasi, kuni sihtkoht vastab.

:::tip Pea meeles
**Staatilise marsruudi** lisab administraator käsitsi: sihtvõrk, võrgumask, järgmine hüpe ja liides. **traceroute**'iga saab paketi teed jälgida ruuter ruuteri haaval.
:::

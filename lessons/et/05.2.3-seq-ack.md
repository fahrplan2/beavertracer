# Järjenumbrid ja kinnitusnumbrid

:::sim
url=/sims/lesson-5.1.btsim
:::

Kuidas TCP teab, kas kõik on kohale jõudnud — ja mis järjekorras? Kumbki pool **nummerdab baidid**, mida ta saadab:

- **Järjenumber** (`SEQ`) on selle paketi esimese baidi number.
- **Kinnitusnumber** (`ACK`) ütleb: „Olen siiani kõik kätte saanud — järgmisena ootan baiti nr …“

Lisaks kaks reeglit: `SYN` ja `FIN` loetakse üheks baidiks, kuigi nad andmeid ei kanna. Ja kumbki pool loendab ise — seepärast on kaks numbrivahemikku, diagrammil punane (klient) ja sinine (server).

## Järelarvutamine

Siin on sinu ühendus veel kord. Joonte juures olevad arvud näitavad arvuti loendurit just selles kohas:

:::seq
Client-PC -> Server: SYN
Server -> Client-PC: SYN, ACK
Client-PC -> Server: ACK
Client-PC -> Server: PSH, ACK "Hello World" len=13
Server -> Client-PC: ACK
Server -> Client-PC: PSH, ACK len=13
Client-PC -> Server: ACK
Client-PC -> Server: FIN, ACK
Server -> Client-PC: ACK
Server -> Client-PC: FIN, ACK
Client-PC -> Server: ACK
:::

Käi punane arvurida läbi:

1. Klient alustab väärtusest `SEQ=0`. Tema `SYN` kulutab ühe numbri — server kinnitab väärtusega `ACK=1`.
2. Sõnum algab väärtusest `SEQ=1` ja on 13 baiti pikk (baidid 1 kuni 13). Server kinnitab väärtusega `ACK=14`: „Järgmisena ootan baiti 14.“
3. Kliendi `FIN` on seetõttu `SEQ=14` ja see kinnitatakse väärtusega `ACK=15`.

Serveri sinine rida töötab täpselt samamoodi.

:::tip Pea meeles
**Järjenumber** (`SEQ`) on paketi esimese baidi number. **Kinnitusnumber** (`ACK`) on järgmise baidi number, mida vastuvõtja ootab — kõik sellele eelnev on kohale jõudnud. Kehtib: **ACK = SEQ + vastuvõetud andmete pikkus**; `SYN` ja `FIN` loetakse üheks baidiks. Kumbki pool loendab oma baite.
:::

:::tip Proovi järele
Loo ühendus **Lihtne TCP klient** abil uuesti ja saada kaks sõnumit järjest. Ütle enne ette, millised `Seq` ja `Ack` tulevad veergu **Info** — ja kontrolli seda jälituses järele.
:::

:::note
Päris võrkudes ei algä loendus nullist: kumbki pool valib **juhusliku algusnumbri** (*Initial Sequence Number*, ISN) vahemikus 0 kuni umbes 4,3 miljardit. Kui kõrgeim number on käes, jätkub loendus uuesti nullist. Jälitaja lahutab algusnumbri maha ja näitab **suhtelisi** numbreid — täpselt nagu Wireshark. Seepärast näed `Seq=0` ja `Seq=1`.

Peale selle on igas paketis `Win=` — **akna suurus**: nii palju baite suudab vastuvõtja parajasti vastu võtta. Sellega pidurdab ta liiga kiiret saatjat (*vookontroll*). BeaverTraceris on aken alati ühesuurune.
:::

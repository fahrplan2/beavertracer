# Zgoščene vrednosti: prstni odtis podatkov

:::sim
url=/sims/lesson-8.1.3.btsim
:::

**Zgoščevalna funkcija** iz poljubne količine podatkov — stavka, dokumenta, celega filma — izračuna kratko zaporedje znakov s fiksno dolžino: **zgoščeno vrednost**. Deluje kot **prstni odtis**: enaki podatki vedno dajo isto zgoščeno vrednost, drugačni podatki pa drugačno.

Danes običajna zgoščevalna funkcija se imenuje **SHA-256**. Njena zgoščena vrednost je vedno dolga 256 bitov, kar je kot šestnajstiško število 64 znakov.

## Eksperiment

Na **PC**-ju so v mapi `/home` tri datoteke z majhno kupoprodajno pogodbo. Preklopi v :fa-play: način izvajanja, na **PC**-ju odpri :fa-terminal: **Terminal** in vnesi:

```
$ cd /home
$ cat vertrag.txt vertrag-kopie.txt vertrag-neu.txt
$ sha256sum vertrag.txt vertrag-kopie.txt vertrag-neu.txt
```

## Lastnosti zgoščevalne funkcije

| Lastnost | Pomen |
|---|---|
| **fiksna dolžina** | Ne glede na velikost podatkov ima zgoščena vrednost vedno enako dolžino. |
| **enoličnost** | Enaki podatki vedno dajo isto zgoščeno vrednost. |
| **plazovni učinek** | Že najmanjša sprememba da povsem drugačno zgoščeno vrednost. |
| **enosmerna funkcija** | Iz zgoščene vrednosti podatkov **ni** mogoče izračunati nazaj. |
| **odpornost proti trkom** | Praktično je nemogoče najti dve različni datoteki z isto zgoščeno vrednostjo. |

Zgoščevalna funkcija **ni šifriranje**: ni ključa in ni dešifriranja. Služi drugemu namenu — **celovitosti**.

## Za kaj to potrebujemo?

- **Preverjanje prenosov:** Številne spletne strani poleg datoteke navedejo tudi njeno vrednost SHA-256. Če se zgoščena vrednost tvoje prenesene datoteke ujema z njo, se datoteka med prenosom ni spremenila.
- **Shranjevanje gesel:** Dobre spletne strani ne shranjujejo tvojega gesla, ampak le njegovo zgoščeno vrednost. Pri prijavi se primerja zgoščena vrednost tvojega vnosa. Če je zbirka podatkov ukradena, tat gesel kljub temu ne pozna.
- **Digitalni podpisi:** Namesto celotnega dokumenta se podpiše le njegova zgoščena vrednost — več o tem v naslednjem razdelku.

:::tip Zapomni si
**Zgoščevalna funkcija** (npr. **SHA-256**) iz poljubnih podatkov izračuna **zgoščeno vrednost** fiksne dolžine — **prstni odtis**. Že najmanjša sprememba da povsem drugačno zgoščeno vrednost, iz zgoščene vrednosti pa podatkov ni mogoče izračunati nazaj. Zgoščene vrednosti zagotavljajo **celovitost** podatkov.
:::

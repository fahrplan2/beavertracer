# DNS: imena namesto številk

:::goal
**Učni cilj:** Znaš razložiti, kako DNS prevaja imena v naslove IP, kako so imena hierarhično organizirana, sam ustvariti vnos in poiskati tipične napake DNS.
:::

:::sim
url=/sims/lesson-6.2.btsim
:::

Naslovov IP si skoraj nihče ne zapomni, imen, kot je `www.beaver-schule.de`, pa si. Prevajanje opravlja **Domain Name System** (**DNS**), nekakšen svetovni telefonski imenik interneta.

Na delovni površini je zdaj nekoliko večje omrežje: poleg **Client-PC** in **Webserver** so tu še štirje **strežniki DNS**. Čemu jih je toliko, boš videl na strani po naslednji.

# Primerjava HTTP in HTTPS

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Spletni strežnik **www.beaver-schule.de** ponuja šolski portal z ocenami prek protokola HTTP in tudi prek HTTPS. Kaj vidi prisluškovalec?

## Poskus

1. Preklopi v :fa-play: način izvajanja in na **Client-PC** v :fa-globe: **Brskalnik** najprej odpri `http://www.beaver-schule.de/`, nato še `https://www.beaver-schule.de/`.
2. V načinu :fa-magnifying-glass: **Sled** odpri sled za **Client-PC**.
3. Najprej poišči paket `HTTP/1.1 200 OK` in ga klikni. Spodaj v podrobnostih najdeš vsebino strani.

:::quiz mc
Kaj lahko prisluškovalec vidi pri **HTTP**?
- [x] Celotno spletno stran, tudi Annine ocene
- [ ] Samo naslov strežnika
- [ ] Nič, ker HTTP deluje prek TCP
:::

:::quiz short
Kakšno oceno ima Anna pri matematiki?
= 2
:::

:::evaluate
Preveri odgovore
:::

Zdaj pa del s HTTPS. Poišči paket `[SYN]`, s katerim odjemalec začne drugo povezavo.

:::quiz short
Kateri ciljni port ima povezava HTTPS (stolpec **Info**, `… → ???`)?
= 443
:::

Zdaj zgoraj v polje za filtriranje v sledi vpiši `tls` — tako boš videl samo še pakete TLS.

:::quiz mc
Kaj piše v stolpcu **Info** pri paketih, ki vsebujejo spletno stran?
- [ ] `HTTP/1.1 200 OK`
- [x] `Application Data`
- [ ] `Encrypted HTML`
:::

:::quiz multi
Kaj lahko prisluškovalec pri **HTTPS** kljub temu še vedno vidi?
- [x] IP-naslova odjemalca in strežnika
- [x] Da se uporablja port 443, torej verjetno HTTPS
- [x] Približno koliko podatkov se prenese
- [ ] Katera stran je bila odprta in kaj je na njej
:::

:::evaluate
Preveri odgovore
:::

:::note
Klikni paket **Application Data**: koristni podatki so samo zaporedje navidezno naključnih bajtov. Tracer jih ne more dešifrirati — seančnega ključa ne pozna nič bolj kot napadalec.
:::

:::tip Zapomni si
Pri **HTTP** lahko vsak prisluškovalec prebere celotno spletno stran. Pri **HTTPS** vidi samo še to, **kdo s kom** komunicira (naslova IP, port 443) in **koliko** podatkov se prenese — vsebina je šifrirana v paketih **Application Data**.
:::

# HTTP na roke

:::sim

Če je HTTP navadno besedilo — ali se potem lahko tudi sam pogovarjaš s spletnim strežnikom, povsem brez brskalnika? Da: s programom `telnet` vzpostaviš povezavo TCP na poljubna vrata in besedilo natipkaš sam.

## Poskus

1. Preklopi v način izvajanja :fa-play: **Zagon** in na računalniku **Client-PC** odpri :fa-terminal: **Terminal**.
2. Poveži se z vrati 80 strežnika:
   ```
   $ telnet 192.168.0.20 80
   ```
3. Natipkaj zahtevo vrstico za vrstico — in jo zaključi s **prazno vrstico** (preprosto še enkrat pritisni **Enter**):
   ```
   GET /kontakt.html HTTP/1.1
   Host: 192.168.0.20

   ```

Strežnik odgovori s statusno vrstico, glavami in stranjo s kontaktom — kot besedilo, tako kot ga prejme tudi brskalnik.

:::quiz mc
Po čem strežnik prepozna, da je tvoja zahteva končana?
- [ ] Po posebnem ukazu `END`
- [x] Po prazni vrstici
- [ ] Po določenem času
:::

:::quiz short
Katera vrednost je v odgovoru pri glavi `Content-Type`? (samo prvi del pred `;`)
= text/html
:::

## Namerno povzročanje napak

Udobnejše orodje je `curl`: zahtevo pripravi namesto tebe. Z `-v` (*verbose*, podrobno) pokaže vse, kar potuje sem ter tja — vrstice z `>` je poslal `curl`, vrstice z `<` pa so prišle s strežnika.

Preizkusi:

```
$ curl -v http://192.168.0.20/gibtsnicht.html
$ curl -X POST -d name=Anna http://192.168.0.20/
```

:::quiz short
Katero statusno kodo dobiš za `/gibtsnicht.html`?
= 404
:::

:::quiz short
In katero za zahtevo z metodo `POST`?
= 405
:::

:::evaluate
Preveri odgovore
:::

:::note
Spletni strežnik v BeaverTracer lahko izroča samo datoteke — zato dovoljuje le `GET` in `HEAD`. Pravi spletni strežniki z `POST` sprejemajo na primer obrazce in podatke posredujejo programu.
:::

:::tip Zapomni si
Številni protokoli aplikacijske plasti so **besedilni** — HTTP, pa tudi SMTP, POP3 in IMAP. Zato se lahko z njimi pogovarjaš na roke prek `telnet` in jih bereš v sledilniku. To je priročno pri iskanju napak — hkrati pa varnostna težava: vsak, ki promet prestreza, lahko prebere vse. Kako pomaga šifriranje (HTTPS), se boš naučil v 8. poglavju.
:::

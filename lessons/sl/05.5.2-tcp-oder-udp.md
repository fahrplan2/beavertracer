# TCP ali UDP?

| | TCP | UDP |
|---|---|---|
| Povezava | vzpostavitev s tristopenjskim rokovanjem, urejena prekinitev | je ni — vsak datagram stoji zase |
| Potrditve | da (`ACK`) | ne |
| Izgubljeni podatki | se pošljejo ponovno | ostanejo izgubljeni |
| Vrstni red | se obnovi | ni zagotovljen |
| Glava | vsaj 20 bajtov | 8 bajtov |
| Hitrost | nekoliko počasnejši, več paketov | hiter, malo režije |

Kdaj je manj več?

- **Realni čas:** Pri videotelefoniji, internetni telefoniji ali spletnih igrah šteje vsaka milisekunda. Izgubljen košček zvoka, ki ga prejmeš sekundo pozneje, ni več nikomur v korist — raje kratko zahreščanje kot zakasnitev.
- **Kratke zahteve:** Zahteva **DNS** (»Kateri naslov IP ima `www.beispiel.de`?«) se prilega v en sam datagram, odgovor prav tako. Vzpostavitev povezave bi trojno povečala porabo. Če odgovora ni, program preprosto vpraša še enkrat.

Povsod, kjer mora prispeti vsak bajt — spletne strani, e-pošta, prenosi —, pa je prava izbira TCP.

:::tip Zapomni si
**TCP** je zanesljiv, a zahtevnejši — za vse, kar mora prispeti **v celoti** (splet, e-pošta, datoteke). **UDP** je hiter in vitek, a brez jamstev — za **realni čas** (telefonija, video, igre) in **kratke zahteve**, kot je DNS.
:::

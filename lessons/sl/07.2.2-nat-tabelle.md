# Tabela NAT

:::sim
url=/sims/lesson-7.1.btsim
:::

Ko PC in tablični računalnik hkrati naložita isto spletno stran, obe zahtevi prispeta do spletnega strežnika z naslova `203.0.113.2`. Kako domači usmerjevalnik ve, komu je odgovor namenjen? Vodi evidenco — v **tabeli NAT**.

## Poskus

1. Preklopi v :fa-play: način izvajanja in na **PC-ju** ter na **tablici** odpri `http://www.beispiel.de/`.
2. Klikni na **Heimrouter** in odpri zavihek **NAT**.

Vsaka vrstica je **preslikava**: protokol, naslov IP LAN in vrata LAN naprave v domačem omrežju — ter **vrata WAN**, ki jih usmerjevalnik za to uporablja na svojem javnem naslovu.

:::quiz short
Kateri naslov IP WAN je naveden nad tabelo?
= 203.0.113.2
:::

:::quiz mc
PC in tablični računalnik sta oba vzpostavila povezavo z vrati LAN `49152`. Katera vrata WAN dobita?
- [ ] Oba ista, `49152`
- [x] Vsak drugačna — sicer usmerjevalnik ne bi vedel, komu pripada odgovor
- [ ] Nobenih, NAT spremeni samo naslov IP
:::

:::quiz mc
Odgovor spletnega strežnika prispe na `203.0.113.2` z določenimi **ciljnimi vrati**. Kaj z njim naredi domači usmerjevalnik?
- [x] Poišče vrata v tabeli NAT in pošlje paket na pripadajoči naslov IP LAN in vrata LAN
- [ ] Pošlje paket vsem napravam v domačem omrežju
- [ ] Paket zavrže
:::

:::evaluate
Preveri odgovore
:::

Tu se ponovno pojavijo **vrata** iz 5. poglavja: ker NAT prepisuje tudi vrata, si lahko na stotine povezav deli en naslov. Natančneje se temu zato reče **PAT** (*Port Address Translation*) ali *NAT s prevajanjem vrat* — v vsakdanjem govoru pa vseeno rečemo kar NAT.

Takšna preslikava bi lahko na primer izgledala tako:

| | Paket iz PC-ja (v domačem omrežju) | isti paket v internetu |
|---|---|---|
| Pošiljatelj | `192.168.178.20 : 49152` | `203.0.113.2 : 10001` |
| Prejemnik | `192.0.2.80 : 80` | `192.0.2.80 : 80` |

:::tip Zapomni si
V **tabeli NAT** si usmerjevalnik za vsako povezavo zapomni, katera naprava (**naslov IP LAN in vrata LAN**) se skriva za katerimi **vrati WAN**. Odgovore iz interneta nato prek ciljnih vrat spet dodeli pravi napravi. Ker se prepisujejo tudi vrata, natančneje govorimo o **PAT**.
:::

# Uporaba modelov

Protokole iz eksperimenta z začetka poglavja razvrsti v ustrezno plast OSI:

:::quiz match
Ethernet -> Plast 2 — povezavna
IPv4 -> Plast 3 — omrežna
TCP -> Plast 4 — prenosna
HTTP -> Plast 7 — aplikacijska
:::

:::evaluate
Preveri razvrstitev
:::

Za konec še imena podatkovnih enot:

:::quiz match
Frame -> Plast 2 — povezavna
Paket -> Plast 3 — omrežna
Segment -> Plast 4 — prenosna
:::

:::evaluate
Preveri razvrstitev
:::

Zdaj imaš potrebno orodje, da protokole v prihodnje pravilno razvrstiš. Od naslednjega poglavja naprej bomo plasti obravnavali po vrsti — začenši s plastjo 2 in vprašanjem, kako stikalo pravzaprav ve, kam mora posredovati paket.

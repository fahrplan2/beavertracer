# HTTPS

:::osi 5
:::

**HTTPS** (*HTTP Secure*) je povsem običajen HTTP — le da ne poteka neposredno prek TCP, temveč skozi vmesno šifrirano plast: **TLS** (*Transport Layer Security*). Predhodnik TLS se je imenoval **SSL**; zato se še vedno pogosto govori o »SSL-potrdilih«.

```
ohne Verschlüsselung:   HTTP  →  TCP  →  IP
mit Verschlüsselung:    HTTP  →  TLS  →  TCP  →  IP
```

HTTP od tega ne opazi ničesar: zahteve pošilja kot običajno, TLS jih šifrira, TCP jih prenaša. V modelu OSI se TLS nahaja med prenosno in aplikacijsko plastjo, torej v plasti 4/5 — nadgrajuje TCP in upravlja zavarovano sejo.

| | HTTP | HTTPS |
|---|---|---|
| Vrata | 80 | **443** |
| Naslov | `http://…` | `https://…` |
| Vsebina berljiva v Tracerju? | da | ne |
| Brskalnik prikaže | »ni varno« | ključavnico |

TLS ob vzpostavitvi povezave opravi vse, kar si spoznal v tem poglavju:

- Strežnik se izkaže s svojim **digitalnim potrdilom** (**pristnost**).
- Obe strani se z algoritmom **Diffie-Hellman** dogovorita za **sejni ključ** — strežnik svoj delež **podpiše**.
- Nato se vsi podatki šifrirajo z **AES** (**zaupnost**) in zaščitijo pred spremembami (**celovitost**).

Načelo ni omejeno na splet: tudi e-pošta (razdelek 8.4) in številni drugi protokoli potekajo skozi TLS na enak način.

V naslednjih razdelkih boš HTTPS opazoval v Tracerju, ga sam nastavil in raziskal, kdaj brskalnik opozori — in zakaj.

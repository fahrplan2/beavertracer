## Ping od zunaj

Preklopi v :fa-play: način izvajanja **Zagon** in s **Internet-PC** pošlji ping šolskemu strežniku:

```
$ ping -c 2 198.51.100.10
```

Nato v požarnem zidu odpri zavihek **Protokoll**.

## Skeniranje vrat: zavrženo ali zavrnjeno?

Zdaj ciljno preglej pet vrat. Vrata 3306 (podatkovna zbirka) na šolskem strežniku sploh niso v uporabi.

```
$ nmap -p 22,25,80,110,3306 198.51.100.10
```

:::quiz match
22 (zavržena) -> filtered
25 (dovoljena, storitev teče) -> open
110 (zavrnjena) -> closed
3306 (dovoljena, brez storitve) -> closed
:::

:::evaluate
Preveri razvrstitev
:::

:::quiz multi
Kaj lahko napadalec sklepa iz rezultata?
- [x] Pri `filtered` ve: tam je požarni zid, ki pakete pogoltne
- [x] Pri `closed` ne more ločiti, ali požarni zid zavrača ali preprosto ne teče nobena storitev
- [ ] Pri `filtered` ve, katera storitev teče za temi vrati
- [ ] Pri `closed` je storitev kljub temu dosegljiva
:::

:::evaluate
Preveri odgovore
:::

Na koncu poglej še stolpec **Treffer** v seznamu pravil: tam požarni zid šteje, koliko paketov je že obravnavalo posamezno pravilo. Vrednost ob **Standardrichtlinie** šteje vse pakete, za katere ni ustrezalo nobeno pravilo.

:::tip Zapomni si
**Zavrženi** paketi izginejo brez sledu: `ping` sporoči časovno omejitev, `nmap` sporoči `filtered`. **Zavrnjene** pakete požarni zid odgovori z zavrnitvijo (pri TCP z RST) — od zunaj to izgleda kot zaprta vrata. **Protokol** požarnega zidu pokaže, katere pakete je ustavil, stolpec **Treffer** pa, katero pravilo je zaleglo.
:::

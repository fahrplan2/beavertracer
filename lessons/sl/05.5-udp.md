# UDP: močna poenostavitev

:::goal
**Učni cilj:** UDP znaš primerjati s TCP in utemeljiti, za katere aplikacije je UDP boljša izbira.
:::

:::sim
url=/sims/lesson-5.5.btsim
:::

TCP naredi veliko — vzpostavitev povezave, potrditve, ponovni prenos, vrstni red. To pa stane čas in dodatne pakete. Drugi pomembni protokol prenosne plasti se skoraj vsega tega odpove: **User Datagram Protocol** (**UDP**). Njegovi paketi se imenujejo **datagrami**.

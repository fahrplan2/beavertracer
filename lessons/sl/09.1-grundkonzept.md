# Paketni filter: pravila

Najpreprostejša in najpomembnejša vrsta požarnega zidu je **paketni filter**. Pregleda vsak paket, ki gre skozenj, in na podlagi **seznama pravil** odloči, ali ga spusti naprej. Pri tem bere samo glave plasti 3 in 4 — vsebine (npr. spletne strani) ne gleda.

## Iz česa je sestavljeno pravilo

| Polje | Pomen | Primer |
|---|---|---|
| **Smer** | S katere strani prihaja paket? | A → B (iz interneta v šolsko omrežje) |
| **Protokol** | TCP, UDP, ICMP ali poljuben | TCP |
| **Izvorni IP** | naslov ali omrežje pošiljatelja | poljuben |
| **Izvorna vrata** | vrata pošiljatelja | poljubna |
| **Ciljni IP** | naslov ali omrežje prejemnika | `198.51.100.10` |
| **Ciljna vrata** | vrata prejemnika, torej storitev | `80` |
| **Dejanje** | Kaj se zgodi z ujemajočimi se paketi? | Dovoli |

Prazno polje pomeni »poljubno«. Omrežja se zapisujejo v zapisu CIDR, na primer `198.51.100.0/24`, razponi vrat pa s pomišljajem, na primer `1024-65535`.

## Vrstni red je odločilen

Požarni zid preverja pravila **od zgoraj navzdol**. Odloča **prvo pravilo, ki se ujema** — vsa naslednja se za ta paket ne pregledujejo več. Če se ne ujema nobeno pravilo, velja **privzeta politika** (*Default Policy*).

## Tri možna dejanja

| Dejanje | Kaj naredi požarni zid | Kaj opazi pošiljatelj |
|---|---|---|
| **Dovoli** (*Allow*) | Paket se posreduje naprej | — |
| **Zavrzi** (*Drop*) | Paket se brez komentarja zavrže | sploh nič — čaka, dokler ne poteče časovna omejitev |
| **Zavrni** (*Reject*) | Paket se zavrže, pošiljatelj pa dobi zavrnitev: pri TCP **RST**, sicer ICMP »nedosegljivo« | takoj sporočilo o napaki |

Kaj je boljše? **Zavrzi** napadalcu izda manj in ga stane čas, ker mora pri vsakem poskusu čakati. **Zavrni** je prijaznejše do lastnih uporabnikov: program takoj dobi sporočilo o napaki, namesto da dolgo visi. V praksi se zato pakete od zunaj običajno zavrže, pakete iz lastnega omrežja pa zavrne.

:::quiz match
Dovoli -> Paket se posreduje naprej
Zavrzi -> Paket izgine, pošiljatelj zaman čaka na odgovor
Zavrni -> Paket se ne posreduje naprej, pošiljatelj pa takoj dobi zavrnitev
Privzeta politika -> Velja, če se ne ujema nobeno pravilo
:::

:::tip Zapomni si
**Paketni filter** preveri vsak paket glede na smer, protokol, naslove in vrata z **seznamom pravil**. O dejanju odloča **prvo ujemajoče se pravilo**: **Dovoli**, **Zavrzi** (tiho) ali **Zavrni** (z zavrnitvijo). Če se ne ujema nobeno pravilo, velja **privzeta politika**.
:::

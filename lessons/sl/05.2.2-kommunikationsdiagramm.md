# Komunikacijski diagram

:::sim
url=/sims/lesson-5.1.btsim
:::

Potek povezave narišemo kot **komunikacijski diagram**: odjemalec in strežnik dobita vsak svojo navpično črto, čas teče od zgoraj navzdol. Vsaka puščica je en paket. Narisana je poševno, ker je vsak paket nekaj časa na poti.

Tako izgleda tvoja povezava s prejšnje strani — primerjaj jo vrstico za vrstico s sledjo:

:::seq
Client-PC -> Server: SYN
Server -> Client-PC: SYN, ACK
Client-PC -> Server: ACK
Client-PC -> Server: PSH, ACK "Hello World" len=13
Server -> Client-PC: ACK
Server -> Client-PC: PSH, ACK len=13
Client-PC -> Server: ACK
Client-PC -> Server: FIN, ACK
Server -> Client-PC: ACK
Server -> Client-PC: FIN, ACK
Client-PC -> Server: ACK
:::

Nad vsako puščico so **zastavice**, pod njo pa številki `SEQ` in `ACK`. **DATA** označuje pakete s koristno vsebino. Rdeče številke pripadajo odjemalcu, modre strežniku — kaj pomenijo, razloži naslednja stran.

## Zastavice

| Zastavica | pomeni | Pomen |
|---|---|---|
| **SYN** | *synchronize* | vzpostavitev povezave, določitev začetne številke |
| **ACK** | *acknowledge* | potrjuje prejete podatke |
| **PSH** | *push* | podatke takoj predaj programu |
| **FIN** | *finish* | »Končal sem« — prekinitev povezave |
| **RST** | *reset* | prekinitev ali zavrnitev povezave (več o tem v 5.3.2) |

## Tri faze

**Vzpostavitev:** odjemalec pošlje `SYN`, strežnik odgovori s `SYN, ACK`, odjemalec potrdi z `ACK`. Ker so potrebni natanko trije paketi, to imenujemo **tristopenjsko rokovanje**.

**Podatki:** prejemnik vsak paket s podatki potrdi z `ACK`. Tu strežnik pošlje odmev nazaj — tudi tega odjemalec potrdi.

**Prekinitev:** vsaka stran posebej zaključi svojo smer pošiljanja: `FIN` od odjemalca, `ACK` od strežnika — nato `FIN` od strežnika, `ACK` od odjemalca. To so štirje paketi.

:::tip Zapomni si
Povezava TCP poteka v treh fazah: **vzpostavitev** s **tristopenjskim rokovanjem** (`SYN` → `SYN, ACK` → `ACK`), **prenos podatkov** (vsak podatkovni paket se potrdi z `ACK`) in **prekinitev** (vsaka stran pošlje `FIN` in dobi `ACK`).
:::

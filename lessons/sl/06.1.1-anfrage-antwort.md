## Kako izgleda zahteva

V sledi klikni na paket `GET / HTTP/1.1` in razpri **Hypertext Transfer Protocol**. Zahteva HTTP je čisto besedilo:

```
GET / HTTP/1.1              ← Methode, Pfad, Version
Host: 192.168.0.20          ← Header: zusätzliche Angaben
…
                            ← Leerzeile: Ende der Anfrage
```

Odgovor strežnika je zgrajen povsem enako — s statusno vrstico, glavami (headerji), prazno vrstico in nato z dejansko datoteko:

```
HTTP/1.1 200 OK             ← Version, Statuscode, Text
Content-Type: text/html     ← Header: Art der Datei
Content-Length: 301         ← Header: Größe in Byte
                            ← Leerzeile
<!doctype html> …           ← die Datei selbst
```

:::seq
mode: text
Client-PC -> Server: GET / | Zahteva HTTP
Server -> Client-PC: 200 OK | index.html
Client-PC -> Server: GET /style.css | Zahteva HTTP
Server -> Client-PC: 200 OK | style.css
:::

## Metode in statusne kode

**Metoda** pove, kaj odjemalec želi:

| Metoda | Pomen |
|---|---|
| **GET** | prenesti datoteko |
| **POST** | poslati podatke strežniku, npr. izpolnjen obrazec |
| **HEAD** | prenesti samo glave (headerje), brez datoteke |

**Statusna koda** pove, kako je šlo. Prva števka izda vrsto odgovora:

| Koda | Besedilo | Pomen |
|---|---|---|
| **200** | OK | vse je v redu |
| **301** | Moved Permanently | stran se je trajno preselila |
| **404** | Not Found | datoteke ni |
| **405** | Method Not Allowed | ta metoda tukaj ni dovoljena |
| **500** | Internal Server Error | napaka na strežniku |

`2xx` pomeni uspeh, `3xx` preusmeritev, `4xx` napako odjemalca (napačna zahteva), `5xx` napako strežnika.

:::tip Zapomni si
**HTTP** deluje po **načelu zahteve in odgovora**: odjemalec pošlje **zahtevo** (metoda, npr. `GET`, pot, glave), strežnik odgovori s **statusno kodo** (npr. `200 OK`, `404 Not Found`), glavami in datoteko. Za vsako datoteko spletne strani obstaja ločena zahteva.
:::

# O conexiune de la început până la sfârșit

:::sim
url=/sims/lesson-5.1.btsim
:::

Pe **Server** rulează serviciul Echo pe portul `5000`: fiecare mesaj este trimis imediat înapoi. Cu **Client TCP simplu** poți controla o conexiune pas cu pas — fiecare buton reprezintă o fază.

## Experimentul

1. Comută în modul :fa-play: **Rulare**, fă clic pe **Client-PC** și deschide **Client TCP simplu**.
2. La **Host** introdu `192.168.0.20`, iar la **Port** introdu `5000`.
3. Fă clic pe **Conectare**.
4. Scrie `Hello World` în câmpul de mesaj și fă clic pe **Trimitere**. În fereastra de chat vezi imediat după aceea ecoul serverului.
5. Fă clic pe **Deconectare**.
6. Comută în modul :fa-magnifying-glass: **Urmărire** și deschide cu **+** un trace pentru **Client-PC**, interfața `eth0`.

:::note
Cele două pachete ARP de la început le cunoști deja din capitolul 1. În coloana **Info** a pachetelor TCP apare mai întâi `49152 → 5000` (de la ce port la ce port), apoi, între paranteze drepte, **flagurile**, iar după aceea numere precum `Seq=`, `Ack=` și `Len=`. Despre aceste numere vorbim începând cu pagina 5.2.3 — aici te concentrezi pe flaguri și pe `Len`.
:::

## Faza 1: Conectare

:::quiz short
Câte pachete TCP au fost schimbate după ce ai făcut clic pe **Conectare** — înainte ca mesajul tău să fie trimis?
= 3
= trei
:::

:::quiz mc
Cine trimite primul pachet cu `[SYN]`?
- [x] Client-PC
- [ ] Serverul
:::

:::quiz mc
Cu ce flaguri răspunde serverul?
- [ ] `[SYN]`
- [x] `[SYN, ACK]`
- [ ] `[ACK]`
- [ ] `[FIN, ACK]`
:::

## Faza 2: Trimitere

`Len` indică câți octeți de date utile transportă un pachet.

:::quiz short
Câți octeți transportă pachetul cu mesajul tău (`Len`)?
= 13
:::

:::note
`Hello World` are doar 11 caractere. Clientul TCP adaugă însă un sfârșit de rând (2 octeți, `\r\n`) — așa se așteaptă multe protocoale de internet, precum SMTP sau HTTP.
:::

:::quiz mc
Ce trimite serverul înapoi imediat după mesajul tău — chiar înainte de ecou?
- [x] Un pachet cu `[ACK]` și `Len=0` — o confirmare fără date
- [ ] Nimic
- [ ] Un nou `[SYN]`
:::

## Faza 3: Deconectare

:::quiz short
Câte pachete fac parte din închiderea conexiunii — începând cu primul pachet cu `FIN`?
= 4
= patru
:::

:::quiz mc
Ce comunică o parte prin `FIN`?
- [x] „Am terminat” — nu mai trimite date
- [ ] „A apărut o eroare”
- [ ] „Urmează date noi”
:::

:::evaluate
Verifică răspunsurile
:::

## Unde se regăsesc cele patru sarcini?

Asociază unde regăsești în trace sarcinile din secțiunea 5.1:

:::quiz match
Stabilirea conexiunii -> Cele trei pachete [SYN], [SYN, ACK] și [ACK]
Transmitere fiabilă -> Pachete cu [ACK] și Len=0, care confirmă recepția
Închiderea conexiunii -> Pachetele cu FIN și confirmările lor
Multiplexare -> Numerele de port 49152 → 5000 dinaintea parantezelor drepte
:::

Verifică asocierile

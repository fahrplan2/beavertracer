# Aplicarea modelelor

Asociază protocoalele din experimentul de la începutul capitolului cu stratul OSI corespunzător:

:::quiz match
Ethernet -> Strat 2 — Legătură de date
IPv4 -> Strat 3 — Rețea
TCP -> Strat 4 — Transport
HTTP -> Strat 7 — Aplicație
:::

:::evaluate
Verifică asocierea
:::

Și, în final, denumirile unităților de date:

:::quiz match
Frame -> Strat 2 — Legătură de date
Pachet -> Strat 3 — Rețea
Segment -> Strat 4 — Transport
:::

:::evaluate
Verifică asocierea
:::

Astfel ai instrumentele necesare pentru a încadra corect protocoalele de acum încolo. Începând cu capitolul următor parcurgem straturile pe rând — începând cu stratul 2 și cu întrebarea cum știe de fapt un switch încotro trebuie să trimită mai departe un pachet.

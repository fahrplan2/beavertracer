## Ce se ascunde în routerul de acasă

| Rolul în routerul de acasă | Ce face | îl cunoști din |
|---|---|---|
| **Switch** | conectează dispozitivele la porturile LAN | capitolul 3.1 |
| **Punct de acces** | conectează telefoanele, tabletele și laptopurile la rețea prin WLAN | capitolul 3.3 |
| **Router** | conectează rețeaua de acasă cu rețeaua furnizorului — este **gateway-ul** | capitolul 4.3 |
| **Server DHCP** | distribuie adrese, gateway și server DNS | capitolul 6.4 |
| **DNS** | redirecționează cererile de nume sau indică serverul DNS al furnizorului | capitolul 6.2 |
| **NAT** | conectează toate dispozitivele la internet printr-o **singură** adresă publică | nou — secțiunea 7.2 |

Portul **WAN** (*Wide Area Network*) duce către furnizor, porturile **LAN** și rețeaua WLAN duc în rețeaua de acasă. Multe routere de acasă conțin în plus un **modem** — acesta convertește datele pentru linie (DSL, cablu, fibră optică). BeaverTracer nu simulează acest lucru; aici portul WAN este conectat direct la rețeaua furnizorului.

:::quiz match
Switch -> Conectează dispozitivele la porturile LAN
Punct de acces -> Conectează tabletele și telefoanele la rețea prin WLAN
Server DHCP -> Distribuie adrese dispozitivelor din rețeaua de acasă
Router -> Conectează rețeaua de acasă cu rețeaua furnizorului
:::

Verifică asocierea

:::tip De reținut
Un **router de acasă** reunește mai multe dispozitive: **switch**, **punct de acces WLAN**, **router** (gateway către internet), **server DHCP** și **redirecționare DNS** — plus **NAT**. Portul **WAN** duce către furnizor, porturile **LAN** și rețeaua WLAN duc în rețeaua de acasă.
:::

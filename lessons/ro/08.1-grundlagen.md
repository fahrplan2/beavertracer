# Bazele criptografiei

**Criptografia** este știința cifrării. Înainte de a începe, câțiva termeni care apar în mod repetat în acest capitol:

| Termen | Semnificație |
|---|---|
| **Text clar** | Mesajul care poate fi citit, de ex. `Treffen um 10 Uhr` |
| **Text cifrat** | Mesajul cifrat, de ex. `Wuhiihq xp 10 Xku` |
| **Cifrare** | Text clar → text cifrat |
| **Decifrare** | Text cifrat → text clar |
| **Procedeu** (*algoritm*) | Regula de calcul după care se face cifrarea |
| **Cheie** | Informația suplimentară secretă de care are nevoie procedeul |

## Procedeul nu este secret — cheia da

Ai putea crede că un procedeu este cu atât mai sigur, cu cât îl cunosc mai puțini oameni. Adevărul este exact invers: toate procedeele folosite astăzi sunt descrise **public** și au fost verificate ani de zile de specialiști din întreaga lume pentru a le descoperi punctele slabe. Singurul lucru care rămâne secret este **cheia**.

Acest principiu a fost formulat încă din 1883 de olandezul Auguste Kerckhoffs. Avantajul: dacă o cheie este divulgată, se schimbă pur și simplu cheia — nu întregul procedeu.

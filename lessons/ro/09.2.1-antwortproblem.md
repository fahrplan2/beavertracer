# Problema răspunsului

:::sim
url=/sims/lesson-9.2.btsim
:::

Firewall-ul funcționează acum după principiul listei albe (whitelist): politica implicită este **Alle verwerfen**. O singură regulă permite rețelei școlii să navigheze pe web: **B → A, TCP, port destinație 80, Zulassen**. Modul este setat pe **Stateless**.

## Experimentul

1. Treci în modul :fa-play: **Rulare** și deschide pe **Lehrer-PC**, în :fa-globe: **Browser**, adresa `http://203.0.113.80/`.
2. Uită-te în **Firewall** la **Protokoll** și la **Treffer**.

:::quiz mc
Ce se întâmplă în browser?
- [ ] Apare pagina de la www.beispiel.de
- [x] Pagina nu se încarcă, browserul așteaptă și în cele din urmă afișează o eroare
:::

:::quiz mc
Care pachete apar în jurnalul firewall-ului ca respinse (`DROP`)?
- [ ] Cererile Lehrer-PC către portul 80
- [x] Răspunsurile de la `203.0.113.80` cu **port sursă 80** către Lehrer-PC
- [ ] Niciunul
:::

:::quiz short
În ce direcție (A→B sau B→A) circulă pachetele respinse?
= A→B
= A → B
= AtoB
:::

:::evaluate
Verifică răspunsurile
:::

Cererea de la Lehrer-PC are voie să iasă — dar chiar și `SYN, ACK` de la serverul web nu mai ajunge înapoi, pentru că pentru direcția A → B nu există nicio regulă potrivită, deci se aplică **Alle verwerfen**.

## Soluția naivă

S-ar putea adăuga o a doua regulă: **A → B, TCP, port sursă 80, Zulassen** — „tot ce vine de la portul 80 are voie să intre”. Atunci navigarea pe web funcționează într-adevăr.

:::quiz mc
De ce este periculoasă această regulă?
- [ ] Pentru că serverele web nu folosesc niciodată portul 80 ca port sursă
- [x] Un atacator își poate trimite pur și simplu pachetele cu portul sursă 80 — iar firewall-ul le lasă să treacă spre **orice** port din rețeaua școlii
- [ ] Pentru că paginile web se încarcă mai lent
:::

:::evaluate
Verifică răspunsul
:::

Portul sursă este stabilit chiar de expeditor — un firewall nu se poate baza pe el. Un firewall fără stare nu știe însă dacă un pachet este **răspunsul la o cerere** sau o **nouă încercare de conexiune** din exterior. Exact acest lucru îl schimbă modul cu stare.

:::tip De reținut
Un filtru de pachete **fără stare** verifică fiecare pachet în parte. Răspunsurile au atunci nevoie de reguli proprii pentru direcția inversă — iar astfel de reguli (de ex. „portul sursă 80 are voie să intre”) pot fi exploatate de atacatori, deoarece expeditorul poate alege liber portul sursă.
:::

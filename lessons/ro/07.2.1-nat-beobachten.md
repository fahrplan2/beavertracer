## Experimentul

1. Treci în modul :fa-play: **Rulare**, fă clic pe **PC** și accesează în :fa-globe: **Browser** adresa `http://www.beispiel.de/`.
2. În modul :fa-magnifying-glass: **Urmărire**, deschide un trace pentru **PC** și un al doilea pentru serverul web **www.beispiel.de**.
3. Compară în ambele trace-uri pachetul `GET / HTTP/1.1`: cine apare ca expeditor (**Quelle**)?

:::quiz mc
Ce adresă de expeditor are `GET` în trace-ul **PC-ului**?
- [x] Adresa privată a PC-ului (`192.168.178.…`)
- [ ] `203.0.113.2`
- [ ] `192.0.2.80`
:::

:::quiz short
Și ce adresă de expeditor vede **serverul web**?
= 203.0.113.2
:::

:::quiz mc
Ce adresă este `203.0.113.2`?
- [ ] Adresa serverului web
- [x] Adresa WAN a routerului de acasă
- [ ] Adresa DNS-ului furnizorului
:::

:::evaluate
Verifică răspunsurile
:::

## Ce se întâmplă în spate

Routerul de acasă înlocuiește, în fiecare pachet care pleacă spre internet, adresa privată a expeditorului cu propria **adresă WAN publică** — și, de obicei, și portul expeditorului. Pentru serverul web pare că cererea vine de la routerul de acasă. Când răspunsul se întoarce, routerul de acasă schimbă adresa la loc și trimite pachetul mai departe către PC.

Astfel, întreaga rețea de acasă poate ieși pe internet cu o singură adresă publică — iar dispozitivele de pe internet nu văd niciodată adresele private.

## Drumul spre internet

Introdu pe **PC**, în :fa-terminal: **Terminal**:

```
$ traceroute 192.0.2.80
```

:::quiz short

= patru
:::

:::quiz mc
Ce adresă afișează `traceroute` pentru primul router?
- [x] `192.168.178.1` — adresa LAN a routerului de acasă
- [ ] `203.0.113.2` — adresa lui WAN

:::

:::tip De reținut
**NAT** (*Network Address Translation*) înlocuiește, pe drumul spre internet, adresa **privată** a expeditorului unui dispozitiv cu **adresa WAN publică** a routerului — iar la răspunsuri face invers. Astfel, toate dispozitivele din rețeaua de acasă își împart **o singură** adresă IPv4 publică. Asta economisește adrese și ascunde adresele private față de internet.
:::

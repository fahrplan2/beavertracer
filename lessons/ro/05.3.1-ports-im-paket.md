## Două feluri de porturi

**Portul destinație — serviciul:** Un program server așteaptă conexiuni la un port fix — se spune că **ascultă** acolo. Pentru serviciile cunoscute, numerele sunt stabilite la nivel mondial, acestea fiind **porturile well-known** (de la 0 la 1023). De aceea, un browser știe fără să întrebe: serverele web ascultă pe portul 80.

**Portul sursă — expeditorul:** Portul de pe partea clientului este ales de sistemul de operare pentru fiecare conexiune nouă, dintr-un interval înalt (în BeaverTracer începând de la 49152). După el, clientul recunoaște căreia dintre conexiunile sale îi aparține un răspuns.

O conexiune este deci determinată în mod unic de patru informații: **adresa IP și portul de pe ambele părți**. Perechea formată din adresa IP și port se numește **socket**, de ex. `192.168.0.20:80`.

## O privire asupra serverului

Treci înapoi în modul :fa-play: **Rulare**, deschide pe **Server** :fa-terminal: **Terminal** și introdu:

```
$ ss
```

`ss` afișează toate socketurile calculatorului. Rândurile cu `LISTEN` sunt programe care ascultă la un port. Rândurile cu `ESTABLISHED` sunt conexiuni existente — cu socketul propriu (*Local Address:Port*) și socketul părții opuse (*Peer Address:Port*).

:::

Conexiunea clientului TCP este, în schimb, încă deschisă, pentru că nu ai făcut încă clic pe **Deconectare**.

## Cele mai importante porturi well-known

| Port | Protocol | Serviciu |
|---|---|---|
| 22 | SSH | administrare securizată la distanță (linie de comandă criptată) |
| 25 | SMTP | trimiterea e-mailurilor |
| 53 | DNS | traducerea numelor în adrese IP (de obicei prin UDP) |
| 80 | HTTP | pagini web |
| 110 | POP3 | preluarea e-mailurilor |
| 143 | IMAP | gestionarea e-mailurilor pe server |
| 443 | HTTPS | pagini web criptate |

:::tip De reținut
**Porturile** (de la 0 la 65535) separă conexiunile de pe un calculator. Serviciile server **ascultă** la **porturi well-known** fixe (de ex. HTTP 80, HTTPS 443), iar clienții primesc pentru fiecare conexiune un **port sursă** înalt liber. O conexiune este determinată în mod unic de **adresa IP și portul ambelor părți**.
:::

:::quiz match
22 -> SSH
25 -> SMTP
53 -> DNS
80 -> HTTP
110 -> POP3
143 -> IMAP
443 -> HTTPS
:::

Dacă HTTP este text simplu, putem oare să vorbim singuri cu un server web, fără niciun browser? Da: cu `telnet` stabilești o conexiune TCP către orice port și tastezi tu însuți textul.

## Experimentul

1. Treci în modul :fa-play: **Rulare** și deschide :fa-terminal: **Terminal** pe **Client-PC**.
2. Conectează-te la portul 80 al serverului:
   ```
   $ telnet 192.168.0.20 80
   ```
3. Tastează cererea rând cu rând și încheie-o cu un **rând gol** (apasă încă o dată **Enter**):
   ```
   GET /kontakt.html HTTP/1.1
   Host: 192.168.0.20

   ```

Serverul răspunde cu linia de stare, anteturi și pagina de contact, sub formă de text, exact așa cum o primește și browserul.

## Provocarea unor erori

O unealtă mai comodă este `curl`: trimite cererea în locul tău. Cu `-v` (*verbose*, detaliat) afișează tot ce circulă în ambele sensuri: rândurile cu `>` au fost trimise de `curl`, iar cele cu `<` au venit de la server.

Încearcă:

```
$ curl -v http://192.168.0.20/gibtsnicht.html
$ curl -X POST -d name=Anna http://192.168.0.20/
```

:::quiz short
Ce cod de stare primești pentru `/gibtsnicht.html`?
= 404
:::

:::quiz short
Dar pentru cererea cu metoda `POST`?
= 405
:::

:::evaluate
Verifică răspunsurile
:::

:::note
Serverul web din BeaverTracer poate livra doar fișiere, de aceea permite numai `GET` și `HEAD`. Serverele web reale primesc, de exemplu, formulare prin `POST` și transmit datele mai departe către un program.
:::

:::tip De reținut
Multe protocoale ale stratului aplicație sunt **bazate pe text**: HTTP, dar și SMTP, POP3 și IMAP. De aceea le poți „vorbi" manual cu `telnet` și le poți citi în Tracer. Acest lucru este practic pentru depanare, dar reprezintă și o problemă de securitate: oricine interceptează traficul poate citi totul. Cum ajută criptarea (HTTPS) vei învăța în capitolul 8.
:::

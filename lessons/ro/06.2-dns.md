# DNS: nume în loc de numere

:::goal
**Obiectiv de învățare:** Poți explica cum traduce DNS numele în adrese IP, cum sunt organizate ierarhic numele, poți crea singur o înregistrare și poți găsi erori DNS tipice.
:::

:::sim
url=/sims/lesson-6.2.btsim
:::

Adresele IP abia le poate reține cineva — nume precum `www.beaver-schule.de` însă da. Traducerea o face **Domain Name System** (**DNS**), un fel de agendă telefonică mondială a internetului.

Pe spațiul de lucru se află acum o rețea ceva mai mare: pe lângă **Client-PC** și **Webserver** există patru **servere DNS**. De ce sunt atât de multe, vei vedea două pagini mai departe.

# Semnături digitale

Prin criptare se obține **confidențialitatea**, iar cu ajutorul valorilor hash se detectează modificările. Dar cum dovedești **de la cine** provine un mesaj? Pe hârtie se semnează. În rețea există pentru asta **semnătura digitală**.

## Perechea de chei folosită invers

La criptare, expeditorul folosește cheia **publică** a destinatarului. La semnătură este invers: expeditorul folosește **propria cheie privată**. Deoarece doar el deține această cheie, doar el poate genera această semnătură. Verifica o poate, în schimb, oricine — cu cheia **publică** a expeditorului.

**Semnarea** (Anna semnează un contract):

1. Anna calculează **valoarea hash** a contractului.
2. Ea combină valoarea hash cu **cheia ei privată**. Rezultatul este **semnătura**.
3. Ea trimite contractul împreună cu semnătura lui Ben.

**Verificarea** (Ben controlează semnătura):

1. Ben calculează el însuși valoarea hash a contractului primit.
2. El verifică semnătura cu **cheia publică** a Annei: se potrivește cu această valoare hash?
3. Dacă se potrivește, Ben știe două lucruri:
    - Contractul provine într-adevăr de la Anna — doar ea deține cheia privată (**autenticitate**).
    - Contractul nu a fost modificat pe parcurs — altfel ar avea o altă valoare hash (**integritate**).

:::note
De ce semnează Anna doar valoarea hash și nu întregul contract? Metodele asimetrice sunt lente. Valoarea hash este întotdeauna scurtă — indiferent dacă contractul are o pagină sau o mie de pagini.
:::

:::tip De reținut
O **semnătură digitală** este generată de expeditor din **valoarea hash** a mesajului și din **cheia lui privată**. Oricine o poate verifica cu **cheia publică** a expeditorului. O semnătură validă dovedește **de la cine** provine mesajul (**autenticitate**) și că **nu a fost modificat** (**integritate**).
:::

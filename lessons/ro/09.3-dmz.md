# DMZ

:::sim
url=/sims/lesson-9.3.btsim
:::

Până acum, **Schulserver** se afla în aceeași rețea cu **Lehrer-PC**. Asta este periculos: Schulserver este accesibil din internet. Dacă un atacator găsește o vulnerabilitate în serverul web și preia controlul calculatorului, ajunge **în mijlocul rețelei școlii** — iar firewallul nu mai poate face nimic, deoarece traficul de la Schulserver către Lehrer-PC nu trece prin el.

Soluția: serverele care trebuie să fie accesibile din internet se plasează într-o **rețea separată**, între internet și rețeaua internă. Această rețea se numește **DMZ** (*zonă demilitarizată*, după fâșia neutră dintre două granițe).

## Structura

Pe spațiul de lucru vezi modelul clasic cu **două firewalluri**:

```
Internet ──[ Firewall außen ]── Schulrouter ──── DMZ: Schulserver (198.51.100.10)
                                    │
                             [ Firewall innen ]
                                    │
                    LAN: Lehrer-PC (192.0.2.20), Schüler-PC (192.0.2.21)
```

- **Firewall außen** protejează totul față de internet. Portul A este conectat la internet, portul B la Schulrouter.
- **Firewall innen** protejează LAN-ul — inclusiv față de DMZ. Portul A este conectat la Schulrouter, portul B la LAN.

Deocamdată, ambele firewalluri lasă totul să treacă.

## Sarcină: securizarea DMZ

Setează **ambele** firewalluri pe **Stateful** și **Respinge tot** și adaugă regulile potrivite:

- **Firewall außen:** dinspre interior spre exterior (B → A) este permis tot; dinspre exterior (A → B) doar TCP 80 și 25 către Schulserver `198.51.100.10`.
- **Firewall innen:** din LAN (B → A) este permis tot; în direcția LAN (A → B) nu este nevoie de nicio regulă — răspunsurile se întorc prin tabelul de stări.

:::note
Multe firewalluri au trei sau mai multe interfețe („zone”) și realizează o DMZ într-un singur dispozitiv. Principiul este același: traficul dintre internet, DMZ și LAN trebuie să treacă întotdeauna prin reguli. Modelul cu două firewalluri are un avantaj: un atacator trebuie să depășească **două** obstacole — adesea se folosesc chiar dispozitive de la producători diferiți, pentru ca aceeași vulnerabilitate de securitate să nu le deschidă pe ambele.
:::

:::tip De reținut
În **DMZ** se plasează toate serverele care trebuie să fie accesibile din internet. Aceasta se află între două firewalluri (sau într-o zonă separată a unui firewall): internetul are voie doar către anumite servicii din DMZ, LAN-ul are voie în DMZ și în internet — dar din DMZ și din internet **nu există nicio cale spre LAN**. Dacă un server din DMZ este compromis, LAN-ul rămâne protejat.
:::

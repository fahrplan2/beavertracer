# Configurarea unui server DHCP

:::sim
url=/sims/lesson-6.4.2.btsim
:::

De data aceasta serverul DHCP nu este încă configurat. Tu stabilești ce setări distribuie:

| Setare | Valoare |
|---|---|
| Interval de adrese | `192.168.0.100` până la `192.168.0.120` |
| Gateway | `192.168.0.1` |
| Server DNS | `192.168.0.53` |

1. Treci în modul :fa-play: **Rulare**, fă clic pe **DHCP-Server** și deschide aplicația **Server DHCP**.
2. Introdu **Început interval**, **Sfârșit interval**, **Gateway** și **DNS-Server**, fă clic pe **Salvează** și apoi pe **Pornește**.
3. La **Laptop 1** și **Laptop 2**, în :fa-gear: **Setări IP**, setează modul pe **DHCP** și fă clic de fiecare dată pe **Aplică**.
4. Verifică în serverul DHCP, în fila **Leases**, cine a primit ce adresă.

:::note
Intervalul de adrese se alege astfel încât să nu intre în conflict cu adresele fixe: serverele, routerele și imprimantele primesc adesea adrese fixe în afara intervalului DHCP — aici, de exemplu, chiar serverul DHCP cu `192.168.0.2`.
:::

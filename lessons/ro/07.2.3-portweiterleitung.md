# Din exterior spre interior: redirecționarea de porturi

:::sim
url=/sims/lesson-7.2.3.btsim
:::

În rețeaua de acasă există acum un **Heim-Webserver** propriu (`192.168.178.10`). Clara vrea să acceseze pagina din deplasare — laptopul ei **Clara** este conectat la internet, în dreapta.

## Problema

1. Treci în modul :fa-play: **Rulare** și deschide pe **Clara**, în :fa-globe: **Browser**, adresa `http://203.0.113.2/` — adresa publică a rețelei de acasă.
2. Browserul așteaptă și tot așteaptă. După câteva secunde, apasă **Stopp**.
3. În modul :fa-magnifying-glass: **Urmărire**, deschide o urmărire pentru **Heimrouter**, interfața `wan0`.

:::quiz mc
Ce se întâmplă cu stabilirea conexiunii lui Clara (`[SYN]` către portul 80)?
- [x] Ajunge la routerul de acasă — dar acesta nu o redirecționează mai departe și nu răspunde
- [ ] Ajunge la serverul web de acasă, care răspunde cu RST
- [ ] Nu ajunge deloc la routerul de acasă
:::

:::evaluate
Verifică răspunsul
:::

Pentru un pachet care vine din exterior nu există nicio intrare în tabelul NAT: nimeni din rețeaua de acasă nu a inițiat această conexiune. Routerul de acasă nu știe cărui dispozitiv să îl trimită — și îl aruncă.

## Configurarea redirecționării de porturi

Cu o **redirecționare de porturi** (la unele routere *deschidere de porturi*) stabilești: tot ce ajunge la un anumit port WAN merge către un anumit dispozitiv din rețeaua de acasă.

1. Fă clic pe **Heimrouter** și deschide fila **Port FW**.
2. Creează o regulă: protocol `TCP`, port WAN `80`, IP LAN `192.168.178.10`, port LAN `80`, apoi fă clic pe **+ Hinzufügen**.
3. Deschide din nou pe **Clara** adresa `http://203.0.113.2/`.

:::task
title: Serverul web de acasă este accesibil din exterior?
Verifică dacă Clara poate stabili din internet o conexiune la portul 80 al adresei publice a rețelei de acasă. Pentru aceasta, simularea trebuie să ruleze în modul Rulare.
check: tcpOpen(12, "203.0.113.2", 80)
:::

:::warning
O redirecționare de porturi deschide o breșă spre interior: oricine din internet poate ajunge la dispozitivul din spatele ei — inclusiv atacatorii care caută automat porturi deschise. De aceea redirecționează doar ce este cu adevărat necesar și ține dispozitivul actualizat. Mai multe despre aceasta în capitolul 9 (firewall).
:::

:::tip De reținut
Din exterior, nimeni nu poate iniția o conexiune către un dispozitiv aflat în spatele NAT — routerul nu știe încotro să o trimită. O **redirecționare de porturi** stabilește: pachetele către un anumit **port WAN** merg către o anumită **adresă IP LAN** (și un port LAN). Astfel, un server din rețeaua de acasă devine accesibil din internet.
:::

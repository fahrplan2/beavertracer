# Tabelul NAT

:::sim
url=/sims/lesson-7.1.btsim
:::

Când PC-ul și tableta încarcă aceeași pagină web în același timp, ambele cereri ajung la serverul web de la `203.0.113.2`. De unde știe routerul de acasă cui îi este destinat un răspuns? Ține evidența — în **tabelul NAT**.

## Experimentul

1. Treci în modul :fa-play: **Rulare** și accesează `http://www.beispiel.de/` atât de pe **PC**, cât și de pe **Tablet**.
2. Fă clic pe **Heimrouter** și deschide fila **NAT**.

Fiecare rând este o **asociere**: protocolul, adresa IP LAN și portul LAN ale dispozitivului din rețeaua de acasă — și **portul WAN** pe care routerul îl folosește pentru acesta pe adresa sa publică.

:::quiz short
Ce adresă IP WAN apare deasupra tabelului?
= 203.0.113.2
:::

:::quiz mc
PC-ul și tableta au stabilit amândouă o conexiune cu portul LAN `49152`. Ce port WAN primesc?
- [ ] Amândouă același port, `49152`
- [x] Fiecare un port diferit — altfel routerul nu ar ști cui îi aparține răspunsul
- [ ] Niciunul, NAT modifică doar adresa IP
:::

:::quiz mc
Un răspuns de la serverul web ajunge la `203.0.113.2` cu un anumit **port de destinație**. Ce face routerul de acasă cu el?
- [x] Caută portul în tabelul NAT și trimite pachetul către adresa IP LAN și portul LAN corespunzătoare
- [ ] Trimite pachetul către toate dispozitivele din rețeaua de acasă
- [ ] Elimină pachetul
:::

:::evaluate
Verifică răspunsurile
:::

Aici intră din nou în joc **porturile** din capitolul 5: deoarece NAT rescrie și porturile, sute de conexiuni pot partaja o singură adresă. Strict vorbind, acest mecanism se numește de aceea **PAT** (*Port Address Translation*) sau *NAT cu traducere de port* — în practica de zi cu zi se spune totuși pur și simplu NAT.

Iată, de exemplu, cum ar putea arăta o astfel de traducere:

| | Pachet de la PC (în rețeaua de acasă) | același pachet în internet |
|---|---|---|
| Expeditor | `192.168.178.20 : 49152` | `203.0.113.2 : 10001` |
| Destinatar | `192.0.2.80 : 80` | `192.0.2.80 : 80` |

:::tip De reținut
În **tabelul NAT**, routerul reține pentru fiecare conexiune ce dispozitiv (**adresa IP LAN și portul LAN**) se află în spatele cărui **port WAN**. Răspunsurile din internet le atribuie din nou dispozitivului corect pe baza portului de destinație. Deoarece sunt rescrise și porturile, se vorbește mai exact despre **PAT**.
:::

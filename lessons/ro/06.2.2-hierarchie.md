# Cum este organizat DNS

:::sim
url=/sims/lesson-6.2.btsim
:::

Niciun server nu poate cunoaște toate numele din lume. De aceea DNS este construit **ierarhic** — la fel ca numele în sine. Ele se citesc de la dreapta la stânga:

```
www . beaver-schule . de . (Root)
 │          │         │      └─ Root-Server: kennen die Server aller Top-Level-Domains
 │          │         └─ Top-Level-Domain (TLD): der de-Server kennt alle .de-Domains
 │          └─ Domain: der Schul-DNS ist für beaver-schule.de zuständig
 └─ Rechnername innerhalb der Domain
```

Serverul care răspunde de un domeniu și cunoaște cu adevărat răspunsul se numește **autoritativ**. Drumul până la el este parcurs pentru PC de un **resolver** — aici calculatorul **DNS-Resolver**.

## Experimentul

1. Treci în modul :fa-play: **Rulare** și introdu în :fa-terminal: **Terminal** de pe **Client-PC**:
   ```
   $ nslookup www.beaver-schule.de
   ```
2. În modul :fa-magnifying-glass: **Urmărire**, deschide o urmărire (trace) pentru **DNS-Resolver**.

Resolverul a trimis pentru tine o serie întreagă de interogări. Asociază cine a dat fiecare răspuns:

:::quiz match
Root-Server (192.168.0.101) -> Trimitere: Pentru .de este responsabil ns.nic.de
de-Server (192.168.0.102) -> Trimitere: Pentru beaver-schule.de este responsabil ns.beaver-schule.de
Schul-DNS (192.168.0.103) -> Răspuns: www.beaver-schule.de are adresa 192.168.0.20
:::

:::quiz mc
Pe cine întreabă resolverul primul?
- [x] Serverul root
- [ ] Schul-DNS
- [ ] Client-PC
:::

:::evaluate
Verifică răspunsurile
:::

:::note
Între timp, resolverul întreabă și adresele serverelor către care a fost trimis (`A ns.nic.de`). Serverele DNS reale trimit de obicei aceste adrese direct în răspuns. În plus, resolverele rețin fiecare răspuns o vreme (**cache**) — la următoarea interogare pentru același nume răspund imediat singure. Cât timp se păstrează răspunsul este indicat în înregistrare ca **TTL** (*Time to Live*), în secunde.
:::

## Cele mai importante tipuri de înregistrări

| Tip | Semnificație | Exemplu |
|---|---|---|
| **A** | nume → adresă IPv4 | `www.beaver-schule.de` → `192.168.0.20` |
| **AAAA** | nume → adresă IPv6 | `www.beaver-schule.de` → `2001:db8::20` |
| **CNAME** | nume → alt nume (alias) | `web.beaver-schule.de` → `www.beaver-schule.de` |
| **MX** | serverul de e-mail responsabil pentru un domeniu | `beaver-schule.de` → `mail.beaver-schule.de` |
| **NS** | serverul DNS responsabil pentru un domeniu | `beaver-schule.de` → `ns.beaver-schule.de` |

:::tip De reținut
DNS este **ierarhic**: **serverele root** trimit către serverele **domeniilor de nivel superior** (de ex. `.de`), iar acestea către serverele **domeniilor** individuale. Serverul **autoritativ** responsabil cunoaște răspunsul. Un **resolver** parcurge acest drum pentru PC și reține răspunsurile (**cache**). Tipuri importante de înregistrări: **A**, **AAAA**, **CNAME**, **MX**, **NS**.
:::

## Crearea unei înregistrări

Școala dorește ca site-ul ei web să fie accesibil suplimentar și la `intranet.beaver-schule.de`.

1. În modul :fa-play: **Rulare**, fă clic pe **Schul-DNS** și deschide aplicația **DNS-Server**.
2. Deschide fila **A**. Fă clic pe **+** și introdu în rândul nou numele `intranet.beaver-schule.de` și adresa `192.168.0.20`.
3. Testează pe Client-PC cu `nslookup intranet.beaver-schule.de`.

:::task

check: resolves(2, "intranet.beaver-schule.de", "192.168.0.20")
:::

O pagină web este deci adesea alcătuită din multe fișiere: text, foi de stil, imagini. Pentru fiecare dintre ele, browserul trimite o cerere separată.

## Cum arată o cerere

Fă clic în trace pe pachetul `GET / HTTP/1.1` și deschide **Hypertext Transfer Protocol**. O cerere HTTP este text simplu:

```
GET / HTTP/1.1              ← Methode, Pfad, Version
Host: 192.168.0.20          ← Header: zusätzliche Angaben
…
                            ← Leerzeile: Ende der Anfrage
```

Răspunsul serverului are exact aceeași structură — cu o linie de stare, header-e, o linie goală și apoi fișierul propriu-zis:

```
HTTP/1.1 200 OK             ← Version, Statuscode, Text
Content-Type: text/html     ← Header: Art der Datei
Content-Length: 301         ← Header: Größe in Byte
                            ← Leerzeile
<!doctype html> …           ← die Datei selbst
```

:::seq
mode: text
Client-PC -> Server: GET / | Cerere HTTP
Server -> Client-PC: 200 OK | index.html
Client-PC -> Server: GET /style.css | Cerere HTTP
Server -> Client-PC: 200 OK | style.css
:::

## Metode și coduri de stare

**Metoda** spune ce vrea clientul:

| Metodă | Semnificație |
|---|---|
| **GET** | preia un fișier |
| **POST** | trimite date către server, de exemplu un formular completat |
| **HEAD** | preia doar header-ele, fără fișier |

**Codul de stare** spune cum a decurs cererea. Prima cifră indică tipul răspunsului:

| Cod | Text | Semnificație |
|---|---|---|
| **200** | OK | totul este în ordine |
| **301** | Moved Permanently | pagina s-a mutat definitiv |
| **404** | Not Found | fișierul nu există |
| **405** | Method Not Allowed | această metodă nu este permisă aici |
| **500** | Internal Server Error | eroare pe server |

`2xx` înseamnă succes, `3xx` redirecționare, `4xx` o eroare a clientului (cerere greșită), `5xx` o eroare a serverului.

:::tip De reținut
**HTTP** funcționează după **principiul cerere-răspuns**: clientul trimite o **cerere** (metodă precum `GET`, cale, header-e), iar serverul răspunde cu un **cod de stare** (de ex. `200 OK`, `404 Not Found`), header-e și fișierul. Pentru fiecare fișier al unei pagini web există o cerere separată.
:::

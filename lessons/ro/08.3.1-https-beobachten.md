# HTTP și HTTPS în comparație

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Serverul web **www.beaver-schule.de** oferă portalul de note al școlii atât prin HTTP, cât și prin HTTPS. Ce vede cineva care interceptează traficul?

## Experimentul

1. Treci în modul :fa-play: **Rulare** și deschide pe **Client-PC** în :fa-globe: **Browser** mai întâi `http://www.beaver-schule.de/`, apoi `https://www.beaver-schule.de/`.
2. Deschide în modul :fa-magnifying-glass: **Urmărire** un trace pentru **Client-PC**.
3. Caută mai întâi pachetul `HTTP/1.1 200 OK` și dă clic pe el. Jos, în detalii, găsești conținutul paginii.

:::quiz mc
Ce poate vedea cineva care interceptează traficul în cazul **HTTP**?
- [x] Pagina web completă, inclusiv notele Annei
- [ ] Doar adresa serverului
- [ ] Nimic, deoarece HTTP rulează peste TCP
:::

:::quiz short
Ce notă are Anna la matematică?
= 2
:::

:::evaluate
Verifică răspunsurile
:::

Acum partea cu HTTPS. Caută pachetul `[SYN]` cu care clientul începe a doua conexiune.

:::quiz short
Ce port de destinație are conexiunea HTTPS (coloana **Info**, `… → ???`)?
= 443
:::

Introdu acum sus, în câmpul de filtrare al trace-ului, `tls` — astfel vei vedea doar pachetele TLS.

:::quiz mc
Ce apare în coloana **Info** la pachetele care conțin pagina web?
- [ ] `HTTP/1.1 200 OK`
- [x] `Application Data`
- [ ] `Encrypted HTML`
:::

:::quiz multi
Ce poate totuși să vadă cineva care interceptează traficul în cazul **HTTPS**?
- [x] Adresele IP ale clientului și ale serverului
- [x] Că se folosește portul 443, deci probabil HTTPS
- [x] Aproximativ câte date sunt transmise
- [ ] Ce pagină a fost accesată și ce conține aceasta
:::

:::evaluate
Verifică răspunsurile
:::

:::note
Dă clic pe un pachet **Application Data**: datele utile sunt doar o succesiune de octeți aparent aleatorii. Tracer-ul nu le poate decripta — cunoaște cheia de sesiune la fel de puțin ca un atacator.
:::

:::tip De reținut
La **HTTP**, oricine interceptează traficul poate citi pagina web completă. La **HTTPS**, el vede doar **cine vorbește cu cine** (adrese IP, port 443) și **cât de mult** — conținutul se află criptat în pachetele **Application Data**.
:::

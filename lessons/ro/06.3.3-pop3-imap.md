# POP3 sau IMAP?

:::sim
url=/sims/lesson-6.3.btsim
:::

Pentru preluarea mesajelor există două protocoale. În această simulare, **Anna folosește POP3**, iar **Ben folosește IMAP**.

## Experimentul

1. În modul :fa-play: **Rulare**, trimite un e-mail de la **Ben** către `anna@beaver-schule.de`.
2. La **Anna**, în aplicația **E-Mail**, apasă pe **Preluare**.
3. Deschide traseele pentru **Anna** și pentru **Ben** și compară comenzile folosite la preluare.

:::quiz match
USER / PASS -> POP3: autentificare cu nume de utilizator și parolă în doi pași
RETR -> POP3: descărcarea unui mesaj
LOGIN -> IMAP: autentificare cu nume de utilizator și parolă
SELECT INBOX -> IMAP: deschiderea unui dosar pe server
:::

:::evaluate
Verifică asocierea
:::

## Diferența

| | POP3 | IMAP |
|---|---|---|
| Port | 110 | 143 |
| Idee de bază | mesajele se **descarcă** — apoi, de obicei, se șterg de pe server | mesajele **rămân pe server** și sunt gestionate acolo |
| Dosare, citit/necitit | doar pe propriul dispozitiv | pe server — la fel peste tot |
| Mai multe dispozitive (telefon, laptop) | nepractic: fiecare dispozitiv are o altă stare | ideal: toate dispozitivele văd aceeași căsuță poștală |

:::note
Programul de e-mail din BeaverTracer lasă mesajele pe server chiar și în cazul POP3. Programele reale le șterg adesea după descărcare — sau le lasă acolo doar o perioadă.
:::

:::quiz mc
Lena își citește e-mailurile pe telefon, pe tabletă și pe laptopul de la școală. Ce ar trebui să folosească?
- [ ] POP3, pentru că este mai simplu
- [x] IMAP, pentru că toate dispozitivele văd aceeași căsuță poștală de pe server
- [ ] SMTP, pentru că este făcut pentru preluare
:::

:::evaluate
Verifică răspunsul
:::

:::tip De reținut
**POP3** descarcă mesajele de pe server pe **un singur** dispozitiv. **IMAP** gestionează căsuța poștală **pe server** — cu dosare și stare citit/necitit pentru toate dispozitivele în același timp. Ambele servesc doar la **preluare**; trimiterea se face întotdeauna cu **SMTP**.
:::

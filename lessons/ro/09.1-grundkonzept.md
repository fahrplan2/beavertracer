# Filtru de pachete: reguli

Cel mai simplu și mai important tip de firewall este **filtrul de pachete**. El se uită la fiecare pachet care îl traversează și decide, pe baza unei **liste de reguli**, dacă pachetul are voie să treacă. Pentru asta citește doar antetele straturilor 3 și 4 — conținutul (de exemplu pagina web) nu îl analizează.

## Din ce este alcătuită o regulă

| Câmp | Semnificație | Exemplu |
|---|---|---|
| **Direcție** | Din ce parte vine pachetul? | A → B (din internet în rețeaua școlii) |
| **Protocol** | TCP, UDP, ICMP sau oricare | TCP |
| **IP sursă** | adresa expeditorului sau rețeaua acestuia | oricare |
| **Port sursă** | portul expeditorului | oricare |
| **IP destinație** | adresa destinatarului sau rețeaua acestuia | `198.51.100.10` |
| **Port destinație** | portul destinatarului, adică serviciul | `80` |
| **Acțiune** | Ce se întâmplă cu pachetele care se potrivesc? | Permite |

Un câmp gol înseamnă „oricare”. Rețelele se scriu în notația CIDR, de exemplu `198.51.100.0/24`, iar intervalele de porturi cu cratimă, de exemplu `1024-65535`.

## Ordinea contează

Firewall-ul verifică regulile **de sus în jos**. **Prima regulă care se potrivește** decide — toate regulile următoare nu mai sunt luate în considerare pentru acel pachet. Dacă nicio regulă nu se potrivește, se aplică **politica implicită** (*Default Policy*).

## Trei acțiuni posibile

| Acțiune | Ce face firewall-ul | Ce observă expeditorul |
|---|---|---|
| **Permite** (*Allow*) | Pachetul este redirecționat mai departe | — |
| **Elimină** (*Drop*) | Pachetul este aruncat fără niciun comentariu | nimic — așteaptă până expiră un timeout |
| **Respinge** (*Reject*) | Pachetul este aruncat, iar expeditorul primește un refuz: în cazul TCP un **RST**, altfel un mesaj ICMP „destinație inaccesibilă” | imediat un mesaj de eroare |

Care variantă este mai bună? **Eliminarea** îi dezvăluie mai puțin unui atacator și îi consumă timp, pentru că trebuie să aștepte la fiecare încercare. **Respingerea** este mai prietenoasă cu proprii utilizatori: un program primește imediat un mesaj de eroare, în loc să rămână blocat mult timp. În practică, de aceea se elimină de obicei pachetele din exterior și se resping pachetele din propria rețea.

:::quiz match
Permite -> Pachetul este redirecționat mai departe
Elimină -> Pachetul dispare, iar expeditorul așteaptă în zadar un răspuns
Respinge -> Pachetul nu este redirecționat mai departe, dar expeditorul primește imediat un refuz
Politica implicită -> Se aplică atunci când nicio regulă nu se potrivește
:::

:::tip De reținut
Un **filtru de pachete** verifică fiecare pachet, pe baza direcției, protocolului, adreselor și porturilor, în raport cu o **listă de reguli**. **Prima regulă care se potrivește** decide acțiunea: **Permite**, **Elimină** (în tăcere) sau **Respinge** (cu refuz). Dacă nicio regulă nu se potrivește, se aplică **politica implicită**.
:::

# Introducerea rutelor statice

:::sim
url=/sims/lesson-4.5.2.btsim
:::

De data aceasta, între firma A și firma B se află **două** routere. Ele sunt conectate printr-o mică rețea proprie, **rețeaua intermediară** `10.0.0.0/30`:

| Router | Interfață | Adresă IP | Rețea |
|---|---|---|---|
| Router A | `eth0` | `192.168.0.1/24` | Firma A (Anna) |
| Router A | `eth1` | `10.0.0.1/30` | Rețea intermediară |
| Router B | `eth0` | `10.0.0.2/30` | Rețea intermediară |
| Router B | `eth1` | `172.16.0.1/24` | Firma B (Clara) |

:::note
O rețea `/30` are exact două adrese utilizabile — perfect pentru conectarea a două routere (vezi secțiunea 4.2.3).
:::

## Problema

Treci în modul :fa-play: **Rulare** și dă ping de la **Anna** către Clara (`ping 172.16.0.10`). Clara nu răspunde — în schimb, Router A (`192.168.0.1`) raportează „Rețea de destinație inaccesibilă”.

Uită-te la **Tabel de rutare IPv4** al routerului **Router A**.

:::quiz mc
De ce nu ajunge ping-ul Annei la Clara?
- [ ] Anna nu a introdus un gateway
- [x] Router A nu cunoaște rețeaua `172.16.0.0/24` — nu este conectată direct la el și nu există nicio rută către ea
- [ ] Rețeaua intermediară este prea mică
:::

:::evaluate
Verifică răspunsul
:::

## Introducerea rutei

Router A trebuie să învețe: pachetele pentru `172.16.0.0/24` merg către Router B (`10.0.0.2`), prin `eth1`.

1. La **Router A**, deschide fila **Tabel de rutare IPv4** și dă clic pe **+ hinzufügen**.
2. În rândul nou introdu: **Ziel** `172.16.0.0`, **Netzmaske** `255.255.255.0`, **Urmatorul salt** `10.0.0.2`, **Iface** `eth1`.
3. Salvează rândul cu bifa :fa-check:. În coloana **Quelle** apare acum **Static**.

Dă ping din nou către Clara — acum răspunsul ajunge.

:::note
Router B cunoaște deja drumul înapoi spre firma A: în tabela sa de rutare există deja o rută statică pentru `192.168.0.0/24` prin `10.0.0.1`. De ce este acest drum de întoarcere la fel de important, vei vedea pe pagina următoare.
:::

## Urmărirea drumului: traceroute

Cu `traceroute` poți afișa prin ce routere trece un pachet. Introdu pe **Anna**:

```
$ traceroute 172.16.0.10
```

:::quiz short
Prin câte routere trece pachetul de la Anna la Clara?
= 2
= două
= doua
:::

:::quiz mc
Ce adresă afișează `traceroute` pentru Router B?
- [x] `10.0.0.2` — adresa sa din rețeaua intermediară, prin care intră pachetul
- [ ] `172.16.0.1` — adresa sa din firma B
- [ ] `192.168.0.1`
:::

:::evaluate
Verifică răspunsurile
:::

`traceroute` folosește un truc cu **Time to Live** din secțiunea 4.3.1: mai întâi trimite un pachet cu TTL 1. Primul router scade 1, ajunge la 0, aruncă pachetul și raportează acest lucru înapoi expeditorului — astfel Anna cunoaște primul router. Apoi urmează TTL 2 pentru al doilea router și tot așa, până când destinația răspunde.

:::tip De reținut
O **rută statică** este introdusă manual de administrator: rețeaua de destinație, masca de rețea, următorul salt și interfața. Cu **traceroute** se poate urmări drumul unui pachet router cu router.
:::

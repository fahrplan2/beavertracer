# Valori hash: amprenta digitală a datelor

:::sim
url=/sims/lesson-8.1.3.btsim
:::

O **funcție hash** calculează, dintr-o cantitate oarecare de date — o propoziție, un document, un film întreg — un șir scurt de caractere, de lungime fixă: **valoarea hash**. Ea funcționează ca o **amprentă digitală**: aceleași date dau întotdeauna aceeași valoare hash, iar date diferite dau o valoare hash diferită.

Funcția hash folosită astăzi în mod obișnuit se numește **SHA-256**. Valoarea ei hash are întotdeauna 256 de biți, adică 64 de caractere scrisă ca număr hexazecimal.

## Experimentul

Pe **PC**, în folderul `/home`, se află trei fișiere cu un mic contract de vânzare-cumpărare. Comută în modul :fa-play: **Rulare**, deschide pe **PC** :fa-terminal: **Terminal** și introdu:

```
$ cd /home
$ cat vertrag.txt vertrag-kopie.txt vertrag-neu.txt
$ sha256sum vertrag.txt vertrag-kopie.txt vertrag-neu.txt
```

## Proprietățile unei funcții hash

| Proprietate | Semnificație |
|---|---|
| **lungime fixă** | Indiferent cât de mari sunt datele, valoarea hash are întotdeauna aceeași lungime. |
| **univocă** | Aceleași date dau întotdeauna aceeași valoare hash. |
| **efect de avalanșă** | Chiar și cea mai mică modificare dă o valoare hash complet diferită. |
| **funcție unidirecțională** | Din valoarea hash datele **nu** pot fi recalculate. |
| **rezistentă la coliziuni** | Este practic imposibil să găsești două fișiere diferite cu aceeași valoare hash. |

O funcție hash **nu este criptare**: nu există nicio cheie și nicio decriptare. Ea servește unui alt scop — **integrității**.

## La ce folosește?

- **Verificarea descărcărilor:** Multe site-uri web indică, pe lângă un fișier, și valoarea lui SHA-256. Dacă valoarea hash a fișierului descărcat de tine se potrivește cu ea, fișierul nu a fost modificat pe parcurs.
- **Stocarea parolelor:** Site-urile bune nu stochează parola ta, ci doar o valoare hash a ei. La autentificare se compară valoarea hash a ceea ce ai introdus. Dacă baza de date este furată, hoțul tot nu cunoaște parolele.
- **Semnături digitale:** În loc să semnezi un document întreg, semnezi doar valoarea lui hash — mai multe despre aceasta în secțiunea următoare.

:::tip De reținut
O **funcție hash** (de ex. **SHA-256**) calculează din date oarecare o **valoare hash** de lungime fixă — o **amprentă digitală**. Chiar și cea mai mică modificare dă o valoare hash complet diferită, iar din valoarea hash datele nu pot fi recalculate. Valorile hash asigură **integritatea** datelor.
:::

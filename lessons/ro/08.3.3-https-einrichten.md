# Configurarea HTTPS

:::sim
url=/sims/lesson-8.3.3.btsim
:::

Aici continuăm de unde s-a oprit secțiunea 8.2.2: pe serverul web **www.beaver-schule.de** se află **Schul-CA** și un certificat de server emis de aceasta, iar **Client-PC** are încredere în Schul-CA. Doar că serverul web nu vorbește încă HTTPS.

## Înainte

Treci în modul :fa-play: **Rulare** și deschide pe **Client-PC**, în :fa-globe: **Browser**, adresa `https://www.beaver-schule.de/`.

:::quiz mc
Ce se întâmplă?
- [x] Conexiunea nu se stabilește — niciun serviciu nu ascultă pe portul 443
- [ ] Browserul avertizează în legătură cu un certificat nesigur
- [ ] Pagina este afișată fără lacăt
:::

:::evaluate
Verifică răspunsul
:::

## Activarea HTTPS

1. Deschide pe serverul web **Server HTTP** și fă clic pe **Stoppen** — cât timp serverul rulează, setările nu pot fi modificate.
2. Treci la fila **HTTPS**:
    - Bifează **HTTPS aktivieren**, **HTTPS-Port** `443`
    - La **Zertifikat** alege certificatul de server `www.beaver-schule.de` — nu Schul-CA!
    - Fă clic pe **Verwenden**
3. Fă clic pe **Pornește**.

Deschide din nou pagina pe Client-PC prin `https://`. Fă clic pe lacăt și verifică emitentul și valabilitatea.

:::task
title: HTTPS configurat?
Verifică dacă Client-PC poate prelua https://www.beaver-schule.de/ fără avertisment de certificat. Pentru aceasta, simularea trebuie să ruleze în modul Rulare.
check: httpsOk(2, "https://www.beaver-schule.de/")
:::

:::quiz mc
De ce nu ai voie să alegi în Serverul HTTP certificatul **Schul-CA**?
- [ ] Pentru că certificatele CA nu pot cripta
- [x] Pentru că este emis pentru numele `Schul-CA`, nu pentru `www.beaver-schule.de` — browserul ar avertiza
- [ ] Pentru că Schul-CA nu are cheie privată
:::

:::quiz mc
Ce ar vedea un dispozitiv care **nu** are încredere în Schul-CA, de exemplu telefonul unui oaspete?
- [ ] Pagina complet normal, cu lacăt
- [x] Un avertisment de certificat, deoarece nu poate urmări lanțul de încredere până la o CA cunoscută
- [ ] Nimic, pentru că conexiunea este respinsă
:::

:::evaluate
Verifică răspunsurile
:::

:::note
Pentru site-urile web publice este nevoie de un certificat de la o CA preinstalată în toate browserele. Din 2015 există **Let's Encrypt**, o CA care emite astfel de certificate gratuit și automat — unul dintre principalele motive pentru care astăzi aproape toate site-urile web folosesc HTTPS.
:::

:::tip De reținut
Pentru **HTTPS**, serverul web are nevoie de un **certificat de server cu cheie privată**, al cărui nume se potrivește cu adresa, și trebuie să **asculte pe portul 443**. Clientul are încredere în pagină doar dacă recunoaște **CA** care a emis certificatul.
:::

# Cine primește ce pachet?

:::sim
url=/sims/lesson-3.1.2.btsim
:::

Acum Anna, Ben și Clara sunt conectați la switch (porturile 1, 2 și 3). Când Anna trimite un pachet către Ben: îl primește doar Ben — sau și Clara?

Gândește-te puțin la ce crezi că se va întâmpla. Apoi încearcă.

## Experimentul

1. Treci în modul :fa-play: **Rulare**, deschide :fa-terminal: **Terminal** pe **Anna** și dă ping către Ben:
   ```
   $ ping 192.168.0.11
   ```
2. Treci în modul :fa-magnifying-glass: **Urmărire** și deschide cu **+** o urmă (trace) pentru **Clara**, portul `eth0`.
3. Deschide cu **+** o a doua urmă pentru **Ben**, portul `eth0`. Sus poți comuta între cele două urme.

:::quiz short
Câte pachete au ajuns la **Clara**?
= 1
= unu
= una
= un pachet
:::

:::quiz mc
Care a fost acel pachet?
- [x] Cererea ARP „Who has 192.168.0.11?” către toți (broadcast)
- [ ] Un ping (Echo Request) de la Anna
- [ ] Răspunsul ARP de la Ben
:::

:::quiz mc
Și ce a ajuns la **Ben**?
- [ ] Doar cererea ARP
- [ ] Doar pingurile
- [x] Cererea ARP și toate pingurile
:::

:::evaluate
Verifică răspunsurile
:::

## Ce se află în spate

Cererea ARP are ca destinație **broadcast** — este adresată *tuturor*. De aceea switch-ul a transmis-o pe fiecare port, inclusiv către Clara. Pingurile, în schimb, au fost adresate doar lui Ben. Switch-ul le-a trimis exclusiv pe portul lui Ben — Clara nu a observat nimic din toate acestea.

:::tip De reținut
Un **broadcast** este adresat tuturor dispozitivelor din rețeaua locală — switch-ul îl distribuie pe toate porturile. Un **unicast** este adresat exact unui singur dispozitiv — switch-ul îl trimite doar pe portul la care este conectat acel dispozitiv.
:::

## O privire în switch

Dar de unde știe switch-ul la ce port este conectat Ben? Treci înapoi în modul :fa-play: **Rulare** și dă clic pe **Switch**. În fila **SAT** vezi tabela sa de adrese, cu două coloane: **MAC** și **Port**.

:::quiz mc
Ce dispozitive apar în tabela de adrese?
- [ ] Anna, Ben și Clara
- [x] Doar Anna și Ben
- [ ] Doar Ben
:::

:::quiz short
La ce port este conectat Ben, conform tabelei? Sfat: adresa MAC a lui Ben o găsești în Tracer, în răspunsul lui ARP `192.168.0.11 is at …`.
= 2
= port 2
:::

:::quiz mc
De ce lipsește Clara din tabelă?
- [ ] Cablul ei este defect
- [x] Nu a trimis încă niciun pachet
- [ ] Switch-ul memorează cel mult două intrări
:::

:::evaluate
Verifică răspunsurile
:::

Switch-ul **învață** din mers: la fiecare cadru (frame) care ajunge la el, se uită la adresa MAC a **expeditorului** și își notează la ce port este conectat acel dispozitiv. Când a sosit cererea ARP a Annei, a notat „Anna → port 1”, iar la răspunsul lui Ben „Ben → port 2”. Clara nu a trimis nimic — deci încă nu o cunoaște.

:::tip De reținut
Un switch memorează în **tabela de adrese** (**SAT**, *Source Address Table*) sub ce adresă MAC este accesibil fiecare dispozitiv și pe ce port — acest lucru îl învață din adresele expeditorilor. Dacă cunoaște destinația unui cadru, îl trimite doar pe acel port. Dacă nu o cunoaște (sau dacă este un broadcast), îl trimite pe toate porturile.
:::

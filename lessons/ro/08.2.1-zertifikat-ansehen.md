# Vizualizarea unui certificat

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Pe spațiul de lucru vezi **Client-PC**, un **DNS-Server** și serverul web al școlii, `www.beaver-schule.de`. Serverul web oferă paginile sale și prin **HTTPS**.

## Lăcățelul din browser

1. Treci în modul :fa-play: **Rulare**, dă clic pe **Client-PC** și deschide :fa-globe: **Browser**.
2. Accesează `https://www.beaver-schule.de/` — fii atent la **https**.
3. În stânga adresei apare un **lăcățel**. Dă clic pe el.

:::quiz short
Pentru ce nume a fost emis certificatul (subiect fără `CN=`)?
= www.beaver-schule.de
:::

:::quiz short
Cine a emis certificatul (emitent fără `CN=`)?
= Biber Root CA
:::

:::evaluate
Verifică răspunsurile
:::

## De ce are Client-PC încredere în certificat?

Pe **Client-PC** deschide :fa-shield-halved: **Zertifikatverwaltung** și treci la fila **Vertrauenswürdige CAs**.

:::quiz mc
Ce găsești acolo?
- [x] Certificatul **Biber Root CA**
- [ ] Certificatul pentru `www.beaver-schule.de`
- [ ] Nicio intrare
:::

:::quiz mc
Cum se vede că Biber Root CA este o autoritate de certificare rădăcină (Root-CA)?
- [x] Este **autosemnată**: subiectul și emitentul sunt identice
- [ ] Numele ei se termină cu „CA”
- [ ] Nu are cheie publică
:::

:::quiz mc
Pe Client-PC, la **Privater Schlüssel** scrie „Ja” sau „Nein”?
- [ ] Ja — clientul are nevoie de cheia privată a CA-ului pentru a verifica semnăturile
- [x] Nein — pentru verificare este suficientă cheia publică; cheia privată o deține doar CA-ul
:::

:::evaluate
Verifică răspunsurile
:::

## Cealaltă parte: serverul web

Deschide acum pe serverul web **www.beaver-schule.de** :fa-shield-halved: **Zertifikatverwaltung** (fila **Meine Zertifikate**) și privește certificatul acestuia.

:::quiz multi
Ce este adevărat pentru certificatul de pe serverul web?
- [x] La **Privater Schlüssel** scrie „Ja” — serverul îl necesită pentru stabilirea conexiunii
- [x] **Lanțul** este `www.beaver-schule.de ← Biber Root CA`
- [x] **Amprenta** este aceeași ca în fereastra lăcățelului din browser
- [ ] Este autosemnat
:::

:::evaluate
Verifică răspunsurile
:::

:::note
**Amprenta** este o valoare hash calculată peste certificat. Cu ajutorul ei poți compara rapid două certificate — fără a verifica fiecare câmp în parte.
:::

:::tip De reținut
**Serverul web** deține certificatul său **împreună cu cheia privată**. **Clientul** cunoaște doar **certificatul Root-CA** (fără cheia privată) — acesta îi este suficient pentru a verifica semnătura de pe certificatul serverului. Dacă dai clic pe **lăcățel** în browser, vezi subiectul, emitentul, amprenta și perioada de valabilitate.
:::

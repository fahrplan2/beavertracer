## De unde știe PC-ul care este serverul DNS?

Deschide pe **Client-PC** :fa-gear: **Setări IP**: în câmpul **DNS-Server** se află `192.168.0.53` — calculatorul **DNS-Resolver**. Către el trimite PC-ul fiecare cerere de nume.

Poți întreba serverul DNS și direct, fără browser. Deschide :fa-terminal: **Terminal** și introdu:

```
$ nslookup www.beaver-schule.de
```

`nslookup` arată mai întâi ce server a fost întrebat, apoi răspunsul. Pentru comparație, întreabă după un nume care nu există, de ex. `nslookup gibtsnicht.beaver-schule.de`.

:::quiz mc
Ce răspunde serverul DNS pentru numele necunoscut?
- [ ] O adresă IP aleatorie
- [x] `NXDOMAIN` — acest nume nu există
- [ ] Nimic
:::

:::evaluate
Verifică răspunsul
:::

:::tip De reținut
**DNS** traduce nume (de ex. `www.beaver-schule.de`) în adrese IP. Înainte ca un PC să poată stabili o conexiune cu un nume, el întreabă **serverul DNS** înregistrat în setările sale IP — de obicei prin **UDP, port 53**. Cu `nslookup` poți trimite manual cereri DNS.
:::

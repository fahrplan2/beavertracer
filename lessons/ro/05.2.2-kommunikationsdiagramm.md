# Diagrama de secvență

:::sim
url=/sims/lesson-5.1.btsim
:::

Desfășurarea unei conexiuni se desenează sub forma unei **diagrame de secvență**: clientul și serverul primesc fiecare câte o linie verticală, iar timpul curge de sus în jos. Fiecare săgeată este un pachet. Este desenată oblic, pentru că fiecare pachet petrece puțin timp pe drum.

Așa arată conexiunea ta de pe pagina anterioară — compar-o rând cu rând cu trace-ul:

:::seq
Client-PC -> Server: SYN
Server -> Client-PC: SYN, ACK
Client-PC -> Server: ACK
Client-PC -> Server: PSH, ACK "Hello World" len=13
Server -> Client-PC: ACK
Server -> Client-PC: PSH, ACK len=13
Client-PC -> Server: ACK
Client-PC -> Server: FIN, ACK
Server -> Client-PC: ACK
Server -> Client-PC: FIN, ACK
Client-PC -> Server: ACK
:::

Deasupra fiecărei săgeți se află **flag-urile**, iar dedesubt numerele `SEQ` și `ACK`. **DATA** marchează pachetele cu date utile. Numerele roșii aparțin clientului, cele albastre serverului — ce înseamnă ele, aflăm pe pagina următoare.

## Flag-urile

| Flag | provine de la | Semnificație |
|---|---|---|
| **SYN** | *synchronize* | stabilește conexiunea, fixează numărul de start |
| **ACK** | *acknowledge* | confirmă datele primite |
| **PSH** | *push* | transmite imediat datele către program |
| **FIN** | *finish* | „Am terminat” — închide conexiunea |
| **RST** | *reset* | întrerupe sau refuză o conexiune (mai multe în 5.3.2) |

## Trei faze

**Stabilire:** clientul trimite `SYN`, serverul răspunde cu `SYN, ACK`, iar clientul confirmă cu `ACK`. Deoarece sunt necesare exact trei pachete, procedura se numește **handshake în trei pași**.

**Date:** fiecare pachet cu date este confirmat de destinatar cu un `ACK`. Aici serverul trimite înapoi ecoul — și acesta este confirmat de client.

**Închidere:** fiecare parte își încheie separat sensul de transmisie: `FIN` de la client, `ACK` de la server — apoi `FIN` de la server, `ACK` de la client. Sunt patru pachete.

:::tip De reținut
O conexiune TCP se desfășoară în trei faze: **stabilirea** cu **handshake în trei pași** (`SYN` → `SYN, ACK` → `ACK`), **transferul de date** (fiecare pachet de date este confirmat cu `ACK`) și **închiderea** (fiecare parte trimite `FIN` și primește un `ACK`).
:::

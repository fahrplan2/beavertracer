# Fără stare sau cu stare

O conexiune are întotdeauna **două sensuri**: PC-ul profesorului trimite o cerere către un server web de pe internet — iar serverul web trimite pagina web înapoi. Un firewall care funcționează după principiul listei albe (whitelist) trebuie deci să lase să treacă nu doar cererea, ci și **răspunsul**.

Pentru aceasta există două tipuri de filtre de pachete:

| | **Fără stare** (*stateless*) | **Cu stare** (*stateful*) |
|---|---|---|
| Mod de funcționare | verifică fiecare pachet separat, fără memorie | reține conexiunile permise într-un **tabel de stări** |
| Răspunsuri | necesită o regulă separată pentru sensul invers | sunt lăsate automat să treacă, deoarece aparțin unei conexiuni cunoscute |
| Utilizare | dispozitive simple, filtre foarte rapide | practic orice firewall de astăzi |

În următoarele două secțiuni vei vedea de ce filtrele fără stare au probleme cu răspunsurile — și cum le rezolvă un firewall cu stare.

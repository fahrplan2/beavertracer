# DHCP: automat în rețea

:::goal
**Obiectiv de învățare:** Poți explica cum primește un dispozitiv automat setările IP prin DHCP, poți configura un server DHCP și poți recunoaște și remedia erorile tipice DHCP (de ex. o adresă 169.254).
:::

:::sim
url=/sims/lesson-6.4.btsim
:::

Până acum ai introdus manual pentru fiecare dispozitiv adresa IP, masca de rețea, gateway-ul și serverul DNS. Într-o școală cu sute de laptopuri, tablete și telefoane acest lucru ar fi imposibil — iar fiecare greșeală de tastare ar fi o eroare în rețea.

Această muncă este preluată de **Dynamic Host Configuration Protocol** (**DHCP**): un **server DHCP** distribuie automat setările fiecărui dispozitiv care intră în rețea.

# Modelle anwende

Ordne die Protokolle aus dem Experiment vom Anfang des Kapitels ihrer OSI-Schicht zu:

:::quiz match
Ethernet -> Schicht 2 — Sicherung
IPv4 -> Schicht 3 — Vermittlung
TCP -> Schicht 4 — Transport
HTTP -> Schicht 7 — Anwendung
:::

:::evaluate
Zuordnung prüfe
:::

Un zum Schluss die Name vun de Dateneinheite:

:::quiz match
Frame -> Schicht 2 — Sicherung
Paket -> Schicht 3 — Vermittlung
Segment -> Schicht 4 — Transport
:::

:::evaluate
Zuordnung prüfe
:::

Damit hast du des Handwerkszeug, um Protokolle künftisch sauber einzuordne. Ab em näschste Kapitel gehe mer die Schichte der Reih nach dorsch — angefange mit Schicht 2 un de Frag, wie ein Switch eigentlich waaß, wohin er ein Paket weiterleite muss.

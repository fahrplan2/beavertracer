## Zwei Sorte Ports

**Ziel-Port — der Dienst:** E Server-Programm wart an eme feste Port uff Verbindunge — mer sagt, es **lauscht** dort. For bekannte Dienste sinn die Nummern weltweit festgelegt, die **Well-known Ports** (0 bis 1023). E Browser waaß deshalb ohne nachzufrage: Webserver lausche an Port 80.

**Quell-Port — der Absender:** Den Port uff der Client-Seit sucht sich des Betriebssystem for jede neue Verbindung selbst aus eme hohe Bereich aus (in BeaverTracer ab 49152). An dem erkennt der Client, zu welcher vun seine Verbindunge e Antwort gehört.

E Verbindung is also eindeutig durch vier Angabe bestimmt: **IP-Adresse und Port uff beide Seite**. Des Paar aus IP-Adresse und Port nennt mer **Socket**, z.B. `192.168.0.20:80`.

## E Blick uff den Server

Wechsel zurück in den :fa-play: **Laafe lasse**-Modus, mach uff em **Server** des :fa-terminal: **Terminal** uff und gib ei:

```
$ ss
```

`ss` zeigt alle Sockets vum Rechner. Zeile mit `LISTEN` sinn Programme, die an eme Port lausche. Zeile mit `ESTABLISHED` sinn bestehende Verbindunge — mit em eigene Socket (*Local Address:Port*) und em Socket vun der Gegenseit (*Peer Address:Port*).

:::quiz multi

- [x] 5000
- [ ] 49152
- [ ] 443
:::

:::quiz mc

- [ ] `192.168.0.20:80` mit `192.168.0.10:49152` — die Verbindung vum Browser
- [ ] Beide
:::

## Die wichtigste Well-known Ports

| Port | Protokoll | Dienst |
|---|---|---|
| 22 | SSH | sichere Fernwartung (verschlüsselte Kommandozeil) |
| 25 | SMTP | E-Mails verschicke |
| 53 | DNS | Namme in IP-Adresse übersetze (meist iwwer UDP) |
| 80 | HTTP | Webseite |
| 110 | POP3 | E-Mails abhole |
| 143 | IMAP | E-Mails uff em Server verwalte |
| 443 | HTTPS | verschlüsselte Webseite |

:::tip Merksatz
**Ports** (0 bis 65535) halte die Verbindunge uff eme Rechner auseinander. Server-Dienste **lausche** an feste **Well-known Ports** (z.B. HTTP 80, HTTPS 443), Clients krieje for jede Verbindung en freie hohe **Quell-Port**. E Verbindung is eindeutig durch **IP-Adresse und Port vun beide Seite** bestimmt.
:::

:::quiz match

53 -> DNS
80 -> HTTP
110 -> POP3
143 -> IMAP
443 -> HTTPS
:::

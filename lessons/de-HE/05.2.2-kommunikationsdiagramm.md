# Des Kommunikationsdiagramm

:::sim
url=/sims/lesson-5.1.btsim
:::

Den Ablauf vun re Verbindung zeichent mer als **Kommunikationsdiagramm**: Client un Server kriege jeweils e senkrechte Linie, die Zeit läuft vun owwe noch unne. Jeder Pfeil is e Paket. Er is schräg gezeichnet, weil jedes Paket e bissje unnerwegs is.

So sieht deine Verbindung vun de letzte Seit aus — vergleich se Zeil für Zeil mit'm Trace:

:::seq
Client-PC -> Server: SYN
Server -> Client-PC: SYN, ACK
Client-PC -> Server: ACK
Client-PC -> Server: PSH, ACK "Hello World" len=13
Server -> Client-PC: ACK
Server -> Client-PC: PSH, ACK len=13
Client-PC -> Server: ACK
Client-PC -> Server: FIN, ACK
Server -> Client-PC: ACK
Server -> Client-PC: FIN, ACK
Client-PC -> Server: ACK
:::

Iwwer jedem Pfeil stehe die **Flags**, drunner die Nummern `SEQ` un `ACK`. **DATA** markiert Pakete mit Nutzdate. Die rote Zahle gehöre zum Client, die blaue zum Server — was se bedeute, klärt die nächst Seit.

## Die Flags

| Flag | steht für | Bedeutung |
|---|---|---|
| **SYN** | *synchronize* | Verbindung uffbaue, Startnummer festlege |
| **ACK** | *acknowledge* | bestätigt empfangene Date |
| **PSH** | *push* | Date sofort an des Programm weitergewwe |
| **FIN** | *finish* | „Isch bin fertisch“ — Verbindung abbaue |
| **RST** | *reset* | Verbindung abbreche odder ablehne (dazu mehr in 5.3.2) |

## Drei Phase

**Uffbau:** Der Client schickt `SYN`, der Server antwortet mit `SYN, ACK`, der Client bestätigt mit `ACK`. Weil genau drei Pakete nötisch sin, haast des **Drei-Wege-Handshake**.

**Date:** Jedes Paket mit Date werd vum Empfänger mit eme `ACK` bestätigt. Hier schickt der Server des Echo zurück — aach des bestätigt der Client.

**Abbau:** Jede Seit beendet ihr Senderichtung einzeln: `FIN` vum Client, `ACK` vum Server — dann `FIN` vum Server, `ACK` vum Client. Des sin vier Pakete.

:::tip Merksatz
E TCP-Verbindung läuft in drei Phase ab: **Uffbau** mit'm **Drei-Wege-Handshake** (`SYN` → `SYN, ACK` → `ACK`), **Datenübertragung** (jedes Datepaket werd mit `ACK` bestätigt) un **Abbau** (jede Seit schickt `FIN` un kriegt e `ACK`).
:::

# HTTP un HTTPS im Vergleisch

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Der Webserver **www.beaver-schule.de** bietet des Notenportal vun de Schul sowohl iwwer HTTP als aach iwwer HTTPS aa. Was sieht aaner, där mithorscht?

## Des Experiment

1. Wechsel in de :fa-play: **Ausführen**-Modus un ruf uff em **Client-PC** im :fa-globe: **Browser** erscht `http://www.beaver-schule.de/` uff, hinnerher `https://www.beaver-schule.de/`.
2. Mach im :fa-magnifying-glass: **Hinnerherschleiche**-Modus en Trace uff fer de **Client-PC**.
3. Suchemol erscht des Paket `HTTP/1.1 200 OK` un klick druff. Unne in de Details findst du de Inhalt vun de Seit.

:::quiz mc
Was kann aaner, där mithorscht, bei **HTTP** sehe?
- [x] Die komplett Webseit, aach Annas Note
- [ ] Nur die Adress vum Server
- [ ] Nix, weil HTTP iwwer TCP laaft
:::

:::quiz short
Welche Note hat Anna in Mathematik?
= 2
:::

:::evaluate
Antworte prüfe
:::

Jetzt kimmt de HTTPS-Daal. Suchemol des `[SYN]`-Paket, mit dem de Client die zweit Verbindung aafangt.

:::quiz short
Welche Zielport hat die HTTPS-Verbindung (Spalt **Info**, `… → ???`)?
= 443
:::

Gib jetzt owwe im Filterfeld vum Trace `tls` ei — dann siehst du nur noch die TLS-Pakete.

:::quiz mc
Was steht in de Spalt **Info** bei de Pakete, die die Webseit enthalte?
- [ ] `HTTP/1.1 200 OK`
- [x] `Application Data`
- [ ] `Encrypted HTML`
:::

:::quiz multi
Was kann aaner, där mithorscht, bei **HTTPS** trotzdem noch sehe?
- [x] Die IP-Adresse vun Client un Server
- [x] Dass Port 443 benutzt werd, also wahrscheinlisch HTTPS
- [x] Wie viel Date ungefähr iwwertrage werre
- [ ] Welche Seit aufgerufe wurd un was druff steht
:::

:::evaluate
Antworte prüfe
:::

:::note
Klick emol uff e **Application Data**-Paket: Die Nutzdate sin nur e Folg vun scheinbar zufällische Bytes. Der Tracer kann se net entschlüssele — er kennt de Sitzungsschlüssel genauso wenisch wie e Angreifer.
:::

:::tip Merksatz
Bei **HTTP** kann jeder, der mithorscht, die komplett Webseit lese. Bei **HTTPS** sieht er nur noch, **wer mit wem** schwätzt (IP-Adresse, Port 443) un **wie viel** — der Inhalt steckt verschlüsselt in **Application Data**-Pakete.
:::

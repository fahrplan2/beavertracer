# Wie DNS organisiert is

:::sim
url=/sims/lesson-6.2.btsim
:::

Kein einzelner Server kann alle Name von de ganze Welt kenne. DNS is deshalb **hierarchisch** uffgebaut — genauso wie die Name selbst. Mer liest se von rechts noch links:

```
www . beaver-schule . de . (Root)
 │          │         │      └─ Root-Server: kennen die Server aller Top-Level-Domains
 │          │         └─ Top-Level-Domain (TLD): der de-Server kennt alle .de-Domains
 │          └─ Domain: der Schul-DNS ist für beaver-schule.de zuständig
 └─ Rechnername innerhalb der Domain
```

Der Server, der für e Domain zuständig is un die Antwort wirklisch kennt, haaßt **autoritativ**. De Weg dorthin iwwernimmt for de PC en **Resolver** — hier der Rechner **DNS-Resolver**.

## Des Experiment

1. Wechsel in de :fa-play: **Ausführen**-Modus un gib uff dem **Client-PC** im :fa-terminal: **Terminal** ei:
   ```
   $ nslookup www.beaver-schule.de
   ```
2. Mach im :fa-magnifying-glass: **Verfolgung**-Modus en Trace uff for de **DNS-Resolver**.

Der Resolver hat for disch e ganze Reihe von Anfrage gestellt. Ordne zu, wer welche Antwort gegeb hat:

:::quiz match
Root-Server (192.168.0.101) -> Verweis: Für .de ist ns.nic.de zuständig
de-Server (192.168.0.102) -> Verweis: Für beaver-schule.de ist ns.beaver-schule.de zuständig
Schul-DNS (192.168.0.103) -> Antwort: www.beaver-schule.de hat die Adresse 192.168.0.20
:::

:::quiz mc
Wen fragt der Resolver als Erstes?
- [x] Den Root-Server
- [ ] Den Schul-DNS
- [ ] Den Client-PC
:::

:::evaluate
Antworte prüfe
:::

:::note
Zwischedurch fragt der Resolver aach noch de Adresse von de Server, uff die er verwiese worde is (`A ns.nic.de`). Echte DNS-Server schicke die Adresse meistens gleich mit. Außerdem merke sich Resolver jede Antwort e Weil lang (**Cache**) — die nächste Anfrage nach demselbe Name beantworte se sofort selbst. Wie lang, steht im Eintrag als **TTL** (*Time to Live*) in Sekunde.
:::

## Die wichtigste Eintragstypen

| Typ | Bedeutung | Beispiel |
|---|---|---|
| **A** | Name → IPv4-Adresse | `www.beaver-schule.de` → `192.168.0.20` |
| **AAAA** | Name → IPv6-Adresse | `www.beaver-schule.de` → `2001:db8::20` |
| **CNAME** | Name → annerer Name (Alias) | `web.beaver-schule.de` → `www.beaver-schule.de` |
| **MX** | zuständiger Mailserver vun ere Domain | `beaver-schule.de` → `mail.beaver-schule.de` |
| **NS** | zuständiger DNS-Server vun ere Domain | `beaver-schule.de` → `ns.beaver-schule.de` |

:::tip Merksatz
DNS is **hierarchisch**: **Root-Server** verweise uff die Server von de **Top-Level-Domains** (z.B. `.de`), die uff die Server von de einzelne **Domains**. Der zuständige **autoritative** Server kennt die Antwort. En **Resolver** geht dene Weg for de PC un merkt sich die Antworte (**Cache**). Wichtige Eintragstypen: **A**, **AAAA**, **CNAME**, **MX**, **NS**.
:::

## En Eintrag anlege

Die Schul will, dass ihr Webseite zusätzlich unner `intranet.beaver-schule.de` erreichbar is.

1. Klick im :fa-play: **Ausführen**-Modus uff de **Schul-DNS** un mach die App **DNS-Server** uff.
2. Mach de Reiter **A** uff. Klick uff **+** un trag in die neu Zeil de Name `intranet.beaver-schule.de` un die Adresse `192.168.0.20` ei.

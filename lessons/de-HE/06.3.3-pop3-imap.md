# POP3 oder IMAP?

:::sim
url=/sims/lesson-6.3.btsim
:::

Zum Abholle gibt's zwei Protokolle. In dere Simulation verwendet **Anna POP3** un **Ben IMAP**.

## Des Experiment

1. Schick im :fa-play: **Ausführen**-Modus ei Mail vun **Ben** an `anna@beaver-schule.de`.
2. Klick bei **Anna** in der App **E-Mail** uff **Abrufen**.
3. Mach Traces uff, fer **Anna** un fer **Ben**, un vergleich die Befehle beim Abholle.

:::quiz match
USER / PASS -> POP3: Anmelde mit Benutzername un Passwort in zwei Schritt
RETR -> POP3: ei Nachricht runnerlade
LOGIN -> IMAP: Anmelde mit Benutzername un Passwort
SELECT INBOX -> IMAP: en Ordner uff em Server uffmache
:::

:::evaluate
Zuordnung prüfe
:::

## Der Unnerschied

| | POP3 | IMAP |
|---|---|---|
| Port | 110 | 143 |
| Grundidee | Mails **runnerlade** — hinnerher meistens uff em Server lösche | Mails **bleiwe uff em Server** un werre dort verwaltet |
| Ordner, gelese/ungelese | nur uff em eigene Gerät | uff em Server — iwwerall gleich |
| Mehrere Geräte (Handy, Laptop) | unpraktisch: Jedes Gerät hat en annern Stand | ideal: alle Geräte sehn des selbe Postfach |

:::note
Des E-Mail-Programm in BeaverTracer losst die Mails aach bei POP3 uff em Server liege. Echte Programme lösche se nach em Runnerlade oft — odder losse se nur e Weilsche liege.
:::

:::quiz mc
Lena liest ihre Mails uff em Handy, em Tablet un em Schul-Laptop. Was sollt se verwende?
- [ ] POP3, weil's einfacher is
- [x] IMAP, weil alle Geräte des selbe Postfach uff em Server sehn
- [ ] SMTP, weil's zum Abholle gedacht is
:::

:::evaluate
Antwort prüfe
:::

:::tip Merksatz
**POP3** lädt Mails vum Server uff **ei** Gerät runner. **IMAP** verwaltet des Postfach **uff em Server** — mit Ordner un Gelese-Status fer alle Geräte gleichzeitig. Beide dienen nur zum **Abholle**; verschickt werd immer mit **SMTP**, gell?
:::

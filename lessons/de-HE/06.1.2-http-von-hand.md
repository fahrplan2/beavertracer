# HTTP vun Hand

:::sim
url=/sims/lesson-6.1.btsim
:::

Wenn HTTP reiner Text is — kann mer dann aach selbst mit eme Webserver babbele, ganz ohne Browser? Ja: Mit `telnet` baust du eine TCP-Verbindung zu eme beliebische Port uff und tippst den Text selbst.

## Des Experiment

1. Wechsel in den :fa-play: **Laafe lasse**-Modus un mach uff em **Client-PC** des :fa-terminal: **Terminal** uff.
2. Verbinn disch mit Port 80 vom Server:
   ```
   $ telnet 192.168.0.20 80
   ```
3. Tipp die Anfrage Zeile fer Zeile — un schließ se mit einer **leere Zeile** ab (einfach noch emol **Enter**):
   ```
   GET /kontakt.html HTTP/1.1
   Host: 192.168.0.20

   ```

Der Server antwortet mit Statuszeile, Headern un der Kontaktseite — als Text, genau so wie der Browser se aach kriggt.

:::quiz mc
Woran erkennt der Server, dass deine Anfrage zu Ende is?
- [ ] An eme besondere Befehl `END`
- [x] An der leere Zeile
- [ ] Nach ener bestimmte Zeit
:::

:::quiz short
Welcher Wert steht in der Antwort beim Header `Content-Type`? (nur der erste Teil vor em `;`)
= text/html
:::

## Fehler provoziere

Ebbes Bequemeres is `curl`: Des stellt die Anfrage fer disch. Mit `-v` (*verbose*, ausführlich) zeigt es dabei alles, was hin- un hergeht — Zeile mit `>` hat `curl` gesendet, Zeile mit `<` sin vom Server komme.

Probier's emol aus:

```
$ curl -v http://192.168.0.20/gibtsnicht.html
$ curl -X POST -d name=Anna http://192.168.0.20/
```

:::quiz short
Welche Statuscode kriggst du fer `/gibtsnicht.html`?
= 404
:::

:::quiz short
Un welche fer die Anfrage mit der Methode `POST`?
= 405
:::

:::evaluate
Antworte prüfe
:::

:::note
Der Webserver in BeaverTracer kann nur Dateie ausliefern — deshalb erlaubt er nur `GET` un `HEAD`. Echte Webserver nemme mit `POST` zum Beispiel Formulare entgege un reiche die Date an e Programm weiter.
:::

:::tip Merksatz
Viele Protokolle der Anwendungsschicht sin **textbasiert** — HTTP, aber aach SMTP, POP3 un IMAP. Mer kann se deshalb mit `telnet` vun Hand babbele un im Tracer mitlese. Des is praktisch zur Fehlersuche — aber aach e Sicherheitsproblem: Jeder, der mitschneidet, kann alles lese. Wie Verschlüsselung (HTTPS) helft, lernst du in Kapitel 8, gell?
:::

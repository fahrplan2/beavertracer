# Es Zertifikat agucke

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Uff de Arbeitsfläche siehste de **Client-PC**, e'n **DNS-Server** unn de Webserver vun de Schul, `www.beaver-schule.de`. De Webserver bietet seine Seite aach iwwer **HTTPS** aa.

## Es Schloss im Browser

1. Wechsel in de :fa-play: **Ausführen**-Modus, klick uff de **Client-PC** unn mach de :fa-globe: **Browser** uff.
2. Ruf `https://www.beaver-schule.de/` uff — gib Acht uff es **https**.
3. Links newwer de Adress erscheint e **Schloss**. Klick driwwer.

= www.beaver-schule.de
:::

:::quiz short
Wer hat das Zertifikat ausgestellt (Aussteller ohne `CN=`)?
= Biber Root CA
:::

## Worum vertraut de Client-PC dem Zertifikat?

Mach uff dem **Client-PC** die :fa-shield-halved: **Zertifikatverwaltung** uff unn wechsel in de Reiter **Vertrauenswürdige CAs**.

:::quiz mc
Was findste do?
- [x] Es Zertifikat vun de **Biber Root CA**
- [ ] Es Zertifikat vun `www.beaver-schule.de`
- [ ] Kaa Einträsch
:::

:::quiz mc
Woran sieht mer, dass die Biber Root CA e Root-CA is?
- [x] Se is **selbstsigniert**: Betreff unn Aussteller sinn gleich
- [ ] Ihr Name hört uff „CA“ uff
- [ ] Se hat kaan öffentliche Schlüssel
:::

:::quiz mc
Steht beim Client-PC unner **Privater Schlüssel** „Ja“ odder „Nein“?
- [ ] Ja — de Client braucht de private Schlüssel vun de CA, um Signature zu prüfe
- [x] Nein — zum Prüfe reicht de öffentliche Schlüssel; de private Schlüssel hat nur die CA
:::

## Die Gegeseit: de Webserver

Mach jetzt uff dem Webserver **www.beaver-schule.de** die :fa-shield-halved: **Zertifikatverwaltung** uff (Reiter **Meine Zertifikate**) unn guck der sei Zertifikat aa.

:::quiz multi
Was stimmt für es Zertifikat uff dem Webserver?
- [x] Unner **Privater Schlüssel** steht „Ja“ — de Server braucht en für de Verbindungsaufbau
- [x] Die **Kette** lautet `www.beaver-schule.de ← Biber Root CA`
- [x] Der **Fingerabdruck** is derselbe wie im Schloss-Fenster vum Browser
- [ ] Es is selbstsigniert
:::

:::evaluate
Antworte prüfe
:::

:::note
Der **Fingerabdruck** is e Hashwert iwwer es Zertifikat. Damit kann mer zwaa Zertifikate schnell vergleiche — ganz ohne alle Felder oans nach em annern zu prüfe.
:::

:::tip Merksatz
De **Webserver** hat sei Zertifikat **mit privatem Schlüssel**. De **Client** kennt nur es **Zertifikat vun de Root-CA** (ohne privaten Schlüssel) — des reicht ihm, um die Signatur uff dem Server-Zertifikat zu prüfe. Klickste im Browser uff es **Schloss**, siehste Betreff, Aussteller, Fingerabdruck unn Gültischkeit.
:::

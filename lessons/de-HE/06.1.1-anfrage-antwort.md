E Webseit besteht also oft aus vielle Dateie: Text, Stylesheets, Bilder. Für jede schickt der Browser e eigene Anfrag.

## Wie e Anfrag aussieht

Klick im Trace uff des Paket `GET / HTTP/1.1` un klapp **Hypertext Transfer Protocol** uff. E HTTP-Anfrag is reiner Text:

```
GET / HTTP/1.1              ← Methode, Pfad, Version
Host: 192.168.0.20          ← Header: zusätzliche Angaben
…
                            ← Leerzeile: Ende der Anfrage
```

Die Antwort vom Server is genauso uffgebaut — mit ere Statuszeil, Headern, ere Leerzeil un danoh de eigentliche Datei:

```
HTTP/1.1 200 OK             ← Version, Statuscode, Text
Content-Type: text/html     ← Header: Art der Datei
Content-Length: 301         ← Header: Größe in Byte
                            ← Leerzeile
<!doctype html> …           ← die Datei selbst
```

:::seq
mode: text
Client-PC -> Server: GET / | HTTP-Anfrage
Server -> Client-PC: 200 OK | index.html
Client-PC -> Server: GET /style.css | HTTP-Anfrage
Server -> Client-PC: 200 OK | style.css
:::

## Methode un Statuscodes

Die **Methode** sacht, was der Client will:

| Methode | Bedeutung |
|---|---|
| **GET** | e Datei abrufe |
| **POST** | Date an de Server schicke, z.B. e ausgefüllts Formular |
| **HEAD** | nur die Header abrufe, ohne die Datei |

Der **Statuscode** sacht, wie's gelaufe is. Die erscht Ziffer verrät die Art vun de Antwort:

| Code | Text | Bedeutung |
|---|---|---|
| **200** | OK | alles in Ordnung |
| **301** | Moved Permanently | die Seit is dauerhaft umgezoge |
| **404** | Not Found | die Datei gibt's net |
| **405** | Method Not Allowed | die Methode is hier net erlaubt |
| **500** | Internal Server Error | Fehler uff em Server |

`2xx` haast Erfolg, `3xx` Umleitung, `4xx` e Fehler vom Client (falsche Anfrag), `5xx` e Fehler vom Server.

:::tip Merksatz
**HTTP** arbeitet noh dem **Anfrag-Antwort-Prinzip**: Der Client schickt e **Anfrag** (Methode wie `GET`, Pfad, Header), der Server antwortet mit eme **Statuscode** (z.B. `200 OK`, `404 Not Found`), Headern un de Datei. Für jede Datei vun ere Webseit gibt's e eigene Anfrag.
:::

:::

# Endereços IP e máscara de rede

:::goal
**Objetivo de aprendizagem:** Consegues converter números entre o sistema decimal e o sistema binário, determinar a parte de rede e a parte de anfitrião de um endereço IP com a máscara de rede e calcular o endereço de rede, o endereço de broadcast, bem como o número de hosts de uma rede.
:::

:::sim
empty
:::

Se um endereço pertence à própria rede, um PC não o decide com números decimais como `192.168.0.10`, mas bit a bit. Para conseguires perceber isto, precisas do **sistema binário** — é aqui que esta secção começa.

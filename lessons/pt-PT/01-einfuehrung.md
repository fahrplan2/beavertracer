# Introdução ao BeaverTracer

O BeaverTracer é uma simulação com a qual podes montar redes por ti próprio, colocá-las em funcionamento e acompanhar o respetivo tráfego pacote a pacote — sem hardware real.

Neste primeiro capítulo ficas a conhecer a própria ferramenta: a interface, os três modos de trabalho, e constróis a tua primeira pequena simulação. No final, acedes a uma página web e vês quanto acontece, de facto, em segundo plano — o ponto de partida para tudo o que vem a seguir.

:::note
Os capítulos são sequenciais. Dedica tempo a este primeiro capítulo — saber utilizar a ferramenta é a base para tudo o resto.
:::

## Dois tipos de portas

**Porta de destino — o serviço:** um programa servidor aguarda ligações numa porta fixa — diz-se que **escuta** nessa porta. Para os serviços conhecidos, os números estão definidos a nível mundial: são as **well-known ports** (0 a 1023). Por isso, um navegador sabe, sem perguntar, que os servidores Web escutam na porta 80.

**Porta de origem — o remetente:** a porta do lado do cliente é escolhida pelo sistema operativo, para cada nova ligação, a partir de um intervalo alto (no BeaverTracer, a partir de 49152). É por ela que o cliente reconhece a que ligação sua pertence uma resposta.

Uma ligação fica assim determinada de forma inequívoca por quatro dados: **endereço IP e porta de ambos os lados**. O par formado por endereço IP e porta chama-se **socket**, p. ex. `192.168.0.20:80`.

## Uma olhadela ao servidor

Volta ao modo de execução :fa-play: **Executar**, abre o :fa-terminal: **Terminal** no **Server** e escreve:

```
$ ss
```

O `ss` mostra todos os sockets do computador. As linhas com `LISTEN` são programas que escutam numa porta. As linhas com `ESTABLISHED` são ligações existentes — com o socket próprio (*Local Address:Port*) e o socket da outra parte (*Peer Address:Port*).

:::

O `ss` ainda a mostra por pouco tempo como `TIME-WAIT`: o servidor espera algum tempo para ver se ainda chegam pacotes atrasados dessa ligação. ## As well-known ports mais importantes

| Porta | Protocolo | Serviço |
|---|---|---|
| 22 | SSH | acesso remoto seguro (linha de comandos cifrada) |
| 25 | SMTP | envio de e-mails |
| 53 | DNS | tradução de nomes em endereços IP (normalmente através de UDP) |
| 80 | HTTP | páginas Web |
| 110 | POP3 | obtenção de e-mails |
| 143 | IMAP | gestão de e-mails no servidor |
| 443 | HTTPS | páginas Web cifradas |

:::tip Ponto-chave
As **portas** (0 a 65535) distinguem as ligações num computador. Os serviços de servidor **escutam** em **well-known ports** fixas (p. ex. HTTP 80, HTTPS 443); os clientes recebem, para cada ligação, uma **porta de origem** alta e livre. Uma ligação fica determinada de forma inequívoca pelo **endereço IP e pela porta de ambos os lados**.
:::

:::quiz match
22 -> SSH
25 -> SMTP
53 -> DNS
80 -> HTTP
110 -> POP3
143 -> IMAP
443 -> HTTPS
:::

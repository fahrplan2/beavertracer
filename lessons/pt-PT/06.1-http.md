# HTTP: páginas web

:::goal
**Objetivo de aprendizagem:** Consegues descrever a estrutura de um pedido e de uma resposta HTTP, explicar os métodos e os códigos de estado mais importantes e fazer tu próprio um pedido HTTP manualmente.
:::

O **Hypertext Transfer Protocol** (**HTTP**) é a linguagem em que os navegadores e os servidores web comunicam entre si. No servidor encontra-se a página web da **Beaver-Schule**: uma página inicial, uma página de contacto e uma folha de estilos para o aspeto visual.

# HTTP à mão

:::sim

:::

Se o HTTP é texto simples — também se pode falar diretamente com um servidor web, sem qualquer navegador? Sim: com `telnet` estabeleces uma ligação TCP a qualquer porta e escreves tu próprio o texto.

## A experiência

1. Muda para o modo de execução :fa-play: **Executar** e abre o :fa-terminal: **Terminal** no **Client-PC**.
2. Liga-te à porta 80 do servidor:
   ```
   $ telnet 192.168.0.20 80
   ```
3. Escreve o pedido linha a linha — e termina-o com uma **linha vazia** (basta premir **Enter** mais uma vez):
   ```
   GET /kontakt.html HTTP/1.1
   Host: 192.168.0.20

   ```

O servidor responde com a linha de estado, os cabeçalhos e a página de contacto — como texto, tal como o navegador também a recebe.

:::quiz mc
Como é que o servidor reconhece que o teu pedido terminou?
- [ ] Por um comando especial `END`
- [x] Pela linha vazia
- [ ] Após um determinado tempo
:::

:::quiz short
Que valor aparece na resposta no cabeçalho `Content-Type`? (apenas a primeira parte antes do `;`)
= text/html
:::

## Provocar erros

Uma ferramenta mais cómoda é o `curl`: faz o pedido por ti. Com `-v` (*verbose*, detalhado) mostra tudo o que vai e vem — as linhas com `>` foram enviadas pelo `curl`, as linhas com `<` vieram do servidor.

Experimenta:

```
$ curl -v http://192.168.0.20/gibtsnicht.html
$ curl -X POST -d name=Anna http://192.168.0.20/
```

:::quiz short
Que código de estado obténs para `/gibtsnicht.html`?
= 404
:::

:::quiz short
E qual obténs para o pedido com o método `POST`?
= 405
:::

:::evaluate
Verificar respostas
:::

:::note
O servidor web do BeaverTracer só consegue fornecer ficheiros — por isso só permite `GET` e `HEAD`. Os servidores web reais aceitam, por exemplo, formulários com `POST` e passam os dados a um programa.
:::

:::tip Ponto-chave
Muitos protocolos da camada de aplicação são **baseados em texto** — o HTTP, mas também o SMTP, o POP3 e o IMAP. Por isso, podes falar com eles à mão com `telnet` e lê-los no Tracer. Isto é prático para a deteção e resolução de problemas — mas é também um problema de segurança: quem captura o tráfego consegue ler tudo. Como a cifragem (HTTPS) ajuda, aprenderás no capítulo 8.
:::

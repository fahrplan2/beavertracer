# A firewall com estado

:::sim
url=/sims/lesson-9.2.btsim
:::

Uma firewall **com estado** (*stateful*) memoriza cada ligação que permitiu uma vez numa **tabela de estados**: protocolo, ambos os endereços e ambos os portos. Se chegar um pacote que corresponda a uma entrada — independentemente do sentido —, deixa-o passar sem mais verificações. As novas ligações, pelo contrário, têm de passar pelas regras.

## Observar

1. Na **Firewall**, define o **Modo** como **Stateful**.
2. No **PC Professor**, no :fa-globe: **Navegador**, acede novamente a `http://203.0.113.80/`.
3. Abre imediatamente na firewall o separador **Zustände**.

:::quiz mc
O que acontece agora?
- [x] A página carrega e, em **Zustände**, aparece a ligação do PC do professor para `203.0.113.80:80`
- [ ] A página não carrega, porque as respostas continuam sem regra
:::

:::quiz short
Que porto aparece na tabela de estados em **Ziel**?
= 80
:::

:::evaluate
Verificar respostas
:::

As entradas em **Zustände** desaparecem passado algum tempo (coluna **Timeout**) se deixar de haver tráfego na ligação.

## Tarefa: a firewall da escola

Configura agora a firewall como uma escola real precisa:

- **A partir da rede da escola** é permitido tudo para a Internet (sentido B → A, qualquer protocolo).
- **A partir da Internet** só são acessíveis a Web (80) e a receção de correio (25) do servidor da escola.
- Todo o resto é **descartado**, e o modo é **Stateful**.

:::task
title: Firewall da escola configurada?
Verifica se a rede da escola consegue aceder à Internet, se a partir do exterior só a Web e o correio do servidor da escola estão acessíveis e se o PC do professor é inacessível a partir do exterior.
check: tcpOpen(8, "203.0.113.80", 80)
check: tcpOpen(1, "198.51.100.10", 80)
check: tcpOpen(1, "198.51.100.10", 25)
check: tcpFails(1, "198.51.100.10", 22)
check: pingFails(1, 8)
:::

:::quiz mc
O PC do professor faz ping a `203.0.113.80`. As respostas voltam?
- [x] Sim — o ping foi permitido de B → A e a resposta pertence a este estado
- [ ] Não — não existe nenhuma regra para ICMP vindo do exterior
:::

:::evaluate
Verificar resposta
:::

:::tip Ponto-chave
Uma **firewall com estado** regista cada ligação permitida numa **tabela de estados** e deixa passar todos os pacotes dessa ligação nos **dois sentidos**. Assim, bastam regras para o **estabelecimento de ligação**: «O interior pode aceder ao exterior» e «do exterior apenas para determinados serviços». As ligações iniciadas no exterior para a rede da escola continuam bloqueadas.
:::

# Configurar HTTPS

:::sim
url=/sims/lesson-8.3.3.btsim
:::

Aqui continuamos do ponto onde a secção 8.2.2 terminou: no servidor web **www.beaver-schule.de** estão a **Schul-CA** e um certificado de servidor emitido por ela, e o **Client-PC** confia na Schul-CA. Só que o servidor web ainda não fala HTTPS.

## Antes

Muda para o modo de execução (:fa-play: **Executar**) e, no **Client-PC**, abre no :fa-globe: **Navegador** o endereço `https://www.beaver-schule.de/`.

- [x] A ligação não é estabelecida — nenhum serviço escuta na porta 443
- [ ] O navegador avisa que o certificado não é seguro
- [ ] A página é apresentada sem cadeado
:::

:::evaluate
Verificar resposta
:::

## Ativar o HTTPS

1. No servidor web, abre o **Servidor HTTP** e clica em **Parar** — enquanto o servidor estiver a funcionar, não é possível alterar as definições.
2. Muda para o separador **HTTPS**:
    - Assinala **Ativar HTTPS** e define **Porta HTTPS** como `443`
    - Em **Certificado**, seleciona o certificado de servidor `www.beaver-schule.de` — não a Schul-CA!
    - Clica em **Utilizar**
3. Clica em **Iniciar**.

Abre a página novamente no Client-PC através de `https://`. Clica no cadeado e verifica o emissor e a validade.

:::note
Para sites públicos, é necessário um certificado de uma CA que esteja pré-instalada em todos os navegadores. Desde 2015 existe a **Let's Encrypt**, uma CA que emite estes certificados de forma gratuita e automática — uma das principais razões pelas quais hoje quase todos os sites utilizam HTTPS.
:::

:::tip Ponto-chave
Para **HTTPS**, o servidor web precisa de um **certificado de servidor com chave privada**, cujo nome corresponda ao endereço, e tem de escutar na **porta 443**. O cliente só confia no site se conhecer a **CA** emissora.
:::

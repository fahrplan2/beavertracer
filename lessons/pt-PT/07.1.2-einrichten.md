# Configurar o router doméstico

:::sim
url=/sims/lesson-7.1.2.btsim
:::

Acabou de ser ligado um novo router doméstico — mas ainda ninguém consegue aceder à Internet. Recebeste do fornecedor uma carta com os **dados de acesso**:

| Dados de acesso | Valor |
|---|---|
| Endereço IP WAN | `203.0.113.2` |
| Comprimento do prefixo | `/30` |
| Gateway (router do fornecedor) | `203.0.113.1` |
| Servidor DNS do fornecedor | `198.51.100.10` |

1. Muda para o :fa-play: modo de execução (**Executar**), clica no **Heimrouter** e abre o separador **WAN**.
2. Introduz os dados de acesso e clica em **Aplicar**.
3. Liga o **Tablet** ao Wi-Fi: :fa-gear: **Definições de IP**, separador **WiFi**, SSID `Biberbau`, **Aplicar**.
4. Testa no PC com `ping 192.0.2.80` ou no **Navegador** com `http://www.beispiel.de/`.

:::note
Na prática, o router doméstico costuma obter o seu endereço WAN automaticamente do fornecedor (por DHCP ou através de um início de sessão com nome de utilizador e palavra-passe). Dados de acesso fixos, como aqui, são mais comuns em ligações empresariais.
:::

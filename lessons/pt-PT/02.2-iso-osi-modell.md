# O modelo de referência ISO/OSI

O modelo ISO/OSI divide a comunicação entre dois dispositivos em sete camadas. Cada camada tem uma função claramente delimitada e utiliza apenas os serviços da camada imediatamente abaixo:

<tr class="osi-l6"><td>6</td><td>Apresentação</td><td>Formato dos dados, cifragem</td><td>JPEG, ASCII, MIME</td></tr>

Da experiência na página anterior, já conheces quatro destas camadas: Ethernet (2), IPv4 (3), TCP (4) e HTTP (7). Estes são exatamente os números e as cores que o Tracer te mostra na árvore de protocolos.

:::tip Regra mnemónica
Da camada 7 para baixo: **A**s **A**ndorinhas **S**ó **T**ransportam **R**amos **L**eves **F**inos — **A**plicação, **A**presentação, **S**essão, **T**ransporte, **R**ede, **L**igação de dados, **F**ísica.
:::

:::note Casos-limite
Nem todos os protocolos se encaixam exatamente numa só camada. Por isso, o Tracer mostra várias camadas para estes protocolos:

- **ARP** — camada 2/3: não tem cabeçalho IP, mas liga endereços IP (camada 3) a endereços de hardware (camada 2).
- **TLS** — camada 4/5: assenta diretamente sobre o TCP e gere uma sessão protegida.
- **HTTPS** (HTTP dentro de TLS) — camadas 5–7: a clássica camada de aplicação do modelo TCP/IP, que vais conhecer na próxima página.
:::

:::note
A camada 1 descreve a transmissão propriamente dita dos sinais no cabo ou por via rádio. O BeaverTracer não simula este nível — os cabos são sempre considerados ligados sem erros, não há problemas de sinal nem colisões. No Tracer, a análise começa, por isso, na prática na camada 2.
:::

## Abrir camada a camada

Clica no pequeno triângulo antes de **Ethernet**, **Internet Protocol Version 4**, **Transmission Control Protocol** e **Hypertext Transfer Protocol**. Cada camada traz as suas próprias informações:

| Camada na árvore | O que encontras nela | Para quê |
|---|---|---|
| Ethernet | `Source` e `Destination`: endereços MAC como `aa:57:28:…` | que placa de rede na rede local |
| IPv4 | `Source Address` `192.168.0.10`, `Destination Address` `192.168.0.20` | que computador — mesmo além dos limites da rede |
| TCP | `Source Port` `49152`, `Destination Port` `80` | que programa no computador |
| HTTP | `GET / HTTP/1.1`, `Host: 192.168.0.20` | a mensagem propriamente dita do navegador |

Observa também estas duas linhas: em Ethernet aparece `Type: IPv4` e em IPv4 aparece `Protocol: TCP`. Assim, cada camada revela *o que contém* — desta forma, o destinatário sabe como deve continuar a desembrulhar.

## Um envelope dentro de um envelope

O que acabaste de ver é criado no remetente da seguinte forma:

1. O navegador escreve a mensagem propriamente dita: `GET / HTTP/1.1` (**HTTP**).
2. O **TCP** encapsula-a e coloca as portas à frente — para que chegue ao programa certo.
3. O **IP** encapsula o conjunto e coloca os endereços IP à frente — para que chegue ao computador certo.
4. A **Ethernet** coloca tudo numa trama com os endereços MAC — para que chegue, na rede local, à placa de rede certa.

No destinatário, o processo é exatamente o inverso: cada camada retira a sua parte e passa o resto para cima. É como uma carta metida em vários envelopes — dentro, a mensagem; por fora, em cada envelope, o endereço para quem o vai abrir a seguir.

:::tip Ponto-chave
Cada camada coloca as suas próprias informações de controlo — o **cabeçalho** (*header*) — à frente dos dados da camada superior. Este embrulhar e desembrulhar chama-se **encapsulamento**.
:::

Consoante a camada, o «pacotinho» tem um nome próprio:

| Camada | Protocolo no exemplo | Nome da unidade de dados |
|---|---|---|
| Camada 2 | Ethernet | **Frame** (trama) |
| Camada 3 | IPv4 | **Pacote** |
| Camada 4 | TCP | **Segmento** |

:::note
No dia a dia — e também neste curso — diz-se muitas vezes simplesmente «pacote», independentemente da camada. Quando for importante ser rigoroso, usa os nomes da tabela.
:::

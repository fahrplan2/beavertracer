# Uma ligação do princípio ao fim

:::sim
url=/sims/lesson-5.1.btsim
:::

No **Server** corre o serviço de eco na porta `5000`: devolve imediatamente cada mensagem que recebe. Com o **Cliente TCP Simples** podes controlar uma ligação passo a passo — cada botão é uma fase.

## A experiência

1. Muda para o modo de execução :fa-play: **Executar**, clica no **Client-PC** e abre o **Cliente TCP Simples**.
2. Em **Host** introduz `192.168.0.20` e em **Port** introduz `5000`.
3. Clica em **Ligar**.
4. Escreve `Hello World` no campo de mensagem e clica em **Enviar**. Na janela de chat vês logo a seguir o eco do servidor.
5. Clica em **Desligar**.
6. Muda para o modo :fa-magnifying-glass: **Rastreamento** e, com **+**, abre um trace para o **Client-PC**, interface `eth0`.

:::note
Já conheces os dois pacotes ARP do início do capítulo 1. Na coluna **Info** dos pacotes TCP aparece primeiro `49152 → 5000` (de que porta para que porta), depois, entre parênteses retos, as **flags** e, a seguir, números como `Seq=`, `Ack=` e `Len=`. Os números são tratados a partir da página 5.2.3 — aqui concentras-te nas flags e em `Len`.
:::

## Fase 1: Ligar

:::quiz short
Quantos pacotes TCP foram trocados depois de clicares em **Ligar** — antes de a tua mensagem ser enviada?
= 3
= três
:::

:::quiz mc
Quem envia o primeiro pacote com `[SYN]`?
- [x] O Client-PC
- [ ] O Server
:::

:::quiz mc
Com que flags responde o servidor?
- [ ] `[SYN]`
- [x] `[SYN, ACK]`
- [ ] `[ACK]`
- [ ] `[FIN, ACK]`
:::

## Fase 2: Enviar

`Len` indica quantos bytes de dados úteis um pacote transporta.

:::quiz short
Quantos bytes transporta o pacote com a tua mensagem (`Len`)?
= 13
:::

:::note
`Hello World` tem apenas 11 carateres. No entanto, o cliente TCP acrescenta uma terminação de linha (2 bytes, `\r\n`) — é o que muitos protocolos da Internet, como SMTP ou HTTP, esperam.
:::

:::quiz mc
O que é que o servidor devolve logo a seguir à tua mensagem — ainda antes do eco?
- [x] Um pacote com `[ACK]` e `Len=0` — uma confirmação sem dados
- [ ] Nada
- [ ] Um novo `[SYN]`
:::

## Fase 3: Desligar

:::quiz short
Quantos pacotes pertencem ao encerramento — a partir do primeiro pacote com `FIN`?
= 4
= quatro
:::

:::quiz mc
O que comunica um dos lados com `FIN`?
- [x] «Terminei» — já não envia mais dados
- [ ] «Ocorreu um erro»
- [ ] «Aí vêm novos dados»
:::

Verificar respostas

## Onde estão as quatro tarefas?

Associa onde encontras no trace as tarefas da secção 5.1:

:::quiz match
Estabelecimento de ligação -> Os três pacotes [SYN], [SYN, ACK] e [ACK]
Transmissão fiável -> Pacotes com [ACK] e Len=0 que confirmam a receção
Encerramento da ligação -> Os pacotes com FIN e as respetivas confirmações
Multiplexagem -> Os números de porta 49152 → 5000 antes dos parênteses retos
:::

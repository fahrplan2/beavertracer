Uma página web é, portanto, muitas vezes composta por vários ficheiros: texto, folhas de estilos, imagens. Para cada um deles, o navegador envia um pedido próprio.

## Como é um pedido

No trace, clica no pacote `GET / HTTP/1.1` e expande **Hypertext Transfer Protocol**. Um pedido HTTP é texto simples:

```
GET / HTTP/1.1              ← Methode, Pfad, Version
Host: 192.168.0.20          ← Header: zusätzliche Angaben
…
                            ← Leerzeile: Ende der Anfrage
```

A resposta do servidor tem a mesma estrutura — com uma linha de estado, cabeçalhos, uma linha vazia e, a seguir, o ficheiro propriamente dito:

```
HTTP/1.1 200 OK             ← Version, Statuscode, Text
Content-Type: text/html     ← Header: Art der Datei
Content-Length: 301         ← Header: Größe in Byte
                            ← Leerzeile
<!doctype html> …           ← die Datei selbst
```

:::seq
mode: text
Client-PC -> Server: GET / | Pedido HTTP
Server -> Client-PC: 200 OK | index.html
Client-PC -> Server: GET /style.css | Pedido HTTP
Server -> Client-PC: 200 OK | style.css
:::

## Métodos e códigos de estado

O **método** indica o que o cliente quer:

| Método | Significado |
|---|---|
| **GET** | obter um ficheiro |
| **POST** | enviar dados para o servidor, p. ex. um formulário preenchido |
| **HEAD** | obter apenas os cabeçalhos, sem o ficheiro |

O **código de estado** indica como correu o pedido. O primeiro dígito revela o tipo de resposta:

| Código | Texto | Significado |
|---|---|---|
| **200** | OK | tudo em ordem |
| **301** | Moved Permanently | a página mudou-se definitivamente |
| **404** | Not Found | o ficheiro não existe |
| **405** | Method Not Allowed | este método não é permitido aqui |
| **500** | Internal Server Error | erro no servidor |

`2xx` significa sucesso, `3xx` redirecionamento, `4xx` um erro do cliente (pedido incorreto), `5xx` um erro do servidor.

:::tip Ponto-chave
O **HTTP** funciona segundo o **princípio pedido-resposta**: o cliente envia um **pedido** (método como `GET`, caminho, cabeçalhos) e o servidor responde com um **código de estado** (p. ex. `200 OK`, `404 Not Found`), cabeçalhos e o ficheiro. Para cada ficheiro de uma página web existe um pedido próprio.
:::

500 -> Ocorreu um erro no servidor
:::

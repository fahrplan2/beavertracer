# Ver um certificado

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Na área de trabalho vês o **Client-PC**, um **DNS-Server** e o servidor web da escola, `www.beaver-schule.de`. O servidor web oferece as suas páginas também através de **HTTPS**.

## O cadeado no navegador

1. Muda para o modo de execução :fa-play: **Executar**, clica no **Client-PC** e abre o :fa-globe: **Navegador**.
2. Acede a `https://www.beaver-schule.de/` — repara no **https**.
3. À esquerda do endereço aparece um **cadeado**. Clica nele.

:::quiz short
Para que nome foi emitido o certificado (Assunto sem `CN=`)?
= www.beaver-schule.de
:::

:::quiz short
Quem emitiu o certificado (Emissor sem `CN=`)?
= Biber Root CA
:::

:::evaluate
Verificar respostas
:::

## Porque é que o Client-PC confia no certificado?

No **Client-PC**, abre a :fa-shield-halved: **Zertifikatverwaltung** e muda para o separador **Vertrauenswürdige CAs**.

:::quiz mc
O que encontras lá?
- [x] O certificado da **Biber Root CA**
- [ ] O certificado de `www.beaver-schule.de`
- [ ] Nenhuma entrada
:::

:::quiz mc
Como se vê que a Biber Root CA é uma CA de raiz?
- [x] É **autoassinada**: o assunto e o emissor são iguais
- [ ] O nome termina em "CA"
- [ ] Não tem chave pública
:::

:::quiz mc
No Client-PC, em **Privater Schlüssel** aparece "Ja" ou "Nein"?
- [ ] Ja — o cliente precisa da chave privada da CA para verificar assinaturas
- [x] Nein — para verificar basta a chave pública; a chave privada só a CA a tem
:::

:::evaluate
Verificar respostas
:::

## O outro lado: o servidor web

Agora, no servidor web **www.beaver-schule.de**, abre a :fa-shield-halved: **Zertifikatverwaltung** (separador **Meine Zertifikate**) e vê o respetivo certificado.

:::quiz multi
O que é verdade para o certificado no servidor web?
- [x] Em **Privater Schlüssel** aparece "Ja" — o servidor precisa dele para o estabelecimento de ligação
- [x] A **cadeia** é `www.beaver-schule.de ← Biber Root CA`
- [x] A **impressão digital** é a mesma que aparece na janela do cadeado do navegador
- [ ] É autoassinado
:::

:::evaluate
Verificar respostas
:::

:::note
A **impressão digital** é um valor de hash calculado sobre o certificado. Permite comparar rapidamente dois certificados — sem ser necessário verificar um a um todos os campos.
:::

:::tip Ponto-chave
O **servidor web** possui o seu certificado **com chave privada**. O **cliente** conhece apenas o **certificado da CA de raiz** (sem chave privada) — isso basta-lhe para verificar a assinatura no certificado do servidor. Ao clicar no **cadeado** no navegador, vês o assunto, o emissor, a impressão digital e a validade.
:::

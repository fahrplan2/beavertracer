# O sistema binário

Um computador, no seu íntimo, só conhece dois estados: corrente ligada ou corrente desligada. Para isso escrevem-se **1** e **0**. Uma posição deste tipo chama-se **bit**. Também cada endereço IP não passa, para o computador, de uma sequência de zeros e uns — para perceberes como funcionam as máscaras de rede, nesta página aprendes a ler estes números e a convertê-los tu próprio.

## Como contamos normalmente: o sistema decimal

No dia a dia, calculamos com dez algarismos (0 a 9). Cada posição vale dez vezes mais do que a posição à sua direita: unidades, dezenas, centenas, milhares. O número `305` significa, portanto:

| Valor posicional | 100 | 10 | 1 |
|---|---|---|---|
| Algarismo | 3 | 0 | 5 |
| Valor | 300 | 0 | 5 |

300 + 0 + 5 = **305**

## O sistema binário

No **sistema binário** (em alemão também *Binärsystem*) existem apenas dois algarismos: 0 e 1. Cada posição vale o **dobro** da posição à sua direita: 1, 2, 4, 8, 16, 32, 64, 128 …

O número binário `00001101` significa, portanto:

| Valor posicional | 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1 |
|---|---|---|---|---|---|---|---|---|
| Bit | 0 | 0 | 0 | 0 | 1 | 1 | 0 | 1 |
| Valor | | | | | 8 | 4 | | 1 |

8 + 4 + 1 = **13**

Ou seja, basta somares os valores posicionais onde está um 1.

:::tip Ponto-chave
Um **bit** é uma posição no sistema binário (0 ou 1). **8 bits** formam um **byte** — em redes, a este grupo de 8 bits chama-se também **octeto**. Os valores posicionais de um octeto são **128, 64, 32, 16, 8, 4, 2, 1**.
:::

## De decimal para binário

No sentido inverso, percorres os valores posicionais da esquerda para a direita e perguntas de cada vez: **o valor posicional ainda cabe no meu número (restante)?** Se sim, escreves um 1 e subtrais o valor posicional. Se não, escreves um 0.

Exemplo: `168`

| Valor posicional | cabe em …? | Bit | Resto |
|---|---|---|---|
| 128 | 168 → sim | **1** | 40 |
| 64 | 40 → não | **0** | 40 |
| 32 | 40 → sim | **1** | 8 |
| 16 | 8 → não | **0** | 8 |
| 8 | 8 → sim | **1** | 0 |
| 4 | 0 → não | **0** | 0 |
| 2 | 0 → não | **0** | 0 |
| 1 | 0 → não | **0** | 0 |

Lido de cima para baixo: 168 = **10101000**

:::

## Endereços IP no sistema binário

Um endereço IPv4 é composto por **32 bits**, ou seja, quatro octetos. Como ninguém consegue memorizar 32 zeros e uns, cada octeto é escrito como um número decimal e separam-se por pontos:

```
11000000 . 10101000 . 10110010 . 00000001
   192   .   168    .   178    .    1
```

:::quiz short

= 32
:::

:::

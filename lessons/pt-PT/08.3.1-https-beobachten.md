# HTTP e HTTPS em comparação

:::sim
url=/sims/lesson-8.2.1.btsim
:::

O servidor web **www.beaver-schule.de** disponibiliza o portal de notas da escola tanto por HTTP como por HTTPS. O que vê alguém que esteja à escuta?

## A experiência

1. Muda para o :fa-play: modo de execução (**Executar**) e, no **Client-PC**, abre no :fa-globe: **Navegador** primeiro `http://www.beaver-schule.de/` e depois `https://www.beaver-schule.de/`.
2. No modo :fa-magnifying-glass: **Rastreamento**, abre um trace para o **Client-PC**.
3. Procura primeiro o pacote `HTTP/1.1 200 OK` e clica nele. Em baixo, nos detalhes, encontras o conteúdo da página.

:::quiz mc
O que pode ver alguém que esteja à escuta em **HTTP**?
- [x] A página web completa, incluindo as notas da Anna
- [ ] Apenas o endereço do servidor
- [ ] Nada, porque o HTTP funciona sobre TCP
:::

:::quiz short
Que nota tem a Anna a Matemática?
= 2
:::

:::evaluate
Verificar respostas
:::

Agora a parte do HTTPS. Procura o pacote `[SYN]` com que o cliente inicia a segunda ligação.

:::quiz short
Qual é a porta de destino da ligação HTTPS (coluna **Info**, `… → ???`)?
= 443
:::

Introduz agora `tls` no campo de filtro do trace, no topo — assim vês apenas os pacotes TLS.

:::quiz mc
O que aparece na coluna **Info** nos pacotes que contêm a página web?
- [ ] `HTTP/1.1 200 OK`
- [x] `Application Data`
- [ ] `Encrypted HTML`
:::

:::quiz multi
O que pode alguém que esteja à escuta ainda assim ver em **HTTPS**?
- [x] Os endereços IP do cliente e do servidor
- [x] Que é utilizada a porta 443, ou seja, provavelmente HTTPS
- [x] Aproximadamente quantos dados são transmitidos
- [ ] Que página foi acedida e o que lá está escrito
:::

:::evaluate
Verificar respostas
:::

:::note
Clica num pacote **Application Data**: os dados úteis são apenas uma sequência de bytes aparentemente aleatórios. O Tracer não os consegue decifrar — conhece a chave de sessão tão pouco quanto um atacante.
:::

:::tip Ponto-chave
Em **HTTP**, qualquer pessoa à escuta consegue ler a página web completa. Em **HTTPS**, só vê **quem fala com quem** (endereços IP, porta 443) e **quanto** — o conteúdo vai cifrado dentro de pacotes **Application Data**.
:::

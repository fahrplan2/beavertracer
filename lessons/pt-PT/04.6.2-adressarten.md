# Os tipos de endereço mais importantes

No IPv6, o início de um endereço indica para que serve:

| Tipo de endereço | reconhecível por | para quê |
|---|---|---|
| **Link-Local** | `fe80::` | Só é válido na **própria rede local**. Cada dispositivo atribui a si próprio este endereço automaticamente — nunca é encaminhado por um router. |
| **Global Unicast** | `2…` ou `3…` (`2000::/3`) | Endereço único a nível mundial, acessível na Internet. O prefixo é fornecido pelo fornecedor de Internet. |
| **Unique Local** | `fd…` (`fc00::/7`) | Para redes privadas, comparável a `192.168.x.x` no IPv4. |
| **Loopback** | `::1` | O próprio dispositivo — como `127.0.0.1` no IPv4. |
| **Multicast** | `ff…` | Para um **grupo** de dispositivos, p. ex. `ff02::1` = todos os dispositivos da rede local. |

:::note
O intervalo `2001:db8::/32` está reservado para exemplos e material didático — nunca aparece na Internet real. Por isso, vês este intervalo neste curso.
:::

Uma novidade importante: **o IPv6 já não tem broadcast.** O que no IPv4 era um broadcast para todos, o IPv6 resolve com endereços **multicast** — a mensagem só vai para os dispositivos que estão interessados nesse grupo.

:::tip Ponto-chave
Todo o dispositivo IPv6 tem pelo menos um **endereço link-local** (`fe80::…`) para a própria rede e, normalmente, também um **endereço global** para a Internet. Em vez de broadcast, o IPv6 utiliza **multicast** (`ff…`).
:::

::1 -> Loopback — o próprio dispositivo
ff02::1 -> Multicast — todos os dispositivos da rede local

# O router

:::goal
**Objetivo de aprendizagem:** Consegues explicar como um router liga duas redes, configurar o gateway num PC e justificar quando é que um PC entrega um pacote diretamente e quando o faz através do gateway.
:::

:::sim
url=/sims/lesson-4.3.1.btsim
:::

Um **router** liga redes diferentes entre si. Para isso, tem uma interface própria para cada rede — e, em cada interface, um endereço IP próprio pertencente exatamente a essa rede. Na área de trabalho voltas a ver a Firma A e a Firma B, desta vez com um router no meio.

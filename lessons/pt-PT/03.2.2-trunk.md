# VLANs através de dois switches: o trunk

:::sim
url=/sims/lesson-3.2.2.btsim
:::

A escola tem dois pisos, cada um com um switch, ligados por um cabo na **porta 8**:

| Switch | Porta 1 (VLAN 10, Verwaltung) | Porta 2 (VLAN 20, Computerraum) |
|---|---|---|
| **Switch EG** (rés-do-chão) | Sekretariat `192.168.0.10` | Anna `192.168.0.20` |
| **Switch OG** (primeiro andar) | Schulleitung `192.168.0.11` | Ben `192.168.0.21` |

As VLANs nas portas dos PC já estão configuradas.

## O problema

Muda para o :fa-play: modo de execução e faz ping a partir da **Anna** ao Ben (`ping 192.168.0.21`). Ambos estão na VLAN 20 — e mesmo assim não há resposta.

No separador **VLAN** de um switch, observa a linha **port 8**: continua em `untagged` com PVID `1`. Ou seja, por este cabo passa apenas a VLAN 1 — nem a VLAN 10 nem a VLAN 20.

No entanto, pelo cabo entre os switches têm de passar frames de *ambas* as VLANs. Para isso, o switch cola em cada frame uma pequena etiqueta com o ID da VLAN: a **etiqueta VLAN** (VLAN tag). Assim, o switch na outra extremidade sabe a que VLAN pertence a frame.

## Configurar o trunk

Faz isto nos **dois** switches:

1. Clica no switch e abre o separador **VLAN**.
2. Na linha **port 8**, define o **Modo** como `tagged` e introduz `10,20` em **VLANs Permitidas**.
3. Clica em **Aplicar**.

Depois, faz de novo ping a partir da **Anna** ao Ben — e, para comparar, à Schulleitung (`ping 192.168.0.11`).

:::quiz mc
O que acontece agora?
- [x] A Anna alcança o Ben, mas não a Schulleitung
- [ ] A Anna alcança o Ben e a Schulleitung
- [ ] A Anna continua sem alcançar ninguém
:::

Verificar resposta
:::

## A etiqueta VLAN no Tracer

Muda para o :fa-magnifying-glass: modo **Rastreamento** e, com **+**, abre um trace para o **Switch EG**, porta **8** — é o cabo entre os switches. Clica num dos pings da Anna (`Echo (ping) request`).

Na árvore de protocolos surgiu uma nova linha, logo abaixo de Ethernet: **802.1Q Virtual LAN**. Esta é a etiqueta VLAN.

:::quiz short
Que ID de VLAN consta na etiqueta do ping da Anna?
= 20
:::

Para comparar, abre um trace para o **Ben** (`eth0`) e clica no mesmo ping.

:::quiz mc
O que reparas no Ben?
- [ ] Lá consta a mesma etiqueta com o ID 20
- [x] Lá falta a linha 802.1Q — o switch removeu a etiqueta antes da porta do Ben
- [ ] O ping nem sequer chega ao Ben
:::

:::evaluate
Verificar respostas
:::

:::tip Ponto-chave
Um **trunk** é uma ligação através da qual passam frames de várias VLANs — normalmente entre dois switches. Para isso, cada frame recebe uma **etiqueta VLAN** com o ID da VLAN (norma **IEEE 802.1Q**). Estas portas chamam-se **tagged**. Numa porta **untagged** está ligado um dispositivo normal; o switch remove a etiqueta antes de enviar a frame para lá.
:::

# Criar uma CA própria

:::sim
url=/sims/lesson-8.2.2.btsim
:::

Para `www.beaver-schule.de` ainda não existe nenhum certificado. Em vez de pedir um a uma CA comercial, a escola cria a sua **própria CA**: a **Schul-CA**. Muitas empresas e escolas fazem isto para os seus servidores internos.

Na realidade, a Schul-CA funcionaria num computador próprio, especialmente bem protegido. Aqui, desempenhas todos os papéis no próprio servidor Web.

## Passo 1: gerar a Schul-CA

1. Muda para o modo de execução :fa-play: **Executar** e, no servidor Web **www.beaver-schule.de**, abre a :fa-shield-halved: **Zertifikatverwaltung**.
2. No separador **Generieren**:
    - **Common Name:** `Schul-CA`
    - **Typ:** Selbstsigniert
    - Assinala **Dies ist ein CA-Zertifikat**
    - **Speichern unter:** `schul-ca.cert.json`
3. Clica em **Zertifikat generieren**.

Isto cria um novo **par de chaves**. O certificado contém a chave pública; a chave privada fica no ficheiro do servidor Web.

## Passo 2: emitir o certificado do servidor

Novamente no separador **Generieren**:

- **Common Name:** `www.beaver-schule.de` — exatamente o nome que se escreve no navegador
- **Typ:** Von CA signiert, **Signierende CA:** Schul-CA
- **Speichern unter:** p. ex. `www.beaver-schule.de.cert.json`

No separador **Meine Zertifikate** vês agora os dois certificados. Clica no novo certificado do servidor:

:::quiz short
Quem é o **Aussteller** do certificado do servidor (sem `CN=`)?
= Schul-CA
:::

:::quiz mc
Qual é a sua **Kette**?
- [x] `www.beaver-schule.de ← Schul-CA`
- [ ] `Schul-CA ← www.beaver-schule.de`
- [ ] `www.beaver-schule.de` (autoassinado)
:::

:::evaluate
Verificar respostas
:::

## Passo 3: ensinar a Schul-CA ao cliente

O PC cliente ainda não conhece a Schul-CA — não está pré-instalada no seu navegador. Tens de lhe dar o respetivo certificado, e **sem a chave privada**:

1. No servidor Web, em **Meine Zertifikate**, seleciona a **Schul-CA** e clica em **Kopieren** (não em *Kopieren + Schlüssel*!).
2. No **PC cliente**, abre a :fa-shield-halved: **Zertifikatverwaltung**, separador **Vertrauenswürdige CAs**.
3. Clica em **Einfügen: Schul-CA**.

:::warning
A **chave privada da CA** é o segredo mais valioso de toda a infraestrutura: quem a tiver pode emitir certificados para **quaisquer** nomes, nos quais todos os clientes passarão a confiar. Nunca deve sair do computador da CA.
:::

:::task
title: Schul-CA configurada?
Verifica se existe no servidor Web um certificado para www.beaver-schule.de emitido pela Schul-CA e se o PC cliente confia na Schul-CA.
check: hasCert(4, "www.beaver-schule.de", "Schul-CA")
check: trusts(2, "Schul-CA")
:::

:::quiz mc
Porque é que copias para o cliente apenas o certificado **sem** a chave privada?
- [ ] Porque copiar com a chave demora mais tempo
- [x] Para verificar assinaturas basta a chave pública; com a chave privada, qualquer pessoa no cliente poderia emitir certificados por si própria
- [ ] Porque, caso contrário, o cliente não consegue estabelecer ligação
:::

:::evaluate
Verificar resposta
:::

Ainda não configuraste o servidor Web — continua a falar apenas HTTP. Aprenderás a ativar o HTTPS na secção 8.3.3.

:::tip Ponto-chave
Uma **CA própria** consiste num **certificado de CA autoassinado** com chave privada. Com ele emitem-se **certificados de servidor** cujo Common Name corresponde ao nome do servidor. Para que os clientes confiem nestes certificados, recebem o **certificado da CA sem chave privada** na sua lista de **CAs de confiança**.
:::

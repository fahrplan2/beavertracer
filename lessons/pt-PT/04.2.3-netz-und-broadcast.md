# Endereço de rede, endereço de broadcast e anfitriões

Em cada rede, dois endereços têm uma função especial:

- O **endereço de rede** é o endereço **mais baixo** da rede: todos os bits da parte de anfitrião são 0. Designa a rede como um todo, por exemplo em tabelas de encaminhamento.
- O **endereço de broadcast** é o endereço **mais alto** da rede: todos os bits da parte de anfitrião são 1. Tudo o que for enviado para ele vai para todos os dispositivos da rede.

Nenhum destes endereços é **atribuído** a dispositivos. Todos os endereços intermédios estão disponíveis para dispositivos (**anfitriões**).

## Um exemplo simples

`192.168.0.12/24` — a parte de anfitrião é o último octeto:

| | Endereço |
|---|---|
| Endereço de rede (parte de anfitrião = 0) | `192.168.0.0` |
| Endereço de broadcast (parte de anfitrião = 255) | `192.168.0.255` |
| Intervalo para anfitriões | `192.168.0.1` – `192.168.0.254` |
| Número de anfitriões | 254 |

## Quando a fronteira está a meio do octeto

Torna-se mais difícil quando o comprimento do prefixo não é um múltiplo de 8. Nesse caso, converte o octeto em causa para o sistema binário. Exemplo: `194.9.190.12/27`.

Os primeiros três octetos pertencem por inteiro à [[n|parte de rede]] (24 bits). Do último octeto, **3 bits** ainda pertencem à parte de rede (24 + 3 = 27) e os restantes **5 bits** à [[h|parte de anfitrião]]:

| | último octeto (binário) | decimal |
|---|---|---|
| Endereço IP | [[n|000]][[h|01100]] | 12 |
| Máscara de rede (`/27`) | [[n|111]][[h|00000]] | 224 |
| Endereço de rede: bits de anfitrião a 0 | [[n|000]][[h|00000]] | **0** |
| Endereço de broadcast: bits de anfitrião a 1 | [[n|000]][[h|11111]] | **31** |

Resultado:

- Endereço de rede: `194.9.190.0`
- Endereço de broadcast: `194.9.190.31`
- Intervalo para anfitriões: `194.9.190.1` – `194.9.190.30`
- Número de anfitriões: 2⁵ − 2 = **30**

:::tip Ponto-chave
**Endereço de rede:** todos os bits de anfitrião a 0 (endereço mais baixo). **Endereço de broadcast:** todos os bits de anfitrião a 1 (endereço mais alto). Nenhum dos dois é atribuído a dispositivos. Uma rede com comprimento de prefixo *n* tem **2<sup>32 − n</sup> − 2** endereços utilizáveis para anfitriões.
:::

:::tip Dica: o tamanho do bloco
Se já percebeste o método no sistema binário, existe um atalho: **256 menos o octeto da máscara** dá o tamanho de uma rede nesse octeto. Com `/27` (máscara 224), isso é 256 − 224 = **32**. As redes começam então em 0, 32, 64, 96 … — o endereço `.12` pertence à rede que começa em `.0`, o endereço `.70` à rede que começa em `.64`.
:::

## Os tamanhos de rede mais importantes

| Prefixo | Máscara de rede | Anfitriões |
|---|---|---|
| `/8` | `255.0.0.0` | 16 777 214 |
| `/16` | `255.255.0.0` | 65 534 |
| `/24` | `255.255.255.0` | 254 |
| `/25` | `255.255.255.128` | 126 |
| `/26` | `255.255.255.192` | 62 |
| `/27` | `255.255.255.224` | 30 |
| `/28` | `255.255.255.240` | 14 |
| `/29` | `255.255.255.248` | 6 |
| `/30` | `255.255.255.252` | 2 |

:::note
A rede mais pequena habitual na prática é a `/30`: tem exatamente dois endereços utilizáveis e é muitas vezes usada para a ligação entre dois routers. Um `/32` designa um único endereço — não é utilizável como rede, mas aparece em tabelas de encaminhamento e em regras de firewall.
:::

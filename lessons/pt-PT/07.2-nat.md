# NAT: vários dispositivos, um só endereço

:::goal
**Objetivo de aprendizagem:** Consegues mostrar no Tracer como o NAT substitui o endereço do remetente, ler a tabela NAT e explicar porque é que as ligações do exterior para a rede doméstica precisam de um reencaminhamento de portas.
:::

:::sim
url=/sims/lesson-7.1.btsim
:::

O fornecedor de serviços normalmente atribui a uma ligação doméstica apenas **um** endereço IPv4 público — o endereço WAN do router doméstico. Todos os dispositivos da rede doméstica têm de o partilhar. A forma como isto funciona chama-se **NAT** (*Network Address Translation*, tradução de endereços).

# DNS: nomes em vez de números

:::goal
**Objetivo de aprendizagem:** Consegues explicar como o DNS traduz nomes em endereços IP, como os nomes estão organizados de forma hierárquica, criar tu próprio uma entrada e encontrar erros típicos de DNS.
:::

:::sim
url=/sims/lesson-6.2.btsim
:::

Quase ninguém consegue decorar endereços IP — mas nomes como `www.beaver-schule.de` já é diferente. A tradução é feita pelo **Domain Name System** (**DNS**), uma espécie de lista telefónica mundial da internet.

Na área de trabalho encontra-se agora uma rede um pouco maior: além do **Client-PC** e do **Webserver**, existem quatro **servidores DNS**. Para que servem tantos, vais ver daqui a duas páginas.

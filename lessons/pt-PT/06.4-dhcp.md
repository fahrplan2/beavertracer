# DHCP: entrar na rede automaticamente

:::goal
**Objetivo de aprendizagem:** Consegues explicar como um dispositivo obtém automaticamente as suas definições de IP através de DHCP, configurar um servidor DHCP e identificar e resolver erros típicos de DHCP (p. ex., um endereço 169.254).
:::

:::sim
url=/sims/lesson-6.4.btsim
:::

Até agora, introduziste à mão o endereço IP, a máscara de rede, o gateway e o servidor DNS de cada dispositivo. Numa escola com centenas de portáteis, tablets e telemóveis, isso seria impossível — e cada erro de digitação seria um problema na rede.

Este trabalho é assumido pelo **Dynamic Host Configuration Protocol** (**DHCP**): um **servidor DHCP** distribui automaticamente as definições a cada dispositivo que entra na rede.

# Como trabalhar com o curso

Este curso decorre diretamente no BeaverTracer: à esquerda constróis e observas redes, à direita, no **painel de lições**, lês as instruções.

## Navegar entre páginas

Com **Zurück** e **Weiter** avanças página a página pelo curso. Através de **Übersicht** (ou de :fa-list: no topo do painel de lições) podes saltar para qualquer capítulo.

## A simulação certa para cada página

Sempre que mudas de página, o BeaverTracer carrega automaticamente a simulação que pertence a essa página — assim, começas sempre a partir de um estado funcional.

:::warning
Aquilo que constróis ou alteras numa página desaparece na página seguinte. É de propósito: cada página começa com um estado inicial limpo.
:::

- Com :fa-rotate-left: no topo do painel de lições, repões a simulação no início da página atual — útil quando te perdeste.
- Se quiseres continuar a construir a partir de uma simulação, clica em :fa-file-import: **Adoptar** na barra de ferramentas. O painel de lições fecha-se e a simulação passa a ser tua.

## Guardar e carregar

Uma simulação é um único ficheiro (`.btsim`) que descreve toda a tua rede — todos os dispositivos, cabos e as respetivas definições. Enquanto o painel de lições estiver aberto, os botões :fa-file: **Neu**, :fa-file-arrow-up: **Laden** e :fa-file-arrow-down: **Guardar** estão ocultos. Depois de **Adoptar** (ou quando fechas o painel de lições com **×**) encontras estes botões na barra de ferramentas, à direita dos botões de modo — no modo de edição.

## Caixas, quizzes e tarefas

:::goal
**Objetivo de aprendizagem** — aparece no início de uma secção: é o que vais conseguir fazer depois.
:::

:::tip Ponto-chave
Resume brevemente um termo técnico ou uma relação importante — bom para estudar para os testes.
:::

- As **perguntas do quiz** respondes diretamente na página e verificas com o botão por baixo. Quase todas as respostas podes ler no teu ecrã, se olhares com atenção.
- As **tarefas** com o botão **Verificar tarefa** analisam a tua simulação para ver se tudo está configurado corretamente — por exemplo, se dois PCs se alcançam.

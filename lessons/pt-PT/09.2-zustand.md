# Sem estado ou com estado

Uma ligação é sempre composta por **dois sentidos**: o PC do professor envia um pedido a um servidor web na Internet — e o servidor web devolve a página web. Uma firewall baseada no princípio da lista de permissões (*whitelist*) tem, por isso, de deixar passar não só o pedido, mas também a **resposta**.

Para isso existem dois tipos de filtros de pacotes:

| | **Sem estado** (*stateless*) | **Com estado** (*stateful*) |
|---|---|---|
| Funcionamento | verifica cada pacote individualmente, sem memória | memoriza as ligações permitidas numa **tabela de estados** |
| Respostas | precisam de uma regra própria para o sentido inverso | são deixadas passar automaticamente, porque pertencem a uma ligação conhecida |
| Utilização | dispositivos simples, filtros muito rápidos | praticamente todas as firewalls atuais |

Nas próximas duas secções vais ver por que razão os filtros sem estado têm problemas com as respostas — e como uma firewall com estado os resolve.

# Resumo e perspetivas

## Firewalls em muitos locais

Encontras o filtro de pacotes deste capítulo em muitos dispositivos:

- **Router doméstico:** Todos os routers domésticos são também uma firewall com controlo de estado. Com IPv4, o NAT assume uma parte dessa função: ninguém consegue iniciar uma ligação a partir do exterior, enquanto não existir um reencaminhamento de portas (capítulo 7). Com IPv6, todos os dispositivos têm endereços públicos — nesse caso, só a regra da firewall «nada de novo vindo do exterior» garante a mesma proteção.
- **Firewall pessoal:** O Windows, o macOS e o Linux também têm uma firewall integrada no próprio computador. Protege o dispositivo mesmo em redes alheias, por exemplo no Wi-Fi de um café, e consegue definir regras por programa.
- **Firewall de nova geração (Next-Generation Firewall)** e **Web Application Firewall (WAF):** Não olham apenas para endereços e portas, mas para o conteúdo dos pacotes — até à camada de aplicação. Assim, conseguem detetar, por exemplo, ataques em pedidos HTTP. No caso do HTTPS, para isso têm de quebrar a cifragem (capítulo 8).
- **IDS/IPS:** Um *Intrusion Detection System* deteta padrões suspeitos no tráfego de dados e dá o alarme; um *Intrusion Prevention System* bloqueia-os, além disso, por si próprio.

:::note
Uma firewall é apenas **uma** peça da segurança. Não ajuda se um serviço permitido (por exemplo, o servidor web) tiver ele próprio uma vulnerabilidade, se alguém abrir um programa malicioso recebido por e-mail ou se uma palavra-passe for fraca. Por isso, atualizações, palavras-passe seguras, cifragem e uma divisão inteligente da rede (DMZ, VLANs do capítulo 3) fazem sempre parte da solução.
:::

## Testa-te

:::quiz mc
Uma firewall funciona com a política predefinida «Descartar tudo» e uma única regra «A → B, TCP 443, Permitir». Chega um pacote A → B para a porta TCP 22. O que acontece?
- [ ] É permitido
- [x] É descartado
- [ ] É rejeitado
:::

:::quiz mc
O `nmap` indica `filtered` para uma porta. O que significa isto?
- [ ] Na porta está a ser executado um serviço
- [ ] O servidor respondeu com um RST
- [x] Não houve qualquer resposta — provavelmente uma firewall está a descartar os pacotes
:::

:::quiz multi
Que afirmações são verdadeiras?
- [x] Numa firewall com controlo de estado (stateful), as respostas a ligações permitidas voltam automaticamente
- [x] Uma lista de permissões (whitelist) é mais segura do que uma lista de bloqueio (blacklist), porque os novos serviços permanecem automaticamente bloqueados
- [x] Os servidores acessíveis a partir da Internet devem ficar numa DMZ
- [ ] Uma firewall protege também contra ataques entre dois computadores na mesma rede atrás dela
- [ ] As regras são sempre todas verificadas e a mais restritiva prevalece
:::

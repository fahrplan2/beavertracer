# Fundamentos da criptografia

**Criptografia** é a ciência da cifragem. Antes de começarmos, alguns termos que vão aparecer repetidamente neste capítulo:

| Termo | Significado |
|---|---|
| **Texto simples** | A mensagem legível, p. ex. `Treffen um 10 Uhr` |
| **Texto cifrado** | A mensagem cifrada, p. ex. `Wuhiihq xp 10 Xku` |
| **Cifrar** | Texto simples → texto cifrado |
| **Decifrar** | Texto cifrado → texto simples |
| **Método** (*algoritmo*) | A regra de cálculo segundo a qual se cifra |
| **Chave** | A informação secreta adicional de que o método necessita |

## O método não é secreto — a chave é

Poder-se-ia pensar que um método é tanto mais seguro quanto menos pessoas o conhecerem. O contrário é que é verdade: todos os métodos atualmente utilizados estão descritos **publicamente** e foram examinados durante anos por especialistas de todo o mundo à procura de vulnerabilidades. Apenas a **chave** permanece secreta.

Este princípio foi formulado já em 1883 pelo neerlandês Auguste Kerckhoffs. A vantagem: se uma chave for revelada, basta trocar a chave — e não todo o método.

Nas secções seguintes ficas a conhecer os quatro blocos de construção com que se constroem ligações seguras:

1. **Cifragem simétrica** — rápida, mas com um problema de chaves
2. **Cifragem assimétrica** — chave pública e chave privada
3. **Valores de hash** — a impressão digital dos dados
4. **Assinaturas digitais** — assinaturas eletrónicas

No fim, vês como estes blocos funcionam em conjunto (**cifragem híbrida**).

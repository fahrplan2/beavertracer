# Valores de hash: a impressão digital dos dados

:::sim
url=/sims/lesson-8.1.3.btsim
:::

Uma **função de hash** calcula, a partir de uma quantidade qualquer de dados — uma frase, um documento, um filme inteiro —, uma sequência curta de caracteres de comprimento fixo: o **valor de hash**. Funciona como uma **impressão digital**: dados iguais dão sempre o mesmo valor de hash, dados diferentes dão um valor diferente.

A função de hash hoje habitual chama-se **SHA-256**. O seu valor de hash tem sempre 256 bits, ou seja, 64 caracteres em hexadecimal.

## A experiência

No **PC**, na pasta `/home`, existem três ficheiros com um pequeno contrato de compra e venda. Muda para o modo de execução (:fa-play: **Executar**), abre o :fa-terminal: **Terminal** no **PC** e escreve:

```
$ cd /home
$ cat vertrag.txt vertrag-kopie.txt vertrag-neu.txt
$ sha256sum vertrag.txt vertrag-kopie.txt vertrag-neu.txt
```

## Propriedades de uma função de hash

| Propriedade | Significado |
|---|---|
| **comprimento fixo** | Independentemente do tamanho dos dados, o valor de hash tem sempre o mesmo comprimento. |
| **determinística** | Dados iguais dão sempre o mesmo valor de hash. |
| **efeito avalanche** | Mesmo a mais pequena alteração dá um valor de hash completamente diferente. |
| **função unidirecional** | Não é possível recalcular os dados a partir do valor de hash. |
| **resistente a colisões** | É praticamente impossível encontrar dois ficheiros diferentes com o mesmo valor de hash. |

Uma função de hash **não é cifragem**: não existe chave nem decifragem. Serve outro propósito — a **integridade**.

## Para que serve?

- **Verificar transferências:** Muitos sites indicam, junto de um ficheiro, o respetivo valor SHA-256. Se o valor de hash do ficheiro que transferiste coincidir com esse, o ficheiro não foi alterado pelo caminho.
- **Guardar palavras-passe:** Os bons sites não guardam a tua palavra-passe, mas apenas um valor de hash dela. No início de sessão, compara-se o valor de hash do que introduziste. Se a base de dados for roubada, o ladrão continua a não conhecer as palavras-passe.
- **Assinaturas digitais:** Em vez de um documento inteiro, assina-se apenas o seu valor de hash — mais sobre isto na próxima secção.

:::tip Ponto-chave
Uma **função de hash** (por exemplo, **SHA-256**) calcula, a partir de dados quaisquer, um **valor de hash** de comprimento fixo — uma **impressão digital**. Mesmo a mais pequena alteração dá um valor de hash completamente diferente, e não é possível recalcular os dados a partir do valor de hash. Os valores de hash garantem a **integridade** dos dados.

# HTTPS

:::osi 5
:::

**HTTPS** (*HTTP Secure*) é HTTP normal — só que não corre diretamente sobre TCP, mas através de uma camada cifrada pelo meio: o **TLS** (*Transport Layer Security*). O antecessor do TLS chamava-se **SSL**; por isso, ainda se fala frequentemente em "certificados SSL".

```
ohne Verschlüsselung:   HTTP  →  TCP  →  IP
mit Verschlüsselung:    HTTP  →  TLS  →  TCP  →  IP
```

O HTTP não se apercebe de nada: envia os seus pedidos como habitualmente, o TLS cifra-os e o TCP transporta-os. No modelo OSI, o TLS situa-se entre a camada de transporte e a camada de aplicação, ou seja, na camada 4/5 — assenta sobre o TCP e gere uma sessão protegida.

| | HTTP | HTTPS |
|---|---|---|
| Porta | 80 | **443** |
| Endereço | `http://…` | `https://…` |
| Conteúdo legível no Tracer? | sim | não |
| O navegador mostra | "não seguro" | cadeado |

No estabelecimento de ligação, o TLS trata de tudo o que aprendeste neste capítulo:

- O servidor identifica-se com o seu **certificado** (**autenticidade**).
- Ambos os lados negoceiam, com **Diffie-Hellman**, uma **chave de sessão** — o servidor **assina** a sua parte.
- Depois, todos os dados são cifrados com **AES** (**confidencialidade**) e protegidos contra alterações (**integridade**).

O princípio não se limita à Web: também o correio eletrónico (secção 8.4) e muitos outros protocolos passam pelo TLS da mesma forma.

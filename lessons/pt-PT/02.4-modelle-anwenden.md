# Aplicar os modelos

Associa os protocolos da experiência do início do capítulo à respetiva camada OSI:

:::quiz match
Ethernet -> Camada 2 — Ligação de dados
IPv4 -> Camada 3 — Rede
TCP -> Camada 4 — Transporte
HTTP -> Camada 7 — Aplicação
:::

:::evaluate
Verificar associação
:::

E, para terminar, os nomes das unidades de dados:

:::quiz match
Frame -> Camada 2 — Ligação de dados
Pacote -> Camada 3 — Rede
Segmento -> Camada 4 — Transporte
:::

:::evaluate
Verificar associação
:::

Com isto, já tens as ferramentas para classificar corretamente os protocolos daqui para a frente. A partir do próximo capítulo, vamos percorrer as camadas por ordem — começando pela camada 2 e pela questão de como é que um switch sabe, afinal, para onde deve reencaminhar um pacote.

## A experiência

1. Muda para o modo de execução :fa-play: **Executar**, clica no **Client-PC** e abre o :fa-globe: **Navegador**.
2. Desta vez, acede a `http://www.beaver-schule.de/` — com um nome em vez de um endereço IP.
3. Muda para o modo :fa-magnifying-glass: **Rastreamento** e abre um trace para o **Client-PC**.

Logo no início — ainda antes do estabelecimento de ligação com `[SYN]` — aparecem dois pacotes com o protocolo **DNS**.

:::quiz short
Para que endereço IP envia o Client-PC o seu pedido DNS?
= 192.168.0.53
:::

:::quiz short
Que endereço IP consta na resposta para `www.beaver-schule.de`?
= 192.168.0.20
:::

:::quiz mc
Clica no pedido DNS e expande a árvore de protocolos. Que protocolo de transporte e que porta de destino são utilizados?
- [ ] TCP, porta 80
- [x] UDP, porta 53
- [ ] UDP, porta 67
:::

:::evaluate
Verificar respostas
:::

Só depois de o Client-PC conhecer o endereço IP é que estabelece a ligação TCP com o servidor Web — tal como no capítulo 5.

:::seq
mode: text
Client-PC -> DNS-Resolver: DNS-Anfrage | A www.beaver-schule.de?
DNS-Resolver -> Client-PC: DNS-Antwort | A 192.168.0.20
:::

## Como é que o PC conhece o servidor DNS?

No **Client-PC**, abre as :fa-gear: **Definições de IP**: no campo **DNS-Server** consta `192.168.0.53` — o computador **DNS-Resolver**. É para ele que o PC envia todos os pedidos de nomes.

Também podes questionar o servidor DNS diretamente, sem navegador. Abre o :fa-terminal: **Terminal** e introduz:

```
$ nslookup www.beaver-schule.de
```

O `nslookup` mostra primeiro que servidor interrogou e depois a resposta. Para comparar, pergunta por um nome que não existe, p. ex. `nslookup gibtsnicht.beaver-schule.de`.

:::quiz mc
O que responde o servidor DNS ao nome desconhecido?
- [ ] Um endereço IP aleatório
- [x] `NXDOMAIN` — este nome não existe
- [ ] Rigorosamente nada
:::

:::evaluate
Verificar resposta
:::

:::tip Ponto-chave
O **DNS** traduz nomes (p. ex. `www.beaver-schule.de`) em endereços IP. Antes de um PC poder estabelecer uma ligação a um nome, pergunta ao **servidor DNS** que está configurado nas suas definições de IP — normalmente através de **UDP, porta 53**. Com o `nslookup` podes fazer pedidos DNS manualmente.
:::

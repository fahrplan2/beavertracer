# Atribuir endereços IP

:::sim
url=/sims/lesson-1.2.2.btsim
:::

Para que dois dispositivos possam comunicar entre si, precisam de um endereço IP na mesma rede. Na área de trabalho vês dois PCs ligados — exatamente como os acabaste de montar tu próprio.

1. Muda para o modo de execução :fa-play: **Executar** e clica em **Computer 1** para o abrir.
2. Abre aí as :fa-gear: **Definições de IP**. Um PC novo já tem o endereço `192.168.0.10` com a máscara de rede `/24` — podes deixá-lo assim.
3. Abre agora o **Computer 2**. Tem o *mesmo* endereço `192.168.0.10` — isso não pode funcionar, porque cada endereço só pode aparecer uma vez na rede. Altera-o para `192.168.0.11` (máscara de rede `/24`).

:::tip Ponto-chave
Um **endereço IP** (p. ex. `192.168.0.10`) é o endereço de um dispositivo na rede — comparável a um número de porta. Cada endereço IP só pode aparecer **uma vez** numa rede.
:::

:::task
title: Endereços atribuídos corretamente?
Fica no modo de execução e verifica se ambos os PCs têm endereços adequados e se conseguem comunicar entre si.
check: ip(1, "192.168.0.10/32")
check: ip(3, "192.168.0.11/32")
check: pingOk(1, 3)
:::

:::note
O que significa exatamente `/24` e como dividir uma rede de forma sensata vamos ver em pormenor no capítulo 4. Por agora basta saber que ambos os endereços têm de começar por `192.168.0.` e não podem repetir-se.
:::

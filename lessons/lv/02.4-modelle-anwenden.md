# Modeļu pielietošana

Piešķir protokolus no šīs nodaļas sākuma eksperimenta to OSI slānim:

:::quiz match
Ethernet -> 2. slānis — datu saite
IPv4 -> 3. slānis — tīkls
TCP -> 4. slānis — transports
HTTP -> 7. slānis — lietojumi
:::

:::evaluate
Pārbaudīt sasaisti
:::

Un visbeidzot datu vienību nosaukumi:

:::quiz match
Frame -> 2. slānis — datu saite
Pakete -> 3. slānis — tīkls
Segments -> 4. slānis — transports
:::

:::evaluate
Pārbaudīt sasaisti
:::

Tagad tev ir nepieciešamie rīki, lai turpmāk protokolus pareizi klasificētu. Sākot ar nākamo nodaļu, mēs izskatīsim slāņus pa kārtai — sākot ar 2. slāni un jautājumu, kā komutators patiesībā zina, uz kurieni jāpārsūta pakete.

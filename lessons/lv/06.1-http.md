# HTTP: tīmekļa lapas

:::goal
**Mācību mērķis:** Tu vari aprakstīt HTTP pieprasījuma un atbildes uzbūvi, izskaidrot svarīgākās metodes un statusa kodus un pats ar rokām izveidot HTTP pieprasījumu.
:::

:::sim
url=/sims/lesson-6.1.btsim
:::

**Hiperteksta pārsūtīšanas protokols** (**HTTP**, angliski *Hypertext Transfer Protocol*) ir valoda, kurā savā starpā sazinās pārlūki un tīmekļa serveri. Serverī atrodas **Beaver-Schule** tīmekļa vietne: sākumlapa, kontaktu lapa un stila lapa, kas nosaka izskatu.

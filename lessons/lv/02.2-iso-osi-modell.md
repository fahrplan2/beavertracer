# ISO/OSI references modelis

ISO/OSI modelis sadala komunikāciju starp divām ierīcēm septiņos slāņos. Katram slānim ir skaidri norobežots uzdevums, un tas izmanto tikai tieši zem tā esošā slāņa pakalpojumus:

No iepriekšējās lapas eksperimenta tu jau pazīsti četrus no šiem slāņiem: Ethernet (2), IPv4 (3), TCP (4) un HTTP (7). Tieši šos numurus un krāsas Tracer parāda protokolu kokā.

:::tip Atmiņas palīgs
No 7. slāņa uz leju: **L**ielisks **P**ārlūks **S**ūta **T**ik **T**ālu **D**atus **F**iziski — **L**ietojumu, **P**rezentācijas, **S**esijas, **T**ransporta, **T**īkla, **D**atu saites, **F**iziskais.
:::

:::note Robežgadījumi
Ne katrs protokols precīzi iekļaujas vienā slānī. Tāpēc Tracer šiem protokoliem rāda vairākus slāņus:

- **ARP** — 2./3. slānis: tam nav IP galvenes, bet tas savieno IP adreses (3. slānis) ar aparatūras adresēm (2. slānis).
- **TLS** — 4./5. slānis: tas atrodas tieši virs TCP un pārvalda drošu sesiju.
- **HTTPS** (HTTP TLS iekšienē) — 5.–7. slānis: TCP/IP modeļa klasiskais lietojumu slānis, ar kuru tu iepazīsies nākamajā lapā.
:::

:::note
1. slānis apraksta faktisko signālu pārraidi pa kabeli vai pa gaisu. BeaverTracer šo līmeni nesimulē — kabeļi vienmēr tiek uzskatīti par bezkļūdu savienotiem, signāla problēmu un kolīziju nav. Tāpēc Tracer analīze praktiski sākas ar 2. slāni.
:::

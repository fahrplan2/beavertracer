# HTTP un HTTPS salīdzinājums

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Tīmekļa serveris **www.beaver-schule.de** piedāvā skolas atzīmju portālu gan caur HTTP, gan caur HTTPS. Ko redz noklausītājs?

## Eksperiments

1. Pārslēdzies uz :fa-play: **Palaist** režīmu (Izpildes režīmu) un **Client-PC** :fa-globe: **Pārlūks** vispirms atver `http://www.beaver-schule.de/`, pēc tam `https://www.beaver-schule.de/`.
2. Atver :fa-magnifying-glass: **Izsekošana** režīmā trasējumu priekš **Client-PC**.
3. Vispirms atrodi paketi `HTTP/1.1 200 OK` un noklikšķini uz tās. Apakšā detaļās atradīsi lapas saturu.

:::quiz mc
Ko noklausītājs var redzēt, izmantojot **HTTP**?
- [x] Visu tīmekļa lapu, arī Annas atzīmes
- [ ] Tikai servera adresi
- [ ] Neko, jo HTTP darbojas pa TCP
:::

:::quiz short
Kāda atzīme Annai ir matemātikā?
= 2
:::

:::evaluate
Pārbaudīt atbildes
:::

Tagad HTTPS daļa. Atrodi `[SYN]` paketi, ar kuru klients sāk otro savienojumu.

:::quiz short
Kāds ir HTTPS savienojuma mērķa ports (kolonna **Info**, `… → ???`)?
= 443
:::

Tagad augšā trasējuma filtra laukā ievadi `tls` — tad redzēsi tikai TLS paketes.

:::quiz mc
Kas ir rakstīts kolonnā **Info** paketēm, kas satur tīmekļa lapu?
- [ ] `HTTP/1.1 200 OK`
- [x] `Application Data`
- [ ] `Encrypted HTML`
:::

:::quiz multi
Ko noklausītājs, izmantojot **HTTPS**, tomēr vēl var redzēt?
- [x] Klienta un servera IP adreses
- [x] To, ka tiek izmantots ports 443, tātad, visticamāk, HTTPS
- [x] Aptuveni cik daudz datu tiek pārsūtīts
- [ ] Kura lapa tika atvērta un kas tajā ir rakstīts
:::

:::evaluate
Pārbaudīt atbildes
:::

:::note
Noklikšķini uz **Application Data** paketes: lietderīgā slodze ir tikai šķietami nejaušu baitu virkne. Izsekotājs to nevar atšifrēt — tas sesijas atslēgu zina tikpat maz kā uzbrucējs.
:::

:::tip Iegaumējamais secinājums
Izmantojot **HTTP**, jebkurš noklausītājs var izlasīt visu tīmekļa lapu. Izmantojot **HTTPS**, viņš redz tikai to, **kas ar ko** sazinās (IP adreses, ports 443) un **cik daudz** — saturs ir šifrētā veidā **Application Data** paketēs.
:::

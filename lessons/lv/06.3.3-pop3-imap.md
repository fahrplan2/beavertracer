# POP3 vai IMAP?

:::sim
url=/sims/lesson-6.3.btsim
:::

Pastkastes satura lejupielādei ir divi protokoli. Šajā simulācijā **Anna izmanto POP3**, bet **Ben izmanto IMAP**.

## Eksperiments

1. :fa-play: **Palaist** režīmā nosūti e-pastu no **Ben** uz `anna@beaver-schule.de`.
2. Pie **Anna** lietotnē **E-Mail** noklikšķini uz **Lejupielādēt**.
3. Atver trasēšanas ierakstus (traces) priekš **Anna** un **Ben** un salīdzini komandas, kas tiek izmantotas e-pastu saņemšanai.

:::quiz match
USER / PASS -> POP3: pieteikšanās ar lietotājvārdu un paroli divos soļos
RETR -> POP3: ziņojuma lejupielāde
LOGIN -> IMAP: pieteikšanās ar lietotājvārdu un paroli
SELECT INBOX -> IMAP: mapes atvēršana serverī
:::

:::evaluate
Pārbaudīt sasaisti
:::

## Atšķirība

| | POP3 | IMAP |
|---|---|---|
| Ports | 110 | 143 |
| Pamatideja | e-pastus **lejupielādē** — pēc tam tos parasti dzēš serverī | e-pasti **paliek serverī** un tiek pārvaldīti tur |
| Mapes, izlasīts/neizlasīts | tikai savā ierīcē | serverī — visur vienādi |
| Vairākas ierīces (telefons, klēpjdators) | neērti: katrai ierīcei ir atšķirīgs stāvoklis | ideāli: visas ierīces redz vienu un to pašu pastkasti |

:::note
E-pasta programma BeaverTracer atstāj e-pastus serverī arī POP3 gadījumā. Īstas programmas pēc lejupielādes tos bieži dzēš — vai atstāj tikai uz kādu laiku.
:::

:::quiz mc
Lena lasa savus e-pastus telefonā, planšetdatorā un skolas klēpjdatorā. Ko viņai vajadzētu izmantot?
- [ ] POP3, jo tas ir vienkāršāks
- [x] IMAP, jo visas ierīces redz vienu un to pašu pastkasti serverī
- [ ] SMTP, jo tas ir paredzēts e-pastu saņemšanai
:::

:::evaluate
Pārbaudīt atbildi
:::

:::tip Iegaumējamais secinājums
**POP3** lejupielādē e-pastus no servera uz **vienu** ierīci. **IMAP** pārvalda pastkasti **serverī** — ar mapēm un izlasīšanas statusu visām ierīcēm vienlaikus. Abi kalpo tikai e-pastu **saņemšanai**; sūtīšana vienmēr notiek ar **SMTP**.
:::

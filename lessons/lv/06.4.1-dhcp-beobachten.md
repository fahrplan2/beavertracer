# Adreses automātiska iegūšana

:::sim
url=/sims/lesson-6.4.btsim
:::

Pie slēdža ir pieslēgts **DHCP-serveris** un divi portatīvie datori. Portatīviem datoriem vēl ir fiksētas adreses.

## Eksperiments

1. Pārslēdzies uz :fa-play: **Palaist** režīmu (Izpildes režīms), noklikšķini uz **Laptop 1** un atver :fa-gear: **IP iestatījumi**.
2. Nomaini **Modus** no **Statisks** uz **DHCP** un noklikšķini uz **Pielietot**.
3. Pagaidi dažas sekundes: lauki aizpildās paši.
4. :fa-magnifying-glass: **Izsekošana** režīmā atver izsekošanu (trace) priekš **Laptop 1**.

:::quiz table
| Iestatījums | saņemts no DHCP servera |
|---|---|
| IP adrese | {192.168.0.100} |
| Vārteja | {192.168.0.1} |
| DNS serveris | {192.168.0.53} |
:::

:::quiz short
Cik DHCP pakešu tu atrodi izsekošanā?
= 4
= četras
:::

:::quiz mc
Uz kādu mērķa IP adresi Laptop 1 sūta savu pirmo paketi (`DHCP Discover`)?
- [ ] Uz DHCP serveri `192.168.0.2`
- [x] Uz `255.255.255.255` — visiem (apraide)
- [ ] Uz vārteju `192.168.0.1`
:::

:::quiz mc
Kāda sūtītāja IP adrese ir šai pirmajai paketei — un kāpēc?
- [x] `0.0.0.0` — portatīvajam datoram vēl vispār nav adreses
- [ ] `192.168.0.10` — tā vecā adrese
- [ ] `192.168.0.100` — tā jaunā adrese
:::

## Kas slēpjas aiz tā: DORA

Ierīce bez adreses nezina, kur atrodas DHCP serveris, un tai nav arī savas sūtītāja adreses. Tāpēc tā izsaucas tīklā ar **apraidi** (broadcast). Process sastāv no četriem soļiem — pēc to sākumburtiem **DORA**:

:::seq
mode: text
Laptop 1 -> DHCP-Server: DHCP Discover | „Vai šeit ir DHCP serveris?“
DHCP-Server -> Laptop 1: DHCP Offer | „Tu vari saņemt 192.168.0.100.“
Laptop 1 -> DHCP-Server: DHCP Request | „Es ņemu 192.168.0.100.“
DHCP-Server -> Laptop 1: DHCP ACK | „Apstiprināts — derīgs 3600 sekundes.“
:::

Adrese tiek tikai **aizdota** (*Lease*): pēc **nomas laika** (lease time) beigām ierīcei tā ir jāpagarina, citādi serveris to drīkst izsniegt no jauna. Kuras adreses pašlaik ir aizdotas, tu redzi **DHCP serveris** cilnē **Leases**.

:::tip Izmēģini pats
Iestati arī **Laptop 2** uz DHCP. Kādu adresi tas saņem? Pēc tam apskaties DHCP servera **Leases**.
:::

:::tip Iegaumējamais secinājums
**DHCP** automātiski izsniedz IP adresi, tīkla masku, vārteju un DNS serveri. Process saucas **DORA**: **D**iscover (klients meklē ar apraidi), **O**ffer (serveris piedāvā), **R**equest (klients pieņem), **A**CK (serveris apstiprina). Adrese tiek aizdota uz **nomas laiku**. DHCP izmanto **UDP**, portu 67 (serveris) un 68 (klients).
:::

:::quiz match
Discover -> Klients ar apraidi meklē DHCP serveri
Offer -> Serveris piedāvā adresi
Request -> Klients pieprasa piedāvāto adresi
ACK -> Serveris apstiprina piešķiršanu
:::

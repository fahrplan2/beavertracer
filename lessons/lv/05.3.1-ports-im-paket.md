## Eksperiments

1. Pārslēdzies uz :fa-play: **Palaist** režīmu (Izpildes režīmu), noklikšķini uz **Client-PC** un atver :fa-globe: **Pārlūks**. Atver `http://192.168.0.20/`.
2. Loga augšdaļā noklikšķini uz **Zurück**, atver **Vienkāršs TCP klients** un savieno to ar `192.168.0.20`, ports `5000`. Atstāj savienojumu atvērtu.
3. Pārslēdzies uz :fa-magnifying-glass: **Izsekošana** režīmu, atver izsekošanu priekš **Client-PC** un noklikšķini uz paketes ar `[SYN]`. Izvērs **Transmission Control Protocol**.

TCP galvenes pašā augšā ir divi porti: **Source Port** (avota ports) un **Destination Port** (mērķa ports).

:::quiz table
| Savienojums | Avota ports | Mērķa ports |
|---|---|---|
| Pārlūks → tīmekļa serveris | {49152} | {80} |
| TCP klients → atbalss pakalpojums | {49153} | {5000} |
:::

## Divu veidu porti

**Mērķa ports — pakalpojums:** servera programma gaida savienojumus noteiktā portā — saka, ka tā **klausās** šajā portā. Zināmiem pakalpojumiem numuri ir noteikti visā pasaulē — tie ir **Well-known porti** (no 0 līdz 1023). Tāpēc pārlūks bez jautāšanas zina: tīmekļa serveri klausās 80. portā.

**Avota ports — sūtītājs:** Porta numuru klienta pusē operētājsistēma katram jaunam savienojumam pati izvēlas no augsta diapazona (BeaverTracer sākot no 49152). Pēc tā klients atpazīst, kuram no viņa savienojumiem pieder atbilde.

Savienojumu tātad viennozīmīgi nosaka četri lielumi: **IP adrese un ports abās pusēs**. IP adreses un porta pāri sauc par **sokeju (socket)**, piemēram, `192.168.0.20:80`.

## Skats uz serveri

Pārslēdzies atpakaļ uz :fa-play: **Palaist** režīmu, atver uz **Server** :fa-terminal: **Termināls** un ievadi:

```
$ ss
```

`ss` parāda visus datora sokešus. Rindas ar `LISTEN` ir programmas, kas klausās kādā portā. Rindas ar `ESTABLISHED` ir izveidoti savienojumi — ar paša sokeju (*Local Address:Port*) un pretējās puses sokeju (*Peer Address:Port*).

:::quiz multi
Kuros portos klausās serveris?
- [x] 80
- [x] 5000
- [ ] 49152
- [ ] 443
:::

:::quiz mc
Kuru savienojumu `ss` parāda kā `ESTABLISHED`?
- [x] `192.168.0.20:5000` ar `192.168.0.10:49153` — TCP klienta atvērtais savienojums
- [ ] `192.168.0.20:80` ar `192.168.0.10:49152` — pārlūka savienojums
- [ ] Abus
:::

:::note
Pārlūka savienojums jau ir pārtraukts — pēc lapas ielādes tas tika beigts ar `FIN`. `ss` to vēl īsu brīdi rāda kā `TIME-WAIT`: serveris kādu laiku gaida, vai vēl nepienāks aizkavētas šī savienojuma paketes. Savukārt TCP klienta savienojums vēl ir atvērts, jo tu vēl neesi noklikšķinājis uz **Atvienot**.
:::

## Svarīgākie Well-known porti

| Ports | Protokols | Pakalpojums |
|---|---|---|
| 22 | SSH | droša attālinātā administrēšana (šifrēta komandrinda) |
| 25 | SMTP | e-pasta sūtīšana |
| 53 | DNS | vārdu pārvēršana IP adresēs (parasti izmantojot UDP) |
| 80 | HTTP | tīmekļa lapas |
| 110 | POP3 | e-pasta saņemšana |
| 143 | IMAP | e-pasta pārvaldība serverī |
| 443 | HTTPS | šifrētas tīmekļa lapas |

:::tip Iegaumējamais secinājums
**Porti** (no 0 līdz 65535) nošķir savienojumus vienā datorā. Servera pakalpojumi **klausās** noteiktos **Well-known portos** (piem., HTTP 80, HTTPS 443), klienti katram savienojumam saņem brīvu augstu **avota portu**. Savienojumu viennozīmīgi nosaka **abu pušu IP adrese un ports**.
:::

:::quiz match
22 -> SSH
25 -> SMTP
53 -> DNS
80 -> HTTP
110 -> POP3
143 -> IMAP
443 -> HTTPS
:::

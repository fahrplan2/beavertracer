## Eksperiments

1. Pārslēdzies uz :fa-play: **Palaist** režīmu (Izpildes režīms), noklikšķini uz **Client-PC** un atver :fa-globe: **Pārlūks**.
2. Šoreiz atver `http://www.beaver-schule.de/` — ar vārdu, nevis IP adresi.
3. Pārslēdzies uz :fa-magnifying-glass: **Izsekošana** režīmu un atver trasējumu (trace) priekš **Client-PC**.

Pašā sākumā — vēl pirms savienojuma izveides ar `[SYN]` — ir divas paketes ar protokolu **DNS**.

:::quiz short
Uz kādu IP adresi Client-PC sūta savu DNS pieprasījumu?
= 192.168.0.53
:::

:::quiz short
Kāda IP adrese ir atbildē uz `www.beaver-schule.de`?
= 192.168.0.20
:::

:::quiz mc
Noklikšķini uz DNS pieprasījuma un izvērs protokolu koku. Kurš transporta protokols un kurš mērķa ports tiek izmantots?
- [ ] TCP, ports 80
- [x] UDP, ports 53
- [ ] UDP, ports 67
:::

:::evaluate
Pārbaudīt atbildes
:::

Tikai pēc tam, kad Client-PC zina IP adresi, tas izveido TCP savienojumu ar tīmekļa serveri — tieši tāpat kā 5. nodaļā.

:::seq
mode: text
Client-PC -> DNS-Resolver: DNS-Anfrage | A www.beaver-schule.de?
DNS-Resolver -> Client-PC: DNS-Antwort | A 192.168.0.20
:::

## No kurienes dators zina DNS serveri?

Atver **Client-PC** :fa-gear: **IP iestatījumi**: laukā **DNS-Server** ir `192.168.0.53` — dators **DNS-Resolver**. Uz to dators sūta katru vārda pieprasījumu.

Tu vari DNS serverim jautāt arī tieši, bez pārlūka. Atver :fa-terminal: **Termināls** un ievadi:

```
$ nslookup www.beaver-schule.de
```

`nslookup` vispirms parāda, kuram serverim tas jautāja, un pēc tam atbildi. Salīdzinājumam pajautā pēc vārda, kura nav, piemēram, `nslookup gibtsnicht.beaver-schule.de`.

:::quiz mc
Ko DNS serveris atbild uz nezināmo vārdu?
- [ ] Nejaušu IP adresi
- [x] `NXDOMAIN` — šāda vārda nav
- [ ] Neko
:::

:::evaluate
Pārbaudīt atbildi
:::

:::tip Iegaumējamais secinājums
**DNS** pārvērš vārdus (piemēram, `www.beaver-schule.de`) IP adresēs. Pirms dators var izveidot savienojumu ar vārdu, tas pajautā **DNS serverim**, kas norādīts tā IP iestatījumos — parasti izmantojot **UDP, portu 53**. Ar `nslookup` tu vari DNS pieprasījumus veikt manuāli.
:::

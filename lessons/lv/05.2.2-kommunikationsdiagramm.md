# Sekvenču diagramma

:::sim
url=/sims/lesson-5.1.btsim
:::

Savienojuma norisi zīmē kā **sekvenču diagrammu**: klients un serveris saņem katrs pa vertikālai līnijai, laiks plūst no augšas uz leju. Katra bulta ir viena pakete. Tā ir uzzīmēta slīpi, jo katra pakete kādu brīdi atrodas ceļā.

Šādi izskatās tavs savienojums no iepriekšējās lapas — salīdzini to rindu pa rindai ar izsekošanas ierakstu:

:::seq
Client-PC -> Server: SYN
Server -> Client-PC: SYN, ACK
Client-PC -> Server: ACK
Client-PC -> Server: PSH, ACK "Hello World" len=13
Server -> Client-PC: ACK
Server -> Client-PC: PSH, ACK len=13
Client-PC -> Server: ACK
Client-PC -> Server: FIN, ACK
Server -> Client-PC: ACK
Server -> Client-PC: FIN, ACK
Client-PC -> Server: ACK
:::

Virs katras bultas ir **karodziņi** (flags), zem tās — numuri `SEQ` un `ACK`. **DATA** apzīmē paketes ar lietderīgajiem datiem. Sarkanie skaitļi pieder klientam, zilie — serverim; ko tie nozīmē, paskaidrots nākamajā lapā.

## Karodziņi

| Karodziņš | apzīmē | Nozīme |
|---|---|---|
| **SYN** | *synchronize* | izveidot savienojumu, noteikt sākuma numuru |
| **ACK** | *acknowledge* | apstiprina saņemtos datus |
| **PSH** | *push* | nekavējoties nodot datus programmai |
| **FIN** | *finish* | „Esmu pabeidzis” — pārtraukt savienojumu |
| **RST** | *reset* | pārtraukt vai noraidīt savienojumu (vairāk par to 5.3.2) |

## Trīs fāzes

**Izveide:** klients nosūta `SYN`, serveris atbild ar `SYN, ACK`, klients apstiprina ar `ACK`. Tā kā nepieciešamas tieši trīs paketes, to sauc par **trīspusējo rokasspiedienu** (three-way handshake).

**Dati:** katru paketi ar datiem saņēmējs apstiprina ar `ACK`. Šeit serveris sūta atbalsi atpakaļ — arī to klients apstiprina.

**Pārtraukšana:** katra puse savu sūtīšanas virzienu beidz atsevišķi: `FIN` no klienta, `ACK` no servera — pēc tam `FIN` no servera, `ACK` no klienta. Tās ir četras paketes.

:::tip Iegaumējamais secinājums
TCP savienojums norit trijās fāzēs: **izveide** ar **trīspusējo rokasspiedienu** (`SYN` → `SYN, ACK` → `ACK`), **datu pārraide** (katra datu pakete tiek apstiprināta ar `ACK`) un **pārtraukšana** (katra puse sūta `FIN` un saņem `ACK`).
:::

## Tagad tu

Klients šoreiz sūta tikai `Hi` (ar rindas beigu zīmi — 4 baiti). Ieraksti trūkstošos karodziņus — secība vienā laukā nav svarīga.

:::quiz seq
hide: counters
Client-PC -> Server: ? SYN
Server -> Client-PC: ? SYN, ACK
Client-PC -> Server: ? ACK
Client-PC -> Server: PSH, ACK "Hi" len=4
Server -> Client-PC: ? ACK
Client-PC -> Server: ? FIN, ACK
Server -> Client-PC: ? ACK
Server -> Client-PC: ? FIN, ACK
Client-PC -> Server: ? ACK
:::

## Eksperiment

1. Pređi u režim :fa-play: **Pokreni** (Režim izvršavanja), klikni na **Client-PC** i otvori :fa-globe: **Pregledač**. Učitaj `http://192.168.0.20/`.
2. Klikni na **Zurück** na vrhu prozora, otvori **Jednostavni TCP klijent** i poveži ga sa `192.168.0.20`, port `5000`. Ostavi vezu otvorenom.
3. Pređi u režim :fa-magnifying-glass: **Praćenje**, otvori trag (trace) za **Client-PC** i klikni na paket sa `[SYN]`. Otvori **Transmission Control Protocol**.

Sasvim na vrhu TCP zaglavlja nalaze se dva porta: **Source Port** (izvorni port) i **Destination Port** (odredišni port).

:::quiz table
| Veza | Izvorni port | Odredišni port |
|---|---|---|
| Pregledač → veb server | {49152} | {80} |
| TCP klijent → eho servis | {49153} | {5000} |
:::

## Dve vrste portova

**Odredišni port — servis:** Serverski program čeka veze na fiksnom portu — kaže se da tamo **osluškuje**. Za poznate servise brojevi su utvrđeni na svetskom nivou, to su **Well-known portovi** (od 0 do 1023). Zato pregledač zna bez pitanja: veb serveri osluškuju na portu 80.

**Izvorni port — pošiljalac:** Port na strani klijenta operativni sistem sam bira za svaku novu vezu iz visokog opsega (u programu BeaverTracer od 49152). Po njemu klijent prepoznaje kojoj od njegovih veza pripada odgovor.

Veza je, dakle, jednoznačno određena sa četiri podatka: **IP adresom i portom na obe strane**. Par koji čine IP adresa i port naziva se **socket**, npr. `192.168.0.20:80`.

## Pogled na server

Vrati se u režim :fa-play: **Pokreni**, na **Server**-u otvori :fa-terminal: **Terminal** i unesi:

```
$ ss
```

`ss` prikazuje sve sokete računara. Redovi sa `LISTEN` su programi koji osluškuju na nekom portu. Redovi sa `ESTABLISHED` su postojeće veze — sa sopstvenim soketom (*Local Address:Port*) i soketom druge strane (*Peer Address:Port*).

:::quiz multi
Na kojim portovima server osluškuje?
- [x] 80
- [x] 5000
- [ ] 49152
- [ ] 443
:::

:::quiz mc
Koju vezu `ss` prikazuje kao `ESTABLISHED`?
- [x] `192.168.0.20:5000` sa `192.168.0.10:49153` — otvorena veza TCP klijenta
- [ ] `192.168.0.20:80` sa `192.168.0.10:49152` — veza pregledača
- [ ] Obe
:::

:::note
Veza pregledača je već raskinuta — nakon učitavanja stranice prekinuta je pomoću `FIN`. `ss` je još kratko prikazuje kao `TIME-WAIT`: server neko vreme čeka da vidi hoće li stići zakasneli paketi ove veze. Veza TCP klijenta je, nasuprot tome, još otvorena jer još nisi kliknuo na **Iskopčajte se**.
:::

## Najvažniji Well-known portovi

| Port | Protokol | Servis |
|---|---|---|
| 22 | SSH | bezbedno daljinsko održavanje (šifrovana komandna linija) |
| 25 | SMTP | slanje e-pošte |
| 53 | DNS | prevođenje imena u IP adrese (najčešće preko UDP-a) |
| 80 | HTTP | veb stranice |
| 110 | POP3 | preuzimanje e-pošte |
| 143 | IMAP | upravljanje e-poštom na serveru |
| 443 | HTTPS | šifrovane veb stranice |

:::tip Zapamti
**Portovi** (od 0 do 65535) razdvajaju veze na jednom računaru. Serverski servisi **osluškuju** na fiksnim **Well-known portovima** (npr. HTTP 80, HTTPS 443), a klijenti za svaku vezu dobijaju slobodan visok **izvorni port**. Veza je jednoznačno određena **IP adresom i portom obe strane**.
:::

:::quiz match
22 -> SSH
25 -> SMTP
53 -> DNS
80 -> HTTP
110 -> POP3
143 -> IMAP
443 -> HTTPS
:::

# POP3 ili IMAP?

:::sim
url=/sims/lesson-6.3.btsim
:::

Za preuzimanje pošte postoje dva protokola. U ovoj simulaciji **Anna koristi POP3**, a **Ben IMAP**.

## Eksperiment

1. U :fa-play: režimu **Pokreni** pošalji mejl od **Ben** na `anna@beaver-schule.de`.
2. Kod **Anna** u aplikaciji **E-Mail** klikni na **Učitaj**.
3. Otvori tragove (trace) za **Anna** i za **Ben** i uporedi komande pri preuzimanju.

:::quiz match
USER / PASS -> POP3: prijavljivanje korisničkim imenom i lozinkom u dva koraka
RETR -> POP3: preuzimanje jedne poruke
LOGIN -> IMAP: prijavljivanje korisničkim imenom i lozinkom
SELECT INBOX -> IMAP: otvaranje fascikle na serveru
:::

:::evaluate
Proveri povezivanje
:::

## Razlika

| | POP3 | IMAP |
|---|---|---|
| Port | 110 | 143 |
| Osnovna ideja | Poruke se **preuzimaju** — nakon toga se obično brišu sa servera | Poruke **ostaju na serveru** i tamo se njima upravlja |
| Fascikle, pročitano/nepročitano | samo na sopstvenom uređaju | na serveru — svuda isto |
| Više uređaja (telefon, laptop) | nepraktično: svaki uređaj ima drugačije stanje | idealno: svi uređaji vide isto poštansko sanduče |

:::note
Program za e-poštu u BeaverTracer-u ostavlja poruke na serveru i kod POP3. Pravi programi ih nakon preuzimanja često brišu — ili ih ostave samo neko vreme.
:::

:::quiz mc
Lena čita svoju poštu na telefonu, tabletu i školskom laptopu. Šta bi trebalo da koristi?
- [ ] POP3, jer je jednostavniji
- [x] IMAP, jer svi uređaji vide isto poštansko sanduče na serveru
- [ ] SMTP, jer je namenjen za preuzimanje
:::

:::tip Zapamti
**POP3** preuzima poruke sa servera na **jedan** uređaj. **IMAP** upravlja poštanskim sandučetom **na serveru** — sa fasciklama i statusom pročitano/nepročitano istovremeno za sve uređaje. Oba služe samo za **preuzimanje**; slanje se uvek obavlja pomoću **SMTP**-a.
:::

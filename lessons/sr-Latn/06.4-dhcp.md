# DHCP: automatski u mrežu

:::goal
**Cilj učenja:** Možeš da objasniš kako uređaj putem DHCP-a automatski dobija svoje IP postavke, da podesiš DHCP Server i da prepoznaš i otkloniš tipične DHCP greške (npr. adresu 169.254).
:::

:::sim
url=/sims/lesson-6.4.btsim
:::

Do sada si svakom uređaju ručno upisivao IP adresu, mrežnu masku, mrežni prolaz (gateway) i DNS server. U školi sa stotinama laptopova, tableta i mobilnih telefona to bi bilo nemoguće — a svaka greška u kucanju bila bi greška u mreži.

Taj posao preuzima **Dynamic Host Configuration Protocol** (**DHCP**): **DHCP Server** automatski distribuira postavke svakom uređaju koji se priključi na mrežu.

# Kako je DNS organizovan

:::sim
url=/sims/lesson-6.2.btsim
:::

Nijedan pojedinačni server ne može da zna sva imena na svetu. Zato je DNS izgrađen **hijerarhijski** — kao i sama imena. Čitaju se sdesna nalevo:

```
www . beaver-schule . de . (Root)
 │          │         │      └─ Root-Server: kennen die Server aller Top-Level-Domains
 │          │         └─ Top-Level-Domain (TLD): der de-Server kennt alle .de-Domains
 │          └─ Domain: der Schul-DNS ist für beaver-schule.de zuständig
 └─ Rechnername innerhalb der Domain
```

Server koji je nadležan za neki domen i zaista zna odgovor naziva se **autoritativni**. Put do njega za PC preuzima **resolver** — ovde je to računar **DNS-Resolver**.

## Eksperiment

1. Pređi u :fa-play: **Režim izvršavanja** i na računaru **Client-PC** u :fa-terminal: **Terminal**u unesi:
   ```
   $ nslookup www.beaver-schule.de
   ```
2. U :fa-magnifying-glass: režimu **Praćenje** otvori trag (trace) za **DNS-Resolver**.

Resolver je umesto tebe postavio čitav niz upita. Upari ko je dao koji odgovor:

:::quiz match
Root-Server (192.168.0.101) -> Upućivanje: Za .de je nadležan ns.nic.de
de-Server (192.168.0.102) -> Upućivanje: Za beaver-schule.de je nadležan ns.beaver-schule.de
Schul-DNS (192.168.0.103) -> Odgovor: www.beaver-schule.de ima adresu 192.168.0.20
:::

:::quiz mc
Koga resolver pita prvog?
- [x] Root server
- [ ] Schul-DNS
- [ ] Client-PC
:::

:::evaluate
Proveri odgovore
:::

:::note
Usput resolver pita i za adrese servera na koje je upućen (`A ns.nic.de`). Pravi DNS serveri te adrese obično odmah pošalju zajedno sa odgovorom. Osim toga, resolveri pamte svaki odgovor neko vreme (**keš**) — na sledeći upit za isto ime odgovaraju odmah sami. Koliko dugo, piše u zapisu kao **TTL** (*Time to Live*) u sekundama.
:::

## Najvažniji tipovi zapisa

| Tip | Značenje | Primer |
|---|---|---|
| **A** | ime → IPv4 adresa | `www.beaver-schule.de` → `192.168.0.20` |
| **AAAA** | ime → IPv6 adresa | `www.beaver-schule.de` → `2001:db8::20` |
| **CNAME** | ime → drugo ime (alias) | `web.beaver-schule.de` → `www.beaver-schule.de` |
| **MX** | nadležni mejl server domena | `beaver-schule.de` → `mail.beaver-schule.de` |
| **NS** | nadležni DNS server domena | `beaver-schule.de` → `ns.beaver-schule.de` |

:::tip Zapamti
DNS je **hijerarhijski**: **root serveri** upućuju na servere **top-level domena** (npr. `.de`), a oni na servere pojedinačnih **domena**. Nadležni **autoritativni** server zna odgovor. **Resolver** prelazi taj put umesto PC-a i pamti odgovore (**keš**). Važni tipovi zapisa: **A**, **AAAA**, **CNAME**, **MX**, **NS**.
:::

## Kreiranje zapisa

Škola želi da njena veb stranica bude dostupna i na adresi `intranet.beaver-schule.de`.

1. U :fa-play: **Režimu izvršavanja** klikni na **Schul-DNS** i otvori aplikaciju **DNS-Server**.
2. Otvori karticu **A**. Klikni na **+** i u novi red upiši ime `intranet.beaver-schule.de` i adresu `192.168.0.20`.
3. Testiraj na računaru Client-PC pomoću `nslookup intranet.beaver-schule.de`.

title: Da li je novo ime upisano?
Proverite da li Client-PC razrešava ime intranet.beaver-schule.de u adresu veb servera. Simulacija za to mora da radi u režimu izvršavanja.
check: resolves(2, "intranet.beaver-schule.de", "192.168.0.20")
:::

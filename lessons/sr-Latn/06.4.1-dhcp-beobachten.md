# Automatsko dobijanje adrese

:::sim
url=/sims/lesson-6.4.btsim
:::

Na switch su povezani **DHCP Server** i dva laptopa. Laptopi još uvek imaju fiksne adrese.

## Eksperiment

1. Pređi u :fa-play: **Režim izvršavanja**, klikni na **Laptop 1** i otvori :fa-gear: **IP postavke**.
2. Promeni **Režim** sa **Statički** na **DHCP** i klikni na **Primeni**.
3. Sačekaj nekoliko sekundi: polja se popunjavaju sama.
4. U :fa-magnifying-glass: **Praćenje** režimu otvori trace za **Laptop 1**.

:::quiz table
| Postavka | dobijeno od DHCP servera |
|---|---|
| IP adresa | {192.168.0.100} |
| Gateway | {192.168.0.1} |
| DNS server | {192.168.0.53} |
:::

:::quiz short
Koliko DHCP paketa pronalaziš u trace-u?
= 4
= četiri
:::

:::quiz mc
Na koju odredišnu IP adresu Laptop 1 šalje svoj prvi paket (`DHCP Discover`)?
- [ ] Na DHCP server `192.168.0.2`
- [x] Na `255.255.255.255` — svima (broadcast)
- [ ] Na gateway `192.168.0.1`

:::quiz mc

## Šta se krije iza toga: DORA

Uređaj bez adrese ne zna gde se nalazi DHCP server, a nema ni sopstvenu adresu pošiljaoca. Zato se **broadcastom** obraća celoj mreži. Postupak ima četiri koraka — nazvan prema početnim slovima **DORA**:

:::seq
mode: text
Laptop 1 -> DHCP-Server: DHCP Discover | „Ima li ovde DHCP servera?“
DHCP-Server -> Laptop 1: DHCP Offer | „Možeš dobiti 192.168.0.100.“
Laptop 1 -> DHCP-Server: DHCP Request | „Uzimam 192.168.0.100.“
DHCP-Server -> Laptop 1: DHCP ACK | „Potvrđeno — važi 3600 sekundi.“
:::

Adresa je samo **pozajmljena** (*lease*): po isteku **lease vremena** uređaj mora da je produži, inače server sme ponovo da je dodeli. Koje su adrese trenutno izdate, vidiš na **DHCP Serveru** u kartici **Leases**.

:::tip Probaj sam
Podesi i **Laptop 2** na DHCP. Koju adresu dobija? Zatim pogledaj **Leases** na DHCP serveru.
:::

:::tip Zapamti
**DHCP** automatski dodeljuje IP adresu, mrežnu masku, gateway i DNS server. Postupak se zove **DORA**: **D**iscover (klijent traži broadcastom), **O**ffer (server nudi), **R**equest (klijent prihvata), **A**CK (server potvrđuje). Adresa je pozajmljena na **lease vreme**. DHCP koristi **UDP**, port 67 (server) i 68 (klijent).
:::

:::quiz match
Discover -> Klijent broadcastom traži DHCP server
Offer -> Server nudi adresu
Request -> Klijent traži ponuđenu adresu
ACK -> Server potvrđuje dodelu
:::

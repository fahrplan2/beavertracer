# Pozivanje i posmatranje veb stranice

Za ovaj deo ne gradiš ništa sam: na radnoj površini se nalazi pripremljena simulacija sa jednim **Client-PC** i jednim **Webserver**.

## Pozivanje stranice

1. Pređi u režim :fa-play: **Pokreni**.
2. Na **Client-PC** otvori aplikaciju :fa-globe: **Pregledač** i unesi adresu veb servera: `http://192.168.0.20/`.
3. Pređi u režim :fa-magnifying-glass: **Praćenje** i pomoću **+** otvori trace za **Client-PC**, priključak `eth0` — potpuno isto kao kod pinga.

:::note
Za jedno jedino pozivanje stranice ovo je iznenađujuće mnogo paketa — znatno više nego kod pinga. Učitavanje veb stranice je višestepeni proces, a ne jedna pojedinačna radnja.
:::

## Čitanje liste paketa

Još ne moraš da znaš šta tačno rade pojedini protokoli. Sve što ti treba za sledeća pitanja nalazi se u kolonama **Protokol** i **Info**.

:::quiz mc
Koji protokol se nalazi na samom vrhu liste?
- [x] ARP
- [ ] TCP
- [ ] HTTP
:::

:::quiz short
Prebroj: koliko **TCP** paketa stoji pre prvog **HTTP** paketa?
= 3
= tri
:::

:::quiz mc
Šta veb server odgovara na zahtev pregledača? Pogledaj kolonu Info drugog HTTP paketa.
- [ ] GET / HTTP/1.1
- [x] HTTP/1.1 200 OK
- [ ] 404 Not Found
:::

Proveri odgovore
:::

## Imenovanje uključenih protokola

Iz svojih zapažanja sada možeš da pročitaš koji je protokol za šta bio zadužen.

:::tip Savet
Pročitaj još jednom kolone **Info**: `Who has …?`, `[SYN]`, `[SYN, ACK]`, `[ACK]`, `GET /` i `200 OK` odaju skoro sve.
:::

:::quiz match
ARP -> Pita sve u mreži: „Ko ima IP adresu 192.168.0.20?“
TCP -> Uspostavlja vezu pomoću tri kratka paketa pre nego što podaci počnu da teku
HTTP -> Zahteva veb stranicu (GET) i vraća je (200 OK)
:::

:::evaluate
Proveri povezivanje
:::

:::tip Zapamti
Pozivanje veb stranice odvija se u stepenima: prvo **pronaći** server u mreži (ARP), zatim **uspostaviti** vezu (TCP), pa **zatražiti i isporučiti** stranicu (HTTP) — i na kraju vezu ponovo **raskinuti** (TCP paketi sa `[FIN]` na kraju liste).
:::

:::note
Ovaj put si IP adresu servera uneo direktno, pa **DNS** („prevođenje“ imena poput `www.beispiel.de` u IP adresu) još nije došao do izražaja. To nadoknađujemo u 6. poglavlju.
:::

Da li si primetio da protokoli u strukturi paketa nose obojene oznake sa brojevima? Šta je s tim, objasnićemo u 2. poglavlju. Tamo ćemo videti kako se brojni protokoli sistematski razvrstavaju — pomoću OSI i TCP/IP referentnog modela. Time je 1. poglavlje završeno.

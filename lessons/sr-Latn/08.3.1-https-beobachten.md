# HTTP i HTTPS u poređenju

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Veb server **www.beaver-schule.de** nudi školski portal sa ocenama i preko HTTP-a i preko HTTPS-a. Šta vidi neko ko prisluškuje?

## Eksperiment

1. Pređi u :fa-play: **Pokreni** režim (Režim izvršavanja) i na **Client-PC** u :fa-globe: **Pregledač** prvo otvori `http://www.beaver-schule.de/`, a zatim `https://www.beaver-schule.de/`.
2. U :fa-magnifying-glass: **Praćenje** režimu otvori trace za **Client-PC**.
3. Prvo pronađi paket `HTTP/1.1 200 OK` i klikni na njega. Dole u detaljima ćeš naći sadržaj stranice.

:::quiz mc
Šta onaj ko prisluškuje može da vidi kod **HTTP-a**?
- [x] Celu veb stranicu, uključujući i Anine ocene
- [ ] Samo adresu servera
- [ ] Ništa, jer HTTP radi preko TCP-a
:::

:::quiz short
Koju ocenu ima Anna iz matematike?
= 2
:::

:::evaluate
Proveri odgovore
:::

Sada sledi HTTPS deo. Pronađi paket `[SYN]` kojim klijent započinje drugu vezu.

:::quiz short
Koji odredišni port ima HTTPS veza (kolona **Info**, `… → ???`)?
= 443
:::

Sada u polje za filter na vrhu trace-a upiši `tls` — tada ćeš videti samo TLS pakete.

:::quiz mc
Šta piše u koloni **Info** kod paketa koji sadrže veb stranicu?
- [ ] `HTTP/1.1 200 OK`
- [x] `Application Data`
- [ ] `Encrypted HTML`
:::

:::quiz multi
Šta onaj ko prisluškuje i kod **HTTPS-a** ipak može da vidi?
- [x] IP adrese klijenta i servera
- [x] Da se koristi port 443, dakle verovatno HTTPS
- [x] Otprilike koliko se podataka prenosi
- [ ] Koja je stranica otvorena i šta se na njoj nalazi
:::

:::evaluate
Proveri odgovore
:::

:::note
Klikni na paket **Application Data**: korisni podaci su samo niz naizgled nasumičnih bajtova. Tracer ih ne može dešifrovati — ključ sesije ne poznaje ništa više nego napadač.
:::

:::tip Zapamti
Kod **HTTP-a** svako ko prisluškuje može da pročita celu veb stranicu. Kod **HTTPS-a** vidi samo **ko s kim** komunicira (IP adrese, port 443) i **koliko** podataka — sadržaj je šifrovan unutar paketa **Application Data**.
:::

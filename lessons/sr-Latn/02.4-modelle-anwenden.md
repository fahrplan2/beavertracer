# Primena modela

Dodeli protokole iz eksperimenta s početka poglavlja njihovom OSI sloju:

:::quiz match
Ethernet -> Sloj 2 — Veza podataka
IPv4 -> Sloj 3 — Mrežni sloj
TCP -> Sloj 4 — Transport
HTTP -> Sloj 7 — Aplikacija
:::

:::evaluate
Proveri dodelu
:::

I na kraju nazivi jedinica podataka:

:::quiz match
Frame -> Sloj 2 — Veza podataka
Paket -> Sloj 3 — Mrežni sloj
Segment -> Sloj 4 — Transport
:::

:::evaluate
Proveri dodelu
:::

Time imaš alat da ubuduće pravilno razvrstavaš protokole. Od sledećeg poglavlja prolazimo kroz slojeve redom — počevši od sloja 2 i pitanja kako switch zapravo zna kuda mora da prosledi paket.

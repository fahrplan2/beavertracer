# Rezime i pogled unapred

## Firewall-ovi na mnogim mestima

Paketski filter iz ovog poglavlja možeš pronaći u mnogim uređajima:

- **Kućni ruter:** Svaki kućni ruter je ujedno i firewall koji prati stanje veze (stateful). Kod IPv4 deo toga preuzima NAT: Spolja niko ne može da započne vezu dok ne postoji prosleđivanje porta (poglavlje 7). Kod IPv6 svi uređaji imaju javne adrese — tada isti nivo zaštite obezbeđuje samo firewall pravilo „spolja ništa novo ne ulazi“.
- **Personal Firewall:** I Windows, macOS i Linux imaju ugrađen firewall na samom računaru. On štiti uređaj i u tuđim mrežama, npr. na Wi-Fi mreži nekog kafića, i može da postavlja pravila po programu.
- **Next-Generation-Firewall** i **Web Application Firewall (WAF):** Oni ne gledaju samo adrese i portove, već i sadržaj paketa — sve do aplikativnog sloja. Tako, na primer, prepoznaju napade u HTTP zahtevima. Kod HTTPS-a zbog toga moraju da razbiju enkripciju (poglavlje 8).
- **IDS/IPS:** *Intrusion Detection System* prepoznaje sumnjive obrasce u saobraćaju i podiže alarm; *Intrusion Prevention System* ih dodatno i sam blokira.

:::note
Firewall je samo **jedan** element bezbednosti. Ne pomaže ako sama dozvoljena usluga (npr. veb server) ima ranjivost, ako neko otvori zlonamerni program iz e-pošte ili ako je lozinka slaba. Zato ažuriranja, sigurne lozinke, enkripcija i promišljena podela mreže (DMZ, VLAN-ovi iz poglavlja 3) uvek spadaju u celinu.
:::

## Testiraj se

:::quiz mc
Firewall radi sa podrazumevanom politikom „Odbaci sve“ i jednim jedinim pravilom „A → B, TCP 443, Dozvoli“. Paket A → B stiže na TCP port 22. Šta se dešava?
- [ ] Biće dozvoljen
- [x] Biće odbačen
- [ ] Biće odbijen
:::

:::quiz mc
`nmap` za neki port prijavljuje `filtered`. Šta to znači?
- [ ] Na portu radi neka usluga
- [ ] Server je odgovorio sa RST
- [x] Nije stigao nikakav odgovor — verovatno firewall odbacuje pakete
:::

:::quiz multi
Koje tvrdnje su tačne?
- [x] Kod stateful firewall-a odgovori na dozvoljene veze automatski prolaze nazad
- [x] Bela lista je sigurnija od crne liste, jer nove usluge automatski ostaju blokirane
- [x] Serveri koji su dostupni sa interneta spadaju u DMZ
- [ ] Firewall štiti i od napada između dva računara u istoj mreži iza njega
- [ ] Sva pravila se uvek proveravaju, pobeđuje najstrože
:::

# Posmatranje UDP-a

:::sim
url=/sims/lesson-5.5.btsim
:::

Na **Serveru** ovog puta radi **UDP Eho-Server** na portu `5000`. I ovde je kabl pripremljen: **drugi datagram** od Client-PC-ja ka serveru se gubi.

## Eksperiment

1. Pređi u :fa-play: režim **Pokreni** (Režim izvršavanja) i na **Client-PC**-ju otvori :fa-terminal: **Terminal**.
2. Pomoću `nc` pokreni UDP „vezu“ ka serveru (`-u` označava UDP):
   ```
   $ nc -u 192.168.0.20 5000
   ```
3. Ukucaj redom `eins`, `zwei` i `drei` i svaki put pritisni **Enter**. Svaki red koji se vrati je eho servera.
4. Sačekaj nekoliko sekundi, a zatim u režimu :fa-magnifying-glass: **Praćenje** otvori trag za **Client-PC**.

:::quiz mc
Koji se eho vraćaju?
- [ ] Sva tri, `zwei` nešto kasnije
- [x] Samo `eins` i `drei` — `zwei` nedostaje i ne šalje se ponovo
- [ ] Nijedan
:::

:::quiz multi
Koji paketi koje poznaješ iz TCP-a potpuno nedostaju kod UDP-a?
- [x] Uspostavljanje veze (`SYN`)
- [x] Potvrde (`ACK`)
- [x] Raskid veze (`FIN`)
- [ ] Paketi sa brojevima portova
:::

:::evaluate
Proveri odgovore
:::

Klikni na jedan od UDP paketa i otvori **User Datagram Protocol**. U poređenju sa TCP zaglavljem, UDP zaglavlje je sićušno: **Source Port**, **Destination Port**, **Length** (dužina) i **Checksum** (kontrolna suma) — zajedno samo 8 bajtova. TCP zaglavlje ima najmanje 20 bajtova, sa rednim brojem i brojem potvrde, flagovima i veličinom prozora.

:::quiz mc
Koji zadatak iz odeljka 5.1 UDP ipak obavlja?
- [x] Multipleksiranje — preko portova
- [ ] Uspostavljanje veze
- [ ] Pouzdan prenos
:::

:::evaluate
Proveri odgovor
:::

:::tip Zapamti
**UDP** je **bez uspostavljanja veze**: nema uspostavljanja veze, nema potvrde, nema ponovnog slanja, nema redosleda. Nudi samo **portove** (multipleksiranje) i **kontrolnu sumu**. Zauzvrat je brz i lagan — UDP zaglavlje ima samo 8 bajtova. Ako se datagram izgubi, program mora sam da se pozabavi time — ili mu je svejedno.
:::

# Veza od početka do kraja

:::sim
url=/sims/lesson-5.1.btsim
:::

Na **Serveru** radi Echo servis na portu `5000`: svaku poruku odmah šalje nazad. Pomoću **Jednostavni TCP klijent** možeš korak po korak kontrolisati vezu — svako dugme je jedna faza.

## Eksperiment

1. Pređi u :fa-play: režim **Pokreni**, klikni na **Client-PC** i otvori **Jednostavni TCP klijent**.
2. U polje **Host** upiši `192.168.0.20`, a u polje **Port** upiši `5000`.
3. Klikni na **Povežite se**.
4. Ukucaj `Hello World` u polje za poruku i klikni na **Pošalji**. U prozoru za razgovor odmah zatim vidiš odjek servera.
5. Klikni na **Iskopčajte se**.
6. Pređi u :fa-magnifying-glass: režim **Praćenje** i pomoću **+** otvori trag za **Client-PC**, priključak `eth0`.

:::note
Dva ARP paketa na početku već poznaješ iz poglavlja 1. U koloni **Info** TCP paketa prvo stoji `49152 → 5000` (sa kog na koji port), zatim u uglastim zagradama **zastavice** (flags), a posle toga brojevi poput `Seq=`, `Ack=` i `Len=`. Brojevima se bavimo od strane 5.2.3 — ovde obrati pažnju na zastavice i `Len`.
:::

## Faza 1: Povezivanje

:::quiz short
Koliko TCP paketa je razmenjeno nakon što si kliknuo na **Povežite se** — pre nego što je tvoja poruka poslata?
= 3
= tri
:::

:::quiz mc
Ko šalje prvi paket sa `[SYN]`?
- [x] Client-PC
- [ ] Server
:::

:::quiz mc
Kojim zastavicama server odgovara na to?
- [ ] `[SYN]`
- [x] `[SYN, ACK]`
- [ ] `[ACK]`
- [ ] `[FIN, ACK]`
:::

## Faza 2: Slanje

`Len` označava koliko bajtova korisnih podataka paket nosi.

:::quiz short
Koliko bajtova nosi paket sa tvojom porukom (`Len`)?
= 13
:::

:::note
`Hello World` ima samo 11 znakova. TCP klijent međutim dodaje kraj reda (2 bajta, `\r\n`) — tako to očekuju mnogi internet protokoli kao što su SMTP ili HTTP.
:::

:::quiz mc
Šta server šalje nazad odmah nakon tvoje poruke — još pre odjeka?
- [x] Paket sa `[ACK]` i `Len=0` — potvrdu bez podataka
- [ ] Ništa
- [ ] Novi `[SYN]`
:::

## Faza 3: Prekid veze

:::quiz short
Koliko paketa pripada raskidanju veze — počevši od prvog paketa sa `FIN`?
= 4
= četiri
:::

:::quiz mc
Šta strana saopštava sa `FIN`?
- [x] „Završio sam“ — više ne šalje podatke
- [ ] „Došlo je do greške“
- [ ] „Evo novih podataka“
:::

:::evaluate
Proveri odgovore
:::

## Gde se kriju četiri zadatka?

Poveži gde u tragu pronalaziš zadatke iz odeljka 5.1:

:::quiz match
Uspostavljanje veze -> Tri paketa [SYN], [SYN, ACK] i [ACK]
Pouzdan prenos -> Paketi sa [ACK] i Len=0 koji potvrđuju prijem
Raskidanje veze -> Paketi sa FIN i njihove potvrde
Multipleksiranje -> Brojevi portova 49152 → 5000 ispred uglastih zagrada
:::

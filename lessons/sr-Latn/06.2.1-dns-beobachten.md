:::seq

:::

## Odakle PC zna DNS server?

Na **Client-PC** otvori :fa-gear: **IP postavke**: u polju **DNS-Server** stoji `192.168.0.53` — računar **DNS-Resolver**. Njemu PC šalje svaki upit za ime.

DNS server možeš da pitaš i direktno, bez pregledača. Otvori :fa-terminal: **Terminal** i unesi:

```
$ nslookup www.beaver-schule.de
```

`nslookup` prvo prikazuje koji server je pitao, a zatim odgovor. Za poređenje pitaj za ime koje ne postoji, npr. `nslookup gibtsnicht.beaver-schule.de`.

:::quiz mc
Šta DNS server odgovara na nepoznato ime?
- [ ] Nasumičnu IP adresu
- [x] `NXDOMAIN` — to ime ne postoji
- [ ] Ništa
:::

:::evaluate
Proveri odgovor
:::

:::tip Zapamti
**DNS** prevodi imena (npr. `www.beaver-schule.de`) u IP adrese. Pre nego što PC može da uspostavi vezu sa imenom, pita **DNS server** koji je upisan u njegovim IP postavkama — najčešće preko **UDP, port 53**. Pomoću `nslookup` možeš ručno da postavljaš DNS upite.
:::

## Kako izgleda zahtev

Klikni u trace-u na paket `GET / HTTP/1.1` i raširi **Hypertext Transfer Protocol**. HTTP zahtev je običan tekst:

```
GET / HTTP/1.1              ← Methode, Pfad, Version
Host: 192.168.0.20          ← Header: zusätzliche Angaben
…
                            ← Leerzeile: Ende der Anfrage
```

Odgovor servera je građen na isti način — sa statusnom linijom, header-ima, praznim redom i zatim samom datotekom:

```
HTTP/1.1 200 OK             ← Version, Statuscode, Text
Content-Type: text/html     ← Header: Art der Datei
Content-Length: 301         ← Header: Größe in Byte
                            ← Leerzeile
<!doctype html> …           ← die Datei selbst
```

:::seq
mode: text
Client-PC -> Server: GET / | HTTP zahtev
Server -> Client-PC: 200 OK | index.html
Client-PC -> Server: GET /style.css | HTTP zahtev
Server -> Client-PC: 200 OK | style.css
:::

## Metode i statusni kodovi

**Metoda** govori šta klijent želi:

| Metoda | Značenje |
|---|---|
| **GET** | preuzimanje datoteke |
| **POST** | slanje podataka serveru, npr. popunjenog formulara |
| **HEAD** | preuzimanje samo header-a, bez datoteke |

**Statusni kod** govori kako je prošlo. Prva cifra otkriva vrstu odgovora:

| Kod | Tekst | Značenje |
|---|---|---|
| **200** | OK | sve je u redu |
| **301** | Moved Permanently | stranica je trajno premeštena |
| **404** | Not Found | datoteka ne postoji |
| **405** | Method Not Allowed | ova metoda ovde nije dozvoljena |
| **500** | Internal Server Error | greška na serveru |

`2xx` znači uspeh, `3xx` preusmeravanje, `4xx` grešku klijenta (pogrešan zahtev), `5xx` grešku servera.

:::tip Zapamti
**HTTP** radi po **principu zahtev–odgovor**: klijent šalje **zahtev** (metodu poput `GET`, putanju, header-e), a server odgovara **statusnim kodom** (npr. `200 OK`, `404 Not Found`), header-ima i datotekom. Za svaku datoteku veb stranice postoji poseban zahtev.
:::

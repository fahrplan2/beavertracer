# Traženje grešaka: ime ne funkcioniše

:::sim
url=/sims/lesson-6.2.3.btsim
:::

Jedna nastavnica javlja: „`www.beaver-schule.de` mi se ne učitava. Ali sa `http://192.168.0.20` radi!“ Ovako *treba* da bude podešeno:

| Šta | Treba da bude |
|---|---|
| DNS server na Client-PC | `192.168.0.53` (DNS-Resolver) |
| Unos u Schul-DNS | `www.beaver-schule.de` → `192.168.0.20` |

Pronađi greške i otkloni ih.

<details>
<summary>Savet 1: Šta kaže nslookup?</summary>

Na Client-PC unesi `nslookup www.beaver-schule.de`. Koji server je `nslookup` pitao — i šta je vratio? (Odgovor stiže nakon nekoliko sekundi.)
</details>

<details>
<summary>Savet 2: A sada?</summary>

Ako dobiješ odgovor, uporedi adresu sa planom. Gde je ovo ime uneto?
</details>

:::task
title: Razrešavanje imena popravljeno?
Proverava da li Client-PC razrešava www.beaver-schule.de na pravu adresu. Simulacija mora da radi u režimu izvršavanja.
check: resolves(2, "www.beaver-schule.de", "192.168.0.20")
:::

## Šta se dešavalo?

:::quiz multi
Koje tvrdnje su tačne?
- [x] Na Client-PC je kao DNS server bila uneta adresa `192.168.0.35` — tamo niko ne odgovara
- [x] U Schul-DNS je `www.beaver-schule.de` pokazivao na `192.168.0.21` umesto na `192.168.0.20`
- [ ] Veb server je bio isključen
- [ ] Root server nije poznavao domen `.de`
:::

:::evaluate
Proveri odgovor
:::

:::tip Zapamti
Ako veza radi sa **IP adresom**, ali ne i sa **imenom**, problem je u **DNS-u**. Prvo proveri **uneti DNS server** (odgovara li uopšte?), zatim sam **unos** (da li je adresa tačna?). `nslookup` prikazuje oba podatka: koji server je pitan i šta je odgovorio.
:::

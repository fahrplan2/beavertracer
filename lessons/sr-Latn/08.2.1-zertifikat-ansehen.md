# Pregled sertifikata

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Na radnoj površini vidiš **Client-PC**, **DNS-Server** i školski veb server `www.beaver-schule.de`. Veb server svoje stranice nudi i preko **HTTPS**-a.

## Katanac u pregledaču

1. Pređi u :fa-play: **Ausführen**-režim izvršavanja, klikni na **Client-PC** i otvori :fa-globe: **Pregledač**.
2. Otvori `https://www.beaver-schule.de/` — obrati pažnju na **https**.
3. Levo od adrese pojavljuje se **katanac**. Klikni na njega.

:::quiz short
Za koje ime je izdat sertifikat (subjekat bez `CN=`)?
= www.beaver-schule.de
:::

:::quiz short
Ko je izdao sertifikat (izdavalac bez `CN=`)?
= Biber Root CA
:::

:::evaluate
Proveri odgovore
:::

## Zašto Client-PC veruje sertifikatu?

Na **Client-PC**-ju otvori :fa-shield-halved: **Zertifikatverwaltung** i pređi na karticu **Vertrauenswürdige CAs**.

:::quiz mc
Šta tamo nalaziš?
- [x] Sertifikat **Biber Root CA**
- [ ] Sertifikat za `www.beaver-schule.de`
- [ ] Nema unosa
:::

:::quiz mc
Kako se vidi da je Biber Root CA root CA?
- [x] **Samopotpisana** je: subjekat i izdavalac su isti
- [ ] Njen naziv se završava na „CA“
- [ ] Nema javni ključ
:::

:::quiz mc
Da li kod Client-PC-ja pod **Privater Schlüssel** piše „Ja“ ili „Nein“?
- [ ] Ja — klijentu je potreban privatni ključ CA da bi proveravao potpise
- [x] Nein — za proveru je dovoljan javni ključ; privatni ključ ima samo CA
:::

:::evaluate
Proveri odgovore
:::

## Druga strana: veb server

Sada na veb serveru **www.beaver-schule.de** otvori :fa-shield-halved: **Zertifikatverwaltung** (kartica **Meine Zertifikate**) i pogledaj njegov sertifikat.

:::quiz multi
Šta važi za sertifikat na veb serveru?
- [x] Pod **Privater Schlüssel** piše „Ja“ — serveru je potreban za uspostavljanje veze
- [x] **Lanac** glasi `www.beaver-schule.de ← Biber Root CA`
- [x] **Otisak prsta** je isti kao u prozoru sa katancem u pregledaču
- [ ] Samopotpisan je
:::

:::evaluate
Proveri odgovore
:::

:::note
**Otisak prsta** je heš vrednost izračunata nad sertifikatom. Pomoću njega se dva sertifikata mogu brzo uporediti — bez pojedinačne provere svih polja.
:::

:::tip Zapamti
**Veb server** poseduje svoj sertifikat **sa privatnim ključem**. **Klijent** poznaje samo **sertifikat root CA** (bez privatnog ključa) — to mu je dovoljno da proveri potpis na sertifikatu servera. Kada u pregledaču klikneš na **katanac**, vidiš subjekat, izdavaoca, otisak prsta i period važenja.
:::

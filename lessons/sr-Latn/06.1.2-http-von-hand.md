# HTTP ručno

:::sim

:::

Ako je HTTP običan tekst — može li se onda i sam razgovarati sa veb serverom, potpuno bez pregledača? Da: pomoću `telnet` uspostaviš TCP vezu sa bilo kojim portom i sam ukucaš tekst.

## Eksperiment

1. Pređi u :fa-play: **Pokreni** režim izvršavanja i otvori :fa-terminal: **Terminal** na **Client-PC**.
2. Poveži se sa portom 80 servera:
   ```
   $ telnet 192.168.0.20 80
   ```
3. Ukucaj zahtev red po red — i završi ga **praznim redom** (jednostavno još jednom pritisni **Enter**):
   ```
   GET /kontakt.html HTTP/1.1
   Host: 192.168.0.20

   ```

Server odgovara statusnom linijom, zaglavljima i stranicom sa kontaktom — kao tekst, baš onako kako je dobija i pregledač.

:::quiz mc
Po čemu server prepoznaje da je tvoj zahtev završen?
- [ ] Po posebnoj komandi `END`
- [x] Po praznom redu
- [ ] Nakon određenog vremena
:::

:::quiz short
Koja vrednost stoji u odgovoru kod zaglavlja `Content-Type`? (samo prvi deo pre `;`)
= text/html
:::

## Izazivanje grešaka

Udobniji alat je `curl`: on postavlja zahtev umesto tebe. Sa `-v` (*verbose*, detaljno) prikazuje sve što ide tamo-amo — redove sa `>` je poslao `curl`, redovi sa `<` stigli su od servera.

Probaj:

```
$ curl -v http://192.168.0.20/gibtsnicht.html
$ curl -X POST -d name=Anna http://192.168.0.20/
```

:::quiz short
Koji statusni kod dobijaš za `/gibtsnicht.html`?
= 404
:::

:::quiz short
A koji za zahtev sa metodom `POST`?
= 405
:::

:::evaluate
Proveri odgovore
:::

:::note
Veb server u BeaverTracer-u može samo da isporučuje datoteke — zato dozvoljava samo `GET` i `HEAD`. Pravi veb serveri pomoću `POST` primaju, na primer, formulare i prosleđuju podatke nekom programu.
:::

:::tip Zapamti
Mnogi protokoli aplikativnog sloja su **tekstualni** — HTTP, ali i SMTP, POP3 i IMAP. Zato se sa njima može razgovarati ručno pomoću `telnet` i pratiti ih u Tracer-u. To je praktično za traženje grešaka — ali i bezbednosni problem: svako ko snima saobraćaj može da pročita sve. Kako šifrovanje (HTTPS) pomaže, naučićeš u poglavlju 8.
:::

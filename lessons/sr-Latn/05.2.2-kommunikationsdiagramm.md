# Dijagram komunikacije

:::sim
url=/sims/lesson-5.1.btsim
:::

Tok jedne veze crta se kao **dijagram komunikacije**: klijent i server dobijaju po jednu uspravnu liniju, a vreme teče odozgo nadole. Svaka strelica je jedan paket. Nacrtana je kosa zato što je svaki paket neko vreme na putu.

Ovako izgleda tvoja veza sa prethodne stranice — uporedi je red po red sa tragom (trace):

:::seq
Client-PC -> Server: SYN
Server -> Client-PC: SYN, ACK
Client-PC -> Server: ACK
Client-PC -> Server: PSH, ACK "Hello World" len=13
Server -> Client-PC: ACK
Server -> Client-PC: PSH, ACK len=13
Client-PC -> Server: ACK
Client-PC -> Server: FIN, ACK
Server -> Client-PC: ACK
Server -> Client-PC: FIN, ACK
Client-PC -> Server: ACK
:::

Iznad svake strelice nalaze se **flegovi**, a ispod njih brojevi `SEQ` i `ACK`. **DATA** označava pakete sa korisnim podacima. Crveni brojevi pripadaju klijentu, a plavi serveru — šta oni znače, objašnjeno je na sledećoj stranici.

## Flegovi

| Fleg | skraćenica za | Značenje |
|---|---|---|
| **SYN** | *synchronize* | uspostavljanje veze, određivanje početnog broja |
| **ACK** | *acknowledge* | potvrđuje primljene podatke |
| **PSH** | *push* | podatke odmah prosledi programu |
| **FIN** | *finish* | „Završio sam“ — raskidanje veze |
| **RST** | *reset* | prekida ili odbija vezu (više o tome u 5.3.2) |

## Tri faze

**Uspostavljanje:** klijent šalje `SYN`, server odgovara sa `SYN, ACK`, a klijent potvrđuje sa `ACK`. Pošto su potrebna tačno tri paketa, to se zove **trostruko rukovanje (three-way handshake)**.

**Podaci:** svaki paket sa podacima primalac potvrđuje paketom `ACK`. Ovde server šalje eho nazad — i to klijent potvrđuje.

**Raskidanje:** svaka strana zasebno završava svoj smer slanja: `FIN` od klijenta, `ACK` od servera — zatim `FIN` od servera, `ACK` od klijenta. To su četiri paketa.

:::tip Zapamti
TCP veza se odvija u tri faze: **uspostavljanje** pomoću **trostrukog rukovanja** (`SYN` → `SYN, ACK` → `ACK`), **prenos podataka** (svaki paket sa podacima potvrđuje se paketom `ACK`) i **raskidanje** (svaka strana šalje `FIN` i dobija `ACK`).
:::

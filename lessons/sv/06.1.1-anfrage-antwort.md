En webbsida består alltså ofta av många filer: text, stilmallar, bilder. För var och en skickar webbläsaren en egen förfrågan.

## Hur en förfrågan ser ut

Klicka på paketet `GET / HTTP/1.1` i tracen och fäll ut **Hypertext Transfer Protocol**. En HTTP-förfrågan är ren text:

```
GET / HTTP/1.1              ← Methode, Pfad, Version
Host: 192.168.0.20          ← Header: zusätzliche Angaben
…
                            ← Leerzeile: Ende der Anfrage
```

Serverns svar är uppbyggt på samma sätt — med en statusrad, headers, en tom rad och därefter själva filen:

```
HTTP/1.1 200 OK             ← Version, Statuscode, Text
Content-Type: text/html     ← Header: Art der Datei
Content-Length: 301         ← Header: Größe in Byte
                            ← Leerzeile
<!doctype html> …           ← die Datei selbst
```

:::seq
mode: text
Client-PC -> Server: GET / | HTTP-förfrågan
Server -> Client-PC: 200 OK | index.html
Client-PC -> Server: GET /style.css | HTTP-förfrågan
Server -> Client-PC: 200 OK | style.css
:::

## Metoder och statuskoder

**Metoden** anger vad klienten vill:

| Metod | Betydelse |
|---|---|
| **GET** | hämta en fil |
| **POST** | skicka data till servern, t.ex. ett ifyllt formulär |
| **HEAD** | hämta bara headers, utan filen |

**Statuskoden** anger hur det gick. Den första siffran avslöjar typen av svar:

| Kod | Text | Betydelse |
|---|---|---|
| **200** | OK | allt är i sin ordning |
| **301** | Moved Permanently | sidan har flyttats permanent |
| **404** | Not Found | filen finns inte |
| **405** | Method Not Allowed | den här metoden är inte tillåten här |
| **500** | Internal Server Error | fel på servern |

`2xx` betyder framgång, `3xx` omdirigering, `4xx` ett fel hos klienten (felaktig förfrågan), `5xx` ett fel hos servern.

:::tip Att komma ihåg
**HTTP** fungerar enligt **förfråganssvarsprincipen**: Klienten skickar en **förfrågan** (metod som `GET`, sökväg, headers), servern svarar med en **statuskod** (t.ex. `200 OK`, `404 Not Found`), headers och filen. För varje fil på en webbsida görs en egen förfrågan.
:::

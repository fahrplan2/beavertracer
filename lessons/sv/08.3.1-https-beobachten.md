# HTTP och HTTPS jämfört

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Webbservern **www.beaver-schule.de** erbjuder skolans betygsportal både via HTTP och via HTTPS. Vad ser någon som lyssnar på trafiken?

## Experimentet

1. Växla till :fa-play: **Kör**-läget och öppna på **Client-PC** i :fa-globe: **Webbläsare** först `http://www.beaver-schule.de/` och därefter `https://www.beaver-schule.de/`.
2. Öppna en trace för **Client-PC** i :fa-magnifying-glass: **Spårning**-läget.
3. Leta först upp paketet `HTTP/1.1 200 OK` och klicka på det. Nere i detaljerna hittar du sidans innehåll.

:::quiz mc
Vad kan någon som lyssnar på trafiken se vid **HTTP**?
- [x] Hela webbsidan, även Annas betyg
- [ ] Bara serverns adress
- [ ] Ingenting, eftersom HTTP går över TCP
:::

:::quiz short
Vilket betyg har Anna i matematik?
= 2
:::

:::evaluate
Kontrollera svar
:::

Nu till HTTPS-delen. Leta upp `[SYN]`-paketet som klienten använder för att påbörja den andra anslutningen.

:::quiz short
Vilken målport har HTTPS-anslutningen (kolumnen **Info**, `… → ???`)?
= 443
:::

Skriv nu `tls` i filterfältet högst upp i tracen — då ser du bara TLS-paketen.

:::quiz mc
Vad står i kolumnen **Info** för paketen som innehåller webbsidan?
- [ ] `HTTP/1.1 200 OK`
- [x] `Application Data`
- [ ] `Encrypted HTML`
:::

:::quiz multi
Vad kan någon som lyssnar på trafiken ändå se vid **HTTPS**?
- [x] Klientens och serverns IP-adresser
- [x] Att port 443 används, alltså sannolikt HTTPS
- [x] Ungefär hur mycket data som överförs
- [ ] Vilken sida som hämtades och vad som står på den
:::

:::evaluate
Kontrollera svar
:::

:::note
Klicka på ett **Application Data**-paket: Nyttolasten är bara en följd av till synes slumpmässiga bytes. Tracern kan inte dekryptera den — den känner lika lite till sessionsnyckeln som en angripare.
:::

:::tip Att komma ihåg
Vid **HTTP** kan vem som helst som lyssnar läsa hela webbsidan. Vid **HTTPS** ser han eller hon bara **vem som pratar med vem** (IP-adresser, port 443) och **hur mycket** — innehållet finns krypterat i **Application Data**-paket.
:::

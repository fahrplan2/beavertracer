# Tillämpa modellerna

Koppla ihop protokollen från experimentet i början av kapitlet med rätt OSI-lager:

:::quiz match
Ethernet -> Lager 2 — Länk
IPv4 -> Lager 3 — Nätverk
TCP -> Lager 4 — Transport
HTTP -> Lager 7 — Applikation
:::

:::evaluate
Kontrollera kopplingarna
:::

Och till sist namnen på dataenheterna:

:::quiz match
Frame -> Lager 2 — Länk
Paket -> Lager 3 — Nätverk
Segment -> Lager 4 — Transport
:::

:::evaluate
Kontrollera kopplingarna
:::

Nu har du verktygen för att kunna placera in protokoll på rätt lager framöver. Från och med nästa kapitel går vi igenom lagren i tur och ordning – med början i lager 2 och frågan om hur en switch egentligen vet vart den ska vidarebefordra ett paket.

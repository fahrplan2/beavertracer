# DNS: namn istället för nummer

:::goal
**Lärandemål:** Du kan förklara hur DNS översätter namn till IP-adresser, hur namnen är organiserade hierarkiskt, skapa en post själv och hitta typiska DNS-fel.
:::

:::sim
url=/sims/lesson-6.2.btsim
:::

IP-adresser är det knappast någon som kan komma ihåg — men namn som `www.beaver-schule.de` går bra. Översättningen sköts av **Domain Name System** (**DNS**), en slags världsomspännande telefonkatalog för internet.

På arbetsytan finns nu ett något större nätverk: Förutom **Client-PC** och **Webserver** finns det fyra **DNS-servrar**. Varför det behövs så många får du se två sidor längre fram.

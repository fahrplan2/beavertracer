# WLAN: nätverk utan kablar

:::goal
**Lärandemål:** Du kan förklara hur en åtkomstpunkt kopplar ihop ett WLAN med det kabelanslutna nätverket, ansluta en enhet till WLAN via SSID och motivera varför ett WLAN måste krypteras.
:::

Mobiler, surfplattor och bärbara datorer har oftast ingen nätverksport längre – de är anslutna via radio, över ett **WLAN** (*Wireless LAN*, trådlöst lokalt nätverk). För att de ändå ska kunna kommunicera med datorerna och servrarna som sitter på kabel behövs en enhet som förbinder radio och kabel.

:::note
I verkligheten beror ett WLAN på räckvidd, väggar och störningar. BeaverTracer förenklar detta: alla enheter med samma WLAN-namn delar ett gemensamt radionätverk – oavsett var de står på arbetsytan.
:::

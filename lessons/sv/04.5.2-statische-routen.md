# Lägga in statiska rutter

:::sim
url=/sims/lesson-4.5.2.btsim
:::

Den här gången finns det **två** routrar mellan företag A och företag B. De är sammankopplade via ett eget litet nätverk, **mellannätet** `10.0.0.0/30`:

| Router | Gränssnitt | IP-adress | Nätverk |
|---|---|---|---|
| Router A | `eth0` | `192.168.0.1/24` | Firma A (Anna) |
| Router A | `eth1` | `10.0.0.1/30` | Zwischennetz |
| Router B | `eth0` | `10.0.0.2/30` | Zwischennetz |
| Router B | `eth1` | `172.16.0.1/24` | Firma B (Clara) |

:::note
Ett `/30`-nätverk har exakt två användbara adresser – perfekt för att koppla ihop två routrar (se avsnitt 4.2.3).
:::

## Problemet

Växla till :fa-play: **Kör**-läge och pinga Clara från **Anna** (`ping 172.16.0.10`). Clara svarar inte – i stället hör Router A (`192.168.0.1`) av sig med ”Zielnetz nicht erreichbar”.

Titta på **Routningstabell IPv4** för **Router A**.

:::quiz mc
Varför kommer Annas ping inte fram till Clara?
- [ ] Anna har inte angett någon gateway
- [x] Router A känner inte till nätverket `172.16.0.0/24` – det är inte direkt anslutet till den, och det finns ingen rutt dit
- [ ] Mellannätet är för litet
:::

:::evaluate
Kontrollera svar
:::

## Lägga in rutten

Router A måste lära sig: paket till `172.16.0.0/24` ska skickas till Router B (`10.0.0.2`), och det via `eth1`.

1. Öppna fliken **Routningstabell IPv4** på **Router A** och klicka på **+ hinzufügen**.
2. Fyll i den nya raden: **Ziel** `172.16.0.0`, **Netzmaske** `255.255.255.0`, **Nächster Hop** `10.0.0.2`, **Iface** `eth1`.
3. Spara raden med bocken :fa-check:. I kolumnen **Quelle** står det nu **Statisk**.

Pinga Clara igen – nu kommer svaret.

:::note
Router B känner förresten redan till vägen tillbaka till företag A: I dess routingtabell finns redan en statisk rutt för `192.168.0.0/24` via `10.0.0.1`. Varför den här returvägen är lika viktig får du se på nästa sida.
:::

## Följa vägen: traceroute

Med `traceroute` kan du visa vilka routrar ett paket passerar. Skriv in följande på **Anna**:

```
$ traceroute 172.16.0.10
```

:::quiz short
Hur många routrar passerar paketet från Anna till Clara?
= 2
= två
:::

:::quiz mc
Vilken adress visar `traceroute` för Router B?
- [x] `10.0.0.2` – dess adress i mellannätet, via vilken paketet kommer in
- [ ] `172.16.0.1` – dess adress i firma B
- [ ] `192.168.0.1`
:::

:::evaluate
Kontrollera svar
:::

`traceroute` utnyttjar ett knep med **Time to Live** från avsnitt 4.3.1: Först skickas ett paket med TTL 1. Den första routern drar av 1, får 0, kastar paketet och meddelar avsändaren – då känner Anna till den första routern. Sedan skickas TTL 2 för den andra routern, och så vidare tills målet svarar.

:::tip Att komma ihåg
En **statisk rutt** läggs in för hand av administratören: målnätverk, nätmask, nästa hopp och gränssnitt. Med **traceroute** kan man följa ett pakets väg router för router.
:::

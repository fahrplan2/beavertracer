# Observera TCP

:::goal
**Lärandemål:** Du hittar i Tracer var TCP utför transportlagrets fyra uppgifter, kan visa en TCP-förbindelse som ett sekvensdiagram och kan räkna efter sekvensnummer och bekräftelsenummer.
:::

:::sim
url=/sims/lesson-5.1.btsim
:::

**Transmission Control Protocol** (**TCP**) ligger bakom nästan allt på internet som måste komma fram på ett tillförlitligt sätt: webbsidor, e-post, nedladdningar och fjärradministration via SSH.

På de följande sidorna observerar du en enda TCP-förbindelse från början till slut — och letar själv efter var TCP sköter uppkoppling, tillförlitlig överföring och nedkoppling.

# HTTP för hand

:::sim

:::

Om HTTP är ren text — kan man då också prata med en webbserver själv, helt utan webbläsare? Ja: med `telnet` kopplar du upp en TCP-förbindelse till valfri port och skriver texten själv.

## Experimentet

1. Växla till :fa-play: **Kör**-läge och öppna :fa-terminal: **Terminal** på **Client-PC**.
2. Anslut till serverns port 80:
   ```
   $ telnet 192.168.0.20 80
   ```
3. Skriv in förfrågan rad för rad — och avsluta den med en **tom rad** (tryck bara på **Enter** en gång till):
   ```
   GET /kontakt.html HTTP/1.1
   Host: 192.168.0.20

   ```

Servern svarar med statusrad, headers och kontaktsidan — som text, precis som webbläsaren får den.

:::quiz mc
Hur märker servern att din förfrågan är slut?
- [ ] Genom ett särskilt kommando `END`
- [x] Genom den tomma raden
- [ ] Efter en viss tid
:::

:::quiz short
Vilket värde står i svaret vid headern `Content-Type`? (bara den första delen före `;`)
= text/html
:::

Kontrollera svar
:::

## Framkalla fel

Ett bekvämare verktyg är `curl`: Det skickar förfrågan åt dig. Med `-v` (*verbose*, utförlig) visar det allt som skickas fram och tillbaka — rader med `>` har `curl` skickat, rader med `<` kom från servern.

Prova:

```
$ curl -v http://192.168.0.20/gibtsnicht.html
$ curl -X POST -d name=Anna http://192.168.0.20/
```

:::quiz short
Vilken statuskod får du för `/gibtsnicht.html`?
= 404
:::

:::quiz short
Och vilken får du för förfrågan med metoden `POST`?
= 405
:::

:::evaluate
Kontrollera svar
:::

:::note
Webbservern i BeaverTracer kan bara leverera filer — därför tillåter den bara `GET` och `HEAD`. Riktiga webbservrar tar till exempel emot formulär med `POST` och skickar vidare data till ett program.
:::

:::tip Att komma ihåg
Många protokoll i applikationslagret är **textbaserade** — HTTP, men också SMTP, POP3 och IMAP. Därför kan man prata med dem för hand via `telnet` och läsa med i spårningen. Det är praktiskt vid felsökning — men också ett säkerhetsproblem: Alla som fångar upp trafiken kan läsa allt. Hur kryptering (HTTPS) hjälper får du lära dig i kapitel 8.
:::

## Vad som finns i hemmarutern

| Roll i hemmarutern | Vad den gör | du känner igen det från |
|---|---|---|
| **Switch** | ansluter enheterna till LAN-portarna | kapitel 3.1 |
| **Åtkomstpunkt** | ansluter mobiler, surfplattor och bärbara datorer till nätverket via WiFi | kapitel 3.3 |
| **Router** | ansluter hemmanätverket till leverantörens nätverk — den är **gateway** | kapitel 4.3 |
| **DHCP Server** | delar ut adresser, gateway och DNS-server | kapitel 6.4 |
| **DNS** | vidarebefordrar namnförfrågningar eller anger leverantörens DNS-server | kapitel 6.2 |
| **NAT** | ger alla enheter tillgång till internet via **en** offentlig adress | nytt — avsnitt 7.2 |

Porten **WAN** (*Wide Area Network*) leder till leverantören, portarna **LAN** och WiFi leder in i hemmanätverket. Många hemmarouters innehåller dessutom ett **modem** — det översätter data för anslutningen (DSL, kabel, fiber). BeaverTracer simulerar inte det; här sitter WAN-porten direkt i leverantörens nätverk.

:::quiz match
Switch -> Ansluter enheterna till LAN-portarna
Åtkomstpunkt -> Ansluter surfplattor och mobiler till nätverket via WiFi
DHCP Server -> Delar ut adresser till enheterna i hemmanätverket
Router -> Ansluter hemmanätverket till leverantörens nätverk
:::

:::evaluate
Kontrollera matchningen
:::

:::tip Att komma ihåg
En **hemmarouter** förenar flera enheter: **switch**, **WiFi-åtkomstpunkt**, **router** (gateway till internet), **DHCP Server** och **DNS-vidarebefordran** — dessutom **NAT**. **WAN**-porten leder till leverantören, **LAN**-portarna och WiFi leder in i hemmanätverket.
:::

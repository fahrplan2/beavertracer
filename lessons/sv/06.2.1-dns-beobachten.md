## Hur känner datorn till DNS-servern?

Öppna :fa-gear: **IP-inställningar** på **Client-PC**: I fältet **DNS-Server** står `192.168.0.53` — datorn **DNS-Resolver**. Dit skickar datorn varje namnförfrågan.

Du kan också fråga DNS-servern direkt, utan webbläsare. Öppna :fa-terminal: **Terminal** och skriv:

```
$ nslookup www.beaver-schule.de
```

`nslookup` visar först vilken server som frågades och sedan svaret. Fråga för jämförelse efter ett namn som inte finns, t.ex. `nslookup gibtsnicht.beaver-schule.de`.

:::quiz mc
Vad svarar DNS-servern på det okända namnet?
- [ ] En slumpmässig IP-adress
- [x] `NXDOMAIN` — det här namnet finns inte
- [ ] Ingenting alls
:::

:::evaluate
Kontrollera svaret
:::

:::tip Att komma ihåg
**DNS** översätter namn (t.ex. `www.beaver-schule.de`) till IP-adresser. Innan en dator kan koppla upp sig mot ett namn frågar den **DNS-servern** som är inställd i dess IP-inställningar — oftast via **UDP, port 53**. Med `nslookup` kan du ställa DNS-förfrågningar för hand.
:::

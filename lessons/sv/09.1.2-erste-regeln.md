# Dina första egna regler

:::sim
url=/sims/lesson-9.btsim
:::

Nu är det din tur. Brandväggen släpper fortfarande igenom allt. Se till att bara **Webseite (80)** och **Mail-Empfang (25)** på skolservern går att nå från internet. **SSH (22)**, **POP3 (110)** och **IMAP (143)** ska inte längre gå att nå från internet.

## Lägga in regler

1. Klicka på **Firewall**. Standardpolicyn förblir tills vidare **Alle zulassen**.
2. Ta bort den befintliga regeln (den tillåter ändå allt) och skapa med **+ Regel hinzufügen** en regel för varje port som ska vara stängd:
    - **Richtung** A → B (från internet)
    - **Protokoll** TCP
    - **Ziel-Port** t.ex. `22`
    - **Aktion** Verwerfen
3. Kontrollera från **Internet-PC** med `nmap 198.51.100.10` att bara de rätta portarna är öppna.

:::task
title: Bara webb och e-post utifrån?
Kontrollerar att skolservern från internet bara går att nå på port 80 och 25 — och att lärar-datorn fortfarande kan hämta e-post och surfa på internet. Simuleringen måste köras i Körläge för att detta ska fungera.
check: tcpOpen(1, "198.51.100.10", 80)
check: tcpOpen(1, "198.51.100.10", 25)
check: tcpFails(1, "198.51.100.10", 22)
check: tcpFails(1, "198.51.100.10", 110)
check: tcpFails(1, "198.51.100.10", 143)
check: tcpOpen(8, "198.51.100.10", 110)
check: tcpOpen(8, "203.0.113.80", 80)
:::

:::quiz mc
Lärar-datorn kan fortfarande hämta e-post från skolservern via POP3 (110). Varför påverkas den inte av brandväggen?
- [ ] För att brandväggen känner igen lärare
- [x] För att dess paket inte alls passerar brandväggen — lärar-datorn och skolservern sitter på samma switch bakom brandväggen
- [ ] För att POP3 är ett säkert protokoll
:::

:::evaluate
Kontrollera svar
:::

:::note
En brandvägg skyddar bara trafik som flödar **genom den**. Den ser inte vad som händer inuti skolnätverket. En infekterad dator i skolnätverket kan alltså ändå angripa skolservern — det handlar avsnittet om DMZ om.
:::

:::tip Att komma ihåg
För varje tjänst som inte ska gå att nå utifrån stänger en regel med **Richtung**, **Protokoll** och **Ziel-Port** åtkomsten. Om reglerna fungerar kontrollerar man utifrån med en **portskanning**.
:::

# Ställ in HTTPS

:::sim
url=/sims/lesson-8.3.3.btsim
:::

Här fortsätter vi där avsnitt 8.2.2 slutade: På webbservern **www.beaver-schule.de** finns **Schul-CA** och ett serverscertifikat som den har utfärdat, och **Client-PC** litar på Schul-CA. Men webbservern pratar ännu inte HTTPS.

## Innan

Växla till :fa-play: **Kör**-läget (Körläge) och öppna `https://www.beaver-schule.de/` i :fa-globe: **Webbläsare** på **Client-PC**.

:::quiz mc
Vad händer?
- [x] Anslutningen kommer inte till stånd — ingen tjänst lyssnar på port 443
- [ ] Webbläsaren varnar för ett osäkert certifikat
- [ ] Sidan visas utan hänglås
:::

:::evaluate
Kontrollera svar
:::

## Slå på HTTPS

1. Öppna **HTTP-Server** på webbservern och klicka på **Stoppa** — så länge servern körs går det inte att ändra inställningarna.
2. Växla till fliken **HTTPS**:
    - Kryssa i **Aktivera HTTPS**, **HTTPS-port** `443`
    - Välj serverscertifikatet `www.beaver-schule.de` under **Certifikat** — inte Schul-CA!
    - Klicka på **Använd**
3. Klicka på **Starta**.

Öppna sidan på Client-PC igen via `https://`. Klicka på hänglåset och kontrollera utfärdare och giltighet.

:::task
title: HTTPS inställt?
Prüft, ob der Client-PC https://www.beaver-schule.de/ ohne Zertifikatswarnung abrufen kann. Die Simulation muss dafür im Ausführen-Modus laufen.
check: httpsOk(2, "https://www.beaver-schule.de/")
:::

:::quiz mc
Varför får du inte välja certifikatet för **Schul-CA** i HTTP-Server?
- [ ] För att CA-certifikat inte kan kryptera
- [x] För att det är utfärdat för namnet `Schul-CA`, inte för `www.beaver-schule.de` — webbläsaren skulle varna
- [ ] För att Schul-CA inte har någon privat nyckel
:::

:::quiz mc
Vad skulle en enhet se som **inte** litar på Schul-CA, t.ex. en gästs mobiltelefon?
- [ ] Sidan helt normalt med hänglås
- [x] En certifikatvarning, eftersom den inte kan följa förtroendekedjan till en känd CA
- [ ] Ingenting alls, eftersom anslutningen nekas
:::

:::evaluate
Kontrollera svar
:::

:::note
För offentliga webbplatser behövs ett certifikat från en CA som är förinstallerad i alla webbläsare. Sedan 2015 finns **Let's Encrypt**, en CA som utfärdar sådana certifikat gratis och automatiskt — en huvudorsak till att nästan alla webbplatser idag använder HTTPS.
:::

:::tip Att komma ihåg
För **HTTPS** behöver webbservern ett **serverscertifikat med privat nyckel** vars namn stämmer med adressen, och den måste lyssna på **port 443**. Klienten litar bara på sidan om den känner till den utfärdande **CA:n**.
:::

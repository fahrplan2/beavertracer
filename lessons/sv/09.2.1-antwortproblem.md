# Svarsproblemet

:::sim

Brandväggen arbetar nu enligt vitlisteprincipen: standardpolicy **Alla förkastas**. En enda regel tillåter skolnätverket att surfa: **B → A, TCP, mål-port 80, Tillåt**. Läget är inställt på **Stateless**.

## Experimentet

1. Byt till :fa-play: **Kör**-läge och öppna `http://203.0.113.80/` i :fa-globe: **Webbläsare** på **Lehrer-PC**.
2. Titta på **Protokoll** och **Träffar** i **Firewall**.

:::quiz mc
Vad händer i webbläsaren?
- [ ] Sidan från www.beispiel.de visas
- [x] Sidan laddas inte, webbläsaren väntar och visar till slut ett felmeddelande
:::

:::quiz mc
Vilka paket står som förkastade (`DROP`) i brandväggens protokoll?
- [ ] Lärar-PC:ns förfrågningar till port 80
- [x] Svaren från `203.0.113.80` med **källport 80** till lärar-PC:n
- [ ] Inga alls
:::

:::quiz short
I vilken riktning (A→B eller B→A) går de förkastade paketen?
= A→B
= A → B
= AtoB
:::

:::evaluate
Kontrollera svar
:::

Lärar-PC:ns förfrågan får gå ut — men redan webbserverns `SYN, ACK` kommer inte tillbaka, eftersom det inte finns någon passande regel för riktningen A → B, och därför gäller **Alla förkastas**.

## Den naiva lösningen

Man skulle kunna lägga till en andra regel: **A → B, TCP, käll-port 80, Tillåt** – "allt som kommer från port 80 får komma in". Då fungerar surfandet faktiskt.

:::quiz mc
Varför är den här regeln farlig?
- [ ] För att webbservrar aldrig använder port 80 som källport
- [x] En angripare kan helt enkelt skicka sina paket med källport 80 — då släpper brandväggen igenom dem till **vilken** port som helst i skolnätverket
- [ ] För att webbsidorna då laddas långsammare
:::

:::evaluate
Kontrollera svar
:::

Källporten bestäms av avsändaren själv — en brandvägg får inte lita på den. En tillståndslös brandvägg vet dock inte om ett paket är **svaret på en förfrågan** eller ett **nytt anslutningsförsök** utifrån. Det är precis det som det tillståndsbaserade läget ändrar.

:::tip Att komma ihåg
Ett **tillståndslöst** paketfilter kontrollerar varje paket för sig. Svar behöver då egna regler för returriktningen — och sådana regler (t.ex. "källport 80 får komma in") kan utnyttjas av angripare, eftersom avsändaren fritt kan välja källport.
:::

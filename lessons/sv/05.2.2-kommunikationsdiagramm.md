# Sekvensdiagrammet

:::sim
url=/sims/lesson-5.1.btsim
:::

Förloppet för en anslutning ritas som ett **sekvensdiagram**: klienten och servern får varsin lodrät linje (livslinje), och tiden går uppifrån och ned. Varje pil är ett paket. Pilen är ritad på sned eftersom varje paket är en liten stund på väg.

Så här ser din anslutning från förra sidan ut — jämför den rad för rad med spårningen:

:::seq
Client-PC -> Server: SYN
Server -> Client-PC: SYN, ACK
Client-PC -> Server: ACK
Client-PC -> Server: PSH, ACK "Hello World" len=13
Server -> Client-PC: ACK
Server -> Client-PC: PSH, ACK len=13
Client-PC -> Server: ACK
Client-PC -> Server: FIN, ACK
Server -> Client-PC: ACK
Server -> Client-PC: FIN, ACK
Client-PC -> Server: ACK
:::

Över varje pil står **flaggorna**, under dem numren `SEQ` och `ACK`. **DATA** markerar paket med nyttolast. De röda talen hör till klienten, de blå till servern — vad de betyder förklaras på nästa sida.

## Flaggorna

| Flagga | står för | Betydelse |
|---|---|---|
| **SYN** | *synchronize* | upprätta anslutning, fastställa startnummer |
| **ACK** | *acknowledge* | bekräftar mottagna data |
| **PSH** | *push* | lämna omedelbart över data till programmet |
| **FIN** | *finish* | ”Jag är klar” — avsluta anslutningen |
| **RST** | *reset* | avbryta eller avvisa anslutning (mer om detta i 5.3.2) |

## Tre faser

**Uppkoppling:** Klienten skickar `SYN`, servern svarar med `SYN, ACK` och klienten bekräftar med `ACK`. Eftersom exakt tre paket behövs kallas det **trevägshandskakning**.

**Data:** Varje paket med data bekräftas av mottagaren med ett `ACK`. Här skickar servern tillbaka ekot — även det bekräftar klienten.

**Nedkoppling:** Varje sida avslutar sin sändriktning för sig: `FIN` från klienten, `ACK` från servern — sedan `FIN` från servern, `ACK` från klienten. Det blir fyra paket.

:::tip Att komma ihåg
En TCP-anslutning går igenom tre faser: **uppkoppling** med **trevägshandskakning** (`SYN` → `SYN, ACK` → `ACK`), **dataöverföring** (varje datapaket bekräftas med `ACK`) och **nedkoppling** (varje sida skickar `FIN` och får ett `ACK`).
:::

## Nu är det din tur

Klienten skickar den här gången bara `Hi` (4 byte med radslut). Fyll i de saknade flaggorna — ordningen inom ett fält spelar ingen roll.

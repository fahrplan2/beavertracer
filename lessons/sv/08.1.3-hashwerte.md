# Hashvärden: datats fingeravtryck

:::sim
url=/sims/lesson-8.1.3.btsim
:::

En **hashfunktion** beräknar en kort teckensträng med fast längd — **hashvärdet** — utifrån valfri mängd data: en mening, ett dokument eller en hel film. Det fungerar som ett **fingeravtryck**: samma data ger alltid samma hashvärde, andra data ger ett annat.

Den hashfunktion som används i dag heter **SHA-256**. Dess hashvärde är alltid 256 bitar långt, alltså 64 tecken som hexadecimalt tal.

## Experimentet

På **PC** ligger tre filer med ett litet köpeavtal i mappen `/home`. Växla till :fa-play: **Kör**-läget, öppna :fa-terminal: **Terminal** på **PC** och skriv:

```
$ cd /home
$ cat vertrag.txt vertrag-kopie.txt vertrag-neu.txt
$ sha256sum vertrag.txt vertrag-kopie.txt vertrag-neu.txt
```

## Egenskaper hos en hashfunktion

| Egenskap | Betydelse |
|---|---|
| **fast längd** | Oavsett hur stora datan är har hashvärdet alltid samma längd. |
| **entydig** | Samma data ger alltid samma hashvärde. |
| **lavineffekt** | Redan den minsta ändring ger ett helt annat hashvärde. |
| **enkelriktad funktion** | Datan **går inte** att räkna ut utifrån hashvärdet. |
| **kollisionsresistent** | Det är i praktiken omöjligt att hitta två olika filer med samma hashvärde. |

En hashfunktion är **ingen kryptering**: Det finns ingen nyckel och ingen dekryptering. Den tjänar ett annat syfte — **integritet**.

## Vad behöver man det till?

- **Kontrollera nedladdningar:** Många webbplatser anger sitt SHA-256-värde bredvid en fil. Om hashvärdet för din nedladdade fil stämmer överens med det har filen inte ändrats på vägen.
- **Lagra lösenord:** Bra webbplatser lagrar inte ditt lösenord, utan bara ett hashvärde av det. Vid inloggning jämförs hashvärdet av det du skrev in. Om databasen stjäls känner tjuven ändå inte till lösenorden.
- **Digitala signaturer:** I stället för ett helt dokument signerar man bara dess hashvärde — mer om det i nästa avsnitt.

:::tip Att komma ihåg
En **hashfunktion** (t.ex. **SHA-256**) beräknar ett **hashvärde** med fast längd — ett **fingeravtryck** — utifrån valfria data. Redan den minsta ändring ger ett helt annat hashvärde, och datan går inte att räkna ut utifrån hashvärdet. Hashvärden säkerställer datans **integritet**.
:::

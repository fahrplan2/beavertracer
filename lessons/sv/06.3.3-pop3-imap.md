# POP3 eller IMAP?

:::sim
url=/sims/lesson-6.3.btsim
:::

För att hämta e-post finns det två protokoll. I den här simuleringen använder **Anna POP3** och **Ben IMAP**.

## Experimentet

1. Skicka i :fa-play: **Kör**-läge ett mejl från **Ben** till `anna@beaver-schule.de`.
2. Klicka hos **Anna** i appen **E-Mail** på **Hämta**.
3. Öppna traces för **Anna** och för **Ben** och jämför kommandona vid hämtningen.

:::quiz match
USER / PASS -> POP3: logga in med användarnamn och lösenord i två steg
RETR -> POP3: ladda ner ett meddelande
LOGIN -> IMAP: logga in med användarnamn och lösenord
SELECT INBOX -> IMAP: öppna en mapp på servern
:::

:::evaluate
Kontrollera matchningen
:::

## Skillnaden

| | POP3 | IMAP |
|---|---|---|
| Port | 110 | 143 |
| Grundidé | Mejl **laddas ner** — därefter oftast raderas de på servern | Mejl **ligger kvar på servern** och hanteras där |
| Mappar, läst/oläst | bara på den egna enheten | på servern — likadant överallt |
| Flera enheter (mobil, laptop) | opraktiskt: varje enhet har olika status | idealiskt: alla enheter ser samma brevlåda |

:::note
E-postprogrammet i BeaverTracer låter mejlen ligga kvar på servern även med POP3. Riktiga program raderar dem ofta efter nedladdningen — eller låter dem ligga kvar bara en stund.
:::

:::quiz mc
Lena läser sina mejl på mobilen, surfplattan och skolans laptop. Vad bör hon använda?
- [ ] POP3, eftersom det är enklare
- [x] IMAP, eftersom alla enheter ser samma brevlåda på servern
- [ ] SMTP, eftersom det är avsett för att hämta e-post
:::

:::evaluate
Kontrollera svaret
:::

:::tip Att komma ihåg
**POP3** laddar ner mejl från servern till **en** enhet. **IMAP** hanterar brevlådan **på servern** — med mappar och läst-status för alla enheter samtidigt. Båda används bara för att **hämta**; att skicka sker alltid med **SMTP**.
:::

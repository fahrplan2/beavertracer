## Experimentet

1. Växla till :fa-play: **Kör**-läge, klicka på **Anna** och öppna appen **E-Mail**.
2. Växla till fliken **Skriv**. Ange `ben@biber-mail.de` i fältet **An**, skriv ett ämne och en kort text och klicka på **Skicka**.
3. Vänta några sekunder — e-posten måste först ta sig från e-postserver till e-postserver. Klicka sedan på **Ben**, öppna appen **E-Mail** och klicka på **Hämta**. E-posten från Anna finns där.
4. Öppna en trace för **Mailserver Schule** i :fa-magnifying-glass: **Spårning**-läge.

## Vad som ligger bakom

Ett e-postmeddelande reser i flera etapper — ungefär som ett brev via två postkontor:

1. Annas e-postprogram lämnar över e-posten med **SMTP** till Annas e-postserver.
2. Mailserver Schule ser: mottagaren tillhör en **främmande domän**. Via **DNS** frågar den efter **MX-posten** (*Mail Exchanger*) för `biber-mail.de` och får `mail.biber-mail.de` — därefter även dess IP-adress.
3. Den levererar e-posten med **SMTP** till Mailserver Biber. Där hamnar den i Bens brevlåda.
4. Ben hämtar den från sin e-postserver med **IMAP** (eller **POP3**).

:::seq
mode: text
Mailserver Schule -> Mailserver Biber: SMTP: MAIL FROM | anna@beaver-schule.de
Mailserver Biber -> Mailserver Schule: 250 OK
Mailserver Schule -> Mailserver Biber: SMTP: RCPT TO | ben@biber-mail.de
Mailserver Biber -> Mailserver Schule: 250 OK
Mailserver Schule -> Mailserver Biber: SMTP: DATA | själva e-postmeddelandet
Mailserver Biber -> Mailserver Schule: 250 OK queued
:::

:::tip Att komma ihåg
**SMTP** (port 25) **skickar** e-post: från e-postprogrammet till den egna e-postservern och därifrån till mottagarens e-postserver. Vilken e-postserver som ansvarar för en domän framgår av **MX-posten** i DNS. **POP3** (port 110) och **IMAP** (port 143) används bara för att **hämta** från den egna brevlådan.
:::

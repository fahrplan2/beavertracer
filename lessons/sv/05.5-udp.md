# UDP: den kraftiga förenklingen

:::goal
**Lärandemål:** Du kan jämföra UDP med TCP och motivera för vilka applikationer UDP är det bättre valet.
:::

:::sim
url=/sims/lesson-5.5.btsim
:::

TCP gör mycket — uppkoppling, bekräftelser, omsändning och rätt ordningsföljd. Det kostar dock tid och extra paket. Det andra viktiga protokollet i transportlagret avstår från nästan allt detta: **User Datagram Protocol** (**UDP**). Dess paket kallas **datagram**.

# Titta på ett certifikat

:::sim
url=/sims/lesson-8.2.1.btsim
:::

På arbetsytan ser du **Client-PC**, en **DNS-server** och skolans webbserver, `www.beaver-schule.de`. Webbservern erbjuder sina sidor även via **HTTPS**.

## Hänglåset i webbläsaren

1. Växla till :fa-play: **Kör**-läge (Körläge), klicka på **Client-PC** och öppna :fa-globe: **Webbläsare**.
2. Öppna `https://www.beaver-schule.de/` — var uppmärksam på **https**.
3. Till vänster om adressen visas ett **hänglås**. Klicka på det.

:::quiz short
För vilket namn utfärdades certifikatet (ämne utan `CN=`)?
= www.beaver-schule.de
:::

:::quiz short
Vem har utfärdat certifikatet (utfärdare utan `CN=`)?
= Biber Root CA
:::

:::evaluate
Kontrollera svar
:::

## Varför litar Client-PC på certifikatet?

Öppna :fa-shield-halved: **Zertifikatverwaltung** på **Client-PC** och växla till fliken **Vertrauenswürdige CAs**.

:::quiz mc
Vad hittar du där?
- [x] Certifikatet för **Biber Root CA**
- [ ] Certifikatet för `www.beaver-schule.de`
- [ ] Inga poster
:::

:::quiz mc
Hur ser man att Biber Root CA är en root-CA?
- [x] Den är **självsignerad**: ämne och utfärdare är samma
- [ ] Dess namn slutar på ”CA”
- [ ] Den har ingen publik nyckel
:::

:::quiz mc
Står det ”Ja” eller ”Nein” under **Privater Schlüssel** hos Client-PC?
- [ ] Ja — klienten behöver CA:ns privata nyckel för att kontrollera signaturer
- [x] Nej — för kontrollen räcker den publika nyckeln; den privata nyckeln har bara CA:n
:::

:::evaluate
Kontrollera svar
:::

## Motparten: webbservern

Öppna nu :fa-shield-halved: **Zertifikatverwaltung** på webbservern **www.beaver-schule.de** (fliken **Meine Zertifikate**) och titta på dess certifikat.

:::quiz multi
Vad stämmer för certifikatet på webbservern?
- [x] Under **Privater Schlüssel** står det ”Ja” — servern behöver den för uppkopplingen
- [x] **Kedjan** lyder `www.beaver-schule.de ← Biber Root CA`
- [x] **Fingeravtrycket** är detsamma som i webbläsarens hänglåsfönster
- [ ] Det är självsignerat
:::

:::evaluate
Kontrollera svar
:::

:::note
**Fingeravtrycket** är ett hashvärde över certifikatet. Med det kan man snabbt jämföra två certifikat — helt utan att kontrollera alla fält ett i taget.
:::

:::tip Att komma ihåg
**Webbservern** har sitt certifikat **med privat nyckel**. **Klienten** känner bara till **root-CA:ns certifikat** (utan privat nyckel) — det räcker för att kontrollera signaturen på servercertifikatet. Klickar man på **hänglåset** i webbläsaren ser man ämne, utfärdare, fingeravtryck och giltighet.
:::

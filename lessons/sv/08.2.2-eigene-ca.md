# Bygga en egen CA

:::sim
url=/sims/lesson-8.2.2.btsim
:::

För `www.beaver-schule.de` finns det ännu inget certifikat. I stället för att beställa ett hos en kommersiell CA bygger skolan upp sin **egna CA**: **Schul-CA**. Många företag och skolor gör så för sina interna servrar.

I verkligheten skulle Schul-CA köras på en egen, särskilt välskyddad dator. Här spelar du alla roller själv på webbservern.

## Steg 1: Skapa Schul-CA

1. Växla till :fa-play: **Kör**-läge (Körläge) och öppna :fa-shield-halved: **Zertifikatverwaltung** på webbservern **www.beaver-schule.de**.
2. På fliken **Generieren**:
    - **Common Name:** `Schul-CA`
    - **Typ:** Selbstsigniert
    - Kryssa i **Dies ist ein CA-Zertifikat**
    - **Speichern unter:** `schul-ca.cert.json`
3. Klicka på **Zertifikat generieren**.

Då skapas ett nytt **nyckelpar**. Certifikatet innehåller den publika nyckeln; den privata nyckeln stannar kvar i filen på webbservern.

## Steg 2: Utfärda servercertifikatet

På fliken **Generieren** igen:

- **Common Name:** `www.beaver-schule.de` — exakt det namn man skriver in i webbläsaren
- **Typ:** Von CA signiert, **Signierende CA:** Schul-CA
- **Speichern unter:** t.ex. `www.beaver-schule.de.cert.json`

På fliken **Meine Zertifikate** ser du nu båda certifikaten. Klicka på det nya servercertifikatet:

:::quiz short
Vem är **Aussteller** för servercertifikatet (utan `CN=`)?
= Schul-CA
:::

:::quiz mc
Hur ser dess **Kette** ut?
- [x] `www.beaver-schule.de ← Schul-CA`
- [ ] `Schul-CA ← www.beaver-schule.de`
- [ ] `www.beaver-schule.de` (självsignerat)
:::

:::evaluate
Kontrollera svar
:::

## Steg 3: Lära klienten känna igen Schul-CA

Klient-datorn känner ännu inte till Schul-CA — den är inte förinstallerad i dess webbläsare. Du måste ge den certifikatet, och det **utan privat nyckel**:

1. Välj **Schul-CA** under **Meine Zertifikate** på webbservern och klicka på **Kopieren** (inte på *Kopieren + Schlüssel*!).
2. Öppna :fa-shield-halved: **Zertifikatverwaltung** på **klient-datorn**, fliken **Vertrauenswürdige CAs**.
3. Klicka på **Einfügen: Schul-CA**.

:::warning
CA:ns **privata nyckel** är den mest värdefulla hemligheten i hela anläggningen: den som har den kan utfärda certifikat för **vilka namn som helst**, och alla klienter kommer att lita på dem. Den får aldrig lämna CA-datorn.
:::

:::task
title: Är Schul-CA uppsatt?
Kontrollera om det finns ett certifikat för www.beaver-schule.de på webbservern som har utfärdats av Schul-CA, och om klient-datorn litar på Schul-CA.
check: hasCert(4, "www.beaver-schule.de", "Schul-CA")
check: trusts(2, "Schul-CA")
:::

:::quiz mc
Varför kopierar du för klienten bara certifikatet **utan** privat nyckel?
- [ ] För att kopiering med nyckel tar längre tid
- [x] För att kontrollera signaturer räcker den publika nyckeln; med den privata nyckeln skulle vem som helst på klienten kunna utfärda egna certifikat
- [ ] För att klienten annars inte kan upprätta någon anslutning
:::

:::evaluate
Kontrollera svar
:::

Själva webbservern har du ännu inte ställt om — den talar fortfarande bara HTTP. Hur du aktiverar HTTPS får du lära dig i avsnitt 8.3.3.

:::tip Att komma ihåg
En **egen CA** består av ett **självsignerat CA-certifikat** med privat nyckel. Med det utfärdar man **servercertifikat** vars Common Name motsvarar servernamnet. För att klienter ska lita på dessa certifikat får de **CA-certifikatet utan privat nyckel** i sin lista över **betrodda CA:er**.
:::

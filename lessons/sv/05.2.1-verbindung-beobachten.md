# En anslutning från början till slut

:::sim
url=/sims/lesson-5.1.btsim
:::

På **Servern** körs ekotjänsten på port `5000`: Den skickar tillbaka varje meddelande direkt. Med **Enkel TCP-klient** kan du styra en anslutning steg för steg — varje knapp är en fas.

## Experimentet

1. Byt till :fa-play: **Kör**-läget, klicka på **Client-PC** och öppna **Enkel TCP-klient**.
2. Skriv in `192.168.0.20` vid **Host** och `5000` vid **Port**.
3. Klicka på **Anslut**.
4. Skriv `Hello World` i meddelandefältet och klicka på **Skicka**. I chattfönstret ser du strax därefter serverns eko.
5. Klicka på **Koppla från**.
6. Byt till :fa-magnifying-glass: **Spårning**-läget och öppna med **+** en trace för **Client-PC**, anslutning `eth0`.

:::note
De två ARP-paketen i början känner du redan igen från kapitel 1. I **Info**-kolumnen för TCP-paketen står först `49152 → 5000` (från vilken port till vilken port), sedan inom hakparenteser **flaggorna** och därefter siffror som `Seq=`, `Ack=` och `Len=`. Siffrorna behandlas från sidan 5.2.3 — här håller du utkik efter flaggor och `Len`.
:::

## Fas 1: Anslut

:::quiz short
Hur många TCP-paket utbyttes efter att du klickat på **Anslut** — innan ditt meddelande skickades?
= 3
= tre
:::

:::quiz mc
Vem skickar det första paketet med `[SYN]`?
- [x] Client-PC
- [ ] Servern
:::

:::quiz mc
Vilka flaggor svarar servern med?
- [ ] `[SYN]`
- [x] `[SYN, ACK]`
- [ ] `[ACK]`
- [ ] `[FIN, ACK]`
:::

## Fas 2: Skicka

`Len` anger hur många byte nyttolast ett paket bär på.

:::quiz short
Hur många byte bär paketet med ditt meddelande på (`Len`)?
= 13
:::

:::note
`Hello World` har bara 11 tecken. TCP-klienten lägger dock till ett radslut (2 byte, `\r\n`) — det förväntar sig många internetprotokoll som SMTP eller HTTP.
:::

:::quiz mc
Vad skickar servern tillbaka direkt efter ditt meddelande — redan före ekot?
- [x] Ett paket med `[ACK]` och `Len=0` — en bekräftelse utan data
- [ ] Ingenting alls
- [ ] Ett nytt `[SYN]`
:::

## Fas 3: Koppla från

:::quiz short
Hur många paket hör till nedkopplingen — från och med det första paketet med `FIN`?
= 4
= fyra
:::

:::quiz mc
Vad meddelar en sida med `FIN`?
- [x] ”Jag är klar” — den skickar inga fler data
- [ ] ”Ett fel har uppstått”
- [ ] ”Här kommer nya data”
:::

Kontrollera svaren
:::

## Var finns de fyra uppgifterna?

Para ihop var du hittar uppgifterna från avsnitt 5.1 i tracen:

:::quiz match
Uppkoppling -> De tre paketen [SYN], [SYN, ACK] och [ACK]
Tillförlitlig överföring -> Paket med [ACK] och Len=0 som bekräftar mottagandet
Nedkoppling -> Paketen med FIN och deras bekräftelser
Multiplexering -> Portnumren 49152 → 5000 före hakparenteserna
:::

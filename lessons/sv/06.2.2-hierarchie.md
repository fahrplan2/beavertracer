# Så är DNS organiserat

:::sim
url=/sims/lesson-6.2.btsim
:::

Ingen enskild server kan känna till alla namn i världen. DNS är därför uppbyggt **hierarkiskt** — precis som själva namnen. Man läser dem från höger till vänster:

```
www . beaver-schule . de . (Root)
 │          │         │      └─ Root-Server: kennen die Server aller Top-Level-Domains
 │          │         └─ Top-Level-Domain (TLD): der de-Server kennt alle .de-Domains
 │          └─ Domain: der Schul-DNS ist für beaver-schule.de zuständig
 └─ Rechnername innerhalb der Domain
```

Den server som ansvarar för en domän och verkligen känner till svaret kallas **auktoritativ**. Vägen dit tar en **resolver** hand om åt datorn — här datorn **DNS-Resolver**.

## Experimentet

1. Växla till :fa-play: **Kör**-läget (körläge) och skriv in följande i :fa-terminal: **Terminal** på **Client-PC**:
   ```
   $ nslookup www.beaver-schule.de
   ```
2. Öppna en trace för **DNS-Resolver** i :fa-magnifying-glass: **Spårning**-läget.

Resolvern har ställt en hel rad frågor åt dig. Para ihop vem som gav vilket svar:

:::quiz match
Root-Server (192.168.0.101) -> Hänvisning: För .de ansvarar ns.nic.de
de-Server (192.168.0.102) -> Hänvisning: För beaver-schule.de ansvarar ns.beaver-schule.de
Schul-DNS (192.168.0.103) -> Svar: www.beaver-schule.de har adressen 192.168.0.20
:::

:::quiz mc
Vem frågar resolvern först?
- [x] Root-servern
- [ ] Schul-DNS
- [ ] Client-PC
:::

:::evaluate
Kontrollera svaren
:::

:::note
Mellan varven frågar resolvern också efter adresserna till de servrar som den hänvisades till (`A ns.nic.de`). Riktiga DNS-servrar skickar oftast med dessa adresser direkt. Dessutom minns resolvers varje svar en stund (**cache**) — nästa fråga om samma namn besvarar de då direkt själva. Hur länge anges i posten som **TTL** (*Time to Live*) i sekunder.
:::

## De viktigaste posttyperna

| Typ | Betydelse | Exempel |
|---|---|---|
| **A** | namn → IPv4-adress | `www.beaver-schule.de` → `192.168.0.20` |
| **AAAA** | namn → IPv6-adress | `www.beaver-schule.de` → `2001:db8::20` |
| **CNAME** | namn → annat namn (alias) | `web.beaver-schule.de` → `www.beaver-schule.de` |
| **MX** | ansvarig e-postserver för en domän | `beaver-schule.de` → `mail.beaver-schule.de` |
| **NS** | ansvarig DNS-server för en domän | `beaver-schule.de` → `ns.beaver-schule.de` |

:::tip Att komma ihåg
DNS är **hierarkiskt**: **root-servrar** hänvisar till servrarna för **toppdomänerna** (t.ex. `.de`), och dessa hänvisar vidare till servrarna för de enskilda **domänerna**. Den ansvariga **auktoritativa** servern känner till svaret. En **resolver** går denna väg åt datorn och minns svaren (**cache**). Viktiga posttyper: **A**, **AAAA**, **CNAME**, **MX**, **NS**.
:::

## Skapa en post

Skolan vill att dess webbplats även ska kunna nås på `intranet.beaver-schule.de`.

1. Klicka i :fa-play: **Kör**-läget på **Schul-DNS** och öppna appen **DNS-Server**.
2. Öppna fliken **A**. Klicka på **+** och skriv in namnet `intranet.beaver-schule.de` och adressen `192.168.0.20` på den nya raden.
3. Testa på Client-PC med `nslookup intranet.beaver-schule.de`.

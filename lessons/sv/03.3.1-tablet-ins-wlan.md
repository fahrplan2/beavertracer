# Koppla en surfplatta till WLAN

:::sim
url=/sims/lesson-3.3.1.btsim
:::

Till switchen är **Schul-PC** (`192.168.0.10`) och en **Åtkomstpunkt** anslutna. Surfplattan **Anna** (`192.168.0.30`) ska ansluta till skolans WLAN.

## Hitta WLAN

Växla till :fa-play: **Kör**-läget och klicka på **Åtkomstpunkt**. Där står namnet på dess WLAN, **SSID**: `Schule`.

Åtkomstpunkten fungerar som en brygga: Allt som kommer in till den via radio skickar den vidare till switchen via sin kabel — och tvärtom. På så sätt hamnar Anna och Schul-PC i samma lokala nätverk.

## Ansluta surfplattan

1. Klicka på **Anna**, öppna :fa-gear: **IP-inställningar** och där fliken **WiFi**.
2. Skriv in WLAN-namnet vid **SSID**: `Schule`, och klicka på **Tillämpa**.
3. Öppna :fa-terminal: **Terminal** på Anna och pinga Schul-PC:
   ```
   $ ping 192.168.0.10
   ```

Titta på arbetsytan medan du pingar: Runt Anna och åtkomstpunkten sprids radiovågor ut.

:::tip Att komma ihåg
Ett **WLAN** är ett lokalt nätverk via radio. **Åtkomstpunkten** kopplar ihop WLAN med det kabelanslutna nätverket. Varje WLAN har ett namn, **SSID** (*Service Set Identifier*) — en enhet måste känna till rätt SSID för att kunna ansluta.
:::

:::quiz mc
Vad händer om du skriver in `schule` (med små bokstäver) som SSID hos Anna?
- [ ] Ingenting — det spelar ingen roll om det är versaler eller gemener
- [x] Anna är inte längre ansluten — SSID måste stämma exakt
- [ ] Anna ansluter till ett annat WLAN
:::

# Felsökning: Mejlet kommer inte fram

:::sim
url=/sims/lesson-6.3.4.btsim
:::

Anna meddelar: ”Jag kan inte skicka något mejl till Ben!” Så *ska* det vara konfigurerat:

| Vad | Ska vara |
|---|---|
| Annas utgående server (SMTP) | `mail.beaver-schule.de`, port `25` |
| MX-post för `biber-mail.de` | `mail.biber-mail.de` (prioritet 10) |

Hitta felen och åtgärda dem. Skicka sedan ett mejl från Anna till `ben@biber-mail.de` — uppgiften kontrollerar om det har kommit fram till Bens brevlåda. (Det kan ta några sekunder innan mejlet vidarebefordras mellan mailservrarna.)

<details>
<summary>Tips 1: Vad säger Annas mejlprogram?</summary>

Försök skicka ett mejl och titta på fliken **Protokoll**. Vad svarar servern — låter det som SMTP?
</details>

<details>
<summary>Tips 2: Kommer mejlet tillbaka som ett felmeddelande?</summary>

Hämta Annas post och läs meddelandet från `MAILER-DAEMON`. Varför misslyckades leveransen? Använd `nslookup -type=MX biber-mail.de` på Annas dator för att se om DNS-servern känner till den ansvariga mailservern.
</details>

<details>
<summary>Tips 3: Var ställer man in det?</summary>

Den utgående servern ställer du in i Annas app **E-Mail** under **Einstellungen**. MX-poster hittar du i **DNS-Server** på fliken **MX**.
</details>

:::task
title: Har mejlet kommit fram?
Kontrollerar om det ligger ett mejl i Bens brevlåda på Mailserver Biber.
check: fileExists(5, "/var/mail/ben.mbox")
:::

## Vad var det som hände?

:::quiz multi
Vilka påståenden stämmer?
- [x] Annas utgående server pekade på port 110 — där svarar POP3-tjänsten, inte SMTP
- [x] MX-posten för `biber-mail.de` saknades — Mailserver Schule hittade ingen ansvarig mailserver
- [x] Det mejl som inte kunde levereras kom tillbaka som ett felmeddelande från `MAILER-DAEMON`
- [ ] Bens lösenord var fel
:::

:::evaluate
Kontrollera svar
:::

:::tip Att komma ihåg
Typiska mejlfel: en felaktig **server eller port** i mejlprogrammet (SMTP använder port 25, POP3 port 110 och IMAP port 143) samt en saknad eller felaktig **MX-post** i DNS. Om en mailserver inte kan leverera ett mejl skickar den tillbaka det till avsändaren med ett felmeddelande (**bounce**).
:::

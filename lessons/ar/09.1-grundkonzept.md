# مرشّح الحزم: القواعد

أبسط أنواع جدران الحماية وأهمها هو **مرشّح الحزم**. يفحص كل حزمة تمرّ عبره، ويقرّر بناءً على **قائمة القواعد** ما إذا كان مسموحًا لها بالعبور. وهو يقرأ لذلك رأسَي الطبقتين 3 و4 فقط — أما المحتوى (مثل صفحة الويب) فلا ينظر إليه.

## مم تتكوّن القاعدة

| الحقل | المعنى | مثال |
|---|---|---|
| **الاتجاه** | من أي جهة تأتي الحزمة؟ | A → B (من الإنترنت إلى شبكة المدرسة) |
| **البروتوكول** | TCP أو UDP أو ICMP أو أي بروتوكول | TCP |
| **عنوان IP المصدر** | عنوان المرسِل أو شبكته | أي عنوان |
| **منفذ المصدر** | منفذ المرسِل | أي منفذ |
| **عنوان IP الوجهة** | عنوان المستقبِل أو شبكته | `198.51.100.10` |
| **منفذ الوجهة** | منفذ المستقبِل، أي الخدمة | `80` |
| **الإجراء** | ماذا يحدث للحزم المطابقة؟ | السماح |

الحقل الفارغ يعني «أي قيمة». تُكتب الشبكات بصيغة CIDR مثل `198.51.100.0/24`، وتُكتب نطاقات المنافذ بشرطة مثل `1024-65535`.

## الترتيب هو الحاسم

يفحص جدار الحماية القواعد **من الأعلى إلى الأسفل**. **أول قاعدة تنطبق** هي التي تحسم الأمر — ولا يُنظر إلى القواعد التالية لهذه الحزمة بعد ذلك. وإذا لم تنطبق أي قاعدة، تسري **السياسة الافتراضية** (*Default Policy*).

## ثلاثة إجراءات ممكنة

| الإجراء | ما يفعله جدار الحماية | ما يلاحظه المرسِل |
|---|---|---|
| **السماح** (*Allow*) | تُمرَّر الحزمة | — |
| **الإسقاط** (*Drop*) | تُرمى الحزمة بصمت دون أي ردّ | لا شيء إطلاقًا — ينتظر حتى تنتهي مهلة الانتظار |
| **الرفض** (*Reject*) | تُرمى الحزمة ويتلقى المرسِل ردّ رفض: في TCP حزمة **RST**، وفي غيره رسالة ICMP «يتعذّر الوصول» | رسالة خطأ فورًا |

أيّهما أفضل؟ **الإسقاط** يكشف للمهاجم معلومات أقل ويكلّفه وقتًا، لأنه مضطر إلى الانتظار عند كل محاولة. أما **الرفض** فهو ألطف مع المستخدمين الداخليين: يتلقى البرنامج رسالة خطأ فورًا بدل أن يبقى معلّقًا طويلًا. لذلك تُسقَط عمليًا الحزم القادمة من الخارج في الغالب، وتُرفض الحزم القادمة من الشبكة الداخلية.

:::quiz match
السماح -> تُمرَّر الحزمة
الإسقاط -> تختفي الحزمة، وينتظر المرسِل ردًّا دون جدوى
الرفض -> لا تُمرَّر الحزمة، لكن المرسِل يتلقى ردّ رفض فورًا
السياسة الافتراضية -> تسري عندما لا تنطبق أي قاعدة
:::

:::tip تذكّر
يفحص **مرشّح الحزم** كل حزمة وفق الاتجاه والبروتوكول والعناوين والمنافذ مقابل **قائمة القواعد**. و**أول قاعدة مطابقة** هي التي تحدّد الإجراء: **السماح** أو **الإسقاط** (بصمت) أو **الرفض** (مع ردّ رفض). وإذا لم تنطبق أي قاعدة، تسري **السياسة الافتراضية**.
:::

# DHCP: الانضمام إلى الشبكة تلقائيًا

:::goal
**هدف التعلّم:** تستطيع أن تشرح كيف يحصل الجهاز تلقائيًا على إعدادات IP الخاصة به عبر DHCP، وأن تُعدّ خادم DHCP، وأن تتعرّف على أخطاء DHCP الشائعة (مثل عنوان 169.254) وتصلحها.
:::

:::sim
url=/sims/lesson-6.4.btsim
:::

حتى الآن كنت تُدخل عنوان IP وقناع الشبكة والبوابة وخادم DNS لكل جهاز يدويًا. في مدرسة فيها مئات أجهزة اللابتوب والأجهزة اللوحية والهواتف، سيكون ذلك مستحيلًا، وكل خطأ في الكتابة سيتحول إلى خطأ في الشبكة.

هذا العمل يتولاه **بروتوكول التهيئة التلقائية للمضيف** (**DHCP**، أي Dynamic Host Configuration Protocol): يقوم **خادم DHCP** بتوزيع الإعدادات تلقائيًا على كل جهاز ينضم إلى الشبكة.

# HTTP: صفحات الويب

:::goal
**هدف التعلّم:** تستطيع وصف بنية طلب HTTP والاستجابة عليه، وشرح الطرق ورموز الحالة المهمة، وإرسال طلب HTTP بنفسك يدويًا.
:::

url=/sims/lesson-6.1.btsim
:::

بروتوكول **نقل النص التشعبي** (**HTTP**، اختصارًا لـ Hypertext Transfer Protocol) هو اللغة التي يتخاطب بها المتصفح وخادم الويب مع بعضهما. على الخادم توجد صفحة الويب الخاصة بـ **Beaver-Schule**: صفحة رئيسية، وصفحة اتصال، وورقة أنماط (Stylesheet) تحدد المظهر.

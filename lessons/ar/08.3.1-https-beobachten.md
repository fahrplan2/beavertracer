# مقارنة بين HTTP وHTTPS

:::sim
url=/sims/lesson-8.2.1.btsim
:::

يقدّم خادم الويب **www.beaver-schule.de** بوابة درجات المدرسة عبر HTTP وعبر HTTPS معًا. فماذا يرى من يتنصّت على الاتصال؟

## التجربة

1. انتقل إلى :fa-play: وضع **تشغيل** (وضع التشغيل)، ثم افتح على **Client-PC** في :fa-globe: **المتصفح** أولًا العنوان `http://www.beaver-schule.de/`، وبعده `https://www.beaver-schule.de/`.
2. افتح في :fa-magnifying-glass: وضع **التتبع** تتبعًا (Trace) لـ **Client-PC**.
3. ابحث أولًا عن الحزمة `HTTP/1.1 200 OK` وانقر عليها. ستجد في التفاصيل في الأسفل محتوى الصفحة.

:::quiz mc
ماذا يستطيع من يتنصّت على الاتصال أن يرى عند استخدام **HTTP**؟
- [x] صفحة الويب كاملة، بما فيها درجات Anna
- [ ] عنوان الخادم فقط
- [ ] لا شيء، لأن HTTP يعمل فوق TCP
:::

:::quiz short
ما درجة Anna في الرياضيات؟
= 2
:::

:::evaluate
التحقق من الإجابات
:::

والآن إلى جزء HTTPS. ابحث عن الحزمة `[SYN]` التي يبدأ بها العميل الاتصال الثاني.

:::quiz short
ما المنفذ الهدف لاتصال HTTPS (العمود **Info**، `… → ???`)؟
= 443
:::

اكتب الآن في حقل التصفية أعلى التتبع `tls` — عندها ستظهر لك حزم TLS فقط.

:::quiz mc
ماذا يظهر في العمود **Info** للحزم التي تحتوي على صفحة الويب؟
- [ ] `HTTP/1.1 200 OK`
- [x] `Application Data`
- [ ] `Encrypted HTML`
:::

:::quiz multi
ما الذي يستطيع من يتنصّت على الاتصال أن يراه مع ذلك عند استخدام **HTTPS**؟
- [x] عناوين IP الخاصة بالعميل والخادم
- [x] أنه يُستخدم المنفذ 443، أي أنه على الأرجح HTTPS
- [x] كمية البيانات المنقولة تقريبًا
- [ ] أي صفحة جرى استدعاؤها وما محتواها
:::

:::evaluate
التحقق من الإجابات
:::

:::note
انقر على حزمة **Application Data**: البيانات المفيدة ليست سوى سلسلة من البايتات التي تبدو عشوائية. لا يستطيع المتتبّع فك تشفيرها — فهو لا يعرف مفتاح الجلسة، تمامًا مثل المهاجم.
:::

:::tip تذكّر
عند استخدام **HTTP** يستطيع أي متنصّت قراءة صفحة الويب كاملة. أما عند استخدام **HTTPS** فلا يرى سوى **من يتحدث مع من** (عناوين IP، المنفذ 443) و**كم** البيانات — أما المحتوى فمخبّأ مشفّرًا داخل حزم **Application Data**.
:::

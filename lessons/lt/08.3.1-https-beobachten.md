# HTTP ir HTTPS palyginimas

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Žiniatinklio serveris **www.beaver-schule.de** siūlo mokyklos pažymių portalą tiek per HTTP, tiek per HTTPS. Ką mato pasiklausytojas?

## Eksperimentas

1. Perjunk į :fa-play: **Paleisti** režimą ir **Client-PC** :fa-globe: **Naršyklė** pirmiausia atidaryk `http://www.beaver-schule.de/`, o paskui `https://www.beaver-schule.de/`.
2. :fa-magnifying-glass: **Sekti** režime atidaryk **Client-PC** pėdsaką (angl. trace).
3. Pirmiausia susirask paketą `HTTP/1.1 200 OK` ir spustelėk jį. Apačioje, išsamioje informacijoje, rasi puslapio turinį.

:::quiz mc
Ką pasiklausytojas gali matyti naudojant **HTTP**?
- [x] Visą tinklalapį, taip pat ir Annos pažymius
- [ ] Tik serverio adresą
- [ ] Nieko, nes HTTP veikia per TCP
:::

:::quiz short
Kokį matematikos pažymį turi Anna?
= 2
:::

:::evaluate
Patikrinti atsakymus
:::

Dabar HTTPS dalis. Susirask `[SYN]` paketą, kuriuo klientas pradeda antrąjį ryšį.

:::quiz short
Koks yra HTTPS ryšio paskirties prievadas (stulpelis **Info**, `… → ???`)?
= 443
:::

Dabar viršuje, pėdsako filtro lauke, įvesk `tls` – tada matysi tik TLS paketus.

:::quiz mc
Kas parašyta stulpelyje **Info** prie paketų, kuriuose yra tinklalapis?
- [ ] `HTTP/1.1 200 OK`
- [x] `Application Data`
- [ ] `Encrypted HTML`
:::

:::quiz multi
Ką pasiklausytojas vis dar gali matyti naudojant **HTTPS**?
- [x] Kliento ir serverio IP adresus
- [x] Kad naudojamas 443 prievadas, taigi tikriausiai HTTPS
- [x] Kiek maždaug duomenų perduodama
- [ ] Koks puslapis buvo atidarytas ir kas jame parašyta
:::

:::evaluate
Patikrinti atsakymus
:::

:::note
Spustelėk **Application Data** paketą: naudingieji duomenys yra tik iš pažiūros atsitiktinių baitų seka. Tracer jų iššifruoti negali – jis nežino sesijos rakto, lygiai kaip ir užpuolikas.
:::

:::tip Svarbu įsiminti
Naudojant **HTTP**, bet kuris pasiklausytojas gali perskaityti visą tinklalapį. Naudojant **HTTPS**, jis mato tik tai, **kas su kuo** kalbasi (IP adresai, 443 prievadas) ir **kiek** duomenų perduodama – turinys užšifruotas **Application Data** paketuose.
:::

# Svarbiausi adresų tipai

Pagal IPv6 adreso pradžią galima atpažinti, kam jis skirtas:

| Adreso tipas | kaip atpažinti | kam skirtas |
|---|---|---|
| **Link-Local** | `fe80::` | Galioja tik **savame lokaliame tinkle**. Kiekvienas įrenginys šį adresą susikuria automatiškai — maršrutizatorius jo niekada nepersiunčia toliau. |
| **Global Unicast** | `2…` arba `3…` (`2000::/3`) | Pasaulyje unikalus adresas, pasiekiamas internete. Prefiksą gauni iš interneto paslaugų teikėjo. |
| **Unique Local** | `fd…` (`fc00::/7`) | Privatiems tinklams, panašiai kaip `192.168.x.x` IPv4 atveju. |
| **Loopback** | `::1` | Pats įrenginys — kaip `127.0.0.1` IPv4 atveju. |
| **Multicast** | `ff…` | **Įrenginių grupei**, pvz., `ff02::1` = visi įrenginiai lokaliame tinkle. |

:::note
Pavyzdžiams ir mokymo medžiagai skirtas rezervuotas diapazonas `2001:db8::/32` — tikrame internete jis niekada nepasitaiko. Todėl jį matai šiame kurse.
:::

Viena svarbi naujovė: **IPv6 nebeturi transliacijos (broadcast).** Tai, kas IPv4 buvo transliacija visiems, IPv6 atlieka naudodamas **multicast** adresus — pranešimas siunčiamas tik tiems įrenginiams, kurie domisi šia grupe.

:::tip Svarbu įsiminti
Kiekvienas IPv6 įrenginys turi bent vieną **Link-Local adresą** (`fe80::…`) savo tinklui, dažniausiai dar ir **globalųjį adresą** internetui. Vietoje transliacijos IPv6 naudoja **multicast** (`ff…`).
:::

:::quiz match
fe80::a828:39ff:fee2:4182 -> Link-Local — tik savame tinkle
2001:db8:1::10 -> Global Unicast — pasaulyje unikalus
::1 -> Loopback — pats įrenginys
ff02::1 -> Multicast — visi įrenginiai lokaliame tinkle
fd12:3456::1 -> Unique Local — privatiems tinklams
:::

# Modelių taikymas

Priskirk protokolus iš eksperimento, atlikto skyriaus pradžioje, jų OSI lygmeniui:

:::quiz match
Ethernet -> 2 lygmuo — Kanalo
IPv4 -> 3 lygmuo — Tinklo
TCP -> 4 lygmuo — Transporto
HTTP -> 7 lygmuo — Taikomųjų programų
:::

:::evaluate
Patikrinti priskyrimą
:::

Ir pabaigai – duomenų vienetų pavadinimai:

:::quiz match
Kadras -> 2 lygmuo — Kanalo
Paketas -> 3 lygmuo — Tinklo
Segmentas -> 4 lygmuo — Transporto
:::

:::evaluate
Patikrinti priskyrimą
:::

Dabar turi įrankius, kad ateityje protokolus tinkamai priskirtum atitinkamiems lygmenims. Nuo kito skyriaus lygmenis nagrinėsime paeiliui – pradėsime nuo 2 lygmens ir klausimo, iš kur komutatorius iš tikrųjų žino, kur turi persiųsti paketą.

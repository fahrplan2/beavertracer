# DHCP: automatiškai į tinklą

:::goal
**Mokymosi tikslas:** Gali paaiškinti, kaip įrenginys per DHCP automatiškai gauna savo IP nustatymus, sukonfigūruoti DHCP serverį ir atpažinti bei pašalinti tipines DHCP klaidas (pvz., 169.254 adresą).
:::

:::sim
url=/sims/lesson-6.4.btsim
:::

Iki šiol kiekvienam įrenginiui IP adresą, tinklo kaukę, vartus ir DNS serverį įvesdavai rankiniu būdu. Mokykloje, kurioje yra šimtai nešiojamųjų kompiuterių, planšetių ir telefonų, tai būtų neįmanoma — o kiekviena rašybos klaida tinkle virstų gedimu.

Šį darbą perima **Dynamic Host Configuration Protocol** (**DHCP**): **DHCP serveris** automatiškai paskirsto nustatymus kiekvienam įrenginiui, kuris prisijungia prie tinklo.

# HTTPS

:::osi 5
:::

**HTTPS** (*HTTP Secure*) yra visiškai įprastas HTTP — tik jis veikia ne tiesiogiai per TCP, o per tarpinį šifruotą lygmenį: **TLS** (*Transport Layer Security*). TLS pirmtakas vadinosi **SSL**; todėl dažnai vis dar kalbama apie „SSL sertifikatus“.

```
ohne Verschlüsselung:   HTTP  →  TCP  →  IP
mit Verschlüsselung:    HTTP  →  TLS  →  TCP  →  IP
```

HTTP to nė nepastebi: jis siunčia užklausas kaip įprasta, TLS jas užšifruoja, o TCP perneša. OSI modelyje TLS yra tarp transporto ir taikomųjų programų lygmens, t. y. 4/5 lygmenyje — jis remiasi TCP ir valdo apsaugotą sesiją.

| | HTTP | HTTPS |
|---|---|---|
| Prievadas | 80 | **443** |
| Adresas | `http://…` | `https://…` |
| Turinys įskaitomas Tracer? | taip | ne |
| Naršyklė rodo | „nesaugu“ | spyna |

TLS ryšio užmezgimo metu atlieka viską, ką išmokai šiame skyriuje:

- Serveris identifikuojasi savo **sertifikatu** (**autentiškumas**).
- Abi pusės naudodamos **Diffie-Hellman** susitaria dėl **sesijos rakto** — serveris savo dalį **pasirašo**.
- Po to visi duomenys užšifruojami **AES** (**konfidencialumas**) ir apsaugomi nuo pakeitimo (**vientisumas**).

Šis principas neapsiriboja saugumu žiniatinklyje: el. paštas (8.4 skyrelis) ir daugelis kitų protokolų taip pat veikia per TLS lygiai taip pat.

Tolesniuose skyreliuose stebėsi HTTPS Tracer programoje, pats jį nustatysi ir ištirsi, kada naršyklė įspėja — ir kodėl.

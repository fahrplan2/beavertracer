# NAT lentelė

:::sim
url=/sims/lesson-7.1.btsim
:::

Kai kompiuteris ir planšetė vienu metu atidaro tą pačią svetainę, abi užklausos pas žiniatinklio serverį atkeliauja iš `203.0.113.2`. Iš kur Namų maršrutizatorius žino, kam skirtas atsakymas? Jis veda apskaitą — **NAT lentelėje**.

## Eksperimentas

1. Perjunk į :fa-play: **Vykdymo režimas** ir **PC** bei **Tablet** įrenginiuose atidaryk `http://www.beispiel.de/`.
2. Spustelėk **Heimrouter** ir atidaryk kortelę **NAT**.

Kiekviena eilutė yra **atitikmuo**: protokolas, įrenginio LAN IP ir LAN prievadas Namų tinkle — ir **WAN prievadas**, kurį maršrutizatorius jam naudoja savo viešajame adrese.

:::quiz short
Koks WAN IP rodomas virš lentelės?
= 203.0.113.2
:::

:::quiz mc
Kompiuteris ir planšetė abu užmezgė ryšį su LAN prievadu `49152`. Kokį WAN prievadą jie gauna?
- [ ] Abu tą patį, `49152`
- [x] Kiekvienas skirtingą — kitaip maršrutizatorius nežinotų, kam priklauso atsakymas
- [ ] Jokio, NAT keičia tik IP adresą
:::

:::quiz mc
Žiniatinklio serverio atsakymas pasiekia `203.0.113.2` su tam tikru **paskirties prievadu**. Ką su juo daro Namų maršrutizatorius?
- [x] Suranda prievadą NAT lentelėje ir išsiunčia paketą atitinkamam LAN IP ir LAN prievadui
- [ ] Išsiunčia paketą visiems Namų tinklo įrenginiams
- [ ] Atmeta paketą
:::

:::evaluate
Patikrinti atsakymus
:::

Čia vėl pasitelkiami 5 skyriuje nagrinėti **prievadai**: kadangi NAT perrašo ir prievadus, vienu adresu gali dalytis šimtai ryšių. Tiksliau tai todėl vadinama **PAT** (*Port Address Translation*) arba *NAT su prievadų vertimu* — kasdienėje kalboje vis tiek sakoma tiesiog NAT.

Štai kaip toks vertimas galėtų atrodyti, pavyzdžiui:

| | Paketas iš kompiuterio (Namų tinkle) | tas pats Paketas internete |
|---|---|---|
| Siuntėjas | `192.168.178.20 : 49152` | `203.0.113.2 : 10001` |
| Gavėjas | `192.0.2.80 : 80` | `192.0.2.80 : 80` |

:::tip Svarbu įsiminti
**NAT lentelėje** maršrutizatorius kiekvienam ryšiui įsimena, kuris įrenginys (**LAN IP ir LAN prievadas**) slypi už kurio **WAN prievado**. Atsakymus iš interneto jis per paskirties prievadą vėl priskiria tinkamam įrenginiui. Kadangi perrašomi ir prievadai, tiksliau kalbama apie **PAT**.
:::

# Ataka: DNS klastojimas

:::sim
url=/sims/lesson-8.3.5.btsim
:::

Anna nori **Client-PC** kompiuteryje atidaryti savo internetinę bankininkystę **Biberbank**. Ko ji nežino: kažkas gavo prieigą prie **DNS-Server** ir pakeitė vieną įrašą.

Darbo srityje matai tikrąjį interneto serverį **www.biberbank.de** ir **Angreifer** kompiuterį. Jame veikia banko svetainės kopija.

## 1 dalis: be šifravimo

Pereik į :fa-play: **Paleisti** režimą ir **Client-PC** kompiuterio :fa-globe: **Naršyklė** atidaryk `http://www.biberbank.de/`.

:::quiz mc
Ką matai?
- [x] Biberbank prisijungimo puslapį be jokio įspėjimo
- [ ] Įspėjimą, kad puslapis suklastotas
- [ ] Klaidos pranešimą
:::

:::evaluate
Patikrinti atsakymą
:::

Atrodo viskas normaliai. Bet su kuriuo serveriu naršyklė iš tikrųjų bendrauja? Atidaryk **Client-PC** kompiuterio :fa-terminal: **Terminalas**:

```
$ nslookup www.biberbank.de
```

:::quiz short
Kokį IP adresą DNS serveris pateikia `www.biberbank.de`?
= 192.168.0.66
:::

:::quiz mc
Kam priklauso šis adresas? (Redagavimo režimu spustelėk įrenginius arba pažiūrėk jų :fa-gear: **IP nustatymai**.)
- [ ] Tikrajam Biberbank interneto serveriui
- [x] Užpuolikui
- [ ] DNS serveriui
:::

:::evaluate
Patikrinti atsakymus
:::

Jei Anna dabar būtų įvedusi sąskaitos numerį ir PIN kodą, jie būtų patekę tiesiai pas užpuoliką. Naudojant **HTTP** ji **neturi galimybių** pastebėti apgaulės: adreso juostoje rodomas teisingas pavadinimas, puslapis atrodo tikras.

## 2 dalis: su HTTPS

Dabar atidaryk `https://www.biberbank.de/`.

:::quiz mc
Kas įvyksta?
- [ ] Pasirodo suklastotas puslapis su spynos simboliu
- [x] Naršyklė įspėja: sertifikatas buvo išduotas kitam vardui
- [ ] Pasirodo tikrasis Biberbank puslapis
:::

:::quiz short
Kokiam vardui išduotas užpuoliko sertifikatas (be `CN=`)?
= www.biber-gewinnspiel.de
:::

:::evaluate
Patikrinti atsakymus
:::

Užpuolikas turi net **tikrą** patikimos CA sertifikatą, tačiau jis skirtas jo paties domenui `www.biber-gewinnspiel.de`. Sertifikato `www.biberbank.de` jis negauna iš jokios CA, nes šis domenas jam nepriklauso. O be Biberbank **privačiojo rakto** jis negali panaudoti ir tikrojo jos sertifikato: per pasisveikinimą (angl. handshake) jam reikėtų juo pasirašyti Server Key Exchange.

:::quiz multi
Nuo ko HTTPS čia apsaugo, o nuo ko ne?
- [x] HTTPS atskleidžia, kad serveris nėra tikrasis
- [ ] HTTPS neleidžia suklastoti DNS serverio
- [x] HTTPS padeda tik tada, jei naudotojas rimtai žiūri į įspėjimą
- [ ] Naudojant HTTPS suklastotas puslapis visai nepasiekiamas
:::

:::evaluate
Patikrinti atsakymus
:::

## 3 dalis: DNS serverio sutvarkymas

Atidaryk **DNS-Server** ir pataisyk įrašą `www.biberbank.de`. Teisingą adresą rasi interneto serverio **www.biberbank.de** :fa-gear: **IP nustatymai**. Nepamiršk spustelėti **Išsaugoti**.

:::note
**Client-PC** kurį laiką prisimena DNS atsakymus, kad jam nereikėtų klausti iš naujo kiekvieną kartą (**DNS talpykla**). Kiek laiko, nurodyta stulpelyje **TTL** (*Time to Live*) sekundėmis. Jei `nslookup` iškart po tavo pataisymo vis dar pateikia seną adresą, palauk, kol pasibaigs TTL, ir pabandyk dar kartą.
:::

:::task
title: Ar Biberbank vėl tikra?
Prüft, ob der Client-PC www.biberbank.de zur richtigen Adresse auflöst und die Seite über HTTPS ohne Warnung abrufen kann.
check: resolves(2, "www.biberbank.de", "192.168.0.30")
check: httpsOk(2, "https://www.biberbank.de/")
:::

:::note
Realiame gyvenime užpuolikas retai klastoja patį DNS serverį. Dažniau jis pakiša savo atsakymus viešajame WLAN tinkle, pakeičia namų maršrutizatoriaus nustatymus arba apgaudinėja panašiai atrodančiu adresu, pavyzdžiui, `www.biberbank-login.de` (**sukčiavimas** angl. *phishing*). Nuo panašiai skambančio vardo HTTPS irgi neapsaugo: užpuolikas tam gali gauti galiojantį sertifikatą. Todėl atidžiai skaityk adresą!
:::

:::tip Svarbu įsiminti
Kai **DNS klastojamas**, DNS serveris vardui pateikia užpuoliko adresą. Naudojant **HTTP** to nepastebima. Naudojant **HTTPS** užpuoliko sertifikatas neatitinka atidaryto vardo, todėl naršyklė **įspėja**: svetimų domenų sertifikato jokia CA neišduoda, o tikrojo serverio privačiojo rakto užpuolikas neturi.
:::

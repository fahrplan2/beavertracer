# Sertifikato peržiūra

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Darbo srityje matai **Client-PC**, **DNS-Server** ir mokyklos žiniatinklio serverį `www.beaver-schule.de`. Žiniatinklio serveris savo puslapius siūlo ir per **HTTPS**.

## Spynelė naršyklėje

1. Persijunk į :fa-play: **Paleisti** režimą (Vykdymo režimas), spustelėk **Client-PC** ir atidaryk :fa-globe: **Naršyklė**.
2. Atidaryk `https://www.beaver-schule.de/` — atkreipk dėmesį į **https**.
3. Kairėje nuo adreso atsiranda **spynelė**. Spustelėk ją.

:::quiz short
Kokiam vardui buvo išduotas sertifikatas (subjektas be `CN=`)?
= www.beaver-schule.de
:::

:::quiz short
Kas išdavė sertifikatą (išdavėjas be `CN=`)?
= Biber Root CA
:::

:::evaluate
Patikrinti atsakymus
:::

## Kodėl Client-PC pasitiki sertifikatu?

Atidaryk **Client-PC** :fa-shield-halved: **Zertifikatverwaltung** ir pereik į kortelę **Vertrauenswürdige CAs**.

:::quiz mc
Ką ten randi?
- [x] **Biber Root CA** sertifikatą
- [ ] `www.beaver-schule.de` sertifikatą
- [ ] Įrašų nėra
:::

:::quiz mc
Kaip matyti, kad Biber Root CA yra šakninė CA?
- [x] Ji yra **pasirašyta pati savęs**: subjektas ir išdavėjas sutampa
- [ ] Jos pavadinimas baigiasi „CA“
- [ ] Ji neturi viešojo rakto
:::

:::quiz mc
Ar prie Client-PC ties **Privater Schlüssel** nurodyta „Ja“, ar „Nein“?
- [ ] Ja — klientui reikia CA privačiojo rakto, kad patikrintų parašus
- [x] Nein — patikrinti pakanka viešojo rakto; privatųjį raktą turi tik CA
:::

:::evaluate
Patikrinti atsakymus
:::

## Kita pusė: žiniatinklio serveris

Dabar žiniatinklio serveryje **www.beaver-schule.de** atidaryk :fa-shield-halved: **Zertifikatverwaltung** (kortelė **Meine Zertifikate**) ir peržiūrėk jo sertifikatą.

:::quiz multi
Kas teisinga apie žiniatinklio serverio sertifikatą?
- [x] Ties **Privater Schlüssel** nurodyta „Ja“ — serveriui jis reikalingas ryšio užmezgimui
- [x] **Grandinė** yra `www.beaver-schule.de ← Biber Root CA`
- [x] **Kontrolinis kodas (angl. fingerprint)** yra toks pat kaip naršyklės spynelės lange
- [ ] Jis pasirašytas pats savęs
:::

:::evaluate
Patikrinti atsakymus
:::

:::note
**Kontrolinis kodas** (angl. fingerprint) yra sertifikato maišos reikšmė. Pagal ją galima greitai palyginti du sertifikatus — nereikia tikrinti visų laukų po vieną.
:::

:::tip Svarbu įsiminti
**Žiniatinklio serveris** turi savo sertifikatą **kartu su privačiuoju raktu**. **Klientas** žino tik **šakninės CA sertifikatą** (be privačiojo rakto) — to pakanka, kad jis galėtų patikrinti serverio sertifikato parašą. Spustelėjus naršyklėje **spynelę**, matomas subjektas, išdavėjas, kontrolinis kodas ir galiojimas.
:::

# DNS: vardai vietoje skaičių

:::goal
**Mokymosi tikslas:** Gebėsi paaiškinti, kaip DNS verčia vardus į IP adresus, kaip vardai organizuoti hierarchiškai, pats sukurti įrašą ir rasti tipines DNS klaidas.
:::

:::sim
url=/sims/lesson-6.2.btsim
:::

IP adresų beveik niekas neprisimena — o vardus, tokius kaip `www.beaver-schule.de`, prisimena. Vertimą atlieka **Domain Name System** (**DNS**) — tarsi pasaulinė interneto telefonų knyga.

Darbo srityje dabar yra šiek tiek didesnis tinklas: be **Client-PC** ir **Webserver** yra dar keturi **DNS serveriai**. Kodėl jų tiek daug, pamatysi po vieno puslapio.

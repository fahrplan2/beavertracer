# Atsakymų problema

:::sim
url=/sims/lesson-9.2.btsim
:::

Ugniasienė dabar veikia pagal baltojo sąrašo principą: numatytoji politika **Atmesti viską**. Viena vienintelė taisyklė leidžia mokyklos tinklui naršyti internete: **B → A, TCP, paskirties prievadas 80, Leisti**. Režimas nustatytas į **Stateless**.

## Eksperimentas

1. Perjunk į :fa-play: **Paleisti** režimą (Vykdymo režimas) ir **Lehrer-PC** kompiuteryje :fa-globe: **Naršyklėje** atidaryk `http://203.0.113.80/`.
2. **Firewall** įrenginyje peržiūrėk **Protokoll** ir **Treffer**.

:::quiz mc
Kas nutinka naršyklėje?
- [ ] Atsiranda www.beispiel.de puslapis
- [x] Puslapis neįsikelia, naršyklė laukia ir galiausiai praneša apie klaidą
:::

:::quiz mc
Kurie paketai ugniasienės žurnale pažymėti kaip atmesti (`DROP`)?
- [ ] Lehrer-PC užklausos į 80 prievadą
- [x] `203.0.113.80` atsakymai su **šaltinio prievadu 80** į Lehrer-PC
- [ ] Jokių
:::

:::quiz short
Kuria kryptimi (A→B ar B→A) keliauja atmesti paketai?
= A→B
= A → B
= AtoB
:::

:::evaluate
Patikrinti atsakymus
:::

Lehrer-PC užklausa gali išeiti, tačiau jau žiniatinklio serverio `SYN, ACK` atgal negrįžta, nes krypčiai A → B nėra tinkamos taisyklės, todėl galioja **Atmesti viską**.

## Naivus sprendimas

Galima įrašyti antrą taisyklę: **A → B, TCP, šaltinio prievadas 80, Leisti** – „viskas, kas ateina iš 80 prievado, gali patekti vidun“. Tada naršymas iš tikrųjų pradeda veikti.

:::quiz mc
Kodėl ši taisyklė pavojinga?
- [ ] Nes žiniatinklio serveriai niekada nenaudoja 80 prievado kaip šaltinio prievado
- [x] Užpuolikas gali tiesiog siųsti savo paketus su šaltinio prievadu 80 – tada ugniasienė praleidžia juos į **bet kurį** mokyklos tinklo prievadą
- [ ] Nes tada tinklalapiai įsikelia lėčiau
:::

:::evaluate
Patikrinti atsakymą
:::

Šaltinio prievadą nustato pats siuntėjas – ugniasienė negali juo pasikliauti. Be būsenos veikianti ugniasienė nežino, ar paketas yra **atsakymas į užklausą**, ar **naujas bandymas užmegzti ryšį** iš išorės. Būtent tai pakeičia veikimo su būsena režimas.

:::tip Svarbu įsiminti
**Be būsenos veikiantis** paketų filtras tikrina kiekvieną paketą atskirai. Tada atsakymams reikia atskirų taisyklių grįžtamajai krypčiai, o tokias taisykles (pvz., „šaltinio prievadas 80 gali patekti vidun“) užpuolikai gali išnaudoti, nes siuntėjas šaltinio prievadą gali pasirinkti laisvai.
:::

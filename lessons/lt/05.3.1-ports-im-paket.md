## Eksperimentas

1. Pereik į :fa-play: **Paleisti** režimą, spustelėk **Client-PC** ir atidaryk :fa-globe: **Naršyklė**. Atidaryk `http://192.168.0.20/`.
2. Lango viršuje spustelėk **Atgal**, atidaryk **Paprastas TCP klientas** ir prijunk jį prie `192.168.0.20`, prievadas `5000`. Palik ryšį atvirą.
3. Pereik į :fa-magnifying-glass: **Sekti** režimą, atidaryk **Client-PC** sekimo langą (trace) ir spustelėk paketą su `[SYN]`. Išskleisk **Transmission Control Protocol**.

Pačiame TCP antraštės viršuje yra du prievadai: **Source Port** (šaltinio prievadas) ir **Destination Port** (paskirties prievadas).

:::quiz table
| Ryšys | Šaltinio prievadas | Paskirties prievadas |
|---|---|---|
| Browser → Webserver | {49152} | {80} |
| TCP-Client → Echo-Dienst | {49153} | {5000} |
:::

## Dviejų rūšių prievadai

**Paskirties prievadas – paslauga:** serverio programa laukia ryšių fiksuotame prievade – sakoma, kad ji jame **klauso**. Žinomoms paslaugoms numeriai visame pasaulyje yra nustatyti – tai **gerai žinomi prievadai** (angl. *well-known ports*, nuo 0 iki 1023). Todėl naršyklė be jokių klausimų žino: žiniatinklio serveriai klauso 80 prievade.

**Šaltinio prievadas – siuntėjas:** kliento pusės prievadą kiekvienam naujam ryšiui operacinė sistema pati pasirenka iš aukšto numerių diapazono (BeaverTracer – nuo 49152). Pagal jį klientas atpažįsta, kuriam iš jo ryšių priklauso atsakymas.

Taigi ryšį vienareikšmiškai nusako keturi duomenys: **IP adresas ir prievadas abiejose pusėse**. IP adreso ir prievado pora vadinama **lizdu** (angl. *socket*), pvz., `192.168.0.20:80`.

## Žvilgsnis į serverį

Grįžk į :fa-play: **Paleisti** režimą, serveryje **Server** atidaryk :fa-terminal: **Terminalas** ir įvesk:

```
$ ss
```

`ss` parodo visus kompiuterio lizdus. Eilutės su `LISTEN` – tai programos, klausančios prievado. Eilutės su `ESTABLISHED` – esami ryšiai – su savo lizdu (*Local Address:Port*) ir kitos pusės lizdu (*Peer Address:Port*).

:::quiz multi
Kuriuose prievaduose klauso serveris?
- [x] 80
- [x] 5000
- [ ] 49152
- [ ] 443
:::

:::quiz mc
Kurį ryšį `ss` rodo kaip `ESTABLISHED`?
- [x] `192.168.0.20:5000` su `192.168.0.10:49153` – atviras TCP kliento ryšys
- [ ] `192.168.0.20:80` su `192.168.0.10:49152` – naršyklės ryšys
- [ ] Abu
:::

:::evaluate
Patikrinti atsakymus
:::

:::note
Naršyklės ryšys jau nutrauktas – įkėlus puslapį jis buvo užbaigtas su `FIN`. `ss` jį dar trumpai rodo kaip `TIME-WAIT`: serveris kurį laiką laukia, ar dar neatkeliaus pavėluotų šio ryšio paketų. O TCP kliento ryšys vis dar atviras, nes dar nespustelėjai **Atsijungti**.
:::

## Svarbiausi gerai žinomi prievadai

| Prievadas | Protokolas | Paslauga |
|---|---|---|
| 22 | SSH | saugus nuotolinis valdymas (šifruota komandų eilutė) |
| 25 | SMTP | el. laiškų siuntimas |
| 53 | DNS | vardų vertimas į IP adresus (dažniausiai per UDP) |
| 80 | HTTP | tinklalapiai |
| 110 | POP3 | el. laiškų atsiėmimas |
| 143 | IMAP | el. laiškų tvarkymas serveryje |
| 443 | HTTPS | šifruoti tinklalapiai |

:::tip Svarbu įsiminti
**Prievadai** (nuo 0 iki 65535) padeda atskirti kompiuterio ryšius. Serverių paslaugos **klauso** fiksuotuose **gerai žinomuose prievaduose** (pvz., HTTP 80, HTTPS 443), o klientai kiekvienam ryšiui gauna laisvą aukštą **šaltinio prievadą**. Ryšį vienareikšmiškai nusako **abiejų pusių IP adresas ir prievadas**.
:::

:::quiz match
22 -> SSH
25 -> SMTP
53 -> DNS
80 -> HTTP
110 -> POP3
143 -> IMAP
443 -> HTTPS
:::

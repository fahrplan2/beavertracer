# Adreso gavimas automatiškai

:::sim
url=/sims/lesson-6.4.btsim
:::

Prie komutatoriaus prijungti **DHCP serveris** ir du nešiojamieji kompiuteriai. Kol kas nešiojamieji kompiuteriai turi fiksuotus adresus.

## Eksperimentas

1. Persijunk į :fa-play: **Vykdymo režimas** — tiksliau, į :fa-play: **Paleisti** režimą, spustelėk **Laptop 1** ir atidaryk :fa-gear: **IP nustatymai**.
2. Pakeisk **Modus** iš **Statinis** į **DHCP** ir spustelėk **Taikyti**.
3. Palauk kelias sekundes: laukai užsipildo patys.
4. :fa-magnifying-glass: **Sekti** režime atidaryk **Laptop 1** sekimo įrašą (trasą).

:::quiz table
| Nustatymas | gauta iš DHCP serverio |
|---|---|
| IP adresas | {192.168.0.100} |
| Gateway | {192.168.0.1} |
| DNS serveris | {192.168.0.53} |
:::

:::quiz short
Kiek DHCP paketų rasi sekimo įraše?
= 4
= keturi
:::

:::quiz mc
Kokiu paskirties IP adresu Laptop 1 siunčia savo pirmąjį paketą (`DHCP Discover`)?

## Kas už to slypi: DORA

Įrenginys be adreso nežino, kur yra DHCP serveris, ir neturi savo siuntėjo adreso. Todėl jis šaukia į tinklą per **transliaciją**. Procesas turi keturis žingsnius — pagal pirmąsias raides jis vadinamas **DORA**:

:::seq
mode: text
Laptop 1 -> DHCP-Server: DHCP Discover | „Ar čia yra DHCP serveris?“
DHCP-Server -> Laptop 1: DHCP Offer | „Gali gauti 192.168.0.100.“
Laptop 1 -> DHCP-Server: DHCP Request | „Imu 192.168.0.100.“
DHCP-Server -> Laptop 1: DHCP ACK | „Patvirtinta — galioja 3600 sekundžių.“
:::

Adresas tik **išnuomotas** (angl. *lease*): pasibaigus **nuomos trukmei** įrenginys turi jį pratęsti, kitaip serveris gali adresą išduoti iš naujo. Kurie adresai šiuo metu išnuomoti, matai **DHCP serveris** lange kortelėje **Leases**.

:::tip Išbandyk
Nustatyk DHCP ir **Laptop 2**. Kokį adresą jis gauna? Po to pažiūrėk į DHCP serverio **Leases**.
:::

:::tip Svarbu įsiminti
**DHCP** automatiškai paskirsto IP adresą, tinklo kaukę, šliuzą ir DNS serverį. Procesas vadinamas **DORA**: **D**iscover (klientas ieško per transliaciją), **O**ffer (serveris pasiūlo), **R**equest (klientas priima), **A**CK (serveris patvirtina). Adresas išnuomotas **nuomos trukmei**. DHCP naudoja **UDP**, prievadus 67 (serveris) ir 68 (klientas).
:::

:::quiz match
Discover -> Klientas per transliaciją ieško DHCP serverio
Offer -> Serveris pasiūlo adresą
Request -> Klientas paprašo pasiūlyto adreso
ACK -> Serveris patvirtina paskyrimą
:::

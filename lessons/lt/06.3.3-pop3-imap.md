# POP3 ar IMAP?

:::sim
url=/sims/lesson-6.3.btsim
:::

Laiškams atsisiųsti iš serverio yra du protokolai. Šioje simuliacijoje **Anna naudoja POP3**, o **Ben – IMAP**.

## Eksperimentas

1. :fa-play: **Vykdymo režimu** nusiųsk laišką iš **Ben** adresu `anna@beaver-schule.de`.
2. Ties **Anna** programoje **E-Mail** spustelėk **Gauti**.
3. Atverk **Anna** ir **Ben** pėdsakus (angl. traces) ir palygink komandas, naudojamas laiškams gauti.

:::quiz match
USER / PASS -> POP3: prisijungimas vartotojo vardu ir slaptažodžiu dviem žingsniais
RETR -> POP3: vieno laiško atsisiuntimas
LOGIN -> IMAP: prisijungimas vartotojo vardu ir slaptažodžiu
SELECT INBOX -> IMAP: aplanko atidarymas serveryje
:::

:::evaluate
Patikrinti atitikmenis
:::

## Skirtumas

| | POP3 | IMAP |
|---|---|---|
| Prievadas | 110 | 143 |
| Pagrindinė idėja | laiškai **atsisiunčiami** – paskui dažniausiai ištrinami serveryje | laiškai **lieka serveryje** ir tvarkomi ten |
| Aplankai, perskaityta / neperskaityta | tik paties įrenginio atmintyje | serveryje – visur vienodai |
| Keli įrenginiai (telefonas, nešiojamasis kompiuteris) | nepraktiška: kiekvieno įrenginio būsena skiriasi | idealu: visi įrenginiai mato tą pačią pašto dėžutę |

:::note
BeaverTracer pašto programa laiškus palieka serveryje net naudodama POP3. Tikros programos juos po atsisiuntimo dažnai ištrina arba palieka tik kuriam laikui.
:::

:::quiz mc
Lena skaito savo laiškus telefone, planšetėje ir mokyklos nešiojamajame kompiuteryje. Ką jai reikėtų naudoti?
- [ ] POP3, nes jis paprastesnis
- [x] IMAP, nes visi įrenginiai mato tą pačią pašto dėžutę serveryje
- [ ] SMTP, nes jis skirtas laiškams gauti

Patikrinti atsakymą

:::tip Svarbu įsiminti
**POP3** atsisiunčia laiškus iš serverio į **vieną** įrenginį. **IMAP** tvarko pašto dėžutę **serveryje** – su aplankais ir perskaitymo būsena vienu metu visiems įrenginiams. Abu skirti tik laiškams **gauti**; siunčiama visada naudojant **SMTP**.
:::

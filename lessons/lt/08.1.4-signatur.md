# Skaitmeniniai parašai

Šifravimu pasiekiamas **konfidencialumas**, o maišos reikšmėmis aptinkami pakeitimai. Bet kaip įrodyti, **kas** išsiuntė žinutę? Ant popieriaus pasirašoma. Tinkle tam skirtas **skaitmeninis parašas**.

## Raktų pora panaudojama atvirkščiai

Šifruodamas siuntėjas naudoja gavėjo **viešąjį** raktą. Pasirašant yra atvirkščiai: siuntėjas naudoja **savo paties privatųjį** raktą. Kadangi šį raktą turi tik jis, tik jis gali sukurti šį parašą. O patikrinti jį gali kiekvienas — naudodamas siuntėjo **viešąjį** raktą.

**Pasirašymas** (Anna pasirašo sutartį):

1. Anna apskaičiuoja sutarties **maišos reikšmę**.
2. Ji maišos reikšmę apdoroja savo **privačiuoju raktu**. Rezultatas yra **parašas**.
3. Ji siunčia sutartį kartu su parašu Benui.

**Tikrinimas** (Benas tikrina parašą):

1. Benas pats apskaičiuoja gautos sutarties maišos reikšmę.
2. Jis tikrina parašą Annos **viešuoju raktu**: ar jis atitinka šią maišos reikšmę?
3. Jei atitinka, Benas žino du dalykus:
    - Sutartis tikrai gauta iš Annos — privatųjį raktą turi tik ji (**autentiškumas**).
    - Sutartis kelyje nebuvo pakeista — kitaip ji turėtų kitą maišos reikšmę (**vientisumas**).

:::note
Kodėl Anna pasirašo tik maišos reikšmę, o ne visą sutartį? Asimetriniai metodai yra lėti. Maišos reikšmė visada trumpa — nesvarbu, ar sutartis turi vieną puslapį, ar tūkstantį.
:::

:::quiz mc
Kuriuo raktu Anna **sukuria** savo parašą?
- [x] Savo privačiuoju raktu
- [ ] Savo viešuoju raktu
- [ ] Beno viešuoju raktu
:::

:::quiz mc
Kuriuo raktu Benas **tikrina** parašą?
- [ ] Savo privačiuoju raktu
- [x] Annos viešuoju raktu
- [ ] Annos privačiuoju raktu
:::

:::quiz mc
Užpuolikas perima sutartį ir pakeičia sumą. Parašą palieka nepakeistą. Kas nutinka Beno atliekamo tikrinimo metu?
- [x] Tikrinimas nepavyksta, nes pakeista sutartis turi kitą maišos reikšmę
- [ ] Tikrinimas pavyksta, nes parašas juk tikras
- [ ] Benas apskritai negali patikrinti parašo, nes nežino Annos privačiojo rakto
:::

Patikrinti atsakymus

:::quiz match
Konfidencialiai rašyti Benui -> šifruoti Beno viešuoju raktu
Perskaityti užšifruotą žinutę -> iššifruoti savo privačiuoju raktu
Pasirašyti dokumentą -> savo privačiuoju raktu
Patikrinti parašą -> siuntėjo viešuoju raktu
:::

:::evaluate
Patikrinti suporavimą
:::

:::tip Svarbu įsiminti
**Skaitmeninį parašą** siuntėjas sukuria iš žinutės **maišos reikšmės** ir savo **privačiojo rakto**. Kiekvienas gali jį patikrinti siuntėjo **viešuoju raktu**. Galiojantis parašas įrodo, **kas** išsiuntė žinutę (**autentiškumas**) ir kad ji **nebuvo pakeista** (**vientisumas**).
:::

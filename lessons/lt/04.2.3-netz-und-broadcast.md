# Tinklo adresas, transliacijos adresas ir mazgai

Kiekviename tinkle dvi adresai atlieka ypatingą vaidmenį:

- **Tinklo adresas** yra **žemiausias** tinklo adresas: visi mazgo dalies bitai yra 0. Jis nurodo tinklą kaip visumą, pvz., maršrutizavimo lentelėse.
- **Transliacijos adresas** yra **aukščiausias** tinklo adresas: visi mazgo dalies bitai yra 1. Kas siunčiama šiuo adresu, pasiekia visus tinklo įrenginius.

Abu šie adresai **nepriskiriami** įrenginiams. Visi tarp jų esantys adresai skirti įrenginiams (**mazgams**).

## Paprastas pavyzdys

`192.168.0.12/24` — mazgo dalis yra paskutinis oktetas:

| | Adresas |
|---|---|
| Tinklo adresas (mazgo dalis = 0) | `192.168.0.0` |
| Transliacijos adresas (mazgo dalis = 255) | `192.168.0.255` |
| Mazgų diapazonas | `192.168.0.1` – `192.168.0.254` |
| Mazgų skaičius | 254 |

## Kai riba yra oktete

Sunkiau tampa, kai prefikso ilgis nėra 8 kartotinis. Tada atitinkamą oktetą perskaičiuoji į dvejetainę skaičiavimo sistemą. Pavyzdys: `194.9.190.12/27`.

Pirmieji trys oktetai visiškai priklauso [[n|tinklo daliai]] (24 bitai). Iš paskutiniojo okteto dar **3 bitai** priklauso tinklo daliai (24 + 3 = 27), likę **5 bitai** — [[h|mazgo daliai]]:

| | paskutinis oktetas (dvejetainis) | dešimtainis |
|---|---|---|
| IP adresas | [[n|000]][[h|01100]] | 12 |
| Tinklo kaukė (`/27`) | [[n|111]][[h|00000]] | 224 |
| Tinklo adresas: mazgo bitai į 0 | [[n|000]][[h|00000]] | **0** |
| Transliacijos adresas: mazgo bitai į 1 | [[n|000]][[h|11111]] | **31** |

Rezultatas:

- Tinklo adresas: `194.9.190.0`
- Transliacijos adresas: `194.9.190.31`
- Mazgų diapazonas: `194.9.190.1` – `194.9.190.30`
- Mazgų skaičius: 2⁵ − 2 = **30**

:::tip Svarbu įsiminti
**Tinklo adresas:** visi mazgo bitai lygūs 0 (žemiausias adresas). **Transliacijos adresas:** visi mazgo bitai lygūs 1 (aukščiausias adresas). Abu nepriskiriami įrenginiams. Tinkle, kurio prefikso ilgis yra *n*, mazgams tinkamų naudoti adresų yra **2<sup>32 − n</sup> − 2**.
:::

:::tip Patarimas: bloko dydis
Kai suprasi skaičiavimą dvejetainėje sistemoje, yra trumpesnis kelias: **256 minus kaukės oktetas** duoda tinklo dydį tame okete. Esant `/27` (kaukė 224) tai yra 256 − 224 = **32**. Tada tinklai prasideda nuo 0, 32, 64, 96 … — adresas `.12` yra tinkle, prasidedančiame nuo `.0`, o adresas `.70` — tinkle, prasidedančiame nuo `.64`.
:::

## Svarbiausi tinklų dydžiai

| Prefiksas | Tinklo kaukė | Mazgai |
|---|---|---|
| `/8` | `255.0.0.0` | 16 777 214 |
| `/16` | `255.255.0.0` | 65 534 |
| `/24` | `255.255.255.0` | 254 |
| `/25` | `255.255.255.128` | 126 |
| `/26` | `255.255.255.192` | 62 |
| `/27` | `255.255.255.224` | 30 |
| `/28` | `255.255.255.240` | 14 |
| `/29` | `255.255.255.248` | 6 |
| `/30` | `255.255.255.252` | 2 |

:::note
Mažiausias praktikoje įprastas tinklas yra `/30`: jame yra lygiai du tinkami naudoti adresai, todėl jis dažnai naudojamas ryšiui tarp dviejų maršrutizatorių. `/32` žymi vieną adresą — kaip tinklas jis netinkamas, bet pasitaiko maršrutizavimo lentelėse ir ugniasienės taisyklėse.
:::

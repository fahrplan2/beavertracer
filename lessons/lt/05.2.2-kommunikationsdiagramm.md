# Komunikacijos diagrama

:::sim
url=/sims/lesson-5.1.btsim
:::

Ryšio eiga braižoma **komunikacijos diagrama**: klientas ir serveris gauna po vertikalią liniją, laikas teka iš viršaus į apačią. Kiekviena rodyklė yra vienas paketas. Ji nubrėžta įstrižai, nes kiekvienas paketas šiek tiek laiko keliauja.

Štai kaip atrodo tavo ryšys iš ankstesnio puslapio — palygink jį eilutė po eilutės su trasa:

:::seq
Client-PC -> Server: SYN
Server -> Client-PC: SYN, ACK
Client-PC -> Server: ACK
Client-PC -> Server: PSH, ACK "Hello World" len=13
Server -> Client-PC: ACK
Server -> Client-PC: PSH, ACK len=13
Client-PC -> Server: ACK
Client-PC -> Server: FIN, ACK
Server -> Client-PC: ACK
Server -> Client-PC: FIN, ACK
Client-PC -> Server: ACK
:::

Virš kiekvienos rodyklės pateiktos **vėliavėlės** (angl. *flags*), po ja – numeriai `SEQ` ir `ACK`. **DATA** žymi paketus su naudingaisiais duomenimis. Raudoni skaičiai priklauso klientui, mėlyni – serveriui; ką jie reiškia, paaiškinama kitame puslapyje.

## Vėliavėlės

| Vėliavėlė | reiškia | Reikšmė |
|---|---|---|
| **SYN** | *synchronize* | užmegzti ryšį, nustatyti pradinį numerį |
| **ACK** | *acknowledge* | patvirtina gautus duomenis |
| **PSH** | *push* | iškart perduoti duomenis programai |
| **FIN** | *finish* | „Aš baigiau“ — nutraukti ryšį |
| **RST** | *reset* | nutraukti arba atmesti ryšį (daugiau apie tai 5.3.2) |

## Trys fazės

**Užmezgimas:** klientas siunčia `SYN`, serveris atsako `SYN, ACK`, klientas patvirtina `ACK`. Kadangi reikia lygiai trijų paketų, tai vadinama **trijų žingsnių pasisveikinimu** (angl. *three-way handshake*).

**Duomenys:** gavėjas patvirtina kiekvieną paketą su duomenimis paketu `ACK`. Čia serveris siunčia atgal aidą (angl. *echo*) — klientas patvirtina ir jį.

**Nutraukimas:** kiekviena pusė užbaigia savo siuntimo kryptį atskirai: `FIN` iš kliento, `ACK` iš serverio — tada `FIN` iš serverio, `ACK` iš kliento. Tai keturi paketai.

:::tip Svarbu įsiminti
TCP ryšys vyksta trimis fazėmis: **užmezgimas** su **trijų žingsnių pasisveikinimu** (`SYN` → `SYN, ACK` → `ACK`), **duomenų perdavimas** (kiekvienas duomenų paketas patvirtinamas `ACK`) ir **nutraukimas** (kiekviena pusė siunčia `FIN` ir gauna `ACK`).
:::

## Dabar tavo eilė

Šįkart klientas siunčia tik `Hi` (su eilutės pabaiga – 4 baitai). Įrašyk trūkstamas vėliavėles — tvarka viename lauke nesvarbi.

:::quiz seq
hide: counters
Client-PC -> Server: ? SYN
Server -> Client-PC: ? SYN, ACK
Client-PC -> Server: ? ACK
Client-PC -> Server: PSH, ACK "Hi" len=4
Server -> Client-PC: ? ACK
Client-PC -> Server: ? FIN, ACK
Server -> Client-PC: ? ACK
Server -> Client-PC: ? FIN, ACK
Client-PC -> Server: ? ACK
:::

# Sekos ir patvirtinimo numeriai

:::sim
url=/sims/lesson-5.1.btsim
:::

Kaip TCP žino, ar viskas atkeliavo — ir kokia tvarka? Kiekviena pusė **sunumeruoja baitus**, kuriuos siunčia:

- **Sekos numeris** (`SEQ`) yra pirmojo šiame pakete esančio baito numeris.
- **Patvirtinimo numeris** (`ACK`) sako: „Iki šios vietos viską gavau — toliau tikiuosi baito Nr. …“

Be to, galioja dvi taisyklės: `SYN` ir `FIN` skaičiuojami kaip vienas baitas, nors duomenų ir nenešą. Ir kiekviena pusė skaičiuoja atskirai — todėl yra dvi numeracijos sekos, diagramoje raudona (klientas) ir mėlyna (serveris).

## Perskaičiuojame

Čia dar kartą tavo ryšys. Skaičiai prie linijų rodo kompiuterio skaitiklio reikšmę toje vietoje:

:::seq
Client-PC -> Server: SYN
Server -> Client-PC: SYN, ACK
Client-PC -> Server: ACK
Client-PC -> Server: PSH, ACK "Hello World" len=13
Server -> Client-PC: ACK
Server -> Client-PC: PSH, ACK len=13
Client-PC -> Server: ACK
Client-PC -> Server: FIN, ACK
Server -> Client-PC: ACK
Server -> Client-PC: FIN, ACK
Client-PC -> Server: ACK
:::

Peržiūrėk raudonąją skaičių eilutę:

1. Klientas pradeda nuo `SEQ=0`. Jo `SYN` sunaudoja vieną numerį — serveris patvirtina su `ACK=1`.
2. Žinutė prasideda nuo `SEQ=1` ir yra 13 baitų ilgio (baitai nuo 1 iki 13). Serveris patvirtina su `ACK=14`: „Toliau tikiuosi 14 baito.“
3. Todėl kliento `FIN` turi `SEQ=14` ir patvirtinamas su `ACK=15`.

Mėlynoji serverio eilutė veikia lygiai taip pat.

:::tip Svarbu įsiminti
**Sekos numeris** (`SEQ`) yra pirmojo paketo baito numeris. **Patvirtinimo numeris** (`ACK`) yra kito baito, kurio tikisi gavėjas, numeris — viskas, kas prieš jį, jau atkeliavo. Galioja: **ACK = SEQ + gautų duomenų ilgis**; `SYN` ir `FIN` skaičiuojami kaip vienas baitas. Kiekviena pusė skaičiuoja savo baitus.
:::

:::tip Išbandyk
Dar kartą sukurk ryšį su **Paprastas TCP klientas** ir išsiųsk dvi žinutes iš eilės. Iš anksto pasakyk, kokie `Seq` ir `Ack` bus rodomi stulpelyje **Info** — ir patikrink sekimo rezultate.
:::

:::note
Tikruose tinkluose skaičiavimas nepradedamas nuo 0: kiekviena pusė pasirenka **atsitiktinį pradinį numerį** (*Initial Sequence Number*, ISN) nuo 0 iki maždaug 4,3 milijardo. Pasiekus didžiausią numerį, skaičiavimas vėl tęsiamas nuo 0. Tracer atima pradinį numerį ir rodo **santykinius** numerius — lygiai kaip Wireshark. Todėl matai `Seq=0` ir `Seq=1`.

Be to, kiekviename pakete yra `Win=` — **lango dydis**: tiek baitų gavėjas šiuo metu gali priimti. Taip jis pristabdo per greitą siuntėją (*srauto valdymas*). BeaverTracer programoje langas visada vienodo dydžio.
:::

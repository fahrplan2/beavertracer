# HTTP: tinklalapiai

:::goal
**Mokymosi tikslas:** Gebėsi apibūdinti HTTP užklausos ir atsakymo sandarą, paaiškinti svarbiausius metodus ir būsenos kodus bei pats rankiniu būdu sukurti HTTP užklausą.
:::

**Hiperteksto perdavimo protokolas** (angl. *Hypertext Transfer Protocol*, **HTTP**) yra kalba, kuria tarpusavyje bendrauja naršyklės ir žiniatinklio serveriai. Serveryje yra **Beaver-Schule** tinklalapis: pradžios puslapis, kontaktų puslapis ir stilių failas, nusakantis išvaizdą.

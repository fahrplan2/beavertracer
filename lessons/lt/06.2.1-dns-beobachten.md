## Eksperimentas

1. Perjunk į :fa-play: **Paleisti** režimą (Vykdymo režimas), spustelėk **Client-PC** ir atidaryk :fa-globe: **Naršyklė**.
2. Šį kartą atidaryk `http://www.beaver-schule.de/` — su vardu, o ne IP adresu.
3. Perjunk į :fa-magnifying-glass: **Sekti** režimą ir atidaryk **Client-PC** pėdsaką (angl. trace).

Pačioje pradžioje — dar prieš ryšio užmezgimą su `[SYN]` — matyti du paketai su protokolu **DNS**.

:::quiz short
Kokiu IP adresu Client-PC siunčia savo DNS užklausą?
= 192.168.0.53
:::

:::quiz short
Koks IP adresas nurodytas atsakyme į `www.beaver-schule.de`?
= 192.168.0.20
:::

:::quiz mc
Spustelėk DNS užklausą ir išskleisk protokolų medį. Koks transporto protokolas ir koks paskirties prievadas naudojami?
- [ ] TCP, prievadas 80
- [x] UDP, prievadas 53
- [ ] UDP, prievadas 67
:::

:::evaluate
Patikrinti atsakymus
:::

Tik tada, kai Client-PC sužino IP adresą, jis užmezga TCP ryšį su žiniatinklio serveriu — lygiai kaip 5 skyriuje.

:::seq
mode: text
Client-PC -> DNS-Resolver: DNS-Anfrage | A www.beaver-schule.de?
DNS-Resolver -> Client-PC: DNS-Antwort | A 192.168.0.20
:::

## Iš kur kompiuteris žino DNS serverį?

Atidaryk **Client-PC** :fa-gear: **IP nustatymai**: lauke **DNS-Server** įrašyta `192.168.0.53` — tai kompiuteris **DNS-Resolver**. Būtent jam kompiuteris siunčia kiekvieną vardo užklausą.

DNS serverio gali paklausti ir tiesiogiai, be naršyklės. Atidaryk :fa-terminal: **Terminalas** ir įvesk:

```
$ nslookup www.beaver-schule.de
```

`nslookup` pirmiausia parodo, kurio serverio paklausė, o paskui — atsakymą. Palyginimui paklausk vardo, kurio nėra, pvz., `nslookup gibtsnicht.beaver-schule.de`.

:::quiz mc
Ką DNS serveris atsako į nežinomą vardą?
- [ ] Atsitiktinį IP adresą
- [x] `NXDOMAIN` — tokio vardo nėra
- [ ] Visai nieko
:::

:::evaluate
Patikrinti atsakymą
:::

:::tip Svarbu įsiminti
**DNS** paverčia vardus (pvz., `www.beaver-schule.de`) IP adresais. Prieš kompiuteriui užmezgant ryšį su vardu, jis paklausia **DNS serverio**, nurodyto jo IP nustatymuose — dažniausiai per **UDP, prievadą 53**. Naudodamas `nslookup` gali DNS užklausas pateikti ranka.
:::

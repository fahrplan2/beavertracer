# Kaip organizuota DNS

:::sim
url=/sims/lesson-6.2.btsim
:::

Joks vienas serveris negali žinoti visų pasaulio vardų. Todėl DNS sukurta **hierarchiškai** — kaip ir patys vardai. Juos skaitome iš dešinės į kairę:

```
www . beaver-schule . de . (Root)
 │          │         │      └─ Root-Server: kennen die Server aller Top-Level-Domains
 │          │         └─ Top-Level-Domain (TLD): der de-Server kennt alle .de-Domains
 │          └─ Domain: der Schul-DNS ist für beaver-schule.de zuständig
 └─ Rechnername innerhalb der Domain
```

Serveris, atsakingas už domeną ir tikrai žinantis atsakymą, vadinamas **autoritetingu**. Kelią iki jo kompiuterio vardu nueina **resolveris** — čia tai kompiuteris **DNS-Resolver**.

## Eksperimentas

1. Perjunk į :fa-play: **Paleisti** režimą ir **Client-PC** :fa-terminal: **Terminalas** įvesk:
   ```
   $ nslookup www.beaver-schule.de
   ```
2. :fa-magnifying-glass: **Sekti** režime atidaryk **DNS-Resolver** sekimą.

Resolveris tavo vardu pateikė visą eilę užklausų. Priskirk, kas kokį atsakymą davė:

:::quiz match
Root-Server (192.168.0.101) -> Nukreipimas: už .de atsakingas ns.nic.de
de-Server (192.168.0.102) -> Nukreipimas: už beaver-schule.de atsakingas ns.beaver-schule.de
Schul-DNS (192.168.0.103) -> Atsakymas: www.beaver-schule.de adresas yra 192.168.0.20
:::

:::quiz mc
Ko resolveris klausia pirmiausia?
- [x] Root serverio
- [ ] Schul-DNS
- [ ] Client-PC
:::

:::evaluate
Patikrinti atsakymus
:::

:::note
Tarp kitko resolveris klausia ir serverių, į kuriuos buvo nukreiptas, adresų (`A ns.nic.de`). Tikri DNS serveriai šiuos adresus dažniausiai iškart prideda prie atsakymo. Be to, resolveriai kurį laiką įsimena kiekvieną atsakymą (**talpykla**) — kitą užklausą dėl to paties vardo jie atsako patys iš karto. Kiek laiko — nurodoma įraše kaip **TTL** (*Time to Live*) sekundėmis.
:::

## Svarbiausi įrašų tipai

| Tipas | Reikšmė | Pavyzdys |
|---|---|---|
| **A** | vardas → IPv4 adresas | `www.beaver-schule.de` → `192.168.0.20` |
| **AAAA** | vardas → IPv6 adresas | `www.beaver-schule.de` → `2001:db8::20` |
| **CNAME** | vardas → kitas vardas (pseudonimas) | `web.beaver-schule.de` → `www.beaver-schule.de` |
| **MX** | domeno atsakingas pašto serveris | `beaver-schule.de` → `mail.beaver-schule.de` |
| **NS** | domeno atsakingas DNS serveris | `beaver-schule.de` → `ns.beaver-schule.de` |

:::tip Svarbu įsiminti
DNS yra **hierarchinė**: **šakninės (root) serveriai** nukreipia į **aukščiausio lygio domenų** (pvz., `.de`) serverius, šie — į atskirų **domenų** serverius. Atsakingas **autoritetingas** serveris žino atsakymą. **Resolveris** šį kelią nueina vietoj kompiuterio ir įsimena atsakymus (**talpykla**). Svarbūs įrašų tipai: **A**, **AAAA**, **CNAME**, **MX**, **NS**.
:::

## Įrašo sukūrimas

Mokykla nori, kad jos svetainė būtų pasiekiama ir adresu `intranet.beaver-schule.de`.

1. :fa-play: **Paleisti** režime spustelėk **Schul-DNS** ir atidaryk programą **DNS-Server**.
2. Atidaryk kortelę **A**. Spustelėk **+** ir naujoje eilutėje įrašyk vardą `intranet.beaver-schule.de` ir adresą `192.168.0.20`.
3. Išbandyk Client-PC kompiuteryje su `nslookup intranet.beaver-schule.de`.

:::task
title: Ar naujas vardas įrašytas?
Patikrink, ar Client-PC išsprendžia vardą intranet.beaver-schule.de į žiniatinklio serverio adresą. Tam simuliacija turi veikti Vykdymo režimu.
check: resolves(2, "intranet.beaver-schule.de", "192.168.0.20")
:::

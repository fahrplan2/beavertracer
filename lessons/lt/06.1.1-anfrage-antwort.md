## Kaip atrodo užklausa

Pėdsake spustelėk paketą `GET / HTTP/1.1` ir išskleisk **Hypertext Transfer Protocol**. HTTP užklausa yra grynas tekstas:

```
GET / HTTP/1.1              ← Methode, Pfad, Version
Host: 192.168.0.20          ← Header: zusätzliche Angaben
…
                            ← Leerzeile: Ende der Anfrage
```

Serverio atsakas sudarytas lygiai taip pat — su būsenos eilute, antraštėmis, tuščia eilute ir po jos pačiu failu:

```
HTTP/1.1 200 OK             ← Version, Statuscode, Text
Content-Type: text/html     ← Header: Art der Datei
Content-Length: 301         ← Header: Größe in Byte
                            ← Leerzeile
<!doctype html> …           ← die Datei selbst
```

:::seq
mode: text
Client-PC -> Server: GET / | HTTP užklausa
Server -> Client-PC: 200 OK | index.html
Client-PC -> Server: GET /style.css | HTTP užklausa
Server -> Client-PC: 200 OK | style.css
:::

## Metodai ir būsenos kodai

**Metodas** nurodo, ko nori klientas:

| Metodas | Reikšmė |
|---|---|
| **GET** | gauti failą |
| **POST** | siųsti duomenis serveriui, pvz., užpildytą formą |
| **HEAD** | gauti tik antraštes, be failo |

**Būsenos kodas** nurodo, kaip viskas pavyko. Pirmasis skaitmuo parodo atsako rūšį:

| Kodas | Tekstas | Reikšmė |
|---|---|---|
| **200** | OK | viskas gerai |
| **301** | Moved Permanently | puslapis visam laikui perkeltas |
| **404** | Not Found | tokio failo nėra |
| **405** | Method Not Allowed | šis metodas čia neleidžiamas |
| **500** | Internal Server Error | serverio klaida |

`2xx` reiškia sėkmę, `3xx` – nukreipimą, `4xx` – kliento klaidą (neteisinga užklausa), `5xx` – serverio klaidą.

:::tip Svarbu įsiminti
**HTTP** veikia pagal **užklausos ir atsako principą**: klientas siunčia **užklausą** (metodą, pvz., `GET`, kelią, antraštes), serveris atsako **būsenos kodu** (pvz., `200 OK`, `404 Not Found`), antraštėmis ir failu. Kiekvienam tinklalapio failui siunčiama atskira užklausa.
:::

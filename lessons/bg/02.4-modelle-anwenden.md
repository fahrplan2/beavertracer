# Прилагане на моделите

Съотнеси протоколите от експеримента в началото на главата към съответния им OSI слой:

:::quiz match
Ethernet -> Слой 2 — Канален
IPv4 -> Слой 3 — Мрежови
TCP -> Слой 4 — Транспортен
HTTP -> Слой 7 — Приложен
:::

:::evaluate
Провери съотнасянето
:::

И накрая — имената на информационните единици:

:::quiz match
Frame -> Слой 2 — Канален
Пакет -> Слой 3 — Мрежови
Сегмент -> Слой 4 — Транспортен
:::

:::evaluate
Провери съотнасянето
:::

Така вече разполагаш с необходимия инструментариум, за да класифицираш протоколите правилно. От следващата глава ще разгледаме слоевете един по един — започвайки със слой 2 и въпроса как всъщност един суич знае накъде трябва да препрати даден пакет.

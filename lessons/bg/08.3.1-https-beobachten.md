# Сравнение на HTTP и HTTPS

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Уеб сървърът **www.beaver-schule.de** предлага училищния портал за оценки както през HTTP, така и през HTTPS. Какво вижда някой, който подслушва?

## Експериментът

1. Премини в :fa-play: режим на изпълнение (**Стартиране**) и на **Client-PC** в :fa-globe: **Браузър** отвори първо `http://www.beaver-schule.de/`, след това `https://www.beaver-schule.de/`.
2. В :fa-magnifying-glass: режим **Проследяване** отвори трасиране (Trace) за **Client-PC**.
3. Първо намери пакета `HTTP/1.1 200 OK` и щракни върху него. Долу в детайлите ще намериш съдържанието на страницата.

:::quiz mc
Какво може да види подслушвачът при **HTTP**?
- [x] Цялата уеб страница, включително оценките на Anna
- [ ] Само адреса на сървъра
- [ ] Нищо, защото HTTP работи върху TCP
:::

:::quiz short
Каква оценка има Anna по математика?
= 2
:::

:::evaluate
Провери отговорите
:::

Сега е ред на частта с HTTPS. Намери пакета `[SYN]`, с който клиентът започва втората връзка.

:::quiz short
Кой е целевият порт на HTTPS връзката (колона **Info**, `… → ???`)?
= 443
:::

Сега въведи `tls` в полето за филтър горе в трасирането — така ще виждаш само TLS пакетите.

:::quiz mc
Какво пише в колоната **Info** при пакетите, които съдържат уеб страницата?
- [ ] `HTTP/1.1 200 OK`
- [x] `Application Data`
- [ ] `Encrypted HTML`
:::

:::quiz multi
Какво все пак може да види подслушвачът при **HTTPS**?
- [x] IP адресите на клиента и сървъра
- [x] Че се използва порт 443, т.е. вероятно HTTPS
- [x] Приблизително колко данни се предават
- [ ] Коя страница е отворена и какво има на нея
:::

:::evaluate
Провери отговорите
:::

:::note
Щракни върху пакет **Application Data**: полезните данни са само поредица от привидно случайни байтове. Tracer не може да ги дешифрира — той не познава сесийния ключ, също както и нападателят.
:::

:::tip Запомни
При **HTTP** всеки подслушвач може да прочете цялата уеб страница. При **HTTPS** той вижда само **кой с кого** комуникира (IP адреси, порт 443) и **колко** данни се обменят — съдържанието е скрито, шифровано в пакети **Application Data**.
:::

# Risoluzione dei problemi: la mail non arriva

:::sim
url=/sims/lesson-6.3.4.btsim
:::

Anna segnala: «Non riesco a mandare una mail a Ben!» Ecco come *dovrebbe* essere configurato:

| Cosa | Valore previsto |
|---|---|
| Server di posta in uscita di Anna (SMTP) | `mail.beaver-schule.de`, porta `25` |
| Record MX di `biber-mail.de` | `mail.biber-mail.de` (priorità 10) |

Trova gli errori e correggili. Poi fai inviare ad Anna una mail a `ben@biber-mail.de`: l'attività controlla se è arrivata nella casella di posta di Ben. (L'inoltro tra i mail server può richiedere qualche secondo.)

<details>
<summary>Suggerimento 1: che cosa dice il programma di posta di Anna?</summary>

Prova a inviare una mail e guarda nella scheda **Log**. Che cosa risponde il server? Sembra SMTP?
</details>

<details>
<summary>Suggerimento 2: la mail torna indietro come messaggio di errore?</summary>

Scarica la posta di Anna e leggi il messaggio del `MAILER-DAEMON`. Perché la consegna non è andata a buon fine? Usa `nslookup -type=MX biber-mail.de` sul PC di Anna per verificare se il server DNS conosce il mail server responsabile.
</details>

<details>
<summary>Suggerimento 3: dove si imposta?</summary>

Il server di posta in uscita lo imposti nell'app **E-mail** di Anna, sotto **Impostazioni**. I record MX li trovi nel **Server DNS**, nella scheda **MX**.
</details>

:::task
title: Mail arrivata?
Controlla se nella casella di posta di Ben sul Mailserver Biber c'è una mail.
check: fileExists(5, "/var/mail/ben.mbox")
:::

## Che cosa non andava?

:::quiz multi
Quali affermazioni sono corrette?
- [x] Il server di posta in uscita di Anna puntava alla porta 110: lì risponde il servizio POP3, non SMTP
- [x] Mancava il record MX per `biber-mail.de`: il Mailserver Schule non trovava nessun mail server responsabile
- [x] La mail non recapitabile è tornata indietro come messaggio di errore del `MAILER-DAEMON`
- [ ] La password di Ben era sbagliata
:::

:::evaluate
Controlla la risposta
:::

:::tip Punto chiave
Errori tipici con le e-mail: un **server o una porta** sbagliati nel programma di posta (SMTP usa la porta 25, POP3 la 110, IMAP la 143) e un **record MX** mancante o errato nel DNS. Se un mail server non riesce a recapitare una mail, la rimanda al mittente con un messaggio di errore (**bounce**).
:::

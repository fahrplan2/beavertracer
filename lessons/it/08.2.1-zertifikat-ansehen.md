# Visualizzare un certificato

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Nell'area di lavoro vedi il **Client-PC**, un **server DNS** e il web server della scuola, `www.beaver-schule.de`. Il web server offre le sue pagine anche tramite **HTTPS**.

## Il lucchetto nel browser

1. Passa alla modalità :fa-play: **Esegui**, fai clic sul **Client-PC** e apri il :fa-globe: **Browser**.
2. Apri `https://www.beaver-schule.de/`: fai attenzione all'**https**.
3. A sinistra dell'indirizzo compare un **lucchetto**. Fai clic su di esso.

:::quiz short
Per quale nome è stato emesso il certificato (soggetto senza `CN=`)?
= www.beaver-schule.de
:::

:::quiz short
Chi ha emesso il certificato (emittente senza `CN=`)?
= Biber Root CA
:::

:::evaluate
Verifica le risposte
:::

## Perché il Client-PC si fida del certificato?

Sul **Client-PC** apri la :fa-shield-halved: **Gestione certificati** e passa alla scheda **CA attendibili**.

:::quiz mc
Che cosa trovi lì?
- [x] Il certificato della **Biber Root CA**
- [ ] Il certificato di `www.beaver-schule.de`
- [ ] Nessuna voce
:::

:::quiz mc
Da che cosa si capisce che la Biber Root CA è una CA radice?
- [x] È **autofirmata**: soggetto ed emittente coincidono
- [ ] Il suo nome termina con „CA“
- [ ] Non ha una chiave pubblica
:::

:::quiz mc
Sul Client-PC, alla voce **Chiave privata** c'è scritto „Sì“ o „No“?
- [ ] Sì: il client ha bisogno della chiave privata della CA per verificare le firme
- [x] No: per la verifica basta la chiave pubblica; la chiave privata ce l'ha solo la CA
:::

:::evaluate
Verifica le risposte
:::

## L'altro lato: il web server

Ora apri sul web server **www.beaver-schule.de** la :fa-shield-halved: **Gestione certificati** (scheda **I miei certificati**) e osserva il suo certificato.

:::quiz multi
Che cosa è vero per il certificato sul web server?
- [x] Alla voce **Chiave privata** c'è scritto „Sì“: il server ne ha bisogno per l'instaurazione della connessione
- [x] La **catena** è `www.beaver-schule.de ← Biber Root CA`
- [x] L'**impronta digitale** è la stessa che compare nella finestra del lucchetto del browser
- [ ] È autofirmato
:::

:::evaluate
Verifica le risposte
:::

:::note
L'**impronta digitale** (fingerprint) è un valore hash calcolato sul certificato. Permette di confrontare rapidamente due certificati, senza dover controllare tutti i campi uno per uno.
:::

:::tip Punto chiave
Il **web server** possiede il proprio certificato **con la chiave privata**. Il **client** conosce solo il **certificato della CA radice** (senza chiave privata): questo gli basta per verificare la firma sul certificato del server. Facendo clic sul **lucchetto** nel browser si vedono soggetto, emittente, impronta digitale e validità.
:::

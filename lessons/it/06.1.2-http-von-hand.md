# HTTP a mano

:::sim
url=/sims/lesson-6.1.btsim
:::

Se HTTP è puro testo, puoi parlare direttamente con un web server, senza alcun browser? Sì: con `telnet` instauri una connessione TCP verso una porta qualsiasi e scrivi il testo tu stesso.

## L'esperimento

1. Passa alla modalità di esecuzione (:fa-play: **Esegui**) e sul **Client-PC** apri il :fa-terminal: **Terminale**.
2. Connettiti alla porta 80 del server:
   ```
   $ telnet 192.168.0.20 80
   ```
3. Scrivi la richiesta riga per riga e concludila con una **riga vuota** (basta premere ancora una volta **Invio**):
   ```
   GET /kontakt.html HTTP/1.1
   Host: 192.168.0.20

   ```

Il server risponde con la riga di stato, gli header e la pagina dei contatti. Tutto arriva come testo, esattamente come lo riceve anche il browser.

:::quiz mc
Da cosa capisce il server che la tua richiesta è terminata?
- [ ] Da un comando speciale `END`
- [x] Dalla riga vuota
- [ ] Dopo un certo tempo
:::

:::quiz short
Quale valore compare nella risposta nell'header `Content-Type`? (solo la prima parte prima del `;`)
= text/html
:::

## Provocare errori

Uno strumento più comodo è `curl`, che invia la richiesta al posto tuo. Con `-v` (*verbose*, dettagliato) mostra tutto ciò che viene scambiato: le righe con `>` le ha inviate `curl`, quelle con `<` sono arrivate dal server.

Prova:

```
$ curl -v http://192.168.0.20/gibtsnicht.html
$ curl -X POST -d name=Anna http://192.168.0.20/
```

:::quiz short
Quale codice di stato ricevi per `/gibtsnicht.html`?
= 404
:::

:::quiz short

= 405
:::

:::evaluate

:::

:::note
Il web server di BeaverTracer può solo fornire file, perciò consente soltanto `GET` e `HEAD`. I web server reali, ad esempio, ricevono moduli tramite `POST` e passano i dati a un programma.
:::

:::tip Punto chiave
Molti protocolli del livello di applicazione sono **basati su testo**: HTTP, ma anche SMTP, POP3 e IMAP. Per questo puoi usarli a mano con `telnet` e leggerli nel tracer. È utile per la risoluzione dei problemi, ma è anche un problema di sicurezza: chiunque intercetti il traffico può leggere tutto. Come la crittografia (HTTPS) ti aiuta lo imparerai nel capitolo 8.
:::

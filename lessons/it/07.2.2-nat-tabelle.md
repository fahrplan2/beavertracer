# La tabella NAT

:::sim
url=/sims/lesson-7.1.btsim
:::

Se il PC e il tablet caricano contemporaneamente la stessa pagina web, entrambe le richieste arrivano al server web da `203.0.113.2`. Come fa il router domestico a sapere a chi è destinata una risposta? Tiene un registro: la **tabella NAT**.

## L'esperimento

1. Passa alla modalità di esecuzione (:fa-play: **Esegui**) e apri `http://www.beispiel.de/` sia sul **PC** sia sul **Tablet**.
2. Clicca sul **Heimrouter** e apri la scheda **NAT**.

Ogni riga è un'**associazione**: protocollo, IP LAN e porta LAN del dispositivo nella rete domestica, più la **porta WAN** che il router usa per quella connessione sul suo indirizzo pubblico.

:::quiz short
Quale IP WAN è indicato sopra la tabella?
= 203.0.113.2
:::

:::quiz mc
Il PC e il tablet hanno entrambi instaurato una connessione con la porta LAN `49152`. Quale porta WAN ricevono?
- [ ] Entrambi la stessa, `49152`
- [x] Ognuno una porta diversa, altrimenti il router non saprebbe a chi appartiene la risposta
- [ ] Nessuna, il NAT cambia solo l'indirizzo IP
:::

:::quiz mc
Una risposta del server web arriva a `203.0.113.2` con una determinata **porta di destinazione**. Che cosa fa il router domestico?
- [x] Cerca la porta nella tabella NAT e inoltra il pacchetto all'IP LAN e alla porta LAN corrispondenti
- [ ] Invia il pacchetto a tutti i dispositivi della rete domestica
- [ ] Scarta il pacchetto
:::

:::evaluate
Controlla le risposte
:::

Qui tornano in gioco le **porte** del capitolo 5: poiché il NAT riscrive anche le porte, centinaia di connessioni possono condividere un unico indirizzo. A rigore, quindi, si parla di **PAT** (*Port Address Translation*) o di *NAT con traduzione delle porte*, ma nell'uso comune si dice semplicemente NAT.

Ecco come potrebbe apparire, per esempio, una traduzione di questo tipo:

| | Pacchetto dal PC (nella rete domestica) | lo stesso pacchetto su Internet |
|---|---|---|
| Mittente | `192.168.178.20 : 49152` | `203.0.113.2 : 10001` |
| Destinatario | `192.0.2.80 : 80` | `192.0.2.80 : 80` |

:::tip Punto chiave
Nella **tabella NAT** il router memorizza, per ogni connessione, quale dispositivo (**IP LAN e porta LAN**) si trova dietro quale **porta WAN**. Le risposte provenienti da Internet vengono ricondotte al dispositivo giusto tramite la porta di destinazione. Poiché vengono riscritte anche le porte, più precisamente si parla di **PAT**.
:::

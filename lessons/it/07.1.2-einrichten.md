# Configurare il router domestico

:::sim
url=/sims/lesson-7.1.2.btsim
:::

Un nuovo router domestico è appena stato collegato, ma per ora nessuno riesce ad accedere a Internet. Dal provider hai ricevuto una lettera con i **dati di accesso**:

| Dati di accesso | Valore |
|---|---|
| Indirizzo IP WAN | `203.0.113.2` |
| Lunghezza del prefisso | `/30` |
| Gateway (router del provider) | `203.0.113.1` |
| Server DNS del provider | `198.51.100.10` |

1. Passa alla Modalità di esecuzione (:fa-play: **Esegui**), fai clic sull'**Heimrouter** e apri la scheda **WAN**.
2. Inserisci i dati di accesso e fai clic su **Applica**.
3. Collega il **Tablet** al Wi-Fi: :fa-gear: **Impostazioni IP**, scheda **WiFi**, SSID `Biberbau`, **Applica**.
4. Fai una prova sul PC con `ping 192.0.2.80` oppure nel browser con `http://www.beispiel.de/`.

:::note
Nella pratica il router domestico riceve di solito il suo indirizzo WAN automaticamente dal provider (tramite DHCP oppure con un login con nome utente e password). Dati di accesso fissi come in questo caso sono più comuni nelle connessioni aziendali.
:::

# POP3 o IMAP?

:::sim
url=/sims/lesson-6.3.btsim
:::

Per ricevere la posta esistono due protocolli. In questa simulazione **Anna usa POP3** e **Ben usa IMAP**.

## L'esperimento

1. Nella modalità di esecuzione (:fa-play: **Esegui**), invia una mail da **Ben** a `anna@beaver-schule.de`.
2. Nell'app **E-mail** di **Anna**, clicca su **Scarica**.
3. Apri le tracce per **Anna** e per **Ben** e confronta i comandi usati per ricevere la posta.

:::quiz match
USER / PASS -> POP3: accesso con nome utente e password in due passaggi
RETR -> POP3: scaricare un messaggio
LOGIN -> IMAP: accesso con nome utente e password
SELECT INBOX -> IMAP: aprire una cartella sul server
:::

:::evaluate
Controlla gli abbinamenti
:::

## La differenza

| | POP3 | IMAP |
|---|---|---|
| Porta | 110 | 143 |
| Idea di base | Le mail vengono **scaricate** e poi di solito cancellate dal server | Le mail **restano sul server** e vengono gestite lì |
| Cartelle, letto/non letto | solo sul proprio dispositivo | sul server: uguali ovunque |
| Più dispositivi (smartphone, laptop) | poco pratico: ogni dispositivo ha uno stato diverso | ideale: tutti i dispositivi vedono la stessa casella di posta |

:::note
Il programma di posta di BeaverTracer lascia le mail sul server anche con POP3. I programmi reali spesso le cancellano dopo averle scaricate, oppure le lasciano sul server solo per un certo periodo.
:::

- [x] IMAP, perché tutti i dispositivi vedono la stessa casella di posta sul server

Controlla la risposta
:::

:::tip Punto chiave
**POP3** scarica le mail dal server su **un solo** dispositivo. **IMAP** gestisce la casella di posta **sul server**, con cartelle e stato di lettura uguali per tutti i dispositivi contemporaneamente. Entrambi servono solo per **ricevere** la posta; per l'invio si usa sempre **SMTP**.
:::

# Risoluzione dei problemi: il servizio non risponde

:::sim
url=/sims/lesson-5.3.2.btsim
:::

Dopo un aggiornamento, la scuola segnala: «Il servizio echo rifiuta ogni connessione e anche la pagina web non si carica più.» Secondo lo schema, il **server web** dovrebbe essere in ascolto sulla porta `80` e il **servizio echo** (Server Echo TCP) sulla porta `5000`. Trova gli errori e correggili.

<details>
<summary>Suggerimento 1: cosa risponde il server?</summary>

Prova a connetterti a `192.168.0.20`, porta `5000`, con il **Client TCP Semplice** e apri una traccia per il Client-PC. Con cosa risponde il server al tuo `[SYN]`?
</details>

<details>
<summary>Suggerimento 2: quali porte sono aperte?</summary>

Sul Client-PC, digita nel terminale `nmap -p 80,5000 192.168.0.20`. `nmap` prova le porte una dopo l'altra e mostra quali sono aperte. Con `ss` sul server vedi su quali porte c'è davvero un programma in ascolto.
</details>

<details>
<summary>Suggerimento 3: dove si imposta?</summary>

Sul **Server**, apri le app **Server Echo TCP** e **Server HTTP**. Il servizio è in esecuzione? E su quale porta?
</details>

:::task
title: Servizi raggiungibili?
Verifica se il Client-PC raggiunge il servizio echo sulla porta 5000 e il server web sulla porta 80. Per questo la simulazione deve essere in Modalità di esecuzione.
check: tcpOpen(1, 2, 5000)
check: tcpOpen(1, 2, 80)
:::

## Che cosa era successo?

:::quiz multi
Quali affermazioni sono corrette?
- [x] Al `[SYN]` sulla porta 5000 il server ha risposto con `[RST, ACK]`
- [x] Il servizio echo era in ascolto sulla porta 5050 invece che sulla porta 5000
- [x] Il server web non era nemmeno stato avviato
- [ ] Il cavo tra il Client-PC e il Server era difettoso
:::

:::evaluate
Controlla risposta
:::

:::tip Punto chiave
Se a un `SYN` si riceve in risposta un **`RST`**, su quella porta **nessun programma** è in ascolto: il computer è raggiungibile, ma il servizio no. Cause tipiche: il servizio **non è stato avviato** oppure è in ascolto su **un'altra porta**. Un controllo con `ss` sul server mostra quali porte sono davvero aperte.
:::

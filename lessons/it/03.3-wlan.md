# WLAN: una rete senza cavi

:::goal
**Obiettivo di apprendimento:** Sai spiegare come un access point collega una WLAN alla rete cablata, sai collegare un dispositivo alla WLAN tramite l'SSID e sai motivare perché una WLAN deve essere cifrata.
:::

Smartphone, tablet e portatili spesso non hanno più nemmeno una porta di rete: sono collegati via radio, tramite una **WLAN** (*Wireless LAN*, rete locale senza fili, comunemente chiamata Wi-Fi). Perché possano comunque comunicare con i PC e i server collegati via cavo, serve un dispositivo che colleghi la parte radio a quella cablata.

:::note
Nella realtà una WLAN dipende dalla portata, dai muri e dalle interferenze. BeaverTracer semplifica le cose: tutti i dispositivi con lo stesso nome WLAN condividono un'unica rete radio comune, indipendentemente da dove si trovino nell'area di lavoro.
:::

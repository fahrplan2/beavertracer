# Ottenere un indirizzo automaticamente

:::sim
url=/sims/lesson-6.4.btsim
:::

Allo switch sono collegati un **DHCP-Server** e due laptop. Per ora i laptop hanno ancora indirizzi fissi.

## L'esperimento

1. Passa alla modalità :fa-play: **Esegui**, clicca su **Laptop 1** e apri le :fa-gear: **Impostazioni IP**.
2. Cambia la **Modalità** da **Statico** a **DHCP** e clicca su **Applica**.
3. Aspetta qualche secondo: i campi si compilano da soli.
4. Nella modalità :fa-magnifying-glass: **Traccia** apri una traccia per **Laptop 1**.

:::quiz table
| Impostazione | ricevuta dal server DHCP |
|---|---|
| Indirizzo IP | {192.168.0.100} |
| Gateway | {192.168.0.1} |
| Server DNS | {192.168.0.53} |
:::

:::quiz short
Quanti pacchetti DHCP trovi nella traccia?
= 4
= quattro
:::

:::quiz mc
A quale indirizzo IP di destinazione invia Laptop 1 il suo primo pacchetto (`DHCP Discover`)?
- [ ] Al server DHCP `192.168.0.2`
- [x] A `255.255.255.255`: a tutti (broadcast)
- [ ] Al gateway `192.168.0.1`
:::

:::quiz mc
Quale indirizzo IP del mittente ha questo primo pacchetto, e perché?
- [x] `0.0.0.0`: il laptop non ha ancora nessun indirizzo
- [ ] `192.168.0.10`: il suo vecchio indirizzo
- [ ] `192.168.0.100`: il suo nuovo indirizzo
:::

:::evaluate
Controlla le risposte
:::

## Cosa c'è dietro: DORA

Un dispositivo senza indirizzo non sa dove si trova il server DHCP e non ha nemmeno un proprio indirizzo del mittente. Per questo chiama nella rete tramite **broadcast**. La procedura ha quattro passaggi, chiamati **DORA** dalle loro iniziali:

:::seq
mode: text
Laptop 1 -> DHCP-Server: DHCP Discover | «C'è un server DHCP qui?»
DHCP-Server -> Laptop 1: DHCP Offer | «Puoi avere 192.168.0.100.»
Laptop 1 -> DHCP-Server: DHCP Request | «Prendo 192.168.0.100.»
DHCP-Server -> Laptop 1: DHCP ACK | «Confermato: valido per 3600 secondi.»
:::

L'indirizzo è solo **in prestito** (*lease*): allo scadere del **tempo di lease** il dispositivo deve rinnovarlo, altrimenti il server può assegnarlo di nuovo. Quali indirizzi sono attualmente assegnati lo vedi nel **Server DHCP**, nella scheda **Leases**.

:::tip Provaci
Imposta anche **Laptop 2** su DHCP. Quale indirizzo riceve? Poi guarda i **Leases** del server DHCP.
:::

:::tip Punto chiave
**DHCP** distribuisce automaticamente indirizzo IP, maschera di rete, gateway e server DNS. La procedura si chiama **DORA**: **D**iscover (il client cerca tramite broadcast), **O**ffer (il server offre), **R**equest (il client accetta), **A**CK (il server conferma). L'indirizzo è in prestito per il **tempo di lease**. DHCP usa **UDP**, porta 67 (server) e 68 (client).
:::

:::quiz match
Discover -> Il client cerca un server DHCP tramite broadcast
Offer -> Il server offre un indirizzo
Request -> Il client richiede l'indirizzo offerto
ACK -> Il server conferma l'assegnazione
:::

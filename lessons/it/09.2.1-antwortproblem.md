# Il problema delle risposte

:::sim
url=/sims/lesson-9.2.btsim
:::

Ora il firewall lavora secondo il principio della whitelist: la policy predefinita è **Scarta tutto**. Un'unica regola permette alla rete scolastica di navigare: **B → A, TCP, porta di destinazione 80, Consenti**. La modalità è impostata su **Stateless**.

## L'esperimento

1. Passa alla :fa-play: **Modalità di esecuzione** e sul **Lehrer-PC** apri `http://203.0.113.80/` nel :fa-globe: **Browser**.
2. Nel **Firewall** osserva il **Log** e le **Corrispondenze**.

:::quiz mc
Che cosa succede nel browser?
- [ ] Compare la pagina di www.beispiel.de
- [x] La pagina non si carica, il browser resta in attesa e alla fine segnala un errore
:::

:::quiz mc
Quali pacchetti compaiono nel log del firewall come scartati (`DROP`)?
- [ ] Le richieste del Lehrer-PC verso la porta 80
- [x] Le risposte di `203.0.113.80` con **porta sorgente 80** verso il Lehrer-PC
- [ ] Nessuno
:::

:::quiz short
In quale direzione (A→B o B→A) viaggiano i pacchetti scartati?
= A→B
= A → B
= AtoB
:::

:::evaluate
Verifica le risposte
:::

La richiesta del Lehrer-PC può uscire, ma già il `SYN, ACK` del web server non torna indietro, perché per la direzione A → B non esiste nessuna regola corrispondente e quindi vale **Scarta tutto**.

## La soluzione ingenua

Si potrebbe aggiungere una seconda regola: **A → B, TCP, porta sorgente 80, Consenti**, cioè "tutto ciò che proviene dalla porta 80 può entrare". In effetti, così la navigazione funziona.

:::quiz mc
Perché questa regola è pericolosa?
- [ ] Perché i web server non usano mai la porta 80 come porta sorgente
- [x] Un attaccante può semplicemente inviare i suoi pacchetti con porta sorgente 80: il firewall li lascia allora passare verso **qualsiasi** porta della rete scolastica
- [ ] Perché poi le pagine web si caricano più lentamente
:::

:::evaluate
Verifica la risposta
:::

La porta sorgente la stabilisce il mittente stesso: un firewall non può farci affidamento. Un firewall stateless, però, non sa se un pacchetto è la **risposta a una richiesta** oppure un **nuovo tentativo di connessione** dall'esterno. È proprio questo che cambia con la modalità stateful.

:::tip Punto chiave
Un packet filter **stateless** controlla ogni pacchetto singolarmente. Le risposte richiedono quindi regole proprie per la direzione di ritorno, e regole di questo tipo (ad es. "la porta sorgente 80 può entrare") possono essere sfruttate dagli attaccanti, perché il mittente può scegliere liberamente la porta sorgente.
:::

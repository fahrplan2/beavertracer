# Osservare una risoluzione dei nomi

:::sim
url=/sims/lesson-6.2.btsim

## L'esperimento

1. Passa alla modalità :fa-play: **Esegui**, clicca sul **Client-PC** e apri il :fa-globe: **Browser**.
2. Questa volta apri `http://www.beaver-schule.de/`, usando un nome al posto dell'indirizzo IP.
3. Passa alla modalità :fa-magnifying-glass: **Traccia** e apri una traccia per il **Client-PC**.

All'inizio, ancora prima dell'instaurazione della connessione con `[SYN]`, ci sono due pacchetti con il protocollo **DNS**.

:::quiz short
A quale indirizzo IP il Client-PC invia la sua richiesta DNS?
= 192.168.0.53
:::

:::quiz short
Quale indirizzo IP compare nella risposta per `www.beaver-schule.de`?
= 192.168.0.20
:::

:::quiz mc
Clicca sulla richiesta DNS ed espandi l'albero dei protocolli. Quale protocollo di trasporto e quale porta di destinazione vengono usati?
- [ ] TCP, porta 80
- [x] UDP, porta 53
- [ ] UDP, porta 67
:::

:::evaluate
Controlla le risposte
:::

Solo dopo aver ottenuto l'indirizzo IP, il Client-PC instaura la connessione TCP con il web server, esattamente come nel capitolo 5.

:::seq
mode: text
Client-PC -> DNS-Resolver: Richiesta DNS | A www.beaver-schule.de?
DNS-Resolver -> Client-PC: Risposta DNS | A 192.168.0.20
:::

## Come fa il PC a conoscere il server DNS?

Sul **Client-PC** apri le :fa-gear: **Impostazioni IP**: nel campo **Server DNS** c'è `192.168.0.53`, cioè il computer **DNS-Resolver**. Il PC invia a lui ogni richiesta di risoluzione dei nomi.

Puoi anche interrogare direttamente il server DNS, senza browser. Apri il :fa-terminal: **Terminale** e digita:

```
$ nslookup www.beaver-schule.de
```

`nslookup` mostra prima quale server ha interrogato e poi la risposta. Per confronto, chiedi un nome che non esiste, ad es. `nslookup gibtsnicht.beaver-schule.de`.

:::quiz mc
Che cosa risponde il server DNS per il nome sconosciuto?
- [ ] Un indirizzo IP casuale
- [x] `NXDOMAIN`: questo nome non esiste
- [ ] Nulla
:::

:::evaluate
Controlla la risposta
:::

:::tip Punto chiave
Il **DNS** traduce i nomi (ad es. `www.beaver-schule.de`) in indirizzi IP. Prima di poter instaurare una connessione verso un nome, un PC interroga il **server DNS** indicato nelle sue impostazioni IP, di solito tramite **UDP, porta 53**. Con `nslookup` puoi inviare richieste DNS manualmente.
:::

Una pagina web è quindi spesso composta da molti file: testo, fogli di stile, immagini. Per ciascuno il browser invia una richiesta separata.

## Com'è fatta una richiesta

Nella traccia, clicca sul pacchetto `GET / HTTP/1.1` ed espandi **Hypertext Transfer Protocol**. Una richiesta HTTP è puro testo:

```
GET / HTTP/1.1              ← metodo, percorso, versione
Host: 192.168.0.20          ← header: informazioni aggiuntive
…
                            ← riga vuota: fine della richiesta
```

La risposta del server ha la stessa struttura: una riga di stato, gli header, una riga vuota e poi il file vero e proprio:

```
HTTP/1.1 200 OK             ← versione, codice di stato, testo
Content-Type: text/html     ← header: tipo di file
Content-Length: 301         ← header: dimensione in byte
                            ← riga vuota
<!doctype html> …           ← il file stesso
```

:::seq
mode: text
Client-PC -> Server: GET / | richiesta HTTP
Server -> Client-PC: 200 OK | index.html
Client-PC -> Server: GET /style.css | richiesta HTTP
Server -> Client-PC: 200 OK | style.css
:::

## Metodi e codici di stato

Il **metodo** indica che cosa vuole il client:

| Metodo | Significato |
|---|---|
| **GET** | scaricare un file |
| **POST** | inviare dati al server, ad es. un modulo compilato |
| **HEAD** | scaricare solo gli header, senza il file |

Il **codice di stato** indica com'è andata. La prima cifra rivela il tipo di risposta:

| Codice | Testo | Significato |
|---|---|---|
| **200** | OK | tutto a posto |
| **301** | Moved Permanently | la pagina è stata spostata in modo permanente |
| **404** | Not Found | il file non esiste |
| **405** | Method Not Allowed | questo metodo qui non è consentito |
| **500** | Internal Server Error | errore sul server |

`2xx` significa successo, `3xx` reindirizzamento, `4xx` un errore del client (richiesta errata), `5xx` un errore del server.

:::tip Punto chiave
**HTTP** funziona secondo il **principio richiesta-risposta**: il client invia una **richiesta** (un metodo come `GET`, il percorso, gli header), il server risponde con un **codice di stato** (ad es. `200 OK`, `404 Not Found`), gli header e il file. Per ogni file di una pagina web c'è una richiesta separata.
:::

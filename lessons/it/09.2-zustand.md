# Stateless o stateful

Una connessione ha sempre **due direzioni**: il PC dell'insegnante invia una richiesta a un server web su Internet e il server web rimanda indietro la pagina web. Un firewall basato sul principio della whitelist deve quindi lasciar passare non solo la richiesta, ma anche la **risposta**.

Per questo esistono due tipi di filtri di pacchetti:

| | **Senza stato** (*stateless*) | **Con stato** (*stateful*) |
|---|---|---|
| Funzionamento | controlla ogni pacchetto singolarmente, senza memoria | memorizza le connessioni consentite in una **tabella degli stati** |
| Risposte | richiedono una regola apposita per la direzione di ritorno | vengono lasciate passare automaticamente, perché appartengono a una connessione nota |
| Utilizzo | dispositivi semplici, filtri molto veloci | praticamente ogni firewall moderno |

Nelle prossime due sezioni scoprirai perché i filtri senza stato hanno problemi con le risposte e come un firewall con stato li risolve.

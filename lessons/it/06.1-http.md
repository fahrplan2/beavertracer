# HTTP: pagine web

:::goal
**Obiettivo di apprendimento:** Sai descrivere la struttura di una richiesta e di una risposta HTTP, spiegare i metodi e i codici di stato più importanti e inviare tu stesso una richiesta HTTP a mano.
:::

L'**Hypertext Transfer Protocol** (**HTTP**) è la lingua con cui browser e server web comunicano tra loro. Sul server si trova il sito web della **Beaver-Schule**: una pagina iniziale, una pagina dei contatti e un foglio di stile per l'aspetto grafico.

# Valori hash: l'impronta digitale dei dati

:::sim
url=/sims/lesson-8.1.3.btsim
:::

Una **funzione hash** calcola, a partire da una quantità qualsiasi di dati (una frase, un documento, un intero film), una breve stringa di caratteri di lunghezza fissa: il **valore hash**. Funziona come un'**impronta digitale**: dati uguali producono sempre lo stesso valore hash, dati diversi un valore diverso.

La funzione hash oggi più diffusa si chiama **SHA-256**. Il suo valore hash è sempre lungo 256 bit, cioè 64 caratteri in esadecimale.

## L'esperimento

Sul **PC**, nella cartella `/home`, ci sono tre file con un piccolo contratto di compravendita. Passa alla :fa-play: **Modalità di esecuzione**, apri il :fa-terminal: **Terminale** sul **PC** e digita:

```
$ cd /home
$ cat vertrag.txt vertrag-kopie.txt vertrag-neu.txt
$ sha256sum vertrag.txt vertrag-kopie.txt vertrag-neu.txt
```

## Proprietà di una funzione hash

| Proprietà | Significato |
|---|---|
| **lunghezza fissa** | Indipendentemente dalla dimensione dei dati, il valore hash ha sempre la stessa lunghezza. |
| **deterministica** | Dati uguali producono sempre lo stesso valore hash. |
| **effetto valanga** | Anche la minima modifica produce un valore hash completamente diverso. |
| **funzione unidirezionale** | Dal valore hash **non** è possibile risalire ai dati. |
| **resistente alle collisioni** | È praticamente impossibile trovare due file diversi con lo stesso valore hash. |

Una funzione hash **non è una cifratura**: non c'è nessuna chiave e nessuna decifratura. Serve a uno scopo diverso: l'**integrità**.

## A che cosa serve?

- **Verificare i download:** molti siti web indicano, accanto a un file, il suo valore SHA-256. Se il valore hash del file che hai scaricato coincide, significa che il file non è stato modificato durante il trasferimento.
- **Memorizzare le password:** i siti web ben fatti non memorizzano la tua password, ma solo un suo valore hash. Al login viene confrontato il valore hash di ciò che hai digitato. Se il database viene rubato, il ladro comunque non conosce le password.
- **Firme digitali:** invece di firmare un intero documento, se ne firma solo il valore hash; ne parleremo nella prossima sezione.

Anche la minima modifica produce un valore hash completamente diverso, e dal valore hash non è possibile risalire ai dati. I valori hash garantiscono l'**integrità** dei dati.

# HTTP e HTTPS a confronto

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Il server web **www.beaver-schule.de** offre il portale dei voti della scuola sia tramite HTTP sia tramite HTTPS. Che cosa vede chi sta intercettando il traffico?

## L'esperimento

1. Passa alla modalità :fa-play: **Esegui** e, sul **Client-PC**, apri nel :fa-globe: **Browser** prima `http://www.beaver-schule.de/` e poi `https://www.beaver-schule.de/`.
2. Nella modalità :fa-magnifying-glass: **Traccia** apri una traccia per il **Client-PC**.
3. Cerca prima il pacchetto `HTTP/1.1 200 OK` e cliccaci sopra. Nei dettagli in basso trovi il contenuto della pagina.

:::quiz mc
Che cosa può vedere chi intercetta il traffico con **HTTP**?
- [x] L'intera pagina web, compresi i voti di Anna
- [ ] Solo l'indirizzo del server
- [ ] Niente, perché HTTP funziona su TCP
:::

:::quiz short
Che voto ha Anna in matematica?
= 2
:::

:::evaluate
Controlla le risposte
:::

Ora la parte HTTPS. Cerca il pacchetto `[SYN]` con cui il client avvia la seconda connessione.

:::quiz short
Qual è la porta di destinazione della connessione HTTPS (colonna **Info**, `… → ???`)?
= 443
:::

Ora digita `tls` nel campo filtro in alto nella traccia: così vedrai solo i pacchetti TLS.

:::quiz mc
Che cosa compare nella colonna **Info** per i pacchetti che contengono la pagina web?
- [ ] `HTTP/1.1 200 OK`
- [x] `Application Data`
- [ ] `Encrypted HTML`
:::

:::quiz multi
Che cosa può comunque vedere chi intercetta il traffico con **HTTPS**?
- [x] Gli indirizzi IP del client e del server
- [x] Che viene usata la porta 443, quindi probabilmente HTTPS
- [x] Quanti dati vengono trasmessi, all'incirca
- [ ] Quale pagina è stata aperta e che cosa contiene
:::

:::evaluate
Controlla le risposte
:::

:::note
Clicca su un pacchetto **Application Data**: i dati utili sono solo una sequenza di byte apparentemente casuali. Il tracer non può decifrarli: non conosce la chiave di sessione, esattamente come un attaccante.
:::

:::tip Punto chiave
Con **HTTP** chiunque intercetti il traffico può leggere l'intera pagina web. Con **HTTPS** vede solo **chi comunica con chi** (indirizzi IP, porta 443) e **quanti dati** vengono scambiati: il contenuto viaggia cifrato nei pacchetti **Application Data**.
:::

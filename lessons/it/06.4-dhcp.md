# DHCP: in rete automaticamente

:::goal
**Obiettivo di apprendimento:** Sai spiegare come un dispositivo ottiene automaticamente le sue impostazioni IP tramite DHCP, configurare un server DHCP e riconoscere e risolvere i tipici errori DHCP (ad es. un indirizzo 169.254).
:::

:::sim
url=/sims/lesson-6.4.btsim
:::

Finora hai inserito a mano, per ogni dispositivo, l'indirizzo IP, la maschera di rete, il gateway e il server DNS. In una scuola con centinaia di laptop, tablet e smartphone sarebbe impossibile — e ogni errore di battitura diventerebbe un errore nella rete.

Questo lavoro lo svolge il **Dynamic Host Configuration Protocol** (**DHCP**): un **server DHCP** distribuisce automaticamente le impostazioni a ogni dispositivo che entra nella rete.

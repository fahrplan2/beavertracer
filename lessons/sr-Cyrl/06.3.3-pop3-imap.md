# POP3 или IMAP?

:::sim
url=/sims/lesson-6.3.btsim
:::

За преузимање поште постоје два протокола. У овој симулацији **Anna користи POP3**, а **Ben IMAP**.

## Експеримент

1. У :fa-play: **Покрени** режиму пошаљи поруку од **Ben** на `anna@beaver-schule.de`.
2. Код **Anna** у апликацији **E-Mail** кликни на **Преузми**.
3. Отвори трагове за **Anna** и за **Ben** и упореди команде при преузимању.

:::quiz match
USER / PASS -> POP3: пријављивање корисничким именом и лозинком у два корака
RETR -> POP3: преузимање једне поруке
LOGIN -> IMAP: пријављивање корисничким именом и лозинком
SELECT INBOX -> IMAP: отварање фолдера на серверу
:::

:::evaluate
Провери повезивање
:::

## Разлика

| | POP3 | IMAP |
|---|---|---|
| Port | 110 | 143 |
| Основна идеја | Поруке се **преузимају** — након тога се обично бришу са сервера | Поруке **остају на серверу** и тамо се њима управља |
| Фолдери, прочитано/непрочитано | само на сопственом уређају | на серверу — свуда исто |
| Више уређаја (телефон, лаптоп) | непрактично: сваки уређај има другачије стање | идеално: сви уређаји виде исто поштанско сандуче |

:::note
Програм за е-пошту у BeaverTracer-у оставља поруке на серверу и код POP3. Прави програми их након преузимања често бришу — или их остављају само извесно време.
:::

:::quiz mc
Lena чита своју пошту на телефону, таблету и школском лаптопу. Шта би требало да користи?
- [ ] POP3, јер је једноставнији
- [x] IMAP, јер сви уређаји виде исто поштанско сандуче на серверу
- [ ] SMTP, јер је намењен за преузимање
:::

:::evaluate
Провери одговор
:::

:::tip Запамти
**POP3** преузима поруке са сервера на **један** уређај. **IMAP** управља поштанским сандучетом **на серверу** — са фолдерима и статусом прочитаности за све уређаје истовремено. Оба служе само за **преузимање**; слање се увек обавља преко **SMTP**-а.
:::

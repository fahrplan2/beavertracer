# Веза од почетка до краја

:::sim
url=/sims/lesson-5.1.btsim
:::

На **Серверу** ехо сервис ради на порту `5000`: сваку поруку одмах враћа назад. Помоћу **Једноставног TCP клијента** можеш корак по корак да контролишеш везу — свако дугме је једна фаза.

## Експеримент

1. Пређи у :fa-play: режим **Покрени**, кликни на **Client-PC** и отвори **Једноставан TCP клијент**.
2. У поље **Host** упиши `192.168.0.20`, а у поље **Port** упиши `5000`.
3. Кликни на **Повежи се**.
4. Укуцај `Hello World` у поље за поруку и кликни на **Пошаљи**. У прозору за ћаскање одмах након тога видиш ехо сервера.
5. Кликни на **Прекини везу**.
6. Пређи у :fa-magnifying-glass: режим **Трага** и помоћу **+** отвори трасу за **Client-PC**, прикључак `eth0`.

:::note
Два ARP пакета на почетку већ познајеш из поглавља 1. У колони **Info** TCP пакета прво стоји `49152 → 5000` (са ког на који порт), затим у угластим заградама **флагови**, а после тога бројеви као што су `Seq=`, `Ack=` и `Len=`. О бројевима се говори од странице 5.2.3 — овде обраћаш пажњу на флагове и `Len`.
:::

## Фаза 1: Повезивање

:::quiz short
Колико је TCP пакета размењено након што си кликнуо/кликнула на **Повежи се** — пре него што је твоја порука послата?
= 3
= три
:::

:::quiz mc
Ко шаље први пакет са `[SYN]`?
- [x] Client-PC
- [ ] Сервер
:::

:::quiz mc
Којим флаговима сервер одговара на то?
- [ ] `[SYN]`
- [x] `[SYN, ACK]`
- [ ] `[ACK]`
- [ ] `[FIN, ACK]`
:::

## Фаза 2: Слање

`Len` показује колико бајтова корисних података носи један пакет.

:::quiz short
Колико бајтова носи пакет са твојом поруком (`Len`)?
= 13
:::

:::note
`Hello World` има само 11 знакова. TCP клијент међутим додаје крај реда (2 бајта, `\r\n`) — тако то очекују многи интернет протоколи као што су SMTP или HTTP.
:::

:::quiz mc
Шта сервер шаље назад одмах након твоје поруке — још пре еха?
- [x] Пакет са `[ACK]` и `Len=0` — потврду без података
- [ ] Ништа
- [ ] Нови `[SYN]`
:::

## Где се налазе та четири задатка?

Додели где у траси поново налазиш задатке из одељка 5.1:

:::quiz match
Успостављање везе -> Три пакета [SYN], [SYN, ACK] и [ACK]
Поуздан пренос -> Пакети са [ACK] и Len=0 који потврђују пријем
Раскидање везе -> Пакети са FIN и њихове потврде
Мултиплексирање -> Бројеви портова 49152 → 5000 испред угластих заграда
:::

:::evaluate
Провери повезивање
:::

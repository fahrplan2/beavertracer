# Преглед сертификата

:::sim
url=/sims/lesson-8.2.1.btsim
:::

На радној површини видиш **Client-PC**, **DNS-Server** и веб сервер школе, `www.beaver-schule.de`. Веб сервер своје странице нуди и преко **HTTPS**-а.

## Катанац у прегледачу

1. Пређи у :fa-play: **Ausführen**-режим, кликни на **Client-PC** и отвори :fa-globe: **Прегледач**.
2. Отвори `https://www.beaver-schule.de/` — обрати пажњу на **https**.
3. Лево од адресе појављује се **катанац**. Кликни на њега.

:::quiz short
За које име је издат сертификат (Субјекат без `CN=`)?
= www.beaver-schule.de
:::

:::quiz short
Ко је издао сертификат (Издавалац без `CN=`)?
= Biber Root CA
:::

:::evaluate
Провери одговоре
:::

## Зашто Client-PC верује сертификату?

На **Client-PC**-у отвори :fa-shield-halved: **Zertifikatverwaltung** и пређи на картицу **Vertrauenswürdige CAs**.

:::quiz mc
Шта тамо налазиш?
- [x] Сертификат **Biber Root CA**
- [ ] Сертификат за `www.beaver-schule.de`
- [ ] Нема уноса
:::

:::quiz mc
Како се види да је Biber Root CA коренски CA (Root-CA)?
- [x] **Самопотписан** је: субјекат и издавалац су исти
- [ ] Његово име се завршава на „CA“
- [ ] Нема јавни кључ
:::

:::quiz mc
Да ли код Client-PC-ја под **Privater Schlüssel** пише „Ja“ или „Nein“?
- [ ] Ја — клијенту је потребан приватни кључ CA-а да би проверавао потписе
- [x] Не — за проверу је довољан јавни кључ; приватни кључ има само CA
:::

:::evaluate
Провери одговоре
:::

## Друга страна: веб сервер

Сада на веб серверу **www.beaver-schule.de** отвори :fa-shield-halved: **Zertifikatverwaltung** (картица **Meine Zertifikate**) и погледај његов сертификат.

:::quiz multi
Шта важи за сертификат на веб серверу?
- [x] Под **Privater Schlüssel** пише „Ja“ — серверу је потребан за успостављање везе
- [x] **Ланац** гласи `www.beaver-schule.de ← Biber Root CA`
- [x] **Отисак прста** је исти као у прозору катанца у прегледачу
- [ ] Самопотписан је
:::

:::evaluate
Провери одговоре
:::

:::note
**Отисак прста** је хеш вредност израчуната над сертификатом. Помоћу ње се два сертификата могу брзо упоредити — без провере сваког поља појединачно.
:::

:::tip Запамти
**Веб сервер** поседује свој сертификат **са приватним кључем**. **Клијент** познаје само **сертификат коренског CA-а** (без приватног кључа) — то му је довољно да провери потпис на сертификату сервера. Када у прегледачу кликнеш на **катанац**, видиш субјекат, издаваоца, отисак прста и рок важења.
:::

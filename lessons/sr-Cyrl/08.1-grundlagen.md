# Основе криптографије

**Криптографија** је наука о шифровању. Пре него што почнемо, ево неколико појмова који се у овом поглављу стално појављују:

| Појам | Значење |
|---|---|
| **Отворени текст** | Читљива порука, нпр. `Treffen um 10 Uhr` |
| **Шифрат** | Шифрована порука, нпр. `Wuhiihq xp 10 Xku` |
| **Шифровање** | Отворени текст → шифрат |
| **Дешифровање** | Шифрат → отворени текст |
| **Поступак** (*алгоритам*) | Рачунско правило по којем се шифрује |
| **Кључ** | Тајна додатна информација коју поступак захтева |

## Поступак није тајан — кључ јесте

Могло би се помислити да је поступак то сигурнији што га мање људи познаје. Тачно је управо супротно: сви данас уобичајени поступци су **јавно** описани и стручњаци широм света их годинама проверавају тражећи слабе тачке. Тајан остаје само **кључ**.

Овај принцип је још 1883. поставио Холанђанин Огист Керкхофс (Auguste Kerckhoffs). Предност: ако се кључ открије, једноставно се замени кључ — а не цео поступак.

:::quiz mc
Шта мора да остане тајно код доброг поступка шифровања?
- [ ] Поступак
- [x] Кључ
- [ ] Једно и друго
:::

:::evaluate
Провери одговор
:::

У наредним одељцима упознаћеш четири градивна елемента од којих се граде сигурне везе:

1. **Симетрично шифровање** — брзо, али са проблемом кључа
2. **Асиметрично шифровање** — јавни и приватни кључ
3. **Хеш вредности** — отисак прста података
4. **Дигитални потписи** — електронски потписи

На крају ћеш видети како ови елементи раде заједно (**хибридно шифровање**).

У овој симулацији је неко већ унео три правила у заштитни зид (Firewall). Кликни на **Firewall** и погледај картицу **Regeln**. **Port A** заштитног зида је повезан са интернетом, **Port B** са школским рутером — „A → B“ дакле значи „са интернета у школску мрежу“.

:::quiz table
| Правило | Смер | Протокол | Циљни порт | Акција |
|---|---|---|---|---|
| 1 | A → B | {TCP} | {22} | {Одбацивање} |
| 2 | A → B | TCP | {110} | {Одбијање} |
| 3 | A → B | {ICMP} | било који | Одбацивање |
:::

## Ping споља

Пређи у :fa-play: **Режим извршавања** и пингуј школски сервер са **Internet-PC**-ја:

```
$ ping -c 2 198.51.100.10
```

Затим у заштитном зиду отвори картицу **Protokoll**.

- [ ] `Paket gefiltert`
- [ ] Два одговора од школског сервера
:::

## Скенирање портова: одбачено или одбијено?

Сада скенирај пет портова. Порт 3306 (база података) уопште није покренут на школском серверу.

```
$ nmap -p 22,25,80,110,3306 198.51.100.10
```

:::quiz match
22 (одбачен) -> filtered
25 (дозвољен, сервис ради) -> open
110 (одбијен) -> closed
3306 (дозвољен, нема сервиса) -> closed
:::

:::evaluate
Провери повезивање
:::

:::quiz multi
Шта нападач може закључити из резултата?
- [x] Код `filtered` зна: ту је заштитни зид који гута пакете
- [x] Код `closed` не може да разликује да ли заштитни зид одбија пакете или једноставно не ради ниједан сервис
- [ ] Код `filtered` зна који сервис ради иза порта
- [ ] Код `closed` је сервис ипак доступан
:::

:::evaluate
Провери одговоре
:::

На крају погледај колону **Treffer** у листи правила: ту заштитни зид броји колико је пакета свако правило већ одлучило. Вредност поред **Standardrichtlinie** броји све пакете на које није одговарало ниједно правило.

:::tip Запамти
**Одбачени** пакети нестају без трага: `ping` јавља истек времена, `nmap` јавља `filtered`. На **одбијене** пакете заштитни зид одговара одбијеницом (код TCP-а то је RST) — споља то изгледа као затворен порт. **Протокол** (лог) заштитног зида показује који је пакете зауставио, колона **Treffer** показује које је правило деловало.
:::

# Без стања или са праћењем стања

Веза се увек састоји од **два смера**: Лехрер-ПЦ (Lehrer-PC) шаље захтев веб серверу на интернету — а веб сервер враћа веб страницу. Firewall који ради по принципу беле листе, дакле, не мора да пропусти само захтев, већ и **одговор**.

За то постоје две врсте филтера пакета:

| | **Без стања** (*stateless*) | **Са праћењем стања** (*stateful*) |
|---|---|---|
| Начин рада | проверава сваки пакет појединачно, без памћења | памти дозвољене везе у **табели стања** |
| Одговори | захтевају посебно правило за повратни смер | пропуштају се аутоматски, јер припадају познатој вези |
| Употреба | једноставни уређаји, веома брзи филтри | практично сваки данашњи firewall |

У наредна два одељка ћеш искусити зашто филтри без стања имају проблема са одговорима — и како их firewall са праћењем стања решава.

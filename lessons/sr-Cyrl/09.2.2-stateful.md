# Стање-свесна заштитна баријера

:::sim
url=/sims/lesson-9.2.btsim
:::

**Стање-свесна** (*stateful*) заштитна баријера (firewall) памти сваку везу коју је једном дозволила у **табели стања**: протокол, обе адресе и оба порта. Ако стигне пакет који одговара неком уносу — свеједно у ком смеру —, пропушта га без даље провере. Нове везе, насупрот томе, морају проћи кроз правила.

## Посматрање

1. На **Firewall** уређају подеси **режим** на **Stateful**.
2. На **Lehrer-PC** у :fa-globe: **Прегледач** поново позови `http://203.0.113.80/`.
3. У Firewall уређају одмах отвори картицу **Zustände**.

:::quiz mc
Шта се сада дешава?
- [x] Страница се учитава, а у **Zustände** стоји веза од Lehrer-PC ка `203.0.113.80:80`
- [ ] Страница се не учитава, јер одговори и даље немају правило
:::

:::quiz short
Који порт стоји у табели стања код **циља**?
= 80
:::

:::evaluate
Провери одговоре
:::

Уноси у **Zustände** након неког времена поново нестају (колона **Timeout**), ако преко везе више ништа не пролази.

## Задатак: школска заштитна баријера

Подеси заштитну баријеру сада тако како је треба једној правој школи:

- **Из школске мреже** сме све на интернет (смер B → A, било који протокол).
- **Са интернета** су доступни само веб (80) и пријем поште (25) школског сервера.
- Све остало се **одбацује**, режим је **Stateful**.

:::task
title: Школска заштитна баријера подешена?
Проверава да ли школска мрежа долази до интернета, да ли су споља доступни само веб и пошта школског сервера и да ли је Lehrer-PC споља недоступан.
check: tcpOpen(8, "203.0.113.80", 80)
check: tcpOpen(1, "198.51.100.10", 80)
check: tcpOpen(1, "198.51.100.10", 25)
check: tcpFails(1, "198.51.100.10", 22)
check: pingFails(1, 8)
:::

:::quiz mc
Lehrer-PC шаље ping ка `203.0.113.80`. Да ли се одговори враћају?
- [x] Да — ping је дозвољен смером B → A, одговор припада овом стању
- [ ] Не — за ICMP споља не постоји правило
:::

:::evaluate
Провери одговор
:::

:::tip Запамти
**Стање-свесна заштитна баријера** уписује сваку дозвољену везу у **табелу стања** и пропушта све пакете те везе у **оба смера**. Тако су довољна правила за **успостављање везе**: „изнутра сме ка споља“ и „споља само ка одређеним услугама“. Везе започете споља ка школској мрежи остају блокиране.
:::

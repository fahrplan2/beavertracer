## Експеримент

1. Пребаци се у :fa-play: **Покрени** режим (Режим извршавања), кликни на **Client-PC** и отвори :fa-globe: **Прегледач**. Позови `http://192.168.0.20/`.
2. Кликни при врху прозора на **Назад**, отвори **Једноставан TCP клијент** и повежи га са `192.168.0.20`, порт `5000`. Остави везу отвореном.
3. Пребаци се у :fa-magnifying-glass: **Трага** режим, отвори траг за **Client-PC** и кликни на пакет са `[SYN]`. Рашири **Transmission Control Protocol**.

На самом врху TCP заглавља налазе се два порта: **Source Port** (изворишни порт) и **Destination Port** (одредишни порт).

:::quiz table
| Веза | Изворишни порт | Одредишни порт |
|---|---|---|
| Прегледач → веб сервер | {49152} | {80} |
| TCP клијент → Echo сервис | {49153} | {5000} |
:::

## Две врсте портова

**Одредишни порт — сервис:** Серверски програм чека на везе на фиксном порту — кажемо да на њему **слуша**. За познате сервисе бројеви су одређени широм света, то су **Well-known портови** (од 0 до 1023). Зато прегледач без питања зна: веб сервери слушају на порту 80.

**Изворишни порт — пошиљалац:** Порт на страни клијента оперативни систем сам бира за сваку нову везу из високог опсега (у BeaverTracer-у од 49152). По њему клијент препознаје којој од његових веза припада одговор.

Веза је, дакле, јединствено одређена са четири податка: **IP адреса и порт на обе стране**. Пар који чине IP адреса и порт назива се **сокет**, нпр. `192.168.0.20:80`.

## Поглед на сервер

Врати се у :fa-play: **Покрени** режим (Режим извршавања), отвори на **Server**-у :fa-terminal: **Терминал** и унеси:

```
$ ss
```

`ss` приказује све сокете рачунара. Редови са `LISTEN` су програми који слушају на неком порту. Редови са `ESTABLISHED` су постојеће везе — са сопственим сокетом (*Local Address:Port*) и сокетом друге стране (*Peer Address:Port*).

:::quiz multi
На којим портовима сервер слуша?
- [x] 80
- [x] 5000
- [ ] 49152
- [ ] 443
:::

:::quiz mc
Коју везу `ss` приказује као `ESTABLISHED`?
- [x] `192.168.0.20:5000` са `192.168.0.10:49153` — отворена веза TCP клијента
- [ ] `192.168.0.20:80` са `192.168.0.10:49152` — веза прегледача
- [ ] Обе
:::

Провери одговоре

:::note
Веза прегледача је већ раскинута — након учитавања странице завршена је помоћу `FIN`. `ss` је још кратко приказује као `TIME-WAIT`: сервер неко време чека да ли ће стићи закаснели пакети те везе. Веза TCP клијента је, насупрот томе, још отворена, јер јошниси кликнуо на **Прекини везу**.
:::

## Најважнији Well-known портови

| Порт | Протокол | Сервис |
|---|---|---|
| 22 | SSH | сигуран даљински приступ (шифрована командна линија) |
| 25 | SMTP | слање е-порука |
| 53 | DNS | претварање имена у IP адресе (углавном преко UDP-а) |
| 80 | HTTP | веб странице |
| 110 | POP3 | преузимање е-порука |
| 143 | IMAP | управљање е-порукама на серверу |
| 443 | HTTPS | шифроване веб странице |

:::tip Запамти
**Портови** (од 0 до 65535) држе везе на једном рачунару раздвојеним. Серверски сервиси **слушају** на фиксним **Well-known портовима** (нпр. HTTP 80, HTTPS 443), а клијенти за сваку везу добијају слободан високи **изворишни порт**. Веза је јединствено одређена **IP адресом и портом обе стране**.
:::

:::quiz match

443 -> HTTPS
:::

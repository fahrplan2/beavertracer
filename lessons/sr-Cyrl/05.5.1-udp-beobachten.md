# Посматрање UDP-а

:::sim
url=/sims/lesson-5.5.btsim
:::

На **Server**-у овај пут ради **UDP Ехо-Сервер** на порту `5000`. И овде је кабл припремљен: **други датаграм** од Client-PC-ја до сервера се губи.

## Експеримент

1. Пређи у :fa-play: **Покрени**-режим и на **Client-PC**-ју отвори :fa-terminal: **Терминал**.
2. Помоћу `nc` покрени UDP „везу“ ка серверу (`-u` означава UDP):
   ```
   $ nc -u 192.168.0.20 5000
   ```
3. Укуцај редом `eins`, `zwei` и `drei` и сваки пут притисни **Enter**. Свака линија која се врати је ехо сервера.
4. Сачекај неколико секунди, а затим у :fa-magnifying-glass: **Трага**-режиму отвори трасу за **Client-PC**.

:::quiz mc
Који ехо одговори се враћају?
- [ ] Сва три, `zwei` нешто касније
- [x] Само `eins` и `drei` — `zwei` недостаје и не шаље се поново
- [ ] Ниједан
:::

:::quiz multi
Који пакети које познајеш из TCP-а потпуно недостају код UDP-а?
- [x] Успостављање везе (`SYN`)
- [x] Потврде (`ACK`)
- [x] Раскидање везе (`FIN`)
- [ ] Пакети са бројевима портова
:::

:::evaluate
Провери одговоре
:::

Кликни на један од UDP пакета и отвори **User Datagram Protocol**. У поређењу са TCP заглављем, UDP заглавље је sasvim мало: **Source Port**, **Destination Port**, **Length** (дужина) и **Checksum** (контролни збир) — заједно само 8 бајтова. TCP заглавље има најмање 20 бајтова, са редним бројем секвенце и бројем потврде, заставицама и величином прозора.

- [ ] Успостављање везе
- [ ] Поуздан пренос
:::

:::evaluate
Провери одговор
:::

:::tip Запамти
**UDP** је **без успостављања везе**: нема успостављања, нема потврде, нема поновног слања, нема редоследа. Нуди само **портове** (мултиплексирање) и **контролни збир**. Зато је брз и једноставан — UDP заглавље има само 8 бајтова. Ако се датаграм изгуби, програм сам мора да се побрине за то — или му је свеједно.
:::

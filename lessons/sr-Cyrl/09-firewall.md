Beaver-школа има сопствене јавне адресе (`198.51.100.…`): њен **Schulserver** је директно доступан са интернета — без NAT-а, као што ће ускоро свуда бити са IPv6 (поглавље 7.3). Између интернета и **Schulrouter**-а налази се **фајервол**, који тренутно још увек пропушта све.

Лево видиш „интернет“: један **Internet-PC** и веб сервер `www.beispiel.de`. Десно је школска мрежа са **Schulserver**-ом и **Lehrer-PC**-ем.

## Шта види нападач?

Ко жели да нападне сервер, прво тражи **отворене портове** — дакле сервисе који чекају на везе. Алат за то зове се **скенер портова**; најпознатији је `nmap`.

Пређи у :fa-play: **Режим извршавања**, отвори на **Internet-PC**-у :fa-terminal: **Терминал** и унеси:

```
$ nmap 198.51.100.10
```

`nmap` покушава да успостави TCP везу са 20 најчешћих портова и јавља који су отворени.

:::quiz multi
Који су портови на школском серверу отворени са интернета?
- [x] 22 (SSH, даљинско одржавање)
- [x] 25 (SMTP)
- [x] 80 (HTTP)
- [x] 110 (POP3)
- [x] 143 (IMAP)
- [ ] 443 (HTTPS)
:::

:::evaluate
Провери одговор
:::

Веб-страница (80) и пријем е-порука (25) треба да буду доступни са интернета. Али **даљинско одржавање** (22) и преузимање порука (110, 143) треба само школској мрежи. Сваки отворени порт је могућа површина за напад: ако сервис има безбедносну рупу или слабу лозинку, нападач је може искористити са било ког места на свету — а аутоматски скенери на интернету управо то покушавају у сваком тренутку.

:::tip Запамти
**Фајервол** контролише саобраћај на граници између две мреже и пропушта само оно што је изричито дозвољено. Тако сервиси који су потребни само интерно остају невидљиви за интернет.
:::

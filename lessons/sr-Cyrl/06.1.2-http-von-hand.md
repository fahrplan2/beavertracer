# HTTP ручно

Ако је HTTP чист текст — може ли се онда и сам разговарати са веб сервером, потпуно без прегледача? Да: помоћу `telnet` успостављаш TCP везу са било којим портом и сам куцаш текст.

## Експеримент

1. Пређи у :fa-play: **Покрени** режим и на **Client-PC** отвори :fa-terminal: **Терминал**.
2. Повежи се са портом 80 сервера:
   ```
   $ telnet 192.168.0.20 80
   ```
3. Куцај захтев ред по ред — и заврши га **празним редом** (једноставно још једном притисни **Enter**):
   ```
   GET /kontakt.html HTTP/1.1
   Host: 192.168.0.20

   ```

Сервер одговара статусном линијом, заглављима и страницом са контактом — као текст, баш као што га добија и прегледач.

## Изазивање грешака

Практичнији алат је `curl`: он поставља захтев уместо тебе. Са `-v` (*verbose*, детаљно) приказује све што иде напред-назад — редове са `>` је послао `curl`, а редови са `<` стигли су са сервера.

Пробај:

```
$ curl -v http://192.168.0.20/gibtsnicht.html
$ curl -X POST -d name=Anna http://192.168.0.20/
```

:::note
Веб сервер у програму BeaverTracer може само да испоручује датотеке — зато дозвољава само `GET` и `HEAD`. Прави веб сервери помоћу `POST` примају, на пример, формуларе и прослеђују податке програму.
:::

:::tip Запамти
Многи протоколи апликативног слоја су **текстуални** — HTTP, али и SMTP, POP3 и IMAP. Зато се с њима може разговарати ручно помоћу `telnet` и пратити их у Трагачу. То је практично за тражење грешака — али и безбедносни проблем: свако ко снима саобраћај може све да прочита. Како шифровање (HTTPS) помаже, научићеш у 8. поглављу.
:::

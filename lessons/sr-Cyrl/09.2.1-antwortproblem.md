# Проблем са одговором

:::sim
url=/sims/lesson-9.2.btsim
:::

Firewall сада ради по принципу беле листе: подразумевана политика је **Alle verwerfen**. Једно једино правило дозвољава школској мрежи сурфовање: **B → A, TCP, одредишни порт 80, Zulassen**. Режим је подешен на **Stateless**.

## Експеримент

1. Пређи у :fa-play: **Покрени** режим и на **Lehrer-PC** у :fa-globe: **Прегледач** отвори `http://203.0.113.80/`.
2. На **Firewall** погледај **Protokoll** и **Treffer**.

:::quiz mc
Шта се дешава у прегледачу?
- [ ] Појављује се страница www.beispiel.de
- [x] Страница се не учитава, прегледач чека и на крају пријављује грешку
:::

:::quiz mc
Који пакети су у протоколу firewall-а наведени као одбачени (`DROP`)?
- [ ] Захтеви Lehrer-PC-ја на порт 80
- [x] Одговори са `203.0.113.80` са **изворишним портом 80** ка Lehrer-PC-ју
- [ ] Никакви
:::

:::quiz short
У ком смеру (A→B или B→A) иду одбачени пакети?
= A→B
= A → B
= AtoB
:::

:::evaluate
Провери одговоре
:::

Захтев Lehrer-PC-ја сме напоље — али већ `SYN, ACK` веб сервера не стиже назад, јер за смер A → B не постоји одговарајуће правило, па важи **Alle verwerfen**.

## Наивно решење

Могло би се унети друго правило: **A → B, TCP, изворишни порт 80, Zulassen** — „све што долази са порта 80 сме унутра“. Тада сурфовање заиста функционише.

:::quiz mc
Зашто је ово правило опасно?
- [ ] Зато што веб сервери никада не користе порт 80 као изворишни порт
- [x] Нападач може једноставно да пошаље своје пакете са изворишним портом 80 — тада их firewall пропушта на **сваки** порт у школској мрежи
- [ ] Зато што се тада веб странице спорије учитавају
:::

:::evaluate
Провери одговор
:::

Изворишни порт одређује сам пошиљалац — на њега firewall не сме да се ослања. Али firewall без стања не зна да ли је пакет **одговор на захтев** или **нови покушај успостављања везе** споља. Управо то мења режим са стањем.

:::tip Запамти
**Пакетски филтер без стања** проверава сваки пакет појединачно. Одговори тада захтевају посебна правила за повратни смер — а таква правила (нпр. „изворишни порт 80 сме унутра“) нападачи могу да искористе, јер пошиљалац може слободно да изабере изворишни порт.
:::

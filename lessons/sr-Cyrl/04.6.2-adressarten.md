# Најважније врсте адреса

Код IPv6 по почетку адресе можеш да препознаш чему служи:

| Врста адресе | препознаје се по | чему служи |
|---|---|---|
| **Link-Local** | `fe80::` | Важи само у **твојој локалној мрежи**. Сваки уређај сам себи аутоматски додељује ову адресу — рутер је никада не прослеђује. |
| **Global Unicast** | `2…` или `3…` (`2000::/3`) | Глобално јединствена адреса, доступна на интернету. Префикс добијаш од интернет провајдера. |
| **Unique Local** | `fd…` (`fc00::/7`) | За приватне мреже, упоредиво са `192.168.x.x` код IPv4. |
| **Loopback** | `::1` | Сопствени уређај — као `127.0.0.1` код IPv4. |
| **Multicast** | `ff…` | Ка **групи** уређаја, нпр. `ff02::1` = сви уређаји у локалној мрежи. |

:::note
За примере и наставни материјал резервисан је опсег `2001:db8::/32` — он се у правом интернету никада не појављује. Зато га видиш у овом курсу.
:::

Једна важна новина: **IPv6 више не познаје броадкаст.** Оно што је код IPv4 био броадкаст ка свима, IPv6 решава помоћу **multicast** адреса — порука иде само ка уређајима које та група занима.

:::tip Запамти
Сваки IPv6 уређај има најмање једну **Link-Local адресу** (`fe80::…`) за сопствену мрежу, а обично додатно и **глобалну адресу** за интернет. Уместо броадкаста IPv6 користи **multicast** (`ff…`).
:::

:::quiz match
fe80::a828:39ff:fee2:4182 -> Link-Local — само у сопственој мрежи
2001:db8:1::10 -> Global Unicast — глобално јединствена
::1 -> Loopback — сопствени уређај
ff02::1 -> Multicast — сви уређаји у локалној мрежи
fd12:3456::1 -> Unique Local — за приватне мреже
:::

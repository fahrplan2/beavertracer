Веб-страница, дакле, често се састоји од много датотека: текста, стилских датотека, слика. За сваку од њих прегледач шаље посебан захтев.

## Како изгледа захтев

Кликни у траси на пакет `GET / HTTP/1.1` и отвори **Hypertext Transfer Protocol**. HTTP захтев је чист текст:

```
GET / HTTP/1.1              ← Methode, Pfad, Version
Host: 192.168.0.20          ← Header: zusätzliche Angaben
…
                            ← Leerzeile: Ende der Anfrage
```

Одговор сервера има исту структуру — са статусном линијом, заглављима, празним редом и затим самом датотеком:

```
HTTP/1.1 200 OK             ← Version, Statuscode, Text
Content-Type: text/html     ← Header: Art der Datei
Content-Length: 301         ← Header: Größe in Byte
                            ← Leerzeile
<!doctype html> …           ← die Datei selbst
```

:::seq
mode: text
Client-PC -> Server: GET / | HTTP захтев
Server -> Client-PC: 200 OK | index.html
Client-PC -> Server: GET /style.css | HTTP захтев
Server -> Client-PC: 200 OK | style.css
:::

## Методе и статусни кодови

**Метода** говори шта клијент жели:

| Метода | Значење |
|---|---|
| **GET** | преузети датотеку |
| **POST** | послати податке серверу, нпр. попуњен формулар |
| **HEAD** | преузети само заглавља, без датотеке |

**Статусни код** говори како је протекло. Прва цифра одаје врсту одговора:

| Код | Текст | Значење |
|---|---|---|
| **200** | OK | све је у реду |
| **301** | Moved Permanently | страница је трајно премештена |
| **404** | Not Found | датотека не постоји |
| **405** | Method Not Allowed | ова метода овде није дозвољена |
| **500** | Internal Server Error | грешка на серверу |

`2xx` значи успех, `3xx` преусмеравање, `4xx` грешку клијента (погрешан захтев), `5xx` грешку сервера.

:::tip Запамти
**HTTP** ради по **принципу захтев–одговор**: клијент шаље **захтев** (методу попут `GET`, путању, заглавља), а сервер одговара **статусним кодом** (нпр. `200 OK`, `404 Not Found`), заглављима и датотеком. За сваку датотеку једне веб-странице постоји посебан захтев.
:::

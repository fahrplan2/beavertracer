# HTTP и HTTPS у поређењу

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Веб сервер **www.beaver-schule.de** нуди школски портал са оценама и преко HTTP-а и преко HTTPS-а. Шта види неко ко прислушкује?

## Експеримент

1. Пређи у :fa-play: **Покрени** режим и на **Client-PC** у :fa-globe: **Прегледач** прво отвори `http://www.beaver-schule.de/`, а затим `https://www.beaver-schule.de/`.
2. У :fa-magnifying-glass: **Трага** режиму отвори трагање (trace) за **Client-PC**.
3. Прво потражи пакет `HTTP/1.1 200 OK` и кликни на њега. Доле у детаљима налази се садржај странице.

:::quiz mc
Шта може да види неко ко прислушкује код **HTTP**-а?
- [x] Комплетну веб страницу, па и Анине оцене
- [ ] Само адресу сервера
- [ ] Ништа, јер HTTP ради преко TCP-а
:::

:::quiz short
Коју оцену има Анна из математике?
= 2
:::

:::evaluate
Провери одговоре
:::

Сада следи HTTPS део. Потражи `[SYN]` пакет којим клијент започиње другу везу.

:::quiz short
Који одредишни порт има HTTPS веза (колона **Info**, `… → ???`)?
= 443
:::

Сада у горње поље за филтер у трагању унеси `tls` — тада ћеш видети само TLS пакете.

:::quiz mc
Шта пише у колони **Info** код пакета који садрже веб страницу?
- [ ] `HTTP/1.1 200 OK`
- [x] `Application Data`
- [ ] `Encrypted HTML`
:::

:::quiz multi
Шта неко ко прислушкује ипак може да види код **HTTPS**-а?
- [x] IP адресе клијента и сервера
- [x] Да се користи порт 443, дакле вероватно HTTPS
- [x] Приближно колико се података преноси
- [ ] Која је страница позвана и шта пише на њој
:::

:::evaluate
Провери одговоре
:::

:::note
Кликни на **Application Data** пакет: корисни подаци су само низ наизглед насумичних бајтова. Tracer их не може дешифровати — кључ сесије познаје једнако мало као и нападач.
:::

:::tip Запамти
Код **HTTP**-а сваки прислушкивач може прочитати комплетну веб страницу. Код **HTTPS**-а он види само **ко с ким** комуницира (IP адресе, порт 443) и **колико** — садржај је шифрован унутар **Application Data** пакета.
:::

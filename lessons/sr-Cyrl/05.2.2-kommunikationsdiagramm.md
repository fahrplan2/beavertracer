# Дијаграм комуникације

:::sim
url=/sims/lesson-5.1.btsim
:::

Ток једне везе црта се као **дијаграм комуникације**: клијент и сервер добијају по једну усправну линију, а време тече одозго надоле. Свака стрелица је један пакет. Нацртана је искошено, јер је сваки пакет неко време на путу.

Овако изгледа твоја веза са претходне странице — упореди је ред по ред са трагом:

:::seq
Client-PC -> Server: SYN
Server -> Client-PC: SYN, ACK
Client-PC -> Server: ACK
Client-PC -> Server: PSH, ACK "Hello World" len=13
Server -> Client-PC: ACK
Server -> Client-PC: PSH, ACK len=13
Client-PC -> Server: ACK
Client-PC -> Server: FIN, ACK
Server -> Client-PC: ACK
Server -> Client-PC: FIN, ACK
Client-PC -> Server: ACK
:::

Изнад сваке стрелице налазе се **заставице** (flags), испод њих бројеви `SEQ` и `ACK`. **DATA** означава пакете са корисним подацима. Црвени бројеви припадају клијенту, а плави серверу — шта они значе, објашњава следећа страница.

## Заставице

| Заставица | значи | Значење |
|---|---|---|
| **SYN** | *synchronize* | успоставити везу, одредити почетни број |
| **ACK** | *acknowledge* | потврђује примљене податке |
| **PSH** | *push* | одмах проследити податке програму |
| **FIN** | *finish* | „Завршио сам“ — раскинути везу |
| **RST** | *reset* | прекинути или одбити везу (више о томе у 5.3.2) |

## Три фазе

**Успостављање:** клијент шаље `SYN`, сервер одговара са `SYN, ACK`, а клијент потврђује са `ACK`. Пошто су потребна тачно три пакета, то се зове **тространо руковање** (three-way handshake).

**Подаци:** сваки пакет са подацима прималац потврђује са `ACK`. Овде сервер шаље ехо назад — и то клијент потврђује.

**Раскидање:** свака страна појединачно завршава свој смер слања: `FIN` од клијента, `ACK` од сервера — затим `FIN` од сервера, `ACK` од клијента. То су четири пакета.

:::tip Запамти
TCP веза се одвија у три фазе: **успостављање** путем **тространог руковања** (`SYN` → `SYN, ACK` → `ACK`), **пренос података** (сваки пакет са подацима потврђује се са `ACK`) и **раскидање** (свака страна шаље `FIN` и добија `ACK`).
:::

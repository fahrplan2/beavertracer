# NAT табела

:::sim
url=/sims/lesson-7.1.btsim
:::

Када рачунар и таблет истовремено учитају исту веб-страницу, оба захтева стижу до веб сервера са адресе `203.0.113.2`. Како Кућни рутер зна коме је намењен одговор? Он води евиденцију — у **NAT табели**.

## Експеримент

1. Пређи у :fa-play: **Режим извршавања** и на **PC** и на **Tablet** позови `http://www.beispiel.de/`.
2. Кликни на **Heimrouter** и отвори картицу **NAT**.

Сваки ред је једно **придруживање**: протокол, LAN IP и LAN порт уређаја у Кућној мрежи — и **WAN порт** који рутер за њега користи на својој јавној адреси.

:::quiz short
Која WAN IP адреса стоји изнад табеле?
= 203.0.113.2
:::

:::quiz mc
PC и таблет су оба успоставили везу са LAN портом `49152`. Који WAN порт добијају?
- [ ] Оба исти, `49152`
- [x] Сваки другачији — иначе рутер не би знао коме одговор припада
- [ ] Никакав, NAT мења само IP адресу
:::

:::quiz mc
Одговор веб сервера стиже на `203.0.113.2` са одређеним **одредишним портом**. Шта Кућни рутер ради са њим?
- [x] Тражи порт у NAT табели и шаље пакет одговарајућој LAN IP адреси и LAN порту
- [ ] Шаље пакет свим уређајима у Кућној мрежи
- [ ] Одбацује пакет
:::

:::evaluate
Провери одговоре
:::

Овде се **портови** из 5. поглавља поново појављују: пошто NAT преписује и портове, стотине веза може делити једну адресу. Строго узев, то се зато зове **PAT** (*Port Address Translation*) или *NAT са превођењем портова* — у свакодневном говору ипак се једноставно каже NAT.

Овако би, на пример, могло изгледати једно такво превођење:

| | Пакет са PC-ја (у Кућној мрежи) | исти пакет на интернету |
|---|---|---|
| Пошиљалац | `192.168.178.20 : 49152` | `203.0.113.2 : 10001` |
| Прималац | `192.0.2.80 : 80` | `192.0.2.80 : 80` |

:::tip Запамти
У **NAT табели** рутер за сваку везу памти који уређај (**LAN IP и LAN порт**) стоји иза ког **WAN порта**. Одговоре са интернета поново придружује исправном уређају преко одредишног порта. Пошто се преписују и портови, прецизније се говори о **PAT**-у.
:::

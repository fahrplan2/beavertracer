# Примена модела

Придружи протоколе из експеримента са почетка поглавља њиховом OSI слоју:

:::quiz match
Ethernet -> Слој 2 — Веза података
IPv4 -> Слој 3 — Мрежа
TCP -> Слој 4 — Транспорт
HTTP -> Слој 7 — Апликација
:::

:::evaluate
Провери придруживање
:::

И на крају, називи јединица података:

:::quiz match
Frame -> Слој 2 — Веза података
Пакет -> Слој 3 — Мрежа
Сегмент -> Слој 4 — Транспорт
:::

:::evaluate
Провери придруживање
:::

Тиме имаш потребан алат да убудуће исправно разврставаш протоколе. Од следећег поглавља пролазимо кроз слојеве редом — почев од слоја 2 и питања како switch уопште зна kуда мора да проследи пакет.

# Тражење грешака: име не функционише

:::sim
url=/sims/lesson-6.2.3.btsim
:::

Једна наставница јавља: „`www.beaver-schule.de` се код мене не учитава. Али са `http://192.168.0.20` ради!“ Овако *треба* да буде подешено:

| Шта | Требало би |
|---|---|
| DNS сервер на Client-PC | `192.168.0.53` (DNS-Resolver) |
| Унос у Schul-DNS | `www.beaver-schule.de` → `192.168.0.20` |

Пронађи грешке и отклони их.

<details>
<summary>Савет 1: Шта каже nslookup?</summary>

Унеси на Client-PC `nslookup www.beaver-schule.de`. Који сервер је `nslookup` питао — и шта је стигло назад? (Одговор траје неколико секунди.)
</details>

<details>
<summary>Савет 2: А сада?</summary>

Ако добијеш одговор, упореди адресу са планом. Где је то име унето?
</details>

:::task
title: Да ли је резолуција имена поправљена?
Проверава да ли Client-PC разрешава www.beaver-schule.de на праву адресу. Симулација за то мора да ради у режиму извршавања.
check: resolves(2, "www.beaver-schule.de", "192.168.0.20")
:::

## Шта се догодило?

:::quiz multi
Које тврдње су тачне?
- [x] На Client-PC је као DNS сервер био уписан `192.168.0.35` — тамо нико не одговара
- [x] У Schul-DNS је `www.beaver-schule.de` показивао на `192.168.0.21` уместо на `192.168.0.20`
- [ ] Веб сервер је био искључен
- [ ] Root сервер није познавао домен `.de`
:::

:::evaluate
Провери одговор
:::

:::tip Запамти
Ако веза ради са **IP адресом**, али не и са **именом**, проблем је у **DNS-у**. Прво провери **уписани DNS сервер** (да ли уопште одговара?), а затим сам **унос** (да ли је адреса исправна?). `nslookup` показује обоје: који сервер је питан и шта је одговорио.
:::

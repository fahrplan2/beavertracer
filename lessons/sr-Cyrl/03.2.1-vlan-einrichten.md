# Један свич, две мреже

:::sim
url=/sims/lesson-3.2.1.btsim
:::

На свич су повезана четири рачунара: **Sekretariat** (порт 1) и **Schulleitung** (порт 2) из администрације, као и **Anna** (порт 3) и **Ben** (порт 4) из рачунарске учионице. Сви се налазе у истој мрежи `192.168.0.0/24`.

## Проблем

Пребаци се у :fa-play: **Покрени** режим, на рачунару **Anna** отвори :fa-terminal: **Терминал** и пингуј Sekretariat:

```
$ ping 192.168.0.10
```

Anna без проблема допире до рачунара Sekretariat. Управо то желимо да спречимо.

## Подешавање VLAN-ова

**VLAN** (*Virtual LAN*) је посебна, одвојена мрежа унутар једног свича. Сваки VLAN има број, такозвани **VLAN ID**. Одређујемо: администрација иде у **VLAN 10**, а рачунарска учионица у **VLAN 20**.

1. У Режиму извршавања кликни на **свич** и отвори картицу **VLAN**.
2. Означи опцију **омогући VLAN**. Појављује се табела са по једним редом за сваки порт.
3. У колону **PVID** унеси VLAN ID — за **port 1** и **port 2** по `10`, а за **port 3** и **port 4** по `20`. **Режим** остави на `untagged`.
4. Кликни доле на **Примени**.

:::note
**PVID** је скраћеница од *Port VLAN ID*: све што стигне на овај порт припада овом VLAN-у. Режим `untagged` значи да је на овај порт повезан сасвим обичан рачунар који не мора ништа да зна о VLAN-овима.
:::

## Тестирање

Са рачунара **Anna** још једном пингуј Sekretariat — а затим и рачунар Ben (`ping 192.168.0.21`).

:::quiz mc
Шта се сада дешава?
- [ ] Anna допире до рачунара Sekretariat и до рачунара Ben
- [x] Anna допире до рачунара Ben, али више не допире до рачунара Sekretariat
- [ ] Anna више не допире ни до кога
:::

:::evaluate
Провери одговор
:::

У :fa-magnifying-glass: **Трага** режиму отвори трагање за рачунар **Sekretariat**: Annini ARP упити („Who has 192.168.0.10?“) се тамо уопште не појављују. Њен броадкаст остаје у VLAN-у 20 — за свич су то сада две одвојене мреже које ништа не знају једна о другој.

:::tip Запамти
Помоћу **VLAN-ова** један свич се дели на више логички раздвојених мрежа. Уређаји у различитим VLAN-овима не могу директно да допру један до другог — чак ни броадкаст саобраћај не излази из сопственог VLAN-а. Сваки VLAN има број, такозвани **VLAN ID**.
:::

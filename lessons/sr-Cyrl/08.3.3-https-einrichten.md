# Подешавање HTTPS-а

:::sim
url=/sims/lesson-8.3.3.btsim
:::

Овде настављамо тамо где је стао одељак 8.2.2: на веб серверу **www.beaver-schule.de** налазе се **Schul-CA** и серверски сертификат који је она издала, а **Client-PC** верује Schul-CA. Само што веб сервер још не говори HTTPS.

## Пре

Пребаци се у :fa-play: **Покрени** режим и на **Client-PC** у :fa-globe: **Прегледач** отвори `https://www.beaver-schule.de/`.

:::quiz mc
Шта се дешава?
- [x] Веза се не успоставља — ниједан сервис не слуша на порту 443
- [ ] Прегледач упозорава на небезбедан сертификат
- [ ] Страница се приказује без катанца
:::

:::evaluate
Провери одговор
:::

## Укључивање HTTPS-а

1. На веб серверу отвори **HTTP сервер** и кликни на **Заустави** — док сервер ради, подешавања се не могу мењати.
2. Пређи на картицу **HTTPS**:
    - Означи **Омогући HTTPS**, **HTTPS порт** `443`
    - Код **Сертификат** изабери серверски сертификат `www.beaver-schule.de` — не Schul-CA!
    - Кликни на **Користи**
3. Кликни на **Почни**.

Поново отвори страницу на Client-PC-ју преко `https://`. Кликни на катанац и провери издаваоца и важење.

:::task
title: HTTPS је подешен?
Проверава да ли Client-PC може да преузме https://www.beaver-schule.de/ без упозорења о сертификату. Симулација за то мора да ради у режиму извршавања.
check: httpsOk(2, "https://www.beaver-schule.de/")
:::

:::quiz mc
Зашто у HTTP серверу не смеш да изабереш сертификат **Schul-CA**?
- [ ] Зато што CA сертификати не могу да шифрују
- [x] Зато што је издат за име `Schul-CA`, а не за `www.beaver-schule.de` — прегледач би упозорио
- [ ] Зато што Schul-CA нема приватни кључ
:::

:::quiz mc
Шта би видео уређај који **не** верује Schul-CA, на пример телефон госта?
- [ ] Страницу сасвим нормално, са катанцем
- [x] Упозорење о сертификату, јер не може да прати ланац поверења до познате CA
- [ ] Ништа, јер се веза одбија
:::

:::evaluate
Провери одговоре
:::

:::note
За јавне веб странице потребан је сертификат од CA која је унапред инсталирана у свим прегледачима. Од 2015. постоји **Let's Encrypt**, CA која такве сертификате издаје бесплатно и аутоматски — један од главних разлога због којих данас скоро све веб странице користе HTTPS.
:::

:::tip Запамти
За **HTTPS** веб серверу је потребан **серверски сертификат са приватним кључем** чије име одговара адреси, и мора да слуша на **порту 443**. Клијент верује страници само ако познаје **CA** која је издала сертификат.
:::

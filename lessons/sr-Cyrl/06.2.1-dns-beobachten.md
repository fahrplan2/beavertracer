# Посматрање разрешавања имена

:::sim
url=/sims/lesson-6.2.btsim
:::

## Експеримент

1. Пређи у :fa-play: **Покрени** режим, кликни на **Client-PC** и отвори :fa-globe: **Прегледач**.
2. Овога пута позови `http://www.beaver-schule.de/` — са именом уместо IP адресе.
3. Пређи у :fa-magnifying-glass: **Трага** режим и отвори трагање за **Client-PC**.

Сасвим на почетку — још пре успостављања везе помоћу `[SYN]` — налазе се два пакета са протоколом **DNS**.

:::quiz short
На коју IP адресу Client-PC шаље свој DNS упит?
= 192.168.0.53
:::

:::quiz short
Која се IP адреса налази у одговору за `www.beaver-schule.de`?
= 192.168.0.20
:::

:::quiz mc
Кликни на DNS упит и отвори стабло протокола. Који транспортни протокол и који одредишни порт се користе?
- [ ] TCP, порт 80
- [x] UDP, порт 53
- [ ] UDP, порт 67
:::

:::evaluate
Провери одговоре
:::

Тек пошто Client-PC сазна IP адресу, успоставља TCP везу са веб сервером — баш као у поглављу 5.

:::seq
mode: text
Client-PC -> DNS-Resolver: DNS-Anfrage | A www.beaver-schule.de?
DNS-Resolver -> Client-PC: DNS-Antwort | A 192.168.0.20
:::

## Одакле РС зна DNS сервер?

Отвори на **Client-PC** :fa-gear: **IP подешавања**: у пољу **DNS-Server** стоји `192.168.0.53` — рачунар **DNS-Resolver**. Њему РС шаље сваки упит за име.

DNS сервер можеш да питаш и директно, без прегледача. Отвори :fa-terminal: **Терминал** и унеси:

```
$ nslookup www.beaver-schule.de
```

`nslookup` прво показује који сервер је питао, а затим одговор. За поређење питај за име које не постоји, нпр. `nslookup gibtsnicht.beaver-schule.de`.

:::quiz mc
Шта DNS сервер одговара на непознато име?
- [ ] Насумичну IP адресу
- [x] `NXDOMAIN` — то име не постоји
- [ ] Ништа
:::

:::evaluate
Провери одговор
:::

:::tip Запамти
**DNS** преводи имена (нпр. `www.beaver-schule.de`) у IP адресе. Пре него што РС може да успостави везу са именом, пита **DNS сервер** који је уписан у његовим IP подешавањима — најчешће преко **UDP, порт 53**. Помоћу `nslookup` можеш ручно да постављаш DNS упите.
:::

# Позивање и посматрање веб-странице

За овај део ништа не градиш сам: на радној површини налази се припремљена симулација са једним **Client-PC** и једним **Webserver**.

## Позивање странице

1. Пређи у :fa-play: **Режим извршавања**.
2. На **Client-PC** отвори апликацију :fa-globe: **Прегледач** и позови адресу веб-сервера: `http://192.168.0.20/`.
3. Пређи у :fa-magnifying-glass: режим **Трага** и помоћу **+** отвори трасу за **Client-PC**, прикључак `eth0` — потпуно исто као код пинга.

:::note
За један једини позив странице то је изненађујуће много пакета — знатно више него код пинга. Преузимање веб-странице је вишестепени процес, а не једна појединачна радња.
:::

## Читање листе пакета

Још не мораш да знаш шта тачно раде поједини протоколи. Све што ти је потребно за следећа питања налази се у колонама **Protokoll** и **Info**.

:::quiz mc
Који протокол је сасвим на врху листе?
- [x] ARP
- [ ] TCP
- [ ] HTTP
:::

:::quiz short
Изброј: колико **TCP** пакета стоји испред првог **HTTP** пакета?
= 3
= три
:::

:::quiz mc
Шта веб-сервер одговара на захтев прегледача? Погледај колону Info другог HTTP пакета.
- [ ] GET / HTTP/1.1
- [x] HTTP/1.1 200 OK
- [ ] 404 Not Found
:::

:::evaluate
Провери одговоре
:::

## Именовање учесничких протокола

На основу својих запажања сада можеш да закључиш који је протокол за шта био задужен.

:::tip Савет
Још једном прочитај колоне **Info**: `Who has …?`, `[SYN]`, `[SYN, ACK]`, `[ACK]`, `GET /` и `200 OK` откривају готово све.
:::

:::quiz match
ARP -> Пита све у мрежи: „Ко има IP адресу 192.168.0.20?“
TCP -> Пре него што подаци потекну, успоставља везу помоћу три кратка пакета
HTTP -> Захтева веб-страницу (GET) и враћа је (200 OK)
:::

:::evaluate
Провери повезивање
:::

:::tip Запамти
Позив веб-странице одвија се у корацима: прво **пронаћи** сервер у мрежи (ARP), затим **успоставити** везу (TCP), затим **затражити и испоручити** страницу (HTTP) — и на крају поново **раскинути** везу (TCP пакети са `[FIN]` при крају листе).
:::

:::note
Овога пута си IP адресу сервера унео директно, па **DNS** („превођење“ имена попут `www.beispiel.de` у IP адресу) још није дошао до изражаја. То ћемо надокнадити у поглављу 6.
:::

Да ли си приметио да протоколи у структури пакета имају обојене ознаке са бројевима? Шта то значи, објаснићемо у поглављу 2. Тамо ћемо погледати како се многи протоколи систематски разврставају — помоћу OSI и TCP/IP референтног модела. Тиме је поглавље 1 завршено.

# DNS: имена уместо бројева

:::goal
**Циљ учења:** Можеш да објасниш како DNS преводи имена у IP адресе и како су имена хијерархијски организована, да сам направиш унос и да пронађеш типичне DNS грешке.
:::

:::sim
url=/sims/lesson-6.2.btsim
:::

IP адресе једва да ико може да запамти — а имена као што је `www.beaver-schule.de` могу. Превођење обавља **Domain Name System** (**DNS**), нека врста светског телефонског именика интернета.

На радној површини се сада налази нешто већа мрежа: поред **Client-PC** и **Webserver** постоје и четири **DNS сервера**. Зашто их је толико, видећеш за две странице.

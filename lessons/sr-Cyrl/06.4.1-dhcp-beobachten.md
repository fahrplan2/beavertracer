# Аутоматско добијање адресе

:::sim
url=/sims/lesson-6.4.btsim
:::

На свич су прикључени један **DHCP сервер** и два лаптопа. Лаптопови још увек имају фиксне адресе.

## Експеримент

1. Пређи у :fa-play: режим **Покрени**, кликни на **Laptop 1** и отвори :fa-gear: **IP подешавања**.
2. Промени **Режим** са **Статички** на **DHCP** и кликни на **Примени**.
3. Сачекај неколико секунди: поља се попуњавају сама.
4. У режиму :fa-magnifying-glass: **Трага** отвори траг за **Laptop 1**.

:::quiz table
| Подешавање | добијено од DHCP сервера |
|---|---|
| IP адреса | {192.168.0.100} |
| Gateway | {192.168.0.1} |
| DNS сервер | {192.168.0.53} |
:::

:::quiz short
Колико DHCP пакета налазиш у трагу?
= 4
= четири
:::

:::quiz mc
На коју одредишну IP адресу Laptop 1 шаље свој први пакет (`DHCP Discover`)?
- [ ] На DHCP сервер `192.168.0.2`
- [x] На `255.255.255.255` — свима (броадкаст)
- [ ] На gateway `192.168.0.1`
:::

:::quiz mc
Коју IP адресу пошиљаоца има овај први пакет — и зашто?
- [x] `0.0.0.0` — лаптоп још уопште нема адресу
- [ ] `192.168.0.10` — његову стару адресу
- [ ] `192.168.0.100` — његову нову адресу
:::

Провери одговоре

## Шта стоји иза тога: DORA

Уређај без адресе не зна где се налази DHCP сервер, а нема ни сопствену адресу пошиљаоца. Зато зове у мрежу путем **броадкаста**. Поступак има четири корака — по почетним словима назван **DORA**:

:::seq
mode: text
Laptop 1 -> DHCP-Server: DHCP Discover | „Постоји ли овде DHCP сервер?“
DHCP-Server -> Laptop 1: DHCP Offer | „Можеш добити 192.168.0.100.“
Laptop 1 -> DHCP-Server: DHCP Request | „Узимам 192.168.0.100.“
DHCP-Server -> Laptop 1: DHCP ACK | „Потврђено — важи 3600 секунди.“
:::

Адреса је само **позајмљена** (*Lease*): по истеку **времена закупа** (*lease time*) уређај мора да је продужи, иначе сервер сме поново да је додели. Које су адресе тренутно издате, видиш у **DHCP серверу** на картици **Leases**.

:::tip Пробај сам
Подеси и **Laptop 2** на DHCP. Коју адресу добија? Затим погледај **Leases** на DHCP серверу.
:::

:::tip Запамти
**DHCP** аутоматски додељује IP адресу, мрежну маску, gateway и DNS сервер. Поступак се зове **DORA**: **D**iscover (клијент тражи путем броадкаста), **O**ffer (сервер нуди), **R**equest (клијент прихвата), **A**CK (сервер потврђује). Адреса је позајмљена на време закупа (**lease time**). DHCP користи **UDP**, порт 67 (сервер) и 68 (клијент).
:::

:::quiz match
Discover -> Клијент путем броадкаста тражи DHCP сервер
Offer -> Сервер нуди адресу
Request -> Клијент захтева понуђену адресу
ACK -> Сервер потврђује доделу
:::

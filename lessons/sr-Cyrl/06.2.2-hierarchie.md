# Како је DNS организован

:::sim
url=/sims/lesson-6.2.btsim
:::

Ниједан појединачни сервер не може да зна сва имена на свету. Зато је DNS изграђен **хијерархијски** — баш као и сама имена. Читају се здесна налево:

```
www . beaver-schule . de . (Root)
 │          │         │      └─ Root-Server: kennen die Server aller Top-Level-Domains
 │          │         └─ Top-Level-Domain (TLD): der de-Server kennt alle .de-Domains
 │          └─ Domain: der Schul-DNS ist für beaver-schule.de zuständig
 └─ Rechnername innerhalb der Domain
```

Сервер који је надлежан за неки домен и заиста зна одговор назива се **ауторитативан**. Пут до њега за рачунар преузима **резолвер** — овде је то рачунар **DNS-Resolver**.

## Експеримент

1. Пређи у :fa-play: **Покрени** режим и на рачунару **Client-PC** у :fa-terminal: **Терминал** унеси:
   ```
   $ nslookup www.beaver-schule.de
   ```
2. У режиму :fa-magnifying-glass: **Трага** отвори траг за **DNS-Resolver**.

Резолвер је за тебе поставио читав низ упита. Повежи ко је дао који одговор:

:::quiz match
Root-Server (192.168.0.101) -> Упућивање: За .de је надлежан ns.nic.de
de-Server (192.168.0.102) -> Упућивање: За beaver-schule.de је надлежан ns.beaver-schule.de
Schul-DNS (192.168.0.103) -> Одговор: www.beaver-schule.de има адресу 192.168.0.20
:::

:::quiz mc
Кога резолвер пита први?
- [x] Root сервер
- [ ] Schul-DNS
- [ ] Client-PC
:::

:::evaluate
Провери одговоре
:::

:::note
Између осталог, резолвер пита и за адресе сервера на које је био упућен (`A ns.nic.de`). Прави DNS сервери те адресе обично одмах шаљу уз одговор. Осим тога, резолвери памте сваки одговор неко време (**кеш**) — на следећи упит за исто име одговарају одмах сами. Колико дуго, пише у запису као **TTL** (*Time to Live*) у секундама.
:::

## Најважнији типови записа

| Тип | Значење | Пример |
|---|---|---|
| **A** | име → IPv4 адреса | `www.beaver-schule.de` → `192.168.0.20` |
| **AAAA** | име → IPv6 адреса | `www.beaver-schule.de` → `2001:db8::20` |
| **CNAME** | име → друго име (алијас) | `web.beaver-schule.de` → `www.beaver-schule.de` |
| **MX** | надлежни мејл сервер неког домена | `beaver-schule.de` → `mail.beaver-schule.de` |
| **NS** | надлежни DNS сервер неког домена | `beaver-schule.de` → `ns.beaver-schule.de` |

:::tip Запамти
DNS је **хијерархијски**: **Root сервери** упућују на сервере **домена највишег нивоа** (нпр. `.de`), а ови на сервере појединачних **домена**. Надлежни **ауторитативни** сервер зна одговор. **Резолвер** пролази тај пут за рачунар и памти одговоре (**кеш**). Важни типови записа: **A**, **AAAA**, **CNAME**, **MX**, **NS**.
:::

## Креирање записа

Школа жели да њена веб-страница буде доступна и на адреси `intranet.beaver-schule.de`.

1. У режиму :fa-play: **Покрени** кликни на **Schul-DNS** и отвори апликацију **DNS-Server**.
2. Отвори картицу **A**. Кликни на **+** и у нови ред упиши име `intranet.beaver-schule.de` и адресу `192.168.0.20`.
3. Тестирај на рачунару Client-PC командом `nslookup intranet.beaver-schule.de`.

:::task
title: Ново име је уписано?
Провери да ли Client-PC разрешава име intranet.beaver-schule.de у адресу веб сервера. Симулација при томе мора да ради у режиму извршавања.
check: resolves(2, "intranet.beaver-schule.de", "192.168.0.20")
:::

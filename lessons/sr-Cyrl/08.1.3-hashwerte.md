# Хеш вредности: отисак прста података

:::sim
url=/sims/lesson-8.1.3.btsim
:::

**Хеш функција** израчунава из произвољно велике количине података — једне реченице, документа, читавог филма — кратак низ знакова фиксне дужине: **хеш вредност**. Она функционише као **отисак прста**: исти подаци увек дају исту хеш вредност, а другачији подаци другачију.

Данас уобичајена хеш функција зове се **SHA-256**. Њена хеш вредност је увек дугачка 256 бита, односно 64 знака када се запише као хексадецимални број.

## Експеримент

На **PC**-у се у фолдеру `/home` налазе три датотеке са малим купопродајним уговором. Пређи у :fa-play: **Покрени** режим, на **PC**-у отвори :fa-terminal: **Терминал** и унеси:

```
$ cd /home
$ cat vertrag.txt vertrag-kopie.txt vertrag-neu.txt
$ sha256sum vertrag.txt vertrag-kopie.txt vertrag-neu.txt
```

## Особине хеш функције

| Особина | Значење |
|---|---|
| **фиксна дужина** | Без обзира колики су подаци — хеш вредност увек има исту дужину. |
| **једнозначност** | Исти подаци увек дају исту хеш вредност. |
| **лавински ефекат** | Већ и најмања промена даје потпуно другачију хеш вредност. |
| **једносмерна функција** | Из хеш вредности се подаци **не могу** израчунати уназад. |
| **отпорност на колизије** | Практично је немогуће пронаћи две различите датотеке са истом хеш вредношћу. |

Хеш функција **није шифровање**: не постоји кључ и нема дешифровања. Она служи другој сврси — **интегритету**.

## Чему то служи?

- **Провера преузетих датотека:** Многе веб-странице поред датотеке наводе и њену SHA-256 вредност. Ако се хеш вредност твоје преузете датотеке поклапа са њом, датотека није измењена на путу.
- **Чување лозинки:** Добре веб-странице не чувају твоју лозинку, већ само њену хеш вредност. Приликом пријављивања упоређује се хеш вредност онога што си унео. Ако се база података украде, лопов ипак не зна лозинке.
- **Дигитални потписи:** Уместо читавог документа потписује се само његова хеш вредност — више о томе у наредном одељку.

:::tip Запамти
**Хеш функција** (нпр. **SHA-256**) израчунава из произвољних података **хеш вредност** фиксне дужине — **отисак прста**. Већ и најмања промена даје потпуно другачију хеш вредност, а из хеш вредности се подаци не могу израчунати уназад. Хеш вредности обезбеђују **интегритет** података.
:::

# Ко добија који пакет?

:::sim
url=/sims/lesson-3.1.2.btsim
:::

Сада су Ана, Бен и Клара повезани на свич (прикључци 1, 2 и 3). Када Ана пошаље пакет Бену: да ли га добија само Бен — или и Клара?

Размисли накратко шта претпостављаш. Затим то испробај.

## Експеримент

1. Пређи у :fa-play: **Режим извршавања**, отвори :fa-terminal: **Терминал** на рачунару **Anna** и пингуј Бена:
   ```
   $ ping 192.168.0.11
   ```
2. Пређи у :fa-magnifying-glass: режим **Трага** и помоћу **+** отвори праћење (trace) за **Clara**, прикључак `eth0`.
3. Помоћу **+** отвори други trace за **Ben**, прикључак `eth0`. Горе можеш да се пребацујеш између та два traca.

:::quiz short
Колико је пакета стигло до рачунара **Clara**?
= 1
= један
= један
= jedan
:::

:::quiz mc
Који је то пакет био?
- [x] ARP захтев „Who has 192.168.0.11?“ упућен свима (броадкаст)
- [ ] Ping (Echo Request) од Ане
- [ ] ARP одговор од Бена
:::

:::quiz mc
А шта је стигло до рачунара **Ben**?
- [ ] Само ARP захтев
- [ ] Само pingови
- [x] ARP захтев и сви pingови
:::

## Шта је иза тога

ARP захтев има као одредиште **броадкаст** — упућен је *свима*. Зато га је свич проследио на сваки прикључак, па и Клари. Pingови су, насупрот томе, били адресирани само на Бена. Њих је свич послао искључиво на Бенов прикључак — Клара није ништа приметила.

:::tip Запамти
**Броадкаст** је упућен свим уређајима у локалној мрежи — свич га distribuira на све портове. **Јуникаст** је упућен тачно једном уређају — свич га шаље само на порт на који је тај уређај повезан.
:::

## Поглед у свич

Али како свич зна на који је порт повезан Бен? Врати се у :fa-play: **Режим извршавања** и кликни на **Switch**. На картици **SAT** видиш његову табелу адреса са две колоне: **MAC** и **Port**.

:::quiz mc
Који се уређаји налазе у табели адреса?
- [ ] Ана, Бен и Клара
- [x] Само Ана и Бен
- [ ] Само Бен
:::

:::quiz short
На који је порт повезан Бен према табели? Савет: Бенову MAC адресу налазиш у Tracer-у у његовом ARP одговору `192.168.0.11 is at …`.
= 2
= порт 2
= port 2
:::

:::quiz mc
Зашто Клара недостаје у табели?
- [ ] Њен кабл је покварен
- [x] Још није послала ниједан пакет
- [ ] Свич памти највише два уноса
:::

:::evaluate
Провери одговоре
:::

Свич **учи** узгред: код сваког фрејма који стигне до њега гледа **изворну** MAC адресу пошиљаоца и памти на који је порт тај уређај повезан. Када је стигао Анин ARP захтев, забележио је „Anna → порт 1“, а код Бенова одговора „Ben → порт 2“. Клара није ништа послала — зато је свич још не познаје.

:::tip Запамти
Свич у својој **табели адреса** (**SAT**, *Source Address Table*) памти под којом је MAC адресом који уређај доступан на ком порту — то учи из адреса пошиљаоца. Ако зна одредиште фрејма, шаље га само на тај порт. Ако га не зна (или је у питању броадкаст), шаље га на све портове.
:::

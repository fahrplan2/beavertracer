# ISO/OSI референтни модел

ISO/OSI модел дели комуникацију између два уређаја на седам слојева. Сваки слој има јасно одређен задатак и користи само услуге слоја који се налази директно испод њега:

Из експеримента на претходној страници већ познајеш четири од ових слојева: Ethernet (2), IPv4 (3), TCP (4) и HTTP (7). Управо ове бројеве и боје Трејсер приказује у стаблу протокола.

:::tip Помоћ за памћење
Од слоја 7 наниже: **А**на **П**ије **С**ок **Т**ек **М**ало **В**ише **Ф**лаше — **А**пликација, **П**резентација, **С**есија, **Т**ранспорт, **М**режа, **В**еза података, **Ф**изички.
:::

:::note Гранични случајеви
Није сваки протокол тачно у једном слоју. Зато Трејсер код ових протокола приказује више слојева:

- **ARP** — слој 2/3: нема IP заглавље, али повезује IP адресе (слој 3) са хардверским адресама (слој 2).
- **TLS** — слој 4/5: налази се директно изнад TCP-а и управља заштићеном сесијом.
- **HTTPS** (HTTP унутар TLS-а) — слојеви 5–7: класичан апликативни слој TCP/IP модела, који ћеш упознати на следећој страници.
:::

:::note
Слој 1 описује стваран пренос сигнала кабловима или радио-путем. BeaverTracer не симулира овај ниво — каблови се увек сматрају исправно повезаним, нема ни проблема са сигналом ни колизија. Зато у Трејсеру посматрање практично почиње од слоја 2.
:::

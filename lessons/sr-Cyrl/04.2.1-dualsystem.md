# Бинарни систем

Рачунар у својој суштини познаје само два стања: струја укључена или струја искључена. За то пишемо **1** и **0**. Једно такво место зове се **бит**. И свака IP адреса је за рачунар само низ нула и јединица — да би разумео/ла како функционишу мрежне маске, на овој страници учиш да читаш такве бројеве и сам/а их претвараш.

## Како обично бројимо: декадни систем

У свакодневном животу рачунамо са десет цифара (од 0 до 9). Свако место вреди десет пута више од места десно од њега: јединице, десетице, стотине, хиљаде. Број `305` дакле значи:

| Позициона вредност | 100 | 10 | 1 |
|---|---|---|---|
| Цифра | 3 | 0 | 5 |
| Вредност | 300 | 0 | 5 |

300 + 0 + 5 = **305**

## Бинарни систем

У **бинарном систему** (који се назива и *двојни систем*) постоје само две цифре: 0 и 1. Свако место вреди **дупло** више од места десно од њега: 1, 2, 4, 8, 16, 32, 64, 128 …

Бинарни број `00001101` дакле значи:

| Позициона вредност | 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1 |
|---|---|---|---|---|---|---|---|---|
| Бит | 0 | 0 | 0 | 0 | 1 | 1 | 0 | 1 |
| Вредност | | | | | 8 | 4 | | 1 |

8 + 4 + 1 = **13**

Дакле, једноставно сабереш позicione вредности на којима стоји јединица.

:::tip Запамти
**Бит** је једно место у бинарном систему (0 или 1). **8 бита** чини један **бајт** — у мрежној техници такав пакетић од 8 бита зове се и **октет**. Позиционе вредности једног октета су **128, 64, 32, 16, 8, 4, 2, 1**.
:::

## Из декадног у бинарни систем

Обрнуто, пролазиш кроз позиционе вредности слева надесно и сваки пут се питаш: **Да ли позициона вредност још стаје у мој (преостали) број?** Ако стаје, пишеш 1 и одузимаш позициону вредност. Ако не стаје, пишеш 0.

Пример: `168`

| Позициона вредност | стаје у …? | Бит | Остатак |
|---|---|---|---|
| 128 | 168 → да | **1** | 40 |
| 64 | 40 → не | **0** | 40 |
| 32 | 40 → да | **1** | 8 |
| 16 | 8 → не | **0** | 8 |
| 8 | 8 → да | **1** | 0 |
| 4 | 0 → не | **0** | 0 |
| 2 | 0 → не | **0** | 0 |
| 1 | 0 → не | **0** | 0 |

Читано одозго надоле: 168 = **10101000**

:::tip Савет
Ове вредности ће ти се стално појављивати код мрежних маски — вреди их знати: `10000000` = 128, `11000000` = 192, `11100000` = 224, `11110000` = 240, `11111000` = 248, `11111100` = 252, `11111110` = 254, `11111111` = 255.
:::

## IP адресе у бинарном систему

IPv4 адреса се састоји од **32 бита**, дакле од четири октета. Пошто нико не може да запамти 32 нуле и јединице, сваки октет се пише као декадни број, а бројеви се раздвајају тачкама:

```
11000000 . 10101000 . 10110010 . 00000001
   192   .   168    .   178    .    1
```

:::quiz short
Од колико бита се састоји једна IPv4 адреса?
= 32
:::

:::quiz mc
Колико теоријски постоји различитих IPv4 адреса?
- [ ] 256 × 4 = 1024
- [x] 2³² — око 4,3 милијарде
- [ ] Више него довољно — за сваког човека на Земљи по неколико
:::

:::evaluate
Провери одговоре
:::

:::note
Око 4,3 милијарде звучи као много — али то је мање од једне адресе по човеку на Земљи. Зато је IPv4 већ дуго оскудан. Како се с тим поступа, научићеш касније код NAT-а и IPv6.
:::

# Уношење статичких рута

:::sim
url=/sims/lesson-4.5.2.btsim
:::

Овога пута се између фирме A и фирме B налазе **два** рутера. Они су повезани преко сопствене мале мреже, **прелазне мреже** `10.0.0.0/30`:

| Рутер | Интерфејс | IP адреса | Мрежа |
|---|---|---|---|
| Router A | `eth0` | `192.168.0.1/24` | Фирма A (Anna) |
| Router A | `eth1` | `10.0.0.1/30` | Прелазна мрежа |
| Router B | `eth0` | `10.0.0.2/30` | Прелазна мрежа |
| Router B | `eth1` | `172.16.0.1/24` | Фирма B (Clara) |

:::note
`/30` мрежа има тачно две употребљиве адресе — идеално за повезивање два рутера (види одељак 4.2.3).
:::

## Проблем

Пређи у :fa-play: **Режим извршавања** и пингуј Clara са рачунара **Anna** (`ping 172.16.0.10`). Clara не одговара — уместо тога се јавља Router A (`192.168.0.1`) са поруком „Циљна мрежа није доступна“.

Погледај **Табела рутирања IPv4** на уређају **Router A**.

:::quiz mc
Зашто Аннин пинг не стиже до Clara?
- [ ] Anna нема унет мрежни пролаз (gateway)
- [x] Router A не познаје мрежу `172.16.0.0/24` — она није директно повезана на њега и не постоји рута до ње
- [ ] Прелазна мрежа је премала
:::

:::evaluate
Провери одговор
:::

## Уношење руте

Router A мора да научи: пакети за `172.16.0.0/24` иду ка Router B (`10.0.0.2`), и то преко `eth1`.

1. На уређају **Router A** отвори картицу **Табела рутирања IPv4** и кликни на **+ hinzufügen**.
2. У нови ред унеси: **Ziel** `172.16.0.0`, **Netzmaske** `255.255.255.0`, **Следећи чвор** `10.0.0.2`, **Iface** `eth1`.
3. Сачувај ред кукицом :fa-check:. У колони **Quelle** сада пише **Статички**.

Поново пингуј Clara — сада стиже одговор.

:::note
Router B иначе већ познаје пут назад до фирме A: у његовој табели рутирања већ постоји статичка рута за `192.168.0.0/24` преко `10.0.0.1`. Зашто је овај пут назад подједнако важан, видећеш на следећој страници.
:::

## Праћење пута: traceroute

Помоћу `traceroute` можеш да прикажеш преко којих рутера пакет пролази. Унеси на уређају **Anna**:

```
$ traceroute 172.16.0.10
```

:::quiz short
Преко колико рутера пакет иде од Anna до Clara?
= 2
= два
:::

:::quiz mc
Коју адресу `traceroute` приказује за Router B?
- [x] `10.0.0.2` — његова адреса у прелазној мрежи, преко које пакет улази
- [ ] `172.16.0.1` — његова адреса у фирми B
- [ ] `192.168.0.1`
:::

:::evaluate
Провери одговоре
:::

`traceroute` користи трик са **Time to Live** из одељка 4.3.1: прво шаље пакет са TTL 1. Први рутер одузима 1, добија 0, одбацује пакет и јавља то назад пошиљаоцу — тако Anna сазнаје први рутер. Затим следи TTL 2 за други рутер, и тако даље, све док одредиште не одговори.

:::tip Запамти
**Статичку руту** администратор уноси ручно: одредишну мрежу, мрежну маску, следећи чвор и интерфејс. Помоћу **traceroute** може се пратити пут пакета рутер по рутер.
:::

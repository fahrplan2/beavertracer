# Eine Adresse automatisch beziehen

:::sim
url=/sims/lesson-6.4.btsim
:::

Am Switch hängen ein **DHCP-Server** und zwei Laptops. Noch haben die Laptops feste Adressen.

## Das Experiment

1. Wechsle in den :fa-play: **Ausführen**-Modus, klicke auf **Laptop 1** und öffne die :fa-gear: **IP-Einstellungen**.
2. Stelle den **Modus** von **Statisch** auf **DHCP** und klicke auf **Anwenden**.
3. Warte ein paar Sekunden: Die Felder füllen sich von selbst.
4. Öffne im :fa-magnifying-glass: **Verfolgung**-Modus einen Trace für **Laptop 1**.

:::quiz table
| Einstellung | bekommen vom DHCP-Server |
|---|---|
| IP-Adresse | {192.168.0.100} |
| Gateway | {192.168.0.1} |
| DNS-Server | {192.168.0.53} |
:::

:::quiz short
Wie viele DHCP-Pakete findest du im Trace?
= 4
= vier
:::

:::quiz mc
An welche Ziel-IP-Adresse schickt Laptop 1 sein erstes Paket (`DHCP Discover`)?
- [ ] An den DHCP-Server `192.168.0.2`
- [x] An `255.255.255.255` — an alle (Broadcast)
- [ ] An das Gateway `192.168.0.1`
:::

:::quiz mc
Welche Absender-IP-Adresse hat dieses erste Paket — und warum?
- [x] `0.0.0.0` — der Laptop hat ja noch gar keine Adresse
- [ ] `192.168.0.10` — seine alte Adresse
- [ ] `192.168.0.100` — seine neue Adresse
:::

## Was dahintersteckt: DORA

Ein Gerät ohne Adresse weiß weder, wo der DHCP-Server ist, noch hat es eine eigene Absenderadresse. Es ruft deshalb per **Broadcast** ins Netz. Der Ablauf hat vier Schritte — nach ihren Anfangsbuchstaben **DORA**:

:::seq
mode: text
Laptop 1 -> DHCP-Server: DHCP Discover | „Gibt es hier einen DHCP-Server?“
DHCP-Server -> Laptop 1: DHCP Offer | „Du kannst 192.168.0.100 haben.“
Laptop 1 -> DHCP-Server: DHCP Request | „Ich nehme 192.168.0.100.“
DHCP-Server -> Laptop 1: DHCP ACK | „Bestätigt — gilt für 3600 Sekunden.“
:::

Die Adresse ist nur **geliehen** (*Lease*): Nach Ablauf der **Lease-Zeit** muss das Gerät sie verlängern, sonst darf der Server sie neu vergeben. Welche Adressen gerade verliehen sind, siehst du im **DHCP-Server** im Reiter **Leases**.

:::tip Probier es aus
Stell auch **Laptop 2** auf DHCP. Welche Adresse bekommt er? Schau danach in die **Leases** des DHCP-Servers.
:::

:::tip Merksatz
**DHCP** verteilt IP-Adresse, Netzmaske, Gateway und DNS-Server automatisch. Der Ablauf heißt **DORA**: **D**iscover (Client sucht per Broadcast), **O**ffer (Server bietet an), **R**equest (Client nimmt an), **A**CK (Server bestätigt). Die Adresse ist für die **Lease-Zeit** geliehen. DHCP nutzt **UDP**, Port 67 (Server) und 68 (Client).
:::

:::quiz match
Discover -> Der Client sucht per Broadcast nach einem DHCP-Server
Offer -> Der Server bietet eine Adresse an
Request -> Der Client fordert die angebotene Adresse an
ACK -> Der Server bestätigt die Vergabe
:::

# NAT: viele Geräte, eine Adresse

:::goal
**Lernziel:** Du kannst im Tracer zeigen, wie NAT die Absenderadresse austauscht, die NAT-Tabelle lesen und erklären, warum Verbindungen von außen ins Heimnetz eine Portweiterleitung brauchen.
:::

:::sim
url=/sims/lesson-7.1.btsim
:::

Der Provider gibt einem Heimanschluss normalerweise nur **eine** öffentliche IPv4-Adresse — die WAN-Adresse des Heimrouters. Alle Geräte im Heimnetz müssen sie sich teilen. Wie das funktioniert, heißt **NAT** (*Network Address Translation*, Adressumsetzung).

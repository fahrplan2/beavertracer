# DNS: Namen statt Nummern

:::goal
**Lernziel:** Du kannst erklären, wie DNS Namen in IP-Adressen übersetzt, wie die Namen hierarchisch organisiert sind, einen Eintrag selbst anlegen und typische DNS-Fehler finden.
:::

:::sim
url=/sims/lesson-6.2.btsim
:::

IP-Adressen kann sich kaum jemand merken — Namen wie `www.beaver-schule.de` schon. Die Übersetzung erledigt das **Domain Name System** (**DNS**), eine Art weltweites Telefonbuch des Internets.

Auf der Arbeitsfläche liegt jetzt ein etwas größeres Netz: Neben dem **Client-PC** und dem **Webserver** gibt es vier **DNS-Server**. Wozu so viele, siehst du auf der übernächsten Seite.

# Die NAT-Tabelle

:::sim
url=/sims/lesson-7.1.btsim
:::

Wenn PC und Tablet gleichzeitig dieselbe Webseite laden, kommen beide Anfragen beim Webserver von `203.0.113.2`. Woher weiß der Heimrouter, für wen eine Antwort bestimmt ist? Er führt Buch — in der **NAT-Tabelle**.

## Das Experiment

1. Wechsle in den :fa-play: **Ausführen**-Modus und rufe auf dem **PC** und auf dem **Tablet** jeweils `http://www.beispiel.de/` auf.
2. Klicke auf den **Heimrouter** und öffne den Reiter **NAT**.

Jede Zeile ist eine **Zuordnung**: Protokoll, LAN-IP und LAN-Port des Geräts im Heimnetz — und der **WAN-Port**, den der Router dafür auf seiner öffentlichen Adresse verwendet.

:::quiz short
Welche WAN-IP steht über der Tabelle?
= 203.0.113.2
:::

:::quiz mc
PC und Tablet haben beide eine Verbindung mit dem LAN-Port `49152` aufgebaut. Welchen WAN-Port bekommen sie?
- [ ] Beide denselben, `49152`
- [x] Jeder einen anderen — sonst wüsste der Router nicht, wem die Antwort gehört
- [ ] Gar keinen, NAT ändert nur die IP-Adresse
:::

:::quiz mc
Eine Antwort des Webservers kommt an `203.0.113.2` mit einem bestimmten **Ziel-Port** an. Was macht der Heimrouter damit?
- [x] Er sucht den Port in der NAT-Tabelle und schickt das Paket an die zugehörige LAN-IP und den LAN-Port
- [ ] Er schickt das Paket an alle Geräte im Heimnetz
- [ ] Er verwirft das Paket
:::

:::evaluate
Antworten prüfen
:::

Hier kommen die **Ports** aus Kapitel 5 wieder ins Spiel: Weil NAT auch die Ports umschreibt, können sich hunderte Verbindungen eine Adresse teilen. Genau genommen heißt das deshalb **PAT** (*Port Address Translation*) oder *NAT mit Port-Übersetzung* — im Alltag sagt man trotzdem einfach NAT.

So könnte eine solche Umsetzung zum Beispiel aussehen:

| | Paket vom PC (im Heimnetz) | dasselbe Paket im Internet |
|---|---|---|
| Absender | `192.168.178.20 : 49152` | `203.0.113.2 : 10001` |
| Empfänger | `192.0.2.80 : 80` | `192.0.2.80 : 80` |

:::tip Merksatz
In der **NAT-Tabelle** merkt sich der Router für jede Verbindung, welches Gerät (**LAN-IP und LAN-Port**) hinter welchem **WAN-Port** steckt. Antworten aus dem Internet ordnet er über den Ziel-Port wieder dem richtigen Gerät zu. Weil auch Ports umgeschrieben werden, spricht man genauer von **PAT**.
:::

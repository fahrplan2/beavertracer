# Das Kommunikationsdiagramm

:::sim
url=/sims/lesson-5.1.btsim
:::

Den Ablauf einer Verbindung zeichnet man als **Kommunikationsdiagramm**: Client und Server bekommen je eine senkrechte Linie, die Zeit läuft von oben nach unten. Jeder Pfeil ist ein Paket. Er ist schräg gezeichnet, weil jedes Paket ein wenig unterwegs ist.

So sieht deine Verbindung von der letzten Seite aus — vergleiche sie Zeile für Zeile mit dem Trace:

:::seq
Client-PC -> Server: SYN
Server -> Client-PC: SYN, ACK
Client-PC -> Server: ACK
Client-PC -> Server: PSH, ACK "Hello World" len=13
Server -> Client-PC: ACK
Server -> Client-PC: PSH, ACK len=13
Client-PC -> Server: ACK
Client-PC -> Server: FIN, ACK
Server -> Client-PC: ACK
Server -> Client-PC: FIN, ACK
Client-PC -> Server: ACK
:::

Über jedem Pfeil stehen die **Flags**, darunter die Nummern `SEQ` und `ACK`. **DATA** markiert Pakete mit Nutzdaten. Die roten Zahlen gehören zum Client, die blauen zum Server — was sie bedeuten, klärt die nächste Seite.

## Die Flags

| Flag | steht für | Bedeutung |
|---|---|---|
| **SYN** | *synchronize* | Verbindung aufbauen, Startnummer festlegen |
| **ACK** | *acknowledge* | bestätigt empfangene Daten |
| **PSH** | *push* | Daten sofort an das Programm weitergeben |
| **FIN** | *finish* | „Ich bin fertig“ — Verbindung abbauen |
| **RST** | *reset* | Verbindung abbrechen oder ablehnen (dazu mehr in 5.3.2) |

## Drei Phasen

**Aufbau:** Der Client schickt `SYN`, der Server antwortet mit `SYN, ACK`, der Client bestätigt mit `ACK`. Weil genau drei Pakete nötig sind, heißt das **Drei-Wege-Handshake**.

**Daten:** Jedes Paket mit Daten wird vom Empfänger mit einem `ACK` bestätigt. Hier schickt der Server das Echo zurück — auch das bestätigt der Client.

**Abbau:** Jede Seite beendet ihre Senderichtung einzeln: `FIN` vom Client, `ACK` vom Server — dann `FIN` vom Server, `ACK` vom Client. Das sind vier Pakete.

:::tip Merksatz
Eine TCP-Verbindung läuft in drei Phasen ab: **Aufbau** mit dem **Drei-Wege-Handshake** (`SYN` → `SYN, ACK` → `ACK`), **Datenübertragung** (jedes Datenpaket wird mit `ACK` bestätigt) und **Abbau** (jede Seite schickt `FIN` und bekommt ein `ACK`).
:::

# Der Router

:::goal
**Lernziel:** Du kannst erklären, wie ein Router zwei Netze verbindet, das Gateway an einem PC einstellen und begründen, wann ein PC ein Paket direkt zustellt und wann über das Gateway.
:::

:::sim
url=/sims/lesson-4.3.1.btsim
:::

Ein **Router** verbindet verschiedene Netze miteinander. Dazu hat er für jedes Netz einen eigenen Anschluss — und an jedem Anschluss eine eigene IP-Adresse aus genau diesem Netz. Auf der Arbeitsfläche siehst du wieder Firma A und Firma B, diesmal mit einem Router dazwischen.

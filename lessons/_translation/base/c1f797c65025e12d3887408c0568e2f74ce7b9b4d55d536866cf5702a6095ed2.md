# HTTPS einrichten

:::sim
url=/sims/lesson-8.3.3.btsim
:::

Hier geht es dort weiter, wo Abschnitt 8.2.2 aufgehört hat: Auf dem Webserver **www.beaver-schule.de** liegen die **Schul-CA** und ein von ihr ausgestelltes Server-Zertifikat, und der **Client-PC** vertraut der Schul-CA. Nur spricht der Webserver noch kein HTTPS.

## Vorher

Wechsle in den :fa-play: **Ausführen**-Modus und rufe auf dem **Client-PC** im :fa-globe: **Browser** `https://www.beaver-schule.de/` auf.

:::quiz mc
Was passiert?
- [x] Die Verbindung kommt nicht zustande — auf Port 443 lauscht kein Dienst
- [ ] Der Browser warnt vor einem unsicheren Zertifikat
- [ ] Die Seite wird ohne Schloss angezeigt
:::

Antwort prüfen

## HTTPS einschalten

1. Öffne auf dem Webserver den **HTTP-Server** und klicke auf **Stoppen** — solange der Server läuft, lassen sich die Einstellungen nicht ändern.
2. Wechsle in den Reiter **HTTPS**:
    - Haken bei **HTTPS aktivieren**, **HTTPS-Port** `443`
    - Bei **Zertifikat** das Server-Zertifikat `www.beaver-schule.de` auswählen — nicht die Schul-CA!
    - Auf **Verwenden** klicken
3. Klicke auf **Starten**.

Rufe die Seite auf dem Client-PC erneut über `https://` auf. Klicke auf das Schloss und prüfe Aussteller und Gültigkeit.

:::task
title: HTTPS eingerichtet?
Prüft, ob der Client-PC https://www.beaver-schule.de/ ohne Zertifikatswarnung abrufen kann. Die Simulation muss dafür im Ausführen-Modus laufen.
check: httpsOk(2, "https://www.beaver-schule.de/")
:::

:::quiz mc
Warum darfst du im HTTP-Server nicht das Zertifikat der **Schul-CA** auswählen?
- [ ] Weil CA-Zertifikate nicht verschlüsseln können
- [x] Weil es für den Namen `Schul-CA` ausgestellt ist, nicht für `www.beaver-schule.de` — der Browser würde warnen
- [ ] Weil die Schul-CA keinen privaten Schlüssel hat
:::

:::quiz mc
Was würde ein Gerät sehen, das der Schul-CA **nicht** vertraut, z.B. das Handy eines Gasts?
- [ ] Die Seite ganz normal mit Schloss
- [x] Eine Zertifikatswarnung, weil es die Vertrauenskette nicht bis zu einer bekannten CA verfolgen kann
- [ ] Gar nichts, weil die Verbindung abgelehnt wird
:::

:::evaluate
Antworten prüfen
:::

:::note
Für öffentliche Webseiten braucht man ein Zertifikat einer CA, die in allen Browsern vorinstalliert ist. Seit 2015 gibt es mit **Let's Encrypt** eine CA, die solche Zertifikate kostenlos und automatisch ausstellt — ein Hauptgrund dafür, dass heute fast alle Webseiten HTTPS verwenden.
:::

:::tip Merksatz
Für **HTTPS** braucht der Webserver ein **Server-Zertifikat mit privatem Schlüssel**, dessen Name zur Adresse passt, und muss auf **Port 443** lauschen. Der Client vertraut der Seite nur, wenn er die ausstellende **CA** kennt.
:::

# Von außen nach innen: Portweiterleitung

:::sim
url=/sims/lesson-7.2.3.btsim
:::

Im Heimnetz steht jetzt ein eigener **Heim-Webserver** (`192.168.178.10`). Clara möchte die Seite von unterwegs aufrufen — ihr Laptop **Clara** hängt rechts im Internet.

## Das Problem

1. Wechsle in den :fa-play: **Ausführen**-Modus und rufe auf **Clara** im :fa-globe: **Browser** `http://203.0.113.2/` auf — die öffentliche Adresse des Heimnetzes.
2. Der Browser wartet und wartet. Klicke nach ein paar Sekunden auf **Stopp**.
3. Öffne im :fa-magnifying-glass: **Verfolgung**-Modus einen Trace für den **Heimrouter**, Anschluss `wan0`.

:::quiz mc
Was passiert mit Claras Verbindungsaufbau (`[SYN]` an Port 80)?
- [x] Er kommt beim Heimrouter an — aber der leitet ihn nicht weiter und antwortet nicht
- [ ] Er erreicht den Heim-Webserver, der antwortet mit RST
- [ ] Er kommt gar nicht erst beim Heimrouter an
:::

:::evaluate
Antwort prüfen
:::

Für ein Paket, das von außen kommt, gibt es in der NAT-Tabelle keinen Eintrag: Niemand im Heimnetz hat diese Verbindung begonnen. Der Heimrouter weiß nicht, an welches Gerät er es schicken soll — und verwirft es.

## Die Portweiterleitung einrichten

Mit einer **Portweiterleitung** (bei manchen Routern *Portfreigabe*) legst du fest: Alles, was an einem bestimmten WAN-Port ankommt, geht an ein bestimmtes Gerät im Heimnetz.

1. Klicke auf den **Heimrouter** und öffne den Reiter **Portfreigaben**.
2. Lege eine Regel an: Protokoll `TCP`, WAN-Port `80`, LAN-IP `192.168.178.10`, LAN-Port `80`, und klicke auf **+ Hinzufügen**.
3. Rufe auf **Clara** noch einmal `http://203.0.113.2/` auf.

:::task
title: Heim-Webserver von außen erreichbar?
Prüft, ob Clara aus dem Internet eine Verbindung zu Port 80 der öffentlichen Adresse des Heimnetzes aufbauen kann. Die Simulation muss dafür im Ausführen-Modus laufen.
check: tcpOpen(12, "203.0.113.2", 80)
:::

:::warning
Eine Portweiterleitung öffnet ein Loch nach innen: Jeder im Internet kann das Gerät dahinter erreichen — auch Angreifer, die automatisch nach offenen Ports suchen. Leite deshalb nur weiter, was wirklich nötig ist, und halte das Gerät aktuell. Mehr dazu in Kapitel 9 (Firewall).
:::

:::tip Merksatz
Von außen kann niemand eine Verbindung zu einem Gerät hinter NAT beginnen — der Router weiß nicht, wohin damit. Eine **Portweiterleitung** legt fest: Pakete an einem bestimmten **WAN-Port** gehen an eine bestimmte **LAN-IP** (und einen LAN-Port). So wird ein Server im Heimnetz aus dem Internet erreichbar.
:::

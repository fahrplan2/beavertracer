# Die zustandsbehaftete Firewall

:::sim
url=/sims/lesson-9.2.btsim
:::

Eine **zustandsbehaftete** (*stateful*) Firewall merkt sich jede Verbindung, die sie einmal erlaubt hat, in einer **Zustandstabelle**: Protokoll, beide Adressen und beide Ports. Kommt ein Paket, das zu einem Eintrag passt — egal in welche Richtung —, lässt sie es ohne weitere Prüfung durch. Neue Verbindungen müssen dagegen durch die Regeln.

## Beobachten

1. Stelle in der **Firewall** den **Modus** auf **Stateful**.
2. Rufe auf dem **Lehrer-PC** im :fa-globe: **Browser** wieder `http://203.0.113.80/` auf.
3. Öffne in der Firewall sofort den Reiter **Zustände**.

:::quiz mc
Was passiert jetzt?
- [x] Die Seite lädt, und in **Zustände** steht die Verbindung vom Lehrer-PC zu `203.0.113.80:80`
- [ ] Die Seite lädt nicht, weil die Antworten immer noch keine Regel haben
:::

:::quiz short
Welcher Port steht in der Zustandstabelle beim **Ziel**?
= 80
:::

:::evaluate
Antworten prüfen
:::

Die Einträge in **Zustände** verschwinden nach einer Weile wieder (Spalte **Timeout**), wenn über die Verbindung nichts mehr läuft.

## Aufgabe: Die Schul-Firewall

Richte die Firewall jetzt so ein, wie es eine echte Schule braucht:

- **Aus dem Schulnetz** darf alles ins Internet (Richtung B → A, beliebiges Protokoll).
- **Aus dem Internet** sind nur Web (80) und Mail-Empfang (25) des Schulservers erreichbar.
- Alles andere wird **verworfen**, der Modus ist **Stateful**.

:::task
title: Schul-Firewall eingerichtet?
Prüft, ob das Schulnetz ins Internet kommt, ob von außen nur Web und Mail des Schulservers erreichbar sind und ob der Lehrer-PC von außen unerreichbar ist.
check: tcpOpen(8, "203.0.113.80", 80)
check: tcpOpen(1, "198.51.100.10", 80)
check: tcpOpen(1, "198.51.100.10", 25)
check: tcpFails(1, "198.51.100.10", 22)
check: pingFails(1, 8)
:::

:::quiz mc
Der Lehrer-PC pingt `203.0.113.80` an. Kommen die Antworten zurück?
- [x] Ja — der Ping wurde von B → A erlaubt, die Antwort gehört zu diesem Zustand
- [ ] Nein — für ICMP von außen gibt es keine Regel
:::

:::evaluate
Antwort prüfen
:::

:::tip Merksatz
Eine **zustandsbehaftete Firewall** trägt jede erlaubte Verbindung in eine **Zustandstabelle** ein und lässt alle Pakete dieser Verbindung in **beide Richtungen** durch. So genügen Regeln für den **Verbindungsaufbau**: „Innen darf nach außen“ und „von außen nur zu bestimmten Diensten“. Von außen begonnene Verbindungen ins Schulnetz bleiben gesperrt.
:::

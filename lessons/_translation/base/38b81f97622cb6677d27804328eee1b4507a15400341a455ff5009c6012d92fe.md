# DHCP: automatisch ins Netz

:::goal
**Lernziel:** Du kannst erklären, wie ein Gerät per DHCP automatisch seine IP-Einstellungen bekommt, einen DHCP-Server einrichten und typische DHCP-Fehler (z.B. eine 169.254-Adresse) erkennen und beheben.
:::

:::sim
url=/sims/lesson-6.4.btsim
:::

Bisher hast du jedem Gerät seine IP-Adresse, Netzmaske, das Gateway und den DNS-Server von Hand eingetragen. In der Schule mit hunderten Laptops, Tablets und Handys wäre das unmöglich — und jeder Tippfehler ein Fehler im Netz.

Diese Arbeit übernimmt das **Dynamic Host Configuration Protocol** (**DHCP**): Ein **DHCP-Server** verteilt die Einstellungen automatisch an jedes Gerät, das ins Netz kommt.

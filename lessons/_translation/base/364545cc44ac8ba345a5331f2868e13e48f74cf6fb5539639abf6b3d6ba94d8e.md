# UDP: die starke Vereinfachung

:::goal
**Lernziel:** Du kannst UDP mit TCP vergleichen und begründen, für welche Anwendungen UDP die bessere Wahl ist.
:::

:::sim
url=/sims/lesson-5.5.btsim
:::

TCP leistet viel — Verbindungsaufbau, Bestätigungen, Neuübertragung, Reihenfolge. Das kostet aber Zeit und zusätzliche Pakete. Das zweite wichtige Protokoll der Transportschicht verzichtet auf fast alles davon: das **User Datagram Protocol** (**UDP**). Seine Pakete heißen **Datagramme**.

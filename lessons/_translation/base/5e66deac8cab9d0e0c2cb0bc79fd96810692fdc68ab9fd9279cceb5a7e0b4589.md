# Netzadresse, Broadcastadresse und Hosts

In jedem Netz haben zwei Adressen eine besondere Aufgabe:

- Die **Netzadresse** ist die **niedrigste** Adresse des Netzes: Alle Bits im Hostteil sind 0. Sie bezeichnet das Netz als Ganzes, z.B. in Routing-Tabellen.
- Die **Broadcastadresse** ist die **höchste** Adresse des Netzes: Alle Bits im Hostteil sind 1. Was an sie geschickt wird, geht an alle Geräte im Netz.

Beide Adressen werden **nicht** an Geräte vergeben. Alle Adressen dazwischen stehen für Geräte (**Hosts**) zur Verfügung.

## Ein einfaches Beispiel

`192.168.0.12/24` — der Hostteil ist das letzte Oktett:

| | Adresse |
|---|---|
| Netzadresse (Hostteil = 0) | `192.168.0.0` |
| Broadcastadresse (Hostteil = 255) | `192.168.0.255` |
| Bereich für Hosts | `192.168.0.1` – `192.168.0.254` |
| Anzahl Hosts | 254 |

## Wenn die Grenze mitten im Oktett liegt

Schwieriger wird es, wenn die Präfixlänge kein Vielfaches von 8 ist. Dann rechnest du das betroffene Oktett ins Dualsystem um. Beispiel: `194.9.190.12/27`.

Die ersten drei Oktette gehören vollständig zum [[n|Netzteil]] (24 Bit). Vom letzten Oktett gehören noch **3 Bit** zum Netzteil (24 + 3 = 27), die restlichen **5 Bit** zum [[h|Hostteil]]:

| | letztes Oktett (dual) | dezimal |
|---|---|---|
| IP-Adresse | [[n|000]][[h|01100]] | 12 |
| Netzmaske (`/27`) | [[n|111]][[h|00000]] | 224 |
| Netzadresse: Hostbits auf 0 | [[n|000]][[h|00000]] | **0** |
| Broadcastadresse: Hostbits auf 1 | [[n|000]][[h|11111]] | **31** |

Ergebnis:

- Netzadresse: `194.9.190.0`
- Broadcastadresse: `194.9.190.31`
- Bereich für Hosts: `194.9.190.1` – `194.9.190.30`
- Anzahl Hosts: 2⁵ − 2 = **30**

:::tip Merksatz
**Netzadresse:** alle Hostbits auf 0 (niedrigste Adresse). **Broadcastadresse:** alle Hostbits auf 1 (höchste Adresse). Beide werden nicht an Geräte vergeben. Ein Netz mit der Präfixlänge *n* hat **2<sup>32 − n</sup> − 2** nutzbare Adressen für Hosts.
:::

:::tip Tipp: die Blockgröße
Wenn du das Verfahren im Dualsystem verstanden hast, gibt es eine Abkürzung: **256 minus das Masken-Oktett** ergibt die Größe eines Netzes in diesem Oktett. Bei `/27` (Maske 224) ist das 256 − 224 = **32**. Netze beginnen dann bei 0, 32, 64, 96 … — die Adresse `.12` liegt im Netz ab `.0`, die Adresse `.70` im Netz ab `.64`.
:::

## Die wichtigsten Netzgrößen

| Präfix | Netzmaske | Hosts |
|---|---|---|
| `/8` | `255.0.0.0` | 16 777 214 |
| `/16` | `255.255.0.0` | 65 534 |
| `/24` | `255.255.255.0` | 254 |
| `/25` | `255.255.255.128` | 126 |
| `/26` | `255.255.255.192` | 62 |
| `/27` | `255.255.255.224` | 30 |
| `/28` | `255.255.255.240` | 14 |
| `/29` | `255.255.255.248` | 6 |
| `/30` | `255.255.255.252` | 2 |

:::note
Das kleinste in der Praxis übliche Netz ist `/30`: Es hat genau zwei nutzbare Adressen und wird gerne für die Verbindung zwischen zwei Routern verwendet. Ein `/32` bezeichnet eine einzelne Adresse — als Netz ist es nicht nutzbar, kommt aber in Routing-Tabellen und Firewall-Regeln vor.
:::

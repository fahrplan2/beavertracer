# POP3 oder IMAP?

:::sim
url=/sims/lesson-6.3.btsim
:::

Zum Abholen gibt es zwei Protokolle. In dieser Simulation verwendet **Anna POP3** und **Ben IMAP**.

## Das Experiment

1. Schicke im :fa-play: **Ausführen**-Modus eine Mail von **Ben** an `anna@beaver-schule.de`.
2. Klicke bei **Anna** in der App **E-Mail** auf **Abrufen**.
3. Öffne Traces für **Anna** und für **Ben** und vergleiche die Befehle beim Abholen.

:::quiz match
USER / PASS -> POP3: Anmelden mit Benutzername und Passwort in zwei Schritten
RETR -> POP3: eine Nachricht herunterladen
LOGIN -> IMAP: Anmelden mit Benutzername und Passwort
SELECT INBOX -> IMAP: einen Ordner auf dem Server öffnen
:::

:::evaluate
Zuordnung prüfen
:::

## Der Unterschied

| | POP3 | IMAP |
|---|---|---|
| Port | 110 | 143 |
| Grundidee | Mails **herunterladen** — danach meist auf dem Server löschen | Mails **bleiben auf dem Server** und werden dort verwaltet |
| Ordner, gelesen/ungelesen | nur auf dem eigenen Gerät | auf dem Server — überall gleich |
| Mehrere Geräte (Handy, Laptop) | unpraktisch: Jedes Gerät hat einen anderen Stand | ideal: alle Geräte sehen dasselbe Postfach |

:::note
Das E-Mail-Programm in BeaverTracer lässt die Mails auch bei POP3 auf dem Server liegen. Echte Programme löschen sie nach dem Herunterladen oft — oder lassen sie nur eine Weile liegen.
:::

Lena liest ihre Mails auf dem Handy, dem Tablet und dem Schul-Laptop. Was sollte sie verwenden?
- [ ] POP3, weil es einfacher ist
- [x] IMAP, weil alle Geräte dasselbe Postfach auf dem Server sehen

:::

Antwort prüfen
:::

:::tip Merksatz
**POP3** lädt Mails vom Server auf **ein** Gerät herunter. **IMAP** verwaltet das Postfach **auf dem Server** — mit Ordnern und Gelesen-Status für alle Geräte gleichzeitig. Beide dienen nur zum **Abholen**; versendet wird immer mit **SMTP**.
:::

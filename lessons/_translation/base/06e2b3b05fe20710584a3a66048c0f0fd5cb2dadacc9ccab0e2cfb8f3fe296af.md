# HTTP und HTTPS im Vergleich

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Der Webserver **www.beaver-schule.de** bietet das Notenportal der Schule sowohl über HTTP als auch über HTTPS an. Was sieht ein Mithörer?

## Das Experiment

1. Wechsle in den :fa-play: **Ausführen**-Modus und rufe auf dem **Client-PC** im :fa-globe: **Browser** zuerst `http://www.beaver-schule.de/` auf, danach `https://www.beaver-schule.de/`.
2. Öffne im :fa-magnifying-glass: **Verfolgung**-Modus einen Trace für den **Client-PC**.
3. Suche zuerst das Paket `HTTP/1.1 200 OK` und klicke es an. Unten in den Details findest du den Inhalt der Seite.

:::quiz mc
Was kann ein Mithörer bei **HTTP** sehen?
- [x] Die komplette Webseite, auch Annas Noten
- [ ] Nur die Adresse des Servers
- [ ] Nichts, weil HTTP über TCP läuft
:::

:::quiz short
Welche Note hat Anna in Mathematik?
= 2
:::

:::evaluate
Antworten prüfen
:::

Jetzt der HTTPS-Teil. Suche das `[SYN]`-Paket, mit dem der Client die zweite Verbindung beginnt.

:::quiz short
Welchen Zielport hat die HTTPS-Verbindung (Spalte **Info**, `… → ???`)?
= 443
:::

Gib nun oben im Filterfeld des Traces `tls` ein — dann siehst du nur noch die TLS-Pakete.

:::quiz mc
Was steht in der Spalte **Info** bei den Paketen, die die Webseite enthalten?
- [ ] `HTTP/1.1 200 OK`
- [x] `Application Data`
- [ ] `Encrypted HTML`
:::

:::quiz multi
Was kann ein Mithörer bei **HTTPS** trotzdem noch sehen?
- [x] Die IP-Adressen von Client und Server
- [x] Dass Port 443 benutzt wird, also wahrscheinlich HTTPS
- [x] Wie viele Daten ungefähr übertragen werden
- [ ] Welche Seite aufgerufen wurde und was darauf steht
:::

:::evaluate
Antworten prüfen
:::

:::note
Klicke ein **Application Data**-Paket an: Die Nutzdaten sind nur eine Folge scheinbar zufälliger Bytes. Der Tracer kann sie nicht entschlüsseln — er kennt den Sitzungsschlüssel genauso wenig wie ein Angreifer.
:::

:::tip Merksatz
Bei **HTTP** kann jeder Mithörer die komplette Webseite lesen. Bei **HTTPS** sieht er nur noch, **wer mit wem** spricht (IP-Adressen, Port 443) und **wie viel** — der Inhalt steckt verschlüsselt in **Application Data**-Paketen.
:::

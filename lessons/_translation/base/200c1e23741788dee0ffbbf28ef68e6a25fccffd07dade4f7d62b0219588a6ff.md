# Die wichtigsten Adressarten

Bei IPv6 erkennt man am Anfang einer Adresse, wofür sie gedacht ist:

| Adressart | erkennbar an | wofür |
|---|---|---|
| **Link-Local** | `fe80::` | Gilt nur im **eigenen lokalen Netz**. Jedes Gerät gibt sich diese Adresse automatisch — sie wird nie von einem Router weitergeleitet. |
| **Global Unicast** | `2…` oder `3…` (`2000::/3`) | Weltweit eindeutige Adresse, im Internet erreichbar. Das Präfix bekommt man vom Internetanbieter. |
| **Unique Local** | `fd…` (`fc00::/7`) | Für private Netze, vergleichbar mit `192.168.x.x` bei IPv4. |
| **Loopback** | `::1` | Das eigene Gerät — wie `127.0.0.1` bei IPv4. |
| **Multicast** | `ff…` | An eine **Gruppe** von Geräten, z.B. `ff02::1` = alle Geräte im lokalen Netz. |

:::note
Für Beispiele und Lehrmaterial ist der Bereich `2001:db8::/32` reserviert — er kommt im echten Internet nie vor. Deshalb siehst du ihn in diesem Kurs.
:::

Eine wichtige Neuerung: **IPv6 kennt keinen Broadcast mehr.** Was bei IPv4 ein Broadcast an alle war, erledigt IPv6 mit **Multicast**-Adressen — die Nachricht geht nur an die Geräte, die sich für diese Gruppe interessieren.

:::tip Merksatz
Jedes IPv6-Gerät hat mindestens eine **Link-Local-Adresse** (`fe80::…`) für das eigene Netz, meist zusätzlich eine **globale Adresse** für das Internet. Statt Broadcast verwendet IPv6 **Multicast** (`ff…`).
:::

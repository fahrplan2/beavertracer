# Le routeur

:::goal
**Objectif d'apprentissage :** Tu sais expliquer comment un routeur relie deux réseaux, configurer la passerelle sur un PC et justifier quand un PC remet un paquet directement et quand il passe par la passerelle.
:::

:::sim
url=/sims/lesson-4.3.1.btsim
:::

Un **routeur** relie différents réseaux entre eux. Pour cela, il possède une interface distincte pour chaque réseau, et sur chaque interface une adresse IP propre, issue précisément de ce réseau. Dans l'espace de travail, tu retrouves Firma A et Firma B, cette fois avec un routeur entre les deux.

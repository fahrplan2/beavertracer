# DHCP : rejoindre le réseau automatiquement

:::goal
**Objectif d'apprentissage :** Tu sais expliquer comment un appareil obtient automatiquement ses paramètres IP via DHCP, configurer un serveur DHCP, et reconnaître et corriger les erreurs DHCP typiques (p. ex. une adresse en 169.254).
:::

:::sim
url=/sims/lesson-6.4.btsim
:::

Jusqu'à présent, tu as saisi à la main l'adresse IP, le masque de sous-réseau, la passerelle et le serveur DNS de chaque appareil. Dans un établissement scolaire avec des centaines d'ordinateurs portables, de tablettes et de smartphones, ce serait impossible, et chaque faute de frappe provoquerait une erreur dans le réseau.

C'est le **Dynamic Host Configuration Protocol** (**DHCP**) qui se charge de ce travail : un **serveur DHCP** distribue automatiquement les paramètres à chaque appareil qui rejoint le réseau.

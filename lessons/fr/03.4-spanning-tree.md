# Boucles dans le réseau et Spanning Tree

:::goal
**Objectif d'apprentissage :** Tu sais expliquer comment une tempête de diffusion (broadcast storm) se produit dans un réseau comportant une boucle et comment le Spanning Tree Protocol (STP) empêche les boucles sans renoncer à la tolérance aux pannes.
:::

:::sim
url=/sims/lesson-3.4.1.btsim
:::

Que se passe-t-il quand un câble tombe en panne dans un réseau ? Si tout dépend d'une seule liaison, une partie du réseau se retrouve coupée. C'est pourquoi, dans les réseaux plus grands, on relie souvent les switchs **plusieurs fois** entre eux, comme les trois switchs dans l'espace de travail, qui forment un anneau. Si un câble lâche, il existe un autre chemin.

Ça a l'air bien, mais un tel anneau cache un piège dangereux. Tu vas le découvrir à la page suivante.

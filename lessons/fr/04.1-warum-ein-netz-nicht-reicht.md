Dans l'espace de travail, tu vois deux petits réseaux d'entreprise : **Firma A** avec Anna (`192.168.0.10`) et Ben (`192.168.0.11`), **Firma B** avec Clara (`172.16.0.10`) et David (`172.16.0.11`). Les deux switchs sont même reliés directement par un câble.

## Un ping dans son propre réseau

1. Passe en mode :fa-play: **Exécuter**, ouvre le :fa-terminal: **Terminal** sur **Anna** et envoie un ping à Ben :
   ```
   $ ping 192.168.0.11
   ```
2. Passe en mode :fa-magnifying-glass: **Trace**, ouvre une trace pour **Anna** et clique sur un `Echo (ping) request`.
3. Dans l'arbre des protocoles, déplie la ligne **Internet Protocol Version 4**. C'est la partie IP du paquet, celle dont il est question dans ce chapitre.

:::quiz match
Source Address -> Adresse IP de l'expéditeur
Destination Address -> Adresse IP du destinataire
Time to Live -> Nombre de routeurs que le paquet peut encore traverser
Protocol -> Protocole contenu dans le paquet (ici ICMP, c'est-à-dire le ping)
:::

## Ce qui se cache derrière

Une adresse IP fonctionne un peu comme une adresse postale : une partie indique dans quel **réseau** se trouve un appareil (comme la rue), l'autre partie indique de quel **appareil** il s'agit dans ce réseau (comme le numéro de la maison). Anna se trouve dans le réseau `192.168.0…`, Clara dans le réseau `172.16.0…` : ce sont deux « rues » différentes.

Un PC envoie directement les paquets aux appareils de son *propre* réseau (via ARP et le switch, comme tu le sais déjà). Pour un réseau *étranger*, il a besoin d'un appareil qui relie les réseaux entre eux et transmet les paquets : un **routeur**. Il n'y en a pas encore ici, c'est pourquoi le câble entre les switchs ne sert à rien non plus.

:::tip À retenir
L'**Internet Protocol** (**IP**), sur la couche 3, permet aux paquets d'arriver à destination même entre des réseaux différents. Une **adresse IP** se compose d'une **partie réseau** (quel réseau ?) et d'une **partie hôte** (quel appareil ?). Les appareils d'un même réseau se joignent directement ; pour atteindre d'autres réseaux, il faut un **routeur**.
:::

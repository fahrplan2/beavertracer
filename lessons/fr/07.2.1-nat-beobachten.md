## Ce qui se cache derrière

Dans chaque paquet qui part vers Internet, le routeur domestique remplace l'adresse privée de l'expéditeur par sa propre **adresse WAN publique** — et généralement aussi le port de l'expéditeur. Pour le serveur web, tout se passe comme si la requête venait du routeur domestique. Quand la réponse revient, le routeur domestique remet l'adresse d'origine et transmet le paquet au PC.

Ainsi, tout le réseau domestique peut accéder à Internet avec une seule adresse publique — et les appareils sur Internet ne voient jamais les adresses privées.

## Le chemin vers Internet

Saisis sur le **PC**, dans le :fa-terminal: **Terminal** :

```
$ traceroute 192.0.2.80
```

:::quiz short
Combien de routeurs se trouvent entre le PC et le serveur web ? (Compte toutes les lignes avant la dernière.)
= 4
= quatre
:::

:::quiz mc
Quelle adresse `traceroute` affiche-t-il pour le premier routeur ?
- [x] `192.168.178.1` — l'adresse LAN du routeur domestique
- [ ] `203.0.113.2` — son adresse WAN
- [ ] `203.0.113.1` — le premier routeur du fournisseur d'accès
:::

:::evaluate
Vérifier les réponses
:::

:::tip À retenir
Le **NAT** (*Network Address Translation*) remplace, sur le chemin vers Internet, l'adresse **privée** de l'expéditeur d'un appareil par l'**adresse WAN publique** du routeur — et inversement pour les réponses. Ainsi, tous les appareils du réseau domestique se partagent **une seule** adresse IPv4 publique. Cela économise des adresses et cache les adresses privées à Internet.
:::

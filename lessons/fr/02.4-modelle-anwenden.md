# Appliquer les modèles

Associe les protocoles de l'expérience du début du chapitre à leur couche OSI :

:::quiz match
Ethernet -> Couche 2 — Liaison de données
IPv4 -> Couche 3 — Réseau
TCP -> Couche 4 — Transport
HTTP -> Couche 7 — Application
:::

:::evaluate
Vérifier l'association
:::

Et pour finir, les noms des unités de données :

:::quiz match
Trame -> Couche 2 — Liaison de données
Paquet -> Couche 3 — Réseau
Segment -> Couche 4 — Transport
:::

:::evaluate
Vérifier l'association
:::

Tu as désormais les outils nécessaires pour classer correctement les protocoles. À partir du prochain chapitre, nous parcourons les couches une par une, en commençant par la couche 2 et la question de savoir comment un switch sait réellement vers où il doit transférer un paquet.

# Attribuer des adresses IP

:::sim
url=/sims/lesson-1.2.2.btsim
:::

Pour que deux appareils puissent communiquer, ils ont besoin d'une adresse IP dans le même réseau. Dans l'espace de travail, tu vois deux PC reliés, exactement comme tu viens de les construire toi-même.

1. Clique sur :fa-play: **Exécuter** pour passer en mode Exécution, puis clique sur **Computer 1** pour l'ouvrir.
2. Ouvre les :fa-gear: **Paramètres IP**. Un nouveau PC a déjà l'adresse `192.168.0.10` avec le masque de sous-réseau `/24`. Tu peux la laisser telle quelle.
3. Ouvre maintenant **Computer 2**. Il a la *même* adresse `192.168.0.10`, ce qui ne peut pas fonctionner, car chaque adresse ne doit apparaître qu'une seule fois dans le réseau. Remplace-la par `192.168.0.11` (masque de sous-réseau `/24`).

:::tip À retenir
Une **adresse IP** (par ex. `192.168.0.10`) est l'adresse d'un appareil dans le réseau, comparable à un numéro de maison. Chaque adresse IP ne doit apparaître qu'**une seule fois** dans un réseau.
:::

:::task
title: Adresses correctement attribuées ?
Reste en mode Exécution et vérifie si les deux PC ont des adresses compatibles et peuvent se joindre.
check: ip(1, "192.168.0.10/32")
check: ip(3, "192.168.0.11/32")
check: pingOk(1, 3)
:::

:::note
Ce que signifie exactement `/24` et comment découper judicieusement un réseau, nous le verrons en détail au chapitre 4. Pour l'instant, il suffit de retenir que les deux adresses doivent commencer par `192.168.0.` et ne doivent pas être identiques.
:::

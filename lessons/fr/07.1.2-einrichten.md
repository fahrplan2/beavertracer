# Configurer le routeur domestique

:::sim
url=/sims/lesson-7.1.2.btsim
:::

Un nouveau routeur domestique vient d'être branché, mais personne n'accède encore à Internet. Ton fournisseur d'accès t'a envoyé une lettre avec les **identifiants de connexion** :

| Identifiants de connexion | Valeur |
|---|---|
| Adresse IP WAN | `203.0.113.2` |
| Longueur du préfixe | `/30` |
| Passerelle (routeur du fournisseur d'accès) | `203.0.113.1` |
| Serveur DNS du fournisseur d'accès | `198.51.100.10` |

1. Passe en mode :fa-play: **Exécuter**, clique sur le **Heimrouter** et ouvre l'onglet **WAN**.
2. Saisis les identifiants de connexion et clique sur **Appliquer**.
3. Connecte la **Tablet** au Wi-Fi : :fa-gear: **Paramètres IP**, onglet **WiFi**, SSID `Biberbau`, **Appliquer**.
4. Teste sur le PC avec `ping 192.0.2.80` ou dans le navigateur avec `http://www.beispiel.de/`.

:::note
En pratique, le routeur domestique obtient généralement son adresse WAN automatiquement auprès du fournisseur d'accès (par DHCP ou par une connexion avec nom d'utilisateur et mot de passe). Des identifiants fixes comme ici sont plutôt courants pour les connexions d'entreprise.
:::

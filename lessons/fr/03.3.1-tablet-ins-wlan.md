# Connecter une tablette au Wi-Fi

:::sim
url=/sims/lesson-3.3.1.btsim
:::

Le **Schul-PC** (`192.168.0.10`) et un **Point d'accès** sont branchés sur le switch. La tablette **Anna** (`192.168.0.30`) doit rejoindre le Wi-Fi de l'école.

## Trouver le Wi-Fi

Passe en mode :fa-play: **Exécution** et clique sur le **Point d'accès**. Tu y trouves le nom de son réseau Wi-Fi, le **SSID** : `Schule`.

Le point d'accès fonctionne comme un pont : ce qui lui arrive par radio, il le transmet au switch par son câble, et inversement. Ainsi, Anna et le Schul-PC se retrouvent dans le même réseau local.

## Connecter la tablette

1. Clique sur **Anna**, ouvre les :fa-gear: **Paramètres IP**, puis l'onglet **WiFi**.
2. Dans le champ **SSID**, saisis le nom du réseau Wi-Fi : `Schule`, puis clique sur **Appliquer**.
3. Sur Anna, ouvre le :fa-terminal: **Terminal** et envoie un ping au Schul-PC :
   ```
   $ ping 192.168.0.10
   ```

Pendant le ping, observe l'espace de travail : des ondes radio se propagent autour d'Anna et du point d'accès.

:::tip À retenir
Un **WLAN** (réseau local sans fil) est un réseau local qui fonctionne par radio. Le **point d'accès** relie le WLAN au réseau filaire. Chaque WLAN a un nom, le **SSID** (*Service Set Identifier*) : un appareil doit connaître le bon SSID pour s'y connecter.
:::

:::quiz mc
Que se passe-t-il si tu saisis `schule` (en minuscules) comme SSID sur Anna ?
- [ ] Rien : les majuscules et les minuscules n'ont pas d'importance
- [x] Anna n'est plus connectée : le SSID doit correspondre exactement
- [ ] Anna se connecte à un autre réseau Wi-Fi
:::

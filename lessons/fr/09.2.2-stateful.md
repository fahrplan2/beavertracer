# Le pare-feu à états

:::sim
url=/sims/lesson-9.2.btsim
:::

Un pare-feu **à états** (*stateful*) mémorise chaque connexion qu'il a autorisée une fois dans une **table d'états** : protocole, les deux adresses et les deux ports. Lorsqu'un paquet arrive et correspond à une entrée, quel que soit son sens, il le laisse passer sans autre contrôle. Les nouvelles connexions, en revanche, doivent passer par les règles.

## Observer

1. Dans le **Firewall**, règle le **Mode** sur **Stateful**.
2. Sur le **Lehrer-PC**, ouvre de nouveau `http://203.0.113.80/` dans le :fa-globe: **Navigateur**.
3. Ouvre immédiatement l'onglet **États** dans le pare-feu.

:::quiz mc
Que se passe-t-il maintenant ?
- [x] La page se charge, et **États** affiche la connexion du Lehrer-PC vers `203.0.113.80:80`
- [ ] La page ne se charge pas, car les réponses n'ont toujours pas de règle
:::

:::quiz short
Quel port figure dans la table d'états dans la colonne **Destination** ?
= 80
:::

:::evaluate
Vérifier les réponses
:::

Les entrées dans **États** disparaissent au bout d'un moment (colonne **Timeout**) lorsque plus rien ne passe par la connexion.

## Tâche : le pare-feu de l'école

Configure maintenant le pare-feu comme une vraie école en a besoin :

- **Depuis le réseau de l'école**, tout peut aller vers Internet (sens B → A, protocole quelconque).
- **Depuis Internet**, seuls le web (80) et la réception du courrier (25) du serveur de l'école sont accessibles.
- Tout le reste est **rejeté**, et le mode est **Stateful**.

:::task
title: Pare-feu de l'école configuré ?
Vérifie que le réseau de l'école accède à Internet, que depuis l'extérieur seuls le web et le courrier du serveur de l'école sont accessibles et que le Lehrer-PC est inaccessible depuis l'extérieur.
check: tcpOpen(8, "203.0.113.80", 80)
check: tcpOpen(1, "198.51.100.10", 80)
check: tcpOpen(1, "198.51.100.10", 25)
check: tcpFails(1, "198.51.100.10", 22)
check: pingFails(1, 8)
:::

:::quiz mc
Le Lehrer-PC envoie un ping à `203.0.113.80`. Les réponses reviennent-elles ?
- [x] Oui : le ping a été autorisé de B → A, et la réponse appartient à cet état
- [ ] Non : il n'y a aucune règle pour l'ICMP venant de l'extérieur
:::

:::evaluate
Vérifier la réponse
:::

:::tip À retenir
Un **pare-feu à états** inscrit chaque connexion autorisée dans une **table d'états** et laisse passer tous les paquets de cette connexion dans **les deux sens**. Il suffit donc de règles pour l'**établissement de la connexion** : « l'intérieur peut aller vers l'extérieur » et « depuis l'extérieur, uniquement vers certains services ». Les connexions initiées depuis l'extérieur vers le réseau de l'école restent bloquées.
:::

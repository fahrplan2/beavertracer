# Valeurs de hachage : l'empreinte digitale des données

:::sim
url=/sims/lesson-8.1.3.btsim
:::

Une **fonction de hachage** calcule, à partir de n'importe quelle quantité de données (une phrase, un document, un film entier), une courte chaîne de caractères de longueur fixe : la **valeur de hachage**. Elle fonctionne comme une **empreinte digitale** : des données identiques donnent toujours la même valeur de hachage, des données différentes en donnent une autre.

La fonction de hachage utilisée couramment aujourd'hui s'appelle **SHA-256**. Sa valeur de hachage fait toujours 256 bits, soit 64 caractères en hexadécimal.

## L'expérience

Sur le **PC**, le dossier `/home` contient trois fichiers avec un petit contrat de vente. Passe en mode Exécution avec :fa-play: **Exécuter**, ouvre le :fa-terminal: **Terminal** sur le **PC** et saisis :

```
$ cd /home
$ cat vertrag.txt vertrag-kopie.txt vertrag-neu.txt
$ sha256sum vertrag.txt vertrag-kopie.txt vertrag-neu.txt
```

## Propriétés d'une fonction de hachage

| Propriété | Signification |
|---|---|
| **longueur fixe** | Quelle que soit la taille des données, la valeur de hachage a toujours la même longueur. |
| **déterministe** | Des données identiques donnent toujours la même valeur de hachage. |
| **effet avalanche** | La moindre modification donne une valeur de hachage complètement différente. |
| **fonction à sens unique** | Il est **impossible** de retrouver les données à partir de la valeur de hachage. |
| **résistante aux collisions** | Il est pratiquement impossible de trouver deux fichiers différents ayant la même valeur de hachage. |

Une fonction de hachage n'est **pas un chiffrement** : il n'y a ni clé ni déchiffrement. Elle sert un autre objectif : l'**intégrité**.

## À quoi ça sert ?

- **Vérifier des téléchargements :** de nombreux sites web indiquent la valeur SHA-256 à côté d'un fichier. Si la valeur de hachage du fichier que tu as téléchargé correspond, c'est qu'il n'a pas été modifié en chemin.
- **Stocker des mots de passe :** les sites web bien conçus ne stockent pas ton mot de passe, mais seulement sa valeur de hachage. Lors de la connexion, on compare la valeur de hachage de ce que tu as saisi. Si la base de données est volée, le voleur ne connaît quand même pas les mots de passe.
- **Signatures numériques :** au lieu de signer un document entier, on ne signe que sa valeur de hachage. Plus de détails dans la section suivante.

:::tip À retenir
Une **fonction de hachage** (par ex. **SHA-256**) calcule, à partir de données quelconques, une **valeur de hachage** de longueur fixe : une **empreinte digitale**. La moindre modification donne une valeur de hachage complètement différente, et il est impossible de retrouver les données à partir de la valeur de hachage. Les valeurs de hachage garantissent l'**intégrité** des données.
:::

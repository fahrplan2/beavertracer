# Consulter un certificat

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Sur l'espace de travail, tu vois le **Client-PC**, un **serveur DNS** et le serveur web de l'école, `www.beaver-schule.de`. Le serveur web propose aussi ses pages via **HTTPS**.

## Le cadenas dans le navigateur

1. Passe en mode :fa-play: **Exécution**, clique sur le **Client-PC** et ouvre le :fa-globe: **Navigateur**.
2. Ouvre `https://www.beaver-schule.de/` et fais bien attention au **https**.
3. Un **cadenas** apparaît à gauche de l'adresse. Clique dessus.

:::quiz short
Pour quel nom le certificat a-t-il été délivré (sujet sans `CN=`) ?
= www.beaver-schule.de
:::

:::quiz short
Qui a délivré le certificat (émetteur sans `CN=`) ?
= Biber Root CA
:::

:::evaluate
Vérifier les réponses
:::

## Pourquoi le Client-PC fait-il confiance au certificat ?

Sur le **Client-PC**, ouvre le :fa-shield-halved: **Gestionnaire de certificats** et va dans l'onglet **AC de confiance**.

:::quiz mc
Que trouves-tu à cet endroit ?
- [x] Le certificat de la **Biber Root CA**
- [ ] Le certificat de `www.beaver-schule.de`
- [ ] Aucune entrée
:::

:::quiz mc
À quoi voit-on que la Biber Root CA est une AC racine ?
- [x] Elle est **auto-signée** : le sujet et l'émetteur sont identiques
- [ ] Son nom se termine par « CA »
- [ ] Elle n'a pas de clé publique
:::

:::quiz mc
Sur le Client-PC, est-ce que **Clé privée** indique « Oui » ou « Non » ?
- [ ] Oui : le client a besoin de la clé privée de l'AC pour vérifier les signatures
- [x] Non : la clé publique suffit pour vérifier ; seule l'AC possède la clé privée
:::

:::evaluate
Vérifier les réponses
:::

## De l'autre côté : le serveur web

Ouvre maintenant le :fa-shield-halved: **Gestionnaire de certificats** sur le serveur web **www.beaver-schule.de** (onglet **Mes certificats**) et examine son certificat.

:::quiz multi
Qu'est-ce qui est vrai pour le certificat du serveur web ?
- [x] **Clé privée** indique « Oui » : le serveur en a besoin pour l'établissement de la connexion
- [x] La **chaîne** est `www.beaver-schule.de ← Biber Root CA`
- [x] L'**empreinte** est la même que dans la fenêtre du cadenas du navigateur
- [ ] Il est auto-signé
:::

:::evaluate
Vérifier les réponses
:::

:::note
L'**empreinte** est une valeur de hachage calculée sur le certificat. Elle permet de comparer rapidement deux certificats, sans avoir à vérifier chaque champ un par un.
:::

:::tip À retenir
Le **serveur web** possède son certificat **avec la clé privée**. Le **client** ne connaît que le **certificat de l'AC racine** (sans clé privée) et cela lui suffit pour vérifier la signature du certificat du serveur. En cliquant sur le **cadenas** dans le navigateur, on voit le sujet, l'émetteur, l'empreinte et la période de validité.
:::

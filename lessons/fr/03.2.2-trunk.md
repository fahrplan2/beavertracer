# VLAN sur deux switchs : le trunk

:::sim
url=/sims/lesson-3.2.2.btsim
:::

L'école a deux étages, chacun équipé d'un switch. Les deux switchs sont reliés par un câble sur le **port 8** :

| Switch | Port 1 (VLAN 10, administration) | Port 2 (VLAN 20, salle informatique) |
|---|---|---|
| **Switch EG** (rez-de-chaussée) | Sekretariat `192.168.0.10` | Anna `192.168.0.20` |
| **Switch OG** (étage) | Schulleitung `192.168.0.11` | Ben `192.168.0.21` |

Les VLAN des ports des PC sont déjà configurés.

## Le problème

Passe en mode :fa-play: **Exécuter** et, depuis **Anna**, envoie un ping à Ben (`ping 192.168.0.21`). Tous deux sont dans le VLAN 20, et pourtant aucune réponse n'arrive.

Dans l'onglet **VLAN** d'un switch, regarde la ligne **port 8** : elle est encore réglée sur `untagged` avec le PVID `1`. Seul le VLAN 1 passe donc par ce câble, ni le VLAN 10 ni le VLAN 20.

Or, le câble entre les switchs doit transporter des trames des *deux* VLAN. Pour cela, le switch colle sur chaque trame une petite étiquette qui indique l'ID du VLAN : le **tag VLAN**. Ainsi, le switch à l'autre bout sait à quel VLAN appartient la trame.

## Configurer le trunk

Fais-le sur les **deux** switchs :

1. Clique sur le switch et ouvre l'onglet **VLAN**.
2. Dans la ligne **port 8**, règle le **Mode** sur `tagged` et saisis `10,20` dans **VLANs autorisés**.
3. Clique sur **Appliquer**.

Ensuite, envoie de nouveau un ping à Ben depuis **Anna**, puis, pour comparer, à la Schulleitung (`ping 192.168.0.11`).

:::quiz mc
Que se passe-t-il maintenant ?
- [x] Anna atteint Ben, mais pas la Schulleitung
- [ ] Anna atteint Ben et la Schulleitung
- [ ] Anna n'atteint toujours personne
:::

:::evaluate
Vérifier la réponse
:::

## Le tag VLAN dans le traceur

Passe en mode :fa-magnifying-glass: **Trace** et, avec **+**, ouvre une trace pour **Switch EG**, port **8** : c'est le câble entre les switchs. Clique sur l'un des pings d'Anna (`Echo (ping) request`).

Une nouvelle ligne est apparue dans l'arbre des protocoles, juste sous Ethernet : **802.1Q Virtual LAN**. C'est le tag VLAN.

:::quiz short
Quel ID de VLAN figure dans le tag du ping d'Anna ?
= 20
:::

Pour comparer, ouvre une trace pour **Ben** (`eth0`) et clique sur le même ping.

:::quiz mc
Que remarques-tu chez Ben ?
- [ ] On y trouve le même tag avec l'ID 20
- [x] La ligne 802.1Q n'y figure pas : le switch a retiré le tag avant le port de Ben
- [ ] Le ping n'arrive pas du tout chez Ben
:::

:::evaluate
Vérifier les réponses
:::

:::tip À retenir
Un **trunk** est une liaison qui transporte des trames de plusieurs VLAN, généralement entre deux switchs. Pour cela, chaque trame reçoit un **tag VLAN** contenant l'ID du VLAN (norme **IEEE 802.1Q**). Ces ports sont dits **tagged**. Un appareil ordinaire est branché sur un port **untagged** : le switch retire le tag avant de lui envoyer la trame.
:::

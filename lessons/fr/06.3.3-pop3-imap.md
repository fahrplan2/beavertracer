# POP3 ou IMAP ?

:::sim
url=/sims/lesson-6.3.btsim
:::

Il existe deux protocoles pour récupérer les e-mails. Dans cette simulation, **Anna utilise POP3** et **Ben utilise IMAP**.

## L'expérience

1. En mode :fa-play: **Exécuter**, envoie un e-mail de **Ben** à `anna@beaver-schule.de`.
2. Chez **Anna**, clique sur **Récupérer** dans l'application **E-mail**.
3. Ouvre des traces pour **Anna** et pour **Ben** et compare les commandes utilisées lors de la récupération.

:::quiz match
USER / PASS -> POP3 : connexion avec nom d'utilisateur et mot de passe en deux étapes
RETR -> POP3 : télécharger un message
LOGIN -> IMAP : connexion avec nom d'utilisateur et mot de passe
SELECT INBOX -> IMAP : ouvrir un dossier sur le serveur
:::

:::evaluate
Vérifier l'association
:::

## La différence

| | POP3 | IMAP |
|---|---|---|
| Port | 110 | 143 |
| Idée de base | **télécharger** les e-mails — puis généralement les supprimer du serveur | les e-mails **restent sur le serveur** et y sont gérés |
| Dossiers, lu/non lu | uniquement sur ton propre appareil | sur le serveur — identiques partout |
| Plusieurs appareils (smartphone, ordinateur portable) | peu pratique : chaque appareil a un état différent | idéal : tous les appareils voient la même boîte aux lettres |

:::note
Le programme de messagerie de BeaverTracer laisse les e-mails sur le serveur, même avec POP3. Les vrais programmes les suppriment souvent après le téléchargement — ou ne les y laissent que pendant un certain temps.
:::

:::quiz mc
Lena lit ses e-mails sur son smartphone, sa tablette et l'ordinateur portable de l'école. Que devrait-elle utiliser ?
- [ ] POP3, parce que c'est plus simple
- [x] IMAP, parce que tous les appareils voient la même boîte aux lettres sur le serveur
- [ ] SMTP, parce qu'il est conçu pour la récupération
:::

:::evaluate
Vérifier la réponse
:::

:::tip À retenir
**POP3** télécharge les e-mails du serveur vers **un seul** appareil. **IMAP** gère la boîte aux lettres **sur le serveur** — avec les dossiers et l'état « lu » pour tous les appareils à la fois. Les deux servent uniquement à la **récupération** ; l'envoi se fait toujours avec **SMTP**.
:::

# Dépannage : l'e-mail n'arrive pas

:::sim
url=/sims/lesson-6.3.4.btsim
:::

Anna signale : « Je n'arrive pas à envoyer d'e-mail à Ben ! » Voici comment tout *devrait* être configuré :

| Quoi | Valeur attendue |
|---|---|
| Serveur sortant d'Anna (SMTP) | `mail.beaver-schule.de`, port `25` |
| Enregistrement MX de `biber-mail.de` | `mail.biber-mail.de` (priorité 10) |

Trouve les erreurs et corrige-les. Ensuite, fais envoyer par Anna un e-mail à `ben@biber-mail.de`. La tâche vérifie s'il est bien arrivé dans la boîte aux lettres de Ben. (La transmission entre les serveurs de messagerie peut prendre quelques secondes.)

<details>
<summary>Astuce 1 : que dit le programme de messagerie d'Anna ?</summary>

Essaie d'envoyer un e-mail et regarde l'onglet **Journal**. Que répond le serveur ? Est-ce que ça ressemble à du SMTP ?
</details>

<details>
<summary>Astuce 2 : l'e-mail revient sous forme de message d'erreur ?</summary>

Relève le courrier d'Anna et lis le message du `MAILER-DAEMON`. Pourquoi la remise a-t-elle échoué ? Sur le PC d'Anna, vérifie avec `nslookup -type=MX biber-mail.de` si le serveur DNS connaît le serveur de messagerie compétent.
</details>

<details>
<summary>Astuce 3 : où est-ce qu'on configure ça ?</summary>

Tu configures le serveur sortant dans l'application **E-mail** d'Anna, sous **Paramètres**. Les enregistrements MX se trouvent dans le **Serveur DNS**, dans l'onglet **MX**.
</details>

:::task
title: E-mail arrivé ?
Vérifie si un e-mail se trouve dans la boîte aux lettres de Ben sur le Mailserver Biber.
check: fileExists(5, "/var/mail/ben.mbox")
:::

## Que s'est-il passé ?

:::quiz multi
Quelles affirmations sont correctes ?
- [x] Le serveur sortant d'Anna pointait vers le port 110 : c'est le service POP3 qui y répond, pas SMTP
- [x] L'enregistrement MX de `biber-mail.de` manquait : le Mailserver Schule ne trouvait aucun serveur de messagerie compétent
- [x] L'e-mail impossible à remettre est revenu sous forme de message d'erreur du `MAILER-DAEMON`
- [ ] Le mot de passe de Ben était faux
:::

:::evaluate
Vérifier la réponse
:::

:::tip À retenir
Erreurs typiques avec l'e-mail : un **serveur ou port** incorrect dans le programme de messagerie (SMTP fonctionne sur le port 25, POP3 sur le 110, IMAP sur le 143) et un **enregistrement MX** manquant ou incorrect dans le DNS. Si un serveur de messagerie ne peut pas remettre un e-mail, il le renvoie à l'expéditeur avec un message d'erreur (**bounce**).
:::

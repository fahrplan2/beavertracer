# Adresse réseau, adresse de diffusion et hôtes

Dans chaque réseau, deux adresses ont un rôle particulier :

- L'**adresse réseau** est l'adresse **la plus basse** du réseau : tous les bits de la partie hôte sont à 0. Elle désigne le réseau dans son ensemble, par ex. dans les tables de routage.
- L'**adresse de diffusion** est l'adresse **la plus haute** du réseau : tous les bits de la partie hôte sont à 1. Tout ce qui lui est envoyé parvient à tous les appareils du réseau.

Ces deux adresses ne sont **pas** attribuées à des appareils. Toutes les adresses situées entre les deux sont disponibles pour les appareils (**hôtes**).

## Un exemple simple

`192.168.0.12/24` — la partie hôte est le dernier octet :

| | Adresse |
|---|---|
| Adresse réseau (partie hôte = 0) | `192.168.0.0` |
| Adresse de diffusion (partie hôte = 255) | `192.168.0.255` |
| Plage pour les hôtes | `192.168.0.1` – `192.168.0.254` |
| Nombre d'hôtes | 254 |

## Quand la limite se trouve au milieu d'un octet

Cela se complique lorsque la longueur du préfixe n'est pas un multiple de 8. Tu convertis alors l'octet concerné dans le système binaire. Exemple : `194.9.190.12/27`.

Les trois premiers octets appartiennent entièrement à la [[n|partie réseau]] (24 bits). Du dernier octet, **3 bits** appartiennent encore à la partie réseau (24 + 3 = 27), les **5 bits** restants à la [[h|partie hôte]] :

| | dernier octet (binaire) | décimal |
|---|---|---|
| Adresse IP | [[n|000]][[h|01100]] | 12 |
| Masque de sous-réseau (`/27`) | [[n|111]][[h|00000]] | 224 |
| Adresse réseau : bits d'hôte à 0 | [[n|000]][[h|00000]] | **0** |
| Adresse de diffusion : bits d'hôte à 1 | [[n|000]][[h|11111]] | **31** |

Résultat :

- Adresse réseau : `194.9.190.0`
- Adresse de diffusion : `194.9.190.31`
- Plage pour les hôtes : `194.9.190.1` – `194.9.190.30`
- Nombre d'hôtes : 2⁵ − 2 = **30**

:::tip À retenir
**Adresse réseau :** tous les bits d'hôte à 0 (adresse la plus basse). **Adresse de diffusion :** tous les bits d'hôte à 1 (adresse la plus haute). Aucune des deux n'est attribuée à des appareils. Un réseau avec une longueur de préfixe *n* possède **2<sup>32 − n</sup> − 2** adresses utilisables pour les hôtes.
:::

:::tip Astuce : la taille de bloc
Une fois que tu as compris la méthode dans le système binaire, il existe un raccourci : **256 moins l'octet du masque** donne la taille d'un réseau dans cet octet. Avec `/27` (masque 224), cela fait 256 − 224 = **32**. Les réseaux commencent alors à 0, 32, 64, 96 … — l'adresse `.12` se trouve dans le réseau commençant à `.0`, l'adresse `.70` dans le réseau commençant à `.64`.
:::

## Les tailles de réseau les plus importantes

| Préfixe | Masque de sous-réseau | Hôtes |
|---|---|---|
| `/8` | `255.0.0.0` | 16 777 214 |
| `/16` | `255.255.0.0` | 65 534 |
| `/24` | `255.255.255.0` | 254 |
| `/25` | `255.255.255.128` | 126 |
| `/26` | `255.255.255.192` | 62 |
| `/27` | `255.255.255.224` | 30 |
| `/28` | `255.255.255.240` | 14 |
| `/29` | `255.255.255.248` | 6 |
| `/30` | `255.255.255.252` | 2 |

:::note
Le plus petit réseau couramment utilisé en pratique est le `/30` : il possède exactement deux adresses utilisables et sert souvent à relier deux routeurs. Un `/32` désigne une adresse unique — il n'est pas utilisable comme réseau, mais on le rencontre dans les tables de routage et les règles de pare-feu.
:::

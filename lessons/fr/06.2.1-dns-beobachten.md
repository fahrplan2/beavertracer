# Observer une résolution de noms

## L'expérience

1. Passe en mode :fa-play: **Exécuter**, clique sur le **Client-PC** et ouvre le :fa-globe: **Navigateur**.
2. Cette fois, ouvre `http://www.beaver-schule.de/`, avec un nom au lieu d'une adresse IP.
3. Passe en mode :fa-magnifying-glass: **Trace** et ouvre une trace pour le **Client-PC**.

Tout au début, avant même l'établissement de la connexion avec `[SYN]`, il y a deux paquets avec le protocole **DNS**.

:::quiz short
À quelle adresse IP le Client-PC envoie-t-il sa requête DNS ?
= 192.168.0.53
:::

:::quiz short
Quelle adresse IP figure dans la réponse pour `www.beaver-schule.de` ?
= 192.168.0.20
:::

:::quiz mc
Clique sur la requête DNS et déplie l'arbre des protocoles. Quel protocole de transport et quel port de destination sont utilisés ?
- [ ] TCP, port 80
- [x] UDP, port 53
- [ ] UDP, port 67
:::

:::evaluate
Vérifier les réponses
:::

Ce n'est qu'une fois que le Client-PC connaît l'adresse IP qu'il établit la connexion TCP avec le serveur web, exactement comme au chapitre 5.

:::seq
mode: text
Client-PC -> DNS-Resolver: Requête DNS | A www.beaver-schule.de?
DNS-Resolver -> Client-PC: Réponse DNS | A 192.168.0.20
:::

## Comment le PC connaît-il le serveur DNS ?

Ouvre les :fa-gear: **Paramètres IP** du **Client-PC** : le champ **Serveur DNS** contient `192.168.0.53`, c'est-à-dire l'ordinateur **DNS-Resolver**. C'est à lui que le PC envoie chaque requête de nom.

Tu peux aussi interroger directement le serveur DNS, sans navigateur. Ouvre le :fa-terminal: **Terminal** et saisis :

```
$ nslookup www.beaver-schule.de
```

`nslookup` affiche d'abord le serveur qu'il a interrogé, puis la réponse. Pour comparer, demande un nom qui n'existe pas, par exemple `nslookup gibtsnicht.beaver-schule.de`.

:::quiz mc
Que répond le serveur DNS pour le nom inconnu ?
- [ ] Une adresse IP aléatoire
- [x] `NXDOMAIN` : ce nom n'existe pas
- [ ] Rien du tout
:::

:::evaluate
Vérifier la réponse
:::

:::tip À retenir
Le **DNS** traduit des noms (par exemple `www.beaver-schule.de`) en adresses IP. Avant de pouvoir établir une connexion vers un nom, un PC interroge le **serveur DNS** indiqué dans ses paramètres IP, le plus souvent via **UDP, port 53**. Avec `nslookup`, tu peux envoyer des requêtes DNS manuellement.
:::

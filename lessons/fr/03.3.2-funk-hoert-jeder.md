## Ce qui se cache derrière

Les ondes radio se propagent dans toutes les directions. Ce qu'Anna envoie atteint donc *chaque* appareil à proximité, pas seulement le point d'accès. La radio est un **support partagé**. Normalement, la tablette de Ben ignore tout ce qui ne lui est pas destiné. Mais quiconque *veut* faire une capture peut tout lire.

| | Switch (câble) | Wi-Fi (radio) |
|---|---|---|
| Qui reçoit un unicast ? | seulement le port du destinataire | chaque appareil à portée |
| Un tiers peut-il lire les échanges ? | normalement non | oui, sans difficulté |

:::tip À retenir
La radio est un **support partagé** : tout ce qui est envoyé sur un réseau Wi-Fi peut être reçu par chaque appareil à portée. C'est pourquoi un réseau Wi-Fi doit être **chiffré** (aujourd'hui avec **WPA2** ou **WPA3**). Des inconnus peuvent alors toujours recevoir les données, mais pas les lire.
:::

:::note
BeaverTracer ne simule pas le chiffrement Wi-Fi, c'est pourquoi tu peux tout lire ici. Tu apprendras comment fonctionne le chiffrement au chapitre 8.
:::

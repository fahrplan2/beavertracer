# La table NAT

:::sim
url=/sims/lesson-7.1.btsim
:::

Quand le PC et la tablette chargent la même page web en même temps, les deux requêtes arrivent au serveur web depuis `203.0.113.2`. Comment le routeur domestique sait-il à qui une réponse est destinée ? Il tient un registre : la **table NAT**.

## L'expérience

1. Passe en mode :fa-play: **Exécution** et ouvre `http://www.beispiel.de/` sur le **PC** et sur la **Tablet**.
2. Clique sur le **Heimrouter** et ouvre l'onglet **NAT**.

Chaque ligne est une **correspondance** : le protocole, l'IP LAN et le port LAN de l'appareil du réseau domestique, ainsi que le **port WAN** que le routeur utilise pour cet appareil sur son adresse publique.

:::quiz short
Quelle IP WAN est indiquée au-dessus de la table ?
= 203.0.113.2
:::

:::quiz mc
Le PC et la tablette ont tous deux établi une connexion avec le port LAN `49152`. Quel port WAN reçoivent-ils ?
- [ ] Le même pour les deux, `49152`
- [x] Chacun un port différent, sinon le routeur ne saurait pas à qui appartient la réponse
- [ ] Aucun, le NAT ne modifie que l'adresse IP
:::

:::quiz mc
Une réponse du serveur web arrive à `203.0.113.2` avec un **port de destination** donné. Que fait le routeur domestique de ce paquet ?
- [x] Il cherche le port dans la table NAT et envoie le paquet à l'IP LAN et au port LAN correspondants
- [ ] Il envoie le paquet à tous les appareils du réseau domestique
- [ ] Il rejette le paquet
:::

:::evaluate
Vérifier les réponses
:::

C'est ici que les **ports** du chapitre 5 entrent de nouveau en jeu : comme le NAT réécrit aussi les ports, des centaines de connexions peuvent partager une même adresse. Pour être précis, on parle donc de **PAT** (*Port Address Translation*) ou de *NAT avec traduction de ports*, mais dans la vie courante, on dit quand même simplement NAT.

Voici à quoi pourrait ressembler une telle traduction, par exemple :

| | Paquet du PC (dans le réseau domestique) | le même paquet sur Internet |
|---|---|---|
| Expéditeur | `192.168.178.20 : 49152` | `203.0.113.2 : 10001` |
| Destinataire | `192.0.2.80 : 80` | `192.0.2.80 : 80` |

:::tip À retenir
Dans la **table NAT**, le routeur mémorise pour chaque connexion quel appareil (**IP LAN et port LAN**) se cache derrière quel **port WAN**. Grâce au port de destination, il attribue les réponses venant d'Internet au bon appareil. Comme les ports sont eux aussi réécrits, on parle plus précisément de **PAT**.
:::

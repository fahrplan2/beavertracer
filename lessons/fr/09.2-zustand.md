# Sans état ou avec état

Une connexion comporte toujours **deux sens** : le Lehrer-PC envoie une requête à un serveur web sur Internet, et le serveur web renvoie la page web. Un pare-feu fonctionnant selon le principe de la liste blanche doit donc laisser passer non seulement la requête, mais aussi la **réponse**.

Il existe pour cela deux types de filtres de paquets :

| | **Sans état** (*stateless*) | **Avec état** (*stateful*) |
|---|---|---|
| Fonctionnement | examine chaque paquet séparément, sans mémoire | mémorise les connexions autorisées dans une **table d'états** |
| Réponses | nécessitent une règle spécifique pour le sens retour | sont automatiquement autorisées, car elles appartiennent à une connexion connue |
| Utilisation | appareils simples, filtres très rapides | pratiquement tous les pare-feu actuels |

Dans les deux sections suivantes, tu vas voir pourquoi les filtres sans état ont du mal avec les réponses, et comment un pare-feu avec état résout ce problème.

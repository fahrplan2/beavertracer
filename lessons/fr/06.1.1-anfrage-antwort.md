Une page web se compose donc souvent de nombreux fichiers : texte, feuilles de style, images. Pour chacun d'eux, le navigateur envoie une requête distincte.

## À quoi ressemble une requête

Dans la trace, clique sur le paquet `GET / HTTP/1.1` et déplie **Hypertext Transfer Protocol**. Une requête HTTP est du texte pur :

```
GET / HTTP/1.1              ← Methode, Pfad, Version
Host: 192.168.0.20          ← Header: zusätzliche Angaben
…
                            ← Leerzeile: Ende der Anfrage
```

La réponse du serveur est construite de la même manière — avec une ligne de statut, des en-têtes, une ligne vide, puis le fichier lui-même :

```
HTTP/1.1 200 OK             ← Version, Statuscode, Text
Content-Type: text/html     ← Header: Art der Datei
Content-Length: 301         ← Header: Größe in Byte
                            ← Leerzeile
<!doctype html> …           ← die Datei selbst
```

:::seq
mode: text
Client-PC -> Server: GET / | requête HTTP
Server -> Client-PC: 200 OK | index.html
Client-PC -> Server: GET /style.css | requête HTTP
Server -> Client-PC: 200 OK | style.css
:::

## Méthodes et codes de statut

La **méthode** indique ce que veut le client :

| Méthode | Signification |
|---|---|
| **GET** | récupérer un fichier |
| **POST** | envoyer des données au serveur, p. ex. un formulaire rempli |
| **HEAD** | récupérer uniquement les en-têtes, sans le fichier |

Le **code de statut** indique comment cela s'est passé. Le premier chiffre révèle le type de réponse :

| Code | Texte | Signification |
|---|---|---|
| **200** | OK | tout va bien |
| **301** | Moved Permanently | la page a été déplacée définitivement |
| **404** | Not Found | le fichier n'existe pas |
| **405** | Method Not Allowed | cette méthode n'est pas autorisée ici |
| **500** | Internal Server Error | erreur sur le serveur |

`2xx` signifie succès, `3xx` redirection, `4xx` une erreur du client (requête incorrecte), `5xx` une erreur du serveur.

:::tip À retenir
**HTTP** fonctionne selon le **principe requête-réponse** : le client envoie une **requête** (une méthode comme `GET`, un chemin, des en-têtes), le serveur répond avec un **code de statut** (p. ex. `200 OK`, `404 Not Found`), des en-têtes et le fichier. Chaque fichier d'une page web fait l'objet d'une requête distincte.
:::

:::

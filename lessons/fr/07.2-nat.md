# NAT : plusieurs appareils, une seule adresse

:::goal
**Objectif d'apprentissage :** tu sais montrer dans le traceur comment le NAT remplace l'adresse de l'expéditeur, lire la table NAT et expliquer pourquoi les connexions venant de l'extérieur vers le réseau domestique nécessitent une redirection de port.
:::

:::sim
url=/sims/lesson-7.1.btsim
:::

Le fournisseur d'accès n'attribue normalement qu'**une seule** adresse IPv4 publique à un abonnement domestique : l'adresse WAN du routeur domestique. Tous les appareils du réseau domestique doivent se la partager. Ce mécanisme s'appelle le **NAT** (*Network Address Translation*, traduction d'adresses).

# Comparaison entre HTTP et HTTPS

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Le serveur web **www.beaver-schule.de** propose le portail des notes de l'école à la fois en HTTP et en HTTPS. Que voit un espion ?

## L'expérience

1. Passe en mode :fa-play: **Exécuter** et, sur le **Client-PC**, ouvre d'abord `http://www.beaver-schule.de/` dans le :fa-globe: **Navigateur**, puis `https://www.beaver-schule.de/`.
2. En mode :fa-magnifying-glass: **Trace**, ouvre une trace pour le **Client-PC**.
3. Cherche d'abord le paquet `HTTP/1.1 200 OK` et clique dessus. En bas, dans les détails, tu trouves le contenu de la page.

:::quiz mc
Que peut voir un espion avec **HTTP** ?
- [x] La page web complète, y compris les notes d'Anna
- [ ] Seulement l'adresse du serveur
- [ ] Rien, car HTTP fonctionne au-dessus de TCP
:::

:::quiz short
Quelle note Anna a-t-elle en mathématiques ?
= 2
:::

:::evaluate
Vérifier les réponses
:::

Passons maintenant à la partie HTTPS. Cherche le paquet `[SYN]` avec lequel le client commence la deuxième connexion.

:::quiz short
Quel est le port de destination de la connexion HTTPS (colonne **Info**, `… → ???`) ?
= 443
:::

Saisis maintenant `tls` dans le champ de filtre en haut de la trace : tu ne vois alors plus que les paquets TLS.

:::quiz mc
Qu'indique la colonne **Info** pour les paquets qui contiennent la page web ?
- [ ] `HTTP/1.1 200 OK`
- [x] `Application Data`
- [ ] `Encrypted HTML`
:::

:::quiz multi
Que peut quand même encore voir un espion avec **HTTPS** ?
- [x] Les adresses IP du client et du serveur
- [x] Que le port 443 est utilisé, donc probablement HTTPS
- [x] La quantité approximative de données transférées
- [ ] Quelle page a été consultée et ce qu'elle contient
:::

:::evaluate
Vérifier les réponses
:::

:::note
Clique sur un paquet **Application Data** : les données utiles ne sont qu'une suite d'octets apparemment aléatoires. Le traceur ne peut pas les déchiffrer : il ne connaît pas plus la clé de session qu'un attaquant.
:::

:::tip À retenir
Avec **HTTP**, n'importe quel espion peut lire la page web complète. Avec **HTTPS**, il voit seulement **qui communique avec qui** (adresses IP, port 443) et **en quelle quantité** : le contenu est chiffré dans des paquets **Application Data**.
:::

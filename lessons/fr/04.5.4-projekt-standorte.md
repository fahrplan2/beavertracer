# Projet : une entreprise sur quatre sites

:::sim
url=/sims/lesson-4.5.4.btsim
:::

Une entreprise a son siège à **Hanau** et des filiales à **Kassel**, **Gießen** et **Darmstadt**. Chaque site possède son propre réseau et son propre routeur. Tous les routeurs sont reliés par des liaisons louées à un **réseau central**, dans lequel se trouve aussi le serveur principal de l'entreprise.

## Le plan d'adressage

L'administrateur a attribué les adresses selon le schéma suivant ; elles sont déjà saisies dans la simulation :

| Réseau | Plage d'adresses |
|---|---|
| Réseau central | `10.19.0.0/24` |
| Hanau | `10.19.1.0/24` |
| Kassel | `10.19.2.0/24` |
| Gießen | `10.19.3.0/24` |
| Darmstadt | `10.19.4.0/24` |

| Appareil | dans le réseau central | dans le réseau du site |
|---|---|---|
| Server | `10.19.0.10` | — |
| Router Hanau | `10.19.0.1` | `10.19.1.1` |
| Router Kassel | `10.19.0.2` | `10.19.2.1` |
| Router Gießen | `10.19.0.3` | `10.19.3.1` |
| Router Darmstadt | `10.19.0.4` | `10.19.4.1` |
| PC du site | — | `.2` à chaque fois (p. ex. PC Kassel `10.19.2.2`) |

Sur tous les routeurs, `eth0` donne sur le réseau central et `eth1` sur le réseau du site.

## Ta mission

Pour que tous les ordinateurs de l'entreprise puissent se joindre entre eux et joindre le serveur, il manque encore deux choses :

1. **Passerelles :** configure une passerelle sur les quatre PC et sur le serveur. Les PC utilisent le routeur de leur site ; le serveur utilise le **Router Hanau**.
2. **Tables de routage :** ajoute sur les quatre routeurs les routes qui manquent encore. Chaque routeur doit connaître les réseaux des **trois autres** sites.

Teste au fur et à mesure avec `ping` et `traceroute`.

<details>
<summary>Astuce : à quoi ressemble une route ici ?</summary>

Un exemple pour le **Router Kassel** : les paquets destinés à Gießen (`10.19.3.0/24`) sont envoyés au Router Gießen, à son adresse dans le réseau central, donc **Prochain saut** `10.19.0.3`, **Iface** `eth0`. Sur ce modèle, chaque routeur a besoin de trois routes.
</details>

# HTTP : pages web

:::goal
**Objectif d'apprentissage :** Tu sais décrire la structure d'une requête et d'une réponse HTTP, expliquer les principales méthodes et les principaux codes de statut, et envoyer toi-même une requête HTTP à la main.
:::

:::sim
url=/sims/lesson-6.1.btsim
:::

Le **Hypertext Transfer Protocol** (**HTTP**) est le langage dans lequel les navigateurs et les serveurs web communiquent entre eux. Le serveur héberge le site web de la **Beaver-Schule** : une page d'accueil, une page de contact et une feuille de style pour la mise en forme.

# DNS: ismijiet minflok numri

:::goal
**Għan tat-tagħlim:** Tkun tista' tispjega kif id-DNS jittraduċi l-ismijiet f'IP addresses, kif l-ismijiet huma organizzati b'mod ġerarkiku, toħloq entrata int stess u ssib żbalji tipiċi tad-DNS.
:::

:::sim
url=/sims/lesson-6.2.btsim
:::

Ftit li xejn hemm min jiftakar IP addresses — imma ismijiet bħal `www.beaver-schule.de` iva. It-traduzzjoni ssir mid-**Domain Name System** (**DNS**), tip ta' direttorju tat-telefon dinji tal-internet.

Fuq il-workspace issa hemm network kemmxejn akbar: apparti l-**Client-PC** u l-**Webserver** hemm erba' **DNS servers**. Għaliex hemm tant minnhom, tarah fit-tieni paġna minn din.

# Troubleshooting: il-mejl ma jaslux

:::sim
url=/sims/lesson-6.3.4.btsim
:::

Anna tirraporta: "Ma nistax nibgħat mejl lil Ben!" Hekk *suppost* ikun issettjat:

| X'inhu | Suppost |
|---|---|
| Il-Postausgang ta' Anna (SMTP) | `mail.beaver-schule.de`, port `25` |
| MX-Eintrag ta' `biber-mail.de` | `mail.biber-mail.de` (prijorità 10) |

Sib l-iżbalji usewwihom. Imbagħad ibgħat mejl minn Anna lil `ben@biber-mail.de` — it-task jiċċekkja jekk waslitx fil-mailbox ta' Ben. (It-trasferiment bejn il-mail servers jista' jieħu ftit sekondi.)

<details>
<summary>Suġġeriment 1: X'jgħid il-programm tal-e-mail ta' Anna?</summary>

Ipprova ibgħat mejl u ħares fit-tab **Protokoll**. X'inhu jwieġeb is-server — jinstema' bħal SMTP?
</details>

<details>
<summary>Suġġeriment 2: Il-mejl jiġi lura bħala messaġġ ta' żball?</summary>

Ġib il-posta ta' Anna u aqra l-messaġġ mingħand `MAILER-DAEMON`. Għaliex falliet il-kunsinna? Fuq il-PC ta' Anna uża `nslookup -type=MX biber-mail.de` biex tara jekk id-DNS server jafx liema mail server huwa responsabbli.
</details>

<details>
<summary>Suġġeriment 3: Fejn jiddaħħal dan?</summary>

Il-Postausgang tissettjah fl-app **E-Mail** ta' Anna taħt **Einstellungen**. L-MX entries issibhom fid-**DNS-Server** fit-tab **MX**.
</details>

:::task
title: Il-mejl wasal?
Jiċċekkja jekk hemmx mejl fil-mailbox ta' Ben fuq il-Mailserver Biber.
check: fileExists(5, "/var/mail/ben.mbox")
:::

## X'kien qed jiġri?

:::quiz multi
Liema dikjarazzjonijiet huma veri?
- [x] Il-Postausgang ta' Anna kien jindika lejn port 110 — hemmhekk iwieġeb is-servizz POP3, mhux SMTP
- [x] Kien nieqes l-MX-Eintrag għal `biber-mail.de` — il-Mailserver Schule ma sab ebda mail server responsabbli
- [x] Il-mejl li ma setax jiġi kkunsinnat irritorna bħala messaġġ ta' żball mingħand `MAILER-DAEMON`
- [ ] Il-password ta' Ben kienet ħażina
:::

:::evaluate
Iċċekkja t-tweġiba
:::

:::tip Punt importanti
Żbalji tipiċi fl-e-mail: **server jew port** ħażin fil-programm tal-e-mail (SMTP jaħdem fuq port 25, POP3 fuq 110, IMAP fuq 143) u **MX-Eintrag** nieqes jew ħażin fid-DNS. Jekk mail server ma jistax jikkunsinna mejl, jibgħatu lura lis-sender b'messaġġ ta' żball (**bounce**).
:::

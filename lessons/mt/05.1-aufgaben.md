# X'għandha tagħmel is-transport layer?

:::sim
url=/sims/lesson-5.1.btsim
:::

Fuq is-**Server** qed jaħdmu żewġ servizzi fl-istess ħin: **web server** u **echo service** żgħir, li jibgħat lura minnufih kull messaġġ li jirċievi. B'żewġ esperimenti ssib x'ma jistax jagħmel l-IP waħdu.

## Esperiment 1: Żewġ programmi fl-istess ħin

1. Aqleb għall-Modalità ta' tħaddim :fa-play: **Ħaddem** u kklikkja fuq il-**Client-PC**.
2. Iftaħ il-:fa-globe: **Browser** u ċempel `http://192.168.0.20/`.
3. Kklikkja fuq **Zurück** fin-naħa ta' fuq tat-tieqa u iftaħ is-**Simple TCP Client**. Imla `192.168.0.20` f'**Host** u `5000` f'**Port** u kklikkja fuq **Ikkonnettja**.
4. Aqleb għall-Modalità :fa-magnifying-glass: **Traċċa** u b'**+** iftaħ trace għall-**Client-PC**, port `eth0`.

Kklikkja fuq packet tal-browser (eż. `GET /`) u fuq wieħed tat-TCP client u ftaħ **Internet Protocol Version 4** f'kull wieħed.

:::quiz mc
Liema IP addresses għandhom il-packets tal-browser u tat-TCP client?
- [x] L-istess għat-tnejn: minn `192.168.0.10` lejn `192.168.0.20`
- [ ] Il-browser juża destination IP address differenti mit-TCP client
- [ ] Il-packets tat-TCP client m'għandhomx IP address
:::

:::quiz mc
Allura d-destination IP address hija biżżejjed biex is-server jaf jekk packet jappartjenix lill-web server jew lill-echo service?
- [ ] Iva
- [x] Le — iż-żewġ packets għandhom l-istess destination IP address
:::

Xi ħaġa oħra trid issaħħaħ id-differenza bejn iż-żewġ konnessjonijiet. Ħares lejn il-kolonna **Info** tal-packets bi `[SYN]` — dak huwa l-ewwel packet ta' kull konnessjoni:

:::quiz short
Liema numru jinsab wara l-vleġġa `→` fil-każ tal-**browser**?
= 80
:::

:::quiz short
U fil-każ tat-**TCP client**?
= 5000
:::

:::evaluate
Iċċekkja t-tweġibiet
:::

Dwar dawn in-numri — il-**ports** — se tgħallem aktar fit-taqsima 5.3. Għalissa biżżejjed tkun taf: it-transport layer biss jippermetti li diversi programmi jikkomunikaw fl-istess ħin permezz ta' IP address *waħda* u li kull packet jasal fil-programm it-tajjeb. Dan jissejjaħ **multiplexing**.

## Esperiment 2: Meta packet jintilef

1. Aqleb għall-Modalità ta' tħaddim :fa-play: **Ħaddem** u kklikkja fuq il-**cable** bejn il-Client-PC u s-Server.
2. Fit-tieqa **Verbindung** poġġi **Konfigurierter Paketverlust** fuq `25%`.
3. Fuq il-**Client-PC** iftaħ it-:fa-terminal: **Terminal** u ibgħat sitt pings:
   ```
   $ ping -c 6 192.168.0.20
   ```
   Dan idum madwar nofs minuta — stenna sakemm tidher l-istatistika.

:::quiz mc
X'jiġri?
- [ ] Is-sitt pings kollha jiġu risposti
- [x] Xi pings jibqgħu mingħajr tweġiba — u ħadd ma jibgħathom mill-ġdid
- [ ] Pings li jintilfu jiġu ripetuti awtomatikament sakemm jaslu
:::

:::evaluate
Iċċekkja t-tweġiba
:::

Għal ping dan mhuwiex problema — il-għan tiegħu huwa preċiżament li juri jekk xi ħaġa tintilifx. Imma f'websajt, f'e-mail jew f'download biċċa nieqsa tkun fatali: il-fajl ikun mgħawweġ.

## L-erba' kompiti tat-transport layer

| Kompitu | X'jfisser |
|---|---|
| **Multiplexing** | Diversi programmi u konnessjonijiet jaqsmu IP address waħda; kull packet jasal fil-programm it-tajjeb. |
| **Connection setup** | Qabel ma jgħaddu d-dejta, iż-żewġ naħat jaqblu li se jitkellmu ma' xulxin. |
| **Trasmissjoni affidabbli** | Ir-receiver jikkonferma dak li wasal. Dak li jkun nieqes jerġa' jinbagħat, u l-ordni terġa' tiġi stabbilita. |
| **Connection teardown** | Fl-aħħar, iż-żewġ naħat jagħlqu l-konnessjoni b'mod ordnat. |

:::tip Punt importanti
It-**transport layer** (layer 4) jizgura li d-dejta tasal fil-**programm** it-tajjeb (**multiplexing**). Il-protokoll **TCP** jizgura barra minn hekk li tasal **kollha** u fl-**ordni t-tajba** — b'connection setup, acknowledgements, retransmission u connection teardown.
:::

:::quiz match
Fuq PC jaħdmu fl-istess ħin browser, programm tal-mail u messenger. -> Multiplexing
Qabel ma jgħaddu d-dejta, iż-żewġ naħat jaċċertaw li l-oħra lesta. -> Connection setup
Parti minn fajl ma tasalx u terġa' tinbagħat. -> Trasmissjoni affidabbli
Wara d-download, iż-żewġ naħat jerħu l-konnessjoni mill-ġdid. -> Connection teardown
:::

:::

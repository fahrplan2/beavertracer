# Kollox flimkien: x'jiġri meta tiftaħ websajt?

:::goal
**Għan tat-tagħlim:** Tista' tispjega pass pass liema protokolli f'liema layer huma involuti meta laptop li għadu kemm ġie mixgħul jiftaħ websajt.
:::

:::sim
url=/sims/lesson-6.5.btsim
:::

Issa jingabar flimkien dak kollu li tgħallimt f'dan il-kors. Mal-switch hemm konnessi **DHCP-Server**, **DNS-Server**, **Webserver** u **Laptop** li għadu kemm ġie mixgħul — għad m'għandux IP address u huwa ssettjat fuq DHCP.

## L-esperiment

1. Aqleb għal Modalità ta' tħaddim :fa-play: **Ħaddem** u stenna ftit sekondi.
2. Ikklikkja fuq il-**Laptop**, iftaħ il-:fa-globe: **Browser** u ikteb `http://www.beaver-schule.de/`.
3. Fil-modalità :fa-magnifying-glass: **Traċċa**, iftaħ trace għal-**Laptop**. Hawnhekk hemm l-istorja kollha — mill-ewwel packet.

Poġġi l-passi fl-ordni t-tajba, kif jidhru fit-trace:

:::quiz match
1. Pass -> DHCP: Il-laptop jieħu IP address, gateway u DNS server
2. Pass -> ARP: Il-laptop jistaqsi għall-MAC address tad-DNS server
3. Pass -> DNS: Il-laptop jistaqsi għall-IP address ta' www.beaver-schule.de
4. Pass -> ARP: Il-laptop jistaqsi għall-MAC address tal-web server
5. Pass -> TCP: Three-way handshake mal-web server
6. Pass -> HTTP: GET / u t-tweġiba 200 OK
:::

:::evaluate
Iċċekkja l-ordni
:::

U taħt kollox hemm l-**IP** (layer 3), li jindirizza kull wieħed minn dawn il-packets, u l-**Ethernet** (data link layer, layer 2), li jwasslu sal-apparat li jmiss. Kieku l-web server kien f'network ieħor, kien jiżdied ukoll ir-**router**: allura l-laptop kien jistaqsi għall-MAC address tal-**gateway** tiegħu, mhux għal dak tal-web server.

:::quiz mc
Għaliex il-laptop ma jistax jibgħat it-talba lid-DNS qabel id-DHCP?
- [ ] Għax id-DNS jaħdem biss fuq TCP
- [x] Għax biss permezz tad-DHCP jikseb IP address tiegħu stess u jsir jaf liema DNS server huwa responsabbli
- [ ] Għax id-DNS server jibda biss wara d-DHCP server
:::

:::quiz mc
Kemm konnessjonijiet TCP jistabbilixxi l-browser mal-web server — u għaliex?
- [ ] Waħda, għal kollox flimkien
- [x] Tnejn — waħda għall-paġna u waħda għall-istylesheet
- [ ] Xejn, l-HTTP ma jeħtieġx TCP
:::

:::tip Punt importanti
Wara klikk wieħed biss, il-layers kollha jaħdmu flimkien: id-**DHCP** jagħti s-settings bażiċi, l-**ARP** isib il-MAC addresses fil-network lokali, id-**DNS** jittraduċi l-isem, it-**TCP** jistabbilixxi konnessjoni affidabbli u l-**HTTP** iġib il-paġna — kollox ippakkjat f'**IP** packets u **Ethernet** frames.
:::

B'hekk issa tista' tispjega kif tinfetaħ websajt mill-ewwel packet sa l-aħħar wieħed. Fl-aħħar tal-kapitlu jiġi biss ħarsa qasira lejn protokolli oħra. Fil-kapitli li jmiss se nitkellmu dwar il-home network b'NAT, dwar is-sigurtà u l-encryption — u allura dwar il-mistoqsija kif tipprevjeni li xi ħadd jaqra dawn il-packets kollha.

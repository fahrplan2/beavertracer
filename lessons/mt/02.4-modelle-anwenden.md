# Napplikaw il-mudelli

Qabbel il-protokolli mill-esperiment tal-bidu tal-kapitlu mal-layer OSI tagħhom:

:::quiz match
Ethernet -> Layer 2 — Data link
IPv4 -> Layer 3 — Network
TCP -> Layer 4 — Transport
HTTP -> Layer 7 — Application
:::

:::evaluate
Iċċekkja t-tqabbil
:::

U fl-aħħar, l-ismijiet tal-unitajiet tad-data:

:::quiz match
Frame -> Layer 2 — Data link
Packet -> Layer 3 — Network
Segment -> Layer 4 — Transport
:::

:::evaluate
Iċċekkja t-tqabbil
:::

B'hekk issa għandek l-għodda biex tqiegħed il-protokolli fil-post t-tajjeb tagħhom fil-ġejjieni. Mill-kapitlu li jmiss 'il quddiem se nsegwu l-layers wieħed wara l-ieħor — nibdew bil-layer 2 u bil-mistoqsija dwar kif fil-fatt switch jaf fejn għandu jibgħat packet.

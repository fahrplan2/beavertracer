# Il-home network: router u NAT

:::goal
**Għan tat-tagħlim:** Tista' tsemmi x-xogħlijiet ta' home router, twaqqaf home router, tispjega kif NAT iġib ħafna devices fuq l-internet permezz ta' indirizz pubbliku wieħed, u twaqqaf u tittestja port forward.
:::

:::osi 3
:::

:::sim
url=/sims/lesson-7.1.btsim
:::

Id-dar jikbru malajr għal għaxar devices jew aktar fin-network: mowbajls, laptops, televiżjoni, game console, speakers. Kollha jiksbu indirizzi bħal `192.168.178.20` — minn range **privat** li ma jiġix forwarded fl-internet xejn (kapitolu 4.2.2). U minkejja dan, kull wieħed minn dawn id-devices jaslu fl-internet.

Dan isir possibbli minn kaxxa żgħira li ma tidhirx: il-**home router**. Fuq il-workspace tara fuq ix-xellug home network b'PC u tablet, fuq il-lemin "l-internet" — ir-routers ta' provider, DNS server u l-web server `www.beispiel.de`.

:::note
L-indirizzi pubbliċi f'dan il-kapitolu (`203.0.113.…`, `198.51.100.…`, `192.0.2.…`) huma riżervati għal eżempji u materjal tat-tagħlim — eżattament bħal `2001:db8::` fl-IPv6.
:::

# HTTP bl-idejn

:::sim
url=/sims/lesson-6.1.btsim
:::

Jekk HTTP huwa test sempliċi — nistgħu allura nitkellmu wkoll aħna stess ma' web server, mingħajr ebda browser? Iva: b'`telnet` tibni konnessjoni TCP ma' kull port li trid u tittajpja t-test int stess.

## L-esperiment

1. Aqleb għall-Modalità ta' tħaddim u iftaħ it-:fa-terminal: **Terminal** fuq il-**Client-PC**.
2. Ikkonnettja mal-port 80 tas-server:
   ```
   $ telnet 192.168.0.20 80
   ```
3. Ittajpja t-talba linja b'linja — u agħlaqha b'**linja vojta** (sempliċement agħfas **Enter** darba oħra):
   ```
   GET /kontakt.html HTTP/1.1
   Host: 192.168.0.20

   ```

Is-server iwieġeb b'status line, headers u l-paġna tal-kuntatt — bħala test, eżattament kif il-browser jirċevihom.

:::quiz mc
Kif jaf is-server li t-talba tiegħek spiċċat?
- [ ] Minn kmand speċjali `END`
- [x] Mil-linja vojta
- [ ] Wara ċertu żmien
:::

:::quiz short
X'valur hemm fit-tweġiba fl-header `Content-Type`? (is-sehem l-ewwel biss, qabel il-`;`)
= text/html
:::

:::evaluate
Iċċekkja t-tweġibiet
:::

## Ipprovoka żbalji

għodda aktar komda hija `curl`: tagħmel it-talba għalik. B'`-v` (*verbose*, dettaljat) turi dak kollu li jgħaddi 'l hawn u 'l hemm — il-linji b'`>` intbagħtu minn `curl`, il-linji b'`<` waslu mis-server.

Ipprova:

```
$ curl -v http://192.168.0.20/gibtsnicht.html
$ curl -X POST -d name=Anna http://192.168.0.20/
```

:::quiz short
Liema status code tikseb għal `/gibtsnicht.html`?
= 404
:::

:::quiz short
U liema għat-talba bil-metodu `POST`?
= 405
:::

:::evaluate
Iċċekkja t-tweġibiet
:::

:::note
Il-web server fi BeaverTracer jista' jwassal biss fajls — għalhekk jippermetti biss `GET` u `HEAD`. Web servers veri jirċievu, per eżempju, formoli b'`POST` u jgħaddu d-data lil programm.
:::

:::tip Punt importanti
Ħafna protokolli tal-application layer huma **bbażati fuq it-test** — HTTP, imma wkoll SMTP, POP3 u IMAP. Għalhekk tista' titkellem magħhom bl-idejn b'`telnet` u taqrahom fit-Traċċa. Dan huwa prattiku għat-troubleshooting — imma wkoll problema ta' sigurtà: kull min jirreġistra t-traffiku jista' jaqra kollox. Kif l-encryption (HTTPS) tgħin, titgħallem fil-kapitolu 8.
:::

# Ftuħ u osserva paġna web

F'din il-parti ma tibni xejn int stess: fuq il-workspace hemm simulazzjoni lesta b'**Client-PC** u **Webserver**.

## Ftuħ il-paġna

1. Aqleb għall-modalità :fa-play: **Ħaddem**.
2. Fuq il-**Client-PC**, iftaħ l-app :fa-globe: **Browser** u daħħal l-indirizz tal-web server: `http://192.168.0.20/`.
3. Aqleb għall-modalità :fa-magnifying-glass: **Traċċa** u bil-**+** iftaħ trace għall-**Client-PC**, port `eth0` — eżattament bħal fil-ping.

:::note
Għal ftuħ ta' paġna waħda, dawn huma ħafna packets b'mod sorprendenti — ħafna aktar milli fil-ping. Li tġib paġna web huwa proċess f'ħafna stadji, mhux azzjoni waħda.
:::

## Aqra l-lista tal-packets

Għadek m'għandekx bżonn tkun taf eżattament x'jagħmel kull protokoll. Dak kollu li għandek bżonn għall-mistoqsijiet li ġejjin jinsab fil-kolonni **Protokoll** u **Info**.

:::quiz mc
Liema protokoll jinsab fil-quċċata tal-lista?
- [x] ARP
- [ ] TCP
- [ ] HTTP
:::

:::quiz short
Għodd: kemm hemm packets **TCP** qabel l-ewwel packet **HTTP**?
= 3
= tlieta
:::

:::quiz mc
Xi tweġibha l-web server lit-talba tal-browser? Ħares fil-kolonna Info tat-tieni packet HTTP.
- [ ] GET / HTTP/1.1
- [x] HTTP/1.1 200 OK
- [ ] 404 Not Found
:::

:::evaluate
Iċċekkja t-tweġibiet
:::

## Semmi l-protokolli involuti

Mill-osservazzjonijiet tiegħek issa tista' taqra liema protokoll kien responsabbli għal xiex.

:::tip Suġġeriment
Aqra mill-ġdid il-kolonni **Info**: `Who has …?`, `[SYN]`, `[SYN, ACK]`, `[ACK]`, `GET /` u `200 OK` kważi jgħidulek kollox.
:::

:::quiz match
ARP -> Isaqsi lil kulħadd fin-network: "Min għandu l-IP address 192.168.0.20?"
TCP -> Jibni connection b'tliet packets qosra qabel ma jiċċirkolaw id-data
HTTP -> Jitlob il-paġna web (GET) u jgħaddiha lura (200 OK)
:::

:::evaluate
Iċċekkja t-tqabbil
:::

:::tip Punt importanti
Ftuħ ta' paġna web isir fi stadji: l-ewwel **issib** is-server fin-network (ARP), imbagħad **tibni** connection (TCP), imbagħad **titlob u tgħaddi** l-paġna (HTTP) — u fl-aħħar **tagħlaq** il-connection mill-ġdid (il-packets TCP b'`[FIN]` fl-aħħar tal-lista).
:::

:::note
Din id-darba daħħalt l-IP address tas-server direttament, u għalhekk **DNS** (it-"traduzzjoni" ta' ismijiet bħal `www.beispiel.de` f'IP address) għadu ma ntużax. Dan se nirranġawh fil-kapitolu 6.
:::

Innutajt li l-protokolli fl-istruttura tal-packet għandhom immarkar bil-kuluri b'numri? X'inhi t-tifsira ta' dan se nispjegawha fil-kapitolu 2. Hemmhekk naraw kif nikklassifikaw il-ħafna protokolli b'mod sistematiku — bil-mudell ta' referenza OSI u dak TCP/IP. B'hekk il-kapitolu 1 tlesta.

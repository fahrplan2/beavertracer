# Attakk: DNS spoofing

:::sim
url=/sims/lesson-8.3.5.btsim
:::

Anna tixtieq tiftaħ l-online banking tagħha tal-**Biberbank** fuq il-**Client-PC**. Dak li hi ma tafx: xi ħadd kiseb aċċess għad-**DNS-Server** u biddel entrata.

Fuq il-workspace tara l-web server veru **www.biberbank.de** u l-kompjuter ta' **Angreifer** (attakkant). Fuqu qed taħdem kopja tal-websajt tal-bank.

## Parti 1: Mingħajr encryption

Aqleb għall-Modalità ta' tħaddim (:fa-play: **Ħaddem**) u fuq il-**Client-PC** iftaħ `http://www.biberbank.de/` fil-:fa-globe: **Browser**.

:::quiz mc
X'tara?
- [x] Il-paġna tal-login tal-Biberbank, mingħajr ebda twissija
- [ ] Twissija li l-paġna hi falza
- [ ] Messaġġ ta' żball
:::

:::evaluate
Iċċekkja t-tweġiba
:::

Kollox jidher normali. Imma ma liema server qed jitkellem tassew il-browser? Iftaħ it-:fa-terminal: **Terminal** fuq il-Client-PC:

```
$ nslookup www.biberbank.de
```

:::quiz short
Liema IP address jagħti d-DNS-Server għal `www.biberbank.de`?
= 192.168.0.66
:::

:::quiz mc
Lil min jappartjeni dan l-indirizz? (Fil-Modalità ta' editjar ikklikkja fuq l-apparati jew ħares lejn l-:fa-gear: **IP Settings** tagħhom.)
- [ ] Lill-web server veru tal-Biberbank
- [x] Lill-attakkant
- [ ] Lid-DNS-Server
:::

:::evaluate
Iċċekkja t-tweġibiet
:::

Kieku Anna daħlet in-numru tal-kont u l-PIN issa, kienu jispiċċaw direttament għand l-attakkant. Fil-każ ta' **HTTP** hi **m'għandha ebda ċans** tinduna bl-frodi: il-linja tal-indirizz turi l-isem t-tajjeb u l-paġna tidher vera.

## Parti 2: Bil-HTTPS

Issa iftaħ `https://www.biberbank.de/`.

:::quiz mc
X'jiġri?
- [ ] Il-paġna falza tidher bil-lucchetto
- [x] Il-browser iwissi: iċ-certificate inħareġ għal isem differenti
- [ ] Tidher il-paġna vera tal-Biberbank
:::

:::quiz short
Għal liema isem inħareġ iċ-certificate tal-attakkant (mingħajr `CN=`)?
= www.biber-gewinnspiel.de
:::

:::evaluate
Iċċekkja t-tweġibiet
:::

L-attakkant għandu anke certificate **veru** minn CA fdata — iżda għad-dominju tiegħu stess `www.biber-gewinnspiel.de`. Certificate għal `www.biberbank.de` ma jibqgħax minn ebda CA, għax dan id-dominju mhuwiex tiegħu. U mingħajr l-**private key** tal-Biberbank ma jistax jużah anke ċ-certificate veru tagħha: fil-handshake ikollu jsign-ja bih is-Server Key Exchange.

:::quiz multi
Minn xiex jipproteġi l-HTTPS hawnhekk — u minn xiex le?
- [x] L-HTTPS jikxef li s-server mhuwiex dak veru
- [ ] L-HTTPS jipprevjeni li d-DNS-Server jiġi falsifikat
- [x] L-HTTPS jgħin biss jekk l-utent jieħu t-twissija bis-serjetà
- [ ] Bl-HTTPS il-paġna falza mhijiex aċċessibbli xejn
:::

:::evaluate
Iċċekkja t-tweġibiet
:::

## Parti 3: Irranġa d-DNS-Server

Iftaħ id-**DNS-Server** u ikkoreġi l-entrata għal `www.biberbank.de`. L-indirizz t-tajjeb issibu fl-:fa-gear: **IP Settings** tal-web server **www.biberbank.de**. Tinsiex tikklikkja fuq **Ħifxi**.

:::note
Il-Client-PC jiftakar it-tweġibiet tad-DNS għal ftit żmien, biex ma jkollux għalfejn jistaqsi mill-ġdid kull darba (**DNS-Cache**). Kemm idum, jidher fil-kolonna **TTL** (*Time to Live*) f'sekondi. Jekk `nslookup` jagħti l-indirizz l-qadim direttament wara l-korrezzjoni tiegħek, stenna li tgħaddi t-TTL u erġa' pprova.
:::

:::task
title: Il-Biberbank terġa' hi vera?
Jiċċekkja jekk il-Client-PC isolvix www.biberbank.de għall-indirizz t-tajjeb u jistax jiġbed il-paġna permezz tal-HTTPS mingħajr twissija.
check: resolves(2, "www.biberbank.de", "192.168.0.30")
check: httpsOk(2, "https://www.biberbank.de/")
:::

:::note
Fil-ħajja reali attakkant rarament jifalsifika d-DNS-Server innifsu. Aktar spiss jidħol bit-tweġibiet tiegħu f'WLAN pubbliku, jibdel is-settings ta' home router jew iħajjar b'indirizz li jixbah, bħal `www.biberbank-login.de` (**phishing**). Kontra isem li jinstema' simili l-HTTPS ukoll ma jgħinx — l-attakkant jirċievi certificate validu għalih. Għalhekk: aqra l-indirizz sewwa!
:::

:::tip Punt importanti
F'**DNS spoofing** id-DNS-Server jagħti għal isem l-indirizz ta' attakkant. Fil-każ ta' **HTTP** ma tinduna b'xejn. Fil-każ ta' **HTTPS** iċ-certificate tal-attakkant ma jaqbilx mal-isem li ġie mitlub, u l-browser **iwissi** — għax ebda CA ma toħroġ certificate għal dominji barranin, u l-attakkant m'għandux il-private key tas-server veru.
:::

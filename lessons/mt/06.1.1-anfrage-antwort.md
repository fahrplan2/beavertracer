## Kif tidher talba

Ikklikkja fuq il-packet `GET / HTTP/1.1` fit-trace u iftaħ **Hypertext Transfer Protocol**. HTTP request huwa test sempliċi:

```
GET / HTTP/1.1              ← Methode, Pfad, Version
Host: 192.168.0.20          ← Header: zusätzliche Angaben
…
                            ← Leerzeile: Ende der Anfrage
```

It-tweġiba tas-server hija mibnija bl-istess mod — b'status line, headers, linja vojta u warajhom il-fajl innifsu:

```
HTTP/1.1 200 OK             ← Version, Statuscode, Text
Content-Type: text/html     ← Header: Art der Datei
Content-Length: 301         ← Header: Größe in Byte
                            ← Leerzeile
<!doctype html> …           ← die Datei selbst
```

:::seq
mode: text
Client-PC -> Server: GET / | HTTP-Anfrage
Server -> Client-PC: 200 OK | index.html
Client-PC -> Server: GET /style.css | HTTP-Anfrage
Server -> Client-PC: 200 OK | style.css
:::

## Methods u status codes

Il-**method** tgħid x'jixtieq il-client:

| Method | Tifsira |
|---|---|
| **GET** | jingħalaq fajl (jinġieb fajl) |
| **POST** | jintbagħtu data lis-server, eż. formola mimlija |
| **HEAD** | jinġiebu biss il-headers, mingħajr il-fajl |

L-**status code** jgħid kif mar it-talba. L-ewwel ċifra tgħarraf it-tip ta' tweġiba:

| Code | Test | Tifsira |
|---|---|---|
| **200** | OK | kollox tajjeb |
| **301** | Moved Permanently | il-paġna ngħatat post ġdid b'mod permanenti |
| **404** | Not Found | il-fajl ma jeżistix |
| **405** | Method Not Allowed | dan il-method mhuwiex permess hawn |
| **500** | Internal Server Error | żball fuq is-server |

`2xx` ifisser suċċess, `3xx` redirect, `4xx` żball tal-client (talba ħażina), `5xx` żball tas-server.

:::tip Punt importanti
L-**HTTP** jaħdem bil-**prinċipju ta' talba u tweġiba**: il-client jibgħat **talba** (method bħal `GET`, path, headers), is-server iwieġeb bi **status code** (eż. `200 OK`, `404 Not Found`), headers u l-fajl. Għal kull fajl ta' paġna web hemm talba separata.
:::

:::

# Hash values: il-marka tas-swaba' tad-data

:::sim
url=/sims/lesson-8.1.3.btsim
:::

**Hash function** tikkalkula minn kwantità arbitrarja ta' data (sentenza, dokument, film sħiħ) sekwenza qasira ta' karattri b'tul fiss: il-**hash value**. Taħdem bħal **marka tas-swaba'**: data identika dejjem tagħti l-istess hash value, u data differenti tagħti waħda differenti.

Il-hash function li tintuża llum il-ġurnata hija **SHA-256**. Il-hash value tagħha dejjem ikollha tul ta' 256 bit, jiġifieri 64 karattru bħala numru hexadecimal.

## L-esperiment

Fuq il-**PC**, fil-folder `/home`, hemm tliet fajls b'kuntratt żgħir tal-bejgħ. Qleb għall-modalità ta' tħaddim :fa-play: **Ħaddem**, iftaħ it-:fa-terminal: **Terminal** fuq il-**PC** u ittajpja:

```
$ cd /home
$ cat vertrag.txt vertrag-kopie.txt vertrag-neu.txt
$ sha256sum vertrag.txt vertrag-kopie.txt vertrag-neu.txt
```

:::

:::

## Karatteristiċi ta' hash function

| Karatteristika | Tifsira |
|---|---|
| **tul fiss** | Ma jimportax kemm hi kbira d-data: il-hash value dejjem ikollha l-istess tul. |
| **univoka** | Data identika dejjem tagħti l-istess hash value. |
| **effett ta' valanga** | Anke l-iżgħar bidla tagħti hash value totalment differenti. |
| **funzjoni unidirezzjonali** | Mill-hash value **ma jistax** jerġa' jiġi kkalkulat id-data. |
| **reżistenti għall-kolliżjonijiet** | Fil-prattika huwa impossibbli li ssib żewġ fajls differenti bl-istess hash value. |

Hash function **mhix encryption**: m'hemmx ċavetta u m'hemmx decryption. Isservi għal skop ieħor: l-**integrità**.

## Għal xiex jinħtieġu?

- **Verifika tad-downloads:** Ħafna websajts jagħtu, flimkien ma' fajl, il-valur SHA-256 tiegħu. Jekk il-hash value tal-fajl li niżżilt taqbel miegħu, il-fajl ma nbidilx matul it-triq.
- **Ħażna tal-passwords:** Websajts tajbin ma jaħżnux il-password tiegħek, iżda biss hash value tagħha. Meta tidħol, jitqabbel il-hash value ta' dak li ktibt. Jekk id-database tinsteraq, il-ħalliel xorta ma jkunx jaf il-passwords.
- **Firem diġitali:** Minflok dokument sħiħ, jiġi ffirmat biss il-hash value tiegħu. Aktar dwar dan fit-taqsima li jmiss.

:::tip Punt importanti
**Hash function** (eż. **SHA-256**) tikkalkula minn data arbitrarja **hash value** b'tul fiss, jiġifieri **marka tas-swaba'**. Anke l-iżgħar bidla tagħti hash value totalment differenti, u mill-hash value ma tistax terġa' tiġi kkalkulata d-data. Il-hash values jiżguraw l-**integrità** tad-data.
:::

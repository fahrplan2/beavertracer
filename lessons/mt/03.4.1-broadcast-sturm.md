# Il-broadcast storm

:::sim
url=/sims/lesson-3.4.1.btsim
:::

Tliet switches (A, B, C) huma konnessi f'ring. **Anna** (`192.168.0.10`) hija konnessa mas-switch A, u **Ben** (`192.168.0.11`) mas-switch B.

## L-esperiment

1. Aqleb għall-:fa-play: **Modalità ta' tħaddim**, iftaħ it-:fa-terminal: **Terminal** fuq **Anna** u agħmel ping lil Ben:
   ```
   $ ping 192.168.0.11
   ```
2. Agħlaq it-tieqa t'Anna u ħares lejn il-workspace għal xi ħin: il-packets jduru bla waqfien mar-ring.
3. Aqleb għall-:fa-magnifying-glass: **Traċċa** u bil-**+** iftaħ trace għal **Ben**, port `eth0`. Fuq nett fuq il-lemin tara kemm packets ġew irreġistrati s'issa.
4. Aqleb ftit drabi 'l hawn u 'l hemm bejn **Ħaddem** u **Traċċa** u żomm għajnejk fuq in-numru.

:::quiz mc
X'tara fil-lista tal-packets ta' Ben?
- [ ] Il-pings t'Anna u t-tweġibiet ta' Ben, bħas-soltu
- [x] Dejjem l-istess ARP request "Who has 192.168.0.11?" — u n-numru tal-packets dejjem jikber
- [ ] L-ebda ħaġa, ir-ring jibblokka kollox
:::

:::quiz mc
U x'jirrapporta t-Terminal t'Anna?
- [ ] Il-pings kollha jaslu
- [x] L-ebda ping ma jasal
:::

:::evaluate
Iċċekkja t-tweġibiet
:::

## X'hemm warajh

L-ARP request t'Anna hija broadcast. Is-switch A jibgħatha lill-ports kollha — jiġifieri lis-switch B *u* lis-switch C. It-tnejn jibagħtuha mill-ġdid lill-ports kollha tagħhom, għalhekk ukoll lejn is-switch l-ieħor u lura lejn A. A terġa' tibgħatha 'l quddiem … Il-broadcast idur bla tmiem mar-ring, u ma' kull request ġdida jiżdiedu kopji oħra.

Peress li l-istess frames dejjem jaslu fis-switches minn direzzjonijiet differenti, anke t-tabelli tal-indirizzi tagħhom jitħawdu: darba Anna tkun fuq dan il-port, darba fuq ieħor. Għalhekk anke l-pings ma jibqgħux jaslu.

:::tip Punt importanti
Jekk ikun hemm **loop** bejn is-switches, il-broadcasts jduru bla tmiem min-network u jiżdiedu — **broadcast storm**. Dan jifnijiet in-network. B'differenza mill-IP packets, il-frames tal-Ethernet m'għandhomx "data ta' skadenza" li xi darba twaqqafhom.
:::

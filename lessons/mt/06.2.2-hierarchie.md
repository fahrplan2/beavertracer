# Kif hu organizzat id-DNS

:::sim
url=/sims/lesson-6.2.btsim
:::

L-ebda server wieħed ma jista' jaf l-ismijiet kollha tad-dinja. Għalhekk id-DNS huwa mibni b'mod **ġerarkiku** — bħalma huma l-ismijiet infushom. L-ismijiet jinqraw mil-lemin għax-xellug:

```
www . beaver-schule . de . (Root)
 │          │         │      └─ Root-Server: kennen die Server aller Top-Level-Domains
 │          │         └─ Top-Level-Domain (TLD): der de-Server kennt alle .de-Domains
 │          └─ Domain: der Schul-DNS ist für beaver-schule.de zuständig
 └─ Rechnername innerhalb der Domain
```

Is-server li huwa responsabbli għal domain u li verament jaf it-tweġiba jissejjaħ **awtorittattiv**. Il-mixja lejh isir għall-PC minn **resolver** — hawnhekk il-kompjuter **DNS-Resolver**.

## L-esperiment

1. Aqleb għall-:fa-play: modalità ta' tħaddim (**Ħaddem**) u fuq il-**Client-PC** ikteb fit-:fa-terminal: **Terminal**:
   ```
   $ nslookup www.beaver-schule.de
   ```
2. Fil-modalità :fa-magnifying-glass: **Traċċa** iftaħ trace għad-**DNS-Resolver**.

Ir-resolver għamel serje sħiħa ta' requests għalik. Qabbel min taha liema tweġiba:

:::quiz match
Root-Server (192.168.0.101) -> Referenza: Għal .de huwa responsabbli ns.nic.de
de-Server (192.168.0.102) -> Referenza: Għal beaver-schule.de huwa responsabbli ns.beaver-schule.de
Schul-DNS (192.168.0.103) -> Tweġiba: www.beaver-schule.de għandu l-indirizz 192.168.0.20
:::

:::quiz mc
Lil min jistaqsi r-resolver l-ewwel?
- [x] Lir-root server
- [ ] Lis-Schul-DNS
- [ ] Lill-Client-PC
:::

:::evaluate
Iċċekkja t-tweġibiet
:::

:::note
Bejn waħda u oħra, ir-resolver jistaqsi wkoll dwar l-indirizzi tas-servers li lejhom ġie riferut (`A ns.nic.de`). DNS servers reali normalment jibagħtu dawn l-indirizzi flimkien mat-tweġiba. Barra minn hekk, ir-resolvers jiftakru kull tweġiba għal xi żmien (**cache**) — ir-request li jmiss għall-istess isem iweġbuha minnufih huma stess. Kemm iddum, tidher fl-entrata bħala **TTL** (*Time to Live*) f'sekondi.
:::

## L-aktar tipi importanti ta' entrati

| Tip | Tifsira | Eżempju |
|---|---|---|
| **A** | isem → indirizz IPv4 | `www.beaver-schule.de` → `192.168.0.20` |
| **AAAA** | isem → indirizz IPv6 | `www.beaver-schule.de` → `2001:db8::20` |
| **CNAME** | isem → isem ieħor (alias) | `web.beaver-schule.de` → `www.beaver-schule.de` |
| **MX** | mail server responsabbli ta' domain | `beaver-schule.de` → `mail.beaver-schule.de` |
| **NS** | DNS server responsabbli ta' domain | `beaver-schule.de` → `ns.beaver-schule.de` |

:::tip Punt importanti
Id-DNS huwa **ġerarkiku**: **root servers** jirreferu għas-servers tat-**top-level domains** (eż. `.de`), u dawn għas-servers tad-**domains** individwali. Is-server **awtorittattiv** responsabbli jaf it-tweġiba. **Resolver** jagħmel din il-mixja għall-PC u jiftakar it-tweġibiet (**cache**). Tipi importanti ta' entrati: **A**, **AAAA**, **CNAME**, **MX**, **NS**.
:::

## Toħloq entrata

L-iskola trid li l-websajt tagħha tkun aċċessibbli wkoll fuq `intranet.beaver-schule.de`.

1. Fil-modalità :fa-play: **Ħaddem**, ikklikkja fuq is-**Schul-DNS** u iftaħ l-app **DNS-Server**.
2. Iftaħ it-tab **A**. Ikklikkja fuq **+** u fir-ringiela l-ġdida ikteb l-isem `intranet.beaver-schule.de` u l-indirizz `192.168.0.20`.
3. Ittestja fuq il-Client-PC b'`nslookup intranet.beaver-schule.de`.

:::task
title: L-isem il-ġdid ġie introdott?
Iċċekkja jekk il-Client-PC isolvix l-isem intranet.beaver-schule.de għall-indirizz tal-web server. Is-simulazzjoni trid tkun qed taħdem fil-modalità ta' tħaddim għal dan.
check: resolves(2, "intranet.beaver-schule.de", "192.168.0.20")
:::

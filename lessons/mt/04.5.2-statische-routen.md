# Dħul ta' static routes

:::sim
url=/sims/lesson-4.5.2.btsim
:::

Din id-darba bejn il-Kumpanija A u l-Kumpanija B hemm **żewġ** routers. Huma konnessi permezz ta' network żgħir tagħhom, in-**network ta' tranżitu** `10.0.0.0/30`:

| Router | Interface | IP address | Network |
|---|---|---|---|
| Router A | `eth0` | `192.168.0.1/24` | Kumpanija A (Anna) |
| Router A | `eth1` | `10.0.0.1/30` | Network ta' tranżitu |
| Router B | `eth0` | `10.0.0.2/30` | Network ta' tranżitu |
| Router B | `eth1` | `172.16.0.1/24` | Kumpanija B (Clara) |

:::note
Network `/30` għandu eżattament żewġ indirizzi li jistgħu jintużaw — perfett biex jgħaqqad żewġ routers (ara t-taqsima 4.2.3).
:::

## Il-problema

Aqleb għall-:fa-play: **Ħaddem** (Modalità ta' tħaddim) u agħmel ping lil Clara minn **Anna** (`ping 172.16.0.10`). Clara ma twieġibx — minflok, Router A (`192.168.0.1`) jirrapporta "Zielnetz nicht erreichbar".

Ħares lejn ir-**Routing table IPv4** ta' **Router A**.

:::quiz mc
Għaliex il-ping t'Anna ma jaslux għand Clara?
- [ ] Anna ma daħlitx gateway
- [x] Router A ma jafx in-network `172.16.0.0/24` — mhuwiex konness direttament miegħu, u m'hemm l-ebda route lejh
- [ ] In-network ta' tranżitu huwa żgħir wisq
:::

:::evaluate
Iċċekkja t-tweġiba
:::

## Id-dħul tar-route

Router A jrid jitgħallem: il-packets għal `172.16.0.0/24` imorru għand Router B (`10.0.0.2`), u dan permezz ta' `eth1`.

1. Fuq **Router A**, iftaħ it-tab **Routing table IPv4** u ikklikkja fuq **+ hinzufügen**.
2. Fir-ringiela l-ġdida daħħal: **Ziel** `172.16.0.0`, **Netzmaske** `255.255.255.0`, **Next Hop** `10.0.0.2`, **Iface** `eth1`.
3. Ħifex ir-ringiela bil-marka :fa-check:. Fil-kolonna **Quelle** issa jidher **Statiku**.

Agħmel ping lil Clara darba oħra — issa t-tweġiba tasal.

:::note
Router B, b'mod inċidentali, diġà jaf it-triq lura lejn il-Kumpanija A: fir-routing table tiegħu diġà hemm static route għal `192.168.0.0/24` permezz ta' `10.0.0.1`. Għaliex din it-triq lura hija importanti daqstant, se tarah fil-paġna li jmiss.
:::

## Insegwi t-triq: traceroute

Bil-`traceroute` tista' tara minn liema routers jgħaddi packet. Ittajpja fuq **Anna**:

```
$ traceroute 172.16.0.10
```

:::quiz short
Minn kemm routers jgħaddi l-packet minn Anna lil Clara?
= 2
= tnejn
= żewġ routers
:::

:::quiz mc
Liema indirizz juri `traceroute` għal Router B?
- [x] `10.0.0.2` — l-indirizz tiegħu fin-network ta' tranżitu, li minnu jidħol il-packet
- [ ] `172.16.0.1` — l-indirizz tiegħu fil-Kumpanija B
- [ ] `192.168.0.1`
:::

:::evaluate
Iċċekkja t-tweġibiet
:::

`traceroute` juża trick bit-**Time to Live** mit-taqsima 4.3.1: l-ewwel jibgħat packet b'TTL 1. L-ewwel router inaqqas 1, jasal għal 0, jarmi l-packet u jirrapporta dan lura lis-sender — hekk Anna tkun taf l-ewwel router. Imbagħad TTL 2 għat-tieni router, u hekk 'il quddiem, sakemm id-destinazzjoni twieġeb.

:::tip Punt importanti
**Static route** jdaħħalha l-amministratur bl-idejn: network tad-destinazzjoni, netmask, next hop u interface. Bit-**traceroute** tista' ssegwi t-triq ta' packet router wara router.
:::

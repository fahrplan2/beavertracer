# Ir-router

:::goal
**Għan tat-tagħlim:** Tista' tispjega kif router jgħaqqad żewġ networks, tissettja l-gateway fuq PC u tispjega meta PC jwassal packet direttament u meta jwasslu permezz tal-gateway.
:::

:::sim
url=/sims/lesson-4.3.1.btsim
:::

**Router** jgħaqqad networks differenti ma' xulxin. Għal dan, għandu port separat għal kull network — u fuq kull port IP address tiegħu stess minn eżattament dak in-network. Fuq il-workspace tara mill-ġdid Firma A u Firma B, din id-darba b'router bejniethom.

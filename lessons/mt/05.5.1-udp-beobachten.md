# Josserva UDP

:::sim
url=/sims/lesson-5.5.btsim
:::

Fuq is-**Server** din id-darba jaħdem **UDP Echo-Server** fuq port `5000`. Hawnhekk ukoll il-kejbil huwa mħejji: it-**tieni datagram** mill-Client-PC lejn is-Server jintilef.

## L-esperiment

1. Aqleb għal modalità :fa-play: **Ħaddem** ta' tħaddim u iftaħ it-:fa-terminal: **Terminal** fuq il-**Client-PC**.
2. Bl-użu ta' `nc` ibda "konnessjoni" UDP mas-server (`-u` tfisser UDP):
   ```
   $ nc -u 192.168.0.20 5000
   ```
3. Ittajpja `eins`, `zwei` u `drei` wieħed wara l-ieħor u agħfas **Enter** kull darba. Kull linja li tirritorna hija eko mis-server.
4. Stenna ftit sekondi u mbagħad, fil-modalità :fa-magnifying-glass: **Traċċa**, iftaħ trace għall-**Client-PC**.

:::quiz mc
Liema echoes jirritornaw?
- [ ] It-tlieta kollha, `zwei` ftit aktar tard
- [x] Biss `eins` u `drei` — `zwei` jonqos u lanqas jerġa' jintbagħat
- [ ] Ebda wieħed
:::

:::quiz multi
Liema packets li taf mit-TCP jonqsu għal kollox fl-UDP?
- [x] Connection setup (`SYN`)
- [x] Konfermi (`ACK`)
- [x] Għeluq tal-konnessjoni (`FIN`)
- [ ] Packets b'numri tal-port
:::

:::evaluate
Iċċekkja t-tweġibiet
:::

Ikklikkja fuq wieħed mill-packets UDP u iftaħ **User Datagram Protocol**. Meta mqabbel mal-header tat-TCP, l-header tal-UDP huwa żgħir ħafna: **Source Port**, **Destination Port**, **Length** (tul) u **Checksum** (somma ta' verifika) — flimkien biss 8 bytes. Header tat-TCP għandu mill-inqas 20 byte, bis-sequence number u l-acknowledgement number, flags u d-daqs tat-tieqa.

:::quiz mc
Liema kompitu mit-taqsima 5.1 jagħmel l-UDP xorta waħda?
- [x] Multiplexing — permezz tal-ports
- [ ] Connection setup
- [ ] Trasmissjoni affidabbli
:::

:::evaluate
Iċċekkja t-tweġiba
:::

:::tip Punt importanti
L-**UDP** huwa **connectionless**: ebda setup, ebda aknowledgement, ebda retransmission, ebda ordni. Joffri biss **ports** (multiplexing) u **checksum**. Min-naħa l-oħra huwa mgħaġġel u ħafif — l-header tal-UDP għandu biss 8 bytes. Jekk datagram jintilef, il-programm irid jieħu ħsieb hu stess — jew ma jimpurtahx.
:::

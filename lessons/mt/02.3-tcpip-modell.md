# Il-mudell ta' referenza TCP/IP

Il-mudell ISO/OSI huwa dettaljat ħafna, imma twieled b'mod purament teoretiku. Fil-prattika — u anke fl-internet — minfloku ntuża l-**mudell TCP/IP**, li huwa aktar sempliċi u għandu erba' layers biss. Huwa jgħaqqad diversi layers tal-OSI f'waħda:

| TCP/IP layer | jikkorrispondi għal OSI layer(s) | Protokolli bħala eżempju |
|---|---|---|
| Application | 5, 6, 7 (Session, Presentation, Application) | HTTP, DNS, SMTP |
| Transport | 4 (Transport) | TCP, UDP |
| Internet | 3 (Network) | IP, ICMP |
| Network access | 1, 2 (Physical, Data Link) | Ethernet, WLAN |

L-ARP jinsab fuq il-fruntiera bejn in-network access u l-internet (OSI 2/3, ara l-każijiet fuq il-limitu fl-aħħar paġna).

Fil-prattika, il-qsim f'session/presentation/application rarament ikun ċar u distint — il-biċċa l-kbira tal-protokolli tal-application layer bħall-HTTP jagħmlu dan kollu huma stess. Il-mudell TCP/IP iqis dan billi jgħaqqad dawn it-tliet layers f'waħda biss.

:::note
Meta taqra dwar "layer 2", "layer 3" jew "layer 4" fil-kapitli li jmiss, dejjem qed nirreferu għan-numerazzjoni tal-mudell ISO/OSI — din tibqa' r-referenza komuni f'dan il-kors, anke jekk BeaverTracer u l-prattika ta' kuljum ħafna drabi jaħsbu aktar f'kategoriji TCP/IP.
:::

:::quiz fill
Il-mudell TCP/IP jgħaqqad il-layers tal-OSI session, {presentation} u application f'application layer waħda. Il-layers 1 u 2 tal-OSI flimkien jikkorrispondu għat-TCP/IP layer {network access}.
:::

# Il-firewall stateful

:::sim
url=/sims/lesson-9.2.btsim
:::

Firewall **stateful** (*stateful*) tiftakar kull konnessjoni li ħalliet tgħaddi darba f'**tabella tal-istati**: il-protokoll, iż-żewġ indirizzi u ż-żewġ ports. Jekk jaslilha packet li jaqbel ma' entrata — ma jimpurtax f'liema direzzjoni —, tħallih jgħaddi mingħajr aktar kontroll. Konnessjonijiet ġodda, min-naħa l-oħra, iridu jgħaddu mir-regoli.

## Osserva

1. Fil-**Firewall**, issettja l-**Modus** fuq **Stateful**.
2. Fuq il-**Lehrer-PC**, iftaħ mill-ġdid `http://203.0.113.80/` fil-:fa-globe: **Browser**.
3. Fil-firewall, iftaħ immedjatament it-tab **Zustände**.

:::quiz mc
X'jiġri issa?
- [x] Il-paġna titgħabba, u f'**Zustände** tidher il-konnessjoni mill-Lehrer-PC lejn `203.0.113.80:80`
- [ ] Il-paġna ma titgħabbax, għax it-tweġibiet għad m'għandhom l-ebda regola
:::

:::quiz short
Liema port jidher fit-tabella tal-istati taħt **Ziel**?
= 80
:::

:::evaluate
Iċċekkja t-tweġibiet
:::

L-entrati f'**Zustände** jitilfu wara ftit (kolonna **Timeout**) jekk ma jibqax jgħaddi xejn mill-konnessjoni.

## Task: Il-firewall tal-iskola

Issa ssettja l-firewall kif teħtieġ skola vera:

- **Min-network tal-iskola** jista' jgħaddi kollox lejn l-Internet (direzzjoni B → A, kwalunkwe protokoll).
- **Mill-Internet** jistgħu jintlaħqu biss il-web (80) u l-wasla tal-mail (25) tas-server tal-iskola.
- Kull ħaġa oħra **tiġi mwaqqgħa**, u l-modus huwa **Stateful**.

:::task
title: Il-firewall tal-iskola issettjat?
Jiċċekkja jekk in-network tal-iskola jaslix fl-Internet, jekk minn barra jintlaħqux biss il-web u l-mail tas-server tal-iskola, u jekk il-Lehrer-PC ma jistax jintlaħaq minn barra.
check: tcpOpen(8, "203.0.113.80", 80)
check: tcpOpen(1, "198.51.100.10", 80)
check: tcpOpen(1, "198.51.100.10", 25)
check: tcpFails(1, "198.51.100.10", 22)
check: pingFails(1, 8)
:::

:::quiz mc
Il-Lehrer-PC jibgħat ping lil `203.0.113.80`. It-tweġibiet jirritornaw?
- [x] Iva — il-ping ġie permess minn B → A, u t-tweġiba tappartjeni għal dan l-istat
- [ ] Le — m'hemm l-ebda regola għal ICMP minn barra
:::

:::evaluate
Iċċekkja t-tweġiba
:::

:::tip Punt importanti
**Firewall stateful** tniżżel kull konnessjoni permessa f'**tabella tal-istati** u tħalli l-packets kollha ta' din il-konnessjoni jgħaddu fiż-**żewġ direzzjonijiet**. Hekk huma biżżejjed ir-regoli għall-**connection setup**: "Minn ġewwa jista' jgħaddi lejn barra" u "minn barra biss lejn ċerti servizzi". Konnessjonijiet li jinbdew minn barra lejn in-network tal-iskola jibqgħu mblukkati.
:::

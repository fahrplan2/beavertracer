# Troubleshooting: l-isem ma jaħdimx

:::sim
url=/sims/lesson-6.2.3.btsim
:::

Għalliema tirrapporta: "`www.beaver-schule.de` ma jillodjax għalija. Imma b'`http://192.168.0.20` taħdem!" Hekk *suppost* inhu mwaqqaf:

| X'inhu | Suppost |
|---|---|
| DNS server fuq il-Client-PC | `192.168.0.53` (DNS-Resolver) |
| Daħla fl-Schul-DNS | `www.beaver-schule.de` → `192.168.0.20` |

Sib l-iżbalji u tiswijhom.

<details>
<summary>Ħjiel 1: X'jgħid nslookup?</summary>

Ikteb `nslookup www.beaver-schule.de` fuq il-Client-PC. Liema server staqsa `nslookup` — u x'irritorna? (It-tweġiba tieħu ftit sekondi.)
</details>

<details>
<summary>Ħjiel 2: U issa?</summary>

Jekk tirċievi tweġiba, qabbel l-indirizz mal-pjan. Fejn hu rreġistrat dan l-isem?
</details>

:::task
title: Ir-riżoluzzjoni tal-isem tiswiet?
Jiċċekkja jekk il-Client-PC jirrisolvix www.beaver-schule.de għall-indirizz t-tajjeb. Is-simulazzjoni trid taħdem fil-Modalità ta' tħaddim biex dan jaħdem.
check: resolves(2, "www.beaver-schule.de", "192.168.0.20")
:::

## X'kien qed jiġri?

:::quiz multi
Liema dikjarazzjonijiet huma veri?
- [x] Fuq il-Client-PC kien hemm `192.168.0.35` irreġistrat bħala DNS server — hemm ħadd ma jwieġeb
- [x] Fl-Schul-DNS, `www.beaver-schule.de` kien jindika lejn `192.168.0.21` minflok `192.168.0.20`
- [ ] Il-web server kien mitfi
- [ ] Ir-root server ma kienx jaf d-dominju `.de`
:::

:::evaluate
Iċċekkja t-tweġiba
:::

:::tip Punt importanti
Jekk konnessjoni taħdem bl-**IP address** imma mhux bl-**isem**, il-problema tkun f'**DNS**. Iċċekkja l-ewwel id-**DNS server irreġistrat** (jirrispondi xejn?), imbagħad id-**daħla** nnifisha (l-indirizz hu korrett?). `nslookup` juri t-tnejn: liema server ġie mistoqsi u x'wieġeb.
:::

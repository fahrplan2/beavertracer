# Troubleshooting: is-servizz ma jirrispondix

:::sim
url=/sims/lesson-5.3.2.btsim
:::

Wara update, l-iskola tirrapporta: "Is-servizz echo jirrifjuta kull konnessjoni, u l-paġna web ukoll ma tittellax aktar." Skont il-pjan, il-**web server** suppost jisma' fuq port `80` u s-**servizz echo** (TCP Echo-Server) fuq port `5000`. Sib l-iżbalji u irranġahom.

<details>
<summary>Suġġeriment 1: X'jirrispondi s-server?</summary>

Pprova tikkonnettja ma' `192.168.0.20`, port `5000` bis-**Simple TCP Client**, u iftaħ trace għall-Client-PC. B'xiex jirrispondi s-server għall-`[SYN]` tiegħek?
</details>

<details>
<summary>Suġġeriment 2: Liema ports huma miftuħa?</summary>

Fuq il-Client-PC, ikteb `nmap -p 80,5000 192.168.0.20` fit-**Terminal**. `nmap` jipprova l-ports wieħed wara l-ieħor u juri liema huma miftuħa. Bi `ss` fuq is-server tara fuq liema ports hemm tassew programm li jisma'.
</details>

<details>
<summary>Suġġeriment 3: Fejn jiġi ssettjat dan?</summary>

Fuq is-**Server**, iftaħ l-apps **TCP Echo-Server** u **HTTP-Server**. Is-servizz qed jaħdem? U fuq liema port?
</details>

:::task
title: Is-servizzi jistgħu jintlaħqu?
Iċċekkja jekk il-Client-PC jilħaqx is-servizz echo fuq port 5000 u l-web server fuq port 80. Biex jaħdem dan, is-simulazzjoni trid tkun għaddejja fil-Modalità ta' tħaddim.
check: tcpOpen(1, 2, 5000)
check: tcpOpen(1, 2, 80)
:::

## X'kien qed jiġri?

:::quiz multi
Liema dikjarazzjonijiet huma tajbin?
- [x] Għall-`[SYN]` lejn port 5000, is-server wieġeb bi `[RST, ACK]`
- [x] Is-servizz echo kien qed jisma' fuq port 5050 minflok fuq port 5000
- [x] Il-web server ma kienx tnieda xejn
- [ ] Il-kejbil bejn il-Client-PC u s-Server kien bil-ħsara
:::

:::evaluate
Iċċekkja t-tweġiba
:::

:::tip Punt importanti
Jekk jiġi lura **`RST`** wara `SYN`, ma hemm **ebda programm** li jisma' fuq dak il-port: il-kompjuter jista' jintlaħaq, imma s-servizz le. Kawżi tipiċi: is-servizz **ma tnieda** jew qed jisma' fuq **port differenti**. Ħarsa lejn is-server b'`ss` turi liema ports huma tassew miftuħa.
:::

# Layer 3: Routers, IP addresses u subnetting

:::goal
**Għan tat-tagħlim:** Tista' taqra IP addresses fil-binary, tikkalkula network addresses u broadcast addresses, taqsam network f'subnets ta' daqs indaqs u tgħaqqad networks permezz ta' routers b'routing tables.
:::

:::osi 3
:::

url=/sims/lesson-4.1.btsim
:::

S'issa l-apparat kollu kien f'network lokali *wieħed* — ikkonnettjat permezz ta' switches u Access Points. Iżda l-internet jikkonsisti f'miljuni ta' networks bħal dawn: il-home network tiegħek, in-network tal-iskola, in-network tal-fornitur tal-mobile tiegħek, in-networks ta' data centres kbar.

Kif isib packet it-triq minn network għal ieħor? Dan jieħdu ħsieb il-**layer 3**, in-network layer — bil-**Internet Protocol (IP)**, l-IP addresses u l-apparat li jgħaqqad in-networks ma' xulxin: ir-**routers**.

:::note
L-IP ilu definit fi standard mill-1981, l-**RFC 791**. Il-verżjoni li dan il-kapitolu jittratta prinċipalment hija msejħa **IPv4**. Il-verżjoni l-ġdida **IPv6** se titgħallimha fl-aħħar tal-kapitolu.
:::

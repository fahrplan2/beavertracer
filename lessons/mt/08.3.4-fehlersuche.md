# Troubleshooting: twissijiet dwar iċ-certificate

:::sim
url=/sims/lesson-8.3.4.btsim
:::

Fin-network tal-iskola hemm tliet web servers oħra: il-**Mensa**, il-**Bibliothek** u l-**Sport-AG**. It-tlieta jużaw HTTPS — madankollu l-Browser tal-**Client-PC** juri twissija għal kull wieħed minnhom. Il-Client-PC jafda fis-**Schul-CA**.

## Investiga

Aqleb għall-Modalità ta' tħaddim :fa-play: **Ħaddem** u fuq il-**Client-PC** iftaħ wara xulxin:

- `https://mensa.beaver-schule.de/`
- `https://bibliothek.beaver-schule.de/`
- `https://sport.beaver-schule.de/`

Aqra t-twissija f'kull każ u d-dettalji dwar iċ-certificate (Subject, Issuer, Valid until).

:::quiz match
mensa.beaver-schule.de -> Iċ-certificate skada
bibliothek.beaver-schule.de -> Iċ-certificate huwa self-signed, il-client ma jafdax fih
sport.beaver-schule.de -> Iċ-certificate inħareġ għal isem differenti
:::

:::evaluate
Iċċekkja t-tqabbil
:::

:::quiz short
Għal liema isem inħareġ iċ-certificate tas-Sport-AG (mingħajr `CN=`)?
= www.beaver-schule.de
:::

:::evaluate
Iċċekkja t-tweġiba
:::

## Tiswija tal-Mensa

Il-Mensa hija l-aktar waħda faċli biex tissewwa: iċ-certificate tagħha nħareġ darba mis-Schul-CA — sempliċement skada. Biex inżommuha sempliċi, hawnhekk is-Schul-CA tinsab direttament fuq is-server tal-Mensa.

<details>
<summary>Suġġeriment 1: Toħroġ certificate ġdid</summary>

Fuq **mensa.beaver-schule.de** iftaħ il-:fa-shield-halved: **Zertifikatverwaltung**. Fit-tab **Signieren** tista' tiġi ffirmata mill-ġdid mis-Schul-CA iċ-certificate eżistenti — hekk jieħu validità ġdida. Ħifdu b'isem ġdid tal-fajl, eż. `mensa-neu.cert.json`.
</details>

<details>
<summary>Suġġeriment 2: Uża ċ-certificate il-ġdid</summary>

Fl-**HTTP-Server** tal-Mensa: **Stoppen**, fit-tab **HTTPS** agħżel iċ-certificate il-ġdid (tgħarfu mill-isem tal-fajl), **Verwenden**, **Starten**.
</details>

:::task
title: Il-Mensa tista' terġa' tintlaħaq b'mod sigur?

check: httpsOk(2, "https://mensa.beaver-schule.de/")

## U t-tnejn l-oħra?

:::quiz mc
Kif jissewwa sew il-problema tal-**Bibliothek**?
- [ ] Kull student jikklikkja fuq „Kompli xorta waħda“
- [x] Il-Bibliothek tieħu certificate maħruġ mis-Schul-CA għal `bibliothek.beaver-schule.de`
- [ ] Iċ-certificate self-signed tal-Bibliothek jiddaħħal fuq l-apparati kollha bħala CA fdata
:::

:::quiz mc
U fil-każ tas-**Sport-AG**?
- [ ] Is-Sport-AG tiġi msemmija mill-ġdid `www.beaver-schule.de`
- [x] Is-Sport-AG tieħu certificate tagħha għal `sport.beaver-schule.de`
- [ ] L-arloġġ tas-server jerġa' jiġi rrisettjat lura
:::

:::evaluate
Iċċekkja t-tweġibiet
:::

:::warning
**„Kompli xorta waħda“** quasi qatt mhi idea tajba meta jkun hemm twissija dwar iċ-certificate. Eżattament hekk tidher ukoll sitwazzjoni fejn attakkant jgħaddilek certificate tiegħu stess. Dan japplika wkoll għal `curl -k`: biha jiġi diżattivat iċ-ċekk taċ-certificate — prattiku għall-ittestjar, iżda perikoluż fl-użu reali.
:::

:::tip Punt importanti
Il-Browser jwissi meta certificate ikun **skada**, meta ma **jafx lis-CA** li ħarġitu (eż. fil-każ ta' certificates **self-signed**) jew meta l-**isem** fiċ-certificate ma jaqbilx mal-indirizz li jkun intalab. Is-soluzzjoni hija dejjem certificate xieraq u validu minn CA fdata — mhux li t-twissija tiġi injorata billi tikklikkja fuqha.
:::

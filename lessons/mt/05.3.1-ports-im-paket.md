## L-esperiment

1. Aqleb għall-Modalità ta' tħaddim :fa-play: **Ħaddem**, ikklikkja fuq il-**Client-PC** u iftaħ il-:fa-globe: **Browser**. Ġib `http://192.168.0.20/`.
2. Ikklikkja fuq **Zurück** (Back) fuq nett tat-tieqa, iftaħ is-**Simple TCP Client** u ikkonnettjah ma' `192.168.0.20`, port `5000`. Ħalli l-konnessjoni miftuħa.
3. Aqleb għall-modalità :fa-magnifying-glass: **Traċċa**, iftaħ trace għall-**Client-PC** u ikklikkja fuq packet b'`[SYN]`. Iftaħ **Transmission Control Protocol**.

Fuq nett tal-header tat-TCP hemm żewġ ports: **Source Port** (port tas-sors) u **Destination Port** (port tad-destinazzjoni).

:::quiz table
| Konnessjoni | Source port | Destination port |
|---|---|---|
| Browser → Webserver | {49152} | {80} |
| TCP-Client → Echo-Dienst | {49153} | {5000} |
:::

Iċċekkja t-tweġibiet
:::

## Żewġ tipi ta' ports

**Destination port — is-servizz:** Programm tas-server jistenna konnessjonijiet fuq port fiss — jingħad li **jisma'** hemm. Għas-servizzi magħrufa n-numri huma stabbiliti madwar id-dinja, il-**Well-known Ports** (0 sa 1023). Għalhekk browser jaf mingħajr ma jistaqsi: il-web servers jisimgħu fuq port 80.

**Source port — is-sender:** Il-port fuq in-naħa tal-client jintgħażel mis-sistema operattiva nnifisha għal kull konnessjoni ġdida minn firxa għolja (f'BeaverTracer minn 49152). Bis-saħħa tiegħu l-client jagħraf lil liema waħda mill-konnessjonijiet tiegħu tappartjeni tweġiba.

Konnessjoni hija għalhekk determinata b'mod uniku minn erba' dettalji: **IP address u port fiż-żewġ naħat**. Il-par ta' IP address u port jissejjaħ **socket**, eż. `192.168.0.20:80`.

## Ħarsa lejn is-server

Erġa' aqleb għall-Modalità ta' tħaddim :fa-play: **Ħaddem**, iftaħ fuq is-**Server** it-:fa-terminal: **Terminal** u ikteb:

```
$ ss
```

`ss` juri s-sockets kollha tal-kompjuter. Linji b'`LISTEN` huma programmi li jisimgħu fuq port. Linji b'`ESTABLISHED` huma konnessjonijiet eżistenti — bis-socket tiegħu stess (*Local Address:Port*) u bis-socket tan-naħa l-oħra (*Peer Address:Port*).

:::quiz multi
Fuq liema ports jisma' s-server?
- [x] 80
- [x] 5000
- [ ] 49152
- [ ] 443
:::

:::quiz mc
Liema konnessjoni juri `ss` bħala `ESTABLISHED`?
- [x] `192.168.0.20:5000` ma' `192.168.0.10:49153` — il-konnessjoni miftuħa tat-TCP client
- [ ] `192.168.0.20:80` ma' `192.168.0.10:49152` — il-konnessjoni tal-browser
- [ ] it-tnejn
:::

:::note
Il-konnessjoni tal-browser diġà ngħalqet — wara t-tagħbija tal-paġna, ntemmet b'`FIN`. `ss` xorta juriha għal ftit żmien bħala `TIME-WAIT`: is-server jistenna ftit biex jara jaslux packets tard ta' din il-konnessjoni. Il-konnessjoni tat-TCP client, min-naħa l-oħra, għadha miftuħa għax għadek ma klikkjajtx fuq **Iddekonettja**.
:::

## L-aktar Well-known Ports importanti

| Port | Protokoll | Servizz |
|---|---|---|
| 22 | SSH | manutenzjoni remota sikura (command line encrypted) |
| 25 | SMTP | tibgħat e-mails |
| 53 | DNS | tittraduċi ismijiet f'IP addresses (ġeneralment permezz ta' UDP) |
| 80 | HTTP | paġni web |
| 110 | POP3 | tiġbor e-mails |
| 143 | IMAP | timmaniġġja e-mails fuq is-server |
| 443 | HTTPS | paġni web encrypted |

:::tip Punt importanti
Il-**Ports** (0 sa 65535) iżommu l-konnessjonijiet fuq kompjuter separati minn xulxin. Is-servizzi tas-server **jisimgħu** fuq **Well-known Ports** fissi (eż. HTTP 80, HTTPS 443), il-clients jirċievu għal kull konnessjoni **source port** għoli u ħieles. Konnessjoni hija determinata b'mod uniku mill-**IP address u l-port taż-żewġ naħat**.
:::

:::quiz match
22 -> SSH
25 -> SMTP
53 -> DNS
80 -> HTTP
110 -> POP3
143 -> IMAP
443 -> HTTPS
:::

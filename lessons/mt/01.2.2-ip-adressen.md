# Għoti ta' IP addresses

:::sim
url=/sims/lesson-1.2.2.btsim
:::

Biex żewġ apparat jitkellmu ma' xulxin, għandhom bżonn IP address fl-istess network. Fuq il-workspace tara żewġ PCs konnessi — eżatt kif int stess għadek kif bnejthom.

1. Aqleb għall-:fa-play: **Ħaddem**-Modalità ta' tħaddim u kklikkja fuq **Computer 1** biex tiftaħha.
2. Hemmhekk iftaħ l-:fa-gear: **IP Settings**. PC ġdid diġà għandu l-indirizz `192.168.0.10` bin-netmask `/24` — tista' thalliha hekk.
3. Issa iftaħ **Computer 2**. Għandu *l-istess* indirizz `192.168.0.10` — dan ma jistax jaħdem, għax kull indirizz jista' jidher darba biss fin-network. Ibdlu għal `192.168.0.11` (netmask `/24`).

:::tip Punt importanti
**IP address** (eż. `192.168.0.10`) hija l-indirizz ta' apparat fin-network — tista' tqabbilha man-numru ta' dar. Kull IP address tista' tidher **darba** biss f'network.
:::

:::task
title: L-indirizzi ngħataw sewwa?
Ibqa' fil-Modalità ta' tħaddim u ċċekkja jekk iż-żewġ PCs għandhomx indirizzi xierqa u jistgħux jaslu għand xulxin.
check: ip(1, "192.168.0.10/32")
check: ip(3, "192.168.0.11/32")
check: pingOk(1, 3)
:::

:::note
Xi tfisser eżattament `/24` u kif tinqasam network b'mod sensat nitkellmu dwarha fid-dettall fil-kapitlu 4. Għalissa jibqa' biżżejjed: iż-żewġ indirizzi jridu jibdew b'`192.168.0.` u ma jistgħux jirrepetu lil xulxin.
:::

# HTTPS

:::osi 5
:::

**HTTPS** (*HTTP Secure*) huwa HTTP normali ħafna — ħlief li ma jaħdimx direttament fuq TCP, imma minn ġo layer ikkriptat fin-nofs: **TLS** (*Transport Layer Security*). Il-predeċessur ta' TLS kien jissejjaħ **SSL**; għalhekk spiss għadu jingħad "SSL certificates".

```
ohne Verschlüsselung:   HTTP  →  TCP  →  IP
mit Verschlüsselung:    HTTP  →  TLS  →  TCP  →  IP
```

HTTP ma jinduna b'xejn minn dan: jibgħat ir-requests tiegħu bħas-soltu, TLS jikkriptahom, u TCP iesporthom. Fil-mudell OSI, TLS joqgħod bejn it-transport layer u l-application layer, jiġifieri f'layer 4/5 — jibni fuq TCP u jmexxi sessjoni sigura.

| | HTTP | HTTPS |
|---|---|---|
| Port | 80 | **443** |
| Indirizz | `http://…` | `https://…` |
| Il-kontenut jinqara fit-Traċċa? | iva | le |
| Il-browser juri | "mhux sikur" | lucchett |

TLS jagħmel waqt il-connection setup dak kollu li tgħallimt f'dan il-kapitlu:

- Is-server jidentifika ruħu bis-**certificate** tiegħu (**awtentiċità**).
- It-żewġ naħat jinnegozjaw **session key** bi **Diffie-Hellman** — is-server **jiffirma** s-sehem tiegħu.
- Wara dan, id-data kollha tiġi kkriptata bl-**AES** (**kunfidenzjalità**) u protetta kontra bidliet (**integrità**).

Il-prinċipju mhuwiex limitat għall-web: anki l-e-mail (taqsima 8.4) u ħafna protokolli oħra jgħaddu minn TLS bl-istess mod.

Fit-taqsimiet li jmiss se tosserva l-HTTPS fit-Traċċa, tarmah int stess, u tinvestiga meta l-browser iwissi — u għaliex.

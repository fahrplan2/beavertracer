# Is-sistema binarja

Kompjuter, fil-fond tiegħu, jaf biss żewġ stati: il-kurrent mixgħul jew il-kurrent mitfi. Għalhekk niktbu **1** u **0**. Ċifra bħal din tissejjaħ **bit**. Anke kull IP address, għall-kompjuter, mhi xejn għajr sekwenza ta' żeroijiet u wieħediet — biex tifhem kif jaħdmu n-netmasks, f'din il-paġna se titgħallem taqra dawn in-numri u tikkonvertihom int stess.

## Kif normalment induru: is-sistema deċimali

Fil-ħajja ta' kuljum nagħmlu l-kalkoli b'għaxar ċifri (minn 0 sa 9). Kull pożizzjoni tiswa għaxar darbiet aktar mill-pożizzjoni li għandha fuq il-lemin: unitajiet, għexieren, mijiet, eluf. In-numru `305` għalhekk ifisser:

| Valur tal-pożizzjoni | 100 | 10 | 1 |
|---|---|---|---|
| Ċifra | 3 | 0 | 5 |
| Valur | 300 | 0 | 5 |

300 + 0 + 5 = **305**

## Is-sistema binarja

Fis-**sistema binarja** hemm biss żewġ ċifri: 0 u 1. Kull pożizzjoni tiswa **d-doppju** tal-pożizzjoni li għandha fuq il-lemin: 1, 2, 4, 8, 16, 32, 64, 128 …

In-numru binarju `00001101` għalhekk ifisser:

| Valur tal-pożizzjoni | 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1 |
|---|---|---|---|---|---|---|---|---|
| Bit | 0 | 0 | 0 | 0 | 1 | 1 | 0 | 1 |
| Valur | | | | | 8 | 4 | | 1 |

8 + 4 + 1 = **13**

Allura sempliċement iġġemma l-valuri tal-pożizzjonijiet fejn hemm 1.

:::tip Punt importanti
**Bit** huwa pożizzjoni waħda fis-sistema binarja (0 jew 1). **8 bits** jagħmlu **byte** — fin-networking, grupp ta' 8 bits bħal dan jissejjaħ ukoll **octet**. Il-valuri tal-pożizzjonijiet ta' octet huma **128, 64, 32, 16, 8, 4, 2, 1**.
:::

= 6
:::

:::quiz short
Liema numru deċimali huwa `10000001`?
= 129
:::

## Minn deċimali għal binarju

Bil-maqlub, tgħaddi mill-valuri tal-pożizzjonijiet mix-xellug għal-lemin u kull darba tistaqsi: **Il-valur tal-pożizzjoni għadu jidħol fin-numru (li fadal) tiegħi?** Jekk iva, tikteb 1 u tnaqqas il-valur tal-pożizzjoni. Jekk le, tikteb 0.

Eżempju: `168`

| Valur tal-pożizzjoni | jidħol f'…? | Bit | Fadal |
|---|---|---|---|
| 128 | 168 → iva | **1** | 40 |
| 64 | 40 → le | **0** | 40 |
| 32 | 40 → iva | **1** | 8 |
| 16 | 8 → le | **0** | 8 |
| 8 | 8 → iva | **1** | 0 |
| 4 | 0 → le | **0** | 0 |
| 2 | 0 → le | **0** | 0 |
| 1 | 0 → le | **0** | 0 |

Moqri minn fuq għal isfel: 168 = **10101000**

## Ipprattika

Hawnhekk f'kull tentattiv tikseb numri ġodda — ipprattika sakemm tkun żgur/a minn dan.

:::quiz random dec2bin
count=3
:::

:::quiz random bin2dec
count=3
:::

:::evaluate
Iċċekkja t-tweġibiet
:::

:::tip Suġġeriment
Dawn il-valuri se tiltaqa' magħhom ripetutament man-netmasks — jaqbel li tkun taf minnhom: `10000000` = 128, `11000000` = 192, `11100000` = 224, `11110000` = 240, `11111000` = 248, `11111100` = 252, `11111110` = 254, `11111111` = 255.
:::

## IP addresses fis-sistema binarja

IPv4 address tikkonsisti f'**32 bit**, jiġifieri erba' octets. Peress li ħadd ma jista' jiftakar 32 żero u wieħed, kull octet jinkiteb bħala numru deċimali u jinfirdu b'punti:

```
11000000 . 10101000 . 10110010 . 00000001
   192   .   168    .   178    .    1
```

:::quiz short
Minn kemm-il bit tikkonsisti IPv4 address?
= 32
:::

:::quiz mc
Teoretikament, kemm hemm IPv4 addresses differenti?
- [ ] 256 × 4 = 1024
- [x] 2³² — madwar 4.3 biljun
- [ ] Aktar minn biżżejjed — diversi għal kull persuna fid-dinja
:::

:::evaluate
Iċċekkja t-tweġibiet
:::

:::note
Madwar 4.3 biljun jidher ħafna — imma huwa inqas minn address waħda għal kull persuna fid-dinja. Għalhekk l-IPv4 addresses ilhom skarsi. Kif wieħed jittratta dan se titgħallem aktar tard man-NAT u l-IPv6.
:::

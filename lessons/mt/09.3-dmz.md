# Id-DMZ

:::sim
url=/sims/lesson-9.3.btsim
:::

S'issa, is-**Schulserver** kien fl-istess network tal-**Lehrer-PC**. Dan hu perikoluż: is-Schulserver jista' jintlaħaq mill-Internet. Jekk attakkant isib toqba fil-web server u jieħu f'idejh il-kompjuter, ikun **f'nofs in-network tal-iskola** — u l-firewall ma tistax tagħmel xejn aktar, għax it-traffiku mis-Schulserver lejn il-Lehrer-PC ma jgħaddix minnha.

Is-soluzzjoni: is-servers li jridu jkunu jistgħu jintlaħqu mill-Internet jitqiegħdu f'**network separat** bejn l-Internet u n-network intern. Dan in-network jissejjaħ **DMZ** (*demilitarisierte Zone*, jiġifieri żona demilitarizzata, wara l-istrixxa newtrali bejn żewġ fruntieri).

## L-istruttura

Fuq il-workspace tara l-mudell klassiku b'**żewġ firewalls**:

```
Internet ──[ Firewall außen ]── Schulrouter ──── DMZ: Schulserver (198.51.100.10)
                                    │
                             [ Firewall innen ]
                                    │
                    LAN: Lehrer-PC (192.0.2.20), Schüler-PC (192.0.2.21)
```

- Il-**Firewall außen** tipproteġi kollox mill-Internet. Il-port A hu konness mal-Internet, il-port B mar-Schulrouter.
- Il-**Firewall innen** tipproteġi l-LAN — anki mid-DMZ. Il-port A hu konness mar-Schulrouter, il-port B mal-LAN.

It-tnejn li huma firewalls bħalissa għadhom iħallu kollox jgħaddi.

## Task: Ipproteġi d-DMZ

Issettja **ż-żewġ** firewalls fuq **Stateful** u **Alle verwerfen** u daħħal ir-regoli adattati:

- **Firewall außen:** Minn ġewwa 'l barra (B → A) kollox permess; minn barra (A → B) biss TCP 80 u 25 lejn is-Schulserver `198.51.100.10`.
- **Firewall innen:** Mil-LAN (B → A) kollox permess; fid-direzzjoni tal-LAN (A → B) m'hemmx bżonn ta' regola — it-tweġibiet jirritornaw permezz tat-tabella tal-istati.

:::task

:::note
Ħafna firewalls għandhom tliet portijiet jew aktar („żoni“) u jimitaw DMZ f'apparat wieħed. Il-prinċipju huwa l-istess: it-traffiku bejn l-Internet, id-DMZ u l-LAN irid dejjem jgħaddi minn regoli. Il-mudell b'żewġ firewalls għandu vantaġġ: attakkant irid jegħleb **żewġ** ostakli — spiss jintużaw anki apparati ta' manifatturi differenti, biex l-istess vulnerabbiltà ma tiftaħhomx it-tnejn.
:::

:::tip Punt importanti
Fi **DMZ** jitqiegħdu s-servers kollha li jridu jkunu jistgħu jintlaħqu mill-Internet. Hija tinsab bejn żewġ firewalls (jew f'żona separata ta' firewall waħda): l-Internet jista' jaċċessa biss ċerti servizzi fid-DMZ, il-LAN jista' jmur fid-DMZ u fl-Internet — iżda mid-DMZ u mill-Internet **ma hemm l-ebda triq lejn il-LAN**. Jekk server fid-DMZ jiġi kkontrollat minn attakkant, il-LAN jibqa' protett.
:::

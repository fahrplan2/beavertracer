## L-esperiment

1. Aqleb għall-Modalità ta' tħaddim :fa-play: **Ħaddem**, ikklikkja fuq il-**PC** u iftaħ `http://www.beispiel.de/` fil-:fa-globe: **Browser**.
2. Fil-modalità :fa-magnifying-glass: **Traċċa**, iftaħ trace għall-**PC** u t-tieni wieħed għall-web server **www.beispiel.de**.
3. Qabbel il-packet `GET / HTTP/1.1` fiż-żewġ traces: min hu miktub bħala sender (**Quelle**)?

:::quiz mc
Liema sender address għandu l-`GET` fit-trace tal-**PC**?
- [x] L-indirizz privat tal-PC (`192.168.178.…`)
- [ ] `203.0.113.2`
- [ ] `192.0.2.80`
:::

:::quiz short
U liema sender address jara l-**web server**?
= 203.0.113.2
:::

:::quiz mc
Liema indirizz hu `203.0.113.2`?
- [ ] L-indirizz tal-web server
- [x] L-indirizz WAN tal-home router
- [ ] L-indirizz tad-DNS tal-provider
:::

## X'hemm warajh

Il-home router, f'kull packet li jmur fl-internet, jibdel is-sender address privat bl-**indirizz WAN pubbliku** tiegħu stess — u ġeneralment ukoll is-sender port. Għall-web server jidher li t-talba ġiet mill-home router. Meta t-tweġiba tirritorna, il-home router jerġa' jibdel l-indirizz u jgħaddi l-packet lill-PC.

B'hekk il-home network kollu jista' jidħol fl-internet b'indirizz pubbliku wieħed biss — u l-apparat fl-internet qatt ma jara l-indirizzi privati.

## It-triq lejn l-internet

Fuq il-**PC**, ikteb fil-:fa-terminal: **Terminal**:

```
$ traceroute 192.0.2.80
```

:::quiz short
Kemm hemm routers bejn il-PC u l-web server? (Għodd il-linji kollha qabel l-aħħar waħda.)
= 4
= erbgħa
:::

:::quiz mc
Liema indirizz juri `traceroute` għall-ewwel router?
- [x] `192.168.178.1` — l-indirizz LAN tal-home router
- [ ] `203.0.113.2` — l-indirizz WAN tiegħu
- [ ] `203.0.113.1` — l-ewwel router tal-provider
:::

:::evaluate
Iċċekkja t-tweġibiet
:::

:::tip Punt importanti
Il-**NAT** (*Network Address Translation*) fit-triq lejn l-internet jibdel is-sender address **privat** ta' apparat bl-**indirizz WAN pubbliku** tar-router — u fit-tweġibiet jagħmel il-kuntrarju. B'hekk l-apparat kollu fil-home network jaqsam indirizz IPv4 pubbliku **wieħed**. Dan iffranka l-indirizzi u jaħbi l-indirizzi privati mill-internet.
:::

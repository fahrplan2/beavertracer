# Subnetting pass wara pass

F'din it-taqsima l-bits huma mmarkati bil-kulur: [[n|network part]] · [[e|estensjoni]] · [[h|host part]]

## L-idea

Immaġina biċċa art kbira li trid tinqasam f'lottijiet ta' daqs indaqs. Fis-subnetting, l-art kbira hija n-network oriġinali, u l-lottijiet huma s-subnets.

Teknikament jiġri dan: network jikkonsisti minn network part u host part. Fis-subnetting tieħu xi bits mill-**bidu tal-host part** u żżidhom man-**network part**. Dawn il-bits żejda jissejħu **estensjoni** (jew *subnet bits*). Kull kombinazzjoni possibbli tal-bits tal-estensjoni tagħti subnet separat.

<pre class="bits-block">
qabel (/24):  [[n|NNNNNNNN.NNNNNNNN.NNNNNNNN]].[[h|HHHHHHHH]]
wara  (/26):  [[n|NNNNNNNN.NNNNNNNN.NNNNNNNN]].[[e|EE]][[h|HHHHHH]]
</pre>

## Kemm bits għandek bżonn?

Bi *n* bits ta' estensjoni hemm 2*ⁿ* kombinazzjonijiet — allura 2*ⁿ* subnets:

| Bits ta' estensjoni | Kombinazzjonijiet | Subnets |
|---|---|---|
| 1 | 0, 1 | 2 |
| 2 | 00, 01, 10, 11 | 4 |
| 3 | 000, 001, … 111 | 8 |
| 4 | 0000 … 1111 | 16 |

Jekk, per eżempju, ikunu meħtieġa **tliet** subnets, 1 bit (2 networks biss) mhuwiex biżżejjed — tieħu 2 bits u ssib **erba'** subnets. Waħda tibqa' bħala riżerva.

## Eżempju 1: żewġ subnets, fid-dettall kollu

In-network `192.168.42.0/24` irid jinqasam f'**żewġ** subnets ta' daqs indaqs.

**Pass 1 — Kemm bits?** Għal 2 subnets **1 bit** huwa biżżejjed (2¹ = 2).

**Pass 2 — Prefix length u netmask ġodda.** Minn `/24` isir `/24 + 1 = /25`. In-netmask issa għandha 25 bit bil-valur 1:

<pre class="bits-block">
[[n|11111111.11111111.11111111]].[[e|1]][[h|0000000]]   →   255.255.255.128
</pre>

**Pass 3 — Ikteb in-network address fil-binary system u mmarkaha.** L-ewwel tliet octets ma jinbidlux. Fl-aħħar octet, l-ewwel bit huwa l-estensjoni (E), il-bqija huwa host part (H):

<pre class="bits-block">
[[n|192.168.42.]] [[e|0]] [[h|0 0 0 0 0 0 0]]
            [[e|E]] [[h|H H H H H H H]]
</pre>

**Pass 4 — Għal kull kombinazzjoni tal-estensjoni, iddetermina n-network address u l-broadcast address.** L-estensjoni titqiegħed darba fuq 0 u darba fuq 1. Għan-network address il-host bits kollha huma 0, għall-broadcast address kollha huma 1:

| Subnet | E | Host bits | l-aħħar octet | Address |
|---|---|---|---|---|
| 1 — network address | [[e|0]] | [[h|0000000]] | 0 | `192.168.42.0` |
| 1 — broadcast address | [[e|0]] | [[h|1111111]] | 127 | `192.168.42.127` |
| 2 — network address | [[e|1]] | [[h|0000000]] | 128 | `192.168.42.128` |
| 2 — broadcast address | [[e|1]] | [[h|1111111]] | 255 | `192.168.42.255` |

**Pass 5 — Ikteb ir-riżultat:**

| Subnet | Network address | Broadcast address | Range għal hosts | Hosts |
|---|---|---|---|---|
| 1 | `192.168.42.0/25` | `192.168.42.127` | `.1` – `.126` | 126 |
| 2 | `192.168.42.128/25` | `192.168.42.255` | `.129` – `.254` | 126 |

## Eżempju 2: erba' subnets

L-istess network `192.168.42.0/24`, din id-darba f'**erba'** subnets.

**Pass 1:** 4 subnets → **2 bits** (2² = 4).

**Pass 2:** `/24 + 2 = /26`, netmask [[n|11111111.11111111.11111111]].[[e|11]][[h|000000]] = `255.255.255.192`.

**Pass 3:** Fl-aħħar octet, l-ewwel **żewġ** bits issa huma l-estensjoni: [[e|EE]][[h|HHHHHH]].

**Pass 4:** L-estensjoni tgħodd 'il fuq fil-binary system: 00, 01, 10, 11. Għal kull kombinazzjoni tqiegħed il-host bits darba fuq 0 u darba fuq 1:

| Subnet | EE | Network address (host bits 0) | Broadcast address (host bits 1) |
|---|---|---|---|
| 1 | [[e|00]] | [[e|00]][[h|000000]] = **0** | [[e|00]][[h|111111]] = **63** |
| 2 | [[e|01]] | [[e|01]][[h|000000]] = **64** | [[e|01]][[h|111111]] = **127** |
| 3 | [[e|10]] | [[e|10]][[h|000000]] = **128** | [[e|10]][[h|111111]] = **191** |
| 4 | [[e|11]] | [[e|11]][[h|000000]] = **192** | [[e|11]][[h|111111]] = **255** |

**Pass 5 — Riżultat:**

| Subnet | Network address | Broadcast address | Range għal hosts |
|---|---|---|---|
| 1 | `192.168.42.0/26` | `192.168.42.63` | `.1` – `.62` |
| 2 | `192.168.42.64/26` | `192.168.42.127` | `.65` – `.126` |
| 3 | `192.168.42.128/26` | `192.168.42.191` | `.129` – `.190` |
| 4 | `192.168.42.192/26` | `192.168.42.255` | `.193` – `.254` |

Kull subnet għandu 2⁶ = 64 address, li minnhom 62 għal hosts.

Tinnota xi ħaġa? Is-subnets jinsabu **wieħed wara l-ieħor mingħajr toqob**: kull wieħed jibda eżatt wara l-broadcast address tal-preċedenti. U l-broadcast address tal-aħħar subnet hija eżattament il-broadcast address tan-network oriġinali — b'hekk tista' tikkontrolla r-riżultat tiegħek.

:::tip Punt importanti: subnetting fi ħames passi
1. **Kemm subnets?** Qarreb 'il fuq lejn il-qawwa tat-tnejn li jmiss → *n* bits ta' estensjoni.
2. **Prefix length ġdida** = prefix length l-antika + *n*; minn hemm tiġi n-**netmask** ġdida.
3. Ikteb **in-network address fil-binary system** u mmarka n-network part, l-estensjoni u l-host part.
4. **Għodd 'il fuq l-estensjoni** (00, 01, 10, …): host bits fuq 0 → network address, host bits fuq 1 → broadcast address.
5. **Kontroll:** is-subnets jinsabu wieħed wara l-ieħor mingħajr toqob, u l-aħħar wieħed jintemm bil-broadcast address tan-network oriġinali.
:::

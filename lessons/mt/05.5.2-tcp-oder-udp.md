# TCP jew UDP?

| | TCP | UDP |
|---|---|---|
| Konnessjoni | setup b'three-way handshake, magħluqa ordnata | xejn — kull datagram joqgħod waħdu |
| Aċċettazzjonijiet | iva (`ACK`) | le |
| Data mitlufa | tintbagħat mill-ġdid | tibqa' mitlufa |
| Ordni | terġa' tiġi rrestawrata | mhijiex garantita |
| Header | mill-inqas 20 byte | 8 byte |
| Veloċità | ftit aktar bil-mod, aktar packets | veloċi, ftit overhead |

Meta jkun inqas aktar?

- **Real time:** Fil-vidjokonferenzi, fit-telefonija tal-internet jew fil-logħob online kull millisekonda tgħodd. Biċċa ħoss mitlufa li tinġieb wara sekonda ma tiswa xejn lil ħadd — aħjar kraċk qasir milli dewmien.
- **Talbiet qosra:** Talba tad-**DNS** ("Liema IP address għandu `www.beispiel.de`?") tidħol f'datagram wieħed, u t-tweġiba wkoll. Connection setup kien itella' l-ħidma għal tliet darbiet aktar. Jekk ma tiġi ebda tweġiba, il-programm jistaqsi sempliċement mill-ġdid.

Fejn jeħtieġ li kull byte jasal — paġni web, e-mails, downloads —, TCP, min-naħa l-oħra, huwa l-għażla t-tajba.

:::tip Punt importanti
**TCP** huwa affidabbli, imma jeħtieġ aktar ħidma — għal kull ma jrid jasal **kollu** (web, e-mail, fajls). **UDP** huwa veloċi u sempliċi, imma mingħajr garanziji — għal **real time** (telefonija, vidjo, logħob) u **talbiet qosra** bħad-DNS.
:::

Bis-saħħa ta' dan issa taf l-għodod tat-transport layer. Fil-kapitlu li jmiss se tħares lejn il-protokolli li huma mibnija fuqu: HTTP, DNS, e-mail u DHCP.

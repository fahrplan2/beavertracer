## L-esperiment

1. Aqleb għall-Modalità ta' tħaddim :fa-play: **Ħaddem**, ikklikkja fuq il-**Client-PC** u iftaħ il-:fa-globe: **Browser**.
2. Din id-darba iftaħ `http://www.beaver-schule.de/` — b'isem minflok IP address.
3. Aqleb għall-modalità :fa-magnifying-glass: **Traċċa** u iftaħ trace għall-**Client-PC**.

Fil-bidu nett — qabel il-connection setup b'`[SYN]` — hemm żewġ packets bil-protokoll **DNS**.

:::quiz short
Lejn liema IP address jibgħat il-Client-PC id-DNS request tiegħu?
= 192.168.0.53
:::

:::quiz short
Liema IP address hemm fit-tweġiba għal `www.beaver-schule.de`?
= 192.168.0.20
:::

:::quiz mc
Ikklikkja fuq id-DNS request u iftaħ il-protocol tree. Liema transport protocol u liema destination port jintużaw?
- [ ] TCP, port 80
- [x] UDP, port 53
- [ ] UDP, port 67
:::

:::evaluate
Iċċekkja t-tweġibiet
:::

Il-Client-PC jibni l-konnessjoni TCP mal-web server biss wara li jkun jaf l-IP address — eżatt bħal fil-kapitlu 5.

:::seq
mode: text
Client-PC -> DNS-Resolver: DNS-Anfrage | A www.beaver-schule.de?
DNS-Resolver -> Client-PC: DNS-Antwort | A 192.168.0.20
:::

## Kif jaf il-PC min hu d-DNS server?

Iftaħ fuq il-**Client-PC** l-:fa-gear: **IP Settings**: fil-field **DNS-Server** hemm `192.168.0.53` — il-kompjuter **DNS-Resolver**. Lilu jibgħat il-PC kull talba għal isem.

Tista' tistaqsi lid-DNS server ukoll direttament, mingħajr browser. Iftaħ it-:fa-terminal: **Terminal** u ikteb:

```
$ nslookup www.beaver-schule.de
```

`nslookup` l-ewwel juri liema server staqsa, imbagħad it-tweġiba. Għal paragun, staqsi dwar isem li ma jeżistix, eż. `nslookup gibtsnicht.beaver-schule.de`.

:::quiz mc
Xi twieġeb id-DNS server għall-isem mhux magħruf?
- [ ] IP address każwali
- [x] `NXDOMAIN` — dan l-isem ma jeżistix
- [ ] L-ebda tweġiba
:::

:::evaluate
Iċċekkja t-tweġiba
:::

:::tip Punt importanti
Id-**DNS** jittraduċi ismijiet (eż. `www.beaver-schule.de`) f'IP addresses. Qabel ma PC jista' jibni konnessjoni lejn isem, jistaqsi lid-**DNS server** li huwa rreġistrat fl-IP settings tiegħu — l-aktar permezz ta' **UDP, port 53**. B'`nslookup` tista' tagħmel DNS requests bl-idejn.
:::

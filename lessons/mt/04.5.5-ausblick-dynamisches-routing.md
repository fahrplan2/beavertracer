# Ħarsa 'l quddiem: dynamic routing

Fil-proġett inti daħħalt b'idejk tnax-il route għal erba' siti. Network kbir ta' kumpanija għandu mijiet ta' routers, l-internet għandu għexieren ta' eluf — u kontinwament xi mkien tinqata' linja jew tiżdied waħda ġdida. B'idejn bniedem dan m'għadux jista' jinżamm.

Għalhekk ir-routers normalment jiskambjaw ir-routes tagħhom ma' xulxin awtomatikament. Għal dan hemm **routing protocols**. Allura wieħed jitkellem fuq **dynamic routing** — b'kuntrast ma' **static routing**, fejn kollox jiddaħħal b'idejk.

L-aktar routing protocols magħrufa:

| Protocol | Idea | użu tipiku |
|---|---|---|
| **RIP** (*Routing Information Protocol*) | Kull router regolarment jgħid lill-qraba tiegħu liema networks jista' jilħaq u kemm routers (*hops*) 'il bogħod. | networks żgħar, eżempju tat-tagħlim |
| **OSPF** (*Open Shortest Path First*) | Kull router jaf il-pjan sħiħ tan-network u minnu jikkalkula huwa stess l-iqsar triq. | networks ta' kumpanija |
| **BGP** (*Border Gateway Protocol*) | Operaturi kbar ta' networks (eż. provvedituri tal-internet) jgħarrfu lil xulxin liema networks jilħqu. | l-internet bejn il-provvedituri |

:::quiz match
RIP -> Ir-routers jgħarrfu lill-ġirien tagħhom kemm hops 'il bogħod jilħqu network
OSPF -> Kull router jaf il-network plan kollu u jikkalkula l-iqsar triq
BGP -> Jgħaqqad in-networks tal-provvedituri kbar tal-internet
:::

:::evaluate
Iċċekkja t-tqabbil
:::

:::tip Punt importanti
Fl-**static routing**, amministratur jidħol ir-routes kollha b'idejh. Fid-**dynamic routing**, ir-routers jiskambjaw ir-routes tagħhom awtomatikament bil-għajnuna ta' **routing protocols** bħal RIP, OSPF jew BGP — u jadattaw lilhom infushom meta konnessjoni tfalli.
:::

:::note
BeaverTracer jista' jissimula RIP, OSPF u BGP — issibhom fit-tabs bl-istess ismijiet ta' router. F'dan il-kors nillimitaw ruħna għall-ħarsa 'l quddiem.
:::

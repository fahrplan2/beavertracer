# Twaqqif DHCP server

:::sim
url=/sims/lesson-6.4.2.btsim
:::

Din id-darba d-DHCP server għadu mhux configured. Int tiddeċiedi liema settings se jqassam:

| Setting | Valur |
|---|---|
| Address range | `192.168.0.100` sa `192.168.0.120` |
| Gateway | `192.168.0.1` |
| DNS server | `192.168.0.53` |

1. Aqleb għall-:fa-play: **Ħaddem** modalità ta' tħaddim, ikklikkja fuq l-**DHCP-Server** u iftaħ l-app **DHCP Server**.
2. Imla **Bidu tar-range**, **Aħħar tar-range**, **Gateway** u **DNS-Server**, ikklikkja fuq **Ħifxi** u mbagħad fuq **Ibda**.
3. Fuq **Laptop 1** u **Laptop 2**, fl-:fa-gear: **IP Settings** poġġi l-modalità fuq **DHCP** u ikklikkja kull darba fuq **Apply**.
4. Iċċekkja fid-DHCP server, fit-tab **Leases**, min ħa liema address.

:::note
L-address range tintgħażel b'tali mod li ma tmurx kontra l-indirizzi fissi: servers, routers u printers spiss jingħataw indirizzi fissi barra mid-DHCP range — hawn, pereżempju, id-DHCP server innifsu b'`192.168.0.2`.
:::

:::task
title: DHCP imwaqqaf?
Iċċekkja jekk iż-żewġ laptops ħadux address mid-DHCP range u jistgħux jaslu għand id-DHCP server. Is-simulazzjoni trid tkun qed taħdem fil-modalità ta' tħaddim biex dan jaħdem.
check: ip(3, "192.168.0.96/27")
check: ip(4, "192.168.0.96/27")
check: pingOk(3, 2)
check: pingOk(4, 2)
:::

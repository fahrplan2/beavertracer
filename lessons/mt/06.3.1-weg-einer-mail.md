## L-esperiment

1. Aqleb għall-Modalità ta' tħaddim :fa-play: **Ħaddem**, ikklikkja fuq **Anna** u iftaħ l-app **E-Mail**.
2. Mur fit-tab **Ikteb**. F'**An** imla `ben@biber-mail.de`, ikteb subject u test qasir u ikklikkja fuq **Ibgħat**.
3. Stenna ftit sekondi — il-mail l-ewwel trid tmur minn mail server għall-ieħor. Imbagħad ikklikkja fuq **Ben**, iftaħ l-app **E-Mail** u ikklikkja fuq **Ġib**. Il-mail ta' Anna hi hemm.
4. Fil-Modalità :fa-magnifying-glass: **Traċċa**, iftaħ trace għall-**Mailserver Schule**.

:::quiz mc

- [x] Lill-mail server tagħha stess (Mailserver Schule)
- [ ] Lill-Mailserver Biber
:::

:::quiz mc

## X'hemm warajh

E-mail tivvjaġġa f'diversi stadji — bħal ittra li tgħaddi minn żewġ uffiċċji tal-posta:

1. Il-programm tal-e-mail ta' Anna jgħaddi l-mail permezz ta' **SMTP** lill-mail server ta' Anna.
2. Il-Mailserver Schule jara: ir-receiver jappartjeni għal **domain barrani**. Permezz ta' **DNS** jistaqsi għall-**MX record** (*Mail Exchanger*) ta' `biber-mail.de` u jieħu `mail.biber-mail.de` — u mbagħad ukoll l-IP address tiegħu.
3. Iwassal il-mail permezz ta' **SMTP** lill-Mailserver Biber. Hemmhekk tinżamm fil-mailbox ta' Ben.
4. Ben jiġbidha permezz ta' **IMAP** (jew **POP3**) mill-mail server tiegħu.

:::seq
mode: text
Mailserver Schule -> Mailserver Biber: SMTP: MAIL FROM | anna@beaver-schule.de
Mailserver Biber -> Mailserver Schule: 250 OK
Mailserver Schule -> Mailserver Biber: SMTP: RCPT TO | ben@biber-mail.de
Mailserver Biber -> Mailserver Schule: 250 OK
Mailserver Schule -> Mailserver Biber: SMTP: DATA | il-mail innifisha
Mailserver Biber -> Mailserver Schule: 250 OK queued
:::

:::tip Punt importanti
**SMTP** (port 25) **jibgħat** l-e-mails: mill-programm tal-e-mail lejn il-mail server tiegħek stess u minn hemm lejn il-mail server tar-receiver. Liema mail server hu responsabbli għal domain jidher fl-**MX record** fid-DNS. **POP3** (port 110) u **IMAP** (port 143) jintużaw biss biex **tiġbed** mill-mailbox tiegħek stess.
:::

:::quiz match
SMTP -> Tibgħat l-e-mails u tgħaddihom bejn il-mail servers

:::

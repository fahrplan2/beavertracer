# Ara ċertifikat

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Fuq il-workspace tara l-**Client-PC**, **DNS-Server** u l-web server tal-iskola, `www.beaver-schule.de`. Il-web server joffri l-paġni tiegħu wkoll permezz ta' **HTTPS**.

## Il-lock fil-Browser

1. Aqleb għal :fa-play: **Modalità ta' tħaddim**, ikklikkja fuq il-**Client-PC** u iftaħ il-:fa-globe: **Browser**.
2. Fittex `https://www.beaver-schule.de/` — oqgħod attent għall-**https**.
3. Fuq ix-xellug tal-indirizz joħroġ **lock**. Ikklikkja fuqu.

:::quiz short
Għal liema isem inħareġ iċ-ċertifikat (is-subject mingħajr `CN=`)?
= www.beaver-schule.de
:::

:::quiz short
Min ħareġ iċ-ċertifikat (l-issuer mingħajr `CN=`)?
= Biber Root CA
:::

:::evaluate
Iċċekkja t-tweġibiet
:::

## Għaliex il-Client-PC jafda ċ-ċertifikat?

Fuq il-**Client-PC** iftaħ il-:fa-shield-halved: **Ġestjoni taċ-ċertifikati** u mur fit-tab **Vertrauenswürdige CAs**.

:::quiz mc
Xi ssib hemm?
- [x] Iċ-ċertifikat tal-**Biber Root CA**
- [ ] Iċ-ċertifikat ta' `www.beaver-schule.de`
- [ ] Ebda entrata
:::

:::quiz mc
Kif tara li l-Biber Root CA hija Root-CA?
- [x] Hija **self-signed**: is-subject u l-issuer huma l-istess
- [ ] Isimha jispiċċa b'"CA"
- [ ] M'għandhiex public key
:::

:::quiz mc
Fil-Client-PC, taħt **Privater Schlüssel** hemm "Ja" jew "Nein"?
- [ ] Ja — il-client jeħtieġ il-private key tas-CA biex jivverifika l-firem
- [x] Nein — biex tivverifika jibqa' biżżejjed il-public key; il-private key għandha biss is-CA
:::

:::evaluate
Iċċekkja t-tweġibiet
:::

## In-naħa l-oħra: il-web server

Issa fuq il-web server **www.beaver-schule.de** iftaħ il-:fa-shield-halved: **Ġestjoni taċ-ċertifikati** (tab **Meine Zertifikate**) u ara ċ-ċertifikat tiegħu.

:::quiz multi
X'inhu minnu dwar iċ-ċertifikat tal-web server?
- [x] Taħt **Privater Schlüssel** hemm "Ja" — is-server jeħtieġha għall-connection setup
- [x] Iċ-**ċ-chain** hi `www.beaver-schule.de ← Biber Root CA`
- [x] Il-**fingerprint** huwa l-istess bħal dak fit-tieqa tal-lock tal-Browser
- [ ] Huwa self-signed
:::

:::evaluate
Iċċekkja t-tweġibiet
:::

:::note
Il-**fingerprint** huwa hash value taċ-ċertifikat. B'hekk tista' tqabbel żewġ ċertifikati malajr — mingħajr ma jkollok tivverifika l-oqsma kollha wieħed wieħed.
:::

:::tip Punt importanti
Il-**web server** għandu ċ-ċertifikat tiegħu **mal-private key**. Il-**client** jaf biss **iċ-ċertifikat tas-Root-CA** (mingħajr private key) — dan huwa biżżejjed biex jivverifika l-firma fuq iċ-ċertifikat tas-server. Meta tikklikkja fuq il-**lock** fil-Browser, tara s-subject, l-issuer, il-fingerprint u l-validità.
:::

# Ħaddem ping u segwih fit-Tracer

:::sim
url=/sims/lesson-1.2.3.btsim
:::

Iż-żewġ PCs issa għandhom l-indirizzi `192.168.0.10` u `192.168.0.11`. Wasal iż-żmien għall-ewwel test: b'**ping**, PC jibgħat talba żgħira lil ieħor u jistenna t-tweġiba.

## Tħaddem ping

Aqleb għall-:fa-play: **Modalità ta' tħaddim**. Fuq **Computer 1**, iftaħ it-:fa-terminal: **Terminal** u ktteb:

```
$ ping 192.168.0.11
```

Jekk il-PC l-ieħor iwieġeb, tara linja b'ħin tar-rispons għal kull packet mibgħut — l-ewwel ping tiegħek li rnexxa!

:::tip Punt importanti
**Ping** jiċċekkja jekk apparat ieħor jistax jintlaħaq: jibgħat talba u jkejjel kemm tieħu ħin it-tweġiba.
:::

## Segwih fit-Tracer

Issa aqleb għall-:fa-magnifying-glass: **Traċċa**. Hawnhekk għad m'hemm xejn x'tara — fuq nett fax-xellug, ħdejn **Traces:**, ikklikkja fuq **+**, agħżel **Computer 1** u mbagħad il-port tiegħu `eth0`.

Issa tara lista tal-packets kollha li għaddew minn dan il-port — inklużi l-pings ta' ftit ilu. Ikklikkja fuq wieħed mill-packets: taħtu tara l-istruttura eżatta tiegħu, layer b'layer.

:::tip Punt importanti
Id-data ma tinbagħatx f'daqqa fin-network, imma f'unitajiet żgħar, il-**packets**. Kull packet iġorr is-sender, ir-receiver u parti mid-data.
:::

:::tip
Ping dejjem jikkonsisti minn talba (Echo Request) u tweġiba (Echo Reply) — tistax issib iż-żewġ direzzjonijiet fil-kolonna **Info**?
:::

## Min qed jistaqsi qabel l-ewwel ping?

Fuq nett tal-lista, saħansitra qabel l-ewwel ping, hemm żewġ packets bil-protokoll **ARP**. Aqra l-kolonna **Info** tagħhom — hemm miktub xi ħaġa bħal:

```
Who has 192.168.0.11? Tell 192.168.0.10
192.168.0.11 is at aa:fd:9f:a5:d2:89
```

Computer 1 kien jaf l-IP address tal-PC l-ieħor, imma għadu ma kienx jaf l-**indirizz tal-hardware** tiegħu (il-*MAC address* — kull network card għandha tiegħha). Mingħajru ma jistax jibgħat xejn. Għalhekk l-ewwel jgħajjat fin-network: *"Min għandu 192.168.0.11? Għid lil 192.168.0.10!"* Il-PC li qed jiġi mfittex iwieġeb bl-indirizz tal-hardware tiegħu. Eżattament dan huwa x-xogħol tal-**ARP**.

Wara dan, Computer 1 jiftakar it-tweġiba — huwa għalhekk li l-ARP jidher biss qabel l-ewwel ping u mhux qabel kull wieħed.

:::tip Punt importanti
L-**ARP** isib l-indirizz tal-hardware (**MAC address**) li jaqbel ma' IP address magħruf: il-PC jistaqsi lil kulħadd fin-network, u biss l-apparat li qed jiġi mfittex iwieġeb.
:::

:::quiz mc
Lil min jibgħat Computer 1 l-ewwel packet ta' ARP? Ħares fil-kolonna **Ziel**.
- [ ] Biss lill-PC l-ieħor
- [x] Lill-apparati kollha fin-network (broadcast)
- [ ] Lil server fuq l-internet
:::

:::quiz mc
X'jitgħallem Computer 1 mit-tweġiba tal-ARP?
- [ ] L-IP address tal-PC l-ieħor
- [x] L-indirizz tal-hardware (MAC address) tal-PC l-ieħor
- [ ] L-isem tal-PC l-ieħor
:::

:::evaluate
Iċċekkja t-tweġibiet
:::

B'hekk għamilt darba kompluta tul il-prinċipju bażiku ta' BeaverTracer: ibni, ħaddem, segwi. Fit-taqsima li jmiss, l-affarijiet isiru pass wieħed aktar kumplessi.

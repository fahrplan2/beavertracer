# Troubleshooting: ilbieraħ kien għadu jaħdem

:::sim
url=/sims/lesson-7.2.4.btsim
:::

Ilbieraħ il-web server tad-dar kien jintlaħaq minn barra — il-port forward `TCP 80 → 192.168.178.10:80` huwa mwaqqaf. Wara qtugħ tal-elettriku dalgħodu kmieni, Clara ma tistax tidħol aktar fuq il-paġna. Sib l-iżball u rranġah b'mod permanenti.

<details>
<summary>Suġġeriment 1: Lejn fejn tipponta r-regola?</summary>

Qabbel l-IP tal-LAN fit-tab **Port FW** tal-home router mal-indirizz li l-**Heim-Webserver** għandu tassew bħalissa (:fa-gear: **IP Settings**).
</details>

<details>
<summary>Suġġeriment 2: Għaliex għandu indirizz differenti?</summary>

Il-Heim-Webserver huwa fuq **DHCP**? Allura wara kull restart jieħu xi indirizz ħieles mir-range tal-home router (fit-tab **DHCP**). Kif tiżgura li dejjem ikollu l-istess indirizz?
</details>

:::task
title: Il-Heim-Webserver jintlaħaq mill-ġdid?
Iċċekkja jekk il-Heim-Webserver għandux l-indirizz fiss tiegħu u jekk Clara tilħqux permezz tal-port forward. Għal dan is-simulazzjoni trid taħdem fil-Modalità ta' tħaddim.
check: ip(11, "192.168.178.10/32")
check: tcpOpen(12, "203.0.113.2", 80)
:::

## X'kien qed jiġri?

:::quiz multi
Liema dikjarazzjonijiet huma veri?
- [x] Il-web server tad-dar ħa l-indirizz tiegħu permezz ta' DHCP u wara r-restart kellu wieħed differenti
- [x] Għalhekk il-port forward kien jipponta lejn indirizz li fuqu ma kien għadu jaħdem ebda server
- [x] Indirizz fiss barra mir-range tad-DHCP isolvi l-problema b'mod permanenti
- [ ] Il-provider kien imblokka l-indirizz WAN
:::

:::evaluate
Iċċekkja t-tweġiba
:::

:::tip Punt importanti
L-apparati li lejhom tipponta **port forward** (servers, printers, kameras) għandhom bżonn **indirizz fiss**: jew imdaħħal b'mod statiku u **barra mir-range tad-DHCP**, jew bħala assenjazzjoni fissa fid-DHCP Server tar-router. Inkella wara restart jistgħu jieħdu indirizz differenti — u r-regola tispiċċa fuq xejn.
:::

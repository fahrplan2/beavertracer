# Is-sequence diagram

:::sim
url=/sims/lesson-5.1.btsim
:::

Il-andament ta' konnessjoni jiġi miġbud bħala **sequence diagram**: il-client u s-server kull wieħed jingħata linja vertikali, u l-ħin jgħaddi minn fuq għal isfel. Kull vleġġa hija packet. Hija miġbuda inklinata, għax kull packet jieħu ftit ħin fit-triq.

Hekk tidher il-konnessjoni tiegħek mill-aħħar paġna — qabbilha linja b'linja mat-trace:

:::seq
Client-PC -> Server: SYN
Server -> Client-PC: SYN, ACK
Client-PC -> Server: ACK
Client-PC -> Server: PSH, ACK "Hello World" len=13
Server -> Client-PC: ACK
Server -> Client-PC: PSH, ACK len=13
Client-PC -> Server: ACK
Client-PC -> Server: FIN, ACK
Server -> Client-PC: ACK
Server -> Client-PC: FIN, ACK
Client-PC -> Server: ACK
:::

Fuq kull vleġġa hemm il-**flags**, taħtha hemm in-numri `SEQ` u `ACK`. **DATA** timmarka l-packets b'data utli. In-numri ħomor jappartjenu għall-client, il-blu għas-server — x'jfissru dawn se jinfthiem fil-paġna li jmiss.

## Il-flags

| Flag | tfisser | Tifsira |
|---|---|---|
| **SYN** | *synchronize* | tibni konnessjoni, tistabbilixxi n-numru tal-bidu |
| **ACK** | *acknowledge* | tikkonferma data li waslet |
| **PSH** | *push* | tgħaddi d-data lill-programm minnufih |
| **FIN** | *finish* | "Lestejt" — tneħħi l-konnessjoni |
| **RST** | *reset* | tikkanċella jew tirrifjuta konnessjoni (aktar dwar dan f'5.3.2) |

## Tliet fażijiet

**Setup:** il-client jibgħat `SYN`, is-server iwieġeb b'`SYN, ACK`, il-client jikkonferma b'`ACK`. Peress li jinħtieġu eżattament tliet packets, dan jissejjaħ **three-way handshake**.

**Data:** kull packet b'data jiġi kkonfermat mir-receiver b'`ACK`. Hawnhekk is-server jibgħat l-echo lura — u l-client jikkonferma wkoll dan.

**Teardown:** kull naħa tagħlaq id-direzzjoni tagħha tal-ibgħat waħedha: `FIN` mill-client, `ACK` mis-server — imbagħad `FIN` mis-server, `ACK` mill-client. Dawn huma erba' packets.

:::tip Punt importanti
Konnessjoni TCP tgħaddi minn tliet fażijiet: **setup** bit-**three-way handshake** (`SYN` → `SYN, ACK` → `ACK`), **trasferiment tad-data** (kull packet tad-data jiġi kkonfermat b'`ACK`) u **teardown** (kull naħa tibgħat `FIN` u tirċievi `ACK`).
:::

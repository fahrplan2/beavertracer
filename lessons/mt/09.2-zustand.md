# Stateless jew stateful

Konnessjoni dejjem tikkonsisti f'**żewġ direzzjonijiet**: il-PC tal-għalliem jibgħat talba lil web server fuq l-Internet — u l-web server jibgħat il-paġna web lura. Firewall li taħdem bil-prinċipju tal-whitelist għalhekk mhux biss trid tħalli l-talba tgħaddi, iżda wkoll it-**tweġiba**.

Għal dan hemm żewġ tipi ta' packet filters:

| | **Stateless** (*stateless*) | **Stateful** (*stateful*) |
|---|---|---|
| Kif taħdem | tiċċekkja kull packet waħdu, mingħajr memorja | tiftakar il-konnessjonijiet permessi f'**state table** |
| Tweġibiet | jeħtieġu regola tagħhom għad-direzzjoni lura | jitħallew jgħaddu awtomatikament, għax jappartjenu għal konnessjoni magħrufa |
| Użu | apparat sempliċi, filters veloċi ħafna | prattikament kull firewall tal-lum |

Fl-għaxar taħlitiet li ġejjin se tara għaliex il-filters stateless għandhom problemi bit-tweġibiet — u kif firewall stateful issolvihom.

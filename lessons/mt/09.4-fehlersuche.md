# Troubleshooting: mindu saru r-regoli l-ġodda ma jaħdem xejn

:::sim
url=/sims/lesson-9.4.btsim
:::

Herr Biber, l-amministratur tal-Beaver-Schule, ilbieraħ biddel il-firewall għall-prinċipju tal-whitelist. Minn dakinhar kulħadd qed jilmenta: il-**website tal-iskola** ma tistax tintlaħaq mill-barra, u **ma jaslu ebda e-mails mill-Internet**. Għallinqas: SSH issa huwa mblukkat mill-barra, kif ridna.

Sib l-iżbalji fir-regoli tal-**firewall** u saħħaħhom.

<details>
<summary>Ħjiel 1: Il-packet jaslilha tassew ir-regola t-tajba?</summary>

Ittestja mill-**Internet-PC** bil-kmand `nmap -p 22,25,80 198.51.100.10` u wara ħares fil-firewall lejn il-kolonna **Treffer**. Regola li tibqa' fuq 0 għalkemm kellhom jaslu packets għaliha, tkun moħbija minn regola oħra — jew ma taqbel qatt.
</details>

<details>
<summary>Ħjiel 2: Ħares sewwa</summary>

Qabbel kull numru fir-regoli mal-ports mill-Kapitolu 5: liema port jappartjeni għal HTTP u liema għal SMTP? U aħseb fl-ordni: l-ewwel regola li taqbel tirbaħ.
</details>

:::task
title: Web u mail jistgħu jintlaħqu mill-ġdid?
Iċċekkja jekk il-web u l-mail tas-server tal-iskola jistgħux jintlaħqu mill-Internet u jekk SSH jibqax imblukkat.
check: tcpOpen(1, "198.51.100.10", 80)
check: tcpOpen(1, "198.51.100.10", 25)
check: tcpFails(1, "198.51.100.10", 22)
:::

## X'kien qed jiġri?

:::quiz multi
Liema żbalji kien hemm fir-regoli?
- [x] Ir-regola tal-web kienet tippermetti port 8080 minflok 80
- [x] Ir-regola tal-mail kienet taħt ir-regola „ċaħħad kollox“ u qatt ma ntlaħqet
- [ ] Il-firewall kienet issettjata fuq Stateful
- [ ] Port 25 huwa l-port ħażin għall-mail
:::

:::evaluate
Iċċekkja t-tweġibiet
:::

:::tip Punt importanti
Żbalji tipiċi fir-regoli tal-firewall huma: **numri mqalbin** fil-port, id-**direzzjoni** ħażina u **ordni** ħażina, fejn regola ġenerali tgħatti regola speċifika. Fit-troubleshooting jgħinu **portscan** mill-barra, il-**log** tal-firewall u l-**hit counters** tar-regoli.
:::

# Ikkonnettja żewġ networks

:::sim
url=/sims/lesson-4.3.1.btsim
:::

Ir-router għandu żewġ ports:

| Port | IP address | Network |
|---|---|---|
| `eth0` | `192.168.0.1/24` | Firma A |
| `eth1` | `172.16.0.1/24` | Firma B |

Biex il-PCs jużaw ir-router, f'kull wieħed minnhom hemm imdaħħal **gateway**: għal Anna u Ben `192.168.0.1`, għal Clara u David `172.16.0.1`. Issibu fil-:fa-gear: **IP Settings** fil-field **Gateway**.

:::tip Punt importanti
Il-**gateway** (aktar eżatt: *default gateway*) hija l-IP address tar-router **fin-network tiegħek stess**. Lejn il-gateway, PC jibgħat il-packets kollha li d-destinazzjoni tagħhom tkun f'network barrani.
:::

## L-esperiment

1. Aqleb għall-modalità ta' tħaddim :fa-play: **Ħaddem** u agħmel ping lil Clara minn **Anna** (`ping 172.16.0.10`). Din id-darba taħdem — oqgħod attent għall-valur `ttl=` fl-output.
2. Aqleb għall-modalità :fa-magnifying-glass: **Traċċa** u iftaħ trace għal **Anna**.

Ħares lejn l-ewwel packet (l-ARP request):

:::quiz multi
Liema dikjarazzjonijiet dwar l-ewwel packet huma tajbin?
- [x] Anna diġà taf l-IP address ta' Clara qabel tibgħat il-packet
- [ ] Anna tistaqsi dwar il-MAC address ta' Clara
- [x] Anna tistaqsi lill-apparati kollha fin-network dwar il-MAC address tar-router
- [ ] Anna tistaqsi lis-switch dwar l-IP address ta' Clara
:::

Issa kklikkja fuq l-ewwel `Echo (ping) request` u iftaħ **Ethernet II** u **Internet Protocol Version 4**. Qabbel il-MAC addresses mat-tweġiba ARP ta' qabel.

:::quiz multi
Liema dikjarazzjonijiet dwar il-ping huma tajbin?
- [x] Bħala destination IP address hemm Clara (`172.16.0.10`)
- [ ] Bħala destination IP address hemm ir-router (`192.168.0.1`)
- [x] Bħala destination MAC address hemm il-MAC address tar-router
- [ ] Anna tibgħat il-ping direttament lill-MAC address ta' Clara
:::

:::evaluate
Iċċekkja t-tweġibiet
:::

## X'jagħmel ir-router bil-packet

Ir-router jirċievi l-frame minn għand Anna, jiftaħ l-IP packet u jħares lejn id-**destination IP address**. Minn hemm jagħraf: Clara tinsab fin-network ta' `eth1`. Allura jpoġġi l-packet f'frame **ġdid** — bil-MAC address tiegħu stess bħala sender u l-MAC address ta' Clara bħala destinazzjoni — u jibgħatu hemm.

| X'jiġri fir-router bi … | |
|---|---|
| il-MAC addresses (layer 2)? | jiġu stabbiliti **mill-ġdid** — huma validi biss fin-network rispettiv |
| l-IP addresses (layer 3)? | **jibqgħu l-istess** — minn Anna sa Clara |
| it-Time to Live? | jonqos b'**1** |

:::tip Punt importanti
**Router** jaħdem fuq **layer 3**: Jibgħat il-packets lejn networks oħra abbażi tad-**destination IP address**. L-IP addresses jibqgħu l-istess fit-triq kollha, il-MAC addresses jiġu stabbiliti mill-ġdid f'kull network. Kull router inaqqas it-**Time to Live (TTL)** b'1 — jekk tilħaq 0, il-packet jiġi skartat. B'hekk packet ma jistax jduru bla tmiem.
:::

:::note
Tiftakar fil-broadcast storm mill-kapitlu 3.4? L-Ethernet frames m'għandhomx TTL — l-IP packets għandhom.
:::

## Lil min taf Anna? L-ARP cache

Tiftakar fil-kapitlu 1.2.3? Hemmhekk l-ARP deher biss qabel l-*ewwel* ping, għax il-PC ftakar it-tweġiba. Din il-lista tissejjaħ **ARP cache** (anke *ARP table*). It-talba tissejjaħ **ARP request**, it-tweġiba **ARP reply** (jew *ARP response*).

Aqleb għall-modalità ta' tħaddim :fa-play: **Ħaddem**, iftaħ it-:fa-terminal: **Terminal** fuq **Anna** u ħalli juriha l-ARP cache tagħha:

```
$ arp
```

:::quiz mc
X'hemm fl-ARP cache ta' Anna?
- [x] Biss l-IP address tar-router (`192.168.0.1`) bil-MAC address tiegħu
- [ ] L-IP address ta' Clara bil-MAC address ta' Clara
- [ ] L-addresses tar-router u ta' Clara
:::

:::evaluate
Iċċekkja t-tweġiba
:::

Anna qatt m'għandha bżonn il-MAC address ta' Clara: dak kollu li huwa maħsub għall-Firma B hija tibgħatu lir-router. Il-MAC address ta' Clara jafu biss ir-router — huwa stess staqsa dwaru permezz ta' ARP min-naħa tiegħu.

:::tip Punt importanti
Fl-**ARP cache** apparat jaħżen liema MAC address jappartjeni għal liema IP address — b'hekk ma jkollux bżonn jibgħat ARP request qabel kull packet. Jista' jintwera bil-kmand `arp`. PC jaf biss MAC addresses mill-network **tiegħu stess**: għad-destinazzjonijiet kollha f'networks barranin juża l-MAC address tar-router.
:::

:::note
Fin-networks reali, id-dħul fl-ARP cache jitneħħa wara ftit żmien u jerġa' jiġi mitlub meta jkun hemm bżonn — pereżempju jekk apparat sadanittant ikollu network card differenti. Fi BeaverTracer jibqgħu sakemm tkun għaddejja s-simulazzjoni.
:::

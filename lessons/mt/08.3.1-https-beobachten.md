# HTTP u HTTPS imqabbla

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Il-web server **www.beaver-schule.de** joffri l-portal tal-marki tal-iskola kemm permezz ta' HTTP kif ukoll permezz ta' HTTPS. X'jara min jisma' bil-moħbi?

## L-esperiment

1. Aqleb għall-:fa-play: **Ħaddem**-Modalità ta' tħaddim u iftaħ fuq il-**Client-PC** fil-:fa-globe: **Browser** l-ewwel `http://www.beaver-schule.de/`, imbagħad `https://www.beaver-schule.de/`.
2. Fil-modalità :fa-magnifying-glass: **Traċċa** iftaħ trace għall-**Client-PC**.
3. Fittex l-ewwel il-packet `HTTP/1.1 200 OK` u kklikkja fuqu. Hawn taħt fid-dettalji issib il-kontenut tal-paġna.

:::quiz mc
X'jista' jara min jisma' bil-moħbi f'każ ta' **HTTP**?
- [x] Il-websajt kollha kemm hi, anki l-marki ta' Anna
- [ ] Biss l-indirizz tas-server
- [ ] Xejn, għax HTTP jaħdem fuq TCP
:::

:::quiz short
Liema marka għandha Anna fil-Matematika?
= 2
:::

:::evaluate
Iċċekkja t-tweġibiet
:::

Issa l-parti tal-HTTPS. Fittex il-packet `[SYN]` li permezz tiegħu l-client jibda t-tieni konnessjoni.

:::quiz short
Liema destination port għandha l-konnessjoni HTTPS (kolonna **Info**, `… → ???`)?
= 443
:::

Issa niżżel `tls` fil-qasam tal-filtru tat-trace fuq nett — hekk tara biss il-packets tat-TLS.

:::quiz mc
X'jidher fil-kolonna **Info** tal-packets li fihom il-websajt?
- [ ] `HTTP/1.1 200 OK`
- [x] `Application Data`
- [ ] `Encrypted HTML`
:::

:::quiz multi
X'jista' xorta waħda jara min jisma' bil-moħbi f'każ ta' **HTTPS**?
- [x] L-indirizzi IP tal-client u tas-server
- [x] Li qed jintuża port 443, u għalhekk x'aktarx HTTPS
- [x] Madwar kemm qed tintbagħat data
- [ ] Liema paġna nfetħet u x'hemm fiha
:::

:::evaluate
Iċċekkja t-tweġibiet
:::

:::note
Kklikkja fuq packet ta' **Application Data**: id-data utili hija biss sekwenza ta' bytes li jidhru każwali. It-Tracer ma jistax jiddeċifrahom — ma jafx iċ-ċavetta tas-sessjoni aktar milli jafha attakkant.
:::

:::tip Punt importanti
Fil-każ ta' **HTTP**, kull min jisma' bil-moħbi jista' jaqra l-websajt kollha kemm hi. Fil-każ ta' **HTTPS** jara biss **min qed jitkellemma' min** (indirizzi IP, port 443) u **kemm** — il-kontenut jinsab ikkriptat fil-packets ta' **Application Data**.
:::

# Twaqqif ta' HTTPS

:::sim
url=/sims/lesson-8.3.3.btsim
:::

Hawn nkomplu minn fejn waqfet it-taqsima 8.2.2: Fuq il-web server **www.beaver-schule.de** hemm is-**Schul-CA** u certificate tas-server maħruġ minnha, u l-**Client-PC** jafda s-Schul-CA. Il-problema hi li l-web server għadu ma jitkellimx HTTPS.

## Qabel

Aqleb għall-modalità ta' tħaddim :fa-play: **Ħaddem** u fuq il-**Client-PC** iftaħ `https://www.beaver-schule.de/` fil-:fa-globe: **Browser**.

:::quiz mc
X'jiġri?
- [x] Il-konnessjoni ma tiġix stabbilita — ebda servizz ma qed jisma' fuq port 443
- [ ] Il-browser iwissi dwar certificate mhux sigur
- [ ] Il-paġna tidher mingħajr il-lukkett
:::

:::evaluate
Iċċekkja t-tweġiba
:::

## Ixgħel HTTPS

1. Fuq il-web server iftaħ l-**HTTP-Server** u ikklikkja fuq **Waqqaf** — sakemm is-server ikun qed jaħdem, is-settings ma jistgħux jinbidlu.
2. Mur fit-tab **HTTPS**:
    - Immarka **Ippermetti HTTPS**, **HTTPS-Port** `443`
    - F'**Certificate** agħżel iċ-certificate tas-server `www.beaver-schule.de` — mhux is-Schul-CA!
    - Ikklikkja fuq **Uża**
3. Ikklikkja fuq **Ibda**.

Iftaħ il-paġna mill-ġdid fuq il-Client-PC permezz ta' `https://`. Ikklikkja fuq il-lukkett u ċċekkja min harġu u l-validità.

:::task
title: HTTPS ġie stabbilit?
Jiċċekkja jekk il-Client-PC jistax jiġbed https://www.beaver-schule.de/ mingħajr twissija dwar certificate. Is-simulazzjoni trid tkun qed taħdem fil-modalità ta' tħaddim.
check: httpsOk(2, "https://www.beaver-schule.de/")
:::

:::quiz mc
Għaliex m'għandekx tagħżel iċ-certificate tas-**Schul-CA** fl-HTTP-Server?
- [ ] Għax ċ-certificates tas-CA ma jistgħux jikkriptaw
- [x] Għax inħareġ għall-isem `Schul-CA`, mhux għal `www.beaver-schule.de` — il-browser kien iwissi
- [ ] Għax is-Schul-CA m'għandhiex private key
:::

:::quiz mc
X'jara apparat li **ma** jafdax is-Schul-CA, pereżempju t-telefon ta' mistieden?
- [ ] Il-paġna għal kollox normali bil-lukkett
- [x] Twissija dwar certificate, għax ma jistax isegwi l-katina tal-fiduċja sa CA magħrufa
- [ ] Xejn, għax il-konnessjoni tiġi miċħuda
:::

:::evaluate
Iċċekkja t-tweġibiet
:::

:::note
Għal websites pubbliċi jinħtieġ certificate minn CA li tkun installata minn qabel fil-browsers kollha. Mill-2015 hemm **Let's Encrypt**, CA li toħroġ certificates bħal dawn b'xejn u awtomatikament — raġuni ewlenija għaliex illum kważi l-websites kollha jużaw HTTPS.
:::

:::tip Punt importanti
Għal **HTTPS** il-web server jeħtieġ **certificate tas-server b'private key**, li ismu jaqbel mal-indirizz, u jrid jisma' fuq **port 443**. Il-client jafda l-paġna biss jekk jaf is-**CA** li harġet iċ-certificate.
:::

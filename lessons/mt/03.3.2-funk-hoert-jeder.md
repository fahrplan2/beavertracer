# Ir-radju jisma' kulħadd

:::sim
url=/sims/lesson-3.3.2.btsim
:::

Issa hemm żewġ tablets fil-WLAN `Schule`: **Anna** (`192.168.0.30`) u **Ben** (`192.168.0.31`).

Ftakar fil-kapitolu 3.1: meta Anna għamlet ping lil Ben permezz tas-switch, Clara ma induna b'xejn — is-switch ibgħat il-pings biss lejn il-port ta' Ben. Fil-WLAN huwa l-istess? Aħseb ftit x'tahseb li se jiġri.

## L-esperiment

1. Aqleb għal modalità ta' tħaddim :fa-play: **Ħaddem** u agħmel ping lill-PC tal-iskola minn **Anna** (`ping 192.168.0.10`).
2. Aqleb għal modalità :fa-magnifying-glass: **Traċċa** u b'**+** iftaħ trace għal **Ben**, port `wlan0`.

:::quiz mc
X'tara f'Ben?
- [ ] Biss l-ARP request ta' Anna — bħal ma jiġri mas-switch
- [x] Il-packets kollha bejn Anna u l-PC tal-iskola, inklużi l-pings
- [ ] Xejn xejn, il-pings m'humiex affari ta' Ben
:::

:::evaluate
Iċċekkja t-tweġiba
:::

## X'hemm warajh

L-mewġ tar-radju jinfirex fid-direzzjonijiet kollha. Għalhekk dak li tibgħat Anna jaslu għand *kull* apparat fil-qrib — mhux biss għand l-Access Point. Ir-radju huwa **shared medium**. It-tablet ta' Ben normalment jinjora dak kollu li mhux indirizzat lilu. Iżda kull min *irid* jirreġistra, jista' jaqra kollox.

| | Switch (kejbil) | WLAN (radju) |
|---|---|---|
| Min jirċievi unicast? | biss il-port tar-receiver | kull apparat fil-firxa |
| Terza persuna tista' taqra? | normalment le | iva, faċilment |

:::tip Punt importanti
Ir-radju huwa **shared medium**: dak kollu li jintbagħat fil-WLAN jista' jaqbdu kull apparat fil-firxa. Għalhekk WLAN irid ikun **encrypted** (illum b'**WPA2** jew **WPA3**) — hekk il-barranin jistgħu jirċievu d-data, iżda ma jistgħux jaqrawha.
:::

:::note
BeaverTracer ma jissimulax l-encryption tal-WLAN — għalhekk hawnhekk tista' taqra kollox. Kif taħdem l-encryption se titgħallem fil-kapitolu 8.
:::

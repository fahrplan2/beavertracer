# Troubleshooting: Il-paġna tal-kuntatt nieqsa

:::sim
url=/sims/lesson-6.1.3.btsim
:::

Is-segretarjat jirrapporta: "Fuq il-websajt tagħna, il-link **Kontakt** jwassal biss għal messaġġ ta' żball." Il-paġna tal-kuntatt suppost tkun aċċessibbli fuq `http://192.168.0.20/kontakt.html`. Sib l-iżball u rranġah.

<details>
<summary>Tip 1: Xi jirrapporta s-server?</summary>

Iftaħ il-paġna tal-kuntatt fil-Browser jew b'`curl -v`. Liema status code jerġa' lura? Il-paġna tal-iżball turik ukoll fejn is-server fittex il-fajl.
</details>

<details>
<summary>Tip 2: Fejn jinsabu l-fajls?</summary>

Il-web server iwassal biss fajls mid-**Document Root** tiegħu — dan jidher fl-app **HTTP-Server**. Fuq is-**Server**, fit-**Terminal** ħares b'`ls` x'hemm hemm, u fittex il-paġna tal-kuntatt ukoll f'`/home`.
</details>

<details>
<summary>Tip 3: Ċaqlaq fajl</summary>

B'`mv` tiċċaqlaq fajl: `mv <Quelle> <Zielordner>`.
</details>

:::task
title: Il-paġna tal-kuntatt irranġata?
Jiċċekkja jekk il-paġna tal-kuntatt tinsabx fid-Document Root tal-web server.
check: fileExists(2, "/var/www/kontakt.html")
:::

## X'kien qed jiġri?

:::quiz multi
Liema dikjarazzjonijiet huma veri?
- [x] Is-server wieġeb b'`404 Not Found`
- [x] Il-fajl kien f'`/home` minflok fid-Document Root `/var/www`
- [ ] Il-web server ma kienx inbeda xejn
- [ ] Il-Browser uża l-IP address ħażina
:::

:::evaluate
Iċċekkja t-tweġiba
:::

:::tip Punt importanti
**404** ifisser: il-web server qed jaħdem u jista' jintlaħaq, imma l-**fajl** mitlub ma jeżistix f'dan il-path. Is-server jfittex biss fid-**Document Root** tiegħu (hawn `/var/www`). Qabbel: jekk is-server ma jweġibx xejn jew iweġib b'`RST`, il-problema tkun iżjed fil-fond — fin-network jew fis-servizz innifsu (kapitlu 5.3.2).
:::

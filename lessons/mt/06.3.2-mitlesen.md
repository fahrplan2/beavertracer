# Aqra l-e-mail fit-tracer

:::sim
url=/sims/lesson-6.3.btsim
:::

Bħal HTTP, SMTP huwa wkoll **protokoll tat-test**. Ara x'jgħaddi kollu bħala test sempliċi (plain text) mal-wire.

## L-esperiment

1. Fil-modalità :fa-play: **Ħaddem**, ibgħat mail minn **Anna** lil `ben@biber-mail.de`, bħal fil-paġna ta' qabel.
2. Fil-modalità :fa-magnifying-glass: **Traċċa**, iftaħ trace għal **Anna**. Fil-kolonna **Info** tara d-djalogu SMTP: il-linji b'`C:` jibgħathom il-client, il-linji b'`S:` is-server.

:::quiz short
Liema indirizz hemm wara `MAIL FROM:`?
= anna@beaver-schule.de
= <anna@beaver-schule.de>
:::

:::quiz short
U liema wara `RCPT TO:`?
= ben@biber-mail.de
= <ben@biber-mail.de>
:::

:::quiz mc
Liema kodiċi numeriku jibgħat is-server meta jaċċetta kmand?
- [x] `250`
- [ ] `200`
- [ ] `404`
:::

:::evaluate
Iċċekkja t-tweġibiet
:::

## U l-password?

Qabel `MAIL FROM`, il-programm ta' Anna jidentifika ruħu b'`AUTH PLAIN` u b'sekwenza ta' karattri bħal `AGFubmEAZ2VoZWlt`. Din tidher kriptata, imma mhix: hija biss **Base64**, kodifikazzjoni li kulħadd jista' jittraduċiha lura immedjatament — fiha hemm `anna` u l-password tagħha `geheim`.

Issa ġib il-posta għand **Ben** (**Ġib**) u iftaħ trace għal **Ben**. Meta tinġabar permezz ta' IMAP, tidher saħansitra aktar ċar:

:::quiz short
Liema password jibgħat il-programm tal-e-mail ta' Ben lis-server bħala plain text? (Ħares lejn il-linja b'`LOGIN`.)
= biber123
:::

:::evaluate
Iċċekkja t-tweġiba
:::

:::warning
Mingħajr encryption, kull min jirreġistra t-traffiku jista' jaqra **l-kontenut, is-sender, ir-receiver u l-passwords**. Għalhekk illum jintużaw varjanti kriptati (eż. SMTP b'STARTTLS, IMAPS fuq port 993). Kif taħdem din se titgħallem fil-kapitlu 8.
:::

:::tip Punt importanti
**SMTP**, **POP3** u **IMAP** huma protokolli tat-test: kmandi bħal `MAIL FROM`, `RCPT TO`, `DATA` (SMTP) jew `LOGIN` (IMAP) u t-tweġibiet huma leġibbli. Mingħajr encryption, anki l-**passwords** jgħaddu mal-wire bħala plain text (jew kodifikati biss b'Base64).
:::

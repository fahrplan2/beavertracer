# Firem diġitali

Bil-encryption tinkiseb **kunfidenzjalità**, bil-hash values wieħed jinduna b'tibdil. Imma kif wieħed juri **minn għand min** ġiet messaġġ? Fuq il-karta wieħed jiffirma. Fin-network għal dan hemm il-**firma diġitali**.

## Il-pari ta' keys użata bil-maqlub

Meta wieħed jagħmel encryption, is-sender juża l-key **pubblika** tar-receiver. Mal-firma jiġri l-maqlub: is-sender juża l-key **privata tiegħu stess**. Billi biss hu għandu din il-key, huwa biss jista' joħloq din il-firma. Min-naħa l-oħra, kulħadd jista' jivverifikaha — bil-key **pubblika** tas-sender.

**Iffirmar** (Anna tiffirma kuntratt):

1. Anna tikkalkula l-**hash value** tal-kuntratt.
2. Hi tikkombina l-hash value mal-**key privata** tagħha. Ir-riżultat huwa l-**firma**.
3. Hi tibgħat il-kuntratt flimkien mal-firma lil Ben.

**Verifika** (Ben jivverifika l-firma):

1. Ben jikkalkula hu stess il-hash value tal-kuntratt li rċieva.
2. Hu jivverifika l-firma bil-**key pubblika** ta' Anna: Taqbel ma' dan il-hash value?
3. Jekk taqbel, Ben jaf żewġ affarijiet:
    - Il-kuntratt tassew ġej minn Anna — hi biss għandha l-key privata (**awtentiċità**).
    - Il-kuntratt ma nbidilx matul it-triq — inkella kien ikollu hash value differenti (**integrità**).

:::note
Għaliex Anna tiffirma biss il-hash value u mhux il-kuntratt kollu? Il-metodi asimmetriċi huma bil-mod. Il-hash value dejjem huwa qasir — kemm jekk il-kuntratt ikollu paġna u kemm jekk ikollu elf paġna.
:::

:::quiz mc
B'liema key Anna **toħloq** il-firma tagħha?
- [x] Bil-key privata tagħha
- [ ] Bil-key pubblika tagħha
- [ ] Bil-key pubblika ta' Ben
:::

:::quiz mc
B'liema key Ben **jivverifika** l-firma?
- [ ] Bil-key privata tiegħu
- [x] Bil-key pubblika ta' Anna
- [ ] Bil-key privata ta' Anna
:::

:::quiz mc
Attakkant jaqbad il-kuntratt u jbiddel l-ammont. Il-firma jhalliha kif inhi. X'jiġri meta Ben jivverifika?
- [x] Il-verifika tfalli, għax il-kuntratt mibdul għandu hash value differenti
- [ ] Il-verifika tirnexxi, għax il-firma hija awtentika
- [ ] Ben ma jistax jivverifika l-firma xejn, għax ma jafx il-key privata ta' Anna
:::

Iċċekkja t-tweġibiet
:::

:::quiz match
Tikteb b'mod kunfidenzjali lil Ben -> tagħmel encryption bil-key pubblika ta' Ben

Tiffirma dokument -> bil-key privata tiegħek stess

:::

:::evaluate
Iċċekkja t-tqabbil
:::

:::tip Punt importanti
**Firma diġitali** toħloqha s-sender mill-**hash value** tal-messaġġ u mill-**key privata** tiegħu. Kulħadd jista' jivverifikaha bil-**key pubblika** tas-sender. Firma valida turi **minn għand min** ġie l-messaġġ (**awtentiċità**) u li **ma nbidilx** (**integrità**).
:::

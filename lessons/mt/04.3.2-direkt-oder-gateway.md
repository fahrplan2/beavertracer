# Direttament jew permezz tal-gateway?

:::sim
url=/sims/lesson-4.3.2.btsim
:::

Qabel ma PC jibgħat packet, jiddeċiedi: id-destinazzjoni tinsab fin-**network tiegħu stess**? Biex jaf dan, iqabbel in-network part tal-indirizz tiegħu stess man-network part tal-indirizz tad-destinazzjoni — bl-għajnuna tan-netmask tiegħu.

## Il-proċess

1. **L-IP tad-destinazzjoni tinsab fin-network tiegħu stess?**
   - **Iva:** Il-PC jibgħat il-packet **direttament** lid-destinazzjoni. Għandu bżonn il-MAC address tad-destinazzjoni.
   - **Le:** Il-PC jibgħat il-packet lill-**gateway**. Għandu bżonn il-MAC address tar-router. Jekk ma jkun hemm l-ebda gateway irreġistrat, ma jistax jibgħat il-packet xejn.
2. **Diġà jafu l-MAC address li għandu bżonn** (jinsab fl-ARP cache tiegħu)? Jekk le, isaqsi dwaru permezz ta' **ARP**.
3. Jibgħat il-frame lil dan il-MAC address. L-**IP address tad-destinazzjoni** fil-packet hija fiż-żewġ każijiet id-destinazzjoni vera.

| | direttament (network tiegħu stess) | permezz tal-gateway (network barrani) |
|---|---|---|
| L-ARP jistaqsi dwar … | il-MAC tad-destinazzjoni | il-MAC tar-router |
| MAC tad-destinazzjoni fil-frame | destinazzjoni | router |
| IP tad-destinazzjoni fil-packet | destinazzjoni | destinazzjoni |

## Troubleshooting: Ditta B ma tistax tintlaħaq

Minn mal-bieraħ Anna ma tistax tilħaq il-PCs fid-Ditta B. Hekk *suppost* inhu mwaqqaf in-network:

| Apparat | IP address | Gateway |
|---|---|---|
| Anna | `192.168.0.10/24` | `192.168.0.1` |
| Ben | `192.168.0.11/24` | `192.168.0.1` |
| Clara | `172.16.0.10/24` | `172.16.0.1` |
| David | `172.16.0.11/24` | `172.16.0.1` |

Sib l-iżbalji u irranġahom.

<details>
<summary>Suġġeriment 1: Il-ping ta' Anna jaslu x'imkien?</summary>

Ibgħat ping minn Anna lil Clara u iftaħ trace għal **Clara**. Il-ping wasal? U Claraweġbet?
</details>

<details>
<summary>Suġġeriment 2: David x'qed jagħmel?</summary>

Ibgħat ping minn Anna lil David u iftaħ trace għal **David**. Liema IP address qed isaqsi dwarha David permezz ta' ARP — u jirċievi tweġiba?
</details>

:::task
title: Ditta B tintlaħaq mill-ġdid?

:::tip Punt importanti
PC għandu bżonn il-gateway t-tajjeb mhux biss biex jibgħat, imma wkoll biex **iweġeb**: mingħajr gateway il-ping jaslu, imma t-tweġiba ma ssib l-ebda mod biex terġa' lura. Jekk ikun hemm **gateway address ħażina** irreġistrata, il-PC jistaqsi għalxejn permezz ta' ARP dwar router li ma jeżistix.
:::

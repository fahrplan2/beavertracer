# Min jiġi l-packet?

:::sim
url=/sims/lesson-3.1.2.btsim
:::

Issa Anna, Ben u Clara huma konnessi mas-switch (ports 1, 2 u 3). Meta Anna tibgħat packet lil Ben: jirċevih Ben biss — jew Clara wkoll?

Aħseb ftit x'taħseb li se jiġri. Imbagħad ipprova.

## L-esperiment

1. Aqleb għall-:fa-play: **Ħaddem** Modalità ta' tħaddim, iftaħ it-:fa-terminal: **Terminal** fuq **Anna** u agħmel ping lil Ben:
   ```
   $ ping 192.168.0.11
   ```
2. Aqleb għall-:fa-magnifying-glass: **Traċċa** Modalità ta' tħaddim u b'**+** iftaħ trace għal **Clara**, port `eth0`.
3. B'**+** iftaħ it-tieni trace għal **Ben**, port `eth0`. Fuq nett tista' taqleb 'l hawn u 'l hemm bejn iż-żewġ traces.

:::quiz short
Kemm packets waslu għand **Clara**?
= 1
= wieħed
= waħda
:::

:::quiz mc

- [x] It-talba ARP "Who has 192.168.0.11?" lil kulħadd (broadcast)
- [ ] Ping (Echo Request) minn Anna
- [ ] It-tweġiba ARP ta' Ben
:::

:::quiz mc
U x'wasal għand **Ben**?

## X'hemm warajh

It-talba ARP għandha **broadcast** bħala destinazzjoni — hija indirizzata lil *kulħadd*. Għalhekk is-switch għadda it-talba lil kull port, anki lil Clara. Il-pings, min-naħa l-oħra, kienu indirizzati lil Ben biss. Is-switch bagħathom esklussivament lejn il-port ta' Ben — Clara ma ndunat bl-ebda wieħed minnhom.

:::tip Punt importanti
**Broadcast** huwa indirizzat lill-apparati kollha fil-local network — is-switch jqassmu lill-ports kollha. **Unicast** huwa indirizzat lil apparat wieħed biss — is-switch jibgħatu biss lill-port li miegħu huwa konness dak l-apparat.
:::

## Ħarsa ġewwa s-switch

Imma kif jaf is-switch ma' liema port huwa konness Ben? Erġa' aqleb għall-:fa-play: **Ħaddem** Modalità ta' tħaddim u kklikkja fuq is-**Switch**. Fit-tab **SAT** tara t-tabella tal-indirizzi tiegħu b'żewġ kolonni: **MAC** u **Port**.

:::quiz mc
Liema apparati jidhru fit-tabella tal-indirizzi?
- [ ] Anna, Ben u Clara
- [x] Anna u Ben biss
- [ ] Ben biss
:::

:::quiz short
Ma' liema port huwa konness Ben skont it-tabella? Suġġeriment: l-indirizz MAC ta' Ben issibu fit-Tracer fit-tweġiba ARP tiegħu `192.168.0.11 is at …`.
= 2
= port 2
:::

:::quiz mc
Għaliex Clara ma tidhirx fit-tabella?
- [ ] Il-kejbil tagħha huwa miksur
- [x] Għadha ma bagħtet ebda packet
- [ ] Is-switch jaħżen massimu ta' żewġ entrati
:::

:::evaluate
Iċċekkja t-tweġibiet
:::

Is-switch **jitgħallem** waqt li jaħdem: għal kull frame li jaslu, jarah l-indirizz MAC tas-**sender** u jiftakar ma' liema port huwa konness dak l-apparat. Meta waslet it-talba ARP ta' Anna, innota "Anna → Port 1", u meta waslet it-tweġiba ta' Ben "Ben → Port 2". Clara ma bagħtet xejn — għalhekk għadu ma jafhiex.

:::tip Punt importanti
Switch jiftakar fit-**tabella tal-indirizzi** tiegħu (**SAT**, *Source Address Table*) taħt liema indirizz MAC liema apparat jista' jintlaħaq fuq liema port — jitgħallem dan mill-indirizzi tas-sender. Jekk jaf id-destinazzjoni ta' frame, jibgħatu lil dak il-port biss. Jekk ma jafhiex (jew jekk huwa broadcast), jibgħatu lill-ports kollha.
:::

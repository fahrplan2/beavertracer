# IPv6 fin-network

:::sim
url=/sims/lesson-4.6.3.btsim
:::

Mal-switch huma konnessi Anna, Ben u router. Fuq Anna u Ben, l-IPv6 hija ssettjata fuq **SLAAC (automatisch)** — ħadd ma daħħal IPv6 address għalihom. Ir-router jaf il-prefiss `2001:db8:1::/64`.

## Minn fejn tiġi l-address?

1. Aqleb għall-:fa-play: **Ħaddem** Modalità ta' tħaddim u stenna ftit sekondi.
2. Fuq **Anna** iftaħ it-:fa-terminal: **Terminal** u ikteb `ip a`.

Minbarra l-IPv4 address, tara żewġ linji bi `inet6`: address wieħed bi `scope link` u wieħed bi `scope global`.

:::quiz mc
Liema minn dawn iż-żewġ IPv6 addresses hija l-link-local address?
- [x] Dik li tibda b'`fe80::` (`scope link`)
- [ ] Dik li tibda b'`2001:db8:1:` (`scope global`)
:::

:::quiz mc
Minn fejn jiġi l-prefiss `2001:db8:1:0` tal-global address?
- [ ] Anna ħarġitu minn rasha
- [x] Mir-router — huwa jħabbar il-prefiss fin-network
- [ ] Mis-switch
:::

:::evaluate
Iċċekkja t-tweġibiet
:::

Qabbel l-**Interface-ID** (l-aħħar erba' blokki) mal-**MAC address** t'Anna — issibha fl-:fa-gear: **IP Settings** fil-qiegħ tal-pannell. Pereżempju, mill-MAC address `aa:28:39:e2:41:82` isir l-Interface-ID `a828:39ff:fee2:4182`: fnofs jiddaħħal `ff:fe`, u bit wieħed fil-bidu jinqaleb (għalhekk minn `aa` isir `a8`).

Din il-proċedura tissejjaħ **SLAAC** (*Stateless Address Autoconfiguration*): ir-router iħabbar il-prefiss, u kull apparat jifforma l-Interface-ID waħdu.

:::note
Peress li l-MAC address tidentifika apparat b'mod uniku, apparat jista' jiġi rikonoxxut kullimkien fl-internet permezz tal-Interface-ID. Għalhekk l-apparati reali ġeneralment jużaw ukoll Interface-IDs każwali li jinbidlu regolarment (*Privacy Extensions*) — ftit protezzjoni tad-data.
:::

## Insibu l-ġirien — mingħajr ARP

1. Fuq **Ben** ikteb `ip a` u ħu nota tal-IPv6 address **globali** tiegħu.
2. Agħmel ping lejha minn **Anna**, pereżempju `ping 2001:db8:1:0:…` (bl-address sħiħa ta' Ben).
3. Aqleb għall-:fa-magnifying-glass: **Traċċa** Modalità u iftaħ trace għal **Anna**.

Ħares lejn il-packets eżatt qabel l-ewwel `Echo (ping) request`.

:::quiz multi
Liema dikjarazzjonijiet huma tajbin?
- [x] Minflok ARP request, Anna tibgħat **Neighbor Solicitation** („Min għandu din l-address?“)
- [x] Ben iwieġeb b'**Neighbor Advertisement** u jgħid il-MAC address tiegħu
- [x] It-talba tmur lejn multicast address (`ff02::1:ff…`), mhux lil kulħadd permezz ta' broadcast
- [ ] Anna tibgħat ARP request bħal fl-IPv4
- [x] Ir-router jibgħat regolarment **Router Advertisements** lil `ff02::1` — fihom hemm il-prefiss
:::

:::evaluate
Iċċekkja t-tweġibiet
:::

:::tip Punt importanti
Fl-IPv6, **NDP** (*Neighbor Discovery Protocol*, parti minn ICMPv6) jieħu f'idejh il-kompiti tal-ARP: permezz ta' **Neighbor Solicitation** u **Neighbor Advertisement**, l-apparati jsibu l-MAC addresses tal-ġirien tagħhom. Permezz ta' **Router Advertisements**, ir-router iħabbar il-prefiss — minnu l-apparati jifformaw l-address tagħhom stess permezz ta' **SLAAC**.
:::

# NAT: ħafna devices, indirizz wieħed

:::goal
**Għan tat-tagħlim:** Tista' turi fit-Tracer kif NAT jibdel l-indirizz tas-sender, taqra n-NAT table u tispjega għaliex konnessjonijiet minn barra lejn il-home network jeħtieġu port forward.
:::

:::sim
url=/sims/lesson-7.1.btsim
:::

Il-provider normalment jagħti lil konnessjoni domestika **indirizz IPv4 pubbliku wieħed biss** — l-indirizz WAN tal-home router. L-apparat kollu fil-home network jrid jaqsam dan l-indirizz. Il-mod kif jaħdem dan jissejjaħ **NAT** (*Network Address Translation*, traduzzjoni tal-indirizzi).

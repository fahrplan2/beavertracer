# Network address, broadcast address u hosts

F'kull network, żewġ indirizzi għandhom rwol speċjali:

- In-**network address** hija l-**aktar baxxa** indirizz tan-network: il-bits kollha fil-host part huma 0. Tindika n-network kollu kemm hu, eż. fir-routing tables.
- Il-**broadcast address** hija l-**ogħla** indirizz tan-network: il-bits kollha fil-host part huma 1. Dak li jintbagħat lilha jmur għand it-tagħmir kollu fin-network.

L-ebda waħda minn dawn l-indirizzi **ma** tingħata lil apparat. L-indirizzi kollha bejniethom huma disponibbli għall-apparat (**hosts**).

## Eżempju sempliċi

`192.168.0.12/24` — il-host part huwa l-aħħar octet:

| | Indirizz |
|---|---|
| Network address (host part = 0) | `192.168.0.0` |
| Broadcast address (host part = 255) | `192.168.0.255` |
| Range għall-hosts | `192.168.0.1` – `192.168.0.254` |
| Numru ta' hosts | 254 |

## Meta l-fruntiera tkun f'nofs octet

Isir aktar diffiċli meta l-prefix length ma tkunx multiplu ta' 8. F'dak il-każ tikkonverti l-octet ikkonċernat għal binary system. Eżempju: `194.9.190.12/27`.

L-ewwel tliet octets jappartjenu kompletament għan-[[n|network part]] (24 bit). Mill-aħħar octet, **3 bits** oħra jappartjenu għan-network part (24 + 3 = 27), il-**5 bits** li fadal għall-[[h|host part]]:

| | l-aħħar octet (binary) | deċimali |
|---|---|---|
| IP address | [[n|000]][[h|01100]] | 12 |
| Netmask (`/27`) | [[n|111]][[h|00000]] | 224 |
| Network address: host bits għal 0 | [[n|000]][[h|00000]] | **0** |
| Broadcast address: host bits għal 1 | [[n|000]][[h|11111]] | **31** |

Riżultat:

- Network address: `194.9.190.0`
- Broadcast address: `194.9.190.31`
- Range għall-hosts: `194.9.190.1` – `194.9.190.30`
- Numru ta' hosts: 2⁵ − 2 = **30**

:::tip Punt importanti
**Network address:** il-host bits kollha għal 0 (l-aktar indirizz baxx). **Broadcast address:** il-host bits kollha għal 1 (l-ogħla indirizz). It-tnejn ma jingħatawx lil apparat. Network bil-prefix length *n* għandu **2<sup>32 − n</sup> − 2** indirizzi li jistgħu jintużaw għall-hosts.
:::

:::tip Suġġeriment: id-daqs tal-blokk
Jekk fhimt il-metodu fil-binary system, hemm shortcut: **256 inqas l-octet tal-maskra** jagħti d-daqs ta' network f'dak l-octet. Għal `/27` (maskra 224) dan huwa 256 − 224 = **32**. In-networks imbagħad jibdew fi 0, 32, 64, 96 … — l-indirizz `.12` jinsab fin-network li jibda minn `.0`, l-indirizz `.70` fin-network li jibda minn `.64`.
:::

## L-iktar daqsijiet importanti ta' network

| Prefix | Netmask | Hosts |
|---|---|---|
| `/8` | `255.0.0.0` | 16 777 214 |
| `/16` | `255.255.0.0` | 65 534 |
| `/24` | `255.255.255.0` | 254 |
| `/25` | `255.255.255.128` | 126 |
| `/26` | `255.255.255.192` | 62 |
| `/27` | `255.255.255.224` | 30 |
| `/28` | `255.255.255.240` | 14 |
| `/29` | `255.255.255.248` | 6 |
| `/30` | `255.255.255.252` | 2 |

:::note
L-iżgħar network użat komunement fil-prattika huwa `/30`: għandu eżattament żewġ indirizzi li jistgħu jintużaw u spiss jintuża għall-konnessjoni bejn żewġ routers. `/32` jindika indirizz wieħed — bħala network ma jistax jintuża, iżda jidher fir-routing tables u fir-regoli tal-firewall.
:::

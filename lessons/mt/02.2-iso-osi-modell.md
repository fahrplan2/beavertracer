Mill-esperiment fil-paġna li għaddiet diġà taf erba' minn dawn il-layers: Ethernet (2), IPv4 (3), TCP (4) u HTTP (7). Dawn huma eżattament in-numri u l-kuluri li juriek it-tracer fil-protocol tree.

:::tip Għajnuna biex tiftakar
Mil-layer 7 'l isfel: **A**ħna **P**ersuni **S**ervizzjevoli **T**a' **N**etwork **D**ejjem **P**ronti — **A**pplication, **P**resentation, **S**ession, **T**ransport, **N**etwork, **D**ata Link, **P**hysical.
:::

:::note Każijiet fuq il-limitu
Mhux kull protokoll jaqbel eżattament f'layer waħda. Għalhekk, għal dawn il-protokolli t-tracer juri diversi layers:

- **ARP** — layer 2/3: m'għandux IP header, imma jgħaqqad l-IP addresses (layer 3) mal-hardware addresses (layer 2).
- **TLS** — layer 4/5: joqgħod direttament fuq it-TCP u jamministra session sigura.
- **HTTPS** (HTTP ġewwa TLS) — layers 5–7: l-application layer klassika tal-mudell TCP/IP, li se tkun taf fil-paġna li jmiss.
:::

:::note
Il-layer 1 tiddeskrivi t-trasmissjoni attwali tas-sinjali fuq il-kejbil jew bir-radju. BeaverTracer ma jissimulax dan il-livell — il-kejbils dejjem jitqiesu bħala konnessi mingħajr żbalji, u m'hemm la problemi tas-sinjal u lanqas collisions. Għalhekk, fit-tracer, l-analiżi tibda prattikament mil-layer 2.
:::

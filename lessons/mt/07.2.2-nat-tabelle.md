# In-NAT table

:::sim
url=/sims/lesson-7.1.btsim
:::

Meta l-PC u t-tablet jiftħu l-istess web page fl-istess ħin, it-talbiet t'tnejn jaslu għand il-web server minn `203.0.113.2`. Kif taf il-home router għal min hija maħsuba risposta? Iżomm rekord — fl-**in-NAT table**.

## L-esperiment

1. Aqleb għall-Modalità ta' tħaddim :fa-play: **Ħaddem** u iftaħ `http://www.beispiel.de/` fuq il-**PC** u fuq it-**Tablet**.
2. Ikklikkja fuq il-**Heimrouter** u iftaħ it-tab **NAT**.

Kull ringiela hija **mappatura**: il-protokoll, l-LAN IP u l-LAN port tal-apparat fil-home network — u l-**WAN port** li r-router juża għalih fuq l-indirizz pubbliku tiegħu.

:::quiz short
Liema WAN IP jidher fuq it-tabella?
= 203.0.113.2
:::

:::quiz mc
Il-PC u t-tablet it-tnejn waqqfu konnessjoni bl-LAN port `49152`. Liema WAN port jieħdu?
- [ ] It-tnejn l-istess wieħed, `49152`
- [x] Kull wieħed differenti — inkella r-router ma jkunx jaf lil min tappartjeni r-risposta
- [ ] Xejn, in-NAT jibdel biss l-IP address
:::

:::quiz mc
Risposta mill-web server tasal fuq `203.0.113.2` b'**destination port** speċifiku. X'jagħmel il-home router biha?
- [x] Ifittex il-port fl-in-NAT table u jibgħat il-packet lejn l-LAN IP u l-LAN port korrispondenti
- [ ] Jibgħat il-packet lill-apparati kollha fil-home network
- [ ] Jarmi l-packet
:::

:::evaluate
Iċċekkja t-tweġibiet
:::

Hawnhekk jerġgħu jidhru l-**ports** mill-kapitlu 5: peress li n-NAT jikteb mill-ġdid ukoll il-ports, mijiet ta' konnessjonijiet jistgħu jaqsmu indirizz wieħed. Fil-fatt, għalhekk jissejjaħ **PAT** (*Port Address Translation*) jew *NAT bi traduzzjoni tal-port* — iżda fil-ħajja ta' kuljum ngħidu sempliċement NAT.

Hekk tista' tidher traduzzjoni bħal din, pereżempju:

| | Packet mill-PC (fil-home network) | l-istess packet fuq l-internet |
|---|---|---|
| Sender | `192.168.178.20 : 49152` | `203.0.113.2 : 10001` |
| Receiver | `192.0.2.80 : 80` | `192.0.2.80 : 80` |

:::tip Punt importanti
Fl-**in-NAT table** ir-router jiftakar għal kull konnessjoni liema apparat (**LAN IP u LAN port**) jinsab wara liema **WAN port**. It-tweġibiet mill-internet jerġa' jassenjahom lill-apparat t-tajjeb permezz tad-destination port. Peress li l-ports jinkitbu mill-ġdid ukoll, aktar eżatt nitkellmu dwar **PAT**.
:::

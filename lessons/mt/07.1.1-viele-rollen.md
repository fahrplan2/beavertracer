## Dak kollu li hemm ġewwa l-home router

| Rwol fil-home router | X'jagħmel | taf minn |
|---|---|---|
| **Switch** | iqabbad l-apparat mas-sokits LAN | Kapitolu 3.1 |
| **Access Point** | idaħħal mowbajls, tablets u laptops fin-network bil-WLAN | Kapitolu 3.3 |
| **Router** | iqabbad il-home network man-network tal-provider — huwa l-**gateway** | Kapitolu 4.3 |
| **DHCP Server** | jqassam l-indirizzi, il-gateway u d-DNS server | Kapitolu 6.4 |
| **DNS** | jgħaddi t-talbiet tal-ismijiet 'il quddiem jew jindika d-DNS server tal-provider | Kapitolu 6.2 |
| **NAT** | idaħħal l-apparat kollu fl-internet permezz ta' indirizz pubbliku **wieħed** | ġdid — Taqsima 7.2 |

Il-konnessjoni **WAN** (*Wide Area Network*) twassal għand il-provider, il-konnessjonijiet **LAN** u l-WLAN jwasslu fil-home network. Ħafna home routers fihom ukoll **modem** — dan jittraduċi d-data għall-linja (DSL, kejbil, fibra ottika). BeaverTracer ma jissimulax dan; hawnhekk il-konnessjoni WAN hija direttament man-network tal-provider.

:::quiz match
Switch -> Iqabbad l-apparat mas-sokits LAN
Access Point -> Idaħħal tablets u mowbajls fin-network bil-WLAN
DHCP Server -> Iqassam l-indirizzi lill-apparat fil-home network
Router -> Iqabbad il-home network man-network tal-provider
:::

:::evaluate
Iċċekkja t-tqabbil
:::

:::tip Punt importanti
**Home router** jgħaqqad diversi apparat f'wieħed: **switch**, **WLAN Access Point**, **router** (gateway lejn l-internet), **DHCP Server** u **DNS forwarding** — flimkien ma' **NAT**. Il-konnessjoni **WAN** twassal għand il-provider, il-konnessjonijiet **LAN** u l-WLAN jwasslu fil-home network.
:::

# Troubleshooting: ir-rotta tar-ritorn

:::sim
url=/sims/lesson-4.5.3.btsim
:::

L-istess setup bħal qabel: Firma A — Router A — Zwischennetz — Router B — Firma B. L-amministratriċi daħħlet fuq **Router A** ir-rotta lejn Firma B (`172.16.0.0/24` via `10.0.0.2`). Minkejja dan, Anna tirrapporta: Clara ma tweġibx.

Sib l-iżball u rranġah.

<details>
<summary>Suġġeriment 1: Il-ping ta' Anna jaslilha xorta waħda?</summary>

Ibgħat ping minn Anna lejn Clara u iftaħ trace għal **Clara**. Il-ping jaslilha — u hi twieġeb?
</details>

<details>
<summary>Suġġeriment 2: Kemm jasal traceroute?</summary>

Ikteb `traceroute 172.16.0.10` fuq Anna. Sa liema router jerġgħu lura t-tweġibiet — u liema router kellu jgħaddi t-tweġibiet ta' Clara lil Anna?
</details>

<details>
<summary>Suġġeriment 3: Min jaf liema network?</summary>

Ħares lejn ir-routing table ta' **Router B**. Jaf fejn imorru l-packets għal `192.168.0.0/24`?
</details>

:::task
title: Il-konnessjoni rranġata?
Iċċekkja jekk Router B jafx it-triq lejn Firma A u jekk Anna tilħaqx lil Clara. Is-simulazzjoni trid taħdem fil-Modalità ta' tħaddim biex dan jitwettaq.
check: hasRoute(5, "192.168.0.0/24")
check: pingOk(9, 11)
:::

## X'kien qed jiġri?

:::quiz multi
X'osservajt waqt it-troubleshooting?
- [x] Il-ping ta' Anna wasal għand Clara, u Clara weġbet
- [x] It-tweġiba waqfet f'Router B, għax ma kienx jaf lil Firma A
- [ ] Router A skarta l-ping ta' Anna
- [x] `traceroute` wara Router A wera biss `*`, għalkemm it-triq tal-andata kienet taħdem
:::

:::evaluate
Iċċekkja t-tweġiba
:::

:::tip Punt importanti
Kull konnessjoni teħtieġ **triq tal-andata u triq tar-ritorn**: kull router fit-triq irid jaf iż-żewġ networks — in-network tad-destinazzjoni u n-network tas-sender. **Rotta tar-ritorn** nieqsa hija waħda mill-iżbalji tar-routing l-aktar komuni. Oqgħod attent: `traceroute` juri biss minn fejn ma tergħux jiġu tweġibiet — l-iżball jista' jkun ukoll fit-triq tar-ritorn.
:::

# Il-problema tar-risposta

:::sim
url=/sims/lesson-9.2.btsim
:::

Il-firewall issa taħdem skont il-prinċipju tal-whitelist: default policy **Drop all**. Regola waħda biss tippermetti lin-network tal-iskola tbrawżja: **B → A, TCP, port ta' destinazzjoni 80, Allow**. Il-modalità hija mqiegħda fuq **Stateless**.

## L-esperiment

1. Aqleb għall-modalità ta' tħaddim :fa-play: **Ħaddem** u fuq il-**Lehrer-PC** iftaħ `http://203.0.113.80/` fil-:fa-globe: **Browser**.
2. Fil-**Firewall** ħares lejn il-**Log** u lejn il-**Hits**.

:::quiz mc
X'jiġri fil-browser?
- [ ] Tidher il-paġna ta' www.beispiel.de
- [x] Il-paġna ma tillodjax, il-browser jistenna u fl-aħħar jirrapporta żball
:::

:::quiz mc
Liema packets jidhru fil-log tal-firewall bħala mwaqqgħa (`DROP`)?
- [ ] It-talbiet tal-Lehrer-PC lejn il-port 80
- [x] It-tweġibiet minn `203.0.113.80` b'**source port 80** lejn il-Lehrer-PC
- [ ] L-ebda wieħed
:::

:::quiz short
F'liema direzzjoni (A→B jew B→A) jgħaddu l-packets imwaqqgħin?
= A→B
= A → B
= AtoB
:::

:::evaluate
Iċċekkja t-tweġibiet
:::

It-talba tal-Lehrer-PC tista' toħroġ — imma diġà s-`SYN, ACK` tal-web server ma jirritornax, għax għad-direzzjoni A → B m'hemm l-ebda regola li taqbel, u allura japplika **Drop all**.

## Is-soluzzjoni naïve

Wieħed jista' jdaħħal It-tieni regola: **A → B, TCP, source port 80, Allow** — "dak kollu li jiġi mill-port 80 jista' jidħol". Imbagħad il-brawżjar verament jaħdem.

:::quiz mc
Għaliex din ir-regola hija perikoluża?
- [ ] Għax il-web servers qatt ma jużaw il-port 80 bħala source port
- [x] Attakkant jista' sempliċement jibgħat il-packets tiegħu b'source port 80 — u mbagħad il-firewall iħallihom jgħaddu lejn **kwalunkwe** port fin-network tal-iskola
- [ ] Għax imbagħad il-websites jillodjaw bil-mod
:::

:::evaluate
Iċċekkja t-tweġiba
:::

Is-source port jiddeċiedih is-sender stess — firewall m'għandux jistrieħ fuqu. Firewall stateless iżda ma jafx jekk packet huwiex it-**tweġiba għal talba** jew **tentattiv ġdid ta' konnessjoni** minn barra. Eżattament dan huwa dak li jbiddel il-modalità stateful.

:::tip Punt importanti
Packet filter **stateless** jeżamina kull packet waħdu. It-tweġibiet imbagħad jeħtieġu regoli speċjali għad-direzzjoni ta' lura — u regoli bħal dawn (eż. "source port 80 jista' jidħol") jistgħu jiġu sfruttati mill-attakkanti, għax is-sender jista' jagħżel is-source port liberament.
:::

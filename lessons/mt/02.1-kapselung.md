## L-esperiment

1. Mur fil-:fa-play: **Ħaddem** Modalità ta' tħaddim.
2. Fuq il-**Client-PC**, iftaħ il-:fa-globe: **Browser** u ftaħ `http://192.168.0.20/`.
3. Mur fil-modalità :fa-magnifying-glass: **Traċċa** u b'**+** iftaħ trace għall-**Client-PC**, port `eth0`.
4. Ikklikkja fuq il-packet b'`GET` fil-kolonna Info u ħares lejn il-protocol tree taħtu.

:::note

In-numri bil-kulur fuq il-ġenb tal-lemin diġà taf minn kapitlu 1 — x'jfissru se tagħraf fil-paġna li jmiss.

## Niftħu layer wara layer

Ikklikkja fuq it-trijangolu żgħir quddiem **Ethernet**, **Internet Protocol Version 4**, **Transmission Control Protocol** u **Hypertext Transfer Protocol**. Kull layer iġġib magħha t-tagħrif tagħha stess:

| Layer fl-update tree | X'issib fiha | Għalxiex |
|---|---|---|
| Ethernet | `Source` u `Destination`: MAC addresses bħal `aa:57:28:…` | liema network card fin-network lokali |
| IPv4 | `Source Address` `192.168.0.10`, `Destination Address` `192.168.0.20` | liema kompjuter — anki lil hinn mill-konfini tan-network |
| TCP | `Source Port` `49152`, `Destination Port` `80` | liema programm fuq il-kompjuter |
| HTTP | `GET / HTTP/1.1`, `Host: 192.168.0.20` | il-messaġġ attwali tal-browser |

Ħares ukoll lejn dawn iż-żewġ linji: f'Ethernet hemm `Type: IPv4`, f'IPv4 hemm `Protocol: TCP`. Għalhekk kull layer tgħidlek *x'hemm fiha* — hekk ir-receiver jaf kif għandu jkompli jiftaħ.

## Envelope ġewwa envelope

Dak li għadek kif rajt jinħoloq mas-sender hekk:

1. Il-browser jikteb il-messaġġ attwali: `GET / HTTP/1.1` (**HTTP**).
2. **TCP** iqegħdu ġewwa envelope u jikteb il-ports quddiemu — biex jaslu għand il-programm t-tajjeb.
3. **IP** iqegħed kollox ġewwa envelope u jikteb l-IP addresses quddiemu — biex jaslu għand il-kompjuter t-tajjeb.
4. **Ethernet** iqiegħed kollox f'frame bil-MAC addresses — biex jaslu fin-network lokali għand in-network card t-tajba.

Mar-receiver jaħdem eżatt bil-maqlub: kull layer tneħħi l-parti tagħha u tgħaddi l-bqija 'l fuq. Huwa bħal ittra li titqiegħed f'diversi envelopes — fuq ġewwa l-messaġġ, u barra fuq kull envelope l-indirizz ta' min se jiftaħha wara.

:::tip Punt importanti
Kull layer iżżid l-informazzjoni ta' kontroll tagħha stess — l-**header** — quddiem id-dejta tal-layer ta' fuqha. Dan it-tqegħid u t-tneħħija tal-envelopes jissejjaħ **encapsulation**.
:::

Skont il-layer, il-"pakkett" għandu isem differenti:

| Layer | Protokoll fl-eżempju | Isem tal-unità tad-dejta |
|---|---|---|
| Layer 2 | Ethernet | **Frame** |
| Layer 3 | IPv4 | **Packet** |
| Layer 4 | TCP | **Segment** |

:::note
Fil-ħajja ta' kuljum — u f'dan il-kors ukoll — spiss wieħed jgħid sempliċement "packet", kemm jekk hija layer waħda u kemm jekk oħra. Meta jkun importanti li tkun preċiż, uża l-ismijiet mit-tabella.
:::

:::quiz fill
Mas-sender, kull layer tqiegħed id-dejta tal-layer ta' fuqha ġewwa envelope u żżid {header} quddiemha. Dan il-prinċipju jissejjaħ {encapsulation}. Fuq layer 2 l-unità tad-dejta tissejjaħ {frame}, fuq layer 4 b'TCP {segment}.
:::

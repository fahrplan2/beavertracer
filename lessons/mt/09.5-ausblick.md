# Sommarju u t-triq 'il quddiem

## Firewalls f'ħafna postijiet

Il-filtru tal-packets minn dan il-kapitolu issibu f'ħafna apparati:

- **Home router:** Kull home router huwa wkoll firewall stateful. Bl-IPv4, in-NAT jieħu sehem minn dan: minn barra ħadd ma jista' jibda konnessjoni sakemm ma jkunx hemm port forward (Kapitolu 7). Bl-IPv6 l-apparati kollha għandhom indirizzi pubbliċi — allura r-regola tal-firewall "xejn ġdid ma jidħol minn barra" waħedha tagħti l-istess protezzjoni.
- **Personal Firewall:** Anki Windows, macOS u Linux għandhom firewall inkorporata fuq il-kompjuter innifsu. Din tipproteġi l-apparat anki f'networks barranin, pereżempju fil-WLAN ta' kafetterija, u tista' tistabbilixxi regoli għal kull programm.
- **Next-Generation-Firewall** u **Web Application Firewall (WAF):** Dawn ma jħarsux biss lejn l-indirizzi u l-ports, imma lejn il-kontenut tal-packets — sa l-application layer. Hekk jagħrfu, pereżempju, attakki f'talbiet HTTP. Fil-każ ta' HTTPS, għal dan jeħtieġ li jiftħu l-encryption (Kapitolu 8).
- **IDS/IPS:** *Intrusion Detection System* jagħraf mudelli suspettużi fid-data traffic u jagħti l-allarm; *Intrusion Prevention System* barra minn hekk jibblokkahom hu stess.

:::note
Firewall hija **biċċa waħda biss** mis-sigurtà. Ma tgħinx jekk servizz permess (pereżempju l-web server) innifsu jkollu vulnerabbiltà, jekk xi ħadd jiftaħ programm malizzjuż permezz tal-e-mail, jew jekk password tkun dgħajfa. Għalhekk l-updates, il-passwords sodi, l-encryption u qsim għaqli tan-network (DMZ, VLANs mill-Kapitolu 3) dejjem huma parti mis-sigurtà.
:::

## Ittestja lilek innifsek

:::quiz mc
Firewall taħdem bil-policy default "Armi kollox" u b'regola waħda biss "A → B, TCP 443, Ippermetti". Packet A → B lejn il-port TCP 22 jasal. X'jiġri?
- [ ] Jiġi permess
- [x] Jiġi mormi
- [ ] Jiġi miċħud
:::

:::quiz mc
`nmap` jirrapporta `filtered` għal port. Dan x'jfisser?
- [ ] Fuq il-port qed jaħdem servizz
- [ ] Is-server wieġeb b'RST
- [x] Ma waslet l-ebda tweġiba — x'aktarx firewall qed tarmi l-packets
:::

:::quiz multi
Liema dikjarazzjonijiet huma tajbin?
- [x] F'firewall stateful, it-tweġibiet għal konnessjonijiet permessi jirritornaw awtomatikament
- [x] Whitelist hija aktar sigura minn blacklist, għax servizzi ġodda jibqgħu awtomatikament imblukkati
- [x] Servers li jistgħu jintlaħqu mill-internet jagħmlu sens f'DMZ
- [ ] Firewall tipproteġi wkoll minn attakki bejn żewġ kompjuters fl-istess network warajha
- [ ] Ir-regoli dejjem jiġu ċċekkjati kollha, u l-aktar waħda stretta tirbaħ
:::

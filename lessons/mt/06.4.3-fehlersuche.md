# Troubleshooting: ebda network għal-laptops

:::sim
url=/sims/lesson-6.4.3.btsim
:::

Wara l-btajjel, l-għalliema jirrappurtaw: "Il-laptops tagħna ma jistgħux jidħlu aktar fin-network!" Iż-żewġ laptops huma ssettjati fuq **DHCP**. Skont il-pjan, id-DHCP server suppost jqassam indirizzi minn `192.168.0.100` sa `192.168.0.120`, bil-gateway `192.168.0.1` u d-DNS server `192.168.0.53`.

Sib l-iżbalji u ssewwihom.

<details>
<summary>Tip 1: Liema indirizz għandhom il-laptops?</summary>

Ħares lejn l-:fa-gear: **IP Settings** ta' laptop. Indirizz li jibda b'`169.254` l-apparat tah lilu nnifsu **hu stess** — għax ebda DHCP server ma wieġeb.
</details>

<details>
<summary>Tip 2: Id-DHCP server qed iwieġeb?</summary>

Iftaħ traċċa għal laptop. Tara biss `DHCP Discover` — jew ukoll tweġiba? Imbagħad ħares lejn l-app **DHCP Server**: Qed taħdem? U liema range qed taqsam?
</details>

<details>
<summary>Tip 3: Kif tikseb indirizz ġdid</summary>

Jekk biddilt xi ħaġa fis-server, issettja l-modalità tal-laptop fl-IP settings għal ftit fuq **Statiku** u erġa' fuq **DHCP** u agħfas **Apply** — imbagħad jerġa' jitlob indirizz.
</details>

:::task
title: Il-laptops reġgħu fin-network?
Iċċekkja jekk iż-żewġ laptops għandhomx indirizz mill-range ppjanat u jistgħux jaslu għand id-DHCP server. Is-simulazzjoni trid tkun qed taħdem fil-Modalità ta' tħaddim biex dan isir.
check: ip(3, "192.168.0.96/27")
check: ip(4, "192.168.0.96/27")
check: pingOk(3, 2)
check: pingOk(4, 2)
:::

## X'kien qed jiġri?

:::quiz multi
Liema dikjarazzjonijiet huma veri?
- [x] Id-DHCP server ma kienx beda — il-laptops taw lilhom infushom indirizz `169.254`
- [x] Ir-range tal-indirizzi kien fin-network ħażin (`192.168.1.…` minflok `192.168.0.…`)
- [ ] Il-laptops kienu ssettjati fuq indirizzi fissi
- [ ] Il-gateway kien nieqes fuq is-switch
:::

:::evaluate
Iċċekkja t-tweġiba
:::

:::tip Punt importanti
Jekk apparat ikollu indirizz minn **`169.254.0.0/16`**, ifisser li **ma rċieva ebda tweġiba minn DHCP server** u ta lilu nnifsu indirizz (**APIPA**). B'hekk jista' jilħaq biss apparati oħra li jinsabu fl-istess sitwazzjoni. Imbagħad iċċekkja: Id-DHCP server qed jaħdem? Jistax jintlaħaq? U qed jqassam indirizzi min-**network t-tajjeb**?
:::

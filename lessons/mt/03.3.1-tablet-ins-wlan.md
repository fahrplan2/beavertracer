# Ġib tablet fil-WLAN

:::sim
url=/sims/lesson-3.3.1.btsim
:::

Mal-switch hemm konnessi l-**Schul-PC** (`192.168.0.10`) u **Access Point**. It-tablet **Anna** (`192.168.0.30`) suppost jidħol fil-WLAN tal-iskola.

## Sib il-WLAN

Aqleb għal :fa-play: **Ħaddem** (Modalità ta' tħaddim) u kklikkja fuq l-**Access Point**. Hawn jidher l-isem tal-WLAN tiegħu, l-**SSID**: `Schule`.

L-Access Point jaħdem bħal pont: dak li jaslu bir-radju, jgħaddih lill-switch permezz tal-kejbil tiegħu — u bil-maqlub. B'hekk Anna u l-Schul-PC jispiċċaw fl-istess local network.

## Ikkonnettja t-tablet

1. Ikklikkja fuq **Anna**, iftaħ l-:fa-gear: **IP Settings** u hemmhekk it-tab **WiFi**.
2. Fil-qasam **SSID** ikteb l-isem tal-WLAN: `Schule`, u kklikkja fuq **Apply**.
3. Fuq Anna iftaħ it-:fa-terminal: **Terminal** u agħmel ping lill-Schul-PC:
   ```
   $ ping 192.168.0.10
   ```

Waqt il-ping oqgħod attent għall-workspace: madwar Anna u l-Access Point jinfirxu mewġ tar-radju.

:::tip Punt importanti
**WLAN** huwa local network bir-radju. L-**Access Point** jgħaqqad il-WLAN man-network bil-kejbil. Kull WLAN għandu isem, l-**SSID** (*Service Set Identifier*) — apparat irid ikun jaf l-SSID t-tajba biex jikkonnettja.
:::

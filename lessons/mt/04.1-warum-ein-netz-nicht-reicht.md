# Għaliex network wieħed ma jaqbilx

:::sim
url=/sims/lesson-4.1.btsim
:::

Fuq il-workspace tara żewġ networks żgħar ta' kumpaniji: **Firma A** b'Anna (`192.168.0.10`) u Ben (`192.168.0.11`), **Firma B** bi Clara (`172.16.0.10`) u David (`172.16.0.11`). Iż-żewġ switches huma anke konnessi direttament b'kejbil.

## Ping fin-network tiegħek

1. Aqleb għal :fa-play: **Ħaddem** (Modalità ta' tħaddim), iftaħ it-:fa-terminal: **Terminal** fuq **Anna** u ibgħat ping lil Ben:
   ```
   $ ping 192.168.0.11
   ```
2. Aqleb għal :fa-magnifying-glass: **Traċċa**, iftaħ trace għal **Anna** u kklikkja fuq `Echo (ping) request`.
3. Fil-protocol tree iftaħ ir-ringiela **Internet Protocol Version 4**. Din hija l-parti IP tal-packet — il-parti li dan il-kapitlu jittratta.

:::quiz match
Source Address -> L-IP address tas-sender
Destination Address -> L-IP address tar-receiver
Time to Live -> Kemm routers jista' għad jgħaddi minnhom il-packet
Protocol -> Liema protokoll hemm fil-packet (hawnhekk ICMP, jiġifieri l-ping)
:::

:::evaluate
Iċċekkja t-tqabbil
:::

## Ping lejn network ieħor

Erġa' aqleb għal :fa-play: **Ħaddem** u ibgħat ping minn **Anna** lil Clara (`ping 172.16.0.10`). Wara, ħares lejn it-trace ta' Anna għal darb'oħra.

:::quiz mc
X'jiġri?
- [ ] Il-ping jirnexxi — wara kollox, is-switches huma konnessi
- [x] Ebda ping ma jaslu, u fit-trace ta' Anna ma jidher l-ebda packet lejn Clara — lanqas ARP request
- [ ] Anna tibgħat ARP request, imma Clara ma twieġibx
:::

:::quiz mc
Għaliex Anna ma tibgħat xejn?
- [ ] Il-kejbil bejn is-switches huwa miksur
- [ ] Clara hija mitfija
- [x] Anna tinduna mill-IP address ta' Clara li Clara tinsab f'network differenti — u ma tafx triq lejha
:::

:::evaluate
Iċċekkja t-tweġibiet
:::

## X'hemm warajh

IP address taħdem bħal indirizz postali: parti tgħid f'liema **network** jinsab apparat (bħat-triq), u l-parti l-oħra tgħid liema **apparat** f'dak in-network qed jiġi mfisser (bħan-numru tad-dar). Anna tinsab fin-network `192.168.0…`, Clara fin-network `172.16.0…` — żewġ "toroq" differenti.

Lejn apparati fin-network *tiegħu stess*, PC jibgħat packets direttament (permezz ta' ARP u s-switch, kif diġà taf). Għal network *barrani* jeħtieġ apparat li jgħaqqad in-networks flimkien u jgħaddi l-packets 'il quddiem: **router**. Hawnhekk għad m'hemm l-ebda wieħed — għalhekk anke l-kejbil bejn is-switches ma jgħin xejn.

:::tip Punt importanti
L-**Internet Protocol** (**IP**) fuq il-layer 3 jiżgura li l-packets jaslu anke bejn networks differenti. **IP address** tikkonsisti minn **network part** (f'liema network?) u **host part** (liema apparat?). Apparati fl-istess network jaslu lejn xulxin direttament — għal networks oħra jeħtieġ **router**.
:::

B'hekk jinqalgħu żewġ mistoqsijiet li se nittrattaw fit-taqsimiet li jmiss: Kif jaf PC *eżattament fejn* fl-indirizz jispiċċa n-network part? U kif jaħdem router?

# POP3 jew IMAP?

:::sim
url=/sims/lesson-6.3.btsim
:::

Hemm żewġ protokolli biex timbotta l-mejls lejn il-kompjuter tiegħek. F'din is-simulazzjoni, **Anna tuża POP3** u **Ben juża IMAP**.

## L-esperiment

1. Fil-:fa-play: **Ħaddem** modalità ta' tħaddim, ibgħat mejl minn **Ben** lil `anna@beaver-schule.de`.
2. Ikklikkja fuq **Ġib** fl-app **E-Mail** ta' **Anna**.
3. Iftaħ it-traces għal **Anna** u għal **Ben** u qabbel il-kmandi li jintużaw biex jinġabru l-mejls.

:::quiz match
USER / PASS -> POP3: tidħol bl-isem tal-utent u l-password f'żewġ passi
RETR -> POP3: tniżżel messaġġ
LOGIN -> IMAP: tidħol bl-isem tal-utent u l-password
SELECT INBOX -> IMAP: tiftaħ folder fuq is-server
:::

:::evaluate
Iċċekkja t-tqabbil
:::

## Id-differenza

| | POP3 | IMAP |
|---|---|---|
| Port | 110 | 143 |
| Idea bażika | il-mejls **jitniżżlu** — wara spiss jitħassru mis-server | il-mejls **jibqgħu fuq is-server** u jiġu amministrati hemm |
| Folders, mixjura/mhux mixjura | biss fuq l-apparat tiegħek stess | fuq is-server — l-istess kullimkien |
| Diversi apparati (mowbajl, laptop) | mhux prattiku: kull apparat għandu stat differenti | ideali: l-apparati kollha jaraw l-istess mailbox |

:::note
Il-programm tal-e-mail f'BeaverTracer iħalli l-mejls fuq is-server anke bil-POP3. Programmi reali spiss iħassruhom wara t-tniżżil — jew iħalluhom hemm biss għal xi żmien.
:::

:::quiz mc
Lena taqra l-mejls tagħha fuq il-mowbajl, it-tablet u l-laptop tal-iskola. Xiex għandha tuża?
- [ ] POP3, għax huwa aktar sempliċi
- [x] IMAP, għax l-apparati kollha jaraw l-istess mailbox fuq is-server
- [ ] SMTP, għax huwa maħsub biex jinġabru l-mejls
:::

:::evaluate
Iċċekkja t-tweġiba
:::

:::tip Punt importanti
**POP3** iniżżel il-mejls mis-server fuq apparat **wieħed**. **IMAP** jamministra l-mailbox **fuq is-server** — b'folders u status ta' mixjur/mhux mixjur għall-apparati kollha fl-istess ħin. It-tnejn huma biss biex **jinġabru** l-mejls; il-mejls dejjem jinbagħtu bl-**SMTP**.
:::

# Twaqqif tal-home router

:::sim
url=/sims/lesson-7.1.2.btsim
:::

Home router ġdid kien għadu kif ġie konness — imma s'issa ħadd ma jista' jidħol fuq l-internet. Mingħand il-provider irċevejt ittra bid-**dejta tal-aċċess**:

| Dejta tal-aċċess | Valur |
|---|---|
| WAN IP address | `203.0.113.2` |
| Prefix length | `/30` |
| Gateway (ir-router tal-provider) | `203.0.113.1` |
| DNS server tal-provider | `198.51.100.10` |

1. Aqleb għall-:fa-play: **Ħaddem** Modalità ta' tħaddim, ikklikkja fuq il-**Heimrouter** u iftaħ it-tab **WAN**.
2. Daħħal id-dejta tal-aċċess u ikklikkja fuq **Apply**.
3. Ikkonnettja t-**Tablet** mal-WiFi: :fa-gear: **IP Settings**, tab **WiFi**, SSID `Biberbau`, **Apply**.
4. Ittestja fuq il-PC b'`ping 192.0.2.80` jew fil-**Browser** b'`http://www.beispiel.de/`.

:::note
Fil-prattika, il-home router normalment jieħu l-WAN address tiegħu awtomatikament mingħand il-provider (permezz ta' DHCP jew login b'username u password). Dejta tal-aċċess fissa bħal din hawnhekk hija iktar komuni fil-konnessjonijiet tal-kumpaniji.
:::

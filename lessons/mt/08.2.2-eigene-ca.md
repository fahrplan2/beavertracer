# Nibnu CA tagħna stess

:::sim
url=/sims/lesson-8.2.2.btsim
:::

Għal `www.beaver-schule.de` għad m'hemm ebda certificate. Minflok ma titlob wieħed minn CA kummerċjali, l-iskola tibni **CA tagħha stess**: is-**Schul-CA**. Ħafna kumpaniji u skejjel jagħmlu hekk għas-servers interni tagħhom.

Fir-realtà, is-Schul-CA tkun qed taħdem fuq kompjuter apposta u protett tajjeb ħafna. Hawnhekk inti tilgħab ir-rwoli kollha fuq il-web server innifsu.

## Pass 1: Toħloq is-Schul-CA

1. Mur fil-Modalità ta' tħaddim (:fa-play: **Ħaddem**) u fuq il-web server **www.beaver-schule.de** iftaħ :fa-shield-halved: **Zertifikatverwaltung**.
2. Fit-tab **Generieren**:
    - **Common Name:** `Schul-CA`
    - **Typ:** Selbstsigniert
    - Immarka **Dies ist ein CA-Zertifikat**
    - **Speichern unter:** `schul-ca.cert.json`
3. Ikklikkja fuq **Zertifikat generieren**.

B'hekk jinħoloq **key pair** ġdid. Il-certificate fih il-public key; il-private key tibqa' fil-fajl fuq il-web server.

## Pass 2: Toħroġ is-server certificate

Għal darb'oħra fit-tab **Generieren**:

- **Common Name:** `www.beaver-schule.de` — eżatt l-isem li wieħed jikteb fil-browser
- **Typ:** Von CA signiert, **Signierende CA:** Schul-CA
- **Speichern unter:** per eżempju `www.beaver-schule.de.cert.json`

Fit-tab **Meine Zertifikate** issa tara ż-żewġ certificates. Ikklikkja fuq is-server certificate il-ġdid:

:::quiz short
Min hu l-**Aussteller** tas-server certificate (mingħajr `CN=`)?
= Schul-CA
:::

:::quiz mc
Liema hi l-**Kette** tiegħu?
- [x] `www.beaver-schule.de ← Schul-CA`
- [ ] `Schul-CA ← www.beaver-schule.de`
- [ ] `www.beaver-schule.de` (iffirmat minnu nnifsu)
:::

:::evaluate
Iċċekkja t-tweġibiet
:::

## Pass 3: Ngħallmu lill-client is-Schul-CA

Il-Client-PC għadu ma jafx is-Schul-CA — fil-browser tiegħu ma hijiex installata minn qabel. Għandek tagħtih il-certificate tagħha, imma **mingħajr il-private key**:

1. Fuq il-web server, taħt **Meine Zertifikate**, agħżel is-**Schul-CA** u ikklikkja fuq **Kopieren** (mhux fuq *Kopieren + Schlüssel*!).
2. Fuq il-**Client-PC** iftaħ :fa-shield-halved: **Zertifikatverwaltung**, tab **Vertrauenswürdige CAs**.
3. Ikklikkja fuq **Einfügen: Schul-CA**.

:::warning
Il-**private key tas-CA** hija l-akbar sigriet tas-sistema kollha: min għandu jkollu, jista' joħroġ certificates għal kwalunkwe isem, u l-clients kollha jafdaw fihom. Qatt ma għandha titlaq mill-kompjuter tas-CA.
:::

:::task
title: Schul-CA twaqqfet?
Iċċekkja jekk fuq il-web server hemmx certificate għal www.beaver-schule.de maħruġ mis-Schul-CA u jekk il-Client-PC jafdax fis-Schul-CA.
check: hasCert(4, "www.beaver-schule.de", "Schul-CA")
check: trusts(2, "Schul-CA")
:::

:::quiz mc
Għaliex għall-client tikkopja biss il-certificate **mingħajr** il-private key?
- [ ] Għax il-kopja bil-key iddum itwal
- [x] Biex jiġu vverifikati firem, il-public key tkun biżżejjed; bil-private key kulħadd fuq il-client seta' joħroġ certificates waħdu
- [ ] Għax inkella l-client ma jkunx jista' jagħmel konnessjoni
:::

:::evaluate
Iċċekkja t-tweġiba
:::

Il-web server innifsu għadek ma biddiltux — għadu jitkellem biss HTTP. Kif iddawwal HTTPS se titgħallem fit-taqsima 8.3.3.

:::tip Punt importanti
**CA tiegħek stess** tikkonsisti f'**CA certificate iffirmat minnu nnifsu** b'private key. Biha toħroġ **server certificates** li l-Common Name tagħhom jaqbel mal-isem tas-server. Biex il-clients jafdaw f'dawn iċ-certificates, jiġu mogħtija **l-CA certificate mingħajr il-private key** fil-lista tagħhom ta' **vertrauenswürdige CAs**.
:::

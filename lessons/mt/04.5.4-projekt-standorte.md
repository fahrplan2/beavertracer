# Proġett: Kumpanija b'erba' siti

:::sim
url=/sims/lesson-4.5.4.btsim
:::

Kumpanija għandha l-uffiċċju prinċipali tagħha f'**Hanau** u fergħat f'**Kassel**, **Gießen** u **Darmstadt**. Kull sit għandu network tiegħu u router tiegħu. Ir-routers kollha huma konnessi permezz ta' linji dedikati ma' **network ċentrali**, li fih jinsab ukoll is-server prinċipali tal-kumpanija.

## Il-pjan tal-indirizzi

L-amministratur ta l-indirizzi skont l-iskema li ġejja — diġà huma mdaħħlin fis-simulazzjoni:

| Network | Range tal-indirizzi |
|---|---|
| Network ċentrali | `10.19.0.0/24` |
| Hanau | `10.19.1.0/24` |
| Kassel | `10.19.2.0/24` |
| Gießen | `10.19.3.0/24` |
| Darmstadt | `10.19.4.0/24` |

| Apparat | fin-network ċentrali | fin-network tas-sit |
|---|---|---|
| Server | `10.19.0.10` | — |
| Router Hanau | `10.19.0.1` | `10.19.1.1` |
| Router Kassel | `10.19.0.2` | `10.19.2.1` |
| Router Gießen | `10.19.0.3` | `10.19.3.1` |
| Router Darmstadt | `10.19.0.4` | `10.19.4.1` |
| PC fis-sit | — | kull wieħed `.2` (eż. PC Kassel `10.19.2.2`) |

Fir-routers kollha, `eth0` jindika lejn in-network ċentrali u `eth1` lejn in-network tas-sit.

## Ix-xogħol tiegħek

Biex il-kompjuters kollha tal-kumpanija jaslu wieħed għand l-ieħor u għas-server, għad fadal żewġ affarijiet:

1. **Gateways:** daħħal gateway fl-erba' PCs kollha u fis-server. Il-PCs jużaw ir-router tas-sit tagħhom; is-server juża **Router Hanau**.
2. **Routing tables:** żid ir-routes li għadhom neqsin fl-erba' routers kollha. Kull router irid jaf in-networks tat-**tliet siti l-oħra**.

Ittestja fil-qosor b'`ping` u `traceroute`.

<details>
<summary>Suġġeriment: Kif tidher route hawnhekk?</summary>

Eżempju għal **Router Kassel**: il-pakketti għal Gießen (`10.19.3.0/24`) imorru għand ir-router Gießen fin-network ċentrali tiegħu — għalhekk **Next Hop** `10.19.0.3`, **Iface** `eth0`. Fuq dan il-mudell, kull router jeħtieġ tliet routes.
</details>

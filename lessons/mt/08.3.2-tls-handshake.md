# It-TLS handshake

:::sim
url=/sims/lesson-8.2.1.btsim
:::

Qabel ma tintbagħat l-ewwel talba kriptata, il-client u s-server iridu jaqblu: fuq metodu, fuq session key — u l-client irid jivverifika ma' min qed jitkellem. Din il-connection setup tissejjaħ **TLS handshake**.

## Osserva

Iftaħ `https://www.beaver-schule.de/` fuq il-**Client-PC** (jekk għadek ma għamiltx dan), iftaħ trace għall-**Client-PC** u ffiltra b'`tls`.

:::quiz short

= Client Hello
:::

:::quiz short

## L-andament fid-dijagramma

Mingħajr l-acknowledgements tat-TCP (`ACK`), il-handshake jidher hekk:

:::seq
mode: text
Client -> Server: Client Hello | numru każwali, metodi possibbli
Server -> Client: Server Hello | metodu magħżul, numru każwali
Server -> Client: Certificate | certificate tas-server
Server -> Client: Server Key Exchange | DH share, iffirmat
Server -> Client: Server Hello Done
Client -> Server: Client Key Exchange | DH share tal-client
Client -> Server: Change Cipher Spec | minn issa kriptat
Client -> Server: Encrypted Handshake Message | Finished
Server -> Client: Change Cipher Spec | minn issa kriptat
Server -> Client: Encrypted Handshake Message | Finished
Client -> Server: Application Data | GET / (kriptat)
Server -> Client: Application Data | paġna web (kriptata)
:::

X'jiġri hawn — u liema element mit-taqsima 8.1 hemm warajh:

1. **Client Hello / Server Hello:** Il-client u s-server jsellmu lil xulxin, jiskambjaw numri każwali u jaqblu fuq il-metodi (f'BeaverTracer: key exchange b'**ECDHE**, firma b'**ECDSA**, encryption b'**AES**).
2. **Certificate:** Is-server jibgħat il-**certificate** tiegħu. Il-client jivverifika l-firma tas-CA, il-validità u l-ismijiet. Jekk dan jonqos, jieqaf hawn — u l-browser juri twissija.
3. **Server Key Exchange:** Is-server jibgħat l-**Diffie-Hellman share** tiegħu — u **jiffirmah** bil-private key tiegħu. Il-client jivverifika l-firma bil-public key mill-certificate. B'hekk jaf: Din il-share tassew ġejja mis-sid tal-certificate, mhux minn Man-in-the-Middle.
4. **Client Key Exchange:** Il-client jibgħat id-Diffie-Hellman share tiegħu. Issa t-tnejn jistgħu jikkalkulaw l-istess **session key** — mingħajr ma qatt ġie trasmess.
5. **Change Cipher Spec:** "Minn issa nikkripta."
6. **Encrypted Handshake Message (Finished):** Iż-żewġ naħat jibagħtu — diġà kriptat — checksum fuq il-messaġġi kollha tal-handshake sa dak il-ħin. Jekk attakkant biddel xi ħaġa matul it-triq, ic-checksums ma jaqblux u l-konnessjoni titwaqqaf.
7. **Application Data:** Minn hawn 'il quddiem jiċċirkolaw id-data tal-HTTP — kriptati simmetrikament b'AES.

:::quiz match
Certificate -> Is-server jidentifika ruħu bil-certificate tiegħu
Server Key Exchange -> Diffie-Hellman share iffirmat tas-server
Client Key Exchange -> Diffie-Hellman share tal-client
Change Cipher Spec -> Minn issa jibda l-encryption
Application Data -> Data tal-HTTP kriptata
:::

:::note
Fit-trace tara **żewġ** konnessjonijiet TLS wara xulxin: Il-browser l-ewwel jieħu l-paġna u mbagħad jibni konnessjoni ġdida għall-stylesheet `style.css`. Kull konnessjoni jkollha handshake tagħha u session key tagħha. Il-browsers reali jżommu l-konnessjonijiet miftuħa u b'hekk jevitaw parti minn dan ix-xogħol. Il-verżjoni ġdida **TLS 1.3** teħtieġ ukoll inqas messaġġi mit-TLS 1.2 muri hawn.
:::

:::tip Punt importanti
Fit-**TLS handshake** is-server jidentifika ruħu bil-**certificate** tiegħu, iż-żewġ naħat jaqblu fuq **session key** permezz ta' **Diffie-Hellman** (is-server **jiffirma** is-share tiegħu), u b'**Finished** it-tnejn jivverifikaw liħadd ma biddel il-handshake. Wara, id-data tiġi trasmessa kriptata simmetrikament bħala **Application Data**.
:::

# It-talba ta' web page

:::goal
**Għan tat-tagħlim:** Tesperjenza kemm hija kumplessa t-talba ta' web page u tkun tista' tisma' liema protokolli huma involuti, u f'liema ordni.
:::

Li tiftaħ web page jidher bħal klikk wieħed biss. Fuq il-paġna li jmiss taħdem b'simulazzjoni mħejjija, tosserva fit-tracer kemm hemm warajha, u tirranġa l-protokolli involuti.

# WLAN: network mingħajr kejbils

:::goal
**Għan tat-tagħlim:** Inti tista' tispjega kif Access Point jgħaqqad WLAN man-network bil-kejbil, tpoġġi apparat fil-WLAN permezz tal-SSID, u tispjega għala WLAN irid jiġi encrypted.
:::

Mowbajls, tablets u laptops ġeneralment m'għadhomx għandhom port tan-network — huma konnessi bir-radju, permezz ta' **WLAN** (*Wireless LAN*, network lokali bla wajers). Biex xorta jkunu jistgħu jikkomunikaw mal-PCs u s-servers li huma konnessi bil-kejbil, jeħtieġ apparat li jgħaqqad ir-radju mal-kejbil.

:::note
Fil-fatt, WLAN jiddependi mill-firxa, mill-ħitan u mid-disturbi. BeaverTracer jissimplifika dan: l-apparati kollha bl-istess isem tal-WLAN jaqsmu network tar-radju wieħed komuni — ma jimpurtax fejn jinsabu fuq il-workspace.
:::

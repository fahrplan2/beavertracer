# Konnessjoni mill-bidu sa tmiemha

:::sim
url=/sims/lesson-5.1.btsim
:::

Fuq is-**Server** isservi s-servizz Echo fuq il-port `5000`: kull messaġġ jibgħatu lura minnufih. Bis-**Simple TCP Client** tista' tikkontrolla konnessjoni pass pass — kull buttuna hija fażi.

## L-esperiment

1. Aqleb għall-:fa-play: **Modalità ta' tħaddim**, ikklikkja fuq il-**Client-PC** u iftaħ is-**Simple TCP Client**.
2. Ikteb `192.168.0.20` f'**Host** u `5000` f'**Port**.
3. Ikklikkja fuq **Ikkonnettja**.
4. Ittajpja `Hello World` fil-qasam tal-messaġġ u ikklikkja fuq **Ibgħat**. Fit-tieqa taċ-chat malajr tara l-echo tas-server.
5. Ikklikkja fuq **Iddekonettja**.
6. Aqleb għall-:fa-magnifying-glass: modalità **Traċċa** u b'**+** iftaħ trace għall-**Client-PC**, konnessjoni `eth0`.

:::note
Inti diġà tafu ż-żewġ ARP packets tal-bidu mill-kapitlu 1. Fil-kolonna **Info** tat-TCP packets tidher l-ewwel `49152 → 5000` (minn liema port għal liema port), imbagħad bejn parentesi kwadri l-**flags** u wara numri bħal `Seq=`, `Ack=` u `Len=`. In-numri nitkellmu fuqhom mill-paġna 5.2.3 'il quddiem — hawn oqgħod attent għall-flags u għal `Len`.
:::

## Fażi 1: Ikkonnettja

:::quiz short
Kemm TCP packets ġew skambjati wara li ikklikkjajt fuq **Ikkonnettja** — qabel ma telaq il-messaġġ tiegħek?
= 3
= tlieta
:::

:::quiz mc
Min jibgħat l-ewwel packet b'`[SYN]`?
- [x] Il-Client-PC
- [ ] Is-Server
:::

:::quiz mc
B'liema flags iwieġeb is-server?
- [ ] `[SYN]`
- [x] `[SYN, ACK]`
- [ ] `[ACK]`
- [ ] `[FIN, ACK]`
:::

## Fażi 2: Ibgħat

`Len` jindika kemm bytes ta' dejta utli jġorr packet.

:::quiz short
Kemm bytes iġorr il-packet bil-messaġġ tiegħek (`Len`)?
= 13
:::

:::note
`Hello World` għandu 11-il karattru biss. Madankollu s-TCP client iżid tmiem tas-linja (2 bytes, `\r\n`) — hekk jistennew ħafna protokolli tal-internet bħal SMTP jew HTTP.
:::

:::quiz mc
Xi jibgħat is-server lura direttament wara l-messaġġ tiegħek — saħansitra qabel l-echo?
- [x] Packet bi `[ACK]` u `Len=0` — konferma mingħajr dejta
- [ ] Xejn xejn
- [ ] `[SYN]` ġdid
:::

## Fażi 3: Iddekonettja

:::quiz short
Kemm packets jappartjenu għat-tfejjiq tal-konnessjoni — mill-ewwel packet bi `FIN`?
= 4
= erbgħa
:::

:::quiz mc
Xi tgħid parti meta tibgħat `FIN`?
- [x] "Lestejt" — ma tibgħat l-ebda dejta oħra
- [ ] "Seħħet żball"
- [ ] "Hawn tiġi dejta ġdida"
:::

:::evaluate
Iċċekkja t-tweġibiet
:::

## Fejn jinsabu l-erba' kompiti?

Qabbad fejn issib il-kompiti mit-taqsima 5.1 fit-trace:

:::quiz match
Connection setup -> It-tliet packets [SYN], [SYN, ACK] u [ACK]
Trasmissjoni affidabbli -> Packets bi [ACK] u Len=0 li jikkonfermaw li waslu
Tfejjiq tal-konnessjoni -> Il-packets bi FIN u l-konfermi tagħhom
Multiplexing -> In-numri tal-port 49152 → 5000 qabel il-parentesi kwadri
:::

# Tikseb indirizz awtomatikament

:::sim
url=/sims/lesson-6.4.btsim
:::

Mal-switch hemm konnessi **DHCP Server** u żewġ laptops. Il-laptops għad għandhom indirizzi fissi.

## L-esperiment

1. Aqleb għall-Modalità ta' tħaddim :fa-play: **Ħaddem**, ikklikkja fuq **Laptop 1** u iftaħ l-:fa-gear: **IP Settings**.
2. Biddel il-**Modus** minn **Statiku** għal **DHCP** u ikklikkja fuq **Apply**.
3. Stenna ftit sekondi: il-fields jimtlew weħidhom.
4. Fil-modalità :fa-magnifying-glass: **Traċċa**, iftaħ trace għal **Laptop 1**.

:::quiz table
| Setting | miksub mid-DHCP Server |
|---|---|
| IP address | {192.168.0.100} |
| Gateway | {192.168.0.1} |
| DNS server | {192.168.0.53} |
:::

:::quiz short
Kemm packets tad-DHCP issib fit-trace?
= 4
= erbgħa
:::

:::quiz mc
Lejn liema destination IP address jibgħat Laptop 1 l-ewwel packet tiegħu (`DHCP Discover`)?
- [ ] Lejn id-DHCP Server `192.168.0.2`
- [x] Lejn `255.255.255.255` — lil kulħadd (broadcast)
- [ ] Lejn il-gateway `192.168.0.1`
:::

:::quiz mc
Liema source IP address għandu dan l-ewwel packet — u għaliex?
- [x] `0.0.0.0` — il-laptop għad m'għandux indirizz xorta waħda
- [ ] `192.168.0.10` — l-indirizz qadim tiegħu
- [ ] `192.168.0.100` — l-indirizz il-ġdid tiegħu
:::

:::evaluate
Iċċekkja t-tweġibiet
:::

## X'hemm warajh: DORA

Apparat mingħajr indirizz la jaf fejn hu d-DHCP Server, u lanqas għandu source address tiegħu. Għalhekk isejjaħ fin-network permezz ta' **broadcast**. Il-proċess għandu erba' passi — imsemmi wara l-ewwel ittri tagħhom **DORA**:

:::seq
mode: text
Laptop 1 -> DHCP-Server: DHCP Discover | „Hemm DHCP Server hawn?“
DHCP-Server -> Laptop 1: DHCP Offer | „Tista' tieħu 192.168.0.100.“
Laptop 1 -> DHCP-Server: DHCP Request | „Qed nieħu 192.168.0.100.“
DHCP-Server -> Laptop 1: DHCP ACK | „Ikkonfermat — tgħodd għal 3600 sekonda.“
:::

L-indirizz huwa biss **misluf** (*lease*): wara li tisfa l-**lease time**, l-apparat irid iġedded, inkella s-server jista' jerġa' jagħtih lil ħaddieħor. Liema indirizzi huma mislufin bħalissa tarahom fid-**DHCP Server** fit-tab **Leases**.

:::tip Ipprova int
Poġġi wkoll **Laptop 2** fuq DHCP. Liema indirizz jieħu? Imbagħad ħares lejn il-**Leases** tad-DHCP Server.
:::

:::tip Punt importanti
**DHCP** jqassam awtomatikament l-IP address, in-netmask, il-gateway u d-DNS server. Il-proċess jissejjaħ **DORA**: **D**iscover (il-client ifittex permezz ta' broadcast), **O**ffer (is-server joffri), **R**equest (il-client jaċċetta), **A**CK (is-server jikkonferma). L-indirizz huwa misluf għal-**lease time**. DHCP juża **UDP**, port 67 (server) u 68 (client).
:::

:::quiz match
Discover -> Il-client ifittex DHCP Server permezz ta' broadcast
Offer -> Is-server joffri indirizz
Request -> Il-client jitlob l-indirizz offrut
ACK -> Is-server jikkonferma l-għoti
:::

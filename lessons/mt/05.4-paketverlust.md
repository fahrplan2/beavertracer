# Meta pakketti jintilfu

:::goal
**Għan tat-tagħlim:** Tista' tosserva fit-tracer u tispjega kif TCP jinduna bid-data mitlufa, jibgħatha mill-ġdid u jerġa' jirrestawra l-ordni.
:::

:::

F'din is-simulazzjoni l-kejbil huwa mħejji apposta: it-**tieni packet bid-data** mill-Client-PC lejn is-Server jintilef. (Is-setting issibha meta fil-Modalità ta' tħaddim tikklikkja fuq il-kejbil: **Telf ta' pakkett miġbur**.)

## L-esperiment

1. Aqleb għall-modalità :fa-play: **Ħaddem**, iftaħ fuq il-**Client-PC** is-**Simple TCP Client** u ikkonnettjah ma' `192.168.0.20`, port `5000`.
2. Ibgħat tliet messaġġi wieħed wara l-ieħor: `Hallo`, imbagħad `Welt`, imbagħad `!`.
3. Osserva l-prompt tal-chat: l-echo ta' `Hallo` jasal immedjatament. U t-tnejn l-oħra?
4. Stenna ftit sekondi. Imbagħad, fil-modalità :fa-magnifying-glass: **Traċċa**, iftaħ trace għas-**Server** (ir-receiver), port `eth0`.

:::quiz mc
X'jiġri mill-echoes ta' `Welt` u `!`?
- [ ] L-echo ta' `!` jasal immedjatament, `Welt` jonqos għal dejjem
- [x] It-tnejn jaslu biss wara ftit sekondi — flimkien u fl-ordni t-tajba
- [ ] L-ebda wieħed minnhom ma jasal qatt
:::

## Dak li juri t-tracer

Fis-server il-packet b'`Welt` jonqos — wara kollox intilef. Minflok issib fil-kolonna **Info** tliet indikazzjonijiet fil-parentesi kwadri:

| Indikazzjoni | X'ġara |
|---|---|
| `[TCP Previous segment not captured]` | Il-packet bil-`!` jasal, imma qablu jonqsu bytes — **lakuna**. |
| `[TCP Dup ACK …]` | Is-server jikkonferma darba oħra l-istess numru bħal qabel (*duplicate ACK*): "Għadni qed nistenna l-byte 8." |
| `[TCP Retransmission]` | Il-client jibgħat `Welt` **darba oħra**. |

:::quiz short
Liema sequence number (`Seq`) għandu l-packet immarkat b'`[TCP Retransmission]`?
= 8
:::

:::quiz short
Liema acknowledgement number (`Ack`) jibgħat is-server direttament wara r-retransmission?
= 17
:::

:::quiz mc
Għaliex is-server, wara r-retransmission, jikkonferma minnufih sal-byte 17 — u mhux biss sa tmiem `Welt`?
- [x] Kien diġà rċieva `!` u żammu lura — b'`Welt` il-lakuna ngħalqet, issa kollox sal-byte 16 qiegħed hemm
- [ ] Il-client reġa' bagħat `Welt` u `!` flimkien
- [ ] L-acknowledgement numbers dejjem jiġu rrotondati
:::

:::evaluate
Iċċekkja t-tweġibiet
:::

Fis-sequence diagram dan jidher hekk — il-vleġġa mqattgħa bil-✕ hija l-packet mitluf:

:::seq
Client-PC -> Server: SYN
Server -> Client-PC: SYN, ACK
Client-PC -> Server: ACK
Client-PC -> Server: PSH, ACK "Hallo" len=7
Server -> Client-PC: ACK
Server -> Client-PC: PSH, ACK len=7
Client-PC -> Server: ACK
Client-PC -x Server: PSH, ACK "Welt" len=6
Client-PC -> Server: PSH, ACK "!" len=3
Server -> Client-PC: ACK
Client-PC -> Server: PSH, ACK "Welt" len=6 seq=8
Server -> Client-PC: ACK
Server -> Client-PC: PSH, ACK len=9
Client-PC -> Server: ACK
:::

## X'hemm warajh

Il-client iżomm kull packet mibgħut sakemm jiġi kkonfermat, u jibda **timer** għalih. Jekk il-konferma tdum wisq, jibgħat id-data mill-ġdid — **retransmission** (*Retransmission*).

Is-server jikkonferma dejjem biss sal-**ewwel lakuna**. Id-data li tasal wara (hawn `!`) iżommha lura sakemm il-lakuna timtela. Imbagħad biss jgħaddi kollox lill-programm fl-ordni t-tajba — għalhekk l-echoes ta' `Welt` u `!` waslu flimkien.

:::tip Punt importanti
TCP jagħraf it-telf mill-**konfermi nieqsa**: ir-receiver jikkonferma dejjem biss sal-ewwel lakuna. Jekk il-konferma ma tasalx, is-sender jibgħat id-data **mill-ġdid** meta jiskadi timer (*retransmission*). Dak li jasal wara lakuna ż-żomm ir-receiver lura — hekk id-data tilħaq il-programm **kompluta u fl-ordni t-tajba**.
:::

:::tip Tishil: Fast Retransmit
Wara `Hallo`, ibgħat erba' messaġġi jew aktar malajr wara xulxin. Wara l-packet mitluf, il-client jirċievi tliet *Dup ACKs* wara xulxin — u jibgħat mill-ġdid immedjatament, mingħajr ma jistenna t-timer tiegħu. Din il-proċedura tissejjaħ **Fast Retransmit**.
:::

:::note
Implimentazzjonijiet reali ta' TCP jadattaw ukoll il-veloċità tal-bgħit tagħhom: jekk jintilfu packets, in-network x'aktarx huwa mgħobbi żżejjed, u s-sender jonqos mill-veloċità (*kontroll tal-konġestjoni*). Dan imur lil hinn minn dan il-kors.
:::

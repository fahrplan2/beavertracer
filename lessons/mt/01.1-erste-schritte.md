# Interface u modi

:::goal
**Għan tat-tagħlim:** Tista' timxi fl-interface tal-BeaverTracer u tbiddel bejn it-tliet modi.
:::

:::sim
url=/sims/lesson-1.2.3.btsim
:::

Fuq il-workspace diġà hemm network żgħir ta' żewġ PCs. Fuqu tipprova l-interface int stess ftit tal-ħin oħra.

## L-interface

- **Toolbar fuq nett** — hawn tbiddel il-modalità u tikkontrolla s-simulazzjoni.
- **Toolbox fuq ix-xellug** — jidher biss fil-Modalità ta' editjar. Hawn tagħżel liema apparat se tpoġġi wara (PC, switch, router, …) jew jekk tridx tiġbed cable.
- **Workspace fnofs** — in-network attwali tiegħek. Bir-rota tal-maws tiċċaqlaq il-veduta; billi żżomm il-buttuna **Ctrl** (Mac: **Cmd**) u tuża r-rota tal-maws tagħmel zoom. Inkella, tista' tiċċaqlaq billi żżomm is-space bar jew il-buttuna tan-nofs tal-maws.
- **Pannell tal-lezzjonijiet fuq il-lemin** — hawn qed taqra issa.

## It-tliet modi

BeaverTracer għandu tliet modi, li tibdel bejniethom permezz tat-tliet buttuni l-aktar fuq ix-xellug tat-toolbar:

- :fa-pencil: **Edita** — hawn tibni n-network tiegħek: tpoġġi apparat, torbtu bil-cables, tċaqlqu. Is-simulazzjoni ma taħdimx f'dan il-ħin.
- :fa-play: **Ħaddem** — is-simulazzjoni taħdem. Tista' tiftaħ apparat u, per eżempju, tikteb kmandi fit-Terminal ta' PC.
- :fa-magnifying-glass: **Traċċa** — turik kull packet li għadda mill-konnessjonijiet tiegħek, bil-kontenut eżatt tiegħu.

## Ipprova

1. Ikklikkja fuq :fa-pencil: **Edita**. Fuq ix-xellug jidher it-toolbox. Iġbed **Computer 1** bil-maws lejn post ieħor — il-cable jiċċaqlaq miegħu.
2. Agħmel zoom in u out b'**Ctrl** + ir-rota tal-maws. Bil-buttuna :fa-expand: **Adatta** (fuq isfel il-lemin tal-workspace) il-veduta terġa' tinbidel eżatt skont in-network tiegħek.
3. Ikklikkja fuq :fa-play: **Ħaddem**. It-toolbox jpost jisparixxi. Issa ikklikkja fuq **Computer 1**: tinfetaħ it-tieqa tiegħu bl-apps, bħal fuq kompjuter veru. Agħlqha terġa' b'**×**.
4. Ikklikkja fuq :fa-magnifying-glass: **Traċċa**. Hawn aktar tard jiġu rreġistrati l-packets — għalissa l-lista għadha vojta.

:::tip
Aħjar tour gwidat? Ikklikkja fuq il-logo tal-BeaverTracer fuq nett fuq ix-xellug u agħżel **Tour** fil-menu prinċipali. Il-pannell tal-lezzjonijiet jingħalaq — permezz ta' **Lezzjonijiet** fuq nett fuq il-lemin terġa' lura hawn.
:::

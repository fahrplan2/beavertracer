# Osservazzjoni ta' firewall

:::sim
url=/sims/lesson-9.1.1.btsim
:::

F'din is-simulazzjoni xi ħadd diġà daħħal tliet regoli fil-firewall. Ikklikkja fuq il-**Firewall** u ħares lejn it-tab **Regeln**. **Port A** tal-firewall huwa konness mal-Internet, **Port B** mar-router tal-iskola — "A → B" allura tfisser "mill-Internet lejn in-network tal-iskola".

:::quiz table
| Regel | Richtung | Protokoll | Ziel-Port | Aktion |
|---|---|---|---|---|
| 1 | A → B | {TCP} | {22} | {Verwerfen} |
| 2 | A → B | TCP | {110} | {Zurückweisen} |
| 3 | A → B | {ICMP} | beliebig | Verwerfen |
:::

:::evaluate
Iċċekkja t-tabella
:::

## Ping minn barra

Aqleb għall-:fa-play: **Ħaddem** — **Modalità ta' tħaddim** — u agħmel ping lis-server tal-iskola mill-**Internet-PC**:

```
$ ping -c 2 198.51.100.10
```

Wara iftaħ it-tab **Protokoll** fil-firewall.

:::quiz mc
X'jirrapporta `ping`?
- [x] `Anfrage abgelaufen` — ma jiġi xejn lura
- [ ] `Paket gefiltert`
- [ ] Tweġibiet tnejn mis-server tal-iskola
:::

:::quiz short
B'liema kelma jibdew is-swieq il-ġodda fil-protokoll tal-firewall?
= DROP
:::

:::

## Portscan: miċħud jew rrifjutat?

Issa skennja ħames ports b'mod immirat. Port 3306 (database) mhuwiex qiegħed jaħdem xejn fuq is-server tal-iskola.

```
$ nmap -p 22,25,80,110,3306 198.51.100.10
```

:::quiz match
22 (miċħud) -> filtered
25 (permess, is-servizz qed jaħdem) -> open
110 (rrifjutat) -> closed
3306 (permess, l-ebda servizz) -> closed
:::

:::evaluate
Iċċekkja t-tqabbil
:::

:::quiz multi
X'jista' jikkonkludi attakkant mir-riżultat?
- [x] Meta jara `filtered` jaf: hemm firewall li tibla' l-packets
- [x] Meta jara `closed` ma jistax jaqbad id-differenza bejn firewall li tirrifjuta u sempliċement servizz li ma jkunx qed jaħdem
- [ ] Meta jara `filtered` jaf liema servizz qed jaħdem wara l-port
- [ ] Meta jara `closed` is-servizz xorta jista' jintlaħaq
:::

:::evaluate
Iċċekkja t-tweġibiet
:::

Fl-aħħar ħares lejn il-kolonna **Treffer** fil-lista tar-regoli: hemm il-firewall tgħodd kemm packets diġà ddeċidiet kull regola. Il-valur ħdejn il-**Standardrichtlinie** jgħodd il-packets kollha li magħhom ma laqgħet l-ebda regola.

:::tip Punt importanti
Packets **miċħuda** jisparixxu mingħajr traċċa: `ping` jirrapporta timeout, `nmap` jirrapporta `filtered`. Packets **rrifjutati** il-firewall twieġeb għalihom b'rifjut (fil-każ ta' TCP, RST) — minn barra dan jidher bħal port magħluq. Il-**Protokoll** tal-firewall juri liema packets waqqfet, il-kolonna **Treffer** turi liema regola ħadmet.
:::

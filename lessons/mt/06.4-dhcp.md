# DHCP: awtomatikament fin-network

:::goal
**Għan tat-tagħlim:** Tista' tispjega kif apparat jikseb awtomatikament l-IP settings tiegħu permezz ta' DHCP, twaqqaf DHCP Server u tagħraf u ssolvi żbalji tipiċi ta' DHCP (eż. indirizz 169.254).
:::

:::sim
url=/sims/lesson-6.4.btsim
:::

S'issa daħħalt b'idek l-IP address, in-netmask, il-gateway u d-DNS server ta' kull apparat. Fl-iskola, b'mijiet ta' laptops, tablets u mobiles, dan ikun impossibbli — u kull żball tat-tajpjar ikun żball fin-network.

Din ix-xogħol jagħmlu l-**Dynamic Host Configuration Protocol** (**DHCP**): **DHCP Server** jitrasmetti l-issettjar awtomatikament lil kull apparat li jidħol fin-network.

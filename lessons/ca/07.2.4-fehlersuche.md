# Resolució de problemes: ahir encara funcionava

:::sim
url=/sims/lesson-7.2.4.btsim
:::

Ahir el servidor web domèstic era accessible des de l'exterior: la redirecció de ports `TCP 80 → 192.168.178.10:80` està configurada. Després d'un tall de corrent aquest matí, la Clara ja no pot accedir a la pàgina. Troba l'error i soluciona'l de manera definitiva.

<details>
<summary>Pista 1: On apunta la regla?</summary>

Compara la IP de la LAN que hi ha a **Encaminament de ports** de l'encaminador domèstic amb l'adreça que té realment ara el **Heim-Webserver** (:fa-gear: **Configuració IP**).
</details>

<details>
<summary>Pista 2: Per què té una altra adreça?</summary>

Està el Heim-Webserver configurat amb **DHCP**? Aleshores, després de cada reinici rep una adreça lliure qualsevol del rang de l'encaminador domèstic (a la pestanya **DHCP**). Com pots fer que tingui sempre la mateixa adreça?
</details>

:::task
title: El servidor web domèstic torna a ser accessible?
Comprova si el servidor web domèstic té la seva adreça fixa i si la Clara hi pot accedir mitjançant la redirecció de ports. Perquè funcioni, la simulació ha d'estar en execució en el mode d'execució.
check: ip(11, "192.168.178.10/32")
check: tcpOpen(12, "203.0.113.2", 80)
:::

## Què passava?

:::quiz multi
Quines afirmacions són correctes?
- [x] El servidor web domèstic obtenia l'adreça per DHCP i després del reinici en tenia una de diferent
- [x] Per això la redirecció de ports apuntava a una adreça on ja no hi havia cap servidor en funcionament
- [x] Una adreça fixa fora del rang DHCP soluciona el problema de manera definitiva
- [ ] El proveïdor havia bloquejat l'adreça WAN
:::

:::evaluate
Comprova la resposta
:::

:::tip Idea clau
Els dispositius als quals apunta una **redirecció de ports** (servidors, impressores, càmeres) necessiten una **adreça fixa**: o bé introduïda de manera estàtica i **fora del rang DHCP**, o bé com a assignació fixa al servidor DHCP de l'encaminador. Si no, després d'un reinici potser reben una altra adreça, i la regla deixa d'apuntar a res.
:::

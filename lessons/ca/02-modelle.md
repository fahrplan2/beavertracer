# Models

:::goal
**Objectiu d'aprenentatge:** Pots explicar com un paquet està estructurat en capes (encapsulació), anomenar les capes al Tracer i explicar i comparar el model de referència ISO/OSI i el model de referència TCP/IP.
:::

Al capítol 1 has vist que darrere d'un sol clic en un enllaç hi ha tot un conjunt de protocols diferents: ARP, TCP, HTTP, cadascun amb la seva pròpia funció. Per poder classificar de manera coherent aquesta gran quantitat de protocols, en la tecnologia de xarxes es treballa amb models de capes.

En aquest capítol primer desmuntaràs un paquet individual i després coneixeràs els dos models més importants: el model de referència ISO/OSI, amb les seves set capes, i el model TCP/IP, una mica més pragmàtic, amb quatre. Tots dos els trobaràs una vegada i una altra als capítols següents: són el vocabulari comú amb què parlarem de xarxes a partir d'ara.

# Carregar i observar una pàgina web

Per a aquesta part no has de construir res tu mateix: a l'espai de treball hi ha una simulació preparada amb un **Client-PC** i un **Webserver**.

## Carregar la pàgina

1. Canvia al mode :fa-play: **Executar**.
2. Al **Client-PC**, obre l'aplicació :fa-globe: **Navegador** i entra l'adreça del servidor web: `http://192.168.0.20/`.
3. Canvia al mode :fa-magnifying-glass: **Traça** i obre amb **+** una traça per al **Client-PC**, port `eth0` — exactament igual que amb el ping.

:::note
Per a una sola consulta de pàgina, són sorprenentment molts paquets — molts més que amb el ping. Obtenir una pàgina web és un procés de diverses etapes, no una acció única.
:::

## Llegir la llista de paquets

Encara no cal que sàpigues què fa exactament cada protocol. Tot el que necessites per a les preguntes següents es troba a les columnes **Protocol** i **Info**.

:::quiz mc
Quin protocol hi ha a la part més alta de la llista?
- [x] ARP
- [ ] TCP
- [ ] HTTP
:::

:::quiz short
Compta: quants paquets **TCP** hi ha abans del primer paquet **HTTP**?
= 3
= tres
:::

:::quiz mc
Què respon el servidor web a la sol·licitud del navegador? Mira la columna Info del segon paquet HTTP.
- [ ] GET / HTTP/1.1
- [x] HTTP/1.1 200 OK
- [ ] 404 Not Found
:::

:::evaluate
Comprovar les respostes
:::

## Anomenar els protocols implicats

A partir de les teves observacions ja pots deduir quin protocol s'ha encarregat de què.

:::tip Pista
Rellegeix les columnes **Info**: `Who has …?`, `[SYN]`, `[SYN, ACK]`, `[ACK]`, `GET /` i `200 OK` ja ho diuen gairebé tot.
:::

:::quiz match
ARP -> Pregunta a tothom a la xarxa: «Qui té l'adreça IP 192.168.0.20?»
TCP -> Estableix una connexió amb tres paquets curts abans que flueixin les dades
HTTP -> Sol·licita la pàgina web (GET) i la retorna (200 OK)
:::

:::evaluate
Comprovar l'associació
:::

:::tip Idea clau
Una consulta de pàgina web es desenvolupa per etapes: primer **trobar** el servidor a la xarxa (ARP), després **establir** una connexió (TCP), després **sol·licitar i lliurar** la pàgina (HTTP) — i finalment **tancar** la connexió de nou (els paquets TCP amb `[FIN]` al final de la llista).
:::

:::note
Aquesta vegada has introduït directament l'adreça IP del servidor, per això encara no ha intervingut el **DNS** (la «traducció» de noms com `www.beispiel.de` a una adreça IP). Ho recuperarem al capítol 6.
:::

T'has fixat que els protocols a l'estructura del paquet porten marques de colors amb números? Què signifiquen ho aclarirem al capítol 2. Allà veurem com classificar de manera sistemàtica els molts protocols — amb els models de referència OSI i TCP/IP. Amb això, has acabat el capítol 1.

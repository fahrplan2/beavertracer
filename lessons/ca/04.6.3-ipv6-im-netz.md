# IPv6 a la xarxa

:::sim
url=/sims/lesson-4.6.3.btsim
:::

Al switch hi ha connectats l'Anna, en Ben i un encaminador. A l'Anna i en Ben, IPv6 està configurat en **SLAAC (automàtic)** — ningú no els ha introduït cap adreça IPv6. L'encaminador coneix el prefix `2001:db8:1::/64`.

## D'on surt l'adreça?

1. Canvia al mode d'execució :fa-play: **Executar** i espera uns segons.
2. Obre el :fa-terminal: **Terminal** de l'**Anna** i escriu `ip a`.

A més de l'adreça IPv4, veuràs dues línies amb `inet6`: una adreça amb `scope link` i una amb `scope global`.

:::quiz mc
Quina de les dues adreces IPv6 és l'adreça d'enllaç local (link-local)?
- [x] La que comença per `fe80::` (`scope link`)
- [ ] La que comença per `2001:db8:1:` (`scope global`)
:::

:::quiz mc
D'on surt el prefix `2001:db8:1:0` de l'adreça global?
- [ ] L'Anna se l'ha inventat ella mateixa
- [x] De l'encaminador — anuncia el prefix a la xarxa
- [ ] Del switch
:::

:::evaluate
Comprova les respostes
:::

Compara l'**identificador d'interfície** (els quatre últims blocs) amb l'**adreça MAC** de l'Anna — la trobaràs a baix de tot, a la :fa-gear: **Configuració IP**. De l'adreça MAC `aa:28:39:e2:41:82`, per exemple, surt l'identificador d'interfície `a828:39ff:fee2:4182`: al mig s'hi insereix `ff:fe` i es inverteix un bit del principi (per això `aa` es converteix en `a8`).

Aquest procediment s'anomena **SLAAC** (*Stateless Address Autoconfiguration*): l'encaminador anuncia el prefix i cada dispositiu forma ell mateix l'identificador d'interfície.

:::note
Com que l'adreça MAC identifica un dispositiu de manera inequívoca, mitjançant l'identificador d'interfície es podria reconèixer a qualsevol lloc d'Internet. Per això, els dispositius reals solen utilitzar, a més, identificadors d'interfície aleatoris que canvien regularment (*Privacy Extensions*) — un petit tros de protecció de dades.
:::

## Trobar els veïns — sense ARP

1. Escriu `ip a` a en **Ben** i anota la seva adreça IPv6 **global**.
2. Fes-li un ping des de l'**Anna**, per exemple `ping 2001:db8:1:0:…` (amb l'adreça completa d'en Ben).
3. Canvia al mode :fa-magnifying-glass: **Traça** i obre una traça per a l'**Anna**.

Mira els paquets immediatament anteriors al primer `Echo (ping) request`.

:::quiz multi
Quines afirmacions són correctes?
- [x] En lloc d'una consulta ARP, l'Anna envia una **Neighbor Solicitation** («Qui té aquesta adreça?»)
- [x] En Ben respon amb un **Neighbor Advertisement** i indica la seva adreça MAC
- [x] La consulta va a una adreça multicast (`ff02::1:ff…`), no a tothom per difusió (broadcast)
- [ ] L'Anna envia una consulta ARP com amb IPv4
- [x] L'encaminador envia regularment **Router Advertisements** a `ff02::1` — hi consta el prefix
:::

:::evaluate
Comprova les respostes
:::

:::tip Idea clau
A IPv6, **NDP** (*Neighbor Discovery Protocol*, part d'ICMPv6) assumeix les tasques d'ARP: amb **Neighbor Solicitation** i **Neighbor Advertisement**, els dispositius troben les adreces MAC dels seus veïns. Amb els **Router Advertisements**, l'encaminador anuncia el prefix — a partir d'aquest, els dispositius formen la seva pròpia adreça mitjançant **SLAAC**.
:::

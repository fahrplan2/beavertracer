# Una connexió de principi a fi

:::sim
url=/sims/lesson-5.1.btsim
:::

Al **Server** s'executa el servei d'eco al port `5000`: envia immediatament de tornada cada missatge. Amb el **Client TCP simple** pots controlar una connexió pas a pas: cada botó és una fase.

## L'experiment

1. Canvia al mode :fa-play: **Executar**, fes clic al **Client-PC** i obre el **Client TCP simple**.
2. A **Host** introdueix `192.168.0.20` i a **Port** `5000`.
3. Fes clic a **Connectar**.
4. Escriu `Hello World` al camp del missatge i fes clic a **Enviar**. A la finestra del xat veuràs tot seguit l'eco del servidor.
5. Fes clic a **Desconnectar**.
6. Canvia al mode :fa-magnifying-glass: **Traça** i amb **+** obre una traça per al **Client-PC**, connexió `eth0`.

:::note
Els dos paquets ARP del principi ja els coneixes del capítol 1. A la columna **Info** dels paquets TCP hi ha primer `49152 → 5000` (de quin port a quin port), després, entre claudàtors, els **flags** i a continuació xifres com `Seq=`, `Ack=` i `Len=`. De les xifres ens n'ocupem a partir de la pàgina 5.2.3: aquí et fixes en els flags i en `Len`.
:::

## Fase 1: Connectar

:::quiz short
Quants paquets TCP es van intercanviar després de fer clic a **Connectar**, abans que sortís el teu missatge?
= 3
= tres
:::

:::quiz mc
Qui envia el primer paquet amb `[SYN]`?
- [x] El Client-PC
- [ ] El Server
:::

:::quiz mc
Amb quins flags respon el servidor?
- [ ] `[SYN]`
- [x] `[SYN, ACK]`
- [ ] `[ACK]`
- [ ] `[FIN, ACK]`
:::

## Fase 2: Enviar

`Len` indica quants bytes de dades útils porta un paquet.

:::quiz short
Quants bytes porta el paquet amb el teu missatge (`Len`)?
= 13
:::

:::note
`Hello World` només té 11 caràcters. Però el client TCP hi afegeix un final de línia (2 bytes, `\r\n`): així ho esperen molts protocols d'Internet com SMTP o HTTP.
:::

:::quiz mc
Què et torna el servidor just després del teu missatge, encara abans de l'eco?
- [x] Un paquet amb `[ACK]` i `Len=0`: una confirmació sense dades
- [ ] Res en absolut
- [ ] Un nou `[SYN]`
:::

## Fase 3: Desconnectar

:::quiz short

= 4
= quatre
:::

:::quiz mc
Què comunica una part amb `FIN`?
- [x] «He acabat»: ja no envia més dades
- [ ] «S'ha produït un error»
- [ ] «Aquí arriben dades noves»
:::

Comprova les respostes

## On són les quatre tasques?

Relaciona on retrobes a la traça les tasques de l'apartat 5.1:

:::quiz match
Establiment de la connexió -> Els tres paquets [SYN], [SYN, ACK] i [ACK]
Transmissió fiable -> Paquets amb [ACK] i Len=0 que confirmen la recepció
Finalització de la connexió -> Els paquets amb FIN i les seves confirmacions
Multiplexació -> Els números de port 49152 → 5000 abans dels claudàtors
:::

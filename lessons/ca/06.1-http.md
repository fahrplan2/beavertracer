# HTTP: pàgines web

:::goal
**Objectiu d'aprenentatge:** Pots descriure l'estructura d'una petició i d'una resposta HTTP, explicar els mètodes i els codis d'estat més importants i fer tu mateix una petició HTTP a mà.
:::

:::sim
url=/sims/lesson-6.1.btsim
:::

El **Hypertext Transfer Protocol** (**HTTP**) és el llenguatge en què es comuniquen els navegadors i els servidors web. Al servidor hi ha la pàgina web de la **Beaver-Schule**: una pàgina d'inici, una pàgina de contacte i un full d'estil per a l'aspecte.

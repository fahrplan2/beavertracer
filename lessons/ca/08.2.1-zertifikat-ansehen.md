# Veure un certificat

:::sim
url=/sims/lesson-8.2.1.btsim
:::

A l'espai de treball veus el **Client-PC**, un **DNS-Server** i el servidor web de l'escola, `www.beaver-schule.de`. El servidor web ofereix les seves pàgines també mitjançant **HTTPS**.

## El cadenat al navegador

1. Canvia al mode d'execució :fa-play: **Executar**, fes clic al **Client-PC** i obre el :fa-globe: **Navegador**.
2. Obre `https://www.beaver-schule.de/` — fixa't en el **https**.
3. A l'esquerra de l'adreça apareix un **cadenat**. Fes-hi clic.

:::quiz short
Per a quin nom s'ha emès el certificat (subjecte sense `CN=`)?
= www.beaver-schule.de
:::

:::quiz short
Qui ha emès el certificat (emissor sense `CN=`)?
= Biber Root CA
:::

:::evaluate
Comprova les respostes
:::

## Per què el Client-PC confia en el certificat?

Al **Client-PC**, obre la :fa-shield-halved: **Zertifikatverwaltung** i canvia a la pestanya **Vertrauenswürdige CAs**.

:::quiz mc
Què hi trobes?
- [x] El certificat de la **Biber Root CA**
- [ ] El certificat de `www.beaver-schule.de`
- [ ] Cap entrada
:::

:::quiz mc
Com es veu que la Biber Root CA és una CA arrel?
- [x] És **autosignada**: el subjecte i l'emissor són iguals
- [ ] El seu nom acaba en «CA»
- [ ] No té clau pública
:::

:::quiz mc
Al Client-PC, sota **Privater Schlüssel** hi diu «Sí» o «No»?
- [ ] Sí — el client necessita la clau privada de la CA per verificar signatures
- [x] No — per verificar n'hi ha prou amb la clau pública; la clau privada només la té la CA
:::

:::evaluate
Comprova les respostes
:::

## L'altra banda: el servidor web

Ara, al servidor web **www.beaver-schule.de**, obre la :fa-shield-halved: **Zertifikatverwaltung** (pestanya **Meine Zertifikate**) i mira'n el certificat.

:::quiz multi
Què és cert del certificat del servidor web?
- [x] Sota **Privater Schlüssel** hi diu «Sí» — el servidor el necessita per a l'establiment de la connexió
- [x] La **cadena** és `www.beaver-schule.de ← Biber Root CA`
- [x] L'**empremta digital** és la mateixa que a la finestra del cadenat del navegador
- [ ] És autosignat
:::

:::evaluate
Comprova les respostes
:::

:::note
L'**empremta digital** és un valor hash calculat sobre el certificat. Permet comparar ràpidament dos certificats, sense haver de revisar tots els camps un per un.
:::

:::tip Idea clau
El **servidor web** té el seu certificat **amb clau privada**. El **client** només coneix el **certificat de la CA arrel** (sense clau privada) — això li basta per verificar la signatura del certificat del servidor. Si al navegador fas clic al **cadenat**, veus el subjecte, l'emissor, l'empremta digital i la validesa.
:::

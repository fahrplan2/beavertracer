# Sense estat o amb estat

Una connexió sempre consta de **dues direccions**: l'ordinador del professor envia una sol·licitud a un servidor web a Internet, i el servidor web li retorna la pàgina web. Per tant, un tallafoc basat en el principi de llista blanca no només ha de deixar passar la sol·licitud, sinó també la **resposta**.

Per a això hi ha dos tipus de filtres de paquets:

| | **Sense estat** (*stateless*) | **Amb estat** (*stateful*) |
|---|---|---|
| Funcionament | comprova cada paquet per separat, sense memòria | recorda les connexions permeses en una **taula d'estats** |
| Respostes | necessiten una regla pròpia per al sentit invers | es deixen passar automàticament perquè pertanyen a una connexió coneguda |
| Ús | dispositius senzills, filtres molt ràpids | pràcticament qualsevol tallafoc actual |

En les dues seccions següents veuràs per què els filtres sense estat tenen problemes amb les respostes i com els soluciona un tallafoc amb estat.

:::quiz match
Ethernet -> Capa 2 — Enllaç de dades
IPv4 -> Capa 3 — Xarxa
TCP -> Capa 4 — Transport
HTTP -> Capa 7 — Aplicació
:::

:::evaluate
Comprova l'associació
:::

:::quiz match

:::evaluate
Comprova l'associació
:::

# Llegir el correu al Tracer

:::sim
url=/sims/lesson-6.3.btsim
:::

Igual que HTTP, SMTP també és un **protocol de text**. Mira tot el que viatja en text clar pel cable.

## L'experiment

1. Al mode :fa-play: **Executar**, com a la pàgina anterior, envia un correu d'**Anna** a `ben@biber-mail.de`.
2. Al mode :fa-magnifying-glass: **Traça**, obre un rastre per a **Anna**. A la columna **Info** hi ha el diàleg SMTP: les línies amb `C:` les envia el client, les línies amb `S:` el servidor.

:::quiz short
Quina adreça hi ha després de `MAIL FROM:`?
= anna@beaver-schule.de
= <anna@beaver-schule.de>
:::

:::quiz short
I quina després de `RCPT TO:`?
= ben@biber-mail.de
= <ben@biber-mail.de>
:::

:::quiz mc
Quin codi numèric envia el servidor quan accepta una ordre?
- [x] `250`
- [ ] `200`
- [ ] `404`
:::

:::evaluate
Comprova les respostes
:::

## I la contrasenya?

Abans de `MAIL FROM`, el programa d'Anna s'identifica amb `AUTH PLAIN` i una cadena de caràcters com `AGFubmEAZ2VoZWlt`. Sembla xifrada, però no ho és: és només **Base64**, una codificació que qualsevol pot tornar a traduir a l'instant; conté `anna` i la seva contrasenya `geheim`.

Ara recull el correu a **Ben** (**Obtenir**) i obre un rastre per a **Ben**. Quan es recull per IMAP, es veu encara més clarament:

:::quiz short
Quina contrasenya envia en text clar al servidor el programa de correu de Ben? (Mira la línia amb `LOGIN`.)
= biber123
:::

:::evaluate
Comprova la resposta
:::

:::warning
Sense xifrat, qualsevol que capturi el trànsit de dades pot llegir el **contingut, el remitent, el receptor i les contrasenyes**. Per això avui dia s'utilitzen variants xifrades (p. ex. SMTP amb STARTTLS, IMAPS al port 993). Com funciona això, ho aprendràs al capítol 8.
:::

:::tip Idea clau
**SMTP**, **POP3** i **IMAP** són protocols de text: les ordres com `MAIL FROM`, `RCPT TO`, `DATA` (SMTP) o `LOGIN` (IMAP) i les respostes són llegibles. Sense xifrat, també les **contrasenyes** viatgen pel cable en text clar (o només codificades en Base64).
:::

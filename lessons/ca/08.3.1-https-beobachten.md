# Comparació entre HTTP i HTTPS

:::sim
url=/sims/lesson-8.2.1.btsim
:::

El servidor web **www.beaver-schule.de** ofereix el portal de notes de l'escola tant per HTTP com per HTTPS. Què veu algú que escolta la comunicació?

## L'experiment

1. Canvia al mode d'execució :fa-play: **Executar** i, al **Client-PC**, obre al :fa-globe: **Navegador** primer `http://www.beaver-schule.de/` i després `https://www.beaver-schule.de/`.
2. Al mode :fa-magnifying-glass: **Traça**, obre un traçat per al **Client-PC**.
3. Busca primer el paquet `HTTP/1.1 200 OK` i fes-hi clic. A baix, als detalls, trobaràs el contingut de la pàgina.

:::quiz mc
Què pot veure algú que escolta la comunicació en **HTTP**?
- [x] La pàgina web completa, també les notes de l'Anna
- [ ] Només l'adreça del servidor
- [ ] Res, perquè HTTP funciona sobre TCP
:::

:::quiz short
Quina nota té l'Anna en matemàtiques?
= 2
:::

:::evaluate
Comprova les respostes
:::

Ara la part d'HTTPS. Busca el paquet `[SYN]` amb què el client comença la segona connexió.

:::quiz short
Quin port de destinació té la connexió HTTPS (columna **Info**, `… → ???`)?
= 443
:::

Ara escriu `tls` al camp de filtre de dalt del traçat — així només veuràs els paquets TLS.

:::quiz mc
Què hi ha a la columna **Info** dels paquets que contenen la pàgina web?
- [ ] `HTTP/1.1 200 OK`
- [x] `Application Data`
- [ ] `Encrypted HTML`
:::

:::quiz multi
Què pot veure tot i així algú que escolta la comunicació en **HTTPS**?
- [x] Les adreces IP del client i del servidor
- [x] Que s'utilitza el port 443, és a dir, probablement HTTPS
- [x] Aproximadament quantes dades es transmeten
- [ ] Quina pàgina s'ha consultat i què hi diu
:::

:::evaluate
Comprova les respostes
:::

:::note
Fes clic en un paquet **Application Data**: les dades útils són només una successió de bytes aparentment aleatoris. El Tracer no els pot desxifrar — coneix la clau de sessió tan poc com un atacant.
:::

:::tip Idea clau
En **HTTP**, qualsevol que escolti la comunicació pot llegir la pàgina web completa. En **HTTPS** només veu **qui parla amb qui** (adreces IP, port 443) i **quant** — el contingut va xifrat dins de paquets **Application Data**.
:::

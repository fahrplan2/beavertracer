# WLAN: xarxa sense cables

:::goal
**Objectiu d'aprenentatge:** Saps explicar com un punt d'accés connecta una xarxa WLAN amb la xarxa cablejada, incorporar un dispositiu a la WLAN mitjançant l'SSID i justificar per què una WLAN ha d'estar xifrada.
:::

Els mòbils, les tauletes i els portàtils majoritàriament ja no tenen cap connexió de xarxa: es connecten per ràdio, mitjançant una **WLAN** (*Wireless LAN*, xarxa d'àrea local sense fils). Perquè, tot i això, puguin comunicar-se amb els PC i els servidors connectats per cable, cal un dispositiu que connecti la ràdio i el cable.

:::note
A la realitat, una WLAN depèn de l'abast, de les parets i de les interferències. BeaverTracer ho simplifica: tots els dispositius amb el mateix nom de WLAN comparteixen una xarxa sense fils comuna, independentment d'on es trobin a l'espai de treball.
:::

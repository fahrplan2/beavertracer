# POP3 o IMAP?

:::sim
url=/sims/lesson-6.3.btsim
:::

Per recollir el correu hi ha dos protocols. En aquesta simulació, **l'Anna fa servir POP3** i **en Ben fa servir IMAP**.

## L'experiment

1. En el :fa-play: mode d'execució, envia un correu d'**en Ben** a `anna@beaver-schule.de`.
2. A l'aplicació **E-Mail** de l'**Anna**, fes clic a **Obtenir**.
3. Obre les traces de l'**Anna** i d'**en Ben** i compara les ordres que s'utilitzen en recollir el correu.

:::quiz match
USER / PASS -> POP3: iniciar la sessió amb nom d'usuari i contrasenya en dos passos
RETR -> POP3: descarregar un missatge
LOGIN -> IMAP: iniciar la sessió amb nom d'usuari i contrasenya
SELECT INBOX -> IMAP: obrir una carpeta al servidor
:::

:::evaluate
Comprova l'associació
:::

## La diferència

| | POP3 | IMAP |
|---|---|---|
| Port | 110 | 143 |
| Idea bàsica | **descarregar** els correus — després, normalment, s'esborren del servidor | els correus **es queden al servidor** i s'hi gestionen |
| Carpetes, llegit/no llegit | només al dispositiu propi | al servidor — igual a tot arreu |
| Diversos dispositius (mòbil, portàtil) | poc pràctic: cada dispositiu té un estat diferent | ideal: tots els dispositius veuen la mateixa bústia |

:::note
El programa de correu de BeaverTracer deixa els correus al servidor també amb POP3. Els programes reals sovint els esborren després de descarregar-los, o només els deixen allà durant un temps.
:::

:::quiz mc
La Lena llegeix els seus correus al mòbil, a la tauleta i al portàtil de l'escola. Què hauria de fer servir?
- [ ] POP3, perquè és més senzill
- [x] IMAP, perquè tots els dispositius veuen la mateixa bústia al servidor
- [ ] SMTP, perquè està pensat per recollir el correu
:::

:::evaluate
Comprova la resposta
:::

:::tip Idea clau
**POP3** descarrega els correus del servidor a **un** dispositiu. **IMAP** gestiona la bústia **al servidor**, amb carpetes i estat de lectura per a tots els dispositius alhora. Tots dos serveixen només per **recollir** el correu; l'enviament es fa sempre amb **SMTP**.
:::

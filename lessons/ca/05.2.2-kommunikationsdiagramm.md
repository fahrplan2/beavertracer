# El diagrama de seqüència

:::sim
url=/sims/lesson-5.1.btsim
:::

El desenvolupament d'una connexió es dibuixa com un **diagrama de seqüència**: el client i el servidor tenen cadascun una línia vertical, i el temps avança de dalt a baix. Cada fletxa és un paquet. Està dibuixada en diagonal perquè cada paquet triga una mica a arribar.

Així és la teva connexió de la pàgina anterior — compara-la línia per línia amb la traça:

:::seq
Client-PC -> Server: SYN
Server -> Client-PC: SYN, ACK
Client-PC -> Server: ACK
Client-PC -> Server: PSH, ACK "Hello World" len=13
Server -> Client-PC: ACK
Server -> Client-PC: PSH, ACK len=13
Client-PC -> Server: ACK
Client-PC -> Server: FIN, ACK
Server -> Client-PC: ACK
Server -> Client-PC: FIN, ACK
Client-PC -> Server: ACK
:::

Sobre cada fletxa hi ha els **indicadors (flags)**, i a sota els números `SEQ` i `ACK`. **DATA** marca els paquets amb dades útils. Els números vermells pertanyen al client, els blaus al servidor — què signifiquen s'explica a la pàgina següent.

## Els indicadors (flags)

| Flag | significa | Significat |
|---|---|---|
| **SYN** | *synchronize* | establir la connexió, fixar el número inicial |
| **ACK** | *acknowledge* | confirma les dades rebudes |
| **PSH** | *push* | passar les dades immediatament al programa |
| **FIN** | *finish* | «He acabat» — tancar la connexió |
| **RST** | *reset* | interrompre o rebutjar la connexió (més sobre això a 5.3.2) |

## Tres fases

**Establiment:** el client envia `SYN`, el servidor respon amb `SYN, ACK` i el client confirma amb `ACK`. Com que calen exactament tres paquets, s'anomena **salutació de tres vies (three-way handshake)**.

**Dades:** el receptor confirma amb un `ACK` cada paquet que conté dades. Aquí el servidor retorna l'eco — i el client també el confirma.

**Tancament:** cada costat finalitza per separat la seva direcció d'enviament: `FIN` del client, `ACK` del servidor — després `FIN` del servidor, `ACK` del client. Són quatre paquets.

:::tip Idea clau
Una connexió TCP passa per tres fases: **establiment** amb la **salutació de tres vies** (`SYN` → `SYN, ACK` → `ACK`), **transmissió de dades** (cada paquet de dades es confirma amb `ACK`) i **tancament** (cada costat envia `FIN` i rep un `ACK`).
:::

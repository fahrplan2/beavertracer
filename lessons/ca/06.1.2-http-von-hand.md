# HTTP a mà

:::sim
url=/sims/lesson-6.1.btsim
:::

Si HTTP és text pla, també es pot parlar un mateix amb un servidor web, sense cap navegador? Sí: amb `telnet` estableixes una connexió TCP amb qualsevol port i escrius tu mateix el text.

## L'experiment

1. Canvia al mode d'execució :fa-play: **Executar** i obre el :fa-terminal: **Terminal** al **Client-PC**.
2. Connecta't al port 80 del servidor:
   ```
   $ telnet 192.168.0.20 80
   ```
3. Escriu la petició línia per línia i acaba-la amb una **línia buida** (simplement prem **Enter** una vegada més):
   ```
   GET /kontakt.html HTTP/1.1
   Host: 192.168.0.20

   ```

El servidor respon amb una línia d'estat, capçaleres i la pàgina de contacte, com a text, tal com també la rep el navegador.

:::quiz mc
Com sap el servidor que la teva petició ha acabat?
- [ ] Per una ordre especial `END`
- [x] Per la línia buida
- [ ] Després d'un cert temps
:::

:::quiz short
Quin valor hi ha a la resposta a la capçalera `Content-Type`? (només la primera part abans del `;`)
= text/html
:::

:::evaluate
Comprova les respostes
:::

## Provocar errors

Una eina més còmoda és `curl`: fa la petició per tu. Amb `-v` (*verbose*, detallat) mostra tot el que va i ve: les línies amb `>` les ha enviat `curl`, les línies amb `<` han vingut del servidor.

Prova-ho:

```
$ curl -v http://192.168.0.20/gibtsnicht.html
$ curl -X POST -d name=Anna http://192.168.0.20/
```

:::quiz short
Quin codi d'estat obtens per a `/gibtsnicht.html`?
= 404
:::

:::quiz short
I quin per a la petició amb el mètode `POST`?
= 405
:::

:::evaluate
Comprova les respostes
:::

:::note
El servidor web de BeaverTracer només pot servir fitxers; per això només permet `GET` i `HEAD`. Els servidors web reals accepten, per exemple, formularis amb `POST` i passen les dades a un programa.
:::

:::tip Idea clau
Molts protocols de la capa d'aplicació són **textuals**: HTTP, però també SMTP, POP3 i IMAP. Per això es poden parlar a mà amb `telnet` i llegir-los a la traça. Això és pràctic per a la resolució de problemes, però també és un problema de seguretat: qualsevol que capturi el trànsit ho pot llegir tot. Com ajuda el xifratge (HTTPS) ho aprendràs al capítol 8.
:::

# Obtenir una adreça automàticament

:::sim
url=/sims/lesson-6.4.btsim
:::

Al switch hi ha connectats un **Servidor DHCP** i dos portàtils. Els portàtils encara tenen adreces fixes.

## L'experiment

1. Canvia al mode d'execució :fa-play: **Executar**, fes clic a **Laptop 1** i obre la :fa-gear: **Configuració IP**.
2. Canvia el **Mode** d'**Estàtic** a **DHCP** i fes clic a **Aplicar**.
3. Espera uns segons: els camps s'omplen sols.
4. En el mode :fa-magnifying-glass: **Traça**, obre una traça per a **Laptop 1**.

:::quiz table
| Paràmetre | rebut del servidor DHCP |
|---|---|
| Adreça IP | {192.168.0.100} |
| Gateway | {192.168.0.1} |
| Servidor DNS | {192.168.0.53} |
:::

:::quiz short
Quants paquets DHCP trobes a la traça?
= 4
= quatre
:::

:::quiz mc
A quina adreça IP de destinació envia Laptop 1 el seu primer paquet (`DHCP Discover`)?
- [ ] Al servidor DHCP `192.168.0.2`
- [x] A `255.255.255.255` — a tothom (difusió)
- [ ] Al gateway `192.168.0.1`
:::

:::quiz mc
Quina adreça IP de remitent té aquest primer paquet — i per què?
- [x] `0.0.0.0` — el portàtil encara no té cap adreça
- [ ] `192.168.0.10` — la seva adreça antiga
- [ ] `192.168.0.100` — la seva adreça nova
:::

## Què hi ha al darrere: DORA

Un dispositiu sense adreça no sap on és el servidor DHCP, ni tampoc té una adreça de remitent pròpia. Per això crida a la xarxa mitjançant **difusió** (*broadcast*). El procés té quatre passos — anomenats **DORA** per les seves lletres inicials:

:::seq
mode: text
Laptop 1 -> DHCP-Server: DHCP Discover | „Hi ha aquí algun servidor DHCP?“
DHCP-Server -> Laptop 1: DHCP Offer | „Pots tenir la 192.168.0.100.“
Laptop 1 -> DHCP-Server: DHCP Request | „Agafo la 192.168.0.100.“
DHCP-Server -> Laptop 1: DHCP ACK | „Confirmat — vàlida durant 3600 segons.“
:::

L'adreça només està **prestada** (*lease*): quan acaba el **temps de concessió** (*lease time*), el dispositiu l'ha de renovar; si no, el servidor la pot tornar a assignar. Les adreces que ara mateix estan prestades les pots veure al **Servidor DHCP**, a la pestanya **Leases**.

:::tip Prova-ho
Posa també **Laptop 2** en DHCP. Quina adreça rep? Després mira les **Leases** del servidor DHCP.
:::

:::tip Idea clau
**DHCP** distribueix automàticament l'adreça IP, la màscara de xarxa, el gateway i el servidor DNS. El procés s'anomena **DORA**: **D**iscover (el client cerca per difusió), **O**ffer (el servidor ofereix), **R**equest (el client accepta), **A**CK (el servidor confirma). L'adreça està prestada durant el **temps de concessió**. DHCP utilitza **UDP**, port 67 (servidor) i 68 (client).
:::

:::quiz match
Discover -> El client cerca un servidor DHCP per difusió
Offer -> El servidor ofereix una adreça
Request -> El client sol·licita l'adreça oferta
ACK -> El servidor confirma l'assignació
:::

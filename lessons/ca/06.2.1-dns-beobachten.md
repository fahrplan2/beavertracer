# Observar una resolució de noms

:::sim
url=/sims/lesson-6.2.btsim

## L'experiment

1. Canvia al mode d'execució :fa-play: **Executar**, fes clic al **Client-PC** i obre el :fa-globe: **Navegador**.
2. Aquesta vegada obre `http://www.beaver-schule.de/` — amb un nom en lloc d'una adreça IP.
3. Canvia al mode :fa-magnifying-glass: **Traça** i obre una traça per al **Client-PC**.

Al principi de tot — encara abans de l'establiment de la connexió amb `[SYN]` — hi ha dos paquets amb el protocol **DNS**.

:::quiz short
A quina adreça IP envia el Client-PC la seva consulta DNS?
= 192.168.0.53
:::

:::quiz short
Quina adreça IP hi ha a la resposta per a `www.beaver-schule.de`?
= 192.168.0.20
:::

:::quiz mc
Fes clic a la consulta DNS i desplega l'arbre de protocols. Quin protocol de transport i quin port de destinació s'utilitzen?
- [ ] TCP, port 80
- [x] UDP, port 53
- [ ] UDP, port 67
:::

:::evaluate
Comprova les respostes
:::

Només després que el Client-PC conegui l'adreça IP, estableix la connexió TCP amb el servidor web — igual que al capítol 5.

:::seq
mode: text
Client-PC -> DNS-Resolver: DNS-Anfrage | A www.beaver-schule.de?
DNS-Resolver -> Client-PC: DNS-Antwort | A 192.168.0.20
:::

## Com coneix el PC el servidor DNS?

Obre al **Client-PC** la :fa-gear: **Configuració IP**: al camp **DNS-Server** hi ha `192.168.0.53` — l'ordinador **DNS-Resolver**. A aquest li envia el PC totes les consultes de noms.

També pots preguntar directament al servidor DNS, sense navegador. Obre el :fa-terminal: **Terminal** i escriu:

```
$ nslookup www.beaver-schule.de
```

`nslookup` mostra primer a quin servidor ha preguntat i després la resposta. Per comparar, pregunta per un nom que no existeix, per exemple `nslookup gibtsnicht.beaver-schule.de`.

:::quiz mc
Què respon el servidor DNS al nom desconegut?
- [ ] Una adreça IP aleatòria
- [x] `NXDOMAIN` — aquest nom no existeix
- [ ] Res en absolut
:::

:::evaluate
Comprova la resposta
:::

:::tip Idea clau
El **DNS** tradueix noms (p. ex. `www.beaver-schule.de`) en adreces IP. Abans que un PC pugui establir una connexió amb un nom, pregunta al **servidor DNS** que té indicat a la seva configuració IP — normalment mitjançant **UDP, port 53**. Amb `nslookup` pots fer consultes DNS manualment.
:::

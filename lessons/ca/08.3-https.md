# HTTPS

:::osi 5
:::

**HTTPS** (*HTTP Secure*) és HTTP completament normal, només que no s'executa directament sobre TCP, sinó a través d'una capa xifrada intermèdia: **TLS** (*Transport Layer Security*). El predecessor de TLS s'anomenava **SSL**; per això encara se sol parlar de «certificats SSL».

```
ohne Verschlüsselung:   HTTP  →  TCP  →  IP
mit Verschlüsselung:    HTTP  →  TLS  →  TCP  →  IP
```

HTTP no se n'adona de res: envia les seves peticions com sempre, TLS les xifra i TCP les transporta. En el model OSI, TLS se situa entre la capa de transport i la capa d'aplicació, és a dir, a la capa 4/5: es basa en TCP i gestiona una sessió segura.

| | HTTP | HTTPS |
|---|---|---|
| Port | 80 | **443** |
| Adreça | `http://…` | `https://…` |
| Contingut llegible al Tracer? | sí | no |
| El navegador mostra | «no segur» | un cadenat |

TLS fa durant l'establiment de la connexió tot el que has après en aquest capítol:

- El servidor s'identifica amb el seu **certificat** (**autenticitat**).
- Les dues parts negocien una **clau de sessió** amb **Diffie-Hellman**; el servidor **signa** la seva part.
- Després, totes les dades es xifren amb **AES** (**confidencialitat**) i es protegeixen contra modificacions (**integritat**).

El principi no es limita al web: també el correu electrònic (apartat 8.4) i molts altres protocols passen per TLS de la mateixa manera.

En els apartats següents observaràs HTTPS al Tracer, el configuraràs tu mateix i investigaràs quan el navegador avisa i per què.

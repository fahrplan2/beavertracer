# Adreça de xarxa, adreça de difusió i hosts

En cada xarxa hi ha dues adreces que tenen una funció especial:

- L'**adreça de xarxa** és l'adreça **més baixa** de la xarxa: tots els bits de la part de host són 0. Designa la xarxa com a conjunt, p. ex. a les taules d'encaminament.
- L'**adreça de difusió** és l'adreça **més alta** de la xarxa: tots els bits de la part de host són 1. Tot el que s'hi envia va a parar a tots els dispositius de la xarxa.

Cap d'aquestes dues adreces **no** s'assigna a dispositius. Totes les adreces intermèdies estan disponibles per als dispositius (**hosts**).

## Un exemple senzill

`192.168.0.12/24` — la part de host és l'últim octet:

| | Adreça |
|---|---|
| Adreça de xarxa (part de host = 0) | `192.168.0.0` |
| Adreça de difusió (part de host = 255) | `192.168.0.255` |
| Rang per a hosts | `192.168.0.1` – `192.168.0.254` |
| Nombre de hosts | 254 |

## Quan el límit queda enmig d'un octet

Es complica quan la longitud del prefix no és un múltiple de 8. Aleshores has de convertir l'octet afectat al sistema binari. Exemple: `194.9.190.12/27`.

Els tres primers octets pertanyen íntegrament a la [[n|part de xarxa]] (24 bits). De l'últim octet, **3 bits** pertanyen encara a la part de xarxa (24 + 3 = 27) i els **5 bits** restants a la [[h|part de host]]:

| | últim octet (binari) | decimal |
|---|---|---|
| Adreça IP | [[n|000]][[h|01100]] | 12 |
| Màscara de xarxa (`/27`) | [[n|111]][[h|00000]] | 224 |
| Adreça de xarxa: bits de host a 0 | [[n|000]][[h|00000]] | **0** |
| Adreça de difusió: bits de host a 1 | [[n|000]][[h|11111]] | **31** |

Resultat:

- Adreça de xarxa: `194.9.190.0`
- Adreça de difusió: `194.9.190.31`
- Rang per a hosts: `194.9.190.1` – `194.9.190.30`
- Nombre de hosts: 2⁵ − 2 = **30**

:::tip Idea clau
**Adreça de xarxa:** tots els bits de host a 0 (l'adreça més baixa). **Adreça de difusió:** tots els bits de host a 1 (l'adreça més alta). Cap de les dues no s'assigna a dispositius. Una xarxa amb longitud del prefix *n* té **2<sup>32 − n</sup> − 2** adreces utilitzables per a hosts.
:::

:::tip Consell: la mida del bloc
Quan hagis entès el procediment en sistema binari, hi ha un truc més ràpid: **256 menys l'octet de la màscara** dona la mida d'una xarxa en aquest octet. Amb `/27` (màscara 224) és 256 − 224 = **32**. Les xarxes comencen llavors a 0, 32, 64, 96 … — l'adreça `.12` es troba a la xarxa que comença a `.0`, l'adreça `.70` a la xarxa que comença a `.64`.
:::

## Les mides de xarxa més importants

| Prefix | Màscara de xarxa | Hosts |
|---|---|---|
| `/8` | `255.0.0.0` | 16 777 214 |
| `/16` | `255.255.0.0` | 65 534 |
| `/24` | `255.255.255.0` | 254 |
| `/25` | `255.255.255.128` | 126 |
| `/26` | `255.255.255.192` | 62 |
| `/27` | `255.255.255.224` | 30 |
| `/28` | `255.255.255.240` | 14 |
| `/29` | `255.255.255.248` | 6 |
| `/30` | `255.255.255.252` | 2 |

:::note
La xarxa més petita habitual a la pràctica és `/30`: té exactament dues adreces utilitzables i se sol fer servir per a l'enllaç entre dos encaminadors. Un `/32` designa una única adreça — com a xarxa no es pot fer servir, però apareix a les taules d'encaminament i a les regles de tallafoc.
:::

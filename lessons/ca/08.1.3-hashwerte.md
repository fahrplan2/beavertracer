# Valors hash: l'empremta digital de les dades

:::sim
url=/sims/lesson-8.1.3.btsim
:::

Una **funció hash** calcula, a partir d'una quantitat qualsevol de dades — una frase, un document, una pel·lícula sencera —, una cadena de caràcters curta de longitud fixa: el **valor hash**. Funciona com una **empremta digital**: les mateixes dades donen sempre el mateix valor hash, i unes dades diferents en donen un de diferent.

La funció hash més habitual avui dia es diu **SHA-256**. El seu valor hash sempre té 256 bits de longitud, és a dir, 64 caràcters com a nombre hexadecimal.

## L'experiment

Al **PC**, a la carpeta `/home`, hi ha tres fitxers amb un petit contracte de compravenda. Canvia al :fa-play: mode d'execució (**Executar**), obre el :fa-terminal: **Terminal** del **PC** i escriu:

```
$ cd /home
$ cat vertrag.txt vertrag-kopie.txt vertrag-neu.txt
$ sha256sum vertrag.txt vertrag-kopie.txt vertrag-neu.txt
```

:::quiz short

= 4ea55434
:::

:::tip Prova-ho
Obre `vertrag.txt` amb `nano vertrag.txt`, canvia un sol caràcter (p. ex. un punt per un signe d'exclamació), desa el fitxer i torna a calcular el valor hash. Després torna a canviar el caràcter: el valor hash original torna a aparèixer.
:::

## Propietats d'una funció hash

| Propietat | Significat |
|---|---|
| **longitud fixa** | Tant se val la mida de les dades: el valor hash té sempre la mateixa longitud. |
| **unívoca** | Les mateixes dades donen sempre el mateix valor hash. |
| **efecte allau** | Fins i tot el canvi més petit dóna un valor hash completament diferent. |
| **funció unidireccional** | A partir del valor hash **no** es poden tornar a calcular les dades. |
| **resistent a col·lisions** | A la pràctica és impossible trobar dos fitxers diferents amb el mateix valor hash. |

Una funció hash **no és un xifratge**: no hi ha cap clau ni es pot desxifrar. Serveix per a un altre propòsit: la **integritat**.

## Per a què serveix?

- **Comprovar descàrregues:** Molts llocs web indiquen, al costat d'un fitxer, el seu valor SHA-256. Si el valor hash del fitxer que has descarregat hi coincideix, vol dir que no s'ha modificat pel camí.
- **Desar contrasenyes:** Els bons llocs web no desen la teva contrasenya, sinó només un valor hash d'aquesta. En iniciar la sessió es compara el valor hash del que has escrit. Si es roba la base de dades, el lladre tot i així no coneix les contrasenyes.
- **Signatures digitals:** En lloc de signar un document sencer, se'n signa només el valor hash — en parlarem més a la secció següent.

:::tip Idea clau
Una **funció hash** (p. ex. **SHA-256**) calcula, a partir de dades qualssevol, un **valor hash** de longitud fixa — una **empremta digital**. Fins i tot el canvi més petit dóna un valor hash completament diferent, i a partir del valor hash no es poden tornar a calcular les dades. Els valors hash asseguren la **integritat** de les dades.
:::

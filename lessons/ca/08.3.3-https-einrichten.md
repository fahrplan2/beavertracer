# Configurar HTTPS

:::sim
url=/sims/lesson-8.3.3.btsim
:::

Aquí continuem allà on es va deixar l'apartat 8.2.2: al servidor web **www.beaver-schule.de** hi ha la **Schul-CA** i un certificat de servidor emès per ella, i el **Client-PC** confia en la Schul-CA. Però el servidor web encara no parla HTTPS.

## Abans

Canvia al mode d'execució (:fa-play: **Executar**) i, al **Client-PC**, obre `https://www.beaver-schule.de/` amb el :fa-globe: **Navegador**.

:::quiz mc
Què passa?
- [x] La connexió no s'estableix: cap servei escolta al port 443
- [ ] El navegador avisa d'un certificat no segur
- [ ] La pàgina es mostra sense cadenat
:::

:::evaluate
Comprova la resposta
:::

## Activar HTTPS

1. Al servidor web, obre el **Servidor HTTP** i fes clic a **Aturar**: mentre el servidor està en marxa, no es poden canviar els paràmetres.
2. Canvia a la pestanya **HTTPS**:
    - Marca la casella **Activar HTTPS** i posa **Port HTTPS** `443`
    - A **Certificat**, selecciona el certificat de servidor `www.beaver-schule.de`, no la Schul-CA!
    - Fes clic a **Utilitzar**
3. Fes clic a **Iniciar**.

Torna a obrir la pàgina al Client-PC amb `https://`. Fes clic al cadenat i comprova l'emissor i la validesa.

check: httpsOk(2, "https://www.beaver-schule.de/")

:::quiz mc
Per què no pots seleccionar el certificat de la **Schul-CA** al Servidor HTTP?
- [ ] Perquè els certificats de CA no poden xifrar
- [x] Perquè està emès per al nom `Schul-CA`, no per a `www.beaver-schule.de`: el navegador avisaria
- [ ] Perquè la Schul-CA no té clau privada
:::

:::quiz mc
Què veuria un dispositiu que **no** confia en la Schul-CA, per exemple el mòbil d'un convidat?
- [ ] La pàgina amb total normalitat i amb cadenat
- [x] Una advertència de certificat, perquè no pot seguir la cadena de confiança fins a una CA coneguda
- [ ] Res en absolut, perquè la connexió es rebutja
:::

:::evaluate
Comprova les respostes
:::

:::note
Per a les pàgines web públiques cal un certificat d'una CA que vingui preinstal·lada a tots els navegadors. Des del 2015 existeix **Let's Encrypt**, una CA que emet aquests certificats de manera gratuïta i automàtica, una de les raons principals per les quals avui gairebé totes les pàgines web utilitzen HTTPS.
:::

:::tip Idea clau
Per a **HTTPS**, el servidor web necessita un **certificat de servidor amb clau privada** el nom del qual coincideixi amb l'adreça, i ha d'escoltar al **port 443**. El client només confia en la pàgina si coneix la **CA** emissora.
:::

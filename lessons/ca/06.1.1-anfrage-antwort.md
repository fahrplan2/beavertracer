Així doncs, una pàgina web sovint consta de molts fitxers: text, fulls d'estil, imatges. Per a cadascun, el navegador envia una petició pròpia.

## Com és una petició

Fes clic al paquet `GET / HTTP/1.1` del trace i desplega **Hypertext Transfer Protocol**. Una petició HTTP és text pla:

```
GET / HTTP/1.1              ← Methode, Pfad, Version
Host: 192.168.0.20          ← Header: zusätzliche Angaben
…
                            ← Leerzeile: Ende der Anfrage
```

La resposta del servidor té exactament la mateixa estructura: amb una línia d'estat, capçaleres, una línia buida i, després, el fitxer pròpiament dit:

```
HTTP/1.1 200 OK             ← Version, Statuscode, Text
Content-Type: text/html     ← Header: Art der Datei
Content-Length: 301         ← Header: Größe in Byte
                            ← Leerzeile
<!doctype html> …           ← die Datei selbst
```

:::seq
mode: text
Client-PC -> Server: GET / | Petició HTTP
Server -> Client-PC: 200 OK | index.html
Client-PC -> Server: GET /style.css | Petició HTTP
Server -> Client-PC: 200 OK | style.css
:::

## Mètodes i codis d'estat

El **mètode** indica què vol el client:

| Mètode | Significat |
|---|---|
| **GET** | obtenir un fitxer |
| **POST** | enviar dades al servidor, p. ex. un formulari emplenat |
| **HEAD** | obtenir només les capçaleres, sense el fitxer |

El **codi d'estat** indica com ha anat. El primer dígit revela el tipus de resposta:

| Codi | Text | Significat |
|---|---|---|
| **200** | OK | tot correcte |
| **301** | Moved Permanently | la pàgina s'ha mogut de manera permanent |
| **404** | Not Found | el fitxer no existeix |
| **405** | Method Not Allowed | aquest mètode no està permès aquí |
| **500** | Internal Server Error | error al servidor |

`2xx` vol dir èxit, `3xx` redirecció, `4xx` un error del client (petició incorrecta), `5xx` un error del servidor.

:::tip Idea clau
**HTTP** funciona segons el **principi de petició i resposta**: el client envia una **petició** (mètode com `GET`, camí, capçaleres), el servidor respon amb un **codi d'estat** (p. ex. `200 OK`, `404 Not Found`), capçaleres i el fitxer. Per a cada fitxer d'una pàgina web hi ha una petició pròpia.
:::

# El model de referència ISO/OSI

El model ISO/OSI divideix la comunicació entre dos dispositius en set capes. Cada capa té una tasca clarament delimitada i només utilitza els serveis de la capa immediatament inferior:

Amb l'experiment de la pàgina anterior ja coneixes quatre d'aquestes capes: Ethernet (2), IPv4 (3), TCP (4) i HTTP (7). Aquests són exactament els números i els colors que et mostra el Tracer a l'arbre de protocols.

:::tip Regla mnemotècnica
De la capa 7 cap avall: **A**lguns **P**ares **S**empre **T**ransporten **X**ocolata **E**n **F**ebrer — **A**plicació, **P**resentació, **S**essió, **T**ransport, **X**arxa, **E**nllaç de dades, **F**ísica.
:::

:::note Casos límit
No tots els protocols encaixen exactament en una sola capa. Per això, amb aquests protocols el Tracer mostra diverses capes:

- **ARP** — capa 2/3: no té capçalera IP, però vincula les adreces IP (capa 3) amb les adreces de maquinari (capa 2).
- **TLS** — capa 4/5: se situa directament sobre TCP i gestiona una sessió segura.
- **HTTPS** (HTTP dins de TLS) — capes 5–7: la capa d'aplicació clàssica del model TCP/IP, que coneixeràs a la pàgina següent.
:::

:::note
La capa 1 descriu la transmissió real del senyal pel cable o per ràdio. BeaverTracer no simula aquest nivell: els cables sempre es consideren connectats sense errors, i no hi ha ni problemes de senyal ni col·lisions. Per això, al Tracer l'anàlisi comença pràcticament a la capa 2.
:::

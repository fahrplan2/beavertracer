# Observar el NAT

## L'experiment

1. Canvia al :fa-play: mode **Executar**, fes clic al **PC** i obre `http://www.beispiel.de/` al :fa-globe: **Navegador**.
2. Al :fa-magnifying-glass: mode **Traça**, obre una traça per al **PC** i una segona per al servidor web **www.beispiel.de**.
3. Compara en les dues traces el paquet `GET / HTTP/1.1`: qui hi consta com a remitent (**Quelle**)?

:::quiz mc
Quina adreça de remitent té el `GET` a la traça del **PC**?
- [x] L'adreça privada del PC (`192.168.178.…`)
- [ ] `203.0.113.2`
- [ ] `192.0.2.80`
:::

:::quiz short
I quina adreça de remitent veu el **servidor web**?
= 203.0.113.2
:::

:::quiz mc
Quina adreça és `203.0.113.2`?
- [ ] L'adreça del servidor web
- [x] L'adreça WAN de l'encaminador domèstic
- [ ] L'adreça del DNS del proveïdor
:::

:::evaluate
Comprova les respostes
:::

## Què hi ha al darrere

L'encaminador domèstic canvia, en cada paquet que va cap a Internet, l'adreça de remitent privada per la seva pròpia **adreça WAN pública** — i normalment també el port de remitent. Per al servidor web sembla que la petició vingui de l'encaminador domèstic. Quan la resposta torna, l'encaminador domèstic torna a canviar l'adreça i fa arribar el paquet al PC.

Així, tota la xarxa domèstica pot sortir a Internet amb una sola adreça pública — i els dispositius d'Internet no veuen mai les adreces privades.

## El camí cap a Internet

Escriu al **PC**, al :fa-terminal: **Terminal**:

```
$ traceroute 192.0.2.80
```

:::quiz short
Quants encaminadors hi ha entre el PC i el servidor web? (Compta totes les línies abans de l'última.)
= 4
= quatre
:::

:::quiz mc
Quina adreça mostra `traceroute` per al primer encaminador?
- [x] `192.168.178.1` — l'adreça LAN de l'encaminador domèstic
- [ ] `203.0.113.2` — la seva adreça WAN
- [ ] `203.0.113.1` — el primer encaminador del proveïdor
:::

:::evaluate
Comprova les respostes
:::

:::tip Idea clau
El **NAT** (*Network Address Translation*) substitueix, en el camí cap a Internet, l'adreça de remitent **privada** d'un dispositiu per l'**adreça WAN pública** de l'encaminador — i en les respostes, al revés. Així, tots els dispositius de la xarxa domèstica comparteixen **una** única adreça IPv4 pública. Això estalvia adreces i amaga les adreces privades d'Internet.
:::

# Resolució de problemes: el nom no funciona

:::sim
url=/sims/lesson-6.2.3.btsim
:::

Una professora informa: «`www.beaver-schule.de` no em carrega. Però amb `http://192.168.0.20` sí que funciona!» Així *hauria* d'estar configurat:

| Què | Valor esperat |
|---|---|
| Servidor DNS al Client-PC | `192.168.0.53` (DNS-Resolver) |
| Entrada al Schul-DNS | `www.beaver-schule.de` → `192.168.0.20` |

Troba els errors i soluciona'ls.

<details>
<summary>Pista 1: Què diu nslookup?</summary>

Introdueix `nslookup www.beaver-schule.de` al Client-PC. A quin servidor ha preguntat `nslookup` — i què ha retornat? (La resposta triga uns segons.)
</details>

<details>
<summary>Pista 2: I ara què?</summary>

Si reps una resposta, compara l'adreça amb el pla. On està registrat aquest nom?
</details>

:::task
title: Resolució de noms reparada?
Comprova si el Client-PC resol www.beaver-schule.de a l'adreça correcta. Per això, la simulació ha d'estar en execució en mode d'execució.
check: resolves(2, "www.beaver-schule.de", "192.168.0.20")
:::

## Què passava?

:::quiz multi
Quines afirmacions són correctes?
- [x] Al Client-PC hi havia configurat `192.168.0.35` com a servidor DNS — allà no respon ningú
- [x] Al Schul-DNS, `www.beaver-schule.de` apuntava a `192.168.0.21` en lloc de `192.168.0.20`
- [ ] El servidor web estava apagat
- [ ] El servidor arrel no coneixia el domini `.de`
:::

:::evaluate
Comprova la resposta
:::

:::tip Idea clau
Si una connexió funciona amb l'**adreça IP** però no amb el **nom**, el problema és al **DNS**. Comprova primer el **servidor DNS configurat** (respon realment?) i després l'**entrada** en si (l'adreça és correcta?). `nslookup` mostra totes dues coses: a quin servidor s'ha preguntat i què ha respost.
:::

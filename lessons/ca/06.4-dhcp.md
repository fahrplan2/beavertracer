# DHCP: entrar a la xarxa automàticament

:::goal
**Objectiu d'aprenentatge:** Pots explicar com un dispositiu obté automàticament la seva configuració IP mitjançant DHCP, configurar un servidor DHCP i reconèixer i solucionar errors típics de DHCP (p. ex., una adreça 169.254).
:::

:::sim
url=/sims/lesson-6.4.btsim
:::

Fins ara has introduït a mà, a cada dispositiu, l'adreça IP, la màscara de xarxa, la passarel·la i el servidor DNS. En una escola amb centenars de portàtils, tauletes i mòbils això seria impossible, i cada error de teclat seria un error a la xarxa.

Aquesta feina la fa el **Dynamic Host Configuration Protocol** (**DHCP**): un **servidor DHCP** distribueix automàticament la configuració a cada dispositiu que entra a la xarxa.

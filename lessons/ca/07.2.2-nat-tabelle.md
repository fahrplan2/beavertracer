# La taula NAT

:::sim
url=/sims/lesson-7.1.btsim
:::

Quan el PC i la tauleta carreguen alhora la mateixa pàgina web, les dues sol·licituds arriben al servidor web des de `203.0.113.2`. Com sap l'encaminador domèstic a qui va dirigida una resposta? Ho anota tot — a la **taula NAT**.

## L'experiment

1. Canvia al mode d'execució :fa-play: **Executar** i obre `http://www.beispiel.de/` tant al **PC** com a la **Tablet**.
2. Fes clic a l'**Heimrouter** i obre la pestanya **NAT**.

Cada fila és una **assignació**: protocol, IP LAN i port LAN del dispositiu de la xarxa domèstica — i el **port WAN** que l'encaminador utilitza per a aquesta connexió a la seva adreça pública.

:::quiz short
Quina IP WAN apareix a sobre de la taula?
= 203.0.113.2
:::

:::quiz mc
El PC i la tauleta han establert tots dos una connexió amb el port LAN `49152`. Quin port WAN obtenen?
- [ ] Tots dos el mateix, `49152`
- [x] Cadascun un de diferent — si no, l'encaminador no sabria a qui pertany la resposta
- [ ] Cap, NAT només canvia l'adreça IP
:::

:::quiz mc
Una resposta del servidor web arriba a `203.0.113.2` amb un **port de destinació** determinat. Què en fa l'encaminador domèstic?
- [x] Busca el port a la taula NAT i envia el paquet a la IP LAN i al port LAN corresponents
- [ ] Envia el paquet a tots els dispositius de la xarxa domèstica
- [ ] Descarta el paquet
:::

:::evaluate
Comprovar les respostes
:::

Aquí tornen a entrar en joc els **ports** del capítol 5: com que NAT també reescriu els ports, centenars de connexions poden compartir una sola adreça. Estrictament parlant, per això s'anomena **PAT** (*Port Address Translation*) o *NAT amb traducció de ports* — però en el dia a dia tothom diu simplement NAT.

Així podria ser, per exemple, una traducció d'aquest tipus:

| | Paquet del PC (a la xarxa domèstica) | el mateix paquet a Internet |
|---|---|---|
| Remitent | `192.168.178.20 : 49152` | `203.0.113.2 : 10001` |
| Receptor | `192.0.2.80 : 80` | `192.0.2.80 : 80` |

:::tip Idea clau
A la **taula NAT**, l'encaminador recorda per a cada connexió quin dispositiu (**IP LAN i port LAN**) hi ha darrere de quin **port WAN**. Les respostes d'Internet les torna a assignar al dispositiu correcte mitjançant el port de destinació. Com que també es reescriuen els ports, es parla més exactament de **PAT**.
:::
